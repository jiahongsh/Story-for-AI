## 2.6 二次觉醒

二次觉醒不得写成“情绪足够强就突然开技能”。

- 自我连续性仍成立；
- 原有能力面对无法解决的存在边界问题；
- 新结构与个体适配；
- 现实验证。

重大情感事件只能提供压力和转折，不能单独构成觉醒条件。

# 三、正文写作长期规则

## 3.1 字数

- 单章字数**以对应封板细纲的字数目标为准**。
- 不再使用旧的“全书统一2000-2200字”记忆覆盖细纲。
- 第一卷当前封板细纲多数目标约3000-3300字，具体章节服从各自细纲。
- 内容不够成章时宁可在细纲阶段调整事件块，不靠空转剧情凑字数。

## 3.2 对话

- 禁止流水账式“他说/她说/XX说”连续标签。
- 对话归属优先靠动作、神态、场景焦点和上下文建立。
- 台词之间必须允许动作、观察、心理、环境与信息差进入，不写纯乒乓对话。
- 对话承担潜台词和关系变化，不把人物写成设定播报器。

## 3.3 指代与段落

- 不连续堆叠“他/她/它”。
- 换叙述焦点时优先用名字重新锚定。
- 段首优先用人物名、动作、场景或时间词引领，不让大量新段都以代词开头。
- 连续动作可以省略主语，但不能用代词堆叠代替清晰指代。

## 3.4 设定服务故事

- 所有世界观、力量、市场、势力和数值都必须推动当前冲突或人物选择。
- 禁止百科式设定展示。
- 每次准备写设定前先问：**这个信息在本章推动什么？** 推动不了就不写。
- 城市身份恐怖必须持续落回家庭、医院、社区、工作、旧市场、钟表行、身份系统等具体生活场景。
