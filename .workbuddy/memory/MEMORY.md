### 对话对白写法铁律(2026-08-19 用户批评"流水账"后立规,对标异兽迷城第1-3章原文)
**病根**:近七成行是"XX说"标签,每句对话独立成行,对话之间无动作/神态/停顿——乒乓对打,不是对话。
**零标签硬规则(2026-08-19 用户升级)**:**"他说/她说/XX说"这类说话标签一句都不许出现**——不是降低占比,是零容忍。对话归属一律靠以下手段表达:动作标签(老者把表放下:"...")、神态标签(她眼圈红了:"...")、或干脆不标(双人对话靠上下文,读者不会分不清)。台词必须嵌进动作/段落里流淌。
**六条铁律(每条都对标异兽迷城原文实例)**:
1. **对话嵌进段落**:动作+台词+心理在一段里流淌(异兽:『高阳微笑着走过去,"不好意思,来晚了。"』);不得每句对话单独成行+标签。
2. **说话标签零容忍**:『青灵看也不看高阳:"什么都别问,立刻回家。"』『李薇薇一愣,眨眼道:』——用动作/神态替代"XX说";短对话干脆不标(靠上下文判断谁说)。
3. **对话之间穿插观察/心理/回忆**:两段对话之间必须有叙述推进(异兽第2章高阳问"你奶奶遗体见过吗"中间穿插院长葬礼回忆);对话是叙事长河里的礁石。
4. **台词不直给,藏信息差/潜台词**:异兽『"你说的手,是这种吗?"』一句反转全场;角色各知一半,读者自行拼图;"谁在说谎"比"发生了什么"更吊人。
5. **重复台词立气场**:『"再说。""再说。""再说。"』青灵三段复读立掌控力;重复=掌控力。
6. **打断与欲言又止**:『"其实……""啊!算了,别说了……"』话到一半被打断,留白;不得每句对话都完整你来我往。
**自查标准**:写完后 grep 一遍"XX说"标签,命中数必须为 0;90-100 章已全部回炉清零(2026-08-19)。

### 代词使用铁律(2026-08-19 用户立规)
- **"他/她/它"不可连续重复**——代词密集堆叠产生"糊指代"流水感。
- 对照:异兽迷城第2章名字"高阳"50次/代词"他"18次(名字是代词2.8倍);本书92章"镜辞"3次/"他"126次(代词是名字42倍)——必须翻转。
- 用法:①指代主角/核心角色优先用名字(镜辞/守钟人/芽),不躲着用"他";②换叙述焦点时必用名字锚定(异兽:『李薇薇走在前面。走着走着,她忽然转过身来』——首用名字,句内才用代词);③省主语优于堆代词——连续动作可无主语承接,但省略≠代词堆叠。
- **段首节奏铁律(最根本)**:异兽迷城第1章77行,行首"高阳"11次/"他"仅8次,58行是场景词/时间词开头。**名字或场景词领每一段,段内才用代词;行首"他/她"只承接不引领**。
- **"他/她/它"三个字一视同仁(用户追问"她和它呢"后补)**:"她"(芽/沈竹)与"他"同法,段首→名字锚定(『她讲得那么仔细』→『芽讲得那么仔细』)、句内堆叠→省主语;"它"(怀表/光)是物指代无替代词,单次保留,同一物反复出现时与名词错落(『它是一道光…光在发抖…那道光的边缘』)。
- 自查:任意连续5个自然段,代词"他/她/它"≤4次;段落内"他/她"连续≥3次必须改;**单行"他"或"她"≥3 必须清零**;**段首"他/她"开头的新段必须改**(用名字/场景词领段)。
- 已落盘到 `他们不是人/设定/题材正文提示卡.md`(每章写作前必读的实际约束)。
