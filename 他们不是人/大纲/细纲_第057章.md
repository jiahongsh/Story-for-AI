# 细纲 · 第57章 谁听过这句话

## 第 57 章：谁听过这句话
- **核心事件**：镜辞继续暂停现场，由康宁巷物业在住户自愿前提下做一次极小范围“暴露来源回访”：只询问几名已经主动提到“婚姻关系存续/家庭成员恢复”类似表述的人，他们从哪里听到这层意思。结果大多数都能找到普通传播路径：有人看过APP通知，有人接过客服电话，有人听物业人员复述，有人只是听邻居转述后换了自己的说法。一个起初看似“没看过通知”的老人，最后也在门口监控里被确认曾听见儿子照着客服短信念过。章尾，七个样本只剩一个无法立刻解释：一名保洁阿姨在新版通知下发前一天，就在值班交接本上写过几乎相同的句子。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段3；第57章；统一口径传播调查
- **单元ID/位置**：1-4；第17拍·大部分怪话其实有普通来源
- **目标情绪**：像集体复述 → 一个个找到来源 → 超自然感反而下降 → 主角获得方法信心 → 最后留下真正需要解释的一条
- **主角目标/关键选择**：镜辞想找“没接触过统一话术却复述它的人”；关键选择=接受大部分样本被普通传播解释掉，不为了让案件更玄硬保留错误异常
- **章节定位**：排除法+信息素养；让调查可信度建立在愿意推翻自己猜测上
- **本章结构公式**：节点1（定义最小回访问题） + 节点2（通知暴露） + 节点3（客服暴露） + 节点4（邻居二手传播） + 节点5（老人看似无暴露→监控还原） + 节点6（交接本提前一天出现同句）
- **章首钩子**：康宁巷物业一共找到七个说过类似“关系还在，所以权限该恢复”的人。镜辞先在纸上画了七个圈，然后在每个圈后只写一个问题：`这句话第一次从哪听来的？`
- **本章即时兑现**：第56章提出“先查谁看过、谁没看过”被实际执行；多数统一语言被证明可以由普通传播造成
- **本章禁止提前释放**：保洁交接本句子的真正来源、群体记忆同步、裂缝介入、幕后组织
- **能力边界**：镜辞不到场，不用镜返；所有结论基于自述、消息记录、值班记录和公共区域合法监控
- **契约风险**：契约安全。居民不是实验对象，只回访已经主动参与物业争议且愿意说明信息来源的人

#### 内容概括（五段式）
- **起因**：康宁巷物业经理担心整栋楼都被当成“异常样本”，所以只联系七名已经在前几天主动讨论过关系恢复的住户/工作人员。回访不问“你是不是被影响”，只问第一次从哪里听到相关说法。
- **发展**：第一人直接看过住户APP；第二人接过客服；第三人没看APP，却在物业办公室听工作人员照模板解释；第四人只是回家后听配偶转述。猫眼把每一种传播都画成箭头，几句话很快从一个上游模板长成几十种自然说法。
- **转折**：最像异常的是一位不用智能手机的老住户。他坚持没看通知、没接客服，却说过“人还是一家人，系统把权限恢复就对了”。一开始所有人都以为找到例外。物业回看公共门厅录像，发现前一晚他儿子在门口等电梯时正照着短信念“婚姻关系存续，家庭成员恢复”，老人就在旁边。
- **高潮**：镜辞把这个“例外”划掉。他没有失望，反而更确定调查不能靠气氛。七个圈里六个已经有传播路径。最后一个来自物业保洁阿姨，她不是因为今天说了什么，而是值班交接本里有一句旧记录：`这家婚姻关系还在，家庭成员应该恢复。` 日期比新版客服模板公开上线早一天。
- **结尾**：保洁阿姨已经下班，暂时联系不上。猫眼先核交接本纸张、书写顺序和拍照备份，确认不是后来补写。镜辞只把最后一个圈留白：`她从哪听来的？` 这一次，真正值得追的不是“大家为什么说一样”，而是“这句话最早从哪里冒出来”。

#### 情节安排（多线）
- **主线推进**：统一话术的居民传播大部分被现实渠道解释，只剩一个时间上早于公开模板的来源
- **辅线推进**：镜辞形成“异常越查越少也不是失败”的调查心态
- **事件线/任务线**：列样本 → 追首次暴露 → 找普通传播 → 排伪例外 → 锁交接本时间差
- **任务卡点**：人人说法相似看似超自然 → 一项项还原普通传播 → 只保留真正无法解释的最小剩余
- **感情线/关系线**：康宁巷物业主动保护住户隐私和声誉，不愿让所有人被当怪物，显示普通机构也有自己的伦理判断
- **逻辑线**：上游统一文字 → 多现实传播渠道 → 居民复述 → 绝大多数可解释 → 一条记录早于公开模板

#### 人物关系和出场顺序
- **出场顺序**：镜辞/猫眼（远程整理） → 康宁巷物业 → 若干匿名住户/工作人员 → 保洁阿姨（仅交接本）
- **人物关系变化**：镜辞越来越能接受“删掉自己的异常猜测”本身就是进展
- **视角/信息差**：读者知道保洁记录早一天，但还不知道这一天差异来自内部提前培训、试点版本还是别的东西
