# 《他们不是人》八卷力量体系读者揭露节奏表

> **性质：力量体系叙事执行硬约束。**
>
> 本文件不新增一套能力规则。底层因果服从 `设定/世界观/力量体系.md`，数值服从 `设定/世界观/数值定稿.md`，觉醒/进阶服从 `设定/世界观/刻痕觉醒与进阶机制.md`，具体角色成长服从 `全书能力成长与刻痕角色槽位表.md`。
>
> 本文件只解决一个问题：
>
> **作者后台知道完整体系，不等于读者第一卷就应该收到完整说明书。**
>
> 力量体系必须随着故事认知一起展开。读者先看见现象，再知道名字；先看到代价，再知道资源；先见到不同专业者，再理解六大门类；先见到“高阶能做到什么”，再知道为什么高阶稀少。

# 一、总原则：力量体系必须从悬疑中长出来

正文揭露顺序固定为：

```text
异常现象
↓
角色发现可以重复
↓
某个能力得到生活化名称
↓
代价出现
↓
遇到其他专业者，知道自己不是唯一例外
↓
机构为了协作才建立门类/阶位语言
↓
高阶角色暴露“能力越深，边界越重要”
↓
终局证明力量只是干涉关系的工具，不是身份裁判权
```

禁止顺序：

```text
第一卷开会
↓
六系介绍
↓
五品介绍
↓
九阶介绍
↓
EX/SEE/MEM/WIL/EMP五属性面板
↓
读者开始怀疑自己是不是误点进了游戏Wiki
```

# 二、作者后台 / 机构术语 / 正文常用语言必须分开

## 1. 作者后台始终可用

作者规划阶段可以完整使用：
- 刻痕1-9阶；
- 天赋品级；
- EX / SEE / MEM / WIL / EMP；
- 六大门类；
- 壳Lv；
- 镜返五式；
- 裂隙压；
- 具体技能消耗与识破门槛。

这些是作者控制一致性的工具。

## 2. 机构内部可以使用，但必须符合职业语境

剥壳人、白塔、守夜人可以说：
- “这个真视者大概三阶”；
- “他现在不适合继续透支”；
- “接口污染在上升”；
- “这是镇封方向，不负责身份判断”。

但机构人员也不应该人人像百科词条一样准确报全套面板。

## 3. 正文日常语言优先

普通人和多数剧情段优先写：
- “他今天已经用了两次，再来一次可能撑不住”；
- “她能看见记忆里有东西被反复调用，但不知道哪段是真的”；
- “那个人能封住楼梯口，却看不出里面谁有问题”；
- “镜辞看得出来，但打不过。”

**效果先于术语。**

# 三、第一卷：力量首先是一种恐怖，不是一套职业体系

## 章节范围：001-100

### 读者应该知道

第一卷只需要逐步确认：

1. 镜辞能通过镜面/镜返看见某种普通人看不见的身份错位；
2. 这种能力不是万能真相，它只提示“对不上”；
3. 有些异常对象也能影响记忆、关系与现实记录；
4. 守钟人显然掌握另一套异常经验，证明世界不只有镜辞；
5. 使用更深异常观察会有代价，但不急着量化成数字；
6. “壳”和“裂缝”可以作为事件概念出现，但壳等级和六系体系暂不展开。

### 正文允许出现的正式术语

- 接缝；
- 壳（在世界认知达到相应阶段后）；
- 裂缝/裂隙；
- 镜返；
- 第一式·看见接缝，名称可以在镜辞确认能力结构后逐步稳定。

### 第一卷不建议正式讲透

- 六大门类完整名称；
- 1-9阶完整等级表；
- 凡/良/异/绝/禁忌五品级；
- EX / SEE / MEM / WIL / EMP具体数值；
- 壳Lv完整等级表；
- 二次觉醒理论；
- 镜返后四式名称清单。

### 第一卷能力戏的正确写法

> 镜辞先通过现实证据怀疑 → 镜面只提供一个额外异常 → 他必须继续查。

禁止：

> 镜辞开镜返扫描 → 系统弹出“Lv.2壳，记忆完整度87%”。

### 第一卷结束时读者的力量认知

> **这个世界确实存在可以干涉身份/记忆/关系的异常能力，但任何一种观察都只是证据的一部分。**

这和第一卷认知“我看见，不等于我知道”完全一致。

# 四、第二卷：第一次知道“异常能力已经职业化”

## 章节范围：101-200

第二卷镜辞进入剥壳人工作体系，力量世界才第一次从私人怪事变成职业生态。

### 本卷新增读者认知

1. 人类确实存在稳定刻痕者；
2. 刻痕可以主动调用，不全是镜辞这种特殊个例；
3. 不同能力解决不同问题，存在职业分工；
4. “看见异常”“打穿异常”“处理记忆”“封锁现场”不是一件事；
5. 刻痕者有大致阶位概念，但正文只需要让读者知道1-3阶是常见职业层；
6. 普通专业人员仍然大量存在，而且能决定案件成败。

### 本卷首次适合使用的术语

- **刻痕**：正式成为通用名；
- **刻痕阶位**：可以通过工作对话自然出现，但不安排完整九阶讲课；
- 真视 / 腐蚀 / 蚀忆等门类名称可逐个随具体人物出现，不要求一次讲齐六系；
- EX可以作为机构内部“存在稳定”评估概念第一次出现，但优先描述症状和风险，不频繁报数。

### 镜辞能力推进

- 刻痕约2阶；
- **第二式·照真身**稳定解锁；
- 它能让异常结构更清楚，但不能决定原主生死/伦理处置。

### 建议出现的能力生态

- 1名3阶左右腐蚀执行者或一次性专业者；
- 1名记忆污染处理者可以弱出场；
- 1名环境真视者可暂缓到V3；
- 至少一半重要工作由无刻痕人物完成。

### 本卷力量主题

> **能力越专业，越需要程序限制它的使用范围。**

# 五、第三卷：世界第一次出现成熟职业者

## 章节范围：201-300

旧港、守夜人和大规模裂缝现场让读者第一次看到“主角之外已经工作很多年的高阶体系”。

### 本卷新增读者认知

1. 守夜人有成熟镇封职业；
2. 5-6阶角色可以直接作为工作十几年的老手登场，不必陪主角从1阶升级；
3. 同一门类内部能力也完全不同；
4. 刻痕越高，不是单纯威力越大，而是能处理更多节点、更深结构；
5. 高阶仍需要普通撤离、地形、设备与团队配合。

### 六大门类揭露进度

到V3结束，可以让读者自然知道大部分门类名称：
- 真视；
- 腐蚀；
- 镇封；
- 蚀忆；
- 摹刻/铭刻可以只知道其一或只作为模糊专业方向出现。

仍不需要用一章一次讲完“六系百科”。

### 镜辞突破

- 刻痕约3阶；
- **铭心**在顾横死亡余波中形成；
- 先写“镜辞已经在用顾横留下的判断”，再让能力稳定；
- 明确铭心不能复制超自然天赋。

### 守钟人展示方式

读者第一次比较清楚看到：
- 时间错位感知；
- 定界/镇封；
- 他大约属于明显高于镜辞的成熟职业层。

但不安排“守钟人属性面板”。

### 本卷力量主题

> **真正成熟的能力不是能做更多，而是知道什么时候不能做。**

# 六、第四卷：完整力量体系第一次可以被读者理解

## 章节范围：301-400

白塔是最合适的体系化窗口，因为这里本来就有医疗、研究、刻痕记录与受控诱导。

### 到本卷可以正式讲清

1. 人类侧六大门类全部存在；
2. 1-9阶是干涉深度，不是战斗力排名；
3. 天赋品级和阶位不是一回事；
4. 多数人只有一个主天赋；
5. 二次觉醒极少，不是等级奖励；
6. 刻痕来自裂缝接触 + 自我连续 + 有效干涉 + 结构适配 + 稳定；
7. 白塔可以提高觉醒/稳定概率，但不能指定能力量产超凡者。

### 但讲解必须被病例承载

例如：
- 一个绝品潜力的年轻患者只有2阶，仍不如一个良品5阶老手稳定；
- 一名高阶真视者明确说自己不能判断“这个人是不是坏人”；
- 一名镇封者能封区域，却完全不知道区域内身份真假。

用人物和病例证明体系，禁止连续数页教材台词。

### 镜辞

- 3→4阶；
- **第三式·强制现形**解锁；
- 必须依赖已经确认的真实关系证据；
- 首次出现壳侧结构模拟失控的边角。

### EX/EMP揭露

本卷可以把EX和EMP作为白塔/机构医疗评估语言正式讲清：
- EX是当前存在稳定，不是经验；
- EMP是空化/接口污染风险轴之一；
- EX恢复不等于断裂关系复原。

正文仍然不需要每次战斗报“EX剩余67”。

### 本卷力量主题

> **技术越能精确测量一个人，就越要区分“测到了什么”和“有权决定什么”。**

# 七、第五卷：停止扩张技能表，开始展示“同一个能力能走多深”

## 章节范围：401-500

这一卷不应该靠镜辞新式维持爽感。

### 镜辞

- 刻痕保持约4阶；
- 镜返不新增新式；
- 学会更稳定控制**模拟A·忆序扰动**；
- 重点展示熟练度、代价管理和错误判断，而不是升级。

### 姜霁正式觉醒

- **记忆差分·蚀忆系·异品**；
- 从1阶开始；
- 她先靠多年人的方法完成姜父识别，事件余波后才觉醒；
- 觉醒不能把她之前四卷的专业能力贬成“没超能力所以不完整”。

### 修复师 / 白壳出现后读者理解

- 摹刻系与壳的复制不是一回事；
- 人类摹刻者可以模仿结构，但仍不能复制关系锚点；
- 白壳最危险的不是“会模仿”，而是它能借壳侧身份结构长期接管社会位置。

### MEM/WIL/SEE如何处理

这些可以继续主要留作者后台。

如果正文需要表达镜辞积累：
- 写他能处理更复杂关系；
- 写他能够承受更深镜返；
- 写过去方法开始自动进入判断。

不要让角色互相讨论“我的MEM到60了”。

### 本卷力量主题

> **能力数值越成熟，越不能替人物做判断。**

# 八、第六卷：力量开始服务“保护未知”，而不是更强识破

## 章节范围：501-600

### 镜辞

- 刻痕约5阶；
- 解锁**第四式·遗忘领域**；
- 掌握**模拟B·裂蚀放大**。

第四式的叙事感必须与前三式不同：

前三式都偏向：
> 看得更清楚。

第四式第一次是：
> **主动制造一段“暂时不要被世界稳定命名”的空间。**

它适合：
- 撤离；
- 反追踪；
- 保护新主体；
- 暂停身份锁定。

不能：
- 群体洗脑；
- 让敌人永久失忆；
- 修改数据库。

### 白壳

白壳的主体成长不能伴随“获得新强力技能”。

它真正的成长是：

```text
自动按原主模板
→ 发现偏差
→ 害怕偏差
→ 主动保留偏差
→ 用自己的选择影响别人
```

能力越少抢主题越好。

### 专业能力生态

- 摹刻专业者正式成为白壳对照；
- 铭刻者开始显示“保护已有关系”的作用；
- 镇封仍是现场重要力量。

### 本卷力量主题

> **有时最强的保护不是把身份看得更清楚，而是暂时阻止别人替他下结论。**

---

# 九、第七卷：力量从“个人技能”转向“网络协作”

## 章节范围：601-700

到这一卷，读者已经知道完整力量规则，不应再用新门类制造新鲜感。

### 镜辞

- 6→7阶成熟突破；
- 掌握**模拟C·拟相回声**；
- 三种壳侧模拟形成有限工具箱，但绝不等于获得三门永久天赋。

### 守钟人

- 可完成6→7阶；
- 突破来自守界伦理改变，不是增加封锁面积。

### 姜霁

- 约4→5阶；
- 记忆差分进入跨年份、多来源重建；
- 能力更加专业，而不是开始攻击记忆。

### 高阶角色的功能开始系统化

- 镇封：断裂隙节点；
- 铭刻：保住多个真实版本；
- 真视：找结构与流向；
- 蚀忆：隔离污染；
- 腐蚀：拆已经确认的异常支撑点；
- 摹刻：潜入/模拟接口。

没有任何一系能单独解决“唯一指向”。

### 本卷禁止

- 新增第三个镜辞永久天赋；
- 突然出现8-9阶新人物替主角解题；
- 把高阶等同战斗破坏力；
- 用能力直接让左衡/修复师/壳王承认错误。

### 本卷力量主题

> **当问题已经是网络，没有一个技能还能负责全部答案。**

# 十、第八卷：不再扩能力，只完成前七卷所有能力的分工结算

## 章节范围：701-800

第八卷是能力体系验收，不是DLC。

### 镜辞

- 只允许一次正式7→8阶；
- 终局开放**第五式·记忆归还**；
- 不到9阶；
- 不新增第六式；
- 不临时获得“全城扫描”“复活”“重写世界”等能力。

### 第五式真正能做什么

只重新暴露：

> **现实里本来就仍有承接点，却被唯一指向压平、截留或错配的关系因果。**

所以它必须依赖前七卷实际存在的：
- 小人物记忆；
- 纸档；
- 离线记录；
- 真实生活习惯；
- 家庭选择；
- 后来新形成的关系；
- 不同机构保存的独立版本。

没有承接点，镜辞不能凭空创造。

### 终局能力分工

| 环节 | 主要力量/人物 | 不能做什么 |
|---|---|---|
| 找异常源/错位 | 真视、镜返、环境真视者 | 不能判社会身份 |
| 切裂隙传播 | 守夜人镇封体系 | 不能恢复记录 |
| 隔离群体记忆污染 | 蚀忆专业者、姜霁差分 | 不能创造正确记忆 |
| 保住多版本关系 | 铭刻体系、普通现实见证 | 不能把证词变真 |
| 拆异常节点 | 腐蚀执行者 | 不能在未知目标上随便使用 |
| 潜入/骗接口 | 摹刻/镜辞模拟C | 不能骗真实关系 |
| 重新暴露被压关系 | 第五式·记忆归还 | 不能替世界选唯一真身 |
| 恢复社会生活 | 医疗、社区、物业、警务、家属 | 不能靠异能一键完成 |

### 本卷力量主题

> **最强能力最终不是替世界回答“谁是谁”，而是把被压住的回答权重新交还给很多独立的人。**

# 十一、六大门类的读者出场顺序建议

> 不是硬性“第几章第一次说名字”，但必须控制认知负荷。

| 门类 | 最晚应让读者真正理解 | 最合适的第一印象 |
|---|---|---|
| 真视 | V2 | 看见异常，但不能判断动机 |
| 腐蚀 | V2-V3 | 负责打已经确认的裂隙弱点 |
| 镇封 | V3 | 守住边界，不等于解决边界里的问题 |
| 蚀忆 | V3-V4 | 操作记忆结构，不等于知道记忆真假 |
| 摹刻 | V4-V5 | 会模仿结构，不等于继承身份 |
| 铭刻 | V3铭心先出现，V4-V6理解完整门类 | 保护已有关系，绝不创造关系 |

这样六系不是一口气告诉读者，而是每一系都先有“一个会做具体工作的人”。

# 十二、壳侧力量揭露节奏

壳的Lv体系同样不能第一卷一次说明。

## V1

读者只感受到：
- 有的壳只能模仿一个人；
- 有的壳已经能影响证人版本；
- “强”表现为更难识破，而不是更会打。

## V2

机构内部开始用低阶/中阶/Lv作工作分类。

读者理解：
> 壳等级主要代表它能把身份错位维持到什么深度。

## V3-V4

出现：
- 环境裂隙；
- 记忆操纵；
- 高阶身份结构；
- 领域级影响。

## V5-V6

出现：
- 完美复制；
- 多身份支撑；
- 修复师工程化关系维护；
- 白壳高质量拟魂。

## V7

源隙层正式成为可理解概念：
> 某些高阶壳已经能主动制造局部开放争议位，而不是只等待机会。

## V8

壳王的大规模身份归并是壳侧能力的终点，但必须依赖四条社会/技术链，不能写成它一个人的超能力领域覆盖城市。

# 十三、每场异能冲突的六步结构

为了防止后期战斗退化成技能对轰，重要冲突优先满足以下结构：

### 1. 现实目标

先回答：
> 这场行动到底要救谁、保什么、拿什么证据、关哪个节点？

### 2. 识破

谁负责发现问题？

可能是镜辞，也可能是其他真视者、普通证据或环境观察。

### 3. 定位与验证

异常发生在哪里？有没有独立现实证据支持？

### 4. 专业处理

腐蚀、镇封、蚀忆、摹刻、铭刻各自只处理自己的部分。

### 5. 代价

EX、EMP、伤势、现实权限、关系损伤、失败撤离至少有一项具体代价。

### 6. 余波

战斗结束后：
- 家属怎么办；
- 记录怎么办；
- 误伤怎么办；
- 这个地方之后怎么生活。

如果一场重要异能战打完以后现实世界完全没变化，这场战斗大概率只是烟花。

# 十四、力量体系与小人物系统的接口

能力越强，小人物越不能失去价值。

正式硬锁：

1. **镜辞负责暴露异常，不负责生成现实证据。**
2. **姜霁负责差分，不负责决定家庭关系。**
3. **镇封者负责挡裂缝，不负责决定撤离名单里谁值得救。**
4. **蚀忆者能处理污染，不负责宣布哪段人生是真的。**
5. **铭刻者能保护已有关系，不负责创造关系。**
6. **普通人可以没有任何刻痕，却掌握不可替代的长期生活事实。**
7. **第八卷第五式必须依赖前七卷普通人已经保存的关系承接点。**

因此，力量体系越到后期越应该证明：

> **超能力只能干涉现实，不能代替现实本身。**

# 十五、能力角色实例化上限

为了控制读者认知负担：

- 单卷首次需要读者记住的“新能力人物”建议不超过3-4名；
- 同一场战斗中同时主动展示的独立天赋原则上不超过4种；
- 同一章节原则上不第一次介绍两个以上完整能力规则；
- 新能力如果只用一次，不必命名成华丽专属技；
- 只有跨案件反复出现、会影响人物关系或方法论的能力，才值得正式命名和建卡。

# 十六、正文反游戏化硬锁

以下写法默认需要压缩或改写：

- 高频报当前EX数值；
- 连续出现“XX阶压制XX阶”；
- 角色见面互报品级；
- 每升一阶自动获得新技能；
- 技能冷却秒数成为战斗主叙事；
- 壳Lv直接等于战斗力；
- 六系形成固定坦克/输出/奶妈职业；
- 主角因为MEM达到阈值就当场收到系统提示；
- 觉醒时脑内弹出技能名称和说明；
- 第八卷靠“8阶数值大于敌人”解决终局。

后台可以精确，正文必须自然。

# 十八、最终验收

写到第八卷时，读者应当能够自然理解：

- 为什么镜辞能看出身份错位，却不能一个人判案；
- 为什么姜霁没能力的前四卷仍不可替代；
- 为什么顾横无刻痕仍能改变整个行动体系；
- 为什么守钟人很强，却从来不是万能导师；
- 为什么一个5阶专业者可能比一个天赋更稀有的低阶角色更可靠；
- 为什么白壳形成自己的存在锚点不等于获得人类EX；
- 为什么第八卷不需要所有人突然升到8-9阶；
- 为什么第五式必须依赖普通人留下的关系与版本。

如果读者最终只能记住“镜辞有五招，最后第五招最强”，力量体系就失败了。

真正应该留下的是：

> **越深入存在规则，越没有哪一种力量有资格替别人决定他是谁。**
