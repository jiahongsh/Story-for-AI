# 细纲 · 第52章 一条时间线

## 第 52 章：一条时间线
- **核心事件**：真正陈骁回临江后，陈启明和陈骁授权物业导出仅属于“陈骁”账户的门禁历史。猫眼不碰整栋楼后台，只把这份住户自有记录与陈骁自愿提供的宁州考勤、维修工单、收费单时间进行对照。结果出现多处不可能重叠：同一个“陈骁”在临江刷门禁的几分钟后，宁州系统里又完成签工、结算或监控留痕。单个系统内部都自洽，只有把两个来源放在一起才出现矛盾。更诡异的是，安平里新系统没有保留“两个载体”的痕迹，而是把所有事件平滑排列成一个人的连续历史。章尾，猫眼发现同一套住户关系同步服务还部署在另外三处老旧小区。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段3；第52章；中点后信息层升级
- **单元ID/位置**：1-4；第12拍·局部正确，整体不可能
- **目标情绪**：整理记录 → 单条都合理 → 跨来源出现同时存在 → 一条身份时间线吞掉两个载体 → 风险扩散到多楼栋
- **主角目标/关键选择**：镜辞想知道系统如何处理两个陈骁留下的行为；关键选择=只比较当事人授权的最小必要记录，不把“查清真相”当成无限读取隐私的通行证
- **章节定位**：信息恐怖+调查方法；第一次完整展示“每条记录都可能是真的，拼在一起却不可能属于同一个人”
- **本章结构公式**：节点1（导出单账户门禁历史） + 节点2（陈骁提供宁州最小记录） + 节点3（跨城时间重叠） + 节点4（单系统均未报警） + 节点5（历史被平滑并成一条线） + 节点6（同服务部署到其他小区）
- **章首钩子**：陈骁把手机和物业打印的门禁记录摊在一张桌上：“这一条我在宁州给人换变速箱，这一条我在临江进了我爸家。系统觉得我会分身？”
- **本章即时兑现**：第51章“一个账户塞进两个人的行为”从直觉升级为跨来源可验证矛盾
- **本章禁止提前释放**：谁在主动合并两套人生、身份归并/唯一指向术语、白塔/壳巢、系统如何实现跨载体认证
- **能力边界**：本章无需镜返；信息矛盾可以独立于超自然感知成立
- **契约风险**：契约安全。跨城证据必须有独立来源，不写成“猫眼一查后台就知道全部”

#### 内容概括（五段式）
- **起因**：陈启明和陈骁向物业提出查看自己账户的门禁历史。物业只导出502这一户相关记录，不带其他住户数据。猫眼拿到的也只是他们主动提供的副本。她先要求陈骁把“我那几天在宁州”拆成能够独立核的时间点，而不是一句口头证明。
- **发展**：陈骁挑了几条不涉及客户隐私的记录：汽修厂考勤、自己经手的一张维修工单、午饭支付时间、当天收工签字。每条都只能证明一个小事实。和临江门禁时间一叠，第一处硬矛盾出现：上午十点十七分“陈骁”刷入安平里，十点十九分宁州汽修厂工单上又有陈骁现场签字，两地相隔数百公里。
- **转折**：后面还有两组类似重叠。更怪的是，无论安平里门禁还是宁州汽修系统，各自看都没有错误。前者认为陈骁正常进出，后者认为陈骁正常上班。没有哪一边产生“同一身份同时出现在两地”的告警，因为它们只认识自己的那一段记录。
- **高潮**：猫眼把两套来源按时间排在纸上。她没有写“真假陈骁”，只写“临江载体事件”和“宁州载体事件”。系统一旦把这两个载体都指向同一个身份，就会自然生成一条表面连续、实际不可能的人生时间线。陈骁看了半天，说：“以后有人查我记录，会不会觉得这些事全是我干的？” 猫眼答：“如果没人保留分开的旧来源，会。”
- **结尾**：猫眼顺手核查安平里使用的住户同步服务公开部署信息，没有进入任何住户数据。她发现同一个服务商、同一个版本号，近一个月还上线在永和里2号楼、康宁巷9号楼和柳桥新村3栋。她把三个地址推给镜辞：“你现在的问题不是陈骁一个人。是这套东西还有三处在跑。”

#### 情节安排（多线）
- **主线推进**：确认两个不同载体的现实事件会被同一身份账户自然合并
- **辅线推进**：猫眼的信息来源链再次证明“保留分开的旧版本”比追一个唯一答案更重要
- **事件线/任务线**：授权导出 → 最小化宁州证据 → 对表 → 时间重叠 → 一条线问题 → 找同版本部署范围
- **任务卡点**：单个系统都没错 → 必须跨来源比对 → 不能靠某一个数据库判真 → 发现问题具有可复制性
- **感情线/关系线**：陈骁第一次意识到另一个载体不仅占了他的名字，还可能把不属于他的行为永久写进“他的过去”
- **逻辑线**：双陈骁同时存在 → 各自留下真实行为 → 系统共同指向同一身份 → 未来档案自动把两个人生并成一个人

#### 人物关系和出场顺序
- **出场顺序**：陈骁/陈启明 → 物业经理 → 猫眼 → 镜辞
- **人物关系变化**：镜辞开始理解“信息记录正确”与“主体归属正确”不是一回事
- **视角/信息差**：人物知道服务部署到四处小区，但不知道另外三处是否已经发生身份事件
