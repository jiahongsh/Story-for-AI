# 细纲 · 第27章 记性最好的人

## 第 27 章：记性最好的人
- **核心事件**：镜辞继续追顺记老师傅的现实来源，找到曾负责东里巷二十多年的退休邮递员。老人记性并非神奇，而是保留着按日期记投递异常的工作本。旧本显示顺记长期收过水文/精密计时设备包裹；沈竹失踪前也曾在顺记代签一件设备，签名日期紧挨她去临江03点和渡口的时间。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第27章；顺记与旧测点网络建立现实连接
- **单元ID/位置**：1-3；第2拍·来源实证
- **目标情绪**：继续查人 → 老人记忆有限 → 工作记录比回忆可靠 → 沈竹签名出现 → 顺记作用升级
- **主角目标/关键选择**：镜辞想确认顺记究竟只是修表铺还是旧观测网络的一环；关键选择=优先相信可定位日期的旧投递本，而不是老人“我好像记得”
- **章节定位**：来源链+生活档案章
- **本章结构公式**：节点1（找退休邮递员） + 节点2（老人不记脸但有工作本） + 节点3（水文设备包裹） + 节点4（沈竹代签） + 节点5（时间线交叉）
- **章首钩子**：巷口老人都说“老郑以前收很多奇怪包裹”，但没人记得寄件人。退休邮递员却说：“我脑子不一定记得，我本子可能记得。”
- **本章即时兑现**：顺记与旧测点网络不再靠传闻连接，而有长期物流来源支撑
- **本章禁止提前释放**：老郑与镜辞家族关系、守夜人、顺记真正组织属性、沈竹最终去向
- **契约风险**：契约安全。普通人的职业记录继续有实际价值

#### 内容概括（五段式）
- **起因**：镜辞通过物业和老住户找到退休邮递员老韩。老韩对老郑长相只记得“大概瘦、话少”，反而拒绝顺着镜辞的描述补细节。
- **发展**：老韩翻出自己以前的投递工作本。因为东里巷门牌经常改，他习惯把退件、代签、找不到收件人的包裹单独记一笔。顺记每隔一段时间就会收到精密计时器零件、水文设备附件和旧机芯，寄件单位跨了好几个不同名字。
- **转折**：三年前的一页里有一笔“顺记，郑师傅不在，沈竹代签”。下面还有沈竹手写签名。包裹来自一家已经注销的仪器维修公司，内容备注是“同步计时组件”。
- **高潮**：镜辞把日期与自己已有时间线对上：代签发生在沈竹最后一轮临江03点记录前一天，几天后她出现在渡口。顺记不是她偶尔修表的地方，而是她调查旧测点设备的一处物理接口。
- **结尾**：老韩补充一件小事：老郑真正停止正常收件后，顺记仍偶尔有人以“代收”名义取包裹，但签名每次都不同。镜辞把最近仍有低量用电的事实放在旁边，确认这家店的“后继使用者”可能已经不是老郑本人。

#### 情节安排（多线）
- **主线推进**：顺记与旧观测设备网络连接；沈竹路线进一步实证
- **辅线推进**：顺记停业后仍有人代收，为当前使用者埋伏笔
- **事件线/任务线**：找老韩 → 查工作本 → 包裹来源 → 沈竹签名 → 时间线比对
- **任务卡点**：老人不可靠回忆有限 → 工作本补足 → 记录能证实包裹与签名，仍不能证明老郑现在在哪
- **感情线/关系线**：镜辞通过沈竹真实签名确认她曾在这里工作，不安排“留给儿子的暗号”
- **逻辑线**：顺记假关闭 → 历史包裹 → 旧测点设备 → 沈竹代签 → 当前代收者未知
