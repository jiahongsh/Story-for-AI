# 细纲 · 第2章 先喝汤

## 第 2 章：先喝汤
- **核心事件**：镜辞主动把芽约回旧早餐铺，用可复核的小动作验证自己是不是记错。芽对过去事实答得很准，但对两人之间“不需要说出口的关系习惯”反应持续错位。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；第2章；从异常感受升级为主动验证
- **单元ID/位置**：1-1；第2拍·验证
- **目标情绪**：主角掌控感上升 → 验证成功的小满足 → 证据越多越不安
- **主角目标/关键选择**：镜辞不是要证明“芽不是人”，而是先证明“自己有没有记错”；关键选择=不靠追问记忆题，而是制造一个过去会触发芽本能反应的场景
- **章节定位**：推进章；必须给主角一次主动获取证据的兑现
- **本章结构公式**：节点1（回到旧早餐铺） + 节点2（第一项习惯复测） + 节点3（关系动作复测） + 节点4（旧视频交叉验证） + 节点5（镜辞确认自己没记错）
- **章首钩子**：镜辞提前十分钟到早餐铺，专门让老板给自己留了一只碗沿有缺口的旧瓷碗。他今天不是来吃早饭，是来做一次没人知道的测试。
- **本章即时兑现**：主角提出假设、设计验证、拿到结果，形成观察型爽点；但结果只证明“现在与过去存在关系错位”，不证明超自然原因
- **本章禁止提前释放**：壳、裂缝、镜返、等级、存在力；芽被替换实锤；“习惯=灵魂密码”一类万能判定
- **契约风险**：契约安全。主角拥有因果权和调查主动权

#### 内容概括（五段式）
- **起因**：镜辞约芽去两人从少年时期吃到现在的早餐铺。老板仍认识他们，随口问“还是老样子？”镜辞点头，却故意让老板把一只带缺口的旧碗给自己。
- **发展**：芽坐下后重新先喝了汤。这个动作与昨天相反，镜辞第一反应不是安心，而是警觉：她是不是注意到了自己的视线？接下来她准确说出小时候常坐的位置、老板以前养过的狗、镜辞最讨厌哪种葱花，事实层面几乎无懈可击。
- **转折**：镜辞把那只缺口碗自然地拖到自己面前。过去的芽从不需要提醒，只要看见缺口朝着他，就会顺手把碗转半圈。现在的芽没有动。直到镜辞的视线在碗沿停了两秒，她才像刚想起来似的伸手，把缺口慢慢转开。
- **高潮**：镜辞没有继续问。他借口去结账，从手机旧相册里翻出三年前在这家店拍的一段短视频。画面里真正的芽一边骂他拍得丑，一边在说话途中无意识地把那只缺口碗转了半圈，连眼睛都没往下看。
- **结尾**：镜辞把视频停在芽手指碰到碗沿的那一帧。现在的芽隔着蒸汽朝他笑，动作、表情、说过的话都很像。镜辞却第一次有了一个可以写进维修单的结论：**不是我记错了。**

#### 情节安排（多线）
- **主线推进**：镜辞拿到第一份可复核的关系证据，从“怀疑自己”进入“确认异常存在”
- **辅线推进**：早餐铺老板作为第三方生活见证者出现，但不承担破案功能
- **事件线/任务线**：设计测试 → 观察反应 → 旧视频交叉验证
- **任务卡点**：镜辞担心自己把青春期习惯记得太绝对 → 当前芽重新“先喝汤”制造反证 → 关系动作仍错位 → 视频确认过去确有这个习惯
- **感情线/关系线**：镜辞×芽从“暗中观察”进入“他开始有意隐瞒自己的真实想法”
- **逻辑线**：首章两处异常 → 主动复测 → 芽部分恢复正常 → 第二项关系动作仍错 → 信息痕迹验证镜辞记忆 → 异常可信度上升

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 早餐铺老板 → 芽
- **人物关系变化**：镜辞不再完全依赖对芽的信任，开始建立自己的证据链
- **视角/信息差**：读者和镜辞共同确认“错位是真的”，但仍不知道错位意味着什么

#### 情节细化
- 点1：开场直接交代镜辞提前布置测试，把缺口碗放进场景【钩子/行动·密300】
- 点2：芽到店，重新先喝汤。镜辞表面随意，心里记下“她改回来了”【悬念·密250】
- 点3：老板插入几句旧街日常，证明两人确实长期来这里，不靠旁白讲青梅史【关系·密250】
- 点4：芽准确接住多个过去事实，镜辞一度怀疑自己是否过度敏感【反压·密300】
- 点5：缺口碗测试。镜辞把碗拖到自己面前，不提醒、不暗示【行动·密300】
- 点6：芽最初没有反应，发现镜辞盯着后才补做“转碗”动作，慢半拍成为关键【高潮·密400】
- 点7：镜辞不追问，主动中止测试，避免把自己能观察到什么暴露给对方【人物·密200】
- 点8：他去结账时翻旧手机，找到三年前同店视频【证据·密300】
- 点9：视频中的芽无意识转碗，动作发生在说话过程中，没有表演感【小爽点/确认·密300】
- 点10：镜辞把视频备份，不告诉芽，也不向老板求结论【行动结果·密200】
- 点11：章尾回到现在。蒸汽隔开两人，镜辞得出“不是我记错了”的最小结论【钩子·密300】

#### 结尾设定和钩子
- **结尾设定**：旧视频属于信息痕迹，只能证明过去行为曾存在；不能证明现在的芽是什么，也不能替代后续关系调查
- **章尾钩子**：镜辞已经确认异常真实，下一步必然从“复核过去”转向“观察现在的芽在没人看时会做什么”
