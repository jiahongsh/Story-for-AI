# 细纲 · 第41章 核验日

## 第 41 章：核验日
- **核心事件**：安平里6号楼开始门禁与住户关系核验。镜辞没有冒充工作人员，只以修表摊主和附近住户介绍的普通身份在公共区域观察。他注意到302室的许德昌和许棠：老人把许棠叫“闺女”，邻居也都这么认，但两人没有正式收养手续，户籍并不在同一家庭。新系统要求填写“与户主关系”，工作人员只能把许棠标为“其他/长期访客”。镜辞在两人身上都看不到明显接缝。章尾，新门禁当场把许棠的权限从“住户”降成“访客”，老人第一次皱着眉问：“她在这住了十几年，怎么今天突然成客人了？”
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第41章；安平里关系单元启动
- **单元ID/位置**：1-4；第1拍·建立活人关系基线
- **目标情绪**：普通社区日常 → 核验流程的琐碎 → 一处关系无法被表格容纳 → 实际权限变化 → 轻微但刺人的不安
- **主角目标/关键选择**：镜辞想知道安平里施工到底在处理什么；关键选择=不急着找“壳”，先记录施工前居民之间原本怎么互相称呼、互相照顾、谁替谁做决定
- **章节定位**：都市现实+身份主题；用普通人关系建立后续对照组
- **本章结构公式**：节点1（核验日开始） + 节点2（居民排队填关系） + 节点3（许德昌/许棠关系无法被标准选项容纳） + 节点4（多名邻居自然证实共同生活） + 节点5（门禁权限降级） + 节点6（“怎么成客人了”）
- **章首钩子**：物业桌上摆着一张表，最简单的一栏写着：`与户主关系：配偶 / 子女 / 父母 / 其他。` 镜辞站在人群后面看了几分钟，发现真正麻烦的不是谁填错，而是有些关系根本没有合适的格子。
- **本章即时兑现**：第40章“住户身份与家庭关系核验”进入具体人物，不靠超自然怪象先吓人
- **本章禁止提前释放**：关系归并/身份同步正式术语、唯一指向、安平里是否有壳、幕后为何选择此楼
- **能力边界**：镜辞看不到接缝只能说明当前没有可见身份错位，不能证明两人绝对没有任何异常
- **契约风险**：契约安全。关系问题由现实共同生活建立，不靠一段旁白宣布“他们感情很好”

#### 内容概括（五段式）
- **起因**：次日上午，安平里楼下摆起两张折叠桌。物业、恒泰施工人员和街道协助人员分开做事：一边换门禁设备，一边让住户核姓名、证件、联系电话和家庭关系。多数人边抱怨边填，很像任何一次普通系统升级。
- **发展**：302室的许德昌排到桌前，填“女儿：许棠”。工作人员核证件后发现许棠户籍并不与他同户，也查不到正式收养手续，只能问：“法律关系是什么？”老人愣了半天，说：“她就是我闺女。”许棠在旁边低声补充，自己八岁起就在这里长大，只是当年手续一直没办完整。
- **转折**：镜辞没有只听他们自己说。他在公共区域随口问楼下小卖部老板、隔壁305的大姐和收废品的老人，三个人都自然提到“老许家闺女”“棠棠给她爸买药”“前几年老许住院全是她陪”。这些说法来自不同生活片段，不像统一背出来的答案。
- **高潮**：系统最终把许德昌标成户主，把许棠标成“长期访客/其他关系”。旧门禁卡原本两人都能直接进楼，新系统激活后，许棠刷卡时屏幕却提示：`访客权限，请由住户确认。` 她愣了一下，许德昌从里面给她开门，嘴上还开玩笑“回自己家还得我批准”。
- **结尾**：笑完以后老人没走。他回头看那块新门禁屏，声音低下来：“她在这住了十几年，怎么今天突然成客人了？”镜辞站在几步外，看着许棠和许德昌，两个人脸上都没有他熟悉的接缝。可某种关系已经在系统里被改了一个名字。

#### 情节安排（多线）
- **主线推进**：安平里施工从设备层落到关系分类与权限层
- **辅线推进**：建立许德昌/许棠的施工前关系基线，为后续版本变化提供可复核对照
- **事件线/任务线**：核验 → 填关系 → 系统无法容纳 → 独立邻居证词 → 权限变化
- **任务卡点**：镜辞想找超自然异常 → 现场首先出现的是极普通的行政分类问题 → 他被迫把“关系怎样被系统命名”也纳入调查
- **感情线/关系线**：许德昌×许棠通过称呼、买药、住院、开门等具体行为建立关系，不靠血缘标签
- **逻辑线**：共同生活十余年 → 法律/数据关系不完整 → 新系统只认标准项 → 权限由“住户”变“访客”

#### 人物关系和出场顺序
- **出场顺序**：安平里居民群像 → 许德昌 → 许棠 → 物业工作人员 → 三名独立邻居
- **人物关系变化**：镜辞第一次把一个“看不见接缝”的普通家庭纳入异常调查，不再只盯怪物
- **视角/信息差**：读者与镜辞都不知道这是普通系统缺陷、有人故意设计，还是更大测试的一部分
