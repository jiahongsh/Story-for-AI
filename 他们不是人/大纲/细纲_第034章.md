# 细纲 · 第34章 D4

## 第 34 章：D4
- **核心事件**：镜辞只从公共道路与合法可达的河堤外围核查D4旧泵房。他带着三类计时设备按第16、19章同样方法建立基线，却发现一个反常结果：D4附近几乎没有17和03那种明显走时偏差，现场却留有大量近期维护痕迹。更怪的是，越靠近围栏内旧泵房，镜辞被动看见的环境“接缝感”越强，机械计时反而越整齐。有人似乎不是在消除异常，而是在把异常修得更难被老方法发现。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第34章；现代维护功能第一次显形
- **单元ID/位置**：1-3；第9拍·旧方法失效
- **目标情绪**：谨慎到场 → 数据过分正常 → 现场维护痕迹 → 感知与仪器结果相反 → 意识到“正常”本身可疑
- **主角目标/关键选择**：镜辞想确认D4当前是否仍有异常；关键选择=机械表全部“正常”时不宣布安全，而是把自己的接缝感、现场新旧痕迹和历史记录分开比较
- **章节定位**：调查反转+能力边界章；主角第一次面对“仪器越正常，现场越不对”的情况
- **本章结构公式**：节点1（外围基线） + 节点2（机械计时异常弱） + 节点3（近期维护痕迹） + 节点4（接缝感增强） + 节点5（新旧照片对照） + 节点6（怀疑有人在校正旧指标）
- **章首钩子**：17号会漏拍，03点会走慢。D4什么都没有。三块表在围栏外走得整整齐齐，齐得让镜辞反而不敢往前走。
- **本章即时兑现**：第33章“原位基准件被校正”出现现场效果；旧测点网络正在被某种现代方法改变
- **本章禁止提前释放**：接缝修复师、关系归并、壳巢名称、D4内部设备完整结构
- **能力边界**：镜辞只能感觉现场身份/环境错位更明显，不能靠1阶直接解释“是谁修的、怎么修的”
- **契约风险**：契约安全。异常升级不是怪物数值更高，而是旧调查方法开始失灵

#### 内容概括（五段式）
- **起因**：镜辞按公开工程地址来到南岸旧泵房外围。围栏上挂着恒泰设施的施工牌，项目名写“安全封闭维护”，施工期还没结束。公共河堤可以正常通行，泵房内部禁止进入。
- **发展**：镜辞在围栏外不同位置放置怀表、旧机械表、新机械表和电子计时，记录四十多分钟。结果与17、03完全不同：三块机械表之间几乎没有显著偏差，甚至比旧市场里校表时还整齐。
- **转折**：现场却明显最近动过。围栏内旧电缆被重新理顺，墙上有新打孔，原本锈蚀的一个计时箱外壳保留不换，内部接线却能看见新端子。更重要的是，镜辞越靠近某一段围栏，耳后和视野边缘那种看见接缝前的错位感越明显，远离便减弱。
- **高潮**：他把沈竹旧照片、项目旧附件和现场照片对在一起：过去的测点用“走时不齐”暴露问题；现在D4保留原来的基准件，却把多个机械节拍校得近乎一致。镜辞第一次提出一个工作假设：**有人正在让旧测点“看起来正常”。** 这不等于异常消失，可能只是过去能看到的指标被修掉了。
- **结尾**：一辆恒泰施工车从泵房后门开出来。镜辞没有拍司机脸，只记车牌公开可见部分和离场时间。车经过他身边时，怀表依旧走得很准，但镜辞在副驾驶车窗一闪而过的反光里，看见一道极短的接缝。

#### 情节安排（多线）
- **主线推进**：D4维护效果明确：旧计时异常被压平，身份/环境错位仍在
- **辅线推进**：灰色网络开始与普通施工车辆、项目人员现实接触
- **事件线/任务线**：外围测试 → 数据正常 → 查维护痕迹 → 感知反差 → 历史对照 → 建工作假设
- **任务卡点**：仪器不给异常 → 按旧方法应结束调查 → 现场物理痕迹和镜辞被动感知不支持“安全” → 方法必须升级
- **感情线/关系线**：无情感大回收，保持阶段加压
- **逻辑线**：17/03旧异常 → 恒泰校正 → D4计时变正常 → 接缝仍强 → “异常被修得更难看见”

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 普通施工人员远景/车辆
- **人物关系变化**：镜辞开始真正需要守钟人另一种专业判断，因为自己的物证与旧仪器出现矛盾
- **视角/信息差**：施工人员是否知情未知；禁止把整家公司全员写成壳
