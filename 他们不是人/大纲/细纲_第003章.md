# 细纲 · 第3章 光在发抖

## 第 3 章：光在发抖
- **核心事件**：镜辞为了观察“没人看着时的芽”，在她住处附近第一次稳定看见不属于正常人的“接缝”。镜返第一式以被动视觉形式进入故事，但正文不命名、不解释。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；黄金三章兑现点；完成“主角真的能看见别人看不见的身份破绽”这一读者契约
- **单元ID/位置**：1-1；第3拍·超自然确认
- **目标情绪**：调查掌控感 → 偷窥风险 → 视觉惊悚 → 被反向注意
- **主角目标/关键选择**：镜辞想确认芽独处时是否也会维持那套“标准行为”；关键选择=他在看到异常后压住本能反应，不冲进去、不当场质问，先活着离开
- **章节定位**：黄金三章高压章；必须形成第一次明确超自然兑现
- **本章结构公式**：节点1（合理抵达芽家附近） + 节点2（窗内出现第二道影子） + 节点3（镜中接缝显现） + 节点4（镜辞强行保持安静） + 节点5（芽隔窗回望）
- **章首钩子**：晚上十点十七分，芽给镜辞发消息说“到家了，准备睡”。二十分钟后，镜辞送修好的表给巷口另一位老客户，抬头看见芽房间还亮着灯，窗帘上却叠着两道人影。
- **本章即时兑现**：前两章的异常不再只停留于习惯层面，镜辞第一次获得无法用正常心理学解释的视觉证据
- **本章禁止提前释放**：壳的名称与完整设定、等级数值、裂缝原理、镜返名称、镜返后续式、EX算法
- **能力边界**：镜返第一式=被动看见Lv.1-3基础接缝；本章没有主动施法，不扣主动EX；镜辞只知道“自己看见了某种不对劲的结构”，不知道它叫什么
- **契约风险**：契约安全。黄金三章兑现核心卖点，但不透支解释权

#### 内容概括（五段式）
- **起因**：镜辞晚上给旧街一位客户送修好的表，路线正好经过芽家附近。他本来没打算上楼，直到看到芽房间的窗帘上有两道人影。几分钟前芽还发消息说自己一个人在家。
- **发展**：镜辞没有直接敲门。他绕到少年时熟悉的侧巷，从楼下公共平台能看到芽家阳台的一角。这里不是“青春期翻窗重演”，而是他利用熟悉地形找一个能观察却不暴露自己的位置。
- **转折**：窗帘被风吹开一条缝。芽背对窗户整理东西，镜中却先映出她的脸。镜辞看到那张脸边缘有一条极细的亮线，像皮肤与皮肤没有完全贴合，随着她转头轻轻错开。不是文字，不是系统提示，只是一种他的眼睛以前从没见过、现在却无法忽视的“缝”。
- **高潮**：镜辞盯得太久，亮线从耳后一路滑到颈侧。他产生一种近乎本能的判断：这不是伤疤，也不是镜面反光。与此同时，房间里另一道人影靠近芽，却没有在镜子里留下完整轮廓。镜辞强迫自己松开抓着栏杆的手，没有发出声音。
- **结尾**：他退回巷口时，口袋里的旧怀表轻轻响了一声。本该停死的秒针走了两格，又停住。镜辞还没来得及细看，楼上的窗帘忽然被拉开。芽站在黑掉的房间里，隔着整条巷子，正低头看着他。

#### 情节安排（多线）
- **主线推进**：从“关系错位”正式跨入“身份结构异常”，核心超自然卖点第一次兑现
- **辅线推进**：怀表在异常环境附近出现弱走时异常，只作为物证伏笔
- **事件线/任务线**：送表经过 → 发现异常 → 选择观察 → 看见接缝 → 安全撤离失败一半，被芽注意
- **任务卡点**：镜辞想看独处状态 → 两道人影提高风险 → 接缝让他获得证据 → 芽可能发现他，调查从单向观察变成双向猎视
- **感情线/关系线**：镜辞×芽从“暗中怀疑”升级为“他开始害怕眼前这个熟人”
- **逻辑线**：第二章确认错位真实 → 第三章观察非公开状态 → 看见超自然结构 → 无法正常解释 → 对方疑似注意到他

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 老客户一笔 → 芽 → 房间内第二道人影
- **人物关系变化**：镜辞不再只是在保护青梅关系，而开始本能保护自己
- **视角/信息差**：读者与镜辞共同看见“缝”，但都不知道它是什么；第二道人影的身份继续悬置

#### 情节细化
- 点1：消息时间锚点。“准备睡”与仍亮灯的房间形成第一处冲突【钩子·密250】
- 点2：镜辞送表经过，给夜访提供成年生活中的现实动机【逻辑·密250】
- 点3：窗帘两道人影。他没有上门，而是选择侧巷观察点【行动·密300】
- 点4：芽在房间内正常整理物品，镜辞几乎准备离开【假缓和·密200】
- 点5：镜中先出现接缝。描述以光、皮肤错位、反射异常为主，不出现任何数字【首次兑现·密500】
- 点6：第二道人影靠近，但镜中轮廓不完整，制造第二层未知【悬念·密300】
- 点7：镜辞压住呼吸、松开栏杆、慢慢撤退，体现成年主角的风险判断，不做冲动闯入【人物·密250】
- 点8：撤退过程中他回忆旧视频的芽与眼前的接缝，第一次承认“这已经不是习惯改变能解释的事”【状态变化·密200】
- 点9：怀表秒针走两格又停。镜辞只记录，不推导任何宇宙规则【伏笔·密200】
- 点10：房间突然熄灯，窗帘拉开【加压·密250】
- 点11：芽站在窗后直接看向镜辞所在位置，章尾从“我在观察她”翻转为“她也在看我”【强钩子·密350】

#### 结尾设定和钩子
- **结尾设定**：镜辞已稳定看见一次接缝，但仍没有命名能力、验证对象身份或解释机制的资格
- **章尾钩子**：调查关系发生翻转：芽是否发现镜辞在观察她？第二道人影是谁？怀表为什么短暂走动？三问中下一章只优先回答第一问的一部分，其余继续挂起
