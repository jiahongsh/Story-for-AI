# 细纲 · 第3章 光在发抖

## 第 3 章：光在发抖
- **核心事件**：镜辞夜访芽家确认——第一次看见"接缝"，镜返觉醒（黄金三章的信任崩塌预演+金手指基点）
- **字数目标**：3000 字
- **阶段位置**：开篇期；第1阶段第3章；完成金手指基点+信任崩塌（关键转折）
- **单元ID/位置**：1-1；第3拍·加压（发现芽的接缝）
- **目标情绪**：紧张压抑 → 惊悚反转（看见接缝）→ 茫然（不知道这意味着什么）；本章推进情绪引擎的"释放节点"前奏
- **主角目标/关键选择**：镜辞想确认芽到底怎么了；关键选择=他选择深夜潜入芽家（越过"不该越过的界限"）
- **章节定位**：高压（信任崩塌+金手指觉醒）
- **本章结构公式**：节点1（夜访芽家·紧张铺垫） + 节点2（芽房间的异常·灯光下的一幕） + 节点3（第一次看见"接缝"·镜返觉醒） + 节点4（逃离+茫然·章尾钩子）
- **章首钩子**：动作钩子（镜辞在芽家楼下抬头——她房间的灯亮着，但窗帘后的影子"有两个"）

- **契约风险**：契约安全

#### 内容概括（五段式）
- 起因：镜辞越想越不安，深夜路过芽家，鬼使神差地停下来。她房间灯亮着，窗帘后的影子——有两个。
- 发展：他翻上阳台（少年时爬过无数次），透过窗帘缝隙看进去——芽背对着他，在整理东西，一切正常。他松口气，正要走。
- 转折：芽忽然转头——不是朝他，是朝镜子。镜子里映出的脸，有一道"光在发抖"：那道光的边缘，像衣服上的线头，细细地裂开。那不是人的脸该有的东西。**更诡异的是——他"读到"了一行不该存在的信息：`Lv.2 侵蚀壳 · 伪装度35 · 接缝:明显`。他第一次看见这行"字"，像光斑浮在空气里，眨一眨眼又散成接缝。他不知道这是什么，但他知道：这不是幻觉。**
- 高潮：镜辞僵在阳台上。他眨了三次眼——光还在。芽对着镜子笑了一下，笑容标准得过分，像练习过一万次。他第一次意识到：眼前这个人，可能不是芽。
- 结尾：他跌跌撞撞翻下阳台，跑出巷子。身后，芽房间的灯灭了。他蹲在路灯下喘气，掏出怀表——表盖内侧"镜辞"两个字，在灯光下安静地反光。他忽然想：妈，你走的时候，是不是也是看见了这个？（章尾钩子）

#### 情节安排（多线）
- **主线推进**：金手指基点完成（看见接缝）+ 信任崩塌（芽不是芽？）

- **事件线/任务线**：夜访芽家（验证→撞见真相一角）
- **任务卡点**：镜辞想确认芽 → 卡在"亲眼看见无法解释的东西" → 卡出"她可能不是芽" → 删掉损失=金手指觉醒没落点 → 收束动作=逃离+自我确认（还在喘气=还活着）
- **感情线/关系线**：镜辞×芽=信任崩塌（但读者仍不知芽是否真的被替换——留到第10章）
- **逻辑线**：违和加深（原因）→ 夜访验证（行动）→ 看见接缝（结果）→ "她不是芽"+养母联想（后果/新问题）
