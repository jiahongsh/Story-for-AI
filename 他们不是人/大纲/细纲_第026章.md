# 细纲 · 第26章 东里巷

## 第 26 章：东里巷
- **核心事件**：镜辞明知东里巷可能是饵，仍按风险预案去核查“顺记修表”。铺面表面停业三年，但门锁近期有使用痕迹、电表仍有低量读数，邻居对“老师傅何时离开”的说法也不一致。镜辞不破门、不追神秘背影，只确认：这家店不是简单废弃。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第26章；单元1-3入口
- **单元ID/位置**：1-3；第1拍·可疑地点核查
- **目标情绪**：知道是饵仍进入 → 表面死店 → 细节不对 → 多方说法冲突 → 确认有人仍在使用
- **主角目标/关键选择**：镜辞想验证东里巷地址是否只是诱导；关键选择=只做公开空间能完成的调查，不擅自破门进入
- **章节定位**：悬疑调查章；旧城区不是地下副本地图
- **本章结构公式**：节点1（风险预案） + 节点2（顺记外观） + 节点3（锁与电表异常） + 节点4（邻居时间线冲突） + 节点5（物业缴费记录） + 节点6（假关闭结论）
- **章首钩子**：顺记修表的木牌落满灰，门锁也生了锈。镜辞蹲下看了半分钟，却发现锁芯最里面是亮的。
- **本章即时兑现**：第25章“地址是真的、动机未知”得到第一层验证
- **本章禁止提前释放**：顺记真实用途、老郑身份、壳巢、守夜人、店内秘密
- **契约风险**：契约安全。主角主动选择如何吃“饵”，不是被地址牵着鼻子走

#### 内容概括（五段式）
- **起因**：镜辞先把东里巷地址、预计返回时间分别留给守钟人和一位普通市场熟人，手机不开位置共享，只约好超过时间没回就打电话。他到旧城区后先绕一圈，再从公开街面靠近顺记。
- **发展**：顺记看起来停业很久，招牌褪色、窗内积灰。但门锁锈在外面，锁芯内部却有新鲜摩擦痕；门槛灰尘也有一道不明显的拖擦线，像门近几天开过。
- **转折**：镜辞分别问隔壁裁缝、楼上住户和巷口小卖部。有人说老郑三年前走了，有人说两年前还见过，有人坚持“去年冬天夜里店里还亮过灯”。这些证词不能确定老郑还在，却足以推翻“店三年前彻底废弃”的简单版本。
- **高潮**：物业代收点的公开缴费本显示，这间铺子的电费一直没有完全断，近半年每月都有极低但稳定的用电。缴费人一栏不是老郑姓名，而是统一写“代缴”。镜辞没有继续问是谁代缴，先拍下可公开查到的账页编号。
- **结尾**：他回到顺记门口，透过玻璃看见柜台灰尘中央有一小块颜色更浅的矩形印子，像不久前还摆过一台笔记本电脑或文件盒。镜辞在异常表里写：`地点真实；停业状态可疑；当前使用者未知；不进入。`

#### 情节安排（多线）
- **主线推进**：顺记从“旧地址”升级为仍被使用的可疑节点
- **辅线推进**：镜辞开始形成进入危险地点前的信息冗余和报备习惯
- **事件线/任务线**：到场 → 查门锁 → 访邻居 → 看缴费 → 得出最小结论
- **任务卡点**：店看起来已经废弃 → 细小现实痕迹反驳 → 邻居证词冲突 → 用电记录提供另一层支撑
- **感情线/关系线**：无强情感回收，本章以调查紧张感为主
- **逻辑线**：可疑真线索 → 地址存在 → “停业三年”说法不稳 → 当前有人使用

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 裁缝/楼上住户/小卖部老板 → 物业代收人员
- **人物关系变化**：镜辞不把旧城区居民当背景板，而是按来源分开记录
- **视角/信息差**：谁在代缴、谁在开门仍未知
