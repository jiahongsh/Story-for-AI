# 细纲 · 第5章 标准的芽

## 第 5 章：标准的芽
- **核心事件**：芽"恢复正常"——她重新先喝汤了，但镜辞发现她的"正常"是排练出来的（行为太标准）
- **字数目标**：3000 字
- **阶段位置**：开篇期；第1阶段第5章；信任崩塌深化（"正常"比"异常"更可怕）
- **单元ID/位置**：1-1；第5拍·加压（标准化的芽）
- **目标情绪**：期待（她好像正常了）→ 细思极恐（太正常了=不正常）；本章推进情绪引擎的"压抑累积"至峰值前
- **主角目标/关键选择**：镜辞想确认芽是否真的回来了；关键选择=他选择"继续观察"而非"直接质问"（怕打草惊蛇）
- **章节定位**：普通推进（关系+悬念，恐怖泛化）
- **本章结构公式**：节点1（芽重新先喝汤·镜辞松口气） + 节点2（但她的行为"太标准"——每步都像照剧本） + 节点3（镜辞试探：故意说错一个只有芽知道的事） + 节点4（芽的反应完美但不对·章尾钩子）
- **章首钩子**：延续钩子（"别让任何人知道你能看见"——镜辞决定按兵不动，继续观察芽）
- **爽点**：识破爽点雏形（镜辞"看穿"标准化的破绽）；往下看的理由=芽到底是不是芽
- **本章禁止提前释放**：芽被替换实锤/壳的完整设定/镜返代价
- **契约风险**：契约安全

#### 内容概括（五段式）
- 起因：镜辞按兵不动，继续观察。这天在豆浆铺，芽重新"先喝汤"了——他差点以为之前是自己看错了。
- 发展：但接下来半小时，他的观察者本能越看越冷：芽今天说的每句话、做的每个动作，都"标准"得像照剧本走——她笑起来嘴角的弧度、她点头的节奏、她喝豆浆的次序，全对，全对得过分。
- 转折：镜辞故意试探——他提起一件只有真正的芽才知道的事："你初二那年，我们在操场后墙刻过字，还记得刻的什么吗？"芽愣了一下，随即笑了："当然记得啊，刻的是'芽和镜辞要做一辈子的好朋友'。"——每个字都完美，但镜辞记得，那行字后面其实还有个错别字，芽当年还笑过那个错别字。
- 高潮：镜辞看着她完美的笑，心里某个地方彻底凉了。这个人记得一切，记得每一件"应该记得的事"——但她的记忆像背下来的，不是活出来的。
- 结尾：晚上，镜辞在旧物盒里翻到一张养母留下的纸条（上一章那张"别让任何人知道"），背面还有一行小字，被水渍洇了一半："……如果有一天，你发现最亲的人变了——不要怕，你还有……"后半句看不清了。（章尾钩子）

#### 情节安排（多线）
- **主线推进**：信任崩塌深化——"完美的芽"比"违和的芽"更可怕（记忆是背的，不是活的）
- **辅线推进**：养母纸条背面（"不要怕，你还有……"——线索悬置）
- **事件线/任务线**：观察芽+试探（验证行动）
- **任务卡点**：镜辞想确认芽 → 卡在"她记得一切但对不上细节" → 卡出"记忆是背的" → 删掉损失=恐怖感不成立 → 收束动作=逃离现场+翻旧物盒
- **感情线/关系线**：镜辞×芽=信任崩塌进入"哀"的阶段（他眼睁睁看着她"完美"）
- **逻辑线**：芽恢复"先喝汤"（原因）→ 行为太标准（观察）→ 试探+记忆对不上（结果）→ "她不是她"+养母纸条背面（后果/新问题）

#### 人物关系和出场顺序
- **出场顺序**：豆浆铺老板（群像）→ 芽（"标准的芽"）→ 镜辞 → （旧物盒·纸条背面）
- **人物关系变化**：镜辞×芽：本章后=从"不敢确认"到"确认她不是她"（但读者仍存疑——留到第10章实锤）
- **视角/信息差**：读者与主角同信息量，但"错别字"细节给了读者确定性证据（芽确实不是芽——读者比主角更早确认，制造"主角还在犹豫"的焦虑）
