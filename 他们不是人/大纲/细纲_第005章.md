# 细纲 · 第5章 标准的芽

## 第 5 章：标准的芽
- **核心事件**：芽开始主动恢复镜辞曾经观察到的旧习惯：先喝汤、转开缺口碗沿、接住旧玩笑。镜辞没有因此安心，反而发现这些行为更像“补上来的正确答案”。他第一次尝试用一个全新的关系情境，区分“记得过去”与“真的还按原来的方式在乎一个人”。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；第5章；把“异常=做错”升级为“异常也可以表现得完全正确”
- **单元ID/位置**：1-1；第5拍·伪装适应
- **目标情绪**：短暂松弛 → 正常得过头 → 主角反向设局 → 关系层恐怖加深
- **主角目标/关键选择**：镜辞想知道芽的“恢复正常”是自然回归，还是她在根据自己的反应调整；关键选择=不再测试旧事实，而是制造一个过去没有发生过的新情境
- **章节定位**：关系悬疑推进章；核心不是给出“芽不是芽”的最终答案，而是证明单靠过去记忆无法验证一个人的关系连续性
- **本章结构公式**：节点1（芽恢复旧习惯） + 节点2（恢复得过于精确） + 节点3（镜辞停止旧题测试） + 节点4（新情境反应顺序错位） + 节点5（沈竹纸条背面）
- **章首钩子**：第二天，芽进早餐铺坐下，先喝汤，再把镜辞面前那只缺口碗转了半圈。两个动作都对。镜辞却没有松口气，因为她做第二个动作前，先看了一眼他的眼睛。
- **本章即时兑现**：主角识破“把旧习惯补齐”并不等于关系恢复，调查思路从记忆问答升级为观察关系反应
- **本章禁止提前释放**：芽被替换的最终实锤、壳完整机制、存在锚点术语、白塔、裂缝原理
- **设定边界**：旧习惯只能作为线索，不能写成灵魂验证码；事实记忆、行为模板与真实关系连续性必须保持区别
- **契约风险**：契约安全。恐怖继续落在熟人关系，而不是变成猜密码游戏

#### 内容概括（五段式）
- **起因**：芽像什么都没发生过一样约镜辞吃早餐。这一次她先喝汤，也会主动把缺口碗沿转走，甚至把两人少年时期的玩笑接得一字不差。镜辞表面跟着笑，心里却越来越冷：昨天还缺失的动作，今天全部回来了。
- **发展**：镜辞故意不再问任何“你还记不记得”的问题。事实题已经失去价值，因为芽证明了她可以掌握大量过去信息，也可以快速修正外在行为。他转而观察她什么时候看自己、什么时候先行动、什么时候必须得到提示才给出“正确反应”。
- **转折**：镜辞设计了一个以前从未发生过的新情境。修表时，他故意把一枚细小发条弹到桌边，手指被弹开的金属边缘划出一道血口，同时桌上热汤被碰翻，沿桌面朝怀表流去。真正的选择只有一瞬：先管镜辞的手，还是先救那块他最宝贝的表。
- **高潮**：芽第一反应是伸手去抢怀表，动作快得几乎没有停顿；等她把表抬起来，才转头看见镜辞手上的血，立刻露出恰到好处的紧张，抓纸巾、问疼不疼、责怪他不小心。每一个后续动作都正确。可镜辞记得，过去的芽最烦他拿沈竹的表当命根子，真遇到这种事，她会先骂一句“表坏了还能修，你手能换吗”。这个情境以前从未发生过，因此不存在可以背下来的标准答案。
- **结尾**：镜辞没有拆穿，也没有给自己下“她一定不是芽”的最终结论。他只在维修单背面补了一句：**“她知道芽记得什么，却不一定知道芽会先救什么。”**晚上，他重新翻沈竹那张警告便签，发现背面被水渍遮住的一行字还能辨出半句：**“别急着证明谁是假的，先确认你还信得过什么。”**

#### 情节安排（多线）
- **主线推进**：调查方法升级：从旧记忆问答转向“新情境中的关系选择”，直接服务后续存在锚点主题但不提前说术语
- **辅线推进**：沈竹留下的警告开始体现方法论，不提供怪物百科
- **事件线/任务线**：观察恢复行为 → 判断对方可能在适应 → 设计新情境 → 得到新的关系证据
- **任务卡点**：芽把过去缺失动作全部补齐 → 旧测试失效 → 镜辞被迫改变方法 → 新情境暴露反应优先级差异
- **感情线/关系线**：镜辞×芽从“我怕你变了”进入更痛的阶段：“即使你把过去全部答对，我也不知道现在该怎么相信你”
- **逻辑线**：第二章关系习惯错位 → 第三章接缝 → 第四章确认异常并非孤例 → 第五章芽开始适应观察 → 主角认识到旧习惯本身不能判真伪

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 芽 → 早餐铺老板一笔 → 沈竹通过便签出现
- **人物关系变化**：镜辞开始主动隐藏自己的判断标准，双方关系进入真正的信息博弈
- **视角/信息差**：读者知道镜辞在测试，但不知道芽是否也知道自己正在被测试；两边都可能在观察对方

#### 情节细化
- 点1：开场两项旧习惯全部恢复，芽转碗前先看镜辞一眼【钩子·密300】
- 点2：芽自然接住旧玩笑、旧地名和少年记忆，进一步证明“问过去”已经没意义【反压·密300】
- 点3：镜辞停止抛记忆题，转而统计她“先看我再做”和“直接做”的差别【人物/方法·密250】
- 点4：回到钟表摊，芽留下帮他整理东西，给新情境测试提供自然场景【推进·密200】
- 点5：镜辞故意制造小事故：发条划手+热汤朝怀表流去。危险必须可控，不能真拿命测试【行动·密350】
- 点6：芽第一反应救表，第二反应才救手【高潮·密350】
- 点7：后续关心非常标准：止血、抱怨、收拾桌面，全无明显错误【恐怖·密300】
- 点8：镜辞回想真正的芽过去总把“人比东西重要”挂在嘴边，但这不是一道她曾经回答过的具体题，而是长期关系形成的优先级【关系·密300】
- 点9：镜辞没有得出“百分百替换”结论，只把“关系反应不连续”写入记录【逻辑收束·密200】
- 点10：芽临走时问他：“你最近是不是总在试我？”镜辞抬头，两人第一次正面碰到这层博弈，但他只回：“职业病。”【关系加压·密250】
- 点11：夜里翻便签背面，辨出“别急着证明谁是假的，先确认你还信得过什么”【钩子·密300】

#### 结尾设定和钩子
- **结尾设定**：镜辞目前只能确认三件事：芽存在关系反应错位；她身上有接缝；她可能正在根据镜辞的观察调整行为。仍不能据此推出完整替换机制
- **章尾钩子**：芽已经开始怀疑镜辞在测试她，单向调查结束。第6章以后必须提高双方信息博弈，而不能继续重复早餐习惯测试
