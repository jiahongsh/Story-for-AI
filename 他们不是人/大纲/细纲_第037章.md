# 细纲 · 第37章 清理轨迹

## 第 37 章：清理轨迹
- **核心事件**：意识到自己的反馈会改变现场后，镜辞回查北河17号与临江03号。他不再只看“现在还异常不异常”，而是比较自己第一次到访后的时间线。17号旧机械表已被统一替换，03号河堤旧设备箱也在他离开后两天内更换。猫眼通过公开维修公示、旧网页缓存和一份送货记录确认：两个地点的追加维护都发生在镜辞调查之后，且最终都落到恒泰设施的下游施工链。章尾，镜辞第一次意识到自己的调查本身正在替对方暴露尚未清干净的地方。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第37章；反调查深化
- **单元ID/位置**：1-3；第12拍·代价不是遗忘，而是证据被清理
- **目标情绪**：回头核查 → 熟悉现场已经变样 → 来源链拼接 → 意识到调查副作用 → 策略必须改变
- **主角目标/关键选择**：镜辞想确认D4是否只是个例；关键选择=停止“发现一个点就立刻跑过去”的直线追查，开始先留旧版本、再决定是否现身
- **章节定位**：调查方法升级章；给主角的主动调查增加现实代价
- **本章结构公式**：节点1（回17号） + 节点2（旧物理指标被替换） + 节点3（回03号） + 节点4（维护时间异常） + 节点5（猫眼核来源链） + 节点6（调查=给对方做巡检）
- **章首钩子**：镜辞重新翻到17号第一页记录，忽然发现一个更难受的问题：如果D4会因为他一句话继续施工，那17号和03号在他离开以后发生过什么？
- **本章即时兑现**：未知网络不只盯当前D4，而是在镜辞调查之后持续清理旧点；第16-19章的地点获得后续状态变化
- **本章禁止提前释放**：恒泰背后的真正控制者、完整技术用途、接缝修复师、白塔/壳巢名称
- **能力边界**：镜辞只能比较自己曾经记录过的现象，不能凭镜返知道“谁来修过、什么时候修过”
- **契约风险**：契约安全。代价不是突然扣EX，而是调查行为会改变证据环境

#### 内容概括（五段式）
- **起因**：镜辞先回北河17号。他没有提前联系任何人，只按第16章留下的照片位置重走一遍。原来用于盲测的几只老机械钟已经不在，墙面重新刷过，旧铜牌仍保留，但附近新增一套数字环境监测盒。普通工作人员只知道“前阵子统一维护过”。
- **发展**：他再去临江03号。老机芯此前容易在特定时段出现节拍不匀，如今同一位置的公共设备箱刚换过，旁边施工铭牌日期恰好落在他第一次验证后的第二天。最刺眼的不是“修过”，而是两个旧点都在他调查后不久完成了追加维护。
- **转折**：镜辞没有继续问现场人员，而是把两处公示编号、施工日期和旧照片发给猫眼。猫眼只做来源链：她翻出17号曾经存在但后来撤下的维修页面缓存，又找到03号设备送货单的转手记录。两条线最终都落到恒泰设施的合作施工链，但中间经过不同承包节点，说明不是一个工人一路跟着他跑。
- **高潮**：猫眼把时间排成一列：镜辞第一次到访17号 → 次日新增维护；镜辞验证03号 → 两天内更换设备；镜辞进入D4 → 对方直接开始询问“你还能不能看见”。她没有替他下结论，只说：“你每查到一个还漏着的地方，后面就有人来收尾。”
- **结尾**：镜辞回钟表行，把以后调查流程改了：第一步不再是“去现场”，而是先抓旧网页、旧照片、纸质记录、独立证人；只有保存了旧版本，才考虑出现。他在账本顶端写：`我走过的地方，会变。先留下它没变之前的样子。` 这不是热血宣言，只是一条新的工作规则。

#### 情节安排（多线）
- **主线推进**：确认“镜辞调查轨迹 → 后续维护清理”的时间关联
- **辅线推进**：猫眼的来源链专业再次不可替代；旧17/03不是一次性景点
- **事件线/任务线**：回17 → 发现设备更换 → 回03 → 对比日期 → 猫眼查链 → 修改调查流程
- **任务卡点**：现场已经变化，无法复现旧实验 → 镜辞转查版本与施工时间 → 猫眼补来源链 → 仍不能直接知道幕后是谁
- **感情线/关系线**：镜辞×猫眼从单次买消息转向有限方法合作，但她仍只提供可核来源，不替他承担结论
- **逻辑线**：D4反馈闭环成立 → 反查旧点 → 旧点都在调查后被维护 → 调查本身成为对方的清理提示

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 17号普通工作人员 → 03号公共现场 → 猫眼
- **人物关系变化**：镜辞开始真正理解猫眼为什么执着保存旧版本：现场会改，记录也会改
- **视角/信息差**：只能证明时间关联与施工链交叉，不能证明所有维护都是同一幕后者直接下令
