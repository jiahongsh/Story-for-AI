# 细纲 · 第55章 不用我去

## 第 55 章：不用我去
- **核心事件**：镜辞暂停现场调查的第二天，康宁巷9号楼物业通过安平里同行分享的最小流程，独立处理了一起“标准亲属权限自动恢复”事件：一名住户的前夫被上游系统重新标成“家庭成员/常住”，但双方离婚多年且住户明确拒绝其进入。物业提前保存旧纸册、离婚后的门禁注销记录和住户当前意愿，在02:17同步恢复权限后立即按既有安全规程本地暂停，并留完整冲突日志。当天确实有人拿有效旧关系信息来试门禁，但未能进入。镜辞全程没有到场，也没有看见任何接缝。猫眼只把去标识化流程包和当事人授权的一小段日志交给他。镜辞第一次在结论栏写：`身份未判；风险已阻止。` 章尾，康宁巷日志里出现一个比权限恢复更怪的字段：一条“家庭关系备注”在物业、社区服务端和门禁服务三个彼此独立的系统中于同一分钟自动出现，而本地没人填写过。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段3；第55章；分布式方法第一次完整独立运行
- **单元ID/位置**：1-4；第15拍·保护先于身份裁决
- **目标情绪**：镜辞被迫不去 → 异地消息传来 → 普通流程自行运转 → 风险被拦截 → 主角接受“不知道也能先保护” → 新的信息同步异常
- **主角目标/关键选择**：镜辞想知道自己停下来是否会害到别人；关键选择=遵守三天不跑现场的决定，只审核别人愿意提供的最小记录，不因为焦虑亲自赶去
- **章节定位**：小胜+方法成熟；证明保护行为可以脱离主角超能力运行
- **本章结构公式**：节点1（康宁巷发来预警） + 节点2（镜辞想去但停住） + 节点3（物业按流程保旧版本/确认住户意愿） + 节点4（02:17恢复后本地暂停） + 节点5（有效身份来访者被门禁阻挡） + 节点6（身份未判、风险已阻止） + 节点7（三系统同时出现未知备注）
- **章首钩子**：康宁巷物业经理发消息来时，镜辞已经穿好外套准备出门。守钟人只看了他一眼：“你昨天写的三天，是写给谁看的？” 镜辞站在门口，最后把外套脱了。
- **本章即时兑现**：第53章“无镜辞到场也能预防”的方法，第一次遇到真实来访者并完整阻断风险
- **本章禁止提前释放**：来访前夫是否为壳、三系统同步备注来源、正式身份同步技术、幕后组织
- **能力边界**：镜辞不在现场，没有资格写“壳”或“接缝”；方法能保护人，但不能替代超自然调查与主体判断
- **契约风险**：契约安全。家庭暴力/离婚关系若涉及安全风险，只处理门禁与住户意愿，不写成猎奇冲突；不暴露当事人无关隐私

#### 内容概括（五段式）
- **起因**：康宁巷9号楼物业在上线前筛查发现，一户女性住户名下的前夫被系统重新补成“配偶/家庭成员”，永久门禁待02:17恢复。旧纸册却清楚记录两人多年前已离婚，前夫门禁也由住户本人申请注销。物业通过同行渠道询问安平里该怎么留证。
- **发展**：镜辞看到消息，下意识穿外套想过去。守钟人提醒他刚决定暂停现场。他最后只通过安平里经理转达三件事：先问住户本人当前意愿；保留同步前状态；按已有安全流程处理权限，不讨论“这个前夫到底还是不是前夫”。住户明确回复：不允许恢复，也不同意对方进入住所。
- **转折**：康宁巷物业保存旧注销记录、当前书面意愿和系统待同步字段。凌晨02:17，上游任务果然把前夫权限恢复为正常家庭成员。本地值班人员按住户申请立即暂停，同时生成“上游恢复—本地安全冻结”的完整审计链。
- **高潮**：第二天下午，真有人使用与该前夫身份匹配的有效门禁凭证到场。设备识别出身份，却因本地安全暂停拒绝开门。物业没有和来人争“你是不是本人”，只通知：该住户已明确取消进入授权，如有财产或身份争议走正式程序。来人站了一会儿，最终离开。整个过程没有镜辞、没有镜返，也没有英雄冲出来挡门。
- **结尾**：猫眼在当事住户授权后，只拿到去姓名的权限日志和一段异常字段变化。镜辞在自己记录里第一次写：`身份未判；风险已阻止。` 他盯着这八个字看了很久，觉得比“确认一只壳”更重要。随后猫眼指出另一处怪事：凌晨02:17:03，物业端、社区服务端和门禁服务端同时多出一句完全相同的关系备注：`婚姻关系存续，家庭成员恢复。` 三个系统的本地人员都说自己没填过。

#### 情节安排（多线）
- **主线推进**：分布式现实保护方法成功独立运行；同步异常从权限字段升级到跨系统一致关系备注
- **辅线推进**：镜辞的成长从“我必须去”转为“我可以让别人依据自己有权掌握的事实行动”
- **事件线/任务线**：收到预警 → 不去现场 → 留旧版本 → 住户确认 → 同步恢复 → 本地冻结 → 来访被拒 → 发现三系统备注
- **任务卡点**：镜辞焦虑想赶现场 → 自身状态不适合 → 普通流程能解决安全问题 → 主角必须忍住把自己变成必要条件
- **感情线/关系线**：守钟人通过一句提醒维护镜辞的边界；安平里与康宁巷物业同行之间出现基于真实失败经验的横向影响
- **逻辑线**：上游偏好标准关系 → 前夫权限自动恢复 → 当事人现实意愿与之冲突 → 本地制度先保护人 → 同步开始跨系统传播统一关系说明

#### 人物关系和出场顺序
- **出场顺序**：镜辞/守钟人 → 安平里物业经理（中转） → 康宁巷物业/住户（消息与授权记录） → 来访者（远端事件） → 猫眼
- **人物关系变化**：镜辞开始真正接受“别人不是他的辅助角色，他们可以独立完成保护行动”
- **视角/信息差**：所有人都不知道来访者是否存在身份错位；这个未知不妨碍先尊重住户当前边界
