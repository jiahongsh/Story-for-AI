# 细纲 · 第45章 改回来

## 第 45 章：改回来
- **核心事件**：在许德昌和许棠同意下，镜辞帮他们把旧纸质登记、长期缴费记录、住院陪护和邻居证明整理成一套简单材料。物业经理承认“长期住户/紧急联系人”可以人工恢复，不必等法律收养关系解决。当天许棠门禁与紧急联系人权限恢复，形成一次小胜。可第二天清晨，新系统又把她自动改回“长期访客”，紧急联系人再次清空。物业后台日志显示不是工作人员手改，而是凌晨02:17一次“上游批量同步”覆盖了人工修正。猫眼保存下同步前后版本。章尾，镜辞确认：这不是一次录入错误，而是一套会持续把非标准关系压回统一答案的机制。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第45章；安平里关系单元第一轮高潮
- **单元ID/位置**：1-4；第5拍·人工修正 vs 上游覆盖
- **目标情绪**：整理证据 → 现实协商 → 小胜 → 一夜后被抹回去 → 机制性寒意
- **主角目标/关键选择**：镜辞想确认本地人工判断能否覆盖系统分类；关键选择=不要求物业把许棠“法律上改成女儿”，只争取有生活事实支撑的实际住户/联系人权限
- **章节定位**：小高潮+制度机制曝光；主角取得局部成果后立刻遭遇系统性反扑
- **本章结构公式**：节点1（整理旧版本材料） + 节点2（物业协商） + 节点3（人工恢复权限） + 节点4（居民日常短暂恢复） + 节点5（次晨自动回退） + 节点6（02:17批量同步日志）
- **章首钩子**：许棠没有要求物业证明“我是他女儿”，只把那本旧登记册推过去：“你们至少先把我改回能在他出事时接到电话的人。”
- **本章即时兑现**：第41-44章积累的关系基线与旧版本证据真正改变现实；同时确认问题来自持续同步机制而非单个工作人员误操作
- **本章禁止提前释放**：上游接口真实来源、关系归并/身份同步名称、安平里完整实验目的、幕后组织
- **能力边界**：本章完全靠现实材料、程序和版本日志推进，不使用镜返破解系统
- **契约风险**：契约安全。小胜必须真实有效至少一段时间，回退也必须留下可追查证据，不能为了黑幕强行让所有努力归零

#### 内容概括（五段式）
- **起因**：镜辞没有替许家“证明亲情”，而是把能支持实际权限的材料列出来：旧物业登记、许棠长期缴物业费的记录、医院陪护票据、老许过去几年填写的紧急联系人卡、邻居愿意作证的共同生活事实。许棠自己筛掉隐私过重又没必要的东西。
- **发展**：物业经理起初说系统分类是统一下发，改不了“家庭成员”字段。镜辞问的却不是这个：“长期住户权限和紧急联系人能不能人工设置？” 经理查流程后承认可以。许德昌在旁边只说一句：“你别管系统叫她什么，先让她能回家、我倒了能有人找她。”
- **转折**：当天下午，许棠的门禁恢复为长期住户，紧急联系人也重新挂回302。她第一次刷卡直接进门，许德昌站在里面说“这不就完了”。305大姐照旧把一袋菜让她顺路带上楼。小胜很小，却确实改变了现实行动。
- **高潮**：第二天清晨，许棠出门买早点回来，门禁再次提示“访客权限”。她以为物业又改了，直接去办公室。经理当着她的面打开后台，自己也愣住：昨天下午人工修改记录还在，但凌晨02:17出现一条批量任务，来源栏只写“上游同步”，把302关系数据重新覆盖成核验日版本，紧急联系人同步清空。
- **结尾**：猫眼在获得许棠授权后只保存这条住户的前后日志与时间，不碰全楼个人数据。镜辞把三版状态排在一起：旧系统长期承认她；人工修正再次承认她；上游同步两次把她压回访客。他在账本写：`不是一次写错。它会反复把不标准的答案改回去。` 这才是安平里真正让他发冷的地方。

#### 情节安排（多线）
- **主线推进**：确认安平里存在持续的上游统一同步机制，会主动覆盖本地人工判断
- **辅线推进**：镜辞学会把“关系真实性”和“行政字段/实际权限”分开解决，不试图一次赢下全部定义权
- **事件线/任务线**：收材料 → 谈权限 → 人工修复 → 小胜 → 自动回退 → 保存日志
- **任务卡点**：家庭成员字段无法改 → 镜辞退一步争实际权限 → 成功 → 上游自动覆盖 → 获得更高层机制证据
- **感情线/关系线**：许德昌/许棠关系通过“能回家、能接电话”这种现实需求继续落地；镜辞不是救世主，只帮助他们争取已有生活事实对应的行动空间
- **逻辑线**：旧关系有现实证据 → 本地制度可以人工承认 → 上游批量同步强制覆盖 → 问题不是单个物业判断

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 许棠/许德昌 → 物业经理 → 305大姐 → 猫眼（远程保存版本）
- **人物关系变化**：许家从被动接受系统分类变成主动争取现实权限；物业经理也第一次成为“系统结果不等于本地判断”的见证者
- **视角/信息差**：读者与镜辞都只看到“上游同步”四个字，不知道上游具体是谁、为何必须把许棠压成访客
