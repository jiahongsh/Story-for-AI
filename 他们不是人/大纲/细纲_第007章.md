# 细纲 · 第7章 摊牌前夜

## 第 7 章：摊牌前夜
- **核心事件**：镜辞决定与芽摊牌，但摊牌前发现更多"壳"的痕迹——恐惧从"芽"泛化到"身边很多人"
- **字数目标**：3000 字
- **阶段位置**：开篇期；第1阶段第7章；世界观泛化（"谁不是我"的核心恐怖展开）
- **单元ID/位置**：1-1；第7拍·加压（恐怖的泛化）
- **目标情绪**：决心（摊牌）→ 恐惧扩散（不止芽一个）→ 孤立（只有我能看见）；本章推进情绪引擎"压抑累积"的扩张
- **主角目标/关键选择**：镜辞决定与芽摊牌；关键选择=他在摊牌前夜最后一次"检视"旧货市场，发现"不止芽"
- **章节定位**：普通推进（恐怖泛化+决心铺垫）
- **本章结构公式**：节点1（摊牌决心·准备说辞） + 节点2（旧货市场夜巡·发现多处接缝） + 节点3（卖水果老王当众"换脸"瞬间·实锤） + 节点4（恐惧泛化·"谁不是我"·章尾钩子）
- **章首钩子**：延续钩子（"安全的芽去哪了"——镜辞决定摊牌）
- **爽点**：识破爽点（镜辞"看见"老王换脸的实锤瞬间）；往下看的理由=摊牌结果+谁不是我
- **本章禁止提前释放**：壳的完整设定/壳巢/镜返代价
- **契约风险**：契约安全

#### 内容概括（五段式）
- 起因：镜辞决定摊牌——他要直接问芽："你到底是谁？"他把说辞在心里过了三遍，晚上出门想再确认一次"那个人是不是芽"。
- 发展：他路过旧货市场，看见卖水果的老王在收摊。老王背对着他，肩膀忽然僵了一下——然后，老王"换脸"了：那张脸像水面的倒影被风吹皱，晃了一下，又恢复正常。整个过程不到一秒，镜辞却看得清清楚楚。
- 转折：他想起自己三天前排查时，老王身上有"淡淡的光"。而现在，那个"光"已经不见了——取而代之的是"标准"得体的笑，跟芽一模一样的那种"标准"。
- 高潮：镜辞站在原地，冷汗下来了。他忽然意识到：不是"老王变了"，是"老王早就变了"——只是他以前看不见。他看见接缝才几天，而这些人，可能已经变了很多年。
- 结尾：他转身，快步往芽家走——他要摊牌，而且他必须搞清楚：这座城里，到底有多少人，已经不是人了？（章尾钩子）

#### 情节安排（多线）
- **主线推进**：恐怖泛化（"谁不是我"从芽扩散到全城）+ 摊牌决心
- **辅线推进**：老王的"换脸"（壳的日常恐怖实证）
- **事件线/任务线**：夜巡旧货市场（确认芽前的最后一次观察）
- **任务卡点**：镜辞想确认芽 → 卡在"先撞见老王换脸" → 卡出"早就有很多人变了" → 删掉损失=恐怖不泛化 → 收束动作=转向芽家摊牌
- **感情线/关系线**：镜辞×芽=摊牌前的最后犹豫（他怕摊牌=失去最后一点"芽还是芽"的可能）
- **逻辑线**：决心摊牌（原因）→ 夜巡撞见老王换脸（行动）→ 恐惧泛化（结果）→ 全城有多少"不是人"（后果/新问题）

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 旧货市场（老王换脸实锤）→ （远处摊主群像）→ 芽家方向（章尾）
- **人物关系变化**：镜辞×世界：本章后=从"身边可能有壳"到"身边已经有很多壳"（世界观恐怖全面展开）
- **视角/信息差**：读者与主角同信息量；老王换脸是"壳存在"的第一个确凿实锤（但读者仍不知"壳"这个名称）
