# 细纲 · 第7章 摊牌前夜

## 第 7 章：摊牌前夜
- **核心事件**：镜辞准备与芽摊牌前，第4章那个灰衬衫白领回来取表。几小时后，维修单上的本人却打电话说自己根本没来过。镜辞第一次拿到“同一个社会身份被另一个存在使用”的现实证据。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；第7章；将芽的私人异常扩大为更广泛的身份异常
- **单元ID/位置**：1-1；第7拍·第三方实证
- **目标情绪**：摊牌决心 → 工作日常 → 身份错位 → 现实证据落地 → 风险扩大
- **主角目标/关键选择**：镜辞原本准备今晚去找芽；关键选择=先把白领事件记录完整，再决定是否带着这个证据去摊牌
- **章节定位**：调查推进章；必须给出一个不依赖主角“我感觉”的外部事实冲突
- **本章结构公式**：节点1（准备摊牌） + 节点2（灰衬衫白领取表） + 节点3（接缝复现） + 节点4（真正客户来电） + 节点5（镜辞锁定身份被重复使用）
- **章首钩子**：镜辞在纸上写了三个问题准备晚上问芽，第一问是“你是谁”。还没写第二问，第4章那个灰衬衫白领推门进来，说：“我的表修好了吧？”
- **本章即时兑现**：身份异常第一次从私人关系进入可核验的现实记录，主角的怀疑拥有了客观抓手
- **本章禁止提前释放**：壳的正式分类、组织体系、裂缝、EX、替换流程
- **设定边界**：一个重复身份事件只能证明“有人在冒用/承接同一身份”，不能推出全城已经被替换
- **契约风险**：契约安全。镜辞通过自己的工作记录拿到证据，不靠神秘人喂答案

#### 内容概括（五段式）
- **起因**：镜辞准备今晚找芽摊牌，先在纸上列问题。灰衬衫白领恰好来取前几天送修的机械表。对方准确报出姓名、手机号后四位、表的问题和取件金额。
- **发展**：镜辞在柜台玻璃里再次看见对方领口下的接缝。为了确认不是自己眼花，他换了三个角度，异常都在。他没有拆穿，只按正常流程让对方签字取表，并故意留下取件时间和签名。
- **转折**：当天傍晚，维修单上的手机号打进来。电话里的男人问：“我的表修好了吗？我这两天一直在外地，明天回去拿。”镜辞看着空掉的表盒，问了姓名、型号和故障，全部与下午那个取表人一致。
- **高潮**：镜辞调出店内最普通的监控片段。下午取表的人脸清清楚楚，和客户登记照完全一致；签名也近似。唯一说不通的是，电话那头的人正在另一个城市发来实时视频，手腕上还戴着另一块表。镜辞第一次意识到，自己面对的不是“一个熟人变了”，而是某种东西正在使用人的身份。
- **结尾**：他把三张东西并排放在桌上：维修单、下午签名、客户发来的视频截图。然后把原本写着“你是谁”的那张纸折起来塞进口袋，关了店门，往芽家走。

#### 情节安排（多线）
- **主线推进**：从关系异常升级为社会身份异常，外部证据首次成立
- **辅线推进**：第4章灰衬衫白领伏笔回收；钟表摊职业设定真正参与破局
- **事件线/任务线**：取件 → 记录 → 来电矛盾 → 视频复核 → 决定摊牌
- **任务卡点**：镜辞原本只想处理芽 → 第三方异常插入 → 发现同一身份同时存在两处 → 私人问题扩大成城市风险
- **感情线/关系线**：镜辞×芽：摊牌动机从“我想知道你是不是芽”升级为“我必须知道你和这些身份异常有没有关系”
- **逻辑线**：第4章第二例接缝 → 第7章该对象再次出现 → 客户来电否认取件 → 身份重复成立 → 摊牌必要性上升

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 灰衬衫取表人 → 电话里的真正客户 → 芽只作为章尾目标
- **人物关系变化**：镜辞×世界：从“也许只有少数熟人不对”转为“正常社会记录也可能被身份冒用穿透”
- **视角/信息差**：读者与镜辞共同掌握客观冲突，但仍不知道哪个“周远”才是真正本人，甚至不知道“真正”应如何定义

#### 情节细化
- 点1：镜辞列摊牌问题，突出他已经决定推进而不是继续拖【开场/决定·密250】
- 点2：灰衬衫白领进店取表，准确报出全部取件信息【悬念·密300】
- 点3：镜辞在反射和肉眼中复核接缝，不做更多刺激行为【能力/边界·密300】
- 点4：对方签名离开，镜辞保存时间和监控【调查·密250】
- 点5：真正客户傍晚来电，称自己人在外地且未取表【转折·密400】
- 点6：镜辞反向核对型号、旧磕痕、维修内容，电话双方信息全部吻合【证据·密350】

#### 结尾设定和钩子
- **结尾设定**：镜辞首次掌握不依赖“看见接缝”也成立的身份冲突证据
- **章尾钩子**：如果灰衬衫男人可以使用别人的身份，那么眼前的芽到底继承了什么，又拿走了什么？
