# 细纲 · 第38章 同一张脸

## 第 38 章：同一张脸
- **核心事件**：猫眼从恒泰设施公开招聘旧页面、项目照片和合作方资料里找到一名技术员“陈屿”。照片里的脸与第7-10章冒用“周远”身份来取表、威胁镜辞的灰衬衫男人完全相同。更麻烦的是，“陈屿”这套职业履历在多个独立来源里至少存在五年，而真正的周远也有自己的长期生活记录。镜辞去临江03号外围观察一场公开维护，亲眼看到同一张脸被同事自然叫作“陈工”。镜返第一式仍能看到接缝，但比第10章明显变淡。章尾，对方经过镜辞身边，只随口问了一句：“今天的表，还准吗？”
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第38章；身份恐怖重新压回人物
- **单元ID/位置**：1-3；第13拍·同脸双身份
- **目标情绪**：来源链发现 → 不可能的双重履历 → 现场确认 → 接缝变淡 → 对方主动确认镜辞仍在观察
- **主角目标/关键选择**：镜辞想确认恒泰施工链里是否有自己见过的人；关键选择=只在公开区域观察并比对旧证据，不试图当场拆穿“陈屿”
- **章节定位**：身份恐怖+现实调查；把技术线重新落回“一个熟悉的人到底是谁”
- **本章结构公式**：节点1（猫眼找到陈屿照片） + 节点2（与周远冒用者旧影像比对） + 节点3（两套长期身份同时成立） + 节点4（03号现场见到陈屿） + 节点5（接缝变淡） + 节点6（擦肩一句话）
- **章首钩子**：猫眼把电脑转过来，只说：“你上次那个冒领表的人，换了个名字以后，履历比我们查到的周远还完整。”
- **本章即时兑现**：第7-10章灰衬衫男人重新进入当前主线；D4“修得更难看见”第一次落到具体身份使用者身上
- **本章禁止提前释放**：陈屿到底是不是壳、同一载体如何拥有两套历史、接缝修复技术名称、壳巢/白塔
- **能力边界**：镜返只能确认自己仍看到身份错位接缝，不能读取陈屿记忆，也不能仅凭接缝判定哪套身份才是“原主”
- **契约风险**：契约安全。双身份结论来自旧影像与多来源记录互证，不靠人脸识别软件一句100%匹配宣布真相

#### 内容概括（五段式）
- **起因**：猫眼在恒泰设施几年前的项目新闻里发现一张合影。站在设备柜旁的男人穿工装，胸牌写“陈屿”。镜辞第一眼就认出那张脸：第7章来取表、第10章堵卷帘门的灰衬衫男人。猫眼不接受“看着像”，让镜辞拿出当时保存的监控截图，从耳廓、左眉旧疤、右手小指弯曲三个稳定特征逐项比。
- **发展**：更麻烦的是陈屿不是临时假身份。猫眼找到五年前项目名单、三年前行业培训签到、两年前合作方通讯录，来源彼此独立。与此同时，真正周远在另一座城区有连续工作、家人和缴费痕迹。不是一套资料替掉另一套资料，而是同一张脸在两个方向上都长出了长期历史。
- **转折**：恒泰将在临江03号做一次公开外围维护。镜辞不接触内部，只在公共步道观察。那男人真的来了，穿反光背心，被两个同事自然喊“陈工”；他知道工具放在哪辆车、知道谁负责哪个柜子，动作不像临时背过流程。现场所有社会关系都顺着“陈屿”这一身份自然运作。
- **高潮**：镜辞隔着十几米看他。第10章时那道耳后接缝明显得像皮肤错开一层；现在同一位置仍有线，却细了很多，只有当陈屿和一名老同事说笑、转身应答时才会突然浮一下。镜辞第一次确认：所谓维护不仅在修地点，也可能在降低某个身份错位被他看见的程度。
- **结尾**：施工结束，陈屿跟同事往车边走。经过公共步道时，他没有停，也没有看镜辞，只像随口跟陌生人聊天一样说：“今天的表，还准吗？”镜辞没回答。陈屿已经走过去。镜辞这才确定，对方知道他在这里，也知道他在看什么。

#### 情节安排（多线）
- **主线推进**：灰衬衫男人与恒泰当前施工链连接；身份处理效果已经从地点扩展到具体身份表现
- **辅线推进**：猫眼证明“长期资料完整”仍不等于主体连续；第9章习惯不是身份证的判断再次获得更大尺度验证
- **事件线/任务线**：旧网页发现 → 人工特征比对 → 双身份来源核验 → 公开现场观察 → 接缝变化 → 对方擦肩确认
- **任务卡点**：同一张脸不够证明 → 猫眼要求多来源 → 两套资料都长期完整 → 镜辞无法用“哪份档案更真”简单判定
- **感情线/关系线**：镜辞×猫眼形成更成熟分工：她保版本，他看错位，两人都不能单独宣布谁是谁
- **逻辑线**：恒泰清理链 → 找到陈屿 → 陈屿=旧灰衬衫脸 → 两套长期身份并存 → 接缝比从前更淡

#### 人物关系和出场顺序
- **出场顺序**：猫眼 → 镜辞 → 陈屿/灰衬衫男人 → 恒泰普通同事
- **人物关系变化**：灰衬衫男人从“冒领者”升级为有完整社会履历的当前身份使用者，威胁从伪装技巧升级为现实连续性问题
- **视角/信息差**：陈屿显然知道镜辞仍在做机械表测试，但不解释自己究竟是谁
