# 细纲 · 第36章 假答案

## 第 36 章：假答案
- **核心事件**：承接D4测试短信。镜辞没有立刻回复，而是把对方的问题当成一次反向实验：D4东、西两侧在他眼里都仍有接缝，但西侧更明显。他故意回复“东侧已经看不见，西侧还残着一点”。当晚他与守钟人只在公共区域远距离观察，D4西侧突然出现一支夜间检修队，东侧没有动作。第二天西侧机械计时依旧正常，但镜辞看到的接缝明显变淡。章尾，他确认：对方会根据他的反馈调整现场。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第36章；单元1-3反调查启动
- **单元ID/位置**：1-3；第11拍·第一次反向测试
- **目标情绪**：被测试的不适 → 主动设局 → 等待反馈 → 夜间施工兑现 → 更大的不安
- **主角目标/关键选择**：镜辞想确认“他们是否真的在拿自己的眼睛做校准”；关键选择=第一次主动给对方一条经过设计的、不完全真实的反馈，并在回复前保留原始记录
- **章节定位**：智斗+调查推进；主角第一次利用敌人的需求，而不是继续被动收线索
- **本章结构公式**：节点1（分析短信） + 节点2（重新测D4东西两侧） + 节点3（设计假反馈） + 节点4（夜间西侧单独检修） + 节点5（次日复测） + 节点6（确认反馈闭环）
- **章首钩子**：短信只有一句：“旧表已经看不见了。你还看得见，对吗？”镜辞盯了十分钟，没有回“是”或“不是”，而是问守钟人：“如果他们真想知道答案，我能不能先给他们一个错的？”
- **本章即时兑现**：第35章“他们在测试我的眼睛”从猜测变成可验证反馈闭环
- **本章禁止提前释放**：接缝修复技术名称、幕后组织身份、为什么镜辞的感知特殊、守夜人正式组织、镜返2阶
- **能力边界**：镜返1阶仍只有被动可见性；镜辞无法量化“接缝剩余百分比”，只能按相同观察条件比较强弱
- **契约风险**：契约安全。敌人不是因为愚蠢才听主角一句话，而是把他的反馈作为已有内部测量之外的外部验收样本

#### 内容概括（五段式）
- **起因**：镜辞把陌生短信、D4现场照片和三块机械表的记录摊在桌上。他先做最简单的事：不回复。第二天白天，他再次去D4公共河堤，从同样位置观察东、西两侧。两边仍能看见细微身份/环境错位，其中西侧更明显。
- **发展**：守钟人提醒他：“你想骗他们，先得知道他们自己知道什么。”镜辞不编一个完全不存在的异常，只把真实差异故意夸大：回复`东侧基本看不见，西侧还留着。` 同时把发送时间、现场照片和自己原始判断封存，防止事后记忆被带着跑。
- **转折**：当天夜里，D4并未全面施工。镜辞在河对岸公共步道远远看见两辆维护车进入，施工人员只围住西侧设备间，更换一段不起眼的传感/控制组件并重新做线缆整理。东侧没有任何动作。凌晨一点多车辆离开。
- **高潮**：次日上午，镜辞按同样路线复测。三块机械表依然走齐，守钟人仍能抓到极轻的因果错位；但镜辞看到的西侧接缝比昨天淡了一层，东侧基本没变化。敌人的施工方向与他昨晚故意给出的反馈完全一致。
- **结尾**：镜辞没有兴奋。他把前后照片并排贴进账本，只写：`他们不是在问我哪里有问题。他们已经知道问题在哪。他们问的是——他们修完以后，我还看不看得见。` 手机没有再来消息。可这一次，沉默本身已经回答了问题。

#### 情节安排（多线）
- **主线推进**：未知网络正式形成“内部处理 → 镜辞外部可见性验收 → 再调整”的闭环
- **辅线推进**：守钟人提供实验设计上的谨慎，不替镜辞做决定
- **事件线/任务线**：分析短信 → 复测 → 设计假反馈 → 远距观察施工 → 次日复测 → 得出反馈闭环
- **任务卡点**：镜辞想反骗 → 守钟人指出完全虚构会暴露 → 改成夸大真实差异 → 对方响应 → 实验成立
- **感情线/关系线**：镜辞×守钟人从专业协作进一步变成能互相质疑方法的搭档
- **逻辑线**：对方问“还能不能看见” → 镜辞给方向性反馈 → 施工只改对应区域 → 可见性随后变化

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 守钟人 → D4夜间普通检修人员（远景）
- **人物关系变化**：镜辞第一次不把未知网络当单纯追杀者，而是识别出它需要自己的某种观测结果
- **视角/信息差**：镜辞仍不知道对方如何判断内部处理是否成功，只知道自己的感知被纳入验收

#### 结尾设定和钩子

- **章尾钩子**：如果镜辞的调查结果能直接改变对方施工，那么他此前查过的17号和03号现在变成什么样了？
