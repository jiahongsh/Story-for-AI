# 细纲 · 第036章《两套时间线》

## 章节定位

- **阶段位置**：第一卷031—050“两个陈骁”单元第6章；承接035“双主体同时被现实承认”。
- **单元任务**：第一次在当事人授权下拆分两套生活来源，建立可比较、不可裁决的证据框架。
- **目标情绪**：调查越认真，身份问题越难被粗暴回答。
- **字数目标**：2600字左右。

## 结构公式

主动到场并限定授权 → 临江七周来源落地 → 宁州九年链形成不对称压力 → 当事人质问命名权 → 留下正在继续的现实后果。

## 核心事件

1. 临江陈骁先到物业，主动接受有限核查，但明确拒绝银行卡与私人聊天记录，姜霁让授权范围写进记录。
2. 房东、配送站、排班与同事分别只证明自己亲历的部分；七周生活短，却已有垫付急诊费、换班等后果。
3. 宁州侧先固定已有的六年汽修、三年租住与多年父子联系，不在本章展开全部九年细节。
4. 姜霁将来源、本人陈述、系统承认、他人后续选择分栏，镜辞把“更像真的”修正为“连续性更长”。
5. 临江陈骁追问为什么自己的名字前总要加“临江”，迫使镜辞承认两套时间线都不能被表格直接删掉。

## 人物与小人物

- 出场顺序：临江陈骁 → 杜经理 → 姜霁、镜辞 → 房东 → 马负责人、小赵。
- 杜经理要承担资料调用和隐私边界，不当物业API。
- 房东只谈漏水、房租和日常，不判断身份。
- 小赵的母亲急诊与换班形成临江七周的第一条持续后果。

## 可释放与禁止提前释放

- **可释放**：临江陈骁七周工作、租住与同事关系可独立核验；宁州连续性明显更长。
- **禁止**：复制时间点、谁是真人、七周生活是否等于新存在锚点、02:17操作者、临江陈骁是否参与替代。
- 接缝不得进入公开核查结论；本章不新增能力表现。

## 章尾钩子

配送站次日有一趟必须完成的医院设备配送，小赵母亲又要复查；临江陈骁的“七周”将在调查之外继续制造现实选择。
