# 细纲 · 第30章 顺记里面

## 第 30 章：顺记里面
- **核心事件**：镜辞通过产权人以“看铺准备承租”的方式合法进入顺记。前堂确实像停业多年，但后间明显近期使用：新插线板、打印纸、快递纸箱、拆开的计时组件。最关键的是，他找到一张最近维修单，客户名写“周远”，联系电话正是第7-10章灰衬衫身份使用者留下的号码；旁边三只零件袋分别标着`17`、`03`、`D4`。东里巷当前网络与此前身份冒用者、旧测点网络第一次在同一房间交叉。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第30章；单元1-3第一轮高潮
- **单元ID/位置**：1-3；第5拍·节点交叉
- **目标情绪**：合法进入仍紧张 → 前堂像废店 → 后间新旧分层 → 周远名字出现 → 三个测点代码同场 → 被当前使用者发现
- **主角目标/关键选择**：镜辞想确认顺记当前被用来做什么；关键选择=只拍公开可见和产权人允许查看的物件，不翻封闭私人柜、不带走任何东西
- **章节定位**：阶段高潮；必须完成一次多线交叉，而不是再发一张神秘纸条
- **本章结构公式**：节点1（产权人带看） + 节点2（前堂旧层） + 节点3（后间近期使用层） + 节点4（周远维修单） + 节点5（17/03/D4零件袋） + 节点6（女人现身）
- **章首钩子**：房东把顺记卷帘门拉起来时，灰尘味是真的。可插座旁那根白色电源线，塑料还新得发亮。
- **本章即时兑现**：周远身份冒用线、旧测点线、东里巷当前使用者三条线第一次形成现实交叉
- **本章禁止提前释放**：壳巢正式名称、顺记整个后台组织、D4完整用途、女人身份、老郑现状
- **能力边界**：镜辞仍只能被动看接缝，本章破局靠观察、来源和合法进入，不靠技能升级
- **契约风险**：契约安全。第30章给实质性阶段收获，同时保留更大的组织谜团

#### 内容概括（五段式）
- **起因**：镜辞联系到顺记产权人，说自己也是修表的，想看看旧铺是否适合承租。房东只知道店面多年没人正式做生意，收到租金或代缴款时也懒得管，愿意带他进去看看。
- **发展**：前堂和橱窗确实积灰，旧工具大多锈死。镜辞按守钟人提醒先分“老东西”和“最近东西”：后间地面有新拖痕，一只插线板是近几年型号，垃圾桶里有新快递封条，工作灯灯泡没有积灰。
- **转折**：工作台边压着几张近期维修单。镜辞不翻抽屉，只看露在桌面的那张：客户“周远”，电话正是灰衬衫男人取表时留下的号码，日期在第10章冲突之后。这个名字不是第一次被冒用，而是仍在顺记当前记录里活动。
- **高潮**：旁边三只透明零件袋上用打印标签写着`17`、`03`、`D4`，里面都是老式计时组件和腐蚀零件。17和03是镜辞已经亲自确认的旧测点；D4正是第23章柳树测时牌指向的下游代码。旧观测网络没有只躺在历史里，有人正在把这些点重新收拢进顺记。
- **结尾**：房东的手机突然响了。对方听了两句，脸色变得尴尬，说“这铺有人不租了，咱先出去”。镜辞没有争，拍完允许范围内最后一张照片就离开。巷口，第25章那个女人站在路边。她看着镜辞：“里面比你想的旧，还是比你想的新？”镜辞反问：“你们让我来，不就是想让我看见这些？”女人没有回答，只笑了一下。

#### 情节安排（多线）
- **主线推进**：顺记当前网络与周远身份线、17/03/D4测点线完成交叉
- **辅线推进**：未知势力对镜辞的引导更明确，但动机仍不揭
- **事件线/任务线**：合法看铺 → 分层观察 → 周远维修单 → 测点零件袋 → 突然终止看房 → 巷口对峙
- **任务卡点**：店内旧物很多容易误导 → 守钟人方法帮助分新旧 → 新物件直接连接现行案件 → 对方及时叫停看房
- **感情线/关系线**：镜辞第一次确认自己不是只在追沈竹旧案，当前有人正沿着同一套旧设施活动
- **逻辑线**：假关闭顺记 → 当前使用者 → 老郑旧用途 → 合法进店 → 周远+旧测点同场 → 当前网络成立

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 房东 → 陌生女人（章尾）
