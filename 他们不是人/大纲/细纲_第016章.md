# 细纲 · 第16章 十七号树

## 第 16 章：十七号树
- **核心事件**：镜辞抵达北河村，与眼前存在一起实地核查17号测点。两人确认铜牌属于二十多年前的旧河道观测编号，而不是私人记号。更关键的是：怀表在重新走时后一直稳定，却只在17号测点附近出现持续漏拍，离开几十米便恢复。镜辞用手机计时和另一块普通机械表做对照，确认这是环境异常，不是怀表“认地方”。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2起点；第16章；北河现场调查
- **单元ID/位置**：1-2；第6拍·现场验证
- **目标情绪**：抵达后的陌生感 → 找到编号来源 → 怀表异常 → 对照验证 → 确认这里曾被系统观察过
- **主角目标/关键选择**：镜辞想知道17号测点是什么；关键选择=出现怀表异常后不立刻往“沈竹在附近”上猜，而是用第二块表与手机计时做控制组
- **章节定位**：调查+职业能力兑现；主角主动获得可复核现象
- **本章结构公式**：节点1（抵达17号树） + 节点2（找到旧观测牌信息） + 节点3（怀表漏拍） + 节点4（控制组测试） + 节点5（划出异常范围） + 节点6（发现旧设备固定孔）
- **章首钩子**：昨夜从夹层取出纸条、重新装好后，那块多年不走的怀表第一次连续走了十二个小时。镜辞走到17号树下，它忽然漏了一拍。
- **本章即时兑现**：怀表的“异常样本”功能第一次以可测试方式进入剧情
- **本章禁止提前释放**：裂隙正式理论、17号测点真正项目名称、守夜人体系、沈竹当前状态
- **设定边界**：怀表只能提示环境可能异常，不能定位活人、判断壳或自动解释原因
- **契约风险**：契约安全。职业能力和调查方法持续成为主角代理权来源

#### 内容概括（五段式）
- **起因**：镜辞坐早班车到北河村。眼前存在已经在老槐树旁等他，没有喊“镜辞哥”，也没有装回原芽的说话方式，只把这几天的原始照片、录音和村委公开资料递给他。
- **发展**：两人清理树根旁的泥，完整露出铜牌：`17`下面还有一行几乎锈死的小字，能辨出“旧河道补测”。附近老水泥基座上有四个规则螺栓孔，证明这里过去确实安装过测量设备。镜辞把位置、尺寸和方位全部记录下来。
- **转折**：怀表开始出现不均匀滴答。它昨晚重装后在城里走得稳定，此刻却每隔几十秒漏一拍。镜辞先退到村口，怀表恢复；再回来，又失稳。他借村里修农机的人一块普通机械表，又开手机计时，三种计时工具只有这块老机芯异常。
- **高潮**：镜辞沿树周围每十米测试一次，粗略画出一个不规则范围。最强异常并不以树为中心，而偏向已经干涸的旧河床。眼前存在问：“这是不是说明你妈来过这里？”镜辞摇头：“纸条能说明她知道这里。表只能说明这里现在不正常。别把两件事合成一件。”
- **结尾**：两人走到异常最强的位置，扒开浮土，露出一截已经断掉的金属支架。支架上有被人后来磨掉的编号，只剩一个很浅的字母痕迹。镜辞拍完照，把怀表收回口袋：“先查这套设备是谁装的。”

#### 情节安排（多线）
- **主线推进**：17号从神秘数字变成旧观测点；怀表异常得到控制组验证
- **辅线推进**：眼前存在开始用自己的说话方式和调查动作存在，不再全程模仿原芽
- **事件线/任务线**：到场 → 找编号 → 怀表异常 → 控制实验 → 划范围 → 找旧设备痕迹
- **任务卡点**：怀表异常很诱人 → 主角拒绝直接情感化解释 → 通过对照把它降成“环境样本” → 获得可查设备线
- **感情线/关系线**：镜辞与眼前存在第一次真正并肩调查，但关系仍有边界
- **逻辑线**：沈竹纸条 + 17铜牌 → 现场旧测点 → 老机芯失稳 → 旧设备来源成为下一调查对象

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 眼前存在 → 村里修农机者/村民一笔
- **人物关系变化**：镜辞开始把眼前存在当现场合作者，而不是原芽替代品；但不替她命名
- **视角/信息差**：眼前存在知道自己的主观记忆，镜辞擅长物证和对照，两边互补
