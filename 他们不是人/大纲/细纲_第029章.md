# 细纲 · 第29章 守钟人

## 第 29 章：守钟人
- **核心事件**：镜辞把顺记当前仍有人使用、计时设备包裹、老韩投递本和沈竹代签等证据摆给守钟人，第一次逼他明确回答“顺记以前是什么”。守钟人承认自己认识老郑，也知道顺记过去长期替一批异常观测人员维修廉价计时设备，但拒绝把老郑现在状态、沈竹身世和旧组织全盘交代。他只确认一件关键事实：三年前顺记按理已经停止承担旧用途，如今重新开门的人未必继承原来的立场。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第29章；守钟人第一次针对当前危险做实质交底
- **单元ID/位置**：1-3；第4拍·有限交底
- **目标情绪**：证据压桌 → 老人终于回答 → 历史用途出现 → 仍有信息边界 → 主角获得下一步风险判断
- **主角目标/关键选择**：镜辞想知道是否该把顺记视为“沈竹的安全线”；关键选择=接受“旧用途可信≠当前使用者可信”这一不舒服但必要的答案
- **章节定位**：关系推进+风险校准；守钟人不能成为百科全书
- **本章结构公式**：节点1（镜辞摆证据） + 节点2（守钟人先核来源） + 节点3（承认认识老郑） + 节点4（说明顺记旧用途） + 节点5（拒绝讲家史/组织） + 节点6（确认当前重开异常）
- **章首钩子**：镜辞把老韩的投递本照片、沈竹签名、顺记电表记录和女人开门时间一张张摆开。守钟人看完，只问：“她用的是老郑那把钥匙，还是后来配的？”
- **本章即时兑现**：守钟人从“知道很多但不说”升级为在证据充分时提供必要风险信息
- **本章禁止提前释放**：老郑与沈竹完整亲属关系、守夜人正式结构、存在实验、怀表成对真相
- **契约风险**：契约安全。导师只补主角无法独立获得的历史上下文，不替他查完案

#### 内容概括（五段式）
- **起因**：镜辞不再问“你到底知道多少”，而是把已经核过来源的证据一项项摆出来，最后问：“这家店以前到底干什么？”
- **发展**：守钟人先逐项问证据来源，确认镜辞没有只听陌生女人一面之词后，才承认自己认识顺记的老郑。老郑是修表匠，但顺记过去还接一类特殊活：替一些长期做环境异常记录的人维修和校准便宜机械表、旧计时器和水文设备里的同步部件。
- **转折**：镜辞问这些人是谁。守钟人只说：“以前有人专门管这种走不齐的地方。”不报组织名，也不解释裂隙理论。他承认沈竹后来沿着这些旧测点查过，也确实用过顺记的设备渠道。
- **高潮**：镜辞拿出第28章女人开门和新包裹记录。守钟人脸色变了：三年前顺记就不该继续承担旧维修任务，至少他知道的那条线已经停了。如今有人重新开店、继续收计时设备，说明“旧地方被新的人拿去用了”。这比店里藏着什么更危险，因为它意味着旧观测网络可能正在被重新启用。
- **结尾**：镜辞问：“那我还能进去查吗？”守钟人说：“能。别撬门，找房东。进去以后先看什么是旧的，什么是最近才放进去的。最容易骗人的，不是假的，是把真的东西摆到错误的位置。”

#### 情节安排（多线）
- **主线推进**：顺记旧用途获得历史解释；当前重启被判定为异常
- **辅线推进**：守钟人开始教“新旧层次判断”，但仍保持信息边界
- **事件线/任务线**：摆证据 → 核来源 → 历史说明 → 当前风险 → 制定合法进入方案
- **任务卡点**：镜辞想知道“顺记是不是安全” → 历史上曾可靠 → 当前使用者未知 → 只能分开判断过去与现在
- **感情线/关系线**：镜辞×守钟人：关系从“你为什么瞒我”进入“我拿证据来，你告诉我证据触及的历史”
- **逻辑线**：顺记历史维修网络 → 三年前应停 → 当前重新收件 → 旧节点被新网络重新利用

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 守钟人
- **人物关系变化**：守钟人开始把镜辞当能承担有限风险信息的成年人，而不是必须一直挡在门外的孩子
- **视角/信息差**：守钟人仍知道老郑与沈竹更深关系，第一卷不揭
