# 细纲 · 第18章 旧物

## 第 18 章：旧物
- **核心事件**：镜辞第一次主动用镜返"照"养母留下的旧物（纸条/夹层纸片）——看见残留痕迹（沈竹写纸条时的影像碎片）；守钟人部分交底（"她不是走了，她是去找答案了"）；章尾钩子：纸条背面浮出第二行字（"别去河"被涂掉？或残留里沈竹说了半句）
- **字数目标**：3000 字
- **阶段位置**：开篇期；第1阶段第18章；单元1-2加压（照旧物+守钟人交底）
- **单元ID/位置**：1-2；第18拍·加压（能力使用+关系推进）
- **目标情绪**：专注（照旧物）→ 震动（沈竹的影像）→ 沉重（守钟人交底）→ 悬念（第二行字）；本章推进情绪引擎"加压→期待"环
- **主角目标/关键选择**：镜辞想从旧物里找到答案；关键选择=他第一次主动把镜返用在一件死物上——他开始把能力当成工具（代价的入口）
- **章节定位**：悬念+情感（能力进阶+养母真相半揭）
- **本章结构公式**：节点1（照纸条·第一次主动照旧物） + 节点2（残留影像·沈竹写纸条） + 节点3（残留里她说了半句话） + 节点4（守钟人部分交底） + 节点5（"她去找答案了"） + 节点6（章尾·纸条背面第二行字）
- **章首钩子**：承接钩子（照片背面"去看河"——他先没去，他先回了钟表行）
- **爽点**：能力点（照旧物=镜返新用法）+ 信息点（沈竹写纸条的影像）；往下看的理由=第二行字+她去找什么答案

- **章节内时间**：周三（清晨→深夜）

#### 内容概括（五段式）
- 起因：周三早上，镜辞坐在钟表行里，面前摊着养母的遗物：怀表、纸条、夹层纸片。他决定用那双眼睛，照一照它们。
- 发展：他先照纸条。他定住心神，把目光落在纸条上。残留浮上来：沈竹坐在灯下，写那张纸条。她写"别让任何人知道，你能看见"，停了一下，又写"芽是安全的"。她写得很慢，像在斟酌。
- 转折：残留里，沈竹放下笔，看着窗外，说了一句话。他听清了前半句："如果有一天，他问起来……"后半句，被一阵风一样的东西搅碎了。他看不到她说完。他试着再照一次，残留已经淡了。
- 高潮：傍晚，守钟人来。镜辞问他："她去找什么答案？"守钟人沉默了很久，说："你妈走之前，跟我说过一句话。她说，她不是走了，她是去找答案了。找那个'被吃掉的人能不能回来'的答案。"
- 结尾：守钟人走后，镜辞把纸条翻过来。他"照"过的那一面，纸背的纤维里，浮出一行浅色的字，像是写的时候垫着硬板，笔尖透下去的：芽是安全的。真正要小心的，是……他凑近看。那半句话被撕断的地方，纤维断了，字也断了。他照了三次，都只照到这一行。他放下纸条，看着窗外的夜色，忽然想：她到底在小心什么？
