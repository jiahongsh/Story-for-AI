# 细纲 · 第18章 旧物

## 第 18 章：旧物
- **核心事件**：拿到猫眼的两套撤点资料后，镜辞回头整理沈竹留下的普通旧物，终于认出一个过去毫无意义的旧信封来自17号设备承包商。信封里没有超自然影像，只有五张现场照片和一张手写走时记录。沈竹曾用多块旧机械表比较不同地点的走时偏差，其中下一处被反复标记的位置是“临江老码头03点”。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第18章；沈竹调查方法第一次被还原
- **单元ID/位置**：1-2；第8拍·旧物重新获得意义
- **目标情绪**：翻找旧物 → 普通物件与新资料对上 → 发现沈竹的方法 → 守钟人补一小块 → 下一个坐标出现
- **主角目标/关键选择**：镜辞想找沈竹是否追查过其他测点；关键选择=不用镜返“照旧物”，只用来源、笔迹、磨损、照片背景和走时记录拼接
- **章节定位**：调查+关系；让“物品留下历史”兑现，不让遗物获得作者权限
- **本章结构公式**：节点1（按承包商名称重查旧物） + 节点2（找到旧信封） + 节点3（五张照片与走时表） + 节点4（识别沈竹记录习惯） + 节点5（守钟人解释最低限度方法） + 节点6（临江03点）
- **章首钩子**：猫眼资料右下角那个已经注销二十多年的承包商标志，镜辞在沈竹旧物箱里见过。
- **本章即时兑现**：沈竹不是靠神秘预言调查，她也曾用笨办法、普通设备和重复记录追异常
- **本章禁止提前释放**：守夜人组织、裂隙完整理论、沈竹最终发现、存在实验
- **能力边界**：镜返1阶不能读取死物残忆、重放过去影像或显出隐藏文字
- **契约风险**：契约安全。线索来自前文已存在旧物在新上下文中的重新识别

#### 内容概括（五段式）
- **起因**：镜辞拿着猫眼资料回钟表行，把沈竹旧物重新按“来源”分类，而不是按“有纪念意义/没纪念意义”分类。一个从前只装过旧螺丝的泛黄信封上，印着与17号承包商完全相同的标志。
- **发展**：信封夹层里有五张旧照片：北河17号、临江老码头、一个废弃泵站、两处镜辞不认识的地点。每张照片背面都不是抒情留言，而是时间、天气、表号和走时偏差。沈竹用至少三块机械表和一只电子计时器做过交叉记录。
- **转折**：镜辞认出其中一栏的写法。沈竹以前教他校表时，总把“快/慢”写在数字左边，方便一眼扫差值。眼前这些不是随手笔记，是一套持续了很久的现场记录。17号并非唯一地点。
- **高潮**：守钟人看到表格后终于承认一件小事：沈竹当年发现某些老机芯在特定地点会重复出现走时异常，所以她拿便宜旧表做“笨控制组”。守钟人强调：“表只能告诉她这里不对，没告诉她为什么。”镜辞立刻明白，这和自己第16章做的事几乎一样。
- **结尾**：五张照片中，“临江老码头03点”被沈竹重复去了四次，最后一次记录旁写着：`21:40后偏差扩大，先查环境。` 镜辞把照片翻到正面，认出旧码头仍在城西江边，只是早就废弃。

#### 情节安排（多线）
- **主线推进**：北河17号扩展为多个历史异常测点；临江03点成为下一调查坐标
- **辅线推进**：沈竹与镜辞形成跨时间的方法呼应：两人都先做对照再解释
- **事件线/任务线**：重分旧物 → 找信封 → 读记录 → 守钟人有限交底 → 锁定03点
- **任务卡点**：镜辞希望旧物直接给答案 → 得到的只有大量枯燥数据 → 正是这些数据证明沈竹曾长期调查 → 新坐标可信
- **感情线/关系线**：镜辞第一次不是“听见沈竹留下的话”，而是在她的工作习惯里认出她
- **逻辑线**：猫眼来源链 → 承包商标志 → 沈竹旧记录 → 多点异常 → 临江03点

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 守钟人
- **人物关系变化**：守钟人开始回答“沈竹怎么查”，仍不回答“她最终查到了什么”
- **视角/信息差**：读者与镜辞掌握相同的原始记录；守钟人知道方法历史更多

#### 结尾设定和钩子
- **结尾设定**：旧物的价值来自可追溯使用痕迹与真实生活历史，不来自主动播放记忆
- **章尾钩子**：为什么临江老码头03点只在夜间某个时段出现更大的走时偏差？
