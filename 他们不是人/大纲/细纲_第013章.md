# 细纲 · 第13章 不该在这里的零件

## 第 13 章：不该在这里的零件
- **核心事件**：镜辞重新拆怀表，不再“修到能走”为目标，而是按修表人的方式记录每一道维修痕迹。他发现机芯里有一片不属于原厂结构的极薄止动片，以及一颗带有二次拆装痕迹的螺丝；止动片下面压着纸纤维边角。沈竹不是没修好这块表，她是故意让它停下，并在更深处藏了东西。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；第13章；怀表线第一次物证级推进
- **单元ID/位置**：1-2；第3拍·机械证据
- **目标情绪**：专业专注 → 发现异常零件 → 个人记忆介入 → 克制停手 → 新谜题成立
- **主角目标/关键选择**：镜辞想知道怀表为什么长期停摆；关键选择=发现夹层后不莽拆，而是先拍照、画结构、保留原始位置
- **章节定位**：职业爽点+悬疑推进；让“修表”真正成为主角能力，而不是背景职业
- **本章结构公式**：节点1（按证据流程拆表） + 节点2（发现非原厂止动片） + 节点3（识别沈竹维修习惯） + 节点4（止动片下露出纸纤维） + 节点5（镜辞选择保全位置）
- **章首钩子**：镜辞拆到擒纵机构时停住了。那片压在夹板边缘的薄金属，不属于这款机芯。更麻烦的是，它刚好卡在“让表永远差半格才能走”的位置。
- **本章即时兑现**：怀表“有人故意把它停了”从守钟人的话变成可验证机械事实
- **本章禁止提前释放**：夹层信全文、沈竹失踪真相、特殊机芯与裂隙的完整关系、守夜人体系
- **设定边界**：怀表不是锚点、电池、灵魂容器或技能钥匙；所有推进先以机械物证解释
- **契约风险**：契约安全。主角靠职业能力获得线索，不靠道具主动开口

#### 内容概括（五段式）
- **起因**：眼前芽离开旧街后，镜辞终于有一个不被打断的上午。他把怀表、放大镜、相机和记录纸摆开，决定像处理一件可疑物证一样重新拆表，而不是像过去那样一门心思想让它走起来。
- **发展**：机芯主体没有致命故障。发条、齿轮、擒纵都能工作，但夹板边缘多了一片手工磨出的极薄金属片，正好限制了关键部件的行程。它不是磨损，也不是原厂零件，是后来有人专门加进去的。
- **转折**：镜辞看到固定止动片的螺丝头上有一道极浅的偏斜划痕。他认得这种痕迹：沈竹拧小螺丝时习惯先回退半圈找牙，再重新上紧，留下的受力痕迹和他自己完全不同。过去这只是他修表时嫌她“多此一举”的小习惯，现在却成了关系与物证交叉验证的一条线。
- **高潮**：镜辞把止动片轻轻抬起不到一毫米，看见下面压着一小截发黄的纸纤维。纸不是机芯材料。有人故意利用止动结构把一张纸藏在更深的夹层里。继续拆就能拿出来，但也会破坏止动片与纸张原本的位置关系。
- **结尾**：镜辞停手，先拍下十几张不同角度照片，又按比例画下零件位置。守钟人过来时，看见他没继续拆，只说了一句：“这回像个修表的了。”镜辞问：“以前不像？”守钟人看着那块表：“以前你只想让它走。现在你终于开始问，它为什么停。”

#### 情节安排（多线）
- **主线推进**：怀表出现明确人为机关与夹层物证
- **辅线推进**：沈竹通过真实维修习惯进入调查，而不是通过“遗物显灵”进入剧情
- **事件线/任务线**：拆表 → 发现止动结构 → 识别维修痕迹 → 发现纸纤维 → 保全现场
- **任务卡点**：镜辞想立刻拿出纸 → 意识到位置本身也是信息 → 克制拆解冲动 → 留下完整证据
- **感情线/关系线**：镜辞×沈竹：一个曾经嫌弃过的小动作，在多年后成为他确认“这确实是她动过的”的依据
- **逻辑线**：守钟人“有人故意停表” → 机械止动实证 → 沈竹维修痕迹 → 夹层纸张 → 后续信件线合理启动

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 守钟人
- **人物关系变化**：守钟人第一次看到镜辞用“保留证据”而非“立刻求答案”的方式处理沈竹线
- **视角/信息差**：守钟人显然知道止动机关存在，但他仍不替镜辞解释纸里是什么

#### 结尾设定和钩子
- **结尾设定**：怀表的神秘首先来自人为机关、维修历史与隐藏信息，而不是魔法判断
- **章尾钩子**：沈竹究竟在止动片下面藏了什么，为什么必须让整块表长期停摆才能保住它？
