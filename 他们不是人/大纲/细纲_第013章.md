# 细纲 · 第13章 修表的人

## 第 13 章：修表的人
- **核心事件**：镜辞尝试修怀表——发现机芯完好、发条上满、秒针却纹丝不动（"它不是坏了，是被停的"）；表盘底下刻着一行极小字迹；壳从村子发来报平安短信（河干了、树还在）；守钟人"再等等"
- **字数目标**：3000 字
- **阶段位置**：开篇期；第1阶段第13章；单元1-1余波（怀表线承接）
- **单元ID/位置**：1-1；第13拍·余波（怀表钩子深化+芽线预热）
- **目标情绪**：专注（修表）→ 悚然（刻字）→ 温情（短信）→ 悬疑（"时机"）；本章推进情绪引擎"余波→新钩子"环
- **主角目标/关键选择**：镜辞想修好怀表（"修好就什么都明白"）；关键选择=他决定"自己修"，不找守钟人——他要在别人的引导之外，自己找答案
- **章节定位**：悬疑+情感（怀表钩子+芽线预热）
- **本章结构公式**：节点1（翻工具·决心修表） + 节点2（拆表·机芯完好秒针卡死） + 节点3（第一次修表失败的挫败） + 节点4（表盘底下的刻字） + 节点5（壳的短信·村子） + 节点6（守钟人"再等等"）
- **章首钩子**：承接钩子（"妈，你停表的时候在想什么"——他决定自己问这块表）
- **爽点**：认知点（停表=有设计的行为）+ 情感点（壳的短信报平安）；往下看的理由=表盘刻字+守钟人的"时机"
- **变奏前奏**：无变奏；本章是怀表线的第一次实质推进（单元1-2的预演）
- **本章禁止提前释放**：壳巢/壳的完整设定/养母真相/怀表真相（刻字=新悬念而非答案）/姜霁
- **契约风险**：契约安全
- **章节内时间**：周五（清晨→深夜）

#### 内容概括（五段式）
- 起因：周五天没亮，镜辞醒了。他躺在钟表行的柜台后面，手里攥着那块怀表。他把修表工具摊开，决定自己修这块表。
- 发展：他拆开表壳。机芯完好，齿轮没锈，发条上得满满的，擒纵轮干净得像新的一样。可秒针卡在半格，纹丝不动。他修了二十年表，从没见过这样的停法：它根本不是坏了。它是被人"停"住的。
- 转折：他把机芯重新装好，秒针还是不动。他坐在柜台后面，看着那块表，第一次生出一种修表人最陌生的感觉——挫败。他修不了这块表。因为他不知道，它为什么停。
- 高潮：他翻过表盘，在表盘底面的边沿，看见一行极小的刻字，小到只有修表的人才看得见：别修了，孩子。有些表，修好了才是真的停了。
- 结尾：手机震了一下。壳发来短信："到了。河干了，树还在。我明天去树下坐坐。"他看了很久，把手机放下，把那行刻字又看了一遍，然后轻轻把表装好，放回枕边。傍晚守钟人路过，看了他一眼："修了？"他点头。守钟人摇摇头："再等等。"他问："等什么？"守钟人没答，走了。

#### 情节安排（多线）
- **主线推进**：怀表线（停表之谜+刻字警告）；壳线（到达村子，报平安）
- **辅线推进**：守钟人线（"再等等"——他知道更多）
- **事件线/任务线**：修表（尝试）→ 失败（不知道为何停）→ 刻字（新悬念）→ 短信（芽线预热）
- **感情线/关系线**：镜辞×沈竹=隔着时间对话（刻字像她的声音）；镜辞×壳=分离后的第一次联系
- **逻辑线**：修表（行动）→ 发现停表有设计（认知）→ 刻字警告（新谜）→ "再等等"（守钟人的保留）

#### 人物关系和出场顺序
- **出场顺序**：镜辞（独处修表）→ 壳（短信·不出场）→ 守钟人（傍晚）
- **人物关系变化**：镜辞×沈竹=从"遗物"到"她在对他说话"（刻字）；镜辞×守钟人=守钟人确认他修过表，"再等等"
- **视角/信息差**：读者与主角同信息量；刻字=沈竹对"修表行为"的预判（她知道他会修）；壳的短信=村子现状第一次落地（河干了）
