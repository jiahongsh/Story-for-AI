# 细纲 · 第32章 兴南机电

## 第 32 章：兴南机电
- **核心事件**：镜辞先去正常营业的兴南机电维修点，以修表同行和旧同步模块咨询的身份核查供应链。店员确认最近几个月确实有人反复送修老式同步计时组件，送修单上只写内部编号，其中包括`D4`。付款方不是顺记，而是一家临江市内普通设施维护公司。镜辞没有得到幕后身份，却拿到一条完全独立于神秘女人的现代合同链。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第32章；旧测点网络进入现代供应链
- **单元ID/位置**：1-3；第7拍·普通系统里的异常
- **目标情绪**：普通维修店降低戒心 → 老零件出现 → D4编号命中 → 付款主体意外普通 → 风险从神秘巷子扩散到日常城市维护
- **主角目标/关键选择**：镜辞想确认D4是否近期被维护；关键选择=不冒充执法者套取隐私，只询问公开业务范围、自己带来的同型号零件与可展示的送修标签格式
- **章节定位**：现实调查+信息扩张；越普通越不安
- **本章结构公式**：节点1（普通机电店） + 节点2（同型号组件咨询） + 节点3（店员认出老模块） + 节点4（D4送修单） + 节点5（普通设施公司付款） + 节点6（公开招标信息）
- **章首钩子**：兴南机电没有暗门，没有黑衣人，门口甚至贴着“空调水泵维修八折”。镜辞刚把一张旧同步组件照片放到柜台上，师傅就说：“这个？前阵子修过一批。”
- **本章即时兑现**：旧测点正在被重新维护获得现代供应链证据
- **本章禁止提前释放**：设施维护公司真正后台、D4具体异常功能、壳巢、接缝修复师
- **能力边界**：本章即使店里有人出现接缝，也不能作为合同链结论；调查主轴仍是现实记录
- **契约风险**：契约安全。异常第一次藏进正常商业流程，而不是永远待在神秘地点

#### 内容概括（五段式）
- **起因**：镜辞到兴南机电，发现这里只是旧工业带一家普通维修店。柜台后堆着水泵控制板、变频器和工业计时器。镜辞拿出第30章零件袋照片中能公开辨认的模块型号，问是否还能维修。
- **发展**：维修师傅一眼认出，说这型号早停产了，但近几个月有人送来过十几只，要求“尽量保持原参数，不要换新版”。镜辞问为什么，师傅抱怨这种旧东西难修、钱却给得快，因此印象很深。
- **转折**：师傅翻自己的公开维修登记找型号，镜辞看到编号栏里有`D4-2`、`D4-5`等内部标签，还有几项以`03`开头。镜辞没有偷看客户私人号码，只确认这些标签和他已有旧测点代码形式一致。
- **高潮**：付款抬头并不是顺记，而是一家名字普通得近乎无聊的“临江恒泰设施维护有限公司”。镜辞离店后查公开企业和招标记录，发现恒泰近一年拿过几个“废弃水利设施安全巡检”“旧城区地下设备维护”小项目，金额都不大，散在不同街区，单看毫不起眼。
- **结尾**：其中一份公开项目附件列出“南岸旧泵房安全封闭维护”，地址正落在D4箭头附近。镜辞把它标记为下一站，却没有直接过去。他先把恒泰的公开项目清单发给猫眼，只问：“这些项目的版本有没有改过？”

#### 情节安排（多线）
- **主线推进**：D4近期维护从猜测变成现代商业/合同证据
- **辅线推进**：异常网络渗入普通设施维护，而不是单纯地下组织活动
- **事件线/任务线**：咨询型号 → 员工回忆 → 登记标签 → 付款公司 → 查公开项目 → 请求版本核验
- **任务卡点**：机电店只是普通商家 → 正因为普通，说明幕后网络可以利用正常供应链 → 主角必须追合同而非恐吓店员
- **感情线/关系线**：无强情感线，保持信息章节奏
- **逻辑线**：顺记物流 → 兴南机电 → D4/03送修 → 恒泰设施 → D4封闭维护项目

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 兴南维修师傅 → 猫眼（消息）
- **人物关系变化**：镜辞开始把猫眼用于“版本核验”而不是“帮我查幕后老板”
- **视角/信息差**：兴南机电大概率只是正常供应商；不要把所有接触者都写成阴谋成员
