# 细纲 · 第10章 他们不是人

## 第 10 章：他们不是人
- **核心事件**：灰衬衫身份使用者主动回到钟表摊，不再假装只是取表。他确认镜辞能看见接缝，并用近距离威胁测试镜辞。镜辞没有战斗能力，只能利用旧市场的人群、监控和公开场景逼对方收手。第一轮悬疑从“芽是不是芽”正式扩大为“城市里存在一类使用他人身份的东西”。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；第1-10章第一单元高潮与收束
- **单元ID/位置**：1-1；第10拍·威胁兑现
- **目标情绪**：等待危险 → 对方主动上门 → 近距离压迫 → 主角用现实环境脱险 → 世界尺度打开
- **主角目标/关键选择**：镜辞想确认灰衬衫男人的真正目的；关键选择=面对明显危险不逞强，不尝试“靠看见就打赢”，而是把冲突拉进有人、有监控、有社会记录的公开环境
- **章节定位**：单元高潮章；必须有可见事件和主角有效选择，不用旁白总结十章内容
- **本章结构公式**：节点1（灰衬衫再次上门） + 节点2（直接确认“你看得见”） + 节点3（身份威胁） + 节点4（镜辞借旧市场公开环境破局） + 节点5（私人命名“他们不是人”）
- **章首钩子**：下午六点，镜辞准备提前关门。卷帘门刚落下一半，一只手从外面托住门沿。灰衬衫男人弯腰走进来，手腕上没有那块已经被他取走的表。他看着镜辞说：“你昨天给真正的周远打电话了。”
- **本章即时兑现**：第三方异常从证据层升级为现实威胁；镜辞第一次确认这些身份使用者也会主动处理“看见他们的人”
- **本章禁止提前释放**：壳的正式名称与完整分类、壳巢、裂缝来源、镜返后续式、EX阈值、组织网络
- **能力边界**：镜返第一式仍是被动看见接缝；镜辞没有主动照真身、读取记忆或战斗输出能力
- **契约风险**：契约安全。高潮由镜辞的风险判断与现实行动解决，不靠新技能突然救场

#### 内容概括（五段式）
- **起因**：灰衬衫男人在关门前再次出现，第一句话就点破镜辞联系了维修单上的真正客户。他已经知道镜辞没有把身份冲突当成普通冒领。
- **发展**：男人坐到柜台前，像普通客人一样问：“你看我哪里不对？”镜辞在他耳后与领口都看见接缝，却说“我只知道你不是来修表的”。男人没有否认，反而准确报出镜辞的姓名、住址、沈竹失踪年份以及芽最近的行程，用信息压迫告诉镜辞：双方观察并不对等。
- **转折**：男人伸手压住卷帘门开关，问镜辞为什么不装作没看见。镜辞意识到自己如果继续留在封闭店里就会失去全部主动权。他故意把柜台上一盒细小表簧扫到地上，制造巨大金属声，同时抬高音量叫隔壁摊主帮忙，说“有人冒领客户东西还回来闹事”。
- **高潮**：旧市场还没散尽，隔壁修锁匠、水果摊、送货工很快往门口看。镜辞顺手把店内监控屏幕转向门外，让灰衬衫男人清楚自己正被多人同时记录。对方没有在人群前动手，只松开卷帘门，低声说：“你以为他们看着，就等于他们会一直记得？”然后转身混进收摊人群。
- **结尾**：镜辞没有追。他先把监控备份、维修单和周远的视频放进三个不同位置，再把沈竹便签锁好。守钟人隔着两个摊位看了他很久，只说：“这次知道为什么让你别盯了？”镜辞问：“他们到底是什么？”守钟人没有回答。镜辞回到柜台，在维修记录最下面写下一句自己的临时定义：**“他们不是人。至少，不是他们正在使用的那个人。”**

#### 情节安排（多线）
- **主线推进**：身份异常正式具有敌意和反调查能力；第一单元从私人怀疑扩展为城市威胁
- **辅线推进**：守钟人继续保持知情但不解释；沈竹和芽都被灰衬衫男人掌握，说明镜辞身边关系已进入风险区
- **事件线/任务线**：关店 → 对方上门 → 信息压迫 → 镜辞制造公开事件 → 对方退走 → 备份证据
- **任务卡点**：镜辞想问清目的 → 对方掌握的信息更多且封住出口 → 正面对抗无胜算 → 镜辞转用社会环境和公开记录自保
- **感情线/关系线**：镜辞×旧市场群体第一次体现现实保护价值；普通人的存在不是背景板
- **逻辑线**：第7章重复身份证据 → 第8章芽预警“他知道你看得见” → 第9章确认目标是镜辞 → 第10章对方亲自上门测试并威胁

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 灰衬衫身份使用者 → 隔壁摊主群像 → 守钟人
- **人物关系变化**：镜辞×异常群体：从观察者升级为被观察对象；镜辞×旧市场：普通社会关系第一次成为现实防线
- **视角/信息差**：灰衬衫男人明显知道更多规则；守钟人也知道一部分；镜辞和读者仍只掌握现象，不掌握完整世界解释

#### 结尾设定和钩子
- **结尾设定**：第1-10章完成三个承诺：芽与原关系发生身份错位；镜辞能看见接缝；这种现象不只一个案例且会反向追踪观察者
- **章尾钩子**：灰衬衫男人那句“他们会一直记得吗”第一次把“遗忘”作为威胁抛出，但不在本章解释机制；第11章应从后果或现实异常继续推进，而不是直接宣布镜返扣除记忆
