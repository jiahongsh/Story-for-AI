# 细纲 · 第15章 十七号测点

## 第 15 章：十七号测点
- **核心事件**：镜辞收到北河村“17”铜牌照片后，将它与怀表夹层重新对照。在完整拍摄和记录后，他与守钟人拆出沈竹留下的夹层纸条，纸上第一行正是“北河旧河道，17号测点”。两条彼此独立的线索第一次交叉。纸条同时留下“表停了，人还在”，但镜辞没有把它当生死公式。镜辞决定亲自去北河村。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1收束；第15章；单元1-2正式启动
- **单元ID/位置**：1-2；第5拍·双线交叉
- **目标情绪**：线索碰撞 → 专业拆解 → 私人信息刺痛 → 主角克制解读 → 行动决定
- **主角目标/关键选择**：镜辞想确认“17”是不是巧合；关键选择=即使沈竹纸条写着“人还在”，也只把它当沈竹当时留下的私人信息，不直接宣布她或芽仍活着
- **章节定位**：第一阶段小收束+新任务启动；必须给出足够强的行动理由
- **本章结构公式**：节点1（17号铜牌照片） + 节点2（重新检查怀表夹层） + 节点3（守钟人协助保全式拆解） + 节点4（纸条出现北河17号测点） + 节点5（“表停了，人还在”） + 节点6（镜辞买票）
- **章首钩子**：镜辞把手机上的铜牌照片放大到最大，数字只有两个：17。守钟人看了一眼，脸色第一次明显变了：“这东西，你从哪拍的？”
- **本章即时兑现**：怀表线与村子线第一次用独立物证相互验证，不靠角色突然想起答案
- **本章禁止提前释放**：沈竹当前状态、存在实验、17号测点真正用途、守夜人体系、原芽生死
- **设定边界**：“表停了，人还在”是沈竹写给镜辞的私人信息，不是“表停=人活”的宇宙公式
- **契约风险**：契约安全。第一阶段的调查获得实质性进展，下一阶段行动目标明确

#### 内容概括（五段式）
- **起因**：镜辞把眼前存在发来的铜牌照片给守钟人看。守钟人的反应明显超出普通修表人的范围，但他没有解释17代表什么，只让镜辞把怀表拿出来。
- **发展**：两人按照第13章留下的照片和结构图重新拆表。镜辞负责操作，守钟人只在需要保全夹层位置时提醒。止动片被完整取下，下面那张折得极薄的纸终于能抽出来。纸张受油污和时间影响，只能展开大半。
- **转折**：最上面一行清楚写着：**“北河旧河道，17号测点。”** 镜辞把手机里的树根铜牌照片放到旁边。一个来自眼前存在无法确认来源的记忆现场，一个来自沈竹多年前藏进怀表的纸条，两条线在同一个地点和编号上交叉。
- **高潮**：纸条下方还有一句：“表停了，人还在。”镜辞盯着很久。守钟人问他看懂了什么。镜辞没有说“沈竹还活着”，只说：“她写这句话的时候，至少不想让我把停表当成死亡证明。”这是他第一次主动拒绝让一句希望替自己完成结论。
- **结尾**：纸条还有一小段被油污遮住，只能辨出“旧河道”“不要……”几个字。镜辞把纸条、照片、怀表结构图分别备份，随后买下第二天去北河镇的车票。他给眼前存在发消息：“别动17号测点附近的东西。我过去看。”对方只回了一个字：“好。”

#### 情节安排（多线）
- **主线推进**：沈竹线与村子线第一次交叉；北河村从“记忆验证地点”升级为必须亲自调查的现实坐标
- **辅线推进**：守钟人暴露自己知道17号测点，但继续控制信息释放
- **事件线/任务线**：照片比对 → 怀表拆解 → 纸条验证 → 克制解读 → 购票行动
- **任务卡点**：镜辞想确认17是否巧合 → 夹层纸条给出独立对应 → 私人信息又制造生死诱惑 → 主角只采信能证明的部分
- **感情线/关系线**：镜辞×沈竹：从怀念进入真正调查；镜辞×守钟人：从“老人知道秘密”升级为“老人明确认识这个调查坐标”
- **逻辑线**：第12章村子记忆 → 第13章怀表夹层 → 第14章17铜牌 → 第15章夹层纸条写北河17号测点 → 镜辞必须亲自到场

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 守钟人 → 眼前存在（消息）
- **人物关系变化**：守钟人无法再把北河线完全当成“还不到时候”的秘密压下去；镜辞获得主动调查资格
- **视角/信息差**：守钟人知道17号测点的历史含义，镜辞和读者只知道沈竹曾把它藏进怀表
