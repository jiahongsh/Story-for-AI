# 细纲 · 第33章 三个月前的公司

## 第 33 章：三个月前的公司
- **核心事件**：猫眼核出“恒泰设施”三个月前刚由另一家公司更名而来，旧名下的公开业务只是普通物业与泵房维护；改名后却集中接手数个与17、03、D4地理附近重合的“废弃设施安全项目”。更异常的是，部分公开网页缓存仍保留旧版附件，而现行页面已经把具体设备清单改成笼统的“安全维护”。镜辞第一次看到“同一项目的公开版本被清洗得更干净”。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第33章；现代版本覆盖实证
- **单元ID/位置**：1-3；第8拍·版本清洗
- **目标情绪**：版本核查 → 普通公司历史 → 改名节点 → 项目突然集中 → 缓存旧附件与现行页面冲突 → D4风险升级
- **主角目标/关键选择**：镜辞想判断恒泰只是正常承包商还是被某条网络临时利用；关键选择=不因公司改名直接定罪，而是查改名前后业务和文档变化
- **章节定位**：来源链调查章；猫眼发挥不可替代专业，但结论仍由镜辞整合
- **本章结构公式**：节点1（猫眼给旧公司名） + 节点2（改名前普通业务） + 节点3（改名后异常项目集中） + 节点4（网页缓存保留旧附件） + 节点5（现行附件被概括化） + 节点6（D4具体设备曾列出）
- **章首钩子**：猫眼把两张企业信息页并排给镜辞看。法人、地址、注册资本全没变，只有名字在三个月前换了。更奇怪的是，改名之后，它像忽然知道这座城里哪些“废弃设施”值得花钱维护。
- **本章即时兑现**：第20章“版本被覆盖”从一张客户记录扩大到公开项目文件
- **本章禁止提前释放**：幕后组织、谁下令改文件、唯一指向、白塔技术
- **契约风险**：契约安全。信息升级但仍不把文档异常直接等同超自然操纵

#### 内容概括（五段式）
- **起因**：猫眼找到恒泰更名前的工商快照：旧名“临江安禾物业维修”，多年业务都是小区水泵、电梯机房、排水井巡检，没有任何神秘色彩。
- **发展**：公司三个月前改名后，经营范围变化不大，却在短时间内接到七个分散的小额项目。猫眼把地址落到地图上，镜辞发现其中三处分别靠近北河17、临江03和南岸D4，其余四处也都位于沈竹旧照片没有覆盖到的城市边缘设施。
- **转折**：猫眼从网页缓存和旧下载链接找回一份项目附件。旧附件明确列出“旧同步计时箱检查、机械计时组件原参数修复、环境监测旧支架保留”；现行页面同一附件却只剩“安全封闭、设施维护、隐患排查”。不是内容完全删除，而是把能让人联想到旧观测网络的具体名词全部抹平。
- **高潮**：D4项目旧附件还有一条特别要求：`不得更换原位计时基准件，只允许校正偏差。` 镜辞想到兴南机电师傅说的“保持原参数”。这说明现代维护并非简单拆除废设备，而是在刻意让某些旧部件继续工作。
- **结尾**：镜辞问猫眼旧附件是谁上传的。猫眼说缓存只能证明它曾公开过，不能证明具体上传人。她给每份材料标好来源等级，然后问：“现在还想直接去D4？”镜辞说：“更想。但先从围栏外看。”

#### 情节安排（多线）
- **主线推进**：恒泰改名后集中维护旧测点关联设施；文档被概括化
- **辅线推进**：猫眼“版本差异”专业正式成为案件关键工具
- **事件线/任务线**：查旧名 → 对业务 → 地图标点 → 找缓存 → 比旧新附件 → 锁定原位基准件
- **任务卡点**：公司改名可能只是普通商业行为 → 项目地理重合仍可能巧合 → 旧附件中的计时组件要求把多条独立线索合并
- **感情线/关系线**：镜辞与猫眼形成更成熟交易：她给“曾经不同”的证据，不替他宣布幕后真相
- **逻辑线**：机电维修 → 恒泰 → 更名 → 异常项目集中 → 旧附件清洗 → D4仍保留旧基准件
