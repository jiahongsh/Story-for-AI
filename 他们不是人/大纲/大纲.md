# 大纲 ·《他们不是人》

> **定位**：都市身份恐怖 + 悬疑升级流 + 群像异能。8卷长篇，体量动态控制，暂按每卷80-120章规划。
>
> **核心卖点优先级**：最亲近的人可能已经不是原来的人 > 身份与关系调查 > 镜返升级与团队对抗 > 势力战争与终局哲学。
>
> **创作原则**：数值是作者后台的尺，不是正文的主人；设定跟着冲突揭示；任何角色都必须有不依赖镜辞仍能成立的目标与选择。
>
> **时间锚点**：存在实验发生在开篇约21-22年前，镜辞当时不足1岁；正文主线开篇镜辞**21岁**。临江七中等校园场景只用于少年回忆、旧同学调查与历史关系证据，不把成年主线重新写成校园文。
>
> **术语锚点**：壳侧正式术语优先使用“裂隙压 / 裂隙侵蚀 / 裂隙接口”。`VOID` 只允许作者后台极简缩写，不在正文表现成第二资源条。

## 一、全书总线

### 1. 核心恐怖

镜辞最初面对的问题非常具体：

> **“我最熟悉的人，还是不是原来的那个人？”**

后续所有力量、组织与哲学都必须从这个问题自然长出去，而不能把小说写成“壳素材掉落—升级—打更大Boss”的副本循环。

### 2. 核心主题

底层规则已经统一为：

> 记录 ≠ 记忆 ≠ 铭记。
>
> 真正稳定存在的，是一个生命已经对其他生命造成的不可替代影响。

所以终局不是“谁记得的人更多”。

真正的答案是：

> **关系从来不是单向储存，而是很多生命彼此改变后形成的网络。**

### 3. 镜辞的核心人物错误

前期镜辞会越来越相信：

> “只要我把所有人记住，他们就不会真正消失。”

这句话会逐渐变成另一种危险：

他把所有遗物、责任、死者和未竟之事都往自己身上揽，越来越像一个认为“只有我有资格保存所有人”的私人服务器。

这与壳王“把所有身份归并到唯一答案”形成镜像。

镜辞最终必须学会：

> **铭记不是占有。**

### 4. 镜返代价闭环

镜返使用EX，但EX不是经验值。

EX始终按0-100理解，是当前存在稳定状态。

关键阈值：

- 跌破70：外围社会关系发生一层不可逆断裂；
- 跌破40：熟人共同经历出现永久断层；
- 跌破20：重要关系发生“知道他是谁，却不再熟悉”的错位；
- EX=0：姓名锚点失去稳定指向。

因此主角成长的真正困境是：

```text
遇到必须解决的身份危机
        ↓
镜辞需要更深使用镜返
        ↓
逼近EX关系阈值
        ↓
他害怕失去关系，开始倾向独自承担
        ↓
独自承担又让他更依赖镜返
        ↓
最终必须学会把关系与责任交回整个群体
```

### 5. 终局灾难必须提前生长

“唯一指向”不是第8卷突然出现的世界级能力。

它由前几卷四条原本各有现实用途的链逐步接上：

1. **白塔认证链**：记忆/人格连续认证能证明内部模型高度一致，却曾错误地把内部连续推成主体连续；
2. **关系归并链**：修复师从单个壳的关系图发展到跨案例归并索引，开始决定身份冲突时保留哪个版本、消掉哪些异议；
3. **身份同步链**：左衡推动的身份连续评估接口最初保护自愿融合者免于反复审查，后来让一个错误认证可以自动进入医疗、工作、户籍、财产、监护与组织权限；
4. **群体记忆同步链**：高阶壳与裂缝节点把被选中的身份版本同步到大量活人的显性记忆与关系认知。

第8卷真正可怕的是四条链同时运转，而不是壳王抬手给全城套一个领域。

所以全书必须让读者逐步看到：

> **终局不是壳王凭空造出来的。人类为了保存、便利和稳定而建立的系统，也被一步步推成了它的工具。**

## 二、全书四阶段

### 第一阶段：第1卷 · 日常身份恐怖

任务：
- 立21岁的成年镜辞与旧货市场生活；
- 立芽被替换；
- 立“接缝”；
- 立养母失踪；
- 通过少年回忆让读者真正知道镜辞与芽曾怎样相处；
- 让读者先害怕“身边人不对”，而不是先背世界观。

情绪：亲近感 → 违和 → 怀疑自己 → 证实恐怖。

阶段问题：

> 芽到底发生了什么？

### 第二阶段：第2-5卷 · 调查、组织与关系证据

任务：
- 剥壳人、观潮者、百川堂、白塔逐步展开；
- 姜霁与镜辞建立“行为证据 + 镜返证明”的调查搭档；
- 顾横战死留下组织后果，而非主角经验包；
- 守钟人主动分线；
- 存在实验逐步揭露；
- 姜父线证明“记忆资料正确”仍不等于“这个人还是原来的他”；
- 左衡推动的身份连续评估制度看起来确实解决了一部分自愿融合者的现实困境；
- 白塔对“内部连续”的专业信任开始成为后期错误答案的制度基础。

阶段问题：

> 如果记忆可以复制，究竟什么东西不能被复制？

### 第三阶段：第6-7卷 · 谁拥有作为自己的资格

任务：
- 白壳从“活成原主”走向“成为白壳”；
- 守夜人完整登场；
- 姜霁脱离组织独立调查；
- 修复师的关系归并索引从局部接缝修复扩展为跨案例系统；
- 左衡共存路线崩塌，并暴露现实身份同步接口被壳巢利用；
- 壳王的身份继承错误被逐层看见，但不能因此撤销它造成的大量伤害；
- “壳是否拥有独立存在权”从哲学口号变成真实政治问题；
- 读者第一次看清“唯一指向”并非一个技能，而是一套正在成形的身份基础设施。

阶段问题：

> 一个从别人身份中出生的存在，有没有资格成为自己？

### 第四阶段：第8卷 · 分布式存在与终局归还

任务：
- 壳王与零号身份继承真相；
- 镜返5阶；
- 沈竹线回收；
- 芽保持希望但不坐实复活；
- 各势力分别切断白塔认证、关系归并、现实身份同步与群体记忆/裂缝同步四条链；
- 999+1完成双向关系闭环。

最终问题：

> 当全世界都无法正确指向你时，还有什么能证明你真正存在过？

## 三、节奏原则

不再执行“每次升级必须信任崩塌”“每次大胜必须死人”“每1-2卷一个离去者”的机械公式。

保留更可靠的规则：

> **重大推进必须造成不可轻易撤销的结构变化。**

变化可以是：
- 人死亡；
- 人活着但离队；
- 关系永久改变；
- EX跨过阈值；
- 阵营分裂；
- 身份暴露；
- 据点失去；
- 一条制度被改变；
- 救下一个目标却永久失去另一个选择。

番茄节奏依旧要求快，但“快”指每段冲突都产生新信息、新选择或新代价，不是每十章必须安排一次爆炸。

## 四、关键节点链

1. **第1卷**：芽被替换，镜辞确认世界存在“身份错位”。
2. **第2卷**：镜辞进入剥壳人，与姜霁形成双方法调查体系；镜返2阶。
3. **第3卷**：顾横因组织撤离命令与现场事实冲突，违令开第二撤离线并战死；铭心在余波中觉醒。
4. **第4卷**：守钟人交出怀表与沈竹线索后主动归队；镜返3阶首次在完整关系证据链基础上强制显形；左衡的身份连续评估制度开始被视为现实可行方案。
5. **第5卷**：姜霁确认眼前“父亲身份”不是原来的姜父，但原主生死、当年真实同意范围仍未知；白壳进入主线；白塔用内部记忆与人格模型强化“壳王就是零号延续”的错误答案；修复师的单体关系图首次露面。
6. **第6卷**：白壳产生自己的偏好并第一次违背原主脚本；这次自主选择真实改变至少一个活人的后续行动，形成属于“白壳自己”的关系后果；之后白壳主动使用自己的名字，别人也开始把这些后果准确归到白壳而非原主名下。镜辞与白壳尝试行动共鸣失败，暴露自己的出身偏见；修复师把多个关系图接成归并索引；镜返4阶解锁身份盲区；白壳在已经完成自我成立后主动留下并消散。
7. **第7卷**：左衡路线崩塌并公开承担后果；主角团发现共存派身份同步接口已被接入修复师归并索引；姜父旧案继续追查；“壳王就是零号”的中期答案被撕开；壳王第一次正面提出“让所有关系最终只剩一个指向”的方案。
8. **第8卷**：白塔认证、关系归并索引、现实身份同步与群体记忆/裂缝同步同时失控，城市进入大规模身份归并；关系网络共同抵抗；镜辞MEM达到999，在EX逼近0时仍有一份真实锚点准确指向镜辞本人。作者后台可把条件概括为“999+1超过999”，正文只表现具体关系行动，不显示系统算式。

## 五、目标演变链

| 阶段 | 表面敌人 | 镜辞的目标 | 对“我是谁”的理解 | 被推翻的旧认知 |
|---|---|---|---|---|
| 第1-2卷 | 个体壳 | 找到芽被替换的真相、活下来 | “我只是能看见异常的人” | 壳并非只会机械吃人，它们也会产生身份饥饿与模仿冲动 |
| 第3-4卷 | 壳巢/实验遗留 | 查沈竹与存在实验 | “我是实验造成的半壳接口个体” | 实验没有创造所有壳，只扩大裂缝并制造特殊个体 |
| 第5-6卷 | 壳潮/壳王影响 | 阻止扩大替代，同时理解白壳异常 | “我的特殊不等于我有资格定义别人” | 壳不能继承原主锚点，但可能通过自己的选择产生新锚点 |
| 第7卷 | 左衡路线/壳王 | 回答“谁有资格作为自己存在”，并阻止身份系统被归并 | “我不是所有人的唯一保管者” | 拥有完整记忆并不构成原身份的继承权；制度认证也不等于存在连续；理解反派也不等于免罪 |
| 第8卷 | 壳王的大规模身份归并 | 归还被篡夺的关系指向并切断统一身份基础设施 | “我也需要允许别人认识并记住我” | 存在不是一个人背住所有人，而是关系分布在许多人之间 |

| 第2卷 | 剥壳人、钟表行 | 观潮者、百川堂 | 官方/民间/地下三线出现 |
| 第3卷 | 剥壳人主战派、观潮者 | 顾横线深化 | 组织开始出现真实制度矛盾 |

### 八方立场

| 势力 | 对存在的主要办法 | 优点 | 盲区 |
|---|---|---|---|
| 壳巢 | 完美替代/统一身份指向 | 能保留大量内在记忆并操纵身份网络 | 把身份占有误当存在延续，最终抹除个体差异 |
| 剥壳人 | 制度化识别与清除 | 组织效率、保护大众 | 容易把复杂个体提前归档为“可清除目标” |
| 观潮者 | 地方预警、撤离与猎壳 | 决断快、了解社区 | 容易把真实受害经验扩张成对所有壳的一概判决 |
| 百川堂 | 信息来源链与版本保存 | 连接大量线索、能发现统一覆盖何时发生 | 记录不等于关系，也不能单独判定身份 |
| 白塔 | 记忆存档/恢复/内部连续认证 | 能保留信息连续性、发现记忆篡改 | 容易把内部一致误判为主体连续，无法制造关系锚点 |
| 守夜人 | 守界与裂隙治理 | 能限制裂缝扩大、切断群体同步节点 | 容易为了秩序牺牲个体，也不能单独判定谁是真人 |
| 铭记者协作网络 | 关系确认、证据共享、多来源见证 | 能保留互相冲突却真实的人生版本 | 不能变成镜辞个人崇拜或新的“唯一真相裁判” |
| 钟表行 | 私人生活与旧关系据点 | 提供最具体的日常旁证与时间痕迹 | 规模小，不是万能真相源，更无力解决全城问题 |

## 八、卷级大纲

> **数值规则统一**：EX始终是0-100状态值，不随卷升级。每卷默认战前可恢复到约80-100，真正的危险在关键战中是否跨过70/40/20/0关系阈值。
>
> SEE / WIL / MEM / 刻痕阶承担长期成长。镜返解锁固定为：2阶MEM≥20；3阶MEM≥60；4阶MEM≥120；5阶MEM≥999+终局条件。

### 第一卷：谁不是我？

- **功能**：开篇身份恐怖。
- **当前时态**：镜辞21岁，在旧货市场/钟表行成年生活中遭遇芽身份异常；临江七中只通过少年回忆、旧同学、旧照片等进入叙事。
- **能力**：刻痕1阶 / SEE20 / WIL约30 / MEM 0-10 / 镜返1阶。
- **对手**：Lv.1-2个体壳。
- **主线**：镜辞发现芽出现大量微小违和；自我怀疑；最终看见接缝并确认“她不是原来的她”。
- **关系线**：先通过当前生活与少年回忆让读者相信镜辞与芽真的熟，替换才有疼痛。
- **钩子**：替换壳仍保留“先喝汤”等内在痕迹，但这只证明记忆残留，不证明芽仍活着。
- **禁碰**：完整壳巢、存在实验真相、白塔、镜返2阶。

### 第二卷：剥壳人

- **功能**：组织线与双方法调查体系成立。
- **能力**：刻痕2阶 / SEE40 / WIL约40 / MEM 10-20；卷末满足MEM20后解锁镜返2阶。
- **对手**：Lv.2-3。
- **主线**：进入剥壳人，与姜霁搭档；观潮者、百川堂逐步登场。
- **姜霁定位**：行为指纹是纯技术。她的异常直觉只能提醒“值得多看一眼”，不能直接判壳。
- **镜辞定位**：镜返2阶负责“照出哪里不对”，不替代调查。
- **顾横**：作为战斗导师建立完整人物，不提前把他的死亡当“期待债”。

### 第三卷：存在实验

- **功能**：顾横线结算 + 铭心觉醒 + 实验真相首次成形。
- **能力**：刻痕3阶 / SEE60 / WIL约50 / MEM 20-40 / 镜返2阶 / 铭心觉醒。
- **对手**：Lv.3-4。
- **顾横主线**：组织下达高污染区撤退命令，顾横确认仍有人未被证明不可救，主动违令打开第二撤离线并战死。
- **代价**：一部分人获救、一部分仍失去；顾横死后组织对他的评价分裂。
- **制度后果**：至少推动一项剥壳人行动规则修改。
- **铭心**：在顾横死亡后的余波中觉醒，只能放大已真正进入镜辞身体和判断的影响，不能下载顾横全部战斗经验。
- **实验线**：确认沈竹与旧实验有关，但不把“半壳”全部真相一次说完。

### 第四卷：共存论

- **功能**：白塔、左衡、守钟人分线；第一次成熟关系证据链；终局身份基础设施第一次以“好用制度”形态出现。
- **能力**：刻痕3-4阶 / SEE60-80 / WIL约55 / MEM 40-60；卷末MEM达到60后解锁镜返3阶。
- **对手**：Lv.4-5。
- **镜返3阶规则**：不能看谁不顺眼就开技能。必须先取得真实关系锚点证据，再强制让身份矛盾显形。
- **姜霁功能**：负责建立证据链，确保镜辞不能取代她的调查职业。
- **白塔**：展示“记忆可以恢复，关系不能恢复”的残酷样本，同时建立其内部连续认证方法。这个方法在医疗上有价值，但埋下“内部一致=本人”的错误前提。
- **守钟人**：交出怀表与部分沈竹真相后主动归队，开启自己的守夜人/时间错位调查线。
- **左衡**：共存论第一次作为有吸引力的现实方案出现，而不是一出场就贴反派标签。他推动“自愿融合者身份连续评估”，让通过认证的人免于在每个现实系统反复证明自己。
- **伏笔**：一个通过联合认证的人在医院、工作和剥壳人系统里都被自动采用同一身份结果，当时读者只觉得制度终于没有那么蠢。

### 第五卷：父亲

- **功能**：姜霁独立主线 + 白壳登场 + “壳王是否就是零号”错误答案开始获得证据支持 + 接缝修复第一次被看见是一套关系工程。
- **能力**：刻痕4阶 / SEE80 / WIL约60 / MEM 60-80 / 镜返3阶。
- **对手**：Lv.4-6。
- **姜父线确定事实**：眼前父亲身份不是原来的姜父。
- **保持未知**：姜父肉体是否存活、意识是否连续、当年究竟同意了哪一层方案。
- **关键线索**：旧档案显示姜父可能主动参与某项融合/替代相关实验，但证据不足以证明他同意后来发生的完整身份替代。
- **姜霁觉醒**：在识破后的静默期首次正式觉醒“记忆差分·蚀忆门类”。能力只比较记忆反应与长期关系行为的不一致，不变成通用读心。
- **白壳**：作为壳巢高级执行者出现，起初严格按原主脚本生活。
- **修复师伏笔**：主角团发现某个高阶壳不是“自己很会演”，而是有人为它整理过完整关系图：哪些亲属最危险、哪些生活细节必须补齐、哪些见证者需要被转移或消音。
- **零号线**：白塔旧档案显示壳王拥有零号近乎完整记忆、知识与自我叙事；白塔内部连续认证进一步支持“壳王就是零号延续”的判断，使这个错误答案在专业层面真正站住。
- **制度暗线**：少数被共存派认证的高风险身份开始出现异常“跨系统一致”，但暂时只像行政便利或个别腐败。

### 第六卷：白壳

- **功能**：证明“壳可以形成自己的存在锚点”；姜霁分线；守夜人与壳巢正面扩大；唯一指向的技术前身第一次完整露面。
- **能力**：刻痕5阶 / SEE100 / WIL约70 / MEM 80-120；卷末MEM达到120后解锁镜返4阶。
- **对手**：Lv.5-7。
- **白壳弧线**：
  1. 仍然问“原主会怎么做”；
  2. 出现原主记忆中没有的偏好；
  3. 第一次明确做出原主不会做的选择；
  4. 这个选择让另一个活人的后续行动发生改变，关系后果开始持续；
  5. 白壳主动决定继续使用“白壳”作为自己的名字；
  6. 相关人物开始准确把某些改变归到“白壳自己”，而不是原主名下。这里是对已有独立锚点的确认，不是靠一句台词生成锚点。
- **T15 铭心失败**：镜辞试图通过铭心与白壳建立行动共鸣失败。不是因为“壳不能被铭记”，也不是复制拟魂天赋失败，而是镜辞此前一直只在白壳身上寻找原主残留，没有真正理解白壳自己的判断与选择。
- **镜辞人物伤口**：意识到“口头承认同伴”不等于真正摆脱出身偏见。
- **镜返4阶·遗忘领域**：本质为身份盲区。壳仍能看见、攻击镜辞，但难以通过姓名/身份稳定锁定他；不再统一削弱敌人30%。
- **守钟人再会**：他因追查能消除时间错位的技术进入壳巢相关区域，与镜辞线重新交叉，不是回来救场。
- **关系归并索引**：姜霁和守钟人从不同方向发现，修复师已不再为每只壳单独做关系图，而是在建立跨案例索引，用统一规则决定“发生身份冲突时应保留哪个版本、修改哪些记忆、处理哪些异议者”。
- **白壳与壳王**：白壳形成自己的锚点后，直接证明“壳可以放弃继承旧身份、建立自己的存在”。壳王因此把白壳视为理论性威胁，而不是默许它成长的实验样本。
- **白壳结局**：在人格、新锚点与自主名字都已经成立之后，白壳为掩护多人撤离，主动利用拟魂结构误导壳巢并牺牲。死亡结算的是它最后一次自由选择，不承担“证明它像人”的功能，也不会让受害者自动原谅它。

### 第七卷：替人类活？

- **功能**：共存路线崩塌 + 独立壳政治问题 + 零号/壳王身份继承谜底第一次正面撕开 + 唯一指向基础设施全貌曝光。
- **能力**：刻痕6-7阶 / SEE120-140 / WIL85-100 / MEM 120-300 / 镜返4阶。
- **对手**：Lv.6-9。
- **左衡线**：发现共存路线长期默许不可逆替代后，不用“自杀洗账”结束。更有效的结算是公开证据、失去领导权、接受追责，并看着追随者分裂成反对、修正与继续坚持三派。
- **接口责任**：调查进一步确认左衡曾为了减少自愿融合者反复审查，批准“联合认证结果跨系统同步”。壳巢随后把这一制度接口接入修复师关系归并索引，使一个错误身份认证可以自动扩散到更多现实节点。
- **姜父线**：获得更完整旧案，但仍需要区分“姜父曾经同意一项计划”和“他同意后来发生的一切”。姜父案例成为“有限同意如何被制度偷换成完整替代”的关键证据。
- **白壳后果**：其他壳开始知道“偏离模板也可能形成自己”，壳巢内部第一次出现真正意识形态裂缝。
- **零号错误答案被推翻**：白塔档案能够证明壳王知道零号所有私人记忆，甚至保留零号自认为早已遗忘的细节；但姜霁、沈竹旧资料与关系证据共同证明，零号过去造成的关系后果从未自然延续到壳王。白塔必须公开承认自己此前认证的是“内部连续”，不是主体身份连续。
- **基础设施真相**：主角团拼出完整链条：白塔提供内部连续认证与记忆资料 → 修复师建立关系归并索引 → 共存派身份接口把认证结果同步到现实系统 → 高阶壳/裂缝节点负责群体显性记忆同步。壳王只需要把“冲突时选一个版本”的规则推到全城，就能启动唯一指向。
- **壳王第一次正面对话**：它不求镜辞记住谁，也不承认自己需要被救。它提出自己的答案：既然关系决定身份，只要所有关系最终都只能指向一个版本，“它是不是零号”就会成为一个失去意义的问题。
- **壳王邀请**：镜返能发现身份与关系错位，因此壳王希望镜辞成为“唯一指向”计划的校准接口。镜辞拒绝的原因不只是敌我，而是这个方案必须消灭每个人作为独立存在、提出不同关系答案的权利。
- **关系遗产网络**：顾横旧部、白壳关系者、左衡追随者、守夜人各自继续行动。镜辞开始真正放弃“我一个人背住所有人”的冲动。
- **卷末危机**：即使部分人开始切断接口，系统已经跨越组织边界。第一批普通家庭出现“两个真实人生被行政与记忆同时压成一个版本”的城市级症状，第8卷不是换地图，而是第7卷失败的直接后果。

### 第八卷：他们不是人

- **功能**：壳王终局 + 关系归还 + 芽希望留白 + 四条身份归并链同步断开。
- **能力**：刻痕8-9阶 / SEE160-180 / WIL100-120 / MEM 300→999 / 镜返5阶。
- **对手**：Lv.7-9高阶壳 + 壳王Lv.10。
- **城市级危机**：壳王把既有“冲突身份选择一个版本”的归并规则推向城市。人们不是简单集体失忆，而是出现：
  - 不同家庭同时记得同一个人承担过彼此冲突的人生；
  - 多个人同时被医院、工作、住址等现实系统识别为同一身份；
  - 一个人知道某段往事，却逐渐分不清那段过去究竟属于哪张脸；
  - 学校、单位、家庭等关系节点开始自动采用同一个“标准版本”，原本真实存在过的矛盾被当成错误数据清除。
- **危机机制**：不是单一装置覆盖全城，而是四条链互相放大：
  1. 白塔/泄露资料提供高完整度内部记忆与连续认证；
  2. 修复师关系归并索引决定冲突时保留哪个版本；
  3. 共存派遗留身份同步接口把结果传播到现实社会系统；
  4. 高阶壳与裂缝层同步修改大量人的显性记忆。
- **终局不是单挑**：
  - 守钟人/守夜人负责确认并切断裂缝因果错位与群体记忆同步节点；
  - 姜霁用长期行为与关系证据识别关键活人行为链，并在镜辞身份开始失焦时提供“哪些动作真正属于镜辞”的关系基线；
  - 白塔公开撤销错误连续认证、恢复被篡改的记忆内容，并切断继续向归并系统提供资料的节点；
  - 左衡及共存派修正派负责关闭自己曾推动的跨系统身份同步接口，不得借此洗白；
  - 修复师若在第7卷转为证人，则负责暴露归并索引结构和关闭路径；若拒绝合作，则由主角团强行摧毁其索引节点；
  - 剥壳人冻结高风险错误身份权限、承担大规模撤离与战斗，并保留“身份待复核”状态，不强迫系统立即选一个赢家；
  - 百川堂负责保存、分发被覆盖前的不同版本与来源链，让“异议曾经存在”仍可被证明；
  - 观潮者负责街区级撤离、照护和维持长期生活关系，避免系统错误把真实共同生活的人强行拆散；
  - 独立壳/白壳留下的思想裂缝让部分壳拒绝继续完美替代；
  - 铭记者协作网络维持多来源关系见证，并允许真实但互相冲突的证词暂时共存，不给镜辞建立新中央数据库；
  - 钟表行等普通生活节点保存小尺度使用痕迹，为关系复核提供旁证，而不是终局祭坛。
- **镜辞MEM=999**：作者后台表示他已完成999次有效铭记/关系还原，最多只能与壳王规模999的归并结构持平。
- **关键“1”**：当镜辞EX逼近0、世界无法稳定把名字指向他时，仍有一个活人做出一个只有真正认识镜辞才会作出的选择。
- **后台终局关系**：可概括为 `999（我有效铭记过你们） + 1（仍有人真正认识我） = 1000 > 999`。**正文禁止显示MEM 999→1000、系统判定或数值弹窗，必须先写出那个人的具体行动。**
- **记忆归还**：将壳截留的内在记忆重新与现实仍存在的关系锚点对齐，解除大规模身份篡夺；不复活死者，也不依赖一个中央“正确身份数据库”重新规定所有人的人生。
- **壳王被剥离**：随着被盗记忆重新归位、归并基础设施断链，壳王失去以大量被归并身份与关系网络维持裂隙结构的条件，最终只剩“拥有零号记忆、却不是零号”的新存在。这是它最不愿面对、也无法再靠数据否认的事实。
- **壳王最终选择**：镜辞理解它为何走到这里，但不替受害者原谅。壳王若继续撕裂关系网络，就必须被真正镇封/消灭；若它第一次承认“我拥有零号记忆，但我不是零号”，则必须主动归还剩余身份、从裂缝内部完成闭合，并以自身彻底消失承担最后代价。这个选择不抵消任何旧罪。
- **灾后恢复**：壳王消失后仍不能一键恢复。错误户籍、婚姻、财产、监护、医疗记录、家庭记忆与失踪案必须由各机构和具体关系人长期重建。
- **芽留白**：最后的“先喝汤”只能是希望回声，不能坐实完整复活。更重要的是，芽的痕迹来自多个仍被她改变的人，而不只镜辞。
- **镜辞终点**：不是“带着所有人前行的人”，而是**终于愿意与别人一起承担，也允许自己成为别人生命一部分的人**。

## 九、写作检查

每推进一个大节点，检查：

1. 这段剧情是否仍围绕“身份/关系/存在”卖点，而不是被数值升级抢走？
2. 当前时态的镜辞是否始终是21岁成年人？若出现临江七中，是否明确属于少年回忆/旧关系调查？
3. 正文是否优先使用“裂隙压/裂隙接口”，而不是把VOID写成第二资源条？
4. 镜辞是否又用镜返跳过了姜霁或其他调查者的专业工作？
