# 大纲 ·《他们不是人》

> 定位：都市异能（悬疑升级流·群像）· 番茄男频 · 8 卷 · 动态写书（暂定 800+ 章 / 250 万字+，对标异兽迷城体量，每卷实际长度随写作节奏调整）
> 对标：主对标《异兽迷城》（文风/节奏/模块，见 `对标/异兽迷城/`）；本书只借骨架（情绪引擎/节奏循环/模块卡），皮肉（壳/镜返/存在主题/十一人变奏）全部原创。

## 全书体量与阶段总览

- 全书总章节数：动态（暂定 800+ 章，8 卷，每卷 80-120 章）
- 目标字数：250 万字+（动态调整）
- 全书情绪曲线：日常恐怖（压抑）→ 识破爽感与群像羁绊（期待）→ 真相撕裂与牺牲（震撼/悲壮）→ 存在主题闭环（澄明/释然）
- 核心困境闭环：镜返越强 → 越被遗忘 → 越依赖身边人 → 越怕失去 → 越要变强 → 越被遗忘

### 阶段划分

1. **开篇期（第1卷，约 100 章）**：核心任务 = 立人设（钟表摊主镜辞）+ 立世界观（身边人可能是壳）+ 埋主线钩子（养母失踪/芽被替换）。情绪基调 = 日常恐怖+悬疑。阶段结束读者应建立：对主角的认同（嘴毒心软观察狂）+ 对"谁不是人"的追查期待 + 对"芽可能还在"的希望。
2. **发展期（第2-5卷，约 400 章）**：核心任务 = 组织线展开（剥壳人/壳巢）+ 真相逐层揭（存在实验→血脉关联）+ 群像牺牲（顾横/守钟人/白壳）。情绪基调 = 期待+紧张+间歇爽感+悲壮。阶段结束读者应建立：对壳王/存在实验终局矛盾的迫切期待 + 对"被带着前行"主题的体感。
3. **高潮期（第6-7卷，约 200 章）**：核心任务 = 左衡真相+姜霁父亲线收束+壳潮升级。情绪基调 = 爽感+震撼+反转。阶段结束核心矛盾应：从"打败壳"升维到"证明存在"。
4. **收尾期（第8卷，约 100 章）**：核心任务 = 壳王终局+镜返第5阶+主题闭环+芽的希望留白。情绪基调 = 澄明+悲壮+释然。阶段结束主线伏笔应：回收完毕（养母/芽/壳王），留下"希望"余韵。

### 各阶段节奏公式

- **开篇期**：核心任务=立人设立世界埋钩子 / 情绪基调=恐怖+悬疑 / 爽点密度=每 10-20 章一个小识破爽点 / 伏笔策略=埋养母失踪+芽被替换+镜返代价 / 冲突层级=个体壳威胁 / 阶段钩子=芽的"先喝汤"信号 / 禁止提前释放=壳巢真相+镜返进阶+身世
- **发展期**：核心任务=组织线+真相+牺牲 / 情绪基调=期待+紧张+悲壮 / 爽点密度=每 50-90 章中大爽点 / 伏笔策略=存在实验逐层揭 / 冲突层级=组织内奸+壳巢阴谋 / 阶段钩子=白壳"想成为人"+左衡"共存论" / 禁止提前释放=壳王本体+第5阶+血脉坐实
- **高潮期**：核心任务=真相撕裂+立场对决 / 情绪基调=震撼+反转 / 爽点密度=大高潮密集 / 伏笔策略=回收内奸线与镜像线 / 冲突层级=阵营内战+哲学对决 / 阶段钩子=壳潮降临 / 禁止提前释放=终局宣判+主题闭环
- **收尾期**：核心任务=壳王终局+主题闭环 / 情绪基调=澄明+释然 / 爽点密度=终局大高潮 / 伏笔策略=全部回收+希望留白 / 冲突层级=存在对决 / 必须回收清单=养母真相+芽的希望+壳王+全部变奏

### 目标演变链（boss 层级 · 主角目标 · 身份认知三线反转）

> **核心手法（对标异兽迷城）**：目标不是一条直线——**每次"你以为这就是最终目标"，下一卷就告诉你"不，你追错了"**。异兽迷城的高阳：活下来→查妹妹的事→卧底麒麟→神嗣还是咒渊→苍道=观测者→让极停转；反派：个体兽→内奸→苍母教→麒麟→七死兽→极。本书照此三线反转。

| 阶段 | 反派层级 | 主角目标（不断改变） | 身份认知（逐层反转） | 大反转（推翻上层） |
|---|---|---|---|---|
| 第1-2卷 | **个体壳**（替换芽的壳/旧货市场壳） | 找出替换芽的壳，确认芽是否还在 | 普通人 → 能看见接缝（"眼睛特殊"） | **反转1**：替换芽的壳不是纯恶——它也是"醒来的孤儿"，想成为芽（T02） |
| 第3-4卷 | **壳巢**（存在实验继承者） | 查明养母失踪与存在实验的关系 | 半壳（实验副产品） | **反转2**：养母沈竹不是受害者，是实验研究员——她"带走镜辞"背后有深层原因（T05）；白塔塔主是故交 |
| 第5-6卷 | **壳王**（完美壳） | 对抗壳潮/壳王 | "半壳"这么简单？ | **反转3**：壳王在"选人"，白壳叛变是它默许的试验——它不是毁灭者，是求救者（T13） |
| 第7-8卷 | **遗忘本身/零号** | 与壳王对决 → 理解壳王要什么 | 我是"记忆归还者"/钥匙？ | **终极反转**：壳王请求"帮我记住零号"（T14）；真正的敌人不是壳王，是"遗忘"本身——主角必须证明"被带着前行" |

**目标改变的写作要点：**
1. 每个阶段的目标必须"部分实现但引出更大目标"——不许"打完收工"；
2. 每层反派有"假目标→真目标"的自我反转（壳王：完美替代→逼出记忆归还者→求救）；
3. 主角身份认知逐层反转（普通人→半壳→钥匙→记忆归还者），每层都是"我是谁"的刷新；
4. 目标改变必须由剧情事件驱动（不是作者宣布"目标变了"），且绑定变奏/金句（见 `设定/世界观/力量体系.md` 第八节升级×变奏绑定）。

## 卷级大纲（8 卷鸟瞰 · 含数值平衡引用）

> **数值平衡表**：每卷主角数值水平与对手层级见 `设定/世界观/数值定稿.md` 第六节（第1卷EX100/SEE20/Lv1-2 → 第8卷EX2000+/SEE100+/壳王Lv10）。以下卷纲"主推线/解锁"与数值表严格对应。

### 第一卷：谁不是我？（约 100 章）
- 功能：开篇·立人设立世界·埋钩子 / 所属阶段：开篇期
- 卷契约：日常恐怖+识破爽点；主角高光=第一次看见接缝、第一次用镜返；期待债=芽可能还在、养母失踪之谜
- 数值锚点：EX 100→150 / SEE 20 / 镜返1阶 / 对手 Lv.1-2（芽的替换壳=Lv.2）
- 终局储备：主推线=镜返觉醒（1阶·看见接缝）；战果=识破个体壳（小爽点）+姜霁登场伏笔；本卷解锁=镜返1阶；禁碰=壳巢真相/镜返2阶/身世/铭心（副天赋锁第3卷）
- 核心事件：钟表摊主镜辞发现青梅芽被替换，镜返觉醒，追查养母失踪线索
- 起始状态 → 结束状态：镜辞从"装作正常的钟表摊主" → "看见接缝的觉醒者"

### 第二卷：剥壳人（约 100 章）
- 功能：组织线起步·第一次真负重 / 所属阶段：发展期
- 卷契约：组织+搭档+第一次代价；主角高光=镜返2阶照出真身救人；期待债=顾横之死
- 数值锚点：EX 200→300 / SEE 40 / 镜返2阶 / 对手 Lv.2-3
- 终局储备：主推线=镜返2阶；战果=姜霁搭档线+剥壳人关系网+观潮者/百川堂登场；本卷解锁=镜返2阶+顾横线；禁碰=壳巢/身世/铭心
- 核心事件：进入剥壳人，搭档姜霁，观潮者与百川堂登场，顾横战死前夜
- 起始状态 → 结束状态：孤身调查 → 有组织有搭档但开始失去

### 第三卷：存在实验（约 100 章）
- 功能：真相揭半·**副天赋觉醒** / 所属阶段：发展期
- 卷契约：真相+第一次副天赋；主角高光=**铭心觉醒**；期待债=守钟人传承（3阶）/养母身份
- 数值锚点：EX 350→500 / SEE 60 / 镜返2阶→3阶末 / 铭心觉醒（铭刻异品）/ 对手 Lv.3-4
- 终局储备：主推线=身世揭半+铭心觉醒；战果=顾横遗产（笔记本/起手式）；本卷解锁=存在实验真相（一半）+铭心；禁碰=血脉坐实/壳王/镜返3阶
- 核心事件：追查存在实验，顾横战死（铭心觉醒契机），养母参与实验的身份揭半
- 起始状态 → 结束状态：不知身世 → 知道自己与壳之源头有血脉关联+拥有第二天赋

### 第四卷：共存论（约 100 章）
- 功能：理念对决·组织内奸·守钟人传承 / 所属阶段：发展期
- 卷契约：理念对抗+传承；主角高光=驳左衡"共存论"雏形+镜返3阶强制现形；期待债=剥壳人内部真相
