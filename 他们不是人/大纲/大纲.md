# 大纲 ·《他们不是人》（16 卷标准大长篇定稿）

## 全书概况
- 目标字数：约 270 万字，计划 16 卷（约 900 章，全面对标《异兽迷城》长程四层循环节奏）
- 全书主线：旧货市场修表匠镜辞通过十倍寸镜看穿青梅竹马耳后的非人接缝，手握沈竹遗留的「银灰双环旧怀表」与「银钢捉影镊」，在第一卷末承受第 1 格全城除名代价后，于第二卷开启「拆核上弦（第二重蓄能表盘）」与「镇钟九响」晋升之路；他一边换马甲潜入剥壳人总局与守夜武院、联合觉醒「时痕」天赋的守夜人们闯荡六大断代迷雾禁区、猎杀白塔十二时辰修正司与七大缝皮宗师，一边集齐参号、贰号、壹号三座母钟核心，最终在怀表归零化为「空位行者」后杀入源裂缝救回养母沈竹，以「999+1」万象归位掀翻白塔与零号母表的灭世棋局。

## 〇、P0 级强制工作流与权威树

### 1. P0 级长文写作 Skills 执行铁律
所有规划、出纲、写正文与改稿，**P0 优先**遵守 `AGENTS.md` 中的长文写作闭环：
1. **先读后写**：先读 `skills/story-long-write/SKILL.md` 对应阶段必读清单，以及 `设定/都市异能正文风格卡.md`、`设定/题材正文提示卡.md`、`设定/角色声线节奏卡.md`。
2. **先纲后文**：每一卷先有 `卷纲_第X卷.md`，每一章先出合规细纲并通过 `check-outline-contract.js`；用 `outline_view.py --chapter {N}` 校验剧情段范围。
3. **写前恢复与组装**：先运行 `tracking_commit.py check` 核对账本与派生视图，读 `追踪/上下文.md` 全 7 栏，运行 `build_writer_prompt.py` 核对无误后方能动笔。
4. **同轮检测清零**：正文严格遵循 `long-format.md`（单换行、无加粗分隔线、无工程词），落盘后必须跑通 `storyctl.py chapter check --fix-punctuation --plain`（AI 句式 0 blocking、退化 0）。
5. **串行入账与设定补登**：写完即通过 `tracking_commit.py draft` + `storyctl.py chapter commit` 提交入账；新出现的角色、势力、器物、能力规则同轮补登回 `设定/`。

### 2. 创作权威树
- **L0 已写事实**：`追踪/_tracking-state.json`、`追踪/上下文.md`、`正文/` 已提交章节（第 1–30 章已完结锁定）。
- **L1 全书主脊梁**：`大纲/大纲.md`（本文件）与 `大纲/全书卷纲总览.md`。

- **L3 角色与世界观设定**：`设定/角色/`、`设定/势力/`、`设定/世界观/`。
