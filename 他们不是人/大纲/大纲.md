# 大纲 ·《他们不是人》

> **定位**：都市身份恐怖 + 悬疑升级流 + 群像异能。8卷长篇，体量动态控制，暂按每卷80-120章规划。
>
> **核心卖点优先级**：最亲近的人可能已经不是原来的人 > 身份与关系调查 > 镜返升级与团队对抗 > 势力战争与终局哲学。
>
> **创作原则**：数值是作者后台的尺，不是正文的主人；设定跟着冲突揭示；任何角色都必须有不依赖镜辞仍能成立的目标与选择。

---

## 一、全书总线

### 1. 核心恐怖

镜辞最初面对的问题非常具体：

> **“我最熟悉的人，还是不是原来的那个人？”**

后续所有力量、组织与哲学都必须从这个问题自然长出去，而不能把小说写成“壳素材掉落—升级—打更大Boss”的副本循环。

### 2. 核心主题

底层规则已经统一为：

> 记录 ≠ 记忆 ≠ 铭记。
>
> 真正稳定存在的，是一个生命已经对其他生命造成的不可替代影响。

所以终局不是“谁记得的人更多”。

真正的答案是：

> **关系从来不是单向储存，而是很多生命彼此改变后形成的网络。**

### 3. 镜辞的核心人物错误

前期镜辞会越来越相信：

> “只要我把所有人记住，他们就不会真正消失。”

这句话会逐渐变成另一种危险：

他把所有遗物、责任、死者和未竟之事都收进自己。

这与壳王“把所有身份收进自己”形成镜像。

镜辞最终必须学会：

> **铭记不是占有。**

### 4. 镜返代价闭环

镜返使用EX，但EX不是经验值。

EX始终按0-100理解，是当前存在稳定状态。

关键阈值：

- 跌破70：外围社会关系发生一层不可逆断裂；
- 跌破40：熟人共同经历出现永久断层；
- 跌破20：重要关系发生“知道他是谁，却不再熟悉”的错位；
- EX=0：姓名锚点失去稳定指向。

因此主角成长的真正困境是：

```text
遇到必须解决的身份危机
        ↓
镜辞需要更深使用镜返
        ↓
逼近EX关系阈值
        ↓
他害怕失去关系，开始倾向独自承担
        ↓
独自承担又让他更依赖镜返
        ↓
最终必须学会把关系与责任交回整个群体
```

## 二、全书四阶段

### 第一阶段：第1卷 · 日常身份恐怖

任务：
- 立镜辞；
- 立芽被替换；
- 立“接缝”；
- 立养母失踪；
- 让读者先害怕“身边人不对”，而不是先背世界观。

情绪：亲近感 → 违和 → 怀疑自己 → 证实恐怖。

阶段问题：

> 芽到底发生了什么？

### 第二阶段：第2-5卷 · 调查、组织与关系证据

任务：
- 剥壳人、观潮者、百川堂、白塔逐步展开；
- 姜霁与镜辞建立“行为证据 + 镜返证明”的调查搭档；
- 顾横战死留下组织后果，而非主角经验包；
- 守钟人主动分线；
- 存在实验逐步揭露；
- 姜父线证明“记忆资料正确”仍不等于“这个人还是原来的他”。

阶段问题：

> 如果记忆可以复制，究竟什么东西不能被复制？

### 第三阶段：第6-7卷 · 谁拥有作为自己的资格

任务：
- 白壳从“活成原主”走向“成为白壳”；
- 守夜人完整登场；
- 姜霁脱离组织独立调查；
- 左衡共存路线崩塌；
- 壳王的身份继承错误被逐层看见，但不能因此撤销它造成的大量伤害；
- “壳是否拥有独立存在权”从哲学口号变成真实政治问题。

阶段问题：

> 一个从别人身份中出生的存在，有没有资格成为自己？

### 第四阶段：第8卷 · 分布式存在与终局归还

任务：
- 壳王与零号身份继承真相；
- 镜返5阶；
- 沈竹线回收；
- 芽保持希望但不坐实复活；
- 各势力关系后果进入终局；
- 999+1完成双向关系闭环。

最终问题：

> 当全世界都无法正确指向你时，还有什么能证明你真正存在过？

## 三、节奏原则

不再执行“每次升级必须信任崩塌”“每次大胜必须死人”“每1-2卷一个离去者”的机械公式。

保留更可靠的规则：

> **重大推进必须造成不可轻易撤销的结构变化。**

变化可以是：
- 人死亡；
- 人活着但离队；
- 关系永久改变；
- EX跨过阈值；
- 阵营分裂；
- 身份暴露；
- 据点失去；
- 一条制度被改变；
- 救下一个目标却永久失去另一个选择。

番茄节奏依旧要求快，但“快”指每段冲突都产生新信息、新选择或新代价，不是每十章必须安排一次爆炸。

## 四、关键节点链

1. **第1卷**：芽被替换，镜辞确认世界存在“身份错位”。
2. **第2卷**：镜辞进入剥壳人，与姜霁形成双方法调查体系；镜返2阶。
3. **第3卷**：顾横因组织撤离命令与现场事实冲突，违令开第二撤离线并战死；铭心在余波中觉醒。
4. **第4卷**：守钟人交出怀表与沈竹线索后主动归队；镜返3阶首次在完整关系证据链基础上强制显形。
5. **第5卷**：姜霁确认眼前“父亲身份”不是原来的姜父，但原主生死、当年是否主动参与替代仍未知；白壳进入主线。
6. **第6卷**：白壳产生自己的偏好、第一次违背原主脚本、接受“白壳”为自己名字、形成第一枚独立锚点；镜辞铭心失败暴露自己的出身偏见；镜返4阶解锁身份盲区。
7. **第7卷**：左衡路线崩塌并公开承担后果；姜父旧案继续追查；“壳王就是零号”的中期答案被撕开，壳王第一次正面提出“让所有关系最终只剩一个指向”的方案。
8. **第8卷**：关系网络共同抵抗壳王的大规模身份归并；镜辞MEM达到999，在EX逼近0时仍有一份真实锚点准确指向镜辞本人，形成1000>999。

## 五、目标演变链

| 阶段 | 表面敌人 | 镜辞的目标 | 对“我是谁”的理解 | 被推翻的旧认知 |
|---|---|---|---|---|
| 第1-2卷 | 个体壳 | 找到芽被替换的真相、活下来 | “我只是能看见异常的人” | 壳并非只会机械吃人，它们也会产生身份饥饿与模仿冲动 |
| 第3-4卷 | 壳巢/实验遗留 | 查沈竹与存在实验 | “我是实验造成的半壳接口个体” | 实验没有创造所有壳，只扩大裂缝并制造特殊个体 |
| 第5-6卷 | 壳潮/壳王影响 | 阻止扩大替代，同时理解白壳异常 | “我的特殊不等于我有资格定义别人” | 壳不能继承原主锚点，但可能通过自己的选择产生新锚点 |
| 第7卷 | 左衡路线/壳王 | 回答“谁有资格作为自己存在” | “我不是所有人的唯一保管者” | 拥有完整记忆并不构成原身份的继承权；理解反派也不等于免罪 |
| 第8卷 | 壳王的大规模身份归并 | 归还被篡夺的关系指向 | “我也需要允许别人认识并记住我” | 存在不是一个人背住所有人，而是关系分布在许多人之间 |

## 八、卷级大纲

> **数值规则统一**：EX始终是0-100状态值，不随卷升级。每卷默认战前可恢复到约80-100，真正的危险在关键战中是否跨过70/40/20/0关系阈值。
>
> SEE / WIL / MEM / 刻痕阶承担长期成长。镜返解锁固定为：2阶MEM≥20；3阶MEM≥60；4阶MEM≥120；5阶MEM≥999+终局条件。

### 第一卷：谁不是我？

- **功能**：开篇身份恐怖。
- **能力**：刻痕1阶 / SEE20 / WIL约30 / MEM 0-10 / 镜返1阶。
- **对手**：Lv.1-2个体壳。
- **主线**：镜辞发现芽出现大量微小违和；自我怀疑；最终看见接缝并确认“她不是原来的她”。
- **关系线**：先让读者相信镜辞与芽真的熟，替换才有疼痛。
- **钩子**：替换壳仍保留“先喝汤”等内在痕迹，但这只证明记忆残留，不证明芽仍活着。
- **禁碰**：完整壳巢、存在实验真相、白塔、镜返2阶。

### 第二卷：剥壳人

- **功能**：组织线与双方法调查体系成立。
- **能力**：刻痕2阶 / SEE40 / WIL约40 / MEM 10-20；卷末满足MEM20后解锁镜返2阶。
- **对手**：Lv.2-3。
- **主线**：进入剥壳人，与姜霁搭档；观潮者、百川堂逐步登场。
- **姜霁定位**：行为指纹是纯技术。她的异常直觉只能提醒“值得多看一眼”，不能直接判壳。
- **镜辞定位**：镜返2阶负责“照出哪里不对”，不替代调查。
- **顾横**：作为战斗导师建立完整人物，不提前把他的死亡当“期待债”。

### 第三卷：存在实验

- **功能**：顾横线结算 + 铭心觉醒 + 实验真相首次成形。
- **能力**：刻痕3阶 / SEE60 / WIL约50 / MEM 20-40 / 镜返2阶 / 铭心觉醒。
- **对手**：Lv.3-4。
- **顾横主线**：组织下达高污染区撤退命令，顾横确认仍有人未被证明不可救，主动违令打开第二撤离线并战死。
- **代价**：一部分人获救、一部分仍失去；顾横死后组织对他的评价分裂。
- **制度后果**：至少推动一项剥壳人行动规则修改。
- **铭心**：在顾横死亡后的余波中觉醒，只能放大已真正进入镜辞身体和判断的影响，不能下载顾横全部战斗经验。
- **实验线**：确认沈竹与旧实验有关，但不把“半壳”全部真相一次说完。

### 第四卷：共存论

- **功能**：白塔、左衡、守钟人分线；第一次成熟关系证据链。
- **能力**：刻痕3-4阶 / SEE60-80 / WIL约55 / MEM 40-60；卷末MEM达到60后解锁镜返3阶。
- **对手**：Lv.4-5。
- **镜返3阶规则**：不能看谁不顺眼就开技能。必须先取得真实关系锚点证据，再强制让身份矛盾显形。
- **姜霁功能**：负责建立证据链，确保镜辞不能取代她的调查职业。
- **白塔**：展示“记忆可以恢复，关系不能恢复”的残酷样本。
- **守钟人**：交出怀表与部分沈竹真相后主动归队，开启自己的守夜人/时间错位调查线。
- **左衡**：共存论第一次作为有吸引力的现实方案出现，而不是一出场就贴反派标签。

### 第五卷：父亲

- **功能**：姜霁独立主线 + 白壳登场 + “壳王是否就是零号”错误答案开始获得证据支持。
- **能力**：刻痕4阶 / SEE80 / WIL约60 / MEM 60-80 / 镜返3阶。
- **对手**：Lv.4-6。
- **姜父线确定事实**：眼前父亲身份不是原来的姜父。
- **保持未知**：姜父肉体是否存活、意识是否连续、当年是否完全自愿。
- **关键线索**：旧档案显示姜父可能主动参与某项替代/实验，但证据不足以直接定性。
- **姜霁觉醒**：在识破后的静默期首次正式觉醒“记忆差分·蚀忆门类”。能力只比较记忆反应与长期关系行为的不一致，不变成通用读心。
- **白壳**：作为壳巢高级执行者出现，起初严格按原主脚本生活。
- **零号线**：白塔旧档案显示壳王拥有零号近乎完整记忆、知识与自我叙事，中期允许角色合理形成“壳王就是零号延续”的判断。

### 第六卷：白壳

- **功能**：证明“壳可以形成自己的存在锚点”；姜霁分线；守夜人与壳巢正面扩大。
- **能力**：刻痕5阶 / SEE100 / WIL约70 / MEM 80-120；卷末MEM达到120后解锁镜返4阶。
- **对手**：Lv.5-7。
- **白壳弧线**：
  1. 仍然问“原主会怎么做”；
  2. 出现原主记忆中没有的偏好；
  3. 第一次明确做出原主不会做的选择；
  4. 有活人说“我知道你不是他，我也知道刚才那件事是你做的”；
  5. 主动接受“白壳”作为自己的名字；
  6. 形成第一枚属于白壳自己的存在锚点。
- **T15 铭心失败**：镜辞想调用白壳能力失败，不是因为“壳不能被铭记”，而是镜辞此前一直只在白壳身上寻找原主残留，没有真正理解白壳自己的选择。
- **镜辞人物伤口**：意识到“口头承认同伴”不等于真正摆脱出身偏见。
- **镜返4阶·遗忘领域**：本质为身份盲区。壳仍能看见、攻击镜辞，但难以通过姓名/身份稳定锁定他；不再统一削弱敌人30%。
- **守钟人再会**：他因追查能消除时间错位的技术进入壳巢相关区域，与镜辞线重新交叉，不是回来救场。
- **白壳与壳王**：白壳形成自己的锚点后，直接证明“壳可以放弃继承旧身份、建立自己的存在”。壳王因此把白壳视为理论性威胁，而不是默许它成长的实验样本。
- **白壳结局**：它在已经成为自己之后，为掩护多人撤离主动利用拟魂结构误导壳巢。是否牺牲来自它自己的选择，不用于换取“人格认证”。

### 第七卷：替人类活？

- **功能**：共存路线崩塌 + 独立壳政治问题 + 零号/壳王身份继承谜底第一次正面撕开。
- **能力**：刻痕6-7阶 / SEE120-140 / WIL85-100 / MEM 120-300 / 镜返4阶。
- **对手**：Lv.6-9。
- **左衡线**：发现共存路线长期默许不可逆替代后，不用“自杀洗账”结束。更有效的结算是公开证据、失去领导权、接受追责，并看着追随者分裂成反对、修正与继续坚持三派。
- **姜父线**：获得更完整旧案，但仍需要区分“姜父曾经同意一项计划”和“他同意后来发生的一切”。
- **白壳后果**：其他壳开始知道“偏离模板也可能形成自己”，壳巢内部第一次出现真正意识形态裂缝。
- **零号错误答案被推翻**：白塔档案能够证明壳王知道零号所有私人记忆，甚至保留零号自认为早已遗忘的细节；但姜霁、沈竹旧资料与关系证据共同证明，零号过去造成的关系后果从未自然延续到壳王。
- **壳王第一次正面对话**：它不求镜辞记住谁，也不承认自己需要被救。它提出自己的答案：既然关系决定身份，只要所有关系最终都只能指向它，“它是不是零号”就会成为一个失去意义的问题。
- **壳王邀请**：镜返能发现身份与关系错位，因此壳王希望镜辞成为“唯一指向”计划的校准接口。镜辞拒绝的原因不只是敌我，而是这个方案必须消灭每个人作为独立存在的权利。
- **关系遗产网络**：顾横旧部、白壳关系者、左衡追随者、守夜人各自继续行动。镜辞开始真正放弃“我一个人背住所有人”的冲动。

### 第八卷：他们不是人

- **功能**：壳王终局 + 关系归还 + 芽希望留白。
- **能力**：刻痕8-9阶 / SEE160-180 / WIL100-120 / MEM 300→999 / 镜返5阶。
- **对手**：Lv.7-9高阶壳 + 壳王Lv.10。
- **城市级危机**：壳王开始统一关系指向。人们不是简单集体失忆，而是出现“不同人的人生被记成同一个版本”“多个人同时被社会系统识别为同一身份”“知道某件往事却说不清自己为什么认识那个人”等身份归并现象。
- **终局不是单挑**：
  - 守钟人/守夜人负责确认并封闭裂缝因果错位；
  - 姜霁用长期行为与关系证据确认镜辞本人，抵抗被篡改记录；
  - 白塔提供记忆内容恢复但无法替代关系；
  - 剥壳人承担大规模撤离与战斗；
  - 百川堂负责把被删改的记录重新分发；
  - 独立壳/白壳留下的思想裂缝让部分壳拒绝继续完美替代；
  - 铭记者协作网络保护真实关系指向。
- **镜辞MEM=999**：只能与壳王999级关系篡改持平。
- **关键“1”**：当镜辞EX逼近0、世界无法稳定把名字指向他时，仍有一个活人做出一个只有真正认识镜辞才会作出的选择。
- **终局值**：`999（我有效铭记过你们） + 1（仍有人真正认识我） = 1000 > 999`。
- **记忆归还**：将壳截留的内在记忆重新与现实仍存在的关系锚点对齐，解除大规模身份篡夺；不复活死者。
- **壳王被剥离**：随着被盗记忆重新归位，壳王失去以999份他人身份支撑自己的结构，最终只剩“拥有零号记忆、却不是零号”的新存在。这是它最不愿面对、也无法再靠数据否认的事实。
- **壳王最终选择**：镜辞理解它为何走到这里，但不替受害者原谅。壳王若继续撕裂关系网络，就必须被真正镇封/消灭；若它第一次承认“我拥有零号记忆，但我不是零号”，则必须主动归还剩余身份、从裂缝内部完成闭合，并以自身彻底消失承担最后代价。这个选择不抵消任何旧罪。
- **芽留白**：最后的“先喝汤”只能是希望回声，不能坐实完整复活。更重要的是，芽的痕迹来自多个仍被她改变的人，而不只镜辞。
- **镜辞终点**：不是“带着所有人前行的人”，而是**终于愿意与别人一起承担，也允许自己成为别人生命一部分的人**。

## 九、写作检查

每推进一个大节点，检查：

1. 这段剧情是否仍围绕“身份/关系/存在”卖点，而不是被数值升级抢走？
2. 镜辞是否又用镜返跳过了姜霁或其他调查者的专业工作？
3. 配角的关键选择是否首先服务自己的目标，而不是为了给镜辞升级？
4. 本卷EX是否仍被误写成随卷增长的经验值？
5. 镜返3阶是否有关系证据前置？镜返4阶是否被误写成战斗减益领域？
6. 白塔是否误写成能够恢复关系锚点？
7. 白壳是否已经作为“白壳自己”被指向，而不是靠牺牲证明像人？
8. 守钟人是否仍在推进自己的任务，而不是主角叫他就出现？
9. 顾横、白壳、左衡等人的影响是否分布在多人/制度中，而不是全部落在镜辞身上？
10. 壳王是否保持“可理解但有罪”，并且它的核心执念始终是身份继承而非求爱/求被记住？
11. 是否错误暗示壳王一直在暗中培养镜辞或安排白壳成长？
12. 每次重大胜利是否有不可逆变化，但没有形成固定“下一章死人”公式？
13. 终局999+1是否写成双向关系，而不是系统数值突然+1？
14. 记忆归还后是否明确区分“零号的过去”与“壳王自己的最后选择”？
