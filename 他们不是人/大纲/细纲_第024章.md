# 细纲 · 第24章 有人知道

## 第 24 章：有人知道
- **核心事件**：镜辞从南岸回城后发现，自己离开的两天里至少有一名陌生人到旧市场打听他的行程。不同摊主对陌生人的外貌描述互相矛盾，但三个人都记得对方准确说出“镜辞”“沈竹”“17号”三个词。镜辞意识到，追踪者不仅知道他在查什么，还在主动收集他周围人的反应。他没有把“所有身份使用者共享信息”当成结论，只确认自己被一条现实调查链盯上。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第24章；调查者被反调查
- **单元ID/位置**：1-2；第14拍·反侦察压力
- **目标情绪**：回到熟悉市场 → 熟人提起陌生访客 → 描述互相打架 → 三个关键词稳定一致 → 被盯上的压迫感
- **主角目标/关键选择**：镜辞想知道谁在查自己；关键选择=不追着每个描述猜“到底长什么样”，而是找不同证词中唯一稳定的共同信息
- **章节定位**：都市惊悚+反调查；让危险重新进入普通市场关系
- **本章结构公式**：节点1（修锁匠提访客） + 节点2（三名证人三个外貌版本） + 节点3（三个关键词一致） + 节点4（查看周边监控） + 节点5（只拍到模糊侧影） + 节点6（镜辞改变信息暴露方式）
- **章首钩子**：镜辞刚拉开卷帘门，隔壁修锁匠就问：“你那个姓沈的亲戚找着没？前天有人来问你17号查到哪了。”
- **本章即时兑现**：第10-11章的灰衬衫威胁升级为持续反调查，但仍不提前坐实“壳巢共享意识”
- **本章禁止提前释放**：壳巢、群体记忆同步、唯一指向、追踪者具体身份
- **能力边界**：镜返第一式不能通过别人口述还原对方真身
- **契约风险**：契约安全。危险来自信息暴露与社会环境，不靠突然袭击硬提压强

#### 内容概括（五段式）
- **起因**：镜辞回市场第一天，修锁匠随口说有人在他不在时来问北河17号，还提到了沈竹。镜辞立刻停下手里的活，把询问变成分别访谈，不让几个人聚在一起互相“校正记忆”。
- **发展**：修锁匠记得是个三十多岁的男人，水果摊老板说是个短发女人，送货工则坚持是个戴口罩的年轻人。三种外貌几乎没有交集，连衣服颜色都不同。
- **转折**：镜辞把三份原话分开抄完，发现唯一一致的不是外貌，而是对方问过的三个词：镜辞、沈竹、17号。三个人还都记得陌生人问了一句“他回来以后还会去河边吗”。
- **高潮**：附近两家店的监控只拍到一个远处侧影，角度和压缩都不足以确认性别或面貌。镜辞不强行从模糊画面里“看接缝”，而是确认一个更现实的事实：有人知道他的调查关键词，并且故意通过他周围的人判断下一步行动。
- **结尾**：镜辞把以后所有地点代号重新编号，不再在普通电子客户系统、聊天软件和公开场合写真实调查坐标。他在账本新加一栏：`谁知道这条信息`。守钟人看到后说：“总算开始查消息怎么漏出去的了。”

#### 情节安排（多线）
- **主线推进**：反调查从一次威胁升级为持续信息收集；镜辞开始做信息权限管理
- **辅线推进**：第11章证词错位现象再次出现，但这次稳定关键词帮助镜辞抓共同部分
- **事件线/任务线**：收到访客信息 → 分开访谈 → 比较差异 → 查监控 → 得到最小结论 → 改信息管理方式
- **任务卡点**：三个人对外貌说法完全不同 → 无法还原人物 → 转而分析共同关键词 → 发现真正重要的是对方知道什么
- **感情线/关系线**：镜辞×旧市场：熟人仍能帮助他，但他开始意识到自己的调查也会把他们暴露给危险
- **逻辑线**：第11章证词错位 → 第24章同类现象重现 → 追踪者掌握调查关键词 → 后续必须查信息泄露源

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 修锁匠 → 水果摊老板 → 送货工 → 守钟人
- **人物关系变化**：镜辞开始主动保护普通关系人，不再把他们当免费证人池
- **视角/信息差**：追踪者可能不止一个，也可能是一个能制造记忆错位的人；第一卷不下结论
