# 细纲 · 第23章 柳树的字

## 第 23 章：柳树的字
- **核心事件**：镜辞第二天返回南岸河湾，不寻找“沈竹留给自己的浪漫痕迹”，而是按第22章观测棚基础寻找配套标记。他在柳树背面找到一块被树皮包住大半的铝制测时牌，上面有沈竹的手写数据、日期和缩写。日期晚于她过河台账一天，证明她确实在这里继续做过现场记录。测时牌末尾还有一个未知代码 `D4`，箭头指向下游。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第23章；沈竹南岸调查痕迹实证
- **单元ID/位置**：1-2；第13拍·个人痕迹与专业痕迹重合
- **目标情绪**：精细搜索 → 找到人工标记 → 认出沈竹笔迹 → 日期互证 → 新方向出现
- **主角目标/关键选择**：镜辞想确认沈竹是否真正使用过这个未知测点；关键选择=不拿任何“像沈竹”的东西当证据，必须把笔迹、日期、材料和现场结构同时对上
- **章节定位**：物证兑现章；情感通过职业细节承载，不靠刻“镜”字硬煽
- **本章结构公式**：节点1（按棚基础反推辅助标记） + 节点2（柳树背面铝牌） + 节点3（字迹与记录格式） + 节点4（日期与渡口台账互证） + 节点5（D4下游箭头）
- **章首钩子**：镜辞没有在柳树上找自己的名字。他先找螺丝孔、线槽和固定点。真正让他停住的，是树背面一小块几乎被新树皮吞进去的铝片。
- **本章即时兑现**：沈竹过河后继续调查获得现场实证，且证据属于专业记录而非私人告白
- **本章禁止提前释放**：D4含义、南岸网络全貌、沈竹之后去向、组织身份
- **契约风险**：契约安全。情感高点与调查推进是同一个物证，不额外安排煽情纪念品

#### 内容概括（五段式）
- **起因**：天亮后，镜辞带着昨天测出的水泥底座尺寸回河湾。他按旧观测设备布置习惯寻找固定标尺、线槽或辅助标记，而不是漫无目的翻树根。
- **发展**：柳树背面离地一米多的位置有两枚旧钉，树皮已经长过钉帽。中间夹着一块很薄的铝牌。镜辞只清理表面泥藓，不强拆。牌上能辨出：`S2 / 22:08 / -3.6`，下面还有几个更小的字。
- **转折**：数字排列和正负号写法与第18章沈竹旧表格完全一致，末尾还有她习惯性的“先写慢快、后补表号”的短划。最关键的是日期：正是渡口台账的第二天。至少在那一天，沈竹本人或使用她这套记录习惯的人来到这里继续测过。
- **高潮**：镜辞拿纸张笔迹照片、旧记录和现场铝牌做三方比对，只写最小结论：“沈竹极可能亲自记录。”他没有写“她为我留下”。牌最底下还有 `D4 →`，箭头顺着旧堤指向下游。
- **结尾**：镜辞问附近老店老板D4是什么，对方只记得以前下游还有一处废弃泵房，后来围起来不让进。镜辞把箭头方向画进地图，新的调查目标出现。

#### 情节安排（多线）
- **主线推进**：沈竹在南岸河湾的活动获得强物证；D4指向下游泵房
- **辅线推进**：镜辞越来越会区分“情感上想相信”和“证据实际能支持”
- **事件线/任务线**：寻找辅助标记 → 铝牌 → 笔迹格式比对 → 日期互证 → D4方向
- **任务卡点**：铝牌可能是任何人写的 → 格式、笔迹、日期共同提高可信度 → 仍用“极可能”而非绝对确认
- **感情线/关系线**：镜辞在沈竹的工作习惯中确认亲近感，而不是让沈竹跨三年专门刻一个字等他发现
- **逻辑线**：南岸未知测点 → 辅助测时牌 → 沈竹记录 → D4下游泵房

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 老杂货店老板一笔
- **人物关系变化**：无新核心人物；主角调查方法继续成熟
- **视角/信息差**：D4对老居民只是旧泵房方位，对镜辞可能属于测点网络代码
