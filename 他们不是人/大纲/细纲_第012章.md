# 细纲 · 第12章 两页名字

## 第 12 章：两页名字
- **核心事件**：眼前的芽准备离开旧街。镜辞在证据账本里第一次把“原芽的过去”与“眼前这个存在醒来后的选择”分开记录，拒绝把两者压成一个身份，也拒绝把眼前存在简单写成“假货”。对方透露自己记忆里反复出现一处临江北面的旧村、枯河和大树，却无法确认那是不是原芽真正经历过的地方。她决定亲自去查。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；第12章；芽线从身份摊牌转入来源调查
- **单元ID/位置**：1-2；第2拍·关系拆分
- **目标情绪**：克制告别 → 身份边界刺痛 → 双方第一次谈“现在的你” → 新线索出现 → 主动分线
- **主角目标/关键选择**：镜辞想记录所有与芽有关的证据；关键选择=不把原芽的记忆与眼前存在醒来后的行为混在同一页
- **章节定位**：关系推进+任务启动；必须产生一个新的行动方向，而不是继续重复“她不是芽”
- **本章结构公式**：节点1（眼前芽来告别） + 节点2（镜辞建立两页记录） + 节点3（双方争论“什么算我的经历”） + 节点4（旧村记忆线索） + 节点5（她决定先去查）
- **章首钩子**：眼前的芽看到镜辞的新账本，第一句话不是问灰衬衫男人，而是：“你打算把我写在哪一页？”
- **本章即时兑现**：第8-9章提出的“记忆不等于本人”第一次落实成镜辞的实际调查方法
- **本章禁止提前释放**：存在锚点术语、白壳未来答案、壳来源、原芽生死结论
- **契约风险**：契约安全。灰度来自身份事实与当前选择的冲突，不靠提前给眼前存在发“好人证”

#### 内容概括（五段式）
- **起因**：眼前的芽来钟表行，说自己明早会离开旧街一阵子。她注意到镜辞新买的账本，翻到空白页，问镜辞准备怎么记录她。
- **发展**：镜辞先写一页“芽：过去可确认事实”，记录少年时期、早餐铺、旧同学、照片、第三方证词；又翻到下一页，只写“眼前存在：醒来后可确认行为”，把她最近主动摊牌、警告灰衬衫男人、决定离开的事写进去。她看着第二页很久，问：“连名字都不给？”镜辞说：“我不知道你叫什么。写‘芽’，是在替你和她一起下结论。”
- **转折**：她没有感谢，反而有些恼火。她说自己脑子里有一处反复出现的地方：临江以北一个快废掉的村子、干掉的河床和一棵树。她知道怎么走、知道树根旁有块裂石，却无法确认这些是自己去过，还是原芽留下的记忆。
- **高潮**：镜辞问她为什么一定要去。她答：“因为这是我脑子里少数没有你的地方。如果连那里也是她的，我至少想亲眼确认一次。”这句话第一次把她的目标从“继续当芽”推向“查清自己从哪醒来”。
- **结尾**：镜辞没有阻止，只把村名、路线和她描述的三处细节写进第二页，并要求她到地方后分别拍照，不要先告诉当地人自己记得什么，避免被引导。她看着他：“你这是在调查我。”镜辞说：“也在帮你调查你自己。”

#### 情节安排（多线）
- **主线推进**：原芽/眼前存在正式分轨记录；村子线启动
- **辅线推进**：镜辞开始形成“先记录事实，再决定身份解释”的方法
- **事件线/任务线**：告别 → 账本分类冲突 → 村子线索 → 设计验证方法 → 分头行动
- **任务卡点**：镜辞想准确记录 → “名字”本身就带结论 → 改用事实分层 → 获得新调查坐标
- **感情线/关系线**：镜辞与眼前存在从旧青梅关系彻底退出，进入有边界的合作关系
- **逻辑线**：记忆不等于经历 → 记录必须区分来源 → 村子成为验证记忆来源的第一处现场

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 眼前的芽
- **人物关系变化**：镜辞不再只把对方当“错误版本的芽”，但也不替她提前建立新身份
- **视角/信息差**：眼前存在掌握村子的主观记忆，镜辞掌握外部关系证据，双方各缺一半

#### 情节细化

- 点2：镜辞建立“原芽过去事实”页【调查·密300】
- 点3：另起“眼前存在醒来后行为”页，引发名字争执【关系·密350】

#### 结尾设定和钩子
- **结尾设定**：账本记录的是不同来源的事实，不负责把两个存在强行合并或强行分割成作者答案
- **章尾钩子**：那个旧村到底属于原芽的过去，还是与“眼前存在醒来的来源”有关？
