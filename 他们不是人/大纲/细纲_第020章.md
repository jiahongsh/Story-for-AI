# 细纲 · 第20章 名单

## 第 20 章：名单
- **核心事件**：连续接触北河、猫眼和临江03点后，镜辞回到旧市场，发现自己开始过度怀疑所有变化。他建立一张“谁像壳”的名单，却在核查第一项时就误判：修鞋摊换人只是老师傅生病、侄子临时代班。镜辞当场废掉“人/壳二分名单”，改成“已证实身份冲突 / 有接缝待核 / 普通变化已排除 / 信息版本异常”四类记录。随后他发现第7-10章周远维修单的数字客户记录已经被改写，而手里的纸质复写联仍保留旧号码。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第20章；调查方法第一次主动纠错
- **单元ID/位置**：1-2；第10拍·方法升级
- **目标情绪**：高度警觉 → 自己先犯错 → 尴尬与警醒 → 方法重建 → 真正的数据异常出现
- **主角目标/关键选择**：镜辞想快速筛出市场里的异常者；关键选择=发现误判后主动废掉简单名单，不因为“我是主角我能看见”就坚持自己一定对
- **章节定位**：调查方法章+现实惊悚；需要一次明确误判纠正，防止主角滑向偏执扫描仪
- **本章结构公式**：节点1（写下人/壳名单） + 节点2（修鞋摊被判可疑） + 节点3（核查后证明普通换班） + 节点4（镜辞重做分类） + 节点5（周远数字记录被覆盖） + 节点6（纸质版本幸存）
- **章首钩子**：镜辞在纸上写了二十多个名字，刚准备给第一个人画问号，就被守钟人伸手把笔按住：“你是在查人，还是在给人判刑？”
- **本章即时兑现**：第4章误判意识与猫眼来源链方法结合，形成第一卷稳定调查原则
- **本章禁止提前释放**：唯一指向、白塔技术、壳巢批量改档机制、姜霁正式方法论
- **能力边界**：看见接缝只能提供异常信号；没有接缝不保证一切正常，有接缝也不能自动完成社会身份判定
- **契约风险**：契约安全。主角因果权来自会修正自己的方法，而不是永远猜对

#### 内容概括（五段式）
- **起因**：镜辞回旧市场后，发现修鞋摊换了人、水果摊老板改了口头禅、老王弯腰方式似乎不同。他把这些变化全部抄进账本，一度想直接分成“正常”和“可疑”。
- **发展**：他先查修鞋摊。新来的年轻人确实坐在林师傅的凳子上、用林师傅的工具，回答常客时也不熟练。镜辞越看越觉得像替代，直到隔壁几家商户拿出医院缴费单和视频通话：林师傅腰伤住院，侄子只来代班两周。年轻人没有接缝，只是一个被陌生环境弄得手忙脚乱的普通人。
- **转折**：镜辞意识到，如果继续用“行为变化=身份异常”的逻辑，他迟早会把每个换发型、换口音、换生活习惯的人都列成怪物。他把整张二分名单撕掉，重新画四栏：`已证实身份冲突`、`有接缝待核`、`普通变化已排除`、`信息版本异常`。
- **高潮**：整理旧案件时，他登录钟表行的电子客户系统，发现“周远”的手机号已经变成灰衬衫男人取件时留下的号码，修改时间显示在第10章冲突后的凌晨。系统里没有修改人记录。镜辞立刻翻出自己保留的纸质复写单，上面仍是原周远的号码。
- **结尾**：他把电子页面离线导出、拍屏，又把纸单装进透明袋，分别标注来源和时间。守钟人看着那两套号码，问：“现在你觉得哪个是真的？”镜辞回答：“我只知道它们以前不一样，现在有人想让它们看起来一样。”

#### 情节安排（多线）
- **主线推进**：主角调查方法从二分怀疑升级为证据分级；数字记录出现人为或异常覆盖
- **辅线推进**：猫眼“版本变化”方法在主角自己的生活系统中得到验证
- **事件线/任务线**：列名单 → 查第一个对象 → 误判 → 重建分类 → 发现数字记录改写 → 保存旧版本
- **任务卡点**：镜辞想快速找异常 → 普通变化造成误判 → 被迫承认观察能力也会制造偏见 → 更严格方法反而抓到真正版本异常
- **感情线/关系线**：镜辞×旧市场：他选择保护普通人的“可以变化的权利”，而不是因为恐惧把邻居全变成嫌疑人
- **逻辑线**：接缝优势 → 误判风险 → 分类方法 → 数据覆盖实证 → 身份问题开始进入日常信息系统

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 守钟人 → 修鞋摊侄子 → 周边商户群像
- **人物关系变化**：守钟人不再只说“别看”，而开始逼镜辞思考“看见以后怎么不伤错人”
- **视角/信息差**：谁修改了周远数字记录未知；只能确认修改发生在冲突之后

#### 结尾设定和钩子
- **结尾设定**：第一卷调查红线确立：变化不等于替代，接缝不等于完整判决；版本差异必须保留
- **章尾钩子**：能改写钟表行普通客户系统的人，是否与让多份历史档案趋于统一的是同一类力量？
