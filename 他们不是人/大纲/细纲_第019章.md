# 细纲 · 第19章 河底

## 第 19 章：河底
- **核心事件**：镜辞带两块普通机械表、怀表和电子计时器去临江老码头03点复现沈竹记录。白天无明显异常，21:40后怀表与其中一块老机械表先后出现不同程度走时偏差，电子计时仍稳定。退到上游百米后恢复。退潮露出的江底边缘同时出现一截与北河17号相似的旧测点支架，证明两地曾属于同一套观测网络。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第19章；异常地点网络第一次扩展到城市江边
- **单元ID/位置**：1-2；第9拍·复现实验
- **目标情绪**：白天无果 → 等待时段 → 数据开始偏移 → 现场风险提升 → 旧网络实证
- **主角目标/关键选择**：镜辞想复现沈竹“21:40后偏差扩大”的记录；关键选择=异常出现后不下水追东西，先完成时间、距离和设备差异记录
- **章节定位**：悬疑实验章+城市恐怖；惊悚来自普通江边出现可重复异常，不靠河底鬼影堆氛围
- **本章结构公式**：节点1（白天基线） + 节点2（旧钓鱼人提供生活经验） + 节点3（21:40后走时偏移） + 节点4（退远恢复） + 节点5（退潮露旧支架） + 节点6（不下水）
- **章首钩子**：21:39，三块表和手机计时还完全一致。21:43，沈竹留下的怀表慢了第一拍。
- **本章即时兑现**：沈竹旧记录可被镜辞独立复现；异常并非私人幻觉
- **本章禁止提前释放**：裂隙完整理论、守夜人身份、测点网络建立者、河底具体是什么
- **设定边界**：机械表异常是粗糙环境指标，不是壳探测器；镜辞不能凭走时偏差判断附近谁被替换
- **契约风险**：契约安全。主角有行动、有风险判断、有新物证，不靠莽下河制造高潮

#### 内容概括（五段式）
- **起因**：镜辞下午到老码头，先按沈竹照片角度确认03点位置。白天三块表与手机计时全部正常。他没有因为“什么也没发生”就提前下结论，而是把温度、潮位、风和船流都记下来，等到21:40。
- **发展**：附近一个常年夜钓的老人看他摆了一排表，以为他在做水文测量，随口说这一段江边有个怪事：有些老式电子漂和机械闹钟放久了会“走不齐”，年轻人都当潮气或磁场。老人不知道任何超自然解释，只把它当生活经验。
- **转折**：21:43开始，怀表先漏拍；几分钟后另一块旧机械表也出现轻微偏差，较新的机械表基本正常，手机计时没有变化。镜辞把设备整体移到上游一百多米，偏差逐渐消失；搬回03点附近，又重新出现。
- **高潮**：夜里退潮，码头下方一段淤泥和旧石阶露出来。镜辞用手电照到一截锈蚀金属框，孔位和北河17号旧支架几乎一致，旁边混凝土上还能辨出一个被磨掉大半的“03”。他没有下水，只在安全位置拍照、测距、记录潮位。
- **结尾**：夜钓老人问他下面是不是有什么值钱东西。镜辞看着两组几乎一样的固定孔：“不是东西值钱。是有人以前在两个完全不同的地方，测过同一种问题。”

#### 情节安排（多线）
- **主线推进**：03点异常被复现；北河与临江形成历史观测网络联系
- **辅线推进**：普通人长期生活经验提供“异常一直嵌在城市日常中”的质感
- **事件线/任务线**：建基线 → 等时段 → 记录偏差 → 移动复测 → 退潮见支架 → 保全证据
- **任务卡点**：白天无现象 → 夜间才出现 → 不同设备反应不同 → 主角必须排除“怀表独有魔法”解释
- **感情线/关系线**：镜辞与沈竹的方法再次跨时间重合，但不是“追随她脚印”的抒情观光
- **逻辑线**：沈竹记录 → 独立复现 → 设备差异 → 旧支架相同 → 历史网络存在

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 夜钓老人
- **人物关系变化**：镜辞开始积累普通人的长期观察，而不只向神秘知情者要答案
- **视角/信息差**：老人知道生活经验但不知道原因；镜辞知道17号对应但不知道网络建立者
