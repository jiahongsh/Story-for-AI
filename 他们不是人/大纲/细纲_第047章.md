# 细纲 · 第47章 儿子回来了

## 第 47 章：儿子回来了
- **核心事件**：电梯门打开，一个三十多岁的男人走出来，自称陈骁。长相与陈启明家中旧照片高度一致，身份证、门禁、家庭关系验证全部通过。他知道家里旧地址、母亲忌日、阳台花盆的位置，也能叫出几个老邻居名字。陈启明却始终没有让他进屋，只说：“你很像，但我儿子回来不会先问我Wi-Fi密码。” 这不是单一暗号，而是老人对九年疏远关系的整体违和。镜辞在男人耳后看见一道极淡接缝。章尾，陈启明关上门后第一句话是：“小镜，帮我打个电话。我儿子现在在宁州。”
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段3；第47章；陈骁身份事件正式发生
- **单元ID/位置**：1-4；第7拍·所有证件都认他
- **目标情绪**：期待与戒备 → 外貌资料高度吻合 → 老人迟迟不认 → 镜辞看到极淡接缝 → 另一个联系方式抛出
- **主角目标/关键选择**：镜辞想判断眼前人是否存在身份错位；关键选择=即使看见接缝也不当场宣布“你是假的”，先让陈启明自己决定是否让人进家门
- **章节定位**：身份恐怖+关系判断；把“看见不等于证明”推到现实家庭
- **本章结构公式**：节点1（电梯门开） + 节点2（身份证/人脸/关系全部通过） + 节点3（男人表现出大量正确记忆） + 节点4（陈启明仍不让进门） + 节点5（镜辞看见极淡接缝） + 节点6（老人要打另一个儿子的电话）
- **章首钩子**：电梯里走出来的人和502客厅墙上那张十年前的全家福，几乎是一张脸。
- **本章即时兑现**：第46章自动恢复的“标准儿子”权限被真实使用；系统正确性与关系直觉第一次正面冲突
- **本章禁止提前释放**：眼前陈骁的物种/来源、真正陈骁状态、系统为何能通过验证、壳巢/身份同步术语
- **能力边界**：镜辞看见接缝只能证明当前身份与关系网络存在错位，不能独自证明眼前人犯罪或真正陈骁一定无恙
- **契约风险**：契约安全。陈启明拒绝认人必须建立在长期关系整体违和上，不能靠一道“只有亲儿子知道”的密码题秒判

#### 内容概括（五段式）
- **起因**：电梯停在五楼。男人拖着一个不大的行李箱出来，看见陈启明先愣了一下，然后喊“爸”。物业人员随后上楼，确认门禁刚刚通过，身份证和住户关系也都能在新系统里对上。
- **发展**：男人的外貌与老照片高度一致。他知道母亲去世是哪一年，知道客厅钟以前挂在哪面墙，知道陈启明年轻时腰受过伤，也认出隔壁刘姨。九年足以让一个人变很多，他说自己最近工作停了，想回来陪父亲一阵。
- **转折**：陈启明没有开门。他隔着半扇防盗门问了几个很生活的问题，没有一个是“秘密暗号”。男人大多答得合理，可回答方式总让老人皱眉。最明显的一次，是男人进楼后的第一件事问“家里Wi-Fi还是以前那个吗”。陈启明后来低声告诉镜辞：真正的陈骁九年前走时跟他吵翻，父子这些年只在春节发几句消息；如果真回来，第一句话不会这么轻松。
- **高潮**：镜辞一直没有插话。男人侧身和物业解释时，耳后出现一条极细接缝，比第10章灰衬衫男人最初的缝还淡。它不是“证件错误”的图标，只在男人试图自然接回“儿子”这个关系位置时短暂浮出。镜辞知道自己的怀疑有了方向，却仍没有社会证据。
- **结尾**：陈启明最终说“今天先住外面，我没准备好”，把门关上。男人站了一会儿，没有发火，只说“行，爸你慢慢想”，拖箱回电梯。脚步消失后，老人靠着门站了很久，转身对镜辞说：“小镜，帮我打个电话。我儿子现在在宁州。”

#### 情节安排（多线）
- **主线推进**：同一标准身份进入现实关系空间，形成“系统承认/父亲拒绝/镜辞见缝”的三方冲突
- **辅线推进**：陈启明多年疏远的父子关系说明“关系薄弱”不等于“没有关系”，也更容易被标准资料占位
- **事件线/任务线**：人回来 → 系统验证 → 对话试探 → 父亲拒门 → 镜辞见缝 → 另一个联系方式
- **任务卡点**：所有行政证据支持眼前人 → 镜辞无法公开镜返作为证据 → 只能尊重户主现实边界并寻找独立来源
- **感情线/关系线**：陈启明与亲生儿子的关系本就有伤痕，这让“替代”不是童话式完美家庭被夺走，而是一个破损关系被系统强行补成干净版本
- **逻辑线**：直系关系自动恢复 → 人实际回家 → 文件正确 → 关系接续不自然 → 接缝出现

#### 人物关系和出场顺序
- **出场顺序**：陈启明 → 眼前“陈骁” → 物业人员 → 镜辞
- **人物关系变化**：镜辞第一次参与一个自己看见错位、但当事人必须自行决定是否接纳的家庭场景
- **视角/信息差**：读者知道陈启明还掌握另一个儿子联系方式，但尚未知道电话那头会出现谁

#### 结尾设定和钩子
- **结尾设定**：合法证件、正确记忆和相似身体仍不足以自动证明关系连续性；镜辞的接缝只是调查方向，不是法庭证据
- **章尾钩子**：如果真正的陈骁人在宁州，那么刚才这个所有系统都认作陈骁的人又是谁？
