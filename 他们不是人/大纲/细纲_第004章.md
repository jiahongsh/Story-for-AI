# 细纲 · 第4章 观察者

## 第 4 章：观察者
- **核心事件**：镜辞开始系统排查“接缝”是否只出现在芽身上。他发现自己的眼睛并不是万能验人器：大多数异常都能被现实原因解释，只有一个陌生白领身上出现了与芽高度相似的结构。同时，守钟人的一句警告证明“有人知道这种东西存在”。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；第4章；从单个熟人异常扩大到城市生活中的潜在风险
- **单元ID/位置**：1-1；第4拍·规律初探
- **目标情绪**：主动调查 → 误判缓冲 → 真异常出现 → 被前辈警告 → 孤立感上升
- **主角目标/关键选择**：镜辞想知道昨晚看到的是不是只属于芽；关键选择=不直接拿陌生人做危险试探，而是先建立观察样本
- **章节定位**：信息推进章；重点是“能力有用但不可靠到能直接定罪”
- **本章结构公式**：节点1（建立排查记录） + 节点2（两个现实误判） + 节点3（白领出现真实接缝） + 节点4（守钟人警告） + 节点5（沈竹旧纸条）
- **章首钩子**：镜辞给自己定了一个规矩：今天只看，不问，不跟，不碰。昨晚芽隔着窗户看向他的那一眼，让他第一次意识到，观察别人也可能让自己被观察。
- **本章即时兑现**：读者获得“接缝不是主角胡思乱想”的第二次确认，同时明确镜辞仍会误判普通异常，能力边界开始成形
- **本章禁止提前释放**：壳的正式分类、裂缝、刻痕者、白塔、存在力、镜返名称与后续技能
- **能力边界**：镜辞能看见某些结构异常，但不能仅凭视觉判断一个人的全部身份、记忆来源、危险等级和是否可救
- **契约风险**：契约安全。主角能力没有被组织解释吞掉，也没有升级成无成本鉴定术

#### 内容概括（五段式）
- **起因**：镜辞把维修单背面改成临时观察记录。他从旧货市场最熟悉的人开始看：摊主、顾客、送货员。为了防止自己被昨晚吓出偏见，他强迫自己先找正常解释。
- **发展**：他连续两次“看错”。水果摊老王手指边缘的亮线来自透明胶带反光；赵奶奶眼尾那道细缝只是旧手术疤在镜片中的重影。这两次误判压住主角能力的万能感，也让他更谨慎。
- **转折**：下午，一个穿灰衬衫的白领来修表。镜辞低头登记时，在柜台玻璃反射里看到对方领口下方有与芽同样的细亮结构。换三个角度仍在，离开玻璃反射后肉眼也能捕捉到一瞬错位。这个人却表现得再普通不过。
- **高潮**：白领走后，镜辞试探守钟人：“你有没有见过一个人，看起来哪里都对，可就是像没贴严？”守钟人正在装表针，手停了不到一秒，只说：“能看见，不等于该盯着看。盯久了，对面也会知道。”这句话与昨夜窗后的芽直接咬合。
- **结尾**：镜辞回家翻沈竹留下的旧物盒，在怀表维修票据后面找到一张褪色便签。上面没有解释世界，只写着一句：**“如果你也看见了不该看见的东西，先别告诉任何人。”**字迹是沈竹的。

#### 情节安排（多线）
- **主线推进**：确认“接缝现象不只芽一例”，但通过误判强调调查需要证据
- **辅线推进**：守钟人由普通熟人升级为“明显知道内情的人”；沈竹线第一次与异常直接发生文字关联
- **事件线/任务线**：建立样本 → 排除误判 → 找到第二例 → 试探知情者 → 翻旧物
- **任务卡点**：镜辞想快速确认规律 → 自己连续误判 → 被迫降低结论强度 → 真异常出现更可信 → 守钟人拒绝解释
- **感情线/关系线**：镜辞×守钟人从日常熟悉进入“双方都知道对方藏着东西”的新状态
- **逻辑线**：芽接缝 → 寻找同类现象 → 误判建立边界 → 第二例成立 → 守钟人警告证明有人知道 → 沈竹留下同类警告

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 旧市场群像 → 老王/赵奶奶作为误判样本 → 灰衬衫白领 → 守钟人 → 沈竹通过便签出现
- **人物关系变化**：镜辞开始重新评估守钟人与沈竹过去的关系和知情程度
- **视角/信息差**：守钟人明显比镜辞和读者知道更多，但本章只让他给风险提示，不让他承担设定讲解员

#### 情节细化
- 点1：镜辞写下“只看、不问、不跟、不碰”，把调查方法写成行为，不写说明文【开场/人物·密250】
- 点2：观察旧市场熟人，通过现实细节建立城市烟火与样本基线【日常/推进·密300】
- 点3：老王透明胶反光误判，镜辞主动换角度排除【边界·密250】
- 点4：赵奶奶旧手术疤重影误判，再次提示视觉异常不等于身份异常【边界·密250】
- 点5：灰衬衫白领进店修表。镜辞先从柜台反射捕捉到接缝【悬念·密350】
- 点6：他通过三个角度复核，接缝仍在；不追、不碰、不问私人身份【小兑现·密350】
- 点7：白领离开时回头看了一眼店招，不与镜辞对视，留下“是否察觉被看”的不确定性【悬念·密200】
- 点8：镜辞试探守钟人，用“没贴严”这种生活化描述，不提前说术语【对话·密300】
- 点9：守钟人警告“盯久了，对面也会知道”，与芽窗后回望形成闭环【信息揭示·密350】
- 点10：镜辞回家翻沈竹旧物盒，找到便签【推进·密250】
- 点11：章尾落在沈竹字迹：“如果你也看见了不该看见的东西，先别告诉任何人。”【强钩子·密300】
- `预算合计：3150字（目标3000，范围3000-3300）`

#### 结尾设定和钩子
- **结尾设定**：镜辞确认两件事：接缝不只出现在芽身上；沈竹和守钟人都曾接触过类似异常。除此之外不得替他补结论
- **章尾钩子**：私人悬疑与超自然悬疑第一次接轨：沈竹为什么提前知道镜辞可能“也看见”？
