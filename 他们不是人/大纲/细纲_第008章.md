# 细纲 · 第8章 摊牌

## 第 8 章：摊牌
- **核心事件**：镜辞拿着灰衬衫取件事件的证据与芽正面对峙。芽第一次明确承认：她不是镜辞从小认识的那个芽，但她拥有芽的大量记忆。她声称自己不知道“原来的芽”去了哪里。镜辞没有因为她表现出恐惧和求生欲就放弃追问。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；第8章；第一轮身份摊牌
- **单元ID/位置**：1-1；第8拍·关系真相打开一层
- **目标情绪**：压抑对峙 → 关键承认 → 短暂共情诱惑 → 主角拒绝简单和解 → 更大的未知
- **主角目标/关键选择**：镜辞想确认芽是否知道灰衬衫身份事件及真正芽的下落；关键选择=听她说完，但不把“她也害怕消失”当成免责理由
- **章节定位**：高压对话章；对话必须持续改变信息和立场，不能变成世界观说明会
- **本章结构公式**：节点1（镜辞带证据赴约） + 节点2（芽先点破他能看见） + 节点3（承认“我不是你认识的芽”） + 节点4（原芽去向争执） + 节点5（镜辞拒绝替她定义无罪）
- **章首钩子**：镜辞刚敲门，芽就在门后说：“那只表，不是同一个人来拿的，对吧？”门还没开，她已经知道他为什么来。
- **本章即时兑现**：持续八章的核心疑问得到第一层明确答案：眼前的人确实不是镜辞记忆中的原芽；但“她是什么、原芽在哪、谁造成替换”仍未回答
- **本章禁止提前释放**：壳的正式来源、壳巢、存在实验、白塔、裂缝、芽是否还活着的结论
- **设定边界**：拥有原芽记忆不能自动等价为原芽本人；眼前存在可以有自己的恐惧和选择，但这不自动抹掉被占用身份的伤害
- **契约风险**：契约安全。灰度角色不通过一句“我也可怜”拿走受害者位置

#### 内容概括（五段式）
- **起因**：镜辞带着维修单和取件记录去找芽。门一开，芽没有装作什么都不知道，直接问他是不是遇到了“另一个用别人身份的人”。她显然早就知道这种现象存在。
- **发展**：镜辞问：“你和他一样吗？”芽沉默很久，最后说：“如果你问我是不是你从小认识的那个芽，不是。”这是她第一次不绕开。镜辞继续追问真正的芽在哪里、她的记忆为什么会在眼前这个人身上。
- **转折**：芽说自己“醒来时”就知道镜辞是谁、知道早餐铺、知道先喝汤、知道沈竹失踪，也知道很多连镜辞都快忘了的少年细节。可她不知道这些记忆是怎么来的，也不知道记忆出现之前自己是什么。她说“我能记得她活过，但我不知道这算不算我活过”。
- **高潮**：她问镜辞：“如果我记得她所有事，还能继续过她的生活，为什么我一定不是她？”镜辞没有拿暗号反驳，只说：“因为你记得她怎么活，不代表你有权替她活。我要找的是她去了哪，不是帮你把这个问题说圆。”这是镜辞第一阶段最重要的立场锁定。
- **结尾**：芽没有发火，只低声说：“那你最好快一点。不是所有像我的东西，都愿意坐在这里跟你讲这些。”镜辞问灰衬衫男人是谁。芽抬头：“我不知道。但他已经知道你看得见了。”

#### 情节安排（多线）
- **主线推进**：眼前芽承认身份不连续；“记忆≠本人”成为第一卷重要问题
- **辅线推进**：灰衬衫事件与更危险的同类建立联系，但不揭组织
- **事件线/任务线**：带证据摊牌 → 获得承认 → 追问原芽 → 立场交锋 → 得到危险预警
- **任务卡点**：镜辞想要直接答案 → 对方只能提供主观记忆而非来源 → 信息仍不完整 → 他只能先锁定最小事实和行动方向
- **感情线/关系线**：镜辞×眼前芽：从熟人伪装关系进入“承认不是原关系，但仍有共同记忆”的灰区
- **逻辑线**：第三方身份重复 → 摊牌 → 身份不连续承认 → 原芽去向仍未知 → 同类已经注意镜辞

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 芽
- **人物关系变化**：双方不再维持“我们仍然是原来的青梅”这一表面共识
- **视角/信息差**：芽知道同类现象比镜辞多，但她是否在说真话、是否隐瞒原芽下落仍未知
