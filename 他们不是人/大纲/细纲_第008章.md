# 细纲 · 第8章 摊牌

## 第 8 章：摊牌
- **核心事件**：镜辞与芽正面摊牌——芽承认"她不是芽"，但她的反应出人意料（她不伤人，她"想成为芽"）
- **字数目标**：3000 字
- **阶段位置**：开篇期；第1阶段第8章；信任崩塌的"反转"（壳不是纯恶）
- **单元ID/位置**：1-1；第8拍·转折（摊牌·壳的动机浮现）
- **目标情绪**：紧张对峙 → 反转惊愕（她"想成为芽"）→ 认知动摇（壳也有"想要"？）；本章推进情绪引擎"释放节点"的前奏
- **主角目标/关键选择**：镜辞想逼出真相；关键选择=他选择"不逃不喊"，听她说完（第一次直面壳的"诉求"）
- **章节定位**：高压（摊牌对峙+世界观反转）
- **本章结构公式**：节点1（夜入芽家·对峙） + 节点2（镜辞直接质问"你是谁"） + 节点3（芽的承认·"我不是芽，但我想成为她"） + 节点4（她讲述"学习做芽"的过程·章尾钩子）
- **章首钩子**：延续钩子（全城多少壳+摊牌在即）
- **爽点**：识破爽点（镜辞逼出实锤）+ 反转爽点（壳的动机出人意料）；往下看的理由=壳为什么要成为芽
- **本章禁止提前释放**：壳的完整设定/壳巢/镜返代价/真正的芽在哪（悬置）
- **契约风险**：契约安全

#### 内容概括（五段式）
- 起因：镜辞夜入芽家。芽像是等他很久了，房间灯亮着，她坐在窗边："我知道你会来。"
- 发展：镜辞直接质问："你是谁？芽在哪儿？"芽没有否认，也没有害怕——她低下头："我不是芽。"镜辞的拳头攥紧，但她继续说："可我比任何人都想成为芽。"
- 转折：芽（或者说，披着芽的壳）开始讲述：她醒来时只有"芽的记忆"，像看了一部关于芽的电影。她学着芽说话、学芽先喝汤、学芽笑——"我每天都怕自己做得不够像，怕你发现。"她抬头看他："我没有伤害任何人。我只是……不想消失。"
- 高潮：镜辞站在原地，张了张嘴，什么都没说出来。他本来准备了一肚子的质问、愤怒、恐惧——但她说"我只是不想消失"时，他忽然想起自己：他修怀表，也是因为"不想让养母消失"。
- 结尾：她看着他："你可以报警，可以告诉别人，可以恨我。但能不能……别让我回到'什么都不是'的样子？"镜辞没有回答，转身走了。走出巷子，他掏出怀表，表盖内侧"镜辞"两个字反着光——他第一次不确定，自己"看见"的到底该是真相，还是该是"人"。（章尾钩子）

#### 情节安排（多线）
- **主线推进**：信任崩塌的"反转"——壳不是纯恶（"我只是不想消失"）+ 主角立场动摇
- **辅线推进**：真正的芽在哪（悬置——她没提，镜辞也没敢问）
- **事件线/任务线**：摊牌对峙（正面交锋）
- **任务卡点**：镜辞想逼出真相 → 卡在"她承认了但动机出人意料" → 卡出"壳也想被记住"（主题伏笔） → 删掉损失=主题不成立 → 收束动作=无法回答，转身离开
- **感情线/关系线**：镜辞×芽（壳）=从"仇恨"到"动摇"（他无法恨一个"想成为芽"的存在）
- **逻辑线**：摊牌（原因）→ 对峙（行动）→ 她承认+讲述动机（结果）→ "我该恨她吗？"（后果/新问题）

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 芽（壳·等她来）→ （对话对峙）→ 巷子·怀表（章尾）
- **人物关系变化**：镜辞×芽（壳）：本章后=从"确认她是敌人"到"无法定义她"（灰色地带）
- **视角/信息差**：读者与主角同信息量；"壳想成为人"首次浮现（主题的种子，第5-6卷白壳线呼应）
