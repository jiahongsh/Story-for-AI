# 细纲 · 第6章 芽的照顾

## 第 6 章：芽的照顾
- **核心事件**：芽不再装作没发现镜辞的测试。她开始更频繁地出现在钟表摊，用“照顾”贴近他的生活，同时反向记录他的去向和反应。镜辞意识到，自己已经不是单方面观察者。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；第6章；关系悬疑从验证期转入双向信息博弈
- **单元ID/位置**：1-1；第6拍·观察反转
- **目标情绪**：表面温暖 → 被照料的窒息 → 发现对方也在收集自己 → 正面对视
- **主角目标/关键选择**：镜辞想保持正常，让芽继续暴露行为；关键选择=接受她的照顾，但主动隐藏自己的调查记录和判断标准
- **章节定位**：关系高压章；不能再重复“她做错一个旧习惯”的旧模式
- **本章结构公式**：节点1（芽主动留下帮忙） + 节点2（照顾变成对镜辞行程的掌握） + 节点3（镜辞反向藏线索） + 节点4（两人谈“试探”） + 节点5（芽点破夜访）
- **章首钩子**：芽把止血贴放到柜台上，正好压住镜辞昨天写的那张维修单。她笑着说：“你手上的口子换过两次药了，昨晚十一点以后又出去过？”
- **本章即时兑现**：对方不再只是被测试的谜题，而成为会观察、会调整、会施压的主动角色
- **本章禁止提前释放**：壳的完整机制、芽的真正去向、裂缝、EX、白塔等名词
- **设定边界**：芽的照顾可以表现出记忆和学习能力，但不得写成“知道得越多=越像人”的结论
- **契约风险**：契约安全。悬疑从静态辨认升级为双方博弈

#### 内容概括（五段式）
- **起因**：芽带着药和午饭来钟表摊，说镜辞最近脸色难看，留下帮他整理货架。她照顾得很自然，却精准知道镜辞手上的划伤什么时候换过药、昨晚几点不在店里。
- **发展**：镜辞一边让她留下，一边把写有“先喝汤、缺口、新情境”的维修单悄悄压到抽屉最底层。他开始注意到另一件事：芽问的不是“你累不累”，而是“昨晚去哪了”“最近见过谁”“为什么总看别人脖子和耳后”。这些问题都披着关心的外衣。
- **转折**：芽收拾抽屉时差点碰到沈竹便签。镜辞第一次主动撒谎，说里面只是客户欠账单，并顺手把抽屉锁上。芽没有追问，只笑了一下：“你以前不会锁这个抽屉。”
- **高潮**：两人一起吃午饭。芽忽然问：“你最近是不是总在试我？”镜辞回：“职业病，东西坏没坏，总得多看两眼。”芽低头喝汤：“那如果不是东西呢？”两个人第一次不再装作只是在谈早餐和修表。
- **结尾**：芽临走前替他把门帘放下，像随口想起一样说：“对了，那天晚上你在我家楼下站了很久。下次想见我，直接敲门。”她没有回头。镜辞站在柜台后，直到门帘彻底不动，才把锁着的抽屉重新打开。

#### 情节安排（多线）
- **主线推进**：镜辞确认芽已经注意到自己的调查，单向观察正式结束
- **辅线推进**：沈竹便签被镜辞主动保护，体现他开始建立信息安全意识
- **事件线/任务线**：让芽留在店里观察她 → 发现她也在观察自己 → 隐藏记录 → 正面试探
- **任务卡点**：镜辞想装正常 → 芽掌握他的夜间行程 → 他被迫主动撒谎 → 芽点破夜访，证明对方比他预想更早发现监视
- **感情线/关系线**：熟人之间的关心仍然存在外形，却开始承担审讯和反侦察功能
- **逻辑线**：第5章芽意识到被测试 → 第6章反向收集镜辞信息 → 镜辞开始藏证据 → 双方进入信息博弈

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 芽 → 两三个修表顾客作为日常遮掩
- **人物关系变化**：镜辞×芽：从“我暗中怀疑你”变成“我们都知道彼此在隐藏东西”
- **视角/信息差**：读者知道镜辞藏了记录，不知道芽究竟看到了多少，也不知道她为什么没有直接阻止他

#### 结尾设定和钩子
- **结尾设定**：镜辞与芽已经进入双向观察。后续不能再靠重复生活习惯拖悬念，必须推进到身份对峙或第三方异常
- **章尾钩子**：芽既然早就知道镜辞在看，为什么一直允许他继续？
