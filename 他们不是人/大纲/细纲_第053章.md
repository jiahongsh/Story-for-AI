# 细纲 · 第53章 四栋楼

## 第 53 章：四栋楼
- **核心事件**：安平里同版本服务还运行在另外三处老旧小区。镜辞第一反应是逐个去现场，但猫眼指出：他前面已经证明“自己出现会改变现场”，而且四栋楼同时盯不现实。安平里物业经理在取得几位同行同意后，只把“上线前先留纸质台账、异常权限不要急着覆盖、住户争议先按实际居住者意愿暂停”的经验转给其他小区。四处按同一份最小检查表自行筛查，不传整楼隐私。当天夜里，永和里2号楼物业发现上游同步将在次日自动恢复一个已经注销七年的“直系哥哥”门禁权限，并在当事住户确认“不允许进入”后提前本地暂停、保留日志。镜辞没有到场，风险第一次在进入楼栋之前被挡住。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段3；第53章；调查方法开始分布化
- **单元ID/位置**：1-4；第13拍·不能所有地方都靠镜辞跑
- **目标情绪**：风险扩散 → 主角想全包 → 被现实能力边界卡住 → 方法拆分 → 异地小区主动发现问题 → 第一次无主角到场预防成功
- **主角目标/关键选择**：镜辞想确认另外三处是否安全；关键选择=放弃亲自跑遍所有点，允许别人只用自己能理解、能执行的规则先保护居民
- **章节定位**：方法扩散+小胜；第一次证明有效调查不必须围绕主角本人运转
- **本章结构公式**：节点1（三个新地址） + 节点2（镜辞准备逐个跑） + 节点3（猫眼指出现场会被他改变） + 节点4（安平里物业分享最小检查流程） + 节点5（永和里发现自动恢复权限） + 节点6（当事住户提前冻结）
- **章首钩子**：镜辞把三个地址抄下来，已经开始查公交路线。猫眼看了一眼：“你真准备一天跑三栋？” 镜辞说：“不去怎么看？” 猫眼回：“你去了，那里还会是你想看的样子吗？”
- **本章即时兑现**：第37章“镜辞出现会触发清理”和第50章“现实证据能让别人行动”合并成新的工作方式
- **本章禁止提前释放**：正式组织、剥壳人、白塔、同版本服务背后的真正控制者
- **能力边界**：其他人不能替镜辞看接缝，但完全可以处理权限、旧版本和当事人安全；镜辞不应成为所有问题的必要入口
- **契约风险**：契约安全。所谓“检查流程”不是新组织规章，只是几个物业之间基于真实事故分享的临时经验

#### 内容概括（五段式）
- **起因**：三个新地址摆在桌上：永和里2号楼、康宁巷9号楼、柳桥新村3栋。镜辞下意识开始规划路线，想先去离得最近的永和里。猫眼直接把他的地图按住，提醒他D4之后所有现场都会因他的出现产生变化，而且他已经连续多日跑现场，判断未必还稳定。
- **发展**：安平里物业经理比镜辞更实际。他不懂壳、接缝，也不需要懂。他只知道自己亲手改过的权限会被上游覆盖，于是联系另外三处同版本物业同行，分享三件事：上线前留一份旧纸质/旧系统状态；家庭关系争议不要销毁旧记录；住户明确拒绝某人进入时，先按现有安全规程临时停权限并留日志。
- **转折**：四栋楼各自只查自己的住户，不互传整套数据。永和里物业很快回电话：一户独居女性的“直系哥哥”门禁将在次日同步后恢复，但这个哥哥七年前因为家庭纠纷已经搬走、权限注销。物业联系住户本人，她明确表示近期没有邀请哥哥回来，也不同意恢复门禁。
- **高潮**：永和里没有等系统真的恢复后再出事故。物业在住户签字下预先设置本地暂停，并把旧注销记录、住户当前意愿和上游待同步字段分别保存。凌晨02:17，同步任务果然尝试恢复该权限；本地安全规则将它拦截并生成冲突日志。没有陌生人刷卡，没有楼道对峙，甚至没有镜辞到场。
- **结尾**：安平里经理把去除住户姓名的冲突日志截图发来。镜辞盯着“上游恢复失败 / 本地安全暂停保留”看了很久。过去一个月，他总觉得只有自己看见缝才能阻止事情发生。现在第一次，没人看见接缝，也有人把门守住了。

#### 情节安排（多线）
- **主线推进**：同版本服务确认扩散；调查/保护方法开始分散给普通现实角色
- **辅线推进**：镜辞“必须亲自扛所有问题”的倾向第一次被方法本身反驳
- **事件线/任务线**：三地址 → 想亲跑 → 经验转发 → 永和里筛出高风险权限 → 联系住户 → 02:17拦截
- **任务卡点**：地点太多、主角出现会改变现场 → 无法亲查 → 将可执行部分拆给物业 → 成功预防一个事件
- **感情线/关系线**：安平里物业经理从被动卷入者成长为能把失败经验交给同行的人，关系影响开始横向传播
- **逻辑线**：安平里事故 → 临时流程 → 其他小区上线前筛查 → 同样自动恢复模式出现 → 无镜辞参与也能先保护住户

#### 人物关系和出场顺序
- **出场顺序**：镜辞/猫眼 → 安平里物业经理 → 永和里物业（电话/消息）→ 当事住户（不直接暴露个人细节）
- **人物关系变化**：镜辞第一次主动让出“必须由我判断”的位置；普通人获得自己的行动空间
- **视角/信息差**：永和里只确认权限风险，不知道那个哥哥是否真的会来，也不知道背后是否超自然
