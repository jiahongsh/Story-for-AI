# 细纲 · 第14章 村里的三个版本

## 第 14 章：村里的三个版本
- **核心事件**：眼前存在抵达北河村后，严格按镜辞第12章设计的“先记录、后询问”方法调查。她发回三组现场材料：枯河和大树与记忆吻合；记忆里的裂石却早已被移走；一位老太太独立提到“以前有个年轻姑娘在树下坐过”，但对年份、发型和来向说法前后矛盾。村子证明那段记忆不是凭空捏造，却不能证明那个姑娘就是原芽，更不能证明原芽仍活着。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；第14章；村子线第一次现场验证
- **单元ID/位置**：1-2；第4拍·现场盲测
- **目标情绪**：等待消息 → 现场吻合带来期待 → 关键细节冲突 → 证人再添希望 → 主角主动压住结论
- **主角目标/关键选择**：镜辞想判断眼前存在的村子记忆有没有外部对应；关键选择=即使出现“年轻姑娘”证词，也只记作线索，不写“芽还活着”
- **章节定位**：调查推进+希望克制；一章必须同时给“支持”和“反证”，避免线索单向坐实
- **本章结构公式**：节点1（第一组现场照片） + 节点2（两处吻合一处不符） + 节点3（查村史确认裂石早已移动） + 节点4（老太太独立证词） + 节点5（镜辞要求保留原话与时间）
- **章首钩子**：上午九点十七分，镜辞收到三张没有任何说明的照片。第一张是干涸的河床，第二张是老槐树，第三张却只有一块新水泥地。眼前存在随后发来一句：“第三处不对。”
- **本章即时兑现**：第12章建立的验证方法真正产生结果；眼前存在不是去“寻找灵魂”，而是在测试自己的记忆来源
- **本章禁止提前释放**：原芽生死、存在实验、沈竹与村子的完整关系、壳来源
- **设定边界**：任何照片、老人证词或旧习惯都只能构成信息/记忆痕迹，不能单独证明存在连续性
- **契约风险**：契约安全。给希望但同时给反证，不用一条巧合证据强行续命角色

#### 内容概括（五段式）
- **起因**：眼前存在按约定先发照片，不附解释。枯河、大树与她在钟表行描述的一致；记忆中树根旁应该有一块斜裂的大石，现场却只有新铺的水泥。
- **发展**：她去村委公开栏和老住户处查，不问“这里以前是不是有块裂石”，只问旧河道什么时候整修。记录显示六年前清淤时那块大石被吊走，说明她脑中的场景至少对应过村子的旧状态，但那段记忆究竟属于谁仍不知道。
- **转折**：她在树旁休息时，一位老太太主动问她是不是来找“以前那个姑娘”的。眼前存在没有说自己像谁，只打开录音，让老人自己讲。老太太说那姑娘曾在树下坐一下午，有时说是三四年前，有时又说“那会儿老桥还没拆”；发型一会儿说短，一会儿又说扎着辫子。
- **高潮**：眼前存在把录音原文件发给镜辞，没有写“她来过”。镜辞逐句记下：地点证词可用；人物身份不确定；时间互相冲突；“姑娘”可能是原芽，也可能是别的人，甚至可能是另一名使用相似身份的存在。他第一次主动把希望写在结论之外。
- **结尾**：眼前存在发来最后一条消息：“我本来想听她说‘那就是你’。现在反而更不知道我记得的是谁了。”镜辞回复：“不知道就先写不知道。”几分钟后，她发来一张树根近照：泥里露出半截生锈的小铜牌，上面只有两个已经磨花的数字——`17`。

#### 情节安排（多线）
- **主线推进**：村子记忆获得外部对应，但身份与时间继续悬置
- **辅线推进**：眼前存在开始主动遵守证据边界，而不是只追求“证明我是芽”
- **事件线/任务线**：现场拍摄 → 查旧改造记录 → 获得证人原话 → 记录矛盾 → 新物证17出现
- **任务卡点**：想确认记忆来源 → 场景吻合 → 时间和人物证词冲突 → 只能得到“记忆有现实来源”而非“原芽身份答案”
- **感情线/关系线**：镜辞与眼前存在的合作开始建立在共同调查规则上，而不是旧青梅关系上
- **逻辑线**：村子记忆 → 现场核验 → 旧状态被证实 → 人物身份仍不确定 → 17号铜牌成为下一条可查物证

#### 人物关系和出场顺序
- **出场顺序**：镜辞（远程）→ 眼前存在（照片/消息）→ 村中老太太（录音）
- **人物关系变化**：眼前存在第一次主动把“我想相信的答案”与“实际拿到的证据”分开
- **视角/信息差**：老太太可能记错；眼前存在也可能被自身记忆引导；只有多源交叉后才能继续推进
