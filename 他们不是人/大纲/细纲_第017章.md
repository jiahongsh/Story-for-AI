# 细纲 · 第17章 猫眼

## 第 17 章：猫眼
- **核心事件**：镜辞回城后追查17号测点旧设备来源，公开档案却在关键年份突然断掉。他通过旧仪器零件商找到地下信息经纪人猫眼。猫眼不提供“真相”，只卖给他两套互相矛盾、但都能追到来源的旧档案，并指出沈竹失踪前曾购买过同一批北河撤点资料。镜辞第一次接触“来源链”概念。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第17章；地下信息线启动
- **单元ID/位置**：1-2；第7拍·来源链
- **目标情绪**：查档碰壁 → 找到特殊渠道 → 交易博弈 → 得到矛盾版本 → 发现沈竹曾追同一条线
- **主角目标/关键选择**：镜辞想知道谁安装17号设备；关键选择=接受“买来的不是答案，而是资料从哪来的”这种交易方式
- **章节定位**：信息推进章；猫眼首次出场必须建立专业性和边界，禁止变成作者答案卡
- **本章结构公式**：节点1（公开档案断档） + 节点2（零件商引荐） + 节点3（猫眼核验镜辞手里资料） + 节点4（交易条件） + 节点5（两套矛盾撤点记录） + 节点6（沈竹旧购买记录）
- **章首钩子**：镜辞查到17号测点所属的旧设备型号，却发现市档案馆线上目录里，北河旧河道那一年的整册设备维护记录刚好缺页。
- **本章即时兑现**：第11章“保留不同版本”的方法得到专业升级；猫眼提供的是版本变化和来源层级
- **本章禁止提前释放**：百川堂正式组织名、白塔、壳巢、17号测点真正超自然用途、沈竹最终去向
- **契约风险**：契约安全。猫眼不夺走主角调查结算权

#### 内容概括（五段式）
- **起因**：镜辞根据北河现场设备孔距和残存支架，查到二十多年前一款水文补测设备。公开目录能查到采购，却查不到北河17号撤点原因，关键年度的维护册在数字目录里显示“未扫描”。
- **发展**：他拿着支架照片去问旧仪器零件商。老板不认识设备来历，只给他一个旧城地址，说那里有人专门收“已经没有人想认的旧资料”。镜辞按地址找到猫眼。猫眼是女人，帽檐压得低，第一件事不是问他想知道什么，而是问照片什么时候拍、原文件还在不在、有没有经过聊天软件压缩。
- **转折**：猫眼给出交易条件：800元人民币，加一份17号现场照片的原始文件副本，并允许她留下匿名交易凭证。她提供两套资料。官方数字版写“17号测点因设备故障撤销”；一份来自当年承包商的纸质复印件却写“连续同步异常，建议封存，不再更换设备”。
- **高潮**：镜辞问哪份是真的。猫眼说：“我只能告诉你哪份先出现。”她展示版本时间：承包商纸件早于官方数字录入；官方版本是在多年后统一补录。随后她翻出一条旧交易索引：沈竹失踪前几个月，曾通过同一条来源购买“北河17号撤点原始记录”和“旧河道异常设备清单”。
- **结尾**：镜辞追问沈竹买完后去了哪里。猫眼合上索引：“这条线我没有可靠来源。没有就说没有。”她把两份资料推回来，“你真正该查的不是哪份写得更像真话。是为什么后来只剩下一份。”

#### 情节安排（多线）
- **主线推进**：17号测点由现场物证进入档案版本冲突；沈竹与该调查线建立独立记录联系
- **辅线推进**：猫眼建立来源链专业与交易边界
- **事件线/任务线**：查型号 → 公开档案缺口 → 找特殊渠道 → 交易 → 比较版本 → 沈竹交易索引
- **任务卡点**：镜辞想买“答案” → 猫眼只卖来源链 → 两套资料互相冲突 → 主角获得新的调查问题而非现成结论
- **感情线/关系线**：镜辞×猫眼建立互不信任但可复核的交易关系
- **逻辑线**：17号现场 → 设备型号 → 撤点记录冲突 → 版本晚期被统一 → 沈竹曾追查同一冲突

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 旧仪器零件商 → 猫眼
- **人物关系变化**：镜辞第一次接触一个明确把“来源可靠性”高于“故事好不好听”的情报者
- **视角/信息差**：猫眼知道更多渠道，但她也不知道17号真正发生过什么
