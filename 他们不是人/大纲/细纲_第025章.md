# 细纲 · 第25章 她说

## 第 25 章：她说
- **核心事件**：一名陌生女人主动来到钟表行，准确说出沈竹曾频繁去“东里巷一家修表铺”，并声称自己“只是替人带句话”。镜辞被动看见她耳后存在接缝，但没有因此相信或否定她提供的信息。他用非引导式追问逼她给出可核细节，随后在沈竹旧物中找到三张独立存在的旧零件收据，地址正是东里巷。线索是真的，送线索的人为什么要把他往那里引仍未知。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第25章；单元1-2收束并进入1-3
- **单元ID/位置**：1-2→1-3；第15拍·真线索与坏动机可以同时存在
- **目标情绪**：陌生访客上门 → 她知道沈竹 → 主角不接受现成答案 → 独立旧票据证实部分内容 → 明知可能是饵仍决定查
- **主角目标/关键选择**：镜辞想查信息泄露源和沈竹下一处活动点；关键选择=把“提供者是否可信”与“信息是否可验证”拆开处理
- **章节定位**：高压信息博弈章；第25章情绪锚点来自主角明知被引导仍保留主动权
- **本章结构公式**：节点1（陌生女人主动上门） + 节点2（被动接缝信号） + 节点3（沈竹/东里巷线索） + 节点4（镜辞追问来源） + 节点5（旧收据独立互证） + 节点6（决定把东里巷当“可疑真线索”调查）
- **章首钩子**：女人进门后没拿任何东西出来，只说：“你查17号、03点，还去了一趟南岸。再往下查，你会去东里巷。”镜辞抬眼时，看见她耳后有一道极细的接缝。
- **本章即时兑现**：镜返第一式继续只提供“身份错位信号”；真正的信息判断来自来源和独立证据
- **本章禁止提前释放**：镜返第二式、壳等级数据、壳巢、女人所属势力、东里巷内部真相
- **能力边界**：镜辞不能主动照她、读取记忆、读取等级或因为看见接缝直接知道她在撒谎
- **代价边界**：本章不存在“使用镜返后市场老人开始忘记镜辞”的随机代价
- **契约风险**：契约安全。危险人物可以说真话，主角必须判断为什么这句真话被送到自己面前

#### 内容概括（五段式）
- **起因**：陌生女人在午后客少时进入钟表行。她没有修表需求，开口便点出北河17、临江03和南岸旧堤。镜辞被动看见她耳后接缝，却继续像面对普通客人一样问：“你想修什么？”
- **发展**：女人说沈竹失踪前一个多月常去东里巷一家老修表铺，那地方现在仍开着。她不肯说明消息来自谁，只说“有人觉得你该去那里”。镜辞没有问“那家店是不是壳巢”，而是要求地址、店名、沈竹去过的大致日期和她凭什么知道。
- **转折**：女人只能给出地址和一个旧店名，对日期说得很模糊。镜辞指出：“你知道我最近去哪，却说不清三年前的来源。说明这句话未必是你查出来的。”女人笑了：“可地址是真的。你敢不敢去，是你的事。”说完离开。
- **高潮**：镜辞没有跟踪她，先回头查沈竹旧物。他按东里巷地址重翻过去从未重视的零件票据，找到三张不同月份的现金收据，店名与女人所说一致；其中一张背面还有沈竹记的机芯型号，与第18章多点测时记录使用的旧表型号相同。东里巷确实与沈竹调查有关。
- **结尾**：镜辞在异常记录表里没有写“女人说真话”，而写：`信息：部分独立证实；来源：未知；提供动机：高风险。` 他把东里巷标成下一站，又在旁边加一句：`先假设这是饵。`

#### 情节安排（多线）
- **主线推进**：东里巷线启动；敌对/未知势力开始主动投放信息
- **辅线推进**：主角学会“坏来源也可能携带真信息”
- **事件线/任务线**：陌生人上门 → 接缝信号 → 给线索 → 追来源失败 → 旧票据互证 → 风险标记后行动
- **任务卡点**：镜辞不能相信信使 → 也不能因为信使异常就丢掉可能有价值的线索 → 独立旧票据解决“信息能否用”，但不解决“为什么有人要他去”
- **感情线/关系线**：镜辞与沈竹继续通过普通生活账单和工作记录建立真实连接，而不是通过超自然回放
- **逻辑线**：第24章有人掌握他的调查关键词 → 第25章有人主动给下一处真线索 → 说明对方可能在引导他的路线

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 陌生女人 → 守钟人短暂收尾
- **人物关系变化**：镜辞第一次正面处理一个“可能敌对、但给出真信息”的身份异常者
- **视角/信息差**：女人知道镜辞行程，但她自己可能也只是传递信息的一层
