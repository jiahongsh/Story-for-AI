# 细纲 · 第001章《她把缺口转向我》（主笔重写版）

- **核心目标**：立住修表匠镜辞与青梅「芽」七年相依为命的市井烟火气，随即通过两个极小日常习惯的错位撕开裂缝，并在章尾用「寸镜反光里的拧头接缝 + 停死七年的怀表跳格」直接引爆超自然恐怖。
- **出场人物**：镜辞、芽（当前存在）、老陈（隔壁五金摊）、赵奶奶（卖菜摊主）。
- **关键情节点**：
  1. 芽清晨踹门送早饭，压住米粒螺丝盒拌嘴，隔壁老陈扯嗓子拆台，展现旧货市场熟人生态。
  2. 芽一眼认出 0.8 与 1.0 零件格，点出工作台最里侧沈竹失踪七年留下的银灰旧怀表（十一天极限，昨晚彻底停死在十一与十二之间，表盘内圈刻着十道细痕）。
  3. 饭桌上的两处致命违和：从小胃寒必先喝两口热汤的芽，今天先咬了油条；原本每次都会顺手把破碗豁口转向墙面（「你手比我值钱」）的她，把崩边的豁口直直对准了镜辞修表的左手。
  4. 芽离店挤入早市人群后，镜辞戴上单眼寸镜低头擦拭柜台玻璃，却在寸镜斜角反光里瞥见：本该离开的芽折返站在门外死角阴影里，双手扶住自己脑袋往左硬拧了半寸，耳根后露出一道惨白无血的细缝，随即严丝合缝贴回。
  5. 屋里死寂，工作台最里头停死未上弦的旧怀表自己「咔哒」跳了一格，指针压在十二正上方。
