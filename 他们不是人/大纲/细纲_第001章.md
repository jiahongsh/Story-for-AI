# 细纲 · 第1章 钟表行的客人

## 第 1 章：钟表行的客人
- **核心事件**：21岁的镜辞在旧货市场钟表摊接待青梅芽。芽仍记得两人的过去，却丢了一个几乎不可能丢的关系习惯，镜辞第一次明确意识到“她哪里不对”。
- **字数目标**：3000 字
- **阶段位置**：第一卷开篇；阶段1“日常里的第一个错位”；建立主角、旧市场生活与核心恐怖卖点
- **单元ID/位置**：1-1；第1拍·异常进入日常
- **目标情绪**：熟悉 → 一瞬违和 → 强行解释 → 再次违和
- **主角目标/关键选择**：镜辞想把今天的维修单做完、维持正常生活；关键选择=发现芽的异常后不立刻质问，而是先记住细节并观察第二次
- **章节定位**：开篇高信息章；必须在前500字让“熟人不对劲”的卖点可见
- **本章结构公式**：节点1（芽带早餐进店，异常先发生） + 节点2（修表日常与镜辞观察力随行动建立） + 节点3（沈竹怀表进入） + 节点4（第二个关系习惯错位） + 节点5（镜辞决定验证）
- **章首钩子**：芽把早餐放到维修台旁，像过去无数次那样招呼镜辞趁热吃，却先拿起豆浆，没有先碰那碗汤。镜辞的手停在镊子上，因为她从十三岁起就没有改过这个顺序。
- **本章即时兑现**：镜辞不是“莫名觉得不对”，而是能指出具体、可复核的行为差异；读者第一章就获得一次观察型小爽点
- **本章禁止提前释放**：壳、镜返、等级、裂缝、存在力等名词；芽被替换的结论；沈竹失踪真相
- **设定边界**：镜辞当前约21岁；临江七中只可通过少年回忆出现；本章不出现任何数值读取或超自然解释
- **契约风险**：契约安全。核心卖点仍归镜辞的观察与选择，不由神秘组织替他解释

#### 内容概括（五段式）
- **起因**：早市刚散，芽拎着两份早餐进钟表摊。镜辞正在给客人的机械表换游丝。她随手把他的那份推到老位置，却先喝了豆浆，没有像过去那样“先喝汤”。这一处异常发生在最普通的动作里，开篇立刻见钩。
- **发展**：镜辞没问。他继续修表，通过换游丝、听摆频、辨认客人腕表上的旧磕痕，建立“维修者+观察者”人设。芽能自然接上他们少年时的旧话题，也记得镜辞不吃香菜、记得钟表摊几点关门，看起来没有任何问题。
- **转折**：镜辞从抽屉里取出沈竹失踪前留下的旧怀表。表盖内刻着“镜辞”，机械结构没有明显损坏，却总在修好后重新停摆。芽看了一眼，准确记得他这些年一直在修它。信息都对，这反而使刚才那一点错位更刺眼。
- **高潮**：吃到一半，芽把一只碗推回镜辞面前，缺口正朝着他。镜辞记得自己十四岁时被这种缺口划破过嘴，从那以后芽每次坐在对面，都会下意识把缺口转向自己那边。这个动作从没人约定过，也没人专门提起过。
- **结尾**：芽笑着问他怎么不吃。镜辞也笑，说“烫”。他没有纠正碗的位置，只把这件事记了下来。芽走后，他在维修单背面写了两个词：**先喝汤、缺口朝外。**然后把纸压进抽屉。第一次，他准备像检查一块走时异常的表一样，检查一个自己认识了很多年的人。

#### 情节安排（多线）
- **主线推进**：首章即抛出“最熟悉的人可能不再是原来的人”的核心恐怖，不等到章尾才出现异常
- **辅线推进**：沈竹失踪+旧怀表，只露私人线索，不解释怀表机制
- **事件线/任务线**：修表工作中穿插芽带来的早餐；镜辞从被动察觉转为主动记录
- **任务卡点**：镜辞想把异常归因于“人会变” → 第二个无意识关系习惯也错位 → 普通解释开始不够用 → 他决定验证
- **感情线/关系线**：镜辞×芽仍保持熟稔，恐怖来自“表面关系没有破裂，内部熟悉感先裂了一条缝”
- **逻辑线**：习惯错位 → 自我解释 → 更多正常信息抵消怀疑 → 第二处关系动作错位 → 主角建立验证目标

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 芽 → 修表客人一笔 → 沈竹通过怀表被提及
- **人物关系变化**：镜辞×芽：从默认信任变为“暂不声张的观察状态”
- **视角/信息差**：读者与镜辞同信息量。读者只知道芽有两处反常，不知道原因

#### 情节细化
- 点1：**前300字直接出异常**。芽进店、早餐落桌、先拿豆浆。镜辞的镊子停半秒，没有旁白解释世界观【钩子·密250】
- 点2：镜辞继续修机械表。通过听声音判断摆轮偏差、看表带磨损推断客人惯用手，建立职业能力与观察习惯【人物/爽点·密350】
- 点3：芽与他闲聊近况，准确接住少年往事与生活信息，让“她明明都记得”成立【关系·密300】
- 点4：沈竹旧怀表登场。明确是“失踪前留下”，镜辞已修过很多次；不赋予超自然结论【伏笔·密300】
- 点5：镜辞短暂说服自己：人长大后改掉早餐顺序太正常，没必要把青梅当故障件【缓冲·疏150】
- 点6：第二处错位发生。芽把缺口碗沿朝向镜辞，没有过去那个几乎无意识的保护动作【悬念·密400】
- 点7：镜辞不拆穿，只用一句“烫”掩过去。体现他不是冲动型主角【人物·密250】
- 点8：芽提到下周可能去外地看亲戚，为镜辞留下有限验证窗口【推进·密200】
- 点9：芽离开后，镜辞检查碗沿，确认缺口确实在那里，不是自己看错【小兑现·密200】
- 点10：他在维修单背面写下“先喝汤、缺口朝外”，将怀疑变成主动任务【决定·密250】
- 点11：章尾压一句动作：镜辞把纸塞进怀表下面，抽屉合上时，怀表本该停死的秒针跳了一格。他抬头再看，秒针没有继续走。只记下，不解释【钩子·密300】
- `预算合计：3150字（目标3000，范围3000-3300）`

#### 结尾设定和钩子
- **结尾设定**：主角已经从“感觉不对”进入“准备验证”的行动状态；怀表只出现一次不稳定走时异常，不得写成识壳雷达
- **章尾钩子**：双钩子：镜辞要验证芽；停死多年的怀表在芽离开后跳了一格。下一章优先兑现前者，后者只挂起
