# 细纲 · 第1章 钟表行的客人

## 第 1 章：钟表行的客人
- **核心事件**：钟表摊主镜辞的日常——修表、观察细节、被一位"奇怪客人"（芽）的细微违和吸引
- **字数目标**：3000 字
- **阶段位置**：开篇期；第1阶段第1章；建立人设基点+日常恐怖基调
- **单元ID/位置**：1-1；第1拍·建立期待（日常）
- **目标情绪**：日常安心 → 细微不安（"哪里不对"但说不清）；本章推进情绪引擎的"悬念供给"环
- **主角目标/关键选择**：镜辞想修好一只停摆的旧怀表（养母遗物）；关键选择=他习惯性观察每一位客人（人设锚点）
- **章节定位**：低压生活（日常建立，但暗藏违和钩子）
- **本章结构公式**：节点1（钟表行日常+镜辞人设） + 节点2（怀表遗物·"镜辞"刻字） + 节点3（芽来取表·细微违和） + 节点4（违和定格·章尾钩子）
- **章首钩子**：氛围钩子（潮湿的午后，旧货市场的钟表行，滴答声）— 日常中透出"这里不普通"
- **爽点**：无显性爽点（低压章），功能=立人设+立日常恐怖基调；给读者往下看的理由=芽的违和悬念
- **本章禁止提前释放**：芽是壳的事实（本章只给违和，不给真相）/镜返/养母失踪
- **数值呈现（铁律）**：本章**不出现任何数值读取**（镜辞读到 Lv 数据是第3章镜返觉醒后的事）——第1章只有"哪里不对"的直觉，读者与主角同信息量，保持惊悚悬念（见 `设定/世界观/力量体系.md` 第九节叙事揭示路径：第1卷读者只以为"主角眼睛特殊"）
- **契约风险**：契约安全（开篇承诺日常恐怖+观察者主角，正常兑现）

#### 内容概括（五段式）
- 起因：镜辞在旧货市场的钟表行修表，生意冷清，他习惯性观察每个路人（人设：强迫症式观察细节）。
- 发展：他取出养母留下的旧怀表——停摆多年，表盖内侧刻着"镜辞"二字。他想修好它，却总修不好（象征：有些东西修不好）。
- 转折：青梅芽来取修好的手表。她一切正常——但镜辞注意到一个违和：她吃随身带的豆浆时，没像往常那样"先喝一口汤"。
- 高潮：他盯着她看，想开口问，又咽回去。两人照常聊天，芽笑着告别。
- 结尾：镜辞低头修表，指针滴答——他忽然想不起，芽是从什么时候开始，喝豆浆不先喝汤了。（章尾钩子：细微违和定格）

#### 情节安排（多线）
- **主线推进**：建立主角+日常恐怖基调（"身边人可能变了"的种子）
- **辅线推进**：怀表遗物（养母失踪的引子）
- **事件线/任务线**：修表（日常）+ 观察芽的违和（悬念）
- **任务卡点**：镜辞想修好怀表 → 卡在"修好它=放下养母"的心理门槛 → 卡出他对"过去"的执念 → 删掉损失=失去人设锚点 → 收束动作=放下怀表去招呼客人
- **感情线/关系线**：镜辞×芽=青梅日常（温馨底色），本章埋下"可能变了"的裂缝
- **逻辑线**：怀表停摆（原因）→ 镜辞想修好（行动）→ 修不好+芽的违和（结果）→ 他开始怀疑"是不是有什么变了"（后果/新问题）

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 旧货市场路人（群像一笔）→ 芽 → （守钟人远处身影一笔）
- **人物关系变化**：镜辞×芽：本章前=无话不谈的青梅 → 本章后=镜辞心中多了一道"裂缝"
- **视角/信息差**：读者知道芽"哪里不对"吗？——只通过镜辞的观察，读者也只感到"违和"（与主角同信息量，制造恐怖）
