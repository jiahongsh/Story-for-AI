# 细纲 · 第28章 有人回来

## 第 28 章：有人回来
- **核心事件**：根据第27章“两周前仍有人代收”的记录，镜辞选择在公开位置观察顺记，而不是夜闯。第二天下午，第25章送来东里巷线索的陌生女人果然用钥匙进入顺记，并签收一只新的计时设备包裹。她在店内停留四十多分钟后离开。镜辞确认：把自己引到东里巷的人，同时也是这家“停业修表铺”的当前使用者之一。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第28章；东里巷当前线从传闻进入人物行动
- **单元ID/位置**：1-3；第3拍·当前使用者现身
- **目标情绪**：耐心观察 → 熟悉身影出现 → 快递交接 → 她与顺记直接连接 → 镜辞意识到自己被主动引导
- **主角目标/关键选择**：镜辞想确认谁在使用顺记；关键选择=即使看到第25章女人，也不冲上去摊牌，先记录她进入、取件和离开的完整行为链
- **章节定位**：监视与反监视章；紧张来自双方都知道对方可能在看
- **本章结构公式**：节点1（公开位置观察） + 节点2（女人出现） + 节点3（钥匙开门） + 节点4（签收计时设备包裹） + 节点5（店内用电上升） + 节点6（女人离开前反看镜辞方向）
- **章首钩子**：下午三点十二分，顺记那把“生锈三年”的锁被人一次拧开。拿钥匙的人，正是三天前来钟表行告诉镜辞东里巷地址的女人。
- **本章即时兑现**：第25章“真线索可能是操纵”获得现实证据
- **本章禁止提前释放**：女人身份、顺记后台组织、老郑当前状态、包裹具体用途
- **能力边界**：镜辞被动看见女人接缝，但无法因此知道她的组织、动机或记忆
- **契约风险**：契约安全。主角没有为了爽点把调查变成尾随打斗

#### 内容概括（五段式）
- **起因**：镜辞根据最近代收时间，选了巷口一家能看见顺记门口的面馆，正常点餐、换位，不把自己藏成蹩脚侦探。等到第三个小时，第25章女人出现。
- **发展**：她没有试锁，也没有敲门，直接拿钥匙进去。十几分钟后快递员到场，电话打给她；她出来签收一个长方形硬纸箱，面单品名只写“计时设备配件”。镜辞记下快递公司、时间和箱体尺寸，不冒险偷拍个人隐私信息。
- **转折**：女人进去后，顺记旁边电表的瞬时读数明显上升；四十多分钟后恢复低值。她离开时没有带那个箱子，说明店内确实存在近期工作，而不是单纯回来拿旧物。
- **高潮**：女人走到巷口时忽然停了一秒，朝镜辞所在面馆方向看了一眼。她没有走过来，也没有做威胁动作，只继续离开。镜辞无法确认她是否真正看见自己，但也无法再把“我在观察她”当成单向关系。
- **结尾**：镜辞没有跟踪女人，转而去查顺记产权和租赁状态。他发现店铺登记仍在一个老房东名下，没有有效公开租约。要知道里面现在是什么，最安全的方法不是撬门，是找产权人。

#### 情节安排（多线）
- **主线推进**：当前使用者与第25章信使合一；顺记仍在运行
- **辅线推进**：现实包裹再次把顺记与计时设备连接
- **事件线/任务线**：观察 → 女人开门 → 收包裹 → 用电变化 → 产权查询
- **任务卡点**：确认当前使用者后很想直接跟 → 跟踪会进入对方预设场景 → 主角改查房屋产权，保持控制权
- **感情线/关系线**：镜辞与陌生女人形成“彼此可能都知道对方在看”的紧张关系
- **逻辑线**：近期代收 → 当前开门者 → 计时设备包裹 → 店内工作 → 产权成为合法入口

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 陌生女人 → 快递员一笔
- **人物关系变化**：女人从“提供线索者”升级为顺记当前网络参与者
- **视角/信息差**：她是否故意让镜辞看到自己仍未知
