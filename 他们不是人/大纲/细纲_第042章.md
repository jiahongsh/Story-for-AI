# 细纲 · 第42章 她不是女儿

## 第 42 章：她不是女儿
- **核心事件**：安平里核验次日，物业居民群和楼内服务端同步更新家庭关系。302室被显示为“许德昌：户主；许棠：长期访客/非直系亲属”。镜辞按照第41章留下的基线分别询问三名昨天的独立证人。没人忘记许棠买药、陪床、在这里长大，但其中两个人开始用“亲戚”“照顾老许的姑娘”重新解释这些旧事，只因为系统告诉他们“不是女儿”。第三个人仍坚持“手续归手续，她就是老许闺女”。章尾，许德昌在楼道听见邻居说“原来不是亲闺女”，第一次当面发火。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第42章；安平里关系单元加压
- **单元ID/位置**：1-4；第2拍·标签开始反向解释记忆
- **目标情绪**：系统更新的平常 → 同样记忆得到不同解释 → 镜辞发现“没人真正忘事” → 老人发火 → 关系冲突外化
- **主角目标/关键选择**：镜辞想确认安平里是否已经发生“记忆改写”；关键选择=不用“你还记不记得她是女儿”这种诱导问题，而是先问具体旧事，再问关系称呼
- **章节定位**：调查+社会关系恐怖；区分事实记忆变化与关系解释变化
- **本章结构公式**：节点1（居民端关系同步） + 节点2（镜辞复访三名基线证人） + 节点3（具体旧事都记得） + 节点4（称呼开始分叉） + 节点5（许德昌听见“不是亲闺女”） + 节点6（当面冲突）
- **章首钩子**：昨天还在说“老许家闺女”的305大姐，今天刷着居民群里的新名单，随口改了一句：“原来不是女儿，是照顾他的亲戚啊。”
- **本章即时兑现**：系统分类开始改变社会语言，但尚未证明超自然记忆同步
- **本章禁止提前释放**：群体记忆同步、关系归并、安平里实验目的、任何“系统一改大家就被洗脑”的结论
- **能力边界**：镜辞在三名邻居身上都看不到明显接缝；这不等于他们绝对正常，只说明不能把称呼变化直接归因于壳替换
- **契约风险**：契约安全。先让现实社会的从众/权威效应成立，后续若出现超自然变化才有对照

#### 内容概括（五段式）
- **起因**：物业把核验后的住户信息推送到楼内服务端和居民群，内容没有公开完整证件，只显示户主、常住成员、访客权限等标签。302室一栏里，许棠不再出现在“家庭成员”，而被归到“长期访客”。
- **发展**：镜辞按第41章的三名证人逐一复访。他先问事实，不提系统。小卖部老板还记得许棠每周给老许买降压药；305大姐还记得去年冬天许德昌住院，许棠连续陪了十几天；收废品老人也记得她小时候在楼道写作业。事实没有消失。
- **转折**：再问“她跟老许什么关系”时，答案开始分叉。小卖部老板说“好像是亲戚家的孩子”；305大姐刚看过群通知，说“反正不是亲闺女，应该算照顾他的”；收废品老人却皱眉：“什么亲不亲的，她从小喊爸，我就认这个。”同一批记忆没有变，关系解释却被一张新表重新排序。
- **高潮**：傍晚许棠帮许德昌拎菜上楼，恰好听见两个邻居议论“原来不是亲闺女，难怪户口不一起”。许德昌停下，第一次在楼道里发脾气：“她八岁发烧我抱去医院，她二十岁我给她攒学费，她给我端了十几年药。系统改两个字，你们就替我算她是谁？”
- **结尾**：楼道安静下来。许棠把老人往家里拉，没有解释自己到底算女儿、侄女还是其他。镜辞记下的不是那句吵架，而是三名证人的变化：`事实记忆基本没变；称呼和解释开始向系统标签靠拢。` 这比单纯“忘了”更难处理。

#### 情节安排（多线）
- **主线推进**：安平里系统标签开始反向塑造居民的关系解释
- **辅线推进**：建立“记忆内容”和“关系意义”可以分开变化的早期案例
- **事件线/任务线**：系统同步 → 三人复访 → 事实稳定 → 称呼分叉 → 楼道冲突
- **任务卡点**：镜辞原本想验证记忆是否被改 → 事实层没有明显变化 → 发现更细的“解释权”变化
- **感情线/关系线**：许德昌第一次公开捍卫许棠的关系位置；许棠则没有要求别人给她法律称号
- **逻辑线**：昨天的共同生活证词 → 今日系统标签 → 旧事实保留 → 新标签重新解释旧事实

#### 人物关系和出场顺序
- **出场顺序**：物业群消息 → 小卖部老板 → 305大姐 → 收废品老人 → 许德昌/许棠
- **人物关系变化**：楼内居民对许棠的社会称呼开始分化；许德昌与邻里第一次因“谁有资格定义关系”发生冲突
- **视角/信息差**：读者与镜辞都知道称呼变化，但不知道这是纯社会从众还是后续异常流程的第一步
