# 第二卷《死人续档》 卷纲

## 核心信息

- 章节范围：第31-80章
- 字数目标：15万字
- 本卷定位：发展

## 这卷读者等着看什么

- 读者期待：第一卷末镜辞怀表跌至第1格、全城熟人与官方档案彻底将他遗忘，读者正揪心于「只剩1格还怎么开大招战斗」，同时期待看他如何拿着从黑令统领程晦身上夺来的「城南医院·殡仪续档总库」黑令，以查无此人的幽灵修表匠身份杀入城南，揭开死人续档产业链并实现战力与金手指的双重破局。
- 这卷主打哪条线：战力与金手指破局线（激活怀表第二重「银钢蓄能盘·拆核上弦 + 百表拓印诡械改造成长」，镇钟九响由绷弦满劲晋升第三响「走汞境」至走汞圆满，彻底解决不敢拧表的续航与单一打法痛点）。
- 本卷顺带的收获：撕开白塔「丑时司」与城南第四医院勾结的死人续档黑产；结识初萌赋械系「止缝刃」时痕的地下停尸房缝尸黑医苏晚并收入东巷班底；以「百表拓印」首试机芯魔改并在第 47 章初探地下「黑表鬼市」补弹；为芽换装高品死锁缓冲箍（引出原芽桥洞最后三秒残音 F036）、为姜霁改装银弹膛线并在第 60 章翻出老赵旧档背后「申时司」密印；夺回「参号母钟副发条盒」。
- 这卷揭开或用上的：揭开怀表底盖内侧「第二重·银钢蓄能盘（拆核上弦与百表拓印）」的真正用法；揭开临江「每月廿七 02:17 停电六十秒 / 机械表每日慢 1 秒」的十二整点总倒计时第一道异象（F033）；长线棋手级大反派**温砚（申时掌司）**第 46 章单独以儒雅表客身份登门东巷喝茶修表（F034）；白塔内部洁癖派与黑手套派裂痕初现。
- 这卷先不能揭开、不能用上的：第一重表盘仅剩的第1格底命绝不可动用归零（留待第12卷）；沈竹壳盖下半句「零号表芯不在壳里，在……」的终极坐标不可提前揭晓；白塔至高掌权者左衡真名与本尊不可提前下场；三座母钟合一的神迹不可提前动用。
- 这卷可以新加的：城南第四医院地下停尸回廊的封闭断代地形；白塔「丑时司」掌管尸档调包与活死人续期的牌令职级规矩；「换骨」派大裁缝以死人骨殖拼装走汞、鸣钟战体壳的邪道手段；普通人在绝境抗拒抹除时凝出的「时痕」落痕微兆；地下黑市用高品机芯结算的硬通货规矩。
- 有没有硬伤：没问题

## 全卷规矩

1. 怀表第一重表盘指针死死停在第1格，本卷任何战斗严禁扣减这最后1格底命；所有「卡齿（停摆两秒）」「倍速走针」与卷末「逆摆雏形（触碰器物机括强退三秒）」的消耗，全部来自第35章激活的第二重表盘「血契蓄能弦」（拆解走汞裁缝、银边巡官及以上强敌机芯充能，每拆一核充1至3格并在左腕心脉沉淀一道暗银「拆核走时痕」，本卷上限12格）。
2. 全城普通街坊、剥壳人官方底册与白塔常规检索系统均已查无「镜辞」此人；镜辞利用这一天然隐形优势，对外以「东巷新来的外乡修表匠 / 沈师傅」无名马甲活动，唯有芽记得他的真名，姜霁靠虎口双针孔与银弹账本认人。
3. 严守冷峻硬朗的都市高武与机械悬疑风，禁止回到物业门禁审批、打印费跑腿费拉锯或填表扯皮；所有医院与殡仪馆冲突直接围绕停尸柜活尸暴起、手术台拆骨换核、冷链车劫杀展开；全卷正文与对白全面退用“几阶”，统一呼镇钟九响境名、白塔牌令、壳侧序列与普通人「时痕」火候。
4. 紧扣大纲红线：不提前揭晓沈竹在源裂缝深处的具体状态，不出现左衡真名，不让停摆域以上顶尖战力在本卷提前下场秒杀。

## 核心矛盾

沦为全城无名者的镜辞，必须在不动用怀表最后第1格底命的绝境下，靠修表匠手艺活拆强敌机芯开启第二重「拆核上弦」表盘，撕碎白塔「丑时司」与「换骨」大裁缝在城南医院联手打造的死人续档黑巢，夺回参号母钟副发条盒并晋升镇钟第三响「走汞境」。

## 本卷剧情

### 第一段剧情：死后十一个月的敲门人 <!-- L2-01 -->

- 章节范围：第31-42章
- 参考对标书哪段剧情：异兽迷城《连环杀人案与工会初探》（借什么：主角以隐秘身份切入城市诡异命案、通过死人身上的反常细节顺藤摸瓜揪出伪人，并在首战中验证新能力机制的爽点节奏）
- 这段怎么排：第31-33章镜辞与芽携黑令暗查城南医院外围并借老街暗口放风，接下亡夫赵闻川「火化十一个月后却凭医院错烧纠错红章回家上班、发白纸工资条且旧表倒滴尸油」的诡异修表委托，夜探赵宅抓出「从不碰热汤」违和并照缝看穿假赵闻川胸腔「丑时司副发条」与旧表内侧负四层暗码 → 第34-36章深夜反杀破窗灭口的丑时司银边巡官陆寒小队（1名银边巡官＋2名铜章手），首次完成「拆核上弦（提纯合充入3格血契弦）」；第36章在东巷后堂测试耗1格触发绷弦极限「倍速走针（震裂左掌旧伤、余2格）」，由芽携502旧齿轮重连假陈骁布下城南冷链盯梢线 → 第37-39章顺机芯编号夜潜城南第四医院地下停尸回廊，与暗查尸档的姜霁狭路重逢，联手救下初萌「止缝刃」时痕微兆的缝尸黑医苏晚 → 第40-42章停尸房冷库硬刚白塔丑时司走汞圆满银边巡官秦钊，镜辞无损拧动余下2格血契弦开启卡齿两秒，一锤轰碎敌方胸腔机芯再充3格血弦，拿到通往地下续档手术室的零柒号铜钥。
- 这段答应读者什么：立刻解答读者对「怀表只剩第1格以后怎么打架」的最大担忧，用极其痛快的「活拆强敌机芯逆向上弦」让主角重新实现禁招自由，同时拉满「火化十一个月的死人凭错烧红章回家吃饭拿白纸工资条」的中式都市恐怖感。
- 这段让读者图什么：读者想看主角被全城遗忘后不但没颓废，反而彻底甩开束缚放手猎杀→落在亡夫死而复生却把妻女逼到精神崩溃的林秀母女身上→此前医院以错烧乌龙压住家属不敢声张→这次林秀拿着半夜倒滴尸油的亡夫旧表摸来东巷找无名修表匠→镜辞一眼看穿表壳里的尸油与续档发条，破灭口局亲手活拆银边巡官陆寒脊椎机芯完成首次拆核上弦（充3格），试招留2格备战停尸房→读者看到灭口小队被当场锤爆、大呼过瘾。
- 对这卷的用处：完成第一卷到第二卷的无缝换图与金手指升维，立住「拆核上弦」核心循环，并把视角切入城南第四医院。
- 主角这段要什么：验证怀表底盖副槽能否靠高品机芯逆向上弦，摸清程晦黑令背面「城南医院·批号零柒」到底藏着什么母钟部件。
- 怎么接上前面：直接从第30章末尾镜辞揣着第1格怀表、沈竹残片与程晦黑令残牌望向城南医院的收官画面切入。
- 核心阻碍：怀表第一重表盘只剩第1格不敢乱拧；姜霁手头仅剩11发银芯弹且正遭剥壳人总局内务科停职盘查；城南医院内外遍布白塔丑时司眼线；芽左臂骨裂吊兜无火药可用。
- 主角的关键选择和出手：镜辞拒绝被动等待，借市井暗口放出专收疑难歪表风声引赵闻川案上门；面对丑时司外勤收割小队灭口合围，绝不动第1格底命，纯凭绷弦满劲与捉影镊活拆陆寒等三具脊椎时隙核，提纯楔入怀表底槽打通第二重蓄能盘；第36章改由芽带502旧齿轮暗联假陈骁织起城南盯梢网。
- 怎么兑现、好处归谁：第35章首次拆核上弦充入3格血契弦、第36章测试绷弦倍速耗1格余2格、第42章冷库连开卡齿并再斩银边巡官充回3格；镜辞拿稳第二重蓄能盘、零柒号铜钥与带「止缝刃」微痕的后勤黑医苏晚。
- 这段主打哪条线、顺带收获什么：主打拆核上弦线；顺带推进续档破局线（揭开赵闻川死人续档真相）与铁血暗查线（替姜霁补充银弹并埋下改枪线）。
- 这段在动的其他线：续档破局线从接下林秀委托推到夺得地下续档室零柒号铜钥；铁血暗查线从姜霁应付总局盘查推到停尸房与镜辞重逢联手。
- 这段先不能揭开、不能用上的：见全卷规矩第 1、4 条；此外参号母钟副发条盒的真身在这段只闻其震动、暂不露面。
- 怎么引出下一段：零柒号铜钥背面刻着每逢单数日午夜零点开启的「地下负四层·换骨流水线」，而林秀亡夫的真骨正被拿去喂养那座流水线的核心动力炉。
- 有没有硬伤：没问题

### 第二段剧情：负四层的换骨流水线 <!-- L2-02 -->

- 章节范围：第43-55章
- 参考对标书哪段剧情：异兽迷城《化工厂潜入与小队血战》（借什么：小队换装潜入敌方核心黑工厂、目睹骇人听闻的流水线真相、在敌方封锁拉闸后凭新晋升战力杀穿重围的中高潮结构）
- 这段怎么排：第43-46章苏晚入驻东巷替镜辞伪造医院调校师工牌、镜辞首借「百表拓印」拆秦钊寒雾阀改微缩冻油机关并熔炼余劲破入第三响「走汞境」；第45章白天顶着调校师马甲大摇大摆进院长室喝茶修座钟、当面照缝副院长收加班费（人前显圣）兼撞破住院部“孝顺儿媳”无痛盯梢微恐切片；第46章傍晚儒雅民国表客**温砚**（申时掌司）首次登门东巷喝茶修表试探（F034） → 第47-49章镜辞夜探老城「黑表鬼市」凭修表手艺换足银弹并接502室假陈骁急报，联手芽、姜霁截停冷链车活捉医院副院长 → 第50-52章潜入负四层「换骨流水线」，目睹白塔丑时司批量缝合续档劳工并发现流水线中央锁着半座「参号母钟副发条盒」 → 第53-55章「换骨」宗师座下大弟子（初入鸣钟的缝骨将·柳生骨）率八具铁骨走汞壳合围，镜辞连耗4格血契弦开启「倍速走针+卡齿」配合冻油机关砸碎柳生骨半边骨甲、活拆八具铁骨壳回满8格血弦，炸毁流水线全身而退。
- 这段答应读者什么：兑现主角晋升「走汞境」的力量暴涨爽感，以及「一边打群架一边当场拆核回蓝、越打蓄能格越多」的永动机式狩猎快感。
- 这段让读者图什么：读者想看无名马甲在敌方老巢里大摇大摆搞破坏→落在城南医院衣冠楚楚的专家教授实则是按斤售卖活人骨肉的屠夫这一毒瘤上→此前受害者家属求告无门反被当成精神病关押→这次镜辞拿着调校工牌直接走进院长办公室锁门验缝→镜辞突破走汞境后一锤轰塌负四层骨炉、当场活拆八具铁骨走汞壳机芯边打边上弦→读者看到缝骨将柳生骨被砸断肋骨狼狈逃窜、黑工厂彻底瘫痪。
- 对这卷的用处：作为本卷中点大高潮，确立镜辞走汞境的高武正面硬仗能力，并亮出本卷核心争夺物「参号母钟副发条盒」。
- 主角这段要什么：突破「走汞境」，搞清城南医院拿什么给成百上千具续档活死人供能，并救出冷链车里的无辜街坊。
- 怎么接上前面：凭上一段夺得的零柒号铜钥与苏晚提供的医院内部器械检修单，顺理成章混入医院深处。
- 核心阻碍：负四层设有隔绝常规热武器的「高频骨粉雾障」；敌方主将柳生骨已踏入第四响「鸣钟」境门槛，全身骨骼经过百具走汞壳骨叠焊，坚逾精钢。
- 主角的关键选择和出手：面对八具铁骨走汞壳的消耗战围杀，镜辞不退反进，把围攻他的铁骨壳当成「移动充电宝」，用捉影镊与倒钩铜锤现拆现充，硬生生顶着骨雾杀到柳生骨面前砸裂其主骨。
- 怎么兑现、好处归谁：第44–46章晋升走汞境，第55章大破负四层流水线并重创鸣钟境缝骨将柳生骨；镜辞蓄能盘攒满8格血契弦，苏晚借「止缝刃」时痕定住碎骨缝合流浆，替芽锻造加固耳后「死锁缓冲银箍」。
- 这段主打哪条线、顺带收获什么：主打续档破局线与拆核上弦线双线并爆；顺带收获芽的死锁加固升级与副发条盒的下落。
