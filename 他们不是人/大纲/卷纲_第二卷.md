# 第二卷《死人续档》 卷纲

## 核心信息

- 章节范围：第31-80章
- 字数目标：15万字
- 本卷定位：发展

## 这卷读者等着看什么

- 读者期待：第一卷末镜辞怀表跌至第1格、全城熟人与官方档案彻底将他遗忘，读者正揪心于「只剩1格还怎么开大招战斗」，同时期待看他如何拿着从四阶程晦身上夺来的「城南医院·殡仪续档总库」黑令，以查无此人的幽灵修表匠身份杀入城南，揭开死人续档产业链并实现战力与金手指的双重破局。
- 这卷主打哪条线：战力与金手指破局线（激活怀表第二重「银钢蓄能盘·拆核上弦」机制，武道由二阶巅峰晋升三阶「走汞境」至半步四阶，彻底解决不敢拧表的续航痛点）。
- 本卷顺带的收获：撕开白塔「丑时司」与城南第四医院勾结的死人续档黑产；结识地下停尸房缝尸黑医苏晚并收入东巷班底；为芽换装高阶死锁缓冲箍、为姜霁改装噬时银弹膛线；夺回「参号母钟副发条盒」。
- 这卷揭开或用上的：揭开怀表底盖内侧「第二重·银钢蓄能盘（拆核上弦）」的真正用法；揭开白塔内部按十二时辰编制的「十二时辰修正司（本卷主打丑时司）」与壳侧「七大缝皮宗师（本卷主打换骨宗师一脉）」的冰山一角。
- 这卷先不能揭开、不能用上的：第一重表盘仅剩的第1格底命绝不可动用归零（留待第12卷）；沈竹壳盖下半句「零号表芯不在壳里，在……」的终极坐标不可提前揭晓；白塔至高掌权者左衡真名与本尊不可提前下场；三座母钟合一的神迹不可提前动用。
- 这卷可以新加的：城南第四医院地下停尸回廊的封闭断代地形；白塔「丑时司」掌管尸档调包与活死人续期的职级规矩；「换骨」派大裁缝以死人骨殖拼装三阶、四阶战体壳的邪道手段；地下黑市用高阶机芯结算的硬通货规矩。
- 有没有硬伤：没问题

## 全卷规矩

1. 怀表第一重表盘指针死死停在第1格，本卷任何战斗严禁扣减这最后1格底命；所有「卡齿（停摆两秒）」「倍速走针」与卷末「逆摆雏形」的消耗，全部来自第35章激活的第二重表盘「血契蓄能弦」（拆解三阶以上强敌机芯充能，每拆一核充1至3格，本卷上限12格）。
2. 全城普通街坊、剥壳人官方底册与白塔常规检索系统均已查无「镜辞」此人；镜辞利用这一天然隐形优势，对外以「东巷新来的外乡修表匠 / 沈师傅」无名马甲活动，唯有芽记得他的真名，姜霁靠虎口双针孔与银弹账本认人。
3. 严守冷峻硬朗的都市高武与机械悬疑风，禁止回到物业门禁审批、打印费跑腿费拉锯或填表扯皮；所有医院与殡仪馆冲突直接围绕停尸柜活尸暴起、手术台拆骨换核、冷链车劫杀展开。
4. 紧扣大纲红线：不提前揭晓沈竹在源裂缝深处的具体状态，不出现左衡真名，不让五阶以上顶尖战力在本卷提前下场秒杀。

## 核心矛盾

沦为全城无名者的镜辞，必须在不动用怀表最后第1格底命的绝境下，靠修表匠手艺活拆高阶怪机芯开启第二重「拆核上弦」表盘，撕碎白塔「丑时司」与「换骨」大裁缝在城南医院联手打造的死人续档黑巢，夺回参号母钟副发条盒并晋升三阶高武「走汞境」。

## 本卷剧情

### 第一段剧情：死后十一个月的敲门人 <!-- L2-01 -->

- 章节范围：第31-42章
- 参考对标书哪段剧情：异兽迷城《连环杀人案与工会初探》（借什么：主角以隐秘身份切入城市诡异命案、通过死人身上的反常细节顺藤摸瓜揪出高阶伪人，并在首战中验证新能力机制的爽点节奏）
- 这段怎么排：第31-33章镜辞与芽携黑令夜探城南医院外围，接下亡夫赵闻川「火化十一个月后重新回家上班领工资」的诡异修表委托 → 第34-36章上门验表看穿续档活死人胸腔内的「丑时司副发条」，夜半反杀灭口的三阶续档猎手并首次完成「拆核上弦（充入2格血契弦）」 → 第37-39章顺着机芯编号摸进城南第四医院地下停尸房，与暗查尸档的姜霁狭路重逢，联手救下被裁缝盯上的缝尸黑医苏晚 → 第40-42章停尸房冷库硬刚白塔丑时司三阶巅峰巡查官，镜辞无损拧动血契弦开启卡齿两秒，一锤轰碎敌方胸腔机芯再充3格血弦，拿到通往地下续档手术室的零柒号铜钥。
- 这段答应读者什么：立刻解答读者对「怀表只剩第1格以后怎么打架」的最大担忧，用极其痛快的「活拆强敌机芯逆向上弦」让主角重新实现禁招自由，同时拉满「火化十一个月的死人拎着公文包回家吃饭」的中式都市恐怖感。
- 这段让读者图什么：读者想看主角被全城遗忘后不但没颓废，反而彻底甩开束缚放手猎杀→落在亡夫死而复生却把妻女逼到精神崩溃的林秀母女身上→此前报警被白塔压下、所有人以为只是认错人→这次林秀拿着亡夫停在火化当天的旧表找上东巷无名修表铺→镜辞一眼看穿表壳里的尸油与续档发条，亲手拆开假赵闻川胸膛取出丑时司铁牌并完成首次拆核上弦→读者看到灭口小队被满弦的镜辞当场锤爆、大呼过瘾。
- 对这卷的用处：完成第一卷到第二卷的无缝换图与金手指升维，立住「拆核上弦」核心循环，并把视角切入城南第四医院。
- 主角这段要什么：验证怀表底盖副槽能否靠高阶机芯逆向上弦，摸清程晦黑令背面「城南医院·批号零柒」到底藏着什么母钟部件。
- 怎么接上前面：直接从第30章末尾镜辞揣着第1格怀表、沈竹残片与程晦黑令残牌望向城南医院的收官画面切入。
- 核心阻碍：怀表第一重表盘只剩第1格不敢乱拧；姜霁手头仅剩11发银芯弹且正遭剥壳人总局内务科停职盘查；城南医院内外遍布白塔丑时司眼线。
- 主角的关键选择和出手：镜辞拒绝被动等待，主动挂出「专修死人停表」的木牌引赵闻川案上门；在假赵闻川暴起行凶时，不拧第1格，而是凭二阶巅峰绷弦劲与捉影镊生生撬出其脊椎发条，楔入怀表底槽打通第二重蓄能盘。
- 怎么兑现、好处归谁：第35章首次拆核上弦成功、第42章冷库连开卡齿与倍速走针秒杀丑时司巡查官；镜辞独得5格血契蓄能弦、零柒号铜钥与苏晚这位精通解剖缝合的后勤黑医。
- 这段主打哪条线、顺带收获什么：主打拆核上弦线；顺带推进续档破局线（揭开赵闻川死人续档真相）与铁血暗查线（替姜霁补充两匣特制银弹并改装枪管）。
- 这段在动的其他线：续档破局线从接下林秀委托推到夺得地下续档室零柒号铜钥；铁血暗查线从姜霁应付总局盘查推到停尸房与镜辞重逢联手。
- 这段先不能揭开、不能用上的：见全卷规矩第 1、4 条；此外参号母钟副发条盒的真身在这段只闻其震动、暂不露面。
- 怎么引出下一段：零柒号铜钥背面刻着每逢单数日午夜零点开启的「地下负四层·换骨流水线」，而林秀亡夫的真骨正被拿去喂养那座流水线的核心动力炉。
- 有没有硬伤：没问题

### 第二段剧情：负四层的换骨流水线 <!-- L2-02 -->

- 章节范围：第43-55章
- 参考对标书哪段剧情：异兽迷城《化工厂潜入与小队血战》（借什么：小队换装潜入敌方核心黑工厂、目睹骇人听闻的流水线真相、在敌方封锁拉闸后凭新晋升战力杀穿重围的中高潮结构）
- 这段怎么排：第43-46章镜辞借「查无此人」的黑户身份，伪装成白塔外聘钟表调校师混入城南医院器械科，暗中摸清负四层结构，同时借炼化机芯碎能将武道推入三阶「走汞境（气血如水银走槽、一锤三千斤）」 → 第47-49章502室假陈骁传回安平里失踪人口被冷链车运入医院的急报，镜辞与芽、姜霁里应外合截停冷链车，揪出负责活体分拣的医院副院长 → 第50-52章潜入负四层「换骨流水线」，亲眼目睹白塔丑时司将死人户籍、记忆碎片与高阶壳骨缝合成「永不罢工的完美纳税工具人」，并发现流水线中央靠半座「参号母钟副发条盒」提供走时动力 → 第53-55章「换骨」宗师座下大弟子（四阶初段大裁缝·柳生骨）率八具三阶铁骨壳合围，镜辞连耗4格血契弦开启「倍速走针+卡齿」，以三阶走汞重锤硬生生砸碎柳生骨半边骨甲、活拆八具铁骨壳机芯当场回满8格血弦，带众人炸毁流水线全身而退。
- 这段答应读者什么：兑现主角晋升三阶高武「走汞境」的力量暴涨爽感，以及「一边打群架一边当场拆核回蓝、越打蓄能格越多」的永动机式狩猎快感。
- 这段让读者图什么：读者想看无名马甲在敌方老巢里大摇大摆搞破坏→落在城南医院衣冠楚楚的专家教授实则是按斤售卖活人骨肉的屠夫这一毒瘤上→此前受害者家属求告无门反被当成精神病关押→这次镜辞拿着调校工牌直接走进院长办公室锁门验缝→镜辞突破三阶走汞境后一锤轰塌负四层骨炉、当场活拆八具三阶铁骨壳机芯边打边上弦→读者看到四阶大裁缝柳生骨被砸断肋骨狼狈逃窜、黑工厂彻底瘫痪。
- 对这卷的用处：作为本卷中点大高潮，确立镜辞三阶走汞境的高武正面硬仗能力，并亮出本卷核心争夺物「参号母钟副发条盒」。
- 主角这段要什么：突破三阶「走汞境」，搞清城南医院拿什么给成百上千具续档活死人供能，并救出冷链车里的無辜街坊。
- 怎么接上前面：凭上一段夺得的零柒号铜钥与苏晚提供的医院内部器械检修单，顺理成章混入医院深处。
- 核心阻碍：负四层设有隔绝常规热武器的「高频骨粉雾障」；敌方主将柳生骨已踏入四阶「鸣钟境」门槛，全身骨骼经过百具壳骨叠焊，坚逾精钢。
- 主角的关键选择和出手：面对八具三阶铁骨壳的消耗战围杀，镜辞不退反进，把围攻他的铁骨壳当成「移动充电宝」，用捉影镊与倒钩铜锤现拆现充，硬生生顶着骨雾杀到柳生骨面前砸裂其主骨。
- 怎么兑现、好处归谁：第46章晋升三阶走汞境，第55章大破负四层流水线并重创四阶柳生骨；镜辞蓄能盘攒满8格血契弦，苏晚用缴获的高阶骨殖替芽加固了耳后死锁缓冲箍（令芽可短暂爆发四阶怪力而不呕血）。
- 这段主打哪条线、顺带收获什么：主打续档破局线與拆核上弦线双线并爆；顺带收获芽的死锁加固升级与副发条盒的下落。
- 这段在动的其他线：铁血暗查线从姜霁配合截车推到拿到副院长与白塔丑时司分账黑册；活人锚点线从假陈骁盯梢冷链车推到成功接应获救平民返回安平里安全屋。
- 这段先不能揭开、不能用上的：见全卷规矩第 1、4 条；参号母钟副发条盒在负四层爆炸瞬间被白塔丑时司副掌司提前转移至城南殡仪总库，留待下一段决战夺取。
- 怎么引出下一段：白塔丑时司副掌司（四阶巅峰·钟无咎）震怒之下启动「全城续档尸潮暴走」，并将参号副发条盒设在城南殡仪馆火化总库作为诱杀陷阱，同时向剥壳人总局施压要求逮捕姜霁。
- 有没有硬伤：没问题
