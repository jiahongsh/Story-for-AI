# 第三卷《第十三组无名客》 卷纲（第 81–140 章·阶段规划）

> 承接第二卷《死人续档》斩杀白塔丑时司副掌司钟无咎、缴获「寅时银梭」与总局特聘调令。本卷对标《异兽迷城》第二部《麒麟工会》卧底篇：全城查无此人的镜辞顶着特聘军械修表师「沈先生」马甲混入剥壳人总局后勤科与守夜武院，点拨觉醒「时痕」天赋的平民守夜新锐，在十二外勤组大比与连环内鬼案中扮猪吃虎，破入「鸣钟」境并锻造重器「千钧摆轮锤」。

## 核心信息

- 章节范围：第81-140章
- 字数目标：18万字
- 本卷定位：发展

## 本卷故事线

- **总局潜伏线（主线）**：镜辞以特聘匠师「沈先生」马甲入驻剥壳人总局地下军械库，表面替各组王牌修表改枪、在「黑表鬼市」与武院凭「百表拓印」人前显圣（改出震音铜锤与噬时膛线）、暗中排查「寅时银梭」背后的高层内鬼，与明面优雅喝茶、实则借刀杀人的申时掌司**温砚**首次展开长线暗战，同时揪出潜伏十年的白塔「寅时司」掌司与壳侧「画皮」宗师分身。
- **日常微恐与双伙伴独立暗线**：保留「守夜武院天天给学员打热汤却从不照镜子的炊事阿姨实为『画皮』潜伏钉子」的日常非人微恐线；姜霁顺着老赵殉职残页追查「申时司」密印（同期核查重犯提调单时闪过「安平里陈骁批转城南特别劳务」伏笔 F030，并现出前代镇钟缺角双环印旧照 F035）；芽凭银箍残音暗查北河桥洞旧线索。
- **破境铸锤与时痕群像线（资源线）**：借总局军械库的百年寒铁与凶壳核心，镜辞将八角倒钩铜锤重铸为鸣钟境重器「千钧摆轮锤」，镇钟武道由走汞圆满破入「鸣钟（脏腑洪钟劲）」；同时在守夜武院首开平民「时痕」五大系别大群像（「定瞳 / 骨弦 / 滞隙 / 赋械 / 心锁」各展锋芒，依落痕至鸣钟火候逐级厮杀）。
- **三组立威线（盟友线）**：姜霁（左虎口双针孔隐现「赋械系·噬时蚀铁」微兆）与顾横（「骨弦系」重装硬汉）获得镜辞暗中改造的噬时武装，在十二组大比中横扫绥靖派与内奸派，重夺外勤组话语权。

### 第一段剧情：军械库里的修表匠 <!-- L3-01 -->
- 章节范围：第81-100章
- 这段让读者图什么：全城通缉的无名凶徒大摇大摆坐在剥壳人总局喝茶修表，顺手点拨几名只顾死拼蛮力的守夜武院「落痕 / 绞弦」新人用准时痕窍门；故意刁难他的王牌组长被他随手调校的武器震断虎口，反过来求他改枪。
- 这段怎么排：81-88章持特聘调令入驻总局后勤科、立威挑剔王牌兼点醒武院时痕新秀 → 89-95章暗查老赵当年殉职卷宗、锁定三名高层嫌疑人，**并在地下废档清理通道惊鸿一瞥已彻底滑出系统账本、寸镜照不出皮缝与时痕的「无刻者」曹严（两边卖账初显）** → 96-100章夜半截杀潜入军械库灭口的「画皮」缝合伪人，拆核上弦攒满蓄能盘。

### 第二段剧情：十二外勤组大比 <!-- L3-02 -->
- 章节范围：第101-120章
- 这段让读者图什么：总局三年一度的十二组大比沦为白塔内鬼清洗铁血派的杀局；定瞳、滞隙、骨弦各系时痕尖子齐齐登场，镜辞在台下边磕瓜子边用寸镜指点姜霁、苏晚与二组**贺钧**破招，关键时刻亲自登台一锤震碎黑令级挑衅者。
- 这段怎么排：101-108章大比开启、内奸派暗用白塔殖装重创二组队员，**贺钧亲眼见同袍伤亡抚恤被暗中扣压隐忍埋恨** → 109-115章姜霁持镜辞改装银枪逆转连胜 → 116-120章镜辞晋入「鸣钟」境，铸成「千钧摆轮锤」当众砸烂内奸派压轴缝骨大裁缝。

### 第三段剧情：寅时司掌司现形 <!-- L3-03 -->
- 章节范围：第121-140章
- 这段让读者图什么：镜辞利用此前给总局高官修表留下的「逆向锁簧暗门」，在寅时司掌司发动总局政变瞬间一键锁死全场叛军武器，配合逆摆十秒当众撕下停摆域分身画皮！
- 这段怎么排：121-130章将计就计引诱「寅时」内鬼开启总局底层封锁库 → 131-136章一键引爆修表后门瘫痪叛军、联合顾横姜霁围杀寅时司掌司与画皮分身 → 137-140章缴获指向第四卷「午夜404号环城地铁」的断代车票，全身而退深藏功与名。
