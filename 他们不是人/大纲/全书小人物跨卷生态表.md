# 《他们不是人》全书小人物跨卷生态表

> **性质：全书人物生态执行表。**
>
> 本文件服务于 `角色生态与小人物系统硬约束.md`，负责把“20-30名长线熟面孔”真正实例化到八卷，而不是继续停留在抽象配额。
>
> **核心原则**：这些人物首先是临江市里自己要生活的人，其次才承担证据、制度、情绪或行动功能。任何人物如果连续三次出场都只为给主角递线索，应判定为功能化，需要重写。
>
> **使用方式**：
> - 已在正文/卷纲出现的人物优先保留原事实；
> - “暂定名”只锁人物生态位，不要求在尚未需要时强行登场；
> - 重要人物正式进入正文后，再建立独立角色卡；
> - 同一人物不要求每卷出现，复现间隔可以很长，但下一次出现必须带时间变化或现实后果。
>
> **人数目标**：全书形成约25名稳定熟面孔，其中至少12名无正式刻痕，至少8名可以在核心人物不在场时独立做出影响剧情的现实决定。

# 一、五个城市人物群

全书小人物不平均撒在地图上，而是形成五个可反复回到的现实生活群。

| 人物群 | 目标规模 | 主要作用 |
|---|---:|---|
| 旧市场生活圈 | 6人 | 保存镜辞、芽、沈竹与普通生活的长期关系痕迹 |
| 剥壳人基层与协作岗位 | 6人 | 证明组织由具体工作人员而非几个高层组成 |
| 医院 / 社区 / 警务现实节点 | 5人 | 把身份异常转化为医疗、居住、家庭、工作等现实后果 |
| 百川堂 / 观潮者外围网络 | 4人 | 提供独立来源、民间关系知识与非官方方法 |
| 白塔 / 守夜人基层 | 5人 | 让中后期技术、医疗、守界制度落到具体职业与伦理后果 |

目标总量约26人，其中部分人物可跨群连接。

# 二、旧市场生活圈

## 01｜老陈｜旧市场五金/杂货摊熟人｜已出现

- **定位**：镜辞店铺附近的长期熟面孔，不是专业调查者。
- **自己原本要过的生活**：守摊、盘货、抱怨生意、照顾膝盖和家里老人。
- **真正怕失去的东西**：多年熟客关系和摊位稳定，不愿旧市场因异常调查被整体贴上“有问题”的标签。
- **与镜辞利益关系**：多数时候愿意帮，但如果镜辞的调查影响整条街生意，会直接反对。
- **第一卷功能**：009-010成为灰衬衫事件的普通见证者之一；他的记忆出现版本偏差，证明熟人证词也会被扰动。
- **跨卷变化**：
  - V2：开始自己把特殊客人的外貌/时间写在进货本空页上，但并不认为这是“异常记录法”。
  - V3：因旧市场一次身份核验风波拒绝媒体/围观者拍摊位，表现普通人对异常调查的疲劳。
  - V7：当系统开始统一身份版本时，他拿出多年进货本作为独立旧版本之一。
  - V8：不参加主战场，继续守市场并帮助街坊保留互相冲突却真实的旧记录。
- **最终余波**：镜辞终局后重新回来修表时，老陈第一反应是嫌他欠着一笔小零件钱，而不是发表存在哲学。
- **刻痕**：无。

## 02｜陈姨｜早餐/家常饭熟面孔｜已存在设定

- **定位**：旧市场生活节奏锚点。
- **自己要什么**：把店继续开下去，照顾家人，别让街区一天到晚出事。
- **真正怕失去**：熟客变成陌生人、老街被拆散。
- **核心功能**：芽和镜辞过去生活的外部关系证据，但她从来不能成为“芽认证器”。
- **跨卷变化**：
  - V1：提供日常习惯和普通关系背景，对当前存在既熟悉又偶尔感到不适。
  - V2：学会遇到身份争议时先分别记“谁来过、谁付过钱”，不参与真假判断。
  - V4：因白塔/异常事件造成街坊讨论，她明确表示“你们查你们的，我只认今天谁来吃饭、谁欠钱”。
  - V7：系统记录与她自己多年账本发生冲突，她拒绝覆盖旧本。
  - V8：成为“普通人保留多版本”最生活化的证明之一。
- **刻痕**：无。

## 03｜小满｜旧市场年轻熟人｜已存在设定

- **定位**：用成长变化体现时间流逝的人物。
- **自己要什么**：离开旧市场去读书/工作，又舍不得彻底离开熟悉生活。
- **怕失去**：被成年人不断告诉“以前的事你记错了”。
- **与芽关系**：芽过去帮助过她/改变过一个具体生活习惯，具体事实以后续正文已锁内容为准，不额外发明大事件。
- **跨卷变化**：
  - V1：仍是旧关系痕迹之一，不承担万能回忆。
  - V2-V3：开始出现明显年龄/学业变化，减少在市场出现。
  - V5：一次身份争议中，她第一次坚持“我不知道她是谁，但这件事确实是她后来帮我的”，区分身份和后果。
  - V8：以已经长大的普通青年身份参与社区版本保全，不变成超能力者。
- **刻痕**：无。

## 04｜徐师傅｜修锁/门禁现实证据协作者｜已存在设定

- **定位**：物理边界专家，代表“门、锁、出入记录有时比高深理论更实在”。
- **自己要什么**：做生意、少返工、别让客户因为玄乎问题赖账。
- **错误观点**：前期过度相信物理痕迹比人可靠，后来会被“锁没变、身份却变了”的案例打脸。
- **跨卷变化**：
  - V1：提供锁具、门禁、物理边界证据。
  - V2：主动保留一次换锁前后的两套记录，成为“上一卷方法被普通人学会”的案例。
  - V3：一次旧港行动中，他提供的旧锁型号判断有误，提醒读者专业技能也会错。
  - V7：协助社区把自动门禁改成“冲突版本保留 + 人工异议”而不是只接受中央同步。
- **刻痕**：无。

## 05｜赵叔（暂定）｜旧市场快递/送水熟人

- **首次建议出现**：V1中后段或V2。
- **自己要什么**：准时送完货早点回家，不想卷入任何“特殊调查”。
- **功能**：城市路线、楼栋出入、时间变化的生活观察者；偶尔能提供路线事实，但更多时候什么都不知道。
- **错误观点**：习惯相信“天天见的人肯定不会认错”。
- **关键变化**：V2一次正常人误判案后，他主动承认自己也会因制服、路线习惯产生错误熟悉感。
- **后期**：V7大规模身份混乱时，他仍靠配送路线和现实签收记录帮助社区恢复局部生活秩序。
- **刻痕**：无。

## 06｜周婶（暂定）｜旧市场裁缝/改衣摊主

- **首次建议出现**：V1后半自然露面，不承担主案。
- **自己要什么**：挣钱供女儿生活，最讨厌别人临时改要求。
- **独特观察**：对人的尺寸、衣物磨损和穿衣习惯敏感，但她不会因此成为身份识别专家。
- **功能**：偶尔提供与“外貌一样但生活使用方式不同”相关的微弱现实证据。
- **跨卷变化**：V5后明确说过一次“衣服合身，不代表人没变”，作为生活层面对内部复制主题的回声。
- **刻痕**：无。

# 三、剥壳人基层与协作岗位

## 07｜韩清｜档案与版本核验｜第二卷已预设

- **职业核心**：永远先问“这条数据第一次从哪里出现”。
- **自己要什么**：建立一套即使上级换人也不会丢失来源链的档案方法。
- **错误观点**：前期过度信任“来源可追溯=内容可靠”。
- **成长**：
  - V2：拆续档模板、保存02:17前快照。
  - V3：旧档证明“来源真实也可能只是当时人的错误理解”。
  - V4-V5：参与白塔旧资料新旧版本核验。
  - V7：发现中央认证开始反向污染来源链，主动建立离线分叉档案。
  - V8：成为四链断开后追责档案的关键基层角色。
- **刻痕**：无。

## 08｜罗建平｜现场处置员｜第二卷已预设

- **职业核心**：安全、撤离、控制现场。
- **自己要什么**：让队员活着下班，不想再看到“为了查真相把现场搞成墓地”。
- **错误观点**：前期认为调查员总会低估现场风险，容易把“先控制”扩大成“先冻结”。
- **能力规划**：只有当V2-V3明确需要长期专业腐蚀输出者时，才实例化为“断层·腐蚀系”3阶左右；否则保持无刻痕战术人员。
- **跨卷变化**：顾横死后，他不成为“继承顾横的人”，而是在是否保留第二撤离线问题上持更保守立场，之后被实际救援结果逐渐改变。

## 09｜卢雁｜程序审查 / 现实权限联络｜第二卷已预设

- **自己要什么**：让处置有法可依、有人负责，不愿特殊案件变成“谁声音大听谁的”。
- **错误观点**：前期容易相信“上游已审核”。
- **V2关键误伤**：她参与一次对普通人的过度权限冻结，造成不可立即恢复的现实损失。
- **后续**：
  - V3：推动“不可逆权限必须二次确认”。
  - V4：对左衡制度真实价值保持支持，不因一次错误就反制度。
  - V7：她最先意识到统一身份同步把“审核”变成自动执行，成为拆现实接口链的基层关键人。
- **刻痕**：无。

## 10｜魏勤｜医疗与受害者联络｜第二卷已预设

- **自己要什么**：案件结束后家属仍然能活下去。
- **错误观点**：前期容易因为长期接触受害者而对某些高风险异常对象缺乏耐心。
- **功能**：把“处置成功”翻译成家属后续生活、医疗、安置、赔付。
- **跨卷变化**：
  - V2：赵闻川/许岚等后续复核。
  - V3：顾横事件后负责伤者与家属，不允许全员只悼念英雄。
  - V5：姜父当前替代者的处置中坚持当前主体也需要现实安置。
  - V8：协调身份混乱患者的最低医疗权，不等系统最终判定。
- **刻痕**：无。

## 11｜林序（暂定）｜剥壳人年轻现场员

- **自己要什么**：证明自己不是只会按程序的新兵。

# 四、医院 / 社区 / 警务现实节点

## 13｜方宁（暂定）｜医院信息员

- **首次建议**：V2赵闻川案后。
- **自己要什么**：系统别出事故，自己别因特殊案件背锅。
- **错误观点**：最初相信“系统同步成功就说明上游已经解决”。
- **关键变化**：V2亲眼见到02:17覆盖旧状态后，养成重大身份争议前先留本地快照的习惯。
- **跨卷**：V7她的旧习惯成为阻止医院自动覆盖身份版本的关键。
- **刻痕**：无。

## 14｜杜成｜社区民警（暂定）

- **自己要什么**：辖区少出事，不想每次特殊机构出现就把普通警务全推翻。
- **功能**：坚持只基于现实行为处理非法侵入、暴力、失踪、证据保全，不因“壳”二字跳过程序。
- **错误观点**：前期认为特殊机构喜欢把简单纠纷复杂化。
- **成长**：在V2-V3后学会“身份冲突不代表暂时什么都不能做”，能在不知道超自然全貌时保护人。
- **V8**：参与普通秩序恢复，不进入异常核心作战。
- **刻痕**：无。

## 15｜宋梅（暂定）｜社区网格员

- **自己要什么**：让独居老人、失踪家庭和长期租户别被系统更新漏掉。
- **功能**：非常熟悉“现实上一个人实际住不住这里”，但不掌握世界真相。
- **关键误伤**：V2/V3可安排她因过度相信邻里熟悉感把一个真实回归者当可疑对象，造成舆论伤害。
- **后续**：转而学会记录“事实”和“判断”分栏。
- **V7-V8**：成为社区级多版本保留的自然执行者。
- **刻痕**：无。

## 16｜秦护士（暂定）｜夜班护士

- **自己要什么**：先把病人救活，身份争议别妨碍急救。
- **功能**：医疗伦理现实锚点。
- **跨卷**：
  - V2：拒绝因身份争议暂停紧急治疗。
  - V4：见到受控融合者真实获益，因此不会简单站反白塔。
  - V7：拒绝让中央身份结果自动改变床旁照护记录。
  - V8：继续照护两个系统都声称“不是同一人”的患者，先按当下医学事实处理。
- **刻痕**：无。

## 17｜孙建民（暂定）｜物业经理

- **自己要什么**：小区别出安全事故，也不愿因特殊调查承担无限责任。
- **错误观点**：前期依赖上游系统与门禁自动判断。
- **成长**：
  - V2学会冲突身份先冻结不可逆权限、保留本地人工异议。
  - V3因一次过度冻结遭住户投诉，开始加入期限和复核机制。
  - V7自动同步失控时，他直接关闭一部分中央覆盖，保住本地住户历史版本。
- **刻痕**：无。

# 五、百川堂 / 观潮者外围网络

## 18｜猫眼｜核心外围人物｜已存在

> 猫眼属于核心/长线边界角色，本表只记录她作为“普通信息能力也能改变终局”的生态功能，不替代其独立角色卡。

- **刻痕**：无。
- **长期作用**：来源判断、纸档/离线版本保存、交易伦理。
- **终局价值**：数字链趋向统一时，她保存的多来源版本成为反归并材料之一。

## 19｜韩叔（暂定）｜百川堂第二来源核验点

- **首次建议**：V2中段。
- **职业外壳**：旧书/票据/收藏品修复或二手材料鉴别。
- **自己要什么**：保住自己的来源信用，不愿为任何势力免费站队。
- **错误观点**：认为“只要来源没断，内容本身就值得信”。
- **作用**：证明百川堂不是猫眼私人外挂。
- **后续**：V5遇到修复师制造的“真实来源链伪共识”，被迫升级来源判断方法。
- **刻痕**：无。

## 20｜许澜（暂定）｜观潮者社区联系人

- **首次建议**：V2社区身份争议案。
- **自己要什么**：保护自己熟悉社区，不信任外来机构替街坊做决定。
- **错误观点**：早期使用某些过于粗糙的熟人识别法。
- **成长**：一次误判后承认“熟悉也会错”，但仍坚持长期关系信息不能被机构完全忽略。
- **后期**：V7-V8组织普通社区形成多版本保全网络。
- **刻痕**：可以无；若后续需要铭刻支援位，应另建新人物而非强行给她觉醒。

## 21｜裴洛（暂定）｜观潮者环境真视专业者

- **首次建议**：V3旧港。
- **能力候选**：`潮线·真视系`，2-3阶。
- **职业技能**：地下设施/建筑巡检或测绘经验。
- **自己要什么**：弄清旧港裂隙污染路线，保护仍住在附近的家人。
- **错误观点**：前期认为“看得到裂隙流向”就能决定哪里最危险，忽视人口与撤离现实。
- **人物价值**：证明同为真视系也不能替代镜辞；他看环境，镜辞看身份错位。
- **后期**：V8参与裂缝同步链断开，但不参与身份认证。

# 六、白塔 / 守夜人基层

## 22｜陆谨（暂定）｜白塔普通记忆治疗师

- **首次建议**：V4。
- **自己要什么**：让患者恢复生活能力；真心相信白塔技术值得存在。
- **错误观点**：过度看重内部恢复指标。
- **功能**：必须让读者见到“白塔真的救过人”。
- **成长**：V4一个技术成功但关系未恢复的病例让他开始区分治疗成功和主体认证。
- **V7-V8**：支持停止“内部连续→自动身份认证”，但继续保卫记忆医疗本身。
- **刻痕**：可无，优先保持普通专业者。

## 23｜闻雪（暂定）｜白塔数据审核员

- **自己要什么**：让评估标准一致、可复现，不愿回到“谁关系亲谁说了算”的主观混乱。
- **错误观点**：支持删除高噪声外部关系字段，有充分专业理由。
- **跨卷弧线**：
  - V4支持标准化。
  - V5发现修复师可以工程化操纵“关系看起来正常”。
  - V7意识到中央统一标准已变成自动社会判决。
  - V8参与拆白塔认证链，同时保留可重复检测数据供后续研究。
- **刻痕**：无。

## 24｜程野（暂定）｜守夜人镇封主力

- **首次建议**：V3后半或V4。
- **能力候选**：`封潮·镇封系`，5-6阶成熟职业者。
- **自己要什么**：让裂缝别越过自己负责的边界，尽量让队伍完整回去。
- **错误观点**：早期接受“必要时删掉少数关系痕迹换整体稳定”的老守夜人实用主义。
- **与守钟人区别**：守钟人承担历史、时间错位与人物关系；程野承担现代职业守界与团队协同。
- **成长**：V7开始拒绝以“删关系”作为默认封界代价，V8带多人完成裂缝同步节点断开。

## 25｜林槐（暂定）｜守夜人后勤 / 旧设施维护

- **自己要什么**：那些几十年没人管的守界设施别在自己值班时坏掉。
- **职业技能**：机械、电气、旧式封界设施维护，不靠超能力。
- **功能**：让守夜人不像一群只会念古老规矩的神秘人。
- **跨卷变化**：V3-V4负责旧设施现实维护；V7发现某些自动化改造反而引入统一接口风险；V8参与手动切断节点。
- **刻痕**：无。

## 26｜叶徊（暂定）｜观潮/守夜合作铭刻位

- **首次建议**：V4-V5有真实剧情需要时再实例化。
- **能力候选**：`共证·铭刻系`，3-4阶起。
- **自己要什么**：保护真实共同见证，不愿再看到一整个家庭因记忆污染互相否认。
- **错误观点**：早期容易把“共同记得”误当“共同记得的一定是真的”。
- **成长**：学会铭刻只保护既有关系指向，不替证词背书。
- **V7-V8**：成长到5-6阶，保护多来源关系版本，但绝不能创造新锚点或替代第五式。

# 八、跨卷复现硬规则

## 1. 每次复现至少改变一件现实状态

可选：
- 年龄/学业/工作变化；
- 家庭变化；
- 身体状态；
- 对机构态度；
- 操作习惯；
- 对某个旧人物的新理解；
- 因旧案造成的新成本。

禁止“几年以后还是站在同一个位置说同一句台词”。

## 2. 小人物可以拒绝主角

至少长期保留以下不同立场：
- 相信镜辞但拒绝他的处置建议；
- 不信超自然但愿意保存证据；
- 支持白塔技术但反对身份认证扩张；
- 讨厌剥壳人但会在现实危险时合作；
- 原谅某个当前存在，却拒绝承认它继承原关系；
- 永远无法原谅某个替代者，但仍承认其后来做过的具体事。

## 3. 每卷至少一次核心人物不在场

从V2开始，每卷至少安排一次：

> 镜辞、姜霁以及高层都不在场，普通岗位人物仍依据前卷留下的方法自己做决定。

结果可以成功，也可以错。

关键是世界能自行运行。

## 4. 第八卷禁止“NPC大合唱”

终局熟面孔的回归必须通过各自职业行动完成：
- 护士救人；
- 物业保版本；
- 档案员保来源；
- 修锁师傅断自动门禁；
- 镇封者断裂隙；
- 摊主保账本；
- 民警处理现实安全；
- 普通家庭自己决定关系。

禁止大家排队告诉镜辞“我们都记得你”。

# 十、最终目标

第八卷以前，读者应该自然认识一批并非主角团的人，并能说出：

- 谁习惯保存旧版本；
- 谁最在意现场安全；
- 谁真心相信白塔治疗；
- 谁曾误伤普通人；
- 谁不信镜辞但愿意保存证据；
- 谁被顾横留下的方法救过；
- 谁因为白壳自己的选择改变过；
- 谁在身份同步失控后仍按自己的职业判断行动。

到那时，“存在是分布式关系”才不是终局台词，而是读者已经看了七卷的生活事实。
