# 细纲 · 第35章 走齐的表

## 第 35 章：走齐的表
- **核心事件**：镜辞把D4“机械计时全部正常、接缝感反而增强”的矛盾带回给守钟人。守钟人第一次主动跟他到D4外围，用自己的时间错位感知做验证。他不判断谁是真人，而是发现泵房周边存在极轻微的“结果先于原因”现象：排水沟水面先出现振动，泵机启动声随后才到；门卫身体先转向后门，对讲机呼叫晚半拍才响。普通人会把它们当错觉，守钟人却确认：这里的因果顺序最近被人为整理过。章尾，未知女人发来一句话：“旧表已经看不见了。你还看得见，对吗？”
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第35章；单元1-3第二轮小高潮
- **单元ID/位置**：1-3；第10拍·旧方法失效后的专业验证
- **目标情绪**：带着矛盾求证 → 守钟人亲自到场 → 日常事件顺序出现极细微错误 → 专业确认“被缝过” → 对方目的露出半层
- **主角目标/关键选择**：镜辞想确认D4的“正常”是否也是一种异常；关键选择=承认自己看不懂因果错位，主动请守钟人补专业盲区，而不是强行让镜返解释所有现象
- **章节定位**：专业协作+阶段高潮；建立守钟人的不可替代性
- **本章结构公式**：节点1（镜辞带记录找守钟人） + 节点2（守钟人先质疑控制组） + 节点3（两人去D4外围复测） + 节点4（结果先于原因的细微错位） + 节点5（守钟人确认“这里最近被缝过”） + 节点6（未知女人信息）
- **章首钩子**：守钟人看完镜辞的D4记录，只问一句：“三块表都走齐，你为什么还觉得那里不对？”镜辞说：“因为我看见的缝，比17号更清楚。”老人把老花镜摘下来：“那就麻烦了。”
- **本章即时兑现**：守钟人的时间错位感知第一次在剧情中完成只有他能做的判断；镜辞与导师形成互补而非上下位关系
- **本章禁止提前释放**：守夜人正式组织、接缝修复师、具体“修缝”技术、未知女人身份、幕后组织为什么需要镜辞
- **能力边界**：时间错位只能证明某段因果/同步过程被外力重新排列，不能单独证明某人是壳或哪个身份版本为真
- **契约风险**：契约安全。重要结论来自两种专业互补，没有让导师替主角接管案件

#### 内容概括（五段式）
- **起因**：镜辞把17、03、D4三地记录摊给守钟人。前两处机械表会失步，D4却异常整齐。守钟人先让他重新说明控制条件，确认不是测试方式不同后，才答应去现场看一次。
- **发展**：两人只在公共河堤和围栏外活动。镜辞重复第34章的计时实验，结果相同：所有表都很稳定。守钟人没盯表，而是看施工门、排水沟、值班人的动作和泵房声音，像个无聊到专门挑节拍毛病的老修表匠。
- **转折**：一台排水泵周期性启动。第三次时，守钟人忽然让镜辞盯着水沟。水面先出现一圈细振纹，约半拍后泵房里才传来继电器和电机声。随后门卫在对讲机响起前先转向后门，等了极短一瞬，对讲机才传出“车到了”。单次都可以解释成经验和声音传播，连续几次却始终有同方向的顺序偏差。
- **高潮**：守钟人闭眼听了一会儿，说：“17号是钟自己乱。这里不是钟乱，是事情被排得太齐。”镜辞问是不是有人改了时间。守钟人摇头：“没那么玄。发生过的事还是那些事，但它们留下来的先后缝被人抹平了。我只能告诉你，这地方最近被重新缝过。”他明确拒绝回答“谁是壳”，因为这不是他的能力。
- **结尾**：两人离开D4。回城公交上，镜辞收到一个陌生号码发来的消息：`17会漏，03会慢，D4现在走得很准。旧表已经看不见了。你还看得见，对吗？` 镜辞没有回复。他把信息截屏、导出并记下时间，只在账本写了一句：`他们不是只在给我线索。他们在测试我的眼睛。`

#### 情节安排（多线）
- **主线推进**：D4确实经历近期“因果缝线校平”；未知网络需要镜辞的可见性作为某种测试变量
- **辅线推进**：守钟人的能力第一次真正落地，同时明确不能判身份
- **事件线/任务线**：带数据求证 → 现场复测 → 捕捉顺序错位 → 专业判断 → 收到测试式信息
- **任务卡点**：仪器全部正常 → 镜辞缺乏解释 → 守钟人补上因果顺序维度 → 两种观察共同证明“正常不是自然形成的”
- **感情线/关系线**：镜辞×守钟人：镜辞第一次主动承认“这一块我不会”，守钟人也第一次在当前案件里实际出手而非只说半句
- **逻辑线**：17/03旧指标明显 → D4旧指标被校平 → 守钟人发现时间错位残痕 → 对方信息确认“看不见”正是测试目标之一

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 守钟人 → D4普通值班/施工人员背景 → 未知女人/网络（短信）
- **人物关系变化**：镜辞与守钟人从“一个调查一个保留”进入第一次真正专业协作
- **视角/信息差**：发短信的人显然知道三个测点的旧表现与D4现状，但仍不确认就是第25章女人本人

#### 结尾设定和钩子
- **结尾设定**：第35章不揭“接缝修复”名称，只确认现代维护正在压平旧仪器和时间错位能捕捉的痕迹；镜辞仍能看到某些身份接缝，因此成为对方关注对象
- **章尾钩子**：他们为什么需要知道镜辞还能不能看见？是为了消灭一个观察者，还是为了用他校验自己到底修干净了没有？
