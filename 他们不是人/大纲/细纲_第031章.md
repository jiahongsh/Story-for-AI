# 细纲 · 第31章 饵里有什么

## 第 31 章：饵里有什么
- **核心事件**：顺记一行结束后，镜辞没有立刻追第25章女人，也没有照着店内所有标签继续跑。他把顺记现场拆成“对方明显允许他看见的东西”和“更可能是意外留下的东西”两组：周远维修单、17/03/D4标签摆得过于显眼，可能属于诱导；真正难伪装的是新快递封条上的分拨码、垃圾桶内同批零件包装、插线板购买批次和后间桌面磨耗。镜辞由这些非叙事性痕迹反推出：最近一批设备很可能从南岸D4附近的一家普通机电维修点转来。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第31章；顺记高潮后的主动校准
- **单元ID/位置**：1-3；第6拍·饵料审计
- **目标情绪**：线索很多带来的兴奋 → 怀疑“太顺了” → 拆分可见层与偶然层 → 从垃圾细节找到新方向 → 重新夺回行动权
- **主角目标/关键选择**：镜辞想判断顺记里哪些东西是在“给他看”；关键选择=不沿最醒目的周远/17/03标签直接追，而是优先查对方最难专门布置的来源痕迹
- **章节定位**：调查反转章；高潮后的主角不能变成被线索牵着跑的观众
- **本章结构公式**：节点1（复盘现场照片） + 节点2（发现显眼信息过度集中） + 节点3（建立“展示/偶然”两栏） + 节点4（快递分拨码和包装批次） + 节点5（锁定南岸机电维修点）
- **章首钩子**：镜辞把顺记照片翻到第七遍时，忽然觉得不对。一个真正怕别人发现的地方，为什么会把“周远”“17”“03”“D4”四个他正好认识的词，全放在不用翻抽屉就能看见的位置？
- **本章即时兑现**：第25-30章“未知势力可能在引导镜辞”不再只是台词，而由场景布置本身成为可分析事实
- **本章禁止提前释放**：未知女人所属势力、她为何需要镜辞、接缝修复技术正式概念、D4内部用途
- **能力边界**：本章完全不靠镜返新增信息；主角靠照片、包装和采购痕迹反推
- **契约风险**：契约安全。第30章给出的高密度线索不会被主角无脑全信

#### 内容概括（五段式）
- **起因**：镜辞回到钟表行，把第30章拍到的照片全部按拍摄顺序铺开。他最初想把周远维修单、17/03/D4零件袋当作三条独立突破口，却发现这些东西刚好都摆在产权人带看能自然看到的位置。
- **发展**：他在账本画出两栏：`对方很可能知道我会看见` 与 `对方未必会想到我会查`。前一栏放周远、测点标签和女人章尾现身；后一栏放垃圾桶里的快递封条、不同品牌零件袋的批号、后间插线板型号、桌面最近反复搬动某种长方设备留下的磨痕。
- **转折**：快递封条上虽然收件地址被撕走，但保留着一个区域分拨码。镜辞拿普通快递查询规则和几家网点电话交叉确认，分拨区域不是东里巷，而是南岸旧工业带。两只零件包装上的本地经销贴纸也来自同一区域。
- **高潮**：镜辞进一步查到一家仍营业的“兴南机电维修”，业务包括泵站控制器、旧计时继电器和工业同步模块。它离第23章D4箭头所指的废弃泵房只有不到两公里。这个方向不是女人直接告诉他的，而是从顺记不显眼的物流残留里反推出的。
- **结尾**：守钟人问他为什么不先查周远。镜辞说：“因为周远可能就是他们想让我查的。”他把南岸机电点记成`独立推导A1`，D4记成`历史线索B1`，两者只在地图上画虚线相连。第二天，他准备先去正常营业的机电店，而不是直接闯废泵房。

#### 情节安排（多线）
- **主线推进**：未知势力的“主动展示”被主角识别；D4获得一条独立现实来源
- **辅线推进**：镜辞调查方法升级为分析“线索为什么会出现在自己面前”
- **事件线/任务线**：复盘照片 → 分展示/偶然 → 查分拨码 → 查经销来源 → 锁定普通机电店
- **任务卡点**：第30章信息太多 → 越多越可能被设计 → 主角主动降低显眼线索权重 → 从边角痕迹拿到独立方向
- **感情线/关系线**：镜辞与守钟人的方法关系继续推进，但决定由镜辞自己做
- **逻辑线**：顺记故意展示疑点 → 物流残留 → 南岸工业带 → D4附近机电店

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 守钟人一笔
- **人物关系变化**：守钟人开始看到镜辞不只是“会保存证据”，还会分析证据被展示的动机
- **视角/信息差**：未知女人是否故意留下物流线索仍不知道；因此只标“独立推导”，不标真相
