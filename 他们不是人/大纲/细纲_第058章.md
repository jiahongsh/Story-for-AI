# 细纲 · 第58章 提前一天

## 第 58 章：提前一天
- **核心事件**：康宁巷保洁阿姨回忆，自己那句交接记录不是“突然想到”，而是上线前夜打扫物业办公室时看见一张施工人员落下的试运行确认单。她担心第二天物业忘记处理住户争议，顺手把其中一句意思抄进交接本。物业翻出废纸回收箱暂存袋，真的找到半张撕破的复写联：`关系一致性试运行确认单`。表中除设备状态外，还有一项从未出现在公开产品说明中的验收指标：`关系说明口径一致率`。签字施工单位属于恒泰下游团队，验收人员栏只有一个姓“陈”的潦草签名。章尾，猫眼找到同批试运行表格的缓存截图，其中一栏写着：`住户口述反馈：待复测。`
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段3；第58章；从文字来源进入“人的反馈也被验收”
- **单元ID/位置**：1-4；第18拍·提前一天并不神秘，验收项目才神秘
- **目标情绪**：保洁解释来源 → 找到残纸 → 一天差被现实解释 → 表格出现不该存在的指标 → 住户口述也被纳入验收
- **主角目标/关键选择**：镜辞想解释交接本为何早一天出现；关键选择=当现实来源找到后立即撤销“保洁异常”猜测，把注意力放到真正异常的验收项目上
- **章节定位**：排除+反转；一个疑似超自然点被解释，反而露出更有组织性的现实证据
- **本章结构公式**：节点1（联系保洁阿姨） + 节点2（她回忆试运行纸单） + 节点3（物业找废纸） + 节点4（确认关系一致性试运行） + 节点5（口径一致率指标） + 节点6（住户口述待复测）
- **章首钩子**：保洁阿姨听完问题，在电话那头想了半天：“那句话不是我想的。我好像是在一张施工单上看见的，怕第二天忘，就顺手记了。”
- **本章即时兑现**：第57章唯一未解释样本得到普通信息来源；真正值得怀疑的转为施工验收表为何评估“关系说法一致”
- **本章禁止提前释放**：验收指标完整含义、陈姓验收员身份是否就是陈屿、接缝修复技术、幕后组织
- **能力边界**：本章没有超自然能力参与，所有进展来自人证、废弃纸质物证和公开/缓存资料
- **契约风险**：契约安全。保洁阿姨不是神秘知情者，只是正常工作中看见过一张纸

#### 内容概括（五段式）
- **起因**：康宁巷物业联系到保洁阿姨。她一开始只记得自己确实写过交接本，仔细想后才说，上线前夜办公室堆着施工人员留下的纸，她收桌子时看见一张“关系什么确认单”，上面有一句差不多的话。她担心第二天值班人员漏掉住户争议，就按自己的理解抄了一句。
- **发展**：这解释了为什么她比公开模板早一天写出类似句子。镜辞没有觉得“线索断了”，反而让物业先看看废纸是否还在。因为项目刚上线没几天，办公室废纸按规定还没全部清运，回收袋里真翻出半张被撕开的复写联。
- **转折**：纸头写着`关系一致性试运行确认单`。前几项都很普通：门禁同步、设备在线、账户映射。中间却有一项：`关系说明口径一致率`，后面手写“首轮偏低，需复测”。这个指标在公开产品帮助文档里从没出现。
- **高潮**：表格施工单位是恒泰体系下游承包商，验收栏只有一个潦草“陈”字，无法仅凭签名坐实陈屿。猫眼随后从承包商曾短暂公开的培训截图缓存里找到同类表格，最下方还有一栏：`住户口述反馈：待复测。` 设备项目竟然在记录住户怎么描述家庭关系。
- **结尾**：镜辞把“保洁提前知道”这一异常彻底划掉，改写成：`她只是提前看过验收单。` 然后在下一行写：`真正的问题：他们为什么要验收住户怎么说？` 从D4开始，他是“看不看得见”的验收样本；现在普通住户似乎也有自己的验收指标。

#### 情节安排（多线）
- **主线推进**：关系统一项目明确包含“住户口述反馈/口径一致率”这一隐藏验收维度
- **辅线推进**：恒泰下游施工链再次与住户关系项目连接，但不坐实某一个具体员工责任
- **事件线/任务线**：回访保洁 → 找废纸 → 识别表单 → 查公开缓存 → 发现隐藏指标
- **任务卡点**：提前一天看似超自然 → 保洁找到现实来源 → 原疑点消失 → 物证本身暴露更大目的
- **感情线/关系线**：镜辞练习让“自己的推测被事实否定”而不焦躁，调查成熟度继续提高
- **逻辑线**：公开模板前一天 → 试运行纸单先存在 → 保洁抄录 → 话术传播合理 → 但住户口述为什么成为验收项不合理

#### 人物关系和出场顺序
- **出场顺序**：保洁阿姨（电话） → 康宁巷物业 → 猫眼 → 镜辞
- **人物关系变化**：普通工作人员被从“疑似异常者”还原为普通信息接触者，避免整个城市人人可疑的廉价悬疑
- **视角/信息差**：人物知道项目测住户说法，却不知道是普通满意度调查、社会服从测试还是更深层同步准备
