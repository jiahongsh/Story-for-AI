# 细纲 · 第22章 过河

## 第 22 章：过河
- **核心事件**：镜辞按第21章台账和船工证词过河，目标不是“走沈竹走过的路”本身，而是复原她从渡口到南岸旧堤的实际路线。他用旧地图、路边老店和地形对照排除两个错误方向，最终找到一处与沈竹旧照片背景吻合的河湾，并发现这里曾有一个已拆除的临时观测棚。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第22章；南岸现场路线复原
- **单元ID/位置**：1-2；第12拍·路线落地
- **目标情绪**：行动明确 → 两次走错 → 现场细节逐步对上 → 找到旧河湾 → 新物证出现
- **主角目标/关键选择**：镜辞想定位沈竹过河后的第一个明确停留点；关键选择=不因为“这地方像照片”就马上认定，而是用山形、堤岸角度和旧建筑位置交叉确认
- **章节定位**：调查推进+场景扩张；避免大段走路和抒情占字数
- **本章结构公式**：节点1（带旧地图过河） + 节点2（第一条路线被地形否定） + 节点3（老杂货店提供旧路名） + 节点4（第二处仍不匹配） + 节点5（河湾三项地标同时对上） + 节点6（观测棚基础）
- **章首钩子**：沈竹三年前过河后只留下一个方向：“沿旧堤往下游。”问题是旧堤后来改过两次，现行地图上根本没有当年的路。
- **本章即时兑现**：第21章方向信息转化为可验证地点，推进不是靠“命运指引”
- **本章禁止提前释放**：南岸测点编号、沈竹之后去向、组织身份、姜霁
- **契约风险**：契约安全。章节中至少两次排除错误假设，防止主角一路走一路自动命中

#### 内容概括（五段式）
- **起因**：镜辞带着旧水文图、现行地图和沈竹照片过河。船工只把他送到南岸，后面的路由他自己查。
- **发展**：他先按现行堤路往南走，很快发现远处山形和照片完全不对；又按一条废弃土路转进去，柳树和坡度接近，却少了照片里一根旧输电塔。他把两个地点都标记为排除，不因为“差不多像”硬认。
- **转折**：河边一家开了几十年的杂货店老板告诉他，旧堤改造前还有一条“机修道”，早就被绿化带吞掉。镜辞按老板画的简图绕过一片芦苇和废弃护坡，终于看到照片里那个带缺口的山脊和旧输电塔底座。
- **高潮**：河湾位置、斜坡角度、旧塔基和照片拍摄方向四项同时对上。更重要的是，柳树后方草丛里有一块四角打孔的水泥底座，尺寸明显用于固定轻型观测棚，不是普通路灯或广告牌基础。
- **结尾**：镜辞没有坐下来追忆沈竹。他先测底座、拍照、记方向，又在附近找到一截老电线槽。照片能证明沈竹曾来这里，底座则说明她来的可能不是普通河湾，而是另一处被撤掉的观测点。

#### 情节安排（多线）
- **主线推进**：南岸河湾被可靠定位；新旧测点网络继续扩张
- **辅线推进**：普通老店和旧地名成为城市记忆的一部分
- **事件线/任务线**：过河 → 两次排错 → 获得旧路名 → 找到河湾 → 发现观测棚基础
- **任务卡点**：现行地图失效 → 旧地形与口述补足 → 多项地标同时吻合才确认
- **感情线/关系线**：镜辞通过沈竹的工作痕迹接近她，而非通过“站在同一地方就懂她”这种廉价共鸣
- **逻辑线**：渡口方向 → 旧堤变化 → 机修道 → 河湾照片匹配 → 新观测点遗迹

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 船工一笔 → 老杂货店老板
- **人物关系变化**：镜辞开始主动使用普通地方记忆补齐官方地图缺失
- **视角/信息差**：杂货店老板只知道旧路，不知道观测棚用途
