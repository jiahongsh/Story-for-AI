## 二、对抗尺度只能这样升级

```text
熟人关系里的一个错位
→ 能被现实证据复核的身份案件
→ 有人主动把异常“修正常”
→ 专业组织、记忆技术与制度处理边界
→ 内部连续与关系连续发生冲突
→ 新主体是否能成立
→ 错误答案进入身份基础设施
→ 全城只允许一个身份版本
```

禁止退化成“Lv.2 → Lv.3 → Lv.10”的怪物阶梯。战力只是阻力，身份与关系才是主脊梁。

## 五、第一卷结构重构约束

第一卷详细结构只服从 `卷纲_第一卷.md` 当前 v2。跨卷层只锁以下事项：

1. **001-015**：必须把读者先按在镜辞、芽、钟表摊和旧生活里。接缝要早出现，但世界观解释要晚。
2. **16-30**：调查转向“有人在把异常修正常”；姜霁约23-26章第一次有效出场，不做组织百科导游。
3. **31-50**：用一个足够强的“两个陈骁”案件完成可公开复核的方法，不再用多个社区连续讲同一堂课。
4. **51-65**：对手开始主动利用镜辞的观察能力，故事从调查转入反调查。
5. **66-80**：回到原芽的分布式关系痕迹与当前存在的新选择，防止第一卷变成纯方法论教材。
6. **81-95**：姜霁与镜辞通过实案形成工作关系；剥壳人从工作方式进入，不从会议室进入。
7. **96-100**：周衡以“太正常”作为卷末高阶谜题，落点必须接上现有第100章《第一道缝》。

旧001-099细纲在被逐段重写前，只能作为素材库，不能作为“已发生/已封板”事实源。

## 九、全书长期红线

1. 不把小说写成连续案件合集，每个案件必须改变人物方法、关系或制度。
2. 不让镜辞成为唯一有用的人，也不让姜霁变成另一台验真机器。
3. 不把壳都写成等待清除的同质怪物。
4. 不靠角色死亡机械支付高潮税。
5. 不让组织百科、档案解密或哲学辩论连续吞掉普通生活。
6. 不让白塔恢复真实关系锚点，不让第五式成为宇宙撤销键。
7. 不把999+1写成MEM1000、EX+1、能量+1或大小比较判胜。
8. 不把壳王洗白，也不把它压成“没人爱所以疯了”。
9. 不把第一卷旧细纲中的重复方法课因为“已经写过”重新抬回封板状态。
10. 第104章在第一卷001-099重构与重新验收前保持冻结。

## 十、全书最终故事弧

```text
镜辞想证明：她不是芽
→ 学会证明：身份发生了错位
→ 学会承认：看见不等于判决
→ 发现：裂缝早于实验，人类只是学会利用它
→ 发现：技术可以救人，也可以越权定义人
→ 发现：记忆完全正确仍可能不是同一个主体
→ 发现：不能成为原主，不代表不能成为自己
→ 发现：最大的敌人不是一个假人，而是系统替所有人选择唯一答案
→ 最后承认：存在从来不是唯一记录，而是很多生命真实改变过彼此后的关系网络
```

最终不是回答“他们到底是不是人”，而是追问：

> **一个存在有没有真正作为自己活过、选择过、改变过别人，并承担那些后果？**
