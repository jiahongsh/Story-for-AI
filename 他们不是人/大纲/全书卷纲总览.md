# 《他们不是人》全书卷纲总览

> **定位**：八卷长篇的跨卷导航与偏航检查表。
>
> **权威关系**：本文件不替代各卷卷纲。第一卷服从 `卷纲_第一卷.md`，第二卷服从 `卷纲_第二卷.md`，第三至第八卷分别服从对应粗卷纲；底层世界规则、能力边界、终局硬约束仍高于本表。

# 二、对抗对象必须沿这一条线升级

```text
身边一个不对的人
↓
一桩无法简单裁定的身份案件
↓
利用社会边缘与关系断裂的壳巢行动
↓
记忆技术、医疗与共存制度的边界
↓
能把替代身份修到近乎完美的工程
↓
壳是否能形成自己的存在
↓
专业认证 + 关系归并 + 现实接口组成的基础设施
↓
全城只允许一个身份答案的“唯一指向”
```

禁止退化为：

```text
Lv.2壳
→ Lv.3壳
→ Lv.5干部
→ Lv.10壳王
```

战力提升只能服务对抗尺度变化，不能成为全书主脊梁。

# 三、镜辞真正的升级线

| 卷 | 镜返/能力 | 真正的人物升级 |
|---|---|---|
| 1 | 1阶·被动看接缝 | 学会“我看见，不等于我知道” |
| 2 | 2阶·照真身 | 能力变清楚，但接受自己没有判决权 |
| 3 | 铭心初醒 | 明白一个人离开后仍能分布式改变现实 |
| 4 | 3阶·强制现形 | 接受能力必须受真实关系证据约束 |
| 5 | 3阶稳定；半壳模拟预兆 | 面对“内部全部正确”时仍不偷懒给单一答案 |
| 6 | 4阶·遗忘领域；有限半壳模拟 | 从“接受像人的壳”升级为承认一个存在可以成为自己 |
| 7 | 4阶；半壳模拟风险加剧 | 开始看见自己“替所有人保存”的中心化冲动 |
| 8 | 5阶·记忆归还 | 从“我记住所有人”走向“关系应归还很多独立的人” |

镜返阶位严格锁定：

> **第1卷1阶 → 第2卷2阶 → 第4卷3阶 → 第6卷4阶 → 第8卷5阶。**

不得为了某个卷高潮提前升级。

# 四、核心人物跨卷走向

## 镜辞

```text
辨认真假
→ 建立证据方法
→ 学会团队与铭记
→ 接受技术灰度
→ 面对主体连续难题
→ 修正对壳的出身偏见
→ 修正自己的中心化责任感
→ 把记忆与决定权交还关系网络
```

终局：活下来。

## 姜霁

```text
行为调查搭档
→ 独立方法建立
→ 顾横之后承担第二撤离线纪律
→ 与白塔方法对抗
→ 姜父身份识破 + 记忆差分觉醒
→ 脱离剥壳人独立调查
→ 完成姜父同意边界与零号关系重审
→ 以具体行动完成终局“+1”
```

终局：活下来。

## 顾横

- 第2卷作为活着的老兵进入；
- 第3卷被镜辞改变对普通受害者的看法；
- 第3卷第二撤离线中战死；
- 后续通过姜霁、旧部、组织规则和终局撤离继续存在。

## 左衡

```text
第4卷：真实有效的共存改革者
→ 第5卷：为制度稳定第一次压下异常
→ 第7卷：同意边界、预警与接口扩容责任曝光
→ 失权、公开档案、接受调查
→ 第8卷受控协助切断自己建立的接口
```

终局：活着承担，不用牺牲赎罪。

## 白壳

```text
第5卷：高质量复制者
→ 第6卷：产生偏差
→ 自主选择
→ 真实改变别人
→ 形成自己的存在锚点
→ 自我命名“白壳”
→ 主动留下并消散
```

第6卷死亡，永不复活。

## 修复师

```text
第5卷：单体关系图
→ 第6卷：关系归并索引
→ 白壳成为模型反例
→ 第7卷发现索引已与现实接口拼接
→ 唯一指向要求消灭全部替代版本
→ 与壳王决裂、提供关闭路径
→ 被控制/追责
→ 第8卷仅受控协助断链
```

不能反水即洗白。

## 壳王

```text
前期：只留下“完美替代”影子
→ 第4-5卷：作为“零号主体连续”可信答案出现
→ 第6卷：白壳证明它原本有另一条路
→ 第7卷：零号主体连续被推翻
→ 提出唯一指向
→ 第8卷：身份归还后承认“我拥有零号记忆，但我不是零号”
→ 从源裂缝内部关闭源头并崩解
```

理解来源，不免罪。

## 当前曾使用“芽”身份的存在

- 第1卷开始与原芽身份分离；
- 第2-6卷保持低频独立生活线，不回归旧青梅位置；
- 第7卷正式选择一个属于现在自己的名字；
- 第8卷以自己的身份继续生活。

她不能替代白壳承担“壳能否成为自己”的核心证明。

## 原芽

贯穿全书作为“悬置的失去”。

终局永久希望式留白：
- 不认证复活；
- 不宣布死亡；
- 不作为恋爱竞争者回归。

## 沈竹

当前唯一保留的宏观可控分岔：**最终是否生还尚未硬锁。**

原因不是犹豫结局，而是她的失踪链尚未经过第3-6卷细纲验证。

无论生死，功能已经锁定：
- 第4卷确认实验研究员身份；
- 第7卷提供事故前关系基线的一部分；
- 不能单独证明壳王身份；
- 后期必须完成“替镜辞决定 → 把选择权还给镜辞”的人物结算。

待第3-6卷细纲完整建立失踪因果后再锁生死，不凭作者偏好硬定。

# 九、全书最大红线

1. 不把长篇写成连续案件合集；案件必须承担认知升级。
2. 不把势力展开写成组织百科导览；世界观通过工作、生活、交易和后果出现。
3. 不让镜辞成为唯一有用的人。
4. 不让姜霁成为关系真理扫描仪。
5. 不让小人物只在需要证据或煽情时刷新。
6. 不靠角色死亡支付每卷高潮税。
7. 不让壳王洗白，也不把它扁平成纯疯子。
8. 不让白塔、左衡、修复师的错误变成“其实他们全被骗了”，必须保留各自责任。
9. 不提前消费白壳、零号重审、唯一指向和999+1。
10. 不让终局打完以后世界恢复出厂设置。
11. 不把原芽生死变成必须公布的标准答案。
12. 每卷上一阶段的正确认识只能被扩展，不能被廉价反转成“前面全错”。

# 十、全书最终故事弧

```text
镜辞想证明：她不是芽
↓
学会证明：身份发生了错位
↓
学会承认：看见并不等于判决
↓
发现：裂缝早于实验，人类只是学会利用它
↓
发现：技术可以救人，也可以越权定义人
↓
发现：记忆完全正确仍可能不是同一个主体
↓
发现：不能成为原主，不代表不能成为自己
↓
发现：最大的敌人不是一个假人，而是系统替所有人选择唯一答案
↓
最后承认：存在从来不是唯一记录，而是很多生命真实改变过彼此后的关系网络
```

所以全书最终不是回答：

> **“他们到底是不是人？”**

而是把问题改成：

> **“一个存在有没有真正作为自己活过、选择过、改变过别人，并承担那些后果？”**
