# 第一卷《青梅的皮囊》卷纲（主笔重写版）

> 面向30章高密度快节奏商业连载结构。每章有推进、冲突与硬钩子，能力实战与人世代价同步落地。

## 本卷核心约束与设定规则 <!-- 全卷 -->

- 镜返能力与修表工具绑定：第一式·照缝（借镜面/表蒙反光盯住接缝满三秒可触发借镜窥死）；第二式·卡齿（逆拧银灰旧怀表表冠，令三米内带接缝怪物强制停摆两秒，每次耗两格刻度）；锁簧术（以异种碎核卡死壳体内主筋节点，斩断母巢共振丝）。
- 沈竹遗留银灰旧怀表共十一道刻度，不可逆转恢复（第一重凡尘止逆盘）；每退一格，镜辞与人世间的关系线便松脱一分（先畜生，后街坊，再挚友与至亲），直至第29–30章焊封参号地缝后背面双环底盖震开一线银钢蓄能暗槽，埋下第二卷拆核上弦伏笔。
- 壳的规律：靠吞噬原主记忆碎片并让亲友信以为真来长死接缝，但无法完全复刻原主肌肉空间本能；若获得活人明知真假仍付出的真心，可生出人类血肉（活人锚点）。
- 本卷绝对压住不揭的事项：沈竹七年前进入零号母表裂缝后的真实去向；原芽是否还有生还可能；幕后零号母表的终极控制者。

### 第一段剧情：青梅的皮囊 <!-- L1-01 -->

- 章节范围：第 1-6 章
- 这段让读者图什么：都市熟人身份恐怖开篇爆燃，镜辞从日常微末破绽入手，借表蒙窥死、一针一锤首杀剥皮壳、挑虫结盟姜霁，并在三头怪物封门绝杀中觉醒第二式·卡齿砸断裁缝陈屿右臂。
- 这段怎么排：第1章寸镜反光揭露拧头接缝与怀表跳格 → 第2章早点铺表蒙窥死见北河桥洞 → 第3章取半枚铜齿轮并完成老张头首杀 → 第4章小煤球狂吠体现代价与姜霁持枪夜访 → 第5章挑虫结盟、老陈忘芽、陈屿拎包登门 → 第6章觉醒卡齿砸断陈屿右臂、取出502染血字条。
- 当前状态：已写完并提交追踪。

### 第二段剧情：五零二室的两个儿子 <!-- L1-02 -->

- 章节范围：第 7-10 章
- 这段让读者图什么：极致的真假善恶反转与情绪暴击——没缝的亲儿子持毒刀弑父夺房，有缝的假怪物被半瞎老爹真心喂出活人锚点；镜辞强开卡齿改命断线、打开黄铜母钟拿神兵与血书，却要立刻直面盟友姜霁开始遗忘自己的钝痛，并设法重新锚定姜霁准备夜袭恒泰。
- 这段怎么排：第7章替姜霁拔除主虫后闯502室见双陈骁对峙 → 第8章揭穿真陈骁毒计、陈屿吹骨笛催爆、假陈骁自刺门框求死 → 第9章拍入异种碎核断共振丝反噬重创陈屿、老人眼泪令假陈骁长出真肉、开母钟获捉影镊与恒泰血书，怀表退至第五格致姜霁遗忘初见 → 第10章用捉影镊、加密名片与虎口痊愈铁证重新稳住并唤醒姜霁的战友信任，踩点恒泰设施准备凌晨两点十七分强攻。

### 第三段剧情：凌晨两点十七分的地下站 <!-- L1-03 -->

- 章节范围：第 11-20 章
- 这段让读者图什么：潜入恒泰设施地下三层，正面对抗陈屿背后更大的同步机构与白塔叛徒，用捉影镊大杀四方，解救被当作活体养料的失踪者并与异端芽再度联手撕开壳巢据点。
- 这段怎么排：11-13章潜入恒泰地下三层外围、见识两点十七分活人喂养零号母表真相 → 14-17章白塔内鬼截杀、捉影镊显威挑断铁脊与走汞壳接缝、救出关键线人 → 18-20章与芽前后夹击彻底掀翻恒泰地下三层同步站，陈屿底牌尽出濒临绝境。

### 第四段剧情：旧市场再无熟人 <!-- L1-04 -->

- 章节范围：第 21-30 章
- 这段让读者图什么：第一卷终极爆发与最强刀子收束——彻底清算陈屿、窥见零号母表全貌与沈竹的线索，但为了保住全街人与姜霁性命强开多次镜返导致怀表刻度大幅跌落，回到旧货市场时面临老陈等所有熟人彻底陌生化的宿命冲击。
- 这段怎么排：21-25章地下核心决战与斩杀陈屿、从零号母表残片看见沈竹真相一角 → 26-30章强开镜返压制暴走裂缝、怀表刻度跌入危险区，回到旧市场面对老陈客气陌生的一句「以前老板娘叫沈竹，可惜没留下一儿半女」震撼收卷。
