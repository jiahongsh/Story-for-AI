# 一、第一卷唯一核心承诺

> **最熟悉的人，可能已经不是原来的那个人。**

第一卷不急着回答“壳到底是什么”。

它只把这个私人恐惧逐层扩大：

1. 熟悉的人不对；
2. 现实证据开始互相冲突；
3. 系统能替错误身份开放现实权限；
4. 有人主动维护、修补这些错位；
5. 当前存在即使不是原主，也会继续做选择、承担后果；
6. 专业处理网络能控制危险，但同样会误判；
7. 最难的异常不是最像怪物，而是已经在社会里真实生活了很多年的“普通人”。

第一卷认知终点固定为：

> **我看见，不等于我知道。**
>
> **身份未决，不妨碍先保护具体的人；看见异常，也不赋予镜辞替别人决定主体资格的权力。**

# 五、第一卷最终判据

第一卷成功不取决于读者背会多少设定。

只取决于五件事是否成立：

1. 读者相信“熟悉的人可能不是原来的人”；
2. 读者知道镜辞确实拥有别人没有的观察优势；
3. 镜辞能在章内用这个优势改变局面，但不能一眼判生死善恶；
4. 当前存在、陈骁、老李、周衡分别把“错位”推向不同层级，而不是四次重复同一道题；
5. 到第100章时，“看见不等于知道”必须是镜辞一路付出代价后学会的行动原则，不是一句作者写在墙上的标语。

这五项不再额外复制成写作前检查表。具体章节写完后再做审查。
