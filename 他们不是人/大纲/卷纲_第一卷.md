# 第一卷《谁不是我？》卷纲

## 核心信息
- 章节范围：第1-100章（动态，首批建纲前 10 章）
- 字数目标：约 30 万字（动态调整）
- 本卷定位：开篇·立人设立世界·埋钩子
- **数值锚点（见 数值定稿.md 第六节）**：EX 100→150 / SEE 20 / 镜返1阶 / 铭心锁第3卷（本卷不登场）/ 对手 Lv.1-2（芽的替换壳=Lv.2，旧货市场壳=Lv.1）
- **基调策略（用户定调：保留悬念+逐步战斗）**：前10章保持日常恐怖悬念（豆浆铺违和/芽被替换/摊牌），镜返"读到"壳数据只作辅助；第11章起进入数值战斗（识破/镜返结算/对抗公式）。**不在开头倒设定**（力量之源叙事揭示路径：第1卷只让读者以为"主角眼睛特殊"）。

## 卷契约与终局储备

- **卷契约**：日常恐怖（身边人可能是壳）+ 识破爽点（撕开接缝）+ 主角高光（第一次看见接缝、第一次用镜返救人）；期待债 = 芽可能还在（先喝汤信号）+ 养母失踪之谜（怀表刻名）
- **本卷主推线**：镜返觉醒（1阶·看见接缝）——承担本卷最大高潮（芽被替换+第一次识破）
- **本卷战果**：识破个体壳（小爽点×N）+ 姜霁登场伏笔 + 守钟人关系建立 + 猫眼首次交易
- **本卷解锁的终局里程碑**：镜返 1 阶（看见接缝）；养母失踪线索（怀表）
- **本卷禁碰的终局底牌**：壳巢真相 / 镜返 2 阶以上 / 身世（存在实验血脉关联）/ 壳王 / **铭心（副天赋锁第3卷顾横死后）**
- **契约风险**：契约安全（开篇承诺=日常恐怖+识破，主角保持不可替代的"看见"能力）

## 剧情单元卡

### 剧情单元 1-1：钟表行的日子（第1-15章）
- **单元ID**：1-1
- **章节范围**：第1-15章
- **数值锚点**：EX 100→110 / SEE 20 / 对手 Lv.1-2
- **对标剧情参照**：异兽迷城《觉醒启蒙与三人结盟》（1-1，4-15章；借什么：日常恐怖建立+金手指觉醒的"违和→真相"节拍）
- **单元节拍/章功能分配**：建立期待（钟表行日常+养母遗物）→ 尝试（镜辞习惯性观察细节）→ 加压（芽的细微违和）→ 决定性行动（发现芽的"接缝"）→ 兑现（镜返觉醒+第一次读到壳数据）→ 余波（芽被替换+怀表线索）
- **单元承诺**：向读者承诺"这本书是'身边人不是人'的日常恐怖"——芽是第一个验证
- **单元情绪引擎**：日常安心 → 细微违和（芽的违和）→ 反转惊悚（芽被替换）→ 希望微光（先喝汤信号）
- **卷级贡献**：完成人设基点（嘴毒心软观察狂）+ 切入点基点（芽被替换）+ 金手指基点（看见接缝+读到数据）
- **主角局部目标与核心利益**：确认芽是否被替换；保住"记住芽"的能力
- **因果入口**：养母失踪遗留的怀表（刻名"镜辞"）+ 钟表行日常
- **核心阻碍**：低阶壳的完美伪装（镜辞只能看见接缝，无法证明）；自我怀疑（是不是看错了）
- **关键选择与决定性行动**：镜辞选择"相信自己的眼睛"——第一次当众指出芽是壳（第10章）
- **兑现方式与归属**：镜返觉醒（看见接缝被确认）+第一次读到 `Lv.2 侵蚀壳`；收益归主角（能力）与读者（世界观真相初揭）
- **本单元主推线/战果**：主推=镜返觉醒；战果=养母怀表线索+守钟人关系
- **终局底牌边界**：不碰壳巢/镜返2阶/身世/铭心
- **禁止提前释放**：壳巢存在/芽是否真的回不来（希望悬置）/养母真相/壳的完整设定
- **下一单元因果钩子**：怀表上"镜辞"二字的由来 → 引向养母失踪之谜；豆浆铺"先喝汤"信号成为贯穿全书钩子
- **风险等级**：契约安全
