# 细纲 · 第11章 记错的人

## 第 11 章：记错的人
- **核心事件**：灰衬衫男人离开后的第二天，镜辞主动回访第10章现场证人，发现几名摊主都记得“昨晚有人闹事”，却对那个人的衣着、年龄和离开方向给出互相冲突的答案；监控仍保留部分画面。镜辞第一次确认：异常不仅会使用别人的身份，还可能让“同一件事在不同人的记忆里长成不同版本”。他建立第一本证据账本。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段1；第11章；第10章威胁的现实后果
- **单元ID/位置**：1-2；第1拍·后果验证
- **目标情绪**：余悸 → 主动复核 → 证词互相打架 → 更深的不安 → 主角建立应对方法
- **主角目标/关键选择**：镜辞想确认灰衬衫男人那句“他们会一直记得吗”是不是单纯威胁；关键选择=不靠自己记忆下结论，而是分别询问证人、查看监控、保留原始记录
- **章节定位**：调查推进章；必须让主角做事并得到新信息，不能把“遗忘”直接解释成镜返代价
- **本章结构公式**：节点1（回看监控） + 节点2（分别询问三名证人） + 节点3（证词出现系统性错位） + 节点4（监控提供不完整但客观的第三版本） + 节点5（镜辞建立证据账本）
- **章首钩子**：镜辞一早打开昨晚备份的视频，画面里灰衬衫男人明明穿着灰色衬衫；隔壁修锁匠却一口咬定：“哪有灰的？昨晚那人穿的是蓝夹克。”
- **本章即时兑现**：第10章的“他们会一直记得吗”出现第一层现实后果，但只呈现现象，不解释机制
- **本章禁止提前释放**：蚀忆正式名称、EX阈值、壳分类、白塔/壳巢、完整遗忘机制
- **能力边界**：镜返1阶仍是被动看接缝；本章没有主动EX消耗，也不发生“施法一次随机少一个人记得镜辞”
- **契约风险**：契约安全。异常威胁被兑现，同时主角靠调查而不是突然升级应对

#### 内容概括（五段式）
- **起因**：镜辞把昨晚三份备份逐一核对。店内监控拍到了灰衬衫男人进店、压住卷帘门和离开的背影，虽然脸部因为角度和灯光一直不完整，但衣着和时间都清楚。
- **发展**：他分别去问修锁匠、水果摊老板和送货工。三个人都记得昨晚有人和镜辞起冲突，却分别说对方穿蓝夹克、黑T恤和灰外套；有人记得他往东走，有人说往西走。最诡异的是，他们对镜辞本人、昨晚掉在地上的表簧和“冒领客户财物”这件事都记得正常。
- **转折**：镜辞意识到，这不是“所有人集体失忆”。被改变的恰好是那个男人最需要模糊的部分：身份特征和离开路线。监控却保留了一个相对稳定的版本，说明人的记忆、纸面记录和机器记录可能并不同步。
- **高潮**：镜辞不再试图问“谁记得最准”，而是买来一本硬壳笔记本，把每个证人的原话、询问时间、监控时间码、维修单编号分开记下。他在第一页写的不是“谁是真的”，而是：**“先把不同版本都留下。”**
- **结尾**：守钟人翻了两页，没有夸他，只问：“你怎么知道录像一定比人可靠？”镜辞抬头。守钟人把本子合上：“留着。别急着信哪一个。”

#### 情节安排（多线）
- **主线推进**：异常从“身份冒用”升级为“现实版本可能分裂”；镜辞建立证据保全习惯
- **辅线推进**：守钟人再次证明知道这种现象，却仍拒绝交底
- **事件线/任务线**：核录像 → 访证人 → 比较差异 → 建账本 → 得到新的方法论警告
- **任务卡点**：镜辞想确认一个统一答案 → 证词彼此冲突 → 监控也只能给部分事实 → 被迫从“找唯一答案”转向“保存多个版本”
- **感情线/关系线**：镜辞×旧市场：普通人仍是可靠生活关系，但他们的记忆也可能被外力改写；不能神化也不能轻视
- **逻辑线**：第10章威胁 → 第11章证词错位 → 后续需要更系统地保存关系证据与物证

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 修锁匠 → 水果摊老板 → 送货工 → 守钟人
- **人物关系变化**：镜辞不再只相信“我亲眼看见”，开始建立多来源证据思维
- **视角/信息差**：守钟人显然知道记录也可能不可靠，但暂不解释原因

#### 情节细化

#### 结尾设定和钩子
- **结尾设定**：第一卷的“账本”首先是调查工具和版本保存工具，不是超自然对抗遗忘的法器
- **章尾钩子**：如果人的记忆和机器记录都可能不完整，什么样的证据才能证明“一个人曾经在这里”？
