# 细纲 · 第21章 渡口

## 第 21 章：渡口
- **核心事件**：镜辞根据沈竹旧记录的日期范围，请猫眼只追“可验证出行记录”，而不是购买“最后踪迹答案”。猫眼找到一份临江北岸渡口手写客运台账的旧扫描，某日晚班有“沈竹”姓名与身份证尾号。镜辞亲自去渡口，在不先展示照片的情况下采访仍在跑船的老船工，得到与台账相互独立的证词：那晚确有一名疲惫女人坚持过河，并携带一个装计时设备的金属箱。
- **字数目标**：3000 字
- **阶段位置**：第一卷阶段2；第21章；沈竹路线调查进入可验证的人证+记录阶段
- **单元ID/位置**：1-2；第11拍·路线复原
- **目标情绪**：来源链追踪 → 台账命中 → 现场访谈 → 细节互证 → 对岸成为新行动方向
- **主角目标/关键选择**：镜辞想知道沈竹从03点之后去了哪里；关键选择=让猫眼只给原始来源，不让她替自己找“最后一个见过沈竹的人”
- **章节定位**：调查推进；每个结论至少有两个来源层次
- **本章结构公式**：节点1（限定查询条件） + 节点2（渡口旧台账） + 节点3（独立访船工） + 节点4（设备箱细节） + 节点5（南岸方向）
- **章首钩子**：猫眼把一张发黄台账扫描件推到镜辞面前：“我不知道这是不是她最后一次出现。我只知道这个名字、身份证尾号和日期能互相对上。”
- **本章即时兑现**：猫眼角色边界持续有效；沈竹路线不是一句情报，而是可以复核的记录链
- **本章禁止提前释放**：沈竹最后去向、南岸异常点完整用途、姜霁、守夜人组织
- **契约风险**：契约安全。主角仍负责现场核验和结论

#### 内容概括（五段式）
- **起因**：镜辞把沈竹03点最后一批记录日期交给猫眼，只要求查之后七天内可追溯的交通与住宿纸质记录。猫眼在一批旧渡口承包资料里找到扫描件：北岸渡口晚班台账上写着沈竹名字和身份证尾号，日期与03点最后记录相隔两天。
- **发展**：镜辞去渡口，没有给船工看沈竹照片，只问台账那天晚上有没有临时加客。老船工先说不记得具体长相，却记得一个女人错过正常班次后仍坚持过河，因为她带着一只很重的金属仪器箱，怕水却不肯把箱子放船底。
- **转折**：镜辞再拿出台账姓名，船工才慢慢想起那女人穿灰外套、眼下发青，过河途中一直看两块不同的表。这个细节与沈竹旧照片里的测时习惯一致，却是镜辞此前没有向船工透露的信息。
- **高潮**：船工说女人上南岸后没进镇中心，而是沿旧堤往下游走。她临走前问过一句：“以前测水位的人，南岸是不是也有点位？”船工当年没听懂，只给她指了旧堤方向。
- **结尾**：镜辞把船工原话、台账扫描和沈竹03点记录分开存档，只写结论：“她在03点之后确实过了河，方向南岸旧堤。”他没有写“最后踪迹”。因为他还不知道后面有没有更多记录。

#### 情节安排（多线）
- **主线推进**：沈竹从03点到南岸的路线获得双源支持
- **辅线推进**：沈竹携带多计时设备，继续证明她在做现场对照
- **事件线/任务线**：限定查询 → 台账 → 现场访谈 → 未提示细节互证 → 锁定南岸旧堤
- **任务卡点**：纸面姓名可能伪造 → 独立船工证词补足 → 船工记忆也可能有误 → 两边只支持“她当晚过河”这一最小结论
- **感情线/关系线**：镜辞离沈竹的真实行动越来越近，但始终不把“走她走过的路”当作情感仪式本身
- **逻辑线**：03点记录 → 两天后渡口台账 → 船工设备箱细节 → 南岸旧堤

#### 人物关系和出场顺序
- **出场顺序**：镜辞 → 猫眼 → 老船工
- **人物关系变化**：镜辞与猫眼的交易开始形成稳定规则：她给来源，镜辞负责现实复核
- **视角/信息差**：船工不知道沈竹后来怎样；猫眼也没有“最后踪迹”权限
