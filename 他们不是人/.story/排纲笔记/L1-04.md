# 第四段剧情：旧市场再无熟人 排纲笔记

## 批次定位
- 阶段：第一卷《青梅的皮囊》第四段剧情（第 21–30 章），本批先出第 21–23 章开局。
- 上段已收束（第 18–20 章）：彻底砸废恒泰地下三层分体同步站并截断东巷吸血黑管，保住守钟人与参号残胎；但镜辞怀表拧进第 3 格触发全面陌生化反噬——姜霁战后举枪相向靠实物账勉强恢复共行、东巷老街坊张婶客气问姓、瞎眼守钟人记忆亦现裂缝，顾横更急电证实二十年户籍底册「查无镜辞」且白塔高阶机械清理序列已压往今晚收口清盘；陈屿断左爪重伤滚入零号废料竖井扣死铅门逃窜。
- 本批推进（第 21–23 章）：第 21 章后间炉火回火敲直弯锤并焊上淬火钢倒钩，剥开钢牌背面露出西北变电暗井路线图；姜霁带两匣银弹明算底线共行，三人午后切入三十米暗井却撞见白塔先遣队长严彻正率改造猎犬焊死井门。第 22 章死守仅余三格怀表一格不花，凭油膜强光「照缝」破甲反杀严彻获知陈屿仍在井下屠戮夺臂，跌入排废层后亲见两具被剥去铜臂缝上墙的先遣队尸与墙上渗血狂笑留言。第 23 章从死人装备里翻出白塔「便携核验终端」碎屏，日志亮出「目标镜辞第 8 次自动收敛抹除完成 · 剩余直接接触者 2」，彻底洗清白塔借档案抹除嫁祸的把戏、赢回姜霁毫无保留的战友信任；推开最底层铅闸撞见十倍巨钟「零号母表外井基座」，桥心站着已强换上白塔四阶机械铜臂的陈屿，脚下基石夹缝露出七年前沈竹未写完的半句断语（为第 24–25 章斩杀裁缝与窥见残片真相一角铺足死战舞台）。
- 压住不揭：沈竹七年前进入零号裂缝后的真实去向；原芽是否还有生还可能；幕后零号母表终极控制者左衡真名；第 24–25 章再完成陈屿最终死局并揭沈竹真相残角，第 26–30 章再退至第 1 格演老陈陌生化收卷。

## 写纲前查缺
- 对手：白塔档案外勤三阶半机械先遣队长严彻＋三头铜牙改造机械猎犬（已建卡 [严彻.md](设定/角色/严彻.md)，第 21–22 章拦截并在死前爆出井底骇人情报）＋ 藏在零号底层吞噬先遣队换装新机械双臂的重生狂魔陈屿（[陈屿.md](设定/角色/陈屿.md)，留至第 24–25 章正式清算）。
- 角色：镜辞（[镜辞.md](设定/角色/镜辞.md)）、姜霁（[姜霁.md](设定/角色/姜霁.md)，经历从「只信实物暂行」到第 23 章看破抹除终端后重归并肩的心理反转）、芽（[芽.md](设定/角色/芽.md)）、守钟人（[守钟人.md](设定/角色/守钟人.md)，仅第 21 章协助炉火淬锤定调后留守东巷）。
- 能力与金手指：八角重铜锤回火加焊淬火钢钩与新装备说明见 [外物体系.md](设定/世界观/外物体系.md)；怀表严守第 3 格一格不拧（遵循 [怀表机制.md](设定/世界观/怀表机制.md) 与 [金手指.md](设定/世界观/金手指.md)，靠普通三秒物理反光「照缝」看破咬合 0.1 秒死角而不耗刻度，留足余量给 24–30 章跌往第 1 格收卷大刀）；姜霁弹药由二匣银芯备弹起算并精确扣减。
- 数字与刻度：第四日早晨七点十分淬锤备战 → 午后一点潜入恒泰西北废弃变电室三十米暗井 → 下午一点半截杀严彻组 → 下午两点半撞破井底尸廊与终端碎屏 → 下午三点半对峙零号母表外井基座；怀表始终守在 **第 3 格**（对应终端上的「第 8 次自动收敛抹除」）。
- 场景与布局：钟表行后间铁炉（淬锤起点） → 恒泰西北废弃变电室三十米检修暗井 → 零号外围排废层悬尸廊道 → 零号母表外井基座独木铁桥（已补记进 [地理.md](设定/世界观/地理.md)）。由地面小巷憋屈压抑瞬间切入地底冷硬伏击与惊悚反转，拉开最终决战规模。
- 故事线：主线（找暗阶插零号井、斩白塔先锋、正面会师四阶手臂陈屿并发现沈竹七年前半截断语）；姜霁共行信任弧（靠物理账暂行 → 第 23 章借碎屏抹除实锤彻底看透白塔黑幕站死镜辞身侧）；怀表代价与版本抹除线（用终端日志从系统侧坐实「被擦掉八次」的冷酷真相）。
