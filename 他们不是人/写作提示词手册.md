# 《他们不是人》写作提示词手册

作者：小雨心啊。用途：给 AI 下达可执行任务。不要把它当设定源；世界观、数值、文风仍以仓库里的权威文件为准。

**当前状态**：以 `追踪/_tracking-state.json` 为唯一真源（查阅时记录 `state_revision` 与查阅日期）；100-103 为锁定活动正文、104 冻结属既定流程状态。写入只走 `tracking_commit.py` 串行提交，禁止手改派生视图。**当前施工顺序**见 `大纲/大纲.md` §八（唯一正本）。**全局权威树**见 `大纲/大纲.md` §〇。

> **历史模板说明**：本手册第 16 节及若干命令模板写于 2026-09-18 的「051 起二轮重写」阶段，其中「051-099 一轮稿待二轮」「第 11 条禁用追踪提交脚本」「当前施工点 051」等口径**已失效**；模板正文保留仅为留档，不再作为现行状态依据。权威层级一律以 `大纲/大纲.md` §〇 为准，状态以 `_tracking-state.json` 为准。

使用方法：

1. 先复制「〇、每次必贴」；
2. 再复制对应任务的提示词；
3. 把 `{花括号}` 换成具体章号、人名、问题；
4. 一次只下一件主任务。写正文、修正文、审结构不要混在同一条里。

## 〇、每次必贴

新开对话、换模型、compact 之后，把这一段贴在最前面。

```text
你正在本地 Git 仓库中工作，项目根目录就是当前工作区。不要重新 clone，不要重新初始化仓库。

书名：《他们不是人》。作者：小雨心啊。
类型：中文长篇都市悬疑 / 身份恐怖网络小说。
权威源：遇到冲突时不要综合出第三个版本。数值只看 `设定/世界观/数值定稿.md`；镜返只看 `设定/世界观/金手指.md`；文风只看 `设定/都市异能正文风格卡.md`；认知层级只看 `大纲/认知升级与对抗对象硬约束.md` 第十节；小人物配额只看 `大纲/角色生态与小人物系统硬约束.md`；芽案只看 `大纲/芽案与当前存在跨卷线硬约束.md`。

硬约束（必须遵守，不要在提示词里另编一套）：
1. 存在是关系，不是信息。记录 ≠ 记忆 ≠ 铭记。拥有原主记忆 ≠ 原主本人。
2. 接缝只能证明身份不一致，不能自动证明撒谎、是敌人、原主已死、必须消灭。
3. 镜辞只有镜返 + 铭心。第一卷前段只用第一式。第五式留到第八卷。永不进 9 阶。
4. 姜霁第一卷没有正式刻痕，不能看壳、感知裂缝、读记忆。记忆差分第五卷才觉醒。
5. 顾横、猫眼永远没有正式刻痕。
6. 原芽与当前存在不是同一个角色槽。当前存在不是芽复活。
7. 沈竹最终活着，但第1-6卷只能失踪未决。
8. 壳王有零号记忆，但不是零号主体连续。
9. 陈骁案不得宣布宁州=真人、临江=壳。临江陈骁不是纯反派。02:17 不得提前解释成因。
10. 正文禁止出现「第X章」「第一卷」等作者后台编号。
11. tracking 以 `_tracking-state.json` 为唯一正史权威；写入只走 `tracking_commit.py` 串行提交，禁止手改状态文件与派生视图。
12. 不要擅自新建世界观真相源。

当前状态以 `他们不是人/追踪/_tracking-state.json` 为准；施工顺序见 `大纲/大纲.md` §八；权威树见 §〇。
续写前先读 `他们不是人/追踪/上下文.md` 与 `卷纲_第一卷.md v5`。不要回头改 001-050，除非审查发现明确连续性错误。
本手册不写修订号与接纳范围，避免状态多头。

先做项目恢复检查（git status、目录、上下文），不要立刻写正文。
```

## 一、开场与恢复

### 1. 接手 / 恢复上下文

```text
先不要写正文。执行项目恢复检查：
1. git status / git branch / git log --oneline -15
2. 读 `他们不是人/追踪/上下文.md`
3. 浏览 正文/ 大纲/ 设定/ 设定/角色/ 设定/世界观/
4. 用不超过 20 行汇报：当前施工点、上一章留下的问题、本章必须继承的事实、禁止提前释放的信息、建议的下一步命令。
不要重新设计小说。
```

### 2. 只诊断、不施工

```text
只做状态诊断，列出可选下一步，不要自动写正文、不要改文件。
告诉我：最后完成的二轮章是哪一章、下一章细纲在不在、051-099 一轮稿能不能当参考、有没有阻断项（细纲缺失、硬约束冲突、tracking 损坏）。
然后给出 4 个我可以复制发送的下一句命令。
```

### 3. 新会话压缩恢复

```text
这是 compact 后的新会话。只读 `追踪/上下文.md`、上一章正文、下一章细纲和第一卷卷纲相关段。
用固定 7 栏恢复：当前位置 / 长期约束 / 核心角色状态 / 活跃伏笔 / 近三章速记 / 下一章承诺 / 连贯性风险。
不要通读全书。
```

## 二、选题、设定、大纲

### 4. 开书（停在细纲，不写正文）

```text
按 story-long-write 开书流程走 Phase 1→3：确认选题、核心设定、卷纲、首批 10 章细纲。
默认停在细纲交付，不要自动写第1章。
文风卡和题材提示卡要先立住。数值不要另建第二套。
```

### 5. 补设定，但禁止新真相源

```text
我要补 `{角色/地点/势力/机制}` 的设定。
先找出该领域现有权威文件。如果已有权威源，只补缺口并写明「服从哪一份」。
禁止新建平行世界观、第二套 EX、第二套镜返功能。
写完列出：改了哪些文件、哪些问题仍未知。
```

### 6. 写 / 修卷纲

```text
写或回修 `大纲/卷纲_第{N}卷.md`。
必须回答认知硬约束的三问：本卷开始时镜辞相信什么、什么使它变得不够正确、卷末得到什么更大答案。
同时完成四种推进：对抗对象、世界认识、方法论、伦理难度。
不要写成「打完 Boss 换地图」。
第一卷终点锁死：我看见，不等于我知道。身份未决，不妨碍先保护具体的人。
```

### 7. 中途补细纲 / 扩下一段

```text
不要写正文。先给第{N}-{M}章补细纲。
每章细纲必须有：本章职责、可复核现实状态变化、禁止提前释放、人物出场与各自诉求、章尾钩子、认知层级（L0-L3）、普通人功能（窗口/波纹/证据/误伤/常驻）。
如果一章结束后只有「他们知道了更多」而没有现实状态变化，这一章不合格，重写细纲。
```

## 三、细纲

### 8. 单章细纲

```text
写 `大纲/细纲_第{N}章.md`。先读第{N-1}章正文（或一轮稿）和第{N}章旧细纲。
本章任务：{一句话}。
硬限制：{不能提前揭什么}。
细纲要写到能直接开写：场景顺序、谁主动做什么、什么阻碍、局部结果、新麻烦。
不要写成设定说明书。
```

### 9. 先审细纲再写

```text
审查第{N}-{M}章现有细纲，不要写正文。
检查：每章是否产生真实新状态、有没有重复调查、桌边聊天是否过多、角色是否突然知道不该知道的、超能力是否越界、接缝是否被写成测谎、姜霁是否变成超能力侦探、普通人是否工具化、陈骁案/02:17/芽案是否过早给答案、有没有章节编号进入对白、有没有 AI 式总结、是否与后期硬约束冲突。
输出「结构问题清单 + 推荐修改方案」，然后直接修细纲，不要问我是否修改。
```

### 10. 一轮稿对照细纲

```text
第{N}章已有一轮稿。先对照细纲和 001-050 已定事实，判断：细纲过时、一轮稿过时、还是两者都要改。
原则：001-050 与 100-103 的活动正文高于细纲；051-099 一轮稿不得覆盖 001-050。
只输出判断和修订后的细纲，先不写正文。
```

## 四、写正文

### 11. 写下一章（默认）

```text
写第{N}章正文。先读：第{N-1}章正文、第{N}章细纲、卷纲相关段、本章出场角色卡、追踪/上下文.md。
只写这一章。写完落盘到 `正文/第{N}章_{章名}.md`。
同一轮内立刻去 AI 味自检（能跑 node 就跑 check-ai-patterns.js --check --fail-on=blocking）。
章后短报：修改/新写了什么、为什么、留下了什么悬念、本章解决了什么、制造了什么新问题、人物状态变了什么、普通人生活变了什么、证据链增加了什么、哪些仍未知。
如果只有「他们知道了更多」，回炉本章。
```

### 12. 按五章一批写 / 重写

```text
施工批次：第{N}-{N+4}章。不要一口气写到 100 章。
Step 1 阅读上一章正文、本批细纲、卷纲、相关角色与伏笔。
Step 2 先做连续性审查，输出本批结构问题。
Step 3 有正文则二轮重写，只有细纲则先修细纲再写正文。
Step 4 每章写完做章后检查再进入下一章。
本批完成后做统一连续性复查。tracking 只读，不要跑 tracking 脚本。
```

### 13. 只写 1 章，逐章确认

```text
只写第{N}章，写完停止，等我确认后再写下一章。
不要预写第{N+1}章。
```

### 14. 日更续写（有正文之后）

```text
日更续写第{N}章起，本轮最多 {2或3} 章。
每章写前：读上下文、细纲、文风卡；检查上一章去味欠账。
串行写，不要并发多章。
写完给进度摘要和下一批从哪一章开始。
```

### 15. 写正文时的场面要求

```text
本章必须同时有：都市熟人生活、至少一个阻碍或危险、镜辞（或在场主角）的主动选择、局部结果、一个更大的新问题。
禁止连续两章只问人、查资料、做记录。
禁止用哲学讨论替代人物选择。
镜辞不能当验真设备。镜返必须带来信息，也必须带来暴露或代价。
```

### 16. 从一轮稿改二轮（当前 051 起）

```text
二轮重写第{N}章。一轮稿在 `正文/第{N}章_*.md`，细纲在 `大纲/细纲_第{N}章.md`。
继承世界观、人物、八卷结构、硬约束和 001-050 已完成正文。
不要重新设计小说。不要把一轮稿里越界的能力、百科讲解、测谎式接缝带进二轮。
可保留一轮稿中仍然成立的事件骨架，但必须按当前硬约束重写句子、人物动机和认知层级。
第051-065 的核心是反调查：镜辞从「提供答案」转为「不知道，不是通过」。要有追踪、诱饵、反监听或被送样本，不要写成客服流程课。
```

## 五、回炉与局部修改

### 17. 指定章回炉

```text
回炉第{N}章。先读本章、前一章、后一章、细纲、相关角色卡。
问题是：{具体问题}。
先说明改哪几处、为什么，然后直接改正文。
不要顺手改设定源。不要扩写无关段落。
改完检查与前后章衔接，并短报悬念是否还在。
```

### 18. 只改一个场面

```text
只改第{N}章里「{场面关键词}」这一段。其他段落不要动，除非衔接句必须改。
目标：{例如：让五金店老板有自己的脾气；删掉主题总结；接缝不要写成测谎}。
```

### 19. 连续性错误定点修补

```text
不要重写整章。只修第{N}章里与硬约束或已发生事实冲突的句子。
冲突是：{例如：正文写了「第006章」；姜霁看了接缝；宣布临江陈骁是壳}。
列出原句和改句。能局部改就不整章回炉。
```

### 20. 批量润色但不改情节

```text
润色第{N}-{M}章：只改句子节奏、重复词、碎句、作者解释，不改情节事实、人物决定和证据结论。
如果发现必须改情节才能成立，停下来列问题，不要偷偷改剧情。
```

## 六、去AI味与文风

### 21. 去AI味（默认）

```text
对第{N}章跑去AI味。读 `设定/都市异能正文风格卡.md`。
重点清：连续碎句、作者解释角色刚刚成长了、角色替作者总结主题、万能对仗金句、所有人主动送线索、组织百科。
能跑 node 就执行 check-ai-patterns.js --check --fail-on=blocking，然后改到 blocking 清零。
本章不要跳过去味。
```

### 22. 本章不去味（必须你显式说）

```text
第{N}章不去味。在标题行下加 `<!-- 去味:跳过 -->`。其他章不受影响。
```

### 23. 文风专项：碎句 / 主题论文 / NPC 工具化

```text
只查第{N}章的文风三类问题并改：
1. 连续单词成段的碎句；
2. 角色或旁白发表「记忆不是人」「关系才决定存在」这类论文；
3. 普通人一见主角就变成证据供应商。
改完保留情节，只改写法。
```

### 24. 对话专项

```text
重写第{N}章对话。对话要抢信息、控制权、推责任，不要互相教学。
每人有自己的利益：房租、药、班次、物业费、怕担责。
不要让所有人说话都像调查员。
```

## 七、审查：连续性、伏笔、故事性

### 25. 写前连续性审查（先审后写）

```text
现在不要写正文。输出《第{N}-{M}章施工前连续性审查》：
当前剧情状态、每章任务、结构漏洞、与后期硬约束冲突、必须保留的悬念、需要增强的小人物、需要避免的能力越界、推荐修改方案。
审完后直接按方案修第{N}章，不要停下来问我同不同意。
```

### 26. 查伏笔（当前视图）

```text
查伏笔，范围：第{N}章 或 第{A}-{B}章。
读 `大纲/伏笔总表.md` 和 `追踪/伏笔.md`。
对每条给出：规划首埋、活动正文首埋（若标「待重算」就去正文核对，不要直接引用过期字段）、本章是否触碰、是首埋/增压/变义/回收、有没有提前揭底、有没有该回收却没回收。
特别检查：F01 02:17、芽案、沈竹、周衡接缝、当前存在命名。
不要改 `_tracking-state.json`。发现正文问题时可以改正文或细纲。
```

### 27. 只查「有没有提前揭底」

```text
只检查第{N}-{M}章有没有提前结算后期答案。
禁止提前：沈竹现身或确认生还；原芽生死；第五式；姜霁记忆差分；白壳完整新主体证明；02:17 成因；宁州/临江陈骁谁是壳；组织百科；第8卷陌生人=芽。
列出越界句和应改成什么。越界就改正文。
```

### 28. 回看故事性

```text
从读者视角回看第{N}-{M}章，不要先谈设定。
回答：
1. 读者跟着追的那个问题有没有换过？还是一直在重复「这人有点不对」？
2. 每章有没有一个具体的新麻烦（门打不开、生意没了、权限被覆盖、有人先走了）？
3. 有没有人做了不可逆的选择？
4. 悬念是「好奇设定」还是「担心具体的人」？
5. 哪一章可以删而不影响故事？为什么？
先给判断和证据，再给最小修改方案。我确认后你再改。
```

### 29. 认知升级审查

```text
审查第{A}-{B}章是否完成认知升级，而不是重复验假人。
按 L0 熟悉感异常 → L1 证据边界 → L2 身份制度 → L3 两个现实存在竞争同一身份位置 给每章打标签。
指出高原期、层级透支、调查动作形状重复、接缝目击通胀。
制度层必须有肉身：不能只有工单和页面，要有普通人承担可量化损失。
```

### 30. 前后衔接

```text
检查第{N}章与第{N-1}、第{N+1}章的衔接。
查：时间是否接得上、人物位置、已公开信息、未收回的钩子、重复解释、上一章决定有没有下落。
只改衔接破裂的地方。
```

### 31. 多视角审查

```text
对第{N}-{M}章做 /story-review。本环境按 solo 降级。
用番茄/网文读者视角：追不追、卡不卡、有没有验尸感、主角有没有代理权、章尾要不要点下一章。
输出：结论分数、S2 以上问题清单、每条的 location / evidence / issue / fix。
先不要直接改，等我选要修哪几条。
```

### 32. 黄金三章 / 开篇复查

```text
只审第001-003章（或第{N}-{N+2}章开篇）。

## 八、人物、能力、主题

### 34. 角色状态核对

```

### 35. 小人物专项

```text
审查第{N}-{M}章小人物。
五种功能：窗口、波纹、证据、误伤、常驻。波纹型当场不得再兼任证据型。
制度层旗舰案之前必须先有误伤和波纹。主角造成的现实成本必须可追责（署名、联系方式，或当场挨骂）。
列出工具化人物和最小改法，然后直接改。
```

### 36. 能力越界专项

```text
只查能力越界：镜返是否超出第一式；铭心是否被写成读心；接缝是否当测谎；姜霁/顾横/猫眼是否觉醒。
列出原句，改为合法观察或调查动作。
```

### 37. 主题不要说出来

```text
第{N}章主题只能用动作和选择证明，不要让人物说出来。
删掉或改写所有「记忆不是人」「关系才决定存在」「系统没有权利定义一个人」。
改完后故事结论仍要能被读者自己推出来。
```

### 38. 反派不要降级成怪物

```text
检查 `{人物}` 有没有被写成阴笑、灭口、承认阴谋、突然邪恶人格。
即使最终可能是壳，现在也必须有自己的需要、恐惧、困惑，甚至真心认为「我就是这个人」。
只改越界段落。
```

### 39. 感情线 / 人物关系

```text
检查第{N}-{M}章镜辞与 `{当前存在/姜霁/芽}` 的关系有没有工具化。
芽必须有自己的行动和因果，不能只为推动镜辞成长。
姜霁的价值是她看见镜辞看不见的问题，不是当女主技能包。
列出越界并改。
```

### 45. 卡壳（写不下去）

```text

```

## 十一、组合拳（整段流程一次说清）

下面几条适合「我现在就要开工」时整段复制。

### A. 写下一章的完整流程

```text
贴上「〇、每次必贴」，然后：

任务：二轮重写第051章。
1. 恢复检查，读上下文、050正文、051细纲与一轮稿、051-065卷纲段。
2. 先输出 10 行连续性审查（继承什么、禁止揭什么、一轮稿哪些越界）。
3. 直接重写 051 正文并落盘。
4. 去味自检。
5. 章后短报：改了什么、为什么、留下什么悬念、新的现实状态是什么。
6. 停止，等我看过再写 052。
不要跑 tracking 脚本，不要改设定源。
```

### B. 修某一章的完整流程

```text
任务：修正第{N}章。问题：{一句话}。
1. 读本章及前后章、细纲、对应硬约束。
2. 先给「问题 / 证据 / 改法」，然后直接改。
3. 去味。
4. 检查伏笔有没有被改丢，检查有没有新的越界。
5. 短报。不要扩散到其他章。
```

### C. 查完再决定写不写

```text
任务：准备写第{N}章，但先查。
依次做完再停：恢复上下文 → 细纲审查 → 伏笔触碰检查 → 能力与人物越界预检 → 给出「可以开写 / 必须先改细纲」。
如果必须先改细纲，直接改细纲，不要写正文。
如果可以开写，不要自动开写，等我说「写」。
```

### D. 五章批次收工复查

```text
第{N}-{M}章本批写完。做统一连续性复查，不要开下一批。
查：章间衔接、重复调查、认知是否停在同一层、小人物代价、伏笔有无提前揭底、文风三类病、元叙事穿帮、与 100-103 接口。
只改复查出来的问题。最后给本批是否可提交的判断。未经我说「提交」，不要 git commit。
```

### E. 我要看故事好不好，不要看设定全不全

```text
用普通追更读者的标准读第{N}-{M}章。
禁止先谈三层存在、刻痕、EX。
只谈：想不想点下一章、怕的是谁、讨厌的是谁、哪一段在原地踏步、哪一句假。
每条问题必须引用原文。给「删 / 并 / 改场面」三种最小处方。先不改文件。
```
