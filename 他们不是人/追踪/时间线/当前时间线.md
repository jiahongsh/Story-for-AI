# 当前时间线（第二轮活动正文基线）

> 当前活动正文分成两个已兑现时间段：**第001-011章** 与 **第100-103章**。第012-099章仍只有细纲规划，不能作为已经发生的时间线事实。
>
> 第一段使用正文能够明确推出的相对日序，不擅自补具体年月日。

---

## 第一段：第001-011章

### 第1日

**第001章《钟表行的客人》**
- 早晨，镜辞在旧市场钟表行工作，芽带早餐来。
- 镜辞第一次记录“先喝汤 / 缺口朝外”的关系习惯错位。
- 旧怀表孤立地前跳一格，原因未知。

**第002章前半**
- 当晚，镜辞翻七年前旧视频，确认过去芽确实长期存在相同早餐习惯。

### 第2日

**第002章后半《先喝汤》**
- 次日早晨，镜辞在早餐铺复现条件。
- 芽在察觉镜辞视线后才转开缺口，两人的观察从单向开始变成双向。

### 第3日

**第003章《光在发抖》**
- 正文明示“第三天”。
- 傍晚下雨，镜辞因正常取挂钟工作进入东桥巷。
- 他第一次稳定看到芽耳后至颈侧接缝；手机无法稳定拍清。
- 芽察觉有人长时间观察，但没有精准锁定镜辞位置。
- 当晚镜辞记录异常；怀表保持停止，未与接缝建立因果。

### 第4日

**第004章《不是只有她》**
- 镜辞在旧市场观察其他人，先排除一次普通反光误判。
- 中午前后，灰衬衫以“周远”身份送修石英表，镜辞第二次确认相似接缝存在于陌生人身上。
- 下午/傍晚，镜辞试探守钟人，得到“别急着命名、别一直盯”的有限警告。

### 第5日

**第005章《她也在看我》**
- 芽来钟表行，已明显知道镜辞在测试自己。
- 新事故中她先护住沈竹怀表盒，再处理镜辞手伤；镜辞明确记录“新情境，不设答案”。
- 双方正式进入互相观察状态。

### 第6日

**第006章《两个周远》**
- 14:12左右，灰衬衫以周远身份取走石英表。
- 15:09之后，宁州周远因支付异常联系钟表行，并通过实时工作现场、同事与旧照片形成独立来源。
- 14:13这个时间点形成明确冲突：临江与宁州各有一个同时可验证的“周远”。
- 当晚芽邀请镜辞吃饭。

**第007章《摊牌》**
- 同日晚间，镜辞带两个周远的证据与当前存在摊牌。
- 当前存在明确承认自己不是镜辞从小认识的原芽。
- 她给出北河地点记忆，并决定独自调查。

### 第7日

**第008章《不是她的过去》**
- 次日上午，两人通过七年前烧锅旧事确认：真实共同经历也会产生互相冲突的不完整记忆。
- 下午，当前存在自行前往北河。
- 回到旧市场后，镜辞保存三个版本；灰衬衫再次出现并准确知道她已经去了北河。

**第009章《他们不是人》前半**
- 承接第008章章尾，灰衬衫在钟表行与镜辞正面试探。
- 镜辞通过打开卷帘门、引来摊主与监控制造公开见证。
- 灰衬衫离开前预告：见证者第二天未必仍记得“同一个他”。

### 第8日

**第009章章尾 / 第010章《三个版本》**
- 早晨，老陈对灰衬衫衣着和离开方向的记忆已经漂移。
- 当天镜辞继续回访水果摊老板、赵奶奶并核对监控。
- 下午购买硬壳账本，建立“先把不同版本留下”的方法。
- 晚上约19:00，当前存在已经抵达北河县并发送定位。
- 宁州周远通过警方继续追查临江取表者。

### 第9日

**第011章《两页名字》**
- 早上约09:00，镜辞重新整理“芽”相关记录，正式拆成 `原芽` 与 `当前存在` 两页。
- 当前存在此时已经在北河，名字仍未确定，并明确北河调查不是替镜辞跑腿。
- 中午，镜辞重新取出沈竹怀表，只完成整表/后盖拍照、旧维修记录整理和录像准备，尚未开盖。

## 第二段：第100-103章

### 第100章

- 早上：镜辞在旧市场修表并与猫眼整理周衡资料。
- 中午前后：周衡进入市场，与多名熟人自然互动；镜辞再次短暂看到接缝。
- 晚上：姜霁通知次日清晨前往临江市第二医院。

### 第101章

- 05:58左右：镜辞抵达临江市第二医院，赵闻川身份争议爆发。
- 02:17的上游日志被发现：系统撤销赵闻川死亡状态，恢复身份连续性。
- 医疗救治与身份争议被明确分离处理。

### 第102章

- 07:23左右：许宁手术结束，暂时稳定，转重症监护。
- 上午：医院确认赵闻川旧死亡链编号存在；同时确认死后十一个月的多条连续记录在02:17批量进入本院。
- 调查转向阳台北窗这一可留下独立物理痕迹的事件。

### 第103章

- 11:02左右：进入许宁住所核验阳台维修。
- 随后：纸质物业联、物理维修痕迹与双方叙事被并行保存。
- 进一步调取不联网的电梯维保录像。
- 关键发现：身份恢复前二十一天，赵闻川已出现在楼内。
