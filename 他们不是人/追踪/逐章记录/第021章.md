# 第021章 · 白塔的清道夫，比他们先到了
- 结果：守钟人燃炉备油助镜辞砸直弯锤并加焊钢倒钩，撬开工作钢牌夹层现出西北废变电室三十米暗井路线；姜霁算清四十八发银弹立约共行。三人潜入井底十米铁梁时撞见白塔银边半机械队长严彻率三犬往门上焊高爆封井雷，一滴血水意外砸中严彻铜甲惊动抬头。

  - 下章紧接：严彻发现梁影瞬间击发版本消磁短杖并放出三头铜牙犬围攻；镜辞死按最后三格怀表一格不耗，用废变电绝缘油膜加枪火反光硬盯三秒照缝破开减震甲死角斩杀严彻，从其遗言与挂尸墙惊悉井下惨变

- 守钟人｜核心｜强扛伤势拉炉递淬冷黑油与老火药饼助镜辞重锻升级重锤，继续留守东巷镇护参号
- 镜辞｜核心｜烧直重铜锤并焊妥三寸淬火钢倒钩，剥出焦牌夹层冷井图率人渗下三十米竖井，在滴血惊敌时摁死三格怀表待扑
- 姜霁｜核心｜核清仅余两匣四十八发银弹划明查白塔兼防壳缝底线，断后抹踪并带领全员灭灯压近井底焊点
- 芽｜核心｜收好火药饼率先翻高窗排险并抢占十米横梁摸清焊门敌情，破袖滴落血水意外惊动严彻仰头
- 严彻｜临时｜率工兵与三头铜牙改造机械犬提前往零号排废闸门死焊五分钟高爆封井雷，突感胸甲落血仰头察觉梁影
