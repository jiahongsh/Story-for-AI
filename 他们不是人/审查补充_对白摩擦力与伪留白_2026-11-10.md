## 4. 新增检测维度（建议 Gate H：零摩擦对白 / 伪留白）

三个可测特征，任一超阈值即标记，**不得据此自动改写**：

| 特征 | 建议阈值 | 本次实测 |
|---|---|---|
| 单章 ≤8 字对白占比 | > 65% 标记，> 80% 重点 | 001/004/007/010/012/100 超 75% |
| 单章带摩擦力对白占比 | < 10% 标记 | 001 3.4%、004/012 0%、007 1.8% |
| 连续 ≥5 句完整收尾短对白串 | 出现即标记 | 全书 16 章，001/007/009/011/100/101 达 6 句 |
| 单章完整收尾率 | > 98% 且对话 ≥10 句 | 全书 99.6% |

**判定必须看密度，不看单句**。删除个别漂亮短句反而会把书写平；正确动作是**在乒乓串里掺入毛边**（重复、被打断、跑题、语气词、动作挤进台词中间），让节奏不齐。

暂不并入 `skills/story-deslop/scripts/`：上一轮已发现 skill 自带版与项目版 `check-ai-patterns.js` 字节不同（`21ba950e…` vs `17ef45f0…`），且 `banned-words.md` 要求「同名副本×6 字节同步」。**先跑同步再谈并入**，否则又造一份不同步副本。可复现统计口径见附录。

## 附录｜可复现统计口径

```python
# 在 他们不是人/正文/ 下运行；只统计以中文引号开头的独立对白段
import re, pathlib
FRICTION = ['吧','啊','呢','嘛','哦','诶','喂','呀','啦','咯','呗','嗯','哈','啧','哎','……','—','！']
for f in sorted(pathlib.Path('.').glob('*.md')):
    L = [x.strip() for x in f.read_text(encoding='utf-8').splitlines()
         if x.strip() and not x.startswith('#')]
    d = [m.group(1) for l in L if (m := re.match(r'“([^”]*)”', l))]
    if len(d) < 10: continue
    short = sum(len(s) <= 8 for s in d) / len(d)
    fric  = sum(any(w in s for w in FRICTION) or s.endswith(('，','、')) for s in d) / len(d)
    closed= sum(s.endswith(('。','？','！')) for s in d) / len(d)
    print(f.name[:12], round(short*100,1), round(fric*100,1), round(closed*100,1))
```
