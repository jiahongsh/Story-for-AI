# 第037章 临江七周

本地陈骁本来约好下午去物业。

结果没来。

镜辞等了二十分钟。

姜霁先收到消息。

【配送站出事。】

两人赶到西城时，一辆小货车斜停在门口。

后轮瘪了。

货箱门开着。

地上散了两个破纸箱。

昨天借钱那个年轻同事蹲在旁边，脸色发白。

本地陈骁正拿千斤顶顶车。

“不是让你下午过来？”

镜辞走过去。

“你看不见？”

男人头都没抬。

“车坏了。”

“别人不能换？”

“能。”

“那你——”

“他今天本来替我跑。”

本地陈骁朝年轻人抬了下下巴。

“他妈又住院了。”

年轻人低声骂了一句。

“不是住院，复查。”

“差不多。”

“差很多。”

“那你自己来修。”

年轻人立刻闭嘴。

镜辞看懂了。

三周前，本地陈骁替这人垫急诊费。

同事后来给他换过一周早班。

今天这人母亲复查，本地陈骁又接了他的配送。

一件事已经长出了第二层后果。

不是一条历史记录躺在那里等人核验。

是现在还在继续。

姜霁没有打断。

只站到不碍事的位置。

十分钟后，备胎装好。

本地陈骁站起来，手上全是黑灰。

“去物业？”

“不去了。”

“为什么？”

“我得把这趟送完。”

镜辞有点烦。

“你不是想证明你这七周是真活的？”

本地陈骁笑了一下。

“所以呢？”

“所以你现在该配合我们查。”

“我配合你们，客户那边的货谁送？”

“换个人。”

“刚才你还问别人能不能换。”

镜辞被堵住。

男人把货箱重新关上。

“我不是每天坐这儿等你们鉴定。”

这句话比昨天那句更刺。

姜霁终于开口。

“晚上几点回来？”

“八点后。”

“那八点再核。”

“行。”

她没逼。

镜辞也没再说。

货车开走。

年轻同事站门口看了一会儿。

“你们到底查他什么？”

“身份问题。”

姜霁只给四个字。

“犯法了？”

“还不能这么说。”

“那别把人当犯人查。”

年轻人脸色不好。

“他刚来这边的时候是挺怪。”

镜辞立刻抬眼。

“哪里怪？”

“什么都自己干。”

“别人帮他搬货都不习惯。”

“后来呢？”

“后来被老马骂呗。”

年轻人扯了下嘴角。

“有次我搬箱子砸脚，他先笑我，然后帮我顶了半天班。”

“这种算不算你们要查的？”

镜辞没回答。

姜霁记了一行。

**关系不是一开始就自然。七周内形成。**

晚上八点二十。

本地陈骁回到配送站。

脸上更脏了。

第一句话就是：“你们还真等。”

“你不是让八点来？”

“我客气一下。”

“我们不太会客气。”

姜霁把白天新增的情况给他看。

不是偷偷调查。

是让他知道他们记录了什么。

男人看见“同事母亲复查”“替班配送”时皱眉。

“这个也算？”

“算事实。”

“算身份吗？”

“不直接算。”

“那有什么用？”

姜霁抬眼。

“证明你今天做过什么。”

本地陈骁没说话。

镜辞接了一句。

“以及别人因为你做的事，今天怎么选。”

男人看向他。

“这不就够了？”

镜辞知道他问的不是今天。

“够证明你最近在临江活过。”

“还是不够证明我是陈骁。”

“对。”

本地陈骁笑了一声。

很冷。

“你们这套东西真方便。”

“我做坏事，说我不是原来的陈骁。”

“我做好事，也只算‘最近活过’。”

“那我要怎么样才算？”

镜辞张了张嘴。

没答案。

男人靠着车门。

“我知道我爸四年前换过锁。”

镜辞目光一凝。

“你怎么知道？”

“他自己说过。”

“什么时候？”

“忘了。”

“聊天记录呢？”

“删了。”

“照片？”

“没有。”

“谁能证明？”

本地陈骁脸色一下难看。

“看。”

“又来了。”

“只要我说一件你们暂时找不到外部来源的事，就像我在背答案。”

镜辞没反驳。

因为这正是他刚才的反应。

男人拉开车门。

“你们要查就查。”

“但有件事别弄反。”

“什么？”

“我这七周不是为了证明给你们看的。”

他上车。

“我本来就在过。”

车开走以后，镜辞站在原地。

姜霁收起本子。

“你刚才不舒服？”

“没有。”

“你不愿意把他今天帮同事送货记进去。”

“记了。”

“我说的是第一反应。”

镜辞皱眉。

她没继续拆他。

只是把那页翻过去。

“明天查宁州。”

镜辞看着远处的车尾灯。

本地陈骁可能占用了别人的旧身份。

这件事还没变。

但他今天替一个同事跑了趟货。

那个同事也因此陪母亲做完复查。

这件事同样没法删掉。

麻烦就在这里。

人可以来路有问题。

可他今天造成的后果，不会因为来路有问题就自动变成假的。
