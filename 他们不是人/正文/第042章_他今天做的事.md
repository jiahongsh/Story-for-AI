# 第042章 他今天做的事

第二天下雨。

本地陈骁没进六号楼。

门禁还冻着。

他站在物业棚外等人。

手里一把折叠伞。

昨天下午那个自行车掉链子的小孩先认出他。

“叔叔！”

孩子从奶奶伞底下探头。

本地陈骁抬了下手。

老太太也认出来。

“你来找陈老头？”

“嗯。”

“他下楼买菜去了。”

“我等会儿。”

老太太看了眼雨。

又看他手里那把漏水似的破伞。

“你昨天帮乐乐修车，今天这伞就别撑了。”

她转头让孩子跑回去。

两分钟后，小孩抱下来一把长柄伞。

“我奶奶说借你。”

本地陈骁愣了一下。

“我不用。”

“她说不借就还车链钱。”

男人看着孩子。

最后接了。

“那我等会儿还。”

镜辞和姜霁刚好从路口过来。

整件事没超过三分钟。

却已经形成了昨天那件小事的后果。

他帮孩子修车。

今天孩子家愿意把一把伞交给他。

不是认他是陈启明的儿子。

甚至不关心他到底是谁。

只是因为昨天那个人蹲在台阶边，手上沾了链条油。

姜霁看了一眼镜辞。

“记吗？”

“记。”

“这次挺快。”

“你烦不烦。”

本地陈骁听见了。

“你们还真把我每件事都记？”

“不是每件。”

镜辞低头写。

“会产生后续的。”

“那我今天中午吃面算不算？”

“除非老板因此把店卖给你。”

本地陈骁扯了下嘴角。

“总算会开点玩笑。”

陈启明十分钟后回来。

看见本地陈骁，脚步就慢了。

“不是说公共场所？”

“这里是物业门口。”

“你等我干吗？”

“给你这个。”

本地陈骁从包里拿出一盒药。

陈启明脸立刻沉下去。

“不要。”

“你以前吃的那款停产了。”

“我有医生。”

“这不是给你吃的。”

男人把盒子翻过来。

里面是旧药包装。

“我昨天在行李里翻到的。”

“应该是以前家里剩的。”

陈启明看了一眼。

没接。

“你想证明什么？”

“没想证明。”

“那你拿来干吗？”

“你总问我过去。”

“我就把我有的东西拿出来。”

老人盯了半天。

最后还是没接。

“放物业。”

“行。”

这次本地陈骁没有硬递。

他把盒子交给杜经理。

陈启明转身要走。

镜辞叫住他。

“陈叔，昨天自行车那件事——”

“我听说了。”

“您怎么看？”

老人回头，脸色很难看。

“看什么？”

“他帮别人是他的事。”

“别拿这个劝我认儿子。”

镜辞顿了一下。

“没打算劝。”

“那最好。”

“我只想确认，这件事和父子关系分开记，您没意见？”

陈启明看了他两秒。

“他干了就记。”

“但别写成‘因为他是我儿子所以帮人’。”

“不会。”

“也别写成‘他帮了人所以就是我儿子’。”

“也不会。”

老人点头。

“那随你们。”

这句话其实很重要。

至少镜辞觉得重要。

一个存在今天做了真实的事。

陈启明承认那件事发生过。

但拒绝让它自动进入父子关系。

两层第一次被分得这么清楚。

下午，那个孩子的奶奶又来物业。

不是来作证。

是来还伞。

本地陈骁已经走了。

老太太把伞放柜台。

“等他来给他。”

杜经理随口问：“您不怕他？”

“怕什么？”

“最近502那事闹得挺大。”

老太太摆摆手。

“他们家的事我不管。”

“我只知道昨天乐乐摔车，他帮了忙。”

“伞是借给昨天帮忙那个人的。”

说完就走。

镜辞站在旁边。

这句话比“我相信他是陈骁”有用得多。

因为她没有替本地陈骁背整个身份。

只对自己经历的那一点负责。

镜辞回钟表行后，把本地陈骁那页重新整理。

原来只有：

**身份异常观察。**

**临江近期生活来源。**

他又加了一栏。

**当前可确认行为及后果。**

下面第一条：

**修复住户孩子自行车链条 → 次日孩子家主动借伞。**

第二条：

**此前替同事接配送 → 同事得以陪母亲复查。**

写完以后，他盯着页面。

第011章时，他给当前存在拆过一页。

原芽过去。

当前存在后来做的事。

那时候他觉得自己是在尊重“不是原芽”的边界。

轮到本地陈骁，他却一直把人压在“疑似身份异常”下面。

因为他更不喜欢这个人。

也更怀疑这个人占了别人的位置。

立场一换，记录方法居然也跟着歪。

镜辞很不喜欢这个发现。

猫眼的消息就在这时弹出来。

【安平里又更新了。】

她发来两个版本。

旧版：

**九年前迁往外地 / 长期不在本址。**

新版：

**长期外地工作 / 近期返临恢复常住。**

旁边甚至多了一条自动说明：

**家庭关系持续有效。**

镜辞看着那句“近期返临”。

现实里，本地陈骁这七周确实在临江生活。

系统却在干另一件事。

它不是记录这七周。

它在把这七周往前接。

像这人从来只是外出工作，现在顺理成章回家。

一个刚刚还开放着的争议，正在被写成越来越顺的一条故事。
