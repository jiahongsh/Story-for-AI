# 第55章 树皮

镜辞天亮拉开窗帘。

窗外没有人。窗台下那小块土还在，印子浅，还认得出来。他看了它一眼，没有多看，下楼，出摊。

市场刚醒。卖菜的推着板车进场，铁轮子碾过砖地，哐当哐当。卖早饭的支起棚子，蒸气白茫茫地漫过来。镜辞把工具照旧铺开，马扎摆正，灯从摊板底下拖出来。阳光从顶棚的缝里落下来，刚好照着工作台。把放大镜也摆上，擦了擦镜片。镜片是守钟人给的，旧了，边角有一道细痕，不影响看。抬头看了一眼对面。

对面，收旧书的摊子空着。

蓝布捆成一卷，靠墙根堆着，上头压了块砖。砖是红的，有一角缺了，是它搬来压布的。它没来。

镜辞拆开一块座钟的机芯，上油，调擒纵叉。手很稳。修到第三块的时候，他抬头看了一眼对面，那格空位还是空的。市场里人来人往，卖菜的吆喝，买菜的挑拣，只有那一格，空的。空得他每次抬头，都像看见一个洞。

想起昨天，它坐到摊板前一臂的地方，问"表，在走吗"。今天，那格空了。它不在，比它在更难熬。它在，知道它在哪儿；它不在，不知道它去了哪儿，也不知道它什么时候会回来，会不会回来。修了三块钟，抬头看了七次。每一次，那格都是空的。连那卷蓝布，都像是走了。

修完第三块钟，把它挂到摊板边上的钉子上。钟摆一下一下地走，走得心烦。伸手，把钟摆按住，停了两秒，又松开。钟摆接着走。忽然想，表也是这样吗？按住了，还会走；不按，也一直在走。

中午，卖咸菜的老太从对面走过，朝那格空位看了一眼。

"收书的今儿没来？"

"嗯。"

"少见。"

她说完，走了。镜辞没接话。他知道，它不来，才是真的少见。

低头，继续磨手里的零件。磨着磨着，又抬头看了一眼对面。那格空着，空得心口发慌。放下锉刀，走过去，蹲在蓝布旁边。布卷得很齐，边角压得平整，是它自己卷的。伸手，碰了一下布角。布是凉的。它把摊子收得干干净净，像是把这一格，从市场里取走了。

午后。日头偏西的时候，镜辞低头磨一个零件，磨到一半，手里的锉刀停了。他抬起头。

它站在市场入口。

隔着半个市场。它站得远远的，一直站着，像在确认镜辞还在这里。人群从它身边走过去，没人看它，它也不看他们。它只看镜辞。呼吸停了一拍。隔着半个市场，隔着人群、车板、蒸气，和它隔着那些东西对望。它的目光落在手上，又落在脸上，像是在找什么。找了一圈，没有找到，它就转身了。

站了很久。久到镜辞以为它会走过来，像前几回那样，搬凳子，或者站到他摊板旁边。它没有。它站着，看了他一会儿，转身，走了。

镜辞举起放大镜，隔着人群，读它。

伪装度，34。

昨天35。前天36。它在掉，掉得不算快，但没停过。接缝已经爬到后颈，再往下，就要进衣领里了。衣领底下是什么，镜辞不知道。他只知道，它身上那块露出来的地方，越来越多了。它走的时候，背影比昨天驼了一点，像是压着什么东西，背不起来了。他想起守钟人的话，掉完之前，要么等到，要么换法子。它已经在换了。换到连跟都不跟了。镜辞看着那个背影，直到它混进人群，一点一点小下去，拐过街角，看不见了。

镜辞放下放大镜，把手里的零件搁回台面。他坐了一会儿，没动。市场照常流动，卖菜的、买菜的、修鞋的，谁也没觉得少了什么。只有他，觉得那格空了。

傍晚，猫眼绕过来，压低声音："有个人，在市场上打听你。"

镜辞收东西的手没停。

"问你是哪儿的，家里几口人，做什么营生。不高，走路拖。"

"别管他。"

猫眼看着他，半天，说："成。你心里有数就行。"

猫眼走前，又说："你这两天上火？脸色不好。"

"没睡好。"

猫眼："那就早点睡。"

猫眼走了。镜辞把工具收进包。想起猫眼说的那个"不高，走路拖"。前天傍晚，它在窗外站了一夜。昨天，它把纸条塞进摊板底下。今天，它在市场上打听底细。它一天比一天，离得更近。镜辞不知道它要做什么。只知道，得自己扛着。

卖报纸的老头忘了他，阿婶忘了他，面馆老板记不清了。记住镜辞的人，一个比一个少。不能把猫眼也搭进去。猫眼要是忘了，这个市场里，就真的没人认得镜辞了。想起卖报纸的老头，那天晨间问"你是谁"，眼睛干净得没有一丝犹疑。那是忘了镜辞的人的眼睛。不想在猫眼眼睛里，也看见那种干净。

收摊。镜辞往家走。

走到巷口，他停下来，回头。

没有人。

路灯还没亮，巷口空着。它今天没有跟。镜辞站在原地，站了一会儿。不知道是在等它来，还是怕它来。只知道，它退回去了。它退到入口，退到门口，退到看不见的地方。它把最后一步，留给自己走了。

数着脚步，走了十步，停住，回头看。巷口空着。又走了十步，再回头。还是空的。走完了整条巷子，回了三次头。三次，都没有人。

上楼，开门，进屋，反手锁门。屋里黑着，没有开灯，在门后站了一会儿。以前，它跟到门口，还能在门后感觉到它。今天，门后头空空的，什么也没有。忽然有点想它跟来。这个念头一冒出来，自己都吓了一跳。

夜里。镜辞把《修表入门》摊开，折角页朝上。

他对照着摊板上那几样零件，一样一样认。擒纵叉，管走不稳。游丝，管快和慢。发条盒，管走多久。页边的铅笔批注很小，认真得像怕写错一个字。他认得很慢，像怕认错了，就再也回不去了。

发条盒里的发条，上足了能走一天一夜。游丝只有头发丝细，弯一点，快慢就差一分。擒纵叉咬住齿，一停一放，走得才准。修的从来是别人家的钟，别人家的表。从来没有想过，有一天，要修的是自己的那块。

认到最后，他忽然明白。

会修。一直都会。怕的，是修好的那一天。修好了，表就走了。表走了，它就没了。它等不了了，所以它退半步，把选择权压到肩上。它把教修表的书送到手边，把"你慢慢来"说给镜辞听，然后退到门口，退到入口，退到自己的选择面前。手里拿着答案，却不敢动手。

忽然想起守钟人的话，那块表不是坏了，认得它就走。认得它吗？修了三年表，修过的钟表没有一千也有八百。可那块表，只看过一次，在养母走的那天晚上。它的样子，已经记不全了。

他想起芽。

芽周三一早就上了车，去看亲戚。两天了，没有一个电话。由着她去。有些路，得她自己走。想起岭后村口那棵老槐树，树皮上浅浅的刻痕。想起那个"芽"字，横往右斜。想起那张纸条，横往右斜。想起门外站了一夜的那个影子，不高，走路拖着地。分不清，门口那个影子，和芽，有没有关系。不敢往那上面想。想深了，就得去开信了。

信还在。还是没拆。信放在抽屉最底下，压在树皮和纸条下面。信封的角，摸得起了毛。每天摸一遍，就是不拆。

天亮。镜辞开门。

门口台阶上，放着一片老槐树的树皮。

巴掌大，背面朝上。他蹲下去，翻过来。铅笔字，两个字。

别修。

横，往右斜。跟前天那张纸条，一样。树皮边缘，有一道很浅的旧刻痕，像很久以前，有人用小石头划过。

他直起身。余光里，巷口拐角，有个人影一闪，不见了。矮的。

没有追。蹲在原地，又看了一遍那两个字。别修。写字的人，前天夜里在窗外站了一夜。今天，把话写到了家门口。连镜辞住在哪一栋、哪一层，都知道了。

把树皮举到太阳底下。光透过树皮，边缘那圈旧刻痕更深了，像一条浅沟，长在树皮上。不知道这是谁刻的，也不知道刻的是什么。只知道，刻痕比那两个字，旧得多。

忽然觉得，写字的人，写了两遍"别修"。第一遍，塞在摊板底下，是叫他别在市场修。第二遍，放在家门口，是叫连在家都别修。这个人，怕想修，怕得厉害。

镜辞拿着树皮，站起来，拍了拍膝盖上的土，转身回屋。

把树皮和纸条叠在一起，放回抽屉。抽屉里，还是三样东西。一样教修。一样叫别修。一样，等着打开。
