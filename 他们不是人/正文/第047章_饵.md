# 第47章 饵

周四早上，镜辞比平时早到了半个钟头。

市场还没有全醒。卖菜的刚卸完货，早点摊的油锅冒着烟，蓝布摊子一家一家支起来。他把卷帘门拉上去，把油桶从角落挪出来。

他掀开桶盖。

桶是空的。

他蹲下去，把守钟人给的那块旧怀表放进去。黄铜壳，表盘磨花了，普通得扔进旧货堆里没人会多看一眼。他合上桶盖，拍了拍，把油桶推回角落。

他摸了摸胸口。

钥匙在。

他坐下来，把修表的家什摊开。改锥，镊子，油壶，擦布，一样一样摆好。他今天不打算修什么大活，就守着摊子。

守钟人说，等它来。

上午九点刚过，市场热闹起来。卖瓷器的在吆喝，收破烂的推着板车经过，几个老太太围着菜摊挑挑拣拣。早点摊的老板娘掀开蒸笼，白气腾起来，夹着面香。镜辞低头擦一块表蒙子，擦着擦着，他停住了。

对面，收旧书的摊子，今天没有支起来。

蓝布还捆着，堆在墙根。那个位置空着。

镜辞看了两眼，低下头，继续擦。

他不确定这是好事还是坏事。

他想起猫眼说过的话。卖瓷器的说没换过，修鞋的说老张回老家了，侄子接的摊。他想起修鞋的说话时眼睛盯着自己的鞋，眼神发直。

他把表蒙子放下，端起水杯。

水是凉的。

他坐在摊子后面，看着对面那个空位置，看了一会儿。

九点半，那个位置还是空的。

十点，早点摊收了，卖菜的也走了大半。

十点半。

一个中年人从市场后门走进来。不高，腰板直，头发齐整。他手里抱着一座钟，走到自己摊子前，把蓝布解开，支起来，把钟放在蓝布上，然后坐下。

他没有马上到镜辞这边来。

他坐下之后，先抬头，往市场里看了一圈。

那一圈，看得很慢。

然后他低下头，开始翻书。

镜辞收回目光，继续擦表蒙子。

他擦得很慢。

他知道，会来的。

快到中午的时候，人少了一些。镜辞把擦好的表蒙子放回盒子里，正要起身去灌水，一个人走到他摊子前。

那个人不高，腰板直，头发齐整。他手里抱着一座钟。

钟不大，木壳，灰扑扑的。他把钟放在柜台上。

"修吗？"

镜辞看了他一眼。

颧骨的位置，有一道缝。

缝里有光。

他读到了一行字。还是那行字：Lv.1 侵蚀壳·伪装度45·接缝:稳定。

镜辞没有停。他拿起那座钟，翻过来，看底下的铭牌。牌子磨得看不清字了。他打开后盖，机芯露出来。

锈了。

齿轮咬死在一起，像几片叠死的铁叶子。发条松到底，轴心卡着一层青灰色的泥。

他把钟放在手里，掂了掂。座钟不重，壳是杂木的，上过漆，漆也老了。他拿改锥的尖头，轻轻点了点齿轮。齿轮不动，锈得死死的。

"修。"

那人没说话，站在柜台前面，看他看。

镜辞把后盖合上，放在柜台一边，报了价。

那人没有还价。

他从兜里掏出钱，放在柜台上。

"修好，我下午来取。"

"行。"

那人转身，走了两步，停住了。

他回过头，看着镜辞。

"修表的人，认得表么？"

镜辞的手按在钟壳上。他抬起头，也看着他。

那人脸上没有表情。那道缝，藏在他颧骨的影子里，像一道没合拢的口子。

"修好才算认得。"

那人看了他一会儿。

他没有再说话。他转身，走了。

镜辞看着他的背影，看着他走回市场对面，把那捆蓝布解开，支起摊子，坐下来，拿起一本书。

像什么都没发生过。

镜辞收回目光，把那座钟重新拿起来。

他打开后盖，用改锥轻轻撬开咬死的齿轮。轴心上的泥干了很久，像一层壳。他用镊子一点一点挑，挑出锈渣，再把油滴进去。

一滴油。

齿轮动了。

镜辞拧上后盖，把钟立起来，上满弦。

滴答。滴答。

走起来了。

他盯着那座钟看了一会儿。钟走得稳，秒针一格一格地跳。

他忽然想，它要修的，是不是也是这么一块表。

他把钟放在摊子最里面，靠着墙，让它走。然后他坐下来，把刚才拆下来的锈渣收进一个小碟子里，看了一会儿。

锈渣是青灰色的，和轴心里的泥一个颜色。

他用手指捻了捻。泥是干的，硬邦邦的，像放了很久。

座钟的机芯是国产的，老牌子，二三十年前的东西。这种机芯他见过不少，锈成这样，要么是在漏水的地方放了几年，要么是进水之后没擦，一直闷着。

它从哪儿弄来这么一座钟？

镜辞想了一会儿，没有答案。

他把它放下，开始收拾台面。

中午他没去吃饭。猫眼端着一碗面蹲过来，一边吸溜一边往对面努嘴。

"哎，他找你修钟？"

"嗯。"

"收你多少？"

"没还价。"

猫眼吸面的声音顿了一下。

"没还价？"

"嗯。"

猫眼把面咽下去，看了对面一眼，压低声音："他昨天夜里，在市场里转了一夜。"

镜辞看着他。

"我在后门那儿蹲到两点。他十一点多出来的，没往家走。先在市场办门口站了半天，站那儿不动，像听墙根。后来又去巷口，站着。"

"哪个巷口？"

"后巷那个。他站的位置，对着你的摊子。"

镜辞没说话。

"他平时夜里不出来。我在这儿五年，他以前那摊主，老张，夜里从不出门。这个新来的，头一回。"

猫眼把面吃完了，把碗放在柜台上，抹了抹嘴。

"我跟你讲，你别嫌我多嘴。这人在市场里，谁都不搭理。人家搭话，他就嗯一声。有人卖书给他，翻半天，收不收的，价都不怎么还。你说图什么？收旧书的不图价，图什么？"

"图书。"

"图书？"猫眼撇撇嘴，"图书又不值钱。"

"值钱的图书，人家早就收走了。"猫眼又说，"他收的那些，都是没人要的。"

镜辞没有说话。

他想起那本《修表入门》。折角的书页，怀表机芯的调校。

有人要的，它不碰。

它碰的，都是和表有关的。

下午两点，那人准时来了。

镜辞把修好的座钟放在柜台上。那人拿起来，没有看钟。

他看镜辞。

"多少钱。"

"说好了。"

那人没有再问。他付了钱，抱着钟，走了。

他走到自己摊子前，把钟放在蓝布上，坐下来，继续翻书。

一页，一页。

镜辞把修钟的钱收进抽屉里。

钱是真的。

傍晚，市场开始收摊。卖菜的收筐，卖瓷器的卸板，蓝布一张一张卷起来。镜辞没有马上收。他坐在摊子后面，把修表的家什一件一件收进盒子里。

收得很慢。

他把改锥、镊子、油壶收进盒子，一件一件，收得很慢。

隔壁卖杂货的已经锁了门，冲他喊了一句什么，他应了一声，没听清。

他把盒子盖好，放在柜台下面。他没有拿出来，也没有走。

他坐着，看着市场里的人越来越少。卖菜的推着空车走了，早点摊的老板娘在数钱，收破烂的把板车停在墙根，坐下来抽烟。

天边的云红了一大片。

他把卷帘门拉下来，锁好。

他没有马上走。

他站在自己摊子前面，站了一会儿，然后抬脚，往巷口走。

他走得不慢，也不快。

市场上的人已经走光了。卷帘门一扇一扇拉着，蓝布都收了。卖菜留下的菜叶子，摊在地上，被傍晚的风吹着，滚了两滚。

巷口在市场的东头。他走到巷口，停下来。

他回头看了一眼。

市场那头，收旧书的摊子已经收了。蓝布捆好，堆在墙根。那个位置空着，没有人。

但是巷口对面，墙根的阴影里，站着一个人。

远远的，看不清脸。

那人站着，不动。

镜辞站了一会儿。

他转身，走了。

他没有跑。走得不快不慢，像平常回家。走过三条街，拐进自己的巷子，掏钥匙，开门，进门。

锁门。

他站在门后，没有开灯。

黑暗里，他听见自己的心跳。

他摸了摸胸口。

钥匙在。

他走到墙角，把空油桶挪开，看油桶底下的灰。

灰上，没有脚印。

他把油桶推回去，站起来。没有开灯。靠着墙，坐下来。

黑暗里，他想着那个人站在巷口的样子。

隔着半个市场，隔着黄昏，那个人站着，不动，像在看什么，又像在等什么。

它白天来修钟，问它认得表么。

它夜里站在巷口，对着他的摊子。

它在找表。

不。

它找的是修表的人。

镜辞在黑暗里坐了很久。

他想，它要是真找到了那个修表的人，会做什么？

它会把一块表放在那个人面前，让它修。

修好之后呢？

镜辞不知道。

他想起守钟人的话。

修你的表。开你的摊。等。

等它来。

它来了。

镜辞摸了摸胸口。

钥匙在。

他忽然想，它站在巷口看我的时候，看的到底是摊子，还是脖子上的钥匙？

它要是看见钥匙，就会以为表还在这儿。

它要是以为表还在这儿，就会一直在这儿。

镜辞把钥匙从衣领里拿出来，握在手里。

钥匙是铁的，磨得发亮。他母亲的遗物。铁盒的钥匙。

他握了一会儿，又把它放回衣领里。

黑暗里，墙上的老钟走了一下。

滴答。

他没有动。

他不知道自己坐了多久。站起来时，腿已经麻了。

他走到窗边，拉开一条缝，往外看。

巷子里没有人。

路灯亮着，昏黄的光铺在地上。

他看了很久。

然后他放下窗帘，走回屋里。

躺下的时候，天快亮了。

他闭上眼睛，眼前还是那个人站在巷口的样子。

它站在那儿，不动。

像一块钟。

走也不走，停也不停。

只是站着。

镜辞翻了个身。

他想：明天，它还会来吗？
