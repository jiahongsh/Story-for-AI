# 第032章 一张填不下的表

许棠刷不开门的时候，手里还拎着两袋药。

新门禁响了一声。

红灯。

她又刷一次。

还是红灯。

302里面的许德昌已经听见动静。

“怎么了？”

“你们新系统嫌我脸熟。”

许棠把卡贴第三次。

滴。

红。

老人从屋里出来，拖鞋都没穿好。

“昨天不是还能进？”

“昨天旧系统。”

“那今天呢？”

“今天我可能突然成外人了。”

镜辞和姜霁刚到二楼。

杜经理也在后面跑上来，手里拿着平板。

“先别刷，我看看。”

他调出302住户页面。

许德昌。

户主。

常住。

紧急联系人那栏原本是许棠。

现在变成了：

**其他关系 / 长期访客。**

门禁权限：

**需住户确认。**

许德昌盯着那几个字。

“谁给改的？”

“不是人改的。”

杜经理说完自己都觉得不对劲，赶紧补一句。

“我是说，迁移规则自动分类。”

老人更烦了。

“自动就不是人干的了？”

“不是这个意思。”

许棠把药放到地上。

“能改回来吗？”

“能。”

“多久？”

“我现在就提人工修正。”

杜经理开始点页面。

镜辞没往前凑。

他先看许棠手里的东西。

降压药。

降糖药。

还有一盒老人常吃的胃药。

许德昌已经弯腰去提。

“给我。”

“你别碰，重。”

“我还能提不动两袋药？”

“上次是谁闪了腰？”

“那是箱子太沉。”

“每次都有理由。”

两人一边拌嘴，一边把药拿进屋。

许棠站门外。

因为卡刷不开。

镜辞看了几秒。

“她一直住这？”

旁边邻居正好开门倒水。

“棠棠啊？”

女人笑了。

“十多年了吧。”

“住户登记呢？”

“这个我哪知道。”

“平时老许有事找谁？”

“找她啊。”

女人指了指许棠。

“上次老许住院，我还替她送过两天饭。她陪床陪得脸都青了。”

许棠从屋里探头。

“王姨，别替我写先进事迹。”

“谁夸你了？”

邻居把水盆往里一拖。

“你小时候偷我葡萄我还记得。”

门关了。

镜辞回头看姜霁。

她没记“像女儿”。

只记了几条事实。

多年正常出入。

长期共同生活。

买药。

住院陪护。

邻居默认她是处理许德昌事务的人。

“法律关系呢？”

镜辞压低声音。

“没有正式收养。”

姜霁翻了一页。

“户籍也不在这。”

“所以系统只能写访客。”

“对。”

“这算错吗？”

“看你问哪一层。”

镜辞皱眉。

她把笔帽扣上。

“法律字段没错。”

“生活呢？”

“你自己看。”

许棠正蹲在玄关给许德昌分药。

“白的晚上吃。”

“我知道。”

“昨天你也说知道。”

“你怎么跟我妈一样。”

“你妈要是还在，轮得到我管？”

老人一下安静。

许棠也停了半秒。

然后继续把药装进盒子。

没煽情。

也没人说“你就是我亲女儿”。

过了会儿，杜经理把平板递过来。

“陈叔，您这边点确认。”

“她姓许。”

老人脸拉下来。

“我也姓许。”

杜经理愣了一下。

“许叔，我今天脑子乱。”

“你们系统也乱。”

老人按下确认。

人工修正提交。

几分钟后，许棠重新刷卡。

滴。

绿灯。

门开了。

她抬了抬眉。

“我又被这个家收养一次。”

许德昌在里面骂：“少废话，酱油买了吗？”

“忘了。”

“你看看。”

“你自己记。”

门在两人斗嘴声里关上。

镜辞站在走廊上。

没有接缝。

没有陌生工具车。

没有人在暗处修什么异常节点。

一切都只是系统按规则工作。

可刚才那十几分钟，许棠确实进不了自己住了十几年的家。

姜霁把这一页单独标出来。

**非异常对照。**

镜辞看见。

“还专门记这个？”

“当然。”

“为什么？”

“以后你看见关系和系统打架，别第一反应就找壳。”

“我没那么蠢。”

姜霁看了他一眼。

镜辞不说了。

晚上八点，物业群里发通知。

人工修正已完成的住户可以正常使用新门禁。

许棠在群里回了个“收到”。

十点多，她还发了一张酱油照片。

许德昌回了三个字：

**买错牌。**

第二天早上六点四十。

许棠提着早餐站在六号楼门口。

刷卡。

红灯。

她低头看了看卡。

又刷一次。

还是红。

门禁屏幕上跳出一行小字：

**权限需重新确认。**

许棠站了两秒。

拿手机拨杜经理。

电话还没接通，她抬头看向大厅那台新终端。

屏幕右下角有一条昨夜同步记录。

时间：

**02:17。**
