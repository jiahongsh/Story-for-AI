# 第14章 村子的信

周六清晨，镜辞支好摊子，眼睛落在市场西头。

灰褂卖菜人已经在那儿了。那人穿一件灰扑扑的褂子，弯着腰，把一捆一捆的菜码得整整齐齐。他卖菜跟别人不一样：不吆喝，不称零头，给多少算多少，找零的时候手很稳，从不多找不少找。

镜辞看了他三天了。

第一天，他注意到那人收摊的时间。市场里几十个摊主，收摊的时间各有各的准头：卖菜的王婶看天色，天阴了就走；卖鱼的阿庆看人，人少了就走；卖豆腐的刘姐看表，六点整，一分钟不差。灰褂卖菜人看的是什么呢？那天他收摊的时候，镜辞抬头看了一眼市场口的老钟，六点整。

第二天，他发现那人收摊的路线。挎上菜筐，穿过卖调料的摊子，穿过卖熟食的摊子，往西头那条巷子走。那条巷子，市场里没人去，尽头是堵墙，墙根堆着旧纸箱，是放破烂的地方。

第三天，也就是今天，他决定跟一次。

下午六点，灰褂卖菜人收摊。他弯腰，把菜筐扣上，挎在胳膊上，转身往西走。镜辞放下手里的表，远远地跟上去。

市场里人还多，他隔着两三个摊子，不紧不慢地跟着。那人走得不快，也不回头，穿过卖调料的摊子，穿过卖熟食的摊子，拐进西头那条巷子。

傍晚的太阳斜斜地照着，把那人的影子拖在身后。镜辞数着那人的步子，一步，两步，三步。

那人拐进巷子。

镜辞在巷口停了一下，然后跟进去。

巷子不长，七八米，尽头是一面墙。墙角堆着几只旧纸箱，纸箱上落着灰，压得扁扁的。墙上爬着半墙的枯藤。

没有人。

灰褂卖菜人不在巷子里。

镜辞站在巷子里，把角角落落看了一遍。纸箱后面，空的。枯藤下面，空的。墙上光溜溜的，连个缝都没有。那人挎着菜筐，一个大活人，就这么没了。

他蹲下来，摸了摸墙根的灰。灰是旧的，浮着，没有脚印。他又看了一遍，才慢慢直起身，走出巷子。

他站在巷口，后背凉凉的。

他忽然想：这条巷子，那人走了多少年了？每天都从这儿消失，每天都从那儿出来，第二天照常支摊、卖菜、找零、收摊。他像一个齿轮，嵌在这条巷子里，每天转一圈。

他想起老王。老王的脸，在水面倒影里，洇成一团，又拼回原样。不到一秒，没有人看见。

灰褂卖菜人也是这样。他不是在走路。

他是在消失。

他想起四天前那个晚上，豆浆铺门口，他检视人群的时候，看见过这个人。那层淡淡的灰光，挂在那人指尖，像一层没擦干净的灰。

那时候他还想：看得见，就还有办法。

现在他站在死巷口，忽然不那么确定了。

看得见，又能怎么样？

镜辞看得见老王的脸在水里洇开。看得见早餐铺老板娘围裙上的灰光。看得见灰褂卖菜人每天从死巷里消失。

他看见了那么多。

可他什么也没能拦住。

傍晚，镜辞收了摊，往回走。走得比平时慢。市场里的灯一盏一盏亮起来，卖熟食的摊子飘出卤味，有人蹲在路边啃玉米。他走过那些摊子，走过那些人，心里数着：这个摊主，我认识七年；那个人，我认识三年；那个蹲着啃玉米的，我上礼拜还给他修过表。

他走到家门口，停住了。

门缝里塞着一个牛皮纸信封，上面只写着三个字：镜辞收。

是芽的字。

他认得那个"辞"字的写法。芽写字有个毛病，横总是写不平，往右斜。他撕开信封，抽出信纸。

信纸是作业本上撕下来的，带着格线。字写得很工整，一笔一划，像描的。

镜辞！我到了！

信的开头，是芽的口气。芽写信从来这样，先喊名字，再感叹号，恨不得把信纸撑破。

可下面的字，不是芽的。

芽的字往右斜，横不平。这封信的字，端端正正，横平竖直，每一个字的收笔都稳稳地落在格线上。

那是壳自己的字。

它学芽的口气，学芽的用词，学芽的标点。可它自己的笔迹，从纸背上透出来，藏不住。

镜辞在门口站了一会儿，才把信看完。

河干了。河床露出来，石头白花花的，走上去硌脚。

树还在。很大，我一个人抱不过来。树皮上全是刻痕，一层叠着一层，有名字，有日期，还有一些我看不懂的记号。我在树下坐了一下午。风从河床那边吹过来，吹得树叶子哗哗响。我坐在树根底下，忽然觉得，要是芽在这儿，她也会坐这儿。这棵树底下，被磨出一块光溜溜的土，是坐过很多人的那种。

村里有个老太太，姓周，七十多了，牙都快掉光了。她跟我说，前阵子有个姑娘来过，也是在这棵树下，坐了一下午，一句话没说，坐完了就走了。老太太说，那姑娘穿着红毛衣。

红毛衣。

芽的旧物盒里，那件红毛衣，洗得褪了色，他还留着。

他握着信纸的手，停在半空。

他想起壳到村子才一天。她写信的时候，村里老太太讲的"前阵子"，跟壳到村子的时间对不上。

前阵子。

那是芽的时间。

他站在门口，把那段话看了三遍。太阳落山了，楼道里的灯亮了，昏黄的。他站在那里，把那封信看了一遍又一遍，最后轻轻折好，进了门。

他把信纸夹进账本"芽"那一页。

账本上，"芽"那一页已经写满了。他翻到最后一栏，拿起笔，想写点什么。他想了很久。

他想起芽说过的话：你要是看见有人先喝汤，那就是我。

他想起那个村子，是芽记忆里"想去的地方"。她想去那儿，去了，在树下坐了一下午，穿着红毛衣，一句话没说，坐完了就走了。干干净净的，什么也没留下。

她坐了一下午，在想什么？

她是不是也在想，要是镜辞在就好了？

她走的时候，有没有回头看那棵树？

他忽然想起一件事。壳说过，芽的记忆里，那个村子是她"一直想去的地方"。她想去，可她一直没去。她在这座城市里住了二十几年，坐两小时大巴就能到的地方，她一次都没去过。

她在等什么？

等一个可以去的人？

他拿起笔，写下一行字：

她可能来过。

写完，他把笔放下，把账本合上，放在枕头底下。

夜里十一点，他关了灯，躺下。

外面很静。市场睡了，只有远处的路灯嗡嗡响。

他快睡着的时候，忽然听见脚步声。

布鞋底擦着地的声音，很轻，一下，一下，在他摊子前面停住了。

镜辞睁开眼睛。

没有动。躺在黑暗里，听着外面的动静。脚步声在他摊子前面停了很久，久到他以为那人已经走了。

然后，那脚步声慢慢移到了他的门口。

他家的门，是铁皮门，门缝很窄，漏进来一线光。

他慢慢爬起来，光着脚，走到门边，透过门缝往外看。

路灯底下，灰褂卖菜人站在他家门口。

他背对着路灯，影子拉得很长。他站得笔直，脸朝着门的方向，一动不动。

他在看门。

更准确地说，他在看门里的人。

镜辞站在门后，没有出声。想起白天在死巷里的那面墙，想起老王在水面倒影里洇成一团的脸，想起那个推着婴儿车的年轻女人眼角一闪而过的光。又想起早餐铺老板娘围着围裙冲他笑的样子，想起她问"你叫什么来着"时的神情。

这个市场里，到底有多少人，已经不再是人？

他看见那人站了很久，久到路灯闪了一下。

那人转身之前，做了个动作。他微微偏了偏头，像在听门里的动静，又像在确认什么。

然后，灰褂卖菜人转过身，沿着来路，一步一步走回去。走到巷口，拐进去。

镜辞站在门后，等着那脚步声彻底消失。

他回到床边，躺下，把账本从枕头底下抽出来，攥在手里。

他躺了一夜，没有睡。天快亮的时候，他听见窗外第一声鸟叫。

他把账本放回枕头底下，闭上眼睛，心里想：明天，去车站。
