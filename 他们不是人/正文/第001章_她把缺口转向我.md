# 第001章 她把缺口转向我
镜辞修了七年表，最烦两件事：有人从背后拍他，以及芽一大早踹门。
今天倒好，两样全齐了。
木门被一脚踹得哐当乱晃，两份热气腾腾的早餐先砸上工作台，紧接着一只微凉的手掌啪地按住了他刚夹起来的螺丝盒。盒里躺着一枚米粒大小的蓝钢螺丝，这玩意儿要是蹦地上，趴在水泥缝里找半天都是轻的，运气不好能找到明天早上。
“先吃饭。”
“松手。”镜辞眼皮都没抬，捏着镊子的右手悬在半空纹丝不动，“这颗小，滚了就真没了。”
“你再盯十分钟，它也不会自己下崽。”芽压着盒子纹丝不动，“先吃，油条凉了硬得能敲核桃，到时候别赖我。”
镜辞终于抬起眼。镊子尖还悬着，芽却促狭地弯起眼睛，手一缩，顺势把那两袋早餐往工作台外头推了半米。
半米，刚好卡在他坐着够不着、非得站起来不可的距离。
“行，算你狠。”镜辞叹了口气。
芽噗嗤乐了，又把塑料袋往回带了两寸：“下回我直接把饭搁门口台阶上，谁爱吃谁吃。”
门外拖青菜的塑料轮子咯噔咯噔碾过碎砖，隔壁五金摊的卷帘门哗啦一声拉到顶，老陈叼着没点火的烟探出半个脑袋。旧货市场这点最绝，谁家拌嘴都不用买票，左邻右舍自带板凳当观众。
“又吵呢？”老陈嗓门洪亮。
芽冲店里抬了抬下巴：“他修表修成仙了，不吃饭。”
“饿死省粮！”老陈吼完自己先乐了，拿着抹布敲了敲柜台，“不对，他还欠我两把尖嘴钳的钱没结呢，可不能现在饿死。”
芽只逮着前半句，冲镜辞直拍桌子：“听见没，街坊公议，饿死省粮。”
镜辞懒得搭理这俩活宝，低头把那枚米粒大的蓝钢螺丝稳稳送进分格盘，确认卡进槽位了，才起身去后头洗手。这是跟在养母沈竹身边修表养出来的死毛病：越小的东西，越得先给它找个钉死的位置，不然一转眼就彻底找不着了。
等他擦干手出来，芽已经熟门熟路地从墙根勾出小木凳，连一次性筷子都替他掰开了，还在裤腿上蹭了两下木刺。
钟表行里的规矩，她比店里的旧台账还门儿清：台面上的铜镊子不能乱碰，右边第二个抽屉按尺寸排着发条和游丝，镜辞对零件的时候绝不能从背后拍他肩膀。这些规矩没一条写在纸上，全是两个人从小到大吵架吵出来的。
镜辞顺手把刚拆下来的一枚旧棘轮往右边格子里一搁，芽扫了一眼就皱起眉。
“那格是零点八的，你手里这个至少一点零，别又闭着眼瞎塞。”
镜辞动作一顿，低头对了下刻度，还真是。他挑了挑眉：“可以啊，什么时候把这眼力练出来了？”
“听你念叨八百遍，死人都能学会。”
话音落下的瞬间，镜辞捏着零件的指尖微微一僵。
芽似乎也意识到“死人”这两个字在店里犯忌讳，嘴角收了收，视线顺着工作台往最里头飘过去。
台面最深处的绒布盘里，安安静静躺着一只银灰色的旧怀表。表壳边缘早就磨得发暗，秒针死死卡在十一和十二之间，像一口怎么也咽不下去的气。表盘内圈边缘，刻着十一道极细的刻度。
养母沈竹失踪整整七年，这只怀表镜辞断断续续修了七年。怪得很，里面的机芯明明没有缺件，每次拆开洗油重装，它最多也就能走十一天。十一天一到，不管发条还有没有劲，秒针必定卡回十一和十二之间。
“又停了？”芽把装着小米汤的瓷碗往他手边推了推，“昨晚又熬夜拆它了？”
“嗯，昨晚彻底停死了。”镜辞拉开木凳坐下。
“还修吗？”
“修。”
“要是这辈子都修不好呢？”
“那就修到它肯走为止。”
芽盯着他看了两秒，忽然轻轻笑了一声：“你从小就这死心眼。别人东西坏了第一反应是扔，你第一反应永远是拆开看看里头藏着什么。”
镜辞拿起筷子：“十六岁那年，是谁把我的小闹钟踩扁了还死不承认，害我拆了整整一宿？”
“我啊。”芽答得理直气壮。
“最后赔了我什么？”
“一瓶橘子汽水。”
“半瓶。”镜辞纠正，“另外半瓶你在路上就喝光了。”
“那我不管，反正瓶子归你了。”
一字不差。连十来岁时那点鸡毛蒜皮的烂账，她都记得清清楚楚。
芽低头划拉了两下手机屏幕，顺手从袋子里拈起一根炸得金黄的油条，咔嚓咬了一大口。
镜辞正要去夹第二根油条，筷子尖在半空停了一瞬。
桌上那碗小米汤还冒着白气，浓稠的米油浮在表面，一动没动。
这本来是件小得不能再小的事。芽打小胃就不好，冬天喝口凉风都能吐酸水，被旧街早餐铺的老板娘指着鼻子骂过几回后，硬生生改出了一个铁打的习惯：只要早饭桌上有热汤热粥，哪怕天塌下来，她也必定先喝两口热的垫垫胃，绝不空腹先碰油炸的东西。
有一回两人早上赶末班校车，车都进站了，她非站在马路牙子上先把半杯热豆浆灌下去，结果眼睁睁看着公车尾灯扬长而去，镜辞背着两个人的书包一路骂了她三条街。
人总是会变的。七八年过去，胃养好了，换个吃法也不稀奇。镜辞心里这么劝自己，把筷子换到左手，伸手去夹咸菜。
手腕刚探出去，指节忽然磕在盛小米汤的白瓷碗沿上。
那是早点铺送来的一只老瓷碗，碗口崩掉了一小块三角形的豁口，锋利的白茬正笔直地对着镜辞的左手腕。镜辞下意识缩了下手指。
对面的芽看见了，伸手扶住碗底，往自己面前拉近了一寸。
碗动了，可那个崩掉的尖锐豁口，依然纹丝不动地正对着镜辞。
镜辞这次没有低头。
旧货市场周边的苍蝇馆子全是这种磕磕碰碰的残次碗。以前不管在哪儿吃饭，只要桌上有带豁口的碗，芽坐下来的第一个动作永远是顺手把碗转个圈，豁口既不朝自己，也不朝镜辞，必定转过去贴着墙根。
有一年镜辞嫌她穷讲究，随口刺了她一句是不是强迫症，那丫头翻了个白眼，边啃包子边说：你那双手还得修一辈子表呢，被破碗划了算谁的？你的手比我值钱。
这种小动作，不是背诵记忆能背出来的，那是长在骨头缝里的本能。
“看我干嘛？”芽终于端起小米汤抿了一口，眉头皱了皱，“今天这汤怎么凉得这么快。”
“你最近胃全好了？”镜辞盯着她的眼睛问。
“还行吧，没怎么犯过。”
“现在空腹啃油条也不泛酸水了？”
芽抬起眼皮看了他一下。那一眼很短，快门闪过般一瞬就收了回去，紧接着她又恢复了那副没心没肺的样子，咔嚓咬断半截油条：“吃个早饭你也查户口，越来越像沈姨了。”
称呼对，嫌弃的语气也对，连嚼东西时腮帮子鼓起来的弧度都跟昨天一模一样。
“随口问问。”镜辞收回视线，夹起油条咬了一口，嚼在嘴里却半点油香和滋味都品不出来，发腻得让人反胃。
吃到九点出头，外头日头高了，芽拍拍手站起来，把木凳推回墙根，临走还不忘替镜辞把半开的卷帘门往上顶高一截。门口卖菜的赵奶奶正好推着小车路过，隔着老远喊她：“小芽，晚上过来吃饭不？我留了一袋新土豆，你顺道帮我拎上楼！”
“不一定能早回呢赵奶！您可别自己搬，那老腰不要啦？”
“知道知道，给你留着！”
芽笑着挥挥手，转身扎进熙熙攘攘的早市人流里。卖鱼的摊主正抡着铁锤剁碎冰，三轮车喇叭从巷头一路响到巷尾，老陈还在跟个大爷争一把管钳到底卖十八还是十五，整条旧街烧沸油锅般喧腾热闹，让人挑不出半点毛病。
镜辞站在门口看了两秒，退回店里。
工作台上还摊着刚才没装完的那只老机械表。他坐回木凳上，拿起单眼修表寸镜卡在右眼眶上，顺手抽出一块鹿皮布，低头去擦工作台边缘那块用来垫手、斜对着门外的厚玻璃板。
玻璃擦亮的一瞬间，十倍放大的寸镜视野里，斜斜映出了店门外左侧的墙角阴影。
镜辞擦玻璃的手猛地僵住。
刚才明明已经挥手走进早市人流里的芽，根本没走远。
她不知道什么时候竟折返了回来，正一个人静静站在隔壁五金摊与钟表行交界的那道死角阴影里。从店里平视过去，正好被门框挡得严严实实；可偏偏工作台上的厚玻璃斜了一道角度，把那个死角折射进了镜辞的十倍寸镜里。
反光里的芽脸上没有半点笑意。
之前那种鲜活、狡黠、跟街坊打成一片的神情消失得干干净净，她的脸皮紧绷着，一双黑瞳冷死无波，直勾勾盯着自己空空如也的右手掌心，那是刚才端过缺口瓷碗的手。
紧接着，镜辞浑身的血液瞬间凉透了。
只见阴影里的芽慢慢抬起双手，一手托住自己的下巴，另一手按住后脑勺，不急不缓地双手发力，面无表情地往左一拧。
咔吧。
隔着半扇门和喧嚣的早市，镜辞甚至能从寸镜的画面里看清她颈椎错位的震动。
随着那一下硬生生的拧动，她左侧耳根下方到脖颈交界的地方，原本光洁的皮肤刺啦错开了不到一毫米的豁口，翻出白瓷裂缝般惨白发亮的微光！
那道细缝里没有血，也没有肉，只有一线冷硬发颤的白光在缓缓收缩。
芽用拇指顺着耳后那道细缝重重往里按了一圈，把翘起的皮肉重新抹平，然后松开手，晃了晃脖子，神色旋即恢复如常，转身彻底汇入了早市的人群。
店里死一般安静。
镜辞连呼吸都忘了，右手死死抠着工作台沿，指甲几乎要在木头上抠出印子来。
就在这时，工作台最里头突然传出一声极轻、极脆的金属响动。
咔哒。
镜辞猛地扭过头。
绒布盘里，那只昨晚就彻底停死、连表冠都没上过弦的银灰旧怀表，原本卡死在十一和十二之间的秒针，刚刚自己往后倒退了一整格，死死钉在了第十道细痕上。
