### 3.4 真正的钢索：卷被定义成「回答一个哲学问题」

`大纲.md` §三「八卷认知升级」表，八卷核心问题全是问句（谁不是我？谁有资格回来？记得就是同一个人吗？……），「必须完成的变化」一列全是**学会 / 确认 / 证明 / 建立 / 撕开**：

> 第 1 卷「镜辞确认身份错位存在，并**学会**『我看见，不等于我知道』」

没有一卷写「谁会死」「谁会失去什么」「哪道防线会失守」「什么被不可逆地毁掉」。卷的功能被定成认知命题 → 每章只需贡献一层认知或一份证据 → 零物理事件 → 记录词 4.27:1 → 100 章方法论课。**整数章数只是投影，命题式卷定义才是光源。**

对照对标书 §一·1，每部是情绪折线 + 战役 + 牺牲：「第4部……双亲牺牲悲剧顶点」「第5部下……初雪死崩塌」「第6部……谢幕之战惨烈悲绝」。

### 3.5 文风分层仍要做，但排在最后

风格卡是「唯一文风执行源」，§2.6 把语气锁成「干、少、带点自嘲……不破坏身份恐怖的压抑感」；§九 15 项逐章配额 + 声线卡 5 问 + 每 3-5 章 beat + 每 10-15 章能力释放，全是均匀分布。后果是逐章打卡——我自己写的 011-020 回炉报告那张「16-20 章逐章全 ✅」就是产物，五章一个腔；且八卷冲突形态明明在变，第 7 卷城市级决战还用钟表行腔，等于把高潮写成笔录。

**但这是卷结构解绑之后的收尾工程，不是本轮主战场。**

### 3.6 决定：第一卷终点 = 第 100 章（事件闭环），边界与章号一律不动

作者标准：「**该讲完的事讲完了结束**」。按这个标准逐句核 `正文/第100章_第一道缝.md`（2313 字）：

| 第一卷欠读者的事 | 100 章怎么还的 | 正文原句 |
|---|---|---|
| 周衡连着 5 章「没有缝」，必须给一次能力兑现 | 11:49 柜台玻璃反射中极浅接缝首现，不足一秒 | 「玻璃反射中确认接缝短暂出现，持续不足一秒」「不可重复」 |
| 「看见」不能直接等于「知道」 | 坐实错位，同时明确不回答来源/回填/原身份 | 「接缝坐实了一件事……但它没有替镜辞回答另外那些问题」「还是不知道」 |
| 认知终点要落在人物身上，不能是旁白说教 | 镜辞主动放弃立刻补完 | 「这一次，镜辞没有觉得『不知道』需要马上补完」 |
| 「身份未决，不妨碍先保护具体的人」 | 不追、不喊、不抓；周衡继续修水管、被叫周师傅、被催挂号 | 「没人跟踪。也没人抓捕。」「五金摊老板仍叫他周师傅」 |
| 收束意象 | 修表匠把最后一只客人的表后盖压紧 | 「秒针重新走起来。」 |
| 下一卷硬钩子（不靠空喊） | 姜霁两条消息 + 第二医院定位 | 「明早六点，有案子」「还是外部观察」「临江市第二医院」 |

`卷纲_第一卷.md` §六 本就这么定：「第099章只送来周衡的真实坏表，不确认接缝。**第100章活动正文承担周衡第一次确定接缝和第一卷认知收束**」。

而 `第101章` 第一句就换案：「他死了十一个月，你们让死人签什么字？」——死亡证明 vs 系统在世、配偶权限、病历调阅、家属签字，正是第二卷主题「谁有资格决定这个人还能不能继续使用原来的名字、家庭、住处和社会权限」。**100→101 是干净的卷间切换，不是同卷续航。**

**为什么不是 099 / 103**：

- **099** 收在「一只真的坏表」「合上盒盖…清灰」，接缝未确认、认知终点未落地，两笔最大的账还欠着，属于「没讲完」。
- **103** 收在「这个人先回来了。系统只是晚了三周，才承认他『活着』」——这是赵闻川案的阶段结论，已在第二卷阶段一（101-120）内部；划到 103 会吞掉第二卷开局三章，且让第一卷认知终点出现在新案之后，结构反而散。
- **100** 是唯一一处「旧账结清 + 新钩子抛出」同时发生的章。按作者标准，这就是该结束的地方。

**决定**：第一卷 = 001-100，第二卷 = 101 起，**章号、边界、追踪状态一律不动**；卷的终点定义为「第一卷承诺的全部事件闭环于 100」，不是「凑满 100 章」。

## 四、「约束太强」的真正机制：不是多，是互相打架且没有仲裁

约束体量：大纲 124 文件、设定 46、追踪 437、对标 1355、创作运行 391；仅 5 份跨卷硬约束 + 风格卡 + 题材卡 + 声线卡 + 施工卡，合计约 **5.4 万字**（实测 53,585 字）；每章另有细纲、逐章记录、事实档案。写前包要过 `story-world-engine` 七关，写后要过 7 道门禁，落正文要走「改细纲 → 候选章 → 审批 → tracking_commit → 派生视图」。

但真正卡住的不是数量，是**两套口径方向相反**：

| | 风格卡 v2 | 提速施工卡 |
|---|---|---|
| 方向 | 每章**加**：插话、内心声音、俗喻、体感、长短落差 | 每章**删**：重复解释、同形状调查、反复算账、延宕词 |
| 落点 | 灰度、不判、参差 | 具体新麻烦、现实后果、硬钩子 |
| 验收 | §九 15 项，每章可数，有脚本 | 语义冷读，7 项指标，无脚本 |
| 落正文成本 | 直接写 `正文/`，一轮过门禁 | 先改细纲 → 七关 → 候选章 → 审批 → commit |
| 实际被执行 | **✅ 连续三轮** | ❌ 11-09 写完后一次没动 |

**结论：可量化、有脚本、链条短的那套天然胜出；要改结构、链条长的那套天然被跳过。** 这不是谁偷懒，是流程设计把「磨文风」设成低阻力路径、把「推进剧情」设成高阻力路径。而且风格卡 v2 加进去的「内心声音/干燥点评/不判落点」，客观上还在给延宕词和软收尾供血——今日实测 263→264 就是痕迹。
