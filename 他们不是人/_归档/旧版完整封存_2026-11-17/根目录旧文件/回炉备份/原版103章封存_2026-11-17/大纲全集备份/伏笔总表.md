# 一、伏笔状态必须拆成四个字段

所有A级/S级伏笔同时记录：

1. **规划首埋**：大纲原计划第一次出现的位置；
2. **活动正文首埋**：当前有效正文中，读者真正第一次看到的位置；
3. **实际状态**：未埋 / 已埋 / 已增压 / 已变义 / 已引爆 / 已回收；
4. **连续性有效性**：有效 / 旧稿失效待重埋 / 规划未兑现。

因此：

> **“细纲里写了”不等于“正文已埋”。**
>
> **“旧稿曾经写过”不等于“当前读者已经知道”。**

第001—099章已有活动正文，已发生与首埋须据各章实文核对。100—103虽有正文但尚未接纳到截至099的追踪；本表区分读者已见的锁定正文与追踪当前状态。

# 二、伏笔设计原则

伏笔标准生命周期：

> **埋入 → 误读 → 再现/增压 → 变义 → 复合引爆 → 余波**

但每次再现必须服务当前剧情，并新增信息、改变解释或迫使人物做出新选择。

五类伏笔保持不变：

- **方法裂缝**：不同合理方法推出不同判断；
- **制度原罪**：有现实价值的制度在扩张中越权；
- **关系旧账**：旧判断长期改变具体人的生活；
- **版本凭证**：证明曾存在另一版本，但不能单独证明谁是真人；
- **身份余波**：一个人的影响在本人离开后仍改变现实。

S级伏笔承担跨卷核心答案；A级伏笔承担人物/势力长线；B级伏笔原则上10-30章内兑现。

终局伏笔必须至少提前一卷留下弱信号，且正式引爆前至少经历一次意义变化。
