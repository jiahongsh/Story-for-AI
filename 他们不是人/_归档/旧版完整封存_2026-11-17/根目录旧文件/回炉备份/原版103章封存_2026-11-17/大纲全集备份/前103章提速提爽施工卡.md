统计口径：全部 103 章活动正文，词表见本卡附录 A。**词频只用于定位问题，不作机械改写配额；验收以语义冷读为准。**

## 2. 三条改造原则

1. **提速不删案子**：删的是重复解释、同形状调查、四轮尾声、无效身体反馈、反复算账；省下的篇幅全部给动作与后果。案子、伏笔、人物关系一律保留。
2. **提爽不加战力**：V1 不开第二式、不报数值、不加新天赋。爽点形状只用卷纲 §4 已授权的四种——**看破 / 脱险 / 公开反制 / 迫使敌人改变计划**，以及题材卡 §4 的设局验证、保护证据、制造公共见证、追踪异常、借第一式提前发现风险。
3. **把"未知"从终点改成起点**：保留"我看见，不等于我知道"作为第一卷结论，但每章不能停在"写未见"。**克制本身要变成可使用的武器**（见 §5 样板）。

统一四拍：**看见 → 做成一件事 → 现实里有个可指认变化 → 付一笔代价 / 引出更大问题**。

## 4. 章尾钩子改造

禁用当前高频软收尾：`记下 / 合上本子 / 手机扣在桌上 / 没有 / 先别外传 / 茶凉了`。

允许五种硬钩子，连续 3 章不得同形：

1. **具体新麻烦**：人、物、明确时间（"明天九点名单要挂出去"）。
2. **第三方证词反转**：像 009「不是穿黑外套吗」，由一个不在主角控制内的人说出。
3. **现实字段被改写的截图感**：门禁/联系人/工单/公示页当场变了。
4. **敌人独立行动**：读者看见，镜辞不在场（恐怖节拍硬约束 §3 认知差）。
5. **代价到期**：明天要付什么、谁会来收。

硬约束不变：每 3-5 章一个 beat（诡异细节 + 日常解释）、每案一个不可撤销现实后果、每 5 章至少一次"读者比镜辞多知道一点"，且禁用"他不知道的是……"式旁白。

## 5. 样板：096 改造卡（把"克制"变成爽点）

现状：整章「没看见 → 记上 → 先别下结论 → 先别外传」，主角行动只有"看了一下"，落在风格卡硬性否决项第 12 条的更差版本（用**没看见**代替事件推进）。

改造后四格，**不新增能力、不提前给缝、不违反 096-099 不得确认接缝的接口锁**：

| 格 | 内容 |
|---|---|
| 钩子/目标 | 团队准备按"未见"把周衡从观察名单撤下，姜霁电话要一个结论。 |
| 阻碍 | 镜辞拿不出正向证据，手里只有"未见"；说"再看看"会被当成拖延。 |
| 主动行动 | 他不写一行"未见"就完事，而是把"未见"写成**带限定条件的记录**（哪只看过、什么光线下、谁在场、哪些噪点被排除），并据此要求暂缓一次撤场 / 暂缓一次上门接触——**用"我没看见"挡住一次仓促处置**。 |
| 结果 / 新问题 | 撤场推迟一天（现实状态改变，可指认）；但对方察觉观察节奏变了。章尾用第三方一句话做认知差（读者比镜辞多知道一点）。 |
| 代价 | 为了让"未见"能当挡箭牌，他必须交出一份自己的观察方法说明，暴露加深；守钟人不替他背书。 |

要点：**克制没被删掉，被用成了武器**。这是全卷"提爽不破设定"的标准解法，其余各章照此形状对齐。
