## 第1122章 各司其职

**概要**
龙双手画写意太极、轻拧交汇，世界静止，将两死兽释放的能量与伤害一分不少地返还其体内，二者贴地飞出一公里外重创，留下巨壑。周箐、马克十余秒回归人形，却更暴躁更癫狂。四死兽因争抢龙而内讧争吵，像小孩子过家家，众觉醒者手拉手在一旁围观，龙则如裁判悠然等待。高阳冷却结束，空间跳跃归来与龙重逢；他惊觉金色圣衣未触发，方知被望舒黑夜领域隔绝。死兽慑于傲慢“神嗣须由傲慢亲杀”之令停止纷争，飞入圆月撤离，夜空恢复。九寒、陈萤醒来联络告知安全。斗虎断臂走向龙阴阳怪气，龙转身悲戚溢血，轻声问白兔与歌姬的墓在何处。

**关键事件**
- 龙以太极手势化解，世界静止，伤害返还，死兽飞出一公里外重创
- 周箐马克回归人形，更暴躁更癫狂
- 死兽内讧争吵，众觉醒者围观如团建
- 高阳空间跳跃归来，与龙重逢
- 死兽飞入月亮撤离，夜空恢复
- 九寒陈萤联络告知醒来
- 斗虎调侃龙，龙悲戚问白兔歌姬墓

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 太极手势→世界静止→伤害返还 | 因果反击式扩写，举重若轻 |
| 死兽内讧“像小孩过家家” | 反差解构强大反派 |
| 高阳疑惑金色圣衣未触发 | 细节回收，补望舒领域设定 |
| 傲慢令“神嗣须由傲慢杀” | 宿命规则设定 |
| 龙悲戚问墓 | 以情感落点收束战斗章 |
| 旁观者“咔嚓”零件矫正感 | 通感写法烘托神迹 |

**逐章写法公式**
- 情绪流向：碾压爽感→荒诞→温情重逢→怅惘
- 节奏配比：决战收束→闹剧缓冲→重逢→收尾抒情
- 结构公式：反击→死兽溃→内讧→高阳归→撤离→抒情落点
- 核心技巧：以闹剧消解压迫，再用墓地提问转悲
- 卡点与伏笔：白兔歌姬之死，龙的真实使命
