## 第845章 好多人

**概要**
本章以一场"大团圆式"的群像集会，将分散的战线收拢。一天前，白兔带萌羊离藏身地，与九嗣奈奈在西国酒店汇合，易容打上迷失者气息后潜回离城下水道中的秘密据点——正是十二生肖早期废弃基地。白兔推开伪装密门，被眼前"好多人"震住：九嗣与十二生肖全员齐聚，客厅喧闹拥挤。高阳、斗虎坐主沙发商讨，九寒、钟赫参与；静书抱王蔚洇跑团，格里高主持；张伟等人打牌，天狗听歌，泼猴打太极，青灵等吃泡面。白兔一句脏话打破寂静，奈奈中二登场被青灵镇住。萌羊哭抱死猪与天狗。转入正事：高阳给白兔旗帜符文令【穿梭】冲4级，斗虎宣布"符文共享"计划；九寒向白兔讲明双线作战（攻海川团探底、找贾博士），并定下争取格里高护后方、贾博士带回或杀。章末高阳抛出萌羊与王蔚洇是否上阵的疑问。

**关键事件**
- 白兔带萌羊与奈奈易容汇合，潜回离城下水道秘密据点
- 推开密门见九嗣与十二生肖全员齐聚，群像喧闹
- 奈奈中二登场被青灵镇住，萌羊与死猪、天狗温情重逢
- 高阳给白兔旗帜符文冲穿梭4级，宣布符文共享计划
- 九寒讲明双线作战，定下争取格里高与贾博士；章末问萌羊洇洇是否上阵

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 据点群像 | 分组罗列（商讨/跑团/牌局/独处）如镜头扫场，信息密集不杂乱 |
| 白兔脏话破静 | 以一句粗口打破群像静止，制造喜剧切入 |
| 奈奈中二 | 夸张台词+青灵反差镇压，构建角色关系 |
| 萌羊温情 | 哭抱死猪找天狗，以童真软化战争氛围 |
| 符文共享 | 用"抛接符文"的具象动作传递战略信息 |
| 双线明示 | 由九寒对白兔口述，自然完成情报同步 |

**逐章写法公式**
- 情绪流向：密谋→隐秘→震撼→喧闹→烟火→诙谐→滑稽→温情→驯服→振奋→紧绷→谋略→务实→犹豫
- 节奏配比：群像铺陈占五成（慢，重画面），战略议事占五成（中速，重信息）
- 结构公式：易容汇合 → 密门群像 → 破静互动 → 温情落点 → 转入议事 → 计划明示 → 设疑收尾
- 核心技巧：以"推门见众人"的视点镜头统领群像；用次要角色互动调节战争叙事的沉重
- 卡点与伏笔：萌羊与王蔚洇是否参战、符文共享成效、贾博士双线暗线
