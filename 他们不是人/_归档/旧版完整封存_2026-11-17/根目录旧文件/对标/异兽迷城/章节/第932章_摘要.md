## 第932章 三医院

**概要**
小孙老唐被齐医生识破是偷白大褂的病人，齐医生叮嘱护士盯紧他们吃药、防假吃。齐医生扶了下不存在的眼镜、走路颠簸，左手乌金戒指、袖口淡绿网状烙印——暗示其亦被控制。他回办公室向"苏院长"汇报一切正常，麒麟现身：一周前海川团全员隐秘入驻三医院，他动用万象与傀儡大师，借乌金饰品对医务人员软控制加催眠，并编织精神力之网监控全院。一石（科室主任）汇报：伤员痊愈、无色苏醒、复活药仅剩七颗，贾博士被抢后研发断档；麒麟命其按贾博士传授的方法去白湖酒店取资料，由婷婷以空气人牵手护送。后一石婷婷换便装离开，婷婷嫌医院压抑，一石叮嘱"时刻抓紧我"，并提议先去洗"新年澡"洗走霉运。

**关键事件**
- 齐医生揭穿小孙老唐偷衣，叮嘱盯药防假吃
- 齐医生乌金戒指与烙印暴露被控制，向麒麟汇报
- 麒麟以万象+傀儡大师用乌金饰品控制全院并布精神网
- 一石汇报战况：复活药剩七颗、贾博士断供、按法取资料
- 婷婷以空气人牵手护送一石离院去白湖酒店
- 一石提议先洗"新年澡"洗走霉运

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 乌金戒指烙印 | 用配饰与皮肤印记低调标记"被控" |
| 扶不存在眼镜 | 动作细节写角色仍存旧习惯，强化替换感 |
| 精神力蜘蛛网 | 以"蜘蛛织网"比喻监控，具象化控制力 |
| 复活药七颗 | 用紧缺数字制造资源焦虑与战力失衡 |
| 空气人牵手 | 以身体接触破解隐身逻辑，补设定漏洞 |
| 新年澡仪式 | 用民俗"洗霉运"软化反派日常，反差萌 |

**逐章写法公式**
- 情绪流向：荒诞（病人伪装）→ 冷峻（控制网）→ 权谋（汇报）→ 资源焦虑（药）→ 反差（洗澡）
- 节奏配比：约 20% 病人收尾 + 50% 麒麟控制 exposition + 30% 一石婷婷离院
- 结构公式：伪日常收口 → 反派据点 exposition → 资源盘点 → 行动派遣 → 日常反差
- 核心技巧：用"乌金饰品"回收前文伏笔，集中 exposition 不显冗长
- 卡点与伏笔：乌金饰品控制链、复活药断供、白湖酒店资料、空气人局限
