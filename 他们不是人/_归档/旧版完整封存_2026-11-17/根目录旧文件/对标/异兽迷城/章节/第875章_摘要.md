## 第875章 灾难预感

**概要**
手雷余波仅轻伤大黄蜂与扫晴。一火霸以心眼定位桥底钟赫，铃姐冰霜盲打逼其荡走，荆客怒携流徒、一火霸追向桥头；无色转守为攻，命安禾歌支援、余者散战。李某人见鸦鲨操控鲨鱼来袭，扫晴的灾难预感天赋则提前窥见未来雷电将劈死自己。半小时前，天狗携石化青灵撤离、红晓晓将其复活，木子土以人生小偷偷得青灵雷电与红晓晓隐身，由天狗背负发动远距雷电偷袭。顽鼬挺身发动靶心效应化作避雷针吸聚远程攻击护友，却不知雷电中藏6级空间切割，被切作数片滑落而死。其刺猬反弹令天狗添伤、木子土承10%雷电而麻痹坠江、隐身破除。大黄蜂悲忆顽鼬往日刻薄却总挡伤，悲愤突破6级衰败粉尘吹向天狗二人。

**关键事件**
- 钟赫被定位追逃，无色转守为攻分散指挥
- 木子土偷天赋雷电偷袭，顽鼬靶心效应护友却遭空间切割绞杀
- 顽鼬之死引发刺猬反弹，天狗木子土麻痹坠江破隐
- 大黄蜂悲愤突破衰败粉尘喷向坠落二人

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 灾难预感只看到自身危险 | 天赋局限设定，制造"看见死却看不见真凶" |
| 雷电中藏空间切割的双层杀 | 明雷暗切，欺骗读者与角色同一认知 |
| 刺猬反弹的连锁反噬 | 防御天赋反成伤友引信，悲喜剧反转 |
| 大黄蜂"最讨厌却最难过" | 反差情感铺垫，让毒雾复仇有重量 |
| 人生小偷的"借天赋"机制 | 临时拼装战力，丰富战术层次 |

**逐章写法公式**
- 情绪流向：侥幸余波 → 追击怒火 → 死亡预知 → 壮烈牺牲 → 哀恸复仇
- 节奏配比：追击15%、预警10%、偷袭15%、牺牲高潮35%、情感收束25%
- 结构公式：余波定位 → 转攻追击 → 预知预警 → 借力偷袭 → 护盾牺牲 → 反弹崩盘 → 毒雾复仇
- 核心技巧：用"预感"天赋制造可知而不可避的死亡，再让反弹反噬扩大悲剧
- 卡点与伏笔：衰败粉尘能否命中天狗二人；空间切割来源（木子土/隐藏者）待明
