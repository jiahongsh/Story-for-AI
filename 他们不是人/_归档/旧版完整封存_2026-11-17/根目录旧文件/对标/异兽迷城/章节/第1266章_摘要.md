## 第1266章 投影

**概要**
苍狗摘下面具，露出风流倜傥的桃花眼男子真容。他逐一认出天狗、青灵（表妹）、高阳（黑马），并点出高阳诸多江湖称号。当看到队伍末尾的银发赤瞳白露，二人上演先耳光后热吻的戏剧性重逢——苍狗是白露的前世男友，曾为她付出生命、又给她第二个诅咒，白露爱恨交织“永不原谅”。寒暄后高阳切入正题：你是敌是友？苍狗答“非敌非友”，自称是门后“祂”的一抹投影，死后回归此地。王子凯急于杀之带高阳回家被劝阻，苍狗说明此地有七个房间，祂在最后一间，需逐间“面试”回答问题才能前进。高阳接受面试，苍狗称众人“已在房间里，房间叫黑白长廊”。本章以“投影”点题，既交代苍狗的使者身份，又以他与白露的旧情增添人物厚度，并正式抛出七房间面试的终极规则。

**关键事件**
- 苍狗摘面具显露真容，认出天狗、青灵(表妹)、高阳(黑马)等
- 苍狗与白露先耳光后热吻，揭示二人是前世情侣、爱恨交织
- 高阳问敌友，苍狗答“非敌非友”，自称是门后“祂”的投影
- 王子凯欲杀苍狗被拦，苍狗说明七个房间与“面试”规则
- 高阳接受面试，苍狗告知众人已在第一个房间“黑白长廊”

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 苍狗摘面具露桃花眼 | 延时揭面，先声夺人再给外貌特写 |
| 白露“耳光+热吻” | 动作反差制造戏剧张力，一句带过旧情 |
| “非敌非友/投影”设定 | 谜语式对白，用否定+隐喻延缓信息释放 |
| 王子凯“凯神”耍横 | 喜剧反差，以急躁衬托规则之不可破 |
| 七房间面试规则 | 游戏化设定，把终极考验包装成“社畜面试” |
| 房间即黑白长廊 | 反转式收尾，把读者预期的空间变成题目本身 |

**逐章写法公式**
- 情绪流向：轻佻(认亲)→戏剧(白苍重逢)→肃然(敌友问答)→焦躁(王子凯)→了然(规则)→入题(长廊)
- 节奏配比：人物重逢戏40% + 设定问答40% + 规则收束20%
- 结构公式：揭面认亲 → 白露重逢戏 → 敌友/投影问答 → 王子凯冲突 → 七房间面试规则 → 房间即题目
- 核心技巧：用“前世情侣重逢”的糖衣包裹“终极规则交代”的药核
- 卡点与伏笔：门后“祂”是谁；七个房间各是什么；黑白长廊究竟要回答什么“问题”
