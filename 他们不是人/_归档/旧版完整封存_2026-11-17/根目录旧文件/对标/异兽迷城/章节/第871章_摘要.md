## 第871章 5V5

**概要**
高阳在领域法则的意志作用下被强行"分裂"，丝线状的金色能量从他体表剥离，在天秤上凝成第五个"高阳"幻影，至此对决双方凑齐五对五，被法则宣称为绝对公平。十座天秤缓缓沉入白色地面，锁链解除，选手落地，灰色图腾在每人脚下限定了活动范围，一道半透明能量屏障将两方隔开并屏蔽声音。双方头顶浮现红色血条与金色能量条，高阳凭借游戏经验判断其含义。法则随即将回合制决斗规则以文字形式注入众人视野：每人每回合仅一次出手、一百八十秒决策、能量见底强制休息、血量见底即死、一方全灭结束。贾博士看罢大骂像古早回合制游戏，并发现浴袍无口袋、身无道具；其鹦鹉被描述为毫无战力；尼古盘坐旁观看戏。高阳先后将三人判为"废物"，最终与幻影对视点头，达成"求人不如求己"的默契。

**关键事件**
- 高阳被法则意志分裂出第五位幻影，凑齐5V5，决斗开始
- 天秤沉地、锁链解除，灰色图腾与能量屏障限定并分隔双方
- 血条/能量条浮现，法则注入回合制决斗详细规则
- 贾博士与鹦鹉无战力、尼古只旁观，高阳判"废物"后转与幻影默契自决

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 5V5的"公平"由法则强制拼凑 | 反差设定：以"绝对公平"包装非对称战力 |
| 血条/能量条的游戏化HUD | 跨媒介映射：借游戏UI制造间离趣味 |
| 回合制规则集中灌输 | 信息块前置投放，先立规则再开打 |
| 贾博士"废物×N"连点吐槽 | 重复递进喜剧节奏，缓冲决斗紧张 |
| 高阳与幻影无言点头 | 细节动作代替心理独白，留白抒情 |

**逐章写法公式**
- 情绪流向：诡谲压抑 → 游戏化新奇 → 诙谐自嘲 → 坚毅自决
- 节奏配比：设定铺陈60%、反应吐槽25%、心理收束15%
- 结构公式：法则降临 → 场地/UI具象 → 规则文本灌输 → 战力盘点 → 自我定位
- 核心技巧：用游戏化框架把死斗变轻盈，再用"废物连判"反差收束到主角独力承担
- 卡点与伏笔：幻影真实战力未展示；回合制下弱势方如何翻盘成悬念
