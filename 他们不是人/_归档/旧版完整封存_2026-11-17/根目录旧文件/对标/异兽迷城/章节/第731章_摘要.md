## 第731章 暴走兽群

**概要**
进入高阳视角：精神武装状态下他双眼空无、大脑如机器高速计算。头顶冰霜毒雾笼罩无路可逃，他先发动【游戏玩家】，以白色细线修复奈奈与张伟残肢成光茧——这源于灾难前两秒他做的三件事：大喊危险、把觉悟耐力拉满、将乌金发夹塞给二人。不到半分钟二人被"时光重置"救回昏迷。高阳翻出残损药剂箱，仅余 3 支 C 药剂与 1 支特殊肾上腺素，分身给蔻蜗注射、本体自强唤醒能量；系统突报【幸运点收益增幅至 10000 倍】，随即他吐血透明化——心脏被"心脏小偷"窃取，本体已与幻影置换，捞起蔻蜗瞬移逃离声波袭击。半空零仇、花龟（含六霜肖辛）仍喷毒，炎凉、核东、叨哥落地废墟，称高阳"命硬像蟑螂"。另一线，曼蛇、灰雄全速奔援，灰雄化三米巨熊撞飞杀伐者；街道忽漫紫雾，二人皮肤灼痛刺寒。号角者长啸，迷失兽群全面暴走破窗扑来，灰雄如火车头撕开兽群、曼蛇踏板斩落号角者头颅，却知必须甩开兽群——曼蛇生出"炸弹、公交车"的脱困主意。

**关键事件**
- 高阳精神武装冷静计算，游戏玩家修复奈奈张伟
- 回顾灾难前两秒三动作，二人被重置救回
- 药剂箱残存，分身救蔻蜗，幸运点万倍增幅、心脏被偷
- 本体幻影置换，携蔻蜗瞬移逃走
- 零仇等半空放毒，炎凉落地嘲高阳命硬
- 曼蛇灰雄奔援遇紫雾，灰雄巨熊冲阵
- 号角者长啸兽群暴走，曼蛇出"炸弹公交车"之计

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 精神武装下"机器化"内心 | 以冷感内心独白替代情绪，外显武装效果 |
| 倒补"两秒三动作" | 事后回放关键决策，把侥幸生还写成主动布局 |
| 药剂箱"仅余几支"的稀缺 | 用物资清单制造资源紧张 |
| 幸运点万倍＋心脏被偷双转折点 | 一喜一悲叠加，打乱读者预期 |
| 本体/幻影置换的错层 | 用"透明残影"暗示已金蝉脱壳，埋反转 |
| 兽群暴走的丧尸化群像 | 以"黑布被剪刀撕开"比喻，放大压迫 |

**逐章写法公式**
- 情绪流向：冷酷运算 → 救援回放 → 绝境反转 → 敌我交锋 → 群兽围困
- 节奏配比：高阳救援线 55%，工会压制线 15%，曼蛇灰雄线 30%
- 结构公式：状态（武装）→ 行动（救人）→ 反转（置换）→ 对峙（落地）→ 外线（兽群）
- 核心技巧：用"两秒窗口"作为反复回扣的时间锚，串联救援与暴走两条外线
- 卡点与伏笔：幸运点万倍增幅（后续爆发伏笔）；心脏被偷（高阳虚弱钩子）；兽群暴走（曼蛇灰雄脱困悬念）
