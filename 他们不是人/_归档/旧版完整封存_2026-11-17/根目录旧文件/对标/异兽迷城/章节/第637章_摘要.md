## 第637章 严肃一拳

**概要**
黑鱼劝醒贾博士，使其服下假死药，正欲带走却被奈奈预先布下的蛛丝困住。奈奈突破七级大小巨化为近三十米巨人，顶碎别墅冲天。青龙抱起核东小青菜的尸体立于对面楼顶，蓄力三秒"严肃一拳"劈向天空，奈奈却于出拳前一瞬缩成拇指姑娘，一拳落空。青灵御刀携奈奈遁走。青龙于废墟中救出被吊灯贯穿胸口的黑鱼，以C药剂挽回其命，并确认贾博士已落于奈奈之手——调虎离山终成正果。

**关键事件**
- 黑鱼劝服贾博士服假死药，欲带离却被蛛丝所困
- 奈奈七级巨化冲破地底，别墅化为废墟
- 青龙蓄力"严肃一拳"劈空，奈奈缩身遁走，青灵撤离
- 青龙于废墟救出重伤黑鱼，以C药剂续命
- 黑鱼指认贾博士被奈奈攥走，青龙叹任务失手
- 青灵借巨化混乱完成带走贾博士的预案

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 假死药伏笔 | 前文"白天逼吃复活药"在此回收，使双杀可逆转 |
| 蛛丝陷阱 | 以奈奈提前布网解释为何黑鱼功败垂成 |
| 严肃一拳意象 | 用"金色攻击波穿透苍穹"将招式写成视觉奇观 |
| 缩身破局 | 以"大炮打蚊子"比喻点出奈奈并非硬刚，而是算计 |
| 废墟救友 | 用吊灯穿胸、C药剂回血的细节收束青龙重情一面 |

**逐章写法公式**
- 情绪流向：黑鱼焦灼劝离 → 奈奈巨变的震撼 → 青龙落空的不甘 → 救友的沉静
- 节奏配比：劝离与巨化四成，严肃一拳三成，废墟救友三成
- 结构公式：劝离受阻 + 巨化奇观 + 落空对轰 + 救友收束
- 核心技巧：伏笔回收、视觉奇观化招式、以缩身反差破局
- 卡点与伏笔：假死药与复活药双保险；奈奈"假动作"呼应其"中二不傻"
