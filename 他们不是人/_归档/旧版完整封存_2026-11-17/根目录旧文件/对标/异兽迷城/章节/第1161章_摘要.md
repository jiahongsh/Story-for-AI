## 第1161章 不像

**概要**
深夜蛇门，高阳处理完事务遇百里弋归还日记本，确认是否告知死猪萌羊身世。青灵点破高阳的挣扎后离去，高阳终敲开死猪房门，告知巴秋池曾与死猪育有一女、即已觉醒的萌羊。死猪从震惊到坚毅，决定让女儿上战场并誓言保护。高阳转述柳轻盈梦中巴秋池一句“那孩子一点都不像老朱”，死猪看旧照泪笑“不像我，像妈妈”。另线，19号傍晚高阳与青灵在千禧楼摩天轮设下最后一个空间传送点，全城布下十二处传送网待战。全章以“不像”为眼，在身世揭秘与温情留白中收束战前夜。

**关键事件**
- 高阳遇百里弋，确认是否告知死猪萌羊身世
- 青灵点破高阳内心挣扎
- 高阳告知死猪萌羊是其与巴秋池之女且已觉醒
- 死猪决定让萌羊上战场并誓护其安全
- 高阳转述巴秋池梦中留言“不像老朱”
- 死猪看旧照哭笑“像妈妈”
- 高阳青灵设最后一处空间传送点，全城十二处

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 萌羊身世 | 迟来的真相揭示，用“孩子”一词制造爆点 |
| 死猪反应弧 | 从呆滞到坚毅的情绪递进，配旧照留白收尾 |
| “不像老朱” | 借亡者梦话点题，一句话完成情感升华 |
| 青灵点破 | 配角充当镜子，逼主角做决定 |
| 空间传送网 | 设定级布阵，为大战调度铺基础设施 |
| 百里弋自由论 | 用“你的自由”把抉择权交还主角 |

**逐章写法公式**
- 情绪流向：踌躇→震动→坚毅→温情→辽阔，由私密对话转向宏大布阵
- 节奏配比：身世戏七成，传送点三成，旧照段为情感着陆
- 结构公式：偶遇（百里弋）+ 镜子（青灵）+ 揭秘（死猪）+ 留白（旧照）+ 转场（布阵）
- 核心技巧：把“是否上战场”的伦理难题转化为父亲对女儿的信任抉择
- 卡点与伏笔：萌羊已知觉醒但仍被瞒；十二传送点将成大战机动关键；死猪“那孩子得上战场”埋风险
