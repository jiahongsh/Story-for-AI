## 第892章 何为自信

**概要**
王子凯一拳将麒麟如打水漂般轰飞，撞裂江堤；落地后他兴奋大喊“我刚揍了麒麟”，张伟极尽“自信”洗脑：称其为序列零天命，龙都只配提鞋，并透露高阳早交代“你不能杀人，我补枪”。随后本章大段回溯高阳如何发掘张伟“自信”可免疫精神伤害：天狗觉醒“安魂曲”那夜，高阳测试张伟，初测其秒睡大失所望；又询其“地狱之毒”中靠“毒不死我”自我暗示率先醒来，遂故意谎称张伟抗了十几秒、并以“神嗣看人特准”哄其建立自信。次日张伟仍约十秒睡去，天狗却竖拇指“酷”——其安魂曲已二级，证明张伟在进步。高阳由此确认“自信”属唯心主义：越信越能成。实验得出：毒素中等免疫、元素与物理少量免疫、精神近乎全免疫。张伟巩固自信后，高阳进一步试出他可经长期朝夕暗示帮他人建立免疫，遂定计让张伟与王子凯寸步不离，专研传销式洗脑，提炼出“凯神”这一兴奋词，将“凯神”与“免疫万象”等同。然安魂曲不等于万象，风险犹在：原案为斗虎拖傀儡、众人集火、王子凯骨刺偷袭，失败则撤；若同伴陷险，“自信组合”须冒险正面掩护撤退。高阳铭记曼蛇教诲：领袖要确保最终胜利而非当下仁慈。

**关键事件**
- 麒麟被打飞撞江堤，王子凯狂喜
- 张伟以“自信”话术给王子凯灌顶
- 高阳布局“连体组合”作底牌
- 天狗安魂曲初测张伟失败，高阳谎言激发
- 二次测试天狗点睛，确认自信=唯心主义
- 四类伤害免疫实验出结论
- “凯神”洗脑话术成型
- 原战术计划复盘与曼蛇教诲

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 王子凯中拳后的狂喜 | 用角色台词直给爽感，承上启下 |
| 高阳的“谎言”铺垫 | 先写失望再写哄骗，把心理操控过程透明化 |
| 天狗“酷”的妙用 | 借配角一句话反转实验结论，轻巧破疑 |
| 自信唯心主义结论 | 用分级实验数据（毒素/元素/物理/精神）支撑设定 |
| 凯神洗脑话术 | 把“传销视频”研究写进战前准备，荒诞又合理 |

**逐章写法公式**
- 情绪流向：胜拳的爽 → 回溯的从容 → 实验的曲折 → 结论的笃定 → 决策的沉重
- 节奏配比：开篇短促爆发，中段长幅回忆慢写，结尾回归战场决策
- 结构公式：战斗结果 + 大段战术回溯（对话驱动）+ 回扣现实决策
- 核心技巧：用“善意谎言+正反馈”展示心力操控；用设定实验把金手指讲圆
- 卡点与伏笔：自信对万象是否真免疫（未实战验证）；高阳的赌注代价
