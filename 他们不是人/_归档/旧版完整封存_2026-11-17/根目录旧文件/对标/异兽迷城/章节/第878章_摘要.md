## 第878章 江湖规矩

**概要**
一火霸发动六感裁判剥夺钟赫的视觉等感官，荆客骨刀斜砍其脖，魅影护体仅撕裂肌肉。钟赫欲翻栏跳江，流徒以江湖规矩强制单挑，街头混混式拳脚将其压制；荆客、安禾歌旁观，等待钟赫魅影褪去暴露致命处再补刀。钟赫渐占上风，魅影却开始褪指露颈，危机临界。白兔受九寒令从桥底穿梭跃出，一脚踢飞荆客救下钟赫；黄芙蓉同时赶到，以乌金拳套制住安禾歌的三棱刺。二人本是旧识，黄芙蓉丢还武器邀其以真本事一战。白兔未恋战再钻桥底，称另有重任。银发老者泼猴现身劝荆客投降，荆客怒斥战争无情，提双刀冲去，泼猴悲悯抬手言"对不住"。

**关键事件**
- 一火霸六感裁判盲钟赫，流徒江湖规矩强制单挑压制
- 荆客安禾歌伺机补刀，钟赫魅影临界褪去
- 白兔穿梭救钟赫、黄芙蓉旧识制安禾歌并还武器
- 泼猴现身劝降，荆客怒拒冲去

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 六感裁判定向剥夺感官 | 天赋"分敌我"机制，精准削弱不误伤 |
| 江湖规矩强制单挑 | 规则类天赋制造荒诞肉搏，打破战力差 |
| 白兔"踢飞救场"的迟来奇兵 | 桥底伏兵回收，节奏一松一紧 |
| 黄芙蓉旧识对峙的温情 | 敌我情谊线，软化对立 |
| 泼猴"对不住"的悲悯收束 | 高手压场留白，章节断在冲突前 |

**逐章写法公式**
- 情绪流向：诡谲剥夺 → 荒诞单挑 → 冷肃补刀 → 惊艳解围 → 悲悯收束
- 节奏配比：控制戏30%、肉搏20%、解围25%、旧识戏15%、高手登场10%
- 结构公式：感官剥夺 → 规则单挑 → 伺机补刀 → 奇兵解围 → 旧识对峙 → 高手压场
- 核心技巧：用"规则类天赋"制造以弱制强的荒诞张力，再用旧识温情与高手压场收束
- 卡点与伏笔：泼猴对荆客下何种手；白兔桥底"更重任务"为何
