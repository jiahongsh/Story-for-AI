## 第899章 第四回合

**概要**
决策阶段，姜爷提醒秦右勿被高阳"攻心"。秦右内心天人交战：他深知高阳上回合暗示杀己或真动手——自己当年的【追踪】引发摘星阁事件、【读心术】助千禧楼爆炸致柳轻盈、歌姬死，又刚重创高阳，高阳临死拖仇人陪葬合乎情理。了了则断言高阳必杀自己与姜爷，命秦右继续进攻，并以"空间搅拌机+枪神补枪"论证高阳不敢放任二人，必耗大能强杀其一；更以自身不防御立状，赌高阳杀姜爷，逼秦右同进退。秦右终被说服。第四回合开始，高阳行动力未因伤下降，图腾先绿，攻击目标却指向姜爷——了了猜中却忧心高阳之强。高阳燃起火焰之翼，将全部能量灌入右拳打出"焰拳"，火焰瀑布吞没姜爷，灰屏障保护了了、秦右。高阳赌上一切强穿姜爷防御，五秒后姜爷生死成谜。

**关键事件**
- 姜爷提醒秦右防攻心，秦右推算己或被杀
- 了了部署秦右进攻、己与姜爷防御
- 了了以不防御立状逼秦右共攻
- 高阳先动攻姜爷，焰拳吞没之
- 五秒后姜爷生死未明

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 秦右天人交战 | 多段内心独白，自我博弈 |
| 了了的论证链条 | 因果递推（空间搅拌机→必死） |
| 立状不防御 | 以自身为押注，强化说服 |
| 高阳伤势不影响行动力 | 反预期细节，维持压迫 |
| 火焰之翼→焰拳 | 能量收束的视觉奇观 |
| 灰屏障护旁观者 | 规则隔离，聚焦单点对决 |

**逐章写法公式**
- 情绪流向：秦右的疑惧 → 了了的强势说服 → 共谋的紧张 → 高阳出手的震撼 → 姜爷生死的悬吊
- 节奏配比：心理博弈约55%（秦右/了了决策），动作约35%（焰拳），悬念约10%
- 结构公式：敌方内部分歧（攻心奏效） → 指挥者以逻辑+立状统一 → 回合行动（反预期目标+全力爆发） → cliffhanger
- 核心技巧：用"内心独白"外化秦右的自私与恐惧；以"立状"将赌注具象化；用能量收束（翼→拳）造爆发
- 卡点与伏笔：姜爷是否死；高阳能量大耗后的虚弱；了了秦右下一手
