## 第656章 格老师

**概要**
本章以罐头的一场童年噩梦开场：五岁的她呼唤父亲却被浑身是伤、面无表情的父亲抛弃，惊醒后发现是高阳守在床边。高阳交给罐头一项秘密任务，让她以九嗣组织身份去接触作家格里高。下午三点，百川团黄连组的三人——组长黄连、5级魅影钟赫、谈判专家横木——驱车来到东豫区秋山小区（别名离城新墓园，因正对坟山而房价低廉、低收入者聚集）。三人刻意不露迷失者印记，带烟、酒、书作见面礼上门拉拢，却连敲多次门才等到邋遢憔悴的格里高应门。横木以"知名作家"身份攀谈，借笔名"格里高"出自卡卡卡《变化记》的典故递上《卡卡卡传》作为见面礼，格里高神色稍缓，终于放三人进门。本章完成从梦境到现实任务的过渡，并正式引出拉拢强者的组织博弈主线。

**关键事件**
- 罐头被童年被父亲抛弃的噩梦惊醒，发现高阳在床边
- 高阳将秘密接触任务交给罐头，罐头主动请缨
- 介绍秋山小区正对坟山、廉价出租、低收入者聚集的地理背景
- 百川团黄连、钟赫、横木三人带礼物驱车登门拉拢格里高
- 电梯内三人讨论礼物与策略，黄连叮嘱钟赫闭嘴交给横木
- 格里高门铃损坏、反复敲门后才现身，形象邋遢憔悴
- 横木以作家身份与笔名典故破冰，递书获准入门

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 童年噩梦中的父亲抛弃 | 梦境预叙，以温情画面反衬创伤，埋性格伏笔 |
| 秋山小区=离城新墓园 | 地名的反差命名+环境白描，营造诡谲廉价感 |
| 百川团三人组队形 | 外貌特写逐一定妆（黑西装/模特身材/平庸亲和） |
| 见面礼的差异化选择 | 以"烟酒书"细节体现角色性格与谈判话术 |
| 格里高的邋遢出场 | 慢镜头式外貌堆砌（鸡窝头/血丝眼/啤酒肚） |
| 笔名典故破冰 | 文化梗精准命中虚荣，软化对抗姿态 |

**逐章写法公式**
- 情绪流向：梦境感伤→清醒尴尬→任务紧张→登场神秘→谈判试探
- 节奏配比：梦境慢（约1/3）→现实任务过渡（1/6）→环境铺陈（1/6）→上门博弈（1/3）
- 结构公式：噩梦钩子 + 任务布置 + 地理背景卡 + 反派组团登场 + 目标人物亮相
- 核心技巧：用"廉价坟景小区"反讽严肃的组织拉拢，以礼物细节做人物速写
- 卡点与伏笔：罐头任务内容未明说；格里高的天赋实力留白待揭
