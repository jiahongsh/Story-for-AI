## 第1243章 终极邪神

**概要**
本章是侠水基地桌游的延续，以终极邪神为戏眼。王蔚洇征求同伴意见后推开石门，格里高关灯以烛台代光，绘声讲述阴冷之风自众人心中钻出黑线、凝成黑钥匙、召出终极邪神，随即开灯戴黑面具跳上沙发猖狂自称迷宫之主。五人齐喊招式合攻却被化解，张伟火大称都六神装了半路冒犯规邪神，婷婷抱怨，唯萌羊因见过更不讲理的现实而默然。格里高以隐藏BOSS喻意外先至辩解，张伟反呛游戏里找真实脑袋有问题。邪神给出献祭一人的两难，张伟弃局时撞见高阳立于格里高身后，惊喜问安；萌羊唤黑马哥哥扑抱，王蔚洇觉其更像大人称黑马叔叔。高阳夺过说明书念无字拒绝邪神再给机会丢回，格里高抗议神嗣乱改剧本，就坡下驴重开赌局，将骰子交王蔚洇祈抛定幸运。

**关键事件**
- 王蔚洇征询后推开石门
- 格里高演绎心中黑线召出终极邪神
- 五人合攻被化解、张伟吐槽战力
- 邪神两难选择、张伟撞见高阳
- 高阳乱改剧本破次元收束冲突
- 格里高重开赌局交骰子定幸运

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 石门抉择 | 借每个角色性格决定行动，群像速写 |
| 心中黑线 | 用阴冷之风来自心中将游戏恐怖内化为心理 |
| 邪神扮演 | 格里高戴面具跳沙发，夸张反差制造笑点 |

| 高阳乱改剧本 | 用念无字说明书破次元，轻松收束冲突 |
| 骰子定幸运 | 以王蔚洇祈祷抛骰承接下一章 |

**逐章写法公式**
- 情绪流向：童趣—惊悚—热闹—诙谐—惊喜—欢乐
- 节奏配比：游戏对话九成，动作点缀一成
- 结构公式：游戏推进遭遇BOSS→角色吐槽破紧张→高阳介入破次元→重开赌局
- 核心技巧：以桌游为容器盛放群像与隐喻（邪神=未知命运）
- 卡点与伏笔：王蔚洇抛骰结果、高阳神嗣身份被调侃
