## 第772章 神爱世人

**概要**
明镜笃定二人能抵达彼岸，描述梦中化作极光飞出迷雾、抵达世界尽头即是彼岸，那里有伟大温柔、慈爱悲悯、无所不知的神——「神爱世人，世人爱神；众生爱世界，世界爱众生」。尘埃笑称这爱来爱去「好傻」，明镜却说神的爱永恒，而二人彼此之爱虽短暂却已拥有。翌日下午三点，雪国机场走出八人伪装游客团：无色扮导游，奶奶李某人、父亲青龙、母亲柳轻盈、大女儿了了、女婿钟赫、小女儿六霜、大舅死猪。了了本已退居情报幕后却被迫出战，靠【从心】序列187的「低调气场」与「求饶降仇」平替千面人。钟赫作为斗虎新派来的「影鼠二代」陪同考核，陷于前领导前同事的修罗场。据柳轻盈情报尘埃藏极光镇，唯一官道是长途汽车站，众人入住旅馆、李某人却坚持按兵不动且不言原因。夜深李某人与炎凉通话后静坐窗前，柳轻盈借邀了了泡温泉支开她单独与李某人密谈。了了至女士温泉撞见无色与六霜——摘星阁一役消耗未复的六霜正与对麒麟工会无感的无色同池尴尬。无色问六霜是否事先已知摘星阁结果，六霜坦然「知道，要全歼九嗣」，无色怒其连投靠九嗣的两个孩子都不放过。

**关键事件**
- 明镜描绘彼岸与「神爱世人」信仰，尘埃以彼此之爱作解
- 八人游客团空降雪国，了了凭【从心】低调气场掩饰队伍
- 钟赫以影鼠二代身份陪同，陷前同事修罗场
- 李某人抵极光镇后按兵不动，夜与炎凉通话
- 柳轻盈支开了了欲单独密谈李某人
- 温泉中无色质问六霜摘星阁全歼与无辜孩童

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 神爱世人台词 | 借兄妹对话把宗教命题写成缠绵情话，柔化反派 |
| 八人家庭伪装清单 | 用「全家福」角色分配表，信息一目了然且带喜感 |
| 从心双能力 | 以功能解说带出队伍为何非她不可，坐实工具人价值 |
| 影鼠二代修罗场 | 借人物旧关系网制造戏剧张力，不费额外笔墨 |
| 按兵不动留白 | 李某人不言原因，用「等」制造读者追问 |
| 温泉质问前置 | 把摘星阁旧罪在温泉私密空间引爆，为下章冲突蓄势 |

**逐章写法公式**
- 情绪流向：极光下的信仰柔光 → 机场伪装的轻喜剧 → 旅馆的悬停 → 温泉的暗流
- 节奏配比：信仰对话（15%）＋游客团组建（35%）＋按兵不动（20%）＋温泉相遇（30%）
- 结构公式：A线苍母兄妹（信仰收束）→ B线海川小队（集结/潜入/内部张力）
- 核心技巧：用「家庭cosplay」喜剧外壳包裹严肃潜入，再用温泉把旧罪矛盾推到台前
- 卡点与伏笔：李某人为何按兵不动；了了被支开后柳轻盈要谈什么；摘星阁血债将在六霜线引爆
