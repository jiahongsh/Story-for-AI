## 第828章 动手

**概要**
大寒夜九点，麒麟赴李夫人办公室追问知识符文融合进度：李夫人未融，须圣水，而手中木乃伊提纯尚待时日，杂质还会致怪物化。麒麟疑高阳欺骗，李夫人以“掉包会打草惊蛇”反驳。麒麟叹高阳成长迅猛、已悟绝对防御并具生兽血脉，且“命运锁链”所锁之物连先知亦不可窥。为取更多筹码，麒麟决走险棋：与李夫人同处并以万象自我暗示“害我者即杀你”，逼其服复活药借先知预判。戴歪脸面具、换赛博义肢的炎凉携贾博士所制之物入场，麒麟定“明日动手”、交炎凉执行。同刻情报部门柳轻盈、婷婷值守，婷婷兴奋分享观影。

**关键事件**
- 麒麟夜访问符文融合，李夫人称须圣水且未融
- 麒麟疑高阳欺骗，二人就掉包说交锋
- 叹高阳绝对防御与生兽血脉，命运锁链避先知
- 麒麟决走险棋，以万象挟李夫人借先知预判
- 炎凉携贾博士所制之物入场，定明日动手
- 同刻监控室柳轻盈婷婷值守，闲聊观影

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 圣水门槛 | 用“杂质致怪物化”的限制抬高八级突破成本 |
| 掉包之争 | 借两方推演写高阳布局的不可测 |
| 命运锁链 | 一句话设定补全，解释先知失效的边界 |
| 万象挟持 | 用“自杀式自我暗示”把预判变成人质博弈 |
| 双线并置 | 阴谋线与监控闲笔同夜并放，蓄势待发 |

**逐章写法公式**
- 情绪流向：冷峻商议 → 对峙猜忌 → 忌惮评估 → 孤注一掷 → 山雨欲来
- 节奏配比：办公室密谋(80%) + 监控室闲笔(20%)
- 结构公式：问符文(设限) → 疑阳(博弈) → 评估威胁 → 定险棋(绑先知) → 定动手日 → 同刻闲笔反差
- 核心技巧：把“反派行动计划”用对话逐层摊开，让读者比主角先知危机
- 卡点与伏笔：麒麟明日动手目标、知识符文最终归属、李夫人先知是否准确、炎凉所携之物用途
