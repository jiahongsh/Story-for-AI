## 第898章 一只臭鸟

**概要**
回合继续，了了上回合蓄力，本回合【枪神】两发子弹洞穿鹦鹉头胸，鹦鹉当场死亡，贾博士假意悲痛欲绝、跪地哭丧，实则演戏。秦右对此士气大振，发动"荆棘地刺"，高阳虽尽力闪避仍被三根荆棘刺中小腿、侧腰与背部，血槽减损四分之一。贾博士攻向姜爷，被其空间转换完美闪避。尼古照旧放弃行动、絮叨布道。回合结束、屏障隔音后，高阳发现明镜浮雕之脸更模糊，并拆穿贾博士"演戏"——贾博士坦言给鹦鹉的"药"只是身上搓的泥丸，专为诱使敌方重视、替高阳争取生存空间；又透露鹦鹉大脑心脏已移位、喂过复活药，可复活或克隆。高阳叹服其天才布局。他表面镇定实则心里没底，刻意以冷静姿态加剧了了的紧张、诱其微表情泄密。末了，高阳隔屏障向秦右比出抹脖手势：下回合，杀你。

**关键事件**
- 了了枪杀鹦鹉，贾博士假哭演戏
- 秦右荆棘地刺重创高阳
- 贾博士坦白泥丸诈敌、鹦鹉可复活
- 高阳以镇定攻心，诱了了露微表情
- 高阳向秦右比颈示杀

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 贾博士假哭真演 | 情绪反转，先悲后"废话"破功 |
| 荆棘地刺的生成过程 | 动态描写（树苗→三米刺）递进展现 |
| 泥丸诈敌 | 无实物骗局，信息战巧思 |
| 鹦鹉可复活/克隆 | 留活口设定，消解死亡重量 |
| 高阳攻心策略 | 以表情为武器，心理博弈 |
| 比颈手势 | 视觉化威胁，简短动作收章 |

**逐章写法公式**
- 情绪流向：了了的轻松得手 → 贾博士的假悲 → 高阳受创的压抑 → 贾博士坦白的释然 → 高阳攻心的冷笑 → 抹脖悬念
- 节奏配比：动作约35%（枪杀/荆棘），对话博弈约50%（贾博士坦白/高阳攻心），设定约15%
- 结构公式：回合行动收尾（击杀+受创） → 屏障隔音后的信息揭示（诈敌真相） → 心理战升级（攻心+威胁预告）
- 核心技巧：用"假哭→破功"完成角色反差；以"泥丸诈敌"展示信息战；用镇定表情作攻心武器
- 卡点与伏笔：鹦鹉能否复活；高阳能量见底；下回合杀秦右的威胁是否兑现
