## 第1206章 以身入局

**概要**
千禧楼内，九寒向高阳、贾博士剖白完整战术：贪婪当年故意交底"无法窥探你与龙的命运"，意在打明牌、留后路。要破它，须让贪婪确信龙与高阳无暇对付自己——唯有九寒死、使其占有无缺命运，方能坐实"龙对付傲慢、高阳对付嫉妒"的假象，诱其现身。贾博士以记忆裁缝删改九寒相关记忆不留痕迹；死亡成为最真实的诱饵。高阳点破诈骗本质在认知局限：自私者无法理解无私牺牲。九寒三请获批。实验室门开，陈萤一身跑步装寻来，九寒眉目温柔，似有私语相托。本章以"以身入局"收束布局，将牺牲升华为胜天半子的谋略。

**关键事件**
- 九寒剖白：贪婪故意交底是打明牌留后路
- 破局关键：九寒以身入局，死而赠命运诱贪婪现身的假象
- 贾博士以记忆裁缝删改九寒记忆造不留痕迹的假象
- 高阳点破诈骗本质在认知局限，自私者难解无私
- 九寒三请获批；陈萤跑步装寻来，九寒欲私语相托

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 故意交底 | 以"打明牌"重读旧设定，翻出阴谋层 |
| 以身入局 | 用"死亡是最真实诱饵"凝练核心谋略 |
| 记忆造假 | 以命运/记忆二分论证骗局可行性，逻辑自洽 |
| 认知局限论 | 用"守财奴不信穷人散财"类比点题，通俗深刻 |
| 陈萤寻来 | 以跑步装日常切入，于谋略高潮回落温情 |

**逐章写法公式**
- 情绪流向：沉静（剖白）→ 凝重（牺牲）→ 悲怆（获批）→ 温柔（陈萤）
- 节奏配比：战术复盘 30% / 阴谋重读 20% / 以身入局 30% / 认知论点题 10% / 陈萤寻来 10%
- 结构公式：重读"故意交底" → 破局须死赠命运 → 记忆造假论证 → 认知局限论 → 三请获批 → 陈萤寻来私语
- 核心技巧：以"命运/记忆二分"自洽骗局逻辑；用"守财奴不信穷人散财"类比通俗点题
- 卡点与伏笔：九寒"我的命我做主"定下牺牲基调；陈萤跑步装寻来暗示二人关系线将收；记忆造假为前情（1199高阳删记忆）呼应
