## 第634章 不讲武德

**概要**
王子凯被蹬飞坠入泳池，破水而出喊出"不讲武德"，手背弹出骨刺。平行闪回中，灰雄巨熊在街头发动嘲讽逃窜，遭青灵冰龙拦截、古狮狮人合体追猎、森鹤植物阻路，眼看脱身却被叶片附着的冰霜冻成冰棺含笑而亡。花龟悲见故人，与六霜森鹤三头六臂合体反杀三头高级兽，觉悟中调虎离山计。回到前院，王子凯骨刺突袭割伤青龙手臂，坦承奉兄弟令只废不杀，青龙恍然七影已算准其无限进化底牌。

**关键事件**
- 王子凯泳池破水，亮出骨刺，与青龙隔空叫阵
- 灰雄街头逃窜闪回：冰龙、狮人、植物三重拦截层层加码
- 森鹤冰霜附叶封棺，灰雄含笑发动对命运的嘲讽而亡
- 花龟悲恸，三头六臂合体反杀三头高级兽，识破调虎离山
- 王子凯骨刺割伤青龙手臂，展现前所未见武器
- 不杀令揭底：七影算准无限进化，青龙以杀心之差立誓

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 不讲武德台词 | 以角色口语化吐槽点题，强化王子凯狂傲人设 |
| 冰棺之死 | 用"冰晶之花层层绽放"的意象化描写渲染壮烈 |
| 花龟人情伏笔 | 借女儿手术旧恩，使反派击杀带愧疚与悲情 |
| 三头六臂 | 直接说明合体增益与无主脑缺陷，埋默契隐患 |
| 骨刺破防 | 以青龙"快忘了被砍伤"的惊骇侧写武器威胁 |

**逐章写法公式**
- 情绪流向：王子凯的戏谑 → 灰雄逃亡的紧张 → 冰棺悲壮 → 青龙警觉升级
- 节奏配比：闪回占六成（逃亡—死亡—合体），现线占四成（对峙升级）
- 结构公式：现线小冲突 + 长闪回（诱饵 demise） + 现线揭示收束
- 核心技巧：双时间线并置、以意象写死、借设定升级威胁
- 卡点与伏笔：灰雄之死强化诱饵代价；骨刺破青龙肉身，颠覆其无敌认知
