## 第1205章 归墟

**概要**
主宰领域内，龙将贪婪定格半空、迫其匍匐神座之前，点破它并非输给龙，而是输给自身的贪婪——若始终藏于命运便无人能擒。龙降下第七道审判"归墟"：天地化为铅色苍穹与迷雾汪洋，巨型深渊吞纳环形瀑布，永难填满。贪婪膨胀为乌云妄图塞住深渊，却被抽丝剥茧化为黑线吸入；其红色竖眼放射万千叠影、倾倒毕生占有的命运切片，如胶片之雨坠入无底。最终仅余一道简笔视线——最初的贪欲本相，被黑线牵拽散入深渊。审判落幕，龙唯余淡淡倦怠。场景转千禧楼，九寒向高阳直言已看穿布局：龙才是贪婪对手，自己一组仅为诱饵，并提出改进方案。

**关键事件**
- 龙将贪婪定格神座前，点破其败于自身贪婪
- 龙降第七审判"归墟"，深渊吞纳永难填满
- 贪婪膨胀乌云欲塞深渊失败，被化为黑线吸入
- 红眼倾倒毕生命运切片如胶片雨坠入无底，终余简笔贪欲本相
- 场景转千禧楼，九寒向高阳直言龙才是对付贪婪之人、自组为诱饵并提出改进

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 归墟意象 | 以"铅色苍穹加环形瀑布深渊"构建宏大审判空间 |
| 乌云塞渊 | 用"塞子"比喻贪婪垂死挣扎，荒诞而悲壮 |
| 命运胶片 | 以"胶卷盘抽出电影胶片"喻占有的命运倾泻 |
| 简笔贪欲 | 回收至"一道视线一念贪欲"的本相，首尾闭环 |
| 龙之倦怠 | 以"淡淡倦怠"反写神性冷漠，余味收束 |

**逐章写法公式**
- 情绪流向：恐惧（贪婪绝境）→ 绝望（归墟）→ 悲壮（倾泻）→ 倦怠（审判毕）
- 节奏配比：神座审判 20% / 归墟空间 15% / 挣扎塞渊 20% / 命运胶片雨 30% / 转场布局 15%
- 结构公式：龙点破败因 → 第七审判归墟 → 乌云塞渊失败 → 红眼倒命运（本相回收）→ 龙倦怠 → 转千禧楼九寒剖白
- 核心技巧：以"铅色苍穹加环形瀑布深渊"构建宏大意象；回收至"一念贪欲"简笔本相，首尾闭环
- 卡点与伏笔：九寒"龙才是对手、自组为诱饵"点出后续两章布局主线；归墟"填不满"隐喻贯穿
