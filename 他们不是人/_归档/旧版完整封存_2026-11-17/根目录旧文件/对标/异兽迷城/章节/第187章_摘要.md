## 第187章 逃生

**概要**：十二人转身就跑，打算回工地取装备，可余鹏谅尸变后带着丧尸群从教学楼侧面冲出拦路，身后又有丧尸追击，众人被迫冲进教学楼楼梯间。罐头被丧尸抓住脚踝，灰雄和高阳联手把她救下，队伍转进三楼，前后又遇丧尸，九寒当机立断让老乔撬保健室的门锁。九寒、黑雀、高阳、灰雄、曼蛇五人殿后，黑雀扭断丧尸脖子却险些被咬，西燃抱着灭火器砸碎丧尸头骨，点出"必须破坏头部"的铁律——黑雀是没有童年的孤儿拳手，一句"谢了"道尽心酸。楼道口六只丧尸被众人三十秒内击毙，老乔终于开锁，众人钻进保健室抵住门，丧尸被别处的尖叫声引走。缓过一口气后，罐头掀开纱帘，发现保健室的病床下有人影。

**关键事件**：1.回工地路线被尸变余鹏谅带领的丧尸群截断，众人被迫冲进教学楼楼梯间 2.五人殿后，黑雀扭脖遇险被西燃灭火器救下，点出"必须破坏头部"的杀尸铁律 3.老乔撬开保健室门锁，众人脱险，罐头发现病床下有人影

**逐章写法公式**：

- **情绪流向**：起：绝境（逃路被断） → 承：鏖战（五人殿后） → 转：脱险（开锁进室） → 合：新疑（纱帘人影）
- **节奏配比**：慢铺垫 10% / 快冲突 70% / 爽点爆发 15% / 悬念留白 5%
- **本章结构公式**：逃路被断（绝境压迫） + 楼梯救援（险中求生） + 开锁殿后（双线鏖战） + 保健室脱险（喘息加新钩）
- **本章核心技巧**：全程高密度战斗中用"开锁倒计时"作主线节拍器，穿插角色身世做情绪缓冲
- **卡点与伏笔**：结尾卡点：悬念卡点——罐头掀开纱帘发现病床区"好像有个人"，下章期待人影身份与敌友属性；埋设/回收伏笔：黑雀"没看过丧尸电影"的身世 → 角色背景铺垫；老乔"觉醒前是小偷" → 队伍分工笑点；被咬伤者 → 尸变规则悬置
