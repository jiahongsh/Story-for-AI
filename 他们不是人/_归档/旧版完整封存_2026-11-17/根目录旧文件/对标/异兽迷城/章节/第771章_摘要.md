## 第771章 生命之树

**概要**
柳轻盈离办公室后，麒麟征询李某人意见。李某人认为可合作：清算尘埃既能打击苍母教，又可促进合并后的内部团结与士气；麒麟仍存戒心，疑柳轻盈是九嗣苦肉计，李某人则以其与死猪十年执念佐证绝非演戏，并主动请缨随行，凭【先知】在三天内若有生命威胁会浮现模糊画面以规避风险，更笑言要改变「老太婆无用」的形象。镜头切至雪国极光镇圣山教堂，被绑的林大健困于忏悔室、虚弱濒幻，对面的尘埃以「生命是原罪」等偈语戏弄后离去。尘埃穿过林地至灰色荒原巨石，与坐看极光的明镜（律起）会合，坦言一路留痕、神嗣或明日追来，明镜称已备妥。兄妹静观极光，尘埃追问光与世界的来处，明镜答「来自生命之树」——那是他们寄宿人类前常梦见的、结满果实坠入河流的巨树。尘埃掏出泛黄兄妹照，说不愿忘记自己的脸；明镜劝其外表不重要、万物有灵，尘埃靠其肩，轻问二人能否抵达彼岸。

**关键事件**
- 李某人力主与柳轻盈合作，麒麟保留苦肉计疑虑
- 李某人以先知能力请缨随行，欲重塑形象
- 林大健囚于圣山教堂忏悔室，尘埃以原罪偈语戏弄
- 尘埃与明镜荒原会合，确认诱饵布局就绪
- 生命之树设定揭出：兄妹梦中的起源之树与果实意象
- 泛黄照片与灵魂之辩，尘埃倚明镜肩问彼岸

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 十年执念破苦肉计疑 | 用时间长度作可信度论据，四两拨千斤 |
| 先知模糊画面预警 | 以能力设定自然解释李某人敢亲赴险地 |
| 忏悔室囚禁的仪式感 | 宗教空间＋遍体鳞伤，强化受害者无辜与反派冷酷 |
| 原罪偈语 | 用反派台词外化信仰内核，不另作说明 |
| 生命之树梦境意象 | 白墙黑墙/眼睛手的河流/巨树果实，以超现实画面承载世界观 |
| 泛黄照片与倚肩 | 物件＋肢体语言双写兄妹羁绊，柔化反派 |

**逐章写法公式**
- 情绪流向：海川团会议的分寸权衡 → 雪国教堂的阴森 → 荒原极光的空灵 → 兄妹温情的怅惘
- 节奏配比：合作决策（30%）＋林大健囚禁（20%）＋荒原会合（20%）＋生命之树/彼岸（30%）
- 结构公式：A线海川团定计 → B线雪国诱饵现场（受害者/布局者双视点）
- 核心技巧：双线冷调互文，用「会议理性」对照「极光诗意」，把反派写成有信仰的兄妹
- 卡点与伏笔：先知随行降低行动风险；林大健饵待九嗣/海川团入局；生命之树起源设定铺开
