## 第1286章 故人

**概要**
了了点破真相：海中见血肉、沙上见枯骨并非幻象，而是真实形态切换——正因早立沙地只见白骨，低势令千里眼漏看。张伟得意“海洋生、沙漠死，它介于生死”，格里高觉近而未达，陈萤也自认猜错，张伟自嘲成小丑。忽而身后白骨拔地、大地震颤，朱雀发动无敌，残骨冲沙成暴，拼成白色宫殿般的封闭迷宫。陈萤断海沙两界皆未死，仅形态异，生命力更旺。张伟、王子凯起跳验证却剧烈干呕，众好奇皆跳，尖叫呕吐；唯天狗抱萌羊因属“沙视角”不跳。高阳亦跳，遭身心双重冲击：巨物体内如流脓伤口，汇集最血腥丑陋腐败的生命“污染”。脱困后回蓝沙，沙丘下暖橙光引众靠近，竟见汉堡薯条可乐与穿童礼服的落寞男孩——小天。陈萤摘戒解无敌抱其泣不成声，未戴面具苍狗立于身后。萌羊含泪相认，小天笑言想她与洇洇；白露冷问把戏，苍狗喊冤，留“也是投影？”之疑。

**关键事件**
- 了了点破双态真实切换，千里眼漏看之谜解
- 白骨暴起成迷宫，陈萤断其未死
- 起跳验内，巨物体内如生命污染
- 迷宫脱困回蓝沙，沙下微光引路
- 故人小天现身，陈萤悲喜相拥
- 苍狗真容、萌羊相认、投影之疑

**逐章写法公式**
- 情绪流向：通透 → 自嘲 → 诡谲 → 错愕 → 厌恶 → 松驰 → 悲喜 → 悬疑
- 节奏配比：解密三成，迷宫惊变三成，体内厌恶二成，故人温情两成
- 结构公式：悬念回收 + 困境突降 + 生理验真 + 脱困转暖 + 故人点题留白
- 核心技巧：以“小天”这一情感锚点将抽象生命主题落回人物羁绊
- 卡点与伏笔：留“小天是否投影”“苍狗真意”两悬念，承接前情
