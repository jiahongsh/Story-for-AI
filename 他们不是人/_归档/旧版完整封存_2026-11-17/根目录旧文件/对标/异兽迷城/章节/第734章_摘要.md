## 第734章 小瞧的代价

**概要**
核东切裂石墙却不见高阳，警觉防瞬移偷袭；叨哥闭眼发动【心眼】，捕捉到地下杀气高呼"小心脚下"——一只手幽灵般破土抓住核东脚踝。6 级火焰在 2000 多点精神力下，纵有偏科守卫元素防御翻倍，核东仍如干稻草被火柱焚成焦骨，复活药失效。死前他只余懊恼：是小瞧了对方。章节回溯高阳的天赋配置——派青灵接高欣欣时复制了红晓晓【游戏玩家】与可又【奇怪】，遇袭后救下奈奈张伟、给蔻蜗注药并顺手复制【穿梭】，方才遁地得手。高阳匕首刺叨哥咽喉，却被炎凉【空间魔术】错开距离、空间搅拌机挖去半块臂肌；C 药剂又与酥魅毒液紊乱反伤。微小珞的玩具机器人降下扫射，高阳提前打出最后底牌【奇怪】口哨：一秒一断的哨声恰好补齐瞬移间隔、抢先 0.1 秒反应窗，于叨哥眼中如幽灵卡顿挪移，三次哨声后焰拳撕碎机器人。叨哥丧失战意欲逃，终被乌金匕首穿心烧穿。末了高阳惊觉：炎凉早预判他会杀叨哥，直接对同伴下死手、眼都不眨——这便是"小瞧的代价"。

**关键事件**
- 高阳遁地抓踝，火柱焚杀核东
- 核东死前懊恼自己小瞧对方
- 回溯高阳复制游戏玩家/奇怪/穿梭的天赋组合
- 高阳刺叨哥被炎凉空间魔术破，C药剂与毒液紊乱
- 微小珞玩具机器人扫射压制
- 高阳发动奇怪口哨，一秒卡顿无缝瞬移
- 焰拳撕机器人，叨哥穿心死，炎凉预判杀己方

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 心眼"地下杀气"的悬念回收 | 把上章"墙后人不见"立刻兑现为遁地杀招 |
| 核东"是我小瞧了他"的临终独白 | 以反派自白点题，完成标题呼应 |
| 天赋组合的战前回溯 | 倒叙解释"为何能遁地/为何能控场"，补设定 |
| 空间魔术的距离错层 | 用"不是闪现是空间变了"颠覆直觉，写炎凉老辣 |
| 口哨卡顿补瞬移间隔 | 把两个独立天赋缝成连招，呈现"行云流水" |
| 炎凉预判杀同伴的冷酷 | 以"眼都不眨"把反派无情推到顶点，留震撼尾 |

**逐章写法公式**
- 情绪流向：暗杀惊悚 → 反派悔悟 → 设定回溯 → 连招炫技 → 冷酷收尾
- 节奏配比：核东之死 25%，回溯 15%，对峙破局 25%，口哨连招 25%，炎凉收尾 10%
- 结构公式：暗杀（兑现）→ 点题（自白）→ 补设（回溯）→ 炫技（连招）→ 升华（反派无情）
- 核心技巧：用"小瞧"作题眼贯穿——核东小瞧丧命，炎凉不小瞧反杀己方
- 卡点与伏笔：高阳左手废/小腿受限（重伤伏笔）；炎凉空间魔术老辣（终极对手钩子）；奇怪口哨机制（后续战术资产）
