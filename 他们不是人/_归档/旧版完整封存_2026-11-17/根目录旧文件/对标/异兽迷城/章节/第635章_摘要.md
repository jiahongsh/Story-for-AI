## 第635章 三头六臂

**概要**
承接闪回，灰雄察觉体表异样，发现森鹤叶上附着的冰霜将其层层封入冰晶之花凝成冰棺，含笑发动对命运的嘲讽而亡。花龟悲见故人头颅，与六霜森鹤三头六臂合体反杀三头高级兽，觉悟中调虎离山。回到前院时间线，王子凯骨刺从天突袭割伤青龙手臂，青龙惊觉肉身首破；王子凯坦承奉兄弟令只废不杀，青龙恍然七影已将其无限进化算作底牌，遂以"怀杀心者与不怀杀心者之差"立誓决胜。

**关键事件**
- 灰雄死前察觉冰霜异变，冰晶之花封棺，含笑而亡
- 花龟悲恸，三头六臂合体，反杀三头高级兽并识破调虎离山
- 前院线：王子凯骨刺突袭，青龙手臂首破
- 无限进化迟迟未触发，青龙研判王子凯两大劣势
- 不杀令揭底，七影算准青龙底牌
- 青龙以杀心之差宣言，决斗升格

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 冰晶之花意象 | 用"绝美冰棺""层层叠叠"把死亡写成凄美画面 |
| 三头六臂机制 | 说明增益与无主脑缺陷，暗示合体风险 |
| 无限进化设定 | 以"为何未触发"的疑问制造悬念与战力悬念 |
| 杀心之差 | 借青龙独白点出本作核心对决逻辑：动机决定胜负 |
| 双线收束 | 闪回线以死收，现线以宣言收，情绪对位 |

**逐章写法公式**
- 情绪流向：灰雄濒死的悲壮 → 花龟哀而转狠 → 前院对峙的惊与醒
- 节奏配比：闪回收尾四成，前院对峙六成，末句蓄势
- 结构公式：闪回终幕（诱饵死） + 现线揭示（底牌亮） + 宣言钩子
- 核心技巧：意象化死亡、设定驱动悬念、独白点题
- 卡点与伏笔：无限进化未触发埋后续反杀；杀心之差为终局对决定调
