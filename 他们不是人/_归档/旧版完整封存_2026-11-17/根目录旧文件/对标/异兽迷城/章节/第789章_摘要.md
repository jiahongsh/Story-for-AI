## 第789章 反击

**概要**
无色组展开全面反击。艾曼6级【臂力】甩出带金尾迹的乌金回旋镖，具自动校准与半跟踪之力；微小珞的机器人玩具赋能成三米高蓝色能量机甲，高射炮嘶鸣；林福以【符咒术】舞桃木剑指天，黄色符咒如群鸟扑向奈奈；回车则扮啦啦队长以【心理暗示】高喊"能打中她"，放大己方命中、削弱奈奈闪避。奈奈虽及时升空，回旋镖却在射手领域加持下紧追，她扭身躲过却左臂被割得深可见骨。陈萤急令"快变小"，奈奈缩至正常大小，背上炸弹与陈萤失去支撑坠向陨石坑——回旋镖折回再击，奈奈缩成拳头大才躲过。坠落中的陈萤本可活命，却被仇恨驱使想借超近距引爆与敌同归于尽，掏枪欲打中炸药箱。千钧一发，奈奈俯冲捞住她，以"命属吾王不准死"拒其赴死。奈奈升空时大腿中弹，陈萤的C药剂脱手；全速俯冲闪避中，九寒示警前方五十米是林福的符咒"天罗地网"。陈萤叫奈奈弃己逃走，奈奈却攥紧她冲向网墙——减速必死，鱼死网破或有一线。

**关键事件**
- 无色组多天赋集火奈奈（回旋镖、机甲、符咒、心理暗示）
- 奈奈左臂受创、缩身坠弹，陈萤起同归于尽之念
- 奈奈捞人拒其赴死，二人撤离时大腿中弹、C药剂脱手
- 前方天罗地网绝境，奈奈携陈萤鱼死网破冲阵

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 多天赋集火 | 用"回旋镖+机甲+符咒+暗示"的并列镜头，写敌方团队战的层次 |
| 左臂受创 | 以"深可见骨鲜血四溅"的特写，把压迫感钉在身体上 |
| 缩身坠弹 | 用"正常→拳头大"的连续变小，把闪避写成惊险的尺度游戏 |
| 同归于尽之念 | 以陈萤"靠仇恨支撑活下去"反写求死，把悲绝推到自觉 |
| 命属吾王 | 用奈奈中二台词拒死，把搞笑人设拧成重情羁绊 |
| 天罗地网收束 | 以"减速必死、鱼死网破"的二选一，把章末卡在绝境钩子上 |

**逐章写法公式**
- 情绪流向：集火压迫 → 受创惊险 → 悲绝求死 → 羁绊拒死 → 绝境钩子
- 节奏配比：集火 30% / 受创闪避 30% / 心理 20% / 绝境收束 20%
- 结构公式：敌方多天赋集火 + 奈奈受创缩身 + 陈萤求死念 + 奈奈捞人拒死 + 天罗地网绝境
- 核心技巧：用"缩小"这一动作反复制造惊险与反转，并把陈萤的复仇黑化与奈奈的守护执念对撞，章末以绝境二选一卡死
- 卡点与伏笔：伏笔——陈萤求死线（关联790是否真死）；C药剂脱手（后续疗伤缺口）；奈奈左臂大腿伤（战损累积）；符咒天罗地网如何破（790王子凯线呼应）；回车心理暗示写敌方辅助机制
