## 第1193章 闹鬼

**概要**
青扬大桥的“恋爱游戏”继续推进。张伟在鸦鲨指导下用一周时间刷属性：上课遇不到周箐、打工攒钱增体格、深夜扮鬼吓情侣。他急于去酒吧撞周箐被鸦鲨劝阻，转而按行程在教室、社团多方打听线索。白露给出三段对话，其中“小树林闹鬼”的突兀提示被鸦鲨解读为关键伏笔；张伟还从白露口中得知自己才是“主角脸”，而鸦鲨气质只像女主弟弟。酒吧打听无果后，深夜行动点张伟果断选择小树林扮鬼。本章是典型的“刷副本查攻略”结构，以轻松游戏感包裹紧迫的时间压力，基调诙谐、悬疑而暗藏危机。

**关键事件**
- 张伟一周刷属性，周箐始终缺席课堂
- 张伟欲去酒吧被鸦鲨劝阻，按行程查线索
- 白露给出三段对话，小树林闹鬼成突兀伏笔
- 白露揭示自己始终停留同一场景，并点评主角气质
- 张伟酒吧打听周箐无果，确认线索断点
- 深夜行动点张伟选定小树林扮鬼

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 属性养成可视化 | 用“五维属性/行动点”游戏术语，把成长写成可量化进度条 |
| 三段对话埋线 | 让白露台词中1、3为CP线服务，唯2突兀，形成后续解读空间 |
| NPC恒定场景 | 借白露“只出现两次”揭示游戏机制的恐怖感，反差制造毛骨悚然 |
| 主角脸反差 | 用“鸦鲨像女主弟弟”的调侃，反向坐实张伟的攻略位 |
| 行动点抉择 | 把深夜选项罗列出来，让主角“凭直觉”选小树林，推进剧情 |

**逐章写法公式**
- 情绪流向：刷属性的充实 → 查无此人的焦躁 → 对话解谜的趣味 → 选定方向的笃定
- 节奏配比：养成日常 40% / 线索搜集 35% / 选项抉择 25%
- 结构公式：时间跳跃（一周）→ 多场景跑腿（教室/社团/酒吧）→ 关键对话埋线 → 深夜选项收束
- 核心技巧：用游戏系统外壳（选项、好感、场景跳转）稀释悬疑，再用“突兀台词”戳破平静
- 卡点与伏笔：周箐消失一周；小树林闹鬼提示；领域撑不久，恋爱游戏进入倒计时
