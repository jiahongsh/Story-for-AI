## 第660章 蠢狗

**概要**
背刺者竟是乱鉴——他与天狗同奉命监视格里高，听炎凉长老"见九嗣人格杀勿论"而动手。钟赫破口大骂"蠢狗"，痛惜活口可作人质筹码，尸体只能审一次。天狗冷冷附和"蠢狗"。乱鉴委屈躲回水中消失。钟赫跪地为罐头阖眼，却触到透明消散的幻影——中计了。原来两分钟前高阳以7级【千面人】变作罐头模样，借【隐身】在五人面前走出电梯诱其上钩，再以【幻影】+【瞬移】分身逃跑、真身潜入格里高书房。真身高阳念出格里新高赞的绝妙开头"多年以后，面对真理之门……"，趁其沉浸写作以D药剂迷晕，扛起人带笔记本从阳台消失。横木砭镰酥魅门外毫无察觉。章末切回凌晨别墅，罐头与红晓晓同眠，回忆上午高阳借天赋时暧昧揉脸捋发的羞耻瞬间。本章揭穿上一章假死，完成高阳智取格里高的核心转折。

**关键事件**
- 乱鉴背刺真相：奉炎凉命格杀九嗣，钟赫怒骂蠢狗
- 天狗附和"蠢狗"，乱鉴委屈消失
- 钟赫阖眼发现罐头是幻影，识破中计
- 倒叙：高阳千面人变罐头、隐身诱敌、幻影分身真身入屋
- 高阳念出格里高开头、D药剂迷晕、扛人带笔记本撤离
- 章末罐头回忆上午高阳借天赋的暧昧动作

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 蠢狗双骂 | 重复台词（钟赫+天狗）强化讥讽与角色反差 |
| 尸体幻影消散 | 触感异常（不对）→透明→消失，三段递进揭谜 |
| 高阳计划倒叙 | 先给结果再回填两分钟前布局，解上章悬念 |
| 千面人设定 | 借"被动能力不受20秒限制"补规则细节 |
| 绝妙开头展示 | 直接引一句（非大段）点格里高写作执念 |
| 暧昧回忆收章 | 以羞耻闪回软化智取后的情绪，留糖伏笔 |

**逐章写法公式**
- 情绪流向：错愕真相→愤怒讥讽→悲恸假死→智取爽感→撤离从容→甜蜜回味
- 节奏配比：背刺真相（1/6）→骂战（1/6）→幻影揭谜（1/6）→高阳倒叙（1/3）→回忆收尾（1/6）
- 结构公式：刺客动机揭晓 + 骂战反差 + 假死破解 + 主角智取倒叙 + 目标带走 + 情感闪回
- 核心技巧：用"幻影触感"做物理化揭谜，用倒叙把上一章逃亡翻转为诱敌
- 卡点与伏笔：高阳如何安置格里高（下章地下室）；罐头与高阳暧昧线开启
