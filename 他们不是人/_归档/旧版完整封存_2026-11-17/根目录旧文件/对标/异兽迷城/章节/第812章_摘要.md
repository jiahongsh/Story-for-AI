## 第812章 震怒

**概要**
一石急令闭眼，了了紧闭双眼仍遭麒麟外溢精神力冲击，幻见遮天巨蟒、猩红信子，原始恐惧沁骨。麒麟拐杖头被捏碎、眼镜坠地碎裂，旋即身体一歪气晕倒地，两秒后睁眼更冷。一石扶起他，麒麟吩咐：一石带青龙尸体回营保存，了了再搜尸体，曲幽以空间传送感知四十八小时内空间战斗痕迹。曲幽在石柱林发现强烈空间能量残留，疑似炎凉战死处。麒麟令三人先回酒店，独留遗址，对着空气呼唤"炎叔"现身。

**关键事件**
- 了了闭眼仍遭精神力冲击见巨蟒幻象
- 麒麟捏碎拐杖眼镜，气晕两秒后更冷
- 一石扶起麒麟，领受三项指令
- 一石带青龙尸体保存，了了再搜
- 曲幽感知石柱林强烈空间痕迹（炎凉疑似死处）
- 麒麟令三人撤离，独唤炎凉现身

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 闭眼仍受冲击 | 精神力外溢的具象化（巨蟒幻象） |
| 拐杖眼镜碎裂 | 细节外化失控的怒 |
| 气晕两秒 | 反差弱化，避免神格化 |
| 三项指令分派 | 用命令推进多线侦查 |
| 空间痕迹定位 | 能力机制锚定炎凉死处 |
| 独唤炎凉 | 留白式收尾制造悬念 |

**逐章写法公式**
- 情绪流向：恐惧 → 失控 → 收敛 → 指令 → 定位 → 悬念
- 节奏配比：精神冲击约40%，指令分派约40%，独留收尾约20%
- 结构公式：精神冲击 → 怒之失控 → 恢复指令 → 分派侦查 → 痕迹定位 → 独唤收束
- 核心技巧：幻象外化情绪、细节碎裂、命令推进
- 卡点与伏笔：炎凉是否还活着；石柱林空间痕迹真相；麒麟独留目的
