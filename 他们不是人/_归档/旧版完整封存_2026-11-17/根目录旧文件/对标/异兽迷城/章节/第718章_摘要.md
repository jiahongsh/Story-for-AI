## 第718章 动手吧

**概要**
凌晨，陈萤凭多年特权潜入观海楼李夫人密室，取走伤害与生命两块符文回路，却撞见轮椅上的李夫人静候多时——她早已生疑，此来正是要取消陈萤权限。师徒对峙，李夫人却逼陈萤开枪，要"先骗过自己"方能骗过天下。陈萤含泪连开三枪，李夫人以血泊中的"走"字成全这场叛逃投名状，并延时按下警报布局自己的退场。陈萤易装为送货员，与张伟、野峰等汇合逃离。凌晨三点，十一人潜入废弃的11中旧礼堂躲避，小天持续感知、蔻蜗穿墙把风、沙叶下净化印记，苦候至四点，小天终于察觉有人逼近。

**关键事件**
- 陈萤潜入密室取走两块符文回路
- 李夫人现身逼陈萤开枪成全叛逃
- 陈萤连开三枪，李夫人布局退场
- 陈萤易装与张伟野峰汇合逃离
- 十一人潜入11中旧礼堂据守
- 小天感知到有两人逼近接应

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 密室机关 | 用假书加乌金共振门做"特权失效"的物化象征 |
| 师徒相向开枪 | 以弑师极端情境压情感极值，完成投名状 |
| 先骗自己论 | 借李夫人之口点出"表演"方法论，深化主题 |
| 延时警报 | 用一分钟默数制造生死 suspense 与布局感 |
| 易装逃逸 | 送货员乔装加破坏监控，写谍战式脱身 |
| 礼堂据守配置 | 以天赋分工（感知/穿梭/净化）展团队协同 |

**逐章写法公式**
- 情绪流向：潜行紧张→师徒对峙虐心→枪响决裂→脱身利落→据守悬盼
- 节奏配比：密室戏占五成慢工细活，枪戏短促爆裂，尾段转静悬
- 结构公式：潜入取材→师徒摊牌→弑师投名→乔装脱逃→据守待援
- 核心技巧：用"门禁共振"写特权与背叛，用延时警报制造回环悬念
- 卡点与伏笔：李夫人是否真死；符文去向；逼近者是敌是友
