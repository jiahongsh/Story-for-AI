## 第1137章 坚强

**概要**
承接屋顶对峙，加纳利被点破暗恋后应激否认，安禾歌坦荡拆穿其敌意源于同性之情。安禾歌自述因不善沟通被贴孤僻标签难脱身，唯黄连无偏见待她；忆跨年广场人群拥挤，黄连发动重力将其托起看烟花，并道出"我们都是站在热闹边缘的人"，加纳利落泪认同。加纳利哭诉众人虽好却只当她是小狗，唯黄连让她觉自己是女生。安禾歌顺势提杀贪婪为黄连报仇，劝加纳利借天赋代战——"我死你记得黄连，皆死则无人记得"。加纳利见其首笑自愧不如，泣而应允"约好了"。另一边，唐坷德将新悟石化天赋赠张伟，斗虎痛心"好天赋给弱鸡"，贾博士以麒麟旧识反驳。深夜厨房，唐坷德告知当普通人并赠天赋，张伟接下；提昔日鸿门宴之争今认张伟正确，张伟自责害死同伴，二人碰啤酒誓"敌人是神明也要干翻祂"。

**关键事件**
- 安禾歌拆穿加纳利敌意源于同暗恋黄连队长
- 安禾歌自述孤僻标签与黄连无偏见的温柔，回忆烟花托举
- 加纳利崩溃大哭，被劝将天赋借安禾歌代其报仇
- 加纳利见安禾歌首笑，含泪应允赠天赋之约
- 唐坷德将石化天赋赠张伟，斗虎痛心贾博士反驳
- 厨房夜话，唐坷德赞张伟鸿门宴路线正确，二人碰杯誓战神明

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 加纳利应激否认 | 用人物应激反应外化内心防线 |

| 天赋错配戏谑 | 用战力落差制造反差笑点 |
| 鸿门宴旧账 | 以过往分歧的和解收束人物成长 |

**逐章写法公式**
- 情绪流向：应激否认 → 温情剖白 → 崩溃共鸣 → 悲壮约定 → 戏谑和解 → 热血碰杯
- 节奏配比：屋顶情感戏约60%，厨房战力戏约40%
- 结构公式：敌意拆穿 + 回忆锚点 + 同频共鸣 + 牺牲说服 + 旧账和解
- 核心技巧：用"黄连"为情感轴心，串起两个边缘少女的羁绊
- 卡点与伏笔：加纳利赠天赋后能否参战；张伟得石化天赋的战力补完
