## 第712章 知心嗑

**概要**
张伟夜访陈萤，坦言自己无门可投，希望借陈萤与高阳的老交情作保，一同投靠九嗣。陈萤权衡后决定带张伟与小天出走，但对是否策反整个3组心存顾虑。张伟以"人间清醒"的姿态，逐条分析九嗣的优势：高阳堪比位面之子的气运、九嗣六个月便四分天下的惊人战绩、在暗处比在明处更安全、以及令人死心塌地的企业文化。陈萤对张伟刮目相看。整章以密室般的浴室长谈为舞台，用纯对话推进，借一个"小人物"之口完成对主角团实力的侧写，并为后续鸿门宴与集体叛逃埋下伏笔。

**关键事件**
- 张伟登门请求陈萤带其投靠九嗣
- 陈萤决定带张伟、小天出走，暂不带全组
- 张伟点破组内对李夫人与炎凉长老的不满
- 张伟以位面之子类比，论证高阳的主角光环
- 张伟列举高阳六个月四分天下的战绩数据
- 张伟归纳九嗣在暗处更安全与企业文化的优势

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 张伟主动投靠的动机 | 以"投靠无门"示弱，制造依赖，反衬其精明 |
| 陈萤带人出走的顾虑 | 内心独白分层：牵连风险、策反难度、人质逻辑 |
| 九嗣实力侧写 | 借配角之口做"他者视角"背书，避免主角自夸 |
| 位面之子论 | 用历史类比加数据对比，把玄学运气写成可量化战绩 |
| 在暗处更安全 | 明暗对照的结构性论点，服务后续游击战术 |
| 企业文化认同 | 以"传销式团结"反讽笔法收束，强化组织吸引力 |

**逐章写法公式**
- 情绪流向：轻松试探 → 渐入佳境的信任 → 激昂认同
- 节奏配比：对话占比约九成五，几乎无动作描写，靠信息密度推进
- 结构公式：请求→答应→顾虑→分析×4→认同（单场景闭环）
- 核心技巧：用低配角做"实力旁白"，以闲谈承载设定 exposition
- 卡点与伏笔：张伟把消息透露给沙叶（后文引爆）；3组是否集体出走的悬念
