# 本书文风 ·《他们不是人》（唯一正文风格与红线基准）

> 本文件为《他们不是人》正文写作、改稿与审稿的唯一文风基准（已合并原《都市异能正文风格卡》，由写作组装脚本自动注入）。

## 一、核心质感与叙事原则

1. **基调：冷峻市井烟火 × 诡谲机械意象 × 凌厉动作杀伐**
   - 日常段写活旧货市场、早点铺、老城筒子楼的真实油烟与市井拌嘴，让熟人关系鲜活可信。
   - 一旦切入异常与交锋，瞬间拉出冷硬、压迫、精密如拆表机芯的惊悚质感，多用齿轮、游丝、棘爪、发条、淬火钢针、白瓷豁口、尸油与铁锈味等具体触感写恐怖与战斗。
2. **先见血与后果，后补逻辑**
   - 异常出现后三段内必须引发试探、对抗或现实危险；世界观与体系解释藏在修表、挑虫、验尸、拆核的动作交锋中顺带甩出，绝不开会念设定说明书。
3. **叙述者在场，但不抢戏不说教**
   - 叙述者敢下短促狠辣的判断与适度冷嘲，严禁公文体、报告腔与心理分析长篇总结。
4. **动作戏写清空间与 0.1 秒时间差**
   - 打斗靠「反光锁定死角 → 0.1 秒咬合延迟 → 钢针/断钢卡主筋 → 倒钩重锤碎核 → 捉影镊活拆上弦」的具体匠人手艺写爽感，不写空泛的「大战三百回合」。
   - 情绪落地靠选择、台词与硬后果：紧张时写手握刀柄打滑、针尖挑破皮肉、锤砸骨裂、左腕拆核走时痕渗血灼痛，不靠套路微动作凑字数。

## 二、单章推进节拍与命名规范

1. **单章标准推进节拍**
   - 章首压迫或反常切口 → 主角主动设局试探或出手 → 局势意外反转或外敌突袭 → 手艺/智斗/群像配合硬破局 → 实打实的代价或收获落地 + 强悬念章尾（章尾必须停在具体危险、惊悚照面、底牌亮出或人物失忆瞬间，严禁「合上本子、倒掉凉茶」式软收尾）。
2. **章节命名铁律（5–12 字冷硬短句）**
   - **严禁七言章回体对仗标题**：禁止 `XXXXXXX，XXXXXXX` 评书演义式对仗名，保持全书统一的现代都市冷硬悬疑质感。
   - **一眼吸睛但绝不剧透**：抓取反常识悖论、诡异动作切口、人情刀子反差、倒计时压迫或带刺问句（如《她把缺口转向我》《当假货比真人更像人》《救了一车人，没一个认得她》），严禁在标题里提前剧透反派死法或内鬼真名。

## 三、硬性禁忌清单（零容忍）

- **严禁「一阶至九阶 / 低阶 / 高阶」旧等级词**：全书正文叙述与人物对白统一按阵营直呼**镇钟九响境名**（校眼、绷弦、走汞、鸣钟、停摆域、断代身、逆时主、空位、万象归位）、**白塔牌令**（灰牌巡卒、铜章哨/铜章手、银边巡官、黑令统领、白塔掌司、裁天司命）、**壳侧序列**（剥皮种、铁脊体/猎犬、裁缝、缝骨将/大裁缝、缝皮宗师、母巢王座、古钟主、终焉主脑）与**普通人「时痕」火候**（落痕、绞弦、走汞、鸣钟、断代往后）。
- **严禁官僚文书拖戏**：禁止出现公证员式「暂不判断、留档观察、两份分存互不合并」，禁止用物业门禁审批、打印费、跑腿费扯皮稀释生死主线。
- **严禁 AI 句式与套路微动作**：禁止使用 `——` 破折号与无纠错对象的「不是 A，而是 B」句式；控制「像/仿佛」比喻密度（每千字不超过 3 处）；禁止刷屏「指尖/指节微颤、喉结滚动、目光微沉」。
- **严守排版格式**：相邻段落之间只用一个换行符 `\n`（无空行），对话独立成段，严禁夹带 `**加粗**`、`*斜体*`、`---` 分隔线或任何章节工程词。
