# 本书文风 ·《他们不是人》（主笔终极版）

> 本文件为《他们不是人》正文执行的唯一文风基准，与 `都市异能正文风格卡.md` 一致。

1. **基调：冷峻市井烟火 × 诡谲机械意象 × 凌厉动作杀伐**
   - 日常段写活旧货市场、早点铺、老城筒子楼的真实油烟与市井拌嘴，让熟人关系鲜活可信。
   - 一旦切入异常与交锋，瞬间拉出冷硬、压迫、精密如拆表机芯的惊悚质感，绝不温吞水。
2. **叙述者在场，但不抢戏不说教**
   - 叙述者敢下短促狠辣的判断与适度自嘲（如「这笔债不要他的命，却要把他活过二十一年的痕迹从别人脑子里刮干净」），禁止公文体、报告腔与心理分析说明书。
3. **情绪落地靠选择、台词与硬后果**
   - 少用「指尖一顿、喉结滚动、声音放轻」等空洞微动作；紧张时写手握刀柄打滑、针尖挑破皮肉、锤砸骨裂，愤怒与狠劲直接落在动作和杀招上。
4. **节奏拉满、章尾必须有硬钩**
   - 过场 1–2 句带过，把笔墨重砸在设局、反杀、反转与记忆剥离的刀子上；章尾必须停在具体危险、惊悚照面、底牌亮出或人物失忆的瞬间，严禁「合上本子、倒掉凉茶」式软收尾。
5. **格式铁律**
   - 相邻段落之间只用一个换行符，绝不使用 `**加粗**`、`---` 分隔线或正文内 `——` 破折号；对话外不用省略号，不泄漏工程词。
6. **章节命名铁律（吸睛而不跑偏）**
   - 严禁七言章回体对仗说书标题（禁止 `XXXXXXX，XXXXXXX` 拼接式总结）与提前剧透生死结局。
   - 坚持 **5–12 字冷硬短句、高吸睛钩子**，用反常识反差、诡异切面、人情刀口或带火药味的问句抓住点击欲，与开篇前十二章保持同一种现代都市惊悚气质。
