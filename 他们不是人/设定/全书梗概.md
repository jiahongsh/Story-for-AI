# 全书梗概

## 主角最终要什么
旧货市场修表匠镜辞要查清养母沈竹七年前拆碎三座母钟、孤身跃入源裂缝的真相，找齐参号、贰号、壹号三座母钟的核心部件救回沈竹；同时在「怀表一步步剥离人世记忆」的残酷宿命里，替身边那些生出活人真心的同伴（芽/南芽、姜霁、守钟人、假陈骁等）砸碎白塔与源裂缝强加的「唯一标准版本」，守住一个允许残缺、允许挣扎也允许真情存在的人间。

## 最大的阻碍
表层阻碍是垄断城市记忆篡改、死人续档与重装处决权柄的「白塔（十二时辰修正司 + 四大续档财阀 + 三大司命）」以及暗面横行的「壳巢（七大缝皮宗师 + 十二母巢死壳王座）」；深层阻碍是白塔至高执棋者左衡与盘踞在零号母表深处的「源裂缝唯一指向主脑」——它们企图吞噬整座临江市的时间线，把所有人类格式化成没有异议与痛苦的空壳。

## 前几次大转折
1. **第一次大转折（第 1 卷末·第 30 章）**：镜辞在恒泰地下三层与零号外井斩杀走汞裁缝陈屿、击溃白塔黑令统领程晦并焊封参号地缝，但银灰旧怀表第一重「凡尘止逆盘」跌至最后第 1 格——全城街坊、官方档案乃至守钟人全部忘掉「镜辞」是谁，唯余体内钉着死锁的芽呕血死记他的名字。镜辞由此从普通修表匠化身为官方底册查无此人的「幽灵猎手」。
2. **第二次大转折（第 2–3 卷·第 31–140 章）**：镜辞在城南医院破获死后十一个月凭空回家上班的「死人续档」黑产，意外开启怀表第二重「银钢蓄能盘（拆核上弦）」——猎杀走汞以上半壳或时辰司修正官活拆机芯即可逆向充能放招，不伤第 1 格底命，唯每拆一核在腕脉沉淀一道暗银「拆核走时痕」；卷末借参号副发条盒拓印游丝母印解锁「逆摆雏形（触碰器物回退 3 秒）」，盒体镇回东巷座钟底。他更借「查无此人」的无名身份换马甲潜入剥壳人总局与守夜武院，在十二外勤组「时痕」武者大比中揪出白塔「寅时司」内鬼，镇钟武道连破「走汞」与「鸣钟」两响。
3. **第三次大转折（第 4–6 卷·第 141–315 章）**：镜辞首闯「午夜 404 号环城地铁」断代禁区正式觉醒完整版第三式「逆摆（局部三米内十秒结构回溯）」，随后大闹四大续档财阀换皮宴夺回参号母钟主摆轮；在第六卷「七年前沉没的旧江心洲」百人级会战中，老队长顾横燃尽骨弦系「鸣钟」极限焊死禁区泄洪闸护住平民船队**彻底壮烈牺牲**，芽在万千同类围杀下震碎原芽身份枷锁、将沈竹死锁熔入心口化为本命心锁，立名「南芽」踏入停摆域战体，与破入停摆域的镜辞联手斩落首位缝皮宗师【换骨】本尊。
4. **第四次大转折（第 7–11 卷·第 316–610 章）**：镜辞在东巷融合双母钟部件开启第三重「赤铜母钟盘（第四式偷刻）」，令东巷老铺滑入「半断代折叠夹缝」护住满街平民烟火，百名「无名钟表行（空位同盟）」奇人分散地下黑表鬼市单线猎杀，连斩白塔十二时辰修正司掌司与七大缝皮宗师；第 11 卷左衡亲自下场在城南启动「唯一答案」版本收敛，十万市民沦为微笑木偶。
5. **第五次大转折（第 12–14 卷·第 611–795 章）**：为救下被左衡因果律锁定的南芽与姜霁，镜辞亲手掰断第一重表盘仅剩的第 1 格，怀表彻底归零！代价由「忘名」升级为「现世转身即忘的活体盲区」，连姜霁与南芽都当场忘记了他的存在；镜辞在绝对孤寂中踏入第 0 格「空位行者（第四重紫金空位盘）」，成为万法不沾身的逆时至空位无名死神，分兵破灭剩余母巢王座、杀穿源裂缝内环，与半石化镇守裂缝七年的养母沈竹正面重逢。

## 结局
在第十五至十六卷终局之战中，深陷活体盲区的姜霁凭左手虎口双针孔、南芽凭缺口瓷碗与本命心锁，在漫天火光里冲破第 0 格法则重新认出那个无名修表匠并嘶声喊出「镜辞」之名；守钟人燃尽余生重启三母钟大阵，镜辞以积攒十五卷的 999 道拆核走时因果痕配合伙伴们的「+1」真情锚点，开启第五重「零号神迹盘·万象归位」，轰碎左衡与唯一指向主脑，闭合源裂缝。战后，旧货市场东巷的钟表行重新拉开卷帘门，镜辞坐在单眼寸镜后，迎向提着热豆浆推门而入的姜霁与南芽：「这一次，咱们重新认识一下。」
