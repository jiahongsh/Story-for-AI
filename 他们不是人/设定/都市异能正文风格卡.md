# 都市异能正文风格卡（主笔重构版 v3）

## 一、核心原则：像爆款网文那样讲故事

1. **先见血与后果，后补逻辑**：异常出现后三段内必须引发试探、对抗或危险；世界观解释藏在修表、挑虫、对峙的过程中顺带甩出，绝不开会念设定。
2. **对话要带人味与机锋**：熟人拌嘴接地气，敌我交锋藏杀机；不让不同角色都用同一套冷静书面语说话。
3. **机械与身体意象结合**：多用齿轮、游丝、棘爪、发条、淬火钢针、白瓷豁口、油烟与铁锈味等具体质感写恐怖与战斗。
4. **动作戏写清空间与时间差**：打斗靠「反光锁定死角 → 0.1秒咬合延迟 → 钢针卡主筋 → 重锤碎核」这类具体手艺写爽感，不写「大战三百回合」。

## 二、硬性禁忌清单（零容忍）

- 禁止出现公证员式「暂不判断」「留档观察」「两份分存互不合并」等官僚拖戏操作。
- 禁止用无休止的物业门禁、打印费、快递退件费稀释主线冲突。
- 禁止使用 `——` 破折号与「不是A，而是B」类 AI 腔对比句式；控制「像/仿佛」比喻密度，多写直接动作与物理质感（全篇控制在每千字 3 个比喻以内为佳）。
- 禁止出现「指尖/指节微颤、喉结滚动」等套路微动作凑字数。
- 禁止在正文里夹带 `**加粗**`、`---`、空行或章节工程词。

## 三、单章标准结构

> **章首压迫/异常 → 主角主动设局/出手 → 局势意外反转或外敌突袭 → 能力/智斗硬破局 → 实打实的代价咬人 + 强悬念章尾**

## 四、章节命名规范（吸睛但克制）

- **严禁七言章回体对仗标题**：禁止使用 `XXXXXXX，XXXXXXX` 式评书/武侠演义对仗名（如「黑封铁皮锁老巷，盲翁火钳揭参号」），必须保持全书统一的现代都市冷硬悬疑质感。
- **5–12 字短句、一眼吸睛**：章名必须像钩子一样勾住读者点击欲，优先抓取「反常识悖论、诡异动作切口、人情刀子反差、倒计时压迫或带刺问句」（参考标杆：《她把缺口转向我》《当假货比真人更像人》《救了一车人，没一个认得她》《谁说车里装的不是人？》《他把自己焊进了旋转铜核》）。
- **只抛切口与矛盾，严禁标题剧透**：不把反派怎么死、内鬼是谁揭穿、靠哪一招收官直接摊平在标题里，留足阅读张力。
