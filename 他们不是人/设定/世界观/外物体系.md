# 外物体系 · 修表匠神兵与裂隙奇物（主笔重构版）

| 物品 | 来源/归属 | 核心功能与战斗用途 |
|---|---|---|
| **十倍修表寸镜 / 抛光纯银怀表** | 钟表行常规家当 | 折射并聚焦反光，触发「第一式·照缝」的借镜窥死与死角锁定 |
| **三寸淬火钢针 & 八角重铜锤** | 钟表行传承工具 | 钢针卡死低阶壳耳后传动主筋，重铜锤一击震碎喉间暗红裂隙核 |
| **暗红裂隙碎核** | 剥皮壳死后喉间结晶 | 烘烤散发腥味可作诱饵引出潜伏侵蚀虫（第7章救姜霁）；亦可当作「止逆棘爪」拍入壳主筋卡死自爆并反噬远程控制线（第9章断陈屿共振丝） |
| **双半黄铜齿轮 & 无针黄铜母钟** | 沈竹所留三只母表之一 | 两半齿轮拼合可弹开母钟暗格，内藏高阶镇钟器物与绝密线索 |
| **神兵·银钢捉影镊** | 第9章502母钟暗格取出 | 陨铁银钢铸造，可直接挑断三阶以下所有壳与半壳接缝，专克缝皮金线 |
| **沈竹血书胶片** | 第9章母钟暗格取出 | 指明「城南恒泰设施地下三层，每晚02:17用活人喂养零号母表；别信白塔」 |
| **七年前双环断角锤旧铜表** | 第14章恒泰地下血表墙角取下 | 盖内刻有沈竹与守钟人校表双环暗记及钢针短句，证实七年前零号初启夜二人共碎三表致守钟人双目毁盲，并指明二号母表在白塔底座、参号母表隐在旧货市场老巷 |
| **周谨血衣红印密令** | 第14章自周谨尸身缴获、第15章拆阅 | 盖有白塔督察科暗红印章，批示若恒泰外围池受损则明晚十点半借老城改造清拆旧货市场东巷全段，将钟表行留守人员尽数扣入零号深池充数 |
| **顾横密援军绿药弹箱** | 第15章顾横于恒泰厂门暗中塞入货车 | 内含四匣特制银芯弹、军用止血绷带及一台干净加密电台，成为镜辞与姜霁后期联系二组及硬撼清拆队的物资支撑 |
| **参号母表（缺摆轮残胎）** | 隐于钟表行后间老座钟底座青石地砖下 | 沈竹七年前拆碎的三只母表之参号，核心调速摆轮被沈竹带入源裂缝，仅余空胎靠守钟人血契铜印与大铜锤强镇吊住东巷半城气息（第16–18章） |
| **徐正老城管网蓝图** | 第17章自陈屿强拆指挥车铁柜中救出的老工程师徐正献出 | 防水油纸绘制，标明直插恒泰地下三层南侧竖井的三号一米二管径废弃排水总渠（距东巷七号铁井四百二十米双向闸门）与十米顶层散热铜井，助三人完成第18章水顶双翼突袭 |
| **铜甲护卫 / 铜甲缝合屠夫** | 陈屿第18章于恒泰地下同步大厅催动的重傀 | 护卫高两米二、披铆钉铜甲与紫黑颈缝；屠夫高三米、居于中心玻璃缸，与陈屿胸腔金线焊入的中央分体同步铜核高频共振，可借青铜声波剧烈冲击并撕裂高阶死锁 |
