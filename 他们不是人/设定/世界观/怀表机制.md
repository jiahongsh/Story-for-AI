# 怀表机制 · 遗物锚点 + 记事 + 钥匙（唯一权威）

> **定位**：怀表是本书的核心外物，承载三层功能——**铭记锚点（遗物）+ 记事（存在残留的刻度）+ 钥匙（"听得见"的资格载体）**。它是沈竹（及外婆）留给镜辞的遗产，也是"表走=人在"这一母题的物理载体。
> **本文件收敛**此前散落在伏笔（F002/F018/F070/F104/F149/F260/F261/F262/F265）、外物体系（遗物/信物）、力量体系（镜返3阶守钟人交表）中的表线机制，是怀表的唯一权威。与正文冲突时，以本文件为准。

---

## 一、表是什么（身份与来历）

- **镜辞戴的这块表 = 外婆的表**：外公（郑师傅）当年买给外婆的表。外婆某晚说"要出远门"，把表留下，再没回来。沈竹十六岁趁外公不在拿走这块表，说要"自己修，修好了给你送回来"，修了十几年没修好，表盖内侧刻了"镜辞"二字。
- **沈竹也有一块表**：与镜辞的表是**一对**（同一个师傅做的、同一套零件），她走的那天，她的表停了，指针停在她离开的位置。
- **为什么镜辞的表"怎么修都不走"**：不是坏了。是沈竹**故意停表**——把时间停在她离开那天。表盖底盘刻字（沈竹的字）："别修了，孩子。有些表，修好了才是真的停了。"她预判了镜辞会修，这是留给他的一句话。
- **表里藏着什么**：夹层里一封沈竹的信，第一句就是「表停了，人还在」。镜辞取信装回后，表第一次开始走——它等到了"听得见它的人"。

## 二、表的三层机制（统一，不打架）

### 1. 铭记锚点（遗物 · 外物体系已定义）

- 表是**存在力的物理锚点**：沈竹（外婆）的存在没有完全消失，而是寄居在表里。谁戴着它，谁就"带着"这个人走。
- 功能：EX 上限提升（+50）；承载"身世线索"（第4卷真相钥匙）。
- 代价：**情感债**——戴着表 = 必须"带着沈竹走"，履行她的未竟之事（找到答案）。丢表 = 存在力上限下降 + 主题背叛。

### 2. 记事（表 = 舍不得的事的刻度）

- **表替主人记事**：它不走钟点，它记"舍不得的事"。主人舍不得的人、事、习惯，它都记着。走得慢是舍不得放下，走得快是怕来不及记。
- **表走 = 有人在记；表停 = 没人记了 / 人不记了**：
  - 表走 = 主人（或铭记者）还在记着那些舍不得的事 → 人就没走远；
  - 表停 = 不记了（忘了，或"不用记了"）→ 人走了 / 放下了。
- **沈竹的表停在她走那天**：她"不记事了"（把事交给了镜辞，信他记着）。她的表停 = 她离开；镜辞的表走 = 他还在记 → 她没走远。这是"表停，人走？"悬念的机制底牌：**表停≠人死，只是"她不记了，换你记"**。

### 3. 钥匙（"听得见"的资格载体）

- **表 = 钥匙**：不是力量的来源，是**资格的载体**。守钟人/灰褂人反复暗示"谁拿得动这块表，谁就听得见"。
- **镜辞能看见壳（镜返），不是表给的**——镜返是半壳血脉自带（见力量体系）。表的作用是：**它承载了沈竹"听得见"的执念，把"铭记"这个信念传给了镜辞**。表是"沈竹听不见、镜辞听得见"之间的那座桥。
- 因此表与镜返的关系是：**镜返是天赋（血脉），表是锚点（传承）**。镜返让镜辞"看见接缝"，表让镜辞"记得为什么看"——一个是眼睛，一个是心。

## 四、写作红线（防止表线崩坏）

1. **表不能给镜辞"开挂"**：表是锚点和传承，不是能力来源。镜辞的镜返靠血脉，表靠信念——两者分开，别让表变成"戴上就变强"的道具。
2. **表走表停的判定不能滥用**：表的状态是"主题刻度"（有没有人记），不是"战斗雷达"。别写成"表停了→立刻有危险"这种廉价预警。
3. **"表停=人走"永不坐实为死亡**：沈竹生死留白（表停=她不记了，不是她死了）。坐实=主题崩塌。
4. **一对表的关系**：镜辞的表（外婆的）+沈竹的表（一对），一个师傅做的——这个"师傅"在第4卷守钟人交表时揭示，现在不点破。
5. **表不能替代铭记**：铭记是主角的核心能力（记住别人=补存在力），表只是锚点之一。别让表喧宾夺主，成了"万能钥匙"。
6. **怀表来历的两条口径（防冲突）**：沈竹对守钟人自称"十六岁捡的"（F067），实为"拿外婆的表"（F079）——前者是她的谎/简化说法，后者是真相。写回忆时别把两条混成"两个来历"，统一按"对外说捡的、实为外婆的"处理。
