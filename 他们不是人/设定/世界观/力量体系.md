# 力量体系 · 作者后台定稿

> **核心**：本书是都市身份恐怖为表、可验证异能规则为里。数值服务一致性，不替代悬疑、关系和人物选择。
> **权威关系**：本文件负责底层因果；存在衰减、身份位置闭合与成壳条件细节服从 `存在衰减与空缺机制.md`；具体数值服从 `数值定稿.md`；觉醒与进阶服从 `刻痕觉醒与进阶机制.md`；镜辞主天赋细节服从 `金手指.md`。
> **正式术语**：刻痕统一使用 **1-9阶**；镜返统一使用 **第一式至第五式**。禁止再把镜返五式写成人物阶位或另一套独立等级。壳侧正式术语统一使用 **裂隙压 / 裂隙侵蚀 / 裂隙接口**。

## 一、世界底层：存在不是信息，而是关系

一个人的现实存在分为三层：

| 层级 | 定义 | 能否独立支撑存在稳定 |
|---|---|---|
| 信息痕迹 | 身份证、照片、监控、数据库、聊天记录 | 否 |
| 记忆痕迹 | 活人知道“有这么个人/发生过这些事” | 只能提供认知连续性 |
| 存在锚点 | 一个人真实改变了另一个生命的情感、选择、习惯或人生轨迹 | 是 |

**记录 ≠ 记忆，记忆 ≠ 铭记。**

存在裂缝不是能源矿，而是世界在“存在归属失配”时出现的异常接口。

当存在锚点持续断裂，首先发生的是**归属失稳**，而不是自动生成壳。真正形成可供裂缝稳定侵入的存在空缺，还要求：
- 现实仍留有一个没有正常闭合的身份位置；
- 该位置缺乏稳定关系指向；
- 裂缝能够接触并沿该位置侵入；
- 裂隙压先于现实重新完成归属确认而稳定下来。

因此：

> **死亡不等于存在空缺，遗忘不等于成壳。**
>
> **锚点失稳 + 身份位置开放 + 裂缝介入，才构成壳形成的底层条件。**

一个人正常死亡且身份、责任、关系完成现实闭合后，即使多年后资料消失、后人淡忘，也不会重新自动打开一个身份空位。相反，失踪、身份回填、多版本争夺、异常权限持续运行等情况更危险，因为现实仍在要求“某个人继续占据这里”，却已经无法稳定回答“究竟是谁”。

裂缝可以：
- 放大、扭曲或切断存在关系；
- 给人留下刻痕，使其能主动干涉存在规则；
- 沿开放存在空缺塑造壳；
- 形成可供壳调用的裂隙压。

## 二、两条力量路径：EX 与裂隙压

### 2.1 人类侧：EX

**EX（Existence Stability）= 个体维持“我仍然是我”的当前存在稳定值。**

刻痕者通过裂缝接口，以自身EX为代价干涉现实。EX短时消耗可以通过休息、自我稳定和仍存在的关系确认回升，但已经永久断裂的存在锚点不会因为睡眠、存档或技术治疗自动恢复。

镜返造成的关系损伤服从 `数值定稿.md` 的70 / 40 / 20 / 0层级规则。

### 2.2 壳侧：裂隙压

**裂隙压 = 存在裂缝沿存在空缺进入现实后形成的异常驱动力。**

壳不使用正常人类意义上的EX战斗池。它们依靠裂隙接口承受、引导和放大裂隙压。

因此必须区分：

> **力量来源 ≠ 身份来源 ≠ 存在资格。**

壳可以很强，却没有人类EX；一只壳也可能在停止冒充原主、以自己的身份作出选择并真实改变别人后，形成属于自己的新存在锚点。新锚点不会把它自动切换成人类刻痕体系。

## 三、壳吞噬的边界

壳能够夺取和复制：
- 原主的内在记忆；
- 身份认知；
- 语言、习惯和行为模式；
- 对社会关系的知识。

壳不能把存在于别人身上的东西一起吞掉：
- 别人因原主形成的习惯；
- 别人因原主作出的现实选择；
- 别人对原主形成的情感连续性；
- 原主已经嵌入他人生命的因果结果。

**接缝**来自“壳内部复制的身份/记忆”与“现实仍存的外部关系因果”无法完全对齐。

因此：
- 接缝能证明身份存在错位；
- 接缝不能单独证明原主肉体仍然活着；
- 接缝不能单独证明眼前存在必然敌对；
- 将所有原主体都视为完整囚禁在替代者内部、等待统一救出的旧处置模型已经废止。

## 四、人类侧：刻痕者 1-9阶

存在裂缝在人身上留下刻痕。刻痕者的正式成长标尺只有 **1-9阶**，代表对存在规则的干涉深度。

### 六大门类

| 门类 | 定位 | 核心干涉对象 |
|---|---|---|
| 真视 | 感知/破解 | 身份与真实的错位 |
| 蚀忆 | 记忆攻击 | 内在记忆痕迹 |
| 腐蚀 | 存在攻击 | EX与存在稳定 |
| 摹刻 | 拟态/复制 | 行为与能力结构 |
| 镇封 | 领域/压制 | 裂缝接口与裂隙压流动 |
| 铭刻 | 强化/祝福 | 关系锚点与存在稳定 |

正常规则为 **1个主天赋 + 0-3个副天赋**。

二次觉醒不等于一次强情绪高潮直接开技能。其机制统一服从 `刻痕觉醒与进阶机制.md`：已有天赋必须遭遇原有干涉方式无法解决、又直接触及自身存在边界的问题，并经过接触积累、自我连续性保持、结构适配和现实验证，才可能形成第二条稳定干涉通道。

## 五、镜辞：刻痕阶位 + 镜返五式

镜辞同时拥有两套不同维度的描述，必须严格分开：

1. **刻痕1-9阶**：镜辞作为刻痕者的通用成长深度；
2. **镜返五式**：主天赋“镜返”的五层权限。

### 镜返五式

1. **第一式·看见接缝**：源头级被动接口，可看到最基础身份错位；不受普通SEE阈值限制。
2. **第二式·照真身**：读取壳体内原主残留和关键异常参数。
3. **第三式·强制现形**：必须以已确认的真实关系证据为参照，把调查得到的身份矛盾强制显形；不能替代调查。
4. **第四式·遗忘领域**：制造身份指向盲区，干扰依赖姓名、记忆、关系的锁定和追踪；不直接削弱敌方战斗参数，也不替代镇封。
5. **第五式·记忆归还**：终局只对仍真实存在、却被唯一指向错误压平或截留、且现实仍有独立关系承接点的记忆与身份因果起作用。它能让这些因果重新显露，并让错配记忆重新获得现实参照；不能复活死者、凭空制造锚点、强制恢复感情、删除真实后续人生，也不能替世界裁定唯一身份。它更不能在四条归并链仍运行时单独把全城恢复原样。

镜辞的永久能力只保留：
- 主天赋：镜返·真视禁忌品；
- 副天赋：铭心·铭刻异品。

其余壳侧能力只能作为**临时解析并模拟的具体结构**，不能固化成整套门类，也不能形成“EX耗尽后切裂隙压继续施法”的第二资源池。

### 终局阶位

- 第7卷完成6→7阶成熟突破；
- 第8卷只允许一次正式升阶：**7→8阶**；
- 第五式属于主天赋终局权限开放，不要求先达到9阶；
- 9阶保留为人类刻痕体系理论上限，不作为镜辞终局排面要求。

## 六、核心角色能力边界

### 姜霁

- 前期“行为指纹”是纯调查技术，不是超能力。
- 第5卷正式觉醒第一项刻痕能力：**记忆差分·蚀忆**。
- 只能识别记忆反应与长期行为/关系基线之间的异常差值，不能通用读心，不能直接判定人/壳。

### 守钟人

- 开篇稳定阶位：**约6阶**。
- 主天赋：**时间错位感知·真视异品**。
- 副天赋：**定界·镇封良品**，属于早年守夜人生涯形成的二次觉醒。
- 第6-7卷完成 **6→7阶**。
- 其壁垒不是战力不足，而是必须否定旧守夜人“牺牲少数关系痕迹换边界稳定”的伦理逻辑，并用现实行动证明：守界是在不先抹除具体人的前提下争取处理时间。
- 第8卷保持7阶即可，不为了终局排面强升9阶。

### 顾横

- 全书无正式刻痕。
- 战斗价值来自训练、枪械、战术、肌肉记忆与撤离设计。

### 猫眼

- 无正式刻痕。
- 核心能力是来源判断、线人网络、版本保存和承担信息后果。

### 白壳

- 不进入人类刻痕1-9阶。
- 壳侧能力为拟魂·摹刻绝品。
- 它是否形成自身存在锚点，与是否获得人类超凡能力无关。

## 七、壳等级与识破

壳等级使用 Lv.1-10，与人类刻痕阶位不是同一体系。

- Lv.1-3：身份模仿与基础侵蚀；
- Lv.4-5：记忆操控与存在腐蚀；
- Lv.6-7：领域与完美伪装；
- Lv.8：群相壳，可同时维持多个被盗身份并让多套社会关系互相作证；
- Lv.9：源隙壳，可主动制造局部存在空缺；
- Lv.10：壳王，直接干涉大规模身份归属。

普通真视服从SEE阈值；镜返第一式是源头级被动例外。高阶目标需要镜返对应式、真实关系证据和团队协作，不能把镜返写成万能扫描仪。

## 八、对抗与结算规则

| 层 | 判定 | 原则 |
|---|---|---|
| 识破层 | 看穿伪装 | 普通真视服从SEE阈值；镜返第一式例外 |
| 镜返层 | 比对身份/锚点 | 镜返对应式已解锁；第三式起必须有关系证据 |
| 战斗层 | 正面压制 | 人类天赋输出对抗壳的裂隙干涉参数，多数高阶战必须团队协同 |
| 抵抗层 | 抗侵蚀/操控 | WIL与当前EX共同决定 |
| 铭记层 | 终局归还 | 有效关系再暴露、多源独立承接与四链断开共同破坏“唯一指向”闭环 |

**999+1**只存在于作者后台，并按 `999+1终局机制.md` 解释：999代表镜辞主动铭记/承接的单向极限，+1正式由姜霁承担，代表另一个生命对镜辞的反向真实指向。它不是MEM+1、EX复活、战力增加，也不使用“1000>999”直接判定终局胜负；城市级胜利仍依赖四条链被分别切断。

## 九、白塔技术边界

白塔可以：
- 保存资料和主观记忆；
- 重放、检测、编辑记忆痕迹；
- 辅助定位异常。

白塔不能：
- 从数据库制造存在锚点；
- 自动恢复已经断裂的真实关系；
- 复制情感连续性；
- 用存档让死者重新成为原来的那个人。

典型情况是：一个人可以重新“知道”某段共同经历，却仍觉得那段记忆像别人的录像。**信息回来，不代表关系回来。**

## 十、力量体系防崩红线

1. 刻痕只写1-9阶；镜返只写第一至第五式。
2. 镜返不负责主要输出，第三式不替代调查，第四式不替代镇封，第五式锁终局且不负责制造唯一答案。
3. 接缝、残忆、结晶都不能单独证明死者复活。
4. 壳不能继承原主已有关系锚点，但可以以自己的身份形成新的锚点。
5. 白塔不能技术制造或恢复真实锚点。
6. MEM不是EX药包；裂隙压不是镜辞第二蓝条。
7. 每次真正的大幅变强都必须带来不可轻易撤销的代价，但禁止机械安排“每次升级必背叛/必死人”。
8. 超凡不是参与异常世界的入场券，普通人的调查、关系、证词、战术和选择必须持续有效。
9. 正文不显示游戏式升级播报、掉落经验或技能树界面。
10. 存在锚点崩塌不自动生成壳；必须同时检查身份位置是否开放、裂缝是否介入以及现实是否已完成闭合。
11. 第五式只能重新暴露仍有现实承载点的关系因果；若承接关系真正消失，则没有可被重新对齐的对象。
12. 任何文件若再次把镜返写成独立阶位制、把二次觉醒写成一次强情绪高潮的即时奖励，均以本文件、`数值定稿.md` 与 `刻痕觉醒与进阶机制.md` 为准并立即修正。
13. 第8卷镜辞只允许完成一次7→8正式升阶；不得为了终局排面追加9阶。
