# 交易市场体系 · 存在力的流通

> **⚠️ 定位声明（用户明确，最高优先）**：**本体系只为"更真实 + 推动剧情"服务，是推动剧情的工具，不是展示对象。** 市场在故事中的功能 = 资源线/情报线/社交线/伦理钩子/危机触发（见第五节），用于让主角"变强需要做生意、追查需要进市场、谈判需要中立地带"。**禁止市场百科化**——读者不需要知道的交易规则不写；市场只在推动剧情时出场，不单独开"市场观光章"。此原则适用于一切设定（见 `MEMORY.md` 设定服务故事铁律）。

> **定位**：外物体系（记忆结晶/刻痕石/遗物/白塔记忆药）的"血管"——没有市场，外物就是死资源。本文件定义**交易媒介（用什么钱）、交易场所（在哪交易）、交易规则（谁定规则/怎么定价/安全怎么保证）**，构成完整的"存在经济"。
> **对标说明**：异兽迷城无成熟交易体系（仅"安梁大市场"等地名），本书自建差异化——交易市场与"存在力/记忆/裂缝"世界观完全咬合，货币本身就是存在力的等价物。

## 一、交易媒介（用什么钱）

> **核心**：普通货币买不到记忆结晶——本书的交易媒介是**"存在力等价物"**，分三档。

| 媒介 | 本质 | 购买力 | 获取方式 |
|---|---|---|---|
| **碎忆币**（流通主币） | 记忆结晶碎粒（低纯度碎片打磨成币） | 日常交易（情报/低阶材料/人工） | 猎壳/裂缝采集/打工 |
| **整忆晶**（大额货币） | 完整记忆结晶（中纯度） | 装备/高阶材料/突破辅助 | 猎高阶壳/任务报酬 |
| **记忆之核**（顶级硬通货） | 高纯度记忆结晶 | 绝品外物/独家情报/大额交易 | 极稀有（绝品级） |

**为什么要用记忆当钱**：记忆结晶本身就是"存在力"的凝结——**用记忆币交易 = 用"被吃掉的人的存在"交易**。这暗含一个伦理钩子：这座城市的繁荣建立在"被遗忘者的残骸"之上（与主题咬合）。

## 二、交易场所（在哪交易 · 分三层市场）

### 第一层 · 地表市场（合法·半公开）
- **场所**：临江市旧货市场（主角钟表行所在地）延伸出的"旧物街"——表面卖旧货，暗格卖"收藏品"（低阶外物）。
- **交易方**：普通刻痕者、剥壳人文职、猎壳散户。
- **商品**：碎忆币交易低阶外物（碎晶/粗石/普通遗物复制品）。
- **监管**：剥壳人暗中盯梢（官方"合法化"但监控）——这里交易的壳物必须"登记来源"。
- **风险**：低（但货源来路不明时有，可能买到"壳设的局"）。

### 第二层 · 地下市场（灰色·核心交易场）
- **场所**：百川堂的地下交易所（旧电厂地下一层，需暗号进入）——**外物+情报一条龙**。
- **交易方**：观潮者、剥壳人特战员、白塔线人、独立刻痕者、甚至壳巢的代理。
- **商品**：整忆晶交易中高阶外物（结晶/磨石/灵痕石/记忆药）、独家情报、壳巢动向。
- **规则**：百川堂定规矩（"三不卖"底线：不卖会死人的假情报/不卖孩子/不卖必死局）、明码标价、买卖双方身份互保（面具入场）。
- **风险**：中高——**在这里交易=被百川堂记账**（它掌握你的底牌），且可能被对家（壳巢代理）盯上。

### 第三层 · 白塔柜台（机构级·半合法灰色）
- **场所**：白塔医疗中心前台（表面是"记忆档案服务"，实际出售记忆药/记忆存档/记忆移植）。
- **交易方**：富人（保存自己记忆）、壳巢（买记忆完善壳）、走投无路的刻痕者。
- **商品**：记忆药（临时复制天赋/恢复记忆/记忆移植）。
- **规则**：白塔的"合法化灰色"——有合同、有价格、有"售后服务"（副作用自负），但**它的商品本质是"记忆的商品化"**（存档≠铭记）。
- **风险**：高——白塔的药有后遗症（记忆混乱/人格碎片化），且**一旦在白塔"存档"，你的记忆就进了它的数据库**（可能被卖/被用）。

## 三、交易规则（谁定规则 · 怎么定价）

### 3.1 定价逻辑（为什么值这个价）
- **外物价格 = 存在力含量**：记忆结晶按纯度定价（碎晶<结晶<记忆之核）；刻痕石按 SEE 加成定价；遗物按"承载的存在力+情感债"定价（遗物是唯一"无价"的——因为情感债无法标价）。
- **稀缺性定价**：裂缝高发区的外物便宜（货源多），和平区贵；壳潮期间外物暴跌（猎壳者变多）。
- **情报溢价**：百川堂的情报按"时效+致命度"定价——时效性越高越贵，越致命越贵（但"必死局"不卖）。

### 3.2 交易安全（凭什么放心）
- **面具制**：地下市场买卖双方面具入场，身份互保——百川堂担保"不在场内黑吃黑"（但它在场外记你的账）。
- **验货制**：白塔柜台有"记忆检测仪"（验货真伪）；地下市场靠"观潮者异人"验货（看得见=能验真）。
- **担保制**：大额交易由百川堂做中间人（抽成 10%），违约者被列入黑名单（全市场拒收）。

### 3.3 交易风险（为什么不是躺赚）
- **货源风险**：壳物可能来路不明（买了"壳设的局"=引祸上身）；
- **身份风险**：交易记录在百川堂手里=把柄；
- **伦理风险**：用"被吃掉的人的存在"交易=道德阴影（主角的阴影面之一）；
- **代价风险**：外物本身有代价（吞结晶精神污染/带刻痕石空化）——**市场只负责卖，不负责你的代价**。

## 四、各方势力在市场中的角色（市场=势力角力场）

| 势力 | 在市场中的角色 | 目的 |
|---|---|---|
| **百川堂** | 地下市场主办方/中间人/情报商 | 信息+抽成（它掌握所有人的交易记录=底牌） |
| **剥壳人** | 地表市场监管者 | "合法化"监控，登记壳物来源（防外物流向壳巢） |
| **白塔** | 机构级卖家（记忆药/存档） | 记忆商品化盈利 + 收集记忆数据库（灰色） |
| **观潮者** | 买家+验货方（异人验真） | 猎壳所需外物 + 防止壳巢买走关键材料 |
| **壳巢** | 隐藏买家（通过代理） | 买记忆完善壳的伪装、买刻痕石研究裂缝 |
| **主角** | 独立买家/卖家 | 猎壳得结晶→卖/自用；找遗物线索；借市场追查养母失踪 |

## 五、市场与剧情功能位

- **资源线**：主角通过市场获取外物（猎壳卖结晶→攒钱买刻痕石/遗物线索）——"变强"不止打怪，还要"做生意"。
- **情报线**：百川堂市场=情报集散地（养母踪迹/壳巢动向/白塔底细都从这流出来）。
- **社交线**：市场是各方势力碰面的"中立地带"（谈判/交易/偶遇）。
- **伦理钩子**：市场的繁荣=被遗忘者的残骸——主角每次交易都在提醒读者"这座城的存在建立在什么之上"（主题暗线）。
- **危机触发**：市场可能被壳巢渗透（代理买货）、被观潮者冲击（杀光主义砸场）、被剥壳人查封（政策变化）——市场本身是战场。
