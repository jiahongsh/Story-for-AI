# 核心地理锚点（主笔重构版）

- **旧货市场钟表行**：镜辞与守钟人相依为命七年的老店，前间修表暗藏钢针重锤，后间有烧尸毁核的铁皮炉，是主角大本营与日常烟火核心；第27–30章遭白塔四阶水压撞车轰碎左半扇门后由镜辞亲手钉楔修门、挂回招牌，后堂青砖裂缝亦被火钳铁锁焊封重归平静，守钟人昏睡后榻保命。
- **老郭早餐铺 / 东桥巷 / 旧货市场南口卡哨**：旧街日常中心与平民退避防线；第27–30章顾横保下老陈与摊贩平安退撤后于第30章晨市重开早点铺与辣椒摊，然全街在怀表第1格下已彻忘镜辞，老陈顺口唏嘘「以前老板娘叫沈竹，可惜没留下一儿半女」。
- **北河桥洞**：真芽七天前遇险并藏下半枚带血铜齿轮的地方。
- **安平里六号楼 502 室**：退休钟表匠陈启明居所，藏有另半座黄铜母钟，也是真假陈骁修罗场与全书首个「活人锚点」诞生地。
- **城南恒泰设施（地下三层）**：第一卷下半段核心决战地——表面是城市管网设施公司，地下三层隐藏着每晚 **凌晨 02:17** 用失踪活人喂养「零号母表」的同步黑巢。
- **白塔总部与零号源裂缝**：第二至六卷主战场，掌握记忆篡改与全城版本收敛权柄的伪善机构。
- **零号母表外环祭池（第12章现形）**：位于城南恒泰设施地下三层青铜铸铁地板之下，深井内壁缠满暗红发条与滴血铜链，每晚 **02:17** 开启绞盘吊入失踪活人强行抽离生机喂养母表。
- **恒泰西北废弃变电暗井（第21–22章切入点）**：位于焦黑工作钢牌背面标注的冷僻检修暗阶尽头，避开已经塌毁的三号总渠主洞，可垂直下切三十米直抵零号排废层中段走廊，正对白塔先遣清道封焊点。
- **零号母表外井基座（第23–25章现形）**：穿过排废廊尽头重型铅闸后的直径三十米极深圆井，西侧石台仅有独木无栏生锈窄铁桥通向中央暗水上空十倍规模的漆黑青铜巨钟骨架；第25章撬板验明巨钟核心凹槽早在七年前遭人强凿挖空大半、仅余几十条强焊红铜外引副管与白塔新压钢箍吊命；独木铁桥西端紧贴版本档案铁柜背面另藏一条溢水旧砖隙，直抵持续渗雾的窄墙裂缝与钉钩残丝边。
- **城南老棉纺二厂宿舍区（第32–35章赵闻川旧宅）**：红砖六层老筒子楼，距旧货市场东巷约二十分钟车程，紧邻城南第四医院旧北街。楼道狭长潮湿、铁栅防盗门生锈，露天平台水管常年积水，是白塔丑时司重点盯防的续档活死人回居点。
- **城南第四医院与地下停尸回廊（第2卷主战场）**：表面为城南老牌综合医院，地下二至三层分设封闭隔离特护区与冷链停尸回廊，负四层深处则为每逢单数日午夜开启的「换骨流水线」（以城南红印批号「零柒」对外调派活体与骨殖）。
- **城南殡仪馆（火化总库，第2卷下半段战场）**：距城南第四医院约两公里，地下由废弃冷链排水通道相连，暗藏白塔丑时司初级断代迷雾区与火化调包总库。
