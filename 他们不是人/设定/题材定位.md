# 题材定位 ·《他们不是人》（主笔重构版）

- **书名**：他们不是人
- **题材类型**：悬疑脑洞 / 都市异能 / 都市日常
- **目标平台**：番茄小说（男频强节奏悬疑爽文）
- **对标**：无（主笔独立商业化重构，只取市井烟火与强节奏杀伐感，不束缚于旧版对照）
- **核心一句话**：你最亲近的人已被换了皮，它背熟了你的一切过往；修表青年镜辞手持能照出接缝与死前残影的眼睛、一把能卡死时停的旧怀表，在每开一次能力就失去一部分人世熟人记忆的代价下，杀穿伪人黑巢、寻回生机。

## 作者已定

- 彻底废除旧版「公证员不判、留档分袋、物业文书拉锯」写法；主角发现异常即设局试探，抓到破绽即下针反杀。
- 金手指与修表匠身份焊死：一式照缝（借镜窥死）→ 二式卡齿（停摆两秒）→ 锁簧术断母巢共振丝 → 三式逆摆 → 四式空位行者 → 五式万象归位。
- 怀表十一格刻度不可逆递减，代价必须具体咬在活人身上（先狗、后街坊、再过命盟友忘记初见）。
- 壳的规律：靠记忆欺骗长死接缝，但吞不走原主肌肉空间本能；若得活人明知真假仍付出的真心，可生出人类血肉（活人锚点）。
- 每3章有小反转或交锋，每10章必有硬战利品或能力/器物兑现，每卷必有不可逆重创与人世记忆剥离。
- 本书正文严格遵守长篇格式（段落单换行、无加粗分隔线、零破折号）与 P0 长文写作流程闭环。
