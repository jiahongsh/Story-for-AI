# 题材定位

## 基本信息
- 书名：《他们不是人》
- 题材类型：都市异能 / 都市高武 / 身份悬疑 / 升级流 / 群像
- 目标平台：番茄小说
- 核心梗：青梅竹马被披着人皮的怪物顶替，修表匠主角凭一双照出接缝与死前残影的眼睛、一只既会剥离人世记忆又能靠拆解高阶怪机芯逆向上弦的旧怀表，从老街修表铺一路杀穿整座伪人迷城。
- 微创新点：将「身边人被伪人顶替」的极致日常惊悚，与「修表匠拆骨锁簧+掠夺发条机芯上弦」的都市高武养成深度结合；第一卷末怀表跌至第 1 格令全城忘掉主角名字，反倒让他在第二卷起化身「查无此人的幽灵猎手」，人前换马甲潜入各大势力修表套话，人后拎八角铜锤灭门拆核。
- 预计字数：270 万字（约 900 章，16 卷标准大长篇）；目标读者：喜欢《异兽迷城》《十日终焉》《斩神》的番茄男频都市高武与悬疑升级流读者。

## 作者已定
- 章节标题采用 5–12 字冷峻都市悬疑短章名，吸睛有悬念，禁止七言章回体对仗标题，禁止标题剧透兑现结果。
- 彻底废除旧版文书拉锯（物业门禁审批、打印费跑腿费拉锯、内部复核填表扯皮），所有冲突直接落在肉身生死、家破人亡、抢夺核心机芯与记忆抹除刀子上。
- 按方案 B（约 800–1000 章 / 250–300 万字，16 卷标准番茄爆款大长篇）扩容全书架构：不动已写完的第 1–30 章正史，从第二卷起引入「拆核上弦（第二重蓄能表盘）」解决不敢拧表的痛点，补齐「镇钟九响 + 五重表盘进化 + 匠造高武武装」体系，并将世界生态扩充为「无名钟表行（空位同盟）、剥壳人总局十二组、白塔十二时辰修正司与四大续档财阀、七大缝皮宗师与十二母巢王座、六大断代迷雾禁区」。
- **第 38 章起彻底启用「钟表机芯成色 × 镇钟九响 + 普通人时痕体系 + 唯一体系外变量」**：全书设定、大纲与第 38 章起正文中完全删除「一阶至九阶」称谓，三大超凡阵营分别直呼「镇钟九响境名（校眼 → 绷弦 → 走汞 → 鸣钟 → 停摆域 → 断代身 → 逆时主 → 空位 → 万象归位）」「白塔牌令（灰牌巡卒 → 铜章哨/铜章手 → 银边巡官 → 黑令统领 → 白塔掌司 → 裁天司命）」「壳侧序列（剥皮种 → 铁脊体/猎犬 → 裁缝 → 缝骨将/大裁缝 → 缝皮宗师 → 母巢王座 → 古钟主 → 终焉主脑）」；增设普通人守夜觉醒**「时痕」体系**（落痕 → 绞弦 → 走汞 → 鸣钟 → 断代往后五重火候，定瞳/骨弦/滞隙/赋械/心锁五大天赋系别）；并确立**「第十二格冗余余数（一核三面：被剪昨天 → 后天无刻者曹严 → 空秒追债反噬）」**与**「全员动态阵营流动（含正方贺钧幻灭反水、程晦叛塔投壳、真陈骁黑化投敌）」**长线架构。

## 核心设定
- 一句话梗概：旧货市场年轻修表匠镜辞发现青梅竹马「芽」被裂隙怪物换了皮囊，为查清养母沈竹七年前拆碎三座母钟的真相并护住身边仅存的活人锚点，他手握银灰旧怀表与捉影镊，以拆核上弦之法一步步登顶镇钟九响「万象归位」，掀翻白塔与源裂缝统治的伪人迷城。
- 主角：镜辞，冷峻狠辣的旧货市场修表匠；金手指为「沈氏银灰旧怀表（五重表盘·拆核上弦）」与「镜返秘传」；弱点是护短记仇且每次突破表盘底限都会承受人世关系剥离；核心动机是找回养母沈竹下落，并在被世界遗忘的宿命里守住那些凭真心记住他的人。
- 世界观骨架：现代都市临江市表象下是「壳」渗透的猎场；超凡体系分为「镇钟九响 / 白塔牌令 / 壳侧怪物序列」，另有普通市民与一线凡人觉醒的「时痕」五大天赋系别；社会暗面由「白塔十二时辰修正司 + 四大续档财阀」与「壳巢七大缝皮宗师 + 六大断代禁区」共同割据。
- 核心冲突：主线矛盾是镜辞率领的「空位同盟（活人真情锚点）」与企图用死人续档、版本收敛抹杀一切不完美人性的「白塔+源裂缝母表」之间的死战；最大阻碍是白塔至高执棋者左衡与零号母表背后的源裂缝意志。

## 读者期待
- 读者来追什么：身边人真假难辨的认知反转爽感、修表匠以精妙手艺拆解高武巨怪的暴力美学、拆核上弦后连开禁招的破境爽感、马甲潜伏敌营的扮猪吃虎，以及「哪怕全世界忘了你，我仍凭刀疤认出你」的群像宿命羁绊。
- 主角自己拿主意、自己拿结果的地方：每一次看穿伪装死角、每一次拆核上弦与锻造武装、每一次封闭断代禁区的规则破局，全由镜辞亲手拍板、亲手下锤拿到核心机芯收益。
- 不能被拿走的东西：沈竹遗留的银灰旧怀表、银钢捉影镊、三座母钟核心部件，以及东巷老钟表行的大本营主导权，绝不上交任何官方机构。
- 还没兑现的期待：养母沈竹留下的半截壳盖「零号表芯不在壳里，在……」的下半句真相；假芽体内原芽死锁的最终蜕变；怀表第二重「蓄能表盘」的首次拆核上弦爆发；姜霁与守钟人被抹除记忆的跨卷重锚。
- 题材边界：都市高武与诡道机械悬疑结合，哪怕借用剥壳人总局渠道也是平起平坐的暗线交易或马甲潜伏，绝不写主角向官僚体制憋屈投降当打手。

## 后面才揭开或用上的东西
- 头号宿敌：白塔至高掌权者左衡与源裂缝「唯一指向」主脑，最早第 11 卷正面登台对决、第 15–16 卷终局清算。
- 最终真相或身世：壳并非外来物种，而是世界时间线被源裂缝清零剥落后的反噬空壳；零号母表早在七年前甚至更早就多次修剪过临江旧昨天，怀表缺失的「第 12 格余数」后天落入白塔弃卒曹严身上形成「无刻者」漏洞；全城机械表每日慢 1 秒，正步步逼近「十二整点总归零」全局倒计时；白塔三大裁天司命中藏有七年前背叛沈竹与守钟人的前代镇钟大师兄纪渊；沈竹以半石化肉身卡死源裂缝七年，最早第 9 卷录像揭秘叛徒、第 11 卷揭露本质、第 14 卷见到沈竹本尊。
- 金手指上限：怀表第五重表盘「零号神迹盘·万象归位（999+1）」，最早第 16 卷终局动用。
- 身份或地位的终点：统御地下「无名钟表行（空位同盟）」、令白塔十二时辰司与十二母巢王座闻风丧胆的**九响至高·无名镇钟王座（万象归位）**，最早第 13–16 卷登顶。
- 实力一级一级怎么往上走：主体系「镇钟九响 + 怀表五重表盘 + 十六卷势力地图」共 9 重境界与普通人「时痕」五重火候并行，每重约 30 万字（约 100 章），合起来支撑 270 万字（900 章）大长篇；敌人按「走汞裁缝 / 银边巡官 → 黑令统领 / 缝骨将 → 时辰司掌司 / 缝皮宗师 → 断代禁区领主 → 母巢王座 / 裁天司命 → 古钟主 → 终焉主脑」逐级递进，绝不越境秒顶级 Boss。

## 这本书靠什么吸引人
- 表层卖点：最熟悉的人耳后藏着惨白接缝，修表匠主角一眼看穿死前残影，用镊子与铜锤当场拆骨除皮。
- 深层爽点（可重复+长线双引擎）：①可重复爽点——旁人眼里的无解高阶诡怪，在镜辞眼里全是一台台漏出 0.1 秒咬合死角的破钟表，拆核还能给怀表上弦充能；②长线情感爽点——全城档案与熟人把我忘光又如何？老子换个无名马甲照样杀穿全城，而真正生死与共的伙伴哪怕失忆百次，依然会在战火里把后背交给我。
- 长线钩子：找齐沈竹七年前拆碎的三座母钟核心（参号、贰号、壹号），杀入零号源裂缝救回养母，掀翻白塔「唯一标准答案」的灭世棋局。
