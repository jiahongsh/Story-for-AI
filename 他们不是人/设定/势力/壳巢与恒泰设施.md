# 势力 · 壳巢与恒泰设施（城市黑手套与暗面王座）

- **暗面最高序列**：壳侧由停摆域至断代身的**「七大缝皮宗师」（换骨、画皮、替命、织影、嫁梦、铸心、饲钟）**以及沉睡在断代禁区底层、对应逆时主的**「十二母巢死壳王座」**统御。
- **第一卷涉案外围骨干**：陈屿（仅是七大缝皮宗师外围最末流的走汞裁缝学徒，代号「裁缝」）、剥皮种、猎犬铁脊体群体、白塔丑时司外勤督察。
- **运作方式**：以「临江恒准外包」「恒泰设施」「城南第四医院」等名义掩护地下裂隙运输，利用凌晨 **02:17** 同步窗口强行篡改市政门禁、户籍与殡仪档案，把失踪活人送往城南地下三层喂养零号母表，并派外围裁缝为刚套皮的壳修补接缝、抹杀目击者。
- **深层核心结构（第17–18章探明）**：外围祭池底下另藏挑高十来米的地下青铜同步大厅（安置百余只青铜巨齿轮及中央分体同步铜核），靠三号一米二废弃排水总渠反向倒抽东巷地脉与参号母表；并常驻两具走汞档「铜甲护卫」及一尊三米高、受母巢高频共振驱动的「铜甲缝合屠夫」。
- **零号母表外井基座（第22–25章探明）**：经西北变电室三十米冷僻暗井直通「零号外围排废中廊」，再破开锈死重铅大闸后即抵直径三十米的凿岩圆井深坑。暗水上空悬浮比恒泰分体站大出十倍不止的漆黑青铜巨钟骨架，顶棚两条结霜粗铜主引管朝城北东巷方向持续抽吸；第25章破板验实巨钟真芯早在七年前被人暴凿挖空大半，仅靠几十条暗红辅助外管及白塔近三年赶造强压钢箍维系伪芯运转，陈屿断丝毙命后伪芯失衡已触发底层暴走震颤。
