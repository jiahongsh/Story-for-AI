# 角色 · 陆寒（白塔丑时司三阶外勤收割组长）

- **姓名**：陆寒
- **身份**：白塔十二时辰修正司·丑时司驻城南第四医院外勤回收小队队长（三阶巅峰外勤修正官，第 34–35 章登场伏诛）。
- **武装与能力**：身着可防常规匕首划刺的白塔暗蓝护颈内甲，脊椎与胸椎正中嵌合一枚高纯度三阶「时隙蓄能驱动核」，右臂装配加压折叠骨剪刀，擅长配合两名二阶铜章收割手封门绞杀失控续档活死人及知情目击者。
- **性格与定位**：冷酷精于封口账目的白塔底层小头目，把续档活死人和普通住户视作「随时可以连人带表打包销账的报废损耗件」；第 34–35 章率队破窗灭口赵闻川与镜辞，却因轻视这名毫无档案记录的「东巷外乡修表匠」，在楼道窄弯处被镜辞以水反光盯满三秒「照缝」揪出护颈 0.1 秒滞隙，遭重铜锤钢倒钩掀开护颈、由银钢捉影镊活生生拆走脊椎时隙核，成为镜辞第二重「银钢蓄能盘」首次拆核上弦的祭品。
- **声线**：习惯先报封口编号再下杀手，嗓音冷滑油腻，带着基层外勤官仗着后台抹账权限的傲慢轻蔑。
