# 角色 · 守钟人（引路老前辈）

姓名：守钟人

- **身份**：钟表行后间修了半辈子老座钟的瞎眼老人；真实身份是上一代**「镇钟人」核心**、沈竹的授业师傅与秘密看守者。
- **背景与性格**：
  - 七年前城西镇钟总堂遭大弟子纪渊出卖覆灭之夜，他双目被毁后与沈竹联手拆碎三座分母钟并假死脱身，随后秘密迁入旧货市场东巷借「参号残胎地脉盲区」隐姓埋名，替沈竹看护十四岁的镜辞与店里的铁炉子整整七年。
  - 嘴硬心软、江湖气极重，平时像个聋瞎怪老头坐在后间喝凉茶，关键时刻直接抡火钳、抛八角重铜锤，比谁都护犊子。第十六卷终局为重启三只母钟大阵燃尽最后寿命，死在老座钟前。
- **声线**：沙哑如生锈铁片摩擦，惜字如金，点拨人只说最要命的一句实话。
- **第16–30章关键进展**：在钟表行后间老座钟木座下守着缺失调速摆轮的半座「参号母表（残胎）」；第17–20章拎火钳救老陈并用血契铜印与大铜锤死镇青砖十二小时护住东巷。第26–29章孤身独抗白塔清拆重伤折腿吐血、被镜辞冒死抢入柜台后，因第1格抹除冲击而彻忘镜辞姓名仅觉其锤风酷似「竹子丫头」客气问「贵姓」；参号地砖受震裂口狂喷冻雾之际，老人仍在重伤半昏中凭本能盲拍出贴胸「血契铜印」卡入南槽、与镜辞手头沈竹壳盖残片隔空合卯助其重封地缝，随即耗尽精力陷入深重昏迷。第30章清晨被安顿于后间布帘木榻休养，呼吸转稳保住老命，留待后续卷章。
