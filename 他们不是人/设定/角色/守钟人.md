# 角色 · 守钟人（引路老前辈）

- **身份**：钟表行后间修了半辈子老座钟的瞎眼老人；真实身份是上一代**「镇钟人」核心**、沈竹的授业师傅与秘密看守者。
- **背景与性格**：
  - 七年前与沈竹一起杀入源裂缝拆碎三只母表，瞎了一双眼睛后隐居旧货市场，替沈竹看护十四岁的镜辞与店里的铁炉子整整七年。
  - 嘴硬心软、江湖气极重，平时像个聋瞎怪老头坐在后间喝凉茶，关键时刻直接抡火钳、抛八角重铜锤，比谁都护犊子。第六卷终局为重启三只母钟通道燃尽最后寿命，死在老座钟前。
- **声线**：沙哑如生锈铁片摩擦，惜字如金，点拨人只说最要命的一句实话。
- **第16–28章关键进展**：在钟表行后间老座钟木座下守着缺失调速摆轮的半座「参号母表（残胎）」；第17–20章拎火钳救老陈并用血契铜印与大铜锤死镇青砖十二小时护住东巷，但受第3格余震始记混十四岁旧事。第26–28章孤身独抗白塔清拆重伤折腿吐血、死按青砖不放被镜辞冲入救回柜台后；因第26章怀表跌入**第1格**抹除冲击，第27章盲眼触摸镜辞锤把后虽辨出其锤风似当年「竹子丫头」却彻底忘净师徒过往，客气生分询问「小伙子贵姓」；第28章硬吃四阶声波护盾重震再呕黑血仍苦劝陌生小师傅速逃，终在参号地砖受零号失衡扯裂两寸喷雾时仰跌出位。
