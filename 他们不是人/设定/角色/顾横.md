# 顾横（剥壳人带路人 · 老兵）

## 配角卡
- **姓名**：顾横
- **性别**：男
- **角色功能**：战友 / 战斗导师 / 剥壳人主战派老兵 / 第一批真离开者
- **与主角关系**：师徒（镜辞进剥壳人的带路人）
- **外貌特征**：壮实，两道断眉，手上的茧比脸皮厚；说话像下命令，笑起来像打雷
- **核心特质**：外冷内热、嘴硬心软、把"记住战友"当本能
- **标志性特征**：有个从不承认的私人笔记本，记着每个战死战友的忌日和习惯——"只是怕忘了该给谁上香"
- **退场方式**：第3卷战死（正面兑付大战代价）——主角第一次真正"负重"

## 独立人格设计
- 不是"送经验的NPC"——他有自己的战争创伤（他带过的兵一批批死，他靠笔记本撑着），有自己的坚持（主战派，坚信壳必须清除）。
- 他的死不是"为了让主角成长"的工具——他是为了守住剥壳人的防线、为了给同伴争取撤离时间而死（兑付重大收益：主角一行的存活+防线守住）。
- 语言风格：命令式、糙话、但从不说废话。

## 与主题咬合
- 变奏（重伤退场/战死前）：「命令会撤销，番号会裁撤。可练进骨头里的东西，跟着人走——我记不清好多人的脸了，可我记得他们出刀的姿势。」
- 功能：军人语系，用"肌肉记忆/训练痕迹"诠释延续——最硬的壳下是最深的铭记。
- 遗产（负重清单第2项）：出刀姿势（肌肉记忆，主角战斗的起手式）+ 私人笔记本（主角续写它，记下被他连累而离开的人）。

## 人物弧线
| 卷 | 状态 | 关键转变 |
|---|---|---|
| 2 | 带路人，考验镜辞 | 收下这个"看得见接缝的小子" |
| 3 | 并肩作战 | 战死——把笔记本和起手式留给主角 |

## 写作要点
- 他的死要"重"：有铺垫（前几章立住他的糙和暖）、有现场（他守的防线）、有余波（主角继承遗产）。
- 不写"英雄主义口号"——他死前可能只说一句糙话（"愣着干嘛，走啊。"），动作比台词重。
