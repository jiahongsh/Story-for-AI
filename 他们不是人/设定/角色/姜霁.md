# 姜霁（女主）

## 配角卡（女主 · 独立人格）
- **姓名**：姜霁（jì）
- **性别**：女
- **角色功能**：女主 / 剥壳人行动员 / 行为指纹法学家 / 独立复仇线主角（绝不陪衬）
- **与主角关系**：搭档 → 战友 → 恋人（双向奔赴，但各自带伤）
- **外貌特征**：短发利落，惯穿深色战术外套；眼神极冷静，看人先看手和肩膀；左耳一枚旧耳钉（父亲留下的）；说话快、判断准，偶尔毒舌
- **核心特质**：冷静果决、方法论独立、嘴上不信"直觉"（后被爱击穿）
- **标志性特征**：靠"行为指纹"识别壳——看微表情/习惯性小动作/应激反应，从不靠肉眼接缝
- **退场方式**：活到终局（主角不能失去所有人，她是活着的锚点）；第7-8卷可重伤但活下来

## 独立人格设计（核心：全程不是主角陪衬）
- **独立动机线**：父亲（老剥壳人）被壳替换，她被蒙在鼓里整整十年，直到第5卷亲手执行任务时识破——她恨壳，更恨剥壳人"共存派"的冷血。**关键设定：父亲没死，只是被囚禁在壳体内**（"被壳替换≠死亡"，原主还喘着，有救回可能）——所以她的主线是"查清父亲的下落、把他救回来"，不是"调查父亲之死"。这条线与主角的调查线平行，只在交汇点协作。
- **独立方法论**：练不出镜返，便自创"行为指纹识别法"——主角靠肉眼接缝，她靠行为分析，两种方法论冲突又互补，谁都不从属谁。她是"存在感知谱系"中的**微弱感知者**（天生直觉，见 `设定/世界观/力量体系.md` 第三节）——她说不清"哪里不对"，但直觉会本能避开某些人；行为指纹法是把这份直觉训练成可用的方法。
- **多天赋（对齐"每人都有多天赋觉醒契机"）**：主天赋=行为指纹·真视良品（天生直觉）；**副天赋=蚀忆**·第5卷识破父亲是壳——十年记忆之痛击开心门（读心/忆潮：读取他人表层记忆、让目标记忆混乱）。觉醒发生在识破后的**静默时刻**（那晚她独自整理父亲留下的东西，才"听见"那些记忆），**觉醒瞬间不说金句**——变奏台词「爱过的人骗不了我」在觉醒**之前**的识破现场自然说出，是她情感的顶点，不是天赋的咒语（见 `设定/世界观/数值定稿.md` 一·五节写作规则1/5）。
- **独立行动力**：顶级枪械 + 近身格斗 + 蚀忆副天赋（战斗中"读"敌人动作意图/断忆卡顿），有自己的行动章节、自己的高光时刻、自己的牺牲与抉择。
- **关键选择**：第6卷发现剥壳人高层已被壳巢渗透，独自脱离组织单干——她的愤怒和复仇由她自己结算。

## 与主题咬合
- 变奏（识破父亲是壳的瞬间）：「我认得出他，不是因为证据——是因为我爱过他。爱过的人，骗不了我。」
- 功能：行为指纹法学家被"爱"击穿方法论——她一生靠证据和逻辑活着，唯独这一次，靠爱认出了父亲。独立人格的高光时刻。
- 她是"铭记者"的活体代表：她记着父亲的习惯，也记着镜辞每一次被遗忘的名字。

## 与对标书女主的切割
- 青灵（异兽迷城）：恋人+并肩战力，多次死而复生，情感线深；
- 姜霁：**独立复仇线+独立方法论+独立行动章节**——不是"主角的恋人"这个功能位，而是"有自己主线的女主"。她的父亲线、她的脱离组织、她的行为指纹法，离开主角也完全成立。
