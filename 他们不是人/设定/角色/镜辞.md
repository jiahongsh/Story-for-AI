# 镜辞（主角）

## 主角卡
- **姓名**：镜辞（姓镜，名辞）
- **性别**：男
- **角色定位**：能看见"壳"接缝的孤儿——全书唯一能识破伪装的人，从"被遗忘的羔羊"成长为"带着所有人前行的人"。
- **身份标签**：旧货市场二手钟表摊主 → 剥壳人特聘"识破者" → 存在实验真相的追查者
- **外貌特征**：偏瘦，总穿旧夹克，左腕戴养母留下的旧怀表（不报时，当护身符）；眼神习惯性扫视细节，手指有拆表芯的油渍；笑起来有点苦
- **性格关键词**：嘴毒心软、观察力强迫症、看似冷淡实则护短、表面漫不经心实则负重
- **核心目标**：追查养母失踪真相 → 保护身边人不再被壳替换 → 让"被遗忘的人"得到铭记
- **核心动机**（情感驱动）：芽被替换是他第一道伤，养母失踪是他永远的缺口——他不想再"来不及"
- **致命弱点**：救人心切导致冒进（会为救一个人暴露自己/透支镜返）；害怕被遗忘却拼命使用会加速遗忘的能力
- **口头禅/标志动作**：给怀表上弦（重大抉择前）；吃面前停一下（芽的习惯，他继承了）；"我看见"（看见接缝时的低语）

## 金手指与天赋（详见 设定/世界观/金手指.md · 数值定稿.md）

### 主天赋 · 镜返（真视门类·禁忌品 · 5阶）
- **镜返**（5阶）：看见接缝 → 照出真身 → 强制现形 → 遗忘领域 → 记忆归还
- **代价**：每用一次，世上少一个人记得他（先路人，后熟人，最后至亲）——被动遗忘
- **隐性真相（第4卷）**：镜返是"存在实验"的副产品，血脉与壳之源头相连（养母沈竹曾参与实验）

### 副天赋之一 · 铭心（铭刻门类·异品 · 第3卷觉醒）
> 镜辞的副天赋不止铭心一个：铭心（第3卷·铭刻门类）+ 蚀忆/腐蚀/摹刻（后期半壳血脉解锁，详见 `数值定稿.md` 4.3 节）。本节只详述铭心——**副天赋不是主天赋的附庸，有独立高光，也有独立失败名场面**。

- **觉醒**：第3卷顾横战死时觉醒——"练进骨头里的东西跟着人走"刺激了血脉中的铭刻天赋。
- **能力**：把"铭记的存在力"化为临时强化——**记住一个人的"遗产"（习惯/信念/招式），就能短暂借其力**。顾横死后，镜辞的起手式是他教的（肌肉记忆）；铭心激活时，可临时获得"被铭记者的能力片段"（顾横的战斗直觉、守钟人的时间感知、芽的感知敏锐）。
- **本质（与主题咬合）**：铭心 = "被带着前行"的具象化——他越铭记谁，越能"成为"谁。但**它只能借"被他铭记的人"之力，借不来陌生人的力**。
- **品级**：异品（副天赋，强度 ≤ 主天赋一半，符合多天赋规则）。

### 副天赋的失败名场面（对标异兽迷城"精神武装失败"Ch971）
> **关键设计**：副天赋必须有"崩的时刻"——能力不是万能，主角不是无敌，悲剧是真实的。

- **失败名场面（第6卷·白壳赴死时）**：镜辞想用铭心借"白壳的能力"（拟魂·摹刻绝品）去救白壳——**但铭心借不来"未被铭记者的力"**（白壳是壳，不是被铭记的人）。铭心激活失败，反噬空化，他只能眼睁睁看着白壳赴死。
- **为什么是名场面**：①宣告天赋的边界（铭心只认"被铭记的人"，壳不在其中）②主题的残酷（他越想救，越发现"铭记"救不了所有人）③和镜返代价叠加（越用能力越空，越空越救不了人）——**双重失败，悲剧成真**。
- **后续影响**：这次失败让镜辞明白——铭心不是"万能外挂"，是"责任"（借谁的力量，就要替谁走下去）。它从"变强的捷径"变成"负重的证明"。

## 与主题咬合
- 变奏（终局自我和解）：「我曾怕自己像从未出现过一样消散，直到我看见你们带着我的习惯、我的信念、我的名字继续往前走——原来我早就活成了你们生命里的一部分。」
- 短句版：「镜返让我从世界上淡去，可我救下的人、守住的事、爱过的人，都会替我把这条路走下去。这就够了。」
- 核心困境闭环：镜返越强→越被遗忘→越依赖身边人→越怕失去→越要变强→越被遗忘

## 与对标书主角的切割
- 高阳（异兽迷城）：系统【幸运】"活得越久越强"——被动变强，靠时间堆；
- 镜辞：镜返"照出真身"——主动识破，但要付存在感。**一个靠活，一个靠照；一个变强，一个变孤。**
