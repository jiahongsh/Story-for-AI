# 角色 · 陈屿（代号「裁缝」· 第一卷反派）

- **姓名**：陈屿

- **身份**：壳巢暗面「七大缝皮宗师」外围最末流的走汞裁缝学徒，表面挂靠恒准外包与恒泰设施当技术员（曾化名周远），黑名单代号「裁缝」。
- **特征**：左眉上方有浅白色旧疤，右手小指微弯伸不直，鼻梁上架金丝边眼镜，穿熨烫平整的浅灰衬衫。
- **性格与变态美学（彻底重构）**：
  - 优雅斯文、骨子里却把「修补壳的接缝、看活人在至亲面前崩溃」当成艺术品来欣赏的疯子。他用金线缝合自己的半壳躯体，擅长炼制裂隙蚀液与吹奏母巢死人骨笛远程引爆下线。
  - 第6章在钟表行被镜辞一锤砸断右手小臂、一针划崩耳后金线半张脸垮塌；第9章在502室楼下遭共振丝崩断反噬七窍流血；第13–14章在恒泰地下三层二楼监控室被破窗追上的芽以碎玻璃割断左手腕屈肌筋并踩碎第二支备用骨笛，双手俱废之际撞开排污废料斜道滚动逃命；第16–19章在双腕废尽后强行削平截口，用粗黑金线把两副三寸「黄铜机械骨刺棘爪」生生缝进双肩肉筋，先策动强拆东巷并沿三号总渠逆吸参号母表，第18章疯魔焊胸入核祭出三米「铜甲缝合屠夫」，第19章遭二秒停摆连毁重傀与分体同步铜核，左肩黄铜棘爪更被芽生生连肉筋扯撕下来，惨嚎拍开核座排废泄压闸滚落通往零号深处的竖井并拉死重铅闸保住最后残命。
  - 第22–23章在零号外围排废中廊截杀并吞并白塔先遣死士，将两具空袖尸骸以粗黑金线整齐缝口吊悬壁管、留字「多谢白塔，这两条胳膊很顺手」，反手把剥自死士的**一对白塔黑令制式机械电弧铜臂**（小臂外缘带尺半长锯齿铜刃，可爆闪淡蓝消磁电弧）强行用粗黑金线接回血肉肩窝，在三十米零号外井底座独木铁桥正中堵截三人展开决死拼杀。
  - **第24–25章最终伏诛**：在三尺独木铁桥遭芽借其自身消磁电弧引爆整块老火药饼炸废左黑令电弧臂，被镜辞三秒照缝摸破右肩液压 0.1 秒滞隙并以淬火钢倒钩连窝扯飞右黑令电弧铜臂坠井；退死巨钟底座撕甲露出胸口直连巨钟暗槽的黑金共生线并强撞半格手动抽吸阀后，遭姜霁点碎棘轮与左膝、芽以断钢楔死铜齿轮、镜辞打入三寸淬火钢针行锁簧术憋断共振后由银钢捉影镊剪断共生丝并一锤震碎心口残核，临死狂笑吐露「十层巨钟七年前已被挖空一半」后坠入三十米黑水深井彻底毙命。
