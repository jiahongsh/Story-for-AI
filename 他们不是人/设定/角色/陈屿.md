# 角色 · 陈屿（代号「裁缝」·第一卷头号反派）

- **身份**：高阶半壳修复师，表面挂靠恒准外包与恒泰设施当技术员（曾化名周远），黑名单代号「裁缝」。
- **特征**：左眉上方有浅白色旧疤，右手小指微弯伸不直，鼻梁上架金丝边眼镜，穿熨烫平整的浅灰衬衫。
- **性格与变态美学（彻底重构）**：
  - 优雅斯文、骨子里却把「修补壳的接缝、看活人在至亲面前崩溃」当成艺术品来欣赏的疯子。他用金线缝合自己的半壳躯体，擅长炼制裂隙蚀液与吹奏母巢死人骨笛远程引爆下线。
  - 第6章在钟表行被镜辞一锤砸断右手小臂、一针划崩耳后金线半张脸垮塌；第9章在502室楼下遭共振丝崩断反噬七窍流血，第一卷后段将在恒泰地下三层迎来彻底清算。
