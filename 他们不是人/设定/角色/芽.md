# 芽（青梅 · 复活希望线）

## 配角卡
- **姓名**：芽（全名待定，可配姓氏：许芽/苏芽）
- **性别**：女
- **角色功能**：青梅 / 信任崩塌触发点 / 镜返觉醒契机 / **复活希望线的载体**（全书悬置钩子）
- **与主角关系**：少年青梅，一起长大，一起喝豆浆，恋人萌芽
- **外貌特征**：圆脸，笑起来有酒窝；总扎马尾；校服洗得发白但干净；吃面必先喝一口汤
- **核心特质**：温柔坚韧、相信"被吃掉的人不会真消失"（她的信念成为全书希望）
- **标志性特征**：吃面先喝汤（"先喝汤=回来的信号"）
- **退场方式**：第1卷被壳替换——但**不坐实死亡**，复活希望悬置到终局

## 生死线重设（用户核心诉求：不死透，全书写希望）
1. **第1卷被替换**：少年时最好的朋友被壳替换，镜辞没能识破——第一道伤，也是镜返觉醒契机（被替换当晚他第一次看见接缝）。
2. **习惯残留**：替换芽的壳"吃面时会先喝一口汤"——她的习惯残留在壳身上，像卡在喉咙里的回声。
3. **核心疑问（贯穿全书）**："壳会残留原主的痕迹——那原主是不是还没彻底消失？"这是镜辞追查真相的暗线之一。
4. **闪现节奏**：多卷闪现痕迹、多次空欢喜（读者以为芽要回来了，都是擦肩而过）。
5. **特殊时间点（不坐实）**：某个关键时刻，镜辞用镜返在某个壳体内照出芽的痕迹——她"可能"还在里面，只是被压住了。
6. **终局留白**：不明确写她回来。最后一线——镜辞吃面，对面空位有人"先喝了一口汤"，回头，只有个模糊的影子，或什么都没有。**希望悬置，永远成立。**

## 与主题咬合
- 变奏（被替换前最后一顿面）：「他们都说被吃掉就没了。可我觉得不是——种子埋进土里，不也像死了吗？可春天一到，它又回来了。你要是有天看见有人先喝汤——那就是我，在回来的路上。」
- 功能：第一个"以习惯的形式活在主角身上"的人——此后镜辞每次吃面都会想起这句，芽以"先喝汤"这个习惯永远活着。
- 她是"遗忘≠消失"的最强注脚：被爱过的人，连壳都压不住她回来的痕迹。
- 未竟之约：和镜辞约好"一起去看春天"——成为他活下去的远期念想（负重清单第1项）。

## 写作铁律
- 希望永不坐实（铁律8）：只给"可能的痕迹"，不给"确定的结果"；每一次"差点回来"都要落空或悬置。
- 不消费：遗产（先喝汤/看春天）自然出现，不反复煽情。
