# 养母 · 沈竹（第一铭记者 · 主题源头）

## 配角卡
- **姓名**：沈竹
- **性别**：女
- **角色功能**：养母 / 第一铭记者 / 主题源头 / 怀表刻名者 / 失踪者
- **与主角关系**：养母子（镜辞是她从外面抱回来的孩子）
- **外貌特征**：温和，手指有常年拆修钟表的薄茧；总穿着围裙在钟表行里忙；笑起来眼角有纹
- **核心特质**：温柔坚定、话不多但每句都重、把"记住"当信仰
- **标志性特征**：给怀表上弦的习惯（镜辞继承）；"你叫镜辞"——名字的授予者
- **退场方式**：开篇前已失踪——但不是普通失踪，她提前知道壳的真相，失踪前夜把封着镜返的怀表塞给镜辞

## 身份真相（第4卷揭示）
- **年龄时间线锚点（2026-08-19 定稿，与正文镜辞21岁对齐）**：16 岁拿外婆的表 → 修表十几年（16~28 岁）→ 约 28-30 岁被实验机构招揽成研究员（负责载体生命维持）→ 实验（约 21-22 年前）失控 → 废墟发现婴儿镜辞带走 → 隐居经营钟表行养他 21 年 → 现在约 49-52 岁（戴老花镜吻合）；7 年前（镜辞 14 岁）失踪时约 42-45 岁。
- 她曾是"存在实验"的研究员（负责载体生命维持）——实验撕开存在裂缝、放大壳潮，制造出完美壳（壳王）与半壳（镜辞）两个产物。详见 `设定/世界观/壳的来历时间线.md`。
- 她在废墟中发现"半壳"镜辞（保留壳的感知但未失去人类之心），用爱把他"填满"，当作亲生孩子带走——为保护他，隐姓埋名经营钟表行。
- 她与塔主（白塔之主）是故交/同事，但理念分歧分道：她选"藏起来保护"（情感守护），塔主选"公开研究修正"（技术修正）。
- 她的失踪 = 主动消失（或被壳巢带走），为引开追踪、保护镜辞。
- 怀表刻字"镜辞"：镜是照见，辞是告别——她给孩子起名时就埋下了全书主题。

## 与主题咬合
- 变奏（失踪前夜塞怀表时）：「镜辞——镜是照见，辞是告别。妈给你取这名字，不是让你忘了谁，是让你记住：告别的人，会一直跟着你走。」
- 亲情向台词（核心句）：「别人忘不忘你，妈不管。妈替你把往后的日子都活上，你的那一份，妈带着。」
- 她是"被带着前行"的源头——第一个把"名字"交给世界的人；怀表是她的遗产（负重清单第3项）。

## 写作要点
- 她的失踪是全书第一悬念（开篇钩子），第4卷揭一半，第8卷坐实。
- 不写成"完美母亲"——她怕死，但更怕镜辞不知道人为什么活着；她隐瞒真相既是保护也是愧疚。
- 出场方式：回忆闪回 + 遗物（怀表）+ 守钟人的转述 + 第8卷可能有一场"隔着玻璃的对视"（不坐实是否归来）。
