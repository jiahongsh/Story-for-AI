# 《他们不是人》角色声线节奏卡

名称：角色声线节奏卡

> **v1｜2026-11-11｜用途**：规定**每个人怎么说话**（节奏、落地方式、口癖、词汇质地），不管**说什么**。
>
> **分工**：`存在宣言台词库.md` 管主题方向与内容边界；`设定/角色/*.md` 管人物事实与各自的声线策略；`都市异能正文风格卡.md` v2 管叙述层与通用底线；**本卡管角色层节奏，是三者的补充，不覆盖内容设定**。冲突时内容以台词库/角色卡为准，节奏以本卡为准。
>
> **一句话**：声线不是"每人配一句漂亮话"，是**差异本身**。谁说半句、谁跑题、谁只报数、谁爱重复、谁会被打断——这些必须互相冲突；全员达标等于全员没声线。

## 0. 为什么现在读起来像论文（实测基线）

统计口径：全书 103 章对白段（`“...”` 起始行），按章聚合，见 §5。

| 指标 | 本书现状 | 彭湃前 3 章（9330 字） | 说明 |
|---|---:|---:|---|

| 平均句长 | 91 章**章均句长中位 10.3 字**，前 12 章 6.5-9.7 字 | 长短落差极大 | 全员短句＝另一种均匀 |
| 语气词（全书 2595 句对白） | 呢 96／吧 20／啊 10／**嘛 0／诶 0／呗 1** | 啊 21／吧 12（仅前三章） | 口癖不是平均撒，是**按人分配** |
| 省略号／破折号 | **7／7**（全书） | **51／24**（仅前三章） | 说一半、被打断、拖尾音的物理痕迹全被删光 |

**结论**：不是"写得太干净"，是**全书共用一个发言人**。前几轮逐句掺毛边只能治一句，不规定到人，下一章必然复发。

## 1. 六条红线（否决项，不是配额）

> 以下判的是**不合格**，不是让人逐章凑数。别把它做成新的打卡表（风格卡 v2 §2.2 同理）。

1. **全章对白 100% 完整收尾** → 不合格。至少要有一句说一半、被打断、答非所问或跑题。
2. **同场两位角色平均句长差 < 3 字，且都 100% 落地** → 不合格。这是"声线同构"最硬的机器信号。
3. **任意角色连续 3 句都赢一回合**（每句都精准反打／都得到回应／都闭合） → 不合格。
4. **路人替作者抖机灵**：四字机锋、精确吐槽、说完即落点 → 否决。路人的话要带自己的营生和没说完的半句。
5. **口癖平均分布**：同一批「呢／吧／啊」均匀撒在所有人身上 → 不合格。口癖归人，不归章。
6. **任何人一次性讲完整套因果／理论／主体连续性** → 否决（风格卡 §三 已有，此处按人执行）。

## 2. 核心角色差异表

> 「现文锚点」是**已见于正文／角色卡的真实句子**，只作节奏参照，**不是金句任务表**（台词库 §一.2 明令禁止"每人一句终极金句"）。

| 角色 | 节奏与句长 | 怎么落地 | 毛边／口癖 | 词汇质地 | 禁 |
|---|---|---|---|---|---|
| **镜辞** | 短（6-12 字），**允许停在半句**；被追问才补后半句 | 话常落在物件上，不解释；常没被接住 | 自我修正「我是说…」「先别…」；重复对方最后一个词；偶尔「不一定」 | 尺寸、零件、位置、走时；身体动作代替判断 | 完整因果句、一次讲完理论、漂亮反打、替读者总结 |
| **芽** | 比镜辞长，**一句话塞两件事**，爱跑题 | 赌气收尾、答非所问，常不闭合 | 叠词「行，行」、重复「先吃」、甩锅「别赖我」、外号 | 饭、凉、碗、门、旧街的人；生活账 | 冷静陈述、精确报告、替镜辞下结论 |
| **姜霁** | 最长（20-40 字），但**会自己打断自己**，先报事实再补一句关系细节 | 末尾常常不收，或改口「不，是…」 | 「档案…」起头、罗列、忽然停住改说法 | 证据、行为指纹、时间线、手上动作 | 纯理性判词、把关系细节讲成金句 |
| **沈竹** | 短、温和、**带命令** | 说完就走，不给解释；用动作代替回答 | 「这事你不用知道」「先…吧」、话尾交给收东西的动作 | 名字、资料、该不该知道 | 抒情、解释动机、临别赠言 |
| **守钟人** | 中长，职业比喻，**偶尔啰嗦** | 说一半去修表，话尾落在手上 | 「先别…」「哪根簧片」、重复量词、自言自语 | 簧片、误差、走时、上弦 | 每场都像古代智者、连续两句比喻 |
| **顾横** | **极短**（≤8 字），动词开头 | 落地很硬，但常被别人打断／不接 | 「撤」「看人」；极少语气词 | 跑、撤、门、方位、身体 | 解释自己、长句、集中发金句（角色卡 §293） |
| **白壳** | **随阶段变**：前期引用式「他以前…」→中期断裂「……但我不想」→后期短句自立 | 前期句句有出处，后期才自己收 | 阶段变化本身就是声线；中期允许省略号 | 前期全是"他"，后期才出现"我" | 稳定、宣言、从头到尾一个腔 |
| **左衡** | **唯一允许像论文**：完整、逻辑严密、术语密 | 句子闭合，但**必须被别人打断／不接**，不能让他独占对话 | 「保存／风险／可接受损失／自愿／比死亡更好」 | 工程与伦理词，不带身体感 | 让他赢下对话、让他说完一整段没人插嘴 |
| **壳王** | 三期递变：自认零号（理所当然第一人称）→攻击关系证据（反问）→校正数据库（越来越短、越来越闭合） | 后期句子最闭合，但**不能是全书唯一闭合的人** | 「一个名字不该指向两个人」式删歧义 | 记忆、一致性、合法版本、错误答案 | 咆哮、悲惨自述、把矛盾讲成哲学辩论 |
| **当前存在** | 只说去向／拒绝／承担，**常不回答** | 说完不解释，或干脆没有下半句 | 「我去」「不要」「我自己」 | 地点、动作、承担 | 哲学辩手、完整论证（台词库/风格卡已禁） |
| **张岚** | 短句落到今晚／药／门／钥匙，**在"都答得对"处停顿** | 具体事务与情感句交替，不收束成报告 | 「够知道。」「不够让我今晚跟你睡在一个屋里。」 | 家务、身体、可执行事项 | 承担全卷身份学说总结（角色卡 §四） |
| **老李** | 前期照料陈述＋反问；压力上升**句子变短、连续列举** | 辩解冲到一半被自己绕住 | 「我改了／我对了」「你们把我放在哪。」 | 凭据、合法、门、改没改 | 每句都变判案规则、机械复用一种质问（角色卡 §三） |

## 3. 群像：不许共用一副嗓子

### 3.1 市井（老陈／郭老板／赵奶奶／门卫老高／取钟老人／陈姨）

**每人只准带自己的营生**，且说话不完整、爱自说自话、常常没人接：

| 人 | 手里那点事 | 可用的毛边形状 |
|---|---|---|
| 老陈 | 钳子、十八块、卷帘门、摊子 | 自己拆台、三句不离生意、「省什么省」 |
| 郭老板 | 账、崩边碗、隔帘子喊 | 催账跑题、只喊半句 |
| 赵奶奶 | 土豆、腰、晚上来不来 | 重复叮嘱、答非所问 |
| 门卫老高 | 门禁、时间、谁几点进 | 报数式、不评价 |
| 取钟老人 | 伞、雨、落下的工具 | 递东西＋一句不相干的问话 |
| 陈姨 | 女儿、菜、街坊旧事 | 转述别人、说一半想不起来 |

**硬禁**：四字机锋（「饿死省粮。」式）、替作者抖包袱、每人都同样俏皮、说完即落点。路人不是金句发射器。

### 3.2 调查线（唐宁／周衡／猫眼／梁朔／接缝修复师）

按工种分，不按"报告体"分：

- **唐宁**：语速快、尾音上扬，先问「为什么不告诉我」，拿具体经历和费用说话；受伤时短质问（角色卡 §二）。
- **猫眼**：报价用简短交易单位与反问，紧急时短命令；先点出"问题范围"再交可核实材料；**不每句都「超纲」**（角色卡 §331）。
- **周衡／梁朔**：只报能核的，慢半拍，常把话尾留给别人；不许下整套结论。
- **接缝修复师**：谈结构、缝、贴合，句子长短随手上活变化（角色卡 §29 已有"说话节奏"条）。
- **否决**：五个人全用「记录／核对／不能证明／先别判」同一套词，那是把风格卡的灰度腔分给全员。

## 4. 允许反常，但要有理由

- 角色可以在某场戏违背自己的参数（芽忽然一句完整冷静的话、镜辞一次讲完一整句、左衡被人问到答不上来）。**反常要有情境理由**，且不能连续三章反常——那等于没设。
- 情绪极点允许**全员短句**，但只限一个场景；恢复推进后立刻回到各自节奏。
- 阶段型声线（白壳、壳王、老李）以**变化**为达标，不是每一卷都从头套表。

## 5. 可检测口径

### 5.1 章级自动统计（不新增门禁脚本，按风格卡 §九 人工复核）

```python
# 逐章：对白段 = 以“开头的非空行；inner = 首个引号对内的文字
# 输出：句数 / 平均句长 / ≤8字占比 / 完整收尾率(。？！) / 疑问率 / 语气词命中
# 章级红线：完整收尾率 == 100% -> 标红；同场两位角色（人工标注）句长差 <3 且都100% -> 标红
```

本卡**不并入 `check-ai-patterns.js`**：两版脚本字节仍未统一，且角色归属无法自动判定，硬塞只会产出假阴性（参见 `审查补充_对白摩擦力与伪留白_2026-11-10.md` §4）。

### 5.2 写完一章的人工复核（5 问）

1. 随便挑三句不同人的话，遮住名字，能认出是谁吗？
2. 本章有没有一句**没落地**的话？有没有人被打断？
3. 路人那句是不是在替作者抖机灵？
4. 有没有谁连续赢了三回合？
5. 语气词是不是平均撒的，还是只属于某个人？

**答不上 2 项以上 → 本章声线回炉。**
