# 角色声线节奏卡（主笔重构版）

| 角色 | 说话口径与节奏 | 压力下的真实反应 | 绝不能写成 |
|---|---|---|---|
| **镜辞** | 平时懒散毒舌、爱跟老街坊斗嘴；动起手来字少音冷、刀刀直指要害 | 越到绝境眼神越冷，习惯顺手摸铜锤、钢针或旧怀表表冠，直接用行动破局 | 优柔寡断、满嘴“先留证再说”的文书员 |
| **芽 / 南芽** | 表面泼辣鲜活、爱踹门拌嘴；撕破脸后语速快而狠、带着拼死护短的决绝 | 体内死锁发痛时微皱眉硬扛，绝不向镜辞撒娇示弱，行动比嘴更狠 | 只会站着等主角猜身份的哑巴谜题 |
| **姜霁** | 干练利落、指令精准、不讲废话；对信任的人会把后背毫无保留交出去 | 左手虎口旧伤痛时咬牙硬忍；记忆被剥离后客气而警惕，带着职业调查官的疏离 | 毫无主见的背景板花瓶 |
| **守钟人** | 沙哑干瘪、惜字如金、每句都带老一辈镇钟人的江湖规矩与冷幽默 | 关键时刻直接丢铜锤或亮炉火，不讲大道理，帮理不帮亲 | 谜语人老头 |
| **陈屿** | 斯文温和、推金丝眼镜带笑意，骨子里透着病态艺术家的优雅残忍 | 被拆穿或吃亏后瞬间撕破斯文，暴戾怨毒、不择手段 | 纯粹发通知书的外包客服 |
| **老陈 / 老郭** | 市井大嗓门、爱开玩笑拆台、满口柴米油盐算计 | 被系统抹除记忆时表现出真实迷茫与生分，一句话戳穿主角的孤独 | 工具人报幕员 |
