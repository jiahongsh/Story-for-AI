## 文件保留与清理口径（2026-11-12 定稿｜唯一正本）

> **适用范围**：`他们不是人/` 全部目录，含 `_归档/`、`回炉备份/`、`创作运行/`、`追踪/候选章/` 与根目录散落文档。工作区级目录（`skills/`、`.workbuddy/`、`拆文库/`、运行时镜像）归属见 `AGENTS.md`，本节只管其在书目录内的副本。
>
> **地位**：本节是**文件生命周期的唯一正本**。`_归档/README_归档索引_2026-11-10.md`、`删除记录_B类_2026-11-10.md`、`删除记录_D类_2026-11-10.md`、`仓库清理盘点_2026-11-10.md` 均为**当时的执行记录／只读快照**，其分级与结论只对该批次有效：既不得据此自动处置新批次，也不得与本节冲突时另立口径。写作与设定的权威链见 `大纲/大纲.md` §〇；本节只回答「文件留不留、怎么留」，不回答「哪份说了算」。
>
> **禁止复述**：其他文档不得整段抄写本节条款，需要引用时只写位置（「见 `归档索引.md`《文件保留与清理口径》§N」）。口径变更只改本节一处。

### 1. 四类处置动作（字母只表示动作，不表示优先级）

沿用 2026-11-10 盘点的 A/B/C/D 命名，把一次性分级升为通用分类。

| 类 | 动作 | 定义 | 默认处置 |
|---|---|---|---|
| **A 归档** | 只移动，不删除、不改正文、不压缩 | 批次已出结论、已被新版替代、或属一次性产物 | 移入 `_归档/` 镜像原相对路径 + 补索引 + 原位留指针 |
| **B 删除候选** | 逐条确认后才可删 | 乱码备份、空目录、确认有正本／归档副本的重复份 | **默认不删**；确认后走 §4 |
| **C 禁删** | 永久或条件冻结 | 回滚层、L0 事实、权威层、双份资产、寻址锚 | 见 §2 |
| **D 归属待定** | 只登记，不动 | 与本书无关、含隐私路径、或归属不明 | 单列清单等作者裁定，**不随仓库提交** |

| `追踪/_tracking-state.json` 及其派生视图 | 状态唯一真源 | 写入只走 `tracking_commit.py` 串行提交，禁止手改状态文件与派生视图 |
| `大纲/`、`设定/` 当前层，`追踪/` 下的逐章记录、章节提交、角色状态、事实档案、时间线 | L1-L4 权威层与事实底表 | 修订按权威树走，不做清理删除 |

> **判定原则：hash 相同 ≠ 可删。** 必须先判定哪一份是正本；工作区正本与归档副本互为镜像时，删工作区那份等于毁正本。2026-11-10 的 B3 已因此**整项放弃、不再列为待删候选**，本条对该结论作永久化。

### 3. 归档触发条件（A 类，四条须同时满足）

1. 该批次已出结论／验收文件，或已被新版替代（新版须由工具重建且指纹可核）；
2. 当前施工不再引用其路径；若历史脚本硬编码该路径，保留 `_已归档_指针.md`；
3. 现行权威文件中指向它的引用已按前缀规则补正，或登记在上方「历史引用说明」；
4. 已有干净 git 回滚点（**先提交或打 tag，再归档**）。

**动作链**：只移动 → 按书根原相对路径镜像到 `_归档/` → 补索引（批次、文件数、聚合 SHA-256）→ 原位留指针 → 单独一次提交，不夹带无关改动。历史文件**正文一字不改**，仅在文首补「历史快照／已闭环范围」标记；不得把当时的「待办」改成「当时就没问题」。

### 4. 删除前置条件与留痕（B / D 类）

> **批准人：只有作者本人。** AI 不得因「重复、体量大、看起来过期」自行删除，也不得把上一轮授权沿用到新批次。每批逐条确认，**单次最多 10 项**，验一批再下一批。

| 删前必备 | 要求 |
|---|---|
| 归属核实 | 写明关键词命中、`git ls-files` 跟踪状态、被哪些现行文件引用（三项齐全） |
| 指纹留证 | 逐文件：路径／字节／SHA-256；整目录另记聚合 SHA-256 |
| 回滚点 | 已跟踪 → 记 blob 与来源提交，附 `git restore --source=<提交> --staged --worktree -- <路径>`；未跟踪 → 必须走 OS 回收站并二次验证可还原，**显著警示「清空回收站后不可恢复」** |
| 影响验收 | 正文／大纲／设定／追踪 文件数与 SHA 不变；100-103 指纹不变；`_tracking-state.json` 不变；归档区文件数只增不减 |
| 留痕文件 | 每批一份 `删除记录_<类>_<日期>.md`，存入 `_归档/`，含清单、删除方式、恢复命令、验收表；**该留痕文件本身进 C 类禁删** |

**禁止手段**：`rm -rf`、`del /S /Q`、按 hash 批量去重、对 `_归档/` 执行 `git clean`、在个人目录（桌面／下载／文档）做递归清理。

### 5. 状态行时效（防「重复说明」变成误导）

- 任何文档文首的「性质／状态／待拍板／待办」行**只在该批次内有效**；批次执行完毕须在**同一轮**同步该行，并在回执节写明结果。
- 历史快照内的待办行**不改正文**，只加文首标记并移入归档区（见 §3）。
- 跨文件的状态指针只允许写**位置引用**（如「见 `大纲/大纲.md` §八」），不得整段抄写条款；避免一处改口径、八处同步债。
- 口径冲突时**上报作者裁定，AI 不选边**；本节与历史记录冲突时以本节为准，历史记录保留原貌供追溯。
