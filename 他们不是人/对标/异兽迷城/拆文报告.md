## 一、一句话结论与题材定位

《异兽迷城》是一部**都市异能 / 悬疑惊悚 / 升级流 / 群像**长篇：以"迷城＝兽之领域"的悬疑谜团为底色，随主角金手指【幸运】"活得越久越强"的成长与多势力群像更迭，逐步揭开世界真相，并在终焉之门前的谢幕之战中完成主角蜕变。核心驱动 = 谜团（迷城＝兽之领域）+ 主角蜕变（金手指【幸运】）+ 多线群像势力更迭；结构为 8 部（十二生肖→麒麟工会→猩红潮汐→命运之锁→第五部上/中/下→终焉之门 + 附录）。

（提炼自 `情绪模块.md` 一、二节，权威详见该文件）

**读者想看什么（按强度排序）：**
1. **认知反转 / 信任崩塌**——身边亲密者竟是伪装猎手（基调恐怖202/诡异189，主题悬念1102，居首）。"你以为的战友/亲人其实是兽"。

3. **群像羁绊与惨烈牺牲**——并肩战友的死与重生（主题友情157/亲情108）。"羁绊越深，牺牲越痛"。
4. **绝境翻盘**——低战力靠机制/智斗逆袭（基调紧迫203/惊奇226）。
5. **世界谜团逐层揭示**——迷城→苍道＝观测者→极（基调悬疑301/好奇208）。"答案一层套一层"。
6. **惨烈决战 / 史诗感**——多方势力总决战（基调震撼214/悲凉203）。"代价巨大的胜利"。

**情绪引擎公式**（驱动单章/单元情绪产出）：
`悬念供给（迷雾/伏笔）→ 压抑累积（威胁逼近/信任危机）→ 释放节点（反杀/揭示/牺牲）→ 余波（代价/新钩子）`
其"齿轮"是 `节奏.md` 的"小/中/大循环"：每圈重复"供给→压抑→释放→余波"，范围逐级放大（单元→部→全书）。

## 三、关键信息与扩写技法总览

（基于 `节奏.md` 二、三节与 `情绪模块.md` 二节；权威详见 `节奏.md`）

全书扩写遵循"长压抑→短爆发"的节奏，技法可归为以下类型与效果：

| 技法类型 | 表现方式 | 效果 |
|---|---|---|
| **延迟揭示链** | 关键信息推进 16 条路径统一走"进入→延迟/误导→验证→爆发→余波"（如终焉之门 Ch396→7-3、苍道=观测者 Ch918→949–952） | 长程追更动力，"埋得下、收得回" |
| **爽点循环** | 12+ 条"铺垫→释放→余波"（何姨反杀、复制首杀、愤怒三拳、令极停） | 约每 10–20 章小爽点、每 50–90 章中/大爽点，维持黏性 |
| **规则博弈替代战力** | 封闭规则局（如狼人杀试炼、裁决者领域）替代纯数值对抗 | 制造智力爽点、拉长中循环 |
| **乐写哀缓冲** | 长暖段（守岁 913–942）后骤降悲剧（971 初雪死） | 落差放大悲恸，长间隔不泄气 |
| **群像缓冲** | 支线日常/情感闲笔（鬼团跟踪、巴秋池怀旧）承载节拍 | 缓和惨烈，保群像温度 |
| **世界谜团分层** | 每揭示一层真相抛更大新疑问（终局仍留"门后战局""命格碎片"） | 保证续作空间 |

## 十、写法技巧清单

（覆盖要求的 7 类技法，例据均溯源硬事实章号）

- **一笔两用**：单物品/事件同时推进两条线。例：符文回路既是物资争夺轴又是开门钥匙（Ch53 古井光束 / 7-3 龙交十二符文门开 / 8-6 门内归手）；乌金发夹既藏信息又暗线蓄势（913–942 守岁）。
- **延迟揭示**：关键信息走"进入→延迟/误导→验证→爆发→余波"。例：终焉之门 Ch396 姜爷"勿开"→Ch446–447 幻象落空→7-3 门开（节奏.md 关键信息 11）；苍道=观测者 Ch918 入雾→Ch949–952 验证→Ch995 爆发。
- **视角欺骗**：读者被误导以为角色是人类/盟友。例：王子凯"天命少年"实为痴兽（Ch11–13 装死 / Ch48 揭痴兽 / Ch52 序列0）；妹妹高欣欣妄兽温柔猎杀（Ch14 虚惊 / Ch60–61 掏心）。
- **对比锚点**：用日常温馨反衬恐怖异常。例：古家村"吃席呕吐蚯蚓""遗照只有四人""凶宅几十年无人住"制造违和锚点（Ch36–40）；父母爱情回忆（Ch523–526）舒缓插叙 vs 喱国探秘惨烈。
- **行为循环**：角色重复行为模式强化人设/埋钩。例：高阳"每次升级伴随信任崩塌"（情绪模块.md 规则A）；"乐写哀"长暖段后骤降悲剧（913–942 守岁→971 初雪死）；苍道每届时间线切断为七条"蚯蚓"轮回（Ch1091–1092）。
- **身体反应替代心理描写**：以生理/物象反应写情绪，避免直白心理剖白。例：Ch199 精神崩溃（连续失同伴）、Ch570 嚎啕（双亲化尘）、Ch896 白兔"消音辞世"、Ch368 吴大海"机械臂摸手"写死别、Ch1214 "废墟彩虹终幕"写悲绝。
- **跨章回扣（物品/意象在不同章节承担不同功能）**：白猫（Ch18–19 异化→Ch28 电线→Ch96 立碑→Ch113 墓园初雪白露→8部收束未明）；勿忘我（Ch253 买勿忘我兑现鬼马遗愿→葬礼延续）；天赋表/序列号（Ch7–8 黄警官序列表→Ch84 疑造假→Ch85 姜爷自曝）；"月色真美"暗号（Ch135→Ch243 回收相认鬼马）；"7预言"（Ch134→Ch255→Ch257）。
