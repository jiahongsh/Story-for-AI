## 一、读者需求 / 情绪引擎

**读者想看什么（按强度排序，源自全局主题 Top 与基调 Top）：**
1. **认知反转 / 信任崩塌**：身边亲密者竟是伪装猎手（基调恐怖202/诡异189；主题悬念1102）。——"你以为的战友/亲人其实是兽"。
2. **金手指成长爽感**：主角"活得越久越强"的可见升级（主题成长158/热血209；角色高阳出场989）。——"能力边界不断被打破"。
3. **群像羁绊与惨烈牺牲**：并肩战友的死与重生（主题友情157/亲情108）。——"羁绊越深，牺牲越痛"。
4. **绝境翻盘**：低战力绝境靠机制/智斗逆袭（基调紧迫203/惊奇226）。——"看似必死，底牌反杀"。
5. **世界谜团逐层揭示**：迷城＝兽之领域→苍道＝观测者→极（基调悬疑301/好奇208）。——"答案一层套一层"。
6. **惨烈决战 / 史诗感**：多方势力总决战（基调震撼214/悲凉203）。——"代价巨大的胜利"。

**情绪引擎公式**（驱动单章/单元的情绪产出）：
`悬念供给（迷雾/伏笔）→ 压抑累积（威胁逼近/信任危机）→ 释放节点（反杀/揭示/牺牲）→ 余波（代价/新钩子）`
该引擎的"齿轮"是**节奏.md**里的"小/中/大循环"：每圈都重复"供给→压抑→释放→余波"，但范围逐级放大（单元→部→全书）。

## 二、故事框架与套路运行图

```
[世界观谜团埋设] ──► [主角金手指觉醒/升级] ──► [身边人信任危机(反转)]
        │                    │                        │
        └──── 势力更迭线 ◄───┴──── 群像羁绊线 ◄──────┘
                          │
                  [中循环：部内核心战役]
                          │
                  [大循环：全书级决战] ──► [世界真相揭示 + 主角蜕变]
                          │
                  [新钩子/未闭合悬念]（门后战局未收束）
```

**运行规则（本书套路如何转）：**
- 规则A：每一次"升级"都伴随一次"信任崩塌"（如复制觉醒伴随妹妹妄兽、绝对防御伴随麒麟杀机）。
- 规则B：每一次"大爽"都预付"惨烈代价"（摘星阁/青扬大桥/谢幕之战皆以队友牺牲换取）。
- 规则C：伏笔必"前置埋设 + 延后兑现"，跨章跨度常达数十至数百章（见节奏.md 伏笔地图）。
- 规则D：长间隔用"乐写哀/切片缓冲/悬念错位"维持期待，不靠纯动作堆砌。

## 三、可复现模块卡（10 张）

### 模块卡 1 · 金手指成长锚点
- **情绪链**：憋屈受限 → 隐忍蓄力 → 升级瞬间碾压爽感 → 新上限的期待。
- **功能位**：主角能力线主轴；每部至少一次可见升级，维持"变强"承诺。
- **可替换项**：成长机制（如"存活时长""击杀数""任务完成度"）、升级表现形式（新技能/数值突破/系统提示）。
- **不可照搬项**：原文专名【幸运】"活得越久越强"、序列号体系、具体升级章（如 27/77/744）及标志台词不得作为模板。
- **来源**：节奏.md 关键信息推进 12（高阳神嗣线）；agg_part1 角色弧。

### 模块卡 2 · 信任崩塌 / 认知反转
- **情绪链**：温馨/信赖 → 细微违和 → 反转惊悚（"原来你是猎手"） → 余震（人兽伦理悬置）。
- **功能位**：恐怖/悬疑基调发生器；可置于亲人、恋人、战友任一关系。
- **可替换项**：伪装身份类别（亲属/同伴/恩师）、反转触发物（异常行为/身体特征/记忆破绽）。
- **不可照搬项**：原文专名（妄兽/嗔兽/痴兽/号角者）、"掏心温柔猎杀""吃心的请求"等独特事件与台词不得照搬；"妹妹高欣欣"等具体人物不可作模板。
- **来源**：节奏.md 情绪触动点 Ch61/Ch70；agg_part1 单元四。

### 模块卡 3 · 双面卧底 / 身份博弈
- **情绪链**：潜伏紧张 → 身份逼近暴露 → 绝境自证/反转结盟 → 立场洗白或牺牲。
- **功能位**：权谋线推进；制造"主角在敌营"的持续高压。
- **可替换项**：潜入动机（组织命令/假死反卧底/情报交换）、信物机制、相认暗号形式。
- **不可照搬项**：原文专名"插眼计划""双子镯"、暗号"月色真美"、麒麟工会/苍母教等组织名与具体章节（135/242）不得照搬。
- **来源**：节奏.md 关键信息推进 8（鬼马线）、11（终焉之门/卧底）；agg_part2 单元1/4。

### 模块卡 4 · 规则博弈生死局
- **情绪链**：诡异压制（出局即死）→ 推理博弈 → 身份反转/悍跳 → 幸存释然或惨胜。
- **功能位**：中层悬疑单元；用"封闭规则"替代纯战力对抗，制造智力爽点。
- **可替换项**：游戏规则外壳（狼人杀/回合制死斗/成语接龙领域）、筹码（生命/记忆/天赋）、反转角色定位。
- **不可照搬项**：原文专名"狼人杀试炼""裁决者领域""5V5回合制"、左爷/明镜等人物、具体牌局顺序不得照搬。
- **来源**：节奏.md 中高潮 3-3/7-4；agg_part3 单元3、agg_part6 单元五。

### 模块卡 5 · 群像牺牲催泪
- **情绪链**：羁绊日常铺垫 → 绝境舍身（自爆/挡刀）→ 催泪名场面 → 释然或重生。
- **功能位**：大高潮的情感重量；用"代价"兑换"胜利的真实感"。
- **可替换项**：牺牲方式（自爆/挡刀/献寿）、羁绊关系（战友/师徒/恋人）、重生机制（拉魂/复活药/记忆留存）。

## 四、重组与复现指南

1. **取骨架不取皮肉**：复现故事时，只借模块卡的"情绪链 + 功能位"，用自有世界观专名与事件顺序填充"可替换项"；凡"不可照搬项"所列专名/台词/章号，一律置换。
2. **节奏对齐**：将模块按节奏.md 的"小/中/大循环"排布——每单元含 1–3 小循环，每部含 1–2 中循环，全书含 5–6 大循环；保持"供给→压抑→释放→余波"齿轮不空转。
3. **代价绑定爽感**：套用模块卡 5/6/7 时，务必让"爽点释放"预付"惨烈代价"，否则胜利失真（本书核心经验：无代价的胜利不成立）。
4. **伏笔跨距管理**：用模块卡 8 时，埋设与兑现跨度建议 ≥ 全书 5%–15% 章量，并预设"误导方向"提升回收冲击力。
5. **长间隔不泄气**：套用模块卡 9 时，缓冲段必须暗藏"错位钩子"（模块卡 8），避免纯水；推荐"乐写哀"落差结构制造记忆点。
6. **谜团分层**：套用模块卡 10 时，每揭示一层真相须同时抛出一个更大的新疑问（本书终局仍留"门后战局""命格碎片"未闭合），保证续作空间。
