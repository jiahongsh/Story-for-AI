## 第766章 不配为人

**概要**
高阳与柳轻盈在梦中展开情报交易：他以"炎凉即姜爷"（S级）与"麒麟真实目的为开门反面即不开门"（S+级）两则情报，交换柳轻盈手中情报。柳轻盈肃然并质疑高阳为复仇造谣，高阳坦荡自证。柳轻盈回赠海川团合并情报，并索要击杀尘埃的最后一刀。高阳言九嗣优先复仇。柳轻盈劝其勿被仇恨蒙蔽，高阳以"不配为人"明志，并求购炸药欲炸百川团地下基地。深夜柳轻盈将两情报记入乌金日记，纸面浮现"收到"，她于黑暗中抽烟发呆。

**关键事件**
- 高阳以情报换情报，真伪取决于柳轻盈手中一情报
- 高阳问猩红潮汐X问题情报源是否姜爷，柳轻盈笑而不答
- 高阳抛S级情报：炎凉长老即姜爷，准确率九成
- 柳轻盈认可多事连上，评估特殊时期算S级
- 高阳抛S+情报：麒麟真实目的为开门反面即不开门
- 柳轻盈肃然质疑高阳为复仇造谣，高阳坦荡自证
- 柳轻盈回赠海川团合并情报，坦言麒麟防范她
- 柳轻盈要杀尘埃时捎上自己最后一刀，高阳允复仇优先
- 柳轻盈劝高阳勿被仇恨蒙蔽，高阳言不配为人显决绝
- 高阳向柳轻盈求购炸药欲炸百川团地下基地
- 柳轻盈允弄炸药并劝三思，高阳言应劝麒麟
- 深夜柳轻盈记黑皮日记：炎凉=姜爷、麒麟不开门，可信度高
- 日记纸面浮现"收到"，柳轻盈抽烟于黑暗客厅发呆

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 情报等价交换框架 | 用交易结构包装核心爆点，节奏克制 |
| S/S+分级定级 | 游戏化分级，强化情报分量 |
| "开门的反面"表述 | 留白式结论，保留谜底勾连前文 |
| "不配为人"明志 | 短句金句，收束仇恨主题 |
| 炸药炸深渊的意象 | 极端目标外化复仇烈度 |
| 乌金日记"收到" | 神秘收尾，暗示更高层监视者 |

**逐章写法公式**
- 情绪流向：试探博弈 → 抛料震动 → 质疑对峙 → 交易达成 → 决绝明志 → 神秘收束
- 节奏配比：梦中交易占七成，炸药支线占一成，深夜日记占二成
- 结构公式：情报博弈（明线爆点） + 复仇表态 + 神秘日记钩子
- 核心技巧：用"情报商谈判"外壳递送主线真相，结尾留神秘监视者
- 卡点与伏笔：日记另一端"收到"者是谁、炸药后续、麒麟是否真不开门
