## 第36章 此非彼

**概要**：黑发将胖俊抛起拖向枯井，王子凯跃起以异化双臂锁住胖俊，双腿卡住井台与黑发僵持，却被甩成「大摆锤」在祠堂横冲直撞，半分钟拆光整座祠堂。青灵挥长刀斩断发丝以为得救，却被新涌出的黑发缠住手腕也成人粽，高阳开枪证实子弹穿过发丝如穿水流、根本无效。黑发将胖俊青灵拖向井口，王子凯、青灵双腿卡住井沿，高阳黄警官冲上抓住两人，五人抱成畸形的「三头六臂」与黑发拔河，王子凯嘴上说「牺牲你一个救我们四个」，实际死也不松手。井口地面骤然塌陷，五人坠入地底。高阳醒来时天光大亮，身处艳阳高照的古家村村口，青灵正咬着绷带绑伤，系统提示已进入「未知领域」、幸运点收益增幅至2倍。成群白鹅穿过，一个老大爷问他们是不是来吊丧的，讲述隔壁华子一家五口一夜分尸的惨案。高阳发现村口那块刻着「古」字的石碑完好无损——来时它明明是裂开的。结论：这个古家村，不是之前那个古家村。

**关键事件**：1.王子凯异化双臂锁住胖俊与黑发拔河，五人抱成「三头六臂」卡住井口，地面塌陷集体坠入地底 2.高阳在艳阳高照的古家村村口醒来，系统提示进入未知领域、幸运点收益增幅至2倍 3.老大爷口述华子一家五口分尸惨案，高阳凭完好的石碑断定此古家村非彼古家村

**逐章写法公式**：

- **情绪流向**：起：紧张（发丝救人拔河） → 承：压抑（五人坠井） → 转：惊异（艳阳古村、系统提示） → 合：悬念（此非彼的结论）
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：发丝救人拔河（冲突爆发） + 坠井转场（场景切换） + 艳阳村口醒来（氛围反差） + 老大爷口述惨案（线索揭示）
- **本章核心技巧**：用一场激烈的拔河混战把主角团「送」进新场景，再以「同一地点的两种状态」制造时空悬念
- **卡点与伏笔**：结尾卡点：信息揭示卡点——完好石碑证明此古家村非彼古家村，下章期待众人探明穿越真相与华子案；埋设/回收伏笔：华子一家分尸惨案 → 与三十年前古家村灭门案呼应；完好石碑 → 时空异常的证据；幸运点2倍增幅 → 高阳金手指升级
