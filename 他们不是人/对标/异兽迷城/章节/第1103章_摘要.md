## 第1103章 思考

**概要**
本章承接上章逃亡，高阳带领鸦鲨与四十五名同伴借次元空间与瞬移飞行极速撤离马克的追杀，全程不到一分钟。分身穿金色圣衣发动觉悟之力烧毁实验室断后，却在马克手下仅撑一分钟便自毁。高阳吐血意识到分身已死，旋即陷入深度推演：分身本可完成任务后逃生，主动自杀必有缘由。他推断死兽阵营或具备支配、审问尸体的能力，分身以焚天自焚确保尸身灰飞烟灭、不被利用；反推分身第一时间便断定死兽中有其熟人，遂排除朱雀与已火化的麒麟，锁定仍有一具尸体可能被死兽寄生。章末在高阳"还有一具尸体"的惊觉中收束，留下关于李某人尸体的强烈悬念。

**关键事件**
- 高阳率众借次元空间与隐身飞行极速撤离，分身自焚断后烧毁实验室。
- 抵达货轮后分身死亡，高阳吐血，众人清点四十五人无伤亡。
- 高阳推演分身自杀原因，锁定死兽或能支配、审问尸体。
- 排除朱雀与麒麟，高阳惊觉还有一具尸体未被处理。

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 分身仅T0.5却撑一分钟 | 用具体战力分级制造实力落差，凸显死兽恐怖 |
| 次元空间十分钟内危险 | 设定硬性时间限制，为撤离添压迫感 |
| 分身自焚灭尸 | 以角色性格反推行为动机，强化逻辑可信度 |
| 熟人熟悉度推论 | 借阵营关系做排除法，推进悬念 |
| 百里弋未提醒 | 留白式旁观者立场，埋后续立场伏笔 |

**逐章写法公式**
- 情绪流向：紧张撤离→震撼失分身→冷静推演→悬疑收束
- 节奏配比：动作戏短促（约三成），心理推演为主（约七成）
- 结构公式：撤离结果→发现异常→性格外推→排除法→悬念钩子
- 核心技巧：以角色一贯性格反推其选择，用"分身即我"的同质逻辑增强推理说服力
- 卡点与伏笔：末句"还有一具尸体"截断；百里弋未提醒的立场存疑
