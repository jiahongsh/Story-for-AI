## 第667章 666

**概要**
栗子掀开灰布，纯乌金打造的"弑龙巨剑"闪亮登场——长215厘米、重500余斤，剑锋为斜三角、未开刃，靠与杀人专家能量共振形成十倍剑气。斗虎在速写本狂写"666！！！！！"，兴奋不已。栗子按需定制售后：可找江浩借黄连【重力】赋能减重三分之二，友情价20金乌币；斗虎砍价至10块。斗虎令栗子将巨剑收进木匣、自己一周后再碰，暗防其若内奸在乌金注诅咒。陈萤恰至，见斗虎提木匣分享喜悦；栗子却怨其装哑不理自己。陈萤将栗子拉入内室，直言绿茶死于内奸"尘埃"之手，栗子已是重点嫌疑人，敦促其吐实。栗子终松口，称绿茶死前两日曾来找她。

**关键事件**
- 栗子揭幕弑龙巨剑，斗虎写"666"狂喜
- 说明巨剑未开刃、靠能量共振，赋能减重方案与砍价
- 斗虎防诅咒令栗子收好、自己一周后再碰
- 陈萤到访，斗虎分享喜悦，栗子怨其装哑
- 陈萤告知栗子为内奸嫌疑人，逼其吐实
- 栗子承认绿茶死前两日曾找过她

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 巨剑参数量化 | 长215/重500斤等具体数字，增强"终极兵器"真实感 |
| 斗虎"666"无声狂欢 | 哑角用文字表情替代台词，保留喜感 |
| 能量共振代开刃 | 用设定解释非常规兵器，展示力量体系 |
| 斗虎防诅咒迟碰 | 内心独白暴露多疑，呼应内奸悬疑 |
| 陈萤三不接触规矩 | 以"保密称呼/不接触"侧面写组织互防 |
| 绿茶要"针"伏笔 | 栗子将说出的奇葩要求，预留下章爆点 |

**逐章写法公式**
- 情绪流向：狂喜交付→精明砍价→暗防疑云→质询推进
- 节奏配比：武器展示约四成，防范心理约两成，质询线约四成
- 结构公式：宝物揭幕 → 设定讲解+交易 → 暗线防备 → 第二条质询线收束
- 核心技巧：用"哑角文字"制造独特喜剧节奏；双线（取货/查内奸）在同一空间交汇
- 卡点与伏笔：乌金诅咒防备、绿茶所求"乌金针"、栗子是否真内奸
