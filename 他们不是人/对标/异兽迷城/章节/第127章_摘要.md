## 第127章 新任务

**概要**：青灵得到"心法"后一整个下午都努力入定修炼，高阳愧疚却只能任其自然；晚自习结束收到白兔加密短信，让他立刻到本部。高阳与青灵在巷口换便服时故意问修炼有无用，青灵如实答"没用"，高阳顺势称心法与斗虎训练相冲突、把这事翻篇。千禧大楼-F6，青灵去虎门，高阳进了猴门的复古电影院，正放《大闹天宫》。龙蜷在观众席角落，电影高潮处问高阳：若是齐天大圣会去大闹天宫么？高阳盘算过"反问加识谎者套话"会侮辱龙智商，索性实话实说"会"，答"因为天庭在那"。龙笑了，说"白兔没骗我，或许我们真的是一种人"，又自嘲跟我像不是好事。龙先夸他一个月拿两块符文是福星、点出七块符文后暗流汹涌，随即交托一个连斗虎都不知道的神秘任务——第一步只是"继续做好自己"，时机成熟任务自会找上门，暗号出现时高阳自会明白、可自由选择接受或拒绝。高阳讨到"能力范围内任意一件事"的奖励承诺，龙在他掌心写下四个字。

**关键事件**：1.龙在电影院借《大闹天宫》考验高阳，获答"因为天庭在那" 2.龙交托神秘任务：第一步"继续做好自己"，以暗号触发 3.高阳讨到"任意一件事"的奖励承诺，龙在掌心写下暗号四字

**逐章写法公式**：

- **情绪流向**：起：轻松（心法翻篇） → 承：神秘（电影院会面） → 转：热血（天庭之答） → 合：悬念（暗号任务）
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：翻篇日常（缓冲）+ 电影拷问（考验人设）+ 天庭之答（通关盖章）+ 暗号任务（抛出S级悬念）
- **本章核心技巧**：用一部老动画完成对主角"人设"的检验，再把考试通关转化为顶级任务委派，一处两用
- **卡点与伏笔**：结尾卡点：悬念型——龙在手心写下四个字的暗号，任务内容与触发时机成最大悬念；埋设/回收伏笔：白兔引荐龙 → "我们是一种人"背书（回收）；七块符文暗流汹涌 → 更大危机逼近（埋设）；斗虎不知任务 → 斗虎"不自觉参与"预言（埋设）
