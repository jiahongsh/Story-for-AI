## 第894章 巨大代价

**概要**
本章揭出麒麟真正的底牌是生兽傀儡。他本不信高阳“生兽圣水助觉醒者融符文达8级”的情报，却受其启发：只要贾博士能从尸骨提取圣水，他便可循圣水与生兽建立联结、以傀儡大师操控。跨物种联结有副作用，他为此“献祭”右眼——对万象天赋者，眼睛重若心脏，当年朱雀劝戴隐形眼镜他都恐惧放弃，如今却主动挖去右眼珠，只为理想之道毫不犹豫。生兽将复活三分钟、按其意志行动，这是极限。他起初不用杀手锏，一则或不必走到这步、留作更大用，二则要诱敌深入多杀主力，可惜最重要的两个对手不在场。只要把参战者制成傀儡（单王子凯、斗虎便足以震慑拦路者），他便胜券在握。江上白骨生兽成形：绷带如翼骨铺开，女尸灌注能量充盈白骨，随即爆开增生白肉填满——一只真正的生兽复活，形似庄梅二形态却更巨更邪，因其曾怀最接近咒渊的生兽。张伟惊醒、王子凯亦回神，却对复活过程有种“异乡遇同乡”的熟悉恍惚。他不顾毒雾冲向麒麟、骨刺刺胸却无实感——张伟急喊“你中幻术了”！原来麒麟那番对白一边蓄力、一边以真实场景对王子凯施了数秒微幻觉，张伟免疫才将其唤醒。麒麟失右眼一杖重击王子凯心脏，王子凯如石子在江面打七八个水漂落对岸浅滩，腰部束缚带散，背上张伟不见——七八米外张伟多处骨折、流血昏迷。王子凯喂C药剂续命，见张伟仍有微息。他念高阳“无张伟绝不能独对麒麟”，抬头望见巨大生兽：“打不了主人我还打不了狗么！”纵身冲向夜空。

**关键事件**
- 生兽傀儡是麒麟真正底牌
- 麒麟献祭右眼换跨物种联结
- 生兽三分钟限制与诱敌深入的考量
- 白骨生兽复活成形（参照庄梅二形态）
- 王子凯中微幻觉，张伟免疫唤醒
- 麒麟重击王子凯心脏，二人坠江分离
- 张伟重伤，C药剂续命
- 王子凯转攻生兽

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 生兽底牌的揭晓 | 先否定高阳情报再转“受启发”，把反转讲圆 |
| 献祭右眼的代价 | 用“连隐形眼镜都怕”的旧事反衬此刻决绝，抬升人物 |
| 诱敌深入的算计 | 用“两个关键对手不在”留遗憾钩子，暗示高阳/了了 |
| 生兽复活的视觉流 | 绷带→骨→肉的递进描写，堆出邪异生命力 |
| 微幻觉的伏笔回收 | 把上章长对白重新定性为“蓄力+幻术”，反转认知 |

**逐章写法公式**
- 情绪流向：底牌揭晓的凝重 → 献祭的悲壮 → 复活的可怖 → 幻觉破局的惊 → 转攻的烈
- 节奏配比：前半中速说明（设定交代），中段慢写复活奇观，后段加速对决收束
- 结构公式：底牌设定回溯 + 生兽复活奇观 + 幻觉破局 + 转场攻势
- 核心技巧：用“代价”反衬反派信念硬度；用“对白即幻术”做认知反转
- 卡点与伏笔：生兽三分钟倒计时；张伟生死；王子凯独战生兽的走向
