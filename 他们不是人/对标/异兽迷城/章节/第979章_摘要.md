## 第979章 支点

**概要**
黎明前边境荒岛，九嗣与十二生肖几乎全员集结广场，三油桶燃起篝火。静书被救回、一石施治后召开全体会议，营救决议全票通过，但方案分裂为三派：杀麒麟优先派、救人质优先派、服从派。两位领袖暂不表态旁听。贾博士不耐无效讨论，以四个"有没有可能"戳破幻想，主张"复杂事简单化，找支点"。高阳随即点明支点就是"杀麒麟"。九寒、斗虎击节认同，贾博士满意离场。高阳进一步阐明：无论局面如何变化，杀麒麟是唯一稳定的战略，以不变应万变；曲幽以电竞思维补述"见麒麟就杀"。一石仍忧此方案只存于理论。

**关键事件**
- 全员集结，营救决议全票通过
- 方案三派分歧（杀麒麟/救人质/服从）
- 贾博士四问破幻想，提"找支点"
- 高阳定"杀麒麟"为战略支点
- 战略先行、战术万变的原则确立
- 曲幽电竞类比补述，一石存疑

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 三派分歧 | 用列表式群像表态，快速铺开立场光谱 |
| 贾博士的四问 | 以连续反问制造沉默压强，打破情绪化讨论 |
| 支点隐喻 | 用"杠杆撬物"的日常意象转喻战略聚焦 |
| 领袖暂不发言 | 刻意留白，蓄积高阳定调的权威感 |
| 电竞类比 | 用曲幽职业病口吻通俗化"以不变应万变" |

**逐章写法公式**
- 情绪流向：群情→争执→冷场→顿悟→笃定
- 节奏配比：会议群像（55%）+ 贾博士破局（25%）+ 高阳定调（20%）
- 结构公式：集结议事→派系分歧→长者破幻→点明支点→战略阐明→留疑收尾
- 核心技巧：借"外部聪明人"打破群体迷思，再由领袖收口定战略
- 卡点与伏笔：杀麒麟战略统摄后文所有战术；一石的疑虑为实战风险埋线
