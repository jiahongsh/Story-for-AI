## 第910章 疯子

**概要**
本章回叙高阳“挖人”计划的由来：自了了未杀贾博士、高阳求稳未杀她那刻起，高阳便动念救人再招降。他此前除穿梭、感知外还复制了神迹系天赋“游戏玩家”，与裁决者能量相融；趁明镜油尽灯枯、领域失控，构想出“卡BUG”——在域内给生命打上游戏玩家印记，域外再发动即可复活。他为防了了反杀而隐瞒计划，借两次“假休息”将乌金发夹打上印记，第三回合用掌刺（而非痛苦更小的匕首）穿心，只为把发夹留在了的体内完成标记。域外高阳靠药剂硬撑发动游戏玩家，赌赢复活，自身能量透支昏厥。数分钟后了了在胶囊列车苏醒，瞬夺贾博士手枪，精准推演出全程，却被藏身车顶的高阳以匕首抵颈“通过考验”。了了问为何救想杀他的人，高阳答“想活下去有什么错”，了了叹其“真是个疯子”。

**关键事件**
- 高阳萌生挖人计划，借游戏玩家天赋卡BUG
- 假休息暗标发夹，掌刺穿心留标记
- 域外发动游戏玩家，高阳透支复活了了
- 了了列车苏醒，瞬夺贾博士手枪
- 了了推演复活真相，高阳藏车顶现真身
- 高阳通过考验，了了叹其“疯子”

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| “卡BUG”复活构想 | 设定巧思：以系统兼容性制造合理金手指 |
| 假休息的 double meaning | 叙事诡计：同一动作藏两层真意，制造信息差 |
| 掌刺替代匕首的细节 | 因果伏笔：为留发夹选更残忍法，显角色狠决与缜密 |
| 了了推演的精准 | 人物对等：以同样聪明回应高阳，确认“同类” |
| 车顶藏身的反转 | 悬念回收：昏迷高阳是幻影，呼应瞬移与复制天赋 |

**逐章写法公式**
- 情绪流向：回叙谋算→隐秘布局→惊险复活→恍惚苏醒→俏皮博弈→温情收束
- 节奏配比：计划回叙35% + 复活代价20% + 列车博弈35% + 考验收束10%
- 结构公式：回叙缘起 → 暗中布局 → 域外兑现 → 苏醒反制 → 双向确认
- 核心技巧：用“章末回叙”补充前章留白，再用列车戏完成人物关系闭环
- 卡点与伏笔：了了是否真归顺；高阳重伤如何恢复；鹦鹉/婷婷寒蜩线
