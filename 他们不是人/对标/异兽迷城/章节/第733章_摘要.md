## 第733章 不采纳

**概要**
曼蛇的假投降把古狮、乱鉴搞懵。乱鉴想起上次杀"罐头"被钟赫、天狗痛骂，不敢擅杀，正犹豫间九寒狙击命中其大腿，曼蛇趁机拔腿狂奔，却懊恼飞刀因毒雾僵硬未能洞穿乱鉴心脏；古狮为避子弹失了追击时机。九寒开启群体传音串联战况：据点遭袭、高阳未死但不妙、余人凶多吉少，并约罐头回来吹散毒雾——可惜罐头外出未归，末了九寒惊呼"看到罐头了"。高空毒雾中央，花龟、六霜、肖辛维持三头六臂喷毒附寒，零仇罩风元素免伤却嫌"打下手太无聊"，命微小珞以【玩具】飞碟托住花龟后自己长出风翼冲出毒雾去杀人。废墟里高阳面对炎凉、核东、叨哥，理性最优解是逃走，却"不采纳"——因奈奈张伟昏迷、陈萤失志、蔻蜗垂危至少三个半活人要救。他选最差解：速杀眼前之敌再毁毒雾源头。炎凉不轻敌，发动大面积空间搅拌机，高阳瞬移闪火球逼近核东；核东觉被小瞧，三拨琴弦切裂石墙，墙后人却已不见。

**关键事件**
- 曼蛇假降迷惑古狮乱鉴，九寒狙击乱鉴大腿
- 曼蛇借机突围，九寒群体传音串联战况
- 传音约罐头吹雾，罐头外出未归
- 高空三头六臂维持毒雾，零仇无聊欲出杀
- 微小珞玩具飞碟托花龟，零仇风翼冲出
- 高阳最优解"逃"不采纳，选救人的最差解
- 炎凉空间搅拌机，高阳闪火球逼核东切墙落空

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 假投降制造敌人内耗 | 以"弃械"骗犹豫，把战场心理写成博弈 |
| 群体传音的多人对话流 | 用聊天式播报并行情报，兼顾群像与节奏 |
| 零仇"无聊"的反差动机 | 杀戮狂不为胜负只为痛快，立危险配角 |
| 玩具飞碟的具象化 | 把召唤天赋落成"十米蓝碟"，可视可感 |
| "最优解不采纳"的领袖抉择 | 用理性反衬责任，把逃与留写成主题 |
| 核东"被小瞧"的傲慢破绽 | 以情绪露破绽，为高阳下一章反杀铺垫 |

**逐章写法公式**
- 情绪流向：诈降脱困 → 传音汇流 → 高空待机 → 领袖抉择 → 对峙落空
- 节奏配比：曼蛇脱困线 35%，传音群像 20%，高空线 20%，高阳抉择线 25%
- 结构公式：诈降（心理战）→ 汇流（情报）→ 待机（敌态）→ 抉择（主题）→ 对峙（伏笔）
- 核心技巧：多线用"传音/高空/废墟"三景并列，结尾落回高阳与核东的针锋相对
- 卡点与伏笔：曼蛇假降真假（续）；罐头归来吹雾（解毒伏笔）；高阳最差解（下章反杀钩子）；核东被小瞧（下章代价）
