## 第601章 锁定嫌疑人

**概要**
本章围绕“锁定尘埃嫌疑人”展开。高阳向三领袖提出核心推断：内奸尘埃具备自我洗脑、连自己都能骗过的能力，故能长期潜伏。他还原绿茶心路——凭借读心术偶然听到尘埃体内“另一个声音”，疑其具真假人格而深入调查，最终被察觉并下诅咒灭口。高阳给出三条锁定标准：其一尘埃为女性(朱雀自玄武处获线索、初雪以灵魂气味再确认)；其二十年内加入者不可排除，陈萤、无色可能为早年激活的苍母教休眠间谍；其三尘埃三日内与绿茶有过友善肢体接触。李某人凭岛国之行排除陈萤。陈萤随后报上绿茶三日接触的女性名单，剔除不可能者仍余八名嫌疑人。高阳指出识谎者因对方自欺而失效。会议敲定后天晚八点下深渊取符文，并设计绳系铃铛配李某人十秒先知预警的营救方案。散会后高阳服下美梦软糖，准备与柳轻盈做情报交易。

**关键事件**
- 高阳推断尘埃具自我洗脑能力，还原绿茶调查路径
- 提出女性、十年范围无效、三日接触三条锁定标准
- 李某人排除陈萤，陈萤报出八名嫌疑人名单
- 确认识谎者对该内奸无效
- 敲定后天晚八点下深渊，规划绳铃+先知营救
- 高阳服美梦糖，准备夜会柳轻盈

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 尘埃“自欺”设定 | 以反直觉能力解释长期潜伏合理性，升级悬疑 |
| 绿茶双声线索 | 借读心术回收前期伏笔，串联人格主题 |
| 三条锁定标准 | 用排除法结构收束零散线索，制造推理快感 |
| 八名嫌疑人名单 | 罗列具名清单增强真实感与压迫感 |
| 识谎者失效 | 用能力克制关系制造困境，抬高反派 |

**逐章写法公式**
- 情绪流向：推理铺陈(冷静)→标准递进(收紧)→名单揭晓(压迫)→计划定调(决心)→交易前奏(暗涌)
- 节奏配比：推理陈述占六成，名单与计划各约两成，结尾过渡
- 结构公式：反派能力设定 + 主角推理三标准 + 名单收束 + 行动倒计时 + 钩子(交易)
- 核心技巧：以“排除法+克制关系”把宏大的内奸谜题压缩为可操作清单
- 卡点与伏笔：八名嫌疑人身份、苍母教休眠间谍、下深渊时间表、美梦交易
