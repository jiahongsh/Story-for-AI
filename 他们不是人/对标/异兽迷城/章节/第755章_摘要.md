## 第755章 想不起来

**概要**
木屋外,高阳与高欣欣风雪中无声相拥十秒。屋内,高阳跪在轮椅前紧握朱雀冰凉的双手,立誓救她、为她报仇,回忆翻涌。雪地中,奈奈用“捏脸”天赋为众人换上陌生面孔伪装——高欣欣cos游戏角色“碍事梨”逗哥开心,高阳则选换“李三光”的脸。分兵出发:鸦鲨走海路,高阳、高欣欣、王子凯伪装游客飞离城,朱雀被放进带透气孔的行李箱、借【绝对防御】屏蔽结界躲过安检托运。机舱里,高阳感受兄妹与兄弟的依偎一度柔软,旋即仇恨复燃、眼神转冷。他攥拳自问天赋为何升不到七级,喃喃“为什么……想不起来”自己真正渴望的目标。

**关键事件**
- 兄妹风雪拥抱,情感团圆
- 高阳立誓救朱雀、复仇
- 奈奈为众人换脸伪装
- 高欣欣cos游戏角色逗哥
- 朱雀行李箱托运,三人飞离城
- 高阳机上软硬切换,参悟遇瓶颈

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 十秒无声拥抱 | 以“不言”写厚重亲情,留白胜千言 |
| 捏脸换装 | 用游戏梗轻量化潜行伪装,节奏调剂 |
| 朱雀托运 | 以“绝对防御小花招”回收前设(白虎搬尸),巧思复用 |

| 天赋七级瓶颈 | 把战力体系与心理动机挂钩,设成长悬念 |
| 想不起来 | 章末内心独白点题,把外部危机转入内心谜题 |

**逐章写法公式**
- 情绪流向：团圆温情 → 立誓燃恨 → 轻松伪装 → 潜行紧绷 → 机上软硬切换 → 自我诘问
- 节奏配比：情感慢镜铺陈,伪装戏轻快,机舱内心戏收束
- 结构公式：重逢 → 誓言 → 伪装准备 → 分兵出发 → 旅途心理 → 瓶颈点题
- 核心技巧：用“身体温暖—心理冷硬”的瞬间反转写人物撕裂
- 卡点与伏笔：高阳真实渴望是什么；天赋七级如何突破；离城潜伏是否会被发现
