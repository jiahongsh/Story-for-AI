## 第1160章 保险

**概要**
贾博士分析出可用高阳或龙的血液提炼药剂，暂时抵抗贪婪的命运侵占，但时效仅数秒，难点在于自动判定的注射工具。九寒提出“戒指方案”：戴戒指后以手指是否十秒不动为判定条件自动注射。潜伏巡逻的安禾歌主动要求也配一枚，贾博士应允做两枚。九寒仍不满足，支开安禾歌后开启防窃听干扰球，向高阳提出第三道保险并获批准，又拜托高阳作为“隐身见证人”在场，当面约出陈萤似有重大告白。全章以“保险”为线索层层加码，在推进战术严谨性的同时，埋下九寒与陈萤的情感暗线。

**关键事件**
- 贾博士分析血液药剂可短暂免疫命运侵占
- 判定注射是技术难点（概念伤害难监测）
- 九寒提出戒指自动注射方案
- 安禾歌现身索要戒指，贾博士做两枚
- 九寒要求再加第三道保险并获批
- 九寒约陈萤谈话，高阳当隐身见证人

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 血液药剂免疫命运 | 设定解说的因果链，先点威胁再给解法 |
| 判定难题 | 制造技术障碍，推动角色智慧破局 |
| 戒指十秒判定 | 极简规则设计，用日常动作做触发器 |
| 安禾歌偷听 | 配角主动介入，强化复仇动机 |
| 第三道保险 | 悬念叠加，防窃听营造机密感 |
| 隐身见证人 | 三角关系设定，为告白造私密张力 |

**逐章写法公式**
- 情绪流向：务实→机巧→温情，技术讨论渐入人物关系
- 节奏配比：药剂分析四成，戒指方案三成，情感暗线三成
- 结构公式：难题（如何注射）+ 巧解（戒指判定）+ 扩员（安禾歌）+ 加码（第三保险）+ 暗线（陈萤）
- 核心技巧：把抽象“概念伤害难判定”转化为“手指十秒不动”的具体可操作规则
- 卡点与伏笔：九寒的第三道保险内容未揭晓；陈萤被约谈话，暗示情感或遗言
