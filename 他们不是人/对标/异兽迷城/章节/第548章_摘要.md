## 第548章 泡澡小公主

**概要**：人鬼殊途，鬼团与众人分道扬镳。临别白露转交初雪熬夜写就的明信片信，高阳读后回信并揉白猫脑袋，惹来白露死亡凝视。回酒店统一汇报口径后高阳向麒麟报备。夜半青灵察觉高阳有心事，追问下方尖碑壁画后的异样，高阳约她回离城再做件事再坦白。归国后高阳借火从斗虎处复制【杀人专家】，又在麻辣烫摊以"陈萤爱泡澡"为引子，电话把正泡澡的陈萤骗至校门口。戏谑其"泡澡小公主"后转入正题，试探陈萤能否信任、可否被自己挖角，抛出"三大组织难圆愿望、李夫人亦不能"的论断。

**关键事件**：1.鬼团分道扬镳，初雪明信片信与回信 2.青灵夜半察觉高阳心事，约定回城后坦白 3.高阳复制斗虎【杀人专家】 4.高阳电话骗泡澡的陈萤到校门口 5.高阳试探挖角陈萤，抛出三大组织不乐观论

**逐章写法公式**：

- **情绪流向**：起：温馨 → 承：轻松 → 转：暧昧紧张 → 合：严肃
- **节奏配比**：慢铺垫 40% / 快冲突 0% / 爽点爆发 10% / 悬念留白 50%
- **本章结构公式**：离别赠信 + 夜谈埋线 + 能力复制 + 泡澡钓人
- **本章核心技巧**：用生活化细节（泡澡）自然完成从喜剧到挖角严肃的转场
- **卡点与伏笔**：结尾卡点：悬念型-高阳断言李夫人也实现不了陈萤愿望；埋设/回收伏笔：回收"方尖碑壁画"伏笔，埋设高阳独立势力意图
