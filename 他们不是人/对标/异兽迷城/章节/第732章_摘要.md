## 第732章 投降

**概要**
曼蛇为开路当机立断斩断左手掷地，断手爆炸掀起光火血肢，为灰雄争取空隙；灰雄冲向路口公交车，抱车横移、掀飞小轿车堵缺口，草草架起只拖半分钟的防御工事。二人奔向摘星阁，曼蛇断腕却血流不止——6 级壁虎再生被毒雾毒素遏制。十字路口黑鱼骑赛摩载小青菜、古狮骑巨狮自楼顶包抄，分头接战：灰雄一巴掌扇飞赛摩，遭黑鱼蛛丝、小青菜魔发钢丝缠缚，却用"脸真长""头皮屑真多"的嘲讽使二人中招后惊醒后撤；森鹤藤条锁住灰雄咽喉，被其扯碎。三人服复活药、带偏科守卫印记围而不攻，只等毒雾耗死灰雄。危急时九寒【传音】指示，狙击子弹洞穿小青菜肩，灰雄趁机突围奔曼蛇。另一线曼蛇与古狮追逐，古狮竟纵走哺乳动物朋友不肯送死；曼蛇评估正面五五开、断腕加毒雾毫无胜算，分神间乱鉴自窗中刺出乌金三棱刺，被曼蛇反挡，古狮堵死后路——曼蛇夹击下高喊"我投降！"

**关键事件**
- 曼蛇断手爆炸开路，灰雄公交车筑临时工事
- 毒雾遏制曼蛇再生，断腕血流不止
- 黑鱼小青菜骑摩、古狮骑狮包抄拦截
- 灰雄嘲讽破缠，森鹤锁喉被撕
- 三人围而不攻，等毒雾耗死灰雄
- 九寒传音狙击救场，灰雄突围
- 曼蛇被乱鉴古狮夹击，喊投降

**关键信息与扩写技法**
| 信息点 | 扩写技法 |

| 自断 hand 的狠招开路 | 以身体代价换机动，凸显绝境决断 |

| 围而不攻"等毒雾" | 以环境杀替代正面战，写敌人的从容 |

| 曼蛇"投降"的反转收尾 | 绝境急转，把硬汉逼到低头留钩 |

**逐章写法公式**
- 情绪流向：决绝开路 → 缠斗破局 → 被围焦灼 → 远程救场 → 绝境投降
- 节奏配比：灰雄线缠斗 55%，曼蛇线追逐 35%，九寒救援 10%
- 结构公式：开路（牺牲）→ 拦截（群战）→ 困局（耗杀）→ 救援（远程）→ 收降（反转）
- 核心技巧：双线（灰雄破围 / 曼蛇被围）同时推进，用九寒传音作汇流点
- 卡点与伏笔：曼蛇投降真假（下章收尾钩子）；毒雾持续耗血（时间压迫）；古狮仁念（可争取伏笔）
