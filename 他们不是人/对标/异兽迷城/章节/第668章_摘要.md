## 第668章 直觉

**概要**
栗子向陈萤回忆：绿茶死前两日带酒食来访，奇葩地要一根乌金针，扎入体内重伤灵魂、令其出窍却不伤身；栗子判断理论可行但需灵体伤害天赋者赋能，难度极高，绿茶遂放弃，并嘱其保密。陈萤问不出遗物线索，嘱栗子保密、且之后别与组织中任何人（尤其女性）当面接触。陈萤离厂，于水泥路遇蹲在废轮胎上抽烟的斗虎，脚下放着巨剑木匣。斗虎忽问"你信直觉么"，随即拔青犬妖刀，称凭直觉认定陈萤就是内奸"尘埃"，刀光贴颈却未发动刀气。他先诈称"嫌疑解除"收回刀，待陈萤稍松又冷笑补刀——匕首刺入陈萤胸口，心脏停摆，陈萤倒地溢血。

**关键事件**
- 栗子述绿茶索要乌金针重伤灵魂的奇葩要求
- 陈萤问不出遗物，嘱栗子保密并避接触女性
- 陈萤离厂遇斗虎，被问"你信直觉么"
- 斗虎拔刀指控陈萤是尘埃，刀贴颈未下杀招
- 斗虎先诈"解除嫌疑"收回刀
- 斗虎冷笑补匕首，刺穿陈萤胸口致心脏停摆

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 乌金针灵魂重伤 | 以"奇葩要求"包装高危伏笔，留解读空间 |
| 陈萤三不接触指令 | 用规矩侧面写组织内信任崩坏 |
| 斗虎问直觉铺垫 | 看似闲聊实为心理战前奏，制造错愕 |
| 刀光贴颈不发动 | 留白杀意，先吓后杀的节奏控制 |
| "骗你的"反转 | 二次反转破防，读者与角色同被诈 |
| 心脏停摆描写 |  senses化骤停，强化死亡真实感 |

**逐章写法公式**
- 情绪流向：怀旧感伤→叮嘱凝重→错愕→惊悚→死亡震撼
- 节奏配比：回忆交代约三成，废车场外对峙约七成
- 结构公式：信息回收（绿茶线索） → 安全叮嘱 → 偶遇设局 → 双重反转刺杀
- 核心技巧：用"直觉"作荒诞借口合理化突袭；以"诈降+补刀"双层反转拉满戏剧张力
- 卡点与伏笔：乌金针用途、陈萤是否真死、斗虎为何独行查内奸
