## 第1108章 战力对折

**概要**
本章转回西国死镇营地。迷雾吞噬的废弃小镇中，北部中学篮球馆成了几十名觉醒者的临时庇护所，全员禁出不外。逃亡三日休整无聊，斗虎与老7抛接篮球消遣，朱雀掷空罐截球引其过去谈正事。一番"臭袜子"拌嘴后，朱雀亮出8级【等价交换】的核心"生命银行"——可永久转换生命体间的生命、能量与天赋。她设想将多天赋集中一身以收"一加一大于二"之效，奈何时间无多；细列交易限制（须自愿、一年不可重复、能量天赋仅一对一且永久不可还、己与高阳今年禁交易）后，斗虎算出开战前至多将半数人天赋转另一半，即"战力对折"。朱雀顺势提出不愿参战者自愿退场变回普通人以免牺牲，待高阳归来议决。章末青灵与三女吃泡面忆家乡菜，思绪飘远时忽觉后背一凉，危机将至。

**关键事件**
- 西国营地群像：斗虎老7抛球消遣，朱雀截球谈事。
- 朱雀揭生命银行，提出集中/转移天赋增战力。
- 斗虎算得"战力对折"，朱雀拟自愿退场方案待高阳定夺。
- 青灵等吃泡面忆食，章末后背一凉留危机钩子。

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 死镇篮球馆 | 用废弃空间写"末日避难所"氛围 |
| 臭袜子拌嘴 | 以轻喜剧缓冲战前沉重，塑人物关系 |
| 生命银行规则 | 用设定清单（限制逐条）做实能力边界 |
| 战力对折 | 以数学化结论凝练战略取舍 |
| 后背一凉 | 温情忆食后突转警觉，断于危机前 |

**逐章写法公式**
- 情绪流向：闲适松弛→诙谐拌嘴→神秘布局→冷静权衡→温情警觉
- 节奏配比：群像闲笔（约四成），能力设定（约四成），危机钩子（约两成）
- 结构公式：营地群像→引子截球→能力揭晓→规则条陈→折中方案→危机预兆
- 核心技巧：用日常拌嘴与乡愁软化硬核设定，再以"后背一凉"急转制造落差
- 卡点与伏笔：青灵后背一凉的危机源留待下章；自愿退场方案待高阳回归议决
