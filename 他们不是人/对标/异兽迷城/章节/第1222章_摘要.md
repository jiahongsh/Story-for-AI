## 第1222章 推演结果

**概要**
扮演成百里弋的唐小聪睁眼记忆断层，高阳不给其思考，直问是否推演过结局；对方点头承认却惊觉自己竟忘了推演结果。高阳令其盘腿重演，因果棋盘在心中展开，下棋悔棋高速运算，半分钟后眼底掠过惊讶，推演结束。高阳当机立断令红晓晓时光重置该格空间，强行中断NPC使唐小聪变回昏迷；一石注药剂与状态令其半分钟苏醒，贾博士发动记忆裁缝读取残留——唐小聪全忘，贾博士称残留感受悲观却更倾向"一起上"，收回单挑提议，气氛降至冰点。高阳右手轻抬，绝对结界绽金色莲花化屏风防傲慢读唇，定"十分钟拟定战术"。随后结界碎为金色大雪，高阳孤身立雪中向王子凯选"一对一"。王子凯满意，响指隐去王座与暗红心脏，金发生金光、双瞳绽金纹。他嫌高阳"眼神不对"、笑意转失落之际，高阳借【诈骗】令其分神，以【瞬影】抱缚欲复刻杀麒麟战术，奈何一秒成型的绝对结界太慢；王子凯未动仅体内震荡便将高阳震飞，若非金色圣衣护体五脏六腑已碎，撞断三柱仍在飞，王子凯追上前。

**关键事件**
- 扮演体重演推演，红晓晓时光重置强行中断NPC
- 贾博士记忆裁缝读出残留：悲观但倾向一起上，收回单挑
- 高阳金色屏风防读唇，定十分钟战术后孤身应战
- 王子凯隐王座兽化，金纹战斗态亮相
- 高阳诈骗分神+瞬影抱缚失败，被震荡震飞

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 推演窃取闭环 | 用"扮→演→重置→裁缝"四步收束1221伏笔，节奏紧凑 |
| 残留感受 | 不直给结局而给"悲观但一起上"的模糊指引，保悬疑 |
| 金色屏风 | 以视觉化结界交代防读唇，兼作心理隔离意象 |
| 眼神不对 | 回扣1219"眼中有光"，用同一意象收束宿敌心理线 |
| 杀麒麟战术复刻 | 借前情战术类比，凸显层级差距的残酷反差 |

**逐章写法公式**
- 情绪流向：窃果紧张 → 结果失望 → 冰点转定 → 孤身决绝 → 碾压惊心
- 节奏配比：推演闭环（35%）＋结果部署（20%）＋独身应战（15%）＋交战碾压（30%）
- 结构公式：重演推演 → 中断读取 → 模糊指引 → 屏风定计 → 孤身开局 → 战术失败
- 核心技巧：把跨章伏笔（扮演/杀麒麟）在单章内完成"设-收-用"闭环
- 卡点与伏笔：残留"一起上"为后续群攻埋线；金色圣衣与瞬影为续战斗保留变量
