## 第840章 给我根烟

**概要**
本章承接上章，以地下据点与西国北郊两线展开。据点线中，萌羊扑入白兔怀中，白兔察觉斗虎尚未告知萌羊歌姬死讯，强忍心痛安抚。她走进铁门房间，见斗虎满地烟头、叼着熄烟颓然枯坐，便以调侃掩饰关切，并一针见血拆穿其自责。白兔复盘替身计划：歌姬花店近千禧楼、又是天狗与九嗣联络点，最适合留守站岗，斗虎的下意识判断救了全员——若歌姬是替身，疯批麒麟必将察觉并罢手。她劝斗虎振作为歌姬报仇，斗虎眼中重燃冷光，并透露天狗将赴西国与他领袖面谈。北郊线中，高阳红衣骑赛摩夜探农场，穿越牧场橡树林至小湖，遇一中风老人端坐轮椅，正疑惑间，背后乌金巨剑劈下，被绝对防御金盾挡开，偷袭者现身。

**关键事件**
- 萌羊迎白兔，白兔发现斗虎隐瞒歌姬死讯、自身颓废自责
- 白兔复盘替身计划，点明歌姬真实身份反而瞒过麒麟、救了十二生肖
- 斗虎振作，透露天狗将赴西国与他领袖会谈
- 高阳夜探西国北郊农场，至小湖边遇诡异轮椅老人
- 老人背后突袭，高阳以绝对防御金盾挡下乌金巨剑

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 斗虎颓废态 | 细写烟灰烫唇无觉、满地烟头，用外部物象折射内心 |
| 白兔强忍悲痛 | 以"胸前抽痛"的生理反应外化情绪，克制不煽情 |
| 替身计划复盘 | 借对话倒叙补完前情，逻辑链条清晰 |
| 高阳夜骑镜头 | 比喻（光虫游过黑色动脉）强化速度感与孤独 |
| 轮椅老人怪貌 | 逐部位白描（酒槽鼻、黄牙、歪嘴）营造惊悚 |
| 巨剑突袭转折 | 先静后动，以"肃杀劲风"预警再引爆冲突 |

**逐章写法公式**
- 情绪流向：温情→隐痛→颓丧→戏谑→沉痛→理性→后怕→坚毅→暗涌→凌厉→幽寂→诡异→骤变
- 节奏配比：据点对话占六成（缓，重心理），北郊行动占四成（急，重画面），结尾突袭收束
- 结构公式：重逢温情 → 死亡隐瞒 → 颓废自责 → 逻辑复盘 → 振作转折 → 场景切换 → 夜探设伏 → 突袭揭幕
- 核心技巧：以"烟"为道具贯穿据点线（讨烟、点烟、自责），用外部物象写内心；双线收束于同一冲突
- 卡点与伏笔：天狗访西国领袖会谈、轮椅老人真实身份、偷袭者（斗虎）现身
