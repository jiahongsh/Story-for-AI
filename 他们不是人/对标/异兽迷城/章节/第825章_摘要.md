## 第825章 最后一次交易

**概要**
高阳入梦回到旧居卧室，柳轻盈红裙银发再现初遇场景，但二人已非旧时模样。柳轻盈开门见山宣布金盆洗手、加入海川团，坦言是为替小巴报仇走错一步而买单，亲手杀尘埃并不后悔；她承认卖过九嗣情报却称高阳期望如此，并谢极光镇夜高阳提醒。临别前她在高阳潜意识植入可维持半年的梦境，约定若己死他便知其所托。高阳婉拒其暧昧，互道魅力相惜后梦碎于虚空。三日后时间跳切，歌姬在生如夏花店迎来斗虎与两名实习新人横木、静书，并被唤上阁楼，为下章组织动向埋线。

**关键事件**
- 高阳入梦，柳轻盈再现初遇场景但关系已变
- 柳轻盈宣布退出情报交易、加入海川团并交代动机
- 植入半年期梦境托付，约定死后高阳方知所托
- 高阳婉拒暧昧，二人互道珍重，梦境如程序删减消散
- 三日后歌姬在花店迎斗虎与实习新人横木、静书
- 斗虎唤歌姬上阁楼，引向组织搬家密谈

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 梦境复刻初遇 | 用场景镜像制造“物是人非”的对照张力 |
| 金盆洗手宣告 | 借角色自白一次性交付动机、补偿与谢意三信息 |
| 梦境种子 | 以“若我死你便知”的延后约定做长线伏笔 |
| 三日后跳切 | 用时间跳跃切换阵营视角，拓展叙事半径 |
| 新人群像 | 借静书视歌姬为偶像的闲聊，轻巧补全组织人事 |

**逐章写法公式**
- 情绪流向：怀旧暧昧 → 决绝释然 → 悬疑承诺 → 空寂 → 晴明舒缓
- 节奏配比：梦境对话(65%) + 梦境退场(10%) + 时间跳切(25%)
- 结构公式：入梦复刻 → 重大宣告(动机) → 托付伏笔 → 婉拒收束 → 梦碎 → 现实新线接入
- 核心技巧：把“情报线收尾”与“新阵营线开启”压缩进同一场梦，再用跳切拓面
- 卡点与伏笔：柳轻盈真实立场、半年梦境托付内容、海川团后续、花店阁楼密谈
