## 第639章 高大人

**概要**
凌晨两点，喱国贫民窟铁皮屋内，青灵、王子凯、灰雄、奈奈、红晓晓披斗篷待命，贾博士苏醒吐出河水，怒索实验室与鹦鹉，被青灵一拳打晕由奈奈易容。转场岛国水也街民宿，高阳西装红酒居高临下审贾博士，九寒立于身后呵令其称"高大人"。高阳软硬兼施招揽贾博士遭拒，退而求其供给物资清单，并以"草船借箭"暗示借麒麟资源；贾博士一语识破：高阳从一开始便没真想让他加入。

**关键事件**
- 贫民窟集结：五人披斗篷待命，王子凯劫后沉睡，灰雄扛来贾博士尸体
- 贾博士苏醒怒索实验室与鹦鹉，被青灵一拳打晕交奈奈易容
- 转场岛国民宿：高阳西装红酒审贾博士，九寒立后呵令称"高大人"
- 高阳破功软语，招揽贾博士加入九嗣遭一口回绝
- 备选方案：高阳递物资清单，以乌金电池等换贾博士两件事就放人
- 贾博士识破"草船借箭"，点破高阳本无意让其加入

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 底层集结反差 | 用拾荒老人与铁皮屋的贫民意象，对照高手夺人后的落点 |
| 一拳治嘴 | 以青灵干脆打晕替代辩论，写其务实狠辣 |
| 高大人仪式感 | 用九寒呵令与红酒坐姿，外化领袖权威与距离 |
| 草船借箭 | 借成语双关，暗示将借敌方资源养己，埋战略伏笔 |
| 识破算计 | 以贾博士一句反将，打破高阳控场，留余韵 |

**逐章写法公式**
- 情绪流向：贫民窟的狼狈松弛 → 青灵狠厉 → 民宿的威压 → 高阳破功的松弛与算计被识
- 节奏配比：贫民窟过场三成，民宿对峙七成
- 结构公式：任务收尾（夺人落定） + 转场 + 领袖审讯 + 算计互搏
- 核心技巧：场景反差、以道具写权威、成语双关埋线
- 卡点与伏笔：草船借箭暗示后续对麒麟资源战；贾博士"不站队"成可变筹码
