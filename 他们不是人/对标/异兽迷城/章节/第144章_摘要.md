## 第144章 节外生枝

**概要**：三人正对付店内的暴走迷失者罗姐时，一只年轻嗔兽杀伐者冲破内房木门加入战局——它是没能及时离店的按摩小姐，撞见三觉醒者与暴走迷失者对峙而兽性苏醒。杀伐者先扑高阳被躲，转攻曼蛇被短刀架住，灰雄化狗熊扑来它却灵巧绕开再扑高阳，高阳喷火将它逼上吊扇；杀伐者荡向灰雄肩头欲砍其颈，曼蛇飞刀刺中它的灯泡眼，灰雄趁机擒踝狂摔半分钟，磕断脊椎，曼蛇补三刀刺心。杀伐者死后尸体缩回年轻女性模样。三人回神发现罗姐已从店门口逃走，高阳与曼蛇沿血迹翻墙追入隔壁新小区，灰雄带三名队友把守小区门口。曼蛇断言受刺激的迷失者会像受伤动物躲起舔舐伤口，还提到认识一个以虐待迷失者为乐的觉醒者及其"乐园"。草丛血迹未凝，目标就在附近。

**关键事件**：1.杀伐者破门突袭，三人配合围杀（火焰逼退、飞刀破眼、灰雄狂摔断脊、曼蛇补刀） 2.杀伐者尸体复原年轻女性，罗姐趁乱逃离，高阳曼蛇循血追踪 3.曼蛇透露迷失者习性并提及虐待迷失者的觉醒者及其"乐园"，草丛发现新鲜血迹锁定目标

**逐章写法公式**：

- **情绪流向**：起：紧张（杀伐者破门） → 承：热血（三人围杀） → 转：意外（罗姐逃逸） → 合：悬念（血迹锁定目标）
- **节奏配比**：慢铺垫 10% / 快冲突 60% / 爽点爆发 15% / 悬念留白 15%
- **本章结构公式**：杀伐者破门（制造突发强敌） + 三人配合作战（展示团战默契） + 罗姐趁乱逃逸（延续主线任务） + 循血追踪（埋曼蛇黑暗见闻与追逃悬念）
- **本章核心技巧**：用一场插曲级遭遇战制造高密度动作戏，战斗一结束立刻把镜头切回主线追逃，插曲既展示战力又推动任务
- **卡点与伏笔**：结尾卡点：行动卡点——草丛发现未凝固血迹、目标就在附近，下章期待揪出罗姐；埋设/回收伏笔：罗姐兽化下保有一丝理智、会用武器 → 连环杀人案真相；曼蛇提及虐待迷失者的觉醒者及其"乐园" → 黑暗世界观线索；灰雄与曼蛇"一人半只算平手" → 二人竞争关系
