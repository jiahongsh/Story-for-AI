## 第1087章 发自真心

**概要**
深夜，傲慢王子凯于红色殿堂召集六位死兽王座上的同族。高欣欣赌气飞走后仍被迫归来，缩在嫉妒王座上如闹脾气少女；马克褪去中风痴呆之态，重现昔日拳王锋芒；暴食刘大爷、懒惰望舒、色欲周箐悉数到场；贪婪李某人以尸体还魂，浑身缠黑雾、双腿生红眼，自称提前苏醒的代价。众人闲谈间点破李某人并非寄生而是彻底“占有”了宿主的一切，连名字都被剥夺。高欣欣怒斥李某人污蔑其兄高阳为咒渊，李某人坦言高阳之兄多次坏其好事，险些令神嗣高阳丧命。周箐对神嗣垂涎欲滴，与高欣欣针锋相对。王子凯威压尽显，黄金殿堂之威令六兽俯首，最终以“发自真心”宣告在座皆垃圾、高阳之命为己所有，挥手散会。

**关键事件**
- 王子凯深夜于红色殿堂召集六死兽，高欣欣被迫归来
- 李某人以尸体之姿提前苏醒，黑雾缠身、双腿生红眼
- 望舒点破李某人“占有”而非寄生，连宿主真名都一并夺走
- 高欣欣与李某人因“咒渊”旧怨对峙，周箐觊觎神嗣高阳
- 王子凯释放黄金殿堂威压，六兽臣服，下令高阳之命归己
- 王子凯“发自真心”宣称众人皆垃圾，散会

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 六死兽齐聚、各据王座 | 群像分镜：逐一特写衣着、神态、动作，建立阵营阵容 |
| 李某人借尸还魂、腿生红眼 | 身体恐怖描写：以“复古晚礼服”比喻弱化惊悚，制造反差 |
| “占有”而非“寄生”、夺去名字 | 概念反转：用对话点破设定，借望舒之口交代“名字=身份命运” |
| 王子凯黄金殿堂威压 | 抽象力量具象化：以“殿堂压脊”写压迫感，收放只在念间 |
| 首领与成员的张力 | 威压反差：先卖关子再瞬间碾压，确立绝对权威 |

**逐章写法公式**
- 情绪流向：闲散群像 → 暗流交锋 → 威压爆发 → 狂傲收束
- 节奏配比：群像铺垫(40%) + 对话交锋(35%) + 力量爆发(15%) + 收尾(10%)
- 结构公式：阵营集结(全员亮相)→旧怨对话(信息释放)→首领立威(高潮)→散场
- 核心技巧：用“反差感”塑造死兽——周箐魅魔化却斗嘴、望舒慵懒如居家，弱化物设距离
- 卡点与伏笔：李某人“提前苏醒的代价”、无法窥探高阳命运、王子凯独占高阳的用意
