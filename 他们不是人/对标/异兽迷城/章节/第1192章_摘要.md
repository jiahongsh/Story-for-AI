## 第1192章 将来

**概要**
复刻骏马坐轮椅现身，骏马以光盾周旋并不屑纠缠，转而用伪造的“白兔遗书”诱敌——实为对折计划名单，借物品复制与诈骗天赋让复刻体能量短路，匕首刺心了结。九寒组四人合拢警惕真正的敌人贪婪，黑白灰旷野上黑色火焰凝成李某人。九寒发动三头六臂失败，命运丝线已悄然洞穿众人、完成“联结”，贪婪开始“占有”。安禾歌靠药剂咬出狂犬病扰乱其心智，九寒则传送门突进发动不可逆的自爆，抱住李某人；骏马将陈萤拉入绝对结界，红光淹没一切。本章是智取镜像与绝境反转的高潮过渡，基调诡谲、惨烈而悲壮。

**关键事件**
- 骏马诱杀轮椅上的复刻骏马，继承白兔的跳跃天赋
- 九寒组四人合拢，贪婪以李某人形态现身
- 九寒三头六臂失败，命运丝线完成联结与占有
- 揭示贪婪刻意弱化镜像诱四人杀己，从而绑定命运
- 安禾歌药剂摆脱支配，狂犬病咬李某人争取三秒
- 九寒传送门+自爆抱住李某人，骏马护陈萤入绝对结界

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 伪造遗书诱敌 | 用“情感软肋（白兔）”做饵，再以物品复制替换名单，完成诈骗闭环 |
| 命运丝线的数据化 | 将“占有命运”比喻为数据通过网线传输，具象化抽象支配 |

| 绝对结界的守护 | 用“伤害触发金痣”的被动机制，把护友写成本能反应 |

**逐章写法公式**
- 情绪流向：轻蔑斩镜像的爽利 → 敌人现身的压抑 → 中计的错愕 → 绝地反击的惨烈
- 节奏配比：镜像收尾 25% / 反派登场与解说 35% / 反转大战 40%
- 结构公式：单体智杀（骏马）→ 群体合拢 → 反派登场 → 阴谋揭晓 → 双线反击（安禾歌扰乱+九寒自爆）
- 核心技巧：先小胜再大挫，用“自以为赢了”反衬贪婪的棋高一着，再靠牺牲翻盘
- 卡点与伏笔：命运丝线早已洞穿四人；九寒自爆不可逆，结界外红光淹没留生死悬念
