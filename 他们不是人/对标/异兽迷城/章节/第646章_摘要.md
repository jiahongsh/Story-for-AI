## 第646章 丰富经验

**概要**
清晨观海楼，陈萤带小天见李某人，汇报九嗣已通过传音联系上小天，并隐瞒是自己派小天寻人。九寒以传音提出暗中合作：助百川找出内奸尘埃，交换符文资源租借或至少保持中立。李某人干脆答应，要求绝对保密、自己抽身不留痕，并嘱小天继续搜寻新觉醒者壮大百川。陈萤小天下楼即被九寒传音，黄拱门早餐时以咖啡为掩护详谈。双方论证复制、幻影分身、时光重置均无法安全排查尘埃。九寒要求陈萤每夜11点阳台待命、不定时传音按指示行动，并令其偷组织符文作计划一环；陈莹识破乃利用而拒，对小天宣称"合作失败"作掩护。末了陈萤最终OK，确认找内奸合作仅高阳、九寒、陈萤三人知晓。

**关键事件**
- 陈萤向李某人汇报九嗣联系上小天
- 九寒传音提案暗中合作抓内奸
- 李某人应允并嘱壮大百川
- 黄拱门密谈，论证多种天赋不可用于排查
- 九寒令偷符文，陈萤识破拒绝对小天演"失败"
- 三人密约落成，仅高阳九寒陈萤知情

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 隐瞒派小天 | 用信息差立陈萤的自主与忠诚，埋上级不知情 |
| 传音对话体 | 以[九寒:][陈萤:]格式呈现精神交流，省去旁白 |
| 天赋不可行论证 | 借角色之口系统厘清规则边界，服务后续破局 |
| 偷符文试探 | 用"假要求"测试陈萤底线，反转合作真实性 |
| 对小天演失败 | 以第三人视线遮蔽，保留暗盟的隐蔽性 |

**逐章写法公式**
- 情绪流向：郑重→试探→决断→密谈→冲突→定约
- 节奏配比：高层密谈（约35%），传音对话（约50%），日常掩护（约15%）
- 结构公式：汇报立项→传音提案→上层应允→技术论证→底线试探→暗盟落成
- 核心技巧：用"传音"这一无痕媒介构建只属于三人的秘密通道
- 卡点与伏笔：内奸尘埃、高阳遗忘/受限的天赋规则、陈萤双面掩护
