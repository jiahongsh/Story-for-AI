## 第1135章 绝杀

**概要**
本章承接前情，红晓晓将陈萤与九寒重置回几分钟前，二人只余模糊感觉。张伟误以为两人已被色欲"抢跑"确立关系，备受打击后又释然祝福，引发全场起哄。九寒当众直球告白并强吻陈萤，陈萤虽社死却暗自感激，二人在作战会议上定情。镜头随即拉回正题：朱雀揭示死兽能力与其名相关，既是武器也是弱点，并列出七死兽对应"神"之七部位（色欲=血、暴食=牙、懒惰=尾、愤怒=角、贪婪=眼、嫉妒=翼、傲慢=心），格里高直指那分明是恶魔。朱雀更点出死兽内部并非铁板一块，嫉妒曾不听指挥，且贪婪对傲慢怀有"不屑、惧怕又想控制"的复杂情感。结尾高阳对战术微微点头，埋下伏笔。

**关键事件**
- 红晓晓将陈萤、九寒重置回几分钟前，二人只留模糊记忆
- 张伟误以为二人被色欲"抢跑"确立关系，释然后大方祝福
- 九寒作战会议当场告白并强吻陈萤，全员起哄
- 朱雀揭示死兽能力即其名，对应"神"的七个身体部位
- 死兽内部出现裂痕：嫉妒曾不听指挥，贪婪对傲慢情感复杂
- 高阳对斗虎表示战术"有，但不多"，留下悬念

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 重置只留模糊感觉 | 用配角误读制造喜剧误会与信息差 |
| 张伟"弯道超车"心理 | 以第三方单恋视角反衬主角感情落定 |
| 作战会议当场定情 | 严肃场景插入高甜冲突，制造社死反差 |
| 七死兽对应七部位 | 用表格式设定揭示集中抛出世界观 |
| 死兽内部不统一 | 借敌方裂隙埋下可利用的战术支点 |
| 贪婪对傲慢的复杂情感 | 以人格化情感描写让反派关系可博弈 |

**逐章写法公式**
- 情绪流向：误会哄闹 → 高甜社死 → 利落收束 → 设定肃然 → 悬念上扬
- 节奏配比：前半轻松喜剧约40%，后半情报揭示与伏笔约60%
- 结构公式：情感收尾（前情兑现）+ 会议转场 + 设定批量揭示 + 战术钩子
- 核心技巧：用群体起哄的喧闹反衬随后情报的冷峻，张弛交替
- 卡点与伏笔：高阳"有，但不多"的战术；死兽内部分裂可供利用
