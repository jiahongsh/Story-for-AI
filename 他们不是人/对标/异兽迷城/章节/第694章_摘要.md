## 第694章 计划复盘

**概要**
本章以"复盘"视角回溯雪夜之局的来龙去脉。平安夜，灰雄被留在离江苑别墅看家（陪沉睡的惊蛰），正憋屈时收到"诸事顺，利"短信，欣喜买酒买夜宵准备庆祝。与此同时，陈萤驾车载小天与伪装后的高阳、青灵、罐头、奈奈返程南冀区，奈奈在青灵腿上为高阳复原身形。陈萤追问计划真相，高阳从九寒联系陈萤那天讲起：起初他毫未怀疑黄连；锁定嫌疑人名单后借斗虎"杀美女"排除陈萤；了了将百川团全员列入嫌疑，令高阳醍醐灌顶；直到扫墓时回想起小刘的【仇恨种子】竟达四级——而精神符文从未流入散人，遂推断百川团内奸借符文帮小刘升级，将嫌疑人缩至无色、黄连、绿茶三人。

**关键事件**
- 灰雄留守看家，收捷报短信后买酒庆祝
- 车队返程，奈奈为高斯复原身形
- 陈萤追问，高阳复盘计划起点
- 借斗虎排除陈萤嫌疑
- 了了将全员列嫌疑，突破高阳思路
- 扫墓忆小刘仇恨种子，锁定符文借出者

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 灰雄看家 | 用"老子是熊不看家"吐槽写喜剧留白 |
| 捷报短信 | 回扣前文"诸事顺，利"，形成信息闭环 |
| 车内复盘 | 以"问答+回溯"结构交代推理链条 |
| 了了视角 | 用配角一句话撬动主角认知转折 |
| 仇恨种子 | 以"散人如何升4级"反推，逻辑闭环 |
| 缩窄三人 | 用并列名单收束排查，为下章铺垫 |

**逐章写法公式**
- 情绪流向：憋屈 → 欣喜 → 安稳 → 求知 → 反思 → 顿悟
- 节奏配比：灰雄支线（轻喜剧）约三成，车内复盘（理性回溯）约七成
- 结构公式：后方庆祝 + 凯旋返程 + 抛出疑问 + 逐层回溯 + 关键线索闭环
- 核心技巧：用"复盘"把前文谜团以推理链重新讲清
- 卡点与伏笔：精神符文流向、三人保管组、下章高阳决策
