## 第691章 任务失败

**概要**
本章揭开上章死局真相，并完成绝地逆转。黄连死而复生，摘下墨镜露出幽蓝眼珠，自陈为寄宿者之王"贪兽"（即潜伏的尘埃）——当年大火中正是他寄生黄连才使其活命，如今强行苏醒只为夺舍陈萤。陈萤厉声质问其杀害巴秋池、绿茶的灭口真相，双方对峙。高阳（伪装罐头）满面鲜血持乌金匕首瞬移突袭，缠斗中黄连激活陈萤体内诅咒种子，其灵魂即将爆裂。千钧一发，真正的罐头与青灵自三公里外大楼御刀驰援，罐头发动【游戏玩家·时光重置】，以白色触须将高阳、小天、陈萤回档三分钟前、消去一切诅咒。青灵御刀追击尘埃，尘埃不敌遁逃，刺杀神嗣任务宣告失败，但九嗣成功揪出内奸真身。

**关键事件**
- 黄连死而复生，揭露寄宿者之王"贪兽"即尘埃
- 陈萤质问尘埃灭口巴秋池、绿茶，双方对峙
- 贪兽欲夺陈萤身躯，以十龙寨旧恩相胁
- 高阳伪装罐头持匕首瞬移突袭，焰拳缠斗
- 黄连激活陈萤诅咒种子，罐头时光重置救场
- 青灵御刀追杀尘埃，尘埃不敌遁逃，任务失败

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 寄生反转 | 以"摘墨镜露幽蓝眼"的视觉爆点揭身份 |
| 寄宿者之王 | 用"共用躯壳"设定解释前后矛盾 |
| 夺舍威胁 | 以"白天是你晚上是我"具象寄生恐怖 |
| 时光重置 | 用"神圣白光触须裹成光茧"神迹化描写 |
| 高空驰援 | 以"黑衣马尾御刀+羽绒服搂腰"画面感入场 |
| 任务失败 | 以尘埃自认失败收束，反衬计划成功 |

**逐章写法公式**
- 情绪流向：惊悚反转 → 愤怒对峙 → 阴森压迫 → 凌厉突击 → 神圣逆转 → 不甘遁逃
- 节奏配比：身份揭露与对峙（中速）约四成，突袭+重置+追击（高速）约六成
- 结构公式：死而复生揭底 + 寄生对峙 + 伪装反击 + 神迹救场 + 追击收网
- 核心技巧：用"时光重置"这一规则级能力制造绝境翻盘
- 卡点与伏笔：贪兽夺舍意图、可又骗局、律起接应线
