## 第213章 战后创伤

**概要**：次日十点，高阳在白虎分部5007房醒来，服用二级恢复药后伤口基本愈合、只留浅浅疤痕，他机械地吃着三明治和牛奶，没什么胃口。他彻底接受了过去24小时的一切：4组5组调查11中误入符洞，牺牲西燃、李暗、老乔、修一、黑雀、湘蝶，重伤九寒——这不过是官方通告，真实报告里湘蝶是苍母教安插的内鬼一事已由高阳和灰雄直接向玄武汇报。回溯当晚：一行人用最后一支C药剂救下重伤昏迷的九寒，找回同伴尸体带回旗台，靠两块符文回路开启光柱通道回到现实；青龙长老带队封锁搜查却因符洞边界的"集体沉默"效应无法切入，第二天深夜等到了奇迹，两位长老各保管一块符文、护送伤员回总部审讯。玄武摘下面具、眼神疲倦脸色苍老，为心腹折损一半还出了叛徒而高兴不起来。凌晨三点高阳回到白虎分部倒头就睡，醒来后收到加密短信：11点30分，蓝房子心理诊所——工会疑似要评估他的战后心理状态。他切回"日常高阳"，给妈妈打电话补病假、哄好她，跟妹妹高欣欣微信互怼，然后打车前往诊所，前台短发小姐却问他有没有预约。

**关键事件**：1.高阳在白虎分部醒来，官方通告列出牺牲与重伤名单，真实报告（湘蝶是苍母教内鬼）已直报玄武 2.回溯队伍脱困全过程：光柱通道回归现实、青龙玄武封锁接应、符洞边界"集体沉默"效应、长老审讯，玄武为折损心腹而疲惫 3.高阳处理家人日常后收到蓝房子心理诊所的加密短信，赴约时被前台问"有预约么"

**逐章写法公式**：

- **情绪流向**：起：压抑（战后创伤与名单） → 承：回溯（组织善后与长老反应） → 转：日常（家人温情回温） → 合：悬念（心理诊所邀约）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：晨起恢复（战后状态） + 官方通告（战果清算） + 脱困回溯（补全收尾） + 家庭日常（情绪回温） + 诊所邀约（新悬念钩子）
- **本章核心技巧**：用"大战后的第二天"作章节骨架，借报告、回溯、家庭对话三种载体把战争后果、组织运作、主角身份并线收束，最后用一个突兀的"心理诊所"制造新钩子
- **卡点与伏笔**：结尾卡点：悬念型——前台问"有预约么"，蓝房子心理诊所是谁安排的、要做什么，答案留到下一章；埋设/回收伏笔：符洞边界的"集体沉默"效应 → 辅助符文的功能设定留待展开；湘蝶是苍母教内鬼直报玄武 → 高阳的功绩与后续晋升基础；两块符文由两位长老分头保管 → 神迹符文线的前置
