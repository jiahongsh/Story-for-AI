## 第645章 人类并不感谢

**概要**
炎凉改口让肖辛、酥魅住实验室待命，贾博士明白被监视，问要研发什么，炎凉递纸条列需求后贾博士评估可行松口。炎凉严令肖辛不得向朱雀汇报，违者后果自负。凌晨四点千禧楼鼠门，斗虎召集会议讨论宣战，达成暂不站队的中立共识；留白兔、天狗，白兔转述朱雀来电问态度，回"不插手但活捉青蛇归我们"以释疑，斗虎令天狗常驻歌姬花店盯梢，自己定调"什么都不做吃瓜"，白兔热血被现实浇灭。凌晨五点百川团监房，张伟囚中读《三人本》入宏观超脱心境，厌弃人类、自谓"人类并不感谢张伟"。陈萤放其自由，张伟故作"人类与我无关"冷拒，闻宣战文瞬间破功，雀跃喊"燃"回归阵营。

**关键事件**
- 炎凉安插监视并令肖辛保密
- 鼠门会议定中立，白兔回朱雀话术
- 斗虎布天狗盯梢、定调吃瓜
- 张伟读《三人本》入超脱心境
- 陈萤放张伟，张伟冷拒
- 张伟读宣战文复燃

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 保密令 | 用一句威压收束实验室线，埋肖辛两难 |
| 中立话术 | 借白兔之口设计"不撇清反而生疑"的外交逻辑 |
| 吃瓜定力 | 用斗虎的懒战略对照白兔的热血，制造落差笑点 |
| 书中悟道 | 用小说《三人本》作精神道具，荒诞化张伟蜕变 |
| 冷拒到复燃 | 一冷一热反转，喜剧收束并润滑阵营回归 |

**逐章写法公式**
- 情绪流向：牵制→中立权衡→冷眼→荒诞超脱→戏谑反转→复燃
- 节奏配比：阵营反应（约50%），张伟线（约40%），承上（约10%）
- 结构公式：实验室收尾→第三方会议→布子旁观→囚中异变→放出反转→读文回归
- 核心技巧：用"吃瓜势力+喜剧配角"稀释宣战后的紧绷，保留多线弹性
- 卡点与伏笔：肖辛保密两难、天狗花店盯梢、张伟心态摇摆
