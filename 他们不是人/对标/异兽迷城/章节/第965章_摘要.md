## 第965章 A与B

**概要**
麒麟从容审视钟赫，点破其以愤怒掩盖对强者的恐惧，并辩称不杀是为留人质换符文。李某人痛陈高阳乃“咒渊”、毁灭是命运，自称一直在抗争。钟赫不辩，却讲起同学A霸凌B的寓言：A以伪善理由支配践踏弱者，自己侥幸未成B，却至今惧怕那套逻辑。他由此悟出“怕无用”，立誓绝不让世界交予A，否则人人皆成B。长篇大论实为障眼——灯灭刹那，钟赫早以储物柜阴影幻化的“黑鞋带”为掩护，经书房通风管绕至电闸拉下总闸。魅影不受精神束缚，即便施术者被控仍可惯性杀敌两秒。十八黑影战士合围，武器刺入麒麟与李某人身体。钟赫正疑得手，却想起偷袭前一秒李某人闭眼“不忍”的神情——她能看到十秒后的未来，为何不提醒麒麟？原因成谜。

**关键事件**
- 麒麟点破钟赫恐惧，以人质逻辑自辩不杀
- 李某人咒渊之辩，钟赫以A与B寓言回应
- 钟赫借长谈掩护，灯灭后拉闸发动影之军团
- 魅影惯性机制确保两秒必杀，十八黑影合围
- 李某人闭眼“不忍”留先知未警之疑

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 恐惧的心理学拆解 | 用“愤怒掩盖恐惧、怕一切强者”逐层剥开角色内核 |
| A与B的寓言映射 | 以校园霸凌隐喻正邪权力结构，避免直白说教 |
| 长谈即掩护的诡计 | 把心理独白同时写成战术拖延，双层功能 |
| 魅影机制的硬设定 | 以“不受精神束缚+惯性两秒”解释为何能破麒麟 |
| 闭眼不警的反转钩子 | 用李某人“不忍”的细微表情埋下未解疑点 |

**逐章写法公式**
- 情绪流向：对峙的冷辩 → 寓言的沉痛 → 立誓的硬气 → 灯灭的骤变 → 合围的凌厉 → 疑云的悬停
- 节奏配比：对话博弈（35%）→ 寓言讲述（30%）→ 偷袭行动（20%）→ 合围收束（10%）→ 悬念钩子（5%）
- 结构公式：恐惧点破 → 人质自辩 → 咒渊之辩 → A与B寓言 → 立誓 → 闭眼伏笔 → 灯灭偷袭 → 拉闸合围 → 先知之疑
- 核心技巧：以“讲述即掩护”将文戏与武戏合一，用寓言完成主题升华，再以机制设定圆回偷袭合理性
- 卡点与伏笔：李某人为何不提醒麒麟；麒麟是否真被刺杀；钟赫能否全身而退
