## 第141章 初次行动

**概要**：灰雄一把抢走罐头手机让队员听命，高阳以"七影"之名正式认领第5行动组队长，宣布当晚有任务，众人反应各异。灰雄拿来资料袋——连环杀人案已是第六起，死者现场照片与个人资料铺满茶几，曼蛇对觉醒者世界之外的案子不以为然，罗尼开口讲话断句独特，西燃与灰雄因"迷雾世界"话题被喝止。高阳细看照片专盯眼睛和手指，问"受害者的共同点"时罐头答"都死得很惨"被拍脑袋，西燃罗尼也找不出门道。高阳故弄玄虚宣布"有共同点"、出发"抓凶手"，曼蛇不满质问觉醒者为何管兽的破事，被一句"你会感兴趣的"吊住。凌晨一点六人挤一辆车赶往白杏巷，车上高阳揭晓核心推理：凶手很可能不是以"人"的身份作案，而是以"兽"的身份作案；灰雄曼蛇先后两眼放光反应过来，罐头一头雾水直呼"职场霸凌"。

**关键事件**：1.高阳以七影之名当上第5行动组队长，宣布当晚出任务 2.灰雄调出六起连环杀人案资料，众人看不出共同点 3.前往白杏巷途中高阳揭晓凶手"以兽的身份作案"

**逐章写法公式**：

- **情绪流向**：起：热闹（组队搞笑） → 承：铺题（凶案资料） → 转：亮剑（出发抓凶手） → 合：顿悟（"兽"的身份）
- **节奏配比**：慢铺垫 55% / 快冲突 15% / 爽点爆发 15% / 悬念留白 15%
- **本章结构公式**：认领队长（确立领导地位） + 摊开凶案（抛出新案件） + 卖关子出发（立威信） + 揭晓推理（锁定方向）
- **本章核心技巧**：让新队长用"你找不到的共同点"作谜面层层收网吊胃口，再揭底，既立威又带出世界观设定
- **卡点与伏笔**：结尾卡点：悬念型——"凶手以兽的身份作案"结论刚揭晓，具体凶手是谁留待下章；埋设/回收伏笔：瞳孔与手指特征 → 兽类辨认法；罗尼西燃对迷雾世界的求知欲 → 后续世界观探讨；曼蛇对凶案的不满 → 队内磨合冲突
