# 第001章 钟表行的客人

芽一脚踢开钟表行的门，把早餐放到小桌上，又伸手按住镜辞刚夹起来的螺丝盒。

“先吃。”

“松手。”

“你再修十分钟，这颗螺丝也不会长大。”

镜辞抬头看她。

“会丢。”

芽立刻把手收了回去。

“那你当我没碰。”

门外有人拖着一筐青菜经过，塑料轮子压过碎砖，咯噔两声。隔壁五金摊刚升起卷帘门，老陈探头往里看了一眼。

“又吵？”

芽冲外面抬下巴：“他不吃饭。”

“饿死省粮。”

“听见没？”

镜辞没理他们，把米粒大小的螺丝放进零件盘，才起身洗手。

芽已经把木凳从墙边勾出来，又把早餐往工作台远处推了半米。

她知道规矩。

知道工具不能乱碰，知道右边第二个抽屉按尺寸分着发条和游丝，知道镜辞修表时最烦别人从背后拍他，也知道他一忙起来能坐到下午两点。

甚至镜辞刚把拆下来的零件往右边放，她就扫了一眼。

“那格0.8，你这个至少1.0。”

镜辞看了看。

“你什么时候会这个了？”

“听你念八百遍，死人都能学会。”

镜辞动作顿了一下。

芽也停了一瞬。

工作台最里面躺着一只旧怀表。

银灰色外壳磨得发暗，秒针停在十一和十二之间。

那是沈竹留下的东西。

沈竹失踪七年，镜辞就修了它七年。

能走。

会停。

最长一次撑过十一天。

“又停了？”

芽把小米汤往他这边推。

“昨晚。”

“还修？”

“修。”

“修不好？”

“继续修。”

芽笑了。

“你小时候就这样。一个东西坏了，别人扔了，你非要拆开。”

“十六岁那个闹钟，谁把齿轮踩弯的？”

“我。”

“谁死不承认？”

“我。”

“赔了什么？”

“一瓶汽水。”

“半瓶。”

“你喝了一半。”

一点没错。

镜辞坐下，掰开筷子。

芽已经开始吃了。

先咬油条。

镜辞看了她一眼。

芽没注意，继续低头回消息。

桌上那碗小米汤还冒着热气。

过去很多年，芽吃早餐一定先喝热的。

不是讲究。

她小时候胃不好，被早点铺老板娘骂出来的习惯。两个人有次赶公交，她非站在路边先灌两口豆浆，结果一起错过车，镜辞骂了她一路。

这么小的事，换了也正常。

镜辞没问。

他伸手去夹第二根油条，手腕蹭到旁边白瓷碗。

碗沿缺了一小块。

他把手缩回来。

芽看见了。

没动碗。

镜辞的筷子停了半秒。

“怎么？”

“碗有缺口。”

“我看见了。”

芽顺手把碗往自己面前拉了一点。

缺口还是朝着镜辞。

这次镜辞没再低头。

以前旧市场早餐铺全是这种破碗。

芽每次拿到缺口的，都会随手转开。

不是朝自己。

是朝墙。

有一次镜辞问她有病吗。

她只回了一句：“你手比我值钱。”

太小了。

小到谁都不会拿它当秘密。

芽终于端起汤喝了一口。

“凉得这么快。”

“你最近胃好了？”

“还行。”

“现在先吃油的？”

芽抬眼。

只有一下。

“吃个油条你也管？”

“随口问。”

“少学沈姨。”

叫法没错。

语气也没错。

镜辞把这个问题压了回去。

人会变。

一个早餐顺序，一只破碗，什么也证明不了。

九点多，芽准备走。

她把木凳推回墙边，又替镜辞把半开的卷帘门往上顶了一截。

门口卖菜的赵奶奶叫住她。

“芽，晚上来不来？那袋土豆你帮我提一下。”

“不一定。您别自己搬，腰又不想要了？”

“知道知道。”

芽摆摆手，挤进市场人群。

卖鱼的在剁冰，电动车喇叭响个不停，老陈正跟客户争一把钳子到底值不值十八块。

她认识这里的人。

这里的人也认识她。

一切正常。

镜辞回到工作台，把那只送修的机械表装好。

五分钟后，他又停下。

维修单背面是空的。

他拿笔写了两行。

**先喝汤。**

**缺口朝外。**

写完，他自己都觉得荒唐。

镜辞把笔扔下，继续修表。

十分钟。

二十分钟。

那两行字一直压在手边。

最后他骂了一句，拉开最下面的抽屉。

里面塞着几部旧手机和两块移动硬盘。

沈竹失踪以后，他把过去的照片、视频、维修记录全整理过一遍。

如果是自己记错了，旧东西总该留下一点痕迹。

镜辞拿出那部七年前的手机，插上充电线。

屏幕亮起。

开机密码还是以前那个。

他点进视频文件夹。

没有给芽发消息。

先找证据。
