## 1. 三条转向

| # | 旧 | 新 |
|---|---|---|
| 1 | 负面清单命中数 → 定档 → 决定改写力度 | **反向 Gate（Gate H/I）先判**；不过关直接 CONCERNS，即使 0 blocking |

| 3 | 规则自证（拿本书自己的文本验证规则） | **正样本校准前置**：新增／升级任何规则，先拿外部人写正文试；正样本被判不合格 → 先怀疑规则，不怀疑文本 |

> 与 `pattern-governance.md` 一致：命中只说明需要看语境，不等于用了 AI。v2 是把这条从"参考"提为**执行顺序**。

## 2. 新增两个反向 Gate（查少了什么）

| Gate | 查什么 | 怎么判 | 否决线（不是配额） | 依据 |
|---|---|---|---|---|
| **H 声线差异** | 同场不同人的句长、落地方式、口癖、词汇质地是否互相冲突 | 五问：遮名字能否认人／有没有一句没落地／路人是否替作者抖机灵／有没有人连赢三回合／语气词是否按人分配 | 答不上 2 项以上 → 声线回炉；全章对白 100% 完整收尾 → 不合格 | `他们不是人/设定/角色声线节奏卡.md` §1、§5.2 |
| **I 叙述者在场** | 有没有人讲这件事、主角是不是哑巴观察者、有没有体感与长短落差 | 数插话／内心声音／生活化比喻／≥40 字长句与 ≤6 字重拍 | 通篇只有动作和物件 → 不合格；主角全程无内心声音 → 不合格 | `他们不是人/设定/都市异能正文风格卡.md` v2 §2.2-§2.5、§九 11-15 |

**两条都是否决线，不是打卡表**：连续三章都"刚好达标"同样判不合格；允许某章反常，但要有情境理由（风格卡 §2.2、节奏卡 §4）。

## 3. 判定优先级（重写）

| 层 | 内容 | 处置 |
|---|---|---|
| 反向 Gate H/I | 声线差异、叙述者在场 | **主判**；不过关 → CONCERNS / 声线回炉 |

| 结构假设 | 人物声线趋同、章尾／缓冲装置同构、复验链重复 | semantic review；先给证据，不自动重排 |

## 4. 正样本校准 protocol（审查前必跑）

| 用途 | 样本 | 性质 |
|---|---|---|
| **外部尺子**：规则自检 | 对标作品真实正文（彭湃前 3 章 8.0 千字，逐字摘录见 `拆文库/异兽迷城/文风.md` §8） | 只读，**不得混入本书声音画像** |
| **内部画像**：是否偏离自己的声音 | 本书已接纳正文（`追踪/章节提交/` committed 回执 ≥5 章） | 按 `accepted-voice-profile.md` 生成，advisory |

**步骤**：
1. 把外部尺子跑一遍当前规则集；若它拿到 blocking／大量 advisory，**先记录并复核规则**，不得直接把该结果当"对标作品有问题"。
2. 再跑待审正文；两个结果并列写进报告（§5）。
3. 新增或升级任何自动修复规则前，按 `pattern-governance.md`「模式晋级门」准备 25 hot + 25 human control 样本；未达精确率 0.80 保持 candidate/advisory。
4. `accepted-voice-profile.md` 明确禁止对标作品／外部语料混入本书画像——**外部尺子与内部画像是两个用途，不得合并成一个"质量分"**。

## 5. 报告模板必填字段（改造）

在 `SKILL.md` Phase 1「AI 味检测报告」的「整体评估」中，除原有四行外**必须补齐**：

```
- 正样本校准：{外部尺子结果} / {本书画像结果，未配置写 not_configured}
- 反向 Gate H 声线差异：{通过/不通过，五问逐项}
- 反向 Gate I 叙述者在场：{通过/不通过，插话/内心/比喻/长短落差}
- 0 命中说明：{仅表示未踩负面清单，不等于像人写的}
- 人味判断：{一句话，必须落到"有没有人在讲"或"谁的嗓子不像谁"}
```

**结论约束**：
- 反向 Gate 任一不通过 → 不得输出「轻度」「不建议改写」「PASS 类」结论。
- 0 blocking / 0 advisory 只能写成事实，**不能当评价**。
- 「只检测 / 仅标注」模式同样必须输出反向 Gate 结果，只是不改文。
- `/story-review` 的 Findings 需新增两条检查：文字自然度看 Gate I、对话质量看 Gate H；不得只按禁用词表打分。

### 5.1 复核口径补记（2026-11-11 12:07，回炉 001-003 时发现）

「对白段 = 以 `“` 开头的行」有两类盲区：

1. **漏**：嵌在叙述行里的台词（如 `老人的视线…：“这雨，还等啊？”`）不进统计，003 这类独角戏章会被误判成「100% 完整收尾」。
2. **误**：`“东桥巷12号”`、`“备注”`、`“伤口”` 这类字段／引用引号被当成台词。

Gate H 复核须改用**全部引号对**（`re.findall(r'“([^”]*)”')`），人工排除字段／引用引号，再按 `。？！` 结尾判完整落地。同一份文本两种口径可差 5-10 个百分点，**报告必须写明用了哪种**。本章回炉实测：行首口径 100%→94.9%；全部引号对口径 97.4%→90.4%。
