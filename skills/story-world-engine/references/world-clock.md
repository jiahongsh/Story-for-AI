# 世界时间、离场行动与独立议程

## 推进依据

世界按故事时间、事件触发、资源及人的选择推进，不按“每章所有人行动一次”的机械tick。不要求每章新增幕后大事或新配角。值班、等待、失败、改期、停止、没发生变化都是真实状态。

每个重要独立议程记录：行动者、本人目标、已知信息、开始/截止、地点、资源渠道、触发条件、依赖者、愿付代价、中止条件、当前状态、可能影响对象。未来动作标计划，不能被检索当作已发生。

场景进入前问：

- 主角没来时，店主、窗口人员、组织和对手本来在做什么？
- 本次经过的时间是否足以执行；是否被旧事件触发、阻止或改期？
- 哪些变化与当前叙事有接点，哪些暂不展示？
- 不同人的目标是否冲突，谁有权拒绝或协商？

## 幕后与正史

1. 规划阶段推演多种可能，各自在工作区；未选未来不能改变记忆。
2. 本章候选可以包含读者未见的离场行动，但同样过七关，有时间、资源和来源；未接受前不进正史。
3. 接纳时仅将作者确实锁定已发生的幕后事件提交作者时间线，`reveal_status`按原协议未揭示；读者所知不得泄露。
4. 人物只有亲历或通过真实路径获知，才更新自己的知识。读者看过反派镜头不等于主角知道。
5. 后续通过现场残迹、消息延迟、资源耗尽、拒绝、误会或生活变化展示回声，不强迫每个幕后事件即时上镜。

隐藏事件并不等于毫无证据。作者卡需给真实锁定依据；若当前只是一项猜测或未来计划，不得当过去解释反派准确反制。

## 势力不是一个脑袋

每个动作落实到有权限的执行者。高层目标不直接授予所有成员完整信息、权限和无穷资源。允许成员争预算、抢功、保饭碗、误解指令、拒绝承担，机构也会按程序在主角不知道时运转。

“同公司”“同时间”“同脸”可以是线索，不能自动证明同一制造方；普通系统错误、个人利益与超自然动作分别考虑。

## 世界响应矩阵

对有长期后果的行动至少检查相关几类，不必全部写正文：

| 接触对象 | 可能自主响应 |
|---|---|
| 当事人/家属 | 拒绝、另求帮助、保留关系、改接触安排 |
| 工作/生意 | 替班、索赔、断合作、加价、继续常规任务 |
| 组织 | 换执行者、延期、失败复盘、掩盖、公开修正 |
| 对手 | 从取得的信息推理，不凭作者全知；改方案或停手 |
| 普通关系 | 人情债、怨恨、亲近、信任受损、之后不同的生活决定 |

没有回应也可能成立：没获知、没有能力、损失不值得、已经退出。写明原因，避免把缺回应当自然永久免账。

## 展示预算

核心事件呈现主要代价与关系变化。其余保持紧凑索引，待复现/决策需要时召回。不是每项后果都变成新支线；世界独立运转可以让主角来晚、无功而返或撞见一件早已完成的事，但不能永远只让他旁观。

世界不会自动奖善罚恶。独立人物可以合作、嫉妒、占便宜或善意失败；结果来自条件与选择。
