# 角色卡、个人认知与声线

## 角色身份与层级

所有有决定、有效台词、连续性或复现价值的角色登记稳定身份。具名长期角色完整卡；临时人物最小卡也必须记录动机、恐惧/依恋、条件、声线和时间线引用。纯布景不建立虚假人生。

显示名与身份分开；同名人/冒名者/前后载体分开ID，别名可以指同一人，但需来源。ID只供辅助卡，不改变既有追踪人物名称键或K/R/E/F规则。身份未决不自动合并。

模板见 `assets/character-card.md`。既有长角色卡无需整份重写，补“世界运行”小节并引用旧章节。不能为了填卡编造旧经历。

## 哪些是静态设定，哪些是动态事实

- 人格倾向、长期愿望、声线、背景已批准设定：保存在 `设定/角色/`，注明证据/作者设定状态。
- 当前伤病、位置、资源、关系、知道/误信的信息、做过的事：以原追踪权威和事件为准。
- 本章对动机/认知的解释：工作包中的来源绑定分析；与事实冲突时必须改分析，不反向改正史。
- 候选新角色、新人格、新关系：先放候选/规划；接受前不能当全书既成事实。

用户已授权生成候选正文时，当前授权范围内的新人物设计可以支撑该候选，不要求逐项向用户再请示。保留“候选新设计”标签，并随原接纳流程确认；不能借此篡改老角色的锁定人格、补造过去或突破本次只规划的任务范围。

不得把卡里的“计划成为盟友”“第3卷背叛”写入当前关系或知识。计划属于作者未来方案。

## 欲望不是功能位

按个人优先序列出：生活愿望、当前任务、依恋、不愿失去、底线、可谈条件。合作也要回答“对他有什么意义”，意义可为钱、友情、名誉、责任、好奇或自我证明。

不要求全部目标与主角无关。长期关系本来会塑造人；但“主角需要信息所以他提供”不合格。

缺陷用“诱因→偏向→眼前收益→可能代价→原文锚点”写，别只贴“贪婪/嫉妒”标签。允许人格矛盾：想亲近又怕欠债，讲公正又对亲人双标。重大改变要有事件依据，不随剧情随时刷新性格。

## 个人信息取得卡

用于决定的信息列：

| 字段 | 内容 |
|---|---|
| 信息对象 | 引用E/K/R/F或既有正文锚点；不另造第二事实库 |
| 信念状态 | 亲见、转述、推断、误信、未知；不把推断写成确定 |
| 取得事件/动作 | 谁告诉、本人见到什么、查了哪个可用窗口 |
| 取得时间与顺序 | 不能晚于被它驱动的行动；同章引用先前行动 |
| 权限与可靠性 | 能否接触、是否完整、是否被污染或欺骗 |
| 允许披露对象 | 职业/关系限制；知道不等于有权转述 |
| 改信或遗忘来源 | 何事件推翻了旧信念，不用新版本悄悄盖掉旧错 |

正式变化写入既有 `knowledge`快照和信息取得E事件；上表是辅助阅读索引。作者/读者双时间线不能代替每个人的认知层。

## 声线卡

记录两三项稳定差异即可，详细角色可多些。包括表达需求的策略、称呼与礼貌、句子节奏、职业用词、回避/撒谎方式、压力下变化、对不同关系的差异、不会说的句子和已接纳正文锚点。

例如一位摊主可能先报价再解释；对熟人骂得直，对负责人绕着说；急时句短而不是突然讲哲学。他可以说简单“我不去”“你先付钱”，无需每句独有口头禅。

对白写后做交换测试：去掉姓名，看双方在争什么、隐什么，策略是否不同。辨认不出来时改语言策略与利益，不靠增加夸张标签、动作或方言来掩盖。

临时人物无法提供历史台词时，可用当前有授权的新设计示例，明确不是曾经说过。机器不能把示例当接纳证据。

## 卡的维护与容量

只在目标、资源、信念、关系、缺陷表现或声线证据真正改变时增量更新。正文不为提醒读者“卡还在”硬塞人名。

久别角色回场先查最后事件、未结承诺和经过时间，再定点读旧正文。当前上下文最多六人不表示全书只能记六人；不在上下文的人仍可按角色/事件索引恢复。

可重建时间线卡带来源修订号、哈希与范围。生成卡坏了重建，静态卡与正史相冲突走修订治理，不能手改派生追踪卡。
