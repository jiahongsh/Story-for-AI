## 第901章 正反推

**概要**
秦右辩称高阳必攻己、自己是为胜利，了了怒骂其贪生怕死背约，秦右反呛了了"六天赋赖情报部"更怕死，二人内讧。贾博士趁回合踹姜爷胸口、幸灾乐祸。高阳冷眼判定秦右极度自私（曾算计青梅歌姬），故意攻心赌其自保，果然再中；更以"歌姬为何选鬼马而非你"戳其自尊，秦右放话下回合反杀。第四回合结束进入决策，高阳单膝跪地，借领域法则维持血槽不持续流失，但知脱离领域便可能同归于尽。贾博士提议下回合高阳转为防御，点出姜爷赛博臂藏致命后招、必殊死一搏。高阳权衡瞬移、能量铠甲、绝对结界三方案，贾博士力主绝对结界。二人"正反推"：姜爷既知情报泄露，反因快死急于完成遗愿、绝不敢拖延；贾博士亦排除姜爷先杀己的可能。临了，贾博士托高阳照顾可复活的鹦鹉英武，时间到，第五回合开启。

**关键事件**
- 了了秦右内讧互骂怕死
- 高阳攻心秦右得逞，以歌姬之选激怒
- 贾博士踹姜爷，提议高阳下回合防御
- 高阳权衡三防御方案，贾博士主绝对结界
- 正反推定姜爷必殊死搏，贾博士托孤鹦鹉

**关键信息与扩写技法**

| 领域血槽不衰减 | 规则补丁，埋"脱离即死"隐患 |
| 三防御方案权衡 | 列表式利弊，决策透明化 |

| 贾博士托孤鹦鹉 | 插科打诨软化生死沉重 |

**逐章写法公式**
- 情绪流向：内讧的火爆 → 高阳攻心的冷刺 → 决策的深算 → 正反推的笃定 → 托孤的轻诙
- 节奏配比：对峙对白约40%（内讧/攻心），智斗约45%（防御权衡/正反推），温情约15%
- 结构公式：同盟内爆（互骂） → 反派攻心再中 → 决策期信息整合（赛博臂/血槽规则） → 正反推定策 → 轻诙托孤转场
- 核心技巧：用"正反推"概念具象化博弈；以"列表权衡"让读者代入决策；用插科打诨调节节奏
- 卡点与伏笔：绝对结界能否扛赛博臂；姜爷遗愿内容；鹦鹉复活线
