## 第874章 按计划进行

**概要**
九寒从望远镜发现青灵正与妹妹对话，急令乌鸦扑飞其小腿符咒并啄肩，将她从人格杀陷阱拉回。青灵刚欲后撤，麒麟分神发动精神锁套使其身若坠黄油，挣脱后旋即被无色借曲幽微传送口的石化命中，六秒成石像坠落。天狗背红晓晓隐身接住青灵撤离，红晓晓以游戏玩家时光重置将其复活。九寒确认斗虎拖住青龙后号令按计划总攻、勿近麒麟。李某人预判危险，奈奈巨大化站江中将落水货车掷向桥心，海川团四散，货车冲散阵型；白兔藏身车内投雷，被安禾歌与flower拆弹。荆客以骨质增生替flower挡下狙击子弹。钟赫自桥底爬上，受九寒令以魅影死神之线刺穿flower心脏，念力随之中断，未及升空的手雷轰然爆炸。

**关键事件**
- 九寒乌鸦救回青灵，麒麟精神锁套+无色石化将其定身坠落，天狗红晓晓抢救复活
- 九寒号令按计划总攻，奈奈巨大化掷货车冲散海川团阵型
- 白兔车内投雷被拆，荆客骨甲为flower挡子弹
- 钟赫死神之线背刺flower，念力中断致手雷爆炸

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 乌鸦"啄肩"以痛解人格杀 | 用生理痛觉破精神控制，设定自洽 |
| 石化须借微传送口远程触发 | 天赋链：无色+曲幽组合技 |
| 复活前置"乌金发夹印记" | 规则化复活，避免无代价续命 |
| 货车被两次利用（落水→投掷） | 道具循环复用，省去新设定 |
| 钟赫"桥底爬上"的伏击动线 | 空间低位偷袭，制造背刺惊吓 |

**逐章写法公式**
- 情绪流向：救援脱困 → 定身坠落 → 抢救复活 → 总攻铺开 → 背刺骤变
- 节奏配比：脱困10%、控制击杀20%、抢救15%、总攻30%、暗杀收束25%
- 结构公式：识破陷阱 → 控制链击杀 → 抢救复活 → 总攻信号 → 载具冲击 → 潜伏暗杀
- 核心技巧：把"按计划进行"作为章节脊梁，多线在同一指令下汇流
- 卡点与伏笔：flower死亡触发海川团反扑；钟赫叛变彻底坐实
