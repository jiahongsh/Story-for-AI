## 第216章 日记

**概要**：高阳、罗尼、罐头在西燃家中书柜发现一本牛皮封面笔记本，起初以为是西燃的日记，罗尼辨认字迹后却发现是前任队长三空的私人物品，由此揭开三空死前曾秘密造访西燃家并留下日记的疑团。众人得知西燃一直在私下调查三空死因，气氛凝重。灰雄透露三空今年春天离奇失踪，一周后在离山山沟被发现烧焦的尸体，工会判定为暗杀。更令人心惊的是，与三空私交甚密的3组精英蓝豚同期离奇"心源性猝死"。高阳借由玄武透露的情报与蓝豚的【读心术】天赋，推理出三空察觉工会中层有内鬼，联合蓝豚暗中筛查时打草惊蛇，双双被苍母教灭口；而自己正是被"运气"推到台前的那枚棋子。高阳收起日记本，严令众人对今晚之事保密。

**关键事件**：1.罗尼辨认日记字迹，确认是前队长三空的日记而非西燃的 2.众人推断三空死前秘密拜访西燃并留下日记作为线索 3.灰雄揭露三空被暗杀，尸体烧焦于离山山沟 4.罐头点出蓝豚与三空同期死亡，疑为连环灭口 5.高阳推理内鬼筛查失败招致灭口，收起日记并严令保密

**逐章写法公式**：

- **情绪流向**：起：好奇（发现日记） → 承：悬疑（西燃私下调查） → 转：沉重（暗杀与连环死） → 合：紧张（推理出内奸灭口）
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：发现物件（误认归属） + 身份正名（导出疑团） + 案情回溯（暗杀惨案） + 推理收束（锁定灭口）
