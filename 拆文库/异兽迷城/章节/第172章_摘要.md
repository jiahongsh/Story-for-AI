## 第172章 小组作战

**概要**：兽群破窗涌入，两米高的蜥蜴人杀伐者直扑高阳，被灰雄【野兽】拦腰截下，经曼蛇钉掌后灰雄活生生捏爆其头颅。高阳左右喷火舌解围西燃罗尼，又抓住犬兽后腿放火焚烧；他扯下窗帘盖住废弃木椅点燃篝火，把昏暗礼堂照得亮如白昼，博得九寒赞赏。九寒遇黑影偷袭不慌不忙，三记快拳触发【弱点】，将兽脸砸成压瘪的皮球。高阳子弹打完与4组背靠背结成防御圈，四周仍有三十多只兽，曼蛇倒挂天花板待机。牛轩持话筒宣布"我让你们杀个痛快"，高阳意识到兽群竟听令于牛轩；九寒欲擒贼先擒王却被牛轩看破，牛轩笑着举右手宣布"毕业典礼，正式开始"，一个响指后兽群再度狂扑。

**关键事件**：1.兽群破窗涌入，灰雄【野兽】拦下杀伐者、曼蛇钉掌、灰雄捏爆头颅，完成首杀立威；高阳喷火舌解围西燃罗尼、擒拿犬兽放火 2.高阳扯窗帘点篝火把礼堂照得亮如白昼掌控视野，九寒三快拳触发【弱点】把偷袭之兽砸成皮球，展现双方战力 3.两组合流背靠背结防御圈对峙三十多只兽，牛轩持话筒宣布"我让你们杀个痛快"，响指下令兽群再度扑上

**逐章写法公式**：

- **情绪流向**：起：激烈（兽群破窗） → 承：从容（火舌篝火控场） → 转：震撼（九寒弱点爆发） → 合：危机（牛轩号令兽群）
- **节奏配比**：慢铺垫 15% / 快冲突 60% / 爽点爆发 15% / 悬念留白 10%
- **本章结构公式**：兽群突袭与首杀立威（冲突爆发） + 火舌与篝火控场（战术展开） + 九寒弱点机制展示（实力对撞） + 牛轩号令与毕业典礼（危机升级）
- **本章核心技巧**：全章以高速战斗切镜承载团队分工展示，穿插高阳的战术决策与心理计算维持"作战智慧"爽点，末段以"毕业典礼"响指再度引爆。
- **卡点与伏笔**：结尾卡点：冲突卡点——牛轩打响指宣布"毕业典礼正式开始"，兽群狂乱扑上，下章期待两组合力突围与牛轩的最终底牌；埋设/回收伏笔：罐头隐身、西燃罗尼辅助天赋 → 三人抱团隐身（回收）；【弱点】三快拳机制 → 高阳未来的威胁清单；牛轩控制兽群 → 号角者能力之谜；"毕业典礼" → 牛轩把围杀仪式化
