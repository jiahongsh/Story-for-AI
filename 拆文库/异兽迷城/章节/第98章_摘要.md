## 第98章 7号线

**概要**：陈萤坦白，前天百川团2组已派人进符洞探查，上车后迅速失联至今未出，她低声下气恳求务必救人，实在不行带回遗体甚至遗物。斗虎让陈萤回避、就地开短会，向四人交代符洞凶险未知、去留自愿：青灵为天赋升级当仁不让，高阳略一迟疑也跟上，黄警官本以"老婆怀孕要惜命"婉拒，被斗虎以"组织按职位等级倾斜资源、眼下正是升职机会"点醒，为换取组织帮查老婆怀孕之事咬牙入伙。五人随陈萤进入停运三年的地铁站，站内断水断电漆黑一片，高阳点燃【火焰】当火把。站台处十来个百川团成员等候，紫发男张伟是斗虎狂粉求签名，小男孩小天是发现符洞的【感知】天赋者。陈萤讲述诡异经过：小天感知到站内强生命体，前天正午12点已停运改线的7号线凭空出现，2组贸然上车后失联，昨天正午又准时出现、车上空无一人。斗虎总结众人须上车调查，正午12点整，7号线准时出现。

**关键事件**：1.陈萤交代2组失联经过并恳求救人，斗虎开短会征询去留 2.黄警官以妻孕为由拒去，被斗虎以升职机会与资源倾斜点醒后入伙 3.陈萤讲述已停运的7号线每日正午准时出现、上车者失联，正午12点列车如约而至

**逐章写法公式**：

- **情绪流向**：起：压力（2组失联的求救） → 承：抉择（三人去留、黄警官入伙） → 转：诡异（7号线重现的灵异真相） → 合：降临（列车准时出现）
- **节奏配比**：慢铺垫 40% / 快冲突 0% / 爽点爆发 15% / 悬念留白 45%
- **本章结构公式**：任务背景（2组失联与救人请求）+ 队伍集结（黄警官被说服入伙）+ 现场勘验（进站、张伟追星、小天讲述）+ 钩子降临（7号线出现）
- **本章核心技巧**：把恐怖副本的入场写成层层加码的"明知山有虎"，靠灵异时间线复述与正午出现的准时刻画，把恐惧压在最后一秒释放
- **卡点与伏笔**：结尾卡点：高潮前置——正午12点7号线准时出现，五人是否上车、车上有什么留待下章；埋设/回收伏笔：小天【感知】发现强生命体 → 为车厢内伏兽埋依据；2组上车即失联 → 印证陈萤"弱国无外交"的悲情；黄警官为妻孕入伙 → 与第96章怀孕线呼应，也埋下他惜命保命的性格线；地铁门只开末尾车厢 → 为莫比乌斯环诡计埋细节；张伟求签名"凡人皆有一死" → 伏笔氛围
