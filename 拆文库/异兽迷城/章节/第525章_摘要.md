## 第525章 父母爱情故事2

**概要**：第525章《父母爱情故事2》继续高守的回忆，雨夜牵线把暗恋推向现实。老婆婆拆穿后主动要替高守牵线，确认“雪人”正是常来买吃的林月，并骄傲称看了十几年店认得一半学生。雨大关店，高守殷勤送老婆婆回家，穿过农田来到山脚夯土房，推门却傻眼——伏案写作业的女孩正是暗恋一年的林月，而老婆婆竟是她外婆。林月防备地问“他是谁”。青翎听得幸灾乐祸。高守由此得知林月苦命身世：父母离异、赌棍父亲卷走家财、与外婆相依为命，外婆因怕同学嘲笑令她放学假装不识自己。外婆私下撮合二人交友，林月却摔碗抗拒，外婆安慰高守“要真心恒心”。高守决意追求，次日再访时却接到噩耗——外婆死于三轮车撞店车祸，林月冲入人群见外婆垂危。

**关键事件**：1.老婆婆认出林月并愿牵线，高守雨中送其回家 2.推门惊见林月即外婆家的女孩 3.揭林月苦命身世与外婆撮合心意 4.林月摔碗抗拒，外婆劝高守以真心恒心 5.高守再访前外婆车祸离世，林月见外婆垂危

**逐章写法公式**：

- **情绪流向**：起：好笑（送归揭身份） → 承：温馨（身世与撮合） → 转：紧张（林月抗拒） → 合：悲凉（外婆惨死）
- **节奏配比**：慢铺垫 50% / 快冲突 15% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：雨中牵线 + 身份揭晓 + 身世撮合 + 惨剧收束
- **本章核心技巧**：用“送老人回家”的巧合自然揭身份，再以突降悲剧切断温情
- **卡点与伏笔**：结尾卡点：悲剧钩子——外婆死于三轮车撞店、林月跪地泣求救外婆，情绪急转直下；埋设/回收伏笔：回收老婆婆“牵线”铺垫（第524章），埋设林月“每天看一眼外婆”的真相（实为看外婆非看高守）与后续高考毕表白伏笔
