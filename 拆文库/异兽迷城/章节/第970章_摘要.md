## 第970章 练习

**概要**
白露现身后再无多言，高阳形如失神石像，白露一路自语如对流石。她道出双胞胎心灵感应让她第一时间知晓初雪离开，并带高阳去见藏在“最难忘之地”的妹妹。途中她补全鬼族设定：诅咒源自咒渊，咒渊死则诅咒消，但鬼亦随之消亡，二者相生；春诅咒消散最快，选了风光大葬顺手帮赘婿，惊蛰于除夕离世由她料理后事。白露说初雪走得早自己还能送别，初雪曾言“有了爱的人便不怕”，又自嘲曾爱过人类却将其吃掉。抵达南冀区废弃游乐园，白雪覆压如纯白废墟，白露微笑吐出主题句：“离别这件事，我们每时每刻都在练习。”高阳登上最高处蓝白轿厢，见初雪白裙银发、红玛丽珍鞋倚窗而坐，平静带笑似睡。探鼻息、摸脉搏皆冷，幻想玩笑落空；初雪松手露出那颗薄荷糖——火锅后高阳所赠两颗中舍不得吃的那一颗。

**关键事件**
- 白露一路自语，交代双胞胎感应与初雪藏身“最难忘之地”
- 补全鬼族设定：诅咒与咒渊相生，鬼随咒渊死而亡
- 回顾春、惊蛰、初雪的结局与白露旧情
- 抵达废弃游乐园，白露点出“离别每时每刻都在练习”
- 高阳见初雪遗容，确认死亡，发现那颗舍不得吃的薄荷糖

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 失神同行 | 以“对流石”的静默反差，凸显高阳崩坏与白露冷静 |
| 鬼族设定 | 借人物独白自然补世界观，不另起说明段 |
| 故人回顾 | 用一串逝者往事铺陈悲凉底色 |
| 纯白废墟 | 雪覆游乐园的意象舞台，哀美而寂 |
| 主题句收口 | 把“练习离别”凝成金句，统领全章 |
| 薄荷糖信物 | 以小物收尾，余味悠长，胜于直抒胸臆 |

**逐章写法公式**
- 情绪流向：死寂失神→哀伤独白→宿命悲凉→怅惘回忆→温柔刺痛→哀美抵达→心碎确认→呜咽收束
- 节奏配比：途中独白设定约45%，游乐园场景与主题句约20%，轿厢遗容与信物约35%
- 结构公式：无声同行（状态铺陈）→感应与设定（信息补给）→故人回顾（情感叠层）→抵达舞台（场景定调）→主题句（点题）→遗容确认（悲伤高潮）→薄荷糖（细节余韵）
- 核心技巧：用旅途独白打包设定与回忆；以“最难忘之地”埋收尸地点；结尾用遗物替代痛哭
- 卡点与伏笔：初雪“最难忘之地”即摩天轮、鬼族相生诅咒的后续、薄荷糖与火锅回忆、高阳精神武装将失控
