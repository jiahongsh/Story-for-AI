## 第246章 援兵

**概要**：鬼马将被魅影绞杀之际，一声怪叫骤然解除全体尸体的压制——是罗尼的"混乱"。5组援兵借定位器悄然赶到：罐头现身为罗尼解隐身，曼蛇一刀斩落西燃被缝之头，灰雄熊化挡下修一箭矢。高阳得知手机壳藏定位器，众人迅速分派：九寒对修一、鬼马对4号、灰雄对7号、高阳对三空、曼蛇掩护、罐头罗尼策应。高阳焚鸦冲向三空，却被其风盾吹飞。

**关键事件**：1.罗尼混乱解围、5组援兵现身 2.曼蛇斩西燃头、灰雄熊化挡箭 3.高阳得知定位器、众人分派任务 4.灰雄对7号塌棚、九寒对修一 5.高阳对三空被风盾吹飞

- **情绪流向**：起：压抑 → 承：惊喜 → 转：燃 → 合：紧张
- **节奏配比**：慢铺垫 10% / 快冲突 55% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：绝境解围 + 援兵群像 + 战术分派 + 各自开战
- **本章核心技巧**：用"一声怪叫+团队逐一亮相"把上章窒息瞬间翻成燃向群像，再以分工展开多线战斗
- **卡点与伏笔**：结尾卡点：悬念留白+高阳被三空风盾吹飞；埋设/回收伏笔：回收"手机壳定位器"闲笔，回收网状烙印克制机制
