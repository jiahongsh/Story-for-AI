## 第785章 谜一样的废物

**概要**
高阳再次尝试复制张伟的【自信】依然失败，由此确认自己的6级【复制】只能覆盖序列11至189的天赋，前10位与后10位无法复制，印证了龙关于"天赋首尾相连"的推测。由于张伟从未对任何人使用过【自信】，高阳的系统也无从解析其机制，只能推测该天赋对毒素的抗性强于青龙——猩红潮汐那夜张伟最先苏醒。这个既无战力又无法被解读的张伟，成了"谜一样的废物"。定下复仇计划后众人散去，高阳洗澡归来，遇见在月光下等他的青灵；青灵执意要参战、要跟高阳同组，两度打断他的推辞并抓住他的手以天赋读取其真实顾虑，最终高阳同意调整分组。与此同时，凌晨一点的海川团会议室里，麒麟、李某人、炎凉在防窃听干扰球下密议。李某人判断地下基地难炸、且有秘密暗道可逃，曲幽天赋升4级更为其加了双保险；但当麒麟说"太放心了"、炎凉点出"一切太顺利"，三人顿悟高阳在明知难成仍坚持，必是声东击西，真正的阴谋尚在水面之下。

**关键事件**
- 高阳确认复制天赋边界，张伟【自信】成无法解析的谜
- 青灵执意与高阳同组参战，以天赋读取其顾虑后获准
- 海川团三方密议，李某人亮出暗道与曲幽4级双保险
- 麒麟、炎凉点破高阳"声东击西"，真正的阴谋在暗处

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 复制天赋边界 | 用"前10后10无法复制"的硬规则，把设定落定为可推理的谜面 |
| 张伟废物之谜 | 以"系统无从探索""从没对人用过"双重封锁，强化角色悬疑 |
| 青灵请战 | 用月光客厅的静谧反衬其执拗，把情感线揉进备战 |
| 抓手读取顾虑 | 以肢体接触触发天赋读取，把"说服"改成"看穿"，免去说教 |
| 海川团暗道 | 以"从没使用过只有我知道"的独白，给对手留后手、埋信息差 |
| 声东击西之悟 | 用麒麟一句"太放心了"作引信，三人接力推出反转 |

**逐章写法公式**
- 情绪流向：设定解惑 → 谜题铺陈 → 温情日常 → 密议从容 → 警觉反转
- 节奏配比：设定说明 25% / 青灵线 25% / 海川团密议 35% / 反转收束 15%
- 结构公式：天赋设定揭秘 + 九嗣内部温情 + 海川团密议亮底牌 + 三方推演声东击西
- 核心技巧：双场景对切——九嗣的"组队温情"与海川团的"密议警觉"同时推进，让读者比角色先看到双方底牌
- 卡点与伏笔：伏笔——【自信】无法复制指向后续张伟身世线；曲幽4级与暗道成海川团反杀资本；"声东击西"定调787-790轰炸实为佯攻；尼国地下遗址暗线在786展开
