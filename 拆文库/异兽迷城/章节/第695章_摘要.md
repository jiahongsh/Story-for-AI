## 第695章 计划复盘2

**概要**
本章续写计划复盘的下半段。高阳从陈萤处确认符文由无色、黄连、绿茶三人共同保管（绿茶已死排除），最大嫌疑缩至无色与黄连。但他未点破，而列四点理由决定亲自活捉尘埃以揪出苍之神母：不能百分百确定、元老动不得、诅咒恐拉垫背、私心要活捉而非交百川团。计划最关键人物是曾被忽视的"边缘人物"可又。高阳在【美梦】中以"埃蒙德约定""戒指信息差"两枚感情炸弹拉拢可又，借柳轻盈透露的梦内机制用【识谎者】验证其诚意，可又终选择加入九嗣。更狠的是"困难模式"——让可又假意出卖高阳递投名状给麒麟，借其尾队身份引内奸尘埃现身，完成反间布局。

**关键事件**
- 符文保管三人组，绿茶死排除，锁定无色/黄连
- 高阳列四理由不点破，决意亲自活捉尘埃
- 计划关键人物定为边缘的可又
- 美梦中以埃蒙德约定与戒指信息差拉拢可又
- 识谎者验证可又诚意，可又加入九嗣
- 困难模式：可又假卖高阳当碟中谍，借尾队身份揪尘埃

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 三方保管 | 以"权限事实"压缩嫌疑范围，显理性 |
| 四点理由 | 用并列条目式决策，写主角谋定后动 |
| 边缘棋子 | 以"几乎被忽视"反差突出布局巧思 |
| 感情炸弹 | 用"埃蒙德+戒指"双钩写信息操控 |
| 梦内识谎 | 借设定漏洞（梦中天赋可模拟）做实验证 |
| 困难模式 | 以"碟中谍"反间计收束，抬升格局 |

**逐章写法公式**
- 情绪流向：理性压缩 → 审慎决策 → 巧思定位 → 诚恳拉拢 → 缜密验证 → 大胆布局
- 节奏配比：决策推理（理性）约五成，美梦拉拢与反间（策略）约五成
- 结构公式：缩窄嫌疑 + 不点破的四理由 + 锁定关键人 + 美梦攻心 + 反间收网
- 核心技巧：用"信息差"与"梦境设定"把人物攻心写得可信
- 卡点与伏笔：可又双重身份、麒麟反应、尾队身份诱敌后续
