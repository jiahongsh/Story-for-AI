## 第876章 小溪流

**概要**
老7指力升阶发出金色空气弹撞向坠落的天狗与木子土，奈奈以疾风将二人吹开避过死神。奈奈缩小后乏力浮江呛水，险些溺水，天狗找回控制捞起她贴江飞离。与此同时海王召唤蓝色鲨鱼蹿江咬向海川团，死猪却以时空转换与鲨鱼体内的鸦鲨调换位置现身；铃姐就地取积水化冰刺扎穿鲨鱼，小青菜狮子吼将其崩解，露出其中的死猪。死猪跳桥发动7级野兽，化身高近五米的野猪精，猩红妖气逼人。铃姐三度驭冰能量枯竭，放弃抵抗，在忆及海川团由聚到散、自比幽谷小溪流的苍凉中，被死猪一掌打成脑浆迸裂坠江。柳丁悲愤开枪冲上，被冷静的雨溪拉回。

**关键事件**
- 奈奈疾风救下天狗木子土，自己却溺水被天狗捞走
- 死猪时空转换替换鸦鲨现身，铃姐冰刺+小青菜狮吼破鲨鱼
- 死猪野兽化野猪精，铃姐力竭待戮
- 铃姐忆往昔小溪流后被死猪一掌斩杀，柳丁欲报仇被雨溪拦

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 死猪"藏在鲨鱼里"的置换 | 替身欺诈，反转读者预期 |

| 野兽7级的量化跃升 | 用数字等级清晰标出威胁升级 |

**逐章写法公式**
- 情绪流向：暴烈截杀 → 惊险救援 → 凶猛兽袭 → 狂暴质变 → 苍凉斩杀
- 节奏配比：救援15%、兽袭20%、破防10%、兽化15%、独白斩杀40%
- 结构公式：怒火截杀 → 临门救援 → 海兽突袭 → 位置置换 → 破防露敌 → 兽化升级 → 力竭斩杀
- 核心技巧：以"小溪流"意象完成配角弧光，让碾压式死亡仍有余味
- 卡点与伏笔：死猪野兽化后的弱点待揭；野猪精如何被遏制
