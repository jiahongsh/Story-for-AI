## 第750章 认不认输

**概要**
本章以“认不认输”为题，收束6组切磋赛并引爆离散。赛场上安禾歌招招奔人体弱点，却因禁用暗器缩短距离，被黄芙蓉稳如泰山的肌肉天赋全面压制；夺命剪刀腿亦被对方以“石像”般体魄化解，最终被高举摔地，战败姿势屈辱。黄芙蓉两问“认不认输”，安禾歌倔强挣扎后仍不甘吐出认输二字。黄地厚赌赢、青天高爽快付钞，一句“高级放水无人察觉”勾起黄连组长的沉痛记忆，气氛转冷。钟赫趁机宣布：今日是最后一次训练，他已辞职做散人。静书不舍，木子土以歪诗叹“同林鸟各自飞”。黄芙蓉更在暗恋与决绝中当场宣布：那我也辞职。一隅小队的温情，在乱世合并的巨压下骤然碎裂。

**关键事件**
- 安禾歌招奔弱点，被黄芙蓉肌肉压制
- 夺命剪刀腿被破，安禾歌摔地战败
- 黄芙蓉两问认输，安禾歌不甘认输
- 黄地厚赌赢，青天高付钞，勾黄连放水
- 钟赫宣布辞职，最后一次训练
- 黄芙蓉随之辞职，小队离散

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 招奔弱点 | 以刺客思维写禁用武器下的战术受限 |
| 肌肉压制 | 用被动天赋反差制造以力破巧爽感 |
| 认输拷问 | 用反复逼问写倔强与屈辱的张力 |
| 黄连放水 | 以一句暗语勾连逝者，瞬间转冷 |
| 双辞离散 | 用接连辞职写乱世对小队的碾碎 |

**逐章写法公式**
- 情绪流向：缠斗的紧—压制的闷—落败的屈—逼问的涩—赌赢的乐—黄连的冷—离散的碎
- 节奏配比：格斗细节（45%）→ 认输拷问（20%） → 赌赢支线（10%）→ 黄连转冷（10%）→ 双辞离散（15%）
- 结构公式：武戏高潮（以弱搏强落败） → 认输张力 → 趣味支线转冷 → 辞职宣告 → 连锁离散
- 核心技巧：用“两问认输”的重复句式榨取情绪；以黄连暗语做情绪急转的支点
- 卡点与伏笔：黄芙蓉暗恋钟赫解释其随之辞职；6组崩解为后续合流九嗣或散人线埋伏；黄连躯壳被占留白
