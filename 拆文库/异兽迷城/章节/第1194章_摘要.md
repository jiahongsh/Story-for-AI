## 第1194章 小树林

**概要**
张伟在小树林扮鬼，借游戏“不可见”设定藏于香樟树后，选“扮鬼吓人”罩上白床单。一对情侣中，男性竟推开女方独自逃跑，被推倒的女方瞬间变回“真人”——正是失踪的周箐。张伟先追打上周揍过自己的男NPC报一箭之仇，再回到树下安抚受惊的周箐。周箐哭诉被前男友丢下，张伟编谎称是恶作剧赶跑鬼，顺势装糊涂引她坦白“另一面”。张伟违心说不介意，周箐转悲为喜；当他深情表白“你一点不渣”时，周箐却轻描淡写曝出同时交往七八个人。本章是攻略线的关键破冰，用喜剧反差撕开角色真相，基调俏皮、暧昧而暗藏荒诞。

**关键事件**
- 张伟小树林扮鬼，游戏设定让其不可见
- 情侣男推女自逃，女方变回周箐
- 张伟追打男NPC报一周之仇
- 周箐受惊啜泣，张伟靠近并编谎安抚
- 周箐坦白前男友抛弃与自己的“另一面”
- 张伟表白不介意，周箐曝出同时交往多人

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 游戏不可见设定 | 用“树干挡不住人却没人发现”的不讲理规则，制造荒诞喜感 |
| 选项驱动行为 | 把扮鬼写成弹出三选项，主角选一，保留系统感 |
| NPC变真人转折 | 让“被推开的女性”突然脱离影子态，瞬间锁定目标周箐 |
| 报仇支线调节奏 | 插入追打男NPC的爽段落，缓解攻略戏的黏稠 |
| 反差揭底 | 深情表白后一句“七八个人”当场破功，制造喜剧落差 |

**逐章写法公式**
- 情绪流向：扮鬼的滑稽 → 认出周箐的意外 → 报仇的爽利 → 安抚的暧昧 → 揭底的荒诞
- 节奏配比：喜剧开场 20% / 重逢推进 45% / 对话剖白 35%
- 结构公式：系统选项（扮鬼）→ 意外转折（周箐现身）→ 支线爽点（报仇）→ 双人对话破冰 → 反转收尾
- 核心技巧：用“主角以为在攻略，读者已知是死兽”的信息差制造黑色幽默
- 卡点与伏笔：周箐“另一面”初露；同时交往多人暗示色欲本质，为后续蛊惑埋线
