## 第190章 戴小军

**概要**：持枪男人是教导主任戴小军，手里是把仿真塑料假枪，被九寒一脚踢飞、高阳半空接住。戴小军吓得要钻桌底，九寒抓住他后领问要广播室钥匙，他给出两枚候选钥匙。上课铃前的等待中，戴小军认出九寒是"记者助理"，追问真相并坚持要同行，还翻出一套准备送给校长当生日礼物的高尔夫球杆给大家防身。上课铃响，四人冲出，廊道放倒三只符尸，楼梯间一只跌落，高阳踩背跳过，戴小军有样学样却摔倒被符尸抓住小腿，高阳一球棍救下。回到保健室，灰雄点数发现曼蛇没回来，高阳自责解释曼蛇引开符尸去了一楼，灰雄锤柜泄愤。戴小军与李华凤两同事劫后重逢，互诉伤亡。罐头忽然发现戴小军脱落的皮鞋下，那只穿灰色尼龙袜的脚上，有一道暗红色的血痕。

**关键事件**：1.戴小军假枪被识破，交出广播室钥匙候选，提供球杆防身，坚持同行 2.冲回保健室途中戴小军被符尸抓住小腿，高阳救下；灰雄发现曼蛇未归 3.罐头发现戴小军袜子上有暗红血痕，新一轮危机隐现

**逐章写法公式**：

- **情绪流向**：起：惊险（枪口对峙） → 承：松弛（假枪加钥匙） → 转：紧张（冲楼救援） → 合：惊悚（袜上血痕）
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：假枪闹剧（化开冲突） + 交钥同行（整合战力） + 冲楼救人（险中前行） + 血痕浮现（预埋危机）
- **本章核心技巧**：把一个恐慌的路人角色一步步绑进队伍，再用一处鞋袜细节把"安全"翻成"感染危机"
- **卡点与伏笔**：结尾卡点：惊悚卡点——戴小军袜子上出现暗红色血痕，说明他途中已被咬伤，下章期待感染发作的后果；埋设/回收伏笔：戴小军被符尸抓小腿 → 袜上血痕（本章实锤）；曼蛇引尸下楼 → 生死未卜的支线；戴小军认出九寒"记者助理" → 九寒的公开身份底细；教导主任办公室钥匙 → 广播室钥匙（本章到手）
