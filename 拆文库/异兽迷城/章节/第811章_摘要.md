## 第811章 一具尸体

**概要**
尼国三角塔景区一夜之间被苍道修复如常，居民只当是外星飞船或天罚的离奇传闻。凌晨，神庙遗址广场，麒麟携一石、了了、曲幽经传送门降临，以煤油打火机点燃沟渠火线，勾勒出生兽图腾。了了发动5级昆王遣虫群侦查，确认再无活人，却在四点钟方向发现一具尸体。众人寻去，认出那是无头、干瘪、遍体鳞伤的青龙——而他的头颅被苍道误砌进石柱，七窍流血空洞"望"着麒麟。麒麟背对火光，绿瞳如结冰湖面下燃异火，一石急令众人闭眼。

**关键事件**
- 三角塔被苍道修复，居民传闻离奇
- 麒麟四人传送至神庙遗址点燃生兽图腾火线
- 了了昆王侦查确认无活人，发现尸体
- 认出尸体是无头干瘪的青龙
- 青龙头颅被砌进石柱，空洞望麒麟
- 麒麟震怒前兆，一石令闭眼

**逐章写法公式**
- 情绪流向：平静 → 神秘 → 探查 → 惊愕 → 肃杀 → 山雨欲来
- 节奏配比：日常传闻约20%，遗址探查约80%
- 结构公式：灾后日常 → 小队降临 → 仪式点燃 → 虫群侦查 → 尸体揭示 → 震怒前兆
- 核心技巧：侧面传闻铺垫、能力驱动探查、反差特写
- 卡点与伏笔：青龙炎凉生死成谜；苍道力量衰退；麒麟将如何反应
