## 第192章 广播室

**概要**：灰雄一嗓子把众人从两只迷失者惨死的低落情绪中拽回现实——他们是泥菩萨过江自身难保。高阳分析第二节晚自习还有45到60分钟，大家趁机互相搜身确认无人被咬，九寒补充药品，有人闷头写遗言，高阳想进系统却发现天赋被封、系统失灵。西燃提议分兵去播音室被投票否决，多数人坚信恐怖片里"团队全灭始于分头行动"。9点下课铃响，符尸循声离门，11人队趁隙冲出，李暗与灰雄开道、高阳九寒垫后，刚爬五楼铃声停、符尸扑来。李暗在广播室门口插钥匙却左右都拧不开，耽搁十秒让垫后三人陷入地狱；灰雄夺过高阳的扳手塞进符尸嘴里、抱着符尸当防爆盾硬顶尸群，高阳喊三二一、全员叠罗汉爆发合力终于推倒尸群。11人冲进播音室关门，灰雄累瘫在地，湘蝶开灯，西燃老乔走向工作台——昏暗中一只人影突然冲出来。

**关键事件**：1.众人等下课铃期间互相检查咬伤、高阳发现系统失灵 2.李暗开广播室门钥匙失灵拖延十秒，灰雄抱符尸当盾硬顶尸群、全员合力推倒 3.逃入播音室刚松口气，角落里一只人影扑出

**逐章写法公式**：

- **情绪流向**：起：压抑（迷失者之死、写遗言） → 承：蓄势（互检、等铃、分合之争） → 转：爆发（钥匙失灵、走廊血战、合力推尸） → 合：喘息后惊悚（开灯，人影扑出）
- **节奏配比**：慢铺垫 40% / 快冲突 40% / 爽点爆发 10% / 悬念留白 10%
- **本章结构公式**：重整士气（灰雄吼声）+ 静默备战的倒计时（互检遗言+系统失灵）+ 下课铃突围（冲五楼遇阻）+ 钥匙卡点（李暗开门十秒）+ 走廊血战（符尸盾+三二一爆发）+ 喘息与惊悚钩子（逃进播音室+人影扑出）
- **本章核心技巧**：把"出门去隔壁房间"这种小事拆成秒级生死桥段，用静默倒计时铺垫加压、用钥匙失灵人为制造卡点，最后在喘息处砸出下一轮惊吓
- **卡点与伏笔**：结尾卡点：惊吓型——播音室灯光亮起后，昏暗角落中一只人影突然冲出，是活人、迷失者还是符尸待解，下章将正面对峙；埋设/回收伏笔：系统天赋被封 → 高阳只能倚仗直觉与同伴，后续逃杀中他多次凭此求生；互相检查咬伤 → 为罐头、西燃的伤口疑云埋下比对逻辑；集体行动的恐怖片共识 → 将反讽式回收于西燃"同伴不能放弃同伴"之死
