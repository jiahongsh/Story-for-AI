## 第852章 邪不压正

**概要**
海川团全员在基地、无人外出，电梯却自行下降，老7按下警报器拉响一级戒备，艾曼等人摆阵迎敌。电梯门开，站着黑风衣的高阳，脚边牛皮箱装满写满字的白纸——他并非来战，而以【隐身】【穿梭】的幻影潜入。攻击被淡金结界悉数挡下，高阳冷笑间"消失"，白纸如白鸽涌满大厅，众人捡起才知是一封战书。麒麟拄拐、李某人坐轮椅率众到来，麒麟以精神力确认战书无危险并当众宣读：历数麒麟勾结妄兽、灭口朱雀、撕毁公约偷袭十二生肖、李某人污蔑高阳为咒渊四大罪状，约战小年凌晨青扬大桥。李夫人迅速组织解释反击，麒麟推镜应战："邪不压正，光不惧影，我们跟咒渊是该做个了结了。"

**关键事件**
- 电梯自降触发一级戒备，老7按警报器
- 艾曼率众摆阵，准备迎击来犯之敌
- 电梯门开，高阳幻影携牛皮箱白纸现身
- 攻击被淡金绝对结界全数拦截
- 高阳借隐身穿梭制造幻影后消失，白纸飞散
- 众人发现白纸是战书，老7读其内容
- 麒麟李某人率高层到来，麒麟确认战书无危险
- 战书列四大罪状并约战青扬大桥，麒麟应战

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 电梯自降反常 | 先制造"无人入侵"的逻辑矛盾吊胃口 |
| 高阳幻影入场 | 用黑天使意象+白纸羽翼塑造压迫气场 |
| 绝对结界挡攻击 | 以"无痕拦截"瞬间抬高敌方实力差 |
| 战书全文呈现 | 大段引文作戏剧高潮，罪状逐条引爆 |
| 麒麟读后淡定 | 用面无表情反衬敌方舆论攻势的无力 |
| 邪不压正收题 | 以敌方口号回扣，定下决战基调 |

**逐章写法公式**
- 情绪流向：警报慌乱→对峙紧张→错愕（来者非战）→释然（战书）→舆论震撼→应战肃然
- 节奏配比：戒备三成，高阳亮相三成，战书揭示三成，应战一成
- 结构公式：危机假象→强敌入场→实力炫示→文书落定→敌方定调
- 核心技巧：把"战书"包装成视觉 spectacle（白纸羽翼），以静制动的压迫感
- 卡点与伏笔：高阳真身何在、四大罪状真假、青扬大桥决战走向
