## 第281章 真实而残忍

**概要**：楼下烤鱼时，高阳板脸拉初雪上楼锁门，以"好朋友不吵架、无秘密"温柔引导，逐步套出姐妹吵架的真相。初雪坦白姐姐逼她吃人续命，而自己唯一能下咽的食物竟是高阳，她坚决不肯，两姐妹因此不可调和地爆发争吵、赌气出走。更残酷的是，初雪不吃便无法变回人、不久将死，今日状态已比上次更虚弱。高阳提议自己定时供血供养，初雪激烈拒绝，解释自己并非挑食，而是客观上无法咽下不喜欢的食物，且鬼一旦吃人便失控至人死方休。高阳暗生"或许能中途停止"的念头却不敢冒险。末了初雪一句"好朋友不吃好朋友"令他涌起深重无力，引黄警官"爱真实"语录反转为"失去倍加残忍"。

**关键事件**：1.下楼烤鱼后高阳拉初雪上楼密谈 2.初雪坦白姐姐逼其吃人，自己不肯 3.揭示初雪虚弱加剧、不吃将死 4.高阳提议自己供血供养，初雪拒绝并解释"挑食"是客观无法进食 5.初雪说明鬼吃人不可控，高阳暗生"或许能中途停止"念头未说 6.高阳感悟爱的真实与失去的残忍，带初雪下楼打游戏

**逐章写法公式**：

- **情绪流向**：起：轻松 → 承：沉重 → 转：悲凉/矛盾 → 合：哀伤/温柔
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：温和引导 + 残酷真相 + 内心拉扯 + 金句收束
- **本章核心技巧**：用"温柔套话"节奏缓慢揭开残酷设定，再以台词点题收情绪
- **卡点与伏笔**：结尾卡点：信息揭示型——初雪不吃将死且唯一食物是高阳，两难延续；埋设/回收伏笔：埋设"高阳能否被中途停止进食"疑问，回收黄警官"爱真实"语录
