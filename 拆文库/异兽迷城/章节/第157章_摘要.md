## 第157章 11中

**概要**：深夜乌云遮月，四人翻过门卫室的破窗进入废弃的11中，在公告牌旁见到牛轩约来的三个大学女生：热辣学姐周箐、胆小的JK少女欢欢、坐在花坛边打手游的橙子。牛轩介绍众人时，橙子抬头迎上高阳的目光，惊得"我丢"一声蹿起差点喊出"队……"，被高阳咳嗽制止，谎称是"玩手游认识的"。两人故意走在最后，橙子压低声音叫他"七影队长"，自曝是罐头；高阳说自己是来调查符洞，橙子却老实交代是被室友拉来凑数的。一行七人摸黑进入教学楼，大厅值日栏上贴着褪色学生照，牛轩指着照片里一个女生说跟周箐一模一样，欢欢吓得尖叫，周箐反手打他胳膊说别吓唬人。众人爬上五楼，来到走廊尽头门楣贴着"三年二班"的教室，牛轩慢慢推开门，忽然大惊失色："里面有人！"

**关键事件**：1.四人翻窗进校，与周箐、欢欢、橙子三个大学学姐会合 2.橙子认出高阳是"七影队长"差点喊破，两人落单对质，高阳自称来查符洞，橙子说是被室友拉来凑数 3.七人进教学楼，牛轩拿褪色学生照吓人；爬上五楼三年二班，牛轩推门惊呼"里面有人"

**逐章写法公式**：

- **情绪流向**：起：寒（废校环境的阴森） → 承：巧（橙子差点喊破队长身份） → 转：闹（值日照、胆小鬼的插科打诨） → 合：惊（牛轩推门"里面有人"）
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：废校立境（破败校门+翻窗入园）+ 会合亮角（三个学姐登场、橙子认队长）+ 身份遮护（咳嗽打断+落单对质）+ 探楼小惊（值日照片吓人、胆小二人组）+ 推门惊雷（"三年二班"门后有人）
- **本章核心技巧**：在恐怖推进中埋"身份暴露"的次险，双线张力交替——明线是废校探险，暗线是七影队长马甲随时可能被揭穿
- **卡点与伏笔**：结尾卡点：事件钩子——牛轩慢慢推开"三年二班"的门，忽然大惊失色"里面有人！"；埋设/回收伏笔：橙子认出高阳"七影队长"、自称罐头 → 高阳的工会/队长身份第一次暴露给非核心圈子，社交线扩大；值日栏照片像周箐 → 暗示此地与眼前之人的隐秘联系（呼应11中鬼故事），为真相埋伏；高阳自曝"来查符洞" → 印证上章判断，本次夜探的真实目的浮出；欢欢胆小、周箐胆大、橙子摸鱼 → 三女性格标签，为下章"板仙"游戏的戏份分配埋伏笔
