## 第966章 跟我走

**概要**
合围之中，麒麟与李某人竟化半透明淡绿“幽灵态”——原来麒麟早将埃蒙德尸体制为傀儡、转化其“无敌”天赋。叙述补明傀儡大师“天赋论”名额逻辑：青龙、血珀占二，生兽兜底一，埃蒙德曾因性价比被空置；如今失青龙与生兽，反得空额复用埃蒙德。无敌状态下麒麟终止他技，飘离合围逼向钟赫；钟赫收力武装、以黑色煞气叫板“万象对魅影”，麒麟笑带怜悯。无敌消散、煞枪刺穿麒麟，钟赫自认得手，麒麟却七窍流血而言“你看到我时就已经输了”。真相揭晓：自初见起麒麟便在钟赫脑中植入微幻觉种子，拉闸时种子发芽，钟赫僵立收力、沉浸假性胜利。现实中麒麟当众以乌金拐杖刺穿钟赫心脏，两孩被“遗忘”放倒。挑出发夹排除干扰后，钟赫化为十五分钟完美傀儡，被打包带走，麒麟淡然“回家吧”。

**关键事件**
- 麒麟展“无敌”幽灵态，详解傀儡名额逻辑
- 钟赫以煞气叫板，假性“杀”死麒麟
- 真相：钟赫陷隐性幻觉，实已被拐杖穿心
- 两孩被“遗忘”放倒，钟赫发夹干扰被挑除
- 钟赫化为十五分钟傀儡，被麒麟带走

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 无敌的视觉化 | 以“半透明淡绿幽灵态”具象化不可伤状态 |
| 名额制的硬设定 | 用“天赋论+数字名额”解释战力调度逻辑 |
| 假杀局的镜像结构 | 先写钟赫视角的胜利，再翻 Reality 揭穿幻觉 |
| 微幻觉种子的伏笔 | 把“自初见植入”提前暗藏，回收于拉闸瞬间 |
| 发夹的干扰细节 | 用乌金发夹作契约绊脚石，增加仪式感 |

**逐章写法公式**
- 情绪流向：反转的错愕 → 设定的冷峻 → 叫板的凌厉 → 伪胜的痛快 → 真相的冰冷 → 收束的肃杀
- 节奏配比：反转（10%）→ 设定补明（25%）→ 伪局对峙（20%）→ 揭穿（20%）→ 真实结局（20%）→ 收束（5%）
- 结构公式：无敌显形 → 名额逻辑 → 脱围逼敌 → 煞气叫板 → 伪杀 → 真相翻盘 → 穿心收局 → 发夹除障 → 傀儡带走
- 核心技巧：用“视角欺诈”（先钟赫胜、后麒麟胜）制造双层反转，以硬设定支撑无敌合理性
- 卡点与伏笔：钟赫傀儡十五分钟后如何；发夹原主红晓晓将如何反应；麒麟“回家”后布局
