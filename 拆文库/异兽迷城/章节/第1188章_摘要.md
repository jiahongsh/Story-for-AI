## 第1188章 诈骗

**概要**
凌晨九寒、陈萤、骏马、安禾歌潜入苹果岛荒地，寻得贪婪王座——深处红椅悬浮转动的红色竖眼。骏马以风水察觉此地不聚气不积运，战斗或徒劳，但四人无退路。途中红色竖眼窥探隐秘，被骏马光脉冲爆成血雾。四人合体发动七级三头六臂化为八臂中性形态靠近王座，见被操控的李某人尸体，黑雾缠身、眼缝控其表情声带。骏马佯装被识破，以诈骗命中贪婪本体造成伤害。随后无人驾驶小货车（安禾歌附灵操控）载炸药冲向众人，安禾歌掷乌金暗器、陈萤按遥控发动天赋、九寒钻入暗器，骏马跃空避爆。贪婪惊觉皆为佯攻，真正的进攻将至。

**关键事件**
- 四人潜入苹果岛定位贪婪红椅王座
- 骏马风水预警战或徒劳，竖眼窥探被破
- 三头六臂合体靠近，见李某人傀儡
- 骏马诈骗命中贪婪本体
- 货车暗器多线佯攻，骏马升空避爆
- 九寒钻入暗器，真攻将启

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 红椅红眼王座 | 色彩+窥视意象营造诡秘敌巢 |
| 风水预警 | 以角色专长输出"凶兆"，提前下调胜率预期 |
| 竖眼窥探 | 将"被窥视"具象为脆弱红眼，可破降威 |
| 三头六臂合体 | 设定化团队增幅，视觉化战力整合 |
| 诈骗得手 | 用能力机制制造"假被识破真命中"的反转 |
| 多线佯攻 | 分镜式并行动作制造混乱与悬念 |

**逐章写法公式**
- 情绪流向：肃杀→凝重→阴森→机变→突兀→悬念
- 节奏配比：潜行研判四成、敌体登场两成、智计佯攻四成
- 结构公式：潜入定位→预警研判→合体靠近→傀儡现形→诈骗破绽→多线佯攻
- 核心技巧：以"诈骗"双关串联——既指能力，也指整体战术欺诈
- 卡点与伏笔：贪婪未死且多疑，A计划爆炸能否奏效留至下章
