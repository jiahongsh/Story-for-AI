## 第714章 失格

**概要**
会议转向是否接纳陈萤团队。王子凯冒出滑稽顾虑（怕陈萤瞧见他屁股烧洞的糗事），被高阳看穿。罐头以"队长当初也冒风险挖我们"力主接纳，灰雄细数3组人才——栗子的铁匠、江浩的赋能、浮生的神佑，可九寒泼冷水，并因排外旧习被灰雄提起11中旧事。高阳以投票定夺：五票赞成、一票反对、三票弃权，命九寒接洽。气氛将稳，曼蛇却反常地要求单独说话，骤然以匕首刺向高阳胸口。高阳险险避开，曼蛇冷言"可惜差一点"，抛出"领袖失格"四字，将章节推向悬崖。

**关键事件**
- 王子凯滑稽顾虑被高阳看穿
- 罐头与灰雄力主接纳并列举3组人才
- 九寒质疑神佑并引11中排外旧事
- 高阳投票：五赞成一反对三弃权，命九寒接洽
- 曼蛇反常要求单独谈话
- 曼蛇突袭刺杀高阳，指其领袖失格

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 王子凯糗事 | 用搞笑支线稀释会议严肃，制造人物反差萌 |
| 人才清单 | 罗列天赋做"战力盘点"，服务收编价值论证 |
| 九寒排外旧疾 | 以11中往事埋角色弧光暗线，丰富矛盾层次 |
| 投票决策 | 用民主程序外化分歧，凸显高阳犹豫的性格拐点 |
| 曼蛇反常铺垫 | 前文"毫不在乎"伏笔，使刺杀不突兀 |
| 失格一词双关 | 标题即炸弹，把内部信任危机推向高潮 |

**逐章写法公式**
- 情绪流向：轻松→激辩→民主定调→暗流→突袭爆裂
- 节奏配比：会议群戏占七成，刺杀仅占尾段但冲击极强
- 结构公式：滑稽缓冲→价值辩论→程序决策→反常伏笔→刺杀爆点
- 核心技巧：用喧嚣群像衬孤独反叛者，会议越稳刺杀越狠
- 卡点与伏笔：曼蛇为何反水；高阳"不敢决定"的心理病灶；11中旧事
