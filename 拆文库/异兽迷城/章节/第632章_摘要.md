## 第632章 青龙组

**概要**
青灵接替高阳与黄警官的指挥位置，在队友各有短板的情况下定下不撤退的奇袭决策，队伍由犹豫转为全员参与。镜头平行切至贾博士别墅，花龟与小青菜采购归来，青龙组核心战力悉数亮相：青龙、六霜、黑鱼、森鹤、古狮、核东及一头巨狮。作者借对话与回忆补出古狮的兽王天赋、核东的狮子吼与小青菜的结巴身世，软化反派并埋下人情伏笔。青龙组围绕是否强行带走贾博士产生分歧，青龙以重建实验室相诱。章节收束于六霜六感示警，九嗣小队正悄然逼近。

**关键事件**
- 青灵临危定计，下达十分钟后行动的奇袭命令，红晓晓从怯懦转为加入
- 镜头切至贾博士别墅，花龟与小青菜携物归来，青龙组全员就位
- 青龙组战力逐一亮相，古狮、核东天赋与序列号被明确标注
- 小青菜身世插叙，交代其结巴觉醒与被编入青龙组的由来
- 青龙组争论是否带走贾博士，青龙承诺在十龙寨重建其实验室
- 六霜突生感应，察觉有人靠近，章节以警戒收尾

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 队伍决策真空 | 用"以前靠高阳、黄警官"做对比，凸显新leader的成长压力 |
| 敌方群像铺陈 | 以"进门—环视—逐个特写"的镜头式描写排布阵营 |
| 小青菜身世 | 回忆插叙加结巴细节，软化反派、制造读者共情 |
| 战力坐标系 | 直接标注天赋名称、序列号与系别，建立数值化强度参照 |
| 六霜示警收尾 | 用"安静"二字打断闲谈，瞬间收紧节奏、抛出钩子 |

**逐章写法公式**
- 情绪流向：青灵的焦虑烦躁 → 队伍凝聚 → 敌方从容闲聊 → 突生警戒，张弛交替
- 节奏配比：前七成慢节奏群像与设定铺陈，末尾三成加速收束留白
- 结构公式：A线决策 + B线敌方亮相（平行蒙太奇） + 预警钩子收尾
- 核心技巧：镜头化群像、插叙补人物、以对话藏设定
- 卡点与伏笔：六霜"有人靠近"收尾；青龙"等七影"暗示双方都预期遭遇
