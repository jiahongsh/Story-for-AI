## 第756章 看人真准

**概要**
翌晚离城下水道密室,高阳把王蔚洇、朱雀、高欣欣三位九嗣相关女子托付给作家格里高同住。格里高得知王蔚洇父母双亡成孤儿、朱雀被麒麟“大脑格式化”成植物人、高欣欣半年内连失三位至亲,又惊闻曼蛇死于麒麟偷袭。高阳递上乌金镯,谎称注入诅咒约束格里高,实为【绝对防御】能量监控,并扬言密室除私密空间外皆装监控。格里高又好气又好笑地接受。高阳心中感慨“曼蛇看人真准”——曼蛇唯一看走眼的,恐怕是自己。镜头切到离城大学509室,林大健独玩恐怖游戏、分神想起空床室友,终学会抽烟排遣孤寂。

**关键事件**
- 高阳引见格里高与三女并托付
- 王蔚洇孤女、朱雀植物人、高欣欣丧亲身世揭晓
- 曼蛇死于麒麟偷袭被确认
- 乌金镯“诅咒”实为绝对防御监控
- 密室布控,格里高无奈接受
- 林大健独处寝室孤单抽烟

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 三女悲惨拼盘 | 用并列身世堆叠苦难,强化反派(麒麟)憎恶 |
| 曼蛇之死 | 借配角之口补前情,推进仇恨链条 |
| 镯子谎言 | 角色“撒谎不脸红”写高阳的谋略与冷面 |
| 监控威胁稿子 | 以作家最在意的“稿子”做软胁,幽默化控制 |
| 看人真准 | 章末主题句,回扣曼蛇识人,埋高阳伪装伏笔 |
| 林大健支线 | 孤独群像侧写,为后续交集埋线 |

**逐章写法公式**
- 情绪流向：安置的郑重 → 苦难的沉重 → 博弈的张力 → 幽默化解 → 主题回响 → 孤独尾声
- 节奏配比：前半信息密集、对话推进,中段控制博弈,末段切孤独慢镜
- 结构公式：托付安置 → 身世揭示 → 死亡确认 → 约束博弈 → 监控落定 → 支线收束
- 核心技巧：用“谎言即保护”写灰色主角,道德暧昧增强层次
- 卡点与伏笔：绝对防御是否会被识破；格里高会否越界；林大健何时与高阳交集
