## 第638章 只许成功

**概要**
六霜、花龟、森鹤、古狮回援，惊悉小青菜核东被杀但尸体完整——因白天两人服下贾博士的复活药。贾博士已被带走，古狮遣小白寻人未果，青龙自责失职。十分钟后喱河下游，灰雄被红晓晓"回档"复活，二人乘小船捞起贾博士浮尸。十五分钟前的天台闪回完整披露青灵战术：瓦斯逼敌、灰雄嘲讽诱敌、红晓晓存档、王子凯拖青龙、奈奈巨化抛贾博士入河，青灵御刀撤离。行动号下："只许成功，不许失败。"

**关键事件**
- 青龙组回援，确认双尸因复活药可救，贾博士已被夺
- 古狮遣小白群兽搜寻，青龙内心不抱希望并自责
- 喱河下游：灰雄被红晓晓回档复活，二人捞起贾博士浮尸
- 闪回揭红晓晓爬污水管、卡三十米极限复活灰雄的惨烈过程
- 天台总部署：青灵完整拆解诱敌、拖住、夺人、撤离四步
- 行动誓师"只许成功"，呼应收束全章

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 复活药回收 | 前文"白天逼吃"在此兑现，使双杀转为可逆 |
| 回档惨烈感 | 用爬污水管呕吐的细节，把天赋代价写得具身可感 |
| 天台沙盘 | 以地图加逐人指派，把复杂战术讲得清晰可信 |
| 浮尸收束 | 贾博士"死透"漂河，呼应前文抛河预案，闭环 |
| 只许成功 | 用青灵清冷决绝的口号点题并收束章节 |

**逐章写法公式**
- 情绪流向：回援的忧 → 下游的劫后轻松 → 闪回的惨与巧 → 誓师的燃
- 节奏配比：现线回援与下游四成，天台长闪回六成
- 结构公式：现线后果 + 下游团圆 + 天台闪回（因） + 口号收束
- 核心技巧：伏笔回收、具身写代价、沙盘化战术
- 卡点与伏笔：复活药双保险；红晓晓距离限制埋后续风险
