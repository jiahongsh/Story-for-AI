## 第706章 为生存而战

**概要**
本章聚焦白湖酒店内麒麟工会核心层的战略推演。青龙与朱雀围绕“两个寄宿者之王听命苍母教、急于刺杀神嗣”展开层层推理：青龙先质疑苍母教“船票”的真实性，继而以“七影同样求生”的逻辑反诘其杀神嗣的矛盾；朱雀借贾博士棋盘理论，提出苍母教或本就站在迷雾一方、假扮救世主以行毁灭阴谋，并推断神嗣正是船票或开门关键。路线之争中，炎凉抛出重磅信息——神迹符文与终焉之门由他发现，人类唯有“集齐符文开门”一条生路。他以麒麟昏迷为由下达去留通牒，朱雀经权衡留守，最终炎凉宣布麒麟工会全面开战，三人齐呼“为生存而战”，将全书矛盾推向阵营总决战。

**关键事件**
- 三方推演寄宿者之王与苍母教刺杀神嗣的动机
- 青龙以“生存矛盾”反诘苍母教逻辑
- 朱雀依棋盘理论疑苍母教属迷雾阵营
- 炎凉自曝为终焉之门发现者并定调两条路
- 炎凉以去留通牒试炼忠诚，朱雀留守
- 麒麟工会宣布全面开战，齐呼“为生存而战”

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 苍母教船票真伪 | 以角色推演替代说明，制造信息悬念 |
| 七影生存矛盾 | 用归谬反诘凸显逻辑张力 |
| 贾博士棋盘理论 | 借既有理论快速定位阵营归属 |
| 炎凉发现终焉之门 | 迟来爆点回收权威，颠覆认知 |
| 两路论断 | 二元抉择压缩叙事，逼出立场 |
| 为生存而战口号 | 章末口号收束，点燃情绪 |

**逐章写法公式**
- 情绪流向：思辨推演 → 逻辑反诘 → 权威宣示 → 昂扬宣战
- 节奏配比：约80%对话推演 + 20%表态收束，无动作戏
- 结构公式：问题(刺杀动机)→假设→反诘→定论→号令
- 核心技巧：以会议辩论承载世界观 exposition，信息经交锋浮出
- 卡点与伏笔：神嗣=船票、苍母教属迷雾、终焉之门发现者、全面开战
