## 第602章 大生意

**概要**
高阳借美梦软糖潜入与柳轻盈的梦境交易。梦境重构为古尼国地下神庙遗址，柳轻盈以艳后姿态端坐王座。她提出四项情报需求：终焉之门、死猪前妻之死、一周前青荷公园事件、以及高阳方今晚变故。高阳一反常态全盘托出，将所知几乎和盘告知，换取柳轻盈的等价情报。他先以“我们”虚张声势，逼柳轻盈保证自己不隶属三大组织，否则杀之——虽因美梦中无法发动识谎者而留白。柳轻盈痛快答应。高阳详述终焉之门、青荷公园与绿茶之死，柳轻盈据此确认除麒麟外无人见过终焉之门真容。高阳更在脑中具象终焉之门供其感知。柳轻盈点破高阳神嗣身份，高阳以混血自况，柳轻盈表示不计身份。双方结帐：终焉之门评S级、神嗣与内奸各S-。高阳转而委托打听刺杀自己的西装男，柳轻盈称恰知其人，为下章揭秘埋线。

**关键事件**
- 高阳入美梦，与柳轻盈在神庙梦境中会面
- 柳轻盈开列四项情报需求，高阳决定全盘交易
- 高阳逼柳轻盈保证非三大组织成员（虚张声势）
- 高阳共享终焉之门等情报，柳轻盈确认无人见过其真容
- 高阳神嗣身份被柳轻盈点破
- 高阳委托查西装男刺客，柳轻盈称知其人

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 神庙梦境场景 | 用异域王座意象包装情报场，区隔现实增强神秘 |
| 柳轻盈艳后造型 | 以服饰细节(黄金羽衣/蛇杖)塑造妖娆女王感 |
| 高阳反常大方 | 用“老客户回馈”反差凸显时间紧迫与角色成长 |
| 美梦无法识谎 | 以规则限制制造口头博弈的张力 |
| 神嗣身份曝光 | 借对手之口回收设定，抬升主角分量 |
| 账务评级 | 用S/S-等级量化情报价值，强化“生意”质感 |

**逐章写法公式**
- 情绪流向：入梦(绮丽)→开价(试探)→豪赌(紧张)→身份揭晓(震撼)→委托(钩子)
- 节奏配比：梦境铺陈约两成，情报交锋占主体五成，身份与账务两成，钩子一成
- 结构公式：梦境舞台搭建 + 双向开价 + 主角让利换信任 + 设定回收 + 新委托
- 核心技巧：以“情报即货币”的生意框架包装信息dump，避免平铺直叙
- 卡点与伏笔：西装男(律起)身份、终焉之门真容、柳轻盈背后势力、七预言
