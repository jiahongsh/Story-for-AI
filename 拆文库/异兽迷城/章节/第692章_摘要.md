## 第692章 罐头的大衣

**概要**
本章承接逆转之后，收束伪装线并展开追逃。被重置的三人苏醒，奈奈（伪装高阳）残留被焚惨死的痛苦记忆，小天起初推开陈萤、终在拥抱中释怀原谅。高阳（伪装罐头）完成时光重置后能量透支，罐头为其注入特殊肾上腺素。奈奈发动【千面人】还原真容并帮高阳恢复面容，却因身高差极限只到一米五七——高阳早有预案，用白天买的红色大衣与高跟鞋遮掩，立下大功。章节回溯完整伪装方案：高阳复制罐头【隐身】与红晓晓【游戏玩家】，奈奈复制高阳【幻影】。返程追车中，青灵在十字路口拦截，高阳瞬移车顶甩火球阻住赶来的尘埃与律起；尘埃与律起会合反扑失利，并惊觉被可又骗局坑害，刺杀任务彻底失败。

**关键事件**
- 三人苏醒，小天从恐惧到原谅陈萤
- 高阳透支完成重置，罐头注肾上腺素救回
- 奈奈还原真容，红大衣掩盖高阳身高差
- 完整揭秘雪夜之局的伪装方案
- 追车遇青灵路口拦截，高阳车顶火球断后
- 尘埃律起会合，识破可又假任务骗局

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 小天原谅 | 用"推开—拥抱—大哭"动作链写情感软化 |
| 身高差难题 | 以具体数字（1米79→1米57）制造喜剧反差 |
| 红大衣立功 | 回扣前文礼物，形成物件闭环 |
| 伪装方案回溯 | 用"复制天赋"清单式说明，清晰交代布局 |
| 追车断后 | 以"车顶火球+瞬移"动作戏保节奏 |
| 可又骗局揭露 | 借尘埃之口点出上层反间，抬升格局 |

**逐章写法公式**
- 情绪流向：庆幸苏醒 → 温情和解 → 虚弱救回 → 诙谐收尾 → 急迫追逃 → 不甘识破
- 节奏配比：苏醒与揭秘（中速）约五成，追车拦截（高速）约五成
- 结构公式：死里逃生 + 情感和解 + 伪装解密 + 返程追逃 + 反间揭晓
- 核心技巧：用"红大衣"回扣前文具象伏笔回收
- 卡点与伏笔：可又上层骗局、律起接应、尘埃身份暴露后果
