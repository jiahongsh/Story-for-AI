## 第697章 计划复盘4

**概要**
本章以事后视角倒推收网计划为何成功：麒麟与炎凉险些杀死高阳五人，反而坐实了可又"反水投敌"的真实性，使其被破格擢为玄武长老、获最大自由。可又借机按高阳之法确认黄连即尘埃，九寒再布一子——令陈萤以符文交易为幌骗出黄连与小天，并在汉堡店女厕留下带"游戏玩家"印记的乌金发夹。平安夜西郊公园收网：高阳易容为罐头、奈奈易容为高阳，黄连体内的尘埃将灵魂篝火诅咒注入符文。奈奈扮高阳被活活烧死，至死不显形；尘埃强行苏醒，黄连、小天接连殒命。高阳假死偷袭，配合游戏玩家回档三人与幻影缠斗，尘埃不敌逃走。

**关键事件**
- 倒推复盘：麒麟炎凉的"险些得手"反成可又演戏真实性的背书，可又被任玄武长老。
- 可又确认黄连即尘埃；九寒布子令陈萤带黄连小天以交易为幌出场。
- 高阳变罐头、奈奈变高阳双线易容，做实彼此身份。
- 奈奈被灵魂篝火烧死坚守不露形；尘埃苏醒连杀黄连小天，高阳偷袭击退尘埃。

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| "真实性来自差点害死自己" | 以反逻辑因果为阴谋正名，用对手的狠成全己方可信度 |
| 双魂吸虫设定 | 用"癌细胞扩散"隐喻解释多年潜伏与必死结局，补完世界观 |
| 奈奈焚魂不显形 | 以极致痛苦加信念写配角高光，7级千面人成逻辑支点 |
| 灵魂篝火机制 | 用"触碰一秒、对话十秒"量化诅咒条件，服务战术回档 |
| 游戏玩家回档 | 以系统天赋回收战局，制造"假死翻盘"爽点 |

**逐章写法公式**
- 情绪流向：复盘的自得 → 布置的缜密 → 收网的紧张 → 奈奈之死的悲壮 → 击退的释然
- 节奏配比：复盘铺垫（约40%）→ 易容做实（约20%）→ 生死交锋（约40%），战斗集中于后半
- 结构公式：结果倒推（为何成功）→ 布子（陈萤、发夹）→ 收网（易容、诅咒）→ 牺牲（奈奈死）→ 翻盘（高阳袭）
- 核心技巧：先交代"已经成功"再回放过程，用已知结局消解慌乱、聚焦战术细节
- 卡点与伏笔：尘埃逃脱留后续隐患；双魂吸虫设定埋黄连必死伏笔；游戏玩家回档暗示可复用
