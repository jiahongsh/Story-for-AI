## 第1014章 学弟晚安

**概要**
朱雀意识接入元网络，红蜈蚣闪红、义眼爬数据爬虫，罐头花痴向往却被西燃提醒承受不住副作用。五分钟后朱雀惊醒干呕，定下罐头假名"刘橙子"，令其下午陪刘离去终焉公司办深度合作手续。二人赴终焉产业园康复中心办妥回家，高阳以I芯片浏览"菩提"视角的梦境全息——因系统化身不足一年，可查记忆不超一年，且梦中与现实时间同步。全员连看高阳梦境开头（李薇薇、青灵等），深夜仅余高阳罐头看到古家村惊险段。此后一周同居规律看"剧"，当梦中灰雄等五人出场，罐头只觉"有些像"而非相同，高阳终于确认期待的"破绽"不会到来，黯然离场。

**关键事件**
- 朱雀入网苏醒，定罐头假名刘橙子并派任务
- 高阳二人办终焉手续，浏览梦境全息
- 梦境记忆不超一年且时间同步的设定
- 全员连看梦境，深夜高阳罐头看到古家村
- 一周同居看"剧"，罐头觉梦里人"只是像"
- 高阳确认破绽不会来，黯然离场

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 入网生理反应 | 用义眼爬虫/红蜈蚣闪红把抽象联网具象为身体异变 |
| 呕吐袋细节 | 以日常护理动作反衬联网的生理代价 |
| 菩提摄像机喻 | 把梦境记录比作客观摄像机，统一视角逻辑 |
| 时间不同步设定 | 用"梦中多年/现实一月"反差制造悬疑 |
| 看梦如追剧 | 把内部复盘包装成集体追剧，软化信息量 |
| 只是像非同 | 用罐头的"像"戳破高阳破绽期待，反转落空 |

**逐章写法公式**
- 情绪流向：入网惊险→任务落地→看梦好奇→古家村紧张→同居温馨→破绽落空
- 节奏配比：入网苏醒（快）15% + 办手续（中）15% + 梦境设定（慢）20% + 集体看梦（中）25% + 一周同居（慢）15% + 落空（慢）10%
- 结构公式：联网收尾→手续落地→设定交底→集体观影→日常同居→期待破灭
- 核心技巧：把"寻找破绽"的主线反转为"确认无破绽"，以日常温情衬失落
- 卡点与伏笔：梦里人为何"只是像"、破绽真相、麒麟工会线、刘橙子身份
