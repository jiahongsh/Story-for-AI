## 第757章 长老的召集

**概要**
离城大学509室,林大健边抽烟边看空床,想起弥施失踪、高阳退学、裘丘遇害,热闹寝室只剩自己。他刷朱雀(夏姐)社交动态自愈,却见动态停在几天前,自嘲“我一个人的好天气”。教学楼天台,被明镜寄宿的律起隔空监视林大健;被尘埃寄宿的黄连(戴白面具遮容)提议抓高阳大伯或潜入麒麟,均被明镜否决——明镜要等林大健与高阳产生交集再奇袭,并以裘丘教训警示。尘埃想潜入麒麟被拒。明镜臂上红花(托库斯的【植物】天赋)绽放,示“长老召集”,二人动身。镜头切雪国圣彼林大剧院,看门人尼古(苍母教长老、迷失者之王)于圆桌旁主持,蒂娅、托库斯已就座。

**关键事件**
- 林大健烟思空床,室友离散的孤独
- 明镜天台监视林大健,布局奇袭高阳
- 尘埃提议换目标/潜入麒麟被否
- 明镜臂上红花示长老召集
- 雪国剧院场景铺陈
- 尼古长老(迷失者之王)身份揭晓

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 室友离散拼盘 | 用空床与游戏习惯写孤独,群像侧写不直说 |
| 明镜的奇袭逻辑 | 以“等交集”写反派耐心,反衬高阳被针对 |
| 寄宿设定 | 借对话补明镜/尘埃双生王与失能代价 |
| 红花召集 | 以身体异象做传唤信号,诡艳又省墨 |
| 迷失者之王 | 末段揭身份,用“自欺为人”写角色分裂魅力 |
| 剧院穹顶 | 宗教式华美场景烘托反派阵营的“神圣”感 |

**逐章写法公式**
- 情绪流向：孤独怅惘 → 悬疑监视 → 谋略交锋 → 诡异召集 → 宏大场景铺陈 → 身份揭幕
- 节奏配比：前半抒情慢,中段对话博弈,末段场景转场升格
- 结构公式：孤独群像 → 反派布局 → 策略否决 → 召集信号 → 场景切换 → 阵营亮相
- 核心技巧：双线(主角落寞/反派集结)对切,营造山雨欲来
- 卡点与伏笔：林大健何时成交集支点；苍母教圆桌要议何事；尼古的“王”之悖论
