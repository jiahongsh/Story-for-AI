## 第889章 心眼如藕眼

**概要**
青扬大桥东岸沿江风光带，斗虎与缠满黑绷带的青龙傀儡高速缠斗两分多钟，双方都未使出全力。斗虎顾虑青龙傀儡可能发动“无限进化”被动，吸收其能量并免疫“杀人专家”，故只求缠住它，让麒麟分心、九寒好寻机用王子凯骨刺点穴。反常的是青龙傀儡也陪斗不全力，斗虎推测麒麟在提防死猪用“时空转换”把傀儡带离控制。缠斗中斗虎旁听九寒传音群聊，得知“他不是麒麟、任务失败撤退”，九寒凭望远镜已看穿。斗虎欲再拖延，却突吐黑血虚脱坠地——中毒了。一名穿蓝白病号服、针孔密布的瘦削女子走近，正是死在离山溶洞、尸身存于北归殡仪馆的血珀傀儡，天赋“病人”。斗虎恍悟：青龙傀儡是诱饵，麒麟暗中操控血珀傀儡对所有生命体“病毒感染”，尸体才不怕毒，中招的只有自己。青龙背负血珀扑来时，格里高的“瘟疫骑士”毒素之风横扫，众生平等地腐朽一切，青龙急退并一拳吹散毒风，能量波冲向斗虎原处——却只留下一道三米宽沟壑，人已不见。

**关键事件**
- 斗虎与青龙傀儡互相试探、皆留余力
- 斗虎忌惮“无限进化”被动，只求缠住牵制
- 斗虎监听传音得知替身真相与撤退令
- 斗虎突遭中毒吐血坠地
- 血珀傀儡现身，揭出麒麟双傀儡病毒阴谋
- 格里高毒素之风解围，青龙击散毒风
- 斗虎已被秘密转移，原处只剩沟壑

**关键信息与扩写技法**
| 信息点 | 扩写技法 |
| --- | --- |
| 双方的“留力”博弈 | 双重悬念：都不全力，互猜对方底牌 |
| 无限进化的威胁推演 | 用角色内心逻辑链解释战术克制关系 |
| 中毒的猝然反转 | 先写拖延决心，再瞬间破功，落差制造危机 |
| 血珀傀儡的身份揭晓 | 外貌特写（病号服/针孔/绿眸）暗示死体属性 |
| 毒素之风的“众生平等” | 用规则化设定破局，呼应前文伏笔 |

**逐章写法公式**
- 情绪流向：试探的胶着 → 战术推演的冷静 → 知情的紧绷 → 中毒的猝变 → 阴谋揭晓的寒意
- 节奏配比：缠斗段中速铺陈，传音段信息密集，中毒段急转，解围段快收
- 结构公式：单线战斗 + 旁听情报插叙 + 突袭中毒反转
- 核心技巧：用“双方都不全力”制造双向悬念；用设定（尸体不畏毒）收束逻辑
- 卡点与伏笔：血珀病毒范围与持续；斗虎是否真被转移；麒麟还有几手
