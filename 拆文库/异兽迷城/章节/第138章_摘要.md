## 第138章 案发现场

**概要**：高阳随灰雄、小刘进入白杏巷，来到巷尾"正宗泰式按摩"店，店内前厅坐着几个低头的女郎和情绪激动的老板娘罗姐。小刘介绍死者段更，43岁单身、开手机维修店、常逛风月场所但来这家是头一次，死因是胸口被钝器刺穿、心脏大出血。三楼按摩房内，死者只穿大裤衩四肢张开躺在按摩床上，嘴里全是黑血，胸口插着半米长黑色铁锥，现场有打斗痕迹；死者头顶的墙壁上，用血画着一个圆圈外围带光芒线条、中央竖立眼睛的邪恶图腾。高阳察觉死者指缝有墙灰、表情惊恐中带迷茫，但未表态。灰雄认定是那个每次作案都留图的变态杀人魔，专家猜测其是精神变态或新兴邪恶组织的狂热份子。现场指纹全是店内工作人员，监控只有一楼前厅有，二楼窗户没装防盗窗。下楼后灰雄要带店里人回局里做笔录，高阳叫住他，向老板娘询问生意并索要账本，特意翻看日期后若有所思，心里有了初步猜想，但嘴上说没问题。

**关键事件**：1.勘察连环杀人第六案现场，发现血画眼睛图腾与打斗痕迹 2.确认指纹监控均无有效线索，凶手作案路径成谜 3.高阳借问生意之名索要老板娘账本，从日期记录中看出端倪

**逐章写法公式**：

- **情绪流向**：起：下沉（环境铺陈） → 承：压抑（尸体现场） → 转：推演（线索排查） → 合：暗线（账本起疑）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：入巷探店（环境建压） + 尸体现场（恐怖锚点） + 证据排查（僵局渲染） + 账本取信（主角暗棋）
- **本章核心技巧**：用"主角看得懂、却不下结论"的信息差，把一次普通办案改写成悬案解谜的前置铺垫
- **卡点与伏笔**：结尾卡点：悬念型——高阳合上账本说"我没问题了"，心里却有初步猜想，凶手身份与账本关联待揭；埋设/回收伏笔：墙上眼睛图腾 → 连环案标志与凶手特征；死者指甲墙灰 → 死前挣扎线索；老板娘账本日期 → 左撇子笔画推断伏笔；二楼无防盗窗 → 翻窗作案可能
