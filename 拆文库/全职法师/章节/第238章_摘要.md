# 第238章 被围攻！

**概要**：幽狼兽倔强地独力解决十只黑畜妖，带着可见白骨的重伤一瘸一拐归来，莫凡将它收回并用召唤系星云的魔能喂养，盘算进阶之事，只是顾忌萧院长所赠战将兽魂的失败风险未敢使用。灰一被烧成黑色粉末后，莫凡继续追踪暗影妖兽，发现它竟自投罗网跑进了驯兽铁笼的建筑物。莫凡深知真正主使未现身，不肯结束狩猎，却在门前被沈明笑、罗宋五人堵住；傅天明又率队现身，提议联手除掉莫凡、只求取出妖兽腹中之物。罗宋虽觉对方古怪，但因旧仇未消并不把莫凡"黑教廷走狗"的警告当真。莫凡确认傅天明就是许昭霆生前跟踪的学员，研判司夜统治下敌我实力此消彼长，决定周旋作战。

**关键事件**：1.幽狼兽重伤胜出，莫凡喂能收兽 2.沈明笑罗宋与傅天明队联手围堵莫凡 3.莫凡点破黑教廷无人信，判定傅天明即许昭霆跟踪对象

**逐章写法公式**：

- **情绪流向**：起：温馨（收兽喂养、舔犊日常） → 承：紧张（门前被堵、仇家现身） → 转：压抑（警告无效、十人合围） → 合：热血（莫凡锁定傅天明、冷静布局）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：收兽养伤（战后休整） + 循兽入笼（猎物自投罗网） + 双队合围（仇家与暗敌合流） + 战前换算（定下周旋打法）
- **本章核心技巧**：让明线仇家与暗线黑教廷在同一个门口合流，借一笔荒唐交易完成敌暗我明的信息交接，主角反成全场唯一清醒者
- **卡点与伏笔**：结尾卡点：以一敌十卡点——莫凡被围却不乱，下章期待司夜统治下的周旋反杀；埋设/回收伏笔：战将兽魂未用 → 幽狼兽进阶伏笔；傅天明即许昭霆跟踪对象 → 前案线索回收；罗宋对"腹中之物"的嘀咕 → 他可能后知后觉的钩子
