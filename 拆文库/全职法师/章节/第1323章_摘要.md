# 第1323章 司夜黑魔谭

**概要**：卑匠在高空目睹救下小孩的空间系法师，正遗憾错过一幅"红色地毯"，一只只有他能看见的黑暗之蝇却飞来报信，他目光直射地面，笑着道踏破铁鞋无觅处，从摩天轮顶纵身俯冲而下，黑色利刃直扎刚救下小胖孩的莫凡。莫凡以瞬息移动躲过流星之匕，卑匠现身要求带路去见冷青、否则饶不了他，莫凡放出"想动她先过我这关"。卑匠化入夜色无迹可寻，以毒蛇三角眼的锁身瞳光制住莫凡，莫凡以十二倍暴君荒雷破局，却又落入第二级司夜统治黑魔潭，被黑魔之手拖拽。卑匠使出叛影封喉——莫凡自己的影子爬起持刃抹过他的脖子，小男孩再次吓晕。然而被抹喉的只是暗影傀儡，真莫凡出现在另一方向，雷电疯狂涌起，卑匠认出暗影傀儡后反而燃起杀戮欲。莫凡以雷策电鞭对攻，顾忌广场平民不敢用大威力雷法，卑匠身化虚空残影难以捕捉。魔法协会的人终于赶到，疏散人群、拉起结界救人，但来者最强不过高阶，在黑魔潭前形同摆设，卑匠再次沉入潭中、从莫凡十米外浮现。

**关键事件**：1.黑暗之蝇暴露莫凡位置，卑匠俯冲而下与其交战 2.卑匠叛影封喉抹杀暗影傀儡，莫凡以傀儡骗过对方 3.黑魔潭困住民众，魔法协会援手修为不足形同摆设

**逐章写法公式**：

- **情绪流向**：起：救孩暴露的意外 → 承：卑匠逼路、瞳光锁身的压制 → 转：暗影傀儡反转、雷策对攻 → 合：黑魔潭变幻莫测的悬峙
- **节奏配比**：慢铺垫 10% / 快冲突 55% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：救孩暴露引来卑匠（危机开启） + 锁身与黑魔潭压制（受困） + 暗影傀儡反转与雷策对攻（反击） + 黑魔潭假影莫测（对峙留白）
- **本章核心技巧**：同一回合内安排"被杀—假死反转"，用反派从得意到愕然的表情变化完成一次漂亮的心理落差
- **卡点与伏笔**：结尾卡点：悬念型——卑匠在黑魔潭中真假难辨、随时致命一击，莫凡与被困民众的下一回合生死未卜；埋设/回收伏笔：黑暗之蝇 → 追踪机制的实体化；暗影傀儡 → 莫凡暗影系能力的隐藏底牌；黑魔潭困住普通人 → 战场平民危机的持续变量
