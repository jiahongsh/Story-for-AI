# 第166章 雷霆反击！

**概要**：施法速度不及对手，莫凡果断放弃星图衔接，吹哨唤幽狼兽奔过，抓住长毛跳上狼背，朝远离龙卷中心的方向狂奔，险些被卷入十米吸扯地带；退到铁笼尽头已无路可跑，莫凡想喊出你七也不可能被听见。幽狼兽低吼示意莫凡躲到结界角落，自己朝袭来的龙卷连吐三道飞沙走石无果，随即不等指挥长啸冲刺，以血肉之躯撞向风盘·龙卷最中心——龙卷被撞停、风力锐减，幽狼兽却被抛上三十多米高空。眼看它无法保持平衡、极可能头部着地，牧奴娇扬手操纵一卷残风化为小旋风缓解它的坠势，幽狼兽落地仍撞得骨骼断裂。莫凡收起重伤的幽狼兽，宣告不会认输；牧奴娇再次衔接星图时，莫凡以雷印打断她的中阶施法，趁她闪避雷印的间隙完成自己的雷系星图，操纵雷云化作一道粗壮霹雳撕空劈向牧奴娇。

**关键事件**：1.莫凡骑狼逃亡被逼入绝境 2.幽狼兽以身撞停风盘·龙卷重伤 3.牧奴娇留情救狼 4.莫凡雷印断法并以第二道霹雳反击

**逐章写法公式**：

- **情绪流向**：起：紧张（骑狼逃命） → 承：温馨（狼护主与女神留情） → 转：热血（狼撞龙卷、莫凡反击） → 合：紧张（第二道霹雳劈落的悬置）
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：骑狼避锋（守） + 以身撞卷（召唤兽的牺牲高光） + 收狼亲战（交接棒） + 雷印断法加霹雳反击（反客为主）
- **本章核心技巧**：让召唤兽用自残式牺牲换取战局转换，既解决打不过中阶魔法的死局，又把情绪推高，为主角亲自接棒蓄满动机。
- **卡点与伏笔**：结尾卡点：动作悬置+第二道霹雳朝牧奴娇劈去，下章期待她的应对；埋设/回收伏笔：星子衔接怕干扰的设定→雷印断法的战术依据；牧奴娇的留情→她认输后莫凡留情与两人关系的对照。
