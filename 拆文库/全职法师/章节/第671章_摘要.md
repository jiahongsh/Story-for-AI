# 第671章 战无止境（上）

**概要**：十米高的双面鬼将没有立即冲向莫凡，而是召集周围亡灵发动围攻。莫凡用高阶火系魔法烈拳九宫在地面升起九道熔浆火柱，清掉三十多只普通亡灵。新一波毒腐尸逼近后，莫凡用遁影避开毒液，苏小洛则打开掌心风穴吸走尸毒和毒雨。莫凡借机用雷印麻痹五只毒尸，再以火滋将它们炸碎，感受到高阶后初阶魔法和身体反应的明显提升。双面鬼将终于亲自冲锋，莫凡借亡灵身躯弹开并躲过钩爪，随后拉开距离构成雷电电场，开始描画雷系攻击，雷云在鬼将头顶凝聚。

**关键事件**：1.双面鬼将召集亡灵 2.烈拳九宫清理三十多只亡灵 3.毒腐尸逼近 4.莫凡遁影避毒 5.苏小洛吸走尸毒 6.雷印和火滋击杀五只毒尸 7.双面鬼将近身冲撞 8.莫凡拉开距离召唤雷云

**逐章写法公式**：

- **情绪流向**：起：双面鬼将指挥群攻 → 承：烈拳和毒系配合清理普通亡灵 → 转：鬼将亲自冲锋 → 合：莫凡拉开距离准备雷霆反击
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：九宫清杂（扩大安全区） + 毒系协作（排除持续伤害） + 雷火连击（快速杀敌） + 躲避鬼将（积蓄重击）
- **本章核心技巧**：将战斗拆成普通兵、毒性干扰、战将首领三层威胁，让主角的每次解决都只换来下一层压力。
- **卡点与伏笔**：结尾卡点：雷云已经在双面鬼将头顶凝聚，下一章将直接呈现雷霆攻击结果；埋设/回收伏笔：亡灵毒性与亡灵结晶 → 后续战斗需要避开毒素并寻找致命核心。
