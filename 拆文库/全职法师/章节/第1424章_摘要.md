# 第1424章 世家纷争

**概要**：牧奴欣带莫凡、赵满延进入两大世家商议火脉的大堂，赵满延低声分析牧奴欣敢于带外人入机密商议的魄力。大堂内东方陌与牧善等长辈愁眉商讨开采昆仑山太阳岭火脉之难：火口窟温度堪比超阶魔法，派超阶以下法师九死一生，且有火之生灵栖息。东方烈请缨被长辈喝斥，牧桦主张出钱招募猎人法师，牧奴欣则忧心下方比想象更危险、会白白丢命，牧桦恼怒提及周家、穆氏、大黎世家步步紧逼。

**关键事件**：1.牧奴欣带莫凡赵入大堂，赵分析其魄力 2.长辈商讨火脉开采极难 3.东方烈请缨被斥 4.牧桦主张招募猎人，牧奴欣担忧 5.牧桦怒提世家被压迫

**逐章写法公式**：

- **情绪流向**：起：入大堂的神秘 → 承：长辈商讨的压抑 → 转：东方烈请缨被斥的紧张 → 合：世家被压迫的沉重钩子
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：牧奴欣带人入堂（设局） + 赵满延点魄力（人物侧写） + 长辈列困难（压力堆压） + 东方烈被斥（规则显形） + 牧桦提压迫（危机升级）
- **本章核心技巧**：用配角低语侧写人物城府，再以具体危险清单与世家压迫把任务难度写实
- **卡点与伏笔**：结尾卡点：世家被穆氏等逼迫急需火脉，下章期待莫凡如何介入；埋设/回收伏笔：太阳岭火脉难开采 → 呼应上章莫凡需原始魂种
