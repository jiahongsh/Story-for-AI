# 第1186章 最终审判

**概要**：十天之后，雅典城与神山仍笼罩阴雨，神山风波迎来神官审判。四名神官清查与杜兰克狼狈为奸的五名判官，杜兰克尸身被固定在罪席。伊之纱作为主谋嫌疑人受审，其律师辩称一切系杜兰克利用她名誉所为，伊之纱则低垂眼帘、以真诚眸光请求自降神位弥补，并愿签下永不解除的黑暗契约发誓不迫害心夏，四位神官最终未定其罪。随后对莫凡的审判中，宋启明为换另一位老神官放莫凡一马，暗中接受伊之纱交易，莫凡被判无罪，恶魔系定为需异裁院商议的异端但禁令暂不执行。最后莫凡经大传送阵遣返，问心夏行李，心夏低声说想留下来，并透露自己知道血可激活撒朗血石的原因。

**关键事件**：1.神官审判清查判官、伊之纱脱罪 2.宋启明交易换莫凡无罪 3.莫凡被遣返、恶魔系暂禁 4.心夏决定留下并透露身世线索

- **情绪流向**：起：神官审判的庄严 → 承：伊之纱脱罪的憋屈 → 转：莫凡无罪的释然 → 合：心夏留队与身世钩子
- **节奏配比**：慢铺垫 45% / 快冲突 15% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：神官审伊之纱（权谋） + 宋启明交易（妥协） + 莫凡无罪遣返（落定） + 心夏留帕特农（钩子）

- **卡点与伏笔**：结尾卡点：心夏知血石真相却未说尽，决定留帕特农；埋设/回收伏笔：撒朗血石与心夏身世 → 下章争夺神女之位伏笔。
