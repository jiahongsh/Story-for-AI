# 第1317章 讨回公道

**概要**：吸血鬼博拉风衣一甩张开不见光的黑暗空间，先一拳打落长老林泽两颗牙，再一脚踢断其鼻梁又断三颗老牙，林泽身为毁灭型超阶法师在黑暗幕布下魔法被压制三成、毫无还手之力，被戏耍得受尽屈辱。穆宁雪开口劝莫凡算了，怕真弄死魔法协会长老连议长都不好说话，博拉便把如死狗的林泽拖到莫凡面前。头发高束的康长老现身，劝莫凡坐下说清经过交审判会处理，并答应还他公道。林泽仍不甘心喊"杀人就是杀人决不轻饶"，康大长老却当场训斥：已有同僚汇报是潘西先动用夺命诅咒、莫凡这才杀他，且质问林泽身为纪律长老为何战斗这么久未平息。莫凡补述诅咒系铁律——夺命诅咒以猩红暗芒抽人灵魂，为魔法协会严禁，潘西用此招要夺穆宁雪灵魂令其如王小筠般成空壳，自己轰杀当属正当防卫。随后穆宁雪向康大长老陈述被围攻经过，有人作证、有监控影像为凭，康长老冷漠宣布东海魔法协会不再欢迎南荣、大黎两世家，收回共享的矿脉石山晶库，另寻合作。

**关键事件**：1.博拉以黑暗幕布碾压戏耍超阶长老林泽 2.康大长老训斥林泽偏激武断，认定潘西先用夺命诅咒 3.康长老凭证词影像将南荣、大黎两世家扫出东海魔法协会并收回合作

**逐章写法公式**：

- **情绪流向**：起：博拉痛揍林泽的爽感 → 承：穆宁雪劝停、林泽不甘告状 → 转：康大长老训斥与诅咒铁律揭示 → 合：两世家被扫地出门的清算
- **节奏配比**：慢铺垫 15% / 快冲突 35% / 爽点爆发 35% / 悬念留白 15%
- **本章结构公式**：博拉黑暗碾压林泽（爽点开篇） + 康长老调停、林泽反扑（冲突转折） + 康大长老训斥与夺命诅咒铁律（反转立论） + 两世家被驱逐收回合作（清算收尾）
- **本章核心技巧**：让主角团队的暴力惩罚与协会高层的主持公道并行，暴力负责解气、法规负责定性，双层满足读者
- **卡点与伏笔**：结尾卡点：悬念型——两世家被逐出东海魔法协会、合作被收回，后续会议与凡雪山的资源归属将如何演变；埋设/回收伏笔：夺命诅咒呈猩红暗芒、抽人灵魂 → 潘西之死的正当性依据；王小筠曾遭夺命诅咒成空壳 → 夺命诅咒残酷性的前例佐证；博拉打超阶如闲庭信步 → 其恐怖实力的铺垫
