# 第831章 火焰喷射器

**概要**：小炎姬雀跃发声告知莫凡掌握了新技能，莫凡心中一喜、盘算多喂火灵种助其进阶。劫炎在他身后分化成羽片状、渐成火羽轮廓，莫凡不解这莫非是熟悉的"千层火羽"。正疑惑间，背后两片火焰羽翼猛然舒展、重重后扇，火羽全炸产生凶猛推进力，将无备的莫凡贴着冰面送飞成燃烧炮弹撞向蓝谷凶离兽腹部——幸而他周身裹着玫炎与劫炎形成烈火保护，否则直接撞铠甲自己先碎。广濑与夜罗刹看得傻眼，连蓝谷都茫然，莫凡趁机遁影撤到五十米外。蓝谷举尖足连斩三道，莫凡矮身避过脑袋一斩，第三斩千钧一发时被穆宁雪冰锁缠腰拽退。穆宁雪气得想把他扔进怪嘴，莫凡尴尬认错，与小炎姬好声商量需配合烈拳或炎剑才有攻击性。小炎姬点明火羽可凝两次速度爆发，莫凡弄清这羽翼实为火羽自爆助推、攻逃皆宜却需优化，遂不再莽撞，盘算起冲过去与撤退的章法，而玄蛇铠甲被撕开口子后持续时间变短。

**关键事件**：1.小炎姬新技能、火羽翼误喷送飞莫凡 2.双炎护体撞腹、蓝谷三斩被冰锁救 3.穆宁雪怒讽、莫凡与小炎姬商量配合 4.火羽翼原理揭晓、莫凡谋而后动

**逐章写法公式**：

- **情绪流向**：起：新技能期待的喜 → 承：误喷撞腹的笑 → 转：三斩惊魂的紧 → 合：谋定后动的稳
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：新技能亮相（喜） + 误喷撞腹（笑） + 三斩被救（紧） + 揭原理谋动（稳）
- **本章核心技巧**：用"喜剧失误 + 原理回收"把新能力自然交代，同时用装备倒计时保紧绷。
- **卡点与伏笔**：结尾卡点：莫凡盘算配合与撤退、铠甲将尽，下章期待喷射羽翼如何真正建功；埋设/回收伏笔：玄蛇铠甲裂口 → 持续时间变短，承接上章血斩破甲。
