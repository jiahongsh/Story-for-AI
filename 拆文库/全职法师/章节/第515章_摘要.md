# 第515章 对手是丁雨眠？

**概要**：莫凡的挑战书一下，整个火院骚动，他被封为冲榜狂魔。牧奴娇以新生唯一前50的成绩仍与他差40名，赵满延哭诉自己还在200多名，转而向莫凡描绘世界学府大赛的历练、威尼斯水战与播种世界的愿景，两人一拍即合。莫凡这才想起自己已是内定候选人。清晨小炎姬烧了早餐摊和银行卡，夸它这个月少烧了一家才哄回去，摊主女老板趁机托莫凡带儿子进场观战。莫凡走进火院被贴满作死标签，艾图图、牧奴娇堵在校门问他研究好对手的天生天赋没有，莫凡反问啥天赋，艾图图说出丁雨眠的名字时，莫凡才惊觉自己的对手竟是火榜前十的丁雨眠，两女彻底崩溃。

**关键事件**：1.莫凡挑战前十引发全院骚动 2.赵满延描绘世界学府大赛愿景 3.莫凡不知对手是丁雨眠

**逐章写法公式**：

- **情绪流向**：起：挑战前十的豪气 → 承：学府大赛愿景的兴奋 → 转：小炎姬日常的鸡飞狗跳 → 合：不知对手的爆笑反差
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：冲榜舆论（造势） + 学府大赛目标（立愿） + 小炎姬日常（放松） + 对手悬念（引爆）
- **本章核心技巧**：用大量日常喜剧稀释大战前的紧张，再用主角不知对手的反差把悬念留到结尾
- **卡点与伏笔**：结尾卡点：对手是火榜前十的丁雨眠，下章开战；埋设/回收伏笔：丁雨眠的天生天赋被艾图图的话截断
