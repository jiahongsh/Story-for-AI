# 第435章 特殊癖好

**概要**：反复回放录像确认：柳娴走着走着步子一顿、面前却空无一物，她在幽暗处越走越慢、定在柱子后被挡住大半身躯，表面像发病扶柱，反复看更像被无形之物抓住动弹不得，最终窒息般僵住倒地；霍佗赶到后没有先救人、而是朝空旷的地铁站怒骂追赶，再把柳娴抱出。灵灵推断凶手可能用暗影系魔法藏身柱后，莫凡认同，基本确定对方拥有暗影系能力。查访莫凡冒充的追求者，发现只是普通店员、无线索。转往女子高校找柳茹，同学爆料她一个月"来事"三四次、总请假不去看病——莫凡宿舍探望却被拆穿身份吃了闭门羹。灵灵提出柳茹可能正被偷偷吸血，莫凡推断吸血鬼偏好双胞胎姐妹花、对姐姐下手后又缠上妹妹。两人夜伏宿舍外林子守株待兔，第一夜无获、第二夜只撞见学生私会，直到下半夜莫凡嗅到暗影系力量在空气中弥漫——鱼上钩了。

**关键事件**：1.录像确认柳娴被无形之物抓住、凶手拥有暗影系能力 2.同学口供与探病被拒引出"柳茹正被偷偷吸血"的推断 3.蹲守两夜后暗影系力量现身

**逐章写法公式**：

- **情绪流向**：起：恐怖（录像细读还原遇害过程） → 承：压抑（查访扑空、柳茹被排挤被吸血的处境） → 转：紧张（守株待兔的蹲守煎熬） → 合：紧张（暗影力量弥漫、鱼上钩）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：录像还原（确认作案手法）+查访扑空（线索断头）+女校流言与探病被拒（翻出柳茹被吸血真相）+林中蹲守卡点（猎物上钩）
- **本章核心技巧**：让"同学生活流言"这种闲笔先被读者当成校园恶意，再被灵灵一句话翻转为破案关键，完成信息反转。
- **卡点与伏笔**：结尾卡点：紧张——暗影系力量在林子弥漫、鱼上钩，下章期待吸血鬼现身；埋设/回收伏笔：霍佗怒骂追赶→印证其目击属实；柱后阴影假说→与莫凡暗影系同源、暗示未来对位战；"经常来事"=贫血→柳茹被反复吸血的症候；铁丝网缺口→柳茹翻墙出校的通道。
