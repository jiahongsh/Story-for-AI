# 第676章 火羽千破！

**概要**：面对近万骷髅，莫凡安慰哭泣的小炎姬，强调即使恐惧也要让敌人先颤抖。小炎姬感知到莫凡同样害怕却不屈服，便卷起二十米高火浪独自冲入骷髅海，莫凡以遁影追赶未及。她先放出火鸟贴地扫倒骷髅，却很快被骨墙阻住，骷髅军团随即以密集骨刺和骨矛压制她，令其火焰黯淡、身上出现暗斑。小炎姬拒绝求援，强行引爆火之源泉，让劫炎化作巨大的火焰羽翼；两道火斩分别清倒成片骷髅后，更多敌人再度涌上。她最终崩散火翼，释放千百片会爆裂的火羽，令周围一两百米的骷髅群同时遭受连锁爆炸。

**关键事件**：1.莫凡鼓励小炎姬直面恐惧。 2.小炎姬冲入骷髅海担任先锋。 3.火鸟攻击受阻，小炎姬遭骨雨围攻受伤。 4.小炎姬觉醒火焰羽翼并发动火羽千破。

**逐章写法公式**：

- **情绪流向**：起：悲伤 → 承：热血 → 转：紧张 → 合：爽
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 30% / 悬念留白 5%
- **本章结构公式**：主角安慰契约兽（确立意志） + 契约兽冲阵（主动试探） + 敌群反击受伤（压低战力） + 火翼爆发清场（兑现反击）
- **本章核心技巧**：用一次先受挫的冲阵证明敌群规模，再将技能升级放在伤势和拒绝退缩之后释放。
- **卡点与伏笔**：结尾卡点：战果悬念，火羽爆炸能否在骷髅海中打开生路；埋设/回收伏笔：小炎姬强行催动火源 → 转化为火焰羽翼和火羽攻击。
