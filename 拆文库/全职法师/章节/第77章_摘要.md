# 第77章 别人的垫脚石

**概要**：莫凡步入庄园，很不巧听到肥石、黎文杰和郭彩棠对自己的谈论，暗想他们若知道梵墨和莫凡是同一人不知会是什么表情。大宴厅里，总教官斩空把莫凡抓到一旁再次招揽：毕业后到部队来，军部支撑他大学的大开销，政府部门保他随便踩二世祖；莫凡以守边疆太无聊为由一口回绝，斩空气恼放话他被宇昂打个半死也不管了，随即忽然收起玩笑压低声音，托他在与宇昂决斗的时候多留意一下，追问缘由也只说就多留意，随即被老熟人打断。朱校长、邓凯、杨作河等博城要人陆续到场，均由穆卓云带宇昂亲自迎接；莫凡发觉博城大人物自己基本都见过，意识到出类拔萃的学生身份容易引来各方势力头子关注。宾客们窃议穆氏将只手遮天、莫凡背后有斩空和两位校长力保；肥石向小可解释莫凡一定程度上代表魔法学校势力与世家弟子宇昂决斗、胜者获得地圣泉机会，小可感慨一千五百人里杀出来的最出色学生还不如一个好家世，肥石答投胎就是个技术活。

**关键事件**：1.斩空宴上招揽莫凡入伍被回绝后神秘托付多留意宇昂 2.穆卓云带宇昂亲自迎接朱校长邓凯杨作河等各方大人物 3.小可感慨好家世胜过学校第一，肥石答投胎是技术活

**逐章写法公式**：

- **情绪流向**：起：轻松（宴上重逢斩空）→ 承：紧张（神秘托付不明就里）→ 转：压抑（权贵格局与身份议论）→ 合：压抑（投胎技术活的结论）
- **节奏配比**：慢铺垫 65% / 快冲突 5% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：宴厅遇斩空（叙旧）+ 招揽与回绝（立军方线）+ 神秘托付（埋钩子）+ 宾客科普与感慨（把赌注与主题摊开）
- **本章核心技巧**：用宴会群像借嘴讲清势力格局与赌注，让决斗开打前信息全部到位，同时留一个不肯言明的托付当暗线。
- **卡点与伏笔**：结尾卡点：主题刺点型——好家世压过草根第一的结论刺痛读者，等决斗翻盘；埋设/回收伏笔：斩空的多留意一下 → 未说明的观察任务待决斗兑现；莫凡见遍博城大人物 → 为赛后各方争抢铺垫；博城中阶法师稀有 → 抬高地圣泉与决斗的含金量。
