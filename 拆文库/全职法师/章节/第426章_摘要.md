# 第426章 反杀！

**概要**：莫凡最终没有施展中阶召唤系魔法,老师们大大松了一口气,却不知他的召唤系早已中阶,只是没钱买能到疾星狼级别的契约兽,那是4000万以上的天价。赵季发现莫凡没有契约兽后笑了,想靠终结大魔头扬名,他开启灵级光种的弧面光盾,又用光佑-画壁把莫凡的千钧-霹雳-夜叉整个化解,言语间满是挑衅。莫凡佯装油尽灯枯站在原地,等赵季的烈拳-地煞轰来只以冥离盾后退,上衣被焚成灰烬,胸膛烧伤,疼得直咧嘴。赵季见自己打伤莫凡,以为胜利在望,正要补上最后一拳,冥离盾中央突然飞窜出一道长矛般的尖刺,冥离反刺穿过地煞之花直逼赵季面门。裁判席上魏荣反应极快立起岩障,尖刺近乎刺到赵季脸前。魏荣判定赵季输了,赵季冷汗直冒、失魂落魄,只撂下一句让他受伤也够了。

**关键事件**：1.莫凡千钧-霹雳-夜叉被赵季光佑-画壁化解 2.莫凡被烈拳-地煞烧伤,佯装油尽灯枯 3.冥离反刺突袭,魏荣岩障救援,赵季被判输

**逐章写法公式**：

- **情绪流向**：起：虚惊松气 → 承：光盾压制、烧伤加压 → 转：冥离反刺绝杀 → 合：判负余威
- **节奏配比**：慢铺垫 25% / 快冲突 45% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：交代无契约兽真相(释疑) + 霹雳被化解(受挫) + 示弱挨烧(蓄力) + 冥离反刺反杀(爆发)
- **本章核心技巧**：用"示弱到底+暗藏杀招"的装死打法完成反杀,反杀前让对手心理占尽优势,爆发才够爽
- **卡点与伏笔**：结尾卡点：赵季落败后撂话"让他受伤也够了",火院颜面与莫凡伤势同时存疑;埋设/回收伏笔：召唤系中阶无契约兽 → 为后续购买契约兽埋线；冥离盾反刺效果 → 本场唯一制胜点
