# 第316章 及时赶到，斩空！

**概要**：军官报告一群巨亡蜥逼近，十三位中阶军法师的方阵面临噩梦，蒋艺下令杀出去。脱身的莫凡立在只剩骨架的景观塔上，感悟潜能须在战斗中激发、无此围还要半年，并回味已追上当年的唐月老师。仰躺休息时他发现空中一只白色巨鹰吊着皮网，用意念凝视后如遭霹雳——网中被禁锢精神的正是赵满延、牧奴娇、穆宁雪、白婷婷四人。陆年用魔能灌声让全城听见勒令：莫凡马上跪着到他面前来，否则将心魂被封印、下坠中施展不出魔法的四人扔下去摔成肉泥。赵满延嘶喊提醒要告审判会军法庭，但那高度莫凡根本听不见。白婷婷、牧奴娇沉默听着陆年的尖笑。就在此时，一位穿军袍、脖颈有醒目伤疤的男子扇动风之翼飞来，怒吼勒令陆年放了学员。

**关键事件**：1.军官方阵被巨亡蜥群逼近 2.莫凡发现陆年擒四学员吊在空中 3.陆下最后通牒逼莫凡下跪 4.斩空驾风之翼赶到喝令放人

**逐章写法公式**：

- **情绪流向**：起：紧张（巨亡蜥群压境）→ 承：轻松转紧张（莫凡小憩与发现白鹰）→ 转：压抑（陆年通牒、人质濒死）→ 合：热血（斩空赶到）
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：方阵危机（旧线收尾）+ 塔顶感悟（休整与成长注脚）+ 白鹰认人（新危机引爆）+ 通牒与嘶喊（拉满压抑）+ 风之翼登场（希望钩子）
- **本章核心技巧**：用主角"刚脱险的小憩"作情绪低谷，紧接着抛出更高规格的人质危机，落差把压迫感翻倍
- **卡点与伏笔**：结尾卡点：悬念型——风之翼男子身份未揭、与陆年关系不明，下章期待对峙；埋设伏笔：赵满延"告知审判会军法庭"的嘶喊 → 后续清算伏笔，脖颈伤疤的军袍男子 → 斩空身份与旧史线索
