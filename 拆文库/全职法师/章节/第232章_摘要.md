# 第232章 司夜统治！

**概要**：莫凡交出暗影妖兽后早早退开自保。老生中有影响力的张祥明号召各系先把犯众怒的水系"搅屎棍"扔出去，混战随之演变成系与系的新仇旧怨之战，水系被逐个踹出战场。混战惊动校方，萧院长急忙施展光系高阶魔法结界圈住人群，光系教师全员出动；周正华担心出人命，萧院长下令开启坐落在混战区域的司夜统治大阵——以暗影系魔石摆放星轨星图、可把高阶魔法威力提升数倍至数十倍的大阵。暗石亮起、星图交织，夜幕化作笼罩而下的巨掌斗篷，星光与城市灯火尽数消失，学员陷入伸手不见五指的黑暗且魔法难以释放。黑教廷一方虚惊一场：傅天明献殷勤说明此阵是校方防伤亡的旧备，宇昂转怒为喜——黑暗中唤出黑畜妖无人能识，且司夜统治削弱绝大多数系魔法，火雷召唤三系的莫凡被大幅削弱，正是夺泉杀人的良机。

**关键事件**：1.张祥明率众清算水系，混战变成仇怨之战 2.萧院长开启司夜统治大阵压制全场 3.黑教廷判定大阵反而利好，决意趁黑杀莫凡夺地圣泉

**逐章写法公式**：

- **情绪流向**：起：紧张（莫凡抽身自保） → 承：热血（各系清算水系） → 转：恐怖（司夜统治吞噬黑暗） → 合：压抑（黑教廷窥见杀机）
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：主角抽身（避战保命） + 群体互殴（仇怨失控） + 大阵开启（规则压制） + 敌方窃喜（杀机翻倍）
- **本章核心技巧**：用一道改变环境规则的学院大阵同时压制全场，再借反派视角把它翻转成暗杀的保护伞，一张牌打出两层冲突
- **卡点与伏笔**：结尾卡点：反杀预警卡点——黑教廷判定莫凡被削、杀机最盛，下章期待莫凡在黑暗中的反制；埋设/回收伏笔：司夜统治大阵 → 黑暗环境为暗影系莫凡暗中铺路；灰一点出莫凡火雷召唤三系 → 黑教廷情报网伏笔；傅天明从老师酒后吐露获知大阵 → 校内泄密线
