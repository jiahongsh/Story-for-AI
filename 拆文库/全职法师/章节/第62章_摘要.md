# 第62章 地圣泉

**概要**：穆宇昂到古风茶屋向养父穆卓云抱怨这场决斗无聊，穆卓云解释决斗要办在宇昂的成年礼上：借击败对手在博城名流面前立威树信，为他将来把控城市大权铺路，同时也是他与邓凯、朱校长之间的一次暗斗。他透露莫凡已掌握第二级火滋、修炼速度不慢于大世家出类拔萃的弟子，且被邓凯、斩空、朱校长关注，想下手都不便如愿，宇昂听罢反而觉得这场决斗会有意思许多。叙述层揭开穆卓云的老谋深算：他倾力培养宇昂只为让这个养子替亲生女儿穆宁雪看住博城家底，宇昂再风光也只是穆宁雪的垫脚石。为让宇昂成年礼后彻底碾压同辈，穆卓云承诺开启博城地圣泉给他整整一星期修炼，称其功效相当于加强不知多少倍的星尘魔器、很可能是冲击中阶法师的最佳机会，却拒绝透露地圣泉来历，只强调那是一辈子只有一次的绝佳机会。

**关键事件**：1.穆卓云道出成年礼决斗的立威与暗斗双重目的 2.借宇昂视角确认莫凡已二级火滋且被博城高层护着 3.穆卓云承诺开启地圣泉、暗示冲中阶良机，地圣泉来历成谜

**逐章写法公式**：

- **情绪流向**：起：儿子抱怨决斗无聊的散漫 → 承：父亲层层剖解利害的深沉 → 转：地圣泉许诺的天大好处 → 合：来历封口的悬念收口
- **节奏配比**：慢铺垫 75% / 快冲突 0% / 爽点爆发 10% / 悬念留白 15%
- **本章结构公式**：抱怨决斗（引出议题）+ 剖解利害（抬高对决规格）+ 垫脚石真相（埋内部背叛）+ 地圣泉许诺（抛核心资源悬念）
- **本章核心技巧**：全章以反派父子密谈撑起，用敌方视角完成主角实力认证，再用关键资源来历留白把伏笔钉进读者心里
- **卡点与伏笔**：结尾卡点：资源悬念型——地圣泉大有来历但不必知道，读者记下这个名词待回收；埋设/回收伏笔：一年后成年礼决斗 → 承接上章、定下对决舞台；宇昂是穆宁雪垫脚石 → 反派内讧暗雷；博城地圣泉 → 与后文妖魔偷泉异动直接勾连；邓凯与穆卓云的暗斗 → 暂不解释的悬念线
