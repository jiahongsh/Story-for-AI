# 第1137章 送了八亿

**概要**：埃及换上召唤更快的新队员，小岛几被木乃伊填满，莫凡却因差精魄而眼亮，视亡灵为送钱。米奥斯费劲唤出统领级触虫魔，莫凡不理反扑入亡灵堆。触虫魔乃十五六米骸骨蜈蚣妖，诅咒之气四溢，观众忧其失控伤命，圣裁院与总督论及邪术禁术之辨，却因依托亡灵系无从彻查。莫凡踩木乃伊肩跃至其头颅，意念一拳碎骨，再以念控将殷红木乃伊塞满其嘴、隔空轰入食道，引胃中亡灵炸裂使骨躯四分五裂。米奥斯受辱，赛义德点破莫凡乃杀妖高手需联手，奈夫鲁惜法老之泉。莫凡寻得结晶之骨捏碎令其无法重组，心中暗喜亡灵爆精魄概率高出古都数倍，算得埃及已送约八亿精魄，第五级霹雳到手。

**关键事件**：1.触虫魔登场莫凡反杀 2.圣裁院论邪术无从查埃及 3.莫凡敛八亿精魄五级霹雳

**逐章写法公式**：

- **情绪流向**：起：敌人换人加压 → 承：触虫魔登场 → 转：莫凡智取反杀 → 合：敛财八亿爽点
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：换人加压（危机） + 触虫魔（强敌） + 塞嘴炸胃（智取） + 八亿精魄（收益爽）
- **本章核心技巧**：用看穿复活机制的智斗替代蛮力，再以收益视角把消耗战写成发财爽章
- **卡点与伏笔**：结尾卡点：莫凡五级霹雳已成，下章如何爆发；埋设/回收伏笔：触虫魔结晶骨→智取；小泥鳅→精魄收益
