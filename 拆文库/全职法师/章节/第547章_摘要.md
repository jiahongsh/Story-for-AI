# 第547章 莫凡，真实实力

**概要**：东方烈先以火龙般的烈拳吞没莫凡，场外众人都以为莫凡难以承受。莫凡没有展开防御，而是在小炎姬附体后的血红玫炎中反击，以陨拳蒸发并打穿东方烈的灰炎，连毁其铠魔具和盾魔具，将他轰至吐血倒地。全场因这份超出认知的力量而沉默，莫凡的熟人也察觉到他此前一直隐藏实力。莫凡捏碎刚买的手机后退出尚未结束的比赛，说明要赶赴亡灵之乱中的古都寻找张小侯，并拒绝让牧奴娇和赵满延同行。

**关键事件**：1.东方烈以烈拳抢先压制莫凡 2.莫凡借小炎姬附体反转火系对轰 3.陨拳击败东方烈 4.莫凡离赛赴古都寻张小侯

- **情绪流向**：起：紧张对轰 → 承：火焰压制 → 转：陨拳反杀 → 合：悲愤离场
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：强敌先攻（建立危机） + 主角异火显现（制造反差） + 一击决胜（兑现压制） + 突然离场（转入寻人线）
- **本章核心技巧**：先用旁观者的必败判断抬高危机，再以连续可视化细节完成逆转。
- **卡点与伏笔**：结尾卡点：任务转场+莫凡赶赴古都寻找张小侯；埋设/回收伏笔：碎裂手机与悲愤情绪 → 指向收到的紧急消息。
