# 第373章 祸不单行

**概要**：杭州瘟病隔离区内感染者浑身脓疮、大量饮水也无法缓解，治愈系泰山北斗束手无策，只能给第一批感染者做三天生命倒计时，第二、三批感染人数成倍增加遍布全城。白衣帽男子质问为何不立刻对瘟病源头大蛇采取行动，鹿先生因深知那是守护神而沉默，议员祝蒙与审判长唐忠为隐患战略争执不下。宫廷侍卫李锦带回图腾珠未取回的消息，被押解回杭的唐月与莫凡遭祝蒙怒斥，唐月交出一大瓶摩天蛇血液供鹿先生研制抵抗药剂，两人随即被关押。紧接着军统急报：西岭涌出一大群白魔鹰，无视魔法轰炸正集体飞向杭州，唐忠震惊于这群素来安分的妖魔为何毫无征兆袭城，祝蒙仰天哀叹祸不单行。

**关键事件**：1.治愈系断言第一批感染者三天内全部死亡，疫情成倍扩散 2.唐月献出摩天蛇血液供研制抵抗药剂，与莫凡被关押 3.西岭白魔鹰大群毫无征兆扑向杭州，瘟病之外又添妖魔袭城危机

**逐章写法公式**：

- **情绪流向**：起：压抑（隔离区地狱景象）→ 承：紧张（高层争执与限期倒计时）→ 转：紧张（唐月莫凡被押回受斥）→ 合：压抑（白魔鹰袭城，祸不单行）
- **节奏配比**：慢铺垫 40% / 快冲突 30% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：隔离区惨状（立危机）+ 高层争执（摆立场）+ 唐月献血被押（埋希望）+ 白魔鹰急报（加第二危机）
- **本章核心技巧**：用双危机串联收束——在旧危机刚露出唯一解法时抛出新危机，压缩读者喘息空间
- **卡点与伏笔**：结尾卡点：双危机压顶加三天死线，下章看要塞如何应对白魔鹰；埋设/回收伏笔：蛇血药剂能否根治 → 为玄蛇被冤与真凶线埋因；西岭白魔鹰反常袭城 → 为君主级鹰族与幕后黑手埋线
