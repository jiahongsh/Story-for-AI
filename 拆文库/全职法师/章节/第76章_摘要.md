# 第76章 鸿门宴

**概要**：决斗前夜，莫凡坐在高楼露台喝啤酒俯瞰博城，穆宁雪问了心夏找来，劝他明天别去，宇昂对她父亲言听计从、任何不利都会不死不休地下狠手；莫凡骂宇昂是条好狗，反而说要帮她教训宇昂。穆宁雪提出让他躲过这劫去读大学，四年后她掌控家族权力，那时回博城没人能动他，莫凡一句你要包养我把她说得气走，随后与张小侯短信贫嘴，张小侯也建议他跑、称宇昂整个人怪怪的。次日成年礼，莫凡坐着摩的沿豪车成队的山道上了穆氏庄园，在大铁门口遇上迎接队友的郭彩棠，她满心厌恶放话现在道歉还来得及让宇昂下手轻点，莫凡拿她穿开裆裤的旧事反调戏，气得她喊你去死。宾客们议论这个敢调戏郭彩棠的狂小子是谁，得知他是当众骂过穆老爷子的司机之子、今日与宇昂决斗之人；肥石趁机夸年轻不骄躁的雷系梵墨、劝郭彩棠赶紧倒追，浑然不知梵墨与莫凡是同一人。

**关键事件**：1.穆宁雪夜访劝莫凡弃战，被包养玩笑气走 2.郭彩棠门口放话下马威，莫凡以童年糗事反唇相讥 3.队友们夸梵墨劝郭彩棠倒追，不知梵墨即莫凡

**逐章写法公式**：

- **情绪流向**：起：压抑（夜访劝退示警）→ 承：轻松（包养玩笑与短信贫嘴）→ 转：压抑（门口下马威）→ 合：轻松（梵墨身份错位的反讽）
- **节奏配比**：慢铺垫 50% / 快冲突 20% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：露台夜话示警（立威胁）+ 短信贫嘴过渡（调情绪）+ 门口下马威（入局受压）+ 队友错认梵墨（埋反讽）
- **本章核心技巧**：用旧人劝退与旁人错认两重信息差，把主角真实实力继续藏住，同时用轻佻对话稀释压迫感。
- **卡点与伏笔**：结尾卡点：反讽悬置型——被众人夸赞的梵墨正走进宴会，牵引身份揭晓的时机；埋设/回收伏笔：宇昂言听计从会下狠手 → 具体化对手威胁；梵墨双重身份 → 为猎妖队那边认出莫凡埋线；心夏 → 侧写穆宁雪与莫凡的联系渠道。
