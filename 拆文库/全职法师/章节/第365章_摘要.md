# 第365章 死难者

**概要**：白镇突然全面封锁，两人被困，原计划落脚后立刻送蛇上山就此中断，唐月果断决定入夜硬闯结界，莫凡召出疾星狼驮人行动。同一时间杭州爆发上百名瘟病者，恐慌蔓延：此病无潜伏期、扩散与恶化都极快，一周前的病人已浑身青色水泡。就在两人逃离白镇的那一个小时，最早感染的三名病发者死亡，尸身水泡破裂后被疯狂腐蚀、面目全非，震动医药界。医院里鹿老先生断言从感染到腐坏仅七天、时间太短；祝蒙向唐忠发难，指出感染已破千，唐忠内心动摇——瘟疫死者与一周前两具尸体死状一致，排除了祝蒙嫁祸的可能。祝蒙怒斥感染已达1324人、一周后全都会死，唐忠恳请再给时间调查，承诺让唐月带回蜕皮体液提取抗体，求祝蒙不要赶尽杀绝。

**关键事件**：1.白镇封锁、两人夜闯结界出逃 2.首批三名瘟病者死亡、尸体腐蚀震动医界 3.祝蒙与唐忠医院对峙 4.唐忠承诺带回蛇的体液提取抗体

**逐章写法公式**：

- **情绪流向**：起：压抑（白镇封锁被困） → 承：紧张（入夜硬闯结界） → 转：恐怖（三名死者与腐尸） → 合：压抑（1324人的死线与恳求）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：被困封锁（困境） + 决意硬闯（行动） + 死难爆发（危机升级） + 医院对峙（立场拉扯）
- **本章核心技巧**：把瘟疫恐怖具象成"七天定时"的数字死线与尸体白描，再借医院对峙让立场冲突替代动作冲突。
- **卡点与伏笔**：结尾卡点：死线倒计时型——1324人一周后皆死、抗体承诺悬而未决，期待唐月带回体液；埋设/回收伏笔：唐忠承诺的蜕皮体液→蛇血提取血清线（后续回收）；一周前两具尸体死状一致→蛇是瘟源疑云加深。
