# 第847章 小泥鳅进阶

**概要**：灵灵离开后莫凡回房冥修，手上留着一份星河之脉，因穆宁雪坚决不要便打算用来冲击雷系星河。他回想与蓝谷凶离兽厮杀时为救穆宁雪将霹雳引向自己，意外发现引雷可化作攻击性雷电铠甲，并让魔法触到雷系星云壁垒。坐定入精神世界，莫凡正为星河之脉珍贵、失败即损失一亿而忐忑，交代小泥鳅坠关键时刻帮忙。小泥鳅坠轻轻颤动似在阻止，莫凡探入其内天地，惊见原本的冥河竟扩宽一倍变成冥江，小泥鳅坠靠消化永生之莲剩余能量进阶了。小泥鳅示意等它先稳下来再冲雷系更稳妥，莫凡兴奋盘算空间系星尘也变星云。

**关键事件**：1.莫凡用星河之脉冲雷系，回想引雷护体 2.小泥鳅坠颤动阻止，莫凡发现冥河变冥江 3.小泥鳅示意先稳再冲雷系 4.莫凡畅想空间系进阶

**逐章写法公式**：

- **情绪流向**：起：冥修前的忐忑 → 承：回忆引雷发现 → 转：小泥鳅阻止揭进阶 → 合：稳后再冲的兴奋余波
- **节奏配比**：慢铺垫 50% / 快冲突 0% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：冥修准备（铺垫） + 引雷回忆（回溯） + 坠子进阶（反转） + 规划空间系（钩子）
- **本章核心技巧**：用主角的内心忐忑做"假危机"，再被宝物进阶打破，制造轻爽反转
- **卡点与伏笔**：结尾卡点：小泥鳅进阶后莫凡雷系冲击更稳，下章期待他去杭州问图腾；埋设/回收伏笔：永生之莲剩余能量 → 小泥鳅坠冥河变冥江的伏笔回收
