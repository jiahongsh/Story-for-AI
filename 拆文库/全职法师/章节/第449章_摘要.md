# 第449章 怒战吸血鬼！

**概要**：柳茹在火光余晖里看到莫凡朝她走来，慌忙捂脸遮住收不起来的血牙，自觉是彻头彻尾的怪物。被轰下楼的聂东展开一面墙宽的蝙蝠翅膀飞回，咆哮着把被逐出家庭、丢失猎物都归罪于这个猎法师，誓要让他死无全尸。他先以血液幻化的灭爪抓向莫凡，莫凡暗影位移躲过；聂东自恃暗眼能识破位移、讥其班门弄斧，又唤出上百只夜刃蝙蝠群袭。楼层矮窄施展不开，莫凡抱起浑身是伤的柳茹撞碎玻璃墙从四十层跳下，下坠中以遁影没入楼影脱身，借阴影一路疾行到空旷的金融街十字路口，中央无阴影可借力，追击的蝙蝠却密密麻麻围拢。莫凡索性不跑，描画火焰星图、烈焰聚腕，一记地煞轰裂地面，熔浆火焰汇成吞没他自己的地煞之花，将蜂拥的蝙蝠顷刻焚成灰烬。残余蝙蝠溃散之际，聂东的巨大翅膀笼罩而下，獠牙直咬莫凡脖颈要将其咬断，驾车赶到的赵满延及时咏唱光佑圣盾，光盾隔绝邪物，聂东牙齿冒白烟慌忙退开——光系正是吸血鬼克星。

**关键事件**：1.柳茹捂脸自惭怪物 2.聂东灭爪与蝙蝠群追杀，莫凡抱柳茹跳楼遁影脱身 3.地煞之花焚尽蝙蝠群 4.赵满延光佑圣盾挡下聂东咬颈

**逐章写法公式**：

- **情绪流向**：起：压抑（柳茹捂脸自惭） → 承：紧张（跳楼逃杀、街头被围） → 转：爽（地煞之花焚尽蝙蝠） → 合：紧张（聂东偷袭被圣盾挡下）
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：反派复起立威胁（翅膀回归） + 追逃换场（跳楼遁影穿街） + 地煞反杀（清小怪） + 克星登场（圣盾挡咬）
- **本章核心技巧**：用「地形限制能力→绝境爆发」的攻防转换推进打斗，结尾用属性克制卡住新悬念
- **卡点与伏笔**：结尾卡点：对峙升级——聂东克星光盾出现，人鬼大战正面对决待开；埋设/回收伏笔：柳茹体质异于常人强过法师 → 血脉之谜再添一层；光系克吸血鬼 → 决定后续战术分工
