# 第347章 毫无风度的男人

**概要**：入秋的杭州浙江学府，风云榜上的冰公子柳一林为坐轮椅的心夏冻结湖面架起冰桥想推她去湖心亭，被心夏以"我只想一个人散散步"平静拒绝。路过的陈云琪等三名女生酸溜溜贬损心夏：连走路都要靠轮椅、装楚楚可怜、踩死蚂蚁都要哀怨半天，还惟妙惟肖模仿她说话；柳一林出面斥责你们是不是过分了，反被三女抢白——她们自认有什么说什么、看不惯白莲花就直说，把柳一林说得哑口无言。左右为难之际，一个穿青墨色短衫、煞气笼罩、敞着三颗扣子的痞性男子走过，丢下一句"碧池，就该呆在水里"，接连三脚准确无误把三个女生踹进冰冷湖水。三女没一个水系，落水后衣妆尽毁狼狈不堪。柳一林愣在原地：世上怎么有对女人这么粗鲁、毫无风度的男人——尽管他脑子里已经踹了她们好几遍，二十年的高尚修养却绝不容许他真这么做。

**关键事件**：1.柳一林献殷勤被心夏平静拒绝 2.陈云琪三女嘲讽心夏、抢白柳一林 3.青墨衬衫男三脚踹三女下水，惊呆柳一林

- **情绪流向**：起：秋日校园的闲适 → 承：恶女讥讽的憋闷 → 转：三脚踹水的爆发 → 合：风度之问的错愕轻喜
- **节奏配比**：慢铺垫 35% / 快冲突 35% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：场景（秋日小西湖）+ 殷勤（冰桥被拒）+ 施压（三女讥残抢白）+ 裁决（三脚落水）+ 反应（柳一林的风度崩塌）
