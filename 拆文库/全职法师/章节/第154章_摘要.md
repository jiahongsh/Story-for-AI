# 第154章 阴险罗宋

**概要**：矮瘦男生上场召出一只未成年的小幽狼兽，第一轮就被暗影系学生戏耍得气喘吁吁，只干掉两人便羞红退场，表态以后绝不丢脸，王力挺半讥半讽。郑冰晓接棒，他的岩魔士比白铠战蛰还强、不怕火雷，虽然速度缓慢，凭操控土的能力一连灭掉四组人、累计二十五人后被轮番轰炸踹下台，坐席议论召唤系初阶变态、最强应是食骨妖。王力挺带着四十的数据登场，召出身如秃鹰、背有肉翼的食骨妖，敏捷狡猾到让对手技能彻底落空，他只管站着数数。坐席议论召唤系百人指标与资源转移规则时，罗宋凑过来打听清楚：让召唤系不达标，资源就归土系。他阴笑着走向挑战入口，萧院长不悦质问他不是答应过不再主动挑衅莫凡，罗宋答我不挑衅他——他不动莫凡的召唤兽，而是要把莫凡同系的伙伴全部灭掉，看他怎么靠那只垃圾幽狼兽补足落差，并放话召唤系的资源归土系所有。

**关键事件**：1.矮瘦男生两数据退场，郑冰晓岩魔士连灭四组拿下25人 2.王力挺食骨妖登场，站桩数人 3.罗宋打听资源规则后下场，定计灭莫凡全系伙伴

**逐章写法公式**：

- **情绪流向**：起：小狼怯场的尴尬 → 承：岩魔士横扫的畅快 → 转：食骨妖碾压的压迫 → 合：罗宋下场的阴冷
- **节奏配比**：慢铺垫 30% / 快冲突 45% / 爽点爆发 15% / 悬念留白 10%
- **本章结构公式**：矮瘦男生怯场（示弱对照） + 郑冰晓四组横扫（正反馈） + 食骨妖登场（造无敌错觉） + 罗宋定计入场（反派转折钩）
- **本章核心技巧**：层层递进的召唤兽梯队展示（最弱、中坚、最强），把「最强食骨妖」捧到无敌，再让罗宋入场收割，捧得越高、踩得越狠
- **卡点与伏笔**：结尾卡点：紧张型，中阶罗宋入场直指食骨妖，下章开打；埋设/回收伏笔：罗宋对萧院长「不挑衅莫凡」的承诺（前文）→ 被他钻空子执行，文字游戏式履约；百人指标（前章）→ 成了罗宋下黑手的动机
