# 第278章 杀入敌后

**概要**：穆宁雪独自深入后被七只洞穴魔奴围困，冰锁正在调息、狭窄洞穴中风系魔法威力受限，魔奴还懂得砸碎爬上双脚的冰霜，她被迫后撤并后悔没等莫凡。莫凡借遁影穿梭而至，千钧雷印怒击把死追穆宁雪的魔奴轰成焦黑烂肉，穆宁雪眼中闪过悦色飘回他身旁。随后莫凡玫炎烈拳轰天一拳填满狭窄通道，六只魔奴反身逃窜也尽数化灰，无需赵满延宋霞那样的组合铺垫。穆宁雪看着自信飞扬的莫凡心中涌起涟漪，想起少女时期懂的道理——具备足够实力才有自己选择的权力，原本以为两人会形同陌路，却在同辈实力顶峰相遇。两人借余火发现洞穴转角通向其他巢穴，继续深入。主隧道十五人疲于应付前后夹击、两端尸体成堆，宋霞一拳灭掉四只；魔奴群突然慌乱，莫凡与穆宁雪竟从敌群后方杀出，烈拳地煞与冰锁碾骨冰火合击，集中扎堆的魔奴少说阵亡一二十只。攻守易形，被夹击的变成魔奴群，全队士气高涨前后合围狂轰。

**关键事件**：1.穆宁雪孤军深入陷入七只魔奴围困，后悔没等莫凡 2.莫凡遁影赶到雷火连发救场，穆宁雪对其刮目相看 3.二人绕到魔奴大军后方冰火合击，全队反守为攻

**逐章写法公式**：

- **情绪流向**：起：紧张（穆宁雪被围被动） → 承：爽（莫凡雷火救场） → 转：甜（穆宁雪心起涟漪） → 合：爽（敌后合击攻守易形）
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：围困强手（危机）+ 雷火救场（爽点）+ 情感涟漪（缓冲甜点）+ 敌后合击（大爽点收束）
- **本章核心技巧**：用"被围者视角→援军视角→旁观队伍视角"的三重视角切换，把一场救场戏拆成两波情绪（先救美人、再救全军）
- **卡点与伏笔**：结尾卡点：无硬卡点，合围狂轰收尾留酣畅余韵；埋设/回收伏笔：洞穴转角通向其他巢穴→魔奴巢穴结构线、莫凡遁影位移能力→后续战术牌
