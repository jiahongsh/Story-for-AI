# 第1327章 利用内奸

**概要**：灵灵请心夏让姐姐恢复一会神智，心夏提醒恢复意识会加快生命凋谢。灵灵分析出审判会有内奸、信息会被截获，杀手殿杀姐姐的真正目的不是取她性命，而是阻止冷爵的情报传回审判会总部，于是定下引蛇出洞之计：让冷青以审判长身份向灵隐审判会发出唯有审判长才知道的魔法密码文，宣告情报已委托莫凡等人送回，杀手就一定会主动找上门来。心夏以祝福之音与心灵系魔法助冷青恢复神智，冷青吃力地发出密码文，莫凡掌心的黑色之花随之少了两朵花瓣。冷青在清醒的短暂时光里回想自己与黑教廷斗争的往事，觉得用死亡换一位红衣主教的情报值得，只是把所有的伤留给了年幼的灵灵，一滴黑色泪水滑落。另一边，冷爵对窗台上挂着的叛徒尸体大发脾气，骂卑匠办事不利——人明明没死却谎报已杀，深紫色旗袍美妇劝他再给卑匠一次机会，并向黑暗角落里浮现的卑匠下令：为冷青传信的人叫莫凡，撒朗都在他手上吃过亏，若能杀死他冷爵会对你刮目相看。

**关键事件**：1.灵灵定下利用内奸引杀手主动上门的引蛇出洞之计 2.冷青以审判长身份发出密码文，花瓣少了两朵 3.冷爵因情报外泄暴怒，命卑匠改杀莫凡

**逐章写法公式**：

- **情绪流向**：起：唤醒姐姐的请求与代价 → 承：引蛇出洞的计策与密码文 → 转：花瓣凋落、冷青遗言式回望 → 合：反派定计杀莫凡的钩子
- **节奏配比**：慢铺垫 20% / 快冲突 15% / 爽点爆发 20% / 悬念留白 45%
- **本章结构公式**：灵灵定计利用内奸（出谋） + 密码文传递引敌（执行） + 冷青遗言回望（抒情） + 冷爵布局杀莫凡（反派视角钩子）
- **本章核心技巧**：正反两线并行推进，一方引蛇出洞、一方怒而布局，读者同时掌握两边的下一步棋
- **卡点与伏笔**：结尾卡点：悬念型——卑匠受命杀莫凡、且疑惑冷青为何没死，他何时出手、灵灵的诱饵计划能否钓出他；埋设/回收伏笔：内奸与信息截获 → 引蛇出洞策略的支点；冷青的魔法密码文 → 杀手必须上门的诱饵；撒朗曾在莫凡手上吃亏 → 卑匠对莫凡的重视程度
