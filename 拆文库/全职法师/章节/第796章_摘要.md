# 第796章 噩梦间

**概要**：望月千熏断定制造骚乱的哥哥必被关入噩梦间，莫凡舍命相陪。二人穿过狭窄怪异的走道下到地下花瓶状地厅，发现四名中阶守卫把守，莫凡仗暗影系能力自认可一口气制服三人，由望月千熏对付最远端一人。地厅仅靠微弱烛火照明，莫凡化作影子贴顶贴近守卫，因怕光系法师而在百米外试探。守卫山治察觉黑暗气息异常，同伴却归咎黑暗大阵波动。壁灯接连熄灭引起警觉时，莫凡六柄梨刺从天花顶飞下钉住三人，最远端守卫欲按警报器，却被望月千熏的灰蓝桔梗鬼木手夺下警报器并缠裹成木蚕茧。

**关键事件**：1.望月千熏说明噩梦间机制并定下潜入计划 2.地厅遭遇四名中阶守卫，二人分工 3.莫凡暗影贴近，借壁灯熄灭的空档突袭 4.望月千熏用鬼木手夺警报器制服最后守卫

**逐章写法公式**：

- **情绪流向**：起：二人决定潜入的决意 → 承：地厅探查与分工的加压 → 转：壁灯熄灭、突袭成功的爆发 → 合：制服四守卫的短暂余波
- **节奏配比**：慢铺垫 40% / 快冲突 45% / 爽点爆发 10% / 悬念留白 5%
- **本章结构公式**：说明噩梦间（定目标） + 下探地厅遇守卫（加压） + 莫凡暗影试探（制造紧张） + 双线突袭制服（解决）
- **本章核心技巧**：先立行动规则（警报器机制）再让角色在规则缝隙中破局，用信息差制造紧张
- **卡点与伏笔**：结尾卡点：四守卫被制服，下章期待进入噩梦间见鹤田；埋设/回收伏笔：灰蓝桔梗鬼木手 → 呼应一蒂双花灵种
