# 第1732章 自以为是的蠢男人

**概要**：莫凡与蒋少絮斗嘴，蒋少絮以手握一个更大的秘密吊他胃口，要求他叫姑奶奶才肯说。莫凡先嘴硬说有小灵灵和神鹿图腾之纹不愁找不到下一个图腾，被灵灵一句"我这里没什么线索"打脸后立刻改口叫姑奶奶。蒋少絮讲述哥哥蒋少军约十年前给她讲的都是亲身经历，蒋少军是一名记录者，发现并记载了很多图腾却不打扰它们。蒋少絮透露下一个与霸下有关的图腾也是圣兽图腾的一部分，灵灵质疑玄武只由玄蛇与霸下组成，蒋少絮说玄武不止两者。赵满延恍然大悟神鹿对自己不管用是因为图腾牌子不对，霸下让他找的是同一圣兽牌子的图腾。莫凡说神鹿图腾之力比老月蛾凰赐予的还庞大好几倍，足以送自己进超阶。蒋少絮拒绝说出下一处图腾的位置，要等时机成熟再一起出发。

**关键事件**：1.蒋少絮透露蒋少军是以记录者身份亲历图腾之事 2.蒋少絮点明下一个与霸下有关的图腾同属圣兽，玄武不止玄蛇与霸下 3.蒋少絮拒绝公布下一处图腾位置，约定时机成熟一起出发

**逐章写法公式**：

- **情绪流向**：起：斗嘴轻松 → 承：秘密吊胃口 → 转：神鹿收益对比 → 合：半揭半藏钩子
- **节奏配比**：慢铺垫 70% / 快冲突 0% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：斗嘴引子（立人物关系） + 蒋少军记录者真相（补设定） + 玄武多图腾信息（扩世界观） + 蒋少絮保守秘密（拉高下章期待）
- **本章核心技巧**：用轻松的斗嘴承载关键设定投放，信息量大但靠人物性格差异消解枯燥
- **卡点与伏笔**：结尾卡点：悬念型，蒋少絮握有下一个图腾的线索却不肯全盘说出，下章期待其位置与出发；埋设/回收伏笔：霸下所指的遗失封印之力→指向同一圣兽的其他图腾；神鹿图腾之力→铺垫莫凡冲击超阶
