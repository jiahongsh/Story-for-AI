# 第1547章 岩岗之鲸

**概要**：海蒂质问瓦尼，瓦尼撕破脸皮与欧洲学府学员站在一边，自称顾全大局。莫凡与瓦尼单挑，瓦尼以超阶土系岩鲸连击莫凡，莫凡被岩鲸撞碎铁厂房击飞。海蒂被费列罗、加尔巴、娑法、佐薇四人围攻，靠一心三用抵挡。莫凡以雷系暴君荒雷施压瓦尼，趁机布下黑魔潭将二人困于黑暗沼泽，废掉瓦尼土系在地底穿梭的优势。瓦尼困于黑魔潭无法脱身，转而动用冰系魂尘，与莫凡对峙。

**关键事件**：1.瓦尼撕破脸皮，以超阶岩鲸连击莫凡 2.海蒂被欧洲学府四人围攻，一心三用苦战 3.莫凡用黑魔潭困住瓦尼，废其土系优势，瓦尼转用冰系

- **情绪流向**：起：摊牌开战的对峙 → 承：岩鲸连击的压制 → 转：黑魔潭困敌的翻转 → 合：瓦尼亮冰尘的变数
- **节奏配比**：慢铺垫 5% / 快冲突 65% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：撕破脸皮（摊牌） + 岩鲸轰击（超阶压制） + 黑魔潭困敌（翻转局面） + 冰尘亮底（再添变数）
