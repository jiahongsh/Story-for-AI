# 第198章 心有天使

**概要**：灵灵跑到舞台边，看到满脸血的莫凡忍不住红了眼圈，救援队的治愈系女法师为他疗伤，深可见肉的伤口以肉眼可见的速度愈合，莫凡还笑问会不会毁容。同样在三楼对付了二十多只女妖、负伤的赵满延赶来，莫凡让他去领杀母妖的功劳，交换一颗雷系灵种；赵满延讲了青校区实为外院、实力达标可考主校区、三万学员为此拼命的规则，自知有愧良心仍接受交易。灵灵不平地质问，莫凡解释灵级雷种太贵买不起，要为两年后的猎人争霸拼命提升实力、一定要拿头奖；灵灵指出头奖翼魔具不如盾铠斩魔具实在，莫凡不解释，灵灵便说每个人总有想要变强的理由。莫凡躺在担架上望着被巨兽踩坏的穹顶夜空，心想心里有一位天使，怎能让她没有翅膀。

**关键事件**：1.莫凡伤愈，与赵满延达成让功换雷系灵种的交易 2.莫凡说出目标：两年后猎人争霸夺头奖翼魔具 3.借心有天使点出变强动机收束

**逐章写法公式**：

- **情绪流向**：起：温馨（灵灵落泪、治愈疗伤）→ 承：轻松（让功交易与斗嘴）→ 转：热血（猎人争霸宣言）→ 合：温馨（心有天使望星空）
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：疗伤叙旧（收余波）+ 让功交易（立目标）+ 争霸与翼魔具问答（立动机）+ 天使意象收束（留余韵）
- **本章核心技巧**：战后文戏用一桩以名换利的交易，同时完成人物取舍展示和长线目标埋设。
- **卡点与伏笔**：结尾卡点：留白（天使是谁不点名，翼魔具执念留悬念）；埋设/回收伏笔：雷系灵种之约 → 回收让功交易并指向拍卖会；两年后的猎人争霸 → 长线大赛伏笔；翼魔具头奖 → 天使动机线。
