# 第203章 千万身价的男人

**概要**：莫凡一夜获利2900万，买下精魄的竟然是白家。白藏锋离场路过莫凡时嘲讽很多东西是他这种人这辈子弄不到的、等有了星云魔器修为可轻松碾压他，莫凡故意装怂应付；只有赵满延知道白家的2900万直接进莫凡口袋，笑到不行，白藏锋还自以为家底雄厚。莫凡继续守拍，以1700万拍下能轻松挡战将级全力一击、关键时能射棱刺反击的冥离盾，又问过两千万级的斩魔具后作罢，还得知血兽靴残值约1200万。卖精魄买魔具后余1200万，加存款310万约1510万，他决心换掉要公交转地铁的郊区安置房。学期末临近，下学期唯一的考核是主校区考核；莫凡规划火雷星云升二级、以唐月老师的烈拳·九宫为目标、暗影系学自描星图、召唤系冲中阶。学校里专门针对他的反莫凡社团日渐壮大，莫凡以强者越强自勉。

**关键事件**：1.白家2900万买走莫凡的精魄，白藏锋浑然不知还放话碾压 2.莫凡1700万拍下冥离盾，身家约1510万决意换房 3.确立主校区考核与猎人争霸双目标，反莫凡社团浮出

**逐章写法公式**：

- **情绪流向**：起：爽（2900万入账）→ 承：搞笑（白藏锋冤大头放话）→ 转：爽（买盾算账千万身价）→ 合：热血（双目标与强者越强宣言）
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 35% / 悬念留白 20%
- **本章结构公式**：冤家买货（讽刺爽）+ 装备采购（实力结算）+ 换房算账（身份跃迁）+ 目标清单与仇敌社团（蓄下阶段）
- **本章核心技巧**：让仇敌的家族无意中花巨资买下主角的战利品，用三层信息差叠出讽刺爽点。
- **卡点与伏笔**：结尾卡点：蓄势（主校区考核加反莫凡社团，下阶段战场预铺）；埋设/回收伏笔：冥离盾 → 装备升级回收鳞皮母妖之资；烈拳·九宫 → 唐月老师线目标；赵满延下学期要搬出去住 → 引出莫凡换房合租。
