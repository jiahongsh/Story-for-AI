# 第540章 三巴掌！！

**概要**：烈拳九宫爆发后，许明聪一方的盾魔具和铠魔具均被瓦解，比赛场地与结界都受冲击。顾剑看出莫凡火系玫炎的威力提升与雷系千钧附带的空间震荡，使同样的中阶魔法产生更强破坏；莫凡一方随后获胜。艾图图兴奋亲了莫凡，又坐回原位向顾剑示意自己并非败因。许明聪不服离场，顾剑仍须依赌约爬到艾图图面前，被她连扇两巴掌；她正要打第三掌时，手腕被人握住。

**关键事件**：1.烈拳九宫瓦解敌方全部防御，比赛判定莫凡一方获胜。 2.顾剑辨认出莫凡两种灵种带来的强化效果。 3.顾剑履行赌约爬行，遭艾图图连扇两掌，第三掌被阻止。

**逐章写法公式**：

- **情绪流向**：起：热血 → 承：爽 → 转：轻松 → 合：悬念
- **节奏配比**：慢铺垫 20% / 快冲突 20% / 爽点爆发 45% / 悬念留白 15%
- **本章结构公式**：火系收尾（确认胜势） + 灵种复盘（解释差距） + 裁判判胜（落实结果） + 赌约掌掴（兑现冲突）
- **本章核心技巧**：战斗结束后先用旁观者复盘补充设定，再把前置赌约转化为具象的公开惩罚。
- **卡点与伏笔**：结尾卡点：第三巴掌将落未落+陌生人握住艾图图手腕+等待阻止者身份和反应；埋设/回收伏笔：顾剑爬行赌约→顾剑当众履行并承受艾图图的掌掴。
