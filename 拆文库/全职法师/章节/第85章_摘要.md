# 第85章 天生双系！

**概要**：雷印轰出后全场死寂许久，观礼的博城大人物与同学们都怀疑自己眼花，周姓男子站起质问谁能解释。薛木生先猜莫凡是觉醒了第二系的中阶法师，朱校长却断定他仍是初阶，并激动到肌肉颤抖地说出结论——莫凡是世上极罕见的天生双系，觉醒了火系又觉醒了雷系。消息炸开后，军部首领斩空扬言谁敢抢就抄家，大魔法协会的杨作河、朱校长也当面争抢这名学生。穆卓云对比女儿穆宁雪的灵品冰种后同样动了心思，态度一百八十度转变，主动扶起莫家兴好言安抚。莫家兴从宾客们的争抢中明白儿子足以轰动博城，喜极而泣站起身，也懂了儿子先前叫自己站起来的原因：从此不必再向任何人屈膝卑躬。

**关键事件**：1.朱校长当众断定莫凡是天生双系 2.军部、魔法协会、校方三方当面争抢莫凡 3.穆卓云态度转变扶起莫家兴

**逐章写法公式**：

- **情绪流向**：起：错愕呆滞 → 承：真相揭晓震撼 → 转：三方争抢哄抢 → 合：父亲落泪翻身
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 40% / 悬念留白 10%
- **本章结构公式**：旁观者反应层铺陈呆滞（蓄势）+ 朱校长断言天生双系（揭底）+ 三大势力当面争抢（放大价值）+ 穆卓云转变扶起莫家兴（情感回扣）
- **本章核心技巧**：用层层叠加的旁观者失态放大同一信息的冲击力，再让多方势力争抢把天赋价值具象化成价格
- **卡点与伏笔**：结尾卡点：三方争抢未定归属+魔法高考将近，留下莫凡去处悬念；埋设/回收伏笔：穆宁雪灵品冰种与天生双系对比（双天才并立铺垫）、莫家兴"不必再屈膝"（父子线）、薛木生回忆不起觉醒当天情形（双系来历存疑）
