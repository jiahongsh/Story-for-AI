# 第81章 火滋，爆裂！！

**概要**：朱校长以连脸都冻住呼吸会停止、有生命危险为由要求终止，穆卓云笑着担保火系学生没那么容易在冰雪下死亡，宾客纷纷恭贺；朱校长再催邓凯叫停时，邓凯却在茫茫冰雪中看到一团兀然闪耀的炙热火焰，打消叫停念头说出这莫凡恐怕没我们想象的那么简单。朱校长以强大感知力捕捉到火团燥热狂暴的元素气息，确认这不是二级的火滋·焚骨，小小火团的穿透力与炙热度无与伦比。火滋落在宇昂面前，宇昂不屑地唤醒盾魔具冰埃之盾护住全身，看台上有人叹息零元党斗不过人民币玩家；莫凡高喝火滋·爆裂，火团毫无征兆猛烈炸开，一圈圈火浪向周围翻滚，波动一直传到宾客坐席。满场看得目瞪口呆，认出这是三级火系技能，徐大荒惊觉自己年近三十才费尽心思突破的绝学被一个没毕业的高中生掌握，朱校长邓凯感叹多年未见毕业前掌握三级技能的学生，杨作河、周明军、罗云波当场开口争抢莫凡。

**关键事件**：1.朱校长两度要求终止决斗被穆卓云挡下 2.莫凡火滋·爆裂炸碎冰埃之盾轰飞宇昂 3.杨作河周明军罗云波当场争抢莫凡

**逐章写法公式**：

- **情绪流向**：起：压抑（叫停危机与恭贺声）→ 承：紧张（冰雪中的异样火焰）→ 转：爽（爆裂炸盾轰飞宇昂）→ 合：爽（行家失态三方抢人）
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：叫停危机（拉紧张）+ 感知确认异样（吊胃口）+ 爆裂炸盾（引爆）+ 行家失态抢人（余波扩爽）
- **本章核心技巧**：把底牌揭晓切成发现异样、感知确认、盾牌嘲讽、爆裂打脸四拍，让三级火滋的冲击力逐层放大。
- **卡点与伏笔**：结尾卡点：实力曝光型——更大底牌尚未全亮，各方争抢升温；埋设/回收伏笔：灼烧自有妙用（前章）→ 兑现为三级爆裂；徐大荒的绝学对比 → 量化技能稀有度；三方争抢 → 为莫凡赛后身价与穆氏难堪埋线。
