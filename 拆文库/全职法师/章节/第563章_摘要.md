# 第563章 风……风盘！

**概要**：爬行鬼尸窜出抓住一名青年拖出数米，几个鬼尸扑上将他撕啃得血肉横飞，另两名青年逃回村时一人双臂被两侧腐尸分扯。洪俊满身血口逃回围栏，与先前意气风发的模样判若两人，谢桑以水御护住他，村民才知村落周围遍布变种亡灵，井水神庇佑似已失效，自比落入狼领地的绵羊。张小侯揪住洪俊追问苏小洛下落，得知她在后面便扔开洪俊冲出围栏；苏小洛以香药引开亡灵安然返回，拉他跑回村子，却发现村内木屋道上鬼尸正撕食村民，灰木围栏也拦不住。村民一个个倒下，苏小洛哭颤着跪在泥水中质问神明，张小侯呆立呢喃风字，脚下断断续续描起浅青色星轨，终于施出风盘，漫天雨幕被扭成水龙飓风，卷入的亡灵与木头碰撞烂成一片，却一个村民都没伤到。

**关键事件**：1.鬼尸屠戮青年村民 2.井水神庇佑失效全村恐慌 3.张小侯风盘灭尸护村民

**逐章写法公式**：

- **情绪流向**：起：鬼尸屠戮青年 → 承：洪俊逃回全村恐慌 → 转：苏小洛折返见村内屠杀 → 合：张小侯风盘惊天救场
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：鬼尸屠戮（惨烈导入）+ 洪俊逃回庇佑失效（恐慌升级）+ 苏小洛折返见尸（绝望顶点）+ 张小侯风盘救场（反转高潮）
- **本章核心技巧**：让最被轻视的角色在最绝望时刻爆发出最强力量，完成身份反转。
- **卡点与伏笔**：结尾卡点：风盘绞杀亡灵、张小侯法师身份暴露；埋设/回收伏笔：张小侯脑部记忆障碍与风盘 → 其身份与过去；井水神失效 → 诅咒真相
