# 第642章 引蛇出洞（下）

**概要**：穆白进入永盛茶庄，薛藏把他带到能俯瞰钟楼的阁楼。穆白先以寒暄试探，再谎称莫凡等人已经前往博物馆考证地圣泉与昆井之水的关系。薛藏听到地圣泉可能仍在莫凡手中，立即表现出关注并借口离开。阁楼内，穆白想到自己若判断错误，所有高层将陪撒朗殉葬；若判断正确，母亲、同学和朋友也可能被卷入死亡，但他仍选择引蛇出洞。另一边，薛藏与虎津确认没有禁卫法师跟随，担心地圣泉让亡灵沉寂一天以上，虎津因此痛骂曾经多次失手的宇昂。

**关键事件**：1.穆白进入永盛茶庄 2.薛藏探问博物馆和地圣泉 3.穆白完成假消息投放 4.穆白承受两种结果的压力 5.虎津决定重视地圣泉线索

**逐章写法公式**：

- **情绪流向**：起：避难伪装 → 承：双方试探 → 转：地圣泉诱饵被接收 → 合：穆白承担选择，虎津准备行动
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：进入茶庄（建立伪装） + 递出假消息（测试敌人） + 薛藏离开（触发行动） + 虎津研判（锁定后续目标）
- **本章核心技巧**：用平常亲戚寒暄包裹高风险试探，再切换到敌方密谈验证诱饵是否生效。
- **卡点与伏笔**：结尾卡点：虎津确认地圣泉可能改变战局并再次提到宇昂，下一章期待他亲自现身；埋设/回收伏笔：薛藏与穆贺联系 → 作为虎津接收博物馆消息的渠道。
