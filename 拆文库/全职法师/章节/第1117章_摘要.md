# 第1117章 搏命生存之道！

**概要**：莫凡对队友言明鱼死网破之策，英国进攻性强于希腊，中国全员魔具频出硬抗；艾江图、穆婷颖、官鱼三人专攻希腊队员，往死里打以求换重伤。莫凡只盯阿莎蕊雅疯打，哲罗乐得坐山观虎，希腊渐露不支。阿莎蕊雅识破哲罗放水，令全体暂撤停攻中国，明白再打便是中英蚌相争英得利。人员更换规则交代：每十五分钟可换，期间无人在场即判出局，新员随机传送。希腊新员将入场，英国寻落单未果。穆宁雪、南珏上场与三人会合，南珏以音系探知希腊落单新员极近，众人决意灭之。

**关键事件**：1.莫凡率队与希腊搏命换伤，逼阿莎蕊雅暂撤 2.三方混战更换规则交代，新员将入场 3.穆宁雪南珏上场，南珏探知希腊落单新员

**逐章写法公式**：

- **情绪流向**：起：莫凡鱼死网破令的下 → 承：中希搏命换伤的加压 → 转：阿莎蕊雅暂撤的转折 → 合：新员落单被探知的钩子
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：搏命令下（设策） + 中希换伤（加压） + 阿莎蕊雅暂撤（转折） + 更换规则（铺陈） + 探知新员（钩子）
- **本章核心技巧**：用"宁可自损也要换敌伤"的突围策略，把被动挨打变成主动破局
- **卡点与伏笔**：结尾卡点：众人扑向希腊落单新员，下章风水轮流转围殴；埋设/回收伏笔：南珏音系探知→后文多次定位关键
