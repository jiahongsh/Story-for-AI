# 第117章 神奇治愈系

**概要**：莫凡将心夏抱上轮椅后忽然一阵头晕，从地圣泉出来到现在他没怎么休息、伤口没有及时处理、精神疲惫不堪，担忧这种状态无法再施展消耗魔能的中阶魔法。心夏发现他手臂那条触目惊心的伤口只被布随意包扎、根本止不住血，让他把手臂枕在自己大腿上；她的双腿无病无残、精致如艺术品却天生没有力气，能走几步便气喘，医院查不出原因、更昂贵的医院又去不起，只能耽搁着。随后一股奇异能量从心夏身上升起，圣洁的乳白色出现在指尖，她闭眼将交叠的小手掌覆在莫凡伤口上，乳白色能量像生命精灵般编织损坏的肌肉、重新接上血管，伤口如拉链拉合般肉眼可见地愈合且不留疤痕——这正是治愈系的力量。莫凡记起心夏是整个博城唯一第一系就觉醒治愈的人，治愈属白魔法，往往要到中阶法师中才能找到治愈法师；治愈的温泽还驱散了他的失血眩晕。他问若被割喉能否救回，心夏答"生命在瞬间流逝的话，治愈是没有用的"。心夏手掌扫过他全身，淤青碰伤尽数愈合，莫凡完好如初，还开玩笑要合开去疤痕整形医院。他惊喜发现星云中的魔能也恢复了一些，还能施展中阶魔法离开。

**关键事件**：1.心夏以治愈系瞬间愈合莫凡的重伤与失血 2.补全心夏腿疾与治愈系稀有度的设定 3.魔能恢复，莫凡具备再战中阶的资本

**逐章写法公式**：

- **情绪流向**：起：温馨（枕腿疗伤）→ 承：轻松（能力展示）→ 转：温馨（全身治愈与玩笑）→ 合：轻松（魔能恢复）
- **节奏配比**：慢铺垫 40% / 快冲突 0% / 爽点爆发 30% / 悬念留白 30%
- **本章结构公式**：发现失血（弱点）+枕腿疗伤（关系递进）+能力展示与边界（设定）+魔能回充（续航恢复）
- **本章核心技巧**：战后整备章用"治伤"同时完成感情递进、设定投放、资源回充三件事
- **卡点与伏笔**：结尾卡点：莫凡尚余中阶战力但城内妖魔遍地，回程之路未知；埋设/回收伏笔：心夏第一系觉醒治愈（前文）→本章实战兑现；心夏腿疾无钱医治→翼魔具与赚钱动机留待后文
