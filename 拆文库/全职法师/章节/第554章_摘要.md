# 第554章 消失的羊阳村

**概要**：一行人路过咸池，看见亡灵拾取吸纳月华与死泽能量的白色细沙，胡须随从以为灰蒜在手亡灵不过如此，矮男解释灰蒜比金子难找、无法种植、靠死人肉做养分，唯有危居村人懂得采摘。众人按地图抵达羊阳村所在山坡，山下却只有烧毁的木头堆与黑色泥土，整座村落消失无踪，壮男发疯般冲下山坡也找不到一间茅屋。柳茹对照地图确认位置无误，众人推测村民多半遭了亡灵暴乱，尸体也化作了亡灵。灰蒜即将耗尽而华村尚有两日路程，矮男提议折返古都补给，壮男称再弄到灰蒜要几个月，大胡须随从主张直接闯，黑丝女子建议省用灰蒜、遇亡灵过多再吃。众人行出三四里，一只拿岩石磨牙的腐尸嗅到人肉香扑向黑丝女子，胡须随从阿力用冰锁将其五花大绑、碾骨勒碎。

**关键事件**：1.羊阳村整村消失只剩焚烧痕迹 2.灰蒜告急引发去留争执 3.阿力冰锁碾骨击杀袭击腐尸

**逐章写法公式**：

- **情绪流向**：起：沙地赶路松懈 → 承：村庄消失惊疑 → 转：灰蒜告急去留争执 → 合：腐尸夜袭、冰锁碾骨
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：沙地赶路立设定（灰蒜稀缺）+ 羊阳村消失（悬念升级）+ 灰蒜告急争论（决策冲突）+ 腐尸夜袭冰锁碾骨（小高潮）
