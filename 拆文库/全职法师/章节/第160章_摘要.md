# 第160章 战全系

**概要**：莫凡的宣言让空气凝固，全院上万师生认定他疯了，纷纷质疑召唤系连50人指标都没达到凭什么灭150人。罗宋气恼今日风头全被抢走，暴躁学生起身要冲进铁笼，有城府的人则等着看隐藏的中阶强者收拾他。莫凡站在场中央听着上万人雷鸣般的骂声，回想唐月老师说过天生双系没有庞大资源便一事无成，又想到进阶期幽狼兽冲击战将级远非一瓶炼兽之血可满足，认定输了顶多挨骂、赢了盆满钵溢，唤幽狼兽今天哥俩战个痛快。五千新生的怒火被点燃，入口人满为患；首批五人进场，叫龙傲天的学员话说一半就被幽狼兽一巴掌拍飞五六米，莫凡让幽狼兽手下留情追着其余人跑。他连送一批批挑战者，站在原地等待真正的强者。

**关键事件**：1.宣言引爆全校怒火与围攻 2.莫凡自述夺资源的动机与成本盘算 3.龙傲天五人组被瞬间击溃 4.莫凡连送多批挑战者等待强者

**逐章写法公式**：

- **情绪流向**：起：紧张（万人凝固的敌意） → 承：热血（动机独白与哥俩宣战） → 转：爽（龙傲天一巴掌拍飞） → 合：紧张（等待真正强者的钩子）
- **节奏配比**：慢铺垫 45% / 快冲突 25% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：全场反应层（立敌意规模） + 动机独白（给狂言上保险） + 杂鱼团灭（立门槛落差） + 等待强者（给上升空间留口）
- **本章核心技巧**：大宣言之后不急着打高手，先用动机独白稳人设、再用送人头的杂鱼垫爽点，为真高手对决蓄满落差。
- **卡点与伏笔**：结尾卡点：等待式钩子+莫凡站在原地等真正的强者跳出来，下章期待首个高手；埋设/回收伏笔：唐月的双系资源论→莫凡烧钱人设的长期依据；隐藏中阶强者的传闻→庄离风、白藏锋、牧奴娇的出场铺垫。
