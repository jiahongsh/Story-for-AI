# 第551章 活人、死人

**概要**：莫凡与柳茹住进古都公寓酒店，夜里登上外城墙观察亡灵来袭，为次日出城做心理准备。两人看见亡灵从墓穴苏醒、闻到活人气味后集结冲击城墙，守卫法师用多系魔法阻止其攀墙。被守卫赶离时，莫凡望见远方巨大魆影统领成片亡灵，整夜难忘活人与死人之间的战场。次晨战斗声消失，柳茹随口担忧城墙失守，被楼下老住户斥责。莫凡和柳茹随后到外南门与矮男会合，发现队伍里已有几人，其中戴黑丝面纱的女子格外醒目。

**关键事件**：1.莫凡与柳茹夜登外城墙目睹亡灵攻城。 2.远方巨影号令亡灵，莫凡受到战争震撼。 3.两人次晨赴外南门，与矮男及新队员会合。

**逐章写法公式**：

- **情绪流向**：起：好奇 → 承：紧张 → 转：压抑 → 合：悬念
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：登城观察亡灵防线（适应环境） + 亡灵群冲击城墙（展示危机） + 巨影现身震慑众人（扩大威胁） + 外南门会合见到新成员（引出后续）
- **本章核心技巧**：用城墙内外的人群对照和守卫反应，将背景设定扩写为可见的夜战场景。
- **卡点与伏笔**：结尾卡点：人物悬念，黑丝面纱女子加入出城队伍并引人注意；埋设/回收伏笔：远方巨影与亡灵潮 → 提示古都外存在统领亡灵的强大存在。
