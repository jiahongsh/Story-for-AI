# 第1491章 真正的阿尔卑斯山学府

**概要**：伊迪丝被揭穿后全无悔意，称宁愿每天从尤莱的灵魂躯壳上踩踏而过，众人虽揪出行凶者却无人感到快意。她供出毒咒赫卡萨的缘由：赫卡萨谎称身体不舒服，却要她到房间里相陪。横眉毛的杰西将她拿下押走。莫凡仍觉疑点未清，赫卡萨毒从口入、不知何时被种咒，且伊迪丝并非相关法系却会这些奇异手段。次日清晨，凌长者再度现身闹事，佩里院长一改昨日恭敬，身着素衣与其正面较量，凛然宣称伊迪丝是学府学生、须由圣裁院法律裁决，绝不交给卡萨世族折磨灵魂，学府上下齐声支持，宁与卡萨世族为敌，这才是真正的阿尔卑斯山学府。

**关键事件**：1.伊迪丝供出毒咒赫卡萨的缘由并坦承无悔 2.杰西将伊迪丝拿下押走 3.佩里院长当众对抗凌长者，拒绝交出伊迪丝，坚持由圣裁院审判

**逐章写法公式**：

- **情绪流向**：起：凶手自白的压抑 → 承：疑点未清 → 转：凌长者清晨再闹 → 合：院长硬刚凝聚人心
- **节奏配比**：慢铺垫 40% / 快冲突 35% / 爽点爆发 10% / 悬念留白 15%
- **本章结构公式**：伊迪丝自白押走（了结旧案） + 莫凡留疑点（伏笔） + 凌长者清晨施压（新冲突） + 院长硬刚、学府齐心（主题落点）
- **本章核心技巧**：用院长态度的反转与群像声援，把案件收尾升华为学府精神宣言
- **卡点与伏笔**：结尾卡点：冲突+凌长者退场后学府与卡萨世族的后续碰撞；埋设/回收伏笔：莫凡对毒咒手法的疑问 → 指向伊之纱布局；卡萨世族截人计划 → 下一章押送应对
