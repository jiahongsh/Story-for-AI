# 第1623章 冤家路窄

**概要**：洛茜为接待与赫卡萨同级的祖氏超阶强者祖向天设宴，冷青携莫凡、阿帕丝登门求证竞拍会售出的幼年泰坦巨人之心来历。祖宽立当场冷笑认领该心出自祖氏驻希腊的世家，洛茜则解释卢巴世家只是祖氏在希腊的壳，自己以竞拍会最高价拍下此心。冷青陈述银月泰坦可能玉石俱焚的隐患并请求通报骑士殿，祖家二人拒不负责，冷青严正表态后带莫凡、阿帕丝告辞。牧奴欣起身相送，表明生意留一线的立场，答应托人查泰坦之心来源，随后问起阿帕丝来历。离席后，阿帕丝私下告诉莫凡，宴上有人对她有强烈念头，莫凡以为是祖宽立。

**关键事件**：1.祖向天与祖宽立在晚宴上就泰坦之心来历与莫凡、冷青正面交锋 2.冷青陈述银月泰坦袭城隐患遭祖家拒绝配合 3.阿帕丝点破有人对她有强烈念头

- **情绪流向**：起：晚宴表面客气 → 承：冷青追问泰坦之心、祖家冷笑施压 → 转：莫凡直接质问、双方翻脸 → 合：告辞后阿帕丝低声道破觊觎
- **节奏配比**：慢铺垫 40% / 快冲突 30% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：冷青拦劝（避免冲突）+ 冷青追查泰坦之心（获取信息）+ 莫凡当面质问（引爆冲突）+ 阿帕丝点破觊觎（埋下悬念）
- **本章核心技巧**：用一顿晚宴让多方势力立场与恩怨同时亮相，再以一句反常提示收尾埋雷
- **卡点与伏笔**：结尾卡点：悬念——阿帕丝说有人对她有强烈念头但非祖宽立，下章揭晓真凶；埋设/回收伏笔：银月泰坦袭城隐患、泰坦之心来源、阿帕丝的读心能力
