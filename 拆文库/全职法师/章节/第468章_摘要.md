# 第468章 白沙巨人狂阵

**概要**：阵阵巨响从白沙中炸开，五米高的白沙巨人成排拔地而起，三米沙刀、红瞳嘶吼，几股沙浪同时爆开，沙尘中众人看不清彼此。计划落空——赵满延所在区域的白沙巨人成倍涌出，队列交错攻击。他早叠的三层水御被一刀砍成水珠散落，脸都吓白，幸而及时以光佑-圣盾裹身，仍被连续三波巨砍埋进沙土，只能对着通讯仪大喊救命。心夏想扩散心灵安抚救他，被灵灵拦住——已起杀意的妖兵安抚极难，魔能不能这样耗。心夏咬唇忍住担忧，目光不由转向莫凡那边，幸好那里的白沙巨人远没有赵满延处多，队伍存亡全压在各自阵位上。

**关键事件**：1.白沙巨人狂阵爆发，赵满延处妖兵成倍涌出 2.赵满延三层水御被破，圣盾硬扛三波巨砍 3.灵灵阻止心夏消耗魔能救赵满延

**逐章写法公式**：

- **情绪流向**：起：巨人狂阵爆发 → 承：赵满延独扛成倍妖兵 → 转：水御尽破圣盾续命 → 合：呼救无门，心夏被阻，悬念悬置
- **节奏配比**：慢铺垫 10% / 快冲突 70% / 爽点爆发 5% / 悬念留白 15%
- **本章结构公式**：狂阵爆发（引爆） + 赵满延失守（加压） + 圣盾续命（延命） + 心夏被阻（悬念收束）
- **本章核心技巧**：战斗全程锁在单一角色视角，其他阵位只做一句报数，用偏科视角放大孤立感
- **卡点与伏笔**：结尾卡点：生死悬念型，赵满延在巨人堆中呼救，心夏被阻不能救，下章期待莫凡能否分担；埋设/回收伏笔：白沙巨人懂队列交错战阵 → 战阵类妖魔的设定伏笔；灵灵全局视野 → 队伍中枢功能
