# 第488章 白布人

**概要**：山体洞窟内滚滚熔浆终于有了退潮迹象，闷在洞里的五个人松了一口气，洞窟不大加上熔浆气体时不时飘进来，空气稀薄得差点窒息。等待过程中唯一的庆幸是疾星狼始终没有消失，心夏的眼睛几乎没离开过它片刻，生怕一闭眼它就消失。熔浆流尽、空气从气窟窿溢进来后，五人冲出洞窟顺着熔浆流下的方向往山道下游找莫凡。他们冲到山底却没看见莫凡的身影，反而遇到之前堵住生门的双面龟魔——这种生物成群生活，赵满延刚要算账又出现一只体型更大的铠甲怪物，报仇无望反被追杀，一路逃出火柱山回到岩石沙砾盆地，双面龟魔仍穷追不舍。张小侯担心再被缠住就没了找莫凡的时间，赵满延发现一队人马正在靠近，五人逃到对方面前，为首是个头发倒梳扎辫的中年男子，赵满延惊喜地喊大伯，晨颖神情却格外复杂。赵玉林训斥他们胡闹，赵满延请大伯先解决追兵，赵玉林从代步驯兽上跳下，同时描画多幅星图构建星座，施展土系高阶的石化之力，灰褐色光芒扇形蔓延，冲在最前的双面龟魔瞬间化为硬邦邦的死物，其余龟魔吓得两张脸都白了，弃同伴逃进火柱山。赵满延一脚踢碎石化的龟魔、踩个稀烂泄愤。赵玉林叫住众人，说送他们出去已不可能，要救谁跟他说，灵灵向心夏点头，五人归入队伍。晨颖猛然发现一匹枣红沙漠火马上坐着一个浑身白布缠住的人，那人正用黑眼睛盯着她，竟是她的母亲。白布人点头招呼晨颖却不说话，低声解释沙惘河忽然狂躁，像是西面传来某种不知名的邪力，心灵系法师也无法安抚，各大势力只能挑选等级不高却身怀特殊本领的人渡河，赵玉林恐怕是这次唯一安全过河的高阶法师。

**关键事件**：1.五人逃出火柱山，被成群的石化追杀，恰遇赵玉林队伍 2.赵玉林施展土系高阶石化之力击退双面龟魔 3.晨颖发现队伍里浑身白布缠住的人竟是自己的母亲

**逐章写法公式**：

- **情绪流向**：起：脱困的庆幸 → 承：寻人无果遇群魔的慌乱 → 转：赵玉林石化救场的痛快 → 合：晨颖与母亲相认的震惊与哀恸
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：五人脱困寻莫凡（延续主线）+ 双面龟魔群追杀（制造危机）+ 赵玉林石化之力逆转（爽点）+ 白布母亲现身揭示情报（悬念收束）
- **本章核心技巧**：把逃生、复仇、相认三条情绪线压进一章，用高阶技能的爽点打断追杀节奏，再用身世惨相把情绪拉回沉重
- **卡点与伏笔**：结尾卡点：晨颖母亲随队同寻火劫果实、沙惘河西面邪力成谜，众人能否找到莫凡与果实；埋设/回收伏笔：西面传来的不知名邪力 → 后续沙惘河异变的原因；白布缠身的母亲 → 与火劫果实治愈线相连
