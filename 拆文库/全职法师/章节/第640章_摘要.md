# 第640章 被抹去的记忆

**概要**：山峰之尸踏入北城区，韩寂等人因找不到新办法而陷入绝望。穆白根据母亲提到的宇昂经历，指出叔叔穆贺负责博城灾民安置并把灾难转移到古都。穆贺的名字触发张小侯剧烈头痛，韩寂撕开他的袖子后发现体内潜伏着拇指粗的忘虫。韩寂用治愈精灵蝶压制毒虫，神秘灰白男子解释忘虫会吞吃重要记忆，记忆恢复越多，张小侯离死亡越近。张小侯痛苦中喊出穆贺，神秘男子只能将他打昏，莫凡由此确认虎津大执事就是穆贺。

**关键事件**：1.山峰之尸逼近北城区 2.穆白提到穆贺参与灾民安置 3.张小侯体内发现忘虫 4.忘虫会吞吃重要记忆 5.张小侯喊出穆贺并被强行打昏

**逐章写法公式**：

- **情绪流向**：起：山峰之尸逼近的绝望 → 承：穆白给出嫌疑线索 → 转：忘虫现身并吞噬记忆 → 合：穆贺身份确认，张小侯昏迷
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：外部危机压迫（抬高紧迫感） + 穆白回忆线索（锁定嫌疑） + 忘虫显形（改变认知） + 强行阻断记忆（保住性命）
- **本章核心技巧**：用一个具体身体异物把“失忆”从心理状态转成致命机制，再让线索确认和生命危险同时推进。
- **卡点与伏笔**：结尾卡点：莫凡确认穆贺是虎津大执事，下一章期待引出穆贺并处理软禁高层；埋设/回收伏笔：张小侯听过熟悉声音 → 由忘虫解释记忆缺失。
