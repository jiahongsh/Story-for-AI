# 第315章 烈拳九宫！

**概要**：蒋艺震撼于莫凡在百只蜥颅巨妖环绕下完成突破——军中最胆识过人的法师也不敢在妖魔群中这样做。莫凡让疾星狼退到身边，将全身烈焰收拢凝聚于右腕，以玫炎-烈拳轰向废墟之下，力量达到临界点后嘶吼九宫，方圆一百多米接连炸起九道粗壮火柱呈九宫之阵，成片蜥颅巨妖连同尸体焚成黑色粉末，一只战将级巨亡蜥烧得焦黑仓惶逃走，蜥群一时不敢上前。莫凡乘隙跳上疾星狼，借火烤废墟做跳板、踩着蜥群铺成的肉毯飞驰三秒多跳出包围；随后他收疾星狼回次元位面，在街道死角等来阳光、借楼影施展遁影之术凭空消失。追来的蒋艺只见蜥群反扑向自己一行，推测莫凡还掌握某种隐藏本领，想用追击猎兽追踪却发现自己一行已彻底陷入群蜥。

**关键事件**：1.莫凡首秀烈拳-九宫清场 2.巨亡蜥焦黑逃窜蜥群震慑 3.骑疾星狼背浪飞驰脱围 4.遁影之术凭空消失甩掉蒋艺

- **节奏配比**：慢铺垫 15% / 快冲突 25% / 爽点爆发 45% / 悬念留白 15%
- **本章结构公式**：旁白反应放大（立震撼）+ 烈焰收拢蓄力（延迟满足）+ 九宫火柱清场（爆发）+ 骑狼-收狼-遁影三连逃脱（收尾防拖沓）

- **卡点与伏笔**：结尾卡点：悬念型——蒋艺推测莫凡掌握隐藏本领却无法验证，暗影系信息差延续；埋设伏笔：烈拳-九宫 → 莫凡火系战力新标杆，追击猎兽 → 蒋艺未用出的追踪手段
