# 第324章 蜥群撤离

**概要**：恶魔莫凡爪刃攀上电视塔，塔顶弹跳百余米扑向已飞六七十米高的巨蜥伪龙。伪龙不解退让还遭穷追，吸气鼓成带翅巨球，一口吐出满肚气息——吐息飓风把空中的莫凡拍进居民废区大坑，房屋尽成粉末。莫凡只受皮肉伤便站起；伪龙发现其骨子里的血可媲美统领生物、判断何必招惹，下令全城蜥军撤退，头也不回朝洞庭湖飞去，蜥群如肉毯迁徙、把金林市碾平大半。莫凡感叹这仅是统帅的小族群，比这庞大数十倍的洞庭湖部落不知恐怖到什么程度。另一城区，斩空与陆年鏖战未分高下；陆年转动石化之臂，宣称要给斩空一场城区石化的葬礼，享受地看其逃窜如鹰兔游戏，却发现斩空停步、神情惊愕——斩空提醒他最好看看身后，一个极速驰骋的黑色狂影正越来越近。

**关键事件**：1.伪龙吐息飓风击落莫凡 2.伪龙率全城蜥群撤离金林 3.陆年祭出石化之臂要给斩空石化葬礼 4.黑色狂影逼近陆年身后

**逐章写法公式**：

- **情绪流向**：起：热血（塔顶狂奔扑龙）→ 承：紧张（吐息飓风击落）→ 转：其他（伪龙撤军、余波感慨）→ 合：紧张（石化葬礼与黑色狂影压境）
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 20% / 悬念留白 30%
- **本章结构公式**：追击扑龙（延续上章钩子）+ 吐息反制（受挫立敌规格）+ 撤军与迁徙（大战收束）+ 规模预告（拓世界观）+ 石化之臂（副线反派加码）+ 看看你身后（双线合流钩子）
- **本章核心技巧**：主线大战用"敌方主动撤退"收束避免无限纠缠，同时把镜头切给副线反派压制斩空，用一句提醒让两条线在章末合流
- **卡点与伏笔**：结尾卡点：悬念型——黑色狂影身份未揭、陆年背后遇袭在即；埋设伏笔：洞庭湖部落庞大数十倍 → 下一阶段大舞台，石化之臂魔器 → 斩空危机的筹码，蜥群迁往洞庭湖 → 后续部落冲突引线
