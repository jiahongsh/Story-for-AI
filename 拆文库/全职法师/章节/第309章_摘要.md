# 第309章 蜥颅巨妖巢穴

**概要**：沼泽越来越深，疾星狼凭烂尾楼顶百米冲刺在楼宇间跳跃穿行；追来的军官被冒黑气的泥潭阻挡，女参谋蒋艺令两名土系军法师以地波之术分开泥浆开路，但范围太大只能缓慢推进。莫凡途中遭遇整栋居民楼快速下沉，阳光之下无影可遁，疾星狼险些撞上对面楼墙，靠利爪抓住楼沿才免于坠入下方漩涡中张口等待的二十米巨亡蜥口中。追击的军法师横穿蜥颅巨妖泥潭老巢，用初阶轰炸加中阶交替把一窝妖蜥屠戮干净，训练有素令莫凡心惊。他同时察觉高阶的陆年不知何时从追击行列消失，只剩蒋艺与十三名军官——蒋艺实力中阶巅峰不逊唐月，军官们个个可轻易放出第二级中阶魔法。疾星狼警告前方密布十几个蜥颅巨妖巢穴、九死一生，莫凡咬牙赌命踏入。

**关键事件**：1.楼顶飞渡与下沉楼惊魂 2.军官血洗蜥颅巨妖老巢立威 3.陆年消失、蒋艺率十三军官紧追，莫凡赌命闯巢穴区

**逐章写法公式**：

- **情绪流向**：起：紧张（楼宇飞渡） → 承：恐怖（下沉楼与漩涡巨口） → 转：压抑（追兵碾压立威） → 合：热血（赌命闯巢穴区）
- **节奏配比**：慢铺垫 25% / 快冲突 45% / 爽点爆发 5% / 悬念留白 25%
- **本章结构公式**：地形追逐（跳楼甩追兵）+ 险死还生（下沉楼漩涡）+ 敌方立威（血洗老巢）+ 赌命抉择（踏入巢穴区）
- **本章核心技巧**：用地形规则（泥潭、楼距、阳光无影）同时限制追逃双方，让追逐战变成可见的空间博弈而非单纯比速度
- **卡点与伏笔**：结尾卡点：莫凡踏入十几个巢穴密布的九死一生地带，下章期待巢穴真容与借刀杀人；埋设/回收伏笔：陆年离队失踪→其高阶压场未出、随时再现；蒋艺实力对标唐月→中期强敌标定；二十米巨亡蜥→战将级威胁预演
