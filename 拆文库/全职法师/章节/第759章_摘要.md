# 第759章 以名试毒

**概要**：宫田又向莫凡索问穆宁雪之名，莫凡寒颤迟疑，堆笑称穆宁雪名复杂并反问朋友昏迷发寒之事；山道上的穆宁雪看他如中邪般对空言笑、推演出少女话语，最大的疑惑是为何唯莫凡可见。宫田细声称不知怪病、提及此前有人得怪病，莫凡遂试探承认"赵满延"是昏迷友人、告名后便中招，宫田反问是否疑己，又凄凉笑指莫凡因怕伤穆宁雪才不告名，莫凡坦诚报友名无伤大雅、若危险只报己名。宫田聪明地以"需穆宁雪名作信任佐证"换取出手相助，莫凡为难，穆宁雪得知后主张先避，但当莫凡确认直觉为宫田所为后，穆宁雪决意以身试法、以己名为诱饵，称若无事可逼宫田解赵满延、若出事亦知凶手，并指唯莫凡可见少女故只能自己报名。

**关键事件**：1.宫田索穆宁雪名，莫凡试探确证其与赵满延中招相关 2.穆宁雪愿以己名为诱饵试法 3.莫凡不可替，穆宁雪只能自己报名

**逐章写法公式**：

- **情绪流向**：起：索名寒颤 → 承：试探确认相关 → 转：以名换信博弈 → 合：穆宁雪请缨留悬
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：含糊应对（铺垫） + 试探抛名（加压） + 以名换信（博弈） + 穆宁雪请缨（钩子）
