# 第526章 避开亡灵之法

**概要**：守夜老人说溪水可洗尸毒，但陆红京的腿没有治愈系法师便难好全，众人宿进干草屋一夜无话。天亮村子热闹如常，村堂院中一口大铜箔盛着清水，底部鹅卵石刻着人名，老人解释村里走掉的人都写名沉底，防止他们与外面亡灵为伍。村长自称方谷，被守夜老人称是大法师，他告知勘测队九人来过村提醒一番便去了西面的华村，来时安好。秃顶老头却道从羊阳村到华村要两个白天，意味着队伍必须在外露宿一夜。石少菊恳求村长传授村子在亡灵之地安然无恙的特殊传承，老人们严辞拒绝，方谷松口：村中秘密不能说，但另一法子可以一试，只是出了差池便可能陷入尸群。

**关键事件**：1.村堂铜箔沉名的丧葬规矩与方谷村长登场 2.方谷透露勘测队行踪：九人安好，去了西面华村 3.秃顶老头点破行程需两昼夜，方谷松口传授另一法子

**逐章写法公式**：

- **情绪流向**：起：村中过夜的松懈 → 承：铜箔沉名的怪异 → 转：勘测队线索的意外 → 合：避亡灵之法的松口
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：夜宿晨醒（过渡）+ 村堂规矩（异样）+ 方谷透露行踪（线索）+ 法子松口（钩子）
- **本章核心技巧**：在平静日常里藏异样细节，对话问答间暗渡信息
- **卡点与伏笔**：结尾卡点：方谷松口给法子却预告差池陷尸群，方法为何不能说破；埋设/回收伏笔：铜箔沉名、灰梅、勘测队行踪 → 村庄之谜与失踪案交织
