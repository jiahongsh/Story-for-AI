# 第522章 全图飘红！

**概要**：张小侯边赶路边与莫凡通电话，得知斩空老大提着翼苍狼脑袋回博城后便不知踪影，二人约好有消息互通。队伍踏入咸池，白色细沙原是骸骨风化的粉末，古都安界由时常移动的土墙构成，常有村落被圈到界外，全靠危居一族的避亡灵本领存活，被外国魔法协会称为奇迹之村。队长秦虎宣布首个目的地羊阳村，女军师石少菊提醒太阳将落山，陆红京不屑，秦虎警告此地已被列为橙色地带。妖魔族群分布以绿白橙红紫黑六级标示，古都入夜后安界之外全图飘红。队伍站定安界外，张小侯第一次入亡灵之地，紧张环视时，一双双干枯手臂破土而出，离他不到五米。

**关键事件**：1.张小侯与莫凡通话得知斩空失踪的消息 2.铺陈咸池地貌、古都安界与六色警戒体系 3.队伍入夜站定安界外，尸手破土而出

**逐章写法公式**：

- **情绪流向**：起：电话叙旧的轻松 → 承：咸池地貌的苍凉 → 转：警戒体系的压迫 → 合：尸手破土的惊悚
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：行军对话（人物）+ 地貌安界科普（规则）+ 队伍分歧（预警）+ 破土尸手（钩子）
- **本章核心技巧**：以地图颜色体系为工具把危险等级具象化，再用突然袭击砸碎安全感
- **卡点与伏笔**：结尾卡点：离张小侯不到五米的尸手破土而出；埋设/回收伏笔：全图飘红的安界规则 → 为后文夜行遇袭铺垫
