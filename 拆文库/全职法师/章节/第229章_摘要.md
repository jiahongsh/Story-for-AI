# 第229章 晒照！

**概要**：沈明笑队伍把捕获的暗影妖兽用冰锁锁在废弃仓库，留三名队友看守，他与罗宋去港餐厅吃饭，席间扬言进三步塔后不用关系网就能替罗宋做掉莫凡，还称两家联手不惧白家、牧家。沈林突然来电告知，半小时后莫凡将拖着暗影妖兽出现在驯兽铁笼处，罗宋拨打三名队友电话全部无法接通，两人赶到仓库发现门大开、妖兽失踪、队友昏迷。与此同时，莫凡得到暗影妖兽的消息传遍校园，他竟发朋友圈晒出与被幽狼兽控制的暗影妖兽的合照，近千名毫无头绪的学员涌入驯兽铁笼附近埋伏，藏身处拥挤到熟人尴尬打招呼，沈明笑怒骂要把莫凡泡成肿尸却自知无法与上千学员抗衡。莫凡如期拖着暗影妖兽沿枫树路走向喷泉广场，白藏锋队、贾文清与府天明等各处旁观，无人敢率先动手。

**关键事件**：1.沈明笑仓库失兽，发现被莫凡截胡 2.莫凡朋友圈晒照引来近千学员埋伏驯兽铁笼 3.莫凡拖着暗影妖兽现身，众人围观无人敢先动手

**逐章写法公式**：

- **情绪流向**：起：轻松（反派庆功密谋） → 承：紧张（电话失联、仓库失兽） → 转：轻松（千人埋伏与晒照群嘲） → 合：紧张（莫凡赴会、无人敢动）
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：反派失兽（交代目标易主） + 消息扩散（聚集千人） + 晒照反应（放大莫凡之狂） + 现身赴笼（对峙卡点）
- **本章核心技巧**：全程不见主角抢夺过程，用反派损失、旁观者反应与朋友圈截图三层侧写把"晒照"这一反常行为放大成章末对峙的钩子
- **卡点与伏笔**：结尾卡点：对峙卡点——莫凡拖兽入场、千人围观无人敢先动手，下章期待大混战爆发；埋设/回收伏笔：沈明笑"三步塔内做掉莫凡"的扬言 → 为三步塔篇冲突埋线；沈林动用猎者联盟资源 → 反派背后关系网伏笔
