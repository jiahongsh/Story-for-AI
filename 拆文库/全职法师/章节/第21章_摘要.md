# 第21章 降临学校，穆宁雪

**概要**：年度考核日，张小侯催莫凡赴考，莫凡要再练一会把控、最后一个抵达训练操场。考场由半弧形考官桌和一块西瓜大小、悬浮的黑色星感石构成，学生把手掌放上星感石，考官凭亮度判定一年修炼成果，如高考般决定去留。班主任薛木生激昂动员，柔弱女孩何雨梨花带雨自认要被请离，舍长陆建华拍胸膛安慰反被同学怼。三位政教处考官就位，30个班级1500人列队；校长讲话后校董穆贺致辞，莫凡心中好笑——穆贺什么德性他比谁都清楚。穆贺随即抛出重磅：请到博城最杰出的女魔法师、15岁被帝都学府破格录取的穆宁雪，全场沸腾，流传她觉醒时把脚下地面冻成冰块、8个月学会冰系初阶技能冰蔓、才貌双全。穆宁雪一身雪白高腰紧身裙、雪银中分长发，如天山雪仙女般静立主席台，全校惊寂；莫凡看得出神——这是「出了那件事」后3年来第一次见到她，当年这群孩子口中的小公主已从开朗平易变得难以接近。张小侯叹气说凡哥当初应该带小公主私奔，被莫凡回怼脑子撞厕所门撞傻了。

**关键事件**：1.年度考核开场：星感石考仪规则揭晓 2.穆贺致辞并宣布穆宁雪降临 3.穆宁雪登场惊艳全校 4.莫凡忆起三年前「那件事」后首次再见穆宁雪

- **情绪流向**：起：赶考与考场肃杀（紧张） → 承：何雨垂泪与舍长逞豪（缓冲） → 转：穆宁雪降临全场沸腾（惊艳） → 合：三年再见的怅然（悬念）
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 30% / 悬念留白 25%
