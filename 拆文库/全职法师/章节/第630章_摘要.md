# 第630章 祭祀的猪羊

**概要**：纪念碑后的黑教廷准备杀死莫凡并把柳茹交给手下，张小侯和苏小洛因心念被锁无法提醒。莫凡假装闲谈接近谢桑等人，直接指出村长与黑畜妖勾结，蓝衣女执事随即下令，七八十只黑畜妖从灌木中涌出。女执事带着七名黑衣教士现身，莫凡用言语嘲讽她并命令柳茹反击。面对村民要求莫凡离开、把黑教廷当成救援者的反应，莫凡判断他们并不知道黑教廷的真正目的，决定把蓝衣执事当作博城死难者的祭祀对象。

**关键事件**：1.黑教廷决定处理莫凡 2.莫凡识破谢桑与黑教廷勾结 3.黑畜妖和诅咒畜妖现身 4.蓝衣女执事暴露身份 5.莫凡决定杀死蓝衣执事

**逐章写法公式**：

- **情绪流向**：起：猎杀与受困 → 承：莫凡故意接近 → 转：埋伏爆发与女执事现身 → 合：主角锁定蓝衣执事为祭品
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 20% / 悬念留白 20%
- **本章结构公式**：敌方下令（确定目标） + 莫凡套话（逼出埋伏） + 黑畜妖现身（扩大场面） + 言语挑衅（锁定蓝衣执事）
- **本章核心技巧**：让主角在敌人自以为掌控局势时持续挑衅，以嘴上冲突拖住对方并完成敌方阵容识别。
- **卡点与伏笔**：结尾卡点：蓝衣执事成为莫凡的“祭祀猪羊”，下一章期待正面交锋；埋设/回收伏笔：张小侯等人被心念锁住 → 解释他们无法提醒莫凡。
