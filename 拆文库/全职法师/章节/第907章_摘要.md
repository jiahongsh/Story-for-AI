# 第907章 异变怪物

**概要**：撒朗通讯断后，莫凡知其在逃亡状态不足为惧。柳茹飘回说没找到暴毙毒母，但芳少俪血液心脏异常不像活人；芳少俪解外套露出麦色肌肤，血管爆青、黑包金属乌光——竟以自身为毒母寄体发生异变，狂笑变作七八米黑怪吞吃妖冶男与数人。柳茹血爪仅留痕，莫凡电灾、柳茹血剑皆难破防，毒风将二人打飞，幸恶魔血与血族皆免疫毒性。毒母扑咬，莫凡遁影分身被识破，唤玄蛇铠甲仍被毒牙臂咬住，遂激发雷电掰开毒牙臂。

**关键事件**：1.柳茹报芳少俪血异常 2.芳少俪异变为毒母怪 3.毒母吞吃活人 4.柳茹莫凡合击难破防 5.莫凡玄蛇铠甲被咬

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |

**逐章写法公式**：

- **情绪流向**：起：报异常的疑 → 承：异变吞人的恐 → 转：合击无效的压 → 合：被咬的紧
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 5% / 悬念留白 30%
- **本章结构公式**：报血异常（疑） + 异变吞人（恐） + 合击无效（压） + 被咬续战（紧）
- **本章核心技巧**：用"脱衣"误导后砸异变反转，再用无效攻击写boss压迫
- **卡点与伏笔**：结尾卡点：莫凡如何破防，下章揭晓；伏笔：毒母在芳少俪身内 → 分离才可控
