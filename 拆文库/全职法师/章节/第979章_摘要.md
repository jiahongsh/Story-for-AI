# 第979章 背叛的神殿法师

**概要**：莫凡看着电话根本高兴不起来——就在来电前五秒，同一个号码刚发来"救命"的国际信号。赵满延原本还要调侃，见短信立刻闭嘴。莫凡断定裴历以摄魂控心操控李雨娥，借她之口将自己引入医院陷阱，凭李雨娥平日乐观坚强的性子绝说不出那般孤单话语。穆宁雪提议通知神殿，莫凡与灵灵却摇头：裴历曾是神殿法师，对同僚动向敏锐，神殿一现身他便逃，必须就地在纽约解决。入夜医院人少，正利于驱散，莫凡潜入五楼病房。裴历并不焦急，与李雨娥闲谈中自剖旧怨：他为替上司顶罪被逐出神殿、废除修为，女儿入选帕特农神女殿后却被害，自己无魔法只能眼睁睁看着，是"那人"令他恢复更强魔法，故奉命杀莫凡。李雨娥凭他手背圆疤认出其曾是神殿法师，裴历憎恨称耻辱。通话引莫凡时，莫凡借"你没出去过怎知只有一间病房"的破绽反将一军，早已暗布司夜统治与巨影钉，裴历转身撞窗而逃。

**关键事件**：1.救命短信揭穿摄魂陷阱，拒召神殿决意纽约除患 2.裴历自剖女儿旧怨与背叛神殿之因 3.手背信图被李雨娥认出 4.莫凡借电话破绽反布巨影钉，裴历撞窗逃

**逐章写法公式**：

- **情绪流向**：起：短信揭陷阱的惊 → 承：拒神殿立决心的定 → 转：裴历自白的人性灰度 → 合：电话反杀的爽
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 25% / 悬念留白 30%
- **本章结构公式**：救命短信揭陷阱（破局） + 拒神殿定计（布局） + 裴历自白旧怨（灰度） + 电话反杀逼逃（爽点）
- **本章核心技巧**：用"被忽略的短信+一句反问"做双重反转，把被动引君翻成主动反杀
- **卡点与伏笔**：结尾卡点：追击型，裴历撞窗逃出病房，下章期待莫凡司夜围猎如何收网；埋设/回收伏笔：手背信图 → 回收上章"神殿法师标记"；摄魂控心 → 回收蒋少絮同技能对照
