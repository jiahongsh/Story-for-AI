# 第883章 黑暗仪式

**概要**：旅客与富人们见只是抓些女子，纷纷抱怨回房，一名官员恼怒称审判会、军方、政府、魔法协会都对结界行动不知情，金战猎人团已无法无天。猎人团把束缚女子集中到烧坏的草迷宫，尽是妙龄，卡莉讽刺这不过是富人区潜规则；潘晋恼羞称送审判会，面对官员指责"胡乱影响秩序"只将错就错称"清除不良现象"带走。高处飘窗阁楼，赵品霖与芳少俪俯视这场闹剧，赵品霖赞她耍得团团转。芳少俪耳坠突响，对飘窗半跪称"老师"——那分不清性别的声音正是撒朗，称资深猎人已查到、审判会或盯上此处，令众人混入普通人转移；撒朗更言要拿近战猎人团杀鸡儆猴，显即便自己不在仍支配生死。通讯毕芳少俪跪拜五分钟，唤赵品霖：刚入教便看一场隆重仪式，享受这凄惨嚎叫的夜晚。

**关键事件**：1.官员与卡莉讽刺猎人团闹剧，潘晋将错就错 2.赵品霖芳少俪高处俯视 3.撒朗通讯令混入普通人转移、杀鸡儆猴 4.芳少俪跪拜唤赵品霖看仪式

**逐章写法公式**：

- **情绪流向**：起：官员卡莉讽刺的轻嘲 → 承：潘晋将错就错的荒诞 → 转：高处俯视的暗线冷眼 → 合：撒朗通讯杀鸡儆猴的寒意钩子
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：闹剧收场官员讽（轻嘲） + 潘晋将错就错带人（荒诞） + 高处芳少俪接撒朗令（暗线） + 杀鸡儆猴唤看仪式（钩子）
- **本章核心技巧**：明暗双场景对切——明场闹剧草草收场、暗场大反派隔空下令，用"俯视"视角把两线缝在一章。
- **卡点与伏笔**：结尾卡点：芳少俪唤赵品霖看"隆重仪式"、享受凄惨嚎叫夜，下章期待仪式即毒变爆发；埋设/回收伏笔：撒朗隔空指令 → 本章功能（坐实大反派在幕后，回收古都线）；虎津 → 伏笔（旧部名，后续或回收）
