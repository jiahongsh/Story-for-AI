# 第651章 屠风斩

**概要**：韩寂下令先锋队出击，四位超阶法师从亡灵海中撕开四五百米通道，火系禁卫法师随后以天焰葬礼焚烧地面。禁卫方阵保护莫凡、张小侯、方谷和苏小洛，在风系魔法推动下高速前进。骷髅群和骨臣挡住道路，水系高阶法师用水花天幕包住方阵，化解密集骨兵器攻击。韩寂下令击杀骨臣，暗影力量先将骨臣摧毁，凌溪再以泯风千刃和屠风斩清扫上千骷髅，在亡灵海中劈开一道长长的道路。

**关键事件**：1.四位超阶法师开路 2.天焰葬礼清场 3.禁卫方阵护送小队 4.水花天幕抵挡骷髅群 5.凌溪施展屠风斩清除骨臣和骷髅

**逐章写法公式**：

- **情绪流向**：起：先锋爆发 → 承：方阵推进受阻 → 转：水幕稳住防线 → 合：屠风斩清出长路
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 40% / 悬念留白 5%
- **本章结构公式**：超阶先锋（撕开入口） + 火雨清场（扩大通道） + 方阵护送（保护目标） + 屠风斩（解决骨群）
- **本章核心技巧**：以军团协同替代单个主角硬战，让每一层魔法既解决当前障碍又为下一层推进铺路。
- **卡点与伏笔**：结尾卡点：骷髅海被屠风斩清出数百米道路，下一章将面对尸群；埋设/回收伏笔：水花天幕 → 承接前文高阶水系防御并保护核心小队。
