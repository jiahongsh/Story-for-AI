# 第108章 走出结界

**概要**：薛木生在营地休息时看见莫凡竟走出安全结界，学生们惊呼这辈子都不想再踏出去一步、无法明白是什么给了他勇气。莫凡自认不具备救苦救难的献世之心，连猎妖队长徐大荒的层次都没达到；可一想到连走路都无法做到的心夏深陷妖魔最多的区域、她纯净得不掺人间烟火的眼睛会被恐惧无助填满、会像张英璐那样连一点眷恋机会都没有便消失，他便根本不知道恐惧为何物——有些东西在心里位置早已超越自己，唯有事情真的发生时，决定完全是本能，哪怕搭上性命也义无反顾。纵使队伍断言那个女孩很可能已经死了、前往只是徒劳，他仍斩钉截铁随队奔赴铭文区。八人小队由熟悉博城的徐大荒引路，小可终究未随行，罗云波、潘丽君两位教官同行，博城守护官员、中阶法师程军官亲自带队——人手不足，博城行动的战将级妖魔唯有中阶法师对付得了。队伍沿美鑫高架桥最边缘驾驶暗石发动机的黑色无声摩托疾行，远看如八只黑豹奔跑；程军官感慨召唤兽坐骑更利战斗，可惜召唤系法师各有任务。莫凡借军法师交流补课：魔石驱动的科技设备易引妖魔，法师代步多靠气息与妖魔相似的召唤兽，而召唤系往往中高阶才能觉醒，召唤兽无法普及。临近铭文区时桥梁明显塌方，众人弃车步行，由经验老到的风系罗云波用风轨魔法引开前方妖魔开路——路途漫长、未知数众多，能减少战斗就减少。

**关键事件**：1.莫凡为救叶心夏毅然走出安全结界，随队奔赴铭文区 2.八人精兵小队组建，程军官带队疾行高架桥 3.桥梁塌方弃车步行，罗云波引妖开路逼近铭文区

**逐章写法公式**：

- **情绪流向**：起：紧张（走出结界的惊愕） → 承：压抑（本能论独白与渺茫希望） → 转：热血（八骑疾行高架桥） → 合：紧张（塌方弃车，未知数逼近铭文区）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：出界惊愕（反常立钩）+动机独白（情感正当化）+组队与装备（世界观扩容）+塌方弃车开路（险途推进）
- **本章核心技巧**：先用旁人视角把"走出结界"立成反常事件，再用第一人称本能论把动机从崇高拉回私情，选择因此更可信也更揪心；行军段落顺路完成设定补课。
- **卡点与伏笔**：结尾卡点：推进悬念——八人小队逼近铭文区，叶心夏生死与妖魔入口之战一触即发；埋设伏笔：暗石摩托与魔石引妖设定→装备世界观；召唤兽代步与天鹰→召唤系价值线；桥梁塌方→战将级妖魔活动痕迹；罗云波风轨引妖→风系战术样本；小可未随行→猎妖队留守线。
