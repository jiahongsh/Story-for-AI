# 第762章 器皿妖灵

**概要**：后山荒道漫长、石灯为草所覆，莫凡气头上见草便烧，艾江图阻其放火、以空间之力"碎"扫净荒丛，露出藏于树冠下的古老砖瓦寺堂；莫凡吹去灰尘见堂中陈列一木鱼，弧盖刻满交错古魔文，触之释放亮黄雷丝，蒋少絮称为禁制，南珏辨其为蕴含别力的盾魔具。莫凡忆起唐月所带西湖古阁壁文与之相似，艾江图信南珏能解禁制，众人坐等中南珏全神贯注终停考察，称所见少女很可能是"器妖灵"——魂级器皿沉淀修炼所化、如元素精灵般从强大器皿孕育的生命，木鱼即宫田依附之源、勾魂之根。

**关键事件**：1.后山古寺堂现木鱼魔具，触之雷丝禁制 2.南珏辨木鱼为盾魔具，莫凡联想西湖古阁 3.南珏断少女为器妖灵，木鱼即源头

**逐章写法公式**：

- **情绪流向**：起：后山清场 → 承：木鱼禁制加压 → 转：识货拼图 → 合：器妖灵揭谜
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：入后山清场（铺垫） + 木鱼现禁制（揭示） + 群像识货（拼图） + 器妖灵定论（收束）
- **本章核心技巧**：用"清场→触碰反馈→专家释名"三段把神秘器物与谜底一并交付
- **卡点与伏笔**：结尾卡点：无（谜底收束）；埋设/回收伏笔：木鱼内天地 → 下章展开；西湖古阁文字 → 呼应前文唐月线
