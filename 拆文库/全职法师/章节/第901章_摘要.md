# 第901章 见习蓝衣，周藓

**概要**：莫凡以火滋轰飞一名胖灰衣教士，地煞之炎将其烧成焦尸，余两人借机逃入岔路。莫凡召疾星狼循焦味追踪，不到五分钟截住一名女教士，女教士误认莫凡是审判会人哀求，却被莫凡识破偷施法，疾星狼扑压咬脖将其杀死。循味再追时，祷堂里见习蓝衣执事周藓正跪拜红袍雕塑立誓杀周家人，灰衣力凯仓皇报有闯入者，周藓不屑称无需惊动芳少俪，门外疾星狼驮着莫凡闯入，周藓只轻蔑道一声召唤法师。

**关键事件**：1.莫凡烧死胖灰衣 2.疾星狼追女教士并杀之 3.周藓祷堂立誓 4.力凯报闯入者 5.莫凡狼骑闯祷堂

**逐章写法公式**：

- **情绪流向**：起：烧胖子的爽 → 承：狼追杀女的酷 → 转：周藓立誓的压 → 合：狼骑闯堂的期待
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：轰杀胖子（爽） + 狼追杀女（酷） + 周藓立誓（立反） + 狼骑闯堂（钩子）
- **本章核心技巧**：用召唤兽追踪串起连续猎杀，末尾以轻蔑反派收钩子
- **卡点与伏笔**：结尾卡点：周藓如何应对莫凡，下章开打；伏笔：周藓杀周家 → 身世伏线
