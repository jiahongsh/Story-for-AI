# 第155章 中阶一出！

**概要**：罗宋认定冰系对雷系单挑吃亏，不能坐视莫凡的召唤系顺利成长，凡能给莫凡修炼造成阻碍的事他绝不介意出手。入口处几人劝他等等同组，被他一句我有说要跟你们一组吗呛回。入笼后王力挺讥他肥肉，罗宋饶有兴趣反问一块冰从三十米高砸下来会碎成几段，让他祈祷食骨妖骨骼硬朗。罗宋闭眼再睁，斗兽结界涌起逼人寒气，冰霜冻结大地，冰锁施展，碗口粗冰链自地缝飞起——全场震惊这胖子是中阶魔法师。王力挺想唤回食骨妖已来不及，四五道锁链全方位缠住食骨妖吊挂空中，冰寒入侵将其冻成冰雕，冰锁断裂后从三十多米高空坠落崩裂，肉翅爪子化为粉碎。王力挺失魂落魄，家族辛苦弄来的命根召唤兽若死他就成了废人。顾翰将食骨妖送去救治，罗宋撇嘴。随后罗宋指着剩下两名召唤系学生叫两人一起上，二人定下一顶一攻之策，莫凡好心劝阻反被骂缩头乌龟。

**关键事件**：1.罗宋冰锁冻碎食骨妖，中阶实力震惊全场 2.王力挺命根召唤兽重伤，几近崩溃 3.罗宋叫阵剩余两人，莫凡劝阻被骂

**逐章写法公式**：

- **情绪流向**：起：罗宋阴计上场的冷意 → 承：冰锁现世的震撼 → 转：食骨妖碎裂的残酷爽 → 合：劝阻被骂的憋闷
- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：动机+呛声入场（反派立威） + 三十米坠冰之问（预告） + 冰锁冻雕坠落（兑现碾压） + 王力挺崩溃+叫阵剩余（余波推进）
- **本章核心技巧**：预告—兑现的闭环碾压：反派开场一句谜语式狠话，结尾原样演给你看，台词成为剧透也是判词
- **卡点与伏笔**：结尾卡点：紧张型，两名召唤系学生意气上头要送死、莫凡劝阻无效，全场只剩他一个能收拾残局；埋设/回收伏笔：食骨妖无敌（上章）→ 被中阶冰锁一合碾压回收，捧杀式反转
