# 第1364章 蓝衣莫凡

**概要**：莫凡从昏迷中醒来，发现自己睡在黑教廷安排的床铺上，眼睛因鹰啄伤口无法全睁。女蓝衣执事蓝蝙蝠守在屋中，温言告知秃鹰唾液有毒、普通治愈无法恢复容貌，建议事毕后换身份去帕特农神庙修复。莫凡谎称要回引渡首处复命，蓝蝙蝠转述引渡首命他们打扫战场，反问遇上了审判会的什么人——莫凡只说撞见一个一直跟着牧羊人的青年，在牧羊人呼唤第二、三只冥君蛙后出手，自己侥幸没被雷光束击中内脏。两人互换来历，蓝蝙蝠自报本名不肯透露，莫凡报出北鹿的假名与"梵墨"的本名，又打探出她杀过一个人——把守地中海海要塞的副将军，正是她的丈夫，即"红海盛典"。蓝蝙蝠反问莫凡杀人几何，莫凡答多得数不清、大半是同僚，被认作同类。蓝蝙蝠带莫凡巡查溧岩村迁徙，发现老人恋土不愿走、孤儿遗漏，迁徙拖慢至五天，莫凡心急如焚——若第二只冥君蛙践踏镇北关，冥界纤夫将如收割者般屠杀。北方夜空忽然闪烁冥光，男蓝衣执事已在开启冥界之门，莫凡决意阻止他。

**关键事件**：1.莫凡以"北鹿/梵墨"身份蒙混过关，获蓝蝙蝠信任 2.蓝蝙蝠自述杀了自己的副将军丈夫，完成"红海盛典" 3.莫凡察觉镇北关后迁徙需五天，恐第二只冥君蛙践城 4.北方夜空冥光闪起，男蓝衣已在开启冥界之门

**逐章写法公式**：

- **情绪流向**：起：醒来伪装的戒备 → 承：试探交锋的紧张 → 转：同类的认可 → 合：冥光骤起的紧迫
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：醒来入局（定身份）+ 对话试探（挖情报）+ 巡查村落（摸局势）+ 冥光惊现（抛钩子）
- **本章核心技巧**：把谍报戏写成一场场"比谁先露底"的对话博弈，再用民情观察把个人卧底线拽回全局战场线
- **卡点与伏笔**：结尾卡点：行动式——男蓝衣已在开启冥界之门，莫凡必须设法阻止；埋设/回收伏笔：秃鹰毒毁容建议去帕特农神庙 → 与心夏所在神庙线形成远期交汇
