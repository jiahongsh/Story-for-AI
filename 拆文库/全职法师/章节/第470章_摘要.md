# 第470章 第四级遁影（下）

**概要**：莫凡正缺一颗星子便能将遁影升到第四级，击杀的第四个白沙巨人竟直接掉落奴仆级精魄。他趁战斗间隙强化两颗暗影系星子，遁影成功升级。白沙巨人追踪莫凡的影子堵截，沙尘刀将影子劈得四分五裂，它们以为得手，莫凡却从另一侧现身，原来四级遁影能分化假影迷惑敌人、真身藏在原地。莫凡借此空隙施展玫炎烈拳九宫，九道火焰巨柱喷涌，近二十只战将级白沙巨人尽数被灭，残魄相当于六十个普通奴仆级，下一个精魄凝炼完成一半。他盘算若四十九颗火系星子全部强化，中阶魔法也能升到第四级，战局自此由被动转为主动，五百米外苦战的晨颖看得惊为天人。

**关键事件**：1.第四个白沙巨人直接掉落精魄，莫凡将遁影升至第四级。 2.四级遁影分化假影骗过巨人，莫凡从另一侧施展玫炎烈拳九宫。 3.近二十只白沙巨人尽灭，火系星子强化宏图初显，晨颖惊叹。

**逐章写法公式**：

- **情绪流向**：起：运气垂青的窃喜 → 承：强化星子、遁影升级的期待 → 转：巨人追影斩碎影子的绝境 → 合：九宫清场、战局翻转、晨颖惊叹
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：爆精魄凑齐材料（升级前置）+ 强化星子升四级遁影（能力兑现）+ 假影惑敌九宫清场（爽点爆发）+ 精魄过半与星子宏图（新目标钩子）
- **本章核心技巧**：让升级发生在战斗中而非休整期，用假影误导加范围大招一次兑现两重爽感
- **卡点与伏笔**：结尾卡点：期待——四十九颗火系星子全部强化后中阶魔法升四级，烈拳九宫威力再上层楼；埋设/回收伏笔：白沙巨人残魄顶三个普通残魄 → 成为火系强化长期材料来源
