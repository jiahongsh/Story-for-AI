# 第758章 我能知道她名字吗？

**概要**：莫凡与穆宁雪在初遇少女处停留，莫凡望向挂有白封线、长满杂草的岔路石阶，疑其为锁物封条；他向穆宁雪复述下午宫田找和尚攀谈的经过，穆宁雪称入夜前和尚多已下山做法事、只留吓疯的老和尚，莫凡自责报"赵满延"之名害其中招，穆宁雪笑其不靠谱。二人绕过封条步入岔路，行至山另一侧无路，莫凡粗喊"宫田"寻人无果，归途一阵风送来熟悉芬芳，莫凡忆起少女采香草之事、指认小坡野菊，正欲采花时却发现身旁裙裾并非在坡下五六米的穆宁雪，猛抬头见宫田清纯容颜近在咫尺，宫田微笑问候并嫉妒地打听莫凡同伴之名。

**关键事件**：1.莫凡穆宁雪探封线岔路，莫凡自责害赵满延 2.呼名寻人无果，循野菊香辨少女踪迹 3.采花时宫田突现身旁，打听穆宁雪名

**逐章写法公式**：

- **情绪流向**：起：封线岔路阴森 → 承：自责+寻人无果 → 转：野菊香引线索 → 合：宫田突现索名
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：封线探查（铺垫） + 自责寻人（加压） + 野菊辨踪（转机） + 宫田索名（危机钩子）
- **本章核心技巧**：用"身边人错位破绽"让灵体现身，再以"索名"收束危机升级钩子
- **卡点与伏笔**：结尾卡点：宫田索要穆宁雪名字（强悬念，恐重演赵满延）；埋设/回收伏笔：野菊香 → 少女气息标识；封线岔路 → 锁物之谜待解
