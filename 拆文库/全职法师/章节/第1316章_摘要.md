# 第1316章 多说一句断条腿

**概要**：南荣熙穷尽水之力组成水御与水花天幕，在九宫蛟炎龙面前仍抵挡不住，被烈焰折磨得落荒而逃到鼓浪屿，怒斥妹妹南荣倪判断失误，随即顾及世家声誉果断撤离，把潘西扔下不管。潘西眼看要拿下穆宁雪却杀出莫凡，想起曾能轻松捏死穆宁雪如今却苦攻不下，心生怨怒直接起了杀意，以邪蛛之陷抽取穆宁雪的灵魂之力。莫凡见状彻底暴怒，施展炎姬之怒召出焚天火瀑倾泻而下，将潘西连同他的诅咒一起焚烧，熔浆灌入其身体焚毁血液内脏，当街杀人不留余地，潘西连残渣都找不到。南荣熙、黎红眉吓得浑身冷颤。长老林泽此时才飞来，呵斥莫凡大逆之徒、罪无可恕，莫凡破口大骂他偏袒行凶者；穆宁雪则看穿这正是东海魔法协会设下的鸿门宴。莫凡喊来姗姗来迟的吸血鬼博拉，命他把林泽牙全打碎、弄个半死不活，并放话"再多说一句，多打断条腿"。林泽自恃超阶法师正要降服莫凡，博拉已悄无声息出现在他身后，诡异笑意与危险气息让他脖颈发凉、冷汗淋漓。

**关键事件**：1.南荣熙被蛟炎龙逼退并果断撤离，弃潘西于不顾 2.莫凡以炎姬之怒焚杀潘西，当街杀人不留余地 3.长老林泽现身欲定罪，莫凡命吸血鬼博拉殴打他，博拉悄然逼近林泽身后

**逐章写法公式**：

- **情绪流向**：起：蛟龙压敌、南荣熙溃逃 → 承：潘西夺弓杀意与邪蛛之陷 → 转：炎姬之怒焚尸、当街杀人 → 合：林泽欲定罪反遭博拉锁喉的钩子
- **节奏配比**：慢铺垫 10% / 快冲突 55% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：蛟炎龙逼退南荣熙（战果巩固） + 潘西垂死反扑抽魂（危机） + 炎姬之怒焚杀潘西（情绪顶点） + 林泽定罪遭博拉反制（悬念钩子）
- **本章核心技巧**：把"反派作恶"与"主角复仇"紧贴编排，让读者愤怒刚烧起来就立刻被主角的暴力行为浇灭兑现
- **卡点与伏笔**：结尾卡点：悬念型——超阶长老林泽被吸血鬼博拉贴身，下一回合这位偏袒作恶的长老会被揍成什么样；埋设/回收伏笔：邪蛛之陷抽取灵魂之力 → 莫凡当场暴怒焚杀潘西的导火索；东海魔法协会的鸿门宴 → 林泽与世家勾结的铁证；博拉迟到来援 → 铺垫其身份与实力的反差
