# 第1414章 猎脏者

**概要**：莫凡借帕特农神光闭关，梳理各系前景：暗影系得夜煞后质的飞跃，自信单凭此系可完虐高阶；召唤系可开第二契约、群兽召唤以一敌百；空间系无限潜能却重精神修炼。他悟出高阶"技能衍生"之道——借魂种与领域由把控星子创造魔法，正挑战"一念星图"使中阶招手即来、配合第五级强化战力质变。镜头转飞鸟市东太平洋，海平面上升令笋礁隐没，芍雨率队巡查时发现数具被挖空内脏、不沉的浮尸，确认是"猎脏者"所杀。巡查队仓促返航，回飞鸟市基地城（仍在建造）后向军司黄坤汇报：猎脏者似已察觉基地城意图、提前聚拢，数月海岸线已沦陷数千公里。邵郑大议员五千公里隐患战略虽惊人却仍低估全局，黎霆冷哼主张将清理猎脏者之事交给凡雪山以证其自主权。

**关键事件**：1.莫凡闭关悟技能衍生、冲一念星图 2.飞鸟市海域现猎脏者浮尸、海妖聚拢 3.黎霆主张凡雪山清猎脏者证自主权

**逐章写法公式**：

- **情绪流向**：起：闭关梳理各系的平稳 → 承：技能衍生与一念星图的进阶期待 → 转：海域浮尸的惊悚切片 → 合：海妖聚拢、凡雪山接任务的钩子
- **节奏配比**：慢铺垫 25% / 快冲突 10% / 爽点爆发 15% / 悬念留白 50%
- **本章结构公式**：闭关悟阶（静） + 技能衍生（铺陈） + 海域浮尸（惊悚） + 凡雪山接令（钩子）
- **本章核心技巧**：用星子具象数据把修炼进阶写成可感知台阶，再以"挖空内脏的浮尸"细切片切入海洋危机，轻量却留悬。
- **卡点与伏笔**：结尾卡点：凡雪山将清猎脏者，下章期待凡雪山如何应对海妖；埋设/回收伏笔：凡雪山自主权争议（1412提及强抢） → 本章黎霆以"证明自主权"加码，收束所有权线
