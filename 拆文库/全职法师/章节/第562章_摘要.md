# 第562章 亡灵袭村

**概要**：洪俊第二发火滋被高速移动的腐尸躲过，面目全非的亡灵扑到面前吓得他脸白，村长谢桑及时放出汹涌暴浪将腐尸打落冲走、直冲出一两百米。谢桑训斥洪俊高傲自大差点丢了小命，洪俊转头看见张小侯扶着苏小洛，眼中闪过一丝恼怒，又抢走张小侯的黑伞与苏小洛共撑。苏小洛坚持出村检查腐尸尸体，谢桑安排洪俊随行护卫、让福大留守，另派三名胆大青年同去。众人找到被冲远的腐尸，苏小洛检查后断定这就是一具普通亡灵，可村民坚称世世代代喝井水、上个月每家每户还接受过井水神仪式，不该被亡灵攻击。话音未落，雨幕四周传来拖拽咀嚼关节交响之声，大雨中一双双腥红眼睛死死盯住他们几个活人。

**关键事件**：1.谢桑暴浪救场冲走腐尸 2.洪俊与张小侯争风吃醋 3.苏小洛判定腐尸普通却遭红眼包围

**逐章写法公式**：

- **情绪流向**：起：洪俊火滋失手 → 承：谢桑暴浪救场训斥 → 转：争风吃醋小插曲 → 合：检查腐尸遭红眼包围
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：洪俊失手谢桑救场（战力对比）+ 训斥与争风（人物关系）+ 出村验尸（推理推进）+ 红眼包围（悬念收口）
- **本章核心技巧**：用普通亡灵为何攻击受庇护村民的悖论立悬念，再以红眼包围收束。
- **卡点与伏笔**：结尾卡点：雨幕中四面八方腥红眼睛包围众人；埋设/回收伏笔：井水神仪式失效 → 诅咒疑云；洪俊对苏小洛有意 → 三角关系
