# 第697章 最钦佩的人

**概要**：亡灵之潮褪去，城内法师从瘫软中涌起欢呼，久经绝境逢生相拥而泣。莫凡站在倾斜信号塔上，祭纹消退、银发恢复黑发、火焰雷电收回灵魂，恶魔之力沉眠。张小侯率先醒来抱住莫凡，二人确认斩空一直都在暗中抗争黑教廷，莫凡追问斩空是否算死、究竟古老王还是斩空。莫凡回想斩空历练布置任务、结拜、飞向长天诛杀翼苍狼、金林荒城营救自己的过往，感慨其是自己最钦佩的人。钟楼上虎津大执事穆贺仍被挂风雨中，一男一女上楼，男子表白十年心意，女子冷淡回应后取心杀之。

**关键事件**：1.城内欢庆幸存，莫凡退去恶魔态 2.张小侯醒抱莫凡，二人确认斩空一直在 3.莫凡回忆斩空过往，感慨最钦佩之人 4.钟楼穆贺悬挂，女子杀表白男子取心

**逐章写法公式**：

- **情绪流向**：起：劫后狂欢的释放 → 承：莫凡退恶魔态的平静 → 转：回忆斩空的温情 → 合：钟楼暗杀的寒意
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 25% / 悬念留白 30%
- **本章结构公式**：城内欢庆（情绪释放） + 莫凡退恶魔态（收束） + 张小侯对话忆斩空（温情） + 钟楼暗杀（钩子）
- **本章核心技巧**：用具体往事片段代替评价来塑造角色敬重，结尾以反差暗线收束
- **卡点与伏笔**：结尾卡点：悬念型——钟楼女子取心杀男，身份动机不明，下章揭晓；埋设/回收伏笔：斩空一直都在→暗中抗黑教廷，穆贺悬挂→待清算
