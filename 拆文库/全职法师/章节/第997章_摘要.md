# 第997章 终极引雷，爆！

**概要**：歹蛆伪龙吐黑龙息，莫凡以念控残骸为盾、寂雷死光击穿其背鳍，伪龙怒放乌雷如魔鬼之爪。莫凡在统领级战中玄蛇铠甲难挡，却咬牙将乌雷强行引到自己身上、照单全收压缩成雷爆，两道乌黑死光交汇紫黑吞噬空间，冲天雷光蒸发万吨海水、轰断礁窟，伪龙鳞皮化为乌有、露出体内反哺的白色蚁蛆。莫凡脱力，穆宁雪欲以冰晶刹弓禁术相助，莫凡急劝其勿伤身，但穆宁雪已凝冰晶之弓一箭射出，海洋瞬冻为冰河，歹蛆伪龙穿背化为无数冰晶碎片、再无生命。鲍比看得下巴砸冰面，惊见海变冰原。

**关键事件**：1.莫凡极限引雷爆重创伪龙 2.穆宁雪冰晶刹弓禁术一箭冻杀伪龙 3.歹蛆伪龙化冰晶碎片终结

**逐章写法公式**：

- **情绪流向**：起：龙息雷落的危机 → 承：硬抗与极限引雷铺垫 → 转：雷爆重创与禁术蓄势 → 合：冰河冻杀的终极爽点
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：引雷承压（逆转） + 雷爆毁鳞（高潮） + 禁术劝阻（情感） + 冰晶一箭（终结）
- **本章核心技巧**：用"把敌人力量转为己用"的极限操作制造反转，再用队友禁术收尾
- **卡点与伏笔**：结尾卡点：类型解决+疫苗如何取、战后如何归引下章；埋设/回收伏笔：冰晶刹弓反噬→穆宁雪身体代价伏笔
