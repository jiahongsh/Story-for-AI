# 第773章 更强的器皿

**概要**：邪灵事件解决后众人返回闫明寺，莫凡急去看望已苏醒的穆宁雪，南荣倪正喂她蘑菇汤，而赵满延睡醒后对自己遭难一无所知。江昱告知那些被勾魂者虽醒转却灵魂受损、寿命衰减，南珏则提醒西熊市魔法协会很快会查到这群偷渡者，须尽早离开横跨日本的路途。次日一早南荣倪寻赵满延服药，赵满延却从后山匆匆归来，神神秘秘告诉莫凡他做了个与后山有关的梦，并顺手拿走了破寺堂里那古怪的木鱼器皿。莫凡大惊，因他们此前根本碰不得那器皿。南珏检查发现有灵魂联系存在，莫凡伸手即被黄色禁制排斥，赵满延却拿取无碍。南珏推断木鱼器皿已认赵满延为主，并敏锐指出木鱼器皿反而强烈排斥莫凡，暗示莫凡身上有更强的伴生器皿。

**关键事件**：1.众人返寺，穆宁雪苏醒赵满延懵然 2.江昱南珏提醒离开西熊市 3.赵满延从后山带回木鱼器皿 4.南珏验出木鱼器皿与赵满延灵魂认主 5.南珏推断莫凡身怀更强伴生器皿

**逐章写法公式**：

- **情绪流向**：起：平安归来的轻松 → 承：离程前的日常铺垫 → 转：赵满延突然拿出宝物的惊愕 → 合：南珏推断莫凡秘密的钩子
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：归寺探伤（收尾前情）+ 离程提醒（转场）+ 赵满延取宝（奇遇）+ 验主排斥（设谜）+ 推断更强器皿（钩子）
