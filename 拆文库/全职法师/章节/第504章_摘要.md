# 第504章 联手杀敌！

**概要**：众人记起火劫果实有起死回生之效，齐心要夺果实。鬼妇早有准备，以鬼刑召出半虚无鬼怪攥住赵玉林灵魂，又以摄魂控心操纵八名油尽灯枯的阵法法师扑向史桂，两位高手尽数被制。鬼妇静待果实成熟，莫凡以霹雳-夜叉轰碎阁楼出手，张小侯的风盘-天罗被灵魂冲击打断，冲击如闪电链波及赵满延、南珏。心夏睁开眼睛施展心灵之墙挡下冲击，众人魔法恢复。心夏指出鬼妇分心鬼刑与摄魂控心，心灵与诅咒之力难再施展，联手可战。

**关键事件**：1.鬼刑锁赵玉林、控八法师制史桂 2.莫凡霹雳-夜叉轰阁楼出手 3.心夏心灵之墙破灵魂冲击，众人联手

**逐章写法公式**：

- **情绪流向**：起：夺果救人的急切 → 承：鬼妇连控高手的压抑 → 转：莫凡轰阁楼、心夏破冲击的反攻 → 合：联手可战的宣言
- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：夺果之念立目标（蓄势）+ 鬼妇连控高手（施压）+ 莫凡张小侯反攻受挫（拉锯）+ 心灵之墙翻盘（转折）
- **本章核心技巧**：让团队各用所长破解单体强敌，克制关系写清打法的合理性
- **卡点与伏笔**：结尾卡点：战局钩子——众人联手围攻鬼妇，胜负未分；埋设/回收伏笔：鬼刑与摄魂控心 → 为下一章心灵系对决蓄力
