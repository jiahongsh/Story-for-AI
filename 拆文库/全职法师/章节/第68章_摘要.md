# 第68章 守护街区

**概要**：独眼魔狼被逼急后仰天长吟、狂兽气息如海浪翻滚，打得老街区房屋摇摇晃晃——它在强迫自己进阶。宇昂被气息压得无法呼吸、补不出第二层冰蔓。徐大荒断言吸食了地圣泉的它本就具备进阶资本，若让其进阶成功，连杨作河赶到也未必制服得了；黎文杰脸色苍白劝众人趁早逃离，被徐大荒勃然大怒喝令回头看清背后——老街之后就是霓虹商业区，有看电视的一家老小、备七夕礼物的女孩、散步的老夫妻，全是毫无自保能力的民众。郭彩棠称莫凡今日及时发现避免了一场更大凶灾，徐大荒不再言退，莫凡对其气概暗生钦佩。肥石以地波·迟缓推移魔狼，冰霜却被其滚烫的身体蒸发沸腾；魔狼肌肉变透明、血管清晰可见，肩骨棱角与满是棘骨的背脊破肉而出。徐大荒镇定不住愤然掷出火滋·爆裂，烈焰吞没魔狼，它却浑身披火从爆炸位置飞窜而出、安然无恙，地波也拉不住它的速度——魔狼跃起利爪穿透小可赶织成的水御·守护水甲，将徐大荒胸膛撕出一条长长的裂口，血雾喷洒。

**关键事件**：1.魔狼被逼急强行进阶，冰火两系均无力阻止 2.徐大荒怒斥逃议、死守商业街区民众 3.火滋·爆裂无效、水御被撕，队长徐大荒被开膛重创

**逐章写法公式**：

- **情绪流向**：起：气息风暴的压迫 → 承：退守之争的热血 → 转：爆裂失效的错愕 → 合：队长开膛的揪心
- **节奏配比**：慢铺垫 25% / 快冲突 50% / 爽点爆发 0% / 悬念留白 25%
- **本章结构公式**：强制进阶（危机升级）+ 死守宣言（立价值冲突）+ 爆裂失效（打掉希望）+ 队长重创（代价定格）
- **本章核心技巧**：用希望层层落空（冰蔓蒸沸、爆裂无效、地波失灵、水御被撕）把压迫感推到顶点，末尾以核心角色重伤结算本章代价
- **卡点与伏笔**：结尾卡点：重伤悬念型——徐大荒开膛血雾、生死未卜，魔狼爪锋未收；埋设/回收伏笔：进阶若完成连杨作河也难制 → 抬高中阶救兵的必要性；莫凡及时发现避免更大凶灾 → 郭彩棠亲口认证、主角功绩入账；七夕、商业街烟火气 → 都市日常的脆弱感铺垫；小可水御防御短板 → 承接第60章教训再犯
