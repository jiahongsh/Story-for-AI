# 第1119章 举剑砍人

**概要**：阿莎蕊雅以空间之镯部署：可将哲罗送走两次，每次十分钟，使英国阵脚崩盘；南珏以音系压制大公爵艾琳的鲛皇灵影，莫凡在祝福下解决毁灭法师西士顿。中希联盟逼向英国，哲罗头疼两国联手，调侃要与莫凡共处一夜，莫凡回怼。阿莎蕊雅空间之镯发动，银芒捕获哲罗将其送离战场。南珏音杀音扰逼得艾琳节节败退，阿莎蕊雅给莫凡祝福，莫凡雷爆破西士顿，再唤小炎姬附体凝出二十多米炎剑，西士顿避无可避被横扫吞没。

**关键事件**：1.阿莎蕊雅部署空间之镯送哲罗、南珏压艾琳、莫凡砍西士顿 2.哲罗被空间之镯送走 3.莫凡祝福炎剑横扫西士顿

- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 30% / 悬念留白 5%
- **本章结构公式**：部署分工（设策） + 送走哲罗（反转） + 音压艾琳（推进） + 祝福炎剑（爆发） + 横扫西士顿（爽）
