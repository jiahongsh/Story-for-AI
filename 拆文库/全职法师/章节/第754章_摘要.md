# 第754章 和尚与少女

**概要**：莫凡追问"海洋惩罚"所指，奈良原空只称海域受圣兽支配、嘱其莫碰圣龟否则出海必遭灾难，自报名后离去；山阶上走来高马尾素朴少女宫田，甜美柔弱，向和尚献花梓茶却被高冷避开，莫凡一眼看穿她心仪和尚，宫田自介并主动带莫凡逛寺。奈良原空忽而暴怒冲来将莫凡拽开、身上魔法涌动紧盯宫田，莫凡低头发现宫田小蓝鞋在松软泥地竟无脚印，惊觉异常，和尚警告宫田别打客人主意，宫田委屈跑下寺却转瞬在石阶上消失无踪，莫凡由此惊觉这年轻和尚亦是修为不低的法师。和尚反怪莫凡能看见宫田却不言，称即便法师也不该可见，只嘱咐宫田绝非善类、最好别接触，留下满腹疑问的莫凡。

**关键事件**：1.宫田现身示好和尚被冷遇，带莫凡逛寺 2.莫凡发现宫田无脚印、和尚是法师 3.宫田转瞬消失，和尚称其非善类

**逐章写法公式**：

- **情绪流向**：起：问海洋惩罚 → 承：少女甜美铺垫 → 转：无脚印惊悚+法师现身 → 合：非善留悬
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：问惩罚（铺垫） + 少女示好（甜） + 破绽反转（惊） + 法师身份与非善（钩子）
- **本章核心技巧**：用"甜美形象+一处分镜破绽"做惊悚反转，再用配角警告制造悬念留白
- **卡点与伏笔**：结尾卡点：宫田真相、唯莫凡可见之谜（强悬念）；埋设/回收伏笔：宫田无脚印 → 本章揭示非人；和尚是法师 → 后续助力
