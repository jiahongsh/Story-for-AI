# 第169章 资源嗨到爆！

**概要**：斗兽大赛落幕，斗馆因全系公共资源将归莫凡一人而乱作一团，众系主任束手无策，周正华提议劝莫凡主动放弃。萧院长以"规矩就是规矩"回绝，一声如雷巨响镇住全场，宣布本学期全系公共资源归召唤系所有，随后怒斥各系学生：当初召唤系仅七人时无人喊不公，如今大家无法接受的只是好处落在一个人头上。一名神情清傲的贫寒学生起身质问，说出身寒门的法师靠学校资源维持修炼，一点点资源都很重要。萧院长顺势揭出莫凡来自博城——那场死亡十万人、举国默哀的灾难之城——且家庭背景比多数人还差。全场沉默，牧奴娇也震惊于这个从头到尾不用魔具击败自己的对手竟是一介布衣。莫凡吐槽萧院长未经同意揭老底害他没法"泡富家小姐"，萧院长大笑承认是抓范例骂学生。赛后莫凡独享全系公共修炼资源，自认一秒变富豪。

**关键事件**：1.萧院长拒绝劝退提议、宣布资源归召唤系 2.贫寒学生质问引发博城身世揭示 3.牧奴娇得知莫凡是布衣 4.莫凡独得全系资源狂喜

**逐章写法公式**：

- **情绪流向**：起：紧张（乱局与劝退提议） → 承：压抑（怒斥与贫富质问） → 转：压抑（博城身世揭底） → 合：爽（独得资源一秒变富豪）
- **节奏配比**：慢铺垫 40% / 快冲突 25% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：乱局劝退（压力） + 雷音定规（立威） + 博城揭底（反转） + 资源盘点（兑现爽点）
- **本章核心技巧**：用贫富对立的质问作跳板抛出主角的灾难出身，让针对主角的舆论攻击当场自行瓦解。
- **卡点与伏笔**：结尾卡点：资源兑现+全校公敌身份成立，下章期待资源折算与校园处境变化；埋设/回收伏笔：博城灾难死亡十万→回收前文背景并成为莫凡的身份标签；牧奴娇知其布衣无魔具→修正世家子弟误判，为后续关系转向铺垫。
