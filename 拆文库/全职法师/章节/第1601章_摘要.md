# 第1601章 煞渊飘行

**概要**：青海湖畔四辆越野车载着一群自驾游年轻人在自认神圣的土地上撒欢，前方却毫无征兆降下浓密黑云，褐土地塌陷，塌陷处万鬼狂啸，花衬衫男子回头看见尸物叠成山峰、相互攀爬啃咬搅成腐肉锅炉，当场吓昏，众人拼命逃出后黑色深渊又迅速消失；尼泊尔木城市七万人、印度拉贾斯坦邦相继遭其降临又无恙，纷纷祈祷并请求国际解释。开罗市里莫凡泡澡时才发现自己手臂仍是缺失的肉坨，灵灵来电告知煞渊已空间漂移至阿拉伯、途经尼泊尔印度巴基斯坦，断定古老王把煞渊驻扎在红海虚无岛准备正式与冥界开战，并警告虚无岛既是冥界之门也是黑暗位面入口、让他赶紧回国。灵灵追问第二契约，莫凡才惊觉自己不知何时多出一个契约空间，已可契约第二只召唤兽。挂电话前灵灵留下"等你回来再说"的悬念。莫凡饱睡两天恢复精神，赵满延调侃他断手、递上三盒东西，莫凡不动声色拿走一盒。

**关键事件**：1.煞渊从中国漂移穿越多国直抵红海，古老王陈兵虚无岛 2.莫凡发现自己开辟了第二契约空间 3.灵灵来电留下回国有事的悬念

**逐章写法公式**：

- **情绪流向**：起：郊游欢快 → 承：深渊降临的恐惧 → 转：多国视角叠加震撼 → 合：电话揭示真相+新契约惊喜+回国悬念
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：游客遇险（渲染煞渊之威）+ 尼印两国受害（扩展影响面）+ 莫凡接电（解密真相）+ 新契约与回国钩子（推进主角线）
- **本章核心技巧**：先以路人视角渲染灾难，再切换主角电话解密，用信息差制造双重情绪
- **卡点与伏笔**：结尾卡点：悬念+灵灵"等你回来再说"要说什么；埋设/回收伏笔：第二契约空间 → 第二只契约兽候选；虚无岛=冥界之门+黑暗位面入口 → 后续大战场地
