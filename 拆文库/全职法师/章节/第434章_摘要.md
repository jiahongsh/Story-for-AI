# 第434章 撞到什么！

**概要**：柳茹问莫凡是否觉得姐姐的死不是意外，莫凡点头并请她回忆姐姐身边有无奇怪男子，柳茹答"要说有这样一个男人，你倒挺符合的"——莫凡这才知道自己冒充的对象是追求柳娴的人，记下这条待查线索。柳茹回校后，莫凡化影潜入柳家闺房搜查一无所获。与灵灵汇合：遗体过早火化、无法验证是否被吸血鬼袭击，所有文件都表明柳娴是病发死亡、毫无破绽。唯一突破口是灵灵调出的柳娴死亡当天地铁录像，两人夜里到地铁站按柳娴的路线案情重演，发现两大疑点：最后一班地铁五分钟前已开走、明知无车的柳娴仍走进空无一人的地铁站，且步伐不像追车，判断她是被诱使进站的；莫凡并推断吸血鬼比以往妖魔聪明、懂得伪装死因逃脱猎妖队。灵灵模仿录像走位时突然惊呼——画面里的柳娴停住了，像撞到了什么人一样。

**关键事件**：1.柳茹指认死前接近姐姐的唯一男性正是莫凡冒充的追求者 2.案情重演发现柳娴明知末班车已过仍被诱使进站 3.录像中柳娴像撞到什么一样突然停住

**逐章写法公式**：

- **情绪流向**：起：紧张（死因疑云被双方确认） → 承：压抑（搜房扑空、文件毫无破绽） → 转：紧张（地铁站重演发现无车进站反常） → 合：紧张（"撞到什么"惊呼卡点）
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：问询补线（锁定追求者）+搜房扑空（压低希望）+案情重演（暴露进站反常）+惊呼卡点（撞到什么）
- **本章核心技巧**：把静态的监控录像转化成"夜里按死者动线走一遍"的现场重演戏，用仪式感和环境阴森感放大悬念，结尾掐断在发现异常的一瞬。
- **卡点与伏笔**：结尾卡点：悬念——柳娴像撞到什么人一样停住而面前空无一物，下章期待看清录像真相；埋设/回收伏笔：莫凡冒充的"追求者"→下章查访对象；金林荒城蛊惑魔蛛→莫凡联想吸血鬼可能拥有诱使手段；遗体已火化→验证被袭的路被堵死。
