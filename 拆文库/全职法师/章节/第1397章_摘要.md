# 第1397章 大战蝎君美杜莎

**概要**：宏伟之墙决堤后，斯芬克斯踏过残墙遥望无防护的北原之地，冥界大军释放积郁戾气肆意践踏。残城墙上冷爵狂笑，黑教廷尸体被埋入残骸。莫凡在要塞城处傲立迎击冥界大军，以天焰葬礼化炎剑扎入潮水，剑冕荡开将触之冥界生物烧成灰烬。冷爵暴怒命斯芬克斯、蝎君美杜莎、冥君蛙诛杀莫凡，斯芬克斯遂令蝎君美杜莎率蝎人部落出战。蝎君美杜莎体型擎天，麾下蝎人分褐战将、黑统领、红美杜莎三级；一只三十米红蝎美杜莎率先攻来，万千蝎人如黑蛹将莫凡包围。莫凡施展影狼狂袭，暗斗狼皇分化千狼影解肢蝎人，上千蝎人瞬遭秒杀，随后擒住红蝎美杜莎毒尾将其抡起砸向同伴，另两只红蝎美杜莎当场呆住。

**关键事件**：1.莫凡天焰葬礼炎剑清剿冥界大军 2.斯芬克斯命蝎君美杜莎率蝎人部落出战 3.莫凡影狼狂袭秒杀千蝎、生擒红蝎美杜莎

- **情绪流向**：起：冥界大军践踏的压迫 → 承：莫凡炎剑清场、冷爵催战的紧绷 → 转：蝎群包围绝境 → 合：莫凡破局秒杀生擒的爽点
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：大军压境（加压） + 炎剑清场（解围） + 蝎群围困（绝境） + 影狼破局（爆点）

- **卡点与伏笔**：结尾卡点：大君主蝎君美杜莎尚未亲自出手，下章期待正主交锋；埋设/回收伏笔：红蝎美杜莎被生擒 → 为下章大君主蝎君美杜莎亲战铺垫
