# 第109章 被世界遗弃

**概要**：铭文女子中学南面的购物广场遭魔狼血洗后空无一人，广场遍布人类残肢，四周低吼咆哮不断，不时传来幸存者被妖魔找到的惨叫。地下一楼的沃尔玛超市因需乘电梯下去尚未被妖魔发现，约十五人躲在超市里祈祷。众人决定跟随一名管道工走地下排水道撤往安全结界，一名瘦小女孩恳求有人背走坐轮椅的女孩，被管道工以"下水道多处要爬、带她一两天也到不了"为由拒绝，所有人抛下轮椅女孩离开。轮椅女孩把一条手链托付给瘦小女孩，请她转交家人，并要她告诉家人自己"已经遇难了"。白领贾倩目睹全程，因自己腿伤无法相背，愧疚道歉后追上人群。空荡的超市里只剩叶心夏一人，她不怪任何人，却感到被整个世界遗弃的无助蔓延全身；她推动轮椅到厨具区，吃力站起取下一柄锋利的水果刀回到原位。远处的贾倩看见这一幕，以为她准备自我了断，在愧疚中关上了超市的门。

**关键事件**：1.超市幸存者跟随管道工走地下道撤离，抛下坐轮椅的叶心夏 2.叶心夏把手链托付给瘦小女孩，谎称自己已遇难 3.叶心夏独自取下水果刀，贾倩误以为她将自尽

**逐章写法公式**：

- **情绪流向**：起：压抑（广场死寂）→ 承：悲伤（众人抛下轮椅女孩）→ 转：悲伤（手链托付与"已遇难"谎言）→ 合：紧张（取刀与关门悬念）
- **节奏配比**：慢铺垫 60% / 快冲突 10% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：环境绝境呈现（代入）+撤离决定与抛弃（冲突）+手链托付（转折）+取刀留白（钩子）
- **本章核心技巧**：全章主角不出场，用"被抛弃的静"代替喧嚣渲染，只以一件托付道具做章尾钩子
- **卡点与伏笔**：结尾卡点：取刀+关门，暗示女孩可能自我了断，下章生死未明；埋设/回收伏笔：DIY手链 → 托付给瘦小女孩，成为下一章莫凡锁定沃尔玛超市的关键线索
