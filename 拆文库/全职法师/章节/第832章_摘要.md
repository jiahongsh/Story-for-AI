# 第832章 进阶版陨拳

**概要**：蓝谷凶离兽关节发出金属响，莫凡发现其被巨影钉禁锢的四臂即将恢复自如，再拖下去更不可能对付。夜罗刹舔爪待命，笃定等莫凡吸引注意力后一爪撕开它无鳞的头壳——前提是莫凡先"出卖肉"。穆宁雪冰法将撑不住，急催出手。莫凡凝神再唤小炎姬，火羽汇聚成两片绚烂羽翼，孰料小炎姬抢先喷射，莫凡魂儿还在原地、身体已冲飞五六十米。他下意识甩出最熟练爆炸的"陨拳·九蛟"，一念星轨描出火图，拳未出火蛟随行，人拳合一撞向蓝谷腹部。这一拳堪比高阶火系，叠加喷射速度后拳力火威更盛，红色光团在腹爆卷，十几米海怪离地倒飞、腹铠碎如报废零件、蓝血四溅，连撞三座楼房留下百米焦痕沟壑。广濑伙伴见状惊为天人，广濑下巴砸冰面——说好的"他引怪、猫袭弱点"计划全乱。穆宁雪早知他不按套路。夜罗刹随机应变，趁腹铠破露处消失在火光中；莫凡感黑暗气息猜到小猫，散去火羽翼，操控千上火羽朝蓝谷倒落处飞去层层爆破，将其无铠甲处炸得血肉横飞。

**关键事件**：1.蓝谷臂将恢复、夜罗刹待命袭顶 2.小炎姬抢喷、莫凡陨拳九蛟人拳合一 3.蓝谷腹铠碎倒飞撞楼、旁观惊艳 4.夜罗刹袭弱点、火羽补刀溃烂

**逐章写法公式**：

- **情绪流向**：起：时限压力的紧 → 承：抢喷冲飞的乱 → 转：陨拳爆铠的爽 → 合：补刀溃烂的燃
- **节奏配比**：慢铺垫 15% / 快冲突 25% / 爽点爆发 50% / 悬念留白 10%
- **本章结构公式**：臂将恢复（压） + 抢喷冲飞（乱） + 陨拳碎铠（爽） + 补刀溃烂（燃）
- **本章核心技巧**：用"最熟招式+速度增幅"打出不按计划的爆炸爽点，再用补刀收尾。
- **卡点与伏笔**：结尾卡点：蓝谷被炸溃烂但未死，下章期待它是否反扑；埋设/回收伏笔：夜罗刹袭无鳞头壳 → 承接上章弱点设定，转入实战。
