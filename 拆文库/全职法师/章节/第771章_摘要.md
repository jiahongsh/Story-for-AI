# 第771章 你惹恼我了！

**概要**：莫凡与艾江图在满英山与邪灵奈良原空对峙，两只赤面鬼正疯狂撕扯被抓的和尚七海，奈良原空以七海性命威胁莫凡。艾江图救走和尚后莫凡不再隐藏实力，先用遁影拉开距离，以六道巨影钉锁住两只赤面鬼的咽喉腰身与右腿，再以烈拳轰天砸向墓碑上的诅咒血图。奈良原空浮空欲施展诅咒之指，被莫凡一记烈焰直冲天空打断并击伤。莫凡以念控虚爪将其拽落地面，接霹雳狂舞持续压制。莫凡试图施展高阶天焰礼，却在星子衔接至二百五十六颗时失误导致星图崩垮，反被奈良原空借机以血咒注入赤面鬼。两只赤面鬼自残撕开皮肉，露出穆宁雪与赵满延的面孔，试图扰乱莫凡心神。莫凡凭专注项链识破这是幻术，却仍被彻底激怒，立誓将奈良原空打得永世不得翻身。

**关键事件**：1.赤面鬼撕扯和尚七海，奈良原空以人质威胁莫凡 2.莫凡以巨影钉束缚赤面鬼并烈拳轰天砸诅咒血图 3.莫凡念控虚爪抓奈良原空坠击并霹雳狂舞压制 4.莫凡高阶天焰礼施法失误星图崩垮 5.赤面鬼露出穆宁雪赵满延面孔，莫凡识破幻术但怒而宣战

**逐章写法公式**：

- **情绪流向**：起：邪灵撕人质的压抑 → 承：莫凡连招压制的爽 → 转：高阶失误与挚友面孔出现的惊怒 → 合：识破幻术怒而宣战的钩子
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：邪灵以人质施压（制造危机）+ 莫凡连招压制（展示实力）+ 高阶失误留出破绽（设限）+ 挚友面孔激怒（情绪反转）+ 识破幻术宣战（钩子）
- **本章核心技巧**：用一连串可观察的动作连招堆叠主角强势，再以单个失误与情感锚点制造反转
- **卡点与伏笔**：结尾卡点：莫凡立誓报复，下章期待炎剑出手；伏笔：专注项链破幻、高阶天焰礼未成
