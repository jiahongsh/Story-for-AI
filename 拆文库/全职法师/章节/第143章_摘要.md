# 第143章 入学考试

**概要**：唐月渐渐把莫凡往幽暗林子里引，莫凡见人烟稀少浮想联翩，被唐月没好气点破——是让他在这人少处使用次元召唤，防止召唤出的东西吓到行人。之后一星期莫凡都在请教唐月，唐月正悠闲，让他陪着逛杭州，边游玩边补魔法与战斗知识，还把自己修的火系、暗影系倾囊相授，莫凡这才体会什么叫亲传弟子。临别唐月叮嘱：大学学府竞争残酷，为资源动用家族势力的大有人在，学府是各势力角逐的缩影，校方睁一只眼闭一只眼；莫凡出身普通家庭没有后盾，中阶在明珠这种变态一箩筐的名校算不上顶尖，被欺负过分的可以来找老师做主。莫凡表面受教、内心决定靠自己，做一个能负责的男人不躲别人羽翼下。场景切到明珠学府，臃肿青年罗宋从黑色奔驰下来，抱怨还要等一星期才做决定；李管家纵容地劝他不行就去帝都老家根基，罗宋宣称不靠爸爸也能比嘲笑他的人强，点名要收拾"自以为召唤系了不起"的竞争者。走进试炼馆，罗宋看到场中穿黑色寒酸衬衫的莫凡，从穿着品味直接断定对方是穷酸。

**关键事件**：1.唐月一周亲传火系暗影系知识并陪莫凡备战召唤 2.唐月临别警告大学学府竞争残酷并承诺给莫凡做主 3.富家子罗宋登场立誓碾压莫宋争夺名额

**逐章写法公式**：

- **情绪流向**：起：轻松（林子误会喜剧） → 承：温馨（一周亲传与叮咛） → 转：压抑（罗宋登场立威） → 合：紧张（试炼馆两相对峙）
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 5% / 悬念留白 30%
- **本章结构公式**：误会小品（轻松开场） + 亲传蒙太奇（知识与情感双收） + 临别预警（新舞台规则） + 反派登场（对峙开局）
- **本章核心技巧**：用"温情告别+反派压场"的冷暖对切完成转场，前半章攒下的师门情谊恰好成为后半章读者站队的情绪资本
- **卡点与伏笔**：结尾卡点：强卡点，罗宋以穿着断定莫凡是叼丝，考核一触即发；埋设/回收伏笔：回收唐月火系暗影系修为（倾囊相授）、回收出租车旧情（唐月主动亲近）、埋下罗宋"你知道我的底细"的背景悬念、埋下帝都罗家根基线、埋下李管家"别惹出大事"的预警
