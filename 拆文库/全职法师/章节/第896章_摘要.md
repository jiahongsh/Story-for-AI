# 第896章 冰结之吻

**概要**：莫凡一路用药液毁尸，顺穆宁雪留的冰晶记号摸到地牢，见三人关在普通铁牢、穆宁雪随时能破。莫凡问安，穆宁雪谢赵品霖带他们进老巢。话未说完，穆宁雪嘴角溢出黑血，莫凡如遭霹雳——黑血夺命。郭文衣荣盛惊叫，莫凡遁影抓肩查看，穆宁雪勉强控住反涌。她以冰系领域冻住自己血管拖慢血液循环延缓毒变，提及闫明寺往事。莫凡情绪失控，上前以唇印上她冻紫的冷唇，说有重要的话等她醒来再听。穆宁雪冻结喉咙未能出口，眼中只映着莫凡的脸。

**关键事件**：1.莫凡顺冰晶找到地牢 2.穆宁雪吐黑血毒发 3.穆宁雪冰封自己延缓毒变 4.莫凡冰吻立誓 5.穆宁雪未出口

- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：顺记号寻人（温情） + 黑血毒发（反转） + 冰封自保（解法） + 冰吻立誓（情感）

- **卡点与伏笔**：结尾卡点：穆宁雪能否撑住，下章揭晓；伏笔：闫明寺 → 呼应前作生死情谊
