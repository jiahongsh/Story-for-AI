# 第428章 不依不饶

**概要**：最后一个挑战者是173名的周桐,火院学员死灰复燃,把他当作最后希望。周桐矮个子、下牙包上门牙,笑起来像老鼠,他贼溜溜的眼睛有意无意看向刘黔——刘黔托他帮个小忙,要莫凡被重创到治疗院躺几个月,事成有重谢。莫凡脸色苍白,魔能消耗殆尽,伤势正在恶化。周桐催促魏荣快些开始,魏荣正要宣布,萧院长却不知何时到场阻止,让莫凡下来,又命他向魏荣和全体火院学员低头认错,莫凡照做了。火院学员傻眼,说好的挨个道歉呢,萧院长一句话就洗清了。魏荣不服气,萧院长小声告诉他真打下去周桐不一定打得过莫凡,为世界学府大赛不想暴露莫凡的暗影系,魏荣惊出冷汗,明白这是保住火院声誉,宣布挑战到此为止。火院学员却不依不饶,要求让周桐打下去,艾图图骂火院不要脸,其他院系也站莫凡这边,火院气得七窍生烟,越发不肯放莫凡走。

**关键事件**：1.周桐受刘黔之托要重创莫凡,催促开赛 2.萧院长到场叫停,命莫凡当众认错 3.萧院长私下透露莫凡隐藏天赋,魏荣改口结束挑战,火院学员抗议

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |

**逐章写法公式**：

- **情绪流向**：起：周桐登台蓄势 → 承：萧院长叫停转折 → 转：火院抗议反弹 → 合：双方僵持的钩子
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：周桐阴谋铺垫(暗线) + 萧院长叫停认错(转折) + 低语揭示隐藏天赋(信息差) + 火院不依不饶(反弹)
- **本章核心技巧**：以院长叫停制造"主角被制裁"的假转折,再借低声耳语翻转成"保护性隐藏",让读者与火院同时被吊住
- **卡点与伏笔**：结尾卡点：火院学员拒绝和解,要求莫凡挨个低头认错,僵局待解;埋设/回收伏笔：刘黔托周桐重创莫凡 → 私人恩怨升级伏笔；莫凡暗影系隐藏 → 世界学府大赛底牌铺垫
