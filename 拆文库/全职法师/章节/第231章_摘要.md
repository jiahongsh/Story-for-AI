# 第231章 大混战（下）

**概要**：召唤系的郑冰晓与海大富按兵不动，判断莫凡主动放弃妖兽后己方夺兽希望很大，且召唤系到中阶战团不再占优。王力挺团队为冲动付出代价：食骨妖被一位中阶冰系学长锁住后，关义的一道霹雳将其当场轰得稀烂，血块羽毛洒落，王力挺呆立被队友拖逃。关义携雷冠小组控制暗影妖兽并放话立威，人称其早有入主校区实力、留级只为三步塔奖励。人群里一个捏着嗓子的男声煽动大家围攻关义，紧接着"暴浪·驱逐"将泉池水抽上半空，洪流般不分敌我冲垮聚集的人群；水系魔法师们见状落井下石，接连从各处释放暴浪、暴浪·惊涛，一口气卷灭不下百名学员，广场化为一片湖，善良女生顺手抢救困在漩涡中的人。莫凡驾幽狼兽避到高处心有余悸，感慨同类魔法齐放的破坏力惊人，众多中阶魔法师无辜躺枪出局。

**关键事件**：1.关义霹雳轰碎食骨妖、雷冠小组控制暗影妖兽 2.暴浪·驱逐掀开全场大混战 3.水系集体落井下石卷灭百人，莫凡高处观望

**逐章写法公式**：

- **情绪流向**：起：轻松（召唤系按兵观战） → 承：爽（食骨妖被轰碎、关义立威） → 转：紧张（暴浪连环席卷全场） → 合：压抑（百人出局、广场成湖）
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：旁观蓄力（召唤系等待） + 霹雳反杀（王力挺出局） + 暴浪点火（全场失控） + 高处俯瞰（莫凡收束点评）
- **本章核心技巧**：用同系魔法的连锁复制（一道暴浪引来满场暴浪）把群战写成灾难场面，以人数和魔法名层层堆高烈度
- **卡点与伏笔**：结尾卡点：混乱升级卡点——广场成湖、百人出局而妖兽仍在关义手中，下章期待莫凡出手收网；埋设/回收伏笔：捏嗓子的煽动男声 → 身份未明的搅局者伏笔；郑冰晓召唤系蓄势 → 后续夺兽变数
