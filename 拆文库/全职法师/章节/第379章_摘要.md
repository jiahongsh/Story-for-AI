# 第379章 紧急支援

**概要**：莫凡被玄蛇满身重伤仍安慰唐月的疼惜震撼，冷青坦言自己也偏向守护派却无能为力。祝蒙急于下手，罗冕劝阻称解开大阵死一半人也未必杀得了蜕皮期的玄蛇。宫廷侍卫李锦急报西要塞求援：白魔鹰军团中出现君主级生物，天鹰系统瘫痪，调遣附近所有高阶法师仍挡不住，白魔鹰很可能飞临城市上空。梨天分析玄蛇到下半夜体力才耗尽、雷戒之罚一两天内困得住，力劝先赴前线，罗冕仍坚持先杀蛇，祝蒙最终决断先支援，令武平景率宫廷侍卫驰援、放进一只白魔鹰到安界就拿他问罪。武平景展开六翼率众升空西去，玄蛇暂获喘息，冷青却盯着罗冕说这件事恐怕没有表面那么简单。

**关键事件**：1.李锦急报白魔鹰军团现君主级、西要塞求援 2.梨天分析利弊，祝蒙决断先赴前线支援 3.冷青盯住罗冕，断言此事没有表面那么简单

**逐章写法公式**：

- **情绪流向**：起：温馨（玄蛇安慰唐月的余波）→ 承：紧张（催杀与劝阻拉锯）→ 转：紧张（求援军报、决断离场）→ 合：紧张（冷青点破事不简单）
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 15% / 悬念留白 15%
- **本章结构公式**：余波感怀（立场巩固）+ 催杀拉锯（两难呈现）+ 军报到场（外压介入）+ 升空驰援（热血调度）+ 疑点收尾（悬念上钩）
- **本章核心技巧**：用"外线军情强行中断处决"给主角阵营喘息与查案时间，危机互救式转场
- **卡点与伏笔**：结尾卡点：冷青断言事不简单，下章引出调查线；埋设/回收伏笔：雷戒之罚一两天困得住 → 玄蛇不死的时间窗与离场理由；冷青的怀疑 → 罗冕真凶线起点
