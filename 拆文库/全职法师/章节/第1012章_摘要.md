# 第1012章 进击金字塔！

**概要**：江昱向莫凡强调小法老陵墓海市蜃楼已生灵涂炭，胡夫金字塔出问题便是国灾。莫凡见心夏忙碌，决心尽快结束亡灵战争让她歇息。回营后官鱼正讲计划：海市蜃楼持续会夷平城市，政府派军冲杀金字塔用仪器消除虚影。南珏说最大威胁是毒金木乃伊，其伤势无法愈合，政府希望国府队解决毒金木乃伊统领。官鱼主张擒贼先擒王刺杀统领，南珏忧冒险。莫凡问何不直接抵金字塔消虚影，官鱼冷笑说亡灵死士护陵，靠近十公里便被围死。次日清早大军集结，中国国府队随行，参谋芬纳安排国府队清毒金木乃伊。队伍推浪式前行至五公里营地，再扑十五公里高坡，国府队绕至高坡后侧应对毒金木乃伊，莫凡等人翻坡见金绿色毒金木乃伊铺满山坡。东军统旺科斯对把任务交学生表示不信任。

**关键事件**：1.官鱼南珏定计清除毒金木乃伊统领 2.莫凡得知抵金字塔消虚影之难 3.推浪式进军至五公里营地扑高坡 4.国府队绕后见毒金木乃伊群 5.旺科斯质疑国府队能力

**逐章写法公式**：

- **情绪流向**：起：江昱强调危机 → 承：定计清毒金木乃伊加压 → 转：进军见敌群 → 合：旺科斯质疑留悬念
- **节奏配比**：慢铺垫 40% / 快冲突 25% / 爽点爆发 5% / 悬念留白 30%
- **本章结构公式**：强调海市蜃楼后果（压危） + 定计清统领（目标） + 揭示抵金字塔之难（加难） + 推浪进军见敌群（行动）
- **本章核心技巧**：用军中分歧（冒险派与稳妥派）制造张力，再以敌方规模侧面抬高任务难度
- **卡点与伏笔**：结尾卡点：旺科斯质疑国府队能否对付毒金木乃伊，下章实战揭晓；埋设/回收伏笔：推浪式前进→古都回忆对照；毒金木乃伊→下章实战
