# 第593章 你尸将，我尸臣

**概要**：妖男抓住莫凡衣领飞向黑色沙尘暴中的尸臣，队伍成员以为两人必死，反而因领队主动出击而恢复士气。莫凡在空中抱怨自己刚归队就被拖走，妖男说明自己负责尸臣，只要莫凡吸引尸将注意力，四个系和两只召唤生物正好可以发挥。妖男在莫凡躲过肉触手后答应把尸臣残魄给他，随后将他从百米高空扔进尸群。莫凡以遁影落地，召出疾星狼和小炎姬，发现周围至少有五只尸将，随即安排疾星狼单挑一只，小炎姬布置火墙。

**关键事件**：1.妖男强行带莫凡迎战尸臣 2.两人确定尸臣与尸将的分工 3.莫凡坠入尸群并安排召唤兽迎敌

**逐章写法公式**：

- **情绪流向**：起：强行出战的荒诞 → 承：空中躲避与谈判 → 转：高空坠入尸群 → 合：召唤兽分工并准备防守
- **节奏配比**：慢铺垫 10% / 快冲突 55% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：抓人升空（推动行动） + 空中互骂（缓冲紧张） + 尸群投放（扩大危机） + 召唤兽布阵（建立战术目标）
- **本章核心技巧**：把战术说明藏进角色互骂，再用一次强制投放把说明立即转成连续动作。
- **卡点与伏笔**：结尾卡点：莫凡独处尸群且至少五只尸将逼近，期待火墙能否挡住尸潮；埋设/回收伏笔：妖男承诺尸臣残魄归莫凡 → 后续残魄奖励。
