# 第953章 无耻的骗子！

**概要**：山下，赵满延与守口女子欧妮搭讪调情，通讯仪骤响，欧妮下属急报"我们被打劫了"。赵满延展金色翼魔具抱起欧妮飞上山，欧妮误认他是大金主。山顶上赵满延却看错了局面——把穿红衣挂饰的红饰公会当成村民、把那三百名手无寸铁的村民当成匪盗，竟站到红饰一边要"替天行道"。莫凡为掩饰雌雄双盗计划，当众抹黑赵满延"扣一成钱"。欧妮识破赵满延是骗子，怒极下令围攻；赵满延防御魔具层层无敌，欧妮亲自动用高阶魔法。

**关键事件**：1.赵满延山下与欧妮调情，闻警飞上山 2.赵满延误判敌我站错队 3.莫凡抹黑赵满延掩饰计划 4.欧妮识破骗子怒攻，赵满延防御无敌，欧妮动高阶

**逐章写法公式**：

- **情绪流向**：起：山下调情轻松 → 承：闻警飞山转急 → 转：误判站错队逗闷 → 合：识破怒攻留战钩
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：山下调情（闲笔） + 闻警飞山（转折） + 误判站队（笑点） + 识破怒攻（加压）
- **本章核心技巧**：用"队友认知错位"制造喜剧误会，同时把反派底牌（高阶）提前逼出
- **卡点与伏笔**：结尾卡点：欧妮高阶能否破赵满延防御留悬念；埋设/回收伏笔：雌雄双盗计划→需赵满延配合；金翼魔具→赵满延身家
