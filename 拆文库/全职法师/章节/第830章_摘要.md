# 第830章 合力杀妖！

**概要**：蓝谷凶离兽再举染红光的尖足挥斩，莫凡急喊穆宁雪，穆宁雪娇喝立起连绵冰丘如山屏挡在身前，孰料虚空一斩将三道冰丘依次劈开，凌厉之风打在她无防备的身上，只差毫厘便身首异处，广濑惊得说不出话。穆宁雪断定三人绝非其对手，令莫凡快走，却听得广濑苦笑——狞鲨妖已结成包围圈将他们堵在冻结街道。莫凡骂蓝谷打不动，穆宁雪忽忆艾江图提过其弱点，道出头壳无鳞片覆盖；广濑讶异二人死战不逃，愿唤附近伙伴拖住狞鲨妖。既跑不掉便合力：穆宁雪冻海化冰刺荆棘阻兽冲，夜罗刹恰从高楼归来，鸣叫告知白泣妖已被它杀——它未听命送毒、更关心穆宁雪安危。莫凡初不屑这黑猫，经穆宁雪点出其灵活合适袭弱点，定下夜罗刹攻头顶破绽、莫凡引怪。蓝谷逼近，莫凡唤"小炎姬附体"，劫炎点燃全身，火势竟不因冰霜水雾减弱反而更盛。

**关键事件**：1.冰丘被劈、穆宁雪险死、令走被围 2.忆蓝谷弱点头壳、广濑唤伙伴拖妖 3.夜罗刹归来报杀白泣妖、违命护主 4.定分工袭弱点、小炎姬附体劫炎盛

**逐章写法公式**：

- **情绪流向**：起：冰丘被劈的险 → 承：被围死战的决 → 转：弱点揭晓+夜罗刹归的喜 → 合：小炎姬附体燃向终战
- **节奏配比**：慢铺垫 15% / 快冲突 35% / 爽点爆发 30% / 悬念留白 20%
- **本章结构公式**：险死逼走（压） + 被围亮弱点（转） + 夜罗刹归援（喜） + 分工附体（燃）
- **本章核心技巧**：绝境中"亮弱点+召回援军+附体"三连，把必死局翻成合击局。
- **卡点与伏笔**：结尾卡点：小炎姬附体、火势反盛，下章期待合击蓝谷能否破防；埋设/回收伏笔：夜罗刹杀白泣妖 → 解毒素到手，承接前文"取毒救南荣倪"主线回收。
