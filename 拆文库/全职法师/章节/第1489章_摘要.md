# 第1489章 第七个黄昏

**概要**：布兰妾追问莫凡到底要借什么，莫凡不答，转而请最了解艾美拉的李雨娥帮忙补全艾美拉的杰作。入春第七个黄昏降临，遍植学府的雪熏衣同时绽放，夕阳辉光下费伦学院如梦幻雪国，从高处俯视竟组成一枚覆盖近十平方公里的阿尔卑斯山学府花徽，冲散了学员们的恐惧不安。海蒂回想艾美拉生前最后的话，才明白她多年在花丛忙碌，就是想让全校人在这个黄昏看到心血成果。莫凡却指出花徽正中央缺了一块，缺的正是被封的罗亚花园，并据此推断艾美拉曾偷偷潜入罗亚花园补全那块位置，也因此惹来杀身之祸。

**关键事件**：1.雪熏衣在第七个黄昏齐放，组成覆盖近十平方公里的学府花徽 2.海蒂读懂艾美拉多年心血，悲伤难抑 3.莫凡指出花徽缺失处正是被封的罗亚花园，推断艾美拉因此被杀

- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：托付李雨娥（埋设补全伏笔） + 雪熏衣齐放成花徽（奇观+抒情） + 指出缺失位置（转折） + 点出罗亚花园凶案（钩子）

- **卡点与伏笔**：结尾卡点：信息揭示+艾美拉因潜入罗亚花园被杀；埋设/回收伏笔：李雨娥补全艾美拉杰作 → 引出土壤与凶案；花徽缺失 → 罗亚花园线索
