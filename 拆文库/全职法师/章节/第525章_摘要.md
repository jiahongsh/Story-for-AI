# 第525章 古怪村落

**概要**：张小侯不顾王童劝阻折返救贾曦，却眼看她被尸将舌头卷起、一口咬断，血溅他满脸。他呢喃一声对不起，踏风轨逃出追上队伍。秦虎教训他：这支部队的规矩是沦陷即放弃，回头会全军覆没，违抗命令绝不允许；张小侯只沉浸在不甘中，恨自己速度不够快。队伍减员后抵达羊阳村，村中木屋沿山溪而建，无电无信号，守夜老人要求进村者褪下带血之物与通讯设备，石少菊分析不用设备正是村子避妖的生存之道。设备被一把火烧掉，众人脸色难看。穿村而过一路不见活人，王童疑心是鬼村，张小侯则发现每户门前插着似曾相识的狗爪草（灰梅）。

**关键事件**：1.张小侯折返救人，贾曦被尸将当空咬断殒命 2.秦虎训诫队伍铁律，张小侯沉浸不甘 3.队伍进羊阳村，设备被烧、不见活人、灰梅似曾相识

**逐章写法公式**：

- **情绪流向**：起：折返救人的急切 → 承：贾曦殒命的震惊 → 转：训诫与不甘的压抑 → 合：古怪村落的狐疑
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：冲回救人（情义）+ 当面殒命（打击）+ 队伍铁律训诫（冲突）+ 进村规矩（新谜）
- **本章核心技巧**：用主角的执拗与团队的冷酷对撞立住人物，再借民俗规矩铺开悬疑
- **卡点与伏笔**：结尾卡点：家家门前灰梅似曾相识，村庄处处透着违和；埋设/回收伏笔：灰梅狗爪草 → 张小侯似曾相识，埋下线索
