# 第416章 把我惹火了

**概要**：郑佳慧怯场到连星轨都描画断裂，全场哄笑。莫凡先暗授机宜——中阶施展不出就用初阶、别用拳头打输太假，又毒舌点醒他：包括老师在内没一个人看得起他，他在众人眼里只是个笑话。郑佳慧两次描画星轨失败，赵季骂他是猴子请来的逗比，魏荣为不让莫凡的计划得逞冷言赶他下台，对魏老师话语下意识服从的郑佳慧当即要弃权离开。莫凡冲上去揪住他，怒斥他自私自利：你解脱了，却留我一人面对两百多名挑战者。他的计划就此挑明——故意输给最后一名，变成末名后便无人能挑战他，再趁最后一个挑战周直接挑战前五十名，既躲开车轮战又能晋升排行；但规则规定一方一个魔法都没用时另一方弃权不算输，郑佳慧连初阶魔法都放不出来。郑佳慧哭着道歉要还星云魔器，莫凡看穿魏荣是识破计划、故意赶走绝对服从的郑佳慧。怒极的莫凡立誓：今天要是被人从赛台上打下去，就承认自己是废物中的废物、给系主任道歉、挨个低头认错——他更为郑佳慧这种在卑微服从里挤不出一点骨气的人愤怒。他狠指魏荣大喝：给我叫下一个挑战者。

**关键事件**：1.郑佳慧怯场描不出星轨 2.魏荣赶人、郑佳慧弃权 3.莫凡的输给末名计划曝光 4.莫凡怒而立誓叫下一个

**逐章写法公式**：

- **情绪流向**：起：压抑（怯场哄笑） → 承：紧张（计划被拆穿赶人） → 转：愤怒（莫凡爆发痛骂） → 合：热血（立誓叫阵）
- **节奏配比**：慢铺垫 35% / 快冲突 40% / 爽点爆发 10% / 悬念留白 15%
- **本章结构公式**：暗授机宜（铺垫假打）+ 怯场失败（计划受阻）+ 拆局赶人（危机顶点）+ 怒誓叫阵（转守为攻）
- **本章核心技巧**：把"必胜妙计"写到破产边缘才揭晓，用主角的公开立誓把失去的筹码加倍押回去，情绪从憋屈直转燃
- **卡点与伏笔**：结尾卡点：硬刚宣言——两百人挑战与挨个低头认错的赌约已立，期待莫凡如何打穿；埋设/回收伏笔：输给末名的规则漏洞 → 计划破产后转为正面硬刚；弃权不算输的规则 → 制度约束线；郑佳慧的渴望做法师 → 其翻身弧光起点；魏荣识破计谋 → 师生斗智升级
