# 第670章 高阶蜕变

**概要**：莫凡用烈拳消灭的亡灵数量仍然很少，但他主动冲入亡灵群，依靠晋升高阶后提升的速度、反应和身体素质穿过腐尸，用瞬发火滋击杀奴仆级亡灵。他从数百只亡灵中辨认出一只隐藏的骷髅战将，用巨影钉将其锁死。八只手刀骷髅围攻时，莫凡释放雷印制造麻痹电场，张小侯又用风盘清掉身后亡灵，莫凡近身以烈拳轰杀骷髅战将。战将残骸处随即出现十米高的双面恶鬼，新的更强敌人发出怒吼。

**关键事件**：1.莫凡主动冲入亡灵群 2.高阶身体素质显现 3.火滋击杀腐尸 4.发现骷髅战将 5.巨影钉禁锢目标 6.雷印麻痹手刀骷髅 7.张小侯风盘清场 8.烈拳轰杀骷髅战将 9.双面恶鬼出现

**逐章写法公式**：

- **情绪流向**：起：少量击杀仍不足以改变局面 → 承：高阶身体和瞬发魔法占据主动 → 转：战将被控制并击杀 → 合：更高体型的双面恶鬼登场
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：冲入尸群（展示身体蜕变） + 火滋清杂（降低数量） + 巨影钉锁将（锁定威胁） + 雷风火联动（完成击杀）
- **本章核心技巧**：把新境界拆成速度、反应、意念和瞬发魔法四个具体表现，再用更强敌人的登场阻止战斗过早结束。
- **卡点与伏笔**：结尾卡点：十米高双面恶鬼现身并带来更强气息；埋设/回收伏笔：亡灵战将混在普通亡灵中 → 后续战斗需持续寻找真正的高威胁目标。
