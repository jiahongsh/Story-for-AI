# 第152章 心机战

**概要**：萧院长问谁先来，海大富当仁不让，走向斗场中央，见入口处挑战者排成长龙，便叫最前面几个一起上，称挑战人数都是给他添数据的，激怒四名男生跳入铁笼结界。海大富闭眼施为，次元星轨破开空间，钻出一只三角脑袋遍布角刺、前肢如斧钺、后趾延伸骨镰的白铠战蛰，青短发男子当场色变。海大富警告它不听话、缺胳膊少腿别找他要医药费后，白铠战蛰直接下手，抡起斧钺前肢劈向反应最慢的清秀男生，全校师生倒吸凉气。守护老师顾翰脚下金色星光待命、准备出手，看到男生身上蔚蓝星光闪耀后撤销了释放。清秀男生面前凭空出现岩石盾卡住巨斧，他刚才懦弱吓尿的模样瞬间变成狡黠，手心早已凝聚的光团近距离炸开——光耀·失明，白铠战蛰眼眶被灼烧烂开。众人喝彩，莫凡赞叹这心机吊，感慨明珠学府学生与从前同学根本不在同一层次，期待与他们交手。

**关键事件**：1.海大富召出白铠战蛰，激四人入笼开战 2.清秀男生假意示弱，用岩石盾接斧后近距离光耀·失明灼瞎战蛰 3.莫凡旁观点评心机，暗自兴奋

- **情绪流向**：起：海大富抢擂的嚣张 → 承：战蛰现身的压迫 → 转：清秀男生翻盘的惊艳 → 合：莫凡点评的跃跃欲试
- **节奏配比**：慢铺垫 30% / 快冲突 45% / 爽点爆发 15% / 悬念留白 10%
- **本章结构公式**：挑衅排队者（立狂人） + 召唤白铠战蛰（亮怪物） + 巨斧劈人（危机） + 岩盾+失明反杀（反转）+ 莫凡点评（收势蓄钩）
