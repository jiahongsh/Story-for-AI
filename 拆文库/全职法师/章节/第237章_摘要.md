# 第237章 以暴制暴！

**概要**：灰一嘶吼着令黑畜妖打断莫凡施法，两只妖物贴墙扑向只差一道星轨的莫凡；幽狼兽与主人心灵感应，怒吼冲杀，一爪拍碎一只、再把咬住的另一只当飞弹砸落偷袭者，护住了施法。莫凡先后施展"千钧"震荡震碎近身妖物，再以"霹雳·夜叉"引紫黑雷云当空轰下——灰一的冰锁防御化为泡沫、价值百万的盾魔具也化为乌有，人被空间震荡压得骨头全软趴倒在地。灰一摸向胸口致命毒药欲自我了断，莫凡遁影近前踩住其手腕，施"火滋·焚骨"以烧烤般不致死却极度痛苦的火焰逼问主使。灰一连自杀都被识破，尊严尽失，在火焰中翻滚惨叫。莫凡毫无心慈手软——他记得自己正是用这样的火焰送许昭霆和他的女友离开，黑教廷死前要压榨出等量的痛苦与悔恨。

**关键事件**：1.幽狼兽舍身护法，莫凡千钧震碎近身妖物 2.霹雳·夜叉轰碎冰锁与盾魔具重创灰一 3.莫凡踩腕拦下服毒、焚骨之火逼问主使

**逐章写法公式**：

- **情绪流向**：起：紧张（打断施法的抢时赛） → 承：热血（幽狼兽护法、千钧震敌） → 转：爽（霹雳夜叉轰碎双层防御） → 合：压抑（焚骨逼供、惨叫回荡）
- **节奏配比**：慢铺垫 15% / 快冲突 40% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：抢时断法（敌人急救场） + 护法歼敌（幽狼兽清障） + 双雷轰杀（防御尽碎） + 踩腕焚骨（逼问主使）
- **本章核心技巧**：把"杀"拆成"先废其防、再断其死、后烤其身"三步，用剥夺反抗、剥夺自杀、剥夺尊严的递进把复仇爽点写出层次
- **卡点与伏笔**：结尾卡点：逼供卡点——灰一在火中翻滚仍拒供，下章期待主使名字与宇昂线暴露；埋设/回收伏笔：许昭霆及其女友之死 → 贯穿本卷的复仇动机回收；盾魔具百万价值 → 黑教廷装备财力线索；"告诉我你的主子是谁" → 直指宇昂的钩子
