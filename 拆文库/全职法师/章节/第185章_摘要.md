# 第185章 火速灭妖！

**概要**：莫凡按灵灵指示绕过两百多米无门可通的墙，踹开独立化妆间的门：一个穿表演服的女孩被吊在墙上割腕放血、昏迷不醒，青黄女妖正贪婪舔食墙上鲜血。莫凡怒而火滋·爆裂将其炸飞，再以雷印鞭打、火滋·灼烧把重伤的女妖活活烧死——以放血之刑还治其身。女妖蜕皮露出一个女生，莫凡给她套上表演服，用随身携带的昂贵止血药控制住被吊女孩的动脉伤口。灵灵提示割开拇指，莫凡依言割开表演服女孩拇指，一条小蚯蚓大的寄生妖虫从伤口钻出，被他一把掐死。表演服女孩是治愈系魔法师，主动提出在存放食物水药品的消防舱坐镇治愈伤者，把那里变成安全区。莫凡不肯留名匆匆离开——他在青校区早已是占尽新生资源的全校公敌。灵灵通报红点大规模蜕皮成片行动、被寄生者被潜意识控制在校园内不出校门，莫凡决定把追来的三只女妖引入室内篮球室一网打尽。

**关键事件**：1.莫凡连杀化妆间女妖、以灼烧酷刑处刑 2.割拇指逼出并掐死寄生妖虫，验证解除寄生的手段 3.治愈系女生坐镇消防舱建立安全区，莫凡引三只女妖去篮球室设伏

**逐章写法公式**：

- **情绪流向**：起：紧张（绕路赶场、踹门见惨状） → 承：恐怖（放血寄生现场） → 转：爽（处刑式击杀+掐死妖虫） → 合：紧张（红点成片行动、设伏篮球室）
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：赶场破门（发现罪行现场）+处刑击杀（情绪峰值）+割指除虫+建安全区（方法论落地）+引敌设伏（下一场钩子）
- **本章核心技巧**：用"罪行—惩罚"对称结构写战斗，反派的作恶方式直接成为主角的处决方式，让爽点自带道德正当性。
- **卡点与伏笔**：结尾卡点：诱敌设伏——莫凡要把三只女妖引入篮球室一网打尽，读者等收网；埋设/回收伏笔：拇指割口规则→妖虫实体验证；治愈系女生+消防舱→后续伤员中转站；止血药习惯→猎妖队时期养成的职业细节；"没到校外"的潜意识控制→妖母操控全局的伏笔。
