# 第708章 打一顿就老实了

**概要**：灵隐审判会石桌前，莫凡敲桌质问格洛肯飞机还赔否，格洛肯满脸友善说有保险不用赔，心有余悸。莫凡指心夏问还带走否，格洛肯称心夏被大导师看中、执行命令。唐忠劝莫凡听人说完，格洛肯点出帕特农专治怪疾，心夏求学期间或能治愈腿疾，甚至复活之术也掌握。莫凡看心夏，唐忠证实帕特农治愈远胜魔法协会，并愿亲自陪心夏赴希腊安排住处。心夏问时长，格洛肯答快则一年慢则两年，唐忠说恰与莫凡列国历练期吻合，莫凡终问心夏意见。

- **情绪流向**：起：谈判桌的轻快 → 承：治愈诱饵的期待 → 转：唐忠背书的可信 → 合：问心夏意见的开放
- **节奏配比**：慢铺垫 25% / 快冲突 10% / 爽点爆发 20% / 悬念留白 45%
- **本章结构公式**：飞机不赔（收束） + 带人争议（拉扯） + 治愈筹码（转机） + 问心夏意见（开放）

- **卡点与伏笔**：结尾卡点：开放型——莫凡问心夏意见，留待下章决断；埋设/回收伏笔：帕特农治愈→心夏腿疾线，列国历练→莫凡一年不在国
