# 第349章 从小养大的老婆

**概要**：莫凡到浙江学府接叶心夏，被长期守在心夏身边的"冰公子"柳一林拦下。柳一林以护花自居指责莫凡羞辱心夏，莫凡反问他是否喜欢心夏，柳一林当众承认，莫凡随即宣布心夏是他妹妹、也是他"从小养到大的老婆"，并威胁再纠缠就打得他连他妈都不认识。柳一林翻脸，称浙江学府论实力没人敢这样对他，冰、雷元素气息在林荫道上对撞，围观学员议论心夏追求者多被吓退或被暗地教育，幸灾乐祸等着看外乡人吃亏。柳一林绅士地让心夏退开，莫凡却不推开心夏，星图描画悄无声息又迅捷无比，说着"没那么复杂"连唤千钧、霹雳、夜叉，紫黑色叉状雷电划破午后天空轰然落下。

**关键事件**：1.莫凡当众宣布心夏是他"从小养到大的老婆"并威胁柳一林 2.柳一林承认喜欢心夏、与莫凡剑拔弩张 3.莫凡抢先连发中阶雷系魔法，紫黑霹雳轰落

**逐章写法公式**：

- **情绪流向**：起：轻松 → 承：紧张 → 转：爽 → 合：紧张
- **节奏配比**：慢铺垫 45% / 快冲突 30% / 爽点爆发 20% / 悬念留白 5%
- **本章结构公式**：兄妹登场引冲突（立关系） + 护花者步步紧逼（造对抗） + 老婆宣言引爆（情绪宣泄） + 三咒惊雷收尾（悬置胜负）
- **本章核心技巧**：用旁观者的八卦与幸灾乐祸给反派抬轿，再让主角以最少动作完成最大反差。
- **卡点与伏笔**：结尾卡点：动作悬置——霹雳轰落、柳一林生死未揭，下章期待对决结果；埋设伏笔：心夏追求者被"暗地教育" → 交代柳一林势力与骄横人设；莫凡施法速度远超同辈 → 实力成长坐标。
