# 第1496章 颜秋姐姐

**概要**：布兰妾唤来圣裁院负责整理卷宗的亡灵法师，老人查探后说出尤莱的魂魄平静虔诚、未变亡灵，但尸骸已不在坟下，证实坟墓确实被人动过。海蒂愤怒、布兰妾疑惑，莫凡分析尤莱遗体约一两个月前失踪，而伊之纱与伊迪丝都不知道葬处，推断盗骸与阿尔卑斯山事件可能不相干，线索就此中断。审判日到来，莫凡无罪释放。另一边，穆白借口泡温泉接近赫卡萨，认出其身边一位东方女子，报出自己来自博城、母亲是希怡，女子激动回应，压低声音约他夜钟响后在温泉相见。夜里两人相认，颜秋说明因卡萨世族禁止与外界通信才失联多年，拒绝随穆白回国，只求他保密别生事端。

**关键事件**：1.亡灵法师证实尤莱尸骸已不在坟下 2.审判日莫凡无罪释放 3.穆白在温泉与失散多年的姐姐颜秋相认

- **卡点与伏笔**：结尾卡点：信息揭示+颜秋拒回国、叮嘱保密；埋设/回收伏笔：颜秋身份与卡萨世族 → 后续赫卡萨线；尤莱遗骸被盗 → 盗骸者之谜留待后续
