# 第331章 他是军官！

**概要**：张小侯质问二人是否想吞他的钱，胖老板和大金当场承认并讥笑他轻易交出钻卡。张小侯依军部"民众先行动手即可反击"的明文规定不再讲道义；胖老板叫出大牛四兄弟，四人嘲笑张小侯稚嫩。张小侯冷冷报出九百万来历：三百万是卖贴身魔具所得，六百万来自他单独击杀的十二只战将级妖魔和二百三十一只奴仆级妖魔的尸体，众人笑翻，大牛称自己十六人合力才杀过一只巨亡蜥。动手后张小侯在大牛星图尚未描画三分之一时便完成风系星图，一招风盘-龙卷在店内掀起巨柱旋风，卷飞大牛四人、掀翻后堂墙面，又担心伤及街坊主动散去后续席卷力，整间铺子只剩空架。他踏过废墟无视被打懵的四人，向胖老板讨回钻卡，亮明那是自己的军勋、要求对方对魔法协会自称练功失手，替他隐瞒身在比翼市。胖老板惊觉惹上军官，大金哀叹这不是钓到大鱼，简直是钓来一头大白鲨。

**关键事件**：1.张小侯自报军勋来历遭全场嘲笑 2.一招风盘-龙卷掀翻店铺打趴四法师 3.讨回钻卡并隐瞒军官身份 4.骗子父子发现惹上军方怪胎

**逐章写法公式**：

- **情绪流向**：起：压抑（骗子翻脸讥笑）→ 承：轻松（自报战绩被当吹牛）→ 转：爽（星图快慢对比、龙卷掀店）→ 合：爽（军官身份点破，大白鲨收尾）
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：骗子承认吞钱（撕破脸）+ 叫帮手集体嘲笑（蓄压）+ 自报军勋反被笑（误导加固）+ 一招龙卷定胜负（爽点释放）+ 讨卡亮军勋（身份反转收尾）
- **本章核心技巧**：用"说得越离谱、笑得越大声"的群众反应把实力信息差拉到顶，再以速度对比的碾压式战斗一次性兑现。
- **卡点与伏笔**：结尾卡点：身份揭示卡点——军官身份曝光且要求保密行踪，期待他在洞庭湖的后续行动；埋设伏笔：三枚精魄尚未买到 → 恶魔系养魂的正事仍未办成。
