# 第537章 不按套路的火滋

**概要**：比赛台被冰霜覆盖，许明聪在李杰冰锁夹击与莫凡火滋的配合下，依靠预设风轨连续变向，自信地避开攻击并享受观众喝彩。莫凡的第四级玫炎火滋却爆裂出远超常规的范围，将他掀翻在地。队友点出莫凡火滋的威力来源后，许明聪收起轻敌，放出三枚可潜伏阴影的巨影钉梨刺，准备用禁锢和压制限制莫凡。莫凡认出其威胁，阻止艾图图把防御浪费在自己身上，改让她保护正遭冰锁攻击的刘欣和李杰。

**关键事件**：1.许明聪以风轨躲避冰锁与火滋。 2.莫凡的强化火滋将许明聪炸翻。 3.许明聪布下三枚巨影钉梨刺牵制莫凡。

**逐章写法公式**：

- **情绪流向**：起：轻松自信 → 承：紧张闪避 → 转：爽感打脸 → 合：紧张牵制
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：许明聪闪避攻击（维持优势） + 火滋爆裂越界（打破判断） + 队友解释莫凡强度（补足信息） + 巨影钉潜伏（转换为牵制）
- **本章核心技巧**：先让对手用一连串娴熟动作建立从容感，再以强化技能的实际结果短促反转，并把胜负压力转入尚未发动的限制技能。
- **卡点与伏笔**：结尾卡点：悬念+三枚巨影钉已潜伏，莫凡需防备其发动；埋设/回收伏笔：巨影钉梨刺的连中效果 → 后续限制莫凡施法的威胁。
