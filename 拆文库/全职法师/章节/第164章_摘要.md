# 第164章 所向披靡！

**概要**：霹雳轰碎龟裂的大地，顾翰的金色光系守护抢在白藏锋自己的铠魔具之前护住他全身；他被后坐力压趴在地，没受重伤却因后怕发抖。白藏锋怒指莫凡老师没示意就动手，顾翰直接判他出局，反驳说刚才他根本没有开启魔具的意思、不出手就可能被轰死；白藏锋还嘴硬，顾翰随手画出风系星图，一句"目无尊长，滚"以狂风逐客，白藏锋怒踢结界下场。雷系学员哗然：主修雷系的都没跨入中阶，这个召唤系竟放出中阶雷系魔法；众人终于明白莫凡敢挑战全系，是因为他主修雷系、召唤系只是次修。海大富等人心悦诚服，又有两组人上去送分，萧院长高声宣布199、只剩最后一个名额，周正华劝非中阶者别再以卵击石。罗宋悔恨自己太早出场，忧心资源被莫凡独吞会拉开差距。此时一名绝美女子起身挑战，有人道出她的名字——牧奴娇。

**关键事件**：1.顾翰出手救白藏锋并判其出局轰下场 2.全校确认莫凡是能放中阶魔法的雷系法师 3.计数到199只差一人 4.牧奴娇压轴现身

**逐章写法公式**：

- **情绪流向**：起：紧张（霹雳之后的救援与判罚） → 承：爽（主修揭晓、全系拜服） → 转：轻松（送分组与海大富的狂喜） → 合：紧张（罗宋悔恨与女神压轴）
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：判罚收尾（了结白藏锋） + 反应层正名（全校确认中阶雷法） + 计数推进（199与劝退） + 压轴登场（牧奴娇现身）
- **本章核心技巧**：上一章的大爆点用判罚争执和群体反应层完整消化，再以只差一人的名额稀缺感引出压轴对手。
- **卡点与伏笔**：结尾卡点：人物登场+绝美女子站出挑战、名字牧奴娇，下章期待压轴战；埋设/回收伏笔：顾翰的守护原则→后文他不为牧奴娇出手的对照；罗宋的资源焦虑→其后续针对莫凡的动作；199名额→牧奴娇成为最后一关。
