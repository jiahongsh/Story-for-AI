# 第1629章 坏事撞一起

**概要**：莫凡在餐桌边急中生智，用一番漂亮话圆回差点成渣男的尴尬，穆白向海蒂介绍穆宁雪是莫凡喜欢的人，阿帕丝落井下石。莫凡提议凡雪山帮穆白收集晋级超阶的辅助资源，穆白却称只听管凡雪山的穆宁雪的。穆宁雪道出此行真正要事：东海发现礁金石岛，礁金矿石将在雅典出货，驻岛法师遭金贝戾妖重创需要防御魔具。牧奴欣说明她与祖向天见洛茜正是要谈这笔生意，洛茜本是首选伙伴；穆宁雪却认为洛茜对泰坦事件的态度证明她没有原则，不值得合作。牧奴欣再补充高级矿石在欧洲出售需经欧洲魔法矿物协会批准，而负责这块的正是祖家，莫凡感叹坏事全撞到一起。

**关键事件**：1.穆宁雪道出来雅典的真实目的与礁金石岛之事 2.穆宁雪以原则为由否决与洛茜合作 3.矿石鉴定大权握在祖家手中

- **情绪流向**：起：饭桌尴尬化解的轻松 → 承：穆宁雪道出礁金矿生意 → 转：洛茜合作被否、祖家把持鉴定 → 合：莫凡感叹坏事撞一起
- **节奏配比**：慢铺垫 50% / 快冲突 20% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：化解尴尬（缓氛围）+ 穆宁雪陈述生意（铺信息）+ 洛茜合作被否（立原则）+ 祖家把持鉴定（埋冲突）
