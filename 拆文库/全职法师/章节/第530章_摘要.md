# 第530章 煞渊，万尸坑（下）

**概要**：张小侯在深渊底部看见层层堆叠、遍地蠕动的尸物和密集猩红瞳孔，确认那里是填满万尸的地狱之坑。刀斧尸将逼近时，他背对尸坑准备死战，尸将却突然转向追赶石少菊，张小侯得以沿归路逃离。镜头继而转到钟楼魔法协会，监察员发现古都周边血红地图中出现黑点，副会长彭玉确认羊阳村西面出现煞渊，要求通知各方势力寻找亡灵暴动根由。翌晨，羊阳村的苏小洛在山溪取水时发现溪水染红，并救起浑身血污却尚有气息的男子。

- **情绪流向**：起：恐怖 → 承：紧张 → 转：压抑 → 合：悬念
- **节奏配比**：慢铺垫 20% / 快冲突 25% / 爽点爆发 0% / 悬念留白 55%
- **本章结构公式**：展示万尸坑全貌（兑现章尾恐怖） + 刀斧尸将转移目标（给主角逃路） + 协会确认煞渊与灾变（扩大信息范围） + 村女发现血污幸存者（留下身份钩子）
