# 第40章 不可能任务！

**概要**：总教官斩空宣布考核规则：他刚接到一份悬赏榜上难度最低的悬赏，100名学生中只要有任何队伍或任何一个人完成，全员历练评估通过且得A。广场哗然，班长周敏抗议这与直接判全部不合格没区别，许昭霆追问后得到"那就全部不合格"的答复；张建国等老师也措手不及——学校明明打点过教官。斩空让学生有意见找校董邓凯，骂天澜魔法高中既然是博城最好的公立高中就不该带一群废物来历练，混日子不如滚回学校打木偶；张建国辩称悬赏一般需野外磨砺三到五年的成熟小队才能完成，反被斥为一百名废物还敢称尖子生。斩空随后加码：完成悬赏的小组和个人将获他个人赠送的一件防御魔具。外围老猎者们闻讯疯狂，恳求与学生们公平竞争——魔具与灵魂相连、意念催动即可幻化实物，一件普通防御魔具就值好几十万元，是野外包命的救命神器，莫凡折算成人民币后彻底心动。

**关键事件**：1.斩空抛出悬赏考核：有人完成全员得A，无人完成全部不合格 2.周敏与老师们抗议无效，斩空强硬骂学生是废物 3.斩空加码防御魔具奖励，老猎者们疯狂争抢，莫凡心动

**逐章写法公式**：

- **情绪流向**：起：军法师威压下的紧张 → 承：悬赏规则引爆的错愕 → 转：师生抗议被镇压的憋闷 → 合：魔具奖励点燃的期待
- **节奏配比**：慢铺垫 25% / 快冲突 45% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：总教官立威（压场）+ 悬赏连坐规则（引爆）+ 师生抗议与回怼（加压）+ 魔具奖励（钩子）
- **本章核心技巧**：用连坐制不可能任务同时激活危机、悬念与利益三重钩子
- **卡点与伏笔**：结尾卡点：利益加危机型——防御魔具诱人但悬赏要命，下章期待任务内容揭晓；埋设伏笔：邓凯与斩空的旧关系 → 校方线；一群废物的骂名 → 后文打脸势能
