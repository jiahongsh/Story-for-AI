# 第1332章 钓出内奸

**概要**：莫凡踏着灰烬回到广州塔七十层病房，冯州龙、灵灵迎上来，他发现心夏脸色苍白趴在冷青床边。塔塔揭穿心夏施展了未完全掌握的帕特农大治愈礼赞，那是损耗灵魂的术，只能保住尸体灵魂不散、命脉不断，须每月续施否则冷青仍会死去。心夏仍执意要带冷青回帕特农神庙，每月为冷青施展一次大治愈礼赞，以修为精进护住这一丝气数，两年三年也要唤醒她，莫凡被触动只化作一个拥抱。次日清晨心夏已先行离开。灵灵提出要把红衣大主教冷爵挖出来，透露她此前将给总部的密文处理成多线，把佛山、厦门、深圳、昆明等错误地点发出去，又以猎人大师身份在四地发布悬赏让猎人真去与当地审判长密文人接头。昨晚昆明的猎人没见到接头人，说明接到昆明密讯的人正是黑教廷内奸，疏忽暴露了自己。灵灵决定不急着拔除，放长线钓出冷爵的真面目，莫凡连称灵灵是天才。

**关键事件**：1.心夏以帕特农大治愈礼赞护住冷青命脉，决定带她回帕特农每月续施 2.灵灵揭晓当年密文多线布局，用悬赏猎人真接头的方式钓出内奸 3.昆明猎人未见接头人，黑教廷内奸暴露，灵灵决定放长线

**逐章写法公式**：

- **情绪流向**：起：莫凡负伤归来与心夏耗神的沉重 → 承：心夏执意救冷青的坚定温情 → 转：灵灵揭晓钓内奸布局的反转 → 合：放长线钓大鱼的前景期待
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 30% / 悬念留白 25%
- **本章结构公式**：负伤归塔见心夏耗神（交代代价） + 心夏执意续救冷青（立人设） + 清晨离去留愧意（缓冲） + 灵灵揭晓钓内奸布局（主反转）
- **本章核心技巧**：前半用温情与愧疚收束上一场死亡，后半用一场"自以为聪明反被钓"的布局反转把复仇线重新推上主动
- **卡点与伏笔**：结尾卡点：谋划反转——灵灵布局已成、内奸暴露却暂不拔除，冷爵真面目成为期待；埋设/回收伏笔：多线密文→钓出内奸；冷青带回的讯息→冷爵计划的重要线索
