# 第199章 表彰大会

**概要**：体育馆事件后，李院士在月度全校大会上公布光系学生赵满延击杀母妖、一度被视为全校公敌的召唤系莫凡见义勇为协助救人，三万多名从日夜骂莫凡到今日要集体赞扬他的学员表情无比怪异。人群里一名治愈系清瘦女孩认出莫凡，断定真凶是他；不少现场学生记得是一道中阶雷系魔法杀了妖母、现场另有火系中阶魔法，甚至有男生坚称亲眼看见莫凡召唤幽狼兽、满脸飙血以霹雳杀死战将级妖母，却因莫凡是召唤系加雷系的身份被同学驳回，他扬言要找出黑幕。而这黑幕正是莫凡与赵满延一开始就策划好的，一个为钱一个为名。会后两人下馆子庆祝洗白，约定周天到国贸中心拍卖会，李家拍下灵级雷种给莫凡，莫凡则打算卖掉战将级精魄、换一件盾魔具替代报废的镰骨盾。

**关键事件**：1.校方公布赵满延杀妖母、莫凡协助，学员从骂到赞表情怪异 2.目击学生的火雷双系版本流传，被身份设定否定，扬言查黑幕 3.莫凡赵满延定下周天拍卖会之约，各取所需

**逐章写法公式**：

- **情绪流向**：起：轻松（全校要表扬公敌的滑稽）→ 承：好奇（目击版本与官方版本打架）→ 转：轻松（黑幕真相点破、狼狈为奸下馆子）→ 合：期待（拍卖会之约）
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：表彰公布（立官方版本）+ 目击者议论（真相暗流）+ 内幕点破（一个为钱一个为名）+ 拍卖之约（接下一场）
- **本章核心技巧**：同一事件给官方与民间两个版本，让真相在版本冲突里自己发光。
- **卡点与伏笔**：结尾卡点：约定（周天国贸中心拍卖会，卖精魄买魔具）；埋设/回收伏笔：治愈系清瘦女孩认出莫凡 → 未点名的新角色线；火雷双系男子的传言 → 多系秘密的暗雷；牧奴娇捐赠后众人日夜骂莫凡的旧账 → 校内敌意积累。
