# 第29章 完美释放，火滋！

**概要**：同为火系的周敏看着外溢的光芒满脸不可置信，自问一直看走眼；穆白的脸扭曲抽搐如遭千刀万剐，狗腿子赵坤三无数次揉眼后彻底沦为人群中的滑稽傻影。三位考官落定S评分，全场清楚莫凡的星尘魔能恐怕比穆白还高几分，莫凡潇洒宣布继续考释放。他念起后气势流畅庄严自信，狂热气息扑打在数百人脸颊，火之星轨幻化，一簇火焰在半握的掌心滕然窜起；一声"走你"，火团划出炫目赤红焰尾准确钻入人形木偶，再一声"给我起"，沉寂一秒的火焰在木偶身上狂窜，几秒内吞没整个木偶。全场老师学生领导呆若木鸡，他的火滋毫无停顿，完成速度比穆白更快，火系初阶本就比冰系狂躁，众人反应比看冰蔓强烈十倍。释放评分A、B、A，两项成绩全部压过穆白，稳拿全校第一，薛木生嘴都笑歪了——第一和第二都在他的班级，自认要涨工资升职。猎者联盟高层兼校董邓铠当众称赞穆氏底蕴，称司机的儿子也熏陶得出彩；穆卓云被圈内人恭维得脸上有光，转念起招揽之心：家族年轻辈缺主修火系者，他决定摒弃前嫌给点甜头，把莫凡打发到长子穆江铭处培养成出色的火系家臣。穆卓云捋须唤莫凡上前，莫凡走近时偷看几年不见已长得祸国殃民的穆宁雪，被穆卓云一声咳嗽打断。

**关键事件**：1.火滋完美释放两项全胜锁定全校第一 2.邓铠当众捧场、穆卓云起招揽之心 3.穆卓云唤莫凡上前

**逐章写法公式**：

- **情绪流向**：起：对手崩溃的反应层 → 承：火滋释放全程高能 → 转：双杀定格全校第一 → 合：穆卓云招揽、莫凡被唤上前
- **节奏配比**：慢铺垫 20% / 快冲突 10% / 爽点爆发 55% / 悬念留白 15%
- **本章结构公式**：对手反应（蓄压）+ 释放表演（爆发）+ 双杀定格（满足）+ 招揽悬念（转钩）
- **本章核心技巧**：把最大爽点拆成"星尘S"与"释放A"两级台阶连续兑现，中间夹敌人表情崩溃的持续反应做燃料。
- **卡点与伏笔**：结尾卡点：悬念型，穆卓云叫莫凡过去所为何事；埋设/回收伏笔：回收光芒外溢的判定；穆江铭之名与家臣打算 → 下一章拒招揽打脸的铺垫。
