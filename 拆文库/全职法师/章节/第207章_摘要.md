# 第207章 古都陵墓

**概要**：入冬，莫凡到杭州接放假的心夏，先带她慢慢走过苏堤、逛到雷峰塔。塔下一个黝黑当地人神秘兜售攻略手册，讲这里曾挖出一条粗得要人合抱的白蛇、无人能杀、最后被某位大师耗尽生命之力封印，莫凡饶有兴趣地反手把白蛇故事改编成断桥人蛇恋，开价九块把版权卖回给对方，两人谁都没把东西卖出去，坐轮椅的心夏笑个不停。莫凡由此发现这个世界竟然没有白蛇传之类的古老神话，两个世界连历史人物都一致，神话却出现不一致。心夏一句「可你还是你」让本想自我解嘲的莫凡深思释怀。心夏转述历史老师的话：博城人很可能是地圣泉的守护者，博城由奉古老君王之命世代守护地圣泉的村子繁衍成城，守护者早已销声匿迹，或者整个博城的人都是守护者。莫凡联想到黑教廷摧毁博城的目标可能就是地圣泉，而地圣泉正在自己手上，顿时惊觉危险。心夏又说老师根据史料推测，要弄清真相恐怕得去古都那个我国最有名的亡灵之地——神秘陵墓中寻找，那里亡灵生物可怕到至今没有魔法师敢真正踏入。

**关键事件**：1.杭州游玩，白蛇传说忽悠与反忽悠，莫凡发现两世界神话不一致 2.心夏转述守护者之说，莫凡惊觉黑教廷的目标地圣泉就在自己手上 3.揭出古都陵墓亡灵之地的线索

**逐章写法公式**：

- **情绪流向**：起：轻松（雪中游湖）→ 承：搞笑（忽悠与反忽悠）→ 转：紧张（守护者说与地圣泉推断）→ 合：悬念（古都陵墓亡灵之地）
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：游湖定氛围（温情铺垫）+ 白蛇传说对忽悠（喜剧引出世界观差异）+ 守护者转述（核心设定揭示）+ 陵墓线索（埋新地图钩子）
- **本章核心技巧**：用一段街头买卖的喜剧戏做引子，把世界设定（神话缺失、地圣泉来历、亡灵之地）层层挂到玩笑与转述之后，信息量大而不生硬。
- **卡点与伏笔**：结尾卡点：新地图悬念（古都陵墓亡灵之地，无人敢入的神秘陵墓）；埋设/回收伏笔：封印白蛇传说与三潭印月等地点 → 呼应下章审判会三潭印月结界松动；博城人是地圣泉守护者之说 → 博城灾难真相线；地圣泉在莫凡手上 → 黑教廷追索动机；心夏的历史老师痴迷考古 → 后续考古队线。
