# 第1123章 莫凡VS阿莎蕊雅

**概要**：希腊伽门侬（伽门农）冲入艾江图空间区间打飞艾江图，独自对哲罗；艾江图怒布诅咒邪蛛网将哲罗伽门侬同罩，联盟自此破裂。莫凡低调保存魔能，阿莎蕊雅不满伽门侬坏规矩。二人设计诱英国牧文入套：莫凡假意与阿莎蕊雅内讧，大声称二人有私情以激牧文，牧文信以为真愤慨。阿莎蕊雅黑色之甲变身黑暗剑姬，一剑伤莫凡肩头；二人炎黑对决，牧文以石化攻击被二人同击遍体鳞伤出局。阿莎蕊雅速度与空间结合难寻，莫凡火山拳轰出。

**关键事件**：1.伽门侬破规冲区间，联盟破裂 2.莫凡阿莎蕊雅诱牧文入套 3.阿莎蕊雅黑暗剑姬伤莫凡，二人共灭牧文

- **情绪流向**：起：伽门侬破规联盟裂的波折 → 承：莫凡阿莎蕊雅诱敌的轻松 → 转：黑暗剑姬伤莫凡的紧张 → 合：共灭牧文的爽
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：伽门侬破规（波折） + 低调保存（设策） + 诱牧文（反转） + 剑姬伤莫凡（紧张） + 共灭牧文（爽）
- **本章核心技巧**：用"假内讧真诱敌"的戏中戏，把反派联盟的混乱转为清杂兵机会
- **卡点与伏笔**：结尾卡点：阿莎蕊雅剑姬难缠，下章兵不厌诈设冰锁陷阱；埋设/回收伏笔：黑暗剑主契约→阿莎蕊雅剑姬之力来源
