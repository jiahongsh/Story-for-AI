# 第178章 蜕皮女妖

**概要**：莫凡循阴影遁入小区幽暗的小树林搜妖，先撞见一对深夜幽会的年轻男女，销魂的声音听得他整个人都不好。灵灵通过蓝牙耳机指挥他去物业排查：青天猎所的徽章比警徽还好使，物业报出符合"二十岁以下、魔法师"的有六户登记，其中金玉阁18楼102住着三个明珠学府女生——从那女人的卧室正能看到，她们早是猎物。莫凡赶到102，开门的齐刘海女孩惊喜以为他一路跟来；话音未落，红唇女孩南南像被什么撞飞般从卧室倒飞进走道、后脑溢血瘫软，短发女孩贾文倩则被吊在天花板上，手腕动脉被割开、血顺着白皙的手不停滴落——一个满身鳞片的女人形态怪物张开大了几倍的嘴和长舌，享受地等血滴入喉咙，那张鳞片脸仍能认出正是白天委托的少妇。莫凡看清这活活吊人放血的折磨方式，怒火中烧，刚要施展烈拳，女妖跳窗而出，爪子吸抓垂直高墙、在两楼之间无声攀跳。莫凡让齐刘海女孩带伤者回学校治疗室，自己跳窗遁入十三楼阴影，却因楼间全是空气、没有光暗差而遁不过去。此时灵灵急报：那丈夫也在蜕皮，目标是孩子。莫凡弃追决定先救人完成委托。

**关键事件**：1.锁定金玉阁三女生为猎物 2.南南重伤、贾文倩被吊血 3.女妖现形跳窗攀墙逃走 4.丈夫同夜蜕皮袭子、莫凡回援

- **情绪流向**：起：轻松（林中幽会的乌龙） → 承：紧张（物业排查收窄） → 转：恐怖（吊血现场与女妖现形） → 合：紧张（双妖同袭、回援孩子）
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：林中搜寻（乌龙降温） + 物业锁户（排查收网） + 血案现场（恐怖爆发） + 双妖同袭（危机升级）
- **本章核心技巧**：把恐怖现场安排在主角晚到一步的时间差里，用受害者已受难、真凶正享受的构图点燃追击的急迫感。
- **卡点与伏笔**：结尾卡点：丈夫正在蜕皮、孩子命悬一线，下章期待屋内救人战；埋设/回收伏笔：白天拼车三女生→猎物铺垫兑现；青天猎所徽章的特权→组织公信力细节；楼间无光暗差遁不过去→暗影系行动限制的实战展示，呼应第172章伏笔。
