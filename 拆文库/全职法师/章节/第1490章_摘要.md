# 第1490章 真面目

**概要**：莫凡带众人来到被封的罗亚花园，以尤莱的血滴落花园泥土、罗亚花却没开为切入点，结合穆白在旁荒废草药地做实验发现植物药效失效，推理出有人偷偷改动了最靠近罗亚花园的土壤属性，使没带谎言的血无法与真正的罗亚花形成联系，从而掩盖害死尤莱的真相。莫凡串联线索，认定艾美拉为补全花徽夜里偷潜入罗亚花园、发现土壤问题，因而与尤莱一样被灭口。布兰妾证实尤莱没有撒谎也没有背叛，并揭出觅血器皿照见伊迪丝后院盆栽里映出尤莱的鲜血。面对铁证，伊迪丝终于爆发，供出因尤莱加入帕特农神庙、背叛阿尔卑斯山而无法原谅，认为她不配活在世上。

**关键事件**：1.莫凡借罗亚花园土壤与药效失效实验，推理出土壤被人改动掩盖真相 2.布兰妾揭发觅血器皿照出伊迪丝后院有尤莱的血 3.伊迪丝爆发承认杀尤莱与艾美拉，称因尤莱背叛阿尔卑斯山

- **情绪流向**：起：临门问案 → 承：推理逐层揭破 → 转：觅血器皿铁证定凶 → 合：凶手疯狂自白
- **节奏配比**：慢铺垫 50% / 快冲突 15% / 爽点爆发 5% / 悬念留白 30%
- **本章结构公式**：罗亚花园问罪（开场） + 药效实验旁证（推理） + 觅血器皿定铁证（爆发） + 伊迪丝自白供出动机（收束）
- **本章核心技巧**：用一环扣一环的小证据堆叠出不可辩驳的结论，再让凶手自白完成情绪落点
- **卡点与伏笔**：结尾卡点：信息揭示+伊迪丝承认杀人并供出动机；埋设/回收伏笔：觅血器皿 → 回收土壤移栽证据；清兰草药效失效 → 引出后续春药药效延迟线
