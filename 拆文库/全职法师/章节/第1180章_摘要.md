# 第1180章 死虫侵城

**概要**：黑暗骸旯被莫凡打散气息后，借不死虫萃取活人滋养变得更加强大，弯下头颅以通天般的黑暗犄角将莫凡钉在黑色光幕上，身上不断喷出难以愈合的血洞，心夏见状泪流不止，拼命以意志冲击束缚自己的有罪石，身后的帕特农神魂竟在她呼唤下苏醒、赐予柔和力量。莫凡转头看见神山被不死虫啃噬，对帕特农再无半点好感，反而在裁决法师被吞食时涌起一阵暴戾快意。不死虫继续向城市中心安全结界扩散，判官们愤怒指责圣裁院召唤出魔鬼。危急时刻图腾玄蛇游到黑暗刑场外，以毒雾领域将漫天不死虫尽数杀灭、阻止骸旯获得更多养料，帕特农众人松了口气。骸旯愤怒锤击光幕欲冲出撕碎玄蛇，两巨型生物对峙，莫凡获得喘息之机。

**关键事件**：1.骸旯犄角重创莫凡，心夏引动帕特农神魂 2.莫凡对帕特农生恨、对法师被啃噬感快意 3.不死虫向安全结界扩散，判官指责圣裁院 4.图腾玄蛇毒雾杀灭不死虫，与骸旯对峙

**逐章写法公式**：

- **情绪流向**：起：莫凡被犄角钉死的压迫 → 承：心夏引神魂的微弱希望 → 转：玄蛇解围的爽点 → 合：对峙喘息的暂稳
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：骸旯强化重创莫凡（加压） + 心夏引神魂（希望） + 玄蛇毒雾灭虫（解围） + 双巨兽对峙（钩子）
