# 第884章 黑血夺命

**概要**：旅客们以为只是抓些女子，抱怨回房虚惊一场，郭文衣长吐一口气拍胸脯。潘晋听人冠以"扫黄大队"的讽刺近乎抓狂。猎人队员大童刚要带女子离开，忽觉喉咙被堵说不出话，咳出一大口黑血喷在潘晋脸上；黑血！大童休克，治愈法师灰手以治愈蝶寻伤却遍身无伤，无从下手。大童吐尽黑血后身体干瘪发黑、如焦炭般剥落，在众目睽睽下死去。潘晋疯吼兄弟惨死，络腮胡子随即出现同样症状，闭嘴强忍仍鼓腮爆出血雾。死第二人瞬间引发恐慌，新人慌报李敏有异，潘晋转头见那新人嘴角也涌出黑血，更有人同时发作——恐怖在猎人团中急速扩散。

**关键事件**：1.旅客虚惊回房，潘晋被讽扫黄大队 2.大童突吐黑血无伤而死 3.络腮胡子同症、死第二人引恐慌 4.新人李敏等同涌黑血，多人同时发作

**逐章写法公式**：

- **情绪流向**：起：虚惊回房的轻松 → 承：扫黄讽刺的荒诞 → 转：大童无伤吐血死的恐怖 → 合：多人同时发作的蔓延钩子
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：虚惊回房讽扫黄（轻） + 大童吐黑血死（爆点） + 络腮胡子同死引恐慌（升级） + 多人齐发扩散（钩子）
- **本章核心技巧**：用"喜剧铺垫→离奇死局"的硬反转，把未知毒变的恐怖一次砸到读者面前。
- **卡点与伏笔**：结尾卡点：多人同时吐黑血、毒之魔鬼随机屠杀，下章期待毒变如何蔓延、主角群能否幸免；埋设/回收伏笔：黑血无伤致死 → 本章功能（毒变核心症状，后续全庄园爆发回收）；治愈蝶无伤 → 伏笔（非外伤系诅咒/毒，指向红茶潜伏）
