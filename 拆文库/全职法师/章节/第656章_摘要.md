# 第656章 阴风漩涡

**概要**：韩寂用枯荣巨花连续吞噬尸墙，为队伍打开通路。众人越过尸山后，来自煞渊的阴风越来越强，亡灵数量反而减少。左锋判断风舟无法继续维持，先带高阶法师撤离，独萧又救下被吸向煞渊的同伴。韩寂穿上魔铠继续护送莫凡、张小侯、方谷和苏小洛，四人中方谷、苏小洛和张小侯不受阴风影响，莫凡却被撕扯。小泥鳅坠释放冥河魂光包住莫凡，使他勉强得到保护。韩寂确认危居村后裔能进入煞渊，向四人道别并请求他们带来奇迹。

**关键事件**：1.枯荣巨花持续清除尸墙 2.阴风显示已接近煞渊 3.高阶法师撤离 4.三名危居村后裔不受阴风 5.小泥鳅魂光保护莫凡 6.韩寂送四人到极限位置

**逐章写法公式**：

- **情绪流向**：起：巨花开路 → 承：阴风逼退法师 → 转：血统与魂光验证 → 合：韩寂道别，四人抵达跳渊前
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：巨花清墙（继续推进） + 风舟失稳（削减护送） + 血统测试（确认资格） + 韩寂护送（完成交接）
- **本章核心技巧**：让环境本身承担筛选功能，使角色资格不是靠解释而是通过身体是否受伤直接验证。
- **卡点与伏笔**：结尾卡点：韩寂停在阴风极限位置，四人即将跳入煞渊；埋设/回收伏笔：小泥鳅坠中的冥河 → 保护非后裔莫凡通过阴风区域。
