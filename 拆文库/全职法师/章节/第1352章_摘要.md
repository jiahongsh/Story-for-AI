# 第1352章 从土里爬出来的真相

**概要**：莫凡刚下飞机便接到齐阳的电话，与灵灵、赵满延驾越野车直奔更北面的背脊草原。预防组共十人，齐阳为组长，多是隐藏者、监视者、追踪者，职责是寻找最有力证据再请求剿灭。镇子被毁、与黑教廷脱不了干系的现场令众人困惑：建筑物帐篷完整、值钱东西未少，却遍地血迹、一具尸体都没有，还找到一位精神失常的老牧民送医。组员大蝎猜是北疆荒兽食人，曲康坚称是毒系超阶魔法化人成血水，齐阳问莫凡，莫凡只答"都不是"，还问有吃的吗，让预防组大呼二世祖。莫凡席地用餐，眼见夕阳西沉才示意众人回来，曲康愤然斥责。此时镇子方向传出鬼怪般的叫声，干裂的泥土松动，一只只残缺不全、由不同人肢体拼凑而成的尸怪从土里爬出。莫凡点破这是亡灵——只见血不见尸，是尸体自己爬到土里等到夜里出现，训斥预防组连亡灵常识都没有。他困惑古都浩劫后亡灵已回归墓冢，北疆离亡灵之地有距离且不适合亡灵，不知为何出现被亡灵洗劫的镇子。

**关键事件**：1.镇子被屠、只见血不见尸的现场扑朔迷离 2.拼凑尸怪从土里爬出，莫凡点破是亡灵所为 3.莫凡困惑北疆出现亡灵，决定亲自查镇子、预防组继续追牧羊人

**逐章写法公式**：

- **情绪流向**：起：奔赴现场的紧张 → 承：无尸屠镇与组员争论的悬疑 → 转：尸怪爬出的惊骇 → 合：亡灵之谜与分头行动的沉重
- **节奏配比**：慢铺垫 45% / 快冲突 25% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：紧急北上会合（进入现场） + 现场勘查与争论（设疑） + 莫凡反常从容（伏笔） + 尸怪爬出（真相揭露） + 分头行动（新任务）
- **本章核心技巧**：用主角的"反常冷静"与组员的慌张形成对比，等到真相揭晓再反衬主角的先见，制造推理爽感
- **卡点与伏笔**：结尾卡点：亡灵之谜——北疆为何出现本不该存在的亡灵，古都浩劫的阴影重临；埋设/回收伏笔：精神失常的老牧民→目击者的证词待挖掘；拼凑尸怪→冥辉金字塔与死亡国度的直接产物
