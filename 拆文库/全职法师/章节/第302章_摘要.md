# 第302章 都杀了！

**概要**：黎明时分陆正河守在一言不发的穆宁雪身旁搭话无果，天边出现成对雪白羽翼降落在不远处，他看见后假装无事并暗中环顾寻找莫凡的身影。众人商定返程，许大龙爆出明聪已被廖明轩失手杀死，廖明轩冷汗淋漓否认后崩溃承认控制不了自己，穆宁雪以队长身份宣布返回，众人埋葬明聪、加固坟墓后沿火车铁轨撤离。刚出城，树林中出现二三十名牵着雪白巨鹰的制服队伍，赵明月、菁菁激动地以为是援军，彭亮庆幸郑冰晓有救，唯独赵满延察觉制服颜色古怪、陆正河目光躲闪。为首的叼烟斗男子与陆正河目光示意后，军统陆年轻描淡写下令"闲杂人等，都杀了"，并在陆正河求情时回答"所以才要都灭口"；赵明月、菁菁随即被脚下窜起的冰霜锁链贯穿，化作两具尸体。

**关键事件**：1.明聪死讯揭晓、队伍埋人返程 2.天鹰军法师队伍现身 3.陆年下杀令、赵明月菁菁惨死

**逐章写法公式**：

- **情绪流向**：起：压抑（返程前的死讯） → 承：轻松（出城、鸟鸣冲淡死亡气氛） → 转：恐怖（杀令与两女惨死） → 合：恐怖（屠杀开场未完）
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：死讯揭晓（收束蛊惑线）+ 埋人返程（悲情过渡）+ 假援军现身（误导）+ 杀令落地（反转开局）
- **本章核心技巧**：用"假救援希望"垫高再瞬间打碎，把真正杀令藏在一句轻描淡写的口语里制造语感落差
- **卡点与伏笔**：结尾卡点：杀令已下、两名女生瞬间惨死、屠杀刚开始，下章期待众人如何求生；埋设/回收伏笔：陆正河留信号→杀令真相→叛徒坐实；天鹰队伍制服颜色异常→军中败类集团线索；明聪之死→廖明轩罪责线
