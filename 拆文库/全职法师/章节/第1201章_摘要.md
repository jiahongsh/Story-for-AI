# 第1201章 沙下，危机四伏

**概要**：沙层之下开始涌动，阳光消失处根须如黑色蜈蚣蠕虫沸腾，一头悍兽眨眼被拖入沙下。张小侯高处催促快走，莫凡令他与两名土系法师在前硬化土地。日落实比想象快，众人到硬化区，阳光照不到处根须窜起包围，却因坚沙受阻。飞鼠自告奋勇带路，却踩入夜沙怖魔陷阱被根须树藤困住，葛明光系斩藤相救。张小侯在前方带路避陷阱，莫凡点出单只怖魔活动范围约三百米、离本体越近越难挣。张小侯又踩中一只怖魔陷阱，灵活缺口闯出、指挥绕开。郑通问谁去前面探路“踩雷”，牧奴娇自告奋勇化作风影消失，众人跟随后保持距离。郑通将责任推给莫凡，老猎人许平东质疑牧奴娇带路草率，主张让大健另带路，牧奴娇急喊“别走那里”。

**关键事件**：1.根须涌动、张小侯催硬化土地 2.飞鼠踩陷阱被葛明救 3.张小侯前方避陷阱、牧奴娇自告奋勇探路 4.许平东质疑改道、牧奴娇急喊别走

- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：根须涌动（加压） + 飞鼠被困（危机） + 牧奴娇探路（高光） + 许平东改道（悲剧钩子）
