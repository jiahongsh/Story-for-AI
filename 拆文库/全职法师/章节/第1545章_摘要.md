# 第1545章 一网打尽

**概要**：海夫拉攻势拖住军队注意力，莫凡三人顺利潜入开罗城区。莫凡凭留在阿帕丝身上的黑暗物质追踪到作战指挥镇，途中决定先救赵满延——赵满延身上携带国府徽章，徽章互感应可定位，且其护航能让莫凡肆无忌惮轰炸。作战指挥镇中心堡垒地下有秘密牢房，被俘的欧洲学府学员被关押。瓦尼来见学生，学生们感激瓦尼相救并咒骂莫凡。赵满延认出冈玛少将安然归来，识破瓦尼通敌。冈玛与萨斯密谋：不能放人，把瓦尼也关起来，并要抓住外面三人后一并处置、灭口。

**关键事件**：1.莫凡凭黑暗物质追踪阿帕丝至作战指挥镇 2.瓦尼探视被关学生，赵满延识破其通敌 3.冈玛与萨斯密谋抓全所有人后灭口，连瓦尼也不放过

**逐章写法公式**：

- **情绪流向**：起：潜入城区的谨慎 → 承：探监瓦尼现身 → 转：赵满延识破通敌 → 合：灭口密谋的危机
- **节奏配比**：慢铺垫 30% / 快冲突 10% / 爽点爆发 5% / 悬念留白 55%
- **本章结构公式**：追踪定位（确定目标） + 潜入指挥镇（逼近核心） + 探监反转（识破通敌） + 灭口密谋（危机升级）
- **本章核心技巧**：同时推进"主角逼近"与"反派密谋"两条线，让营救与灭口在同一节点对冲
- **卡点与伏笔**：结尾卡点：军方密谋连瓦尼一并拿下、抓到所有人就灭口，莫凡救人时间被压缩；埋设/回收伏笔：国府徽章定位、瓦尼被关
