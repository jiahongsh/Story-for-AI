# 第15章 妖魔怪谈

**概要**：莫凡送叶心夏回姑姑家，晚饭后照常练习雷系魔法却立刻头疼欲裂，才发现当天两次雷印已把雷系星尘的魔能近乎耗尽，星尘失去光泽陷入晦暗，休息后才缓慢恢复，他由此确认星尘库存魔能、施法即消耗的规则，并想起班主任薛木生强调冥修的教诲。睡到大天亮后星尘已明亮大半，莫凡盘算雷系不便暴露（怕遭博城只手遮天的穆氏世家等嫉妒），决定把火系修炼起来掩人耳目，将每天可承受的10小时冥修分配为8小时修火系、2小时温养雷系，而其他学生一天只能冥修5小时。午饭时小姑莫青下班回来，称莫凡若能成为初阶魔法师就是莫家光宗耀祖；谈到姑丈送物资进山，莫青转述猎者联盟警示文——博城之外频繁出现妖魔迹象，并压低声音透露城市附近一直有妖魔、甚至城市之内就有，还以自己在医院后勤部工作的见闻佐证：手术室一位治疗系法师曾怒斥中邪蛊惑的病人，要求去找猎者联盟查出邪眼沼妖。莫凡觉得不似瞎编，怀疑妖魔真的潜伏在城市之中，遇到一只必死无疑。

**关键事件**：1.莫凡首次体验魔能枯竭，确认星尘消耗规则 2.定下藏雷修火的冥修规划（8小时火系+2小时雷系） 3.莫青透露妖魔逼近博城、城市之内也有妖魔的传闻 4.莫青讲述手术室邪眼沼妖怪谈，莫凡开始相信城中潜伏妖魔

**逐章写法公式**：

- **情绪流向**：起：练功受挫（低落） → 承：规划翻盘（重燃） → 转：饭桌怪谈（不安） → 合：城中有妖的恐惧（悬念）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：消耗受挫（教学规则） + 冥修规划（定修炼目标） + 亲属闲谈（日常过渡） + 怪谈揭示（埋城市危机）
- **本章核心技巧**：用家庭饭桌闲谈承载世界观危险信息，以转述中的转述（莫青听来的手术室对话）给妖魔威胁加可信层
- **卡点与伏笔**：结尾卡点：妖魔可能潜伏城市之内、遇到必死无疑，下章期待危机是否降临；埋设/回收伏笔：邪眼沼妖与中邪蛊惑病人 → 城市妖魔事件线；猎者联盟警示文与安界 → 世界安全秩序设定；穆氏世家只手遮天 → 后续穆宁雪相关冲突；姑丈进山送物资 → 普通人涉险的隐患；8小时修火系规划 → 半年后考核释放火滋
