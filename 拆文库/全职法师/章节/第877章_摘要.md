# 第877章 信仰一个人

**概要**：赵品霖随茶色卷发女服务员芳少俪走入庄园幽暗偏廊，被带入一间尘封封厅，饮下她递来的药水后陷入一阵空间偏转的眩晕，随后落入可受操控的幻觉——在幻境中对汪栩栩泄愤。芳少俪以"梦想成真"蛊惑，称可帮他真实报复那对"狗男女"并占有那位银发女子穆宁雪，但要他先"信奉一个人"。清晨荣盛与莫凡同坐早餐，兴奋低声炫耀昨夜与汪栩栩确立关系、更亲密，莫凡正要夸赞，餐厅门开，赵品霖搂着汪栩栩亲密走入，荣盛脸上幸福笑意瞬间凝固，莫凡也愣住。

**关键事件**：1.赵品霖饮药水陷可控幻觉泄愤 2.芳少俪蛊惑梦想成真占有穆宁雪、要其信奉一人 3.清晨荣盛向莫凡炫耀与汪栩栩关系 4.赵品霖搂汪栩栩进餐厅，荣盛笑容凝固

**逐章写法公式**：

- **情绪流向**：起：随入密室的诡异 → 承：幻觉泄愤的暗黑 → 转：蛊惑占有的诱惑 → 合：清晨撞见入场的错愕
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：随入密室饮药陷幻（设谜） + 芳少俪蛊惑占有穆宁雪（诱线） + 清晨荣盛炫耀关系（甜铺垫） + 赵品霖搂人入场撞碎（反转）
- **本章核心技巧**：把"幸福炫耀"与"当场撞碎"放在章内首尾，用强反差把暗线招募与明线情感同时推到爆点。
- **卡点与伏笔**：结尾卡点：赵品霖搂汪栩栩入场、荣盛笑容凝固，下章期待汪栩栩为何变心；埋设/回收伏笔：可控幻觉药水 → 本章功能（黑教廷精神控制手段，后续回收）；信奉一个人 → 伏笔（赵品霖入教线）
