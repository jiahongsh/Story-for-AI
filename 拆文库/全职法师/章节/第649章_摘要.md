# 第649章 做点什么

**概要**：张小侯决定凭微薄的博城血统可能性跳入煞渊，苏小洛表示同行。面对莫凡的劝问，张小侯说自己不愿活着看着城市和同伴死去，哪怕只有千分之一、万分之一的机会也要尝试救人。莫凡因喝过地圣泉，决定与方谷、张小侯、苏小洛一起进入煞渊。祝蒙、独萧、石峥、李于坚等高层决定杀出道路，韩寂亲自保护四人，军司耀庭安排留守与突围。穆贺被封住心神吊在钟楼示众，石峥提出召集自愿者以更大牺牲换取突围时间。

**关键事件**：1.张小侯决定跳入煞渊 2.苏小洛和莫凡决定同行 3.高层组成护送力量 4.韩寂亲自保护煞渊小队 5.开始筹备大规模突围

**逐章写法公式**：

- **情绪流向**：起：血统犹疑 → 承：张小侯作出选择 → 转：高层集体响应 → 合：突围方案带出牺牲悬念
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：确定跳渊者（明确希望） + 高层表态护送（扩大行动） + 控制穆贺（暂时稳住内鬼） + 提出牺牲方案（抬高代价）
- **本章核心技巧**：用一个普通人的情感选择带动高层重新振作，再把个人冒险扩展为全城共同承担的突围行动。
- **卡点与伏笔**：结尾卡点：石峥提出需要更大牺牲的方案，下一章期待自愿者如何开路；埋设/回收伏笔：莫凡饮下地圣泉 → 成为进入煞渊的额外保护条件。
