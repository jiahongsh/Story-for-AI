# 第459章 沙啸虎！

**概要**：傍晚张小侯回话，冒着被处分的危险也要参加这次行动。夜里莫凡本已打算告诉张小侯不去了，心夏的电话却打了过来，一番「想在你身边离你更近」的剖白让莫凡醒悟自己把她保护得太严密，最终尊重她的决定。队伍就此确定：莫凡、灵灵、张小侯、心夏，加上赵满延带来的表姐晨颖——主修土系、帝都学府主校区总排行靠前的学员，一行六人乘风骆驼奔赴敦煌。过了界碑线妖魔骤然密集，风骆驼不敢前行，众人弃驼步行，刚走出不到五公里，便遇上敦煌土霸主沙啸虎，灵灵警告那是战将级中比较凶猛的生物。

- **情绪流向**：起：集结的兴奋 → 承：心夏电话剖白戳中心事 → 转：莫凡释然同意 → 合：踏入界碑线遭沙啸虎拦路
- **节奏配比**：慢铺垫 60% / 快冲突 15% / 爽点爆发 0% / 悬念留白 25%
- **本章结构公式**：张小侯应召（报喜） + 心夏电话剖白（情感转折） + 六人集结出发（铺势） + 沙啸虎拦路（卡点）

- **卡点与伏笔**：结尾卡点：遭遇战型，刚踏入敦煌地界便撞上战将级沙啸虎，下章期待首战表现；埋设/回收伏笔：晨颖土系主修 → 大漠土元素加成；界碑线 → 安界外妖魔密集的世界规则
