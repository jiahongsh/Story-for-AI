# 第1151章 闯神山

**概要**：帕特农裁决殿内十三判官闭门会，绝大多数判官信血石为最有力证据，认为若血石不能识别则罪石同样荒唐；判官上任滴血烙印于血石、由神官保管，闭门会取出各自身份罪石投举，且忘虫已证实，只差心夏亲口承认——但她因忘虫不知撒朗记忆，承认无意义。闭门会结束，两名超阶圣裁法师开门，包老头宋启明作为上代神官在门外等候，雷纳拍肩轻叹尽力，大判官杜兰克笑其十年未理事务，包老头冷言其下场如艾森德尔后离去，已知罪名将成立。莫凡顺山道过信仰殿、绕裁决殿抵星河山道，包老头与韩寂等在此等候，庞莱说天黑前宣布结果、唯闯山可提出见心夏，并告星河山道有古老压制结界、只能靠自身修为。庞莱苦劝莫凡失败则一身修为付之东流、圣裁判决无人可改，例举圣子文泰、暗影法师艾森德尔均未能免；莫凡说"如果保护不了她，再高的修为再多的荣耀有什么意义"，踏上星河山道。拱形石门裁决法师警告跨入即死，莫凡说考虑清楚了，古钟敲响、"星河山道一名闯入者"警报回荡，压制结界开启将他罩入混沌隧道，四尊杀气雕塑分伫梯次，消息轰动整座神山传遍雅典卫城。

**关键事件**：1.闭门会判官信血石，只差心夏承认但忘虫使其无意义 2.包老头门外知结果，杜兰克嘲讽后其离去 3.莫凡抵星河山道，庞莱告压制结界与闯山规则 4.庞莱劝莫凡勿白牺牲，莫凡决意闯山 5.警报响结界开，莫凡入山道消息轰动神山

- **情绪流向**：起：闭门会铁壁（压抑） → 承：包老头知结果（绝望） → 转：莫凡决意闯山（热血） → 合：警报结界开（紧张悬念）
- **节奏配比**：慢铺垫 35% / 快冲突 5% / 爽点爆发 0% / 悬念留白 60%
- **本章结构公式**：闭门会定调（压抑） + 包老头知结果离去（绝望） + 庞莱告规则劝退（加压） + 莫凡闯山警报响（爆发钩子）
- **本章核心技巧**：用"制度不可破+历史败例"双层加压，把主角闯山写成明知不可为而为之的孤勇，再以环境警报把个人行为仪式化
- **卡点与伏笔**：结尾卡点：悬念+莫凡入星河山道结界开启，下章期待四尊雕塑如何阻路；埋设/回收：包老头老神官身份（可后续干预判官）
