# 第364章 瘟病

**概要**：两人抵达地处安界要塞枢纽、鱼龙混杂的白镇，因瘟病扩散入镇需挨个检查，两人例行受检后被放行，连身份都没查。镇内街道空前冷清，摊贩绝迹、商铺无人，两人住进一家不登记身份的旅店。老板娘称瘟病自大蛇出现后蔓延，认定蛇是瘟疫源头、应尽早找出否则要死人，戴口罩的女儿质疑这些只是道听途说。莫凡察觉唐月有事隐瞒，追问不答；一间房的桥段被拆穿后，深夜两人在阳台对谈，唐月坦白蜕皮期的它确实无毒、但瘟疫是否与它有关她不知道，莫凡推断族长让它离开也是想把瘟疫源带离城市。唐月坚信瘟疫与它无关却方寸大乱，莫凡劝她理智考虑交出它，以免死难扩大。

**关键事件**：1.两人入镇受检、目睹瘟病下的冷清街市 2.老板娘的舆论指控将瘟病与大蛇挂钩 3.唐月坦白不确定瘟疫是否与蛇有关 4.莫凡劝交蛇、两人陷入去留之争

**逐章写法公式**：

- **情绪流向**：起：紧张（入镇挨个盘查） → 承：压抑（冷清街道与舆论指控） → 转：紧张（隐瞒被戳破与深夜坦白） → 合：压抑（交蛇与否的两难）
- **节奏配比**：慢铺垫 60% / 快冲突 10% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：入镇受检（虚假安全感） + 舆论指控（外部压力） + 隐瞒被戳破（信任冲突） + 去留之争（两难悬置）
- **本章核心技巧**：全章不见打斗，用口罩、救护车、市井对话等小镇群像细节把"蛇是不是瘟疫源"的疑云层层加压。
- **卡点与伏笔**：结尾卡点：两难抉择型——莫凡劝交蛇、唐月坚信无关却方寸大乱，期待瘟疫真相揭晓；埋设/回收伏笔：怪病在心夏处（第362章）埋设→本章在白镇与杭州地界全面显形。
