# 第875章 败类，说的是你！

**概要**：莫凡把林中带回的土装进口袋，本已吓跑的郭文衣又折返，莫凡谎称自己是警校生宽慰她那日只是看错，郭文衣将信将疑道谢离去。莫凡打发郭文衣后欲探林子深处，通讯仪显示穆宁雪正靠近，穆宁雪赶来问有何发现，莫凡告知郭文衣所说吃马之物基本是黑畜妖并带了土回去化验。二人潜入林子，撞见女管卡莉与城市猎妖队锋队长在暗中私会，借机串供——卡莉以身体与承诺换取对方在巡查中把地块记录写清白、掩盖庄园"中毒事件"。莫凡借暗影系潜藏紧贴穆宁雪以遮蔽气息，被穆宁雪冷斥为败类，末了穆宁雪点明"败类"说的正是莫凡。

**关键事件**：1.莫凡装土宽慰郭文衣谎称警校 2.穆宁雪前来，二人潜入林子撞见卡莉与锋队私会串供 3.偷听卡莉求包庇掩盖中毒事件 4.莫凡被穆宁雪斥为败类

**逐章写法公式**：

- **情绪流向**：起：宽慰郭文衣的轻松 → 承：潜入林子的紧张 → 转：撞破串供的愤怒揭示 → 合：被斥败类的搞笑钩子
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：装土宽慰郭文衣（收线） + 穆宁雪来探入林（推进） + 撞破卡莉锋队串供（爆点） + 莫凡被斥败类（反转钩子）
- **本章核心技巧**：章末用"败类"指代的错位反转，把严肃黑幕与角色拌嘴并置，松紧交替。
- **卡点与伏笔**：结尾卡点：穆宁雪冷冷点明"我说得是你"，下章期待莫凡如何圆场与继续查卡莉；埋设/回收伏笔：卡莉掩盖中毒事件 → 本章功能（坐实其黑教廷嫌疑，后续烟雾弹回收）；暗影潜藏 → 伏笔（莫凡能力，后续多次用于隐匿）
