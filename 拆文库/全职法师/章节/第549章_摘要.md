# 第549章 古都

**概要**：莫凡与柳茹赶上最后一班抵达咸阳的客机，机场已对所有乘客盘查身份和来意。柳茹因原本的身份记录为死亡而无法正常出示证件，莫凡以玩笑遮掩。二人白天乘疾星狼赶至西安，见到为容纳各城区居民而新建的巨大外城墙，确认古都的防卫已极度紧张。莫凡到钟楼魔法协会向张小侯教官飞角询问，得知张小侯在羊阳村和华村之间执行救援时失踪，遗骸未寻且军方无力核实。为前往羊阳村，他转到鼓楼猎者联盟招募熟手，却先听矮小猎法师说古都的救援委托多半只是收尸。

**关键事件**：1.莫凡和柳茹抵达咸阳 2.二人见到古都外城墙 3.飞角交代张小侯失踪地点 4.莫凡转往猎者联盟寻找向导

**逐章写法公式**：

- **情绪流向**：起：抵达的不安 → 承：城市戒备 → 转：失踪线索落地 → 合：救援任务受阻
- **节奏配比**：慢铺垫 55% / 快冲突 10% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：入境盘查（展示异常） + 穿城见墙（展示危机） + 军方问讯（获取坐标） + 猎者招募（抬高难度）
- **本章核心技巧**：用连续的通行限制和城市设施，把背景危机转成角色即将面对的行动门槛。
- **卡点与伏笔**：结尾卡点：羊阳村救援队伍难寻；埋设/回收伏笔：煞渊附近的羊阳村 → 后续探查地点。
