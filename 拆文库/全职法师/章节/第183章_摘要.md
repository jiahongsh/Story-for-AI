# 第183章 寄生妖魔在校区

**概要**：灵灵被问住后急电求助，得知蜕皮女妖有喝血习性后脸色大变——拥有传染能力的寄生妖魔无异于瘟疫。两人推断出寄生手法：女妖先把寄生血注入短发女孩体内，再把她吊起放掉原本的血，所以女孩没死、也成了携带者，学校已被寄生。红点持续增加，且都朝一个方向汇聚——今晚体育馆有偶像明星演唱会排演，七八千学生到场。灵灵的姐姐给出关键情报：妖血寄生在人的拇指处，给未蜕皮的携带者拇指割开口子即可解除；已蜕皮变妖的必须杀死才会恢复。学校高管把灵灵当恶作剧，猎者联盟已派更高称谓的猎人联系校方。莫凡不愿对携带妖血的正常人下手，决定独自先行冲入体育馆，由灵灵远程指示红点位置。抵达入口展示台时，红点与黑点重叠——一只青黄女妖趴在海报上方，灵灵耳中只剩一片打斗嘈杂。

**关键事件**：1.灵灵确认蜕皮女妖具备传染能力，学校已成寄生疫区 2.获得拇指开口解寄生、杀妖恢复两条处置规则 3.莫凡独自潜入体育馆救人与灵灵失去直观联系，入口即遇袭

**逐章写法公式**：

- **情绪流向**：起：紧张（传染确认） → 承：压抑（学校沦陷的推论） → 转：热血（莫凡领规则独闯体育馆） → 合：紧张（入口遇袭、断联悬念）
- **节奏配比**：慢铺垫 35% / 快冲突 30% / 爽点爆发 5% / 悬念留白 30%
- **本章结构公式**：求助定性（威胁升级）+推演真相（疫区成立）+领取规则（救人手册）+独闯遇袭（战斗开场即断联）
- **本章核心技巧**：用"仪器红点不断增殖"作为贯穿全章的倒计时装置，把静态的信息解释章压出紧迫感。
- **卡点与伏笔**：结尾卡点：命悬一线——女妖扑袭莫凡、灵灵只能听打斗声，读者急知战况；埋设/回收伏笔：短发女孩被吊放血→传染链源头；拇指割口规则→后续批量救人手段；演唱会排演→数千人聚集的祭坛；灵灵姐姐→幕后情报源。
