# 第1051章 神女候选人

**概要**：狼狈的波邦王子在蓝月桥畔被玫瑰小舟上的康蒂老师救起，奉茶暖身，愤称必不放过那中国国府选手，康蒂劝其以正规决斗报复、勿损王室颜面，波邦表面应承却心怀算计，又问起阿莎蕊雅。场景转至希腊雅典卫城帕特农神女殿，心夏向殿母菲琳禀报埃及普希尼城救治与破海市蜃楼之功（实乃莫凡之功她难为情），殿母破例推举她为神女候选人，大贤者梅若拉与众女贤立刻反对，指其心夏非血统、非国籍、无七位女贤举荐、实力未达，认为奖赏过头。

**关键事件**：1.康蒂救波邦，劝其正规决斗报复 2.波邦问阿莎蕊雅，存非分之想 3.心夏禀普希尼功，殿母推举为候选人 4.梅若拉等反对候选人资格

- **本章结构公式**：王子报仇线（暗） + 康蒂劝架（转折） + 心夏获殊荣（高光） + 大贤者反对（阻力）
