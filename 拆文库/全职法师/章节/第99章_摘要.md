# 第99章 （无标题）

**概要**：看着哭得哽咽的何雨，莫凡叹气——她在真妖魔面前与普通少女无异，再遇妖魔还会死人，他只能硬着头皮领队。莫凡向失魂落魄的小队训话：这不是历练而是殊死搏斗，赢了活着输了全死；他讲解主要对手巨眼猩鼠与独眼魔狼的差别，立下遇到三只以上独眼魔狼就各自逃命的红线，并告诫任何看似被击杀的妖魔都不可靠近。随后分派职责：张小侯探路、穆白用冰蔓护人，穆白压下对莫凡的成见点头应命。队伍穿过再无妖魔的一公里主街道，告知楼中未撤的老人和堵在路上的人等大部队跟上。进入如城中小公园般庞大的明园小区后，撞毁的围栏、水池里飘着保安尸体、被血染红的池水令众人汗毛竖立；周敏听见楼里有东西在叫，莫凡望见玻璃后非人的影子，催促别理会快走。张小侯探得前方五只以上巨眼猩鼠，莫凡下令绕行并拍肩肯定；张树华提议杀掉游泳池边喝水的猩鼠，被莫凡以魔能比沙漠里的水都宝贵驳回。九人选宽敞通达的路线，有惊无险穿过明园小区。

**关键事件**：1.莫凡正式接管带队并向全队立下生存规矩 2.队伍绕开五只以上巨眼猩鼠、拒绝无意义战斗，安全穿过明园小区 3.确立遇三只以上独眼魔狼各自逃命的红线

**逐章写法公式**：

- **情绪流向**：起：压抑（训话与何雨的眼泪） → 承：紧张（立规矩、穿街入区） → 转：恐怖（血池尸体与楼中影子） → 合：轻松（绕行避战，有惊无险穿过小区）
- **节奏配比**：慢铺垫 45% / 快冲突 15% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：训话立规（定生存法则）+分派职责（团队成型）+穿街入区（氛围加压）+绕行避战（喘息收束）
- **本章核心技巧**：用规则前置的训话章压住节奏，把威胁分级写成可执行的逃生数字标准，再用环境尸体细节兑现压迫感，全程不打一场仗也维持紧张。
- **卡点与伏笔**：结尾卡点：推进悬念——明园小区已过、离安全结界更近，但更大的威胁独眼魔狼尚未现身；埋设/回收伏笔：三只独眼魔狼逃生红线→后续遇狼回扣；穆白咽下成见→人物关系缓和线；楼中非人影子→小区藏妖佐证；何雨的水御之诺→待兑现的救命技能。
