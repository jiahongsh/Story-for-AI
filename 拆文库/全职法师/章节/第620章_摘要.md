# 第620章 49颗星子！

**概要**：人潮末端接近死街中央，却没有人愿意主动断后，莫凡只好从高处下来和疾星狼守住队尾。他捏碎亡灵结晶只恢复十六分之一魔能，随后肉丘尸臣发出黑暗吐息并弹跃着冲向人群。左锋和另一名禁卫法师被尸臣缠住，左锋让莫凡带法师逃走，莫凡却看见几百名撤离者即将被尸臣吞下并转成骷髅。人群因恐惧停滞，莫凡怒斥左锋后让疲倦的小炎姬附体。他取出刚凝炼的精魄灌入火系星云，最后一颗星子被强化，四十九颗星子全部点亮。

**关键事件**：1. 莫凡和疾星狼承担无人愿意负责的队尾断后 2. 肉丘尸臣突破禁卫法师牵制冲向人群 3. 莫凡完成四十九颗火系星子强化并准备施放烈拳

**逐章写法公式**：

- **情绪流向**：起：疲惫断后 → 承：尸臣逼近 → 转：绝望与愤怒 → 合：小炎姬附体、星子圆满
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：队尾无人守（建立责任缺口） + 资源微量恢复（加重限制） + 尸臣突破（制造终极压迫） + 群体绝望（封锁选择） + 四十九星完成（蓄积反击）
- **本章核心技巧**：把升级资源和倒计时危机绑定，让主角的强化既是能力兑现也是一次无法回避的选择。
- **卡点与伏笔**：结尾卡点：莫凡已完成四十九颗星子强化，尸臣正冲向人群；埋设/回收伏笔：精魄数量上升与四级烈拳 → 下一章释放陨拳九蛟。
