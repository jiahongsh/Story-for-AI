# 第748章 破烂不堪的羽衣

**概要**：众人登岛后艾江图震惊于莫凡独杀赤色裂妖，官鱼归于妖魔旧伤使莫凡侥幸得手，艾江图却因深知赤色裂妖仍具统领之力而判定莫凡强于预期，南珏推测莫凡藏有未露之系，实则为火系与召唤系结合的小炎姬附体。隐患消除后众人抬莫凡返航，莫凡望向穆宁雪，穆宁雪见其死而复生且实力超估心绪复杂，莫凡以"冻海相救当娶以报"相戏，穆宁雪冷脸否认情愫，队伍却因莫凡连日调笑与冰堤之举误信二人有婚约。返飞鸟市后赵满延告知小迪被南荣倪治愈并获祝福，婴孩案仅拔飞鸟市毒瘤、线索上交导师，莫凡心情沉重；韩寂托导师送来古都博物馆绝品残破羽衣琉璃凰羽，莫凡决意复苏后赠予心夏。

**关键事件**：1.众人确认莫凡独杀统领，艾江图与南珏重估其力 2.莫凡戏言娶穆宁雪报恩，队伍误信婚约 3.赵满延报小迪获救、婴孩案线索中断，韩寂赠琉璃凰羽

**逐章写法公式**：

- **情绪流向**：起：震惊确认战果 → 承：群像重估实力 → 转：婚约误会的甜闹 → 合：黑幕钩子与羽衣温情
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：群像确认独杀（回收） + 实力重估（铺垫） + 婚约调笑（调剂） + 案件交割与羽衣到手（钩子+温情）
- **本章核心技巧**：用不同角色对同一事实的反差反应（侥幸/强/藏系）做信息差递进，最后以温情礼物收束
- **卡点与伏笔**：结尾卡点：无（温情收束）；埋设/回收伏笔：琉璃凰羽 → 后续复苏赠心夏；婴孩案更大黑幕 → 长线伏笔
