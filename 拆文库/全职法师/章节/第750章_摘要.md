# 第750章 阴曹蝎

**概要**：塔克拉玛干沙漠中，一座山峰般的尸物踏入蛇蝎狂妖领地，踩踏得族群退散，十几只统领级剧疫蛇蝎簇拥着从沙丘下苏醒的沙漠霸主阴曹蝎，阴曹蝎受威胁率众包围入侵者，却见山峰之尸听从头顶一个"人"的号令按兵不动，那人黑色眸子射下冷芒，阴曹蝎与剧疫蛇蝎战意尽散，山峰之尸从旁走过直奔天山，阴曹蝎灵魂深处的恐惧久久不散。镜头切回太平洋，莫凡首次出海初时兴奋、久则枯燥，整日炸金花与修炼，嫌航行太慢，众水系法师轮流施法将游轮化作快艇箭一般疾驰，甲板上浪花扑面众人畅快。

**关键事件**：1.阴曹蝎率众包围山峰之尸却被峰顶之人震慑退避 2.莫凡首航太平洋觉枯燥 3.众水系加速轮船成快艇

**逐章写法公式**：

- **情绪流向**：起：沙漠压迫铺陈 → 承：霸主苏醒围杀 → 转：一眸退百万兵 → 合：航海轻松加速
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 20% / 悬念留白 20%
- **本章结构公式**：尸物入侵踏疆（铺垫） + 阴曹蝎苏醒围杀（加压） + 峰顶之人震慑退敌（爆发） + 航海加速（收束过渡）
- **本章核心技巧**：用"铺高反派威力+一笔神秘强者压制"做对比锚点，留强者身份做长线钩子
- **卡点与伏笔**：结尾卡点：无（轻松收束）；埋设/回收伏笔：峰顶"人"与山峰之尸 → 神秘强者长线；天山方向 → 后续地图
