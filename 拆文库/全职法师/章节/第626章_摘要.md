# 第626章 软禁高层

**概要**：神秘灰白男子要求众人尽快寻找方谷，韩寂派出禁卫法师并透露自己另有外部人员追查。男子离开后，一具穿着相同衣物的尸体在钟楼南巷被发现，众人以为他已被黑教廷杀死，随后真正的神秘男子现身，说明死者是替身，且有人泄露了集会内容。韩寂确认在座高层中可能藏有撒朗同党，为保证救援计划不被破坏，他调来禁卫法师将所有人包围并用灵魂之链束缚。

**关键事件**：1.韩寂决定寻找方谷 2.神秘男子用替身验证高层中有内鬼 3.韩寂软禁钟楼高层 4.救援计划进入强行保密状态

**逐章写法公式**：

- **情绪流向**：起：愤怒与焦急 → 承：替身死亡造成震荡 → 转：真正男子现身反转 → 合：高层被束缚，危机继续加压
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：确认追查方谷（启动行动） + 抛出替身尸体（制造假死） + 解释监视安排（锁定内鬼） + 软禁高层（确保计划）
- **本章核心技巧**：用一次可验证的替身牺牲，把“有人泄密”的抽象猜疑转成现场证据。
- **卡点与伏笔**：结尾卡点：高层被灵魂之链束缚，方谷尚未找到且古都将覆灭；埋设/回收伏笔：神秘男子的替身 → 验证钟楼集会确实被泄露。
