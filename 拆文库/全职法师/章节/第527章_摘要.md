# 第527章 致命呼吸！

**概要**：夜幕再临，队伍西行无人说话，腐臭死气弥漫。方谷传授的避亡灵之法是：亡灵不靠视觉追踪，视觉差、听觉一般，全靠吞吐死气感知活物呼出的生气，解决呼吸问题即可避其追踪；奴仆级亡灵掩盖气息便够，战将级还要保持绝对静止。众人吃下能掩盖生气的黑蒜状灰蒜，干呕一片。尸物开始从土中钻出，一颗满是蠕虫的脑袋出现在女军官肖静脚边，石少菊按住欲施法的她，众人在上百只亡灵间化作雕塑。张小侯面前两只骷髅近在咫尺，他闭气到极限，试探着缓缓呼出一口气，前面那只骷髅猛然转头，腥红双目直勾勾盯着他，锈迹大闸刀有了举起的迹象。

**关键事件**：1.方谷之法揭晓：亡灵靠嗅生气追踪，灰蒜可掩盖 2.队伍吃灰蒜后遭遇尸群钻出，全员屏息成雕塑 3.张小侯闭气到极限呼出一口气，骷髅转头举闸刀

- **情绪流向**：起：夜幕将临的恐惧 → 承：方谷方法的科普 → 转：吃蒜干呕的插曲 → 合：骷髅转头提闸刀的窒息
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：暮色行军（氛围）+ 避亡灵法科普（规则）+ 尸群包围（危机）+ 呼出一口气（临界）
