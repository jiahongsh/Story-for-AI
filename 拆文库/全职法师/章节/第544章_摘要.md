# 第544章 对手，东方烈！

**概要**：莫凡回想牧奴娇和穆宁雪都可能因家族资源背上束缚，又盘算小炎姬带来的开销，决定出售怖魔种子并接灵灵的委托补充资金和精魄。五天后才举行提名比赛，他确认三天的任务不会冲突。随后莫凡在雾中的明珠学府迷路，赶到比赛场才得知本场对手是火院首榜东方烈，赛场聚集了许多高手。比赛前灵灵为他转移损坏手机的数据，并提醒其中有一条与张小侯有关的重要信息；莫凡意识到张小侯已久未联络，信息成为开赛前的悬念。

**关键事件**：1.莫凡因小炎姬花销决定卖怖魔种子并向灵灵接委托。 2.莫凡赶到提名赛场，确认对手是火院第一东方烈。 3.灵灵转移手机数据并提醒张小侯相关信息。

**逐章写法公式**：

- **情绪流向**：起：轻松盘算 → 承：日常窘迫 → 转：强敌压场 → 合：未读消息带来的不安
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：家庭花费盘算（确立委托） + 抵达赛场动作（进入比赛） + 强敌身份揭示（抬升难度） + 手机通知（埋下突发线）
- **本章核心技巧**：把赛前说明拆入迷路、观众和电话等连续小事件，使战力信息与突发信息同时推进。
- **卡点与伏笔**：结尾卡点：信息钩子，张小侯相关的未读信息等待莫凡查看；埋设/回收伏笔：手机数据导入 → 为下一章噩耗的突然出现提供触发动作。
