# 第690章 内城之上的搏斗！

**概要**：山峰之尸见渺小的恶魔莫凡虐杀它的腐尸军团，彻底暴怒，举起一臂抡过云层卷万钧狂澜砸落内城，一整个一公里长宽街区瞬间夷为粉末；然而陷在粉末中的小人型竟缓缓爬起——恶魔莫凡没死。紫黑电弧在他周身飞舞，他抹去嘴角溢血，渐变紫色的瞳孔再次与高耸的山峰之尸对视。天幕紫黑擎天闪电劈落，竟如浇铸般落在莫凡邪异身躯上，他双臂迎雷化作数十条紫黑游龙，弹射而起将一拳轰在山峰之尸锁骨那处旧伤上，雷电游龙将针口般创伤凿成醒目大窟窿，尸君鲜血如瀑布浇灌而下、后退数百米。钟楼高层从崩塌的邪眼铜镜后本以为莫凡已随空间灭亡，却惊见他逆乱流冲回外城与山峰之尸厮杀，一掌拍下时莫凡惊险移形避过、跳上金色结界。山峰之尸跃到结界之上站立于人们头顶，赵坤三、王三胖仰头认出那魔纹夸张的脸正是莫凡。恶魔莫凡虽暴躁却不失理智，清楚力量对拼是自寻死路，决定去寻找七位超阶法师留在尸君身上的旧伤予以重创。

**关键事件**：1.山峰之尸一臂夷街区，莫凡未死爬起 2.莫凡借擎天闪电化游龙，拳轰锁骨旧伤 3.高层惊见莫凡逆乱流归来 4.尸君跳上结界，赵坤三等认出莫凡 5.莫凡定计寻七强旧伤重创尸君

**逐章写法公式**：

- **情绪流向**：起：尸君暴怒砸街区的绝望 → 承：莫凡爬起硬抗 → 转：游龙轰旧伤爽点 → 合：认亲与定计钩子
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：一臂夷街（加压） + 莫凡未死（反转） + 游龙轰伤（爽点） + 寻旧伤定计（钩子）
- **本章核心技巧**：把“boss旧伤”收束为可操作的战术目标，串联前情与当前战局
- **卡点与伏笔**：结尾卡点：莫凡要找七强旧伤重创尸君，读者期待他如何逐个利用；埋设/回收伏笔：七位超阶法师留伤 → 成为莫凡攻击的坐标
