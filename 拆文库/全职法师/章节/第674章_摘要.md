# 第674章 破灭，骷髅族群！

**概要**：首批亡灵被大量歼灭后，苏小洛提议趁后半夜赶往血祭坛，张小侯也为莫凡的战力自豪，但前方很快再次出现更大的银色空间漩涡。漩涡将外城亡灵汪洋中的骷髅不断卷入死门间，内城一度将其视为削弱围城亡灵的机会。左锋和妖男却在钟楼目击整片骷髅被转移，邪眼铜镜中随即出现密集白骨，确认死门间内落下了近万只骷髅。高层的希望由反复摇摆转为破灭，陆虚断定四名年轻法师必死，韩寂也放弃继续观看，转而准备内城最后的逃亡计划。

**关键事件**：1.小队准备趁夜离开死门间。 2.更大的银色漩涡在前方出现并持续投下亡灵。 3.内城短暂将漩涡当作削弱亡灵汪洋的机会。 4.高层确认近万骷髅被送入死门间，救援希望崩塌。

**逐章写法公式**：

- **情绪流向**：起：轻松 → 承：紧张 → 转：压抑 → 合：悲伤
- **节奏配比**：慢铺垫 20% / 快冲突 20% / 爽点爆发 0% / 悬念留白 60%
- **本章结构公式**：战后撤离动作（延续希望） + 空间漩涡再现（制造异常） + 外城视角解释来源（扩大规模） + 铜镜确认骷髅族群（击碎希望）
- **本章核心技巧**：用同一空间漩涡在内城与死门间的相反意义，先制造利好错觉，再以全景信息完成反转。
- **卡点与伏笔**：结尾卡点：绝境悬念，四人将面对近万骷髅军团；埋设/回收伏笔：银色漩涡通向死门间 → 将外城骷髅持续转移为小队的新敌人。
