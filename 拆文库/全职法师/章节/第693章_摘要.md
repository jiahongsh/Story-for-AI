# 第693章 血王座，古老王

**概要**：九死一生桥开始崩塌，坠入黑色深渊被黑风切碎，唯一剩下的真桥通往陵墓祭坛。祭坛漂浮在无穷黑暗中如亘古石台山，冰冠般的巨阶高过数倍人身，棱角垂落的不是丝绸而是灌溉而下的黏稠血瀑布，龙之颅吐出血水令人毛骨悚然。苏小洛、张小侯、柳茹千辛万苦攀上祭坛顶，见到中央红色翡翠组成的血王座，座上坐着一人——竟是独自走了另一条桥的方谷。方谷缓缓抬下巴开口，自称便是继承古老王一切的统治者，真正的古老王早已消逝，留下与皮囊粘在一起的铠袍与号令亡灵国度的血王座；谁先抵达谁继承一切。苏小洛求他退去亡灵、停止煞渊漂移，方谷却大笑说士兵将臣要帮他夺回都城。三人退却，发现方谷早已不是活人。方谷变尸扑向苏小洛，柳茹将其摔地刺穿心脏，方谷竟不堪一击、只是被铠袍抽空的祭品空壳；黑色铠袍吸尽其生命后飘回王座。祭坛剧烈晃动，煞渊最后一次空间漂移将至，苏小洛悟出古老王复苏需以百万活人为血池祭品。张小侯咬破嘴唇冲向空荡荡的铠袍，却在被包裹前一刻被一双有力的手抛出——来人正是总教官斩空。

**关键事件**：1.三人抵达血王座，方谷自称继承古老王 2.方谷变尸扑苏小洛，被柳茹刺穿心脏成空壳 3.铠袍吸尽方谷飘回王座 4.煞渊将最后一次漂移，苏小洛悟血池祭品 5.张小侯冲铠袍，被斩空救下

**逐章写法公式**：

- **情绪流向**：起：抵达祭坛的艰辛与希望 → 承：方谷身份反转的惊疑 → 转：变尸空壳与铠袍真凶 → 合：煞渊漂移与斩空救场钩子
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：攀抵血王座（抵达） + 方谷继位（反转） + 变尸空壳（破局） + 铠袍危机（钩子）
- **本章核心技巧**：用“人非人、物为真凶”的两次反转，把祭坛场景从解谜扭向更大危机
- **卡点与伏笔**：结尾卡点：张小侯险被铠袍吞没却被斩空救下，读者期待斩空能否压制铠袍、阻止血祭；埋设/回收伏笔：血王座铠袍吸食生命 → 后续斩空以自残同归于尽对抗
