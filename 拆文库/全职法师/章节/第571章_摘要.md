# 第571章 同学聚会

**概要**：莫凡、穆白、赵坤三、王三胖、周敏五人坐在一家陕西菜餐厅，这是博城灾难后唯一一次高中同学聚会。周敏说柳茹先回去了，问莫凡是不是有女朋友，又故意让莫凡看看他现在什么等阶，把意念探进莫凡精神世界，探到其中一个第二级星云便被赶出，噘嘴说也不过如此，王三胖怪叫第二级星云已经很强了。穆白解释古都学府以杀亡灵数量作学分排名，想获提名之争的人夜里都去外城墙蹲着，周敏说今天本要执勤，为聚会特意从远处偷跑过来。赵坤三提起许昭霆，王三胖认真追问兄弟怎么死的，莫凡平静说我把他焚掉的，解释完后众人沉默良久，周敏咬牙痛骂黑教廷。王三胖提议去城墙陪周敏执勤杀亡灵泄愤，众人一致同意。

**关键事件**：1.周敏探查莫凡修为只见第二级星云，王三胖受打击 2.王三胖追问许昭霆死因，莫凡说出焚化经过，众人沉默 3.王三胖提议去外城墙杀亡灵泄愤，众人同意

**逐章写法公式**：

- **情绪流向**：起：宽慰（老友重逢） → 承：轻松（互探修为） → 转：沉重（许昭霆之死） → 合：热血（约战亡灵）
- **节奏配比**：慢铺垫 60% / 快冲突 10% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：叙旧寒暄（情绪建立） + 修为互探（喜剧落差） + 许昭霆追问（情感爆发） + 城墙之约（行动钩子）
- **本章核心技巧**：把沉重往事放进热闹饭局，用氛围反差加重情感分量
- **卡点与伏笔**：结尾卡点：城墙刷分之旅会遇什么，下章期待战亡灵场景；埋设/回收伏笔：许昭霆的焚化之死与黑教廷仇恨
