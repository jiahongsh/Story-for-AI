# 第191章 血腥盛宴

**概要**：莫凡开价先要一件翼魔具，赵满延当场停步放话"你自己去吧，死多少人都不关我的事"；莫凡改口要灵级雷种、否则自己去，赵满延骂了句"算你这贱人够狠"咬牙成交——灵级雷种几千万上下、是拍卖行分分钟被抢走的紧缺资源，但他算过用一颗雷种为赵家换名望是稳赚的交易。两人抵达三楼，得知此处红点密密麻麻，相视苦笑。大广场排演开场：男粉丝举牌应援、人造雨洒落、热舞伴舞引爆全场，学生们浑然不知体育馆早已危机四伏——那些中途去洗手间的害羞女孩，很可能正在换掉一层皮囊。莫凡与赵满延在透明走廊俯瞰：四五千观众中不下一百人被寄生，血正是母妖最需要的东西，血越多它越强。灵灵急报其他区域的青黄女妖正全部往中央场馆聚集，符合它们吸血寄生条件的女魔法师少说三千，若让寄生继续，母妖实力可能突破统领级。赵满延首次露出犹豫问莫凡怕不怕，莫凡答比这更危险的场面都见过，随即让他看身后——一群穿志愿者制服的女生围了上来，还有人喊这里是三楼工作区别乱闯，莫凡低声说：全是红点。

**关键事件**：1.莫凡以灵级雷种为价与赵满延成交头功交易 2.演唱会排演的狂欢与寄生者潜伏形成血腥盛宴前夜的反差 3.二人抵达三楼即被一整群伪装成志愿者的寄生者包围

**逐章写法公式**：

- **情绪流向**：起：轻松（讨价还价成交） → 承：恐怖（狂欢盛景下的换皮预兆） → 转：压抑（百人潜伏、三千目标、统领级警告） → 合：紧张（红点围身卡点）
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：交易成交（合作关系定型）+排演狂欢（灾难前的暖场）+敌情解密（规模与最坏预期）+志愿者围身（图穷匕见收尾）
- **本章核心技巧**：全章把"盛宴"意象双关使用——演唱会的狂欢盛宴与妖魔的血腥盛宴互为镜像，用氛围反差替代战斗推进恐怖。
- **卡点与伏笔**：结尾卡点：身陷重围——一群伪装志愿者的寄生者将二人堵在三楼，开打在即；埋设/回收伏笔：灵级雷种→与莫凡攒钱买雷种的旧目标对接；一百潜伏者、三千目标→屠杀规模预告；统领级→母妖实力上限悬念；洗手间换皮细节→即将到来的集体蜕皮。
