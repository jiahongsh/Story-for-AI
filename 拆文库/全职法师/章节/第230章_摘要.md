# 第230章 大混战（上）

**概要**：莫凡走到广场水池中央，当众宣称老家的特殊泉水被暗影妖兽吞下肚子，谁要妖兽就拿去、他只要泉水，实为告诉藏在学员中的黑教廷成员地圣泉就在这里、有本事跟上千名学生抢。黑教廷小队中的傅天明识破这是诱使，教士宇昂却因手下确认暗影妖兽呼吸中确有地圣泉气息、审判会的人不在附近，决意乘乱杀掉莫凡带走地圣泉，幻想借此升为蓝衣执事，下令不用教廷力量、由手下去抢。牧奴娇在楼顶察觉莫凡今日阴沉、周身缭绕黑暗气息，与当初他挣脱坤之林囚牢时相同，怀疑他会黑暗魔法或身怀黑气器皿。莫凡以道歉为名把暗影妖兽甩给白藏锋，点燃混战：王力挺率先驱食骨妖以利刃羽毛放倒十几人，放话嗜血召唤兽把控不好、死了别怪他冷血；校方早有言在先，争夺中伤亡一律自己负责，弱者纷纷退出。

**关键事件**：1.莫凡公开"泉水在妖兽肚子里"引蛇出洞 2.宇昂决定乘乱夺泉并杀莫凡 3.莫凡把暗影妖兽甩给白藏锋点燃混战，王力挺率先出手震慑全场

**逐章写法公式**：

- **情绪流向**：起：紧张（牧奴娇察觉黑气） → 承：爽（莫凡当众下饵挑衅） → 转：压抑（宇昂决意杀人夺泉） → 合：紧张（混战爆发、王力挺震慑全场）
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：旁观者疑窦（埋黑气伏笔） + 当众下饵（逼黑教廷现身） + 反派密议（暴露杀意） + 甩兽点火（混战开场）
- **本章核心技巧**：主角用一句公开喊话同时操纵千名学员与暗藏的敌人，把"找内鬼"难题转化为"让敌人自己来抢"的诱饵战
- **卡点与伏笔**：结尾卡点：混战卡点——王力挺占据妖兽、群狼环伺，下章期待黑教廷出手与莫凡收网；埋设/回收伏笔：牧奴娇对黑暗气息的怀疑 → 小泥鳅/暗影系秘密伏笔；宇昂"蓝衣执事"野心 → 黑教廷层级线索；校方伤亡自负规定 → 为后续死伤免责铺垫
