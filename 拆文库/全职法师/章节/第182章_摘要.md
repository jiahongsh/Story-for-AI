# 第182章 追踪女妖

**概要**：莫凡自言自语总结出埋头苦修不如生死战斗刺激潜能的经验。回到宿舍撞见反常留宿的赵满延和张平谷，张平谷欲说八卦被赵满延喝止。灵灵来电，她用蜕皮女妖褪下的皮取了血样，做成接入血液数据就能定位的追踪器；委托人开出一百万先付的赏金，要他们救回女主人。两人宿舍楼下会合，灵灵展示魔都电子地图：接入U盘状装置后，携带该血液的女妖位置会以红点显示。等待激活时灵灵讲解寄生原理——被害者是被特殊寄生妖魔寄生的人，白天正常、夜里妖魔汲取养分霸占身体；杀死变妖时的怪物，人就会恢复正常，男主人已被观察验证。可地图激活后红点密密麻麻连成红斑，且就在学校附近不断增多。莫凡猛然冒冷汗，严肃问出关键问题：这种寄生妖怪有没有可能像传染病一样传播。

**关键事件**：1.灵灵用妖皮血样制成血液追踪器，委托升级为一百万救回女主人 2.灵灵讲清寄生原理与解除寄生的方法 3.地图显示学校周边红点密集成片且持续增加，莫凡惊觉寄生妖魔可能传染

**逐章写法公式**：

- **情绪流向**：起：轻松（宿舍闲谈、奶茶会合） → 承：紧张（百万委托与追踪启动） → 转：压抑（寄生原理揭开、红点密布） → 合：紧张（传染疑问出口，答案留给下章）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：经验复盘（收上一章）+委托升级（新目标入场）+原理讲解（建立怪物规则）+仪器异象（抛出最大悬念）
- **本章核心技巧**：用"先立工具的可信度、再让可信工具显示不可信的结果"制造认知反差，把恐怖感压进一个电子地图的红点读数里。
- **卡点与伏笔**：结尾卡点：悬而未决——寄生妖魔会不会传染、红点为何密集成斑，逼读者翻下章；埋设/回收伏笔：蜕皮女妖血样追踪→锁定母妖位置的技术线；一百万委托→金钱动机线；男主人不再蜕皮→杀妖解寄生规则被验证；张平谷被打断的八卦→校园异变的侧面消息。
