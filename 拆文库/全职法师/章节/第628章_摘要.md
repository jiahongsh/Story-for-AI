# 第628章 莫凡，杀意凛然！

**概要**：柳茹确认送血迹的人一直跟着华村，跟踪他们的另有人随后现身，正是伪装混入人潮的方谷。方谷澄清危居村其他六村的死亡由黑教廷造成，并说明黑教廷夺取昆井之泉、让药师苏放炼制九幽之露，借大雨发动亡灵浩劫。他承认自己杀死华村留守者并带走昆井之水，同时指出黑教廷正在假山后挟持村民诱捕自己。方谷提出联手，莫凡却要求由自己亲手杀死这些把博城当作实验场的黑教廷成员。

**关键事件**：1.方谷现身 2.方谷揭露黑教廷利用危居村和博城的计划 3.假山后发现黑教廷埋伏 4.方谷提出联手 5.莫凡决定亲手复仇

**逐章写法公式**：

- **情绪流向**：起：跟踪疑云 → 承：方谷现身与敌意 → 转：博城预演真相引爆杀意 → 合：三人联手但莫凡坚持亲手复仇
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：确认跟踪者（揭示方谷） + 澄清六村惨案（重组敌我） + 发现黑教廷埋伏（制造即时目标） + 约定联手（锁定复仇方向）
- **本章核心技巧**：让反派相关人物先承认自身罪行，再补足更大幕后链条，使敌我关系从单线仇恨变成多方冲突。
- **卡点与伏笔**：结尾卡点：莫凡杀意凛然，要求亲手杀死黑教廷成员；埋设/回收伏笔：昆井之水、九幽之露与博城雨水 → 串联两场灾难。
