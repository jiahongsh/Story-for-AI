# 第18章 队友很重要

**概要**：莫凡报名火系后，唐月探查他气息时唇不由张了张；赵坤三当众揭底，称莫凡上学期期末测试火系星尘和刚觉醒时没差别、一颗星子都把控不了，全班皆知。唐月却惋惜地点出莫凡火系天赋挺好、只是修为太弱，叮嘱他不用功可不行。莫凡明悟气息法则：精神力可感知他人修为、修为瞒不住，但只要隐藏雷系只表露火系，就能借火系掩人耳目；又因刚要学火系就来了厉害的火系老师而信心大增，有望大考核前释放火滋。周敏则因班主任薛木生说过莫凡是班里火系天赋最好、连唐月也说他天赋好而心生不平，盘算年度考核不合格者将被请离学校，莫凡只能再逍遥半年。唐月随后宣布考核规则：不合格请离、按成绩再分班、尖子班享厚爱，她将任尖子班实践课老师，并许诺能完全掌控七颗星子者可私下找她辅导，七颗星子顿时成为全班奋斗目标。学生们攀比星子数（黄飞峰3颗、许青林近4颗），赵坤三吹捧穆白已掌握5颗、连全校最厉害的七班雷系学神也才5颗；穆白表面装淡定，内心感慨赵坤三替主子抬轿恰到好处，人生像打英雄联盟、队友懂配合很重要。

**关键事件**：1.赵坤三当众嘲笑莫凡火系垫底，唐月却点出他火系天赋好 2.莫凡确立「火系掩人耳目」策略并定下考核前释放火滋的目标 3.周敏因天赋排名对莫凡生妒 4.唐月宣布考核与分班规则、七星子私教悬赏，全班攀比星子数

**逐章写法公式**：

- **情绪流向**：起：报名被嘲（压抑） → 承：唐月肯定与藏拙明悟（回升） → 转：考核悬赏点燃全班（热血） → 合：穆白主仆的滑稽合唱（轻松讽刺）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：当众受贬（立敌意） + 权威肯定（埋天赋线） + 规则宣布（定赛程） + 星子攀比（立对照组）

- **卡点与伏笔**：结尾卡点：穆白以5颗星子被捧上神坛，下章期待莫凡的进度线如何推进；埋设/回收伏笔：唐月探查莫凡气息时张唇的微妙反应 → 对莫凡气息的疑问；莫凡火系天赋全班第一（薛木生旧言+唐月认证） → 后续逆袭根据；年度考核淘汰与尖子班规则 → 学期末主线压力；七颗星子可获唐月私教 → 修炼激励钩子；「七班雷系学神才5颗」的传闻 → 真雷系学神莫凡的反讽对照
