# 第197章 单杀母妖！

**概要**：霹雳将鳞皮妖母轰成一具焦黑近乎粉碎的尸体，整个体育馆的青黄女妖像被断掉命脉般纷纷倒地哀嚎，学生们乘机救下被袭同学，被寄生的女孩们纷纷从褪下的鳞皮中爬出，无人知道是谁杀了母妖。莫凡瘫软在舞台上腿肚打颤，后怕唐月老师给的星图之书再慢一点自己就成了爪下亡魂。小泥鳅坠不安分地叫唤，莫凡无力地爬到妖尸旁，一枚幽蓝萤火虫般的光点从尸体中飘出落入坠中，竟是市场最低也能卖到一千万的战将级精魄，经协商由小泥鳅坠收存不吞。随后体育馆钢化顶棚被一脚踩碎，青色铁蹄巨兽从夜空踏落，巨角间站着猎王；光头队长率猎妖队冲入，得知母妖已死于那个学员之手、女孩们都还活着，震惊之余奉命救人。

**关键事件**：1.霹雳单杀母妖，群妖倒台，被寄生女孩全部生还 2.小泥鳅坠收集战将级精魄，市价最低一千万 3.猎王踩巨兽入场，向猎妖队揭示真相并下令救人

**逐章写法公式**：

- **情绪流向**：起：爽（母妖毙命）→ 承：温馨（女孩们生还、莫凡后怕瘫软）→ 转：爽（千万精魄到手）→ 合：紧张（巨兽砸顶、猎王入场揭真相）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 35% / 悬念留白 20%
- **本章结构公式**：霹雳终结（收战）+ 群妖倒台与生还（收人心）+ 精魄入坠（收战利品）+ 猎王入场揭真相（接线下一场）
- **本章核心技巧**：战后连做三次结算——清场、救人、拾宝，用松弛节奏把胜利感拉满再引入新势力。
- **卡点与伏笔**：结尾卡点：揭晓（母妖死于学员之手的真相经猎王之口公开，救人收尾留暖）；埋设/回收伏笔：战将级精魄 → 下文拍卖发财的源头；监控显示妖母战将级 → 侧面坐实莫凡越级单杀含金量；唐月老师的星图之书 → 坐实救命之恩。
