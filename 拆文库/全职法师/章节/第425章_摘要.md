# 第425章 要全军覆没了

**概要**：天已全黑,星光璀璨的夜空下疾星狼因为星光之力恢复能力更强,狼族耐力叠加星纹,一对一根本敌不过。莫凡乘机恢复魔能,以超强雷电力场控制和半个中阶威力的火滋,配合召唤兽把一百多名的高手打得毫无招架之力。闻声赶来的顾翰老师抱怨莫凡把整个火院一锅端,眼里却带着欣慰,看到他活着就够。魏荣最受煎熬,后悔当初给萧院长亲自办转系手续的学生下马威。101名的赵季走上赛台,火院学生眼中闪起回光返照的光辉,认为他是所有挑战者中实力最强的。前100名的强者因规则不能出手,纷纷咬牙切齿,东方明被蘑菇发女生追问却不想说话,他记得自己被莫凡连召唤生物都没用就击败的耻辱。疾星狼伤势积累速度变慢,莫凡考虑到它受伤,把它收回次元空间,几位系主任脸色大变,魏荣担心莫凡还有更高级的契约兽,火院就要全军覆没了。

**关键事件**：1.赵季登台,火院视其为最强挑战者、回光返照 2.疾星狼伤势过重被莫凡收回次元空间 3.魏荣与老师们惊惧莫凡可能还有更强的契约兽

**逐章写法公式**：

- **情绪流向**：起：夜战续航的从容 → 承：火院绝望中燃起希望 → 转：疾星狼撤回引发惊惧 → 合：契约兽悬念炸开
- **节奏配比**：慢铺垫 35% / 快冲突 30% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：星光续航立规则(蓄势) + 赵季登台燃希望(反转前奏) + 前100名嘴炮群像(加压) + 收回疾星狼埋悬念(钩子)
- **本章核心技巧**：用"希望刚燃起就再浇冷水"的两段式反转推进,收尾用一个未出场的更强召唤物制造惊惧
- **卡点与伏笔**：结尾卡点：莫凡是否还有中阶契约兽,魏荣怕火院全军覆没,悬念指向下章;埋设/回收伏笔：疾星狼受伤 → 为收回召唤兽、单人应战做铺垫；莫凡召唤系疑似中阶 → 契约兽悬念
