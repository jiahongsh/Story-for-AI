# 第1020章 黑暗决斗契约（上）

**概要**：穆宁雪疑暗黑挑战荒唐，库伦也不信莫凡知魔法协会不知的契约。莫凡说试一试，四人杀向戾剑死侍，大批游荡亡灵堵死归路。半空芬纳风沙咆哮抛亡灵，但戾剑死侍难对付，两百只缠她，黑暗剑主不理超阶专斩军法师。歇洛令退守五公里，芬纳掩护后撤与大部队会合。芬纳情绪失控，歇洛说只能撤离。莫凡提黑暗契约是唯一闯金字塔法，歇洛不信。祖吉明嗤莫凡多管闲事，穆婷颖不满其冒险连累国府队，莫凡骂回。芬纳决意再冲，旺科斯请代战被拒。芬纳用古埃及语提决斗飞向剑主，知非黑暗者难发动契约，回头望城邦眼含眷恋。

- **情绪流向**：起：疑契约轻 → 承：芬纳开路难缠压 → 转：内讧提契约被否 → 合：芬纳决斗失败埋钩
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：疑契约（轻） + 芬纳开路难（压） + 内讧提契约（争） + 芬纳决斗失败（钩）

- **卡点与伏笔**：结尾卡点：芬纳非黑暗者决斗无效，下章莫凡自荐；埋设/回收伏笔：暗爵斗篷黑暗者身份→莫凡底牌；祖吉明反对→后续矛盾
