# 第536章 诡异身法

**概要**：艾图图担心自己拖累莫凡，莫凡仍自信表示没有问题。第三场对手出现后，顾剑发现领头者是风榜前五的许明聪，李杰和刘欣因此认为己方将三场全输。许明聪从顾剑处得知赌约，先以言语轻视莫凡，莫凡当场反讥。比赛开始后，刘欣和李杰先后用火系、冰系魔法围攻许明聪，却被他以风轨和遁影连续闪避；莫凡看出对方身法不逊于张小侯，悄然把一道火滋混入队友的攻势，为反制埋下准备。

**关键事件**：1.许明聪作为第三场对手出现，队友判断局势不利。 2.莫凡完成队友分工并与许明聪交锋。 3.许明聪用风轨和遁影戏弄进攻，莫凡暗中混入火滋。

**逐章写法公式**：

- **情绪流向**：起：紧张 → 承：压抑 → 转：紧张 → 合：悬念
- **节奏配比**：慢铺垫 25% / 快冲突 45% / 爽点爆发 5% / 悬念留白 25%
- **本章结构公式**：强敌登场（建立难度） + 队友说明能力差距（加压） + 双方组队开战（展开测试） + 敌手连续闪避与莫凡暗中布置（留下反制钩子）
- **本章核心技巧**：用队友预警和连续攻击失效重复证明敌手优势，再以主角不显眼的准备制造信息差。
- **卡点与伏笔**：结尾卡点：莫凡把火滋混入队友攻击，读者等待许明聪如何被击中；埋设/回收伏笔：不描画星图的火滋 → 隐藏魔法气息以避开许明聪察觉。
