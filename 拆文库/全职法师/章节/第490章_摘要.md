# 第490章 夺命森林

**概要**：戴着军方勋章的南珏一行人最先抵达火云森林，却迷失了方向，只知道火劫果实应该出现在温度越高生长越茂密的林子里。一名古铜色皮肤的军官听到像怪物吐舌头的声响，被女军官说是疑神疑鬼。随后古铜军官回头发现负责后方放哨的叶子不见了，满地的落叶上有被拖拽的痕迹。南珏举手停队，断定被选入队伍的都是敦煌军区精英、服从军令，没理由一声不吭脱离队伍；紧接着探路的许东也不见了，南珏脸色一变下令尽快离开。古铜军官质问为什么不救叶子，南珏冷酷地回答想都死在这里就继续去找叶子的尸体。撤离途中陆续又有人离奇失踪，都是转瞬间不见，没有惨叫、没有血迹，只留下落叶中的拖拽痕迹。南珏自认实力极强却察觉不到妖魔气息，推断那生物实力远在他们之上，并回答古铜军官的疑问：它是在享受猫戏老鼠的折磨欲，会一个接一个把他们杀死。另一边，莫凡踏入火云森林就后悔了——这片森林像迷宫，每棵树一模一样、连大小都相同，遍地火红落叶让人分不清方向，他找不到能回到山体内部的洞穴。走累了坐下来休息，莫凡发现双手粘满鲜红液体，放到鼻尖一嗅是人的血，低头才看见自己坐的叶垫子下有一大滩血迹。他在厚厚的叶子间发现一只断掉的血淋淋的手，从手骨看像个女人，又从叶下找出尸体其他部位，凭找到的军法师勋章确认死者是位军法师。莫凡把尸体埋了，心想这片森林不仅有吃人的妖魔还像个迷宫，但愿心夏她们还没走进来，否则就危险了。他决定放弃火劫果实，尽快找到心夏他们，带上灼原土特产回上海卖钱换魔具。

**关键事件**：1.南珏队伍在火云森林接连失踪数人，推断遭遇猫戏老鼠的妖魔 2.莫凡在森林中发现自己坐在一滩血迹上，挖出军法师尸体并掩埋 3.莫凡决定放弃火劫果实，尽快找到同伴撤离

**逐章写法公式**：

- **情绪流向**：起：军方队伍迷失与怪声的疑惧 → 承：接连失踪的恐慌 → 转：猫戏老鼠论断的彻骨寒意 → 合：莫凡发现尸体、掩埋离开的沉重
- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：南珏队伍迷失森林（危机铺垫）+ 队员接连离奇失踪（危机升级）+ 南珏推断妖魔戏耍（危机定性）+ 莫凡发现尸体掩埋（双线交叉）
- **本章核心技巧**：用一连串无法解释的失踪事件制造恐怖感，让队伍最强者的推断既给解释又加深绝望，再切换主角视角用尸体桥段把两条线拧在一起
- **卡点与伏笔**：结尾卡点：吃人妖魔仍潜伏在森林，莫凡能否平安找到心夏等人，军方残队能否逃出森林；埋设/回收伏笔：失踪的军方队员 → 呼应后文三颅邪蟒的袭击；莫凡埋尸军法师 → 与南珏队伍的遭遇形成信息差
