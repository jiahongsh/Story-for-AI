# 第856章 守馆人，穆宁雪

**概要**：岳棠心痛醒又昏，男学员怒指赛义德下重手，赛义德冷淡称亡灵难控、挑战赛除非死亡不担责，反讽下一个会留手。白东威扫视国馆选手，除已离队的陆一林无人能敌死刀木乃伊，李翊君铁骨请战被否，最终生咽屈辱决定给章。正当众人不服的当口，一声清灵之声"我能试一下吗"闯入——穆宁雪银瀑及腰、雪肤绝艳，被牧奴娇认出是刚从国府队退下今日来报道的守馆人。她平淡点头：今日章若发出去，自己第一次守馆便失败，没法接受，且这人真的很过分。

**关键事件**：1.赛义德推责，白东威欲给章 2.李翊君请战被否 3.穆宁雪清灵现身应战 4.牧奴娇认出，穆宁雪立誓不退

**逐章写法公式**：

- **情绪流向**：起：赛义德推责讽刺 → 承：白东威欲给章憋屈 → 转：李翊君请战被否 → 合：穆宁雪清灵登场立誓
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：反派免责（压抑） + 群体憋屈（蓄势） + 请战被否（绝望） + 女主登场（反转）
- **本章核心技巧**：把全场最低气压留给主角逆光登场，用反差完成情绪反转
- **卡点与伏笔**：结尾卡点：穆宁雪立誓不退，下章期待她如何以冰系应战；埋设/回收伏笔：穆宁雪今日来国馆报道 → 守馆人身份的伏笔落实
