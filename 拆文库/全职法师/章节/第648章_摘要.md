# 第648章 古老王后裔

**概要**：面对煞渊逼近，陆虚、李于坚等高层不愿坐等死亡，准备冲出结界与亡灵决战。神秘灰白男子说明可靠消息称煞渊虽是死地，却并非完全不能进入，且煞渊正是古老王陵墓所在。危居村的人可能因古老王后裔血统而被陵墓之门接纳，方谷回忆村中密训，确认祖训确实说村民受神庇佑、坠入死亡国度也会成为宾客，于是愿意进入煞渊。苏小洛请求同行被方谷拒绝，张小侯又根据危居村灰梅和博城祖父去世时的习俗，怀疑自己也有危居村血统并要求同行，周敏担心他并非后裔。

**关键事件**：1.高层准备冲出结界 2.煞渊并非完全不能进入 3.危居村后裔可能被陵墓接纳 4.方谷愿意进入煞渊 5.张小侯提出自己也可能是后裔

- **情绪流向**：起：高层求死 → 承：煞渊出现进入可能 → 转：方谷确认祖训 → 合：张小侯提出血统猜测，队伍再添悬念
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：准备突围（展示绝望） + 公布进入条件（反转希望） + 方谷确认祖训（锁定钥匙） + 张小侯提出血统（扩展队伍）

- **卡点与伏笔**：结尾卡点：张小侯可能并非危居村后裔，下一章期待验证他是否能进入煞渊；埋设/回收伏笔：灰梅、昆井水和博城祖训 → 指向博城与危居村的共同血统。
