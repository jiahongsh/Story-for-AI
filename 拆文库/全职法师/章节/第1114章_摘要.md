# 第1114章 埃及又赢了

**概要**：第一轮后四国入胜者组为希腊、英国、中国、埃及，败者组为美国、加拿大、德国、法国。莫凡击垮德国跃居毁灭法师第三、取代瑞迪；封离抽签遇英国，判断希腊英国皆超级强国，为保存实力毅然放弃本轮，中国落败入一胜组，英国进二胜组。胜者组中希腊与埃及交锋，埃及以亡灵海战术再胜希腊，连败美国、希腊令举世惊呼埃及崛起。阿莎蕊雅在帕特农神山秋千屋得知希腊输给埃及，决定亲赴威尼斯参赛挽尊严。

**关键事件**：1.莫凡排第三，中国遇英国弃保实力落一胜组 2.埃及亡灵战术胜希腊，成二胜黑龙 3.阿莎蕊雅决意赴威尼斯

**逐章写法公式**：

- **情绪流向**：起：排位出炉的整理 → 承：弃保决策的务实 → 转：埃及连胜的惊讶 → 合：阿莎蕊雅登场的钩子
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：排位梳理（设局） + 弃保决策（务实） + 埃及连胜（新威胁） + 阿莎蕊雅登场（钩子）
- **本章核心技巧**：用"放弃一轮"的理性选择，把篇幅让给新对手埃及的威胁铺垫
- **卡点与伏笔**：结尾卡点：阿莎蕊雅赴威尼斯，下章三方混战她将搅局；埋设/回收伏笔：埃及亡灵战术→后文三方混战关键变量
