# 第73章 地圣泉

**概要**：三年时光过去，莫凡把青春献给修炼和猎妖，猎妖数超过十五只，魔法高考与两年前定下的魔法决斗同时临近。穆卓云把决斗时间定在高考前，若莫凡在决斗中出意外很可能影响高考发挥；他还借义子宇昂的十八岁成年礼宴请全城要人，摆明要莫凡当垫脚石。成年礼张罗之际，朱校长和邓凯把莫凡叫到校长室揭开真相：学校与世家定期有一场切磋，当年两人为防穆卓云给莫凡穿小鞋，才把他的挑衅引向这场切磋，并已暗中帮他拖了两年；如今宇昂修为突飞猛涨，莫凡未必是对手。朱校长叮嘱实力不足时忍气吞声并不是坏事，随后说出关键：决斗获胜者将获得博城每年唯一的地圣泉修炼机会，莫凡听到地圣泉三个字，眼睛一下子亮了起来。

**关键事件**：1.穆卓云把决斗定在魔法高考前并借宇昂成年礼操办全城宴席 2.朱校长与邓凯在校长室向莫凡揭开两年前解围真相与两年拖延 3.朱校长揭示决斗获胜者可得博城唯一的地圣泉修炼机会

**逐章写法公式**：

- **情绪流向**：起：压抑（决斗逼近、对手算计）→ 承：温馨（师长关怀与真相揭示）→ 转：轻松（地圣泉奖品抛出）→ 合：紧张（决战在即）
- **节奏配比**：慢铺垫 60% / 快冲突 5% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：交代时间流逝与决斗临近（蓄势）+ 旁人视角点破穆卓云算计（加压）+ 校长室对话揭开两年真相（解压并升格矛盾）+ 抛出地圣泉奖品（立赌注）
- **本章核心技巧**：用师长对话延迟揭示两年前解围的真相，把私人恩怨升格为学校与世家的公开较量，再用高价值奖品给决斗加码。
- **卡点与伏笔**：结尾卡点：奖品揭示型——地圣泉资格归属未定，牵引决斗到来；埋设/回收伏笔：地圣泉 → 为决斗赋予具体赌注；宇昂修为突飞猛进 → 抬高对手威胁；朱校长邓凯的暗中照料 → 为学校阵营后续力保莫凡铺垫。
