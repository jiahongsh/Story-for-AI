# 第688章 战，山峰之尸（中）

**概要**：山峰之尸双腿如天庭巨人垂落人间，整座独立空间剧烈晃动、空气遍布裂痕，它下半身尽数沉入银色漩涡，全身闪耀纯黑雷霆令负荷的空间不堪重负，黑洞风暴四处扩散、吸扯万物。莫凡望向银色门镜，知柳茹等是否已到祭坛未卜，死门间支撑不住必须立刻离开；死门桥多半断裂，唯一出口正是那祸害般的银色漩涡。曾第一次恶魔化他绝不敢闯空间乱流，但此番更强的恶魔化令他掌控了新力量——银色星尘正是空间系。莫凡化火红破风箭矢直插天空，在反向压迫中借银色瞳孔包裹冲向漩涡边缘，却趁千年之尸未觉一头撞入。山峰之尸不耐烦地虚空一踏，黑雷蔓延令死门间裂痕更多、沉沦更快，它自己却从漩涡一跃而起毫发无伤。黎明将至，山峰之尸咆哮驱散云海、喷出尸云，以嫉恶如仇的瞳孔盯住金色结界内的内城，迈步逼近；人们抬头看清那张如死神般巨大的狰狞尸脸，陷入恐慌。

**关键事件**：1.山峰之尸沉入漩涡致空间裂痕与黑洞风暴 2.莫凡借空间系冲出银色漩涡 3.山峰之尸踏天跃出，逼近内城 4.黎明尸脸笼罩内城，人群恐慌

**逐章写法公式**：

- **情绪流向**：起：空间崩裂的危机 → 承：莫凡破局冲出 → 转：尸君跃出逼近 → 合：尸脸笼罩恐慌
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：空间崩裂（加压） + 莫凡冲出（破局） + 尸君跃出（反转） + 尸脸逼近（钩子）
- **本章核心技巧**：用尺度比喻把boss的不可战胜具象化，并以“假希望”错位拉扯情绪
- **卡点与伏笔**：结尾卡点：山峰之尸逼近内城、尸脸笼罩，读者期待结界能否守住；埋设/回收伏笔：银色星尘=空间系 → 支撑莫凡闯空间乱流的关键
