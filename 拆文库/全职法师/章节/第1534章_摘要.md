# 第1534章 护送大队

**概要**：众人摆脱追兵离开落日长坡，查德安排驼兽驮行穿越蝎魔遍地的沙地。途中娑法被一根枯木吓得尖叫，众人怀疑蛇瞳诅咒药水开始失效。佐薇放出食人花取出昏睡的小美杜莎，却发现无人知晓如何取眼泪，诅咒仍在蔓延。队伍前行时遇到一支两百多人的埃及护送大队，带队白砂军法师要求封住众人精神力才肯同行。莫凡独排众议不愿封印精神力，无奈众人多赞同跟随，大家封印精神力随军同行，军官又给每人补上暗影钉。阿帕丝醒来，看到军队的穿着后惊恐指认，抓走她的人穿的是同样的军装。

**关键事件**：1.娑法被枯木吓到，众人怀疑蛇瞳诅咒药水失效 2.取出小美杜莎却无人会取眼泪，诅咒持续蔓延 3.遇埃及护送大队，众人封印精神力随军，阿帕丝认出军装指认歹人

- **情绪流向**：起：甩开追兵的轻松 → 承：诅咒疑云的警觉 → 转：巧遇军队的侥幸 → 合：指认军装的惊变
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：驼兽赶路（穿越沙地） + 诅咒疑云（危机预警） + 巧遇军队（伪安全） + 指认军装（真相反转）
- **本章核心技巧**：先给读者一个"得救"的错觉，再用阿帕丝的指认瞬间推翻，安全感的反转最具冲击
