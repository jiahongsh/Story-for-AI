# 第122章 星之痕

**概要**：老教授最终也没告诉莫凡特招条件。莫家按博城给的地址找到上海远郊安置小区，上千博城人挤在偷工减料的楼里，到市区单程要两个小时，莫凡下决心赶紧赚钱搬家。莫家兴神速重操司机旧业，叶心夏在家自学冥修备战来年魔法高考。莫凡十万块存款要买两本星之痕——火系雷系各一本、每本五万：中阶魔法必须先把49颗星子连成星轨、星轨再连成星图，星之痕就像复杂汉字的"字帖"，是刚迈入中阶者不可或缺的引导道具，十万块就此耗尽。他抱怨双系就是烧钱，随后闭门苦修：估算蓝量只够放三个中阶魔法，面对满场乱窜的星子无从下手，只能对着吞了地圣泉、品次已无法鉴定的小泥鳅坠喋喋不休，威胁它不好好辅佐修炼就把它卖掉。

**关键事件**：1.全家落脚上海远郊安置区 2.十万存款买两本星之痕耗尽 3.莫凡闭关修炼并确认小泥鳅坠品次无法鉴定

**逐章写法公式**：

- **情绪流向**：起：安置区的失落 → 承：体系讲解的干货 → 转：十万清零的肉痛 → 合：闭关修炼的决心
- **节奏配比**：慢铺垫 65% / 快冲突 10% / 爽点爆发 5% / 悬念留白 20%
- **本章结构公式**：落脚安置区（新起点）+ 星之痕购买（资源压力）+ 修炼原理铺陈（体系干货）+ 威胁小泥鳅收尾（伏笔＋喜感）
- **本章核心技巧**：把升级体系讲解全部缝进主角的贫穷焦虑里，设定信息随花钱的痛点一起给
- **卡点与伏笔**：结尾卡点：小泥鳅坠吞地圣泉后品次成谜，绝不再是小星尘魔器；埋设/回收伏笔：星之痕字帖（中阶修炼主线）、十万清零（赚钱动机线）、小泥鳅坠级别（金手指成长线）、雷系中阶从未用过（雷系爆发伏笔）
