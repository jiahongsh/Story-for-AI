# 第702章 下山！

**概要**：唐月来电嗔怪莫凡，莫凡在华山剑锋上汇报修为已恢复、各系星云补回并练到第三级。唐月转告一桩心事：当初杭州市中心图腾玄蛇现身，并非蜕皮躁动，而是盯着莫凡身后离他极近的人感到不安。莫凡恍然想起那人身后正是心夏，图腾玄蛇不可能撒谎，心夏为何让它不安成谜。莫凡遂向老道士辞行下山，老道士自语老朋友挑了个有趣家伙。莫凡飞抵杭州萧山机场，下飞机才打开手机就被几位老大短信咆哮，责其下山不滚去帝都国府报道。

**关键事件**：1.唐月电话，莫凡报修为恢复 2.唐月告知图腾玄蛇曾盯莫凡身后心夏不安 3.莫凡疑心夏身份下山 4.到杭州被催国府报道

**逐章写法公式**：

- **情绪流向**：起：唐月嗔怪的轻松 → 承：图腾玄蛇疑云的紧张 → 转：疑心夏身份的震动 → 合：下山被催报道的轻快
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：电话报修为（日常） + 唐月转述玄蛇疑云（悬念） + 疑心夏下山（行动） + 到杭州被催报道（转场）
- **本章核心技巧**：用第三方转述把身份疑云悬在亲近角色身上，再以日常催促转场
- **卡点与伏笔**：结尾卡点：转场型——莫凡被催国府报道，下章杭州寻心夏；埋设/回收伏笔：图腾玄蛇不安→心夏身份伏笔，老道士→斩空旧识
