# 第1006章 召唤银犀群！

**概要**：邪月下两族从对峙变为对五人的围剿，高阶魔法气息引妖魔群起攻之。蒋少絮说心灵系无法让妖族换地打，莫凡化火翼炮弹撞散沙怖狐，火凤追灭十几只；夜罗刹掠过将偷袭的两只毒火蝎四分五裂。莫凡唤小炎姬分离，炎姬少女以统领级气势震慑沙怖狐、火莲吞没来犯者。江昱高处喊开召唤之门，银甲巨犀群如钢铁洪流冲下践踏沙怖狐，莫凡化影鸟险避。蒋少絮趁势释心灵恐慌，沙怖狐出现大量恐慌、心灵涟漪未被打散，战局现转机。

- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 30% / 悬念留白 5%
- **本章结构公式**：火凤清场（爽点） + 双召唤兽助战（加码） + 巨犀冲阵（高潮） + 心灵恐慌（转机）

- **卡点与伏笔**：结尾卡点：类型悬念+沙怖狐是否真退、能否走出引下章；埋设/回收伏笔：银甲巨犀耗魔能→召唤时限伏笔
