# 第44章 惊现妖魔！

**概要**：百草山谷南面是掌状湖、北面隆起山口，独眼魔狼旧巢穴就在山口处。一组由副班长穆白领队率先爬上山口，女生们对他更加崇拜，赵坤三笑称悬赏不过如此；出身大唐世家的穆白却提醒悬赏不可能那么简单。怯生生的何雨与赵坤三都不敢先进洞，等到三组会合——另外三组估计连妖藤关都没过。赵坤三让光系学生点起移动电灯泡，穆白安排风系在前探路。莫凡却站在洞口盯住山口前的泉池：池边水线显示水位几小时前下降、水痕还在，蒸发没这么快，一组也没理由再装一次水——这里曾是独眼魔狼喝水的盆，说明洞里还有东西住着，前不久还出来喝水，且水位下降这么多，体型特别大或不止一只。张小侯吓得脸色发青，跑去告诉穆白、许昭霆、周敏，话未说完，腥臭妖风裹着水雾扑了40名学生一脸，两声悚然啼叫后，一只绿色獠牙垂到下颚、口水滴落、身躯比骆驼还大一号的深蓝色巨狼踏出黑暗，绿眼俯视着这堆食物，有人发颤喊出跑啊。

**关键事件**：1.一组穆白率队抵达独眼魔狼旧巢穴，等三组会合后入洞 2.莫凡从泉池水线推断洞中仍有大家伙刚喝过水 3.妖魔现身洞口，40名学生被恐惧攫住

**逐章写法公式**：

- **情绪流向**：起：抵达巢穴的松快与得意 → 承：洞口阴森与莫凡水线推理的不安 → 转：妖风啼叫的惊悚 → 合：巨狼现身、喊逃的恐惧顶点
- **节奏配比**：慢铺垫 45% / 快冲突 30% / 爽点爆发 0% / 悬念留白 25%
- **本章结构公式**：一组抵达（立对照组）+ 两组会合入洞（聚人头）+ 水线推理（埋警示）+ 妖魔现身（引爆恐惧）
- **本章核心技巧**：让主角的冷静观察与集体的无知乐观同框，恐怖按气味、声音、目光、形体的顺序分四拍释放
- **卡点与伏笔**：结尾卡点：危机型——巨狼挡在洞口俯视学生，下章期待逃生与反击；埋设伏笔：莫凡水线推理 → 他将凭此保持冷静；穆白的傲气 → 后文被一巴掌打碎
