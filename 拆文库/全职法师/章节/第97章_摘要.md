# 第97章 毫无征兆的死亡

**概要**：博城血色警戒拉响后，天澜魔法高中组织向安全结界大迁徙，先锋小队十人由从过军的老师薛木生领队。莫凡凭猎妖经验向张小侯说明人少的小队反而更不易招惹妖魔群的道理。附近居民纷纷涌向学校，想借师生之力穿越三公里街区，张小侯估算迁徙人数将超四千，队伍变得庞大累赘。张小侯、张璐莹两个风系法师负责探路，主街道被丢弃车辆堵死只能步行。二人先发现书报亭处一只巨眼猩鼠在啃食一个已死的小孩，报信后队伍绕过大巴士，看见倒在血泊中的男孩却不见猩鼠踪影。巨眼猩鼠猛地从车后窜出，一口咬下瘦弱女生张璐莹的脖颈，鲜血喷上大巴士，薛木生被溅了一脸血。莫凡大喊众人躲上巴士，猩鼠因体型卡在巴士门未能续杀。许昭霆愤怒呼唤雷元素要为同学报仇，莫凡发现洒落的寻妖粉朝不同方向飘散，意识到这里不止一只巨眼猩鼠，立刻示警并拽着周敏跑向巴士，还喊话张小侯放弃尸体、把猩鼠引开。张小侯施展风轨想救人已来不及，眼睁睁看着同班两年的女生惨死，双眼通红。

**关键事件**：1.张璐莹被巨眼猩鼠毫无征兆地偷袭咬死 2.莫凡借寻妖粉飘散察觉不止一只巨眼猩鼠并组织众人躲上巴士 3.四千民众涌入迁徙队伍，三公里街区步行突围正式开始

**逐章写法公式**：

- **情绪流向**：起：压抑（空城与民众聚集） → 承：紧张（探路报信、死孩铺垫） → 转：恐怖（张璐莹瞬间被咬杀） → 合：紧张（莫凡示警多只猩鼠，生死悬置）
- **节奏配比**：慢铺垫 40% / 快冲突 30% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：小队出行讲生存逻辑（立认知）+民众聚集加压（增负担）+探路发现死孩（恐怖铺垫）+突袭杀人后示警收束（危机升级钩子）
- **本章核心技巧**：用毫无征兆的突袭死亡打断行进节奏，再借寻妖粉细节把单只妖魔威胁升级为群体威胁，一个死亡同时完成情绪冲击与危机扩容。
- **卡点与伏笔**：结尾卡点：危机悬念——不止一只巨眼猩鼠包围巴士，下章期待突围与反击；埋设/回收伏笔：寻妖粉多向飘散→多只猩鼠围攻的依据；张小侯的怒火→后续复仇动机；许昭霆呼唤雷元素→雷系战力待爆发。
