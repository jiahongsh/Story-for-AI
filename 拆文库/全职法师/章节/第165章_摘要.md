# 第165章 风暴之女

**概要**：沈山河与白藏锋都诧异连牧奴娇也站了出来——她入学第一天便引得无数男生惊呼、几天内被奉为女神，莫凡都在宿舍听舍友深夜提起过她。莫凡打量后承认传闻不足以形容她的绝色，幽狼兽则对这位女子报以极深的警惕与敌意。莫凡先礼后兵提出交易：她赢了只帮系院保住可怜的一点资源，他赢了得所有院系的，提议三七分；院长、主任、顾翰听见这番没节操的讨价还价表情复杂。牧奴娇反问"如果我要七成呢"，见莫凡嘴角一抽，随即点破别耍小聪明——她就是想战，知道她的人都用"天仙之姿，嗜战如魔"八个字形容她。谈判破裂后牧奴娇当场施法，斗馆空气被抽空，她以青色风之星图激化出耸立到馆顶、直径两米的风盘·龙卷；莫凡在狂风中嘶喊改口五成未获理会，龙卷朝人狼碾压而来，而他自己的雷系星图才描画了三分之二。

**关键事件**：1.牧奴娇作为压轴挑战者登场 2.莫凡三七分交易被反将一军 3.牧奴娇先手放出中阶风系魔法风盘·龙卷

**逐章写法公式**：

- **情绪流向**：起：轻松（女神登场的惊艳与调侃） → 承：搞笑（三七分谈判被反将） → 转：紧张（风盘·龙卷成形碾压） → 合：紧张（施法速度差下的先手压制）
- **节奏配比**：慢铺垫 40% / 快冲突 30% / 爽点爆发 5% / 悬念留白 25%
- **本章结构公式**：多层抬轿（立女神地位） + 谈判喜剧（反差消解） + 嗜战本性揭示（转向战斗） + 中阶先手（立实力差）
- **本章核心技巧**：给压轴强敌先安排一场市侩谈判，用人设反差做喜剧缓冲，再让对方的果决开战把喜剧张力瞬间切换成压迫感。
- **卡点与伏笔**：结尾卡点：危机悬置+风盘龙卷压境而莫凡星图未成，下章期待应对手段；埋设/回收伏笔：天仙之姿嗜战如魔八字评→她此后每次出手的性格注脚；修为似在莫凡之上→下章幽狼兽挡龙卷的苦战定级。
