# 第90章 蓝色警戒！

**概要**：长期守泉的梁斌正是靠禁制门后的滋养才进阶中阶。副卫长林雨欣报告巨眼猩鼠挖出的洞穴隧道很深，众人当是偶然、魔法协会也查过无异样，她仍带四名守卫外出；守卫们谈及她一年前失踪的妹妹至今尸骨无存。林雨欣昨天在猩鼠洞穴里发现一滩酷似地圣泉的水，药剂师来电告知：那不是地圣泉，却是特殊环境孕育、受黑暗植物影响的同源之水，像兴奋剂一样疯狂吸食生物营养、令其失去理智，且若不直接饮用，一天之内与地圣泉以假乱真无法分辨。她联想到一年前猩鼠险些挖到地圣泉，浑身发冷。同一时刻，莫家兴冒雨把货运抵雪峰山驿站，天降浑浊如尿色的怪雨；北面关卡的千军长万断风看见两道光耀接连升起——蓝色警戒。

**关键事件**：1.药剂师揭示类地圣泉污水的真相与以假乱真风险 2.林雨欣怀疑有人图谋地圣泉 3.雪峰山驿站两道光耀拉响蓝色警戒

**逐章写法公式**：

- **情绪流向**：起：隐忧不安 → 承：真相渐寒 → 转：疑云密布 → 合：警号炸响
- **节奏配比**：慢铺垫 45% / 快冲突 15% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：洞穴疑点（起疑）+ 药剂师电话层层揭底（加压）+ 巧合自我说服（悬置）+ 怪雨光耀双线并至（炸点收尾）
- **本章核心技巧**：全章用"查案式"慢热结构蓄灾，让读者先于角色拼出真相，灾难抵达时只给信号不给正面
- **卡点与伏笔**：结尾卡点：两道光耀=蓝色警戒，妖魔将至；埋设/回收伏笔：污水以假乱真（回收上章独眼魔狼异动、埋黑教廷调包与暴躁之泉）、林雨欣妹妹失踪（复仇动机线）、浑浊怪雨（雨中催化剂伏笔）、万断风与光耀信号（袭城战引线）
