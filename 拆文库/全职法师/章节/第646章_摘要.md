# 第646章 煞渊袭城

**概要**：穆贺狂笑时，卢欢与骸刹冥主交战的空间突然剥落，黑色混沌从天空扩张并牵动地面下沉，数以万计的亡灵跌入深坑。钟楼众人从鬼哭和尸哮中认出传说中的黑色地带煞渊。穆贺说古老王把陵墓放在这个比地狱更可怕的地方，作为交换撒朗性命的条件。卢欢和骸刹冥主同时被煞渊漩涡吸住，最终坠入深渊，证明煞渊不分人类与亡灵。韩寂被震慑得失去判断，穆贺便以此为“诚意”，要求释放剩余高层。

**关键事件**：1.空间开始剥落 2.地面沉沦形成煞渊 3.古老王陵墓位于煞渊 4.卢欢与骸刹冥主被吸入 5.穆贺借煞渊要求释放高层

**逐章写法公式**：

- **情绪流向**：起：远方异变 → 承：煞渊显形 → 转：强者坠落 → 合：绝望成为新筹码
- **节奏配比**：慢铺垫 10% / 快冲突 35% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：空间剥落（制造异常） + 地面沉沦（扩大灾难） + 强者被吸入（确认规则） + 释放高层（推进谈判）
- **本章核心技巧**：把“皇陵位置”从语言筹码具象化成正在吞噬城市和强者的空间灾害。
- **卡点与伏笔**：结尾卡点：卢欢和骸刹冥主坠入煞渊，穆贺要求释放剩余高层；埋设/回收伏笔：煞渊曾在沙惘河、咸池和北外城出现 → 回收为不断接近内城的空间灾害。
