# 第1366章 孤军奋战

**概要**：紫鬼沉声追问莫凡如何知道老农是审判会的人，莫凡编造出"杀了她的女同伴、逼他吃心脏"的惨案圆谎，紫鬼怒视手下信了三分——莫凡此前昏迷半死，不可能引来审判会。莫凡主动请缨去摸清敌情，紫鬼谨慎吩咐先别动手，随即停止开启冥界之门让阵法师转移。莫凡借口同去，化作一团黑色影烟甩开蓝蝙蝠，以夜煞黑暗物质追踪并影术制住审判使姜林，报出暗号"誓言树"取得信任。他问明贺飞昆带审判使三名、审判员十名，断定实力不足以围剿紫鬼一伙，劝姜林撤走并撒谎告诉贺飞昆黑教廷已撤。莫凡心里盘算两套方案：人多便带审判会剿杀再演苦情戏救下紫鬼蓝蝙蝠，借二人攀上引渡首乌纳斯；人少便劝离以保全已得的信任。他托姜林传信古都军统张小侯，尽全力说服北原兵力守住北原防线，并嘱咐莫要透露自己出现过。临别莫凡暗自悲凉：冷青为保北鹿身份丧命，自己只是接力棒最后一棒。返回途中遇到蓝蝙蝠，他谎称已杀老农，蓝蝙蝠不满其擅自动手，又提醒他别忘差点被秃鹰吃掉，莫凡豪言总有一天把那个人吊上山崖让秃鹰叼肉——诅咒的正是重伤自己的那个人。

**关键事件**：1.莫凡以影术制住审判使姜林，报出"誓言树"暗号取信 2.莫凡摸清贺飞昆小队兵力，断定不够围剿紫鬼一伙，劝其撤离 3.莫凡托姜林传信张小侯守护北原防线 4.莫凡返回向蓝蝙蝠谎称已处理老农

**逐章写法公式**：

- **情绪流向**：起：圆谎脱身的紧绷 → 承：影子擒人的惊险 → 转：两案权衡的智斗 → 合：孤军誓言的黑幽默
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：圆谎取信（稳局面）+ 影术擒使（显手段）+ 劝撤传信（布全局）+ 归途扯谎（续伪装）
- **本章核心技巧**：用"让对手以为在帮他们、实际在替自己布局"的双重叙事，把卧底线的每次选择都写成双向博弈
- **卡点与伏笔**：结尾卡点：悬念式——莫凡放狠话诅咒之人正是自己重伤者，身份谜团未解；埋设/回收伏笔：传信张小侯守护北原防线 → 后续北原战局的援军线
