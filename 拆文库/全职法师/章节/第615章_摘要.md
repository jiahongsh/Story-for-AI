# 第615章 白蚁求生

**概要**：莫凡得知与紫衣法师直接通讯会把位置暴露给亡灵，于是用自言自语的方式报出队伍情况。对方自称禁卫法师左锋，提出由三名禁卫法师对付肉丘尸臣，莫凡负责召集足够多的法师和幸存者穿过死街。莫凡回到藏身处时，矮男已经聚拢四五队人，人数接近五十。众人得知禁卫法师不会替他们清理普通亡灵，穆白用白蚁抱团越过火墙的例子说明必然会有牺牲，矮男随即让人继续召集附近所有活人，准备把这次行动当作最后的逃生机会。

**关键事件**：1. 莫凡与左锋确定禁卫法师和幸存者的分工 2. 矮男召集四五队人并以法师为主 3. 穆白提出白蚁求生理论，众人接受以牺牲换取多数人通过

**逐章写法公式**：

- **情绪流向**：起：试探 → 承：得到援军 → 转：理想破灭 → 合：扩大人群并准备行动
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：传音确认（建立合作） + 聚集人群（扩大目标） + 澄清救援边界（削弱安全感） + 白蚁理论（确立牺牲规则）
- **本章核心技巧**：把突围方案从个人战斗转成群体决策，用一个直观比喻公开揭示代价。
- **卡点与伏笔**：结尾卡点：众人继续召集活人，准备按白蚁求生方式过街；埋设/回收伏笔：白蚁求生理论 → 后续人潮以外围牺牲换取多数人通过。
