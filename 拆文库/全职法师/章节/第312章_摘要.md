# 第312章 独战群蜥

**概要**：莫凡把第四级雷印拍向地面，电弧放射扩散出方圆二十米的麻痹电场，踏入的蜥颅巨妖尽数四肢僵直，且电场消失后能即刻再造，令他独战群蜥立于不败之地。蒋艺始终注视，暗暗诧异这雷印之强已接近凡种中阶魔法，对莫凡的魔法底蕴刮目相看。军官们则围阵用冰系冻结、地波迟缓营造妖蜥无法闯入的力场，并不滥用中阶魔法——野外魔能就是命格，与学员滥用中阶魔法的打法形成对照。莫凡脚边铺了十几具尸体却杯水车薪，一只通红如火、撞得两楼倾斜的火巨亡蜥冲他而来；他想让疾星狼把祸水引向军官，被蒋艺出手拦下。失去疾星狼分忧的莫凡只能依托倒塌楼房居高死守，蒋艺隔着妖群劝他束手就擒——魔能耗干便是腹中之物，而他的实验成功率远比任何人高。

**关键事件**：1.雷印电场独战群蜥立威 2.火巨亡蜥逼近、引祸被蒋艺拦下 3.蒋艺隔群劝降、莫凡继续深入

**逐章写法公式**：

- **情绪流向**：起：爽（雷印电场立威） → 承：压抑（妖潮无边、杯水车薪） → 转：紧张（火巨亡蜥逼近、引祸被拦） → 合：压抑（劝降与孤军深入）
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：技术立威（雷印电场）+ 资源焦虑（魔能对妖潮）+ 威胁升级（战将级登场）+ 劝降拉扯（赌约余波）
- **本章核心技巧**：把守尸数量、安全区半径、魔能存量写成可量化的战况仪表盘，让漫长的守战戏有清晰的输赢刻度
- **卡点与伏笔**：结尾卡点：莫凡魔能渐耗仍往深处走、蒋艺担心他喂了蜥蜴任务失败，下章期待力竭危机或破局；埋设/回收伏笔：赌约"一个要求"悬而未决→结算悬念；火巨亡蜥→战将级压力具象；蒋艺"活体不能死"→她的出手边界；巨蜥伪龙仍在峰顶沉睡→终极炸弹未爆
