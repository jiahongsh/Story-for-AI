# 第111章 再遇黑教廷！

**概要**：莫凡在购物广场旁用雷印抢占先手、再交替火滋的爆裂效果，单独击杀一只满嘴鲜血的独眼魔狼，这是他第一次单独面对并解决一只妖魔。广场旁十层露台上的两名黑衣人因紫色雷光注意到他，蒙面男子认出莫凡后不顾"还有任务在身"的提醒，执意要亲自宰了他，带着几只黑畜妖扑向广场。莫凡避开广场上游荡的巨眼猩鼠潜到商城阶梯，撒出寻妖粉后探测到右侧有生物急速接近，一只黑畜妖隔着玻璃门突袭，莫凡闪躲时手臂仍被划出从肩膀下延伸到胳膊肘的深长血痕，他也由此确认附近有黑教廷的人。蒙面男子现身，出言莫凡不可能活着见到明天的太阳，随后解开头脸绷带，露出左脸被强酸般腐蚀、眼球长在无皮眼眶的骇人面孔——竟是穆家大公子穆宇昂。他嘶吼这张脸拜莫凡所赐，自述十年前就潜伏在穆卓云身边当狗博取信任，就为夺地圣泉交给撒朗换取执事之位，却被莫凡毁掉十年计划、被撒朗把脸压进鬼酸水毁容，扬言要让莫凡全身泡进鬼酸水变成黑畜妖奴隶。

**关键事件**：1.莫凡首次单独击杀独眼魔狼 2.黑教廷蒙面人认出莫凡，带黑畜妖前来猎杀 3.蒙面人解下面罩竟是穆宇昂，自述十年潜伏夺泉计划被莫凡毁掉

**逐章写法公式**：

- **情绪流向**：起：紧张（独战魔狼）→ 承：紧张（被黑教廷盯上+突袭受伤）→ 转：压抑（穆宇昂现身揭阴谋）→ 合：压抑（毁容之仇升级为酷刑威胁）
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：小胜立威（证明主角战力）+敌方视角锁定+玻璃门突袭（反转受制）+解面认人（揭身份）+阴谋独白（升矛盾）
- **本章核心技巧**：先胜后挫的落差结构——用一场小胜垫高主角，再让宿敌携十倍力量登场
- **卡点与伏笔**：结尾卡点：穆宇昂扬言泡鬼酸水，仇恨不可解；埋设/回收伏笔：地圣泉被夺事件（前文）→本章由穆宇昂之口补全黑教廷视角的因果；鹰钩鼻男子提及"任务"→埋向下章十只黑畜妖与妖魔入口
