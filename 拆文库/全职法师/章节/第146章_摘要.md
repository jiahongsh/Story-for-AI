# 第146章 装X遭雷劈

**概要**：幽狼兽凭爆发力飞出流沙，如箭矢般冲向罗宋。罗宋意识到小土系降不住这头幽狼兽，慌乱挪位时摔了一脸泥，恼怒之下决意暴露真正的实力，排列星图施展冰系中阶魔法冰锁，碗口粗的凝冰锁链从他面前的大地裂缝中窜出。考官们震惊于入学新生施展中阶魔法，黎考官出声阻止，罗宋不听，称战斗没有手下留情的说法。然而黎考官冲入考场却不是去拦罗宋，而是奔向莫凡——莫凡脚下已绽放紫色雷系星图，头顶聚起雷云，正排列中阶雷系魔法霹雳。毫无防备的罗宋凉汗全身直冒，两腿发软收回冰锁；莫凡见他识相也散去雷云。幽狼兽跑回莫凡身边，眼中多了恭敬。萧院长宣布莫凡即日起成为明珠学府召唤系新生，又让罗宋入冰系学院，称他开学初上了重要一课，罗宋黑着脸走出试炼场。

**关键事件**：1.罗宋狗急跳墙暴露中阶冰系，要冰锁杀死幽狼兽 2.莫凡同步排出中阶雷系霹雳反制，罗宋吓得收手 3.萧院长拍板录取莫凡入召唤系，罗宋入冰系学院

**逐章写法公式**：

- **情绪流向**：起：幽狼兽破沙而出的畅快 → 承：罗宋掀底牌冰锁的压迫 → 转：莫凡雷云压顶的反制爽 → 合：收场与录取的松弛
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：幽狼兽脱困冲锋（延续钩子） + 罗宋暴露中阶冰锁（危机升级） + 莫凡霹雳反制（压制） + 院长定局双录取（收尾）
- **本章核心技巧**：双底牌对撞——先让对手掀牌施压，再用「劝错人」的反常举止勾出主角更大的底牌，反转在视角差里完成
- **卡点与伏笔**：结尾卡点：余波型，罗宋黑脸退场、两人各入其系，梁子结下；埋设/回收伏笔：莫凡答应唐月要低调（前文约定）→ 被罗宋逼到动粗，回收旧约束同时强化护短人设
