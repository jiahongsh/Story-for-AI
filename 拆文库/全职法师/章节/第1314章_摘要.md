# 第1314章 火速来援，烈星！

**概要**：南荣熙施展通天海柱，将暴浪与水华天幕结合成直径百米的冲击柱，把穆宁雪困于翻滚中心，迫她每秒须挪动五十米。穆宁雪以六翼反裹身体仍被冲飞高空，下坠时潘西已在海面布下诅咒刑场，她咬破嘴唇强行清醒、距刑场不到十米处展开风翼停住，却发觉冰晶刹弓的碎片被潘西压制得死气沉沉。黎红眉以飞岩石墙封路，穆宁雪避无可避之际用瞬凝将冲到跟前三米的百米海柱整个冻成冰楼。潘西忌惮其进步神速，施绝瞳石化令她双腿变成岩石，南荣倪又趁她被完全压制时放出夺命毒海草束缚其双手、绕上咽喉，连南荣熙都心惊小妹这是要穆宁雪的命。对岸轮渡围观者认出穆宁雪，议论世家联手私斗袭击国府荣誉人。就在这时，两栋大楼间一道火焰之光如炙热流星掠过，直径超两百米的火之陨星直冲鼓浪屿，人群沸腾中有人看清，陨星上站着一个全身裹着火焰的人。

**关键事件**：1.穆宁雪瞬凝冻住通天海柱，摆脱南荣熙的水系压制 2.潘西绝瞳石化、南荣倪夺命毒海草连番夹击，穆宁雪被完全压制 3.火之陨星携神秘火中人极速驰援鼓浪屿

**逐章写法公式**：

- **情绪流向**：起：海柱压顶的绝境 → 承：刑场、石化、毒草的连环杀招 → 转：瞬凝冻柱的孤注一掷 → 合：火之陨星降临的救场悬念
- **节奏配比**：慢铺垫 10% / 快冲突 60% / 爽点爆发 15% / 悬念留白 15%
- **本章结构公式**：南荣熙海柱压制（危机开启） + 诅咒刑场与刹弓失效（绝境加深） + 瞬凝冻柱的反击（爽点） + 石化疗毒草再压与陨星来援（钩子）
- **本章核心技巧**：让主角在被压制—反击—再被压制的节奏里一步步透支底牌，最后用外部强力援手打破僵局
- **卡点与伏笔**：结尾卡点：悬念型——全身裹火的人站在两百米陨星上冲向鼓浪屿，身份未明，是敌是友与穆宁雪能否脱险留待下章；埋设/回收伏笔：潘西压制冰晶刹弓碎片的方法 → 围杀的底气来源；轮渡围观者的议论 → 私斗惊动魔法协会与政府；穆宁雪为保命咬唇清醒 → 其意志力的具象体现
