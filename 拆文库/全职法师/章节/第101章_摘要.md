# 第101章 偶遇教官

**概要**：杨作河得知地圣泉在一个凶吉未知的学生手上，整个人好不起来。他怒揭黑教廷图谋：对方已通过虐杀翼苍狼幼崽和暴躁之雨引发灾难，但一只翼苍狼不足以毁城，他们要释放地圣泉数千年的温泽，诱使另外几只统领级妖魔一起袭击博城，百公里内的统领都会嗅到，让博城彻底成人间地狱。两人决定必须在黑教廷之前找到莫凡——林雨欣判断对方已猜到转交之事、正全城搜寻其踪迹；她还冷不丁问出"莫凡若被妖魔吃了，地圣泉被妖魔得到是不是比落入黑教廷好"。明园城区，莫凡打了个喷嚏继续带队：等骨刺狰狼走远后，九人雷霆出手，许昭霆雷印·狂策控制、众人轰炸、莫凡补雷印·怒击，秒杀一只独眼魔狼。张小侯站上电线杆望见城墙般高耸的结界光幕，莫凡提醒还剩六百多米别掉以轻心。过发臭城河的损坏石桥时，对面出现深蓝色四肢着地的狼形生物，众人一惊后发现狼背上坐着教官白阳，学生们崇拜其驾驭幽狼兽的英姿。薛木生说明大部队在后方一公里，白阳称会通知军长加派人手、让众人原地等待，并透露前面有几只不太好对付的妖魔。王三胖报功提到莫凡对付妖魔的经验，白阳神色一动跳下狼背，快步走到莫凡面前紧盯他说：我们大家都在找你。

**关键事件**：1.杨作河揭示黑教廷要用地圣泉引来更多统领级妖魔彻底血洗博城 2.先锋小队双雷配合秒杀独眼魔狼、推进至结界前六百米 3.偶遇召唤系教官白阳，莫凡被告知大家都在找他

**逐章写法公式**：

- **情绪流向**：起：压抑（阴谋详解与搜捕） → 承：轻松（喷嚏过场+秒杀魔狼+望见结界） → 转：紧张（桥心遇狼形生物的假危机） → 合：紧张（白阳盯人，寻找之谜）
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：阴谋揭示（立大背景）+行军爽点（双雷秒杀）+桥心惊变（假危机翻成惊喜）+教官盯人收钩（身份悬念）
- **本章核心技巧**：用"妖魔变坐骑"的反转把一场遭遇惊吓翻成安全感，再立刻用教官一句"我们大家都在找你"把安全感倒转为新悬念，一桥两用。
- **卡点与伏笔**：结尾卡点：身份悬念——白阳口中的"大家"是谁、找莫凡所为何事，地圣泉是否已暴露；埋设伏笔：白阳这只幽狼兽弱于被莫凡宰掉的那只→与前文呼应并暗示召唤兽存量；前面几只不好对付的妖魔→下章战事；黑教廷全城搜捕→追兵线倒计时；"被妖魔吃了反而更好"的冷问→莫凡处境的黑色注脚。
