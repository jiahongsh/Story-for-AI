# 第596章 击穿，霸道陨拳

**概要**：莫凡在两只尸将逼近时尝试一念星轨，连续完成七道星轨并组成完整星图，随后用霹雳狂舞击中喷毒尸将。肉瘤尸将冲来时，他用血兽靴踢飞黑岩石暂时撞倒对方，却被尸将吼声卷起的毒风暴逼退。毒雾追到火焰防护林边缘，玄蛇魔铠释放华光吸收并净化尸毒。莫凡确认一念星轨已经掌握，召小炎姬附体后打出陨拳，暗光贯穿肉瘤尸将整个肚皮，尸将倒地并被劫炎、玫炎吞没。

**关键事件**：1.莫凡完成七道一念星轨 2.玄蛇魔铠吸收尸毒 3.小炎姬附体后的陨拳击穿肉瘤尸将

**逐章写法公式**：

- **情绪流向**：起：施法突破的专注 → 承：雷击与毒风暴追杀 → 转：魔铠吸毒后反转 → 合：附体陨拳一击击穿尸将
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 35% / 悬念留白 5%
- **本章结构公式**：七道星轨（完成突破） + 霹雳狂舞（先行削弱） + 毒风暴追击（制造绝境） + 魔铠净毒与陨拳（反转解决）
- **本章核心技巧**：把能力突破放在危机倒计时中完成，再用已埋设装备的隐藏功能转危为安，最后集中释放升级技能。
- **卡点与伏笔**：结尾卡点：肉瘤尸将倒下但其余尸将仍在；埋设/回收伏笔：玄蛇魔铠的毒物属性 → 本章吸收尸毒。
