# 第261章 被动处境

**概要**：牧奴娇判断一个穆宁雪已难对付、又来一个能操控战将级生物的召唤师，明珠处境更糟，她自告牵制召唤兽，施风轨却也被黏冰拖慢。幽纹暴狼追杀深入敌阵的沈明笑，牧奴娇的陷阱藤蔓被暴狼加速踏出、作用为零，还不能用中阶木系否则会把沈明笑一起困进牢笼。小峰用地波把地表朝沈明笑奔跑的反方向拉扯，暴狼跃起化作巨肉战斧践踏，沈明笑躲开本体却被气旋掀翻吐血，靠水系护体才没去掉半条命；暴狼又在五十米外隔空獠牙啃咬，宋霞及时用圣盾-庇佑救下他，自己反被锁定。牧奴娇以藤蔓骚扰转移暴狼注意力。小峰、明聪趁机描画雷、风双星图，霹雳把沈明笑轰得站不起来，风盘-龙卷袭向莫凡宋霞，靠莫凡召出幽狼兽载两人狂奔甩开。莫凡接管指挥：沈明笑、牧奴娇与幽狼兽一起对付暴狼，宋霞护他；宋霞怒斥沈明笑按莫凡说的做。

**关键事件**：1.沈明笑被暴狼追杀重伤 2.宋霞圣盾救人与牧奴娇解围 3.双星图偷袭再挫明珠 4.莫凡接管指挥重整阵型

**逐章写法公式**：

- **情绪流向**：起：战将级登场后的凝重 → 承：沈明笑被追杀的狼狈与连番救援 → 转：双星图偷袭再挫明珠 → 合：莫凡接管指挥、重整阵型
- **节奏配比**：慢铺垫 15% / 快冲突 70% / 爽点爆发 0% / 悬念留白 15%
- **本章结构公式**：敌兽择弱而噬（选定靶子）+ 陷阱失效与地波拖拽（救援碰壁）+ 隔空獠牙与双星图偷袭（连压到底）+ 莫凡接管指挥（反攻定策收钩）
- **本章核心技巧**：把"被动"写成不断下坠的链条，每层救援都有代价、每个敌招都叠加控制，最后由主角一句干脆的分工夺回节奏主导权
- **卡点与伏笔**：结尾卡点：紧张——明珠重整阵型，沈明笑、牧奴娇、幽狼兽围攻暴狼、宋霞护莫凡，胜负未卜；埋设/回收伏笔：幽纹暴狼蓝纹赋予数倍力量与五十米隔空獠牙 → 召唤兽诡异能力待揭；莫凡幽狼兽首次参战 → 召唤系底牌亮角；沈明笑两系为风与水 → 其配置情报补全
