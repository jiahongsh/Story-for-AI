# 第546章 炎姬附体

**概要**：张小侯所在的西虹小组在古都亡灵乱中全军覆没的消息让莫凡无法接受，他站在赛场中央，对已经开始的比赛毫无反应。白宇郎试图叫停，东方烈和周书茗却将此视作击败莫凡的机会；东方烈因提名票之争和积累的不满直接出手，施展高出常规威力的第四级烈拳，火焰吞向尚未躲避的莫凡。牧奴娇、艾图图和赵满延在台下呼喊，小炎姬也焦急提醒。莫凡在噩耗和攻击中爆发怒火，命令东方烈滚开，小炎姬随即撞入他的身体完成附体，莫凡身上的烈焰骤然爆散，气势压过东方烈。

**关键事件**：1.张小侯所在西虹小组全军覆没的消息击垮莫凡。 2.东方烈无视莫凡失神与白宇郎叫停，发动第四级烈拳。 3.小炎姬附体莫凡，爆发更强烈焰。

**逐章写法公式**：

- **情绪流向**：起：悲伤失神 → 承：对手逼近的紧张 → 转：怒火爆发 → 合：能力揭示带来的热血钩子
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：噩耗确认动作（击穿常态） + 对手趁隙施法（制造危机） + 众人呼喊动作（放大危险） + 契约兽附体（反转局势）
- **本章核心技巧**：将情感崩塌与战斗危机叠加，让主角从静止失神转为爆发反击，形成同一章内的情绪翻转。
- **卡点与伏笔**：结尾卡点：能力反转，炎姬附体后莫凡的烈焰气势反超东方烈，留下攻击如何落幕的期待；埋设/回收伏笔：小炎姬赛前主动现身 → 在莫凡遭火焰威胁时完成附体。
