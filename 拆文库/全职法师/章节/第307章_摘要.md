# 第307章 魂级冰种！

**概要**：冰箭过后冰雹倾倒，冻结的战场上立起一座座面容惊恐的冰雕，有人描画星图到一半便被冰封。众人震撼于一名中阶女法师竟能以领域压制军官群和高阶法师，莫凡也疑惑穆宁雪体内为何藏着不属于她的力量。穆宁雪脱力倒下，冰晶刹弓碎成冰粉，莫凡抱住体温冰凉如死人的她，探到脉搏尚存后命众人带她撤走，托赵满延"无论如何，别让她死了"。罗宋、沈明笑吓得率先分开逃命，彭亮带宋霞走，赵满延不忍负托带三个女人同行。莫凡因对方目标是自己的天生双系、又有天鹰与高阶法师，不敢乱逃，孤身逃入妖魔盘踞的金林荒城借凶物脱身。最先挣脱冰晶的陆年怒而分兵：一路追捕学生要活的，自己亲率余部追"最重要的试验品"，并下令敲碎七座冰雕——穆宁雪一箭秒杀了七名中阶军官。

**关键事件**：1.穆宁雪虚脱濒死、托付与撤离 2.莫凡孤身逃入金林荒城 3.陆年分兵追捕、粉碎七座冰雕

**逐章写法公式**：

- **情绪流向**：起：恐怖（冰封战场余像） → 承：悲伤（濒死托付） → 转：压抑（众人离散） → 合：紧张（陆年分兵追猎）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 15% / 悬念留白 40%
- **本章结构公式**：战果清点（冰雕群像）+ 代价与托付（情感收束）+ 各奔生路（人心分化）+ 反派重启（分兵追猎开新局）
- **本章核心技巧**：以"清尸+分兵"两个反派动作完成战果量化与新压力的转场，让高潮章自然落到下一幕追逃结构
- **卡点与伏笔**：结尾卡点：陆年亲率余部入荒城追"最重要的试验品"，下章期待荒城追逐战；埋设/回收伏笔：穆宁雪体内不属于她的力量→魂级冰种来源悬念；"要活的"追捕令→学生组危机线延续；荒城土著妖魔→莫凡借险反制素材
