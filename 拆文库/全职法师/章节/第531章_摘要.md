# 第531章 提名大赛！

**概要**：临潼军区接到危居村、华村一带的消息，判断前往救援的军方法师已在煞渊附近全军覆没。教官飞角因死者是自己的学生而失控，得知张小侯等人可能跌入煞渊后，意识到搜救几乎没有生还希望，只能暂缓向张小侯的奶奶和发小通报，先设法联系失踪的斩空。魔都的莫凡浏览古都报道时，艾图图告诉他明珠学府各系前二十可参加世界学府大赛提名预选；莫凡考虑到提名可补足自己所需的第四票，又想借团体竞争检验玄蛇铠魔具和小炎姬，决定参加。

**关键事件**：1.临潼军区推断救援队在煞渊附近全军覆没。 2.飞角暂缓向张小侯家人和朋友报丧。 3.莫凡接受艾图图建议，准备参加世界学府大赛提名预选。

**逐章写法公式**：

- **情绪流向**：起：压抑 → 承：悲伤 → 转：轻松 → 合：热血
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：军方接获伤亡消息（确认危机） + 飞角追问煞渊真相（放大代价） + 莫凡获知提名规则（建立新目标） + 莫凡决定参赛（转入竞争线）
- **本章核心技巧**：用前半章的沉重损失制造远方危机，再切换日常对话引出下一段赛事目标。
- **卡点与伏笔**：结尾卡点：赛事竞争，莫凡将带着玄蛇铠魔具和小炎姬参加提名大赛；埋设/回收伏笔：张小侯坠入煞渊的消息 → 飞角暂不通报亲友
