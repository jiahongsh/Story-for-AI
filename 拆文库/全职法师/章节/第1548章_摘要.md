# 第1548章 难缠的对手

**概要**：瓦尼以魂级冰尘护身，莫凡一时难以近身。瓦尼言语激将，捕捉到莫凡呼吸声后以冰尘化作枪林弹雨扫射，击碎的是莫凡的影子替身。莫凡以微弱火烛引瓦尼靠近，用空间系与火系结合的火晶烛在瓦尼防御成型瞬间引爆，将其轰飞。瓦尼靠铠魔具保命，并借铁皮残骸认出方位逃出黑魔潭，自认摆脱领域后莫凡不再是对手。

**关键事件**：1.瓦尼冰尘弹雨击碎莫凡替身，莫凡以火晶烛偷袭炸飞瓦尼 2.瓦尼借铠魔具保命，借铁皮残骸定位逃出黑魔潭 3.瓦尼自认摆脱领域，与莫凡再度对峙

**逐章写法公式**：

- **情绪流向**：起：冰尘护体的僵持 → 承：诱敌冰雨的试探 → 转：火晶烛爆的重创 → 合：瓦尼脱困的变局
- **节奏配比**：慢铺垫 10% / 快冲突 55% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：冰尘僵持（互相试探） + 替身诱敌（骗招反制） + 火晶烛爆（重创瓦尼） + 参照脱困（瓦尼反扑）
- **本章核心技巧**：把超阶对决写成"骗与反骗"的心理战，双方都用细节留一手
- **卡点与伏笔**：结尾卡点：瓦尼逃出黑魔潭，扬言莫凡死期已近；埋设/回收伏笔：夜煞魔影已埋瓦尼身上待触发
