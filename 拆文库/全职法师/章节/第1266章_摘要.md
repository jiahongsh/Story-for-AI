# 第1266章 地狱熔炉仪式

**概要**：犬男扬言让俞师师和飞蛾死不过是念头间的事，随即命凛咒地狱犬向青娥群喷出腐败之息，青娥小小身躯被融成发臭的半胶状滴落水面，金色火焰与腐败之气同时摧毁，巨蛹很快露出一部分。犬男和曾广烈命令打手继续弄断蚕丝准备运走巨蛹时，一阵凛冽之风刮起，断木朝两人砸去，地狱犬跃身挡下。穆宁雪从树冠处款款飘落，犬男认出她正是杀死自己一只地狱犬的仇人，曾广烈也因磐冰领域压灭火焰而恼怒，柯令希却眼尖发现莫凡不在。犬男以名望与穆氏世族威胁穆宁雪退开，穆宁雪面无表情，直接以粘冰冻息生成冰冻气旋，把凛咒地狱犬裹成黏冰之躯，再以绝对雪度将冰与雪凝成巨大的冰雪球封住它，粘冰更飞去护住巨蛹与青娥。犬男勃然大怒，说上次熔炉仪式在休眠才让莫凡和穆宁雪占了便宜，此次要让他们见识真正的力量，他描画诡异的死亡召唤祭文，发动地狱熔炉，将三只凛咒地狱犬搅碎熔炼在一起，三头共颈的凛咒地狱三头犬就此成形。

**关键事件**：1.腐败之息与金火夹攻，青娥大量消融、巨蛹露形 2.穆宁雪登场，磐冰领域压制金焰 3.粘冰冻息加绝对雪度把地狱犬冻成冰雪球，并护住巨蛹 4.犬男发动地狱熔炉，三犬熔成凛咒地狱三头犬

**逐章写法公式**：

- **情绪流向**：起：青蛾被融的惨烈 → 承：穆宁雪救场的压制 → 转：犬男撕破脸的震怒 → 合：地狱熔炉的恐怖成型
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 20% / 悬念留白 20%
- **本章结构公式**：屠蛾立威（压迫）+ 雪女救场（反转）+ 领域压敌（压制）+ 熔炉变身（危机升级）
- **本章核心技巧**：让正派在顺风压制时突然被反派掀开隐藏底牌，用"上次仪式未成"的旧账给大招一个合理出笼借口。
- **卡点与伏笔**：结尾卡点：恐怖类，三头犬成型散发痛苦狂怨气息，战局彻底改写；埋设/回收伏笔：熔炉仪式与凛咒地狱犬熔合 → 下章展开战力，犬男借立功进超阶 → 动机线。
