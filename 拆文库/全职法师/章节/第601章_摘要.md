# 第601章 原来你也是怪物

**概要**：方幼苗因得知村长方谷杀害村民并将他们变成活死人而精神崩溃。柳茹和张小侯分别抵挡活死人的围攻，方谷又强化一只壮年活死人，让它撞碎岩障并杀死逃跑的村民。柳茹为保护剩下的孩子，操控三只少年活死人牵制敌群，再以血牙咬住狂化的壮年活死人，付出骨折代价将其杀死。方谷称她也是怪物，柳茹以行为而非种族回应。

**关键事件**：1.方谷制造的活死人围攻村民和法师 2.柳茹以傀控和血牙保护幸存者 3.方谷与柳茹围绕“怪物”的定义对峙

**逐章写法公式**：

- **情绪流向**：起：真相揭露后的恐惧 → 承：活死人强化与村民被杀的加压 → 转：柳茹以血牙反杀强敌 → 合：怪物定义对峙留下余波
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：真相造成崩溃（确认灾难） + 防线被突破（扩大损失） + 操控与血牙反击（保护孩子） + 口头对峙（留下价值判断）
- **本章核心技巧**：用连续的战斗结果把柳茹的身份暴露与她保护村民的行为并置，形成种族标签和实际行为的反差。
- **卡点与伏笔**：结尾卡点：方谷发现柳茹是非人类，柳茹的身份可能引来新的敌意；埋设/回收伏笔：血族血牙与败血毒 → 本章成为解决狂化活死人的关键能力。
