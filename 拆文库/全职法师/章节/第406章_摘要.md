# 第406章 贱人莫凡

**概要**：艾图图的咆哮余音绕梁，莫凡躺在沙发上感慨斩空应已打过招呼、牵挂自己的人不少，有人牵挂的感觉真好。秋晨他携两位美人返校，自比霸道总裁剧本，唯独两位高傲室友互相挽着走在前面毫不配合。路上艾图图认出周书茗的狗腿子林廷玉，后者当众讥讽艾大小姐又换跟班、讥莫凡中看不中用别像上次那样被周书茗一招放倒；莫凡火起揪住其领结质问哪里不帅得一塌糊涂，把艾图图雷得想拍死他。林廷玉变脸冷声威胁要他叼着双手去医务室，两人剑拔弩张；校霸气度的东方明到场主持，林廷玉称生平最恨人碰领结，莫凡偏手贱当场把花领结扯下，还补刀男人戴花领结太娘炮是在帮他，气得林廷玉扬言宰了他，被东方明硬拖出人群。围观者惊奇林廷玉竟就此离开、猜测莫凡来头；牧奴娇问莫凡是否认识东方明，莫凡耸肩说输在他手上的天才没一万也有八千——不远处的东方明闻言踉跄了一下，差点没忍住杀回来。

**关键事件**：1.莫凡返校途中与周书茗狗腿子林廷玉冲突，当众扯下其领结 2.东方明强行拖走暴走的林廷玉避免开战 3.牧奴娇起疑莫凡与东方明相识，莫凡以输我的天才没一万也有八千回应

- **情绪流向**：起：温馨（牵挂独白） → 承：轻快（携美返校） → 转：剑拔弩张（领结冲突） → 合：快意（大放厥词气踉跄旧识）
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：归来余温（牵挂感）+ 校园日常（双美同行）+ 狗腿挑衅（冲突起）+ 踩逆鳞三连（贱式爽点）

- **卡点与伏笔**：结尾卡点：东方明险些破功杀回，莫凡与东方明的旧怨身份未向女主们揭穿；埋设/回收伏笔：林廷玉提到「上次被周书茗一招放倒」→周书茗实力与旧冲突线；东方明的审判员资格→两人旧交手的伏线；牧奴娇逼婚困局→延续上章情敌线
