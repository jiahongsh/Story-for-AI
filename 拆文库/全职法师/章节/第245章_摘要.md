# 第245章 落网！

**概要**：莫凡将全部玫炎收入手腕、半跪轰出烈拳-地刹，贾文清与傅天明脚下的地面炸裂喷发如小型火山，绽出火柱为枝、火舌为瓣、熔浆为蕊的地刹之花；二人拼死唤出的防护魔具在灵火高温下几秒便烧成粉末，人被轰上半空、承受灵火折磨，坠地时已烧成焦炭，莫凡看都懒得看一眼，转而带火注视宇昂。宇昂惊骇于这个两年前差点考不上魔法高中的人竟握有如此毁灭之力，怒誓今生要将他变成求生不能求死不得的奴隶，却自知动不了他分毫，丢下爪牙与诅咒畜妖仓惶逃出学府，莫凡被困铁笼、隔笼立誓必取其狗命。宇昂逃出明珠学府摘罩露出流血的半腐面孔，向执事汇报任务失败却连唤三声无人应答——执事大人已被捕，魔都教廷成员等于被一锅端；他不敢回教廷、只怕撒朗知道自己还活着，注定被通缉追捕、一生与妖魔作伴。学员围聚驯兽场惊见怪物标本与焦尸；莫凡胸口裂痕触目惊心且被诅咒、疗伤药无法止血，唐月来电告知黑教廷势力将连根拔起、今晚大扫荡，莫凡苦涩道出功臣是许昭霆，并在唐月宽慰宇昂已无处容身后稍安，仍决意有机会便除掉这个隐患。

**关键事件**：1.莫凡地刹之花焚杀贾文清、傅天明 2.宇昂誓杀莫凡后仓惶出逃，惊觉蓝衣执事已被捕、魔都教廷被一锅端 3.唐月确认扫荡启动，莫凡胸口诅咒伤口难愈

**逐章写法公式**：

- **情绪流向**：起：爽（地刹之花处刑） → 承：紧张（隔笼互誓、宇昂出逃） → 转：压抑（执事被捕、一锅端后的丧家之犬） → 合：温馨（唐月报捷与宽慰）
- **节奏配比**：慢铺垫 5% / 快冲突 35% / 爽点爆发 35% / 悬念留白 25%
- **本章结构公式**：地刹处刑（清爪牙） + 隔笼互誓（结死仇） + 执事失联（反派坠落） + 报捷通话（收线与余钩）
- **本章核心技巧**：胜利与失败双线对称推进——主角每清一个敌人，反派就跌落一层，用反派"连唤三声无人应"的静默制造最大信息落差
- **卡点与伏笔**：结尾卡点：余患卡点——宇昂下落不明、莫凡胸口诅咒伤口不愈，下章期待疗伤与战后处置；埋设/回收伏笔：蓝衣执事被捕、魔都黑教廷连根拔起 → 回收夜鹰五分钟部署伏笔；宇昂被通缉、有教廷不敢回、不让撒朗知其存活 → 长线仇敌伏笔；伤口被诅咒 → 诅咒之物后续线；"是许昭霆……" → 许昭霆牺牲线余韵
