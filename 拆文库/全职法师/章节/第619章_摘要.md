# 第619章 秒杀小鬼将！

**概要**：蛛鬼将死后留下的战将级残魄被小泥鳅坠收走，莫凡发现精魄已经凝炼出来。此时人潮仍在斑马线上推进，恶鬼不断跳入外围杀人，莫凡不能贸然用大范围魔法，只能先捏碎亡灵结晶恢复八分之一魔能，再以雷印阻挡路障外的腐尸。腐尸冲破缺口并扑向孩童后，莫凡召出带伤的疾星狼，疾星狼用沙尘飓风撕碎尸群并负责断后。一名高一少年第一次施展治愈系魔法，为疾星狼治好肩背伤口。莫凡让少年跟上人群，提醒他把治愈能力留到内城救更多法师。

**关键事件**：1. 莫凡用亡灵结晶恢复八分之一魔能 2. 疾星狼击杀冲入人潮的腐尸并承担断后 3. 治愈系少年首次施法，为疾星狼疗伤后被莫凡安排撤离

**逐章写法公式**：

- **情绪流向**：起：持续杀戮 → 承：资源不足 → 转：召唤兽清场 → 合：治愈与劝离
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：精魄入坠（补充资源） + 雷印挡尸（维持防线） + 狼兽召唤（填补缺口） + 飓风清场（解除局部危机） + 少年治愈（留下人性余波）
- **本章核心技巧**：用资源消耗限制主角的直接解决能力，再让召唤兽和新人物分担危机与情绪功能。
- **卡点与伏笔**：结尾卡点：莫凡继续在过街队伍后方断后，新的魔能消耗与尸群压力仍在；埋设/回收伏笔：疾星狼肩背旧伤 → 治愈少年首次施法后得到缓解。
