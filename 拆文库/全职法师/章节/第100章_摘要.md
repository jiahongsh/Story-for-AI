# 第100章 战将，骨刺狰狼

**概要**：薛木生长吐一口气说还剩一公里就安全，心中认可让莫凡带队是明智之举——借寻妖粉推断、声东击西、瞬间轰杀，零伤亡穿过妖魔更多的明园小区；莫凡提醒安全结界外妖魔密集程度更高，不可松懈。张小侯在高处发现别处有魔法师在战斗，莫凡令继续前进；张小侯正要下来，猛然看见一颗比三层楼还高的凶狼脑袋从平楼中缓缓伸起，倒刺齿状狞骨醒目。他惊恐地比嘘手势，莫凡捂住要说话的王三胖的嘴，八人躲进墙角大气不敢喘。巨兽鼻息与震动楼房的脚步声逼近，张小侯与狼头高度齐平，感觉那三眼怪物朝他嗅了嗅，幸有垃圾臭味掩盖众人气味，巨兽才踱步远去。薛木生低声揭示这是战将级三眼魔狼，又称骨刺狰狼，三眼近270度视角、钢铁身躯，中阶法师无防备也会被一击毙命，必须留讯息告诉大部队。莫凡望向雾中银贸大厦，想到穹顶统领级翼苍狼更不知可怕到何等程度。场景转至结界南面一公里：女法师林雨欣被两只黑畜妖追杀，杨作河赶到施展风盘·龙卷将妖绞成碎片。二人对话揭示灾难是黑教廷所为、目标是地圣泉；林雨欣借乱窜的独眼魔狼逃出包围，地圣泉已交到一名在地圣泉修炼的学生手里——杨作河诧异问：你是说莫凡，那个天生双系的小子？

**关键事件**：1.先锋小队贴脸遭遇战将级骨刺狰狼，靠垃圾臭味掩护惊险躲过 2.薛木生决定留讯息向大部队通报战将级生物 3.杨作河救下林雨欣，揭示黑教廷是灾难黑手且地圣泉已在莫凡身上

**逐章写法公式**：

- **情绪流向**：起：轻松（一公里之遥的松气） → 承：恐怖（狰狼现身贴脸躲避） → 转：压抑（战将级无解、仰望统领级） → 合：紧张（林雨欣获救+黑教廷真相钩子）
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：里程松气（假安全）+巨狼贴脸躲藏（恐怖加压）+定级宣讲与留讯（世界观扩容）+换线救援揭真相（双线并进收钩）
- **本章核心技巧**：先让体型细节自己吓人、再借老师之口补设定定级，全程不接战就把等级压服读者；结尾切线用一场救援戏自然抛出幕后黑手与地圣泉归属两大钩。
- **卡点与伏笔**：结尾卡点：身份悬念——地圣泉在天生双系的莫凡身上，而黑教廷的目标正是它，下章期待两线交汇；埋设/回收伏笔：回收银贸大厦翼苍狼（seq94-95趴于穹顶）→统领级对比；骨刺狰狼待大部队应对→迁徙路线风险；黑畜妖=黑教廷驱使→主反派线开启；林雨欣借独眼魔狼逃脱→街面群妖乱窜呼应。
