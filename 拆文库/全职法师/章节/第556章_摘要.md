# 第556章 大雨战尸

**概要**：大量腐尸听从尸将号令朝众人聚拢，梦婀派阿力、阿辛阻截腐尸，自己随手扯落面纱露出白玉般完美的脸庞，与莫凡联手迎战刀斧尸将。矮男劝众人快跑，莫凡分析雨中慌不择路只会被逐个瓦解，主张坚持到天亮，并安排柳茹引开亡灵。刀斧尸将依仗斧重蛮力砸击，莫凡以四级雷印借雨水导电布下密密麻麻的电场，但尸物肌骨皆死加上皮糙肉厚，麻痹只能勉强减缓其前冲。莫凡动用血兽靴侧跃避开冲撞，尸将回身速度仍快得惊人，四柄刀斧齐剁，莫凡借黑暗遁形化作真假影子脱身，心有余悸地判定这大尸将比金林荒城的树怪怖魔还强几分，老练猎法师也绝不是对手。

**逐章写法公式**：

- **情绪流向**：起：腐尸围涌临战 → 承：梦婀揭面联手 → 转：雷印电雨受阻、血兽靴险避 → 合：尸将实力远超预估
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：腐尸围涌分派任务（战术展开）+ 梦婀揭面定联手（人设亮点）+ 雷印电雨战尸将（主战）+ 血兽靴遁影周旋（危机维持）
- **本章核心技巧**：用雨天导电的环境细节把主角优势放大到极限仍受挫，反衬强敌。
- **卡点与伏笔**：结尾卡点：尸将追错目标回头再扑；埋设/回收伏笔：柳茹血族身份可免疫亡灵攻击 → 后续战术；梦婀修为与身份 → 未解
