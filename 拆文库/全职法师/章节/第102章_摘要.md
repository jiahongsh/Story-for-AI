# 第102章 突变，叛徒！

**概要**：白阳向莫凡挑明这场灾难是黑教廷所为、他们想借地圣泉引来更多统领级妖魔彻底毁掉博城，随即索要地圣泉，说要马上送回斩空老大那里，落入黑教廷手中博城就完了，薛木生也劝莫凡交出。莫凡不动声色婉拒，说放自己这里也很安全、要亲自交给斩空老大。白阳脸上的和煦笑容瞬间凝固，目光暴出凶光，狰狞扭曲着冷声道"那你就去死吧"，原本温顺的幽狼兽利爪直拍莫凡面门，众人吓呆，周敏惊呼、薛木生怒吼，白阳不予理会。千钧一发之际，斩空所赠的骨镰盾耸立在莫凡身前挡下爪击，莫凡连人带盾被打飞十几米远却保住性命。白阳清楚骨镰盾来历，惊疑这种距离的突袭本连魔具都来不及释放，除非莫凡早已怀疑他的身份。莫凡冷脸狠骂，确信白阳有问题；白阳狂笑好奇自己是如何被怀疑的。莫凡无暇解释，扫向同伴急喊这家伙的召唤兽不止一只，话音未落桥梁扶栏两侧飞窜出两只黑畜妖，镰刀般的前肢分别斩向张小侯和何雨。对教官毫无戒心的张小侯来不及放风轨，闭眼等死，滚烫的血喷了他一脸；他疑惑睁眼，发现袭击自己的黑畜妖已被弹飞摔在摩托车旁，猛回头呆住——一张苍白凄凄的脸映入眼帘，血正从她身上喷洒出来，滚烫得张小侯整个人都要被焚烧。

**关键事件**：1.白阳索要地圣泉被莫凡婉拒后突然叛变，驱幽狼兽突袭莫凡 2.骨镰盾救命，莫凡确认白阳是黑教廷奸细 3.两只黑畜妖偷袭张小侯与何雨，一名苍白脸同伴以身替张小侯挡下致命一击，身份未揭

**逐章写法公式**：

- **情绪流向**：起：紧张（索要地圣泉的试探） → 承：恐怖（变脸突袭） → 转：爽（骨镰盾救命、识破奸细） → 合：悲伤（苍白脸同伴喷血替挡，身份成谜）
- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：索泉试探（阴谋浮出）+婉拒立疑（暗中博弈）+变脸突袭骨盾救命（爆发）+黑畜妖偷袭替挡（悲情收钩）
- **本章核心技巧**：把背叛写成变脸三段式（笑容凝固-凶光-突袭）放大信任崩塌的冲击，结尾用感官错位（先觉血热后觉未死）把替挡者身份压到下一章。
- **卡点与伏笔**：结尾卡点：生死悬念——替张小侯挡击的苍白脸同伴是谁、能否活命；埋设伏笔：白阳要将地圣泉交给红衣执事→黑教廷接头线；骨镰盾回扣斩空所赠→前文魔具伏笔兑现；白阳召唤兽不止两只→战力压迫升级；白阳旧幽狼兽被莫凡所杀→叛变杀意的私怨注脚。
