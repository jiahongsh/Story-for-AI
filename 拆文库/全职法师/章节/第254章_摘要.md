# 第254章 团队比试！

**概要**：上午为其他六所学府与帝都学府切磋，明珠对帝都的重头戏定在下午。莫凡因通宵捣弄小泥鳅坠留在住处补觉缺席观战。帝都学员许大龙当众讥讽转会明珠的罗宋"不想做凤尾跑去当鸡头、在帝都实力平平轮不到出战"，双方从老师卢一鸣、顾翰到学员沈明笑、廖明轩处处针锋相对。莫凡睡到近中午，独自解决午饭，在老树苍天、建筑古老的帝都学府游逛时迷路，靠几位学姐指点才找到仿罗马斗兽场的斗馆。到场恰逢两队开战在即，赵满延告知罗宋与许大龙是老对头、火药味已烧到全队；牧奴娇说明赛制为每方出四人的团队比试，莫凡对团战的变化与配合蠢蠢欲试。

**关键事件**：1.许大龙讥讽罗宋引两校互掐 2.莫凡补觉缺席却放话去见"老情人" 3.莫凡迷路后赶到斗馆 4.得知四人团队比试赛制

**逐章写法公式**：

- **情绪流向**：起：剑拔弩张的口角火药味 → 承：补觉游逛的轻松校园闲笔 → 转：入场后嗅到火药味的兴奋 → 合：四对四团战一触即发的摩拳擦掌
- **节奏配比**：慢铺垫 50% / 快冲突 25% / 爽点爆发 5% / 悬念留白 20%
- **本章结构公式**：两校口角（立敌意）+ 莫凡缺席见"老情人"（留悬念）+ 游逛迷路找斗馆（场景铺垫）+ 赛制说明（战斗预热）
- **本章核心技巧**：大战前章让主角缺席，用双方配角口角铺满敌意，再以主角入场+赛制揭示收拢到战斗起点，敌意与悬念双线并进
- **卡点与伏笔**：结尾卡点：紧张——四对四团队比试一触即发，读者等待莫凡在团战中的表现；埋设/回收伏笔：罗宋与许大龙老对头 → 团战对位冲突线；"去见一位老情人" → 莫凡行踪悬念待揭
