# 第1326章 得了一种病

**概要**：塔塔念叨着殿母会拧掉她耳朵，却已拉着心夏从四千米高空的机舱应急门跃下，以银色翅膀穿破广州塔禁制、直接落到塔顶乘电梯赶到病房。冷青心跳已停止五六分钟，心夏不顾肖安志"接受事实"的说辞，将手掌按在冷青胸口施展帕特农神术，圣青色的神光不断驱散黑暗物质，枯萎的心脏竟恢复了微弱跳动，连第三席治愈法师肖安志都惊得眼珠凸出。心夏解释这是古老的黑暗凋零，必须找到杀手泯碎其黑暗源才能彻底救活，并将一朵七瓣黑色之花印在莫凡掌心——花瓣全部凋零时冷青的生命便流逝干净。塔塔认出这是杀手殿四匠的卑匠，称匠者神出鬼没、国内无人能挖出他们。莫凡鼓励灵灵振作起来用智慧找出杀手，灵灵抹泪后眼中重燃神采，坚定地说：既然找不到，那就让他自己出现。同一夜，卡西大酒店里，从四百米高空坠下后满腹尿意的胖男孩走进浴室，卑匠现身让影子捂住他的嘴，笑着把他拖向通风窗，让他再跳一次——血肉随即涂抹在露天停车场。

**关键事件**：1.塔塔带心夏跃机闯塔，心夏以帕特农神术让冷青恢复微弱心跳 2.心夏给出解法：找到卑匠泯碎黑暗源，并留下七瓣黑暗之花倒计时 3.灵灵振作，决定让匠者自己现身；卑匠逼胖男孩跳楼身亡

**逐章写法公式**：

- **情绪流向**：起：跃机救人的急迫 → 承：神术复活与解法揭示的震荡 → 转：灵灵振作、匠者自己现身的定计 → 合：卑匠再害一命的黑暗收尾
- **节奏配比**：慢铺垫 10% / 快冲突 30% / 爽点爆发 20% / 悬念留白 40%
- **本章结构公式**：塔塔心夏跃机赶到（救场） + 神术复活与花盘解法（定目标） + 灵灵振作定计让匠者现身（转机） + 卑匠害死胖男孩（反派视角钩子）
- **本章核心技巧**：用"倒计时道具"（七瓣花）把救人目标钉成硬性时间线，同时以反派视角插叙制造猫鼠对位的张力
- **卡点与伏笔**：结尾卡点：悬念型——灵灵要用什么方法让神出鬼没的卑匠自己现身，七瓣花已淡一朵的时限之下猎杀即将反转；埋设/回收伏笔：七瓣黑暗之花 → 冷青生命的倒计时；塔塔早年与墓匠过招 → 杀手殿四匠的信息铺垫；灵灵"让他自己出现" → 下一阶段猎杀的核心策略
