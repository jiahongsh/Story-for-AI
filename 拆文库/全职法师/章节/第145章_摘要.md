# 第145章 幽狼兽VS罗宋

**概要**：明珠学府召唤系入学考核现场，莫凡第一次召唤就召出战斗力媲美奴仆级妖魔的幽狼兽，五位考官惊讶，系主任蒋云明当场宣布召唤系要录取他，同场考生罗宋不服，质问凭什么。罗宋不等考官商议出结果，用地波挪到莫凡面前，要求让幽狼兽和自己玩玩，验证它是不是绣花枕头，莫凡应允并让幽狼兽应战。幽狼兽先吐出飞沙走石化作土龙般的沙暴袭向罗宋，被罗宋平移闪过；随后幽狼兽爆发速度飞窜冲击，罗宋神色慌张，施展地波·陷落把试炼场地面化作逆向拉扯的流沙，拖拽幽狼兽四肢下陷、速度骤降。幽狼兽被激怒后强行抽出四肢越跑越快，与流沙赛跑，流沙最终不再能完全阻碍它。

**关键事件**：1.莫凡首次召唤即召出幽狼兽，蒋云明当场拍板要人 2.罗宋不服跳下看台挑衅，与幽狼兽开战 3.罗宋用地波·陷落制造流沙困狼，幽狼兽凭爆发力逐渐挣脱

**逐章写法公式**：

- **情绪流向**：起：考官惊叹的得意 → 承：罗宋挑衅的紧张 → 转：流沙陷落的危机 → 合：幽狼兽加速挣脱的悬念
- **节奏配比**：慢铺垫 25% / 快冲突 55% / 爽点爆发 10% / 悬念留白 10%
- **本章结构公式**：考官定调收人（立主角价值） + 罗宋下场挑衅（树敌） + 沙暴对地波闪避（第一回合） + 陷落流沙困狼（第二回合压制留钩）
- **本章核心技巧**：用对手的成熟技能（地波·陷落）反衬新召唤兽的野性爆发力，胜负不落定、以「流沙不再造成完全阻碍」收章做钩
- **卡点与伏笔**：结尾卡点：悬念型，幽狼兽正在挣脱流沙、胜负未分，下章看反杀；埋设/回收伏笔：白阳的幽狼兽（前文旧角）→ 用作强度对比锚点，暗示莫凡这只更强
