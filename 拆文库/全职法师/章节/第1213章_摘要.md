# 第1213章 毒印，魔蜢追杀

**概要**：石千寿放了几个女子后慢悠悠催林飞历交出大地之蕊，林飞历称无关者不想有人死，石千寿则表示只要告知，几人死活他根本不在意。郑通提醒还有一名未被控制的强者，怕其捣乱，石千寿不屑那只是高阶法师。林飞历指向一面嶙峋岩墙，军官用精致仪器查出大地之蕊确在该方向，林飞历以深褐光圈散去禁制，岩层化泥浆露出悠长通道，石千寿笑称老队长早有防备。童壮押张小侯、林飞历入通道，石千寿令张七虎留守、任何人进即处置。郑通眼露狠光，更不甘牧奴娇逃脱，石千寿亮掌中毒光称放走的人自会有东西招待，郑通惊其可操纵虫群、尘暴魔蜢似听其差遣。石千寿称等拿到大地之蕊郑通得一切，死人沙漠才最放心。石山外，牧奴娇与蒋少絮奔向火焰山脉欲报信救张小侯，猛想起灵灵，却见双马尾的灵灵冷静现身，白白净净发丝整齐，显猎人大师真本事。灵灵问明内情，疑石千寿不会留活口却轻易放两女太怪；山头嗡声渐近，灵灵断定石千寿是毒系超阶、魔蜢做窝与其有关，两女被下了毒印引来尘暴魔蜢，令其往火焰山脉逃，自己先走。两女不敢逗留狂奔，灵灵另向叹莫凡会替她们报仇。石峰后，一名灰蓝军衣高瘦丑陋军官显身，石千寿竟还派人尾随，即便魔蜢未杀也会下杀手。

**关键事件**：1.林飞历以禁制通道换分批放人，石千寿暗下毒印 2.灵灵现身冷静分析，指两女被毒印引魔蜢 3.高瘦军官尾随，石千寿歹毒谨慎

**逐章写法公式**：

- **情绪流向**：起：换蕊放人的表面松动 → 承：毒印暗手现形的寒 → 转：灵灵破局指路 → 合：军官尾随的绝
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：林飞历开禁制换放人（假松） + 石千寿毒印暗手（揭险） + 灵灵现身指毒印（破局） + 军官尾随堵缝（绝路钩）

- **卡点与伏笔**：结尾卡点：高瘦军官尾随欲杀两女，下章莫凡遁影现身救灵灵；埋设/回收伏笔：毒印→魔蜢追击机制；大地之蕊通道→后文争夺；灵灵记号→莫凡循迹
