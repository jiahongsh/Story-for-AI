# 第996章 歹蛆化龙

**概要**：整条乌海伪龙只剩无血无肉的白色骸骨冻结冰中，众人良久未回神。灵灵说蚁蛆诡异消失，让三人在船等时机。三天里灵灵每天只睡三小时守着电脑，称这是除崇明岛外最大悬赏、只想做猎人。歹蛆进入完全体后，灵灵却忽然示意别动——跟踪显示那只歹蛆正以极快速度朝快船游来。蓝色海潮泛黑，深处巨影浮现，穆宁雪卷回鲍比，黑影一口咬掉半截船。灵灵揭穿：这头乌海伪龙就是歹蛆所化！莫凡难接受这巨大落差。歹蛆伪龙嘶吼示威、讥笑人类妄想利用它，已羽化成龙具备伪龙全部能力。灵灵说其妖胆即原歹蛆、必须杀取疫苗。歹蛆伪龙尾部鳞刺如扇拍下破坏光圈，船四分五裂，四人震飞逃向浅礁，莫凡胸中战火更盛。

**关键事件**：1.灵灵三日守候，歹蛆进入完全体却朝船游来 2.袭击快船的乌海伪龙被揭是歹蛆所化 3.妖胆即疫苗须杀，船碎四人逃浅礁

**逐章写法公式**：

- **情绪流向**：起：骸骨寂静的余波 → 承：守候与完全体铺垫 → 转：歹蛆化龙袭船反转 → 合：妖胆目标与战火钩子
- **节奏配比**：慢铺垫 35% / 快冲突 35% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：守候等完全体（蓄势） + 朝船游来（异动） + 化龙袭船（反转） + 妖胆目标（收束）
- **本章核心技巧**：用长线守候蓄势，再以身份反转把"猎物"变成"强敌"
- **卡点与伏笔**：结尾卡点：类型冲突+浅礁如何斩伪龙取妖胆引下章；埋设/回收伏笔：妖胆即疫苗→后续击杀取胆伏笔
