# 第1002章 沙尘狂暴

**概要**：赵满延飞空寻出口，却发现无论看多远都是透红沙、落点偏差三百多米，确认空中也是迷界。众人扎帐篷等救援，江昱以赵满延为圆心反排长龙阵仍找不到出口，只寻回之前绿帐篷旗杆，推断沙漠迷界与混沌系有关、需时间解。夜里沙漠骤冷、风卷沙，赵满延布水华天幕护帐篷，莫凡冥修司夜统治。忽然隆隆轰鸣如卡车队，天沙接壤处浑浊铺满地平线——灾级沙尘暴袭来。蒋少絮坚持踩住原地不挪，因离开越迷失越难救援；穆宁雪以飓风撞开沙飓，赵满延凝岩顶与光弧结界护众人，但沙瀑如瀑布浇灌、沙越堆越厚将五人包成沙碉，似活埋。蒋少絮说只要没移动就好，莫凡却从包里掏出扑克牌要扎金花。

**关键事件**：1.空中也是迷界、反长龙阵失败 2.灾级沙尘暴袭来、众人守原地 3.沙碉包围、莫凡掏扑克

- **情绪流向**：起：寻路失败的压抑 → 承：夜守与混沌推测铺垫 → 转：沙尘暴袭来的危机 → 合：沙碉困守的窒息钩子
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：空中迷界（绝境） + 夜守推测（蓄势） + 沙尘暴守位（危机） + 沙碉困牌（反差）

- **卡点与伏笔**：结尾卡点：类型其他+沙碉中如何脱困引下章；埋设/回收伏笔：混沌系→江昱后续解迷界伏笔
