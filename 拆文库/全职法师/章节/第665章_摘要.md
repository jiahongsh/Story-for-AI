# 第665章 九死一生桥（下）

**概要**：莫凡等人走过一段由白玉女子雕像组成的墓宫通道，尽头逐渐变成狭窄玉石平台，两侧是能够撕碎强大生物的黑色狂风。柳茹发现前方出现十座飞天蛟龙拱桥，张小侯认为桥上暂时没有黑风，方谷和苏小洛却认出这正是九死一生桥。古训只说十座桥中九座为死门、一座为生门，却没有给出正确桥梁的位置。莫凡指出五人分开选择能把总体成功概率提高，但这样会让关系亲近的人分别面对生死。方谷坐下等待他们决定，众人必须在共同进退和分开求生之间作出选择。

**关键事件**：1.五人经过玉石女子雕像 2.通道出现黑风悬崖 3.张小侯探知黑风危险 4.十座蛟龙拱桥出现 5.方谷确认九死一生桥 6.古训揭示九死一生规则 7.众人面对分桥抉择

**逐章写法公式**：

- **情绪流向**：起：雕像通道的短暂调侃 → 承：黑风悬崖压迫 → 转：十座桥和规则揭示 → 合：共同进退或分开求生的两难停住
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：经过雕像（缓冲情绪） + 试探黑风（确认危险） + 发现十桥（提供选择） + 解释概率（制造关系抉择）
- **本章核心技巧**：先以轻松对话降低警惕，再把单纯的迷路问题改写成必须牺牲关系的概率难题。
- **卡点与伏笔**：结尾卡点：五人尚未决定是否分桥，下一章将直接处理生门与死门选择；埋设/回收伏笔：危居村古训 → 提供九死一生桥的唯一规则来源。
