# 第578章 亡君之祸

**概要**：飞角当众走到莫凡面前相认，自称是电话联系过的张小侯的老师，感谢莫凡找回学生，令在场法师对莫凡的身份议论纷纷。飞角通报三次煞渊一次比一次离城更近，祝蒙宣布今夜众人留守城楼、消灭借死气聚集的高阶亡灵，众法师纷纷响应。北面天幕突然传来撼动城墙的嘶吼，鬼魆暴君再度现身，欲借煞渊死气集结亡灵一举攻破北墙，而城墙兵力已无法再调派。祝蒙决意执行预先拟定的斩杀亡君计划，朱参谋坚决反对。僵持之际，猎王独萧走出人群，表示愿意加入。

**关键事件**：1.飞角与莫凡相认，通报三次煞渊一次比一次靠近城市 2.鬼魆暴君现身欲借死气破城，城墙兵力不足 3.祝蒙坚持斩杀亡君计划，朱参谋反对，猎王独萧出场

**逐章写法公式**：

- **情绪流向**：起：郑重压抑（通报凶讯） → 承：众志成城（众人请缨守城） → 转：骤变惊惧（暴君现身） → 合：热血破局（独萧加入）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：相认寒暄（补关系网） + 层层通报（危机升级） + 群情响应（士气铺垫） + 强敌现身（冲突引爆） + 僵局破题（新援登场）
- **本章核心技巧**：危机用一次比一次近的递进法加压，援军用反对声最大者的妥协来衬托价值
- **卡点与伏笔**：结尾卡点：身份悬念——猎王独萧何许人也、实力如何，下章揭晓；埋设/回收伏笔：飞角与张小侯的师生关系 → 与莫凡旧交回扣、为后续联动铺垫
