# 第50章 先救人可好？

**概要**：石台处唐月依召唤师受创的症状判断幽狼兽真的死了，陈伟亮猜它是自己在黑暗洞穴里撞死在岩石上，白阳心中毒怨反驳。洞窟内，斩空呆立在难以置信的一幕前：莫凡背着满身是伤的同伴，发狂的幽狼兽被一根钟乳石贯穿身体钉死。斩空回忆幽狼兽战力不逊真妖魔，放出它只为让学生真正面对一次妖魔，本计划由自己结果它，学生击败它是不可能完成的任务。他问莫凡“你做的”，从现场种种迹象确认正是这名学生用火滋烧断钟乳石砸穿了幽狼兽，疑惑他怎能如此冷静、又怎能让狼站着不动。莫凡出示在洞窟捡到的蓝色手镯，笑问算不算完成悬赏、魔具呢；斩空猛然想起自己压根没准备魔具——悬赏本是预计学生全军覆没的象征性任务，如今竟被逆天完成，只能一脸尴尬连说先救人。

**关键事件**：1.唐月确认幽狼兽已死 2.斩空确认莫凡单杀幽狼兽完成不可能悬赏 3.莫凡当面讨赏、没准备魔具的斩空陷入尴尬

**逐章写法公式**：

- **情绪流向**：起：狼死之谜的疑惑 → 承：洞窟真相揭晓的震撼 → 转：斩空没备魔具的窘迫 → 合：先救人的喜剧收尾
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 30% / 悬念留白 20%
- **本章结构公式**：石台猜死因（延迟揭示）+ 斩空验明单杀（反应放大）+ 出示手镯讨赏（错位冲突）+ 先救人打圆场（喜剧收束）
- **本章核心技巧**：借总教官层层崩塌的内心戏给主角战绩背书，再用讨赏错位把爽点转成喜剧余韵
- **卡点与伏笔**：结尾卡点：几十万的防御魔具悬而未兑，下章期待斩空如何掏钱兑现；埋设/回收伏笔：蓝色手镯完成悬赏 → 魔具兑现线
