# 第1300章 谁吹动了蒲公草？

**概要**：芍女凭听心率的能力指出树根坡一只半藏树凹槽的山人就是古铜牙大山人，它想偷袭一位军方领队。莫凡让赵满延把姑娘们送到大队伍里，自己与芍女一同去杀古铜牙大山人，临行前灵灵严肃提醒他有不好的预感、有些事解释不通，莫凡答应情况不对就跑。两人穿过妖雀领地时，芍女对莫凡的英雄论提出质疑，莫凡说自己不是英雄只是不能视而不见，并解释古都浩劫中他并不是真正拯救古都的人——真正的功劳属于那些用性命引开亡灵的无名者，他只是被保护着冲进煞渊的幸运儿。芍女道歉，说出自己的父亲死于古都的诱饵队伍，她曾想杀决策者后来才明白古都能存活多不容易。两人抵达古铜牙大山人正上方等待时机，莫凡产生奇怪的感觉：蒲公草飞向这里好像不是山人所为，是什么东西在帮助山人狩猎人类。此时古铜牙大山人耐心等到军方领队擦身而过才准备动手，芍女提醒它心率加快，莫凡化身影鸟俯冲而下发动雷爆袭击，紧接着施展暴君领域对抗它的蛮煞之势，用寂雷臂铠与高压闪电区缠斗，又设下暗影剑钉禁锢魔阵封住其行动，最后引雷轰身积蓄能量，喊出「大雷爆」用两道寂雷死光轰掉古铜牙大山人半截身躯，芍女用鬼木手束缚住想逃的它。

**关键事件**：1.芍女凭心率锁定古铜牙大山人，莫凡定下复仇计划 2.灵灵提醒有不好预感 3.莫凡与芍女谈英雄论与古都真相，芍女父亲死于诱饵队 4.莫凡疑心蒲公草背后另有推手 5.莫凡雷爆偷袭、暗影禁锢、大雷爆重创古铜牙大山人，芍女鬼木手束缚

**逐章写法公式**：

- **情绪流向**：起：锁定目标的紧张 → 承：途中谈英雄论与古都往事的沉重 → 转：雷爆偷袭与暗影禁锢的爽 → 合：大雷爆重创、蒲公草疑云的双重钩子
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：芍女锁定目标定计划（铺垫） + 路上谈古都真相与父仇（情感线） + 雷爆偷袭与暗影禁锢缠斗（冲突） + 大雷爆重创与蒲公草疑云（爽点+悬念）
- **本章核心技巧**：把一场复仇战做成「情感铺垫+战术秀」双线：战斗前用英雄论与父仇对话填充人物厚度，战斗中用雷爆-禁锢-大雷爆三段递进兑现爽感，末尾再埋更大阴谋
- **卡点与伏笔**：结尾卡点：大雷爆轰掉古铜牙大山人半截身躯、芍女束缚住它，但蒲公草背后推手成谜 → 下章期待击杀与真相；埋设/回收伏笔：蒲公草非山人所致 → 神树更高层秘密；古都真相 → 芍女心结与后续合作
