# 第838章 队内势力

**概要**：星河之脉大如鹅蛋、晶莹如钻、光点如星河，是中阶冲高阶、将星云化星河的唯一倚仗，凭自身破壁垒极难、自破概率几万中无一。穆宁雪急需此物，而队员们连日闭关正说明已得背后势力所供星河之脉冲阶，全队不久将尽高阶——淘汰日临近，无人再等。穆宁雪见莫凡掌中闪耀的星河之脉，感动难以掩饰：偌大血缘家族因它对自己置之不理，这男人却将它放在自己面前。莫凡称是那夜睡她房睡不着跑去市里买的，甚至调皮想单膝下跪问网友，谢穆氏残忍、谢赤色裂妖祭献精魄、谢国家淘汰体制把自己逼到可下手的绝境。他劝穆宁雪先突破高阶"反正我的就是你的"，语出后紧张如递情书，泉水冻了又融。见穆宁雪不语，他又改口"当借你的，先度难关"。穆宁雪急拦其话，心平气和解释：国府之路更是背后势力资源比拼，一份星河之脉远远不够，借她还拖累其修炼，届时他人多系高阶、他优势荡然无存。

**关键事件**：1.星河之脉设定、全队借势冲高阶 2.穆宁雪感动拒收、莫凡述购脉经过 3.莫凡忐忑表白、改口借脉 4.穆宁雪析资源比拼终拒

**逐章写法公式**：

- **情绪流向**：起：设定压迫的沉 → 承：赠脉感动的暖 → 转：忐忑表白的甜 → 合：理性拒收的实
- **节奏配比**：慢铺垫 25% / 快冲突 0% / 爽点爆发 5% / 悬念留白 20% / 甜 30% / 压抑 20%
- **本章结构公式**：设定钉死（沉） + 赠脉感动（暖） + 忐忑表白（甜） + 理性拒收（实）
- **本章核心技巧**：用"硬设定+软告白"把资源危机与情感线拧成一股，结尾以理性落回现实。
- **卡点与伏笔**：结尾卡点：穆宁雪以资源比拼为由拒收，下章期待莫凡如何破局；埋设/回收伏笔：赤色裂妖精魄 → 换星河之脉，回收前文斩妖所得。
