# 第752章 未知生物

**概要**：莫凡与赵满延落回甲板，众人立栏杆俯见水下黑影仍笼罩轮船、深邃如黑洞深渊，江昱尖叫惊醒全员，众人僵直于那无气息却令人窒息的压迫感中，莫凡称巨影似已潜下，黑影渐淡后众人如虚脱、江昱瘫软甲板。江昱自叹井底之蛙，自认识遍妖魔却无法判断此影，南珏疑其至少君主级，莫凡指其无生命反应存疑，官鱼嗤其没见过君主级却被暗反——莫凡实与图腾玄蛇、山峰之尸等君主打过交道。巨影消失后众人安下心，因受惊航线偏移多行一段才入日本安界，灰色机械化渔船间中国白游轮显突兀，莫凡踏陆地方觉踏实，问谁会日语，蒋少絮称爱看日剧，莫凡附和看柯南遭骂流氓。

**关键事件**：1.众人在甲板直面水下巨影的恐惧 2.江昱南珏莫凡论巨影级别，官鱼被反 3.入日本安界登港，莫凡问日语

**逐章写法公式**：

- **情绪流向**：起：落甲板见黑影加压 → 承：全员恐惧虚脱 → 转：级别争论暗爽 → 合：登港踏实轻松
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：黑影笼罩（加压） + 恐惧虚脱（放大） + 级别争论（信息差） + 登港落地（收束）
- **本章核心技巧**：用"角色身体反应+未知体量"放大恐怖，再用官鱼轻视反衬莫凡隐藏阅历
- **卡点与伏笔**：结尾卡点：无（轻松收束）；埋设/回收伏笔：水下未知巨影 → 后续或再现；莫凡君主阅历（图腾玄蛇/山峰之尸） → 实力背书
