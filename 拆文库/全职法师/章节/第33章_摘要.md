# 第33章 星尘魔器

**概要**：张小侯提醒莫凡宇昂是个变态、能不能活到十八岁第二天都难说，莫凡自信左手火滋烧他个外焦里嫩、右手雷印轰他个皮开肉绽。年度考核最终成绩公布，莫凡以最优异的成绩列大黑板第一，盖过雷系的许昭霆和冰系世家的穆白，无数人在那里狂揉眼睛；他当众怒骂穆卓云并在校董见证下决战穆氏子弟的事也传开，他成了学校双名声人物：一秒变学神的传奇加博城史上最作死的学生。莫凡不理会流言，该吃吃该睡睡照常冥修练释放，被分进约百人的尖子班，班里基本都掌控了七颗星子；实践课仍由来校不到半年、修为据说超过全校任何一位实践老师的唐月执教，班主任仍是薛木生——班上出了两个S级，他因莫凡获校领导关注，也被千叮万嘱要开导莫凡叛逆的性格。新学期过了一个月，学校分配星尘魔器：此器养魂养修、缓解冥修疲劳令修炼者继续修炼，是世家领先平民法师的硬件。规则按年度考核排名分配使用时长、每季度重考重排，尖子班后十名降到普通班。薛木生宣布因莫凡考核时目无尊长，他的使用时间从一个月变成十天作为惩罚，有同学议论他若低头同意加入穆氏没准得到更多，莫凡答没有异议，随后凑到穆白桌前称有个问题要问他。

**关键事件**：1.成绩放榜莫凡双名声全校第一 2.星尘魔器分配规则与莫凡被罚十天 3.莫凡主动找穆白问话

**逐章写法公式**：

- **情绪流向**：起：决斗阴影下的自信 → 承：成绩放榜、双名声发酵 → 转：魔器分配、惩罚削减 → 合：莫凡主动找穆白留钩
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：收束风波（定名声）+ 设定科普（立目标）+ 制度惩罚（造稀缺）+ 主动出击（转钩）
- **本章核心技巧**：把修炼资源的"使用时长"做成可分配、可惩罚的稀缺品，让制度本身成为压迫感与动力源。
- **卡点与伏笔**：结尾卡点：悬念型，莫凡凑到穆白桌前要问什么；埋设/回收伏笔：星尘魔器制度 → 本卷修炼线骨架；季度末位淘汰 → 后续竞争压力；"作死学生"名声 → 人际处境。
