# 第582章 活死人

**概要**：场景转至外城墙西城区老居民区，华村逃出的村民暂住于此。柳茹在屋檐上撞见苏小洛质问村长谢桑——狗子说看到了羊阳村的人，苏小洛追问羊阳村的人到底去了哪里。黑衣男子方谷鬼魅般现身，称来查杀他儿子方流的凶手，疯癫的狗子跳出来指认：是傻子朋友身边的女人，手爪变长刺进方流脑袋。方谷随即描画暗血色的星图，黑气中涌出十几个羊阳村村民，个个栩栩如生，方幼苗激动地想上前拥抱，被苏小洛喝止：他们都已经死了！众人呼出的白气与村民们口鼻耳间穿梭的黑血雾形成对比，揭示了这些村民已是活死人。

**关键事件**：1.苏小洛当众质问村长谢桑羊阳村村民下落 2.方谷现身追查杀子凶手，狗子指认凶手 3.方谷召唤出羊阳村村民，苏小洛揭穿他们是活死人

**逐章写法公式**：

- **情绪流向**：起：压抑（深夜质问） → 承：悚然（方谷现身） → 转：惊骇（尸群涌出） → 合：冰寒（活死人真相）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：深夜质问（立疑点） + 仇家现身（引冲突） + 疯证指认（放情报） + 尸群涌出（爆惊变） + 白气对比（揭真相）
- **本章核心技巧**：以呼气成白雾这一寒夜细节做检验标尺，让超自然真相有了可验证的落点
- **卡点与伏笔**：结尾卡点：危机悬念——院落被活死人村民包围，方谷目的成谜；埋设/回收伏笔：羊阳村覆灭真相与方流之死 → 直指莫凡一行的华村旧事
