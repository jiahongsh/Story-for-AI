# 第672章 战无止境（下）

**概要**：莫凡用连续霹雳击中双面鬼将的头部，使其两张面孔都变得溃烂。鬼将依旧凭借亡灵躯体反复踩踏和挥爪，莫凡用暗影分裂躲过致命踩击，并从五十米外继续引导雷电。双面鬼将被多次霹雳劈得跪地，恢复行动后再次扑来，腹部窟窿中的亡灵结晶暴露出来。莫凡以烈拳轰天直接击碎结晶，将十米鬼躯烧成残渣。钟楼众人通过铜镜看到他已经清理一两百具亡灵和两只战将，随后从他的火、雷、暗影和召唤能力确认他拥有四个系，认为莫凡可能借高阶突破获得新的系，死门间的战局因此出现新的希望。

**关键事件**：1.霹雳击穿双面鬼将头部 2.暗影分裂躲过踩踏 3.连续雷击使鬼将跪地 4.发现亡灵结晶 5.烈拳轰天击碎结晶 6.鬼将化为残渣 7.铜镜观察到莫凡的战果 8.众人确认莫凡拥有四个系

**逐章写法公式**：

- **情绪流向**：起：雷霆命中但鬼将不死 → 承：暗影躲避和连续雷击 → 转：找到亡灵结晶并烈拳终结 → 合：外界确认四系，死门战局重新出现希望
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：霹雳重创（削弱首领） + 暗影闪避（维持距离） + 发现结晶（找到弱点） + 烈拳终结（完成击杀） + 铜镜确认（扩展信息）
- **本章核心技巧**：先让首领承受多次高伤仍不倒，再通过战斗观察揭示亡灵弱点，使最后一击同时完成战斗解决和设定展示。
- **卡点与伏笔**：结尾卡点：莫凡四个系的能力被钟楼确认，但近两千只亡灵仍未清完；埋设/回收伏笔：高阶突破后的觉醒机会 → 为莫凡拥有更多系别和后续战力增长留下明确线索。
