# 第889章 黑畜妖

**概要**：莫凡收起疾星狼，循狼所指方向与穆宁雪等会合，荣盛好奇方向何来被莫凡不耐打断。众人走向主楼后昏暗的橙楼，长廊地毯暗红、两侧多锁着的房间。疾星狼示血腥味从厚重双环拉门处扩散，莫凡见墙边一道浅浅红痕、大小如嘴印，低声对穆宁雪说那是汪栩栩蹭上的血、约臂肩高度的皮外伤，印痕狭长、气味与鞭上一致，证汪来过。荣盛要喊"栩栩"被莫凡捂嘴。推门无锁，里面古饰壁炉鹿头，莫凡闻到黑畜妖与诅咒畜妖特有的气味。郭文衣觉臭，穆宁雪指味从门外传来。莫凡急掩门，走廊奔跑声渐近，郭文衣从门缝见一骨瘦畸形、四脚着地、黑皮鬼猴般的东西爬过——正是她当年夜路所见的"吃马怪人"，莫凡认出是黑畜妖。声渐消，莫凡知此处已是黑教廷地盘，杀一只会惊动全部，更忌惮毒变暴露，遂嘱三人呆着别出声，自己独去行动。

**关键事件**：1.走橙楼长廊见汪栩栩血痕证其来过 2.推门入厅闻黑畜妖味 3.郭文衣门缝见黑畜妖真容 4.莫凡认黑教廷地盘嘱三人勿动

- **情绪流向**：起：循味走橙楼的试探 → 承：血痕证汪来过的厘清 → 转：门缝见黑畜妖的恐怖 → 合：认地盘嘱勿动的克制落点
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：循味走橙楼（探） + 血痕证汪来过（收线） + 门缝见黑畜妖（爆点） + 认地盘嘱勿动（钩子）
