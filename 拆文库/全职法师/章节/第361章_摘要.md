# 第361章 带蛇BOSS跑路

**概要**：离开会议室后，莫凡和唐月马不停蹄赶往三潭映月，携带唐忠交付的图腾珠——一种注入生命能量后可短暂容纳活物的空间器皿。祝蒙此时正调遣人手准备在西湖实施隐患铲除计划，并派人死死盯住唐忠等图腾族骨干，却不知唐忠早有安排；唐忠判断祝蒙不只是驱逐图腾、而是要借蜕皮期最虚弱的时机将它弑杀，必须连夜送走。唐月在三潭映月唤出摩天蛇，跪坐蛇头与之絮语沟通，蛇答应后进入图腾珠，珠色转为青黑。唐月解释蜕皮期的它会变小，莫凡催促赶紧私奔跑路。

**关键事件**：1.唐忠交出图腾珠并定下连夜转移摩天蛇的计划 2.唐月月夜唤蛇、絮语沟通成功 3.摩天蛇进入图腾珠，两人准备跑路

**逐章写法公式**：

- **情绪流向**：起：紧张（受命连夜转移） → 承：温馨（月夜人蛇絮语） → 转：轻松（巨蛇入珠的奇观） → 合：轻松（私奔跑路自嘲）
- **节奏配比**：慢铺垫 50% / 快冲突 10% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：受命取珠（启动行动） + 敌方部署（外部压力） + 月夜唤蛇（情感铺垫） + 收珠跑路（收尾钩子）
- **本章核心技巧**：把"转移物资"式的过场任务写成送别场景，用巨蛇体量与少女絮语的对比锚点撑起情感重量。
- **卡点与伏笔**：结尾卡点：行动启动型——两人带着蛇BOSS连夜出逃，下章期待能否避开祝蒙布控；埋设/回收伏笔：图腾珠生命能量时限→蛇必须出珠续命；蜕皮期体型变小→摩天蛇状态设定。
