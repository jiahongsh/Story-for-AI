# 第632章 一个活口不留

**概要**：小炎姬任意操控火焰，短时间内烧死大半黑畜妖。亡灵大军已逼近一两公里，女执事担心动静引来禁卫法师，只得亲自施展高阶冰系魔法。莫凡同时让小炎姬附体并完成陨拳，先一步轰出九条火焰蛟龙，摧毁黑畜妖和两名黑衣教士的防御，将女执事连人带盾撞进刻字墙。女执事重伤爬出焦土，震惊于中阶魔法的威力，莫凡则宣布今天的黑教廷成员一个活口都不会留下。

**关键事件**：1.小炎姬烧毁大半黑畜妖 2.亡灵大军逼近 3.女执事施展高阶冰魔法 4.莫凡以陨拳击穿防御 5.女执事重伤，莫凡宣布不留活口

**逐章写法公式**：

- **情绪流向**：起：范围火焰清场 → 承：高阶法师出手加压 → 转：陨拳越级击穿防御 → 合：女执事重伤，主角定下灭口目标
- **节奏配比**：慢铺垫 10% / 快冲突 35% / 爽点爆发 45% / 悬念留白 10%
- **本章结构公式**：火焰清场（削弱数量） + 高阶施法（抬高对手） + 附体陨拳（越级爆发） + 防御破碎（确认胜势）
- **本章核心技巧**：先让敌人以等级优势建立自信，再通过施法速度和火焰强度反转其判断。
- **卡点与伏笔**：结尾卡点：女执事重伤而莫凡宣告一个活口不留，下一章期待最后决战；埋设/回收伏笔：小炎姬附体陨拳 → 延续前面对肉丘尸臣的超强火拳威力。
