# 第22章 专治优越狗

**概要**：穆宁雪演讲简短，张小侯劝莫凡两年内加把劲考进帝都学府、届时穆氏家族手再长也管不了，赵坤三立刻跳出挖苦莫凡今天一过就要被清除学校。忍他已久的张小侯怒斥赵坤三像狗一样乱叫——张小侯已是班里少数能施展魔法的学生，赵坤三不过掌控6颗星子。赵坤三随即掀出旧怨：当年莫凡哪来的勇气跟穆宁雪套近乎，要不是他，赵家庄的地就不会被收回；赵家同是穆氏世家家仆，靠给庄园做绿化园丁为生，穆氏庄园贵族上百人却围着上千佣工，整个城区都曾是穆氏家的。被莫凡触怒的老爷子正是主席台偏后那位跺跺脚能让博城震一震的穆卓云，他没让莫凡一家要饭已算仁慈。莫凡意外赵坤三比想象中看清现实，却反唇相讥他有做狗的潜质与觉悟；赵坤三对骂自称吃好狗粮的贵狗、骂莫凡是丧家犬扫把星。莫凡在人群中捕捉到幸灾乐祸的穆白——那个儿时被他摁在地上痛打的寄人篱下小少爷，如今借考核翻身有了还击机会；莫凡判明穆白是蓄谋已久放出赵坤三这条狗，放话自己专治喷子狗和优越狗一百年、以贱服人、睚眦必报。

**关键事件**：1.赵坤三当众挖苦并曝光旧怨：莫凡当年招惹穆宁雪致赵家庄失地 2.穆卓云（被触怒的老爷子）身份揭晓 3.莫凡与赵坤三狗类互骂 4.莫凡识破穆白幕后放狗蓄谋报复

**逐章写法公式**：

- **情绪流向**：起：考帝都的憧憬（轻松） → 承：赵坤三揭疤对骂（愤怒压抑） → 转：穆卓云与豪门压迫（窒息感） → 合：莫凡识破幕后并宣言（爽）
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 15% / 悬念留白 15%
- **本章结构公式**：友人展望（善意的目标） + 敌人揭疤（旧怨信息量） + 阶级图景（世界压迫感） + 主角识局反宣言（收束立人设）
- **本章核心技巧**：用一场骂战同时完成旧事拼图、阶级设定灌输和敌我阵营站位，冲突即信息载体
- **卡点与伏笔**：结尾卡点：莫凡放话专治优越狗、睚眦必报，下章期待考核上正面回击；埋设/回收伏笔：莫凡当年招惹穆宁雪致赵家庄失地、触怒穆卓云 → 三年前旧事核心拼图；穆卓云跺脚震博城的权势 → 后续最高压迫源；穆白蓄谋下狠刀 → 考核陷害线；张小侯已能施展魔法 → 考核表现预埋；赵家与莫家同为穆氏家仆 → 两个仆役家庭的命运镜像
