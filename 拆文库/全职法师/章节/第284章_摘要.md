# 第284章 恐怖巨蜥！

**概要**：楼外的莫凡白婷婷目睹整栋市政大楼枝蔓蠕动完全活化，才明白这些植物本就是妖魔。莫凡指向第二级建筑——一颗树桩般的狰狞硕大脑袋嵌在那里，无数藤须像营养管插进喉咙。白婷婷认出这是血统较高的伪怖魔：以整栋大楼做伪装诱生物栖息，附近没有游荡妖魔恰恰证明此地凶险至极，闯入者都成了它的养料。莫凡想用火轰，白婷婷急忙阻拦——火对它作用不大，人数翻倍也绝非对手，队里若没有光系十分钟内必全军覆没；她因对救过命的莫凡有好感才留下，不经意躲过致命陷阱。莫凡牵挂穆宁雪牧奴娇赵满延却无计可施，只能等众人杀到大厅门口接应。此时黑色狂风席卷，杂物乱飞、自行车被卷起撞碎；乌云下一具长着巨大肉翼的巨蜥躯体逼近，气场强得令人窒息、只生逃念。白婷婷吓得挪不动步，莫凡顾不得隐藏实力强行遁影，星轨连断三四次才成功，携她贴墙遁入老街。白婷婷震惊发现莫凡竟有四系。肉翅巨蜥盘旋后俯冲咬进第二级建筑，钢筋水泥如泡沫粉碎，死死咬住伪怖魔的木桩脑袋；伪怖魔发出防空警报般的尖叫，藤蔓疯狂缠捆巨蜥却如蛛网般尽数崩断，挣扎越来越无力。

**关键事件**：1.莫凡白婷婷识破市政大楼即伪怖魔本体，判断队内无光系必遭覆没 2.肉翅巨蜥降临，莫凡被迫暴露遁影携白婷婷逃命 3.巨蜥与伪怖魔撕咬缠斗

**逐章写法公式**：

- **情绪流向**：起：恐怖（大楼活化） → 承：压抑（无光系必覆没的死局） → 转：紧张（巨蜥降临气场窒息） → 合：恐怖（双魔撕咬、伪怖魔渐弱）
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：识破本体（认知翻盘）+ 死局判断（绝望铺垫）+ 巨蜥压场（更高威胁登场）+ 双魔相争（渔翁悬念收尾）
- **本章核心技巧**：用更高量级的怪物碾压前一个怪物，让"捕食者被捕食"完成威胁升级，同时给被困队伍制造渔翁得利的生机
- **卡点与伏笔**：结尾卡点：伪怖魔挣扎渐弱、胜负将分，楼内队伍命运悬而未决；埋设/回收伏笔：外林安静之谜→伪怖魔猎场（已回收）、莫凡四系被白婷婷撞破→秘密扩散危机线、肉翅巨蜥等级远超队伍→更高级威胁入局、白婷婷因好感留下→情感线记账
