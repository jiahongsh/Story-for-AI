# 第367章 追兵

**概要**：两人双遁救狼未果，对方以中阶植物魔法坤之林围困疾星狼。唐月遁影分化出两个虚实残影与敌人兜圈子作掩护，莫凡遁出重围，用意念锁定藏身高草下的女见习审判员——其植物操控力比牧奴娇还强。莫凡现身后喊出"小龙女，我是你的尹志平啊"，趁对方操控藤蔓反击前掷出巨影钉，贯穿胸口禁锢其身与心神，这是他首次使用第二级巨影钉；调戏一句"美女，有缘再见"后遁走。疾星狼腿伤无法代步，两人以遁影在高草月影间疾行，却被后方不到一公里处出现的飞行追兵咬住。唐月判断对方是持翼魔具的见习审判员与携进阶期锋羽雀的召唤系法师，咋舌于翼魔具之贵与飞翔召唤兽五千万起的身价，遂分工迎战：她对付锋羽雀及其背上三人，莫凡对付翼魔具土豪。

**关键事件**：1.唐月残影掩护、莫凡巨影钉禁锢女见习审判员 2.疾星狼伤重、两人遁影赶路 3.空中追兵现身并判明其豪华配置 4.两人分工迎战

**逐章写法公式**：

- **情绪流向**：起：紧张（救狼被坤之林围困） → 承：爽（残影调虎与巨影钉得手） → 转：轻松（尹志平式调戏） → 合：紧张（空中追兵压境）
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：双遁救狼（配合受挫） + 反猎狙击（擒获强敌） + 整装再逃（过渡） + 空中追兵（新敌压境）
- **本章核心技巧**：用一场"擒敌不杀"的小胜展示主角暗影系成长，紧接着用配置更豪华的追兵抬高压迫感，胜而不泄。
- **卡点与伏笔**：结尾卡点：强敌压境型——翼魔具土豪与锋羽雀三人组咬住两人，期待空地对决；埋设/回收伏笔："小龙女，我是你的尹志平啊"的调戏→与女见习审判员再遇的可能；翼魔具与飞翔召唤兽→下一章东方明登场。
