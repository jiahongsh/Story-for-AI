# 第990章 惹不起

**概要**：穆宁雪潜入浑浊海中层，按灵灵指引找到鲍比，并发现一只满身剑刺的黑影海妖正追逐歹蛆。她以冻结与冰锁控住利剑海妖，莫凡以空间律动将其压扁爆体。灵灵通过通讯得知是剑猬海妖，提醒此物群居，指责二人无脑杀戮会引来同伴。果然浑浊水域四周涌出大量黑影，剑猬海妖成群嗅血聚来。莫凡在水中以退散与疾光电灾勉强抵挡，却被下方更大黑影一口咬向半空，幸得穆宁雪冰锁拽起。快船上灵灵与鲍比已上船，黑色巨口连冰锁将莫凡咬下，穆宁雪立刻冰封灵柩冻住怪物，莫凡从鱼唇死光穿出，踩碎冰天梯落回穆宁雪面前。灵灵提醒歹蛆跑远须甩开海妖，快船驶远仍被追击。灵灵教训莫凡水战弱须低调，莫凡回头看沸腾海面咽口水：海洋里的都是祖宗，惹不起。

**关键事件**：1.穆宁雪冰控、莫凡空间压扁剑猬海妖 2.杀戮引来群居海妖围攻，莫凡遇险被救 3.穆宁雪冰封灵柩冻怪，众人脱险并被教训

**逐章写法公式**：

- **情绪流向**：起：水下伏击的紧张 → 承：无脑杀戮的隐患铺垫 → 转：群妖围攻与遇险反转 → 合：脱险后被教训的余波
- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：冰控剑妖（小胜） + 无脑击杀（埋隐患） + 群妖围攻遇险（爆发） + 冰柩救场脱险（收束）
- **本章核心技巧**：用一次无脑杀戮触发群居妖族围攻，以环境限制放大危机再靠队友兜底
- **卡点与伏笔**：结尾卡点：类型其他+海洋更深处妖族更强引下章；埋设/回收伏笔：剑猬海妖群居→下章礁窟生态铺垫
