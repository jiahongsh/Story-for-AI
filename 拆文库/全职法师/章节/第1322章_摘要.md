# 第1322章 无处不在的黑暗追击

**概要**：莫凡检查冷青的伤势，发现她全身肌肤变铅黑、血液被黑暗物质侵染，常规药物无效，必须白魔法治愈系清除，而莫凡触碰时黑暗物质竟反噬入他的手心。冷青醒来解释这追踪的根源是黑暗侵染：它会侵染目标周围所有物体，通讯设备、魔能、身边的人、药物，任何能量波动都会把黑暗气息反馈给杀手，因此连莫凡与灵灵也已暴露在杀手感知中。小苹绝望地数出死路：去南国审判会遭截杀、用通讯魔法药物被知晓，只能看审判长被折磨致死。莫凡阻止冷青交代遗言，用"没照顾好灵灵就是很差劲的人"的歪理激她求生，并判断杀手不是超阶，决定靠自己会会他。他把小炎姬留在屋里独自出街，穿过杂乱市场与天河区靠近广州塔。塔前又有一个孩子从高空坠落，离地不足五十米、高处法师来不及救，莫凡明知动用魔法会被黑暗杀手定位，仍骂着"算老子倒霉"施展瞬息移动，而他银色光辉闪耀的瞬间，身上泛起黑暗之气化成一只小暗蝇，缓缓飞向广州塔最顶端。

**关键事件**：1.冷青解析黑暗侵染的追踪机制，确认众人皆已暴露 2.莫凡阻止冷青托付遗言，决定靠自己对付杀手 3.莫凡为救坠塔孩童动用瞬息移动，黑暗之气化暗蝇飞向塔顶暴露位置

**逐章写法公式**：

- **情绪流向**：起：伤情解析的压抑 → 承：死局罗列与遗言托付 → 转：歪理激将、决心自战的转折 → 合：救孩暴露、暗蝇飞塔顶的钩子
- **节奏配比**：慢铺垫 20% / 快冲突 20% / 爽点爆发 10% / 悬念留白 50%
- **本章结构公式**：解析黑暗侵染（立规则） + 罗列死局激将冷青（转决心） + 独身出街试探杀手（推行动） + 救孩暴露暗蝇报信（开危机）
- **本章核心技巧**：先用大量篇幅把"不能用魔法"的规则钉死，再让主角明知故犯地打破它，代价即刻兑现制造章尾危机
- **卡点与伏笔**：结尾卡点：悬念型——暗蝇飞向广州塔顶，杀手已然得知莫凡的位置，一场猎杀即将开始；埋设/回收伏笔：黑暗侵染的反馈机制 → 莫凡用魔法即暴露的核心规则；冷青掌握的红衣主教讯息 → 她坚持要交代的内容；包老头在国外遇大事 → 后续支线；赵满延因航班无法来援 → 暂时缺席的伏笔
