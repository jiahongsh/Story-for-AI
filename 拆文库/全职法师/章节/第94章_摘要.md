# 第94章 统领级翼苍狼

**概要**：盘踞银贸大厦之顶的巨兽即统领级翼苍狼，博城任何位置都能目睹它，莫凡对妖魔的认知被彻底推翻——人类在它眼中不过是圈养在都市里的食物。林雨欣僵硬地讲解妖魔分级：幽狼兽、独眼魔狼皆是最低的奴仆级，血纹巨魔鼠是战将级，翼苍狼是统领级、全城唯斩空能在其一击下存活；安界外上百只战将级三眼魔狼率独眼魔狼与军部厮杀，约一千只妖魔窜入城内，猎者联盟邓凯率猎法师封锁猎杀。她揭露真相：黑教廷炼制出与地圣泉以假乱真的暴躁之泉，洒入云雾借大雨催化，令魔狼族群疯狂攻城，意在彻底血洗博城。她嘱莫凡保管好地圣泉、活下去，随后斩断头发、故意吸引黑教廷的注意力奔入雨幕；莫凡转身看见天澜高中后山有大批妖魔奔逐。

**关键事件**：1.林雨欣讲解妖魔分级与全城战况 2.揭露黑教廷以暴躁之泉引狼屠城 3.林雨欣断发诱敌、托付地圣泉后独自赴险

**逐章写法公式**：

- **情绪流向**：起：巨兽慑服 → 承：战况沉重 → 转：黑手惊现 → 合：托付悲壮
- **节奏配比**：慢铺垫 20% / 快冲突 20% / 爽点爆发 0% / 悬念留白 60%
- **本章结构公式**：翼苍狼定级（恐惧标定）+ 战况通报（局势铺开）+ 暴躁之泉揭底（回收真相）+ 断发诱敌与校园告急（托付+接力钩子）
- **本章核心技巧**：本章为"情报章"，借护送者之口一次性交付分级体系、战况与幕后黑手，再用断发的仪式动作把情感落点压在配角身上
- **卡点与伏笔**：结尾卡点：学校后山妖魔群奔逐，主角下一战场切回校园；埋设/回收伏笔：暴躁之泉（回收第90章污水检测结果）、林雨欣妹妹是阴谋更早牺牲品（复仇线）、黑教廷迫切想得到地圣泉（夺宝主线）、翼苍狼与斩空的实力差（后期战力标尺）
