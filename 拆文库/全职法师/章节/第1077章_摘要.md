# 第1077章 第一次作案

**概要**：莫凡与穆宁雪认为在战地首要目标是搜刮资源，不值得与他国硬拼消耗魔能。穆宁雪空中见黑云山聚多人，莫凡断言人多必有好东西。他提出"抢比找快"——省去寻宝、斗妖、防被蹲的风险，直接抢到手就撤，穆宁雪起初犹豫后被拉入伙，并周全提议戴面具换装短时不被认出。另一边，灰蟒山多国学员合力击杀山顶岩魔后，意大利安吉洛独吞值四五亿的石心脏逃窜，被法日学员追杀。安吉洛甩开追兵入山岭得意，却落入莫凡预埋的黑暗禁锢陷阱，戴朴素面具的莫凡走出笑纳石心脏，并戏称是亚克料事如神才在此堵截，让安吉洛记恨亚克之名。

**关键事件**：1.莫凡定下"抢比找快"的夺宝策略、穆宁雪入伙 2.多国合力杀岩魔、安吉洛独吞石心脏 3.安吉洛甩追兵入山岭 4.莫凡黑暗陷阱困安吉洛夺石心脏 5.伪装嫁祸亚克

- **情绪流向**：起：策略商量的轻松 → 承：安吉洛独吞的铺垫 → 转：埋伏夺宝的反转爽 → 合：嫁祸亚克的搞笑余波
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：定抢宝策略（铺垫） + 安吉洛独吞（目标） + 埋伏陷阱（高潮） + 夺宝嫁祸（余波）

- **卡点与伏笔**：结尾卡点：凡雪盗团首案得手，下章期待壮大队伍；埋设/回收伏笔：石心脏 → 凡雪盗团首笔赃物
