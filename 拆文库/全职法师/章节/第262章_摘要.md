# 第262章 拿出真正实力！

**概要**：莫凡把幽狼兽也派去与沈明笑、牧奴娇合战幽纹暴狼，判断暴狼实力不如自己遇过的鳞皮母妖与诅咒畜妖，但战将级天生强过中阶魔法师；他看了眼凝神项链嘀咕收了萧院长好处不能拿钱不办事，随后部署宋霞制住风系并护住自己。穆宁雪突施第二级别冰锁，寒冰锁链钻地而出把莫凡捆成冰锁木乃伊——众人根本没看到她描画星图，她对中阶冰系的掌控近乎瞬发，锁链间的冰刺花更意味着她随时可刺杀被困者。三位老师以为败局已定欲认输，赵满延以莫凡曾独杀鳞皮母妖为由喊再等等；顾翰忽然从冰锁中察觉一股暴躁的强火元素、如血鲜红慢慢透出。陆正河笑言庆功酒，穆宁雪却不松懈，凝视莫凡说出"不要再伪装了，拿出你的全部实力来"——穆氏家族宴客之夜她见识过他天生双系的逆天天赋，上场正是冲此而来。

**关键事件**：1.莫凡派幽狼兽与分工布阵 2.穆宁雪冰锁瞬发囚住莫凡 3.老师欲认输、顾翰察觉冰中透火 4.穆宁雪点破莫凡在伪装

**逐章写法公式**：

- **情绪流向**：起：排兵与卖命吐槽的松弛 → 承：冰锁瞬发囚禁主角的绝望 → 转：场边认输与赵满延苦撑的过山车 → 合：冰中透火与"拿出全部实力"双钩并发
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：派兽布阵（定分工）+ 冰锁秒囚主角（绝望顶点）+ 场边认输与再等等（情绪反复）+ 冰中火光与敌方喊话（双钩反转）
- **本章核心技巧**：先让主角被速攻式控制制造假性败局，再从顾翰的火元素感知与穆宁雪的喊话两个视角同时暗示翻盘，借敌方王牌之口抬高主角的隐藏规格
- **卡点与伏笔**：结尾卡点：紧张——冰锁中透出如血火光，莫凡如何脱困、火系是否曝光在即；埋设/回收伏笔：穆氏家族宴客之夜莫凡展现天生双系 → 重磅往事回扣，穆宁雪与他渊源实锤；凝神项链与萧院长系主任的好处 → 校方交易线；冰刺花杀招未用 → 穆宁雪未下杀手的分寸；鳞皮母妖、诅咒畜妖旧战 → 战绩锚点再回扣
