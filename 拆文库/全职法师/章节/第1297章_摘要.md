# 第1297章 莫凡救美

**概要**：军法师们扑上来保护芍女，却被古铜牙山人接连撕碎，一名军人舍命挂在山人的爪子上仍被撕成碎片，芍女含泪逃入密草，古铜牙山人把怒火发泄在剩下的军法师身上又撕碎五人。与此同时军官们在芍女所指位置救下三名被捆绑的猎人，他们被迫拼命喊叫，年轻军官恍然醒悟这是山人调虎离山的诱饵，赶回才发现满地碎尸——山人利用大队救人心切的心理，用诱饵把队伍调散，真正的目标始终是芍女。莫凡养好伤后用遁影下到树干分叉处查探山人分布，发现一处没有山人设防，落地时看到一个衣裳褴褛、鲜血淋漓的苗条身影倒在树根凹槽里——正是重伤的芍女。莫凡用血剂和高档良药救她，伤药起效让她恢复呼吸。古铜牙山人追来，芍女让他快逃，莫凡说自己来，踏前一步双臂交错放出两道雷电光束击向古铜牙山人。

**关键事件**：1.军法师舍命护芍女，被古铜牙山人撕碎多人 2.山人以捆绑猎人为诱饵调虎离山，军官们中计 3.莫凡查探山人分布，发现落难的芍女 4.莫凡用药救活重伤的芍女 5.古铜牙山人追至，莫凡出手迎战

**逐章写法公式**：

- **情绪流向**：起：军法师舍命护芍女的悲壮 → 承：山人大计中计的血腥 → 转：莫凡巧遇救下芍女的温馨 → 合：古铜牙山人追至、莫凡出手的热血
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：军法师牺牲护芍女（悲壮） + 调虎离山计中计（阴谋揭示） + 莫凡救芍女（线汇合） + 莫凡迎战古铜牙山人（钩子）
- **本章核心技巧**：先让一个传奇强者被敌人用智商击败（中计），再让她被主角恰好救下，两条线在「救」的动作上汇合，把铺垫已久的战场全局收拢回主角行动
- **卡点与伏笔**：结尾卡点：莫凡两道雷电攻向古铜牙山人，胜负未分 → 下章期待雷爆重创；埋设/回收伏笔：彩尾雀救芍女 → 后文敌对种族线；心夏给的帕特农良药 → 莫凡的保命资源
