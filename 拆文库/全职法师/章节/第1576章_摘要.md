# 第1576章 骨骷木乃伊

**概要**：方形门一开，米奥斯第一个喊撤，海蒂标记位置放出群体瞬息移动，六人两段瞬移越过了君主木乃伊。赵满延酝酿防御准备迎击，木乃伊却始终不出手，只阴沉的目送众人跑进方形门，穆白回头看见它还站在原地等待什么。新墓室里堆着一座骷髅头白骨丘，丘顶是一口骨制灵柩，莫凡一拳轰落灵柩，跳出一只无头骨甲木乃伊，随手抓骷髅头装脑袋还嫌小换头。它气息不如君主木乃伊却暴躁力大，追着众人不放，被赵满延挡下后众人全身而退逃进门里，它在门外盯视却不敢离开墓室。

**关键事件**：1.群体瞬息移动两段撤离躲过君主木乃伊 2.新墓室白骨丘顶骨灵柩，烈拳轰出无头木乃伊 3.骨木乃伊暴追被赵满延挡住，众人全身而退

- **情绪流向**：起：逃生紧迫 → 承：木乃伊反常不出手 → 转：新墓室白骨丘换头怪 → 合：暴追被挡、全身而退后疑云再起
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：群体瞬移（撤）＋木乃伊反常目送（悬念）＋白骨丘换头怪（新威胁）＋暴追抵挡（危机）＋疑云收尾（钩子）
