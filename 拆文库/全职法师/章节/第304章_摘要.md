# 第304章 让一个活

**概要**：陆年忌惮弟弟被挟持，摆手令轰炸团停手。原文交代他从军多年无儿无妻，陆正河是家里唯一香火、不能死，但他不能表现出在意弟弟的样子——若非不得已他仍会选择牺牲弟弟，因为他要做的"宏伟"之事若成功将改变世界格局。廖明轩搬出帝都魔法协会廖封之子身份叫嚣威胁，被陆年眼中褐色光芒一闪、灰白物覆体，几秒内化作灰白石雕。面对牧奴娇的质问，陆年意味深长地说"这件事是你爷爷也同意的"。随后他提出"一条命换一条命"让莫凡选：莫凡先点名换五人吓坏罗宋、沈明笑，被拒后干脆说"那让我走"。白婷婷、牧奴娇、赵满延对被放弃各有心酸反应，赵满延托付莫凡将来替他杀陆年。最后陆年揭底：所有人都可以走，唯独莫凡不能走。

**关键事件**：1.陆年石化廖明轩 2.一命换一命的谈判拉扯 3.陆年宣布唯独莫凡不能走

**逐章写法公式**：

- **情绪流向**：起：紧张（停手对峙） → 承：恐怖（廖明轩化雕像） → 转：悲伤（队友告别） → 合：紧张（唯独你不能走）
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 0% / 悬念留白 55%
- **本章结构公式**：反派让步（假意谈判）+ 后台覆灭（立威示威）+ 换命拉扯（人性试炼）+ 目标揭晓（莫凡被锁定）
- **本章核心技巧**：用"选谁活"的道德两难逼出每个角色的一句话遗言式反应，以谈判过程代替打斗推进剧情
- **卡点与伏笔**：结尾卡点：陆年宣布唯独莫凡不能走、这群人神情木然太过诡异，下章期待目的揭晓；埋设/回收伏笔：廖封之子身份→廖明轩之死；牧战兴也同意此事→牧家高层牵连悬念；陆年"宏伟事业"→新系实验线开启
