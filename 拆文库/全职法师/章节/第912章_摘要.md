# 第912章 一个打三个！

**概要**：东方烈认出赛以德气愤，牧奴娇说每国府有三次挑战机会，东方烈骂其不要脸，岳棠心发现穆宁雪闭关不在。莫凡拍胸称有我在，东方烈冷哼其非成员别丢人，莫凡反讥打败过他。白东威认出莫凡是替下国府的莫凡、欲删其名额。赛以德叫嚣，莫凡径直走上斗台，称上次你一人打三，今我站这让你挑三人轮流打。牧奴娇让白教员试试，埃及队嗤之以鼻，赛以德抢先出场。莫凡不由分说火系轰赛以德，白东威傻眼，赛以德暗影拉距召铁尸，莫凡召疾星狼，赛以德再召近统领级死刀木乃伊，莫凡了然其底。

**关键事件**：1.穆宁雪不在众人忧 2.莫凡登台叫战三 3.牧奴娇准其试 4.赛以德抢先出场 5.死刀木乃伊现

**逐章写法公式**：

- **情绪流向**：起：穆宁雪缺的忧 → 承：莫凡登台的狂 → 转：准战的对峙 → 合：底牌现的紧
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：缺人忧（忧） + 登台叫战（狂） + 准战对峙（紧） + 底牌现（钩）
- **本章核心技巧**：用"一打三"狂言拉期待，末尾用底牌收钩
- **卡点与伏笔**：结尾卡点：莫凡如何破死刀木乃伊，下章揭晓；伏笔：死刀木乃伊近统领 → 实力标尺
