# 第290章 集齐七颗

**概要**：莫凡以千钧霹雳一指之雷瞬灭进阶期独眼魔狼，血雨吓傻周围狼群，再以雷印电弧控制住数只、连发三个火滋粗暴轰杀，战后从狼尸中拾得精魄——历练以来久不见精魄让他明白星尘魔器为何稀有昂贵，第六颗星子随之可以强化。另一边疾星狼以受伤为代价咬住三眼魔狼咽喉，三眼魔狼自知不敌，砸出一辆废旧汽车后狂奔逃命，莫凡射出暗影钉将其无声禁锢，疾星狼化作寒芒厉爪割断其双臂与头颈，无头巨狼轰然倒塌；疾星狼吞食其心脏助力成长。莫凡翻检尸体发现无异骸，倒是狼群中有一只独眼魔狼出了根可卖一二十万的异肋骨；残魄还差一些，他收起闪绿光完成勘测的装置，照地图杀向下一个勘测点，只等集齐七颗星子令雷印蜕变。

**关键事件**：1.霹雳瞬灭进阶期独眼魔狼并拾得精魄、强化第六颗星子 2.暗影钉禁锢逃亡的三眼魔狼、疾星狼斩首并吞其心脏 3.检尸得异肋骨、发现残魄不足 4.莫凡收起完成勘测的装置杀向下一勘测点

**逐章写法公式**：

- **情绪流向**：起：强敌瞬灭的爽快 → 承：三眼魔狼逃命的紧张 → 转：斩首吞心的热血 → 合：奔赴下一勘测点的轻快余韵
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：霹雳秒杀（兑现上章卡点） + 拾魄强化（成长结算） + 咬喉掷车（反方挣扎） + 暗影钉禁锢（控场） + 化刃斩首（高潮解决） + 检尸结算与开拔（余波+下章钩子）
- **本章核心技巧**：开章先兑现上章强敌的胜负悬念，再用品鉴战利品式的战后结算段（心脏、异肋骨、残魄账目）把爽感延长
- **卡点与伏笔**：结尾卡点：目标达成型——七颗只差最后一程残魄，下章期待奔赴下一勘测点的遭遇；埋设/回收伏笔：精魄/残魄强化体系 → 回收289章“星子已5颗”进度，埋下“雷印蜕变”待后续兑现；异肋骨（一二十万） → 小额财富线索
