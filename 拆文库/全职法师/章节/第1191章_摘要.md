# 第1191章 没有宽恕的余地！

**概要**：北雨山头，审判长陆斩天将弟弟陆一林的遗物一件件投入火盆焚毁，议员父亲陆辛来电斥他惹麻烦、莫凡已非同一般，陆斩天不听，挂断后集合山下二十余名审判员，其中包括戴一半面具、散发怪物气息的宇昂。副审判长冯景兰不解，审判使夜鹰赶来质问，陆斩天以“常规执法”轻描淡写掩饰。夜鹰指出他是以莫凡父莫家兴与黑教廷有关为由带走盘问，实则是借宇昂与莫凡的旧怨激怒莫凡，让其在北雨山动手、给自己正当处决理由。夜鹰劝阻莫凡冷静，灵灵已查清圈套，但莫凡的两个底线被触——父亲被威胁、许昭霆心结宇昂——决不忍让，认定有些恶人没有宽恕的余地。

**关键事件**：1.陆斩天焚弟遗物、不听父劝集审判员 2.夜鹰识破借宇昂激怒莫凡的圈套 3.莫凡知圈套仍不忍 4.两底线被触，决杀宇昂

**逐章写法公式**：

- **情绪流向**：起：陆斩天焚遗物立誓的冷 → 承：集人设局的压抑 → 转：夜鹰点破圈套的紧张 → 合：莫凡触底线决不忍的燃
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：陆斩天设局（铺线） + 夜鹰点破（揭示） + 莫凡知圈套（抉择） + 两底线触怒（爆发钩子）
- **本章核心技巧**：用“合法外衣掩盖私仇”构造规则困境，再以主角两条具体创伤底线把忍与不忍的抉择推向必战。
- **卡点与伏笔**：结尾卡点：莫凡决不忍，下章大战审判员；埋设/回收伏笔：宇昂与许昭霆旧怨 → 莫凡必杀宇昂伏笔。
