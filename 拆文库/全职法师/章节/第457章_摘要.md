# 第457章 组建团队

**概要**：莫凡与赵满延在包间研读知密卷轴，得知炎姬幼年期喂食灵种碎片可在进阶时蜕出魂种级火焰，是理想的契约兽人选，莫凡决定砸钱把炎姬的情报买全。赵满延派人去猎法师的民间聚集地收集信息，莫凡再按方位购置知密卷轴，摸清了灼原北角的位置、路线与危险性。莫凡随即决定直接出发，往返不过半月，并威逼利诱拖上赵满延。他先后说动智囊灵灵、至交张小侯入队，赵满延坚持必须配一位信得过的治愈系法师，而白婷婷自出事后再未回学校，正当莫凡头疼时，赵满延提醒主修治愈、辅修心灵的心夏正是安抚元素妖的最佳人选。

**关键事件**：1.莫凡决定砸钱买全炎姬情报 2.莫凡说动赵满延、灵灵、张小侯组建队伍 3.赵满延提议让心夏以治愈系加心灵系身份入队

**逐章写法公式**：

- **情绪流向**：起：兴奋 → 承：砸钱心疼与情报积累 → 转：队伍缺口卡住计划 → 合：心夏人选点破，钩子立起
- **节奏配比**：慢铺垫 55% / 快冲突 10% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：确认炎姬价值（定目标） + 收集情报定路线（铺路） + 逐人招兵买马（积势） + 治愈系缺口引心夏（立钩子）
- **本章核心技巧**：用小目标承接大矛盾——整章无战斗，靠资源消耗、人员缺口层层施压，最后用一句话给出唯一解法
- **卡点与伏笔**：结尾卡点：人员缺口型，心夏治愈兼心灵双系成为唯一人选，下章期待她能否入队；埋设/回收伏笔：知密卷轴炎姬信息 → 本章目标来源；白婷婷离校 → 治愈系缺口成因
