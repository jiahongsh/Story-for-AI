# 第608章 城市，岌岌可危

**概要**：莫凡向祝蒙说明古都大雨、亡灵暴动与博城灾难相似，虽然没有证据，祝蒙仍相信他的判断。祝蒙劝莫凡撤到内城，莫凡拒绝被护送，坚持先去北城寻找柳茹、张小侯等朋友；妖男则说青天猎所追查撒朗的零碎线索已经指向古都。四个方向同时拉响紫色警戒，外城墙无法继续防守，近十四公里的内城墙安全结界成为唯一防线。人群在交通瘫痪中逃亡，亡灵潮和骸刹冥主不断摧毁外城墙，山峰之尸从远处逼近。

**关键事件**：1.祝蒙接受莫凡关于黑教廷的判断 2.莫凡决定去北城带朋友撤离 3.古都全面撤入内城结界并面临外城墙崩溃

**逐章写法公式**：

- **情绪流向**：起：线索得到承认的凝重 → 承：朋友诀别与外城墙失守 → 转：全城人群逃向内城 → 合：亡灵巨君持续摧毁防线
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：解释灾难相似性（获得认可） + 坚持寻找朋友（建立行动目标） + 全城撤离（扩大场景） + 亡灵摧毁外城墙（抬高终局压力）
- **本章核心技巧**：把主角的私人救援目标嵌入全城撤离任务，让个人关系和宏观灾难互相推动。
- **卡点与伏笔**：结尾卡点：外城墙在亡灵潮和骸刹冥主攻击下崩溃，山峰之尸仍在逼近；埋设/回收伏笔：撒朗名字与古都线索 → 为后续黑教廷调查和灾难真相推进提供方向。
