# 第371章 天赋排行第五

**概要**：电击贯穿柳一林全身，他连惨叫都发不出，满心疑惑对方为何能无声近身、又为何十五分钟解决中阶无敌的东方明。莫凡兑现"见你一次揍一次"的承诺，一脚把四十二码鞋印踢在他脸旁，还告知鞋底踩过白镇结界墙下的家禽饲养场。唐月随即反攻，第三级烈拳九宫九道火柱将草场烧成焦土，柳钟鸣与同伴苦不堪言，四人尽数解决后两人遁影入山。宫廷侍卫赶到现场，武平景怒斥只会牵制的四人，东方明辩解"见他们实力平平"，柳钟鸣甩锅称他是被另外那个小子打败的。武平景与李锦点破真相：莫凡是天赋排行榜第五的天生双系、明珠学府新纳学员最强，博城灾难与魔都粉碎黑教廷两次计划都与他有关，论天赋背景实力东方明全面不如，十五分钟都撑不住。四人被逐出审判序列，东方明发誓十倍奉还，柳一林本想寻仇，得知东方明都被虐后心生恐惧作罢。

**逐章写法公式**：

- **情绪流向**：起：爽（电击与鞋印羞辱） → 承：爽（烈拳九宫收割） → 转：压抑（侍卫到场问责） → 合：爽（身份点破与代价清算）
- **节奏配比**：慢铺垫 15% / 快冲突 25% / 爽点爆发 50% / 悬念留白 10%
- **本章结构公式**：擒贼羞辱（私仇了结） + 高阶收割（团战终结） + 敌方问责（反应层） + 身份抬咖（战后清算）

- **卡点与伏笔**：结尾卡点：余波加新忧型——追兵溃败、两人遁影入山，期待护送最后一段与宫廷侍卫的正面对上；埋设/回收伏笔：东方明"十倍奉还"→长期仇家线；柳一林恐惧放弃寻仇→性格弧收束。
