# 第865章 撒朗逃脱之地

**概要**：穆宁雪进屋莫凡做贼心虚，听牧奴娇讲国馆事后拍桌怒骂赛义德。灵灵忽然来访，抛出审判会外包的超级悬赏——铲除可能从崇明县逃脱的撒朗黑教廷余党，危险极高。莫凡立刻拦下不让多说，怕牵连身边人，穆宁雪却情绪激动：黑教廷毁了博城与她的家族、逼到改名换姓，养父与亲叔都是黑教廷高层，她即便无悬赏也愿接。莫凡坚持线索在自己手上、不接，穆宁雪气得说不出话，吐露父亲养子与亲弟皆为黑教廷、家族怨念全压在父亲身上。

**关键事件**：1.莫凡心虚，灵灵抛撒朗悬赏 2.莫凡拦话怕牵连 3.穆宁雪激愤立誓接黑教廷 4.穆宁雪吐露家族被黑教廷牵连

**逐章写法公式**：

- **情绪流向**：起：心虚听国馆事 → 承：灵灵抛撒朗悬赏 → 转：莫凡拦话穆宁雪激愤 → 合：吐露家族血仇立誓接
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：心虚听事（日常） + 悬赏抛线（钩） + 拦话护短（暖） + 血仇立誓（燃）
- **本章核心技巧**：用"主角护短 vs 女主血仇"的冲突，把黑教廷主线的人情动机钉死
- **卡点与伏笔**：结尾卡点：穆宁雪吐露父亲被黑教廷牵连、怨念压身，下章期待莫凡如何回应；埋设/回收伏笔：撒朗从崇明岛逃脱 → 黑教廷国内最后据点的伏笔
