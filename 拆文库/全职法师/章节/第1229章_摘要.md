# 第1229章 莫凡老师（上）

**概要**：张小侯回秦岭军区、蒋少絮循勺参谋的消息离去，莫凡和牧奴娇返回魔都。莫凡自觉让小炎姬获得复活和新魂火而牧奴娇一无所获，便把弄碎的石晶给了她。回到住处，牧奴娇提醒两人还没毕业，世界学府之争打完也拿不到学校奖励。二人来到学校找萧院长办提前毕业，萧院长介绍毕业分结业、普通毕业和优秀毕业三种，优秀毕业奖励由全国高校共同发放、受各大势力争抢。可惜能带优秀毕业的导师都去进修了，萧院长心生一计，直接指派莫凡做毕业导师，带队完成他手头水脉循环阵的卡点环节才给优秀毕业资格。莫凡抗议这分明是老师的年度考核指标，牧奴娇在一旁笑称莫凡老师加油。

**关键事件**：1.莫凡把碎石晶赠给牧奴娇 2.牧奴娇提醒莫凡两人尚未毕业 3.萧院长介绍三种毕业制度并说明优秀毕业奖励丰厚 4.萧院长指派莫凡当毕业导师带队做项目

**逐章写法公式**：

- **情绪流向**：起：返城分赠的温情 → 承：毕业常识科普的轻松 → 转：萧院长指派导师的戏剧反转 → 合：莫凡老师上任的期待
- **节奏配比**：慢铺垫 60% / 快冲突 15% / 爽点爆发 5% / 悬念留白 20%
- **本章结构公式**：返程交代众人去向（收旧线）+ 牧奴娇点醒未毕业（设动机）+ 萧院长科普毕业制（铺世界观）+ 指派莫凡当导师（立新身份）
- **本章核心技巧**：用制度规则制造身份反转，先让读者以为莫凡来毕业，再让他被迫当导师
- **卡点与伏笔**：结尾卡点：反差型——莫凡老师即将带毕业生，为下章打脸学生埋线；埋设/回收伏笔：萧院长的水之循环阵项目 → 引出桐乡水脉冒险；优秀毕业奖励 → 后续毕业任务主线
