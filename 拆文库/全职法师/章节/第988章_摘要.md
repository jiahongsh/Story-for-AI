# 第988章 溺咒之因

**概要**：深夜灵灵将水母歹蛆幼体带到海边，放入海水中后它彻底与海水融为一体，借此向莫凡、穆宁雪、鲍比解释溺咒机制：歹蛆入水后肉眼难辨，故溺咒死者身上查不出毒、寄生妖或诅咒迹象。灵灵详述其寄生全过程——从口腔耳鼻进入体内、粘附胃部疯狂摄取养分使人食欲大增，成熟后蚕食身体机能、发出精神控制逼人投海，钻出瞬间抽空寄主能量致其数秒萎蔫而亡，再游入大海。她将歹蛆分为寄生孵化与海洋成长两形态，指出成功操控精神者已如癌症晚期无药可救。灵灵已在歹蛆体内注入跟踪印记，坦言接下来的任务最艰难：必须保护这只脆弱的活体标本平安长成完全体，才能提取疫苗组织交给国际魔法协会，从源头解决溺咒。

**关键事件**：1.灵灵海边放归歹蛆并解释溺咒寄生机制 2.灵灵划分歹蛆两形态并指出晚期无药可救 3.决定保护脆弱活体标本长成完全体以提取疫苗

**逐章写法公式**：

- **情绪流向**：起：海边放蛆的神秘 → 承：寄生机制详述的惊悚铺垫 → 转：疫苗希望的升温 → 合：护蛆长大任务的荒诞悬念
- **节奏配比**：慢铺垫 45% / 快冲突 0% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：放归展示隐形（解释盲区） + 口述寄生过程（坐实机制） + 划分两形态（界定难度） + 定下护蛆任务（抛核心目标）
- **本章核心技巧**：用一次可见的放归实验带出整套不可见寄生设定，把悬赏目标反转成保护任务
- **卡点与伏笔**：结尾卡点：类型行动+如何护脆弱歹蛆长大引下章；埋设/回收伏笔：跟踪印记→后续定位完全体
