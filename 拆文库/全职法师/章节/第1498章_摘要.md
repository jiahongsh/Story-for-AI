# 第1498章 拉他下水

**概要**：九幽后在尤莱墓前感应良久，郑重告诫莫凡夺走遗骸的家伙很强、比她还强，劝他别去招惹，否则有生命危险，莫凡这才作罢。回到阿尔卑斯山学府，珈蓝老师希望让修为卡瓶颈的海蒂随莫凡去埃及历练求突破，李教授、珈蓝、佩里院长齐声相劝。莫凡本欲拿布兰妾同去作说辞来推脱，结果布兰妾竟答应同行，他推脱无门，只能盘算到埃及后把众人安顿好、自己与九幽后单独行动。李教授、郑教授带李夕眉、石俊盛返程，莫凡、穆白、赵满延、布兰妾、海蒂五人飞往开罗。飞机上莫凡才向赵满延坦白此行是开亡灵国战、让本国亡灵帝国反攻埃及，赵满延当场要跳飞机，最后被支走两妞、拉穆白下水的计划说服，贼笑起来。

**关键事件**：1.九幽后感应后警告盗骸者强于自己，莫凡放弃追查 2.布兰妾答应随行，海蒂同往埃及历练 3.飞机上莫凡坦白开亡灵国战计划，赵满延要跳机后被拉下水

**逐章写法公式**：

- **情绪流向**：起：盗骸悬念 → 承：组队变数的意外 → 转：坦白亡灵国战 → 合：拉人下水的默契
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：九幽后警告罢手（收束旧案） + 组队生变（新队伍成型） + 坦白开亡灵国战（任务揭示） + 支走两妞拉穆白下水（方案落定）
- **本章核心技巧**：用喜剧化的组队过程包装一个极其危险的作战计划，让读者在笑声中接受主线推进
- **卡点与伏笔**：结尾卡点：信息揭示+埃及亡灵国战成行、五人行组合确定；埋设/回收伏笔：开冥界大门 → 埃及金字塔主线；赫卡萨与颜秋 → 暂置支线；穆白拉下水 → 后续行动角色
