# 第1382章 攻占魔烽火台

**概要**：神楚之界让冥界大军彻底失去翻越能力，高岩坡上的莫凡看到宏伟之墙矗立终于松口气，但还不能出手——他必须等赵满延杀掉紫鬼后才能释放恶魔开战。黑教廷这边，冷爵见墙咆哮质问，乌纳斯点出这是沉淀五千年的古老东方土系魔法，劝冷爵冷静，并献计：那道压制冥生物的禁制多半对人类不起作用，宏伟之墙靠阵法师在魔烽火台注入土系源泉支撑，杀阵法师比毁墙容易得多。冷爵当即令六鬼率众执事、教士分赴六座魔烽火台格杀勿论，又派乔雀负责镇北关。莫凡发现冥生物对黑教廷人员视而不见，让他们在冥界大军上空来去自如，暗呼不妙。乌纳斯向紫鬼借人，紫鬼把莫凡、蓝蝙蝠与乌鸦三人交到乌纳斯手下，自己率十三名蓝衣执事前往往神木关，莫凡追问解除契约之事，紫鬼笑而不答。莫凡被调离，赵满延连谁是紫鬼都不知道，刺杀计划告急。墙后岩丘下，赵满延与灵灵苦等信号不至，却发现黑教廷外围成员全体浮出水面涌向烽火台。灵灵在小本本上感应到夜煞的黑暗气息——莫凡已把夜煞缠到紫鬼身上，二人可以循黑暗物质指引找到紫鬼，赵满延眼睛一亮。

**关键事件**：1.乌纳斯向冷爵献计：禁制对人类无效，杀阵法师可破墙 2.冷爵令六鬼分率执事教士进攻六座魔烽火台，乔雀负责镇北关 3.紫鬼将莫凡、蓝蝙蝠、乌鸦调给乌纳斯，自己率众前往神木关 4.莫凡被调离、无法传信号，赵满延刺杀计划告急 5.灵灵在小本本上感应到夜煞气息，二人可循黑暗物质找到紫鬼

**关键信息与扩写技法**：

**逐章写法公式**：

- **情绪流向**：起：防线筑成的轻松 → 承：黑教廷识破弱点的紧张 → 转：莫凡被调离、计划告急的焦躁 → 合：夜煞指引带来转机的期待
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：莫凡落心（稳住主线情绪）+ 冷爵定计攻烽火台（敌方推进）+ 紫鬼调走莫凡（计划受阻）+ 夜煞指引现转机（钩子收尾）
- **本章核心技巧**：双线并进——黑教廷的攻与莫凡赵满延的守计划同时推进，用"棋子被调离棋盘"让计划节外生枝，再用手法后手挽回悬念
- **卡点与伏笔**：结尾卡点：赵满延灵灵循黑暗物质追踪紫鬼，但莫凡已被调离、黑教廷全面进攻魔烽火台，下章能否及时刺杀；埋设/回收伏笔：夜煞缠在紫鬼身上→回收莫凡携带夜煞的伏笔，提供追踪线索
