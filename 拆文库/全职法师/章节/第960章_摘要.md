# 第960章 就是想宰了他们

**概要**：赵满延感慨好人难做，莫凡却深信恶人不会突生仁慈，只会变本加厉。莫凡将鼻环法师掷入菱形压缩空间压成人渣，红饰法师尽数被宰，赵满延升起金光将其尸体超度成灰。村民仍替红饰求情，少女贾妮却追出含泪道谢，想求莫凡灭掉红饰公会。老寨长忙拦，贾妮哭诉父亲当场惨死、仇恨难平。莫凡拍她脑袋问是否真想灭红饰，贾妮泪崩直言"是"。赵满延急拦称铲除整个公会非同小可，莫凡却转身朝白头市走去，赵满延蒋少絮跟上。蒋少絮展颜赞其魄力——就打心底想宰了红饰，没别的。

**关键事件**：1.莫凡空间压缩宰红饰，赵满延金光超度 2.贾妮追出道谢，求灭红饰公会 3.贾妮哭诉父死，莫凡问是否想灭红饰 4.莫凡转身赴白头市，蒋少絮赞其魄力

**逐章写法公式**：

- **情绪流向**：起：好人难做叹惋 → 承：宰匪超度解气 → 转：贾妮求灭燃情 → 合：莫凡转身赴战留钩
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 20% / 悬念留白 30%
- **本章结构公式**：宰匪超度（解气） + 村民求情（反衬） + 贾妮求灭（燃点） + 转身赴战（立誓）
- **本章核心技巧**：用"群体懦弱vs个体勇气"的反差立情感支点，把主角决心落到"为弱者出头"而非圣母
- **卡点与伏笔**：结尾卡点：莫凡是否真铲除红饰公会留悬念；埋设/回收伏笔：贾妮父死→灭会动机；空间压缩→实战处刑
