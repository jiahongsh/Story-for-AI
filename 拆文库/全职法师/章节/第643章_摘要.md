# 第643章 虎津现身

**概要**：薛藏担心穆白的消息是圈套，穆贺却认为即使是圈套也必须验证，一旦确认莫凡拥有地圣泉，就要设法救出撒朗。莫凡等人在拥挤的博物馆避难所收到陌生人纸条，被引到馆顶。雨幕下，莫凡看到亡灵军团包围内城和已逼近的山峰之尸，穆贺随后以真面目现身。穆贺承认自己曾想制造事故杀死莫凡父亲，也承认张小侯恢复记忆已无意义；他表示莫凡的地圣泉只能撑到黎明，并要求莫凡配合观看这场“盛典”。

**关键事件**：1.穆贺决定验证地圣泉消息 2.莫凡收到馆顶纸条 3.莫凡观察山峰之尸 4.穆贺以真面目现身 5.穆贺宣称地圣泉无法撑过黎明

**逐章写法公式**：

- **情绪流向**：起：敌方怀疑诱饵 → 承：莫凡被引至馆顶 → 转：虎津真身现身 → 合：黎明倒计时压向城市
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：验证地圣泉（推进敌方行动） + 纸条引人（转移场景） + 远眺亡灵海（扩大危机） + 穆贺现身（锁定对手）
- **本章核心技巧**：让敌人用主角的诱饵反向设置会面场景，并在对话中以私人仇恨和城市倒计时同时施压。
- **卡点与伏笔**：结尾卡点：穆贺说地圣泉只能撑到黎明，下一章期待他提出真正谈判条件；埋设/回收伏笔：穆贺与莫凡父亲旧怨 → 直接转化为面对面挑衅。
