# 第725章 瞬息移动

**概要**：穆宁雪提出可将四座碎岛间的海域冻结以制约赤凌妖，艾江图采纳。十人潜入三角连岛，官鱼与黎凯风先清除礁滩海猴怪，却漏了一只。危急时艾江图施展空间系"瞬息移动"从百米外甲板一瞬现身，隔空取物将逃窜海猴怪甩死在礁石上，众人惊叹其高阶实力。南荣倪以伪装仪藏船留守，众人计划由穆宁雪冻海、莫凡赵满延制造动静引开赤凌妖。

**关键事件**：1.穆宁雪定计冻结海域 2.官鱼黎凯风清礁滩海猴怪漏一只 3.艾江图瞬息移动秒杀逃妖 4.定下冻海引妖计划

**逐章写法公式**：

- **情绪流向**：起：定计的从容 → 承：漏妖的微小危机 → 转：艾江图瞬移秒杀的爆发 → 合：潜入成功定计划的余波
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 30% / 悬念留白 20%
- **本章结构公式**：穆宁雪冻海提议（定略） + 官鱼黎凯风清礁（铺垫） + 艾江图瞬移秒杀（亮牌） + 定引妖计划（推进）
- **本章核心技巧**：用一个小意外逼出核心角色的隐藏高阶能力，以旁观者反应层放大爽感
- **卡点与伏笔**：结尾卡点：赵满延被推去和莫凡炮轰老巢；埋设/回收伏笔：瞬息移动→后续对战赤色裂妖反复使用
