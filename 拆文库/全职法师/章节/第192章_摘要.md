# 第192章 母妖现身！

**概要**：赵满延感慨若非灵灵误打误撞的侦测仪器，谁也想不到这些女志愿者还有另一幅皮囊，他说"这里交给我吧"主动断后；莫凡嘱咐一句小心，身子便沉入脚下阴影消失，赵满延只见坏灯通道里人影一闪，误以为是暗影技能的魔具。莫凡独自赶往升降台，信任拥有光佑·圣盾的赵满延不至于轻易死，要在红点全部聚齐前杀掉母妖。升降台入口处聚着七八个人，穿明艳衣装的偶像少女正是排演主角醋醋，经纪人叮嘱她注意升降台安全。莫凡看准时机遁影潜行到众人身后。技师阿姨关闭入口、让醋醋进入空中舞台，随后笑容转诡——嘴巴似可无限张开、尖牙沾着褐色血迹，双手如橡胶般伸长、指甲变青生刺，三十来岁的女人脸随皮脱落露出青黑色鳞片，撕毁衣服露出满覆鳞片的身躯，长舌直伸到少女面前。化为原形的鳞皮母妖口吐人言，称孩儿们今天终于可以饱餐一顿、还要感谢这场演唱会，随即仰头啼叫传遍中央场馆。醋醋往下看，人群骚动后退，周围一块块人皮掉落、鳞片怪物接连现身，女生尖叫声成为整个场馆的主旋律。

**关键事件**：1.赵满延留下独战志愿者群，莫凡遁影脱队直扑升降台 2.伪装成技师的鳞皮母妖当面蜕皮现身，挟住偶像醋醋所在的空中舞台 3.母妖啼叫唤醒全体被寄生者，中央场馆开始集体蜕皮

**逐章写法公式**：

- **情绪流向**：起：紧张（断后分兵、遁影潜行） → 承：轻松（经纪人与少女的日常叮嘱） → 转：恐怖（技师蜕皮、母妖现身） → 合：恐怖（啼叫唤醒、全场蜕皮的尖叫开场）
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：分兵突进（主角抵达目标区）+日常假象（明星团队谈笑）+当面变身（终战反派揭面）+啼叫开局（灾难正式开场）
- **本章核心技巧**：用"最日常的角色身份+器官级慢镜头变身"组合制造终极恐怖揭面，全场毁灭则只用一声啼叫和远景皮落启动，留白给下一章。
- **卡点与伏笔**：结尾卡点：灾难开场——集体蜕皮已经开始、屠杀一触即发，莫凡与母妖同处升降台区域，决战未开先悬；埋设/回收伏笔：技师阿姨→母妖以最不被防备的身份潜伏的解释；醋醋→新的人质角色；赵满延独战→战况悬念；"感谢你的演唱会"→母妖蓄谋聚集人群的阴谋闭环。
