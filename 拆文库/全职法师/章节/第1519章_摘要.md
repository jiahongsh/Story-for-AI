# 第1519章 君子房型

**概要**：入开罗城，赵满延坚持住市中心最气派酒店。四人加查德兄弟入住，海蒂被迫与莫凡同住"君子房型"。入夜海蒂淋浴布结界，莫凡误以为其被袭闯入，反偷窥侧影。莫凡冥修时精神宇宙突现巨大蛇瞳，方知小看复仇之瞳。

**逐章写法公式**：

- **情绪流向**：起：入城住店的安全感 → 承：被迫同住的轻松拉扯 → 转：误闯偷窥的香艳搞笑 → 合：冥修蛇瞳的惊悚正视
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：入住市中心（稳） + 被迫同屋（闹） + 误闯偷窥（笑） + 冥修蛇瞳（悚）

- **卡点与伏笔**：结尾卡点：莫凡知小看复仇之瞳，下章众人皆中；埋设/回收伏笔：君子房型→后续同屋互动；穆宁雪未看身子→人物暗线。
