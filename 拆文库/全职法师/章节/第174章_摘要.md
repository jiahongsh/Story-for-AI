# 第174章 青天猎所

**概要**：女助理推荐了私人猎所青天猎所——魔都老字号、名声相当好，却总隔三差五招人、猎法师们也不知道什么原因不爱去。莫凡付了中介费寻到地址，喜出望外地发现猎所离学校不算太远。他过静安寺、穿过民国韵味的老街，在巷尾望见风中咯吱作响的青天猎所招牌，店门口一位扎修长双马尾的小姑娘坐在凳子边晃腿边看书，头也不抬地报出规矩：委托起步价三十万，低于三十万的阿猫阿狗委托不接。小姑娘灵灵得知莫凡是来面试的，反而嫌弃他年纪这么小能不能胜任，屋里的爷爷慢悠悠说年轻好、啥都不怕，就是死了可惜。此时一名行色匆匆的艳丽少妇找上门，灵灵和爷爷一句"有肥羊"的对话听得莫凡汗毛竖立。少妇委托：她生病的丈夫可能是妖、半夜出去行凶，早上洗衣服发现衣服上全是血迹，她以前做护士分得清畜生的血；她本想带孩子回娘家，一提这事丈夫的眼睛就好像会变色，只能急中生智改口留下。爷爷质疑若丈夫真是妖魔全家早被吃干净，灵灵则淡然补刀：这些不足以成为铁证，乐观点想，你丈夫或许不是妖魔，只是普普通通的杀人犯——莫凡听完感觉整个人都不好了。

**关键事件**：1.莫凡寻到青天猎所面试 2.灵灵三十万起步报价 3.少妇上门委托称丈夫是妖 4.灵灵"乐观点想"补刀

**逐章写法公式**：

- **情绪流向**：起：轻松（寻店与萝莉接待） → 承：紧张（肥羊对话的压迫） → 转：恐怖（血衣与变色眼睛） → 合：恐怖（杀人犯式"乐观"补刀）
- **节奏配比**：慢铺垫 50% / 快冲突 15% / 爽点爆发 5% / 悬念留白 30%
- **本章结构公式**：寻所面基（新据点登场） + 萝莉报价（人设立住） + 肥羊进门（委托上门） + 妖夫悬案（恐怖钩子）
- **本章核心技巧**：用童颜萝莉的市侩行话与老店做派制造反差，让猎所舞台未开张先有味道。
- **卡点与伏笔**：结尾卡点：丈夫是妖是人是杀人犯悬而未决，下章期待委托定论与莫凡首单；埋设/回收伏笔：猎所总招不到人的怪象→留给后续揭示；三十万起步价→青天猎所实力层级的锚点；做护士的妻子分得清血迹→证词可信度的细节支撑。
