# 第959章 是非不分

**概要**：三人路过白头市南郊安置镇，蒋少絮感知到当初留给红饰法师的精神印记竟在近处自由移动。赵满延想起香草小寨村民正安置于此，三人前往探查。安置区漆黑无防护、政府军早逃，红饰头目洛凌与鼻环法师正虐杀村民、伪造海妖痕迹威逼寨长。莫凡化雷电砸向鼻环法师，提洛凌砸入沙中，卸其双臂踩面门。小寨少女认出莫凡。然而当村民发现是恩人再来，非但不谢，反而埋怨他们又惹恼红饰会招致报复，蒋少絮怒其懦弱到是非不分。

**关键事件**：1.蒋少絮精神印记引路，发现被释红饰在安置区 2.红饰虐杀村民伪造海妖痕迹 3.莫凡雷电击溃红饰、卸鼻环双臂 4.村民反而埋怨恩人是非不分

**逐章写法公式**：

- **情绪流向**：起：印记引路好奇 → 承：安置区惨状愤怒 → 转：莫凡惩治爽爆 → 合：村民埋怨留人性钩
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 20% / 悬念留白 20%
- **本章结构公式**：印记引路（钩谜） + 惨状揭恶（激愤） + 雷电击匪（爽爆） + 村民埋怨（反转）
- **本章核心技巧**：用"追踪标记→揭官放匪→惩治→被救者颠倒"四段写正义的荒诞，结尾留人性思考
- **卡点与伏笔**：结尾卡点：村民颠倒是非，莫凡是否仍管到底留悬念；埋设/回收伏笔：精神印记→追踪红饰；政府放匪→后续守卫军官伏笔
