# 第638章 在劫难逃

**概要**：穆白迟疑时，王三胖误以为他可能就是黑教廷成员，赵坤三立即反驳，莫凡则追问他是否知道其他嫌疑人。穆白正要说出母亲提供的线索，禁卫首席卢欢带人出现并将方谷及众人带到一处庭院。韩寂在药箱堆中接见他们，直接询问方谷是否还有昆井之水。方谷召出暗红色骷髅，说明最后一份昆井之水已被用来淬炼亡灵，愿意让人尝试从骷髅体内提取。韩寂看出无法取回泉水，判断内城已经在劫难逃。

**关键事件**：1.穆白承认掌握母亲提供的线索 2.卢欢带走方谷等人 3.韩寂询问昆井之水 4.方谷召出暗红骷髅 5.昆井之水无法提取

**逐章写法公式**：

- **情绪流向**：起：猜疑与迟疑 → 承：高层力量介入 → 转：昆井之水带来希望 → 合：泉水无法取出，绝望落地
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：穆白欲揭线索（悬念延续） + 卢欢带队转移（改变场景） + 韩寂询问泉水（给出希望） + 骷髅无法取水（希望破灭）
- **本章核心技巧**：把调查线突然转移到高层避难据点，再用一个可见的亡灵载体承接“最后解法”的成败。
- **卡点与伏笔**：结尾卡点：昆井之水无法从骷髅体内提取，内城似乎无法躲过浩劫；埋设/回收伏笔：暗红色钢铁骷髅 → 作为最后一份昆井之水的承载物。
