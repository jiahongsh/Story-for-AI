# 第857章 穆宁雪挑战

**概要**：学员议论穆宁雪实力不弱陆一林，却仍忧岳棠心下场。白东威认真问她是否要对付赛义德，穆宁雪点头，表明第一次守馆绝不让埃及轻易拿章，现下只想重回国府之队、进威尼斯决战。白东威提醒对方强于国府平均，穆宁雪毫不谦虚说离队这会在队里也不弱他人。牧奴娇提醒灰布铁尸沉重、死刀木乃伊近统领级，穆宁雪踏冰阶上台，赛义德打量这银发东方美人却仍傲慢，问"国馆没像样男人吗"，穆宁雪平静反问"你确定能代表埃及队吗"。开打后灰布铁尸冲出，穆宁雪启冰之领域，寒霜令铁尸速度骤降，再以风轨灵巧闪避铁拳，白东威眼前一亮。

**关键事件**：1.穆宁雪立誓守馆，白东威准战 2.牧奴娇提醒亡灵之强 3.穆宁雪踏冰上台，赛义德仍傲慢 4.冰之领域减速铁尸，风轨闪避

**逐章写法公式**：

- **情绪流向**：起：立誓守馆获准 → 承：提醒亡灵强 + 上台 → 转：赛义德傲慢被反问 → 合：冰领域减速铁尸闪避
- **节奏配比**：慢铺垫 45% / 快冲突 25% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：立誓应战（骨） + 提醒+上台（铺垫） + 傲慢交锋（对峙） + 冰域首秀（爽）
- **本章核心技巧**：用"反派傲慢 vs 主角平静反问"的对话交锋，先声夺人立住女主气场
- **卡点与伏笔**：结尾卡点：穆宁雪轻灵闪避令白东威眼前一亮，下章期待她如何冻结铁尸；埋设/回收伏笔：冰之领域 → 穆宁雪天生天赋的伏笔落实
