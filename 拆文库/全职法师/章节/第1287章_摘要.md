# 第1287章 草海之祸

**概要**：汪大阔在溪边训斥汪华陈姗姗见死不救，后悔自己追山人害死一人、郭木壮也难活，胡朵忽然发现天上飘着蒲公草，汪大阔大喜以为遇到天然蒲公草，带着队伍狂喜跟随白绒前行。另一边，一支年轻的猎人队伍进入嵛草阔谷，塌鼻男边走边跟大飞吹嘘海上遇蓝凌妖的经历，转头却发现自己身后根本不是大飞，而是一张狰狞的巨熊脸，被山人一掌拍中面门后掐昏扛走。猎人队长发现塌鼻男失踪，清点人数时另一个叫石牛的又不见了，队长让人聚拢沉住气，队伍在诡异的气氛中不敢再乱找。草海之上，从高处俯瞰只见无数被拨开的路径如小舟航迹从四面八方出现，不断有猎人队伍被拖入草海。阔谷深处，莫凡放火烧草开路加速前进，明白必须在足够多猎人进入前把山人老巢一锅端，否则会有上千猎人死在这里。

**关键事件**：1.汪大阔队伍见到蒲公草狂喜跟随 2.塌鼻男在队伍中被山人悄无声息拍昏扛走 3.猎人队长清点发现连续两人失踪，队伍陷入恐慌 4.草海俯瞰：无数猎人路径深入，不断有队伍遭殃 5.莫凡烧草开路，决定尽快端掉山人老巢

**逐章写法公式**：

- **情绪流向**：起：汪大阔见蒲公草狂喜的讽刺 → 承：塌鼻男被无声猎杀的惊悚 → 转：队伍连续失踪、草海诡异氛围 → 合：莫凡决定抢先端巢的热血
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 5% / 悬念留白 30%
- **本章结构公式**：汪大阔队被白绒引向死亡（对照组铺垫） + 塌鼻男遇袭失踪（猎杀现场） + 队伍恐慌清点（扩散危机） + 莫凡烧草开路定下抢先计划（行动支线）
- **本章核心技巧**：用多线视角拼出全景——贪婪者被诱、猎人被猎、主角抢时间，三条线共享同一空间，读者知道全貌而角色不知，信息差推满悬念
- **卡点与伏笔**：结尾卡点：上千猎人正涌进草海，莫凡要在他们到达前端掉老巢 → 下章期待与山人老巢决战；埋设/回收伏笔：蒲公草诱饵 → 大屠杀倒计时；汪大阔队伍 → 后续重逢线
