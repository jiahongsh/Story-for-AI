# 第1374章 黑教廷契约

**概要**：神都先知确认彬蔚所指的古老防线正是古长城——当年为抵御强大北疆荒兽修建、如今已被遗忘。叶鸿质疑单靠镇北关古长城挡不住胡夫金字塔的亡灵席卷，彬蔚醒悟道出关键：联合整个北原所有古长城之关，在关键位置连成一座山脉屏障，哪怕是胡夫金字塔的亡灵也休想踏入华夏之土半步。几人眼中重焕光芒，叶鸿拍胸保证豁出性命护北原安危，彬蔚作为传承者义不容辞。先知定策：需要胡夫金字塔出现的具体位置，莫凡继续潜伏获取信息，其余人开启古老防线力抗冥军。莫凡与众人分别，独自踏上与斩空当年相同的道路。赵满延提前离开祠堂不愿看莫凡冒险，莫凡寻不到他只好先走。莫凡返回五十公里外孤山上的黑教廷营地，以一颗人的内脏当"夜宵"吓跑蓝蝙蝠，被教众当变态敬而远之。紫鬼转达乌纳斯之令：任务完成，盛典聚首，但莫凡部下尽死，须作为紫鬼部下并签诅咒契约才能入盛典朝拜冷爵。莫凡假意恼怒拒绝，实则明白紫鬼疑心重、必须确保面见者绝对忠诚，先收拾行囊故作离开之态。

**关键事件**：1.彬蔚悟出联合北原所有古长城连成山脉屏障的防线之策 2.神都先知定策——莫凡潜伏刺探位置，其余人开启古老防线 3.莫凡返回黑教廷营地以内脏吓跑蓝蝙蝠，坐实变态人设 4.紫鬼要求莫凡作其部下签诅咒契约方能入盛典，莫凡假意拒绝

**逐章写法公式**：

- **情绪流向**：起：古老防线的峰回路转 → 承：定策分路的壮行 → 转：黑营伪装的惊悚 → 合：契约门槛的斗智
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：联合防线定策（谋退路）+ 分路壮行（布两线）+ 黑营立威（稳伪装）+ 契约斗智（设门槛）
- **本章核心技巧**：把战略定策与卧底日常两条线交叉剪辑，撤退谋略与潜入险局互为背景，节奏一明一暗
- **卡点与伏笔**：结尾卡点：悬念式——蓝蝙蝠察觉莫凡要走的动静，入盛典之路未通；埋设/回收伏笔：诅咒契约 → 莫凡如何在不暴露下签契入盛典的博弈，斩空同路的呼应 → 刺杀冷爵的牺牲预演
