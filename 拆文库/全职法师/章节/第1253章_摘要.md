# 第1253章 金色焚山之火

**概要**：俞师师请莫凡上山烧掉飞月山上凡火难燃的苔皮杂草，为种蓝金草清地，莫凡推脱拒绝，俞师师一个电话打到穆宁雪那里，他便不情不愿地来了。莫凡以精准的火焰掌控从北面一路焚烧，火光如蛟龙卷过山脊却无烟尘。忽然南面那座栖着青娥的山岭被一片辉煌的金色之火吞没，青娥们翅膀被烧毁、跌落在地被烤成尸干，俞师师当场崩溃。原来纵火者是东海魔法协会研司会请来的火系高手曾广烈，他厌恶飞蛾类生物，用放火烧山这种粗暴手段引蛾女现身，同行的柯令希提醒这是穆宁雪的私有领地、魔法禁令在前，曾广烈却讥讽连世家都不放眼里，背后站着苏鹿先生，烧一座山、灭一个门族都不算什么。俞师师展翅现身，被确认正是他们要抓的蛾女，曾广烈一脚踩在飞蛾尸体上，俞师师望着层层尸骸泪流满面、尖牙暴露，发誓要生吃了这几个人。

**关键事件**：1.俞师师借穆宁雪之口使唤莫凡上山烧草 2.金色之火吞没青娥栖息的山岭，青娥大量烧死 3.曾广烈与柯令希现身，供出苏鹿授意抓蛾女 4.俞师师确认蛾女身份，崩溃痛哭发誓报复

- **情绪流向**：起：斗嘴使唤的轻松 → 承：烧山除草的日常 → 转：金火吞山的惨剧 → 合：主谋现身与崩溃的复仇
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：使唤烧山（日常铺垫）+ 火焰展示（能力秀）+ 金火惨案（灾难爆发）+ 恶人自白（揭示主谋）
- **本章核心技巧**：用一次日常任务的执行过程铺垫环境，在中段用错位方向的灾害打破平静，再借反派台词逐步抖出更大的幕后黑手。
