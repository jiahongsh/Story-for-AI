# 第478章 遍地黄金

**概要**：火劫一出各方人马已往灼原赶来，莫凡等人毫无察觉，此时沙惘河涌起不安气息，心夏的安抚开始失效。众人商量去留，心夏判断现在回去已来不及，莫凡拍板硬着头皮进灼原北角，晨颖保证火劫绝不可能一年内出现两次。心夏坐在疾星狼背上闭眼全力开路，安抚受到暴躁白沙巨人的抵抗。刚抵达河畔，小山般的白骨堆触目惊心，犹豫中的杀铠兽被火劫吞没变成皑皑白骨。灵灵指出火劫后灵种数量变多、找到炎姬希望渺茫，心夏提醒获得几个灵种同样满载而归。赵满延视钱如命催促出发，深入不到两公里莫凡便拾到三颗灵种碎片、估摸值五十万，想到一个灵种价值一千五百万到三千万，队伍麻利埋下元素探测器。

**关键事件**：1.沙惘河安抚失效，莫凡拍板硬闯灼原北角。 2.河畔杀铠兽白骨触目惊心，众人转而盯上遍地资源。 3.莫凡拾得灵种碎片，队伍瞄准价值千万级灵种。

- **情绪流向**：起：各方涌动、沙惘河造反的压迫 → 承：进退两难的焦灼 → 转：白骨与灵种碎片打破恐惧 → 合：瞄准千万灵种的亢奋
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 30% / 悬念留白 20%
- **本章结构公式**：沙惘河造反堵退路（绝境）+ 拍板硬闯灼原（决断）+ 白骨立威转念寻宝（情绪反转）+ 灵种碎片拾取（目标升级）
- **本章核心技巧**：用环境步步紧逼迫使队伍转向，再把恐惧直接兑换成寻宝动力
- **卡点与伏笔**：结尾卡点：期待——元素探测器埋下，寻找千万级灵种与炎姬下落；埋设/回收伏笔：晨颖坚持不能回去且保证火劫不再现 → 她对灼原的异常知情持续存疑
