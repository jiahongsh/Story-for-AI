# 第206章 一次五万

**概要**：眼镜儒男韩洛与奶油斯文男贾文清不肯在艾图图面前弱了气势，释放魔法气息压人，贾文清更是一名中阶火系魔法师。牧奴娇被惊动，从二楼严肃出声喝止，韩洛转而彬彬有礼地自我介绍，反咬莫凡是无赖、做梦亵渎牧奴娇才要教训他。牧奴娇证实莫凡确实住在这里并打发两人回去，两人当场傻眼、变脸借口误会匆匆离开，临走对莫凡投去不加掩饰的阴狠目光。牧奴娇责备艾图图胡闹，莫凡趁机立下约法三章：带陌生男人过夜须另一方同意；任何情况下不许进他的房间——他共有四系要修炼，秘密不想被任何人知道；第三条是叫他当挡箭牌、赶苍蝇可以，但按次收费一次五万，艾图图气得张牙舞爪。牧奴娇提醒韩洛贾文清是心胸狭窄的世家子弟、小心被穿小鞋，莫凡不在意，反而盘算最近猎所没生意手痒，正好拿嚣张的世家子弟松松骨头。艾图图发觉这大魔头不像传闻中面目可憎反而好玩，心里盘算若他以后表现满意，就偷偷告诉他已经有人密谋在主校区考核上组团报复他。

**关键事件**：1.牧奴娇出声喝止并证实合租，两名备胎变脸离场 2.莫凡立约法三章，赶苍蝇开价一次五万 3.艾图图对新室友改观，暗藏组团报复的情报未说出口

**逐章写法公式**：

- **情绪流向**：起：紧张（气息对峙）→ 承：爽（牧奴娇实锤打脸）→ 转：搞笑（约法三章与五万报价）→ 合：紧张（组团报复密谋暗埋）
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：气息施压（起冲突）+ 牧奴娇实锤（打脸解决）+ 约法三章（立同居规则与笑点）+ 密谋揭示（埋考核危机）
- **本章核心技巧**：用一句第三方证实完成打脸闭环，再把新危机藏进章尾配角独白，笑点与暗流一章双收。
- **卡点与伏笔**：结尾卡点：悬念暗埋（主校区考核有人组团报复，莫凡本人不知情）；埋设/回收伏笔：韩洛贾文清离开时的阴狠目光 → 后续指使埋伏报复；赶苍蝇一次五万 → 同居日常笑料资产；艾图图握情报待告 → 考核冲突预告；猎所委托三十万起步 → 莫凡身家线索。
