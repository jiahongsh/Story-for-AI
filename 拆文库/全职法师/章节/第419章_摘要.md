# 第419章 大战火院（中）

**概要**：贾振龙早有防备，莫凡五倍威力的爆裂火滋被一股无形力量挡下，只剩一阵风扬起他的刘海。贾振龙随即踩着暗影系星图放出巨影钉-双子——第二级的巨影钉命中后连精神都会被锁住、干扰星子衔接，寻常元素系法师对稀有暗影系了解极浅，换个人真会中招。但莫凡自己就是暗影系高手，修为虽低一级却对巨影钉了如指掌，他用大范围火光把藏于空气中的钉影映出来，灵巧后跳躲过这中阶控制力最强的技能。贾振龙恼怒之下仗着水帘守护护住星图，施展中阶魔法珊炎-烈拳-地煞，灵级火焰加第二级烈拳轰入地面，整座比赛台滚烫欲燃；莫凡开启血兽靴借血兽蛮力跃起躲过地煞喷发，又借玫炎的火系免疫扛住烤灼。落地后他如蓄力豹子极速弹射，跃过透明水帘守护直跳贾振龙头顶，从十米高灌注血兽之力踩下，将其直接震飞下台、口吐鲜血——他手下留情没踩头顶。莫凡点评这暗影系法师竟不紧靠阴影作战、连遁影都施不出。到头来火院还是没逼出莫凡的中阶魔法，白眉笑称又输了，魏荣想骂"真是废"却因对废物一词敏感生生咽回，心里嘀咕还真治不了这小子了。

**关键事件**：1.贾振龙水帘守护挡火滋+巨影钉双子失效 2.珊炎烈拳地煞轰台 3.莫凡血兽靴十米踩踏震飞贾振龙 4.魏荣咽回骂声

**逐章写法公式**：

- **情绪流向**：起：紧张（火滋被挡+暗影钉偷袭） → 承：爽（识破巧躲） → 转：紧张（地煞轰台） → 合：爽（踩踏定胜负+魏荣吃瘪）
- **节奏配比**：慢铺垫 25% / 快冲突 50% / 爽点爆发 20% / 悬念留白 5%
- **本章结构公式**：先手被挡（敌方有备）+ 暗影偷袭（智斗回合）+ 中阶对轰（火力回合）+ 近身踩踏（暴力收官）
- **本章核心技巧**：一场比试拆成控制、轰炸、近身三种打法轮转，用主角"知识差"与"装备差"双重优势交替解局
- **卡点与伏笔**：结尾卡点：连败余波——贾振龙吐血飞下台、魏荣自问治不了这小子，期待更强对手或魏荣亲自出手；埋设/回收伏笔：莫凡暗影系高手底牌 → 双系之外隐藏第三系；血兽靴强化 → 装备战力线；水帘守护道具 → 防具体系；中阶魔法仍未出 → 底牌悬念持续
