# 第834章 潮退，妖退

**概要**：莫凡侧腰中妖斩后严重脱水，蒋少絮喂水、用药箱处理两处伤口并打能量素针助其康复。另一边南荣倪解毒素生效、毒性渐消而清醒，仍显虚弱。海水开始退去，江昱惊喜告知，先前淹没处露出两三米高，海妖活动区被压缩、战斗走向尾声。南荣倪却面带忧郁，低声说历练结束有人要离队——她是在为救了自己的穆宁雪担心。莫凡人性化的建议她主动退让把名额让出，南荣倪却道自己是唯一治愈法师，导师绝不会同意，强行离开也只会另挑治愈法师而非给穆宁雪；赵满延虽战力下游却被财团保送高阶，离队的只可能是穆宁雪。潮水退尽、海妖随大潮撤离，东海城排水与清扫神速，妖尸作为富含自然精华的"移动矿山"被收归区主统计。南珏管钱，将蒋少絮与南荣倪那份佣金一并归给救了二人的穆宁雪，共一千两百万，穆宁雪不矫情收下——她此刻比谁都缺钱。

**关键事件**：1.莫凡脱水被救、南荣倪解毒清醒 2.潮退战斗尾声、南荣倪忧穆宁雪离队 3.治愈不可替代、赵满延财团保送 4.妖尸收归、南珏发佣金穆宁雪收千万

**逐章写法公式**：

- **情绪流向**：起：伤号获救的稳 → 承：潮退松懈的暖 → 转：离队隐忧的沉 → 合：佣金到手(穆宁雪线)的实
- **节奏配比**：慢铺垫 30% / 快冲突 10% / 爽点爆发 10% / 悬念留白 50%
- **本章结构公式**：伤号救治（稳） + 潮退收尾（松） + 离队焦虑（沉） + 佣金落地（实）
- **本章核心技巧**：用"战后收尾"把外部危机转成内部制度焦虑，落地长线伏笔。
- **卡点与伏笔**：结尾卡点：穆宁雪收千万仍不够买星河之脉，下章期待她如何破资源困局；埋设/回收伏笔：解毒素 → 南荣倪清醒，全章主线收口。
