# 第548章 血族也算亡灵

**概要**：莫凡击败东方烈的消息在明珠学府传成不同版本，但他已决定放弃后续提名赛，前往古都确认张小侯的生死。短信虽传来死讯，莫凡仍坚持生要见人、死要见尸，回想张小侯当年不远千里寻找化身恶魔的自己，决心若对方仍活在亡灵中便杀出血路带回。深夜里，莫凡察觉藏在路灯阴影中的柳茹，请身为血族的她同行，以便应对古都亡灵。柳茹答应后，莫凡得知她已靠武力在本地血族中站稳脚跟。

**关键事件**：1.莫凡决定退出提名赛 2.张小侯死讯驱动莫凡赴古都 3.莫凡邀请柳茹同行 4.柳茹说明自己在血族中的处境变化

- **情绪流向**：起：喧闹余波 → 承：死讯压迫 → 转：寻友决心 → 合：同行人加入
- **节奏配比**：慢铺垫 50% / 快冲突 5% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：胜负余波（交代取舍） + 死讯回顾（建立目标） + 夜路相遇（召集伙伴） + 能力补充（准备出发）
- **本章核心技巧**：把角色的远行理由拆进旧事回忆与具体承诺，使任务动机先于行动落稳。
- **卡点与伏笔**：结尾卡点：莫凡携柳茹进入亡灵之乱区域；埋设/回收伏笔：柳茹的血族身份 → 可用于应对古都亡灵。
