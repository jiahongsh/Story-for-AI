# 第190章 只为头功！

**概要**：莫凡与赵满延把蜕皮恢复的女生们送到消防舱，治愈系女孩对莫凡一人解决这么多妖魔竖起大拇指。灵灵传达高层最新判断：母妖可能已察觉封锁，狗急跳墙会给所有青黄女妖植入自杀暗示、抽走被寄生者的生命；猎王进不去、系主任不敢轻易出手、城市猎妖队还在找不被察觉的入口，拖延只会更糟——猎王、院士和系主任的意思是让莫凡出手灭掉母妖。体育馆外，灵灵向高层汇报自己以学院特别奖励和城市猎妖队年度"破除巨大威胁"奖金说动了莫凡，额头冒着黑线；李院士等人因莫凡新生大赛一人打两百名学生、击败牧奴娇的战绩而宽心。光头队长质疑让青校区学生出面草率，被猎王一句"入口找到了吗？没有。那就闭嘴"压了回去。莫凡按灵灵指引杀向三楼，赵满延同往并事先声明你为钱、我为名，有生命危险自己会转身就走；他自曝赵氏世家背景——世家子弟入学为打出名望、为世家招揽人才，解救此次危机能让影响力不输牧奴娇。赵满延提出灭母妖后头功全归自己的交易，让莫凡开价。

**关键事件**：1.灵灵转达高层决定，莫凡接下猎杀鳞皮妖母的任务 2.猎王驳回城市猎妖队反对意见，强推学生出战的方案 3.赵满延自曝世家动机并开出"名头全归我"的交易条件

**逐章写法公式**：

- **情绪流向**：起：温馨（送伤员、获称赞） → 承：紧张（自杀暗示威胁与受命） → 转：轻松（场外扯皮、动机摊牌） → 合：紧张（交易开价，战前谈判悬置）
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：后方安顿（安全区运转）+受命（终战任务下达）+场内场外双线（权力与动机摊牌）+开价收尾（合作条件悬念）
- **本章核心技巧**：用"任务下达"和"条件谈判"两场纯对话戏蓄力，把决战所需的规则、动机、队内关系全部在开打前摊清。
- **卡点与伏笔**：结尾卡点：悬而未决——莫凡尚未报价，交易能否成交、二人如何分工留待下章；埋设/回收伏笔：自杀暗示→终战倒计时；新生大赛打两百人战绩→主角信用背书回扣；赵氏世家与牧奴娇世家对位→世家名望线；消防舱安全区→后方持续运转。
