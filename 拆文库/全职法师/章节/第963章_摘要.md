# 第963章 肉铠毒身

**概要**：港口激战，红饰公会头目卡索以天之纱结成沙盾隔绝莫凡的雷电，并将石化之力借瞳光扩散，莫凡开启血兽靴躲避。卡索为压制莫凡，将毒系高阶魔法修炼至自身，融合妖魔血脉化作青绿肌肉肉铠，肉身强悍。莫凡的陨拳仅在其身上留下焦痕，卡索瞬息近身以石峰撞击、重锤震击将莫凡击伤吐血。远处自由神殿法师与同伙观望，担心莫凡不敌却不敢贸然出手，怕卡索嗅到气息后施毒遁走。莫凡化身火焰炮弹以飞翼陨拳将卡索轰飞数百米，念控集装箱砸落，卡索未死反而打飞箱体起身。此刻莫凡身上燃起两圈劫炎之火，卡索察觉火息来自他物，战局再生变数。

**关键事件**：1.卡索以沙盾与石化之力压制莫凡，并毒变肉铠 2.莫凡陨拳失效遭重创吐血 3.自由神殿法师暗中观望不欲出手 4.莫凡飞翼陨拳反将卡索轰飞并念控集装箱压制 5.卡索未死起身，莫凡燃起劫炎双火

**逐章写法公式**：

- **情绪流向**：起：卡索压制莫凡的紧张 → 承：毒变肉铠加压 → 转：莫凡飞翼陨拳反打之爽 → 合：卡索未死加劫炎火息的悬念
- **节奏配比**：慢铺垫 30% / 快冲突 45% / 爽点爆发 15% / 悬念留白 10%
- **本章结构公式**：卡索沙盾石化压制（立强敌） + 毒变肉铠展现实力（加压） + 莫凡陨拳失效被重创（挫败） + 飞翼陨拳反打加劫炎伏笔（逆转钩子）
- **本章核心技巧**：用反派身体异变叠加第三方权威判断立起强敌，再用主角爆发一击制造爽点反转
- **卡点与伏笔**：结尾卡点：悬念型，莫凡燃起劫炎双火、卡索察觉火息异常，下章期待小炎姬力量揭晓；埋设/回收伏笔：劫炎/小炎姬火息 → 下章揭示为附体来源
