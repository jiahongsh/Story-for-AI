# 第1024章 嬴了战役

**概要**：黑暗剑主暴露，黑气如千万黑蜈蚣飞向莫凡，莫凡暂避。角斗场是压缩空间，莫凡借空间灵性拉距。黑虫无穷，旋涡下压，莫凡发现剑主消失只留空铠甲，冷笑识其本体即黑虫。莫凡托起劫炎火海上升与黑虫漩涡相撞，火烧黑虫如雨落，以缺口蔓燃越烧越猛。莫凡瞬息至漩涡中心火魔图扩成巨烈环，火云天图烧黑虫魂飞魄散。黑虫钻回铠甲重填黑暗魂，剑主站起失气势。炎姬示时光之液将褪，莫凡点头速决。曜日银红光芒坠，剑主被压成黑气引燃，头盔滚落露空洞眼。黑暗契约消，莫凡立劫炎中。炎姬脱离显疲惫，莫凡慰其将更强。慕丁老泪胜利，旺科斯见白光冲金字塔——灼光之器消虚影，亡灵如鱼失水逃散。芬纳瘫坐泪谢，众人围莫凡。芬纳称上宾，莫凡说做该做之事。

**关键事件**：1.黑虫本体识破火海烧 2.火魔图曜日镇杀剑主 3.灼光之器消海市蜃楼 4.亡灵逃散芬纳谢胜 5.众人围莫凡称功臣

**逐章写法公式**：

- **情绪流向**：起：黑虫压境危 → 承：识本体火海反 → 转：曜日镇杀爽 → 合：虚影消胜利释
- **节奏配比**：慢铺垫 10% / 快冲突 40% / 爽点爆发 35% / 悬念留白 15%
- **本章结构公式**：黑虫压（危） + 识本体反（反转） + 曜日杀（爽） + 虚影消胜（释）
- **本章核心技巧**：用敌真身反转完成翻盘，再以终结技与战争胜利双释放收束
- **卡点与伏笔**：结尾卡点：战役胜利众人围莫凡，下章分赃成长；埋设/回收伏笔：灼光之器→前章明示；时光之液褪→小炎姬限制；黑暗剑主残魄→下章收益
