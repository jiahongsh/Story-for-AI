# 第575章 这什么防御！

**概要**：狞骨魔将因冥离刺反击而盯上莫凡，莫凡本想遁影戏耍它，却怕身后周敏遇袭，只得唤出玄蛇魔铠硬接狂风暴雨般的捶砸。地面被砸得凹陷下去，穿铠的人形嵌在岩层里还闪着光泽，狞骨魔将都有些迷惑。它恼怒地把莫凡从土里抓出来握在巨掌中，摊开手用另一只骨锤手狠狠对砸，结果把自己的骨掌砸出大片裂痕、断成几段掉落。众人下巴都快砸到地上，周敏再喊这是什么防御。莫凡表面生龙活虎，实则被冲击力震得七晕八素、骨头散架。他大喊提点穆白：用冰系把狞骨魔将下肢冻脆，再合力攻击它最细最脆的腿。穆白与领队双冰系持续侵蚀，狞骨魔将每迈一步都废很大力气，莫凡一记霹雳看似与它擦身而过，蒋黎骂他打偏，莫凡回骂闭嘴，话音刚落狞骨魔将下肢关节出现无数裂痕不停蔓延。

**关键事件**：1.莫凡玄蛇魔铠硬接狞骨魔将狂锤不死，魔将自碎骨掌 2.莫凡提点穆白与领队双冰系冻结狞骨魔将下肢 3.莫凡霹雳看似打偏，实为灵雷震荡震裂冻脆骨腿

**逐章写法公式**：

- **情绪流向**：起：危机（硬接狂锤） → 承：震惊（掌碎不死） → 转：破局（冰系提点） → 合：蓄力（裂痕蔓延）
- **节奏配比**：慢铺垫 10% / 快冲突 50% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：硬接狂锤（展示防御） + 自碎骨掌（夸张爽点） + 提点冰系（战术转折） + 霹雳埋伏（蓄力收尾）
- **本章核心技巧**：让主角挨打不还手写防御力，再借打偏的魔法埋悬念，末帧崩断
- **卡点与伏笔**：结尾卡点：下肢裂痕蔓延，下章期待崩断与收尾；埋设/回收伏笔：灵雷空间震荡能力
