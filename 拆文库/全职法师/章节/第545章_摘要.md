# 第545章 死讯

**概要**：比赛开始前，莫凡仍等着手机资料导入，东方烈和周书茗则把他视作顶尖新生与提名竞争者。白宇郎向队员说明东方烈拥有变异火星子的天生天赋，任何火系技能都会高出一个等级，要求大家务必牵制他。小炎姬自行出现并表示要帮莫凡，白宇郎虽觉得幼年期契约兽作用有限，仍接受莫凡先让她在场的安排。赛场外聚集了牧奴娇、赵满延等熟人，裁判即将宣布开始时手机资料导入完成。莫凡点开张小侯的信息，本想看到报喜，却被短短一行内容震得浑身颤抖，比赛被突发噩耗截断。

**关键事件**：1.东方烈表露要迅速击败莫凡的自信。 2.白宇郎揭示东方烈的变异火星子并部署牵制。 3.莫凡查看张小侯信息后受到强烈冲击。

**逐章写法公式**：

- **情绪流向**：起：赛前等待 → 承：战力加压 → 转：小炎姬缓冲 → 合：死讯冲击的悬断
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：敌方挑衅对话（确立目标） + 能力规则说明（明确风险） + 契约兽插曲（战术准备） + 手机信息动作（切换危机）
- **本章核心技巧**：用赛前战术拆解不断抬高比赛风险，再在开战的最后一刻以另一条情感线截断预期。
- **卡点与伏笔**：结尾卡点：噩耗内容，莫凡打开张小侯消息后失去常态；埋设/回收伏笔：上一章未读的张小侯信息 → 在比赛开始前完成内容揭示。
