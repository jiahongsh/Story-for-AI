# 第1320章 压缩爆弹

**概要**：莫凡教炎女姬空间律动，从压缩空间开始，炎女姬学得极快。她随手把一立方米外焰压成拇指大的蜡烛火，压缩解除时火焰反而爆出更凶猛气势，莫凡由此顿悟：将大量火焰压成一团、再解除空间压力，便能爆出数倍威力。他让小炎姬往菱形压缩空间不断灌注火焰，火海被压成火晶烛后，空间崩垮的一刻巨型火冕冲击波将连绵山头夷为平地，两人被轰飞，若非玄蛇铠甲莫凡险些成烂泥。莫凡兴奋得把这招定为未来的杀手锏。凡雪山山庄的穆宁雪、穆临生、俞师师却收到巡逻小队警报，以为西面荒山被大黎世家报复轰炸，俞师师凭青娥信号辨认出那是自己人在练魔法，穆宁雪便把他赶到海上练习，吓得海妖逃窜深海。连续几天练习后莫凡已能自如压缩火焰，只是施法需两个高阶魔法的构架时间。他回到凡雪山时灵灵来电，说姐姐冷青被杀手殿高手盯上、差点死在妖都且未脱离危险期，莫凡赶回魔都青天猎所陪她赴妖都，赵满延提及当年赵有乾曾请杀手殿的人杀自己，对杀手殿极度反感。

**关键事件**：1.莫凡与小炎姬顿悟并练成火焰压缩炸弹，夷平连绵山头 2.凡雪山误以为大黎报复，俞师师凭青娥辨认出是自己人 3.灵灵告知姐姐冷青遭杀手殿袭击，莫凡陪她赴妖都

**逐章写法公式**：

- **情绪流向**：起：新技能顿悟的兴奋实验 → 承：威力引爆、误报警报的惊险搞笑 → 转：海练巩固新招的满足 → 合：冷青遇袭、杀手殿登场的紧张钩子
- **节奏配比**：慢铺垫 15% / 快冲突 35% / 爽点爆发 35% / 悬念留白 15%
- **本章结构公式**：压缩实验引爆山头（爽点） + 凡雪山误报与辨认（调剂） + 海练与施法时限（巩固能力） + 冷青遭袭引出杀手殿（开新主线）
- **本章核心技巧**：用一个新技能的发明过程填满前半章，再用一个外部的求救消息把剧情线干净地切到下一段冒险
- **卡点与伏笔**：结尾卡点：悬念型——冷青仍未脱离危险期、杀手殿还可能再出手，莫凡陪灵灵赴妖都的下一步值得期待；埋设/回收伏笔：火晶烛炸弹 → 莫凡未来战斗的杀手锏；冷青的审判长功绩（崇明岛剿灭黑教廷） → 其被杀手殿盯上的可能缘由；赵有乾请杀手殿杀赵满延 → 杀手殿的旧案与赵家线
