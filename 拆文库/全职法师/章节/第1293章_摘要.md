# 第1293章 树层世界

**概要**：众人顺着天冠紫椴树继续往上爬，主树干分化出五个粗壮到看不见顶端的枝干分支，莫凡随意选了中间青黄色树皮的攀爬，沿途遭遇一条体型如长款汽车般巨大的绿色毛虫，灵灵解释大紫椴树对生物有滋养作用。越往上攀，狂风呼啸，终于见到巨大的树枝如城市道路般四通八达，昏暗枝叶间传来持续的拍打声与尖锐啼叫，无数妖雀骤然群起围攻，赵满延用水光双系魔法结成壁障，附上图腾印记仍被利刃骤雨般的攻击撕出裂痕，蓝洛连连施展风系让众人身法轻盈，灵灵骑着飞川皑狼在前面带路，众人逃到妖雀领空之外。妖雀原本是奴仆级生物在此却格外凶猛，天冠紫椴神树的一千五百到两千五百米高度只是最底层。灵灵判断山人是霸占了草海和树根坡的外来者，树上居民没有改变。众人商议不再往上爬，找了个枝干树洞休息，赵满延布置结界。夜里一头狡猾山人撕破结界爬进来要掳走蓝洛，被莫凡意念撞击打飞摔成肉酱，随后树洞外响起山人啼叫，密密麻麻的红眼在山人中闪烁，莫凡带队冲出，只见更多黑色身影如猿猴般敏捷地在枝叶间狂窜追来。

**关键事件**：1.攀爬五支干，遇巨形毛虫 2.妖雀群起围攻，赵满延水光结界被撕裂，众人逃到妖雀领空外 3.灵灵判断山人是外来者、树上居民未变 4.树洞休息，山人偷袭掳蓝洛被莫凡击杀 5.山人大军包围树洞，莫凡带队突围

**逐章写法公式**：

- **情绪流向**：起：攀爬巨树的惊奇 → 承：妖雀围攻的紧张 → 转：逃出领空、推断云顶威胁的压抑 → 合：山人夜袭树洞与包围的恐惧
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：攀树遇巨型毛虫开眼界（铺垫） + 妖雀群攻逃生（冲突） + 灵灵推断云顶巢穴（悬念） + 山人夜袭树洞突围（钩子）
- **本章核心技巧**：把「上树」写成一层比一层危险的生态闯关，每一层生物强度递增，敌人从山人切换到妖雀再切回山人，用环境地图的层级感天然制造不断升级的威胁
- **卡点与伏笔**：结尾卡点：山人如猿猴般敏捷狂窜穷追不舍 → 下章期待树上大逃亡；埋设/回收伏笔：云顶树冠天空巢穴 → 神树最终秘密；妖雀领域 → 后文借道伏笔
