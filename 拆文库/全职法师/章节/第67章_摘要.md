# 第67章 进阶魔狼

**概要**：周敏得知猎妖队赶到如获重生，莫凡趁魔狼被冻住赶紧撤离。郭彩棠用蓝牙耳机通知队员：这是一只处在进阶期的独眼魔狼，与之前那几只巨眼猩鼠一样偷吸了地圣泉的能量，得到巨大好处的它战斗力远超平常妖魔，没有雷系很难控制。站在她身旁的高瘦阴沉男子正是穆卓云的养子宇昂，他称其父悬赏这只胆大包天的畜生已久，今日愿随猎妖队灭了它。宇昂得知方才逃跑的小混蛋就是莫凡，又见其带女同学逃走如吓破胆的老狗，轻蔑认定其斩杀幽狼兽纯属狗运传言。莫凡借口手机落在现场，抽连帽卫衣、蜡笔涂黑脸再戴上口罩，以雷法师梵墨的身份杀回。猎妖队全员到场，郭彩棠与宇昂两道冰蔓叠加冻住魔狼方圆十米，可冰系与火系冲突，徐大荒的火滋·爆裂会轰碎己方冰蔓，众人只能控制无法灭杀；徐大荒已请魔法协会的中阶水系法师杨作河增援，令莫凡一旁待命备用雷印麻痹——话音未落，他神色一变：魔狼的气息突然变强了。

**关键事件**：1.郭彩棠披露魔狼处于进阶期、曾偷吸地圣泉 2.宇昂误判莫凡胆怯、轻蔑鄙视 3.双冰蔓只能控制无法灭杀，等杨作河增援之际魔狼气息暴涨

**逐章写法公式**：

- **情绪流向**：起：狼被冻住的短暂安稳 → 承：宇昂轻蔑的暗流 → 转：变装归队的轻快 → 合：气息暴涨的骤然吊心
- **节奏配比**：慢铺垫 45% / 快冲突 15% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：情报广播（揭进阶期）+ 反派误判（埋轻蔑）+ 变装归队（保双身份）+ 战术困局（蓄大爆发）
- **本章核心技巧**：用一堂现场战术课交代敌我配置与相克关系，把灭杀可能性锁死后再抛气息异动，全章为下一章的爆发蓄力
- **卡点与伏笔**：结尾卡点：异变前兆型——被冻住的魔狼气息莫名变强，进阶在即；埋设/回收伏笔：地圣泉被妖魔偷吸 → 回收前章猩鼠异动、埋博城异变主线；宇昂轻蔑莫凡 → 成年礼决斗前的认知差再加固；杨作河增援在途 → 中阶法师登场的预告；莫凡雷系双身份 → 与周敏、宇昂间的信息差继续滚大
