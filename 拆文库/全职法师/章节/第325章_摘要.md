# 第325章 给我下地狱

**概要**：陆年在石化战场上察觉身后传来充满黑暗气息的冰冷，因斩空脸上挂着奇怪的笑容而转头，看到一张布满黑暗血纹的脸凑到面前——恶魔化的莫凡当面兑现"送你下地狱"的誓言。陆年实验过无数活人，从未见过恶魔化后还能保持人形、口吐人言、留存记忆的试验品，眼前莫凡却三者俱全。恶魔莫凡抓住陆年后脑将其脸砸进坚硬如岩的石化地面，又用燃烧烈焰的右拳轰碎他的牙齿与鼻梁，陆年靠金色铠魔具护体，放出连统领级生物都能石化的石化之力反扑，灰白之力一度将莫凡双腿扎根，莫凡一拳砸地引燃火柱与石化之力对轰。陆年复盘：莫凡是在自己施加精神控制前自行恶魔化，成功得前所未有，若能从副作用中活下来，将成为把至高法师、统领、君主踩在脚下的震惊世界的恶魔。面对陆年"你应该感谢我给你力量"的喊话，莫凡以"当然该感谢你，所以现在就送你下地狱"回应。

**关键事件**：1.恶魔莫凡现身，兑现复仇宣言 2.莫凡摁头砸脸、烈焰拳毁容压制陆年 3.石化之力反扑被火柱顶住 4.陆年复盘出莫凡是保持理智的完美试验品

**逐章写法公式**：

- **情绪流向**：起：紧张（背后黑暗气息逼近）→ 承：爽（摁头砸脸、烈焰拳毁容）→ 转：紧张（石化之力扎根双腿）→ 合：热血（火柱顶破石化，宣判下地狱）
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：察觉异常回头（蓄势）+ 恶魔现身兑现宣言（复仇开场）+ 摁砸与烈焰拳（暴力压制）+ 石化反扑与火柱对轰（攻防拉扯）+ 陆年复盘试验异常（抬升格局）+ 下地狱宣判（章末钩子）
- **本章核心技巧**：用反派专业视角（活人实验专家）的反应层放大主角异常度，让"变强"不靠数值而靠行家的震惊传递。
- **卡点与伏笔**：结尾卡点：宣判式卡点——"现在就送你下地狱"，下章期待陆年之死；埋设伏笔：陆年"若能从副作用中活下来将变成震惊世界的恶魔"→ 恶魔系副作用代价与莫凡潜力的长线伏笔。
