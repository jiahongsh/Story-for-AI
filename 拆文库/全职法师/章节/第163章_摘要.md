# 第163章 粗暴，霹雳！

**概要**：计数逼近150，周正华不安地问萧院长是否真到200就要把全系资源给莫凡，又惊讶幽狼兽支撑到现在仍不见疲倦、气势上像还能再打一百个。看台上，一名俊俏男生催兄长出手，白藏锋起身——贵气男子称他是他们中最早把控星图的人，把风头让给他；沈山河反驳早入中阶不代表日后强弱。白藏锋放话要让明珠学府搞清楚魔都由白家说了算，拒绝与他人组队，断言一人足以对付体力快耗尽的幽狼兽和半吊子中阶法师。光系系主任微笑看着侄子，周正华说白家都动手了风波该收场。白藏锋独入铁笼，以中阶对初阶的优越感对莫凡说教，讲到世家子弟时骤然爆粗色变——莫凡已用幽狼兽身躯挡住他视线，暗暗把控出紫色星图。莫凡骂一句"就你他妈话多"，手指蓝天，白藏锋头顶雷云乍现，粗壮紫色霹雳轰然劈下、地面龟裂，负责保护的顾翰老师都没把握光系守护能否及时挡住。

**关键事件**：1.白藏锋代表魔都世家子弟压轴式入场 2.莫凡借幽狼兽挡视线偷画星图 3.中阶雷系魔法霹雳当头劈下

**逐章写法公式**：

- **情绪流向**：起：紧张（计数逼近与院方不安） → 承：其他（世家群像垫分量） → 转：爽（偷画星图与霹雳当头） → 合：紧张（老师都失措的一击悬而未落）
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：院方不安（抬赌注） + 世家群像（立对手层级） + 说教与偷画（信息差布局） + 霹雳落下（章末大爆点）
- **本章核心技巧**：把主角的先手藏在反派的说教时间里，用挡视线画星图把偷袭写成算计，攻击威力则借保护老师的失措来标定。
- **卡点与伏笔**：结尾卡点：动作悬置+霹雳劈落而救援未定，下章期待白藏锋的生死与判决；埋设/回收伏笔：白家神豪身份→白家后续线；环戒男子、沈山河等魔都世家同辈→同辈强者群像的长期铺垫。
