# 第310章 巨蜥伪龙

**概要**：莫凡进入金林市两公里长的废弃主街，越过一堵高度堪比楼房的凝固泥墙，赫然看见一座完全由凝固泥土堆砌、比市区最高摩天大楼还高一百多米的蜂窝峰穴孤耸在最繁华地段，窟窿密布、泥中混着陷入的汽车、路灯、广告牌与骸骨。他冷静判断进攻金林市的大族群已撤回洞庭湖、峰穴多半只是空壳，却在最顶端看见了那只一口咬死伪怖魔的统领生物——拥有恶龙亚种血统、实力恐胜过翼苍狼的巨蜥伪龙正在酣睡，呼噜如闷雷。追兵蒋艺等翻过泥墙逼近冷笑"看你往哪里跑"，莫凡佯装束手就擒，突然以烈拳轰击峰穴底座：虽只让底座窟窿颤动，却惊得底座区域所有蜥颅巨妖从密密麻麻的窟窿中探出无数脑袋，齐刷刷锁定这片地带的不速之客。

**关键事件**：1.发现蜂窝峰穴空壳与沉睡的巨蜥伪龙 2.蒋艺率队翻墙合围 3.莫凡一拳打草惊蛇、引全巢妖蜥出洞

**逐章写法公式**：

- **情绪流向**：起：压抑（废弃主街残景） → 承：恐怖（峰穴奇观与伪龙现身） → 转：紧张（追兵合围冷笑） → 合：爽（一拳惊巢、群妖锁敌）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 20% / 悬念留白 20%
- **本章结构公式**：地形深入（主街泥墙）+ 奇观揭示（峰穴与伪龙）+ 敌方合围（假投降铺垫）+ 引妖开战（混局开启）
- **本章核心技巧**：把"最强怪物的存在"与"主角的脱身战术"设计成同一件事——伪龙的威慑力直接成为莫凡手里的牌，恐怖与爽点互为杠杆
- **卡点与伏笔**：结尾卡点：无数蜥颅巨妖出洞锁定双方、混战一触即发，下章期待人妖大乱斗；埋设/回收伏笔：巨蜥伪龙咬死伪怖魔的旧事→当前最高战力天花板；空壳峰穴→大族群随时可能回巢的隐患；蒋艺"根本不放在眼里"的轻敌→军官们即将付出的代价
