# 第345章 多一个天敌

**概要**：光落漫丈·圣言的箭雨落下，黑暗属性的沼毒千蚣对光系最为无力，光箭所落壳甲被刺穿融化、如热铁烙蜡般溃烂，痛得它地动山摇地翻滚。莫凡趁乱撤离——一个统领残魄已经够本。千蚣尾巴拍地放出裂缝偷袭离曼，又甩起岩石碎片砸向两人，趁乱窜入泥湖深水区逃走。张小侯喊别让它跑了，离曼淡淡回"你去追"；莫凡按住众人：统领必有过人逃生本领与反杀手段，能灭武壳巨蜥已是奇迹，再贪心可能全死在这。离曼借机科普杀统领之难：能单挑统领的高阶已属极强但多半杀不死，统领会设圈套、身边还有杀不完的奴仆战将炮灰；这次能成功全靠两只统领重伤加深仇。张小侯由此更钦佩敢单挑翼苍狼的斩空。莫凡点破军方也不希望千蚣死，离曼确认：千蚣与蜥族水火不容，康复后实力大增，可牵制整整一个蜥颅巨妖族群。

**关键事件**：1.圣言光箭重创沼毒千蚣，千蚣逃入深泥湖 2.三人放弃追杀，离曼科普杀统领之难 3.确认留千蚣活口当蜥族天敌的军方立场

**逐章写法公式**：

- **情绪流向**：起：箭雨处刑的爽快 → 承：千蚣反扑逃窜的紧张 → 转：见好就收的冷静 → 合：天敌牵制的轻收
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：处刑（圣言箭雨）+ 逃亡（尾拍甩石遁湖）+ 冷静（放弃追杀）+ 复盘（杀统领三难与天敌论）
- **本章核心技巧**：战斗刚收就转入战力学复盘，用配角科普把本次胜利的特殊性讲透，战绩不贬值
- **卡点与伏笔**：结尾卡点：轻收式结尾，以一个月内西照谷见不到蜥蜴的展望收束本谷篇章；埋设伏笔：千蚣康复后实力大增 → 蜥族克星长期存在；张小侯对斩空单挑翼苍狼的钦佩 → 军方高阶战力标尺
