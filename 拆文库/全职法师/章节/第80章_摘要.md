# 第80章 三级冰蔓！

**概要**：莫凡手掌轻挑，把火滋滑落脚下在四周铺成燃烧的火焰地毯，冰霜遇火融化，他不必挪动也不怕被冻；唐月当众点评这招以火护体破冰的巧思，朱校长认可一级火滋破了二级冰蔓。莫凡随即反击释放火滋·焚骨，郭彩棠担忧宇昂被动，穆贺不以为然，穆卓云带着惯有的笑容仿佛一切在掌握；宇昂皮靴发出黄色暗光，靠履魔具印着的地波技能平行挪出四五米躲开焚骨，莫凡看出这印技能的魔具每用一次需魔石充能，又听宇昂放话这场两年的闹剧该结束了、要留他一命看他当众给义父磕头。随后宇昂施展三级冰蔓·覆盖，暴风雪席卷整个决斗场，温度降到连火焰都无法持续燃烧，莫凡的守护火焰被尽数熄灭；肥石惊叫上次见宇昂只掌握凝结、一年不见竟到覆盖境界，宾客纷纷恭贺穆卓云，斩空判定镰骨盾对冰蔓起不到作用，莫凡的魔具在这场决斗中基本无用。

**关键事件**：1.莫凡以火滋灼烧自护破掉冰蔓·凝结 2.宇昂靠履魔具地波躲过焚骨并扬言要莫凡当众磕头 3.宇昂三级冰蔓·覆盖熄灭全部火焰压制莫凡

**逐章写法公式**：

- **情绪流向**：起：爽（巧破冰蔓）→ 承：压抑（瞬移躲招加磕头羞辱）→ 转：压抑（三级冰蔓冰灾压制）→ 合：压抑（魔具无用论断）
- **节奏配比**：慢铺垫 25% / 快冲突 50% / 爽点爆发 15% / 悬念留白 10%
- **本章结构公式**：火滋护体破冻结（小爽）+ 焚骨被瞬移闪避（挫）+ 磕头宣言加码羞辱（蓄怒）+ 三级冰蔓覆盖全场（大压）
- **本章核心技巧**：先给主角一个小高光，再用装备与等级双重压制收走，一升一降把绝望推满，给下一章蓄爆。
- **卡点与伏笔**：结尾卡点：绝境压制型——火焰尽熄、魔具无用，等莫凡破局；埋设/回收伏笔：履魔具需魔石充能的弱点 → 限制瞬移次数；磕头赌注当众挑明 → 为莫家兴代跪蓄痛；宇昂一年从二级到三级 → 暗示穆氏堆资源藏底牌。
