# 第208章 给莫凡当保镖

**概要**：古都陵墓、亡灵之地的概念让莫凡内心卷起千层浪：古都即西安，六朝古都皇陵多如山头，因这个世界存在亡灵生物，陵墓成了妖魔的地下乐园。心夏解释陵墓入口早被猎人发现，亡灵比妖魔凶残十倍百倍，考古法师无功而返，政府已将其列为禁区；她的历史老师一直向校方和政府申请考古法师队伍，博城灾难没查出结果，项目可能成功，届时会挑几名学生随一队实力强劲的法师进入那位古老君王的陵墓。莫凡打电话给住在附近的唐月未接通，便带心夏回上海。场景切到杭州灵隐寺审判会：十名佩圣剑图案的男子汇报各地异动——敦煌沙虎暴走已解决、张槚已缉拿、嘉峪关需增派、千岛湖蛇族泛滥失踪二十人以上、三潭印月结界松动。审判长命唐月看护三潭印月结界，并嘱咐她稳住结界后多留意当初保护地圣泉的孩子，透露主谋撒朗对地圣泉仍不死心，派出的多是爪牙；另派卢俊河赴日查袭击渔村之物，命离姜收网当场击毙那名高阶法师。唐月离开灵隐寺开机，发现莫凡的未接来电，回电斗嘴并约好到上海请他吃麻辣小龙虾。她决定不把危险告诉莫凡，打算暗中处理黑教廷爪牙，心里嘀咕自己竟被派去给这小混蛋当保镖。

**关键事件**：1.心夏补充亡灵之地与考古队申请的情报 2.灵隐寺审判会分工，唐月受命看护三潭印月结界并暗中保护莫凡 3.唐月回电莫凡隐瞒危险，自嘲被派去当保镖

**逐章写法公式**：

- **情绪流向**：起：紧张（亡灵之地后怕）→ 承：紧张（审判会连报异动）→ 转：轻松（唐莫电话斗嘴）→ 合：温馨（隐瞒危险暗中守护）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：亡灵设定消化（接上章）+ 审判会简报（铺全局危机）+ 唐月领命（把危机接到主角头上）+ 瞒护斗嘴（收温情留暗涌）
- **本章核心技巧**：多线危机用一场会议一次性铺开，再用一通电话把最重的一条线悄悄挂到主角身边，全局与个体双视角切换。
- **卡点与伏笔**：结尾卡点：暗涌留白（唐月将赴上海暗中当保镖，黑教廷爪牙将至）；埋设/回收伏笔：三潭印月结界松动 → 呼应上章白蛇封印传说，蛇族线埋下；撒朗对地圣泉死心不改 → 幕后黑手主线；卢俊河赴日查渔村袭击 → 世界异动线；唐月托找对蛇族有吸引力的玉石 → 数章后回收；考古队申请挑学生 → 古都陵墓篇引子。
