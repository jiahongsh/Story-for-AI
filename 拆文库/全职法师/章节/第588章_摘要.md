# 第588章 封喉角鬼

**概要**：余青素惊魂未定，矮男道出偷袭者身份——封喉角鬼，鬼将中最危险的品种，能驾驭影子神出鬼没地割人喉咙，专挑精英法师下手。莫凡随即想通：裹布尸将故意摆造型吸引火力，正是为让封喉角鬼暗杀威胁最大的余青素。莫凡分配任务：矮男、疤男、青辣椒围猎封喉角鬼，裹布尸将交给自己与小炎姬。矮男讲起当年一支十人精锐猎人队被封喉角鬼逐个割喉团灭的往事，只因队中没有光系法师。矮男抛起光耀照亮整个墓室、净化死气，却不见鬼影，他断言其躲在柱子后，余青素以雷电甩向柱后勾出鬼型轮廓，封喉角鬼现形拔腿就跑。矮男持续光耀锁死它的遁影，与疤脸、余青素追猎而去。

**关键事件**：1.矮男揭穿封喉角鬼身份与偷袭计谋，莫凡分配围猎任务 2.矮男以光耀照亮墓室，余青素雷电勾出柱后鬼影 3.封喉角鬼现形逃窜，矮男持续光耀锁死遁影、三人追猎

**逐章写法公式**：

- **情绪流向**：起：后怕（割喉余悸） → 承：忌惮（鬼将科普） → 转：破解（光耀显形） → 合：追猎（围杀开战）
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 15% / 悬念留白 15%
- **本章结构公式**：事后科普（立威胁） + 计谋复盘（明因果） + 旧案恐吓（加分量） + 光耀破影（放克制） + 追猎收尾（转战局）
- **本章核心技巧**：让有克制手段的角色在敌方最阴险的战场发光，把设定知识转化为战斗价值
- **卡点与伏笔**：结尾卡点：战局悬念——封喉角鬼能否被围杀、墓室深处还有何物；埋设/回收伏笔：矮男光系主修的价值 → 本战兑现、为古都后续战局蓄势
