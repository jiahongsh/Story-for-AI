# 第727章 何苦为难自己

**概要**：莫凡一脚踩住海猴怪正要下杀手，数百海猴怪齐扑过来，二人转方向奔向汇合处，发现穆宁雪的冻结已笼罩全岛。赵满延追问莫凡的空间系，莫凡承认高阶觉醒空间系并求保密。赵满延引海水卷成二十米暴浪，却发现赤凌妖控水将浪逆流卷回，高达三十余米拍向二人，莫凡念控尚弱无法击散巨浪，二人狼狈逃命。

**逐章写法公式**：

- **情绪流向**：起：踩猴的轻松 → 承：认空间的得意 → 转：暴浪被逆流的危机 → 合：念控无力狼狈逃的压抑
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：莫凡踩猴认系（亮牌） + 赵满延暴浪（高光） + 赤凌妖逆流（反转） + 念控无力逃（落点）
- **本章核心技巧**：先让配角高光再被克制，用落差把危机感和能力天花板一起立住
- **卡点与伏笔**：结尾卡点：赵满延尖叫浪尖在头上；埋设/回收伏笔：念控弱→后续冻结后练抓妖
