# 第611章 大祸鬼

**概要**：莫凡、周敏、穆白和矮男穿过多个街区，发现山峰之尸投放的亡灵让城市道路变成逃命赛跑。四人接近博城街时，立交桥上的大祸鬼举起汽车砸向道路，一名女人仍困在车内。莫凡借汽车下坠形成的阴影遁入车中，又在车辆落地前带着女人脱离，随后与同伴登上立交桥。周敏认出大祸鬼是能藏入夜幕、用暗钩刺穿头颅的鬼将，并说明它能使用暗影系能力，巨影钉对其无效，必须先用冰锁限制行动。

**关键事件**：1.四人在亡灵城市中向博城街推进 2.莫凡利用连续遁影救出坠车女人 3.众人确认大祸鬼的能力与猎杀方案

**逐章写法公式**：

- **情绪流向**：起：亡灵街区中的压迫 → 承：桥上汽车和女人坠落的危机 → 转：莫凡极限遁影救人 → 合：大祸鬼弱点揭示并等待围杀
- **节奏配比**：慢铺垫 25% / 快冲突 45% / 爽点爆发 15% / 悬念留白 15%
- **本章结构公式**：穿城绕行（保持撤离目标） + 恶鬼砸车（制造即时危机） + 连续遁影（完成救援） + 识别弱点（承接战斗）
- **本章核心技巧**：用一个极短倒计时的救人动作展示主角能力，再让专业配角补出敌方规则，形成能力展示和战术铺垫的连续段落。
- **卡点与伏笔**：结尾卡点：大祸鬼具有暗影系能力，巨影钉无效，必须依靠冰锁限制后再击杀；埋设/回收伏笔：莫凡掌握一念星轨 → 本章连续使用遁影完成高难度救援。
