# 第210章 遭遇埋伏

**概要**：包老头打算叫大生来接这单保护，莫凡见钱眼开，提出自己就是猎人、自己保护自己，只要不出事这钱就归自己，被包老头一本正经地以「你要是死了猎所就有失名誉」驳回。灵灵提醒有人出这么大金额保护他，说明他可能有生命危险；莫凡不当回事，转而猜测能花大钱保护自己的多半是博城那边的人，甚至猜是斩空察觉黑教廷动向委托的。包老头安排大生与灵灵一起照看莫凡。莫凡心事重重地离开猎所，回想白阳、潜伏穆氏十年的宇昂这类无孔不入的暗子，只能走一步看一步。夜里返校他抄近路穿人工湖公园，暗影系中阶的敏锐让他隔着假山察觉人影闪动，有人低令速战速决。三级火滋从假山高处砸落炸开，莫凡跺脚唤起玫炎护体，火焰之衣让扑来的火舌四散窜逃；风系法师又在湖边酿出直径近两米的风盘龙卷，倒吸湖水成水龙席卷而来。莫凡激活血兽靴，算准龙卷轨迹连跳上路灯与树干，龙卷撞进林子。他判断风系中阶法师威胁最大，雷电之力化紫蟒雷印将其麻痹定住，顶着两团爆裂火滋的拦截冲向假山，喝出血兽铁蹄。

**关键事件**：1.莫凡想自接保护自己的单被驳回，包老头派大生灵灵照看 2.夜里穿人工湖公园遭三人埋伏 3.莫凡以玫炎压火、血兽靴躲龙卷、雷印定住风系法师，冲向假山使出血兽铁蹄

**逐章写法公式**：

- **情绪流向**：起：轻松（自接单的算盘）→ 承：紧张（心事重重与夜路）→ 转：爽（玫炎压火、雷印定人）→ 合：紧张（血兽铁蹄蓄势卡点）
- **节奏配比**：慢铺垫 30% / 快冲突 45% / 爽点爆发 20% / 悬念留白 5%
- **本章结构公式**：猎所定单（喜剧+危机确认）+ 夜路心事（蓄压）+ 假山遇袭（冲突爆发）+ 三段反制（爽点递进卡点）
- **本章核心技巧**：先让主角误判危机来源（当喜剧处理），再用实战逐步揭穿误判，一场戏同时完成打斗与认知反转。
- **卡点与伏笔**：结尾卡点：动作悬置（血兽铁蹄踢向假山，招式名即章尾句）；埋设/回收伏笔：大生未到、保护缺位 → 埋伏恰在空档发生；莫凡猜测斩空/博城委托 → 委托人身份悬念；暗影系中阶的感知 → 双系修炼成果展示；风盘龙卷无法变向 → 战斗设定细节可复用。
