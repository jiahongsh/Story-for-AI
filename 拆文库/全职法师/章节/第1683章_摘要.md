# 第1683章 吉祥物

**概要**：陆灼用水珠麻醉之毒配合暗影骚扰，拖垮了已经身中催眠之毒的飞川皑狼，飞川皑狼索性叼起顾盈逃走，冻结湖水成冰道狂奔，又踩着水面上漂浮的蝾魔螺壳当跳板渡湖，把陆灼甩开。顾盈中毒昏沉，飞川皑狼驮她落上一座石湖岛，此时一名风系高阶法师蒋华从空中落下，自称受七星大师所托前来查看契约兽的求救信号。陆灼追上后当场捏造顾盈暗害队友独吞好处的罪名，蒋华不加核实便与他同谋要就地处置顾盈，顾盈认出蒋华是陆灼同伙，心如死灰。陆灼注意到蒋华身后跟着一团火焰小女灵，两人笑称它是喜庆吉祥物——那正是七星大师的契约兽小炎姬，它听得懂人类的嘲笑，此刻正在生气。

**关键事件**：1.飞川皑狼驮顾盈逃离陆灼，踩蝾魔壳跳板渡湖 2.赶来的蒋华与陆灼捏造罪名，决定就地处置顾盈 3.被嘲笑为吉祥物的小炎姬暗中发怒

- **情绪流向**：起：濒死逃命 → 承：陆灼紧追威胁 → 转：援军现身反成死局 → 合：萌物发怒的钩子
- **节奏配比**：慢铺垫 40% / 快冲突 40% / 爽点爆发 0% / 悬念留白 20%
- **本章结构公式**：下毒拖垮（制造危机） + 断尾求生（逃命动作） + 援军反成同伙（反转加压） + 萌物发怒（章尾钩子）
