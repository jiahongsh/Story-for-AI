# 第276章 激战魔奴

**概要**：队中三名火系莫凡、宋霞、赵明月以焚骨烧尽两侧黑藤，焦粉落尽后两侧竟还各藏着一个洞穴。陆正河怒令中段队员灭掉两侧魔奴，莫凡意外此人臭屁归臭屁、指挥起来一点不含糊。帝都学员小峰遭两只魔奴夹击，盾魔具明镜之盾挡下胸前一棒，右小腿却被生生砸碎、左腿再挨一棒，膝盖以下血肉全烂在裤管里。穆宁雪的冰蔓最先出现，不到两秒冻住两只魔奴后肢再爬满全身，追杀生生止住——彭亮震惊这速度绝对比拥有灵级冰种的法师更强。彭亮以遁影将小峰抢回，白婷婷的浅绿治愈光液浇透碎腿为其镇痛，小峰忍痛让她先救别人。前方郑冰晓的岩魔人被敲碎半具身体收回，赵满延释放中阶暴浪如堤坝开闸灌入隧道，把最前面整批魔奴卷入；宋霞趁七八只湿淋淋的魔奴刚爬起，赤色火拳将它们彻底化为黑色粉末。

**关键事件**：1.三火系焚藤又暴露两个侧洞，陆正河怒令清除侧翼 2.小峰双腿被骨棒砸碎，穆宁雪冰蔓不到两秒冻住凶手，白婷婷治愈镇痛 3.赵满延暴浪灌洞、宋霞火拳将湿魔奴尽数焚灭

**逐章写法公式**：

- **情绪流向**：起：紧张（侧洞偷袭）→ 承：恐怖（小峰碎腿）→ 转：爽（冰蔓瞬冻+中阶连招）→ 合：爽（暴浪火拳清场）
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 35% / 悬念留白 5%
- **本章结构公式**：清理侧翼（排近患）+ 伤亡立痛（抬高生死）+ 三段救援（亮配置）+ 双中阶连招（收一城）
- **本章核心技巧**：先让一名配角付出惨痛代价坐实威胁，再让每位主力依次亮绝活，群像战各表一枝
- **卡点与伏笔**：结尾卡点：前方魔奴群只被暂阻、巢穴深处未知→期待后续突围；埋设伏笔：小峰伤情未愈、穆宁雪冰种超越灵级的谜
