# 第989章 坑爹的任务！

**概要**：灵灵要求众人保护那只水母歹蛆平安长大，莫凡与穆宁雪、鲍比听后皆瞠目，直呼这差事荒唐。灵灵解释这是手头唯一活体标本，只有长成完全体才可能提取疫苗组织，抓到如此可控的活体极难，而溺咒发生率正越来越大。鲍比问成长速度，灵灵说入海后成长极快，不出半个月即可变完全体，要莫凡、穆宁雪向国府请假半月。莫凡衡量半月国府资源不过一个灵种，不如赌这三亿五千万悬赏，便打电话给赵满延说明离队。赵满延误以为莫凡被裴历打伤脑子出问题，调侃二人私会。歹蛆游出安界海域后，灵灵平板报警显示它遇险，灵灵将莫凡推入水中去解决天敌，莫凡以空间系制造空气区呼吸，穆宁雪随之下水跟随，众人乘快船在五百米内紧追。

**关键事件**：1.灵灵定下护蛆长大任务，三人难以接受 2.莫凡向国府请假离队半月赌悬赏 3.歹蛆遇险，莫凡穆宁雪入水应对

**逐章写法公式**：

- **情绪流向**：起：任务公布的错愕 → 承：价值与难度铺垫 → 转：离队决定的落地 → 合：遇险入水的行动钩子
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 0% / 悬念留白 55%
- **本章结构公式**：公布护蛆任务（制造错愕） + 解释价值速度（建立目标） + 莫凡离队请假（扫清障碍） + 歹蛆遇险入水（行动钩子）
- **本章核心技巧**：用群像错愕反应放大荒诞任务，再用具体悬赏数字把目标坐实
- **卡点与伏笔**：结尾卡点：类型行动+水下如何对付天敌引下章；埋设/回收伏笔：国府离队→影响后续资源与魂种资金
