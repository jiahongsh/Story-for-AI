# 第695章 斩杀山峰之尸！

**概要**：钟楼之战后莫凡化作虹光飞回外城山峰之尸战场，会长韩寂在众人掩护下完成第三级超阶冰系魔法雪姬之泣-哀世冰雨，冰雨覆盖并冻结了山峰之尸。韩寂传声让莫凡摧毁其咽喉之下的亡灵结晶，莫凡借烈焰魂影与雷霆化作毁灭虹光贯穿山峰之尸咽喉，重创其要害。山峰之尸塞入尸臣止血后向北逃窜，莫凡与祝蒙、神秘会白人、独萧、韩寂五位强者合力追击并同时出手，眼看即将斩杀，山峰之尸身后却浮现混沌之穴将众人所有攻击尽数吸收，莫凡锐眼锁定其头顶站着一个人。

**关键事件**：1.莫凡飞回外城战场，韩寂完成哀世冰雨冻结山峰之尸 2.莫凡贯穿山峰之尸咽喉之下重创要害 3.山峰之尸塞尸臣止血北逃，五强追击合力攻击 4.混沌之穴吸收全部攻击，莫凡发现尸顶有人

**逐章写法公式**：

- **情绪流向**：起：莫凡卷火重来的震撼 → 承：冰封压制与要害点明的紧张 → 转：贯穿重创的爽感 → 合：混沌之穴吞招与尸顶神秘人的悬念
- **节奏配比**：慢铺垫 25% / 快冲突 45% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：莫凡飞回战场（复仇续战） + 韩寂冰封山峰之尸（压制） + 莫凡贯穿咽喉（重创要害） + 合力攻击被混沌之穴吞没（悬念反转）
- **本章核心技巧**：用反派心理误判与强者合力落空制造绝杀前的反转钩子
- **卡点与伏笔**：结尾卡点：悬念型——混沌之穴吞掉合力一击，尸顶出现神秘人，下章揭其身份；埋设/回收伏笔：亡灵结晶→要害设定，混沌之穴→神秘人身份伏笔
