# 第241章 铁笼血战！

**概要**：诅咒畜妖钻入巨大铁笼与莫凡死斗，其唾液带腐蚀性、落地冒黑烟，铁笼结界本就用来困暗影妖兽、封死了暗影系逃脱之路。畜妖速度比当初刚进阶战将不久的鳞皮母妖还快，先以多重镰状飞爪远程压制，莫凡翻滚闪避仍被划出深可见骨的手臂血痕，还被剥夺了描画星图的机会。危急中莫凡唤醒魔具冥离盾挡住削铁如泥的鬼爪，并激活反刺效果，暴雨般带倒勾的菱形刃扎穿畜妖的腐质皮层、放血一片，却被它后翻跳脱倒勾、未受致命伤。莫凡收盾拉开距离后轰出玫炎-烈拳-地刹，火柱如小型火山喷发，畜妖却因这次极速进攻本是试探而灵巧跃开、仅被火舌擦过，落地露出讥讽笑意，随即化为爪风旋风席卷而来；莫凡庆幸手腕留了火焰后手，但余能不足以再放地刹，只能以火拳硬撼，火焰被爪风层层刮开，旋风气势不减。

**关键事件**：1.诅咒畜妖飞爪重创莫凡并封锁其描画星图 2.冥离盾反刺放血却被畜妖跳脱倒勾 3.地刹落空，火拳硬撼爪风旋风陷入危机

**逐章写法公式**：

- **情绪流向**：起：紧张（铁笼死斗开启） → 承：压抑（飞爪见骨、施法被锁） → 转：爽（冥离盾反刺放血） → 合：紧张（地刹落空、旋风压顶）
- **节奏配比**：慢铺垫 10% / 快冲突 50% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：困笼对峙（确立死斗） + 飞爪锁技（绝境加压） + 盾刺反击（攻防转换） + 地刹落空旋风压顶（危机卡点）
- **本章核心技巧**：用"封锁施法→魔具过渡→大招落空→底牌硬撼"的四段攻防换挡，让单体战斗每段的胜负手段各不相同，避免重复对轰
- **卡点与伏笔**：结尾卡点：危机悬置——爪刃旋风刮开火焰、气势不减地席卷莫凡，下章看莫凡如何破局；埋设/回收伏笔：手腕保留火焰（自述留后手）→ 本章末硬撼旋风的底牌；冥离盾反刺倒勾 → 可再克制放血型妖兽的魔具线索
