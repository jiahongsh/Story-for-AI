# 第641章 引蛇出洞（上）

**概要**：众人确认穆贺可能就是撒朗麾下的虎津大执事，穆白最难接受这位一直敬重的叔叔竟与宇昂和博城灾民转移有关。韩寂说明高层软禁计划，若无法找出真正的撒朗，近十位被软禁的高层都将被处死。穆白质疑这种做法可能导致君主级亡灵无人抵抗，莫凡则认为穆贺既是虎津就一定知道撒朗身份，不能让高层成为陪葬。韩寂说断头计划将在山峰之尸攻击结界时执行，莫凡决定主动擒拿穆贺。穆白提出假装去茶庄避难，把地圣泉和博物馆的消息透露给茶庄老板，诱使他向穆贺传信。

**关键事件**：1.穆贺被确认是虎津 2.软禁高层可能集体处死 3.众人争论断头计划 4.莫凡决定擒拿穆贺 5.穆白提出茶庄诱敌计划

**逐章写法公式**：

- **情绪流向**：起：身份震惊 → 承：处决高层的伦理争论 → 转：决定捕捉穆贺 → 合：穆白提出引蛇出洞
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：确认穆贺身份（击穿关系） + 说明软禁代价（抬高选择） + 争论断头计划（制造冲突） + 设计茶庄诱饵（推动行动）
- **本章核心技巧**：用道德两难拖住直接处决，再由主角提出第三条行动路线，保持悬念和主动性。
- **卡点与伏笔**：结尾卡点：穆白准备进入茶庄向薛藏传递假消息，下一章期待虎津上钩；埋设/回收伏笔：薛藏与穆贺联系 → 成为传递诱饵的中间人。
