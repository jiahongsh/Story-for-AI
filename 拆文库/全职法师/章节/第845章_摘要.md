# 第845章 我怕我撕了他

**概要**：冷雨中七人身影渐模糊，唯莫凡调戏穆宁雪的声音清晰，穆宁雪还回应着，官鱼牙齿咯吱响几乎爆炸，蒋少絮讽刺他除了恼羞成怒什么都不敢做。官鱼发现自己连顶撞大爷爷都不敢，承认莫凡敢走、穆宁雪敢选艰难路。祖吉明安慰官鱼等威尼斯后什么女人得不到，南荣倪低声说"真爱啊"，赵满延泪流满面自愧情场手段弱。机场冷雨里飞机滑行，穆宁雪坐窗边，莫凡凑去问有没有感动，她说没有，并认真让莫凡离远点免惹麻烦，莫凡骂谁敢说她是黑教廷就拿鞋底板拍死。后段转灵隐审判会后院，唐忠沏茶问黑发黑须人怎么让封离同意莫凡入队，得知莫凡竟是自己退队，黑发黑须人猛然站起要叫人，听说自退后哑口无言，咬牙说"我怕我忍不住撕了他"。

**关键事件**：1.蒋少絮等点破官鱼不敢作为，衬托莫凡穆宁雪的决绝 2.机场上莫凡与穆宁雪对话，莫凡护她到底 3.灵隐审判会后院唐忠与黑发黑须人饮茶 4.得知莫凡退队，黑发黑须人怒而转无奈

**逐章写法公式**：

- **情绪流向**：起：官鱼被讽恼羞 → 承：机场莫凡护穆宁雪 → 转：黑发黑须人得知退队暴怒 → 合：哑口无言的憋屈余波
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：官鱼挫败（对照） + 机场护持（甜） + 审判会饮茶（转场） + 退队消息（反转）
- **本章核心技巧**：用配角群的对照反应给主角决断定调，再用高层视角的震惊完成章节钩子
- **卡点与伏笔**：结尾卡点：神秘黑发黑须人险些发怒，下章期待其身份与送出之物揭晓；埋设/回收伏笔：黑发黑须人送出的"东西" → 后续莫凡入队缘由的伏笔
