# 第1458章 孙女婿

**概要**：夜静山巅，穆白独自坐望夜空，觉景色比那女孩描述更美，下山回望阳驿站时路过酒吧，正撞一醉醺醺中年男子搂着纤细姑娘往旅店走、手放肆捏臀。姑娘迎面见穆白愣了一瞬，穆白仅停步一瞥便继续前行，月光洒其背影；醉男喝斥姑娘，姑娘答"一个之前的客人而已"。穆白心头泛起无牵无挂的孤独。众人离太阳岭飞回魔都，机上赵满延与空姐调笑，空姐叹海妖横行致国际航线受损。莫凡提及圣裁院已下文书召其近期赴瑞士裁定帕特农神庙旧案，冷爵功过相抵仍要走形式。穆白闻瑞士沉思，说自己母亲领养的姐姐早年随瑞士夫妇去那边、多年无音讯，求与莫凡同往探望并告之母亲离世，之后去凡雪山。赵满延自嘲远离莫凡最安全拒同行，莫凡笑称"又有一个联邦被征服"。回魔都交接祁杉后，莫凡去明珠学府萧院长处喝茶，嫌自身装备简陋、玄蛇铠甲仅够当防毒面具。老教授们见莫凡本要训斥，认出大旗杆后改口猛推销孙女，莫凡调侃名草有主可当暖床丫鬟；萧院长顺势定下由李、郑两位教授以国外学府交流之名带队护送莫凡赴圣裁院。

**关键事件**：1.穆白夜遇陪酒女勾起孤独 2.机上定赴瑞士圣裁院，穆白寻姐 3.莫凡回魔都访萧院长 4.老教授推销孙女，议定教授护送赴圣裁院

- **情绪流向**：起：穆白孤独怅然 → 承：机上定行程的期待 → 转：回魔都闲适 → 合：教授催婚与护送定案的轻松

- **本章结构公式**：穆白孤独一幕（人物） + 机上定瑞士行程（推进） + 回魔都访萧院（过渡） + 教授护送定案（收束）

- **卡点与伏笔**：结尾卡点：铺垫型——李郑教授将带队护送莫凡赴圣裁院；埋设/回收伏笔：穆白瑞士姐姐→新角色与新地图引子；圣裁院裁定→承接帕特农旧案后续
