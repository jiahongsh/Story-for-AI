# 第180章 再蜕皮

**概要**：两只蜕皮妖怪不肯罢休，从窗子爬出、朝下坠的莫凡扑来，下坠速度比莫凡还快——莫凡冷笑等的就是这一刻：屋里怕烈拳烧穿楼层，现在的半空正是绝佳出手时机。他在下坠中交织星图，玫炎聚于手腕成火镯，一拳朝漆黑夜空轰出"玫炎·烈拳·轰天"，拳形烈焰顺高楼方向倒轰而上，把周围高楼染得通红。女妖情急下抓住同样下坠的男妖、狠踩其背弹跳到另一栋楼阳台逃生；男妖被火拳整个吞没，狠狠轰到比楼顶还高的地方，烈拳在楼顶上空炸出一团巨大火光源。这道光投下几栋高楼的阴影，莫凡借楼影在下坠到三楼时施展遁影，落进小广场放下早已晕死过去的小孩。灵灵通话中对莫凡改观：他持有灵级火种、还用过雷系——一个中阶法师施展三系魔法闻所未闻。她检查焦黑尸体时，尸体外皮突然如烤焦地瓜般龟裂，褪去焦皮竟露出活人皮肤，一个赤裸男子像新生婴儿般爬出拼命呼吸——正是那个丈夫。灵灵开口：叫救护车，他是人，别让他死了——他是委托人，死了我们另外二十万就没了。莫凡被这小姑娘雷得外焦里嫩。

**关键事件**：1.空中轰天烈拳重创男妖 2.借火光楼影遁影落地、孩子获救 3.灵灵见证三系与灵级火种 4.男妖焦皮再蜕、恢复人身待救

**逐章写法公式**：

- **情绪流向**：起：紧张（双妖扑坠） → 承：爽（轰天烈拳重创男妖） → 转：好奇（焦皮再蜕出活人） → 合：轻松（二十万救人的黑色幽默）
- **节奏配比**：慢铺垫 15% / 快冲突 40% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：双妖扑坠（危机顶点） + 空中烈拳（爽点爆发） + 遁影落地（危机解除） + 再蜕皮与救护车（反转收尾）
- **本章核心技巧**：用一道烈拳同时完成杀敌、照明、补全遁影条件三件事，让爆发点的每个产物都被后续利用。
- **卡点与伏笔**：结尾卡点：丈夫获救待抢救、女妖逃脱仍在本小区，下章期待妖案收网与委托结算；埋设/回收伏笔：玫炎·烈拳比普通中阶魔法强一倍多→灵种威力的量化回收；委托条款只保孩子、不究猎所责→男人活着的意义在尾笔回收；灵灵认出灵级火种与三系法师→莫凡实力被搭档侧面确认；女妖借男妖垫背逃生→下章猎杀女妖的对手存续。
