# 第1373章 不离开的原因

**概要**：赵满延催促立刻撤离，斥众人螳臂当车，莫凡让他先听神都先知的计划再做决定。先知摆出两个事实：胡夫金字塔出现已无法改变，黑教廷实力胜过现有力量；冷爵从自由神殿获得核心次元零件后筹备已久，可在任何国家设置坐标却偏偏选中中国，有一半是撒朗的功劳，他的邪恶信仰理念是杀掉仇人身边所有在乎的人来攫取怨恨信仰之力。叶鸿愤慨要宰掉冷爵，莫凡坦言有进展未摸到关键，灵灵一眼洞穿他真正的意图——等黑教廷盛典举行找出红衣大主教冷爵。赵满延再次崩溃，斥责这从挖证据升级成刺杀红衣大主教。莫凡长段剖白：放弃追杀等于成就第二个撒朗的帮凶，放走它的后果不堪设想，黑教廷一直在身边、总有天会伤害到在乎的人，博城灾难、古都浩劫、北原危机都让身边人离死亡那么近，这就是他不能转身离开的原因。灵灵眼里布满水雾，骂众人都是混蛋，搂住莫凡彻底变回小女孩。张小侯说总教官听到这些话会骄傲，莫凡答"那就怪他没教我们怎么做懦夫"。神都先知表示若莫凡执意杀冷爵便要兵分两路，并向古长城传承者彬蔚抛出北原古老魔法防线的计划。

**关键事件**：1.神都先知道出冷爵的邪恶信仰理念与选择中国的缘由 2.灵灵洞穿莫凡想刺杀冷爵的意图 3.莫凡长篇剖白不离开的原因 4.神都先知提出开启北原古老魔法防线为撤离争取时间

**逐章写法公式**：

- **情绪流向**：起：去留之争的焦灼 → 承：冷爵理念的惊悚 → 转：莫凡剖白的揪心 → 合：古老防线的一线光
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：去留争吵（立矛盾）+ 冷爵理念揭秘（明敌人）+ 剖白不离开（定主角）+ 古老防线出（留希望）
- **本章核心技巧**：把"要不要撤退"写成一场多人立场交锋，再以主角一段掏心剖白定住叙事重心，最后用新方案把绝望转向行动
- **卡点与伏笔**：结尾卡点：悬念式——北原古老魔法防线如何开启未揭；埋设/回收伏笔：莫凡杀冷爵的决心、斩空的同路 → 盛典刺杀线启动
