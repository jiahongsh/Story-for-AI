# 第153章 刚猛战蛰！

**概要**：后台郑冰晓说海大富被摆了一道，长脸男王力挺却乐见直接出局一个、少人竞争炼兽之血，被郑冰晓怼还有六个人——王力挺根本没把没敢唤出召唤兽的莫凡算进来。郑冰晓提醒众人蒋云明定的百人指标：达不到就把资源分给其他系，平均每人要挡约十五个挑战者；王力挺大话称缺的数目他一人补。场上白铠战蛰失明仍准确扫中谢文峰，海大富点破虫族妖魔素来视觉很弱；谢文峰吐血横飞昏迷，顾翰将其送治，还称死不了的就别浪费他的魔能，阮雅老师摇头责他该出手。青短发男生的雷印抽在角质铠甲上无法钻入肌肉，反被战蛰铁锤脑袋撞飞；风系学生耗尽魔能自行放弃。海大富轻松斩四人，第二轮五人配合得当仍久战落败，第三轮咬牙吃下六人组，第四轮战蛰终于被一名火系女生打回次元空间。只攒下十五人数据的海大富不甘离场，王力挺让矮瘦男生上去探数字，矮瘦男生推给莫凡，莫凡直言召唤兽重伤，被王力挺骂废，默默记下这仇。

**关键事件**：1.百人指标规则揭开，召唤系内部分化 2.战蛰失明反杀，连破四轮挑战后力竭出局，海大富数据定格15 3.莫凡被王力挺当众骂废，暗记仇

**逐章写法公式**：

- **情绪流向**：起：后台拌嘴的轻松 → 承：失明反杀的惊悚 → 转：车轮战的焦灼 → 合：骂废记仇的憋闷
- **节奏配比**：慢铺垫 25% / 快冲突 55% / 爽点爆发 10% / 悬念留白 10%
- **本章结构公式**：指标规则揭底（立团队目标） + 失明翻盘再反转（打脸谢文峰） + 四轮车轮战（消耗与数据） + 骂废记仇（埋主角爆发）
- **本章核心技巧**：用「数据可视化」的轮次计数推进大乱斗，每轮换打法（偷袭、群攻、消耗、强攻），避免重复打斗审美疲劳
- **卡点与伏笔**：结尾卡点：压抑型，莫凡被骂废不还口只记仇，读者憋着等他上场翻盘；埋设/回收伏笔：光耀·失明（上章妙计）→ 被虫族视觉弱属性反制回收；王力挺大话「缺的数目俺一人补」→ 为其食骨妖登场造势
