# 第1283章 丧心病狂的山人

**概要**：高老师只带几名行动快的学员返回内昆嵛山通知政府和军队，把其余学生托付给莫凡和赵满延照顾。队伍在大紫椴树附近遇到两拨为争夺妖冠火拼的猎人，灵灵警告说大紫椴树有警戒意识，人一多就会发出信号召集附近妖魔，果不其然兽吼四起，刘小佳跑去提醒猎人撤离却被拒绝。众人转向别处追寻山人足迹，很快听到之前方向传来凄厉惨叫，折返后只见残肢遍地，血迹被拖向灰色森林。莫凡追入林中，看到一头棕熊毛发的山人手掐一名还活着、被倒拖得鲜血淋漓的女法师的脚踝，莫凡用瞬息移动追上它，刻意不击要害地放出雷电折磨它，最终十二倍威力狂雷将其轰飞上百米撞成焦黑肉泥。刘小佳为女法师治疗腹部撕裂伤，女法师虚弱地凝视莫凡，目光里满是感激。

**关键事件**：1.高老师带队返程报信，学生托付莫凡赵满延 2.大紫椴树下两队猎人火拼，灵灵警告警戒信号将召集妖魔 3.兽吼应验，刘小佳提醒遭拒 4.众人听到凄厉惨叫折返，见猎人残骸 5.莫凡发现山人倒拖活着的女法师，用雷电将其虐杀 6.刘小佳为女法师治疗

**逐章写法公式**：

- **情绪流向**：起：赶路报信的担忧 → 承：猎人火拼与灵灵警告的压抑 → 转：凄厉惨叫与残肢惨状的惊悚 → 合：雷击虐杀山人的爽与女法师获救的沉重
- **节奏配比**：慢铺垫 35% / 快冲突 30% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：高老师带队报信交代局势（推主线） + 猎人火拼与灵灵预警（立规矩） + 惨叫折返见惨状（加压） + 莫凡虐杀山人救女法师（释放）
- **本章核心技巧**：先用专家预言做先验铺垫，让灾祸应验制造信息差爽点；再用「活人倒拖」的具体惨状把仇恨值拉满，使主角的极端暴力成为读者期待的出口
- **卡点与伏笔**：结尾卡点：女法师获救但灰林深处还有更多山人与被掳猎人，莫凡决定去救人 → 下章期待狩猎；埋设/回收伏笔：大紫椴树警戒信号与汪大阔叮嘱 → 解释山人聚集之因；高老师报信 → 政府军队增援线
