# 第292章 禽兽之举

**概要**：明聪取水归来，白婷婷在水里混入驱毒药剂为宋霞清洗带毒的伤口。闷热中白婷婷脱掉外套，明聪盯着她肆无忌惮地窥视；恰在浮想联翩时他感觉自己陷入幻想的泥潭，内心野兽的枷锁彻底断裂——他突然暴力扯断白婷婷的小内衬带子，白婷婷羞怒后退、排列魔法星轨准备自卫。驾幽纹暴狼赶到的陆正河在门外目击这一幕，怒喝“畜生不如”，暴狼一爪摁住明聪。众人围观下明聪清醒过来，脸色发白，连声道歉称自己不知道；陆正河一巴掌打醒他，命小峰、许大龙把他绑在柱子旁，队伍气氛僵冷。夜里莫凡归来，还没反应过来，白婷婷突然小跑扑进他怀里，红着眼圈说“你不要走了好不好”，莫凡答应了。廖明轩阴阳怪气发难，莫凡掏出两个已变绿的勘测器抛给穆宁雪，众人震惊——队伍完成一个勘测点都差点全军覆没。

**关键事件**：1.明聪兽性大发扯断白婷婷衣物 2.陆正河目击并制服明聪、将其绑柱 3.莫凡夜里归队、白婷婷扑入怀中求他别走 4.莫凡亮出两个完成的勘测器震住众人

**关键信息与扩写技法**：

**逐章写法公式**：

- **情绪流向**：起：窥视的压抑 → 承：施暴与制服的紧张 → 转：绑柱清算的愤怒余波 → 合：莫凡归来与投怀的错愕轻快
- **节奏配比**：慢铺垫 35% / 快冲突 35% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：取水归来清洗（日常过渡） + 窥视异化（心理铺垫） + 撕衣施暴（爆发冲突） + 暴狼摁人（制裁） + 绑柱清算（余波） + 莫凡归队投怀与勘测器（爽点收尾）
- **本章核心技巧**：用“施暴—制裁—战绩”三段情绪落差点接排布：先压到谷底再由主角归队拉起，完成压抑到爽的复位
- **卡点与伏笔**：结尾卡点：认可悬置型——两个勘测器抛出、众人将信将疑，下章期待细节与态度反转；埋设/回收伏笔：明聪“我不知道”的失控 → 回收291章水蜘蛛入袖，指向蛊惑能力；白婷婷扑怀求莫凡别走 → 埋白婷婷对莫凡的依赖线
