# 第51章 被莫凡宰了！

**概要**：莫凡要走出洞窟时，一片影子绕石壁旋转，唐月从影子中缓缓站起，惊喜确认他没事，看到被钉如标本的幽狼兽愕然，斩空告知“你们教出了一个很妖孽的学生”。山口外学生们陆续苏醒，见总教官和唐月领着莫凡走出洞穴，众人露出见鬼般的表情，何雨落泪、周敏眼圈泛红，王三胖等人追问逃脱经过，赵坤三风言独眼魔狼定是斩空所杀。斩空公布历练中教官一直随行并为表现出色的学生打分，又揭晓那不是独眼魔狼而是白阳的召唤兽幽狼兽，悬赏实为安排好的演练，学生们后怕得全哭了。张建国进一步说明幽狼兽突然发狂不听命令是超出预料的意外，是莫凡和张小侯把它引入洞窟，全队的命是两人救下的。众人争相道谢认老大，慕白、赵坤三脸色一阵青一阵白。周敏提醒看好洞穴，唐月说召唤兽已经死了，斩空补上“被莫凡杀了”，王三胖瞪着眼没反应过来。

**关键事件**：1.斩空公布随行打分与演练真相 2.张建国说明幽狼兽失控、两人救下全队 3.幽狼兽被莫凡杀死当众揭晓

**逐章写法公式**：

- **情绪流向**：起：生还相见的后怕 → 承：演练真相的哭笑不得 → 转：救命之恩的揭晓 → 合：狼死于莫凡之手的惊雷
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 35% / 悬念留白 15%
- **本章结构公式**：洞口重逢（情绪收束）+ 公布打分与演练（信息揭示）+ 失控意外说明（功绩揭晓）+ 被莫凡杀了（压轴惊雷）
- **本章核心技巧**：同一事件分三层揭底（演练、失控、单杀），每层都刷新学生认知，把爽点拆成阶梯释放
- **卡点与伏笔**：结尾卡点：王三胖瞪眼追问总教官刚才说什么，下章期待全场震动；埋设/回收伏笔：随行打分成绩 → 学生前途线；幽狼兽失控原因仍未明 → 待查
