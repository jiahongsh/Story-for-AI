# 第573章 狞骨魔将

**概要**：黑云低垂的夜里，瞭望塔上一名军衣男子正懒散地观察城墙外的亡灵，盘旋的天鹰突然发出警示叫声，一大片干硬泥土被冲开，一头公牛巨角般的白骨生物从地下爬起，腥红双眼如小灯，抓起岩石砸向天鹰。军衣男子对着通讯仪通报北偏东方向出现战将级亡灵、有损坏城墙的意图。声音传进学员房间，三十岁左右的猎法师领队决定由他们解决，队伍共七人：领队、蒋黎、水系俊男、绒帽女孩、周敏、莫凡、穆白，王三胖赵坤三留在城墙接应。天鹰法师发出信号，三十名火系军法师三波火滋抛下城墙烧成火焰地毯清路，众人跳下城墙杀向狞骨魔将。领队认出这是无妖技但骸骨坚硬如钢、巨力无比的狞骨魔将，需要精锐中阶队伍应对。狞骨魔将离城墙不到三百米，白森森骨躯如呼啸卡车撞来，领队大喊防御，施展的岩障瞬间被撞成粉碎。

**关键事件**：1.天鹰报警，战将级狞骨魔将从土里钻出意图损坏城墙 2.七人中阶队伍出城迎战，三十名火系军法师开路 3.狞骨魔将如卡车冲撞，岩障瞬间粉碎

**逐章写法公式**：

- **情绪流向**：起：平静（夜观亡灵） → 承：警觉（天鹰报警） → 转：冲击（岩障被碎） → 合：凝滞（硬仗开打）
- **节奏配比**：慢铺垫 40% / 快冲突 40% / 爽点爆发 0% / 悬念留白 20%
- **本章结构公式**：警报升起（悬念） + 队伍集结（分工） + 火滋开路（过渡） + 冲撞立威（压力）
- **本章核心技巧**：让新怪先碾压一次己方防御再开打，把boss牌打足再进入对策阶段
- **卡点与伏笔**：结尾卡点：岩障碎了怎么打，下章期待破防办法；埋设/回收伏笔：狞骨魔将离城墙三百米的隐患
