# 第103章 再战幽狼兽！

**概要**：张小侯喉咙被剧痛堵住，喊不出何雨的名字，无数水珠在他面前散落消失，如同何雨的生命在陨落。他心脏剧痛下疯狂衔接星轨放出风轨，从黑畜妖厉爪下抢回血染的何雨闪到远处，但黑畜妖是放血的刽子手、能找准动脉切开便血流不止，血飞散遍地根本止不住。张小侯嘶喊质问何雨为何用水御保护自己而不保护自己，哀求薛老师救她。何雨在他怀中睁眼相望，苍白发紫的脸上有欣慰——终于在危急时刻放出水御保护住一个人；有安然——历练时这个瘦瘦男孩曾舍身救她，今天她也救了他；更多是眷恋。白阳站中央丧心病狂地嘲笑小鬼们有进步，说这是"不要轻易相信任何人"的最后一堂课，谁也别想活着走下这座桥，并驱两只黑畜妖再扑学生，薛木生大喊快退开。另一边莫凡怒火灼烧，面对爪子拍盾拍得生疼暂无法攻击的幽狼兽；幽狼兽嘶吼喷出飞沙走石，莫凡侧滚躲入面包车后，铁皮被打得千疮百孔。他背靠车身凝聚七颗星子的雷电之印，转身直面幽狼兽怒喝"一年前我就宰过你这种东西，今天杀你跟杀狗一样"。雷印·怒击锁定躲避位电瘫幽狼兽，电弧爬满其全身使其丧失行动力；莫凡另一手早握着火滋，先雷再火，小小火团精准飞入嚎叫的狼口，一声"爆裂"在它口腔中彻底炸开。

**关键事件**：1.何雨替张小侯挡击重伤，动脉被切血流不止 2.白阳宣判全队谁也别想活着下桥，驱黑畜妖再袭学生 3.莫凡先雷后火连招，火团飞入幽狼兽口中爆裂

**逐章写法公式**：

- **情绪流向**：起：悲伤（何雨濒死与水珠意象） → 承：压抑（白阳宣判、黑畜妖再袭） → 转：爽（莫凡怒火、雷印抽瘫幽狼兽） → 合：爽（火团入口爆裂，战果留白）
- **节奏配比**：慢铺垫 15% / 快冲突 40% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：牺牲余波（立悲情）+反派宣判（加压）+雷印控场（转折）+火爆狼口（爆发收章）
- **本章核心技巧**：把悲情直接转为主角怒火燃料，用"先雷后火"双段连招让爽点分层引爆，收在爆炸瞬间不写结果，把战果悬置到下章。
- **卡点与伏笔**：结尾卡点：战局悬念——幽狼兽口腔爆裂的战果如何、何雨能否获救、黑畜妖对其他学生的威胁未解；埋设伏笔：黑畜妖放血特性→何雨获救的机制性绝望；白阳"最后一堂课"Flag→待打脸；历练时张小侯舍身救何雨的旧事→两人羁绊回扣；一年前莫凡宰幽狼兽→战绩呼应。
