# 第57章 危险，擦身而过

**概要**：莫凡心急如焚地坐出租车赶到小姑莫青家，转角险些撞上坐轮椅的叶心夏，确认她平安才松了口气——手机停机只是欠费没舍得交。心夏递手帕让他擦汗，讲出失踪案详情：失踪的林云儿是她隔壁班女生，当天还在图书馆跟她打招呼说回宿舍，此后再没人见过，各门监控也没拍到她离开学校，心夏是最后见到她的人。离开图书馆时心夏嗅到像从食堂某处飘来的发馊怪味，当时身子一阵发冷、好像有东西盯着自己，吓得匆匆离开；她自责那可怕的东西一开始的目标可能是自己，是自己匆匆离开才让它转向孤身一人的林云儿。莫凡柔声安慰她五感敏锐却行动不便、保护好自己已很了不起，并回忆幼时打架受伤躲进心夏家被她清洗包扎的往事，发誓不让她再受伤害，拍胸膛保证以城市猎妖队一员的身份解决此事，叮嘱她这几天呆在家里。心夏知道莫凡是雷系法师后心安许多，感到他正一点一点变强，还打趣他黑得差点认不出。莫凡随后来到铭文女子中学，空荡校园里只等来了郭彩棠。

**关键事件**：1.确认心夏平安、停机只是欠费 2.心夏讲出馊味寒意的经历并自责目标本是自己 3.莫凡立誓保护、只身赴校与郭彩棠会合

**逐章写法公式**：

- **情绪流向**：起：狂奔寻人的惊惶 → 承：确认平安的松弛温馨 → 转：自责真相的心疼 → 合：只身赴校的热血
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：寻人虚惊（情绪释放）+ 案情口述（线索集中）+ 自责与安慰（情感深化）+ 赴校会合（转场钩子）
- **本章核心技巧**：用一场虚惊同时完成情报收集与情感加深，怪谈细节由亲历者口述，比作者旁白更有现场感
- **卡点与伏笔**：结尾卡点：郭彩棠到场、夜探将启，期待当晚守食堂；埋设/回收伏笔：馊味+发冷+被盯感 → 妖魔气味与位置线索；心夏是最后目击者 → 她仍可能是目标
