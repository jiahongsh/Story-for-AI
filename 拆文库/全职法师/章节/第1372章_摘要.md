# 第1372章 神都先知

**概要**：赵满延一行踏上北原，心情沉重，想起莫凡"拼尽全力不留悔恨"的话，更觉黑教廷七大红衣主教横行、以他们几人对抗如不自量力。众人按张小侯指引往谷梨村集合，叶鸿彬蔚随行以求亲眼所见，好说服北部军区总部下达撤离命令。抵达谷梨村祠堂，等到的不是莫凡，而是一位灰白长袍遮脸的神秘人——张小侯道出他正是神都先知，古都浩劫时锁定撒朗身份、执行断头台计划的决策者。神都先知自嘲并非先知，说这里不存在转机只有下下策，并从东面带来"国家无情"的暗示。他提及莫凡现在的样子像极了一个人——斩空，当年斩空从翼苍狼获知黑教廷更大后续，求他给一个潜伏代号，明知启用后可能从此消失却毫不犹豫，还在煞渊中舍弃身份潜入黑教廷。莫凡随后披黑色宽松衣袍现身，灵灵扯下布罩露出满是疤痕的脸，赵满延惊得立刻要走。莫凡听完灵灵的胡夫金字塔推断后惊了许久，他猜到是迎接大金字塔，却不料是最可怕的胡夫。神都先知坦言上头确实已放弃这里，莫凡没有抓狂只有无尽悲伤，随即反问对方过来必有计划，不信他只是个传达自生自灭消息的通讯兵。

**关键事件**：1.谷梨村祠堂等来神都先知，道出斩空当年潜伏黑教廷的往事 2.莫凡现身，疤痕面容惊住众人 3.莫凡听完胡夫金字塔推断，惊于预想之外 4.神都先知承认上头已放弃北原，莫凡反问其计划

- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 10% / 悬念留白 40%
