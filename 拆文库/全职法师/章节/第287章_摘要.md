# 第287章 伪怖魔种子

**概要**：靠近市政大楼后小泥鳅坠雀跃无比、周身散发特殊华光，光越强离宝物越近，成了寻宝雷达。莫凡点破自己离队的真正目的并非被气走，而是要查清这里藏着什么——之前全军覆没的猎法师队为何要来，是否也发现了有价值的东西。他凭暗影系能力孤身穿过废墟，躲过砸落的断柱，靠华光强弱反复试步定位出宝物埋在下方，召唤出疾星狼当苦力刨土。花岗岩地板被利爪三两下抓碎，坑中挖出伪怖魔密密麻麻的死根须，根须之下镂空处悬浮着一枚豌豆大小、发浅绿光芒的东西。莫凡认出这是伪怖魔的种子——如同妖魔幼宠，可供召唤系魔法师直接培育；成年伪怖魔实力恐怖、应是战将中血统较高者，种子价值上千万。刚给疾星狼买进阶材料买穷了的莫凡决定卖掉它换钱——他还欠着暗影系灵种的巨款，奴仆级幼宠百万起、战将级幼宠2000万起还常被秒买。他心满意足骑着疾星狼奔向下一个勘测点装样子，勘测需安置释放特殊声波的装置并守护三小时，但声波不完全稳定、某些品种妖魔能察觉，装置能否安然无恙立够三小时很难保证。

**关键事件**：1.莫凡借小泥鳅坠华光雷达在废墟下定位并挖出伪怖魔种子 2.评估种子价值上千万，决定卖掉换暗影系灵种钱 3.骑疾星狼赴勘测点，得知勘测装置声波可能被妖魔察觉

**逐章写法公式**：

- **情绪流向**：起：悬念（雷达指引寻宝） → 承：紧张（断柱险情与定位） → 转：爽（种子出土价值千万） → 合：紧张（声波装置或引来妖魔的预告）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 30% / 悬念留白 25%
- **本章结构公式**：揭真目的（反转开局）+ 雷达寻宝（探索过程）+ 种子现世（收益兑现）+ 装置机制（下章危机预告）
- **本章核心技巧**：寻宝戏用"仪器反馈+动物苦力+市场价背书"三件套，把静态挖掘写出节奏感与获得感
- **卡点与伏笔**：结尾卡点：声波装置可能被妖魔察觉、三小时守护危机四伏；埋设/回收伏笔：猎法师队来此目的之谜→前人来寻宝（部分回收：此地确有宝）、伪怖魔种子→召唤系契约/拍卖线、暗影系灵种欠款→经济压力线、疾星狼战力→独行自保底牌
