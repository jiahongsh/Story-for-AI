# 第1389章 大举进攻镇北关

**概要**：赵满延认出斯芬克斯——代表古埃及的死神，存活了不知多少千年、被埃及供奉为神灵的远古之物，此刻它隔着五六公里朝宏伟之墙吐出一座沙山级别的吐息，黄沙翻滚打得城墙溃败、厚度严重削减，土系源泉被快速消耗，神楚之界威力随之受影响，一大批复冥生物又开始层层叠叠往墙上爬。镇北关本就在乔雀一队的黑教廷疯狂进攻下浴血疲惫，双山关魔烽火随之熄灭，八段古关只剩五段，赵满延直言守不住了。灵灵点出关键：宏伟之墙必须撑住两天，让北原人撤到易守难攻的飞皇市，可才过一天就熄了三道魔烽火，镇北关一旦失守整个防线彻底瓦解。莫凡的契约没有解除，赵满延大受打击，却决定不再逃避、只求守住这里。二人绕开黑教廷冲入镇北关，遇上赶来支援的叶鸿——他已在另一处古关杀掉蓝鬼。灵灵判断持有莫凡契约的人多半会出现在集中攻打的镇北关，赵满延欣喜，向叶鸿道明莫凡有斩杀红衣大主教的能力，三人力求在斯芬克斯破坏镇北关墙前先杀掉那个契约人。

**关键事件**：1.斯芬克斯以沙山吐息令宏伟之墙溃败、厚度严重削减 2.双山关魔烽火熄灭，八段古关仅剩五段，镇北关岌岌可危 3.灵灵点出宏伟之墙须撑住两天以保北原人撤至飞皇市 4.莫凡契约未解，赵满延受打击但仍决定死守 5.叶鸿赶来支援，三人定下先杀契约人再斩冷爵的计划

**逐章写法公式**：

- **情绪流向**：起：斯芬克斯真身压境的恐惧 → 承：城墙连锁崩坏的压抑 → 转：契约未解的打击 → 合：锁定契约人、合力破局的希望
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：斯芬克斯吐息毁墙（大敌压境）+ 魔烽火接连熄灭（局势崩坏）+ 契约未解打击（情绪低谷）+ 锁定契约人在镇北关（转机收尾）
- **本章核心技巧**：大敌压境与内部计划受阻双线合击把情绪压到谷底，再用一个推理得出的破局目标把希望拉回来，绝望尽头给路
- **卡点与伏笔**：结尾卡点：三人合力能否在斯芬克斯破墙前杀掉契约人；埋设/回收伏笔：莫凡契约未解、真持有人在乌纳斯处→莫凡方知晓真目标的渠道尚未打通
