# 第957章 奈何为贼

**概要**：欧妮求饶不成，莫凡抓她砸向正酝酿火系中阶的红饰法师，替蒋少絮解围。疾星狼跃出咬断一法师半臂，天焰葬礼烧成火海驱散围攻者。莫凡救下蒋少絮，引雷电灾横扫，再以暴力火蛟送走冰系法师。赵满延金翼来护，光鳞铠甲挡下欧妮高阶。莫凡再施寂雷死光-雷臂清场，红饰尽数倒下，疾星狼补刀撕咬。欧妮被巨影钉重重禁锢。赵满延叹"卿本佳人，奈何为贼"，蒋少絮制止杀她，称留着或许有用，于是三人押解欧妮前往白头港，蒋少絮称红饰没那么简单。

**关键事件**：1.莫凡砸欧妮救场，疾星狼天焰清场 2.赵满延金翼光甲挡欧妮高阶 3.雷臂清场，欧妮被巨影钉禁锢 4.留欧妮有用，押解白头港，疑红饰不简单

**逐章写法公式**：

- **情绪流向**：起：欧妮求饶加压 → 承：砸人救场爽爆 → 转：金翼挡高阶配合 → 合：留活口押解留钩
- **节奏配比**：慢铺垫 10% / 快冲突 50% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：砸人救场（爽点） + 狼焰清场（炫技） + 金翼挡阶（配合） + 留口押解（蓄势）
- **本章核心技巧**：用"以敌制敌+契约兽+队友互补"三重合力写碾压战，结尾留活口转场
- **卡点与伏笔**：结尾卡点：红饰究竟"不简单"在何处留悬念；埋设/回收伏笔：欧妮被擒→白头港审讯；疾星狼→护主分工
