# 第387章 还有一只天鹰

**概要**：祝蒙察觉罗冕有所隐瞒，罗冕以兵临城下不该内讧搪塞。云枫宣布白魔鹰两小时内抵达、防线最多撑三小时，只剩五小时。冷青提出当务之急是解瘟病、让白魔鹰失去目标，并给出解药——西岭生长的特殊药草鹰红草；罗冕讥讽西岭是白魔鹰老巢无人能入、无兵力可派。云枫想到白魔鹰与天鹰同种不会互相袭击，可派天鹰潜入采草，却被军统明阔提醒当初正是云枫下令处死了要塞全部天鹰，且君主级魔鹰威压下天鹰会叛变，会议陷入沉寂。此时少年王小筠撞开会议大门，喊称有办法采集鹰红草，云枫欲军杖责罚、罗冕斥其胡闹并拂袖离场，冷青指出他正是协助找到瘟病源头的人。王小筠说出办法：西要塞里还有一只天鹰——他违抗军令放走了从小饲养的天鹰，可以乘它潜入西岭；云枫质疑天鹰已失去理智，王小筠补充自己的天鹰血统混杂、毛发灰色，昨天用笛声沟通得到了回应，可唤回验证它不受魔鹰君主控制。

**关键事件**：1.云枫给出五小时倒计时，解药锁定西岭的鹰红草 2.天鹰方案因要塞天鹰被处死而搁浅 3.王小筠闯会献策：还剩一只违令私藏的灰天鹰可用

**逐章写法公式**：

- **情绪流向**：起：倒计时压顶的紧迫 → 承：解药远在敌巢的绝望 → 转：少年闯会献策的转机 → 合：灰鹰唤回验证的悬置
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：时限加压（危机定量化）+ 解药抛出（目标具象）+ 方案两连废（绝望加码）+ 小人物救场（转机后置）

- **卡点与伏笔**：结尾卡点：验证钩子——灰天鹰能否被笛声唤回、不受魔鹰君主控制尚待验证，五小时倒计时继续走；埋设伏笔：王小筠违令放走的灰天鹰（血统混杂、灰色毛发）→ 下章采药行动的执行工具与身世悬念；罗冕拂袖离场 → 与主战派决裂、待清算；云枫处死天鹰的旧令 → 决策失误代价线
