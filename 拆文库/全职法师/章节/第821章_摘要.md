# 第821章 剧毒发作

**概要**：风盘陷阱并非穆宁雪自创，源于西守阁冈本嵩用风盘天罗对付官鱼，虽败却让穆宁雪看出门道，她研究出提前施展风盘天罗强压于空气中、待物体快速接近扰乱临界点便狂卷成更强风壁障的手法。锯齿绿妖对气流无感知，四只夹击触发风盘陷阱，被青色漩涡卷飞，其中两只脑袋相撞、海胆刺扎进彼此脸，神经麻痹后变成皮肉下垂的面瘫老妖，滑稽收场。小头目挣脱冰霜趁穆宁雪背对鼓喉射水柱，穆宁雪以冰锁缠腰惊险躲开，水剑枪打穿石栏。官鱼踩风轨跨几十米来助，凭臂铠刺坐享其成解决两只行动迟缓的绿妖，小头目见状带两只分逃，被穆宁雪急冻住一只、官鱼踩碎另一只。官鱼对穆宁雪展露暖男一面，被支去靠近南珏保护南荣倪。穆宁雪见海水又涨一米，忽闻孩啼——重伤南荣倪的白泣妖未死，断触坠已长回大半。南珏通讯急报：南荣倪中毒，腿上伤口溃烂、血管透出铅白色。

**关键事件**：1.风盘陷阱原理揭晓、绿妖夹击被卷飞变面瘫 2.小头目水柱偷袭、官鱼来助坐收 3.白泣妖未死且自愈、断触坠重生 4.南珏急报南荣倪剧毒溃烂

**逐章写法公式**：

- **情绪流向**：起：战术揭晓的爽 → 承：小头目反扑的紧张 → 转：官鱼入局清场的轻松 → 合：白泣妖未死+剧毒急报的双重钩子
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：陷阱原理收尾（解释） + 小头目反扑（加压） + 官鱼助战清场（爽） + 白泣妖未死+剧毒急报（双钩）
- **本章核心技巧**：章末用两个递进钩子（反常物象+队友中毒）把战斗爽感立刻翻成危机感。
- **卡点与伏笔**：结尾卡点：南荣倪剧毒溃烂垂危，下章期待众人如何解毒；埋设/回收伏笔：白泣妖断触坠 → 自愈重生，呼应前文南荣倪中毒源未除。
