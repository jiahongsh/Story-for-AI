# 第607章 巨君，山峰之尸

**概要**：紫色警戒笼罩古都，居民从睡梦中醒来，看到街区消失和人群逃散。矮男在城楼上因医院被毁而痛哭，莫凡只能用可能早产回家的说法让他稍微镇定。骸刹冥主召集无穷亡灵，远处又出现山峰般的狂尸，雨幕和亡灵潮向古都收拢。祝蒙判断山峰之尸是与图腾玄蛇同时代的大君主，下令撤回内城结界。莫凡告诉祝蒙，自己从雨中嗅到黑教廷气息，祝蒙由此联想到雨水可能是亡灵白昼活动的关键。

**关键事件**：1.紫色警戒下古都居民开始逃亡 2.山峰之尸与骸刹冥主共同压迫城市 3.莫凡指出灾难可能有黑教廷和雨水因素

**逐章写法公式**：

- **情绪流向**：起：居民从日常中醒来见到毁城 → 承：矮男悲痛与亡灵军团逼近 → 转：山峰之尸现身、领袖下令撤退 → 合：莫凡提出黑教廷和雨水线索
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：居民发现异常（扩展灾难） + 亡灵巨君聚集（升级威胁） + 领袖撤回结界（确认无力硬抗） + 旧案经验指向黑教廷（建立调查线）
- **本章核心技巧**：用群像展示灾难规模，再把宏大异常收束到主角的一条感官线索上。
- **卡点与伏笔**：结尾卡点：莫凡以“雨”指向黑教廷，祝蒙开始怀疑雨水改变了亡灵规则；埋设/回收伏笔：博城大雨与古都大雨的相似性 → 转化为黑教廷和撒朗线索。
