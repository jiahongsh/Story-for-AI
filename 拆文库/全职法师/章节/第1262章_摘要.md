# 第1262章 图腾兽，霸下

**概要**：邵郑叹气说出他的预判，几年之后东海岸线将迎来一场海妖战争，亚洲魔法协会的提案被苏鹿否决，国家只能独自面对来自太平洋的强敌，而军方力量已全部投入仍只勉强守住每座城市，一旦海妖战争爆发根本抽不出余力。约五年前有位考古法师与他彻夜长谈，指出一股足以平复战争的力量沉睡在国土之中，邵郑便指派他去寻找图腾兽古迹，此人却失踪了。莫凡猜出那人是蒋少军，邵郑请他捡起这项任务，唤醒沉睡遗忘的图腾兽为海岸线备战，并坦承他唯一能筹集的底气只有图腾兽的援助。莫凡想着凡雪山就在沿海，又对图腾兽感兴趣，便应下此事，邵郑承诺移交蒋少军收集的资料。随后邵郑透露一则隐秘消息，国府队员赵满延被巨兽吞食失踪，而据蒋少军资料，那头海洋巨兽也是一只图腾，应是玄武后代之一的霸下。莫凡回忆在日本时霸下便一路跟随，两人推断赵满延手中木鱼器皿正是霸下的象征器皿，图腾兽与器皿灵魂契约后便守护其主，持有器皿者断不会被伤害，莫凡放下心，认定赵满延没死还走了大运。

**关键事件**：1.邵郑预测海妖战争将临，国家须独自迎战 2.邵郑托付莫凡唤醒图腾兽为海岸线备战 3.揭出吞掉赵满延的巨兽是玄武后代霸下 4.推断木鱼器皿是霸下象征器皿，赵满延应还活着

- **卡点与伏笔**：结尾卡点：期待类，赵满延是否真随霸下生还、木鱼器皿将如何发展；埋设/回收伏笔：蒋少军资料与月蛾凰记载 → 后续任务道具，霸下与玄蛇兄弟关系 → 图腾兽主线。
