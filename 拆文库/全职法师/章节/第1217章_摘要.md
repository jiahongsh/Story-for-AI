# 第1217章 灭掉张七虎

**概要**：暗影军官被莫凡钉死后，张七虎恼羞成怒；漆黑中灵灵悄无声息窜向被俘的金战猎人团，解除了他们身上的桎梏，许平东、杨宝、飞鼠恢复行动便将高阶魔法轰向军官。张七虎如石铠犀牛撞来，借岩石波动在黑暗中锁定莫凡，这一击莫凡来不及瞬移，身影却只是溃散的傀儡残影。莫凡现身张七虎身侧，臂上苍黑雷电打出寂灭死光，十二倍威力的雷束击碎岩甲、贯穿胸腔，张七虎喷血倒地、胸前留拳大焦黑洞。莫凡掌燃烈火凝成炎剑刺入血洞，烈霞之火吞尽体内、灌入熔浆之火爆体而亡，冷道"下辈子别做畜生"。老银红眼冲来被莫凡银辉拍飞，再吃苍雷爪撕成粉碎；黄艺拼杀时被飞川皑狼从身后扑上生撕两半，莫凡令其去漱口别乱吃人。几名强者既死，金战团加入清场，余下中阶军官被禁锢分捕。杨宝、飞鼠叹服莫凡一人抗百官、力斩张七虎。许平东说葛明、张小侯被带入地道寻大地之蕊，飞鼠称石千寿才是最大敌人、须先救团长方能与之较量，莫凡决意跟入。蒋少絮问俘如何处置，莫凡称杀了省事，军官们听得毛骨悚然。

**关键事件**：1.灵灵暗解猎人桎梏，莫凡寂灭死光穿岩甲爆体张七虎 2.苍雷爪撕老银、皑狼撕黄艺，清场 3.探明葛明张小侯去向，决意跟入地道

**逐章写法公式**：

- **情绪流向**：起：暗影解俘翻盘的喜 → 承：寂灭穿甲爆体的炸 → 转：苍雷撕将皑狼生撕的爽 → 合：探明去向跟入的钩
- **节奏配比**：慢铺垫 10% / 快冲突 40% / 爽点爆发 45% / 悬念留白 5%
- **本章结构公式**：灵灵解俘猎人反水（翻盘） + 寂灭死光爆张七虎（爆点） + 苍雷皑狼清场（扫尾） + 探向跟入地道（钩）
- **本章核心技巧**：用暗解桎梏翻盘，再以"自信岩甲→一雷穿爆"的反差收掉首恶，重场嵌狼的诙谐
- **卡点与伏笔**：结尾卡点：莫凡决跟入地道，下章石千寿取命补蕊、林飞历殉道；埋设/回收伏笔：飞川皑狼→生撕黄艺；寂灭死光→穿岩甲；地道→大地之蕊争夺
