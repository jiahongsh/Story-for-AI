# 第1310章 第二契约召唤

**概要**：回到烟台，吃人陷阱的善后移交政府与军方处理，烟台损失了一位退隐的半禁咒级法师和众多猎人，天冠紫椴神树逃走倒也换来外昆嵛山彻底宁静。灵灵从岩氏留下的东西上找到线索，因是古老文字图形需找高手破解，线索指向甘肃——正是蒋少军日记里提过、也是他彻底失踪的地方，而烟台还有一只曾栖息在云顶树冠、似乎比月蛾凰和神树都强大的图腾兽。赵满延抱怨跟莫凡混没好事，莫凡亮出空间系储物区里满满的妖冠之叶，回魔都转卖给另一家企业，得知整件事原是那家日本企业鼓动猎人采叶、紫椴树实为吃人陷阱。莫凡留下钱买两个火系魂种给小炎姬，余钱托烟台高老师发放给死者亲属。他唤醒小炎姬，备好魂种与凛咒地狱三头犬精魄帮她进入成长期，灵灵称小炎姬有望达到母亲姜凤全盛实力，却又叮嘱其年龄偏小、蜕变不可掉以轻心，最后灵灵提到老书上记载召唤系契约魔法可以拥有第二契约兽。

**关键事件**：1.灵灵从岩氏遗物上找到指向甘肃、关联蒋少军失踪的图腾线索 2.莫凡转卖妖冠之叶、分钱给烟台死者家属，备魂种精魄助小炎姬蜕变 3.灵灵提出召唤系魔法可签第二契约兽

**逐章写法公式**：

- **情绪流向**：起：善后交代的沉稳 → 承：线索与横财的处理 → 转：小炎姬蜕变在即的期待 → 合：第二契约设定的勾子
- **节奏配比**：慢铺垫 40% / 快冲突 0% / 爽点爆发 20% / 悬念留白 40%
- **本章结构公式**：善后与图腾线索交代（收束上一事件） + 妖冠之叶变现与分钱（承接物资线） + 小炎姬蜕变筹备（推升级线） + 第二契约抛出（开启新可能）
- **本章核心技巧**：大战之后的过渡章，用物资变现、线索串联、升级筹备三线并行填满，章末以新设定作钩
- **卡点与伏笔**：结尾卡点：悬念型——召唤系可拥有第二契约兽，下章期待小炎姬蜕变是否成功、第二契约对象会是谁；埋设/回收伏笔：甘肃与蒋少军失踪 → 新地图支线；云顶树冠栖息的图腾 → 烟台图腾主线；小炎姬与心夏共心 → 蜕变失败会连累心夏的风险
