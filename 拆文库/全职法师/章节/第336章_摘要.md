# 第336章 卧槽，猴子？

**概要**：远处老树上的张小侯目睹大锤猎人队被沼泽巨物瞬间灭杀，牙齿打颤，许久才回神，还杯弓蛇影地确认自己脚下草地不会升起。他本为安全跟着猎队走，如今精英全灭令他失去方向，但他咬牙不肯走——人没找到怎么能走，只求离沼泽湖中心越远越好。偏偏蜥颅巨妖此时集体回巢（山谷中心每天有约两三个小时的空档，大锤队的计划正是利用这个窗口），不知此节奏的张小侯撞上"回巢潮"，被七八十只巨妖追着提裤子狂奔。另一边，莫凡带着毒未清的离曼南行，靠他给的果实抵挡沼泽毒气；离曼急着去告知猎队并找那个风系法师，莫凡说猎队今晚行动多半没命了，话音未落钻过一处山壁缺口的两人正看见被追到死角的张小侯。张小侯自知无路可逃，深吸一口气喊出要和巨妖拼到天亮；莫凡在缺口招呼他过来，巨妖穿不过山缺口只好作罢。漆黑缺口中张小侯道谢，两人互觉对方声音耳熟；走出缺口月光洒落，四目相对——"卧槽，猴子？""凡哥！！"兄弟相认。

**关键事件**：1.张小侯远观猎队全灭，决意留下寻人 2.撞上蜥颅巨妖回巢潮被围堵 3.莫凡离曼经山壁缺口顺手救人 4.月下相认，凡哥猴子重逢

**逐章写法公式**：

- **情绪流向**：起：恐怖（树上目睹灭队）→ 承：紧张（巨妖回巢围堵狂奔）→ 转：轻松（山壁缺口获救、黑暗互觉耳熟）→ 合：爽（月光下认出彼此，凡哥猴子相认）
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：目击灭队（承接上章余波）+ 去留抉择（立人物义气）+ 回巢潮追杀（危机升级）+ 缺口救人（两线交汇）+ 月下相认（情绪兑现收章）
- **本章核心技巧**：让两条寻找彼此的线在一个山壁缺口前物理相撞，救援顺带完成认亲，一次交汇兑两个情感点。
- **卡点与伏笔**：结尾卡点：重逢卡点——兄弟相认、三人聚齐，期待联手对付山谷巨物与寻找流沼；埋设伏笔：巨物体型庞大行动费劲、多半不乱走 → 讨伐战术依据；解毒果实 → 深入沼泽的通行证；莫凡"我要的东西" → 与流沼灵种的关联。
