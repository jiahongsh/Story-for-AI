# 第1302章 屠杀之雀（上）

**概要**：莫凡质问童尚紫椴树消息是不是他散布的，童尚坦然承认是自己所为，说山人出现并非他所料、猎人们自担风险。莫凡一脚把童尚踹翻，童尚门牙断了一颗满嘴是血，几位军统围住莫凡怒目相视，童尚推开搀扶的人狠声说这一脚他领了，但莫凡若要阻止，他对世界学府之争第一、古都大恩人也不会留情。芍女斥责童尚一句失误死了那么多人，汪华讽刺芍女多管闲事，汪大阔说要与协会长老商议。聂冷山虽代表军方但只是参谋不是决策者，也只得继续战斗。莫凡自认无法以「感觉不安全」驳斥一座城市的未来，把推演的图腾印记交给聂冷山请他探索树层世界时留意拍照，叮嘱神树没那么简单。童尚下令回收战死兄弟遗体。此时最低级的妖雀莫名飞出地盘成群盘绕尖叫，童尚不以为意，孙军统说七彩妖雀追杀完山人飞回来了。树根坡下，女猎人青舒与丈夫东甲立计划用赚到的钱陪女儿小东霞过安稳日子，青舒见七彩云雀落下来递饼干示好，七彩云雀却突然化作风钻带着杀意刺向青舒，东甲立及时施展光之庇佑护住她。

**关键事件**：1.莫凡踹童尚，军统围护、童尚狠话威胁 2.莫凡将图腾印记托付聂冷山 3.低级妖雀盘绕尖叫，童尚不以为意 4.青舒东甲立谈论计划陪女儿 5.七彩云雀突然袭击青舒，东甲立光之庇佑相护

**逐章写法公式**：

- **情绪流向**：起：莫凡踹童尚解气的爽 → 承：权力现实与图腾托付的复杂 → 转：妖雀盘旋预兆、青舒夫妇温馨对话 → 合：七彩云雀突然袭击的惊悚
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：质问与踹童尚（爽点） + 图腾托付与权力无力感（过渡） + 妖雀异常盘旋预兆（悬念） + 青舒遭七彩云雀袭击（惊悚钩子）
- **本章核心技巧**：把「胜利后的人心与危机」并置：一边是权力与英雄的僵局、一边是温馨家庭即将崩塌的预兆，用反差铺垫下一场灾难
- **卡点与伏笔**：结尾卡点：友善的七彩云雀为何袭击青舒，妖雀异动预示着更大的危机 → 下章期待真相与屠杀之雀；埋设/回收伏笔：图腾印记托付聂冷山 → 树层探索与图腾线；青舒东甲立与小东霞 → 岩氏线的交汇；妖雀尖叫盘旋 → 神树异变征兆
