# 第879章 祭献品

**概要**：莫凡将林中土交给灵灵，化验显示唾液成毒腐蚀养料却非黑畜妖或诅咒畜妖，腐蚀性更强、或滋生毒物，正对应城市猎妖队来查的毒性事件。莫凡讲出撞破卡莉与锋队串供，灵灵认为这能卸去黑教廷对三人的警惕、卡莉嫌疑大；又提同学间荣盛汪栩栩赵品霖的纠葛，灵灵判多半无关。另一边赵品霖在酒廊饮闷酒，芳少俪前来，知他觊觎银发穆宁雪，称需"变强"、可送他操纵如召唤法师的生物，前提献祭一名献体。芳少俪亮出汪栩栩的"意外死亡报告"，要他把玩腻的汪栩栩献祭成奴仆；赵品霖犹豫想换陌生人，芳少俪以恐怖气息逼其显决心，点出他想取代堂哥，赵品霖终说"我加入"，被令亲自祭献。

**关键事件**：1.灵灵化验土非畜妖唾液但更强 2.灵灵判卡莉嫌疑大、同学事无关 3.芳少俪许送操纵生物索要献祭 4.亮汪栩栩死亡报告逼赵品霖入教献祭

**逐章写法公式**：

- **情绪流向**：起：化验线索的推进 → 承：同学事判无关的轻描 → 转：芳少俪逼献祭的暗黑 → 合：赵品霖入教的压抑落点
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：化验毒土推线索（查线） + 灵灵判卡莉嫌疑（收线） + 芳少俪亮死亡报告逼献祭（爆点） + 赵品霖入教领命（钩子）
- **本章核心技巧**：双线并置——明线灵灵科学查毒、暗线芳少俪精神围猎，用"死亡报告"把暗线逼到实质。
- **卡点与伏笔**：结尾卡点：芳少俪令赵品霖亲自祭献、称看好他，下章期待祭献如何施行；埋设/回收伏笔：毒土腐蚀性更强 → 本章功能（坐实庄园毒变根源方向）；死亡报告 → 伏笔（汪栩栩生死线，后续揭其被囚浴池）
