# 第1377章 地狱才是你们该呆的地方

**概要**：胡夫金字塔中传出苍老威严的声音，用古老埃及语言宣示降世仪式——以永不停歇的痛苦嘶喊为礼乐，以活人潺潺鲜血为美酒，以铺满大地的残肢内脏头颅为地毯，这声音直击灵魂，回荡脑海久久不散。方跋平原随之沸腾，地裂与厚土层中爬出一个又一个缭绕死气的冥界生物，密密麻麻如黑色灰色潮水簇拥金字塔朝拜，狂热扭曲。那声音再次发令：法老爱沙漠，去吧，将这块大地所有生灵的骨头碾碎成沙堆成沙漠。冥界生物吞没平原向南涌动，被金字塔压裂的大地裂被黑色身躯填满，地表生物踩踏着同伴的脑壳手臂前行，如黑色大地自己蠕动。岩高坡上，紫眼少年冷爵放肆大笑，乌纳斯满脸病态兴奋，超阶法师乔雀也露恐惧；冷爵称与"那位"有约定，随后让众人抬头观礼。坡上站立的正是冷爵派系全部核心——冷爵、双将乌纳斯乔雀、八鬼、一百多名蓝衣执事，引渡首赤鬼缺席。莫凡跪在两百米外抬头，目光穿过层层人群死死盯着冷爵瘦小的背影，惊觉其声音清脆如少年、年龄可能极小。面对这场比想象可怕百倍千倍的冥界狂潮与狂热庆祝的黑教廷，莫凡所有情绪化为灵魂燃烧的怒火——恨不得现在就将他们全部送下地狱，那里才是他们该呆的地方。

**关键事件**：1.金字塔传出法老的降世宣言，以生灵血肉铺架降临仪式 2.冥界生物从地裂爬出，奉旨向南碾碎生灵堆沙漠 3.冷爵派系核心全员现身朝拜，冷爵竟是瘦小少年 4.莫凡跪望冷爵背影，怒火燃至顶点

**逐章写法公式**：

- **情绪流向**：起：法老宣言的毛骨悚然 → 承：冥潮朝拜的惊悚 → 转：冷爵派系现身的震惊 → 合：怒火决意的燃烧
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：法老宣言（立恐怖）+ 冥潮涌动（扩威势）+ 派系亮相（清敌阵）+ 怒焰决意（定杀心）
- **本章核心技巧**：让恐怖景象、敌方阵容、主角情绪三条线在同一场景内汇合，视觉冲击与内心愤怒互相加码
- **卡点与伏笔**：结尾卡点：杀意式——莫凡怒火决意送黑教廷下地狱，动手时机待定；埋设/回收伏笔：冷爵与"那位"的约定、引渡首赤鬼缺席 → 后续冥界协议的真相线
