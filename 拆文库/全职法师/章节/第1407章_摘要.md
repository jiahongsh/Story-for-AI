# 第1407章 毫发无伤

**概要**：飞皇市前线甘雨峰上，彬蔚、先知、赵满延、张小侯、灵灵、叶鸿与众镇守者及三位军司观望，见冥界大军如云翻滚而来正惊慌，却目睹古都亡灵反扑将金字塔冥军节节逼退。张小侯激动得知总教官听见了自己煞渊之言，赵满延惊叹救兵竟是古老王亡灵帝国。迁徙者中最后的芦城老者抵达仍开着的飞皇市门感动落泪，守城法师自认无功。军司周礼盛赞镇守者凭镇北关少数人马拖延近两天，使北原七城四十余镇数百村毫发无伤。先知称最该谢莫凡，其火焰仍点燃众人坚守信念，并见证其从博城求生者成长为真正至尊法师。残墙处铠袍言"死人世界归我管，活人的事你自己处理"，莫凡恶魔血脉褪去仍具战力，借夜煞追踪在冥君蛙背上锁定冷爵，决意活捉以予黑教廷最沉重重拳。

**关键事件**：1.甘雨峰众见古都亡灵反扑、北原迁徙毫发无伤 2.周礼盛赞镇守者拖延之功，先知谢莫凡 3.莫凡借夜煞锁定冷爵、决意活捉

**逐章写法公式**：

- **情绪流向**：起：军司见冥军惊慌 → 承：亡灵反扑、迁徙落定的宽慰 → 转：周礼盛赞、先知谢莫凡的温情高光 → 合：莫凡锁定冷爵、决意活捉的钩子
- **节奏配比**：慢铺垫 25% / 快冲突 10% / 爽点爆发 20% / 悬念留白 45%
- **本章结构公式**：甘雨峰观战（全景） + 迁徙落定（温情） + 周礼点题谢莫凡（高光） + 莫凡活捉冷爵（钩子）
- **本章核心技巧**：在宏大战役后切平民与长官视角收束温情，再用主角一句战术独白自然引出下章追捕行动。
- **卡点与伏笔**：结尾卡点：莫凡决意活捉冷爵，下章期待抓捕过程；埋设/回收伏笔：冷爵身种黑暗物质（1401/1406） → 本章夜煞精准锁定，回收追捕线
