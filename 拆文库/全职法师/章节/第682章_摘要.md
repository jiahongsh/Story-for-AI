# 第682章 脚下一座骨山！

**概要**：古都内城被亡灵与冷雨黑暗困死，钟楼时钟被刻意遮住，无人愿守望死亡倒计时。火焰翅膀摇摇晃晃飞回钟楼的祝蒙议员被左锋、妖男搀下，他双腿带伤、雷霆铠甲破碎，黯然承认输给了山峰之尸，并最关心坠入死门间的莫凡等人——他亲眼看见最强军司耀庭被山峰之尸摁死。妖男指谢桑向众人讲解邪眼铜镜，铜镜里映出死门间中紫黑闪电蔓延、莫凡如孤舟飘摇，脚下却隆起一座由无数骷髅堆成的森白骨山。祝蒙震惊于莫凡一人杀戮之巨，高层韩寂、神秘灰白人、凌溪、楚嘉、陆虚、飞角陆续归来商讨逃亡，灰白人宽慰祝蒙。当众人凑近铜镜看见那座骨山与屹立其上、玄蛇铠甲残缺却仍睁着黑眼的莫凡时，才知他还没死，那颗不屈孤傲的心脏需靠这许多尸体与骨山才体现得淋漓尽致。

**关键事件**：1.祝蒙败回钟楼，承认不敌山峰之尸 2.邪眼铜镜映出死门间莫凡与骨山 3.高层归来商议逃亡，灰白人宽慰祝蒙 4.祝蒙说出莫凡没死，众人见骨山震惊 5.莫凡强弩之末仍屹立骨山

**逐章写法公式**：

- **情绪流向**：起：内城死寂压抑 → 承：高层认输绝望 → 转：铜镜骨山震惊 → 合：不屈信念燃起
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 15% / 悬念留白 40%
- **本章结构公式**：内城绝境（铺压抑） + 祝蒙败回（加压） + 铜镜映骨山（反转） + 莫凡未死（抛钩子）
- **本章核心技巧**：借高层视角与邪眼铜镜的“屏幕”转述，把主角死战变成群体震惊的反应层
- **卡点与伏笔**：结尾卡点：莫凡气数已尽却未死，读者期待他如何撑过血骷骨臣；埋设/回收伏笔：邪眼铜镜 → 后续持续观察死门间战况的窗口
