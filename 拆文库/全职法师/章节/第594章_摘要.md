# 第594章 刷僵尸！

**概要**：小炎姬围绕莫凡吐出大量可持续燃烧的火苗，形成火焰草地毯。畸骨腐尸冲近时被莫凡用雷印麻痹，再被踢入火苗中烧死；莫凡随后用火滋引爆踏过火毯的腐尸，让火苗不断长成火墙和防护林。腐尸越多，火林越旺，残魄也密集飘入小泥鳅坠，莫凡在火焰中持续穿梭并用中阶魔法和火焰屏障刷掉尸群。随着三只毒瘤尸将仍在火林外观望，莫凡确定真正的敌人是它们。

**关键事件**：1.小炎姬铺设持续燃烧的火苗地毯 2.莫凡用雷印和火滋将腐尸转化为火势 3.火林成形并锁定三只毒瘤尸将

**逐章写法公式**：

- **情绪流向**：起：火苗布阵 → 承：腐尸踩火并持续送入燃料 → 转：火林成形、残魄暴增 → 合：清杂兵后锁定三只尸将
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：小炎姬铺火（搭建优势） + 雷印麻痹（阻止突袭） + 火滋引爆（放大火势） + 火林刷怪（积累收益并锁定主敌）
- **本章核心技巧**：把环境布置、敌人特性和资源收集串成同一循环，让每次击杀同时强化防线与成长收益。
- **卡点与伏笔**：结尾卡点：三只毒瘤尸将位于火林外，期待莫凡如何处理；埋设/回收伏笔：火苗会吞食尸体并持续生长 → 后续战斗中的火焰防护林。
