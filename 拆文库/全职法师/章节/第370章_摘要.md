# 第370章 欢迎报仇

**概要**：莫凡左右手火滋连发，火球在东方明身边接连炸开，铠魔具难挡高频轰炸，东方明星图每每将成便被打断，只得退远唤出翼魔具飞上二十米空中欲借烈拳轰炸夺回主动。莫凡道"你觉得我会让你飞起来吗"，脚下紫黑星图早已描画完成，施展千钧-霹雳-夜叉，雷云在东方明头顶成形，惊得他傻眼——对方明明修暗影与火系，雷系从何而来。魔鬼爪状的紫黑雷电将半空中的东方明击落，电弧持续摧残其身，十五分钟之约远未到期；东方明认出天生双系，莫凡笑答"欢迎报仇"。莫凡赶去支援苦战的唐月——她已用斩魔具重创锋羽雀，却遭三名中阶法师轮番轰击只能遁影闪避。两人默契配合，唐月现身诱敌，莫凡遁影潜行摸到柳一林身后，一句"上次我对你下手太轻了"令其浑身冷颤。

**关键事件**：1.火滋连发压制东方明 2.雷系首秀千钧-霹雳-夜叉击落东方明 3.莫凡自曝天生双系 4.莫凡摸到柳一林身后

**逐章写法公式**：

- **情绪流向**：起：爽（火滋连发压制） → 承：紧张（东方明起飞夺主动） → 转：爽（雷系魔爪一击定音） → 合：紧张（柳一林身后的阴影）
- **节奏配比**：慢铺垫 10% / 快冲突 40% / 爽点爆发 40% / 悬念留白 10%
- **本章结构公式**：火力压制（连击） + 升空反制（危机） + 雷系首秀（终结） + 转场擒最弱（新钩）
- **本章核心技巧**：先让敌人的资本（铠魔具、翼魔具、急速天赋）逐一失效，再用双系底牌完成降维打击，最后无缝切到第二条追兵线。
- **卡点与伏笔**：结尾卡点：仇人再遇型——莫凡现身柳一林身后放话，期待"见你一次揍你一次"；埋设/回收伏笔：东方明"你给我等着"→长期仇家线；雷系暴露→下章身份被官方点破。
