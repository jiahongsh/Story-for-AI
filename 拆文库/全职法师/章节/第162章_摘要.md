# 第162章 就你是中阶？

**概要**：庄离风打破常规直扑召唤师本体，海大富带头高喊违规，蒋云明却解释大赛定义下这算不上违规，以前也有别系学员用这招击败过召唤系学长，他从不在课堂事先讲明，就是要学员亲身经历后才记得住召唤法师得懂得保护自己。庄离风借风轨极速冲向莫凡，临近才发现对方手掌上亮起紫光——这世上发紫光的只有雷。莫凡笑说"我可没说我不是中阶魔法师"，释放二级雷印·狂策，狂舞的雷电巨蟒把庄离风抽得满身电弧、动弹不得；莫凡留手没放尽雷印，笑着报数80。坐席炸开：加上罗宋，新生中已出现三个中阶。此后莫凡持续以雷印强控、幽狼兽清场来节省召唤兽体力，人数破百保住召唤系资源，同系五人对他生出钦佩；挑战者只求伤到幽狼兽便觉得赚，计数不知不觉逼近150。

**关键事件**：1.蒋云明解释攻击召唤师并不违规 2.莫凡以雷印·狂策一击锁敌并亮明中阶身份 3.雷印加幽狼兽组合推进计数破百逼近150

**逐章写法公式**：

- **情绪流向**：起：紧张（直扑本体的惊变） → 承：其他（规则解释的缓和） → 转：爽（雷印·狂策一击锁敌） → 合：紧张（尸体成山、逼近150的消耗战）
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：惊变加规则补丁（解决合法性） + 冲锋与紫光（信息反转） + 雷印锁敌（身份揭示兼爽点） + 计数推进（个人秀转消耗战）
- **本章核心技巧**：把身份底牌的揭示安排在对手冲锋的最近距离上，让亮牌本身就是一击，省掉单独的亮相环节。
- **卡点与伏笔**：结尾卡点：数据推进+快达到150人，下章期待更高层级对手与院方态度；埋设/回收伏笔：穆氏山庄旧战→莫凡雷系实力的旧证回收；79与80的报数→计数线的持续更新机制。
