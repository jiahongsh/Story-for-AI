# 第372章 护送完成

**概要**：翻过几座山，图腾珠生命能量将尽，唐月放蛇出珠：青黑雾气喷涌遮蔽视野，莫凡被冰凉蛇鳞推挤、吓奔上高岩，雾海中巨躯翻腾带来来自灵魂的冷意。雾散后蛇躯盘踞整片山头，唐月唤莫凡跳上蛇头，以"让大家伙请你过来"相胁；蛇吐信致谢，唐月笑言以后莫凡不听话就把大家伙放出来。摩天蛇碾山而行，将两人送抵白色巨山半山腰的千洞洞口——洞内如迷宫四通八达、贯穿地下世界。道别时唐月索要血液，蛇自咬躯体吸血一大口，实在得够泡浴缸；唐月解释蛇血里应有瘟疫源，带回或可提取血清。她决定让赶来的宫廷侍卫抓自己回去争取时间——瘟病多存在一分钟就可能多感染一人；莫凡哭笑不得担心公报私仇，最后点破悖论：血若起效，就证明蛇是瘟病来源，祝蒙他们更不会放过它。

**关键事件**：1.放蛇出珠、摩天蛇碾山抵千洞 2.蛇自咬献血一大口 3.唐月定下血清计划、决意让侍卫抓回 4.莫凡点破血清悖论

**逐章写法公式**：

- **情绪流向**：起：紧张（能量将尽放蛇） → 承：恐怖（雾海巨躯的灵魂冷意） → 转：温馨（蛇头致谢与献血） → 合：压抑（回城悖论）
- **节奏配比**：慢铺垫 50% / 快冲突 0% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：放蛇出珠（巨物登场） + 碾山入洞（护送终点） + 索血道别（任务转折） + 回城悖论（全局钩）
- **本章核心技巧**：护送完成的"到达"不写成句号，而用蛇的自伤献血与回城悖论把终点转成下一冲突的起点。
- **卡点与伏笔**：结尾卡点：悖论抉择型——血有效即证明蛇是瘟源、祝蒙更不会放过它，期待回城后的对峙；埋设/回收伏笔：蛇血血清→唐忠体液抗体承诺的回收线；白山千洞迷宫→摩天蛇的长期巢穴；让侍卫抓回去→下一章回城剧情。
