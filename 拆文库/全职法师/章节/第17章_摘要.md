# 第17章 美女老师的火系

**概要**：唐月在操场静立示范施法要领，强调静心、平和、专注，哪怕说话时精神也完全专注在火系星云（随即改口星尘）之中；无风的操场上她的发丝被热气掀动，随后以肃然口吻喝令「让星子听从你的指令」，火辣气息扑面，满脑子龌龊念头的男生们全部怔住。她提醒完成星子排列后不可松懈精神、须立刻锁定释放位置，随即念出「火滋·灼烧」，赤红星轨凝于右手，火焰如子弹贯穿人形木偶；木偶先是一秒无反应引学生质疑，唐月转身自信一笑，木偶体内猛然窜起疯狂火焰，不到2秒吞噬得一干二净。全班48人看呆，莫凡心脏砰跳，被唐月执掌火焰的自信与高贵彻底征服，对比连老头的死气沉沉。唐月随后点名班上火系学生：周敏率先站出并从排斥转为崇拜，黄飞峰幻想成为亲传弟子，水系的陆小斌嚎哭悔恨，口吃的赵大牛被赵坤三嘲讽数名字；唐月心中评估一个班才3个火系、似乎只有周敏天赋好些，此时莫凡走出人群报名火系。

**关键事件**：1.唐月完整演示火滋·灼烧，2秒焚尽人形木偶，全班看呆 2.莫凡被唐月力量气质征服 3.火系学生报名：周敏、黄飞峰、赵大牛 4.莫凡走出人群报名火系（章末卡点）

**逐章写法公式**：

- **情绪流向**：起：静立示范（专注） → 承：气息镇场（敬畏） → 转：木偶焚尽（震撼爆发） → 合：报名收尾（期待）
- **节奏配比**：慢铺垫 25% / 快冲突 10% / 爽点爆发 40% / 悬念留白 25%
- **本章结构公式**：要领讲授（教学铺垫） + 演示爆点（力量立威） + 心理征服（主角视角反应层） + 火系点名（群像+压轴卡点）
- **本章核心技巧**：用「命中后一秒沉寂再爆发」的延迟揭示把单次技能演示拆成两次情绪高点
- **卡点与伏笔**：结尾卡点：莫凡报出火系身份，下章期待唐月对莫凡的注意与众人的反应；埋设/回收伏笔：唐月口误「星云」 → 其真实修为远超初阶的暗线；唐月只认可周敏天赋 → 火系内的同学竞争参照；莫凡压轴报名 → 双系者进入导师视野
