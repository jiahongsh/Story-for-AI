# 第227章 被诅咒的许昭霆

**概要**：唐月来电告知黑教廷在魔都一带的行动全部冲莫凡而去，并解答他的疑惑：黑畜妖不是妖魔，而是灵魂被诅咒的活人，是黑教廷最可怕的秘术。莫凡说出许昭霆被抓，唐月称审判会不能大规模出动，以免把好不容易引入天罗地网的黑教廷团伙放跑。莫凡猛然想到许昭霆变成黑畜妖即意味着对方知道张璐璐住处，不顾市区禁召唤令急唤幽狼兽赶去。天台上张璐璐认出诅咒黑畜妖就是许昭霆，明白他此前一直在保护自己，长爪已贯穿她的身体，她反而不再恐惧；宇昂享受般施舍二人最后谈话时间后狂笑离去，许昭霆发狂咬断自己的手腕、撕皮断爪。莫凡赶到时张璐璐已死，守在尸体旁痛哭的许昭霆认出莫凡，划开腹部取出一块刻着名字的皮革交给他；唐月确认那是蓝衣执事掩人耳目的名字，由此有望顺藤找到红衣主教撒朗，对莫凡下手的主谋很可能是明珠学府学员。莫凡追问让许昭霆变回来的办法。

**关键事件**：1.唐月揭示黑畜妖是被诅咒的活人 2.张璐璐死于许昭霆爪下，许昭霆自残断腕 3.许昭霆从腹中取出刻着蓝衣执事名字的皮革交给莫凡

**逐章写法公式**：

- **情绪流向**：起：来电示警的凝重 → 承：赶赴夜奔的焦灼 → 转：天台认尸的悲恸 → 合：皮革名字点起的复仇火种
- **节奏配比**：慢铺垫 20 / 快冲突 15 / 爽点爆发 5 / 悬念留白 60
- **本章结构公式**：真相揭示（补世界观）+ 夜奔救人（迟一步）+ 双重悲剧（清算情感）+ 遗物递线索（转仇恨）
- **本章核心技巧**：让迟到成为最重的刑罚——主角全程在场却什么都没能阻止，把无力感直接转成下一卷的驱动力
- **卡点与伏笔**：结尾卡点：悬念——许昭霆还有没有变回人的办法；埋设/回收伏笔：黑畜妖是活人 → 回收全书黑畜妖设定；蓝衣执事名字 → 撒朗主谋线的钥匙；主谋藏于明珠学府 → 内奸线升级
