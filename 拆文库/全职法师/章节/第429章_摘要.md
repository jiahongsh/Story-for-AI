# 第429章 怪异体质

**概要**：魏荣拉下脸一声闭嘴压住全场抗议,发表讲话说他今天对火院很失望,挑战没有再进行下去的意义,若真有不满日后用正统方式堂堂正正挑战,自尊要靠双手拼出来,不少学员开始自行惭愧。白眉老师提醒莫凡身上的伤不轻,莫凡下场对萧院长嘀咕您老人家怎么这会才来,萧院长瞪他让他少惹点事。白眉老师检查后说莫凡火焰抗性强,体内残留火疾需相克药剂调理一周,又随口说他体质奇怪,被火焰灼伤的人伤势必然恶化,莫凡的伤处却在自行缓慢恢复,身体里有股暴躁因子,不像元素、白、次元魔法,倒很像黑魔法。莫凡想起自己曾获恶魔系力量,南方军部老法师都说残余消散得差不多,对白眉老师刮目相看。回公寓后艾图图兴奋崇拜地叽叽喳喳,牧奴娇埋怨他出风头,莫凡听着睡了过去。半夜醒来他到阳台喝果啤,感叹主校区前50、前10都是怪物,盘算要提升契约兽、雷系星云、暗影系和魔具。

**关键事件**：1.魏荣训话压住抗议,宣布挑战结束 2.白眉老师察觉莫凡体质怪异,伤处自行恢复,体内有近黑魔法的因子 3.莫凡回公寓反思实力差距,规划提升方向

- **情绪流向**：起：魏荣训话收场 → 承：白眉检查引出体质疑云 → 转：恶魔系痕迹悬念 → 合：深夜自省重启目标
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：魏荣训话压场(收束) + 白眉诊断体质(埋雷) + 恶魔系往事闪回(信息差) + 阳台自省列清单(蓄势)
