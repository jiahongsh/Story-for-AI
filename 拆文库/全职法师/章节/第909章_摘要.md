# 第909章 你这种垃圾

**概要**：毒母身带窟窿剑痕烧烂仍生猛，灵灵劝莫凡先撤，莫凡称一亿多赏金不让。柳茹实力比肩统领，给莫凡吟唱空间，再来天焰葬礼铺满坡殿。莫凡欲令柳茹控住打雷座之书穿脑，柳茹说控不住，此时破损殿外传来穆宁雪与灵灵之声——解药奏效。莫凡如释重负散去天焰葬礼，穆宁雪冰领域冻结全场、黑教徒成冰雕，毒母转杀穆宁雪却被风系飘行躲开。十秒后穆宁雪冻住毒母，莫凡雷束穿其面门，柳茹切丝留头，拽出活着的芳少俪，莫凡骂黑教廷剥皮不过垃圾。

**关键事件**：1.莫凡不舍赏金续战 2.柳茹控不住毒母 3.穆宁雪灵灵赶到 4.冰冻结毒母雷束穿脑 5.拽出芳少俪骂垃圾

- **情绪流向**：起：不舍赏金的硬 → 承：控不住的紧 → 转：同伴赶到安 → 合：冰雷终结的爽
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：不舍赏金（硬） + 控不住（紧） + 同伴至（安） + 冰雷终结（爽）
- **本章核心技巧**：用金钱动机串战斗，双线汇合后以配合技做终结
- **卡点与伏笔**：结尾卡点：芳少俪如何处置，下章揭晓；伏笔：雷座之书五张 → 资源有限
