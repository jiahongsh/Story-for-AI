# 第420章 大战火院（下）

**概要**：赛台下的郑佳慧看莫凡连败近三十人仍只用初阶魔法，对原以为靠小手段避战的他彻底改观，却又摇头不信谁能独抗两百名挑战者。贾振龙败后挑战重回单方面碾压，魏荣念名单都已心不在焉。忽然全场欢呼——第331名的许鸿光隐藏了实力，靠身上的铠魔具完美挡下莫凡的初阶魔法、连中阶烈拳都大打折扣，硬是逼出了莫凡的中阶魔法，虽然终败却让全院振奋。白眉好气又好笑骂这群没出息的东西把逼出一个中阶魔法当大获全胜，魏荣笑容也随之消失：出动三十六名挑战者才做到这一步实在丢人。黄星丽气得立场摇摆，被丁雨眠点破后支支吾吾，刘黔出面用火院颜面论替她解围，黄星丽暗喜院草在意自己。排名靠后的挑战者心态已从狠教训变成能消耗多少是多少。第190名的高挑女学员登场，莫凡本以竹竿身材轻视她，交手才知其火系修为与自己相差无几、还持有附带持续灼烧的上乘火系灵种，只得动用四级雷印铺开群体麻痹的雷电力场，依仗雷系霸道威力艰难击败她并耗费大量魔能。魏荣错愕于"双灵种"，白眉总结：雷火双修、双灵种、双四级初阶魔法，之后没有双灵种的挑战者未必敌得过他。

**关键事件**：1.许鸿光逼出莫凡中阶魔法后终败 2.黄星丽立场摇摆被点破、刘黔解围 3.第190名女学员逼出四级雷印力场 4.白眉断言无双灵种者难敌莫凡

**逐章写法公式**：

- **情绪流向**：起：爽（碾压继续） → 承：紧张（许鸿光逼出中阶） → 转：轻松（看台口水战） → 合：热血（190名硬仗+双灵种曝光）
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：小波折（许鸿光逼牌）+ 看台戏（立场与颜面论）+ 硬仗登场（190名女学员）+ 底牌收拢（白眉定调）
- **本章核心技巧**：在长篇连战里用"逼出一个中阶魔法"当里程碑调节爽感节奏，再用看台三角对话换气口，最后用强敌收束拔高
- **卡点与伏笔**：结尾卡点：战力悬念——白眉断言无双灵种者未必能敌，期待前五十名与东方烈级怪胎下场；埋设/回收伏笔：郑佳慧重新评估莫凡 → 其态度转变线；黄星丽对刘黔的暗喜 → 感情支线；莫凡雷系霸道+大量魔能消耗 → 魔能耗尽危机临近；双灵种曝光 → 全院认知刷新
