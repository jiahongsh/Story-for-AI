# 第850章 一人来踢馆

**概要**：上海浦东机场，埃及十人队伍走出国际到达，领队赛义德摘下墨镜、酒窝明显，被路过女留学生议论帅气，他凭法师听力全听见却只觉有趣。米奥斯询问中国实力，赛义德称派自己为代表去拿国馆之章，其余人另有要事，并点出真正目的在次日飞往古都西安。他独闯中国国馆，军装守卫起初当游客驱赶，赛义德亮出国际身份勋章表明是来挑战，守卫带他入馆。赛义德见国馆三大足球场合、四地形、半球天顶，嘴上赞恢弘却内心认定花哨无意义，得知馆内正有学府学员小比试也不屑观看，催着军哥直接带他去见教员。

**关键事件**：1.埃及队抵沪，赛义德为代表人 2.真正目的在古都西安 3.赛义德独闯国馆亮勋章 4.不屑学员比试，催见教员

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |

**逐章写法公式**：

- **情绪流向**：起：机场登场立狂妄 → 承：点出西安真目的 → 转：独闯国馆亮勋章 → 合：不屑比试催见教员
- **节奏配比**：慢铺垫 50% / 快冲突 10% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：机场登场（立人） + 西安目的（伏笔） + 闯馆亮章（推进） + 催见教员（钩子）
- **本章核心技巧**：用路人反应与内心独白双管齐下，快速立住反派"狂而强"的形象
- **卡点与伏笔**：结尾卡点：赛义德要见国馆教员开打，下章期待国馆如何应对一人踢馆；埋设/回收伏笔：飞往古都西安 → 后续黑教廷/撒朗线的伏笔
