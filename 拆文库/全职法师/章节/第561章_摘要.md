# 第561章 变种亡灵

**概要**：村长谢桑来苏小洛家取药，夸她接替关大叔撑起村中医术，也看出福大不是失忆便是痴傻。屋外谢大婶惊叫报信：村口有亡灵袭击，守村老头被活活吃掉。苏小洛披上蓑衣赶到村口，见血液混雨成溪，腐尸正啃食老人，村民持锄不敢近前。村民称守村老头喝了昆井井水仍遭攻击，断言这是变种亡灵，更有人惊恐历数一周前老贺、三天前一村民接连惨死，断言华村遭了诅咒。腐尸又扑向挥镰刀的青年村民一口咬开他的喉咙，苏小洛奔向灰木闸口想放闸挡尸，腐尸甩开猎物转而扑向她。危急关头洪俊以火滋爆裂轰飞腐尸，救下苏小洛，并傲气自夸一只腐尸他一个人能对付。

**关键事件**：1.村口守村老头被腐尸吃掉 2.变种亡灵与诅咒传言四起 3.洪俊火滋救下苏小洛

**逐章写法公式**：

- **情绪流向**：起：村中日常取药 → 承：惊叫报信村口惨案 → 转：腐尸扑向苏小洛 → 合：洪俊火滋救场
- **节奏配比**：慢铺垫 25% / 快冲突 45% / 爽点爆发 15% / 悬念留白 15%
- **本章结构公式**：谢桑取药日常（村内生态）+ 报信村口惨案（危机导入）+ 腐尸连杀两人（恐怖加码）+ 洪俊火滋救场（小高潮）
- **本章核心技巧**：用村民视角的恐慌对话代替旁白渲染灾变，再让新角色救场立人设。
- **卡点与伏笔**：结尾卡点：洪俊自夸一人能对付腐尸；埋设/回收伏笔：变种亡灵与诅咒 → 村灭之兆；福大头伤失忆 → 身份线
