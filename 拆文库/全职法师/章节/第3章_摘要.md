# 第3章 开学大典

**概要**：莫凡满脑子都是穆贺"连一个初阶魔法师都成为不了"的话，暗骂老子呵呵你一脸。莫家兴谎称托了当教导处主任的老朋友关系解决入学，已知真相的莫凡装出笑脸陪父亲庆祝；晚酒时莫家兴宣布要把家租出去补贴生活、让莫凡住校，心夏住姨姨家，莫凡看着父亲摇晃离去的背影想起朱自清的文章，明白这个中年人可能已无处可住却没有说穿，只立誓最多三年、等魔法大成就什么都会有。暑假两个月莫凡泡进天澜魔法高中图书馆，把九年义务魔法教育内容基本掌握。九月一号开学即觉醒日，图书馆总管理顾老头祝他觉醒火炎系；莫凡被分进高一8班、学号48全班垫底，1号正是穆氏旁系小少爷穆白。开学大典上一千五百名新生列队，老校长训话魔法师以探索人类发展、守护人类为使命，城市之外有无数妖魔虎视眈眈，随后宣布觉醒开始。

**关键事件**：1.莫家兴用"老朋友"谎言掩饰买学籍真相，卖房供莫凡入学，莫凡看穿不说穿 2.莫凡暑期啃完图书馆，从魔法盲补完九年义务教育内容 3.开学大典召开，校长训话后全校觉醒仪式开启

**逐章写法公式**：

- **情绪流向**：起：被话语刺痛的憋屈 → 承：父子谎言晚酒的酸楚温馨 → 转：图书馆苦读的踏实 → 合：大典开幕的期待
- **节奏配比**：慢铺垫 60% / 快冲突 5% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：真相刺痛（立愤）+ 谎言晚酒（立父子情）+ 三年之誓（立目标）+ 啃图书馆（补设定）+ 大典开幕（开启觉醒线）
- **本章核心技巧**：用"父亲的谎言+儿子看穿不说穿"双向隐瞒写父子情，情绪全压在白描动作与心理留白里
- **卡点与伏笔**：结尾卡点：期待型——觉醒开始，莫凡这个走后门的学渣会觉醒什么系；埋设/回收伏笔：心夏住姨姨家→叶心夏线；穆白1号同班→同班对头线；"城市之外无数妖魔虎视眈眈"→妖魔世界观主线；顾老头火炎系祝词→下一章觉醒方向的隐性误导
