# 第633章 血腥红骷髅！

**概要**：莫凡再次施展第四级烈拳，女执事因重伤无法完成高阶冰系星座，只能命令剩余五名黑衣教士共同出手。黑衣教士刚开始描画星图，方谷的暗红色钢铁骷髅突然出现，先后捏爆、撕裂并洞穿三名教士。两名剩余教士调来诅咒畜妖围攻，钢铁骷髅以蛮力将两只诅咒畜妖砸在一起，再用骨锤反复轰击，把它们砸成肉酱。两名教士意识到要逃跑时，骨锤已经从身后罩下。

**关键事件**：1.女执事第二次被烈拳压制 2.五名黑衣教士被迫出手 3.方谷钢铁骷髅现身 4.钢铁骷髅连续杀死三名教士 5.钢铁骷髅砸死两只诅咒畜妖

**逐章写法公式**：

- **情绪流向**：起：女执事挣扎 → 承：黑衣教士被迫上阵 → 转：红骷髅突袭屠杀 → 合：精英敌人被砸成肉酱，逃跑也被截断
- **节奏配比**：慢铺垫 10% / 快冲突 25% / 爽点爆发 55% / 悬念留白 10%
- **本章结构公式**：烈拳压制（延续胜势） + 教士集体施法（制造阻碍） + 钢铁骷髅突袭（打断施法） + 骨锤清场（完成碾压）
- **本章核心技巧**：用突然出现的第三方战力切断敌方蓄力，再通过连续具体动作完成一轮高密度清场。
- **卡点与伏笔**：结尾卡点：剩余教士刚意识到逃跑，骨锤已从身后罩来；埋设/回收伏笔：方谷“亡灵就是村民” → 暗红色钢铁骷髅成为保护亡灵村民的战力。
