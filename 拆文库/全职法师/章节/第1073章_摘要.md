# 第1073章 空间传送大阵

**概要**：莫凡到庞莱住所道谢，江昱敲门时屋内却传来庞莱严厉之声，二人便在院中闲谈夺宝赛。屋内，庞莱正对脸上长疤的老者埃森德尔冷峻相劝，要其向圣裁院自首，埃森德尔却涌起黑暗气息化黑龙天牢将庞莱锁住、未容其施法。院中的莫凡忽感屋内凛冽黑暗之风如黑暗之王降临，疤老者漠然离去后，江昱冲进屋见庞莱被黑暗禁锢、吃瘪咳嗽。夺宝赛开幕当天，国际新闻爆出黑暗之尊埃森德尔被判有罪、圣裁院缉拿，莫凡才知禁锢庞莱者正是他，而自己身上的暗爵斗篷恰是埃森德尔所赠。夺宝赛因此推迟两天，集合场上摆开银色魔石空间魔法大阵，主裁判宣读规则：一百六十名学员打乱落点进夺宝空间，遇险可灌满空间卷轴四秒返回。

**关键事件**：1.庞莱屋内密会埃森德尔反被黑暗禁锢 2.莫凡江昱发现庞莱吃瘪、不知老者身份 3.新闻爆埃森德尔通缉、暗爵斗篷是其赠 4.夺宝赛推迟两天 5.空间魔法阵与规则宣读

**逐章写法公式**：

- **情绪流向**：起：道谢闲谈的轻松 → 承：屋内密谈与黑暗禁锢的紧张 → 转：新闻揭身份反转 → 合：空间阵规则铺开期待
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：庞莱劝自首（冲突铺垫） + 埃森德尔反制锁庞莱（高潮） + 新闻反转揭身份（信息） + 空间阵宣规则（舞台）

- **卡点与伏笔**：结尾卡点：学员将入夺宝空间，下章期待莫凡落点与遭遇；埋设/回收伏笔：暗爵斗篷 → 埃森德尔所赠回扣
