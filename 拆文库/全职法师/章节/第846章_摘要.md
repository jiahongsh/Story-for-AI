# 第846章 接大单子！

**概要**：莫凡返回上海神清气爽，回到空荡荡的公寓，幻想牧奴娇与艾图图，翻看她们闺房小衣物热血沸腾，规划买下房子养两只金丝雀。门铃响起猫眼里却看不见人，开门竟是逃课来看他的灵灵，她说手提电脑告知莫凡回国。莫凡本想借机跟灵灵谈凝华邪珠（红魔）之事，见她正为初一生活厌烦，便改口先不提，打算去问包老头和冷青。莫凡转而问灵灵有没有大单子缺钱用，灵灵说有个价值比几千万更高的超级大单，一般需一整团完成，若加战斗力爆表的穆宁雪冒险可行，并让莫凡先去把高级猎人升级成猎人大师，因积分已够，称谓越高能接悬赏越大。

**关键事件**：1.莫凡回上海公寓，意淫两女又见空房 2.灵灵逃课来访，莫凡暂压红魔话题 3.莫凡问大单子，灵灵抛超级悬赏 4.灵灵要莫凡先升猎人大师

**逐章写法公式**：

- **情绪流向**：起：莫凡回公寓意淫 → 承：灵灵突访转温馨 → 转：压住红魔改谈生意 → 合：超级大单+升级钩子
- **节奏配比**：慢铺垫 40% / 快冲突 0% / 爽点爆发 20% / 悬念留白 40%
- **本章结构公式**：回公寓（日常） + 灵灵来访（重逢） + 压红魔（伏笔） + 抛大单（推进）
- **本章核心技巧**：用日常轻松桥段过渡，把重大伏笔（红魔、超级悬赏）藏在对话里延迟释放
