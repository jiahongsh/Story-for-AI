# 第852章 埃及亡灵系

**概要**：赛义德坚持要先定规则，怕打赢不被认数，白东威骂他欠扁却被反幽默一句"谢谢"噎住，最终同意规则由赛义德开。赛义德开出自坐擂台、给对方三个名额的狂妄条件，牧奴娇拉住白东威分析对方可能擅长群战，另一守馆人提醒怕被激将让东方烈单挑白送章，白东威冷静后咬牙认了"三个就三个"。东方烈主修火系、明珠学府前五，却在大提名之争败给入国府的黎凯风。开打后东方烈谨慎不动，白东威急催抢先，赛义德却已完成魔法——星轨透出邪气血戾如撕开墓穴，白东威一眼看破：亡灵系！那浊气盘绕、黑井通地下的诡异亡灵之息，让全场发寒。

**关键事件**：1.定规则：三名额坐擂 2.牧奴娇等劝白东威莫中计 3.东方烈出战谨慎，赛义德施亡灵魔法 4.白东威看破亡灵系

**逐章写法公式**：

- **情绪流向**：起：规则拉扯 → 承：配角劝谏定三名额 → 转：东方烈谨慎不出手 → 合：亡灵系揭幕发寒
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：规则谈判（博弈） + 劝谏定局（理智） + 东方烈备战（压抑） + 亡灵揭幕（反转）

- **卡点与伏笔**：结尾卡点：亡灵之息弥漫，下章期待灰布铁尸如何碾压东方烈；埋设/回收伏笔：亡灵系稀有 → 后续国馆装备（星云魔器靠进口）的伏笔
