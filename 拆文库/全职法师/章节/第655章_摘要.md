# 第655章 冲向煞渊！

**概要**：耀庭让空间罗盘的银色节点交错成覆盖山峰之尸的罗盘，黑色死轴贯穿其喉咙和胸骨，令这只亡灵霸主停滞并喷出大量鲜血。祝蒙随即以九柄雷神戟组成雷电禁阵，其他超阶法师也开始构建星宫，暂时困住山峰之尸。韩寂抓住机会命令方阵冲向煞渊，左锋报告前方六百米有尸将和尸臣阻路。韩寂在风舟上完成植物系高阶魔法，种子化作吞噬腐尸的黑色巨花，一口吞下数百亡灵，为队伍继续开路。

**关键事件**：1.空间罗盘死轴贯穿山峰之尸 2.祝蒙用雷神戟禁锢山峰之尸 3.超阶法师继续牵制 4.韩寂命令队伍冲向煞渊 5.枯荣巨花吞噬尸群

**逐章写法公式**：

- **情绪流向**：起：死轴命中 → 承：雷阵和星宫禁锢 → 转：队伍抓住窗口冲锋 → 合：巨花清除尸墙，继续逼近煞渊
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：死轴贯穿（制造伤口） + 雷戟禁锢（延长窗口） + 风舟冲锋（推进目标） + 枯荣巨花（清理阻路）
- **本章核心技巧**：把终极强敌的短暂硬直转化为全队移动时间，让单点爆发和群体推进形成因果链。
- **卡点与伏笔**：结尾卡点：前方尸将尸臣密集但韩寂已用巨花打开缺口；埋设/回收伏笔：耀庭的空间波颤判断 → 为死轴的精准命中提供前置技术依据。
