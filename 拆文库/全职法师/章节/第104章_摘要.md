# 第104章 我想要变强

**概要**：爆裂火浪轰断幽狼兽上下颚骨，余焰霸道冲入食道填满腹部，巨响中凶猛幽狼兽彻底变成火烤死物倒在白阳面前。白阳狞笑僵住、阴沉可怕，承认莫凡与见妖魔腿软的学生确实不同、不比老猎法师差，但仍要他死，还说尸体正好喂养下一只召唤兽；他心知将火滋塞入狼口瞬间爆死的手法远超一般学生，但比起拿下地圣泉后的地位，幽狼兽死了就死了。他命令两只黑畜妖杀莫凡——它们比幽狼兽灵活，能跳上车顶、以车为掩护连续变位，还懂得协同分立两侧，令失去骨镰盾、只够连一道星轨的莫凡陷入绝境，只来得及凝聚火滋。危急时穆白喊薛木生释放光耀，薛木生见他掌心凝聚星辰之蓝的光辉当即配合；光耀·失明的强光令白阳不屑——黑畜妖虽是黑暗生物却没有眼睛，不受失明影响。但一声"乌冰斩"从他后方响起，乌黑冰剑无视挡路的汽车生生将其连车斩成两段，白阳左肩脖颈以上被彻底切开，切口冻结寒霜、血一滴未流，倒地面容定格在不敢置信中。随主人死亡，两只黑畜妖像被扼住咽喉般原地扭动融化，五秒内化为冒泡的黑脓水；薛木生擦汗解释黑畜妖与主人灵魂相连。众人看着尸体满脸疲倦，经历教官叛变后对人性有了重新定义。穆白苦笑道出叔叔送的十八岁生日礼物斩魔具总算派上用场——这昂贵到连魔法师都买不起的进攻魔具救了全队。

**关键事件**：1.莫凡火滋爆裂轰杀幽狼兽 2.穆白以叔叔所赠斩魔具乌冰斩一击斩杀叛徒白阳 3.黑畜妖随主人灵魂死亡尽数融化，桥上危机解除

**逐章写法公式**：

- **情绪流向**：起：爽（轰杀幽狼兽） → 承：紧张（双畜夹击绝境） → 转：爽（乌冰斩秒杀白阳） → 合：压抑（众人疲倦与对人性的重新定义）
- **节奏配比**：慢铺垫 15% / 快冲突 35% / 爽点爆发 35% / 悬念留白 15%
- **本章结构公式**：狼口爆杀（收上章战果）+双畜绝境（加压）+光耀声东冰斩击西（翻转击杀）+灵魂连结消畜（解压）+人性余震（余波）
- **本章核心技巧**：用假动作配合完成击杀——光耀·失明看似无效却骗走反派全部注意力，真杀招乌冰斩从背后无声落刀；再借灵魂连结设定一笔清算所有召唤兽，把长战斗快速收束。
- **卡点与伏笔**：结尾卡点：余波悬念——何雨生死未明、地圣泉仍在莫凡身上、黑教廷全城搜捕未解；埋设伏笔：穆白叔叔的十八岁生日斩魔具→穆白家族背景线开启；黑畜妖灵魂连结设定→黑教廷爪牙的作战机制；白阳之死→他口中的红衣执事接头中断、线索断在桥上。
