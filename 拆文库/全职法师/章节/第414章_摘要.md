# 第414章 挑战之周

**概要**：郑佳慧不敢相信莫凡真会把宝贵的星云魔器借给自己，只当玩笑要走，莫凡点破他的病根：一千名后的学员实力半斤八两，他的倒数第一多半是一面对挑战就哆嗦得忘了星轨怎么描绘，随即直接把第一百名专属的星云魔器塞进他手里，郑佳慧当场愣住。挑战之周到来，火院全员聚集大学堂，众人意外莫凡竟敢露面；他依旧坐在黄星丽和丁雨眠后座，仍未见到火系女神正脸。黄星丽警告他排名低于他的人今天都能挑战、拒绝则资源拱手相让，莫凡只调侃她第二次见面就这么关心自己。比赛移师千人比试场，火院占大半、其他院系慕名而来，上月想借挑战博声望的世家子弟风头全被抢光。魏荣亲自主持，宣布莫凡今天的挑战人数达231人，抛出道歉写检讨、挨个低头认错就放过他的条件，被莫凡一句"不需要"回绝。第一位挑战者、排名第736的张佑赫登台叫嚣让他交出资源省医药费，魏荣也放话莫凡若赢不了就滚出火院，莫凡笑答这话太早。白眉老师劝魏荣别与学生怄气，魏荣嘴上说这是磨砺心性、免得他日后死在妖魔手上，实则不过是想出一口被辱骂的恶气。

**关键事件**：1.莫凡把星云魔器塞给郑佳慧 2.挑战之周开启、231人排队挑战莫凡 3.魏荣抛出道歉换放过条件被拒 4.首位挑战者张佑赫登台

**逐章写法公式**：

- **情绪流向**：起：温馨（赠器收心） → 承：紧张（挑战之周降临） → 转：压抑（231人与魏荣施压） → 合：热血（莫凡笑答太早了）
- **节奏配比**：慢铺垫 35% / 快冲突 35% / 爽点爆发 5% / 悬念留白 25%
- **本章结构公式**：赠器结盟（完成郑佳慧交易）+ 大会聚集（交代规则与席位）+ 宣战压人（231人+道歉条件）+ 首战开局（张佑赫登台）
- **本章核心技巧**：用天文数字的挑战人数和满场观战把"围攻"渲染成公共处刑式大场面，再让主角一句轻描淡写的话对冲压力
- **卡点与伏笔**：结尾卡点：首战开打在即——张佑赫已叫嚣、莫凡评价对付起来应该不太困难，期待连扫231人；埋设/回收伏笔：星云魔器借出 → 郑佳慧之战伏笔；丁雨眠正脸未露 → 女神真容悬念；萧院长办转系的背景说 → 魏荣忌惮与莫凡后台线；魏荣出恶气 → 师生梁子加深
