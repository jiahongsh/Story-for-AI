# 第568章 亡灵少年

**概要**：莫凡强行控制住局面时村民已死约一半，他怨村民不听嘱咐乱跑才送命，一个魔法本可灭掉一片亡灵。张小侯用岩系造出七八米高的岩石圈护住村民，谢桑与矮男在壁障上方轰击攀爬的鬼尸。柳茹冲出圈外救回乱跑的狗子，又去救一名腿被鬼尸撕开的少年，狗子却脸色大变，颤抖着指出这少年不是本村人。少年露诡笑，用白骨手掌刺穿柳茹心脏，可柳茹因血族体质毫发无损，先扼住喉咙拧断其脖子，少年顺势装死，柳茹笑说没听过拧断脖子便死掉的亡灵，再以血族之爪从头盖骨贯穿脑部，粉碎维持亡灵行动的亡灵结晶，少年五孔飘出黑气，几秒变成干尸。狗子目睹柳茹被穿心仍反杀的全过程，僵在原地内心崩溃。

**关键事件**：1.突袭过后村民死约一半，张小侯岩圈护住幸存者 2.伪装活人的亡灵少年刺穿柳茹心脏，反被血族体质的柳茹反杀 3.柳茹粉碎亡灵少年的亡灵结晶，揭示亡灵结晶设定

**逐章写法公式**：

- **情绪流向**：起：危急（突围救人） → 承：得救（柳茹救少年） → 转：反杀（伪装偷袭被反杀） → 合：余悸（狗子崩溃）
- **节奏配比**：慢铺垫 30% / 快冲突 50% / 爽点爆发 10% / 悬念留白 10%
- **本章结构公式**：圈外救人（建立信任） + 少年偷袭（反转绝境） + 血族反杀（身份揭示） + 狗子视角（余波）
- **本章核心技巧**：用假死到真死的连续反转撑住单场戏，拿旁观者反应当情绪标尺
- **卡点与伏笔**：结尾卡点：栩栩如生的活死人亡灵从何而来，下章期待莫凡的反应与追查；埋设/回收伏笔：柳茹血族身份在人群面前暴露的隐患
