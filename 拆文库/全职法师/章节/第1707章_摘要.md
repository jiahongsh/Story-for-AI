# 第1707章 卢岭裂谷

**概要**：被血洗激怒的巡山羽妖疯狂撕毁帘叶帐，队伍无处躲藏只得暴露在娑风之下。张小侯强硬反对李德鑫的莽撞赶路，提出改走卢岭裂谷，许参谋担心耗时三天误了救援军司公子的时间，凌菲表态支持后李德鑫才勉强让步。途中木炭脸军人向赵满延求助止血，闹出一段笑话。莫凡向张小侯打听得知紫禁军要去的百拔山正挨着誓言树所在，阿帕丝留下一句"他们很焦虑"的含混提示。

**关键事件**：1.张小侯与李德鑫因前行路线爆发争执 2.队伍决定改走卢岭裂谷 3.木炭脸军人求赵满延止血闹出笑话 4.阿帕丝丢下"他们很焦虑"的悬念提示

**逐章写法公式**：

- **情绪流向**：起：压抑 → 承：争执加压 → 转：路线拍板 → 合：悬念留白
- **节奏配比**：慢铺垫 40% / 快冲突 35% / 爽点爆发 5% / 悬念留白 20%
- **本章结构公式**：妖魔逼迫队伍（制造绝境）+ 内部路线争执（放大矛盾）+ 凌菲拍板走裂谷（解决争执）+ 阿帕丝一句提示（埋设悬念）
- **本章核心技巧**：用外部妖魔压力逼出内部争执，再用第三方调停收束，末尾以一句含混台词埋钩。
- **卡点与伏笔**：结尾卡点：信息揭示型——阿帕丝"他们很焦虑"暗示紫禁军此行另有隐情，下章期待：裂谷途中揭示救援真相；埋设/回收伏笔：百拔山与誓言树同址、紫禁军救援对象身份 → 引出后文蒋少絮重逢与伐树行动
