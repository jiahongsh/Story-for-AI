# 第266章 强化幽狼兽（上）

**概要**：切磋结束后陆正河放话下次要让莫凡好看，卢一鸣感慨小看了明珠学府，并点明接下来最重要的是历练——大学历练直接把学员派到安界之外，无老师跟随、无猎人保护，死亡在所难免。战平消息传回母校，萧院长与周正华欣慰把莫凡塞到帝都立竿见影，莫凡天生双系之名传遍全国高校，掀起天赋排行：他的天生双系排第五，穆宁雪的天生灵种排第九。李静老师宣布历练没有任何保护措施，仅发放光魔法信号笔且救援前提是活着；顾翰、秋雨华严肃告诫往年有死伤。距历练还有五天，莫凡决定用这段时间强化幽狼兽——它在切磋中被战将级幽纹暴狼完爆、骨子里的骄傲被践踏，莫凡要助已入进阶期近一年的它晋升战将级，也让仗着战将生物趾高气昂的陆正河拽不起来。

**关键事件**：1.战平消息传回母校，莫凡天生双系跃升全国话题人物、天赋榜第五 2.导师宣布历练无保护、仅发光魔法信号笔，往年有死伤 3.莫凡决定用五天准备期助受挫的幽狼兽晋升战将级

**逐章写法公式**：

- **情绪流向**：起：轻松（胜后扬名）→ 承：压抑（历练死亡警告）→ 转：热血（强化幽狼兽的决定）→ 合：轻松（憋着打脸陆正河的劲）
- **节奏配比**：慢铺垫 50% / 快冲突 10% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：胜后余波（立势）+ 天赋榜话题（抬咖）+ 历练死亡警告（加压）+ 强化幽狼兽决定（立新目标）
- **本章核心技巧**：用"扬名"与"死亡警告"一抬一压完成过渡，再把新目标接在压力与屈辱上，过渡章不空转
- **卡点与伏笔**：结尾卡点：五天准备期+幽狼兽能否进阶战将级→期待强化过程；埋设伏笔：光魔法信号笔、天赋榜前四的存在、历练方向未公布
