# 第840章 莫凡后头的大人物

**概要**：赵满延向莫凡科普队友背景：艾江图代表北军部、南珏代表西军部，南军部那人因名额所限被刷；蒋少絮身份神秘连他都查不清，必大有来头；南荣倪出自最古老魔法世家之一，凭治愈系全国稀缺稳居不被淘汰，南荣世家靠她逆袭。赵满延还厘清世家（国内超大企业）与世族（国际超级家族）之别，笑莫凡劝南荣倪退让纯属傻气。他警告莫凡别恃实力浪，越往后势力越疯砸资源，星河之脉魔具魂种如流水，届时天赋修为皆虚。莫凡称自己单干惯了、不喜被包养，赵满延倒赞白手起家者方能称霸。话题转到"你后头的大人物"——赵满延咆哮莫凡被直接塞进国府队、其他势力竟无二话，罩他者只手遮半边天。莫凡只知韩寂叫自己来的，赵满延判断另有护国法师级人物因古都经历看好他、却不愿打破其野生长方式，并追问古都火魔神真相，莫凡以"在秦始皇陵墓没见到"机智搪塞。

**关键事件**：1.赵满延揭艾江图/南珏/蒋少絮/南荣倪背景 2.世家世族之别、劝莫凡找靠山 3.莫凡单干论、赵满延赞白手起家 4.莫凡后头大人物、古都火魔神之谜

**逐章写法公式**：

- **情绪流向**：起：背景科普的惊 → 承：势力警告的紧 → 转：单干之争的燃 → 合：大人物+古都谜的悬
- **节奏配比**：慢铺垫 20% / 快冲突 0% / 爽点爆发 5% / 悬念留白 30% / 信息 45%
- **本章结构公式**：背景揭底（惊） + 势力警告（紧） + 单干之争（燃） + 大人物谜（悬）
- **本章核心技巧**：用活宝当"设定播音员"把群像背景、势力逻辑、主角隐藏后台一气抖出。
