# 第917章 有人送钱！

**概要**：米奥斯从昏迷中醒来便歇斯底里要宰了莫凡，觉被干净利落击败比死还难受。赛义德劝她莫凡终会出现在世界学府之争大赛上，到时有全世界瞩目的报仇机会，且众人尚未真正发力，米奥斯情绪稍平，决定立刻回电开罗让古王室多给自己弄资源。埃及队被撵走后中国国馆一片欢呼，白东威暗喜国馆或成挑战失败率最高的地方。此后小国陆续来挑战，莫凡常不用出手。莫凡清楚自己目的在提升实力，扫荡黑教廷分会一月后大笔赏金到账、手机被银行打爆，他购星河之脉欲升暗影系高阶并投三千万补空间系，进三步塔修炼却晋级失败，仅冲开壁垒裂口。柳茹带来好消息：崇明岛牧场庄园主人被审判会盘查，地皮归第二控股人血族匹诺克，匹诺克愿付股份孝敬莫凡以免盘查。莫凡让冷青确认其与黑教廷无瓜葛后收下，匹诺克获释后知莫凡晋级失败，又送上一枚高质量星河之脉，柳茹说往后小血族的孝敬费都打进莫凡账户。

**关键事件**：1.米奥斯败后暴走，赛义德劝其留待国府赛报仇 2.莫凡购星河之脉冲击暗影系高阶失败 3.血族匹诺克献股份与星河之脉，莫凡获持续财源

**逐章写法公式**：

- **情绪流向**：起：米奥斯暴走的余怒 → 承：莫凡资源到账的期待 → 转：晋级失败的小失落 → 合：血族送钱的新爽点
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 30% / 悬念留白 25%
- **本章结构公式**：米奥斯败后立仇（延续）+ 莫凡进补失败（挫折）+ 柳茹牵线血族（转机）+ 匹诺克献星河之脉（收财）
- **本章核心技巧**：用“仇家线”与“财源线”双线并收，让单场胜利同时结仇与得利
- **卡点与伏笔**：结尾卡点：柳茹说孝敬费持续进账，下章期待莫凡如何充填珠子与提升；埋设/回收伏笔：星河之脉晋级失败 → 后续暗影系高阶的待补线
