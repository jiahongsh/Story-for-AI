# 第967章 比怪物还怪物

**概要**：劳伦市长匆匆赶来，震惊地看到不可一世的卡索被困光之牢笼、满身伤痕颓败如囚徒。奥露娜按下录音笔，放出卡索与手下坦言无心对付海妖、捞钱即走的对话，劝诫市长与盗匪合作只会失去民心，海妖之难仍可众志成城。劳伦决定重新下令铲除红饰余党，奥露娜承诺自由神殿派实习法师协助、猎人亦会帮忙。卡索被擒轰动加勒比，猎人蜂拥缉拿余党；香草小寨村民归寨，贾妮激动落泪，因莫凡未回领情而内疚。莫凡因卡索被神殿拿下而失了悬赏金，但奥露娜如实发函令中国方在国府竞争中胜出，暗爵斗篷将分配给他。过加勒比后抵北美，蒋少絮追问莫凡上香草小寨的缘由，方知是凝华邪珠示警却白高兴一场；众人议论队内将淘汰一人，黎凯风或因无宝器出局。抵达墨西哥邦尔萨城，导师将带人走人，莫凡期待与穆宁雪相见；最终导师令六人队内决斗定淘汰，莫凡不在列，众评其"比怪物还怪物"。

**关键事件**：1.奥露娜以录音笔揭卡索真面目，劝服市长铲除余党 2.红饰覆灭轰动加勒比，香草小寨重生 3.莫凡失悬赏金却凭信函获暗爵斗篷 4.凝华邪珠误会，队内淘汰悬念 5.队内决斗莫凡豁免，获"比怪物还怪物"评价

**逐章写法公式**：

- **情绪流向**：起：市长震惊的错愕 → 承：录音揭伪的澄清 → 转：红饰覆灭连锁爽 → 合：暗爵斗篷与决斗豁免的期待
- **节奏配比**：慢铺垫 25% / 快冲突 10% / 爽点爆发 35% / 悬念留白 30%
- **本章结构公式**：录音笔揭卡索（坐实） + 红饰覆灭铺红利（放大） + 暗爵斗篷奖赏（兑现） + 决斗豁免立威（钩子）
- **本章核心技巧**：用反派自己的录音原话坐实恶行，再以群像红利把单场胜利扩成局面胜利
- **卡点与伏笔**：结尾卡点：评价型，莫凡获"比怪物还怪物"称号，下章期待暗爵斗篷到手与队内决斗结果；埋设/回收伏笔：凝华邪珠 → 回收上章莫凡上小寨的动因；暗爵斗篷 → 新装备伏笔
