# 第448章 再敢动她一下试试

**概要**：聂东怒吼柳茹不懂用自己的能力，操纵悬浮鲜血化成长柄血鬼镰横扫，立柱尽断，镰刃从柳茹细腰扫过将她整个人带飞撞穿装潢墙。他咬牙惊疑：血镰舞连战将级生物不防备都能斩杀，却没能拦腰斩断柳茹只将她扫飞，她的体质防御极强，他开始怀疑她究竟是不是血族。柳茹从狼藉中爬起——就是这吸血鬼杀了她相依为命的姐姐，还把她变成吸血鬼，让她再也无法面对刚喜欢上、给晦暗生活带来希望的莫凡；她挤不出眼泪、眼中却慢慢溢血，没自杀只因为要先杀了毁掉自己一切的仇人。她无视腰伤再度扑上，黑影极速、爪芒凌乱，可聂东唤出大批夜刃蝙蝠缠住她、每掠过一次留一道浅伤，再用掌心黑色物质将她轰飞到楼层尽头。聂东提起爬不起身的柳茹，朝钢化玻璃墙反复猛砸——普通人早摔碎，她只是断了几根骨；柳茹体质越强他越愤怒。玻璃彻底碎裂、她险些坠楼之际，莫凡现身楼梯口，火焰之环收在右腕，一句「再敢动她一下试试」，烈拳化作几乎填满三米层高的火焰巨拳轰中毫无防备的聂东，将他带着满身火焰从四十层砸落街道，砸出一个坑。

**关键事件**：1.聂东血鬼镰扫飞柳茹，惊疑其体质 2.柳茹溢血复仇，被蝙蝠群与黑色物质压制 3.聂东反复把柳茹砸向玻璃墙 4.莫凡烈拳将聂东轰出四十层高楼

**逐章写法公式**：

- **情绪流向**：起：紧张（血鬼镰扫飞柳茹） → 承：压抑（溢血独白、被虐砸墙） → 转：爽（莫凡烈拳轰人出楼） → 合：热血（反派燃火坠楼砸坑）
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 30% / 悬念留白 5%
- **本章结构公式**：反派重创柳茹（立力量差） + 复仇独白（给动机） + 三连施虐（压到谷底） + 烈拳救场（一拳翻盘）
- **本章核心技巧**：用「施虐长度」换「救援爽度」，把读者的愤怒攒满后在章尾一拳泄洪
- **卡点与伏笔**：结尾卡点：高潮开局——聂东被轰落街面生死未卜，下章待看地面决战；埋设/回收伏笔：柳茹体质强到血镰难伤、聂东怀疑其血统 → 再度强化「她吸了谁的血」之谜；聂东脖颈创伤血流不止 → 头颈藏血弱点的延续
