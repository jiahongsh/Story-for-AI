# 第946章 杀进去？？

**概要**：灵灵建议莫凡先实地验证象征物规律。夜里莫凡独入矿脉盆地，布下司夜统治将两百多只怪猿困于黑暗，无声清剿后发现一只金毛尾怪猿；验证杀掉象征物后，周边数百幻影怪猿如烟消散。灵灵说明这是古印第安召唤秘法，只对召唤位面生物有效，嘱莫凡保密。莫凡定下两人独闯矿洞之计。清晨众人集结，赵满延转达莫凡方案：正面佯攻吸引怪猿、二人后山闯入；莫特嘲讽两人不可能。艾江图同意配合佯攻。后山会合，赵满延回报莫特拒绝但艾江图已默认，莫凡起身"杀进去"。

**关键事件**：1.夜探矿脉验证金毛尾为象征物，杀之幻影消散 2.灵灵揭示古印第安召唤秘法并嘱保密 3.定下两人独闯+正面佯攻计划 4.莫特嘲讽、艾江图配合，莫凡决意杀入

- **情绪流向**：起：灵灵建议试错 → 承：夜战验证解谜 → 转：秘法揭示加压 → 合：疯狂计划遭嘲留钩
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：夜探布阵清剿（验谜） + 灵灵揭秘法（立规） + 定两人独闯（设局） + 佯攻遭嘲（加压）

- **卡点与伏笔**：结尾卡点：两人能否真的杀入矿洞留悬念；埋设/回收伏笔：金毛尾象征物→实战清剿；古印第安秘法→离梵后人身份
