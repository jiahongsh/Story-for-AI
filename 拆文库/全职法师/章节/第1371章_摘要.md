# 第1371章 胡夫金字塔

**概要**：胡夫金字塔的结论让屋里四人窒息沉默。那是足以吞噬半个埃及国度的巨型亡灵帝国、冥界最宏伟的宫殿，一旦被搬到中国国土，北原疆土将彻底沦陷。叶鸿自认做梦都不敢想这种事；超阶法师彬蔚也感到渺小不堪，胡夫金字塔卷起的亡灵之风能轻易把她撕成碎片；镇北关拼尽全力才勉强挡住一头冥君蛙，而冥君蛙相对胡夫无非是一只蛙形态的纤夫。灵灵率先清醒，提出最理智的方案——找到莫凡告诉他事实，然后立刻离开，抵抗等于死亡。张小侯恰在此时闯入，说他知道凡哥在哪里。灵灵坦承这一切只是推断、无法说服任何官方机构，但请众人相信事实必将发生。赵满延催促彬蔚叶鸿全城撤离，两人却以军人誓言与军令相拒——猎人商人民众可以走，军人不能走。赵满延情绪彻底失控，痛斥上头在遭遇冥君蛙时还调走精英队伍，彬蔚坚持会去说服上面，但未接命令绝不离开；叶鸿则承诺通知军伍之外的人撤离。赵满延懒得再争，带着灵灵张小侯动身寻找莫凡。

**关键事件**：1.胡夫金字塔将被搬到北原的结论令四人陷入绝望 2.灵灵做出撤离决定——找到莫凡告知真相后立刻离开 3.张小侯赶到，称知道莫凡下落 4.彬蔚叶鸿拒绝撤离，誓守镇北关

**逐章写法公式**：

- **情绪流向**：起：结论砸落的窒息 → 承：灵灵决断的冷醒 → 转：军令之争的撕裂 → 合：上路寻凡的决绝
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：胡夫之名的绝望（定基调）+ 灵灵的撤离方案（立决策）+ 军人誓守之争（起冲突）+ 上路寻凡（转行动）
- **本章核心技巧**：让灾难结论先压垮全员，再由最冷静的声音给出方案，用"理智派"与"责任派"的对撞把逃生戏写成道德难题
- **卡点与伏笔**：结尾卡点：行动式——赵满延三人上路寻莫凡，莫凡潜伏状态不明；埋设/回收伏笔：张小侯知道莫凡在哪 → 汇合后重启破局线索
