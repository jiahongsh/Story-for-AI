# 第802章 护送邪珠

**概要**：莫凡虽知红魔来历却不知其下落，名剑顺势委托他将凝华邪珠送往东京旧友处净化，并以可分得的塑魂之力助疾星狼进阶为条件。名剑称莫凡与一秋一样能在邪珠蛊惑下保持清醒，并透露那位旧友曾掌东守阁、是唯一知晓上一代红魔下落之人。莫凡答应护送，望月千熏随行。夜归后莫凡已怀揣银纱包裹的邪珠，赵满延敲门嚷着望月千熏将随队赴东京，莫凡以"遇到麻烦事"搪塞，未将邪珠危险告知同伴。

**关键事件**：1.名剑委托莫凡护送邪珠去东京净化 2.以塑魂之力为条件，莫凡答应 3.名剑透露旧友知其红魔下落 4.夜归赵满延报信，莫凡隐瞒危险

**逐章写法公式**：

- **情绪流向**：起：莫凡对红魔下落无着的郁闷 → 承：名剑委托与条件交换的拉扯 → 转：得知旧友知红魔下落而答应 → 合：夜归隐瞒同伴的钩子
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：名剑委托（递任务） + 条件交换接任务（驱动） + 旧友知红魔（加砝码） + 夜归隐瞒（埋隐患）
- **本章核心技巧**：用角色私人目标（疾星狼进阶）嵌套主线护送任务，再以信息差埋队伍不知情的隐患
- **卡点与伏笔**：结尾卡点：莫凡携珠赴东京，下章期待途中波折；埋设/回收伏笔：银纱包裹邪珠 → 后续被误认普通珠
