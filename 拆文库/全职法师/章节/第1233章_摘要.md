# 第1233章 月光下的大美女

**概要**：白鸿飞吸入夜花粉末昏睡倒地，无数飞蛾用身躯组成担架将他抬走，消失在月光里。莫凡与曹琴琴赶到青衣湖，找不到白鸿飞，只在草丛里发现一枚掩埋半露的校徽。莫凡把猎人大师勋章交给曹琴琴，让她去猎者联盟发布悬赏搜山，自己循着稀疏的荧光追入林中，在一条溪边撞见一位正在沐浴的乌发女子。月光下女子惊怒交加，莫凡连声道是误会。女子自称从小住在这带，指引莫凡去另一处寻找，莫凡放出烈霞之火时，女子眼中流露惧意，暗中遣散了伪装成树叶的飞蛾。莫凡玩笑试探说除非她就是这一带最危险的生物，又笑着收回，让女子虚惊一场。女子放松下来自报姓名俞师师，主动提出帮莫凡找学生。

**关键事件**：1.白鸿飞被夜花粉末催眠，飞蛾抬走 2.莫凡在湖畔发现白鸿飞留下的校徽 3.莫凡派曹琴琴去猎者联盟发悬赏，自己追荧光入林 4.莫凡撞见溪边沐浴的俞师师，试探后获她相助

- **情绪流向**：起：白鸿飞失踪的焦虑 → 承：追荧入林的紧张 → 转：月光下邂逅的暧昧 → 合：彼此试探的暗流
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：飞蛾掳人（设危局）+ 湖畔寻踪发悬赏（布后手）+ 溪边邂逅俞师师（引新人物）+ 试探与反试探（埋暗线）
- **本章核心技巧**：恐怖悬念与暧昧喜剧在同一场景交替，用主角的不正经掩盖真正警觉
- **卡点与伏笔**：结尾卡点：身份悬念型——俞师师主动提出帮莫凡找学生，她正是掳走白鸿飞的蛾女；埋设/回收伏笔：掩埋的校徽 → 白鸿飞留下的求救标记；俞师师对烈霞之火的惧意 → 下章她认出专克虫类的火焰
