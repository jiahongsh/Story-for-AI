# 第528章 为什么抛下我？

**概要**：张小侯脸憋青，终于吐出一口气，面前骷髅却茫然看他、放下闸刀，身后的骷髅也只顾游荡寻骨，灰蒜之法奏效。众人压着心跳穿行于亡灵群中，秦虎以手势维持队形，亡灵最多发出警告叫声。王童得意忘形走最前，离一群腐尸不足二十米时，腐尸集体转身、红瞳扑来，他仓皇吞下灰蒜，腐尸瞬间失去目标、忘了来意。石少菊提醒灰蒜稀有且持续时间短，众人边走边补吃。夜色中前方泥浪轰然翻涌，那头刀斧尸将再次爬出，四臂皆斧刀。石少菊让大家绝对静止，张小侯却发现尸将头颅不见了，随后其脖颈中钻出一颗披头散发的头颅，一百八十度转过来，满血毒怨地开口问为什么抛下我，竟是死去的女军官贾曦。

**关键事件**：1.灰蒜之法奏效，队伍穿行亡灵群如履平地 2.王童得意忘形遭腐尸群扑袭，吞蒜惊险脱身 3.刀斧尸将再现，脖颈钻出贾曦的头颅怨声质问

- **情绪流向**：起：灰蒜奏效的如释重负 → 承：穿行尸群的侥幸 → 转：王童被扑的惊魂 → 合：尸将头颅转头的战栗
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：灰蒜验证（安心）+ 腐尸扑袭（惊魂）+ 补蒜续行（危机感）+ 尸将再生头颅（惊悚钩子）
- **本章核心技巧**：安全期里埋失效计时器，再让老反派以新形态回归引爆恐惧
- **卡点与伏笔**：结尾卡点：贾曦的头颅长在刀斧尸将身上，怨毒质问为何抛下她；埋设/回收伏笔：尸将吞食贾曦 → 本章以吞噬拼凑方式进阶，呼应亡灵拼凑设定
