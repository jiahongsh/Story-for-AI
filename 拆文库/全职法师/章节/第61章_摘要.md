# 第61章 提升，雷系！

**概要**：食堂任务收尾，黎文杰拍着莫凡的肩膀夸他反应快、释放速度惊人，肥石调侃郭彩棠得以身相许报答救命之恩，被菜鸟所救的郭彩棠心情复杂到极点。徐大荒安排黎文杰、肥石随警察搜救失踪已一周的林云儿，其生还几率很小。莫凡趁无人留意，用小泥鳅坠吸走巨眼猩鼠的残魄，盘算残魄市价约一万一个、要让坠子先成长到灵级，随即察觉雷系星子如当初火系蜕变前般雀跃，判断雷印即将升到第二级。校方付20万佣金，莫凡分得10%共2万，抵得上老爸开车近半年收入，小队把他直接转正。场景转至穆氏庄园：穆宇昂用冰蔓·凝结把穆贺的私人泳池冻成冰面，穆贺夸其冰系修为远超同龄人、两年可到冰蔓·覆盖，又提起养父卓云对莫凡耿耿于怀、一年后有场解决那小子的安排，宇昂答根本没把那跳梁小丑放在眼里。

**关键事件**：1.莫凡战后获全队认可、分得2万佣金并被直接转正 2.小泥鳅坠吸走巨眼猩鼠残魄、雷印临近二级蜕变 3.穆宇昂庄园登场亮冰系天赋，轻视莫凡为跳梁小丑

**逐章写法公式**：

- **情绪流向**：起：战后夸奖的轻松融洽 → 承：残魄与星子异动的暗喜 → 转：庄园寒冰与决斗议题的阴冷 → 合：跳梁小丑轻蔑收尾的对抗感
- **节奏配比**：慢铺垫 60% / 快冲突 5% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：战后夸奖（立认可）+ 残魄拾取（推金手指）+ 佣金结算（兑现回报）+ 庄园对话（树反派立钩子）
- **本章核心技巧**：用猎妖队群像的认可侧写主角成长，随后切反派庄园视角，借长辈闲谈埋下一年后决斗的大伏笔
- **卡点与伏笔**：结尾卡点：反派轻视型钩子——宇昂没把跳梁小丑放在眼里，等待被打脸；埋设/回收伏笔：小泥鳅坠吸残魄待成长 → 金手指养成线；雷印将升二级 → 下一章技能升级；林云儿失踪生死未卜 → 悬案线；一年后解决那小子 → 成年礼决斗大伏笔
