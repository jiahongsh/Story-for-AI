# 第713章 苦行历练

**概要**：封离点齐十三人队伍（十正式三替补），官鱼以"一个替补没必要等"暗指莫凡，被封离喝止。封离阐明此行最终目标是威尼斯水都国府之争，历练只为争入场券，且队伍出发时间全程不公开。众人从直升机被扔到偏僻小渔村，发现经费冻结、手机身份证全无、连地图都没有，莫凡咆哮这哪是历练简直苦行僧。蒋少絮点出需自找去日本的船，艾江图定为队长带队去渔村问路。官鱼与蒋少絮提醒此行实为偷渡，被抓暴露身份便历练失败、替补优先被替，危机感拉满。

**关键事件**：1.封离点齐十三人宣布国府之争目标 2.众人被扔小渔村发现身无分文 3.蒋少絮指坐船去日本 4.偷渡暴露则历练失败替补先替

**逐章写法公式**：

- **情绪流向**：起：官鱼暗刺的轻微紧张 → 承：封离宣布目标的庄重 → 转：小渔村身无分文的崩溃 → 合：偷渡危机的悬而未决
- **节奏配比**：慢铺垫 50% / 快冲突 5% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：点齐队伍明目标（建制） + 官鱼暗刺莫凡（小冲突） + 渔村身无分文（落差喜剧） + 偷渡危机（埋悬念）
- **本章核心技巧**：用主角夸张吐槽把"理想与现实落差"转化为喜剧张力，同时借对话逐层揭开生存规则
- **卡点与伏笔**：结尾卡点：悬念型，下一餐都成问题且要偷渡，下章期待如何搞到船与钱；埋设/回收伏笔：替补身份 → 延续；历练失败更替 → 长期压力伏笔
