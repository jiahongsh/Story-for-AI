# 第322章 屠戮蜥海！

**概要**：巨蜥伪龙咧口咬下，方圆百米出现下沉的黑色食道黑洞，连道路楼房带蜥颅巨妖往里吞，又吸气形成拉扯风穴。恶魔莫凡冷笑你喜欢吞就让你吞个够，把膨胀到填满半个街道的巨大火球抛入黑洞，火球在伪龙肚中爆炸撑开肚腩，它全身冒火压制吐焰。见统领狼狈的蜥群如潮水前仆后继涌来；恶魔莫凡骂一堆垃圾，一记爪影近乎撕开两公里主干道，直线上的蜥颅巨妖全部分成两半、血液在裂痕中汇成河。他随后锁定潜伏的土巨亡蜥——战将级中半个无敌的存在，狼魂巨爪抓尾把它甩上高空，紫黑巨雷贯穿脑颅空中秒杀。赵满延惊得下巴合不拢，感叹军方这哪是实验，真就是在制造恶魔。伪龙召集全城蜥子民以肉海围困莫凡，他咧嘴对颤动的小泥鳅坠说：放心，全是你的。

**关键事件**：1.火球入腹炸伤伪龙 2.一爪撕开两公里主干道 3.空中秒杀进阶期土巨亡蜥 4.伪龙召集全城蜥群肉海围城

**逐章写法公式**：

- **情绪流向**：起：恐怖（食道黑洞吞天）→ 承：爽（火球炸腹）→ 转：爽（一爪两公里、秒杀巨亡蜥）→ 合：压抑（肉海围城、杀意宣言）
- **节奏配比**：慢铺垫 10% / 快冲突 30% / 爽点爆发 50% / 悬念留白 10%
- **本章结构公式**：敌人绝招压顶（食道黑洞）+ 顺势反制（火球炸胃）+ 群战清屏（爪影撕街）+ 单点秒杀（雷贯土巨亡蜥）+ 反方集结（肉海围城收尾）
- **本章核心技巧**：连场碾压用"反制-清屏-单杀"三种不同杀法排列，避免同一招重复导致的爽感衰减
- **卡点与伏笔**：结尾卡点：压抑对峙型——全城蜥群围成肉海，大战一触即发；埋设伏笔：小泥鳅坠吸纳战将残魄、垂涎统领亡魂 → 器物升级线，进阶期巨亡蜥的存在 → 蜥族等级体系
