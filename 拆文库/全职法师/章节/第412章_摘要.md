# 第412章 上门女婿

**概要**：莫凡和灵灵不到一星期清完那批低端委托，得佣金约五十万，权当为明年猎人争霸赛刷积分。回校后他的挑战书堆得比委托书还高，所幸正式挑战只在每月第二、第四个星期进行。第一百名的资源让他意外：既有三步塔修炼资格，还分到一件能加快星子连接与星轨衔接、直接提升施法速度的速控魔器。火榜排名还会发放火种碎片，十颗可熔炼一次、有几率出灵种；莫凡已有玫炎，便把碎片换成暗影系，又盘算召唤系幼宠买不起、契约召唤荒废，深感缺钱。他向艾图图请教前五十名奖励（两颗碎片加火属性魔器），得知火属性魔器可与星云魔器叠加单系修炼速度，设想三步塔内三重叠加飞速提升，却被艾图图泼冷水：前五十一个比一个怪胎有钱，没整套极品魔具都不好意思，莫凡这穷鬼的天生双系优势很可能被人换上克制系防御魔具抵消。莫凡也自认非人民币玩家，想到东方明若把翼魔具的钱换成盾或铠魔具自己就难赢。艾图图戏言他去牧家做上门女婿可换一整套高质魔具，莫凡答"这个主意不错"，邪笑注视阳台浇花的牧奴娇。

**关键事件**：1.一周清完委托赚50万 2.获得速控魔器与三步塔修炼资源 3.艾图图讲解前五十奖励与魔具体系差距 4.艾图图戏言做牧家上门女婿

**逐章写法公式**：

- **情绪流向**：起：轻松（清委托赚钱） → 承：紧张（挑战书堆山） → 转：热血（资源体系与变强路径） → 合：甜（上门女婿玩笑收尾）
- **节奏配比**：慢铺垫 55% / 快冲突 5% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：清杂务（了结旧线）+ 盘资源（建立变强清单）+ 讲体系（借友口扩世界观）+ 玩笑收尾（感情线轻钩）
- **本章核心技巧**：把大段设定信息全部缝进对话与主角盘算里，用"问—答—抬杠"的损友对话节奏防止解说枯燥
- **卡点与伏笔**：结尾卡点：感情悬念——上门女婿玩笑与凝视牧奴娇，期待两人关系推进；埋设/回收伏笔：三步塔修炼圣地 → 主校区修炼线；火种碎片换暗影系 → 暗影系灵级提升线；挑战书成山+每月二四周挑战制 → 挑战之周冲突；东方明翼魔具短板 → 后续对战胜负手；猎人争霸赛积分 → 长线赛事伏笔
