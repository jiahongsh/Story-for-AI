# 第368章 青炎，东方明

**概要**：锋羽雀锁定两人，柳钟鸣向武平景汇报行踪，获令缠住目标、别让他们进白山，宫廷侍卫约二十分钟后赶到。首次执行任务的柳一林紧张不安，持翼魔具的东方明自负轻敌，收翅如陨石般轰然落地，踩着焦土喊话束手就擒。唐月低声告知他是东方世家最出色的年轻火法师，莫凡想起自己的玫炎正是托东方世家的福。唐月站开留出单挑空间，东方明嘲讽之余自曝天赋是火系魔法急速释放，星图快到星子相连都看不见，一记烈拳逼得莫凡遁影闪避。莫凡发现其火焰外焰呈淡青色，青炎悄然蔓延到脚下点燃草植，将他包裹其中、无影可遁；他判断这是引燃类灵级火种后心一横砸地，施放玫炎地煞，烈焰之花与青炎轰然相撞。

**关键事件**：1.柳钟鸣通报行踪、二十分钟援军沙漏启动 2.东方明陨石式登场叫阵 3.东方明天赋急速释放压制莫凡 4.青炎围杀、莫凡以地煞对轰

**逐章写法公式**：

- **情绪流向**：起：紧张（锋羽雀锁定） → 承：紧张（东方明陨石落场立旗） → 转：紧张（青炎围杀的绝境） → 合：热血（地煞之花对轰）
- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：敌踪锁定（遭遇） + 通讯定时（沙漏） + 陨石落场（单挑开局） + 青炎围杀与地煞对轰（首次爆发）
- **本章核心技巧**：把"二十分钟援军"设成沙漏，让反派自报天赋完成战力说明，第一回合的压制全部建立在信息差上。
- **卡点与伏笔**：结尾卡点：对决高潮型——玫炎与青炎相撞胜负未分，期待下章分出胜负；埋设/回收伏笔：东方世家与莫凡玫炎的渊源→下章兄长之仇揭晓；二十分钟援军→胜后必须撤离的时限。
