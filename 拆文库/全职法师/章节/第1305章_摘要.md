# 第1305章 魔鬼木尖

**概要**：莫凡、岩氏、芍女、赵满延四人赶往神树，路上岩氏讲述三十年前白魔鹰大部落袭击天冠紫椴神树，她为首的一干超阶法师从防守改为进攻、帮助树部落消灭白魔鹰，血战十天压制住白魔鹰，即将溃败时月蛾凰带着青娥铺天盖地出现，阻止人类杀白魔鹰、疯狂攻击神树部落，站到人类对立面。岩氏别无选择以图腾守护者意念呼唤月蛾凰，亲手把它引入弑杀大阵，月蛾凰垂死身体崩解散做无数青娥飞散，岩氏虽重获信任却深陷自责退出魔法领域。白魔鹰逃到南岭苟延残喘，各高层签订保密协议让神树继续留驻外昆嵛山制约妖魔。莫凡问童尚霸占计划是否会让神树发怒大开杀戒，岩氏说绝不是，从一开始所有人都被玩弄于股掌之中。众人赶到神树前，只见满地血腥尸体、没有半个完整的，军人、猎人、政府人员全部倒下，聂冷山、孙军统、童尚、汪大阔全死，一个活口都没有。岩氏大喊快走，这魔鬼绝不会让看到它真面目的人活着。一根尖尖树枝如神罚之矛刺向莫凡，莫凡化作四道影鸟躲过，神木之矛洞穿地面，又一根神木之矛贯穿落下被堪堪躲过，随后魔鬼尖木如倾盆大雨覆盖方圆千米上空，莫凡无从躲避。

**关键事件**：1.岩氏讲述三十年前白魔鹰战争与月蛾凰的背叛 2.岩氏亲手弑杀月蛾凰的经过与自责 3.众人赶到发现全军覆没、无一活口 4.岩氏喊快走说魔鬼不会放过目击者 5.神木之矛接连袭杀莫凡，尖木暴雨封死退路

**逐章写法公式**：

- **情绪流向**：起：白魔鹰战争往事的悬念 → 承：弑杀月蛾凰的悲伤 → 转：全军覆没现场的恐怖 → 合：神木之矛追杀、尖木暴雨封路的死局
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：岩氏讲述三十年战争（历史揭秘） + 弑杀月蛾凰的自白（情感） + 全军覆没现场（恐怖） + 神木之矛追杀封死（死局钩子）
- **本章核心技巧**：先用完整往事解释「月蛾凰背叛」的悬案，再用全员覆灭的血腥现场把「玩弄股掌」落到实处，最后用逐级失效的逃生手段把莫凡逼入必死局
- **卡点与伏笔**：结尾卡点：尖木暴雨覆盖千米无处可躲，莫凡必死之局 → 下章期待岩氏出手；埋设/回收伏笔：月蛾凰阻止人类杀白魔鹰的动机 → 后文真相；岩氏「被玩弄于股掌」→ 弥天之谎的揭晓
