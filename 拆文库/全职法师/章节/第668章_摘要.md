# 第668章 死门间

**概要**：钟楼众人发现城外银色漩涡正在吞走亡灵，韩寂将其解释为空间乱流。谢桑借助会跟随入侵者的邪眼铜镜，看见被卷走的亡灵如雨般落入莫凡四人所在的独立天地，确认他们走进了死门间。韩寂认为独立空间有出口，但一两千只亡灵会让四人难以活着离开。谢桑进一步说明古老王的墓宫会根据闯入者实力调整死门难度，强者进入后遭遇的亡灵数量和等级会大幅增加。众人由此认识到古老王同时精通亡灵、空间与混沌规则，钟楼气氛转为绝望。

**关键事件**：1.城外银色漩涡吞走亡灵 2.韩寂解释空间乱流 3.邪眼铜镜追踪四人 4.亡灵落入死门间 5.谢桑确认死门 6.韩寂判断有出口但亡灵危险 7.谢桑揭示强者难度规则 8.钟楼众人陷入绝望

**逐章写法公式**：

- **情绪流向**：起：城外异常引发疑问 → 承：铜镜接回死门间 → 转：确认死门并计算亡灵数量 → 合：揭示强者规则，外界几乎不再抱希望
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：观察漩涡（提出异常） + 铜镜追踪（确认位置） + 亡灵落地（明确危机） + 规则说明（提升危险上限）
- **本章核心技巧**：让外部观察者逐层补齐读者信息，同时每次解释规则都把安全空间缩小一层。
- **卡点与伏笔**：结尾卡点：谢桑认为死门不存在活下来的可能，四人即将独自面对亡灵群；埋设/回收伏笔：混沌系强弱相对规则 → 后续战斗难度会与莫凡等人的实际修为绑定。
