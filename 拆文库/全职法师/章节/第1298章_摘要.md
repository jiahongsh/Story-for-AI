# 第1298章 敌对种族

**概要**：莫凡的两道雷电在古铜牙山人面前交织成雷电游龙轰然爆开，摧毁了它的粗糙皮肤，将其炸飞进高草丛中身负重伤。芍女难以置信，莫凡说快上树，没多久会有一大群山人出现，施展影鸟带她上树。芍女说自己被古铜牙山人暗算前是政府请来的音系高手，莫凡认出她所在队伍就是自己提醒过的队伍之一。芍女认出莫凡是世界学府之争第一名，想找他比试。两人回到队伍与赵满延等人汇合，队伍里又添一位绝色美女。莫凡汇报山下山人总数超过五千，灵灵说这是部落级规模；芍女提议除掉山人首领，灵灵补充古铜牙山人都相当狡猾惜命，不会轻易出手。赵满延提议借助更高层栖息的生物力量，灵灵说神树像有领地协议，晨颖困惑大紫椴树只收留温和生物，众人议论外昆嵛山死去的霸主可能是图腾兽，芍女提起被追袭时彩尾雀帮她阻挡了古铜牙山人。此时朝阳方向的树梢上飞出越来越多修长如虹彩尾的飞雀，灵灵指向它们——山人在这片区域有敌对的种族。

**关键事件**：1.莫凡雷爆重创古铜牙山人，带芍女上树 2.芍女认出莫凡是世界学府之争第一名 3.汇合后莫凡汇报山人总数超五千 4.商议对策：除首领、借力高层生物 5.彩尾雀现身朝阳方向，发现山人敌对种族

**逐章写法公式**：

- **情绪流向**：起：雷爆重创古铜牙山人的爽 → 承：上树谈身份的轻松 → 转：五千山人兵力的压抑与对策商议 → 合：彩尾雀敌对种族现身的希望
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 20% / 悬念留白 35%
- **本章结构公式**：雷爆重创敌人（爽点） + 汇合盘点敌情（信息整合） + 商议对策与背景推理（推进） + 彩尾雀敌对种族现身（转折钩子）
- **本章核心技巧**：战斗后转入情报整合场景，用众人对话把零散信息拼成「五千山人-除首领-找盟友」的战略全图，最后用新种族现身给出破局方向
- **卡点与伏笔**：结尾卡点：彩尾雀与山人敌对，是否可借力 → 下章期待结盟或借力；埋设/回收伏笔：外昆嵛山霸主是图腾兽 → 神树背景主线；四命蜥虎领地协议 → 妖魔间关系格局
