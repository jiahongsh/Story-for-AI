# 第467章 逃不过的凶河

**概要**：心夏魔能只够两公里，前方却还有三四公里，灵灵蹙眉无解。张小侯提议最后一两公里全力冲过去，莫凡一巴掌拍醒他——白沙巨人能围成不透风的沙城。众人先议派一人引开妖兵，灵灵随即提出分股方案：速度快的人引开一批、防御强的耗一批、战斗强的快速清扫、心夏安抚一批省魔能。张小侯自告奋勇先去惊醒妖兵，队伍分成五股各就各位，心夏居中举手计时，手放下时心灵魔法即失效。残阳沉入白色地平线，莫凡嘀咕着后悔没先向霍佗讨那件铠魔具，就在最后一抹光辉被收进昏暗之际，心夏素白的右手落了下来，白沙下蛰伏的杀机即将全面爆发。

**关键事件**：1.冲过去方案被否决，灵灵提出分股作战方案 2.队伍五股布阵各就各位 3.心夏举手计时，残阳落尽时放下右手

**逐章写法公式**：

- **情绪流向**：起：魔能死局的焦灼 → 承：方案争论与分股计划 → 转：五股布阵各就各位 → 合：残阳落尽，手落开战
- **节奏配比**：慢铺垫 30% / 快冲突 10% / 爽点爆发 10% / 悬念留白 50%
- **本章结构公式**：否决硬冲（定边界） + 灵灵分股方案（破局） + 五股布阵（蓄势） + 手落开战（引爆）
- **本章核心技巧**：全章无战斗却悬念拉满，用倒计时动作做收束，把读者情绪压到临界再切断
- **卡点与伏笔**：结尾卡点：倒计时引爆型，心夏右手落下，白沙巨人即将全面暴起，下章期待分股作战战果；埋设/回收伏笔：霍佗的铠魔具 → 莫凡未取的装备伏笔；心夏居中可庇护众人 → 全队性命枢纽定位
