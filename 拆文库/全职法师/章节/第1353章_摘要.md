# 第1353章 再入煞渊

**概要**：莫凡把灵灵和赵满延留在北疆，独自连夜赶到古都西安钟楼魔法协会找韩寂，询问煞渊的位置。韩寂一直派人演算煞渊的空间迁徙，告知下次迁徙在明天夕阳时刻、柑西市附近。莫凡立即乘机前往，在荒凉黄土地上面对滔天翻滚的煞气，纵身跃入煞渊。他顺着黑色大地穿过白墓之宫，铜门邪眼、画廊、九死一生桥一一越过，首次踏入悬浮于虚无中的血色祭坛，血色王座上坐着空空如也的黑色盔铠。莫凡唤其"总教官"，古老王开口说你不是我的子孙，莫凡答是他的学生。他深知盔袍中存在誓死捍卫博城的斩空的记忆与灵魂，便当面质问北疆小镇的亡灵洗劫是否是古老王手下所为，心中已做好若答案是"是"便与之宣战的准备。古老王答"不是"，莫凡松了口气。他转告秦羽儿想见他的心意，盔中浮现出斩空灰白透明的脸，随即隐去。莫凡行法师军礼，自嘲曾对张小侯说谎——他其实总是扮演无能为力、瑟瑟发抖的角色。

**关键事件**：1.莫凡独闯煞渊，在血色祭坛见到古老王 2.莫凡质问北疆亡灵屠镇，古老王答非其所为 3.莫凡转达秦羽儿之念，以军礼告别总教官

**逐章写法公式**：

- **情绪流向**：起：独赴古都求坐标的决然 → 承：跃入煞渊的恐惧 → 转：血色祭坛对质古老王的张力 → 合：否认屠镇与军礼告别的悲凉
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：求坐标独赴煞渊（动机） + 穿越陵墓见王（路径） + 质问与宣战预演（冲突） + 秦羽儿之念与军礼（情感落点）
- **本章核心技巧**：把最危险的对质写成一场克制的情感戏，主角以"学生"身份而非敌人姿态问话，反转出温柔
- **卡点与伏笔**：结尾卡点：剖白未了——莫凡对精神支柱的说谎自白无人回应，斩空沉默如昔；埋设/回收伏笔：古老王否认屠镇→北疆亡灵另有来源；秦羽儿的等待→斩空的情感线
