# 第550章 黑心向导

**概要**：莫凡向矮男追问失踪朋友的救援可能，矮男说明古都猎人夜间常会抛下陷困同伴，外城墙外的人过夜几乎必死，所谓救援大多只能收尸。矮男暗示自己有前往羊阳村的办法，莫凡和柳茹先在大厅自行招人，却因羊阳村附近曾出现煞渊而无人愿去，只能回来找他。矮男索要一千万向导费，莫凡起初拒绝，柳茹拿出血族孝敬所得的银行卡解决燃眉之急。莫凡核实矮男和担保猎人大师身份后接受委托，但矮男仍不包保护、允许队伍接其他单，双方在猎者联盟的委托规则下完成交易。

**关键事件**：1.矮男解释古都救援规则 2.莫凡招人遭羊阳村风险劝退 3.矮男开出千万向导费 4.柳茹出钱并确认委托条件

**逐章写法公式**：

- **情绪流向**：起：求援受冷遇 → 承：风险坐实 → 转：高价谈判 → 合：带条件组队
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：向导警告（重设规则） + 自行招募失败（验证规则） + 金钱谈判（获取路径） + 合同限制（保留风险）
- **本章核心技巧**：让配角先抛出夸张判断，再由主角实际试探验证，从而抬高任务门槛。
- **卡点与伏笔**：结尾卡点：向导只保证夜间不被包围，队伍还会加入其他客人；埋设/回收伏笔：煞渊 → 羊阳村附近猎人集体忌惮的危险来源。
