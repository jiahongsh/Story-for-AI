# 第149章 好战之狼

**概要**：深夜莫凡在教学楼露台冥修，把召唤系星尘的魔能全部作为供养幽狼兽的食物，小泥鳅坠的两倍加成让他的魔能恢复速度也达到两倍，召唤系星尘已达三级，但两个多月每天喂养却看不出幽狼兽的变化。冥修中精神烙印传来幽狼兽挑衅般的啼叫——它在次元召唤位面又开战了。莫凡由此重新认识了召唤兽：它们在位面有自己的生活，与法师的协议只是魔能喂养换取召唤战斗，两个多月里这只好斗的狼已打了不下十次，多次伤痕累累。这一战结束，精神烙印弱到极点，幽狼兽生命垂危，莫凡急忙输送魔能把它从死亡边缘拉回，要召它去医务室被它拒绝，只传来躲在安全处自愈的精神信息。天亮后幽狼兽气息平缓，吸收莫凡全部魔能后沉沉昏睡，莫凡认定炼兽之血没希望、只能放弃斗兽大赛。迎新日当天，食堂里男生们打探七名召唤系的召唤兽情报，唯独莫凡的召唤兽无人知晓；李俊巍放话雷系家伙跟他争秦小棉，众人又聊起至高女神牧奴娇。

**关键事件**：1.幽狼兽在次元位面血战濒死，莫凡连夜输魔能救回，它昏睡导致斗兽大赛泡汤 2.莫凡重新理解召唤兽与法师的协议关系 3.迎新日全校打探召唤系情报，莫凡的召唤兽成唯一谜团

**逐章写法公式**：

- **情绪流向**：起：深夜冥修的平静 → 承：烙印示警的揪心 → 转：彻夜救援的松口气 → 合：食堂情报战的暗流
- **节奏配比**：慢铺垫 45% / 快冲突 25% / 爽点爆发 5% / 悬念留白 25%
- **本章结构公式**：冥修喂养日常（立养成系） + 位面血战濒死（危机） + 输能救狼自愈（羁绊+埋损失） + 迎新日情报战（开场前奏）
- **本章核心技巧**：在大赛前一章主动折掉主角的战力底牌（幽狼兽昏睡），把「必然出场」变成「怎么都不能出场」的绝境感，吊足期待
- **卡点与伏笔**：结尾卡点：悬念型，莫凡召唤兽是全场唯一未知数，李俊巍为秦小棉敌意初显，下章大赛开场；埋设/回收伏笔：小泥鳅坠双倍修炼加成（旧设定）→ 回收为魔能恢复快、喂养成优势
