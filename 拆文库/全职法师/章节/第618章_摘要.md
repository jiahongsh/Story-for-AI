# 第618章 顶一个队！

**概要**：撤离队伍用冰锁把车辆捆成路障，壮年跑在前面，女人和孩子被包在中间，但亡灵从汽车顶和四面八方扑来后，人潮迅速失控。矮男提醒摔倒者护住头胸，浓妆女法师却报告三十头腐尸逼近。莫凡从高处落下烈拳轰碎尸群和车辆，替矮男挡住一侧压力。另一侧的杜乐康为同时操控五根冰锁而分神，被蛛鬼将刺伤，盾魔具即将失效时，莫凡连续释放雷电，将蛛鬼将从巴士顶一路轰到车底。穆白和杜乐康由此确认莫凡的毁灭力足以顶一个小队。

**关键事件**：1. 人群经过斑马线时因亡灵冲击失控 2. 莫凡用烈拳轰杀一批腐尸 3. 莫凡连续雷击救下受伤的杜乐康并击杀蛛鬼将

**逐章写法公式**：

- **情绪流向**：起：勉强秩序 → 承：人潮失控 → 转：烈拳救场 → 合：雷击反杀并获得认可
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：车辆成障（建立通道） + 人潮混乱（制造群体危机） + 烈拳开路（解决局部尸群） + 蛛鬼袭击（转移个人危机） + 连续雷击（形成单人小队效果）
- **本章核心技巧**：把两条防线并行推进，先用群体混乱制造大压力，再用个人救援完成局部反转。
- **卡点与伏笔**：结尾卡点：莫凡被视为顶一个队，但死街上的亡灵仍持续涌来；埋设/回收伏笔：小泥鳅坠提炼精魄 → 后续用于恢复魔能和强化星子。
