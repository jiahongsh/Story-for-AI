# 第1387章 风翼斩蓝衣

**概要**：岩之角斗场打开，赵满延像拖死狗一样将紫鬼的尸体高高抛向黑教廷众成员，紫鬼一脉的攻势顿时动摇。镇守方士气逆转，高喊"我们支援来了"反扑。赵满延崩解自己厚厚的岩甲，化成无数细微岩甲片给所有还在战斗的镇守法师加上一层群体防御，凤于飞看到这一幕眼睛闪烁起久违的光芒。曲康大喊诅咒畜妖破不了这层岩铠，镇守法师拧成一股反攻。军法师指认藏在诅咒畜妖后、紫鬼死后成为黑衣指挥的暗影蓝衣，张小侯风驰电掣追杀，速度之快令黑畜妖扑袭全部落空，暗影蓝衣吓得遁影逃上宏伟之墙。张小侯以地牢石墩将其困在墙面，风之翼冲得他失去平衡跌落墙后。暗影蓝衣跪地求饶，暗中却指挥藏身墙上的暗影畜妖如蜘蛛般逼近，狞笑间丧魂之爪袭向张小侯脖后——张小侯连头都不回，身子轻盈一让便轻描淡写地躲过。张小侯冷言痛斥黑教廷用丑陋畜妖害人性命的行径，风之翼自行散成坚韧风切围住暗影蓝衣与其畜妖，凌乱扫过，不到两秒便将他们切割成无数片，血花乱溅，风精灵随后重组风之翼飞回魔烽火台。

**关键事件**：1.赵满延抛出紫鬼尸体，黑教廷攻势动摇，镇守方反攻 2.赵满延崩解岩甲给上百镇守法师加上群体防御 3.张小侯追杀逃上宏伟之墙的暗影蓝衣，地牢困敌 4.暗影蓝衣跪地求饶却指挥暗影畜妖偷袭，被张小侯轻描淡写躲过 5.风切分尸暗影蓝衣与其畜妖

**逐章写法公式**：

- **情绪流向**：起：紫鬼伏诛、士气逆转的痛快 → 承：群体岩铠与反攻的振奋 → 转：暗影蓝衣诈降偷袭的惊险 → 合：轻描淡写反杀的爽快
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 30% / 悬念留白 5%
- **本章结构公式**：抛尸震敌（斩将收尾）+ 群体岩铠反攻（情绪上扬）+ 追杀暗影蓝衣（小boss战）+ 识破诈降反杀（爽点收尾）
- **本章核心技巧**：用一场"斩将后遗症"的打扫战，同时完成士气描写、群体防御展示与一次诈降反杀，情绪由扬到爽一气呵成
- **卡点与伏笔**：结尾卡点：神木关守稳、赵满延张小侯各自收尾，但镇北关仍承受最大压力，下章转场；埋设/回收伏笔：紫鬼之死与契约未解的冲突→为本应释放的莫凡留下隐患
