# 第621章 轰飞尸臣！

**概要**：小炎姬附体后，莫凡以强化完成的四十九颗星子施放陨拳九蛟，九条火蛟同时轰中空中的肉丘尸臣，把这座肉山撞飞数百米并在腹部留下燃烧的窟窿。左锋震惊于中阶法师竟能重创统领级生物，另一名禁卫法师提醒他趁尸臣受伤施展摄魂控心。尸臣被控制后反向冲撞，碾死大量跟随的鬼将和骷髅，人潮从绝望中恢复并冲过死街。莫凡因魔能消耗过大而脸色苍白，却因四级烈拳完成而兴奋，众人则把他记成一拳轰飞尸臣的强者。

**关键事件**：1. 莫凡完成四级烈拳陨拳九蛟 2. 火蛟将统领级肉丘尸臣轰飞并造成腹部创伤 3. 左锋控制尸臣反撞亡灵，七百人成功通过死街

**逐章写法公式**：

- **情绪流向**：起：蓄力 → 承：火拳释放 → 转：尸臣受创反控 → 合：人群获救与强者认可
- **节奏配比**：慢铺垫 10% / 快冲突 35% / 爽点爆发 40% / 悬念留白 15%
- **本章结构公式**：九蛟成形（释放升级） + 尸臣倒飞（完成越级结果） + 禁卫抓住窗口（转入控制） + 亡灵自相碾压（扩大收益） + 人群过街（兑现目标）
- **本章核心技巧**：用主角的一次爆发同时解决敌人、制造旁观反应和完成群体目标，让爽点承担多重剧情功能。
- **卡点与伏笔**：结尾卡点：莫凡完成神功却魔能耗尽，众人已经记住他的强者形象；埋设/回收伏笔：四十九颗星子 → 兑现前章强化资源与四级烈拳目标。
