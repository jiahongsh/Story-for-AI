# 第469章 第四级遁影（上）

**概要**：白沙巨人围攻之下，赵满延凭层层防御技能在包围圈中硬撑，能打到他的只有第一二圈的巨人；张小侯用灵种地波与履魔具四处游走，被十只巨人组成的沙墙堵截后以岩障抵挡、靠风靴爆发逃生。莫凡不走闪避路线，以雷火魔法轰杀巨人，发现雷印的麻痹效果对无血无肉的元素妖无效，改用火滋爆裂打乱阵型。小泥鳅坠吞噬残魄，只收集十只白沙巨人的残魄便凝炼出一颗奴仆级精魄，莫凡的暗影系五颗星子已强化完毕，只差一颗便能将遁影升到第四级，而要再炼一颗精魄还需猎杀近四十只白沙巨人。

**关键事件**：1.张小侯遭十只白沙巨人沙墙堵截，以岩障挡刀、风靴爆发冲出重围。 2.莫凡发现雷印对元素妖无效，靠火滋爆裂与烈拳九宫轰杀巨人。 3.小泥鳅坠吞十只残魄凝出精魄，遁影升四级只差一颗星子。

- **情绪流向**：起：赵满延苦撑、张小侯险象环生的围困 → 承：十只巨人沙墙堵截、岩障粉碎 → 转：风靴逃生、莫凡以杀为主的反击 → 合：精魄进度临门一脚、遁影升级在望
- **节奏配比**：慢铺垫 40% / 快冲突 35% / 爽点爆发 10% / 悬念留白 15%
- **本章结构公式**：双线围困展开战场（建立危机）+ 张小侯岩障风靴脱险（展示敏捷）+ 莫凡雷火轰炸试错（确立打法）+ 残魄凝精魄卡进度（埋升级钩子）
- **本章核心技巧**：用三线视角铺同一场围困战，每线各显人物特性，再以进度数字收口制造升级期待
- **卡点与伏笔**：结尾卡点：悬念——只差一颗星子即可升四级遁影，还需杀近四十只巨人；埋设/回收伏笔：白沙巨人残魄价值远超普通奴仆级 → 成为莫凡强化升级的资源线
