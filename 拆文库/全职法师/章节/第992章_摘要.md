# 第992章 隐患必除！

**概要**：莫凡在浅礁用电流戏弄鱼群，海底忽然涌上地震波、礁窟摇晃。灵灵神色低沉说有麻烦，原来歹蛆已潜到两千四百米深度，惊动了乌海伪龙，那声地震波正是伪龙的吐息。鲍比吓得要开船走人，灵灵厉声阻止，列出数据：不解决则一年溺咒死者超五百、两年超一千，并说视而不见让隐患离开，将来因此而死的人真实存在，我们与帮凶无异。莫凡脑中浮现灵灵日记本上父亲留下的"隐患必除"四字，遂以猎人身份答应一试。灵灵说歹蛆躲藏后仍会去寄生伪龙，必须引它上岸。鲍比想退出，莫凡以屠龙猎人经历自证实力，并亮出二星猎人大师身份。鲍比冷静后提出方案：惊扰刚做妈妈的雷暴乌贼统帅，让整片海域变高压雷区，逼乌海伪龙离海上岸，灵灵负责在潜礁做隔绝带当战场。

**关键事件**：1.乌海伪龙被歹蛆惊动，灵灵以数据与信念劝留 2.莫凡忆日记"隐患必除"决意出手 3.定下惊扰雷暴乌贼逼龙上岸之策

**逐章写法公式**：

- **情绪流向**：起：浅礁闲戏的轻松 → 承：伪龙惊动的危机铺垫 → 转：信念决意与方案反转 → 合：战场布置的行动钩子
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 15% / 悬念留白 40%
- **本章结构公式**：伪龙吐息（危机） + 灵灵劝留（信念） + 莫凡决意（人物弧） + 惊雷引龙方案（策略）
- **本章核心技巧**：用"隐患必除"旧伏笔回扣点燃行动决心，再用妖族特性反制强敌
- **卡点与伏笔**：结尾卡点：类型行动+如何惊扰乌贼引龙上岸引下章；埋设/回收伏笔：灵灵日记"隐患必除"→红魔伏笔回扣
