# 第87章 一鸣惊人

**概要**：猎妖小队的肥石盯着莫凡，小声问同伴这人释放雷印像不像一个人，徐大荒猛然反应过来大叫梵墨就是莫凡，全队恍悟这个神秘雷系队友竟是没毕业的高三学生，火系实力还不逊于队长；对梵墨略有好感的郭彩棠内心复杂。朱校长提议众人在全国魔法高考前暂不透露天生双系的消息，让莫凡在高考时一次举国轰动，杨作河同意最多推迟两周上报，斩空也主动压消息防大组织挖人。唐月向学生们解释封锁是防大势力占据博城、防歹人暗中除掉还是初阶的莫凡。三大势力联合封锁后，莫凡拿到决斗最大彩头——地圣泉一周修炼资格，期待借泉冲击中阶。

**关键事件**：1.猎妖小队认出梵墨即莫凡 2.朱校长主导封锁消息至高考后 3.莫凡获得地圣泉一周修炼资格

**逐章写法公式**：

- **情绪流向**：起：轻松猜疑 → 承：身份恍悟 → 转：封锁隐忧 → 合：彩头在握
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 35% / 悬念留白 20%
- **本章结构公式**：队友拼图认马甲（回收暗线）+ 朱校长提议封口（转折）+ 唐月解释风险（加压）+ 地圣泉彩头（抛出下一目标）
- **本章核心技巧**：用配角对话拼图回收长线马甲，再借封口令与高危解释为奖励剧情同时埋保护与危机两层钩子
- **卡点与伏笔**：结尾卡点：地圣泉一周修炼即将开始，留下修为飞升的悬念；埋设/回收伏笔：梵墨身份曝光（回收猎妖队暗线）、郭彩棠好感（情感线）、唐月暗杀警告（后续黑教廷伏笔）、高考举国轰动（未来爆点）
