# 第583章 黑腐尸大军

**概要**：莫凡随队杀入黑腐尸大军，与小泥鳅坠相约吃个饱——亡灵死后化作的绿色魂气被坠子吸走，正是他火系星子修到33颗的来源。十字疤男踏着冰锁率先杀入尸群，魔藤女法师的荆棘魔藤勒断腐尸、一脚踩烂其头颅。莫凡想搭讪被瞪，矮男现身认亲，介绍这位亡灵榜第七的青辣椒五年斩杀奴仆级亡灵1330只、战将级78只。矮男坦白自己为可卖八百万的荣誉猎人称号而来。莫凡把火滋塞进张嘴的腐尸喉咙，瞬间将其焚成灰烬，小泥鳅立刻吸走魂气，矮男调侃早知他是天赋榜第五的双系法师就给他打九五折。

**逐章写法公式**：

- **情绪流向**：起：亢奋（尸潮开战） → 承：热闹（群像冲杀） → 转：爆料（矮男登场） → 合：戏谑（焚尸打折）
- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：坠子交底（亮收益） + 群像冲杀（展热血） + 矮男爆料（补人设） + 火滋焚尸（放爽点） + 斗嘴收尾（调气氛）
- **本章核心技巧**：战场景象与人物小传并用对话穿插，打斗不冷场、闲聊不拖戏
- **卡点与伏笔**：结尾卡点：战况悬念——尸潮尽头还有何种强敌；埋设/回收伏笔：小泥鳅吸收魂气凝炼精魄 → 为莫凡补齐星子铺路
