# 第196章 命悬一线，巨影钉

**概要**：烈拳·轰天吞没逃窜的妖母，将它掀翻到空中、鳞片烧焦翻卷，但它并没有死，不顾身上未灭的火焰再度冲来，速度丝毫不减。灵灵急劝莫凡快跑，莫凡判断现在跑就是死路一条，赌自己的星图描画比妖母更快，扬手展开唐月老师给的星图之书，调动暗影系星云中49颗星子按印射图案排列，纹丝不动地与妖母的冲刺赛跑。妖母爪风先将莫凡额头到鼻梁、眼角到侧脸的皮肤裂开，利爪擦面而过的瞬间，隐入空气的巨影钉将其影子如剑刺穿钉在舞台，镣铐般的束缚令它腰部以下动弹不得。莫凡双目化为璀璨紫色描出雷系星图，往后一跃指着妖母头顶喝出一个死字，雷云成型，粗壮雷电破空打落，时间仿佛定格。

**关键事件**：1.烈拳重创却未能杀死妖母，其带火再冲速度不减 2.莫凡以星图之书赌速度，49颗星子排列与妖母冲刺赛跑 3.巨影钉钉住妖母影子将其定身，莫凡补上霹雳轰落

**逐章写法公式**：

- **情绪流向**：起：爽（烈拳命中）→ 承：紧张（妖母未死再冲、星子赛跑赌命）→ 转：紧张（爪风裂脸的极限一瞬）→ 合：爽（巨影钉定身、霹雳轰落）
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：烈拳重创（险胜错觉）+ 星图之书赛跑（赌命蓄力）+ 巨影钉定身（绝境翻盘）+ 霹雳轰落（终结定格）
- **本章核心技巧**：让蓄力进度与敌人冲刺距离两条时间线互相咬合，在爪风贴脸的一帧完成反杀。
- **卡点与伏笔**：结尾卡点：结果悬置（雷电轰落、时间定格，战果下章开）；埋设/回收伏笔：唐月老师给的星图之书 → 回收赠书伏笔并在下章自述救命；暗影系中阶巨影钉 → 莫凡暗影系战力升档。
