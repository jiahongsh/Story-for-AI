# 第1152章 希腊铜兽

**概要**：星河山道下信仰殿民众蜂拥而来，认出闯山者是学府之争打败哲罗的莫凡，议论其自取灭亡；山道上方骑士殿人围在出口俯视结界内渺小的莫凡，殿主海隆冷漠说不管他是谁都是自取灭亡，库伦说其为叶心夏、芬哀骂其莽夫。莫凡走到与第一座雕像同阶，希腊铜兽独眼忽然打开直勾勾盯他——这古老生物独眼、四肢肥硕短粗、身躯如巨蟾、犀牛头、鼻有锋利铜角，代表希腊杀伐。铜角指来一道锐利青光逼至，莫凡肩部现小血洞；铜兽故意打偏似热身，独眼带轻蔑，因久无闯入者长眠乐得松动筋骨。它进攻毫无前兆，半趴慵懒下一秒爆发速度贯穿敌人，莫凡连添数道非致命伤。祝蒙急言躲不掉，庞莱说铜兽眼与鼻角锁死目标难闪避只能看莫凡自己。莫凡不再避让冷视铜兽，青光抵面时手成钩爪正面相抗，苍雷爪与铜兽相撞将其倒飞撞上石阶；继而瞬息移动现身以雷臂重砸，"轰"死光之雷炸开电弧如蛟龙，再一记暴君制裁粗壮闪电击穿铜兽身躯左侧到右侧。

**关键事件**：1.民众与骑士殿认出闯山莫凡，议论其自取灭亡 2.希腊铜兽苏醒，铜角青光伤莫凡并戏耍 3.铜兽无前兆难防，祝蒙庞莱点出其锁死目标 4.莫凡苍雷爪硬抗铜兽 5.雷臂爆与暴君制裁重创铜兽

**逐章写法公式**：

- **情绪流向**：起：身份曝光群议（紧张） → 承：铜兽戏耍受挫（憋屈） → 转：锁死难避的绝望（压抑） → 合：雷系硬抗重创（爽）
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 30% / 悬念留白 5%
- **本章结构公式**：民众认出莫凡（曝光） + 铜兽苏醒戏耍（受挫） + 锁死目标难避（加压） + 雷系硬抗重创（爆发）
- **本章核心技巧**：先让守卫人格化戏耍主角制造憋屈，再用"不可闪避"规则逼出正面硬抗，三连雷系技能完成受压反弹的爽点
- **卡点与伏笔**：结尾卡点：冲突+铜兽被暴君制裁击穿未死透，下章期待莫凡如何补刀通过；埋设/回收：神印礼赞两倍雷威（前文设定→此章战力兑现）
