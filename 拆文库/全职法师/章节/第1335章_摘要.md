# 第1335章 嫁祸他人

**概要**：莫凡、灵灵坐在广州五百米信号塔顶吃着广东美食，赵满延提着外卖飞上来一起野餐，叉烧包被风吹落，他不肯求莫凡用空间系帮忙，自己如跳水运动员般倒插下去追包子。莫凡问灵灵想好对策没有，灵灵点头。武夷山审判会的监察长程英独自坐在角怪山高亭露台，恐慌地自语怕被人察觉。女审判员苏青青来告知冷青审判长被杀手殿暗杀的消息，程英确认她不是试探后才收起凶意，随即警告苏青青：冷青曾向武夷山发密文请求接应，地点是昆明，此事不得告诉任何人，审判长死了上头一定会抓替罪羊。苏青青感恩应允。随后在荒废的飞崖桥上，程英以特殊力量禁锢苏青青，用绳套勒住她的喉咙，面无表情地以蓝衣名义引她"到死之国度"。苏青青至死不解视如母亲的恩人为何变成恶鬼，临死想看她一丝不舍却什么都没看到。上半夜过去，她的尸体被巡走人员发现。

**关键事件**：1.程英在飞崖桥绞杀苏青青灭口 2.程英此前将冷青密文转递昆明一事推给苏青青背锅 3.苏青青死后尸体被巡走人员发现

**逐章写法公式**：

- **情绪流向**：起：信号塔顶野餐的轻松日常 → 承：程英露台恐慌与密谋的暗流 → 转：飞崖桥绞杀苏青青的惊骇 → 合：吊尸发现的余悸
- **节奏配比**：慢铺垫 20% / 快冲突 0% / 爽点爆发 0% / 悬念留白 80%
- **本章结构公式**：野餐插科打诨（缓冲） + 程英暴露恐慌（设疑） + 灭口布局（加压） + 绞杀场景（释放） + 尸体被发现（钩子）
- **本章核心技巧**：用日常喜剧作前戏，骤然切到凶杀现场，借受害者临死视角强化恐怖感，让凶手身份先于读者一步暴露
- **卡点与伏笔**：结尾卡点：尸体发现——苏青青之死将武夷山审判会拖入清查；埋设/回收伏笔：昆明密文→钓内奸的关键指向；程英的"替罪羊"理论→苏青青成替死鬼
