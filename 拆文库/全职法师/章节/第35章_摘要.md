# 第35章 成长型星尘魔器

**概要**：莫凡疑惑此前探查泥鳅坠是死水一潭、今天却成滋养温泉，而该校有功效的星尘魔器反倒失灵，惊觉可能是泥鳅坠把校发魔器的能量吸走了。他集中意念在两器之间探寻验证：校发魔器最深处仅剩一丝能量，正被泥鳅坠像拿了根吸管一样持续吸走，若非发现得早连证据都找不到。他抓起泥鳅坠破口大骂，确认这成天被自己骂的小坠子竟真是一件星尘魔器，自己一直坐拥金山去讨饭；可校发魔器已成鹅卵石般的空壳，而十天后期满必须原封归还，若被穆贺抓住把柄，足有理由把他踢出天澜魔法高中。莫凡装出可怜学生的模样打电话向唐月求助，谎称星尘魔器出了点小问题；唐月一听星尘魔器是学校至宝、出问题真是大事，问明他在三号教学楼天台水坝上后只说"给我3分钟"便挂断。莫凡正不信教师公寓再快也赶不及，天台暗处泛起一丝不像空气也不像元素波动的微弱异动，唐月披着针织风衣从乌云阴影与月光的明暗分界处径直走出，全程没有脚步声，像从另一扇门跨出，惊得莫凡倒吸凉气。他犹豫后决定坦诚相见，说出能量转移到了自己的坠子上并掏出泥鳅坠。唐月瞪大眼睛追问来历，莫凡答"祖传的"；唐月沉寂下来反复打量他和坠子，神情凝重地问"这事，你跟别人提过吗"，莫凡心里发毛，暗想这像极了影视里杀人越货的经典对白，月黑风高的天台正符合剧本。

**关键事件**：1.验证泥鳅坠吸走能量、校发魔器报废 2.唐月三分钟从阴影现身天台 3.莫凡坦白交出秘密、唐月凝重追问

**逐章写法公式**：

- **情绪流向**：起：前后反常的疑云 → 承：验证实锤与归还危机 → 转：唐月诡异现身 → 合：凝重追问、杀机错觉
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：发现异常（起疑）+ 主动验证（实锤危机）+ 求助来电（引入强者）+ 走出阴影（异象收口）
- **本章核心技巧**：让"求助对象"以超自然方式登场，用一段明暗分界的氛围描写同时完成人物实力展示与场景惊悚感。
- **卡点与伏笔**：结尾卡点：悬念型，唐月那句追问是善意提醒还是杀人越货前奏；埋设/回收伏笔：唐月阴影行走 → 其隐藏身份与诡异能力的长线；归还危机 → 唐月善后；泥鳅坠真身 → 下章判定。
