# 第680章 死亡制裁？

**概要**：钟楼内，凌溪、左锋和妖男通过邪眼铜镜观看死门间，众人认可莫凡在亡灵群中的战斗力，却仍认为他难以生还；凌溪去接受治疗，左锋的消沉被妖男斥责。死门间里，莫凡用千层火羽和火焰飓风继续消灭铁球、双剪等骷髅，骨堆已淹到脚踝，八方骷髅方阵封住去路。小泥鳅坠将残魄凝成精魄，雷系强化累计到四十八颗，但莫凡还差一颗才能完成所需强化，而新残魄已断绝；他仍决定留在原地继续厮杀，不接受亡灵的死亡制裁。

**关键事件**：1.钟楼众人旁观并判断莫凡接近极限。 2.莫凡被八方骷髅方阵围困仍连续清场。 3.雷系强化停在四十八颗，莫凡坚持继续战斗。

**逐章写法公式**：

- **情绪流向**：起：压抑 → 承：紧张 → 转：热血 → 合：压抑
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：场外旁观动作（给出生还判断） + 场内清场动作（展示坚持） + 强化计数动作（建立目标） + 资源断绝动作（留下死局）
- **本章核心技巧**：在场外用悲观预判压低希望，再让场内人物以连续行动反向支撑意志。
- **卡点与伏笔**：结尾卡点：生死类，莫凡被围困且雷系强化差一颗；埋设/回收伏笔：小泥鳅坠凝魄 → 残魂断绝使强化暂时停滞。
