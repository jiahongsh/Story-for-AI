# 第472章 默契三人组

**概要**：白沙巨人们如打保龄球般撞上巨人墙成片倒下，双方东倒西歪，有的撞得身体粉碎。莫凡起初以为巨人蠢笨，细看才发现张小侯早在地面铺开流沼地波，利用白沙巨人笨重刹不住的特点，用地面自动前推的力量把追兵强行送进同伴组成的沙墙，撞出大缺口。张小侯说明流沼覆盖泥沙后巨人无法遁地、行动笨拙，莫凡竖起拇指夸他在斩空手下学会不少。张小侯以岩壁障掩护，莫凡闭眼快速描画星图，使出千钧霹雳夜叉劈碎五只巨人；赵满延趁圣盾未破施展暴浪冲倒阵脚大乱的巨人，张小侯踩着倒下的巨人身体跳浪而来，莫凡靠血兽靴摇摇晃晃抵达。赵满延感动立誓防御全包，莫凡随即分派战术，三人相互依仗，神情凝重毫无惧色。

**关键事件**：1.张小侯用流沼地波推送白沙巨人撞破巨人墙。 2.莫凡千钧霹雳夜叉、赵满延暴浪夹击，三人会合。 3.莫凡分派聚怪战术，三人背靠背迎战。

**逐章写法公式**：

- **情绪流向**：起：巨人相撞的荒唐混乱 → 承：看破地波原理的恍然 → 转：三人各展所长会合 → 合：分派战术、群狼环伺中的笃定
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：巨人撞墙车祸（结果先行）+ 地波真相揭底（打法确立）+ 雷暴双人夹击会合（战力合流）+ 分派战术备战（新阶段开局）
- **本章核心技巧**：用队员各自的专长串成一次团队配合演出，先给奇观结果再补原理
- **卡点与伏笔**：结尾卡点：期待——三人战术展开后莫凡的烈拳九宫将如何收割群敌；埋设/回收伏笔：白沙巨人残魄一个顶三个 → 莫凡强化精魄的猎场确立
