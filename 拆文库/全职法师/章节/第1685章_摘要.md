# 第1685章 失败的恶人

**概要**：天蒙蒙亮，小炎姬把收拾凄惨的陆灼、蒋华拧回明湖驿站，顾盈与飞川皑狼随后赶到，顾盈讲出陆灼的恶行始末。杨宁记录并通知猎者联盟派调查员，中午时分调查员赶到控制陆灼，莫凡让阿帕丝给蒋华种下恐惧针，蒋华当天便交代了自己和陆灼的旧恶。被催眠带回的李玉梅当面揭发陆灼失职害死仓巾小队以及陈年旧事，莫凡得知陆灼竟是最早发现假血剂的人员，眼神变得凌厉。陆灼临死顽抗嘲讽莫凡迟早同他一样败露，杨宁愤而甩出莫凡的详细资料，陆灼看到罗冕议员与红衣主教冷爵都因莫凡倒台后魂飞魄散，连灵灵的资料也摧毁了他最后的光，最终亲口招供。潘城猎人团队其他人惊觉被陆灼蒙蔽，劫后余生般主动配合莫凡进洞窟搜查，锁定洞窟岛就是大蝾魔藏身之所。

**关键事件**：1.蒋华受恐惧针当众交代旧恶，李玉梅揭发陆灼 2.杨宁甩出莫凡资料击溃陆灼的心理防线 3.陆灼亲口招供，潘城猎人团队配合找到大蝾魔洞窟岛

- **情绪流向**：起：清晨对质 → 承：层层揭发 → 转：资料击溃心防 → 合：招供并转向大蝾魔任务
- **节奏配比**：慢铺垫 40% / 快冲突 30% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：收押审讯（解上一章扣子） + 恐惧针撬口（推进） + 资料压垮自尊（爆发） + 转向洞窟岛（下章钩子）
