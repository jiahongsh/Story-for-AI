**逐章写法公式**：

- **情绪流向**：起：开舱撤离的混乱 → 承：赵穆布三人分层护送的稳妥 → 转：莫凡放狼群屠杀的爽快 → 合：大妖现身的急转与撤退
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：开舱放人（破局） + 分层护送（稳场） + 召唤兽潮（爆发） + 大妖逼退（钩子）
- **本章核心技巧**：先以配角守护技稳住局面，再把主角召唤碾压作为爽点，最后用召唤兽反常逃窜反转出更强威胁。
- **卡点与伏笔**：结尾卡点：大妖现身莫凡撤向布兰妾，下章揭大妖身份；埋设/回收伏笔：飞川皑狼大统领级→后续遇更强敌的尺度参照。
