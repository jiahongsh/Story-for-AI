# 第1289章 胆子比天还大

**概要**：众人步入天冠紫椴神树树荫下，光线穿过枝叶洒落成一束束。树根底座如一座山丘，随意一条盘根就有城市街道宽，走近才发现树纹如同栈道可攀爬。赵满延指着前方根坡上数量庞大的身影——成百上千只山人在啼叫，莫凡的黑暗之瞳锁定站在最高处的古铜牙山人，它体型更大、古铜朝天牙透着贵族气息。山人们手舞足蹈地啼叫，草海中数不清的东西正往这里聚集，一头头山人从后方跳出封死所有退路，数量多出两倍，堵住了返回嵛草海的后路。莫凡透露小炎姬在进阶沉睡期、火系实力大打折扣，赵满延气得骂娘。灵灵建议不能后撤，要往前杀到天冠紫椴神树上躲到别的妖魔地盘，莫凡赞同，蓝洛苦笑说他们胆子比天还大。

**关键事件**：1.众人步入神树树荫，发现树根如街道、树纹如栈道 2.成百上千只山人聚集，古铜牙山人立于最高处 3.山人从草海跳出封死后路，数量多出两倍 4.莫凡透露小炎姬沉睡、火系实力打折 5.灵灵建议往前杀上神树，众人定下计划

**逐章写法公式**：

- **情绪流向**：起：步入神树的好奇 → 承：成百上千山人群的压迫 → 转：后路被封死、小炎姬沉睡的双重危机 → 合：定下「向前杀上树」的冒险计划
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：神树景观引入（铺垫） + 山人军团现身立威（冲突预热） + 退路被封与战力打折（加压） + 灵灵献策向前杀上树（转机）
- **本章核心技巧**：在开战前把「退路」「底牌」「人数」三项全数剥夺，让主角从优势转弱势，再用逻辑推演让冒险方案成为唯一活路，将悬念顶到最高点再收束
- **卡点与伏笔**：结尾卡点：决定冲入万千山人杀上神树，前方还有什么妖魔 → 下章期待突围；埋设/回收伏笔：小炎姬进阶沉睡期 → 后文火系回归的转折；神树上栖息的其他妖魔 → 下一个威胁层
