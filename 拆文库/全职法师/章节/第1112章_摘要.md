# 第1112章 拳灭德国队

**概要**：小炎姬冲破司夜统治附体莫凡，莫凡同时释放暴君之雷与炎姬火领域，将雷火双领域叠加笼罩德国队伍，震撼全场。苍黑雷爪从高空压下将德国三人逼至中央，巨炎拳随之在雷爪中央砸落，黄沙蒸发场地塌陷，德国三人昏死、风笛呆滞崩溃。瑞迪醒来自叹其毁灭只摧毁一人，莫凡的毁灭却足以摧毁一支队伍。破坏力超出赛方防御，结界残破，中国击败强国德国晋级胜者组，议员们畅快。韩寂借转播公开莫凡是古都恩人冷秋，曾跳煞渊救百万人，举国轰动；莫凡下场浑然不知，牧奴娇问其半途退出提名是否去了古都。

**关键事件**：1.莫凡双领域叠加，雷爪加巨炎拳轰垮德国 2.德国败北晋级胜者组，韩寂公开莫凡古都恩人身份 3.牧奴娇追问莫凡去古都

- **情绪流向**：起：小炎姬附体的续势 → 承：双领域叠加的奇观 → 转：雷爪巨炎拳碾碎德国的爆发 → 合：晋级加古都恩人公开的余波钩子

- **本章结构公式**：附体双领域（奇观） + 雷爪逼中央（加压） + 巨炎拳砸落（爆发） + 德国溃败晋级（爽） + 古都恩人公开（钩子）
