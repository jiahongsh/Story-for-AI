# 第1555章 开罗沙土战城

**概要**：莫凡与瓦尼、萨斯厮杀时曾放叛逆魔影追踪冈玛，却被他逃脱，只能靠黑暗物质的气味一路追到开罗战城。他决定潜入人满为患的战城，祭出统领级精魄触发黑暗凋零远程杀死冈玛。战城内埃及军正与海夫拉亡灵大军血战，沙土迷宫般的建筑便于暗影系活动。莫凡在一座硬土大楼遭遇黑蝎怪袭击，抬手用空间系念力把砸落的楼骸砸向大蝎怪将其碾扁，震撼了在场猎人们。女猎人杰妮告之总指挥是伊森军首，并讲述其从边城将军一步步爬上开罗五大军首之一的履历，言语间满是崇拜，莫凡随即朝方塔方向行去。

**关键事件**：1.莫凡凭黑暗物质追踪冈玛至开罗战城，决定祭统领级精魄远程杀他 2.莫凡用空间系念力碾杀黑蝎怪，震慑猎人小队 3.杰妮透露总指挥为伊森军首，莫凡向方塔行进

- **情绪流向**：起：黑暗追踪 → 承：潜入战城 → 转：空间秒杀 → 合：锁定目标
- **节奏配比**：慢铺垫 40% / 快冲突 30% / 爽点爆发 20% / 悬念留白 10%
