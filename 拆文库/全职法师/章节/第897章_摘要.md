# 第897章 更可怕的事情

**概要**：莫凡见穆宁雪毒发，血墨异光浮现欲恶魔化速斩黑教廷，灵灵通讯严厉制止，指出恶魔化需用数十万居民为祭体、会失控屠戮崇明岛。莫凡眼神澄清打消念头。灵灵告知毒变因子与早年鳞皮母妖同源：众人饮下的茶水含细微毒虫，受母虫信号发动便破坏身体，杀母虫则寄生毒虫尽死。但灵灵警告还有更可怕后续——主楼外那些毒变死者竟裂皮坐起，露出青眼重生为怪物。

**关键事件**：1.灵灵制止莫凡恶魔化 2.灵灵析毒变源于鳞皮母妖 3.杀母虫可解全盘 4.灵灵警告更可怕后续 5.毒变死者裂皮坐起

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|

**逐章写法公式**：

- **情绪流向**：起：欲恶魔化的紧绷 → 承：被劝止的后怕 → 转：母虫解法的期待 → 合：死者重生的恐怖
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：劝止恶魔化（控场） + 析母虫源（解法） + 警告后续（加压） + 死者坐起（惊悚）
- **本章核心技巧**：先给解法希望，再用"更可怕"反转把希望压回恐怖
- **卡点与伏笔**：结尾卡点：重生怪物多强，下章揭晓；伏笔：鳞皮母妖 → 早年悬赏案回扣
