# 第1235章 吃人妖怪

**概要**：医院里孩子昏死、气息虚弱的哭声连成一片，家长们认定是蛾女所为，怒不可遏地冲出医院冲向镇政大院，城市猎妖队挡都挡不住。众人冲入大院，却发现被冰霜锁链绑在石柱上的蛾女竟是本镇姑娘俞师师，气势先泄了一半。臃肿妇人王田华翻起旧账，称失踪的烂酒鬼常往俞师师家跑，必是被她吃了；关坪则辩解俞师师曾照看过落水的孩子。一名红眼女人持剪刀扑刺，俞师师周身涌出青色蚕丝结成蚕茧，剪刀无法深入半分。封广阔高声劝阻，强调必须先查清孩子身上是不是诅咒。莫凡在旁暗叹这像极了古代妖女被诬害的剧情，只是俞师师确实是蛾女，孩子昏死也确与她相关。莫凡亮出猎人大师与明珠学府导师双重身份，获准与她交谈，俞师师冷冷放话孩子要死她也别想活，并直言截断水源就是要桐乡颗粒无收、让镇民饿死。

**关键事件**：1.镇民认定蛾女害子，冲入镇政大院 2.发现蛾女竟是本镇姑娘俞师师，王田华指控她吃人 3.女人持剪刀刺俞师师，被青色蚕茧挡下 4.莫凡与俞师师对峙，得知她截断水脉欲饿死镇民

- **情绪流向**：起：孩子昏死的悲恸 → 承：镇民暴怒的洪流 → 转：俞师师身份的震惊 → 合：断水阴谋的对峙
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 5% / 悬念留白 30%
- **本章结构公式**：医院哭声引燃民怨（点燃）+ 冲院发现蛾女是熟人（反转）+ 王田华控诉与蚕茧自保（对峙）+ 莫凡俞师师互撂狠话（摊牌）
