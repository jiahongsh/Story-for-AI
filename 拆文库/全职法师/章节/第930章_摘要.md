# 第930章 说杀就杀！

**概要**：冲出戈壁谷众人疲惫，南荣倪清创莫凡。赵满延问原委，莫凡目光杀意盯陆一林。南珏怒斥陆一林坑害全队，陆一林死不认账。艾江图黑脸相向，陆一林打定主意抵赖。莫凡银光提陆一林摁石壁，说“你要我命我就要你命”。南珏南荣倪劝交导师处理，赵满延说杀了他陆家找麻烦、不如让赵家出面索赔。莫凡松手，忽更强意念将陆一林击飞入橘红戈壁谷，祖吉明黎凯风要救被莫凡烈焰阻隔，莫凡威严称谁救就跟谁为敌。陆一林落地惊醒新石魔，爬求救命，莫凡笑说“你能出来我既往不咎”。谷内传陆一林撕心裂肺惨叫，队伍沉寂。官鱼冷哼不屑，赵满延竖拇指。艾江图说莫凡不动手自己也不留这种人。蒋少絮无怜悯。蒋少絮低声问是否出面摆平陆家，莫凡说不需。队伍远去，凝华珠反应更强，南珏说再四公里见遗迹古城，众人见黑龙般黑灰飓风拔地贯云。

**关键事件**：1.陆一林抵赖，莫凡将其击飞入戈壁谷 2.陆一林死于禁月石魔，队伍沉寂 3.凝华珠更强，众人见黑灰飓风

**逐章写法公式**：

- **情绪流向**：起：质问与抵赖的僵持 → 承：劝阻与松手的假缓和 → 转：击飞入谷的爆发 → 合：惨叫与远去的余寒
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：质问抵赖（僵）+ 众劝松手（缓）+ 击飞入谷（爆）+ 惨叫远去（收）
- **本章核心技巧**：用“假宽恕+真报复”的二次反转完成复仇，借群像多评收束
- **卡点与伏笔**：结尾卡点：黑灰飓风现，下章期待遗迹城异象；埋设/回收伏笔：陆一林心胸狭窄 → 上章拔仪陷害的因果了结
