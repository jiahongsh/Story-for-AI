# 第159章 我全要了！

**概要**：尘埃散尽，全场看见幽狼兽止步在李俊巍面前不到1米处、四肢踩着藤墙，莫凡一声召回，它意犹未尽地踱步而回。许昭霆被追问是否一年没见莫凡，只能说这家伙总是莫名其妙的很强；罗宋暗骂幽狼兽变强，发狠要把给表兄妹的修炼资源全抢过来。召唤系学员因资源有望补回而振奋，又忧心离100人还差50人。莫凡盘算幽狼兽进阶后需冲击战将级的庞大资源，当众向萧院长质疑赛制不公，萧院长公布隐藏标准：召唤系若抵挡下200人轮番挑战，这一届所有院系的修炼资源归召唤系所有，全场沸腾，连周正华都不知道这条规矩。莫凡随即当众表态，抱拳说出"你们的资源，我全要了"，摘掉人畜无害的面具换上狂妄之极的脸。

**关键事件**：1.幽狼兽放李俊巍一马被召回，各方反应震动 2.萧院长公布200人换全系资源的隐藏规则 3.莫凡当众宣言夺取所有院系资源

**逐章写法公式**：

- **情绪流向**：起：爽（留情召回的余威） → 承：轻松（全系振奋与隐忧） → 转：紧张（隐藏规则公布） → 合：爽（全要了的宣言）
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 30% / 悬念留白 20%
- **本章结构公式**：召回收尾（了结上一战） + 各方反应层（铺震动面与罗宋暗线） + 质询引出新规则（抬赌注） + 宣言（把规则兑现成挑衅）
- **本章核心技巧**：用主角向规则制定者当众发问的方式引出隐藏规则，让设定公布变成对话冲突，并立刻用一句宣言把新赌注转成名场面。
- **卡点与伏笔**：结尾卡点：宣言式挑衅+莫凡换上狂妄之极的脸，下章期待全校反弹；埋设/回收伏笔：进阶期幽狼兽需战将级资源→夺资源的动机背书；罗宋要抢表兄妹资源→许昭霆一行的危机线；200人规则→白藏锋、牧奴娇压轴出场的总钩子。
