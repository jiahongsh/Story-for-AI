# 第524章 刀斧尸将

**概要**：石少菊以魔藤束缚巨牛般的大尸物，刀斧手臂却跺裂大地，岩壁防御被腐尸群刨薄。亡灵分奴仆、战将等阶，眼下这头滋养十年以上的上等尸将顶得上三只战将妖魔，且无受伤退怯一说，断臂还能自行跳起抓人。张小侯卖掉熔晶之钻换来的土系魔器令初阶地波重叠强化，一个流沼地波让大片腐尸沉入泥浆再凝固封死，但尸将体型太大无法牵制，最后防御被一刀劈开，血花溅起不知谁被砍中。队伍奔逃，秦虎狠心下令放弃被抓住的人，张小侯回头发现女军官贾曦被尸将长舌缠住腰部，正以冰锁苦撑。

**关键事件**：1.尸将规格揭晓：十年上等尸将，一尸将顶三战将，无受伤概念 2.张小侯魔器叠加地波困住百余腐尸，却被尸将劈开防御 3.队伍奔逃中有人被擒，张小侯发现贾曦被尸将长舌缠住

**逐章写法公式**：

- **情绪流向**：起：魔藤束缚的缠斗 → 承：尸将规格的压迫 → 转：地波定尸的爽快 → 合：防御被劈的绝望
- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 15% / 悬念留白 15%
- **本章结构公式**：石少菊控场（缠斗）+ 尸将科普（加压）+ 张小侯定尸（反攻）+ 贾曦被缠（新危机）
- **本章核心技巧**：怪物先给定量规格再施压，主角的灵种妙用与魔器置换互相印证成长
- **卡点与伏笔**：结尾卡点：贾曦被尸将长舌缠腰，下章救与不救的两难；埋设/回收伏笔：土系魔器重叠功效 → 本章实战验收
