# 第1284章 我来狩猎山人

**概要**：刘小佳的治愈系魔法让女法师腹部伤口快速愈合，莫凡从她口中问出灰林深处还有三四名活着的同伴，随即召唤出统领级飞川皑狼冲入林深处救人。赵满延和灵灵分析出山人专门埋伏在大紫椴树附近，摸清猎人的贪婪习性，专等两败俱伤的队伍下手，外昆嵛山出事的人会比想象多得多。莫凡循血腥味追出两三公里，用暗影禁锢与空间念力制住三头扛着人尸的战将级山人，搭起火刑架慢慢灼烤报复，一头三米多高的统领级山人从高草丛突袭莫凡，被飞川皑狼扑下，几番缠斗后跳上树干消失在灰林里。莫凡救下被拧断四肢的两名男法师和昏迷的女风系法师，处理完伤势正要返回，女风系法师惊醒后不分敌我放出风暴攻击莫凡，被莫凡随手用念力化解。莫凡告诉她山人占领大紫椴树区域、以虐杀人类为乐，并宣布在政府和军队赶来前，他要留下来猎杀这些山人，有多少杀多少。

**关键事件**：1.女法师指路，莫凡召唤飞川皑狼深入灰林救人 2.灵灵分析山人专在大紫椴树附近伏击猎人 3.莫凡暗影禁锢三头山人并火刑架灼烤 4.三米统领级山人偷袭，飞川皑狼扑挡，对方逃脱 5.救下被拧断四肢的猎人，女风系法师受惊攻击莫凡被化解 6.莫凡宣布留下猎杀山人

**逐章写法公式**：

- **情绪流向**：起：救人的急切 → 承：灵灵分析山人习性的压抑 → 转：火烤山人爽点与统领级山人偷袭的紧张 → 合：救人后宣言狩猎的热血
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：询问同伴下落立救人目标（推进） + 召唤飞川皑狼追踪制住山人（爽点） + 统领级山人偷袭与逃脱（冲突） + 救出猎人并宣言狩猎（定调）
- **本章核心技巧**：爽点-危机-悬念三段推进：先给火烤山人的报复爽，再安排更高位阶统领级山人偷袭制造压迫，最后放走强敌留后患，宣言狩猎收束情绪
- **卡点与伏笔**：结尾卡点：莫凡宣言「有多少我杀多少」、政府和军队未到，山人仍在狩猎 → 下章期待狩猎行动；埋设/回收伏笔：三米统领级山人逃脱 → 后文强敌；外昆嵛山原霸主死亡 → 山人占领动机
