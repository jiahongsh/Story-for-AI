# 第507章 附魂，魔王！（上）

**概要**：鬼妇以摄魂控心操纵被邪蛛控制的莫凡，借其火滋击杀心夏。莫凡双眼通红、看到的心夏变成鬼妇模样，双手颤抖间右手已燃起火焰，赵满延、张小侯惊声示警却来不及救援。千钧一发之际，被治愈精灵救回气力的火焰魔女化身火焰撞入莫凡身体，以强大心魂与鬼妇的心念控制抗衡，莫凡凭凝神项链与四系意志挣扎数秒，火焰魔女依附后他烈焰暴涨、火海复燃。鬼妇自知难敌，携火劫果实用地波逃窜，张小侯大喊示警，一直藏在暗中的灵灵抛出先前捕获吸血鬼聂东的光之网，将鬼妇罩住灼烧，鬼妇连滚带翻、痛不欲生。

**关键事件**：1.鬼妇操控莫凡杀心夏 2.火焰魔女依附莫凡救场 3.灵灵光之网罩住逃跑的鬼妇

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |

**逐章写法公式**：

- **情绪流向**：起：心夏将死的惊骇 → 承：莫凡挣扎的紧绷 → 转：火焰依附燃爆的爽 → 合：灵灵收网的意外
- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：摄魂控心暗算（危机制造） + 火焰魔女依附（力量爆发） + 鬼妇携果潜逃（目标转移） + 灵灵光网收网（反转解决）
- **本章核心技巧**：让救场者以附身合体的方式出场，同时用旧道具埋伏完成对逃跑反派的收割
- **卡点与伏笔**：结尾卡点：鬼妇落网被烧、扬言要杀灵灵，下章火焰战斧行刑；埋设/回收伏笔：光之网回收自聂东旧案，凝神项链与四系意志的作用已揭晓
