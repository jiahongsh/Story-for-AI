# 第124章

**概要**：莫凡按唐月指示抵达杭州北面的江南小镇戏水镇，镇上田地龟裂荒废、溪流尽失。在有间客栈见到唐月后，莫凡直问博城灾难时她的去向，猜她去天澜魔法高中教书是做不可告人的事；唐月亮明身份：她是魔法协会审判会的执法法师，黑教廷在博城的计划审判会有所察觉，但她一人之力最多牵制黑教廷名叫撒朗的家伙，其余只能交给斩空，并自责若更早察觉目的就不会酿成祸端。莫凡分析黑教廷策划十年还多、审判会只派她一人卧底，说明上头未足够重视；唐月回应信息已递交、已有高层接手，审判会用不了多久会给博城一个公道。随后转入正题：戏水镇的水资源全部干涸，据说不少别的城镇也发生这种怪事，唐月线索有限，需要莫凡协助跟踪窗外一个被审判会通缉的帽男——此人心术不正、杀的魔法师不比妖魔少。莫凡自认应付不了，唐月许诺拿下他后帮莫凡觉醒暗影系，莫凡立刻应承。

**关键事件**：1.唐月亮明审判员身份并交代博城真相 2.戏水镇等城镇水源离奇干涸 3.唐月请莫凡跟踪通缉犯并许诺帮他觉醒暗影系

**逐章写法公式**：

- **情绪流向**：起：怪镇的疑云 → 承：师生重逢的轻松 → 转：审判员身份揭晓的震动 → 合：跟踪任务的紧张
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：抵达戏水镇（异象开场）+ 客栈会面（情感回温）+ 身份揭晓（信息回收）+ 布置跟踪任务（行动钩）
