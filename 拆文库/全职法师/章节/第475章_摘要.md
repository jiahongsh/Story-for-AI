# 第475章 火劫（上）

**概要**：队伍度过沙惘河进入灼原北角，此地是火盆地形、中央燃烧火焰大地的神秘净土，传说地下藏着高级火种。莫凡花九百万搜集的信息显示炎姬栖息在灼原北角中部，喜欢火焰浓度高于正常五倍之处、孕育时盘踞火焰灵种处。灵灵取出四个锥形元素勘测器让众人埋入土中测元素浓度，埋探测器等于向妖魔发定位、需守护仪器，已有怪物被吸引过来。莫凡疑惑晨颖冒险跟来却什么都不要，不合常理却没有细问。张小侯发现前方烧得很高，火焰如山峦连绵起伏不断变大，莫凡猛然意识到火焰不是在变大而是在往他们移动，大喊快逃，火焰吞没地平线以浩瀚之势扑涌而来。

**关键事件**：1.队伍进入灼原北角，灵灵埋元素探测器测火焰灵种。 2.莫凡起疑晨颖别无所求却坚持同行的动机。 3.远处火焰不断变大，莫凡识破是火劫逼近，大喊快逃。

**逐章写法公式**：

- **情绪流向**：起：踏入灼原北角的期待 → 承：埋探测器、晨颖疑点的铺垫 → 转：远方火焰如山的震撼 → 合：识破火劫逼近、大喊快逃
- **节奏配比**：慢铺垫 45% / 快冲突 25% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：灼原情报铺陈（立目标）+ 埋探测器测灵种（推进程）+ 晨颖动机存疑（埋暗线）+ 火劫逼近快逃（爆转折）
- **本章核心技巧**：用大半章铺目标与疑点，结尾用识破的瞬间把期待全部砸向危险
- **卡点与伏笔**：结尾卡点：恐怖——火焰吞没地平线以浩瀚之势扑涌而来，火劫将至；埋设/回收伏笔：晨颖别无所求跟队 → 动机疑点延续至后续章节
