# 第1071章 极品兽魂

**概要**：莫凡意外顺利将召唤系突破至高阶，随即按庞莱之法为疾星狼进行强骨、换血，疾星狼痛如动过全身手术。塑魂最为痛苦，需召唤兽有极强变强信念，而疾星狼生于兽系古荒大陆、在厮杀中求生，信念充足。小炎姬在一旁舞火焰花环为狼叔叔加油。莫凡引兽魂入体时，因兽魂等级为统领、远强于战将级疾星狼之魂，须以心念松紧有度地牵制。他本奇怪此魂连神殿副长老都争抢，直到疾星狼恐慌退缩、他细看兽魂形态，才发现这看似平常的兽魂竟是栩栩如生的极南冰界大妖，气势胜过早遇的深海伪龙。莫凡盛赞庞莱眼力挑出极品，鼓舞疾星狼拼死塑魂、踏足统领。

**关键事件**：1.莫凡顺利进高阶并为疾星狼强骨换血 2.交代古荒大陆与疾星狼身世背景 3.塑魂开始，莫凡以心念牵制统领级兽魂 4.兽魂现极南冰界大妖原形，莫凡识为极品 5.莫凡鼓舞疾星狼拼死塑魂

**逐章写法公式**：

- **情绪流向**：起：进阶顺利的轻松 → 承：痛苦与背景铺垫加压 → 转：兽魂原形反转揭晓 → 合：鼓舞拼死塑魂的燃点
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：强骨换血写痛（铺垫） + 古荒背景补信念（铺垫） + 塑魂牵制写险（加压） + 兽魂现形反转（高潮）
- **本章核心技巧**：用"角色先疑后恐、再反转揭价值"的延迟揭示，把宝物分量通过对比锚点放大
- **卡点与伏笔**：结尾卡点：疾星狼能否拼死塑魂，下章期待蜕变；埋设/回收伏笔：极南冰界兽魂 → 飞川皑狼来历
