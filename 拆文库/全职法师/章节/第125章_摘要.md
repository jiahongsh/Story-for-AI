# 第125章 火系灵种

**概要**：出发前莫凡又从唐月处"骗"得雷系、火系星图之书各三张，连同原有共七张中阶魔法牌；唐月提醒星图之书用多了星子会难把控、像把孩子给别人养，建议这次用完就停手。莫凡扮成背包客尾随帽男到荒田，目击帽男向老农打听干涸起始时间——约十天前、上游水池变浅，老农还劝他别去上游、那里热得像烧起来。帽男独自往上游去后，唐月以暗影技能神出鬼没地现身会合，两人跟入山中：溪床全干、植物成片萎蔫，莫凡手机还断了信号。唐月突然捂住莫凡的嘴、把他拉进树影，两人身形完全隐没。随后一支猎法师队伍出现，领头的潘熊断言这里一定出了火系灵种、趁没人发现赶紧摘了就发达；疤脸男警告他别耍大家，眼镜男分析短时间变这样绝非干旱，众人决定抢先锁定灵种位置，还叮嘱潘熊灵种要卖掉分钱、不许私自炼化。

**关键事件**：1.莫凡获七张星图之书并受副作用警告 2.师生循老农线索追向干涸溪流上游 3.猎法师队伍现身断言此处有火系灵种

**逐章写法公式**：

- **情绪流向**：起：跟踪的紧张 → 承：线索汇聚的疑云 → 转：捂嘴藏身的心跳 → 合：灵种之名的悬念
- **节奏配比**：慢铺垫 55% / 快冲突 15% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：领取道具（装备更新）+ 荒田问询（线索采集）+ 树影藏身（危机回避）+ 猎法师亮出灵种目标（悬念升级）
- **本章核心技巧**：跟踪戏用"跟丢—补问—再跟上"的节奏避免平铺，让每个环节都换来一条新线索
- **卡点与伏笔**：结尾卡点：火系灵种到底是什么、价值几何，下章借唐月讲解回收；埋设/回收伏笔：星图之书副作用（修炼隐患线）、十天前干涸与上游高温（灵种位置线）、上游聚集的人越来越多（多方争夺伏笔）、潘熊不许私炼之约（队伍内讧隐患）
