# 第715章 别人办不了的事

**概要**：刘孟一路被蒋少絮逗得神魂颠倒，赵满延感慨圣女敌不过狐媚。七八十里路刘孟累垮而法师们步伐暗藏魔法极快，终见飞鸟市与海河港口。赵满延凭财团眼光断言这完美港口本应带飞整城，现实却萧条得反常，断定海妖挡了财路。野兽男祖吉明点破无身份难乘船，莫凡答称法师可替人解决麻烦换偷渡之便，抛下"办一般人办不了的事"的破局思路。

**关键事件**：1.蒋少絮戏弄刘孟使其臣服 2.抵飞鸟市见海河港口 3.赵满延评港口繁荣反差断定海妖挡财 4.莫凡抛"办一般人办不了的事"破局

**逐章写法公式**：

- **情绪流向**：起：蒋少絮戏弄的轻松 → 承：赶路见城的期待 → 转：港口反常的疑惑 → 合：莫凡破局思路的爽利
- **节奏配比**：慢铺垫 45% / 快冲突 0% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：戏弄刘孟（群像喜剧） + 赶路见飞鸟市（推进） + 港口反常分析（埋谜） + 莫凡破局思路（立题眼）
- **本章核心技巧**：用专业配角视角分析环境反常，再把破局法交给主角的职业身份，使悬念与解法同章落地
- **卡点与伏笔**：结尾卡点：悬念型，"办一般人办不了的事"留白，下章期待接什么麻烦换船；埋设/回收伏笔：海妖挡财路 → 衔接下章林氏财团；飞鸟港口 → 后续行动基地
