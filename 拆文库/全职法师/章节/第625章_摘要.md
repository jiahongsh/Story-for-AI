# 第625章 博城与古都

**概要**：钟楼瞭望塔内，神秘灰白男子揭开古都大雨与博城灾难之间的联系，指出博城只是黑教廷以一城生命进行的预演，真正目标是借九幽之露唤醒古老王、摧毁内城传承结界。众人得知昆井源泉能够中和九幽之露，并可争取半天寻找皇陵、封印古老王，但方谷下落不明。面对身份未明的高层集会，神秘男子拒绝摘下面具，怀疑撒朗或其同党就在众人之中。

**关键事件**：1.神秘男子揭露博城灾难是古都阴谋的预演 2.众人得知九幽之露与昆井源泉的关系 3.封印古老王成为解决浩劫的关键 4.神秘男子怀疑高层中藏有撒朗同党

**逐章写法公式**：

- **情绪流向**：起：寂静与震惊 → 承：阴谋规模加压 → 转：昆井源泉带来生机 → 合：身份猜疑留下钩子
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：抛出预演真相（扩大危机） + 解释雨水来源（补全因果） + 提出昆井源泉（给出窗口） + 拒绝露脸（留下内鬼悬念）
- **本章核心技巧**：用一场高层对话把旧灾难、当前浩劫和后续行动目标压缩到同一条阴谋链上。
- **卡点与伏笔**：结尾卡点：神秘男子拒绝摘面具并怀疑在座有人是撒朗，下一步期待锁定内鬼；埋设/回收伏笔：博城灾难与昆井源泉 → 解释古都大雨的实验来源。
