# 第1281章 似人之皮

**概要**：莫凡与晨颖赶到郭木壮指认处，只找到一具无法辨认的残骸，晨颖凭护腕认出死者正是瘦男，两人埋尸后返回，途中意外撞见另一颗更成熟的大紫椴树，树下草地猩红、堆满被咀嚼撕毁的各类残骸，其中不少明显是人。回到集合地，众人得知瘦男死讯后更坚决留守；莫凡、赵满延决定带着郭木壮去找治愈法师，与汪华、陈彬彬等人当场分道扬镳，关溪溪选择跟随。灵灵分析山人应是趁原霸主死亡涌入的外来物种，主张通知政府和军队紧急召回猎人；赵满延则点破进山的猎人平均只有中阶，多数根本不是山人对手。三人途中借飞川皑狼的嗅觉找到第一支收获颇丰的猎人队伍，对方却既没遇过山人、也没有治愈系法师。另一头，猎人茂哥听到山人传言不以为然，认定是竞争者散布谣言吓退胆小鬼，正教训手下小宝时一脚踩入填满血浆残骸的红黑池，扒开树叶赫然看见一张血淋漓的似人之皮。

**关键事件**：1.找到瘦男残骸并埋葬，又见尸堆 2.队伍一分为二，莫凡赵满延带郭木壮求医 3.茂哥队伍误入山人屠宰场发现似人之皮

**逐章写法公式**：

- **情绪流向**：起：悲伤（认尸埋尸） → 承：惊悚（尸堆） → 转：分裂（去留之争） → 合：恐怖（似人之皮）
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：认尸埋尸（给出伤亡）+ 尸堆冲击（放大恐怖）+ 队伍分裂（主角线）+ 无知者遇险（对照组）
- **本章核心技巧**：用平行剪辑让主角线求医无门与配角线无知冒险交叉推进，同时把恐怖与讽刺两种情绪放大
- **卡点与伏笔**：结尾卡点：恐怖定格型，茂哥队伍发现似人之皮，猎人群体即将大批遭难；埋设/回收伏笔：飞川皑狼的嗅觉追踪→后续追踪山人老巢；妖冠为诱饵的猜测→山人囤积妖冠
