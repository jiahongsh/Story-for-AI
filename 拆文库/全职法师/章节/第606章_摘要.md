# 第606章 亡城，紫色警戒！

**概要**：军司陆虚带着失去右臂的伤势返回城楼，四名超阶法师发现亡灵在曙光下仍然活动。巨大的骸刹冥主从北面飞来，陆虚认出它是凶名超过鬼魆暴君的骷髅之主。骸刹冥主在数公里外释放死亡冲击波，北城墙一整段连同附近街区和医院被噬成碎屑。矮男得知怀孕待产的妻子可能在医院，冲动地要出城送死，莫凡用遁影和巨影钉将他拦住。随后北城区被紫色警戒笼罩，古都进入更高等级的灾难状态。

**关键事件**：1.骸刹冥主在白昼出现 2.死亡冲击波摧毁北城墙和医院街区 3.莫凡阻止矮男冲出城楼并拉响紫色警戒

**逐章写法公式**：

- **情绪流向**：起：白昼异常的惊慌 → 承：骸刹冥主现身的恐惧 → 转：死亡冲击波摧毁城墙与医院 → 合：紫色警戒拉响并逼迫所有人撤离
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：强敌登场（刷新尺度） + 死亡波释放（摧毁防线） + 亲人线受击（具体化代价） + 警戒升级（改变全城状态）
- **本章核心技巧**：先用宏观攻击制造视觉冲击，再用医院和待产妻子把灾难后果压到单个角色身上。
- **卡点与伏笔**：结尾卡点：紫色警戒笼罩北城区，安全结界外连法师也难存活；埋设/回收伏笔：莫凡对博城灾难的记忆 → 推动他从单纯撤离转向寻找灾难背后的黑教廷线索。
