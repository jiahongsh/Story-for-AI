# 第854章 骨刀木乃伊（上）

**概要**：学员分析灰布铁尸体型不大却重量惊人、撞上便如东方烈那般，岳棠心自认植物系比牧奴娇更精通亡灵，主动请战获白东威点头。赛义德见女学员眯眼饶有兴致，提醒"大伙计不留情"反被当挑衅。灰布铁尸跳跃十米冲来，岳棠心退后洒下浅绿光点催熟魔藤，待布置完整才出手"魔藤-追袭"缠住铁尸双腿拽地，再布中阶"坤之林"将其困于植物泥潭，学员喝彩、白东威稍安。赛义德却平静称亡灵不止一只，问她能困多少，浊井中先探出的竟是一柄黑色大骨刀。

**关键事件**：1.岳棠心请战，植物系克亡灵 2.魔藤追袭缠铁尸，坤之林困住 3.学员喝彩，白东威稍安 4.赛义德召第二只，浊井先出黑骨刀

- **情绪流向**：起：铁尸重量分析+岳棠心请战 → 承：魔藤布局困铁尸 → 转：坤之林锁死喝彩 → 合：第二只亡灵骨刀现身
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：请战立专（铺垫） + 魔藤布局（智斗） + 坤之林锁（爽） + 骨刀现身（钩子）

- **卡点与伏笔**：结尾卡点：浊井先出黑骨刀，下章期待死刀木乃伊登场；埋设/回收伏笔：岳棠心植物系专精 → 与牧奴娇植物系的对照伏笔
