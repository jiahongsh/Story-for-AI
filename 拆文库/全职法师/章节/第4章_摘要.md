# 第4章 法系觉醒

**概要**：觉醒在20个班级同时进行，莫凡是8班第48号、全班最后一个接受觉醒恩赐。穆白的狗腿子赵坤三当众嘲讽走后门的莫凡会觉醒失败、浪费昂贵的觉醒石能量；张候让莫凡觉醒火系打脸。排队时莫凡发现脖子上嬴老头遗物的黑色坠子从今早起不停颤动，他怀疑这就是世界巨变的罪魁祸首。穆白觉醒穆家本源的寒冰系，寒霜直接冻结觉醒石边缘结成小片冰霜，全班尖叫，薛木生盛赞这是很纯净的冰系、天赋超越常人；穆白暗想自己将更容易被穆家接纳，飞黄腾达之日不远。随后邱月英觉醒土系、许青林觉醒寒冰系却只有淡淡霜雾，陆小斌觉醒水系当场崩溃怪叫。莫凡旁观理清觉醒系含金量：火系初阶就有战斗力，水系初阶技能水御不精修作用不明显。

**关键事件**：1.赵坤三当众唱衰莫凡觉醒失败，张候怒护 2.穆白觉醒穆家本源寒冰系并冻结觉醒石，风头无双 3.莫凡脖子上的黑色坠子狂颤，被指为世界巨变罪魁 4.多名同学陆续觉醒，各系含金量通过对比铺陈

**逐章写法公式**：

- **情绪流向**：起：排队看戏的轻松 → 承：赵坤三唱衰的憋气 → 转：穆白高光觉醒的压迫 → 合：48号将至的紧张
- **节奏配比**：慢铺垫 50% / 快冲突 20% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：规则交代（立仪式）+ 唱衰与助威（拉仇恨）+ 坠子异动（埋金手指）+ 穆白高光（立标杆）+ 群像觉醒（铺系别差异）
- **本章核心技巧**：用一串配角觉醒结果做成"系别含金量对照表"，既教读者规则又给主角的雷火双系提前垫好参照系
- **卡点与伏笔**：结尾卡点：期待型——垫底的48号莫凡终于要上前觉醒，成败与系别双悬念；埋设/回收伏笔：黑色坠子今早狂颤→与第1章戒指/位面巨变呼应，觉醒异变的引信；赵坤三的唱衰→后续打脸债；穆白寒冰系高光→主角双系碾压的对照标尺
