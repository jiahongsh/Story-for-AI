# 第978章 摄魂陷阱！

**概要**：自由岛上，疾星狼幽怨地驮着灵灵的行李步入神殿广场，莫凡一眼读懂它的不情愿。因安全考量，神殿将莫凡安置在自由岛居住，莫凡也怕再伤及无辜不敢乱走，包老头更特意叮嘱其勿鲁莽——这位前神殿法师裴历不仅实力可怕，心计也难捉摸，故令灵灵当日飞抵纽约相助。莫凡不愿坐以待毙，与灵灵盘算底牌：凝华邪珠只集得部分，但尚有三分之一时光之液可令小炎姬化身炎姬女王，以火系领域融化冰雹领域；他坦言裴历冰之领域压火系四到五成，无领域时尚可周旋。穆宁雪主动请缨处理冰之领域，赵满延主张叫上蒋少絮防心灵袭击、合力围猎。与此同时，卡里加力医院里康复的李雨娥凭超常记忆认出戴口罩的清洁工正是行刑人，隐忍不呼救；裴历摘口罩以心灵之剑摄魂控心，操控她打电话将莫凡引来医院设伏。赵满延还以为莫凡是艳遇，莫凡却看着电话脸色骤变。

**关键事件**：1.神殿安置莫凡限足，灵灵携底牌助阵 2.众人定下纽约合猎行刑人之计 3.李雨娥识破裴历伪装 4.裴历摄魂控心引莫凡入医院陷阱

**逐章写法公式**：

- **情绪流向**：起：限足无奈的闷 → 承：底牌清点的期待 → 转：合猎定计的紧 → 合：医院陷阱的悬
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：神殿限足安置（设困） + 底牌清点定计（布局） + 李雨娥识破（破局前奏） + 摄魂引君（钩子）
- **本章核心技巧**：用"战前底牌清点+配角记忆伏笔"把被动围猎翻成主动布局
- **卡点与伏笔**：结尾卡点：危机型，被控李雨娥来电引莫凡入医院，下章期待莫凡如何识破反杀；埋设/回收伏笔：李雨娥记姓氏 → 回收上章细心伏笔；暗爵斗篷 → 新装备伏笔待用
