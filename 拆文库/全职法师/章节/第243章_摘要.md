# 第243章 智斗教廷（下）

**概要**：莫凡拖着重伤自曝苦肉计：为留住宇昂与蓝衣执事，他故意让小泥鳅坠散出完整地圣泉气息令宇昂失智，并疑心天材地宝众多的黑教廷处心积虑谋泉必有蹊跷，联想起心夏说过的博城守护近两千年古老秘密。诅咒畜妖攻势不停，轻易躲开雷印火滋、一爪几乎将莫凡从头颅劈成两半，莫凡却借遁影在迷雾中移形换位，令宇昂扑空气结。傅天明急报司夜统治大阵正在消失、黑暗迷宫散尽喷泉广场外露，宇昂怕身份暴露又忌惮实力远强于学员的校方老师，强令傅天明、贾文清从摸熟的小铁门杀入笼中夺泉。莫凡本为诱宇昂入笼才隐藏实力，见其阴险不肯以身试险，遂不再藏：立于笼中央描画暗影星图，胸前鲜血滴落图上更添邪异，祭出如细长影锋剑般的巨影钉、瞬间贯穿空间消失。二人看傻——莫凡竟是暗影系魔法师；宇昂愤怒颤抖，点破火雷召唤暗影四系集于一身、初阶双系中阶四系高阶恐达六系的逆天天赋，嘶吼杀他。

**关键事件**：1.莫凡自曝苦肉计并疑心地圣泉藏两千年古秘 2.司夜大阵消散，宇昂强令傅天明贾文清入笼夺泉 3.莫凡祭出暗影系巨影钉，四系天赋震惊教廷众人

**逐章写法公式**：

- **情绪流向**：起：压抑（重伤自曝苦肉计） → 承：紧张（避爪、大阵消散、二教徒入笼） → 转：爽（巨影钉穿空） → 合：爽（四系天赋震撼全场、宇昂嘶吼）
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：苦肉计自白（交代策略） + 大阵消散（外部时钟加压） + 二人入笼（诱敌变奏） + 巨影钉掀牌（爽点爆发）

- **卡点与伏笔**：结尾卡点：爆发前夜——影钉穿空未着、宇昂嘶吼杀人，下章期待影钉收割与教廷落网；埋设/回收伏笔：地圣泉或藏特殊作用＋博城两千年古秘（心夏之言）→ 长线大伏笔；司夜统治大阵消散 → 身份暴露与校方驰援时钟；小泥鳅坠 → 地圣泉容器；"每次觉醒得两系"被宇昂点破 → 天赋线升级
