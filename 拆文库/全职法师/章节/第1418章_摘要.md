# 第1418章 当个议员玩玩

**概要**：莫凡回明珠学府见邵郑竟选在自己家见面，牧奴娇因点外卖被邵郑顺手提上楼而紧张无措、忙沏茶招待。邵郑笑言自己也是母校毕业。谈起胡夫金字塔——此事未公开，北原迁徙被视作基地城正常安顿，邵郑请求暂封锁消息以免社会不安、待基地城稳固再联合埃及公布，莫凡应允。邵郑告知明日将冷爵送国际法庭由圣裁院判决，莫凡主张"杀鸡儆猴"晒其罪行敲打黑教廷，并同意移交圣裁院——一来还邵郑人情，二来让圣裁院对莫凡在帕特农之事与图腾玄蛇睁只眼闭只眼。邵郑笑提让莫凡当议员，莫凡摆手推辞，邵郑却点出凡雪山划入飞鸟基地城后土地价值百千倍上升，加以古都名望与世界学府第一，当议员名正言顺。

**关键事件**：1.邵郑家宴谢莫凡，胡夫之事暂不公开 2.冷爵移交圣裁院判决，换圣裁院人情与图腾玄蛇解脱 3.邵郑点出凡雪山价值飙升、邀莫凡当议员

**逐章写法公式**：

- **情绪流向**：起：邵郑家宴的轻松 → 承：胡夫封锁、冷爵移交的政治操作 → 转：圣裁院人情与图腾解脱 → 合：凡雪山价值飙升、议员邀约的钩子
- **节奏配比**：慢铺垫 15% / 快冲突 10% / 爽点爆发 25% / 悬念留白 50%
- **本章结构公式**：家宴谢功（轻） + 胡夫封锁冷爵移交（操作） + 圣裁院人情（收束） + 凡雪山价值（钩子）
- **本章核心技巧**：用配角把政治操作的多重收益写成明牌，再以"地价跳变"把前设强抢隐患翻转为机遇，收束伏笔。
- **卡点与伏笔**：结尾卡点：凡雪山价值飙升、莫凡或成议员，下章期待凡雪山实地状况与穆宁雪；埋设/回收伏笔：凡雪山强抢隐患（1412/1414） → 本章基地城计划令其价值百千倍升，翻转为机遇
