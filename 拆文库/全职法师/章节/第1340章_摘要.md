# 第1340章 影煞魔将

**概要**：莫凡继续试验影煞魔将，却发现飞川皑狼周围没有出现多个强大的影煞魔将，他回忆与卑匠战斗时对方直接捏出许多能自主行走、协同作战的魔影子，自己献祭了统领级残魄却毫无动静。莫凡思考良久意识到，复制影煞需要足够的黑暗能量来捏成。他完成暗影系高阶魔法司夜统治，整个训练场遁入黑暗，黑暗气息浓烈放大恐惧并提升黑暗生物实力。在司夜统治的领域中，莫凡再献祭一个统领级残魄施展夜煞之影，一团黑色气体渐渐雕成狼的轮廓，幻化成复制飞川皑狼的影煞魔将。飞川皑狼扑咬时影煞魔将化作烟散开又在不远处聚拢，随后以同样的扑咬反噬，咬中飞川皑狼身侧，留下黑色腐败痕迹。莫凡由此明白卑匠当时使用的是黑魔潭，影煞魔将从黑暗领域诞生。他信心大增，盘算火系、暗影系及其他系修炼，渴望开启灵灵所说的第二契约、再得一只黑暗属性契约兽。随后莫凡返回武夷山审判会，给监察长程英埋下黑暗种子。

**关键事件**：1.莫凡在司夜统治领域中成功捏出复制飞川皑狼的影煞魔将 2.影煞魔将需黑暗系领域才能诞生，莫凡摸透原理 3.莫凡返回武夷山给程英埋下黑暗种子

- **情绪流向**：起：试验影煞魔将失败的疑惑 → 承：司夜统治领域的压迫性展开 → 转：影煞魔将成形的惊喜与反扑惊险 → 合：摸透原理、信心倍增并布下程英暗棋
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：影煞失败找原因（困惑） + 司夜统治施展（领域铺垫） + 影煞魔将成形对练（爽点） + 原理揭晓与修炼规划（收束） + 程英埋种（钩子）

- **卡点与伏笔**：结尾卡点：布局完成——程英已被黑暗种子侵染，逃脱不得；埋设/回收伏笔：黑魔潭→影煞魔将诞生条件；第二契约与黑暗契约兽→后续召唤系提升线；程英的黑暗种子→追踪冷爵一脉的引线
