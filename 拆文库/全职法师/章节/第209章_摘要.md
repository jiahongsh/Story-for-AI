# 第209章 离谱委托！

**概要**：寒假里莫凡与牧奴娇、艾图图同住一屋，自嘲鼻血长流此生无憾。他只在公共场合冥修雷系与召唤系，暗影系与火系则躲进房间并牢牢控制气息；艾图图有事没事想套他的秘密，莫凡吐槽别以为扑闪眼睛晃着胸口就能让他全盘托出。不久牧奴娇与艾图图回家过年，屋子成了莫凡与心夏两人的空间，心夏修炼认真、马上要突破中阶，莫凡想帮她一把，但小泥鳅坠与莫凡有灵魂联系，在别人手中与九元店挂饰无异，只能作罢，他自己也加紧冲击雷系与火系的下一个境界。寒假结束，莫凡送心夏回校，进入下半学期冲刺，频繁到青天猎所等委托——战斗是提升实力的最好方式，但猎所久无生意，莫凡闲到在阳台看人工湖亭子里亲吻的男女，吐槽几天不打架浑身不自在。灵灵终于来电说有活干，语气怪怪地让莫凡亲自到猎所一趟。包老头推来委托书：委托人自称被特殊情况缠身、只能派人到猎所，请派经验丰富的猎人保护一个人的安危，钱已先汇入账户且数目不小。莫凡读来读去发现不过是保镖委托，直到看清保护对象——委托书上分明写着明珠学府青校区召唤系新生莫凡，委托猎人保护猎人，莫凡当场瀑布汗。

**关键事件**：1.寒假同住日常，莫凡两系保密修炼、心夏将破中阶 2.开学后猎所无生意，莫凡闲得发慌 3.神秘委托到手，保护对象竟是莫凡本人

**逐章写法公式**：

- **情绪流向**：起：轻松（同居寒假日常）→ 承：无聊（猎所没生意的闲）→ 转：紧张（怪委托来电）→ 合：悬念（保护对象竟是自己的荒诞揭晓）
- **节奏配比**：慢铺垫 55% / 快冲突 5% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：寒假修炼日常（过渡蓄力）+ 开学无单闲疯（攒战斗渴望）+ 灵灵怪电话（起事件）+ 委托书揭晓（抛荒诞悬念）
- **本章核心技巧**：用长日常压低节奏后，靠一个反常电话和一纸荒诞委托在章尾骤然拉起悬念，闲与怪的反差就是钩子。
- **卡点与伏笔**：结尾卡点：悬念爆点（谁花大钱委托保护莫凡，委托猎人保护猎人）；埋设/回收伏笔：小泥鳅坠只认莫凡灵魂 → 成长型魔器独占性再确认；猎所委托一次三十万 → 身价对比此次数目不小；灵灵语气怪异 → 猎所内部也觉蹊跷；心夏将突破中阶 → 修为进度线。
