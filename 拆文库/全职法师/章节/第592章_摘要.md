# 第592章 黑色尘暴，尸臣

**概要**：妖男在腐尸军团中发现穿白色鬼衣、处于半虚无状态的亡灵，队伍随即加速向战略地点汇合。黑色腐尸中卷起沙尘暴，天鹰法师的雪白天鹰被肉触手贯穿并在数秒内抽干生命，众人由此确认沙尘暴中的敌人是统领级尸臣。集结法师面对尸臣和周围尸群陷入恐慌，妖男却命令他们继续前进，表示自己会处理尸臣，并点名刚归队的莫凡作为副队长随行出战。

**关键事件**：1.妖男发现白衣亡灵和黑色尘暴 2.天鹰被触手抽干生命并确认尸臣 3.妖男命令莫凡随他迎战尸臣

**逐章写法公式**：

- **情绪流向**：起：汇合推进 → 承：异常尘暴逼近 → 转：天鹰惨死揭示尸臣 → 合：妖男和莫凡被推向新战场
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：发现白衣亡灵（建立征兆） + 尘暴突袭（展示危险） + 众人恐慌（放大等级差） + 妖男点将（切入新冲突）
- **本章核心技巧**：用一只召唤兽的瞬间死亡把抽象的统领级威胁具象化，再用强硬命令把信息转成行动压力。
- **卡点与伏笔**：结尾卡点：妖男要求刚归队的莫凡一起宰尸臣，期待两人如何分工；埋设/回收伏笔：黑色沙尘暴中的肉触手 → 后续尸臣战斗。
