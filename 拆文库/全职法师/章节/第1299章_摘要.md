# 第1299章 树下的血流成河

**概要**：海边的岩氏（晨颖外婆）正享受安逸时光，隔壁小女孩小东霞哭着跑来，说她养的很有灵性的小雀死了——它每天都等在院口等她放学，今天却落在树下不会飞也不会跳。岩氏安慰她以后由自己等她，并劝解年轻父母别让小孩孤独成长。小东霞走后，岩氏挖开树下埋小雀的地方想查明死因，却发现尸体已经只剩羽毛腐肉、降解速度极快，仿佛埋了超过一星期。她猛然想起什么，骇然颤抖，发疯般砸东西后爆发出庞大凌厉的气息，佝偻的身躯窜出上千米，如雄鹰般怒击长天，飞向外昆嵛山方向。另一边，天冠紫椴神树树下血流成河，彩尾妖雀群体发动攻击消灭山人，人类军队与猎人在政府领头下组成厮杀之队复仇，军统与音系高手聂冷山指挥得当，山人惨死两千多，七只古铜牙山人凭统领级战力撑住狂攻。四大五粗的军官率精英百人团撕开缺口，召唤生物冲入粉碎山人鱼群战术。莫凡一行在树层观战，芍女介绍这是烟台王牌、聂冷山是国内高阶法师最强梯次且音系能力在战争中可超越超阶法师。莫凡等古铜牙大山人现身，决定下去杀它报仇。

**关键事件**：1.小东霞的小雀死亡，岩氏安慰她 2.岩氏挖坟发现尸体降解异常，爆发惊人力量飞向外昆嵛山 3.树下彩尾妖雀群攻山人、人类军队组成复仇队围剿 4.山人惨死两千多，七只古铜牙山人撑住狂攻 5.莫凡一行观战，芍女介绍聂冷山，决定等古铜牙大山人

**逐章写法公式**：

- **情绪流向**：起：海边日常的温馨 → 承：小雀死因异常的诡异 → 转：岩氏觉醒暴走的震撼 → 合：树下血战与聂冷山实力的铺垫
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：岩氏日常与小雀之死（铺垫） + 挖坟发现异常觉醒（转折） + 树下人妖血战（战场） + 观战议敌与锁定目标（钩子）
- **本章核心技巧**：用「日常温情-异常细节-强者觉醒」三段式在配角线上造悬念，再切回主战场完成环境升级，两线并行各留钩子
- **卡点与伏笔**：结尾卡点：莫凡决定下去杀古铜牙大山人报仇，那只偷袭他的家伙尚未现身 → 下章期待复仇战；埋设/回收伏笔：岩氏暴走飞向外昆嵛山 → 晨颖外婆与神树的关系即将揭晓；小雀尸体异常 → 神树枯竭征兆
