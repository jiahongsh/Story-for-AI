# 第732章 火焰星座

**概要**：冰面碎裂众人退岛，穆宁雪被莫凡气着更专心冻结。官鱼怒骂莫凡乘人之危。莫凡再提"初吻是我夺的"，穆宁雪心境一乱冰散，怒令其离十米。她凝风壁悬浮如冰雪精灵，冰域更强反将海域彻底封死。四五十只赤凌妖全冲穆宁雪，蒋少絮主张趁机杀妖。莫凡庄严护她，周身火系星图交织成华丽火焰星座。

**关键事件**：1.穆宁雪被气更专心冻结 2.初吻梗乱其心境冰散 3.穆宁雪风壁悬浮强封海 4.赤凌妖全冲穆宁雪莫凡护她燃星座

**逐章写法公式**：

- **情绪流向**：起：退岛的稳 → 承：初吻乱心的甜扰 → 转：风壁强封的炫 → 合：护花燃星座的燃
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：穆宁雪被气专心（变量） + 初吻乱心境（甜扰） + 风壁强封（高光） + 护花燃星座（爆发前）
- **本章核心技巧**：把感情戏当作战力开关，用角色情绪起伏驱动场景转折
- **卡点与伏笔**：结尾卡点：火焰星座成型；埋设/回收伏笔：火焰星座→下章天焰葬礼
