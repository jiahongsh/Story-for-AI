# 第677章 怒燃胸腔！

**概要**：莫凡穿过手刀骷髅组成的骷髅林找到小炎姬，发现她以千层爆破清掉数百骷髅后已力竭。锋刃骨将突然现身，将飞向莫凡的小炎姬斩倒，莫凡以烈拳轰碎其头颅后背起重伤的小炎姬，在骷髅包围中连续落雷、施展地煞，并报出星子强化计数。发现无头的锋刃骨将仍在指挥部下后，他以遁影穿过骨群，来到对方面前追击。

**关键事件**：1.小炎姬力竭后遭锋刃骨将偷袭重伤。 2.莫凡愤怒反击并在骷髅围堵中持续清场。 3.锋刃骨将未死且继续调兵，莫凡遁影追至其前。

**逐章写法公式**：

- **情绪流向**：起：紧张 → 承：悲伤 → 转：热血 → 合：紧张
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：找到同伴动作（确认伤势） + 近身反击动作（击退骨将） + 范围清场动作（抵住围攻） + 遁影追击动作（锁定骨将）
- **本章核心技巧**：用受伤同伴触发即时反击，再以敌军补入把单次胜利压回包围战。
- **卡点与伏笔**：结尾卡点：追击类，莫凡遁影来到无头锋刃骨将面前；埋设/回收伏笔：星子强化计数 → 提示战斗收益仍在累积。
