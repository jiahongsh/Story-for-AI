# 第572章 装得一手好B

**概要**：众人随周敏到西北城角执勤点，这里亡灵数量少，适合学生历练刷排行，城墙宽阔如大马路，角城楼里各系法师往来像小型驿站。周敏带大家到隔屋，屋里坐着别着校徽的学府学员，她胸前戴着火图状徽章，表明火系中阶星云第二级。微胖青年蒋黎以没有法师之章为由让闲杂人离开，周敏急说是来帮忙执勤的高中同学，穆白安排初阶的赵坤三、王三胖在城墙边做接应。蒋黎又发现莫凡还没戴章，瞪眼呵斥他聋还是怎么的。莫凡无所谓地笑笑，随手从口袋掏出一个法师之章戴上，结果抓到的是暗影系中阶第二级，蒋黎嗤之以鼻说明珠学府也就那样。王三胖追问莫凡辅修系都中阶二级，主修的两系呢，莫凡如实说更高一些，王三胖惊为天人，贼笑着夸他装得一手好B。

**关键事件**：1.蒋黎两次刁难没戴法师之章的莫凡 2.莫凡随手掏出暗影系中阶第二级法师之章，蒋黎仍轻蔑 3.王三胖追问出莫凡主修系更高，调侃他装得一手好B

**逐章写法公式**：

- **情绪流向**：起：新鲜（城墙夜景） → 承：憋屈（蒋黎刁难） → 转：爽快（随手掏章） → 合：期待（真实实力未露）
- **节奏配比**：慢铺垫 40% / 快冲突 30% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：城墙见闻（世界观） + 章徽刁难（冲突） + 随手掏章（爽点） + 王三胖点破（蓄势）
- **本章核心技巧**：用藏一手的身份误解制造持续爽点，让配角嘴替读者发问
- **卡点与伏笔**：结尾卡点：出城作战在即，真实实力何时暴露，下章期待战将级亡灵；埋设/回收伏笔：莫凡四个法师之章的主修系
