# 第1196章 自掘坟墓

**概要**：莫凡未立刻答应，仍在气头上，但信得过祝蒙，知陆斩天下半生基本废了。陆辛不甘两个儿子毁于莫凡之手、陆家眼看坐大却崩塌。祝蒙劝陆辛别放议员架子，点出莫凡功绩连议员都未必及，更提及帕特农神庙风波乃莫凡卷起、图腾玄蛇为其踏平神山，陆辛瞪眼难以置信。祝蒙又说最可怕的未必是图腾玄蛇，递过议长邵郑电话，陆辛接听后脸色大变、保证不传第二人，反多几分感激。陆辛对莫凡保证陆家绝不找他及家人麻烦，莫凡冷嘲“上回宰了陆一林，这回饶命好大脸面”。陆辛求饶，莫凡示意博拉放人，祝蒙说陆斩天滥用私刑伤愈后将被带去议长处受罚。

**关键事件**：1.祝蒙劝陆辛莫放架子、提莫凡功绩 2.点破帕特农与图腾玄蛇、议长电话震慑 3.陆辛感激服软、保证不找麻烦 4.莫凡冷嘲、放人，陆斩天将受罚

- **本章结构公式**：祝蒙劝降（铺线） + 图腾玄蛇震慑（加压） + 议长电话服软（转折） + 冷嘲放人（收束钩子）
