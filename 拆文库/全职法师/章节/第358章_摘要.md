# 第358章 设计陷害

**概要**：唐月说明怀疑族内有与外勾结者、守护计划严格保密也可能走漏风声，她给审判长的建议是选信得过的外人——莫凡不属于族内、与哪方势力都无瓜葛、底子清白又机灵应变。莫凡自觉被拉上贼船，又被翻出一直欠她人情的旧账（当年一个星尘魔器），提出容他考虑；唐月说若不愿意就把今天谈话忘掉。她担忧神现身闹市已引起明珠魔法塔会与魔法宫廷的关注，若他们一致决定在蜕皮期处决神，神连反抗的余地都没有。被问为何如此在意，唐月讲出往事：父亲死于妖魔战役，她自幼独居，在灵隐山遇叛逃獠牙兽几乎丧命时獠牙兽被吓得逃跑，她回头看见月光西湖水下巨大的蛇影——那是她第一次见到它，此后只要她在西湖它就会保护她。莫凡动容，以讨一块蜕下异皮做铠魔具材料为由应下帮忙。唐月看手机时脸色骤怒，称有人在设计陷害大家伙，把最新新闻递给莫凡。

**关键事件**：1.唐月以内鬼之忧拉莫凡入守护局 2.唐月自述幼年获蛇相救的过往 3.莫凡以异皮为酬应允帮忙 4.爆出有人设计陷害摩天蛇的新闻

**逐章写法公式**：

- **情绪流向**：起：紧张 → 承：轻松 → 转：温馨 → 合：紧张
- **节奏配比**：慢铺垫 50% / 快冲突 15% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：内鬼与外人逻辑（任务合理化） + 人情拉扯（喜剧缓冲） + 唐月往事（情感深化） + 陷害新闻（骤转卡点）
- **本章核心技巧**：用情感往事（月下蛇影）给守护任务上价值，让主角接活顺理成章。
- **卡点与伏笔**：结尾卡点：危机骤降——陷害新闻内容未展开，下章期待审判会冲突；埋设伏笔：族内勾结者 → 内鬼线；蛇蜕异皮为酬 → 莫凡装备线；明珠魔法塔与魔法宫廷关注 → 下章祝蒙来袭的伏笔。
