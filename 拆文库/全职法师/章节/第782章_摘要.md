# 第782章 植物掌控力

**概要**：藤方信子宣布开始，莫凡与千熏相隔五十米，千熏故意不动观察莫凡一举一动。莫凡拧多道雷印成粗壮雷鞭横甩过去，千熏轻跺脚绽出灰蓝桔梗花骨将雷鞭裹住，植物不导电令莫凡惊讶其掌控力。莫凡散雷换玫炎于拳，千熏素手弹一颗青色种子落入石地，幼苗瞬间妖孽般疯长成灰蓝杂丛林追逐莫凡，莫凡高阶后一跃一二十米踩粗藤再跳才逃出。下坠时植物如鳄鱼张口等他，莫凡索性空中烈拳轰向千熏，千熏临时交缠藤墙挡下，被爆破粉碎，莫凡安然落地逃出种子区。原来坤之种一颗便可在数百平米遍布根须，无论组林还是操纵小片都随心所欲。

**关键事件**：1.千熏以花骨裹盾挡雷鞭 2.莫凡换火，千熏弹种生坤之林 3.莫凡空中借藤再跃逃出 4.莫凡烈拳轰千熏，藤墙被破 5.坤之种设定揭示

**逐章写法公式**：

- **情绪流向**：起：对峙观察的静 → 承：雷鞭被克的惊 → 转：丛林追杀的紧张 → 合：烈拳破墙脱困的爽
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：不动观察（静）→ 雷鞭被克（设强敌）→ 种子生林（压迫）→ 借藤脱困（智斗）→ 烈拳破墙（爽点）
- **本章核心技巧**：用属性克制把主角的拿手雷火先压一头，再以急智与火力破局
- **卡点与伏笔**：结尾卡点：莫凡暂脱种子区，千熏仍有后手；伏笔：坤之种范围、玫炎
