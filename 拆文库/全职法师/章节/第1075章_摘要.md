# 第1075章 共生虫树

**概要**：穆宁雪以冰雪之力克制植物系黑树精，莫凡穿过冰霜黑树精，在中央小黑湖见树精统领——它形似怪口、枝如爪，正抓着一头灰焰巨熊刺得血窟窿、血入湖变黑的血浆湖。树精统领嘶吼发现莫凡，却因眼盲不知小弟已被穆宁雪冻成冰雕。莫凡遁影施展司夜统治笼罩黑暗，先以苍雷爪只劈出缺口，改用火系天焰拳雨轰出大窟窿。湖中根须如巨鳗爬出追莫凡、缠住右腿拉回，小炎姬以劫炎炸开根须。莫凡骇然发现根须竟是吸血邪虫，持烈火炎剑砍断。他借火翼划焰线剑指统领，十五六米炎剑劈开树身吞没怪树，失本体的吸血虫随之自死，穆宁雪见满湖虫尸场面难看。

**关键事件**：1.穆宁雪冰控、莫凡见血浆湖树精统领 2.莫凡司夜统治+雷火攻树精 3.根须现形为吸血邪虫、小炎姬相救 4.莫凡火翼炎剑斩本体 5.虫死、穆宁雪见场面

**逐章写法公式**：

- **情绪流向**：起：冰控寻怪的轻松 → 承：血湖怪物的恐怖铺垫 → 转：雷火攻与根须反转的紧张 → 合：火翼斩本体的爽与收束
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：冰控穿林见怪（铺垫） + 司夜雷火试探（加压） + 根须虫反转求救（冲突） + 火翼斩本体（高潮）
- **本章核心技巧**：用"看似植物、实则虫共生"的中途反转维持战斗新鲜感，并以属性克制写试错节奏
- **卡点与伏笔**：结尾卡点：元晶到手否、亚克师徒是否再来，下章期待被抢；埋设/回收伏笔：小炎姬劫炎 → 克制统领级关键
