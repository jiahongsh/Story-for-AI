# 第1494章 你走错房间了

**概要**：布兰妾被药效燥得神志不清，莫凡情急之下说出自己有女朋友，布兰妾却追问他是不是不喜欢自己。莫凡将她扶进里屋躺下，倒掉她喝的清兰茶，守在厅里的火炉旁，又自嘲能拒绝绝色美女、必能超凡入圣。两人各自强迫自己睡去。清晨海蒂来敲门找布兰妾，开门却见到莫凡，莫凡面不改色谎称布兰妾身子不适、房间炉火生不起来，两人换了房间。海蒂将信将疑离去。莫凡立刻狂奔到布兰妾床前，让她披上大衣从另一边回自己屋子圆谎，布兰妾慌张照做，莫凡祈祷她别想到药是自己下的，否则自己死无全尸。

**关键事件**：1.布兰妾药效上头、含情挽留，莫凡守夜自嘲拒绝诱惑 2.两人各自睡去，清晨海蒂敲门撞见莫凡 3.莫凡谎称换房并让布兰妾披大衣回屋圆谎

- **情绪流向**：起：暧昧升温 → 承：莫凡扶人守夜 → 转：清晨撞破 → 合：仓促圆谎、祈祷瞒过
- **节奏配比**：慢铺垫 45% / 快冲突 25% / 爽点爆发 5% / 悬念留白 25%
- **本章结构公式**：药效上头逼退莫凡（危机） + 守夜自嘲入睡（缓冲） + 海蒂敲门撞破（突发事件） + 编谎换房圆谎（收束）
- **本章核心技巧**：用突发撞破打断暧昧场面，把情绪急转为喜剧式的圆谎危机
- **卡点与伏笔**：结尾卡点：状态变化+布兰妾尚未察觉药是自己下的；埋设/回收伏笔：下药主谋身份 → 后续圆谎与布兰妾察觉的危机线
