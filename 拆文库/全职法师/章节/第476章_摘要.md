# 第476章 火劫（下）

**概要**：莫凡判断相隔甚远仍霸占视线的火焰抵达时会比看到的庞大数十倍，是一场最可怕的火焰劫数。赵满延、晨颖恐惧，众人本能往反方向逃跑。逃出数公里后大地颤动，一群红褐色铠甲、铁蹄震地的杀铠兽飞奔，灵灵认出是战将级群居生物、铠甲是铠魔具好材料，感叹连这种刽子手都被火劫吓得抱头鼠窜。众人逃回沙惘河，杀铠兽冲到河畔不敢前行，心夏叮嘱别离它们太近以免惊醒战将级骨将魔人。逃进沙惘河深处后天边火劫渐渐消散，灼原北角一片火红如烈焰国度，灵灵推测沙惘河里沉睡的白沙妖物大多是历次火劫驱赶生灵跳河致死、日积月累形成。赵满延提议离开，称火劫从未有前人记录，众人也确实没获得过相关消息。

**关键事件**：1.火劫逼近，众人连同杀铠兽群逃入沙惘河避难。 2.灵灵推测沙惘河妖物是历次火劫驱赶生灵积累而成。 3.赵满延提议撤离，火劫无前人记录存疑。

- **情绪流向**：起：识破火劫的恐惧 → 承：杀铠兽群奔逃的震撼 → 转：借沙惘河避难的心惊 → 合：火劫消散、去留抉择的悬置
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：火劫判断定级（立威）+ 杀铠兽群奔逃（侧面渲染）+ 逃入沙惘河避难（绝境求存）+ 灵灵推因与去留之争（悬念收口）
