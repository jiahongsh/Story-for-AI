# 第1228章 无法算计的人

**概要**：要塞城建设终被议员会议驳回，西部军方陆续撤离，安角镇居民获妥善转移。莫凡将大地之蕊交给勺参谋，凝华邪珠却偷吸走石千寿以人命滋养的能量，补足约三分之一。莫凡盘点自身处境，近期无法动用恶魔系之力，决定在凝华邪珠充盈前不出国，避开撒朗的杀机。另一条线里，撒朗在冰湖小屋用冰锥钉膝审问与冷爵联手、冒用她名义的手下，逼问无果后放其带话，让冷爵交还自由神殿之物。撒朗与藏身暗处的属下论及教皇，断定冷爵背后是教皇在操纵，教皇发现她与叶心夏都不受控制，要借选接班人之名清除威胁。属下提及叶心夏已公开宣誓与撒朗为敌，撒朗称只依约保她活到二十岁，必要时会亲自下手。谈及莫凡，撒朗下令找到机会必杀，却又承认莫凡是她唯一无法算计的人，其实力提升过于恐怖，必须在他晋入超阶前处理掉。

**关键事件**：1.凝华邪珠吸走大地之蕊能量补足三分之一，莫凡决定充盈前不出国 2.撒朗冰湖审问冒用她名义的手下并放话让冷爵交还自由神殿之物 3.撒朗与属下推测冷爵背后是教皇，决意慢慢经营扳倒教皇 4.撒朗承认莫凡是无法算计之人，下令超阶前处理掉他

**逐章写法公式**：

- **情绪流向**：起：撤离迁徙的怅然 → 承：凝华邪珠得利的暗喜 → 转：冰湖审问的阴冷 → 合：撒朗忌惮莫凡的悬念
- **节奏配比**：慢铺垫 40% / 快冲突 30% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：安角镇收尾交代（清理战场）+ 凝华邪珠吸能量定下莫凡出国禁令（设限制）+ 撒朗审问引教皇线（开新线）+ 莫凡成撒朗必杀目标（回扣主角）
- **本章核心技巧**：莫凡视角收束旧线，反派视角开新线，双线在"莫凡必须死"这个点上合流
- **卡点与伏笔**：结尾卡点：威胁预告型——撒朗下令在莫凡晋入超阶前处理掉他；埋设/回收伏笔：凝华邪珠缺能量 → 驱动莫凡后续寻能量的行程；教皇与伊之纱、撒朗的三方博弈 → 后续黑教廷主线；心夏与撒朗的生死约定 → 后续帕特农神庙线
