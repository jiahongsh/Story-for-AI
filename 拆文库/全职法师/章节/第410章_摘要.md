# 第410章 装过头了！

**概要**：魏荣宣布最后一名与第一名之间隔着一千一百四十七名条件相似者无数次碰撞的残酷结果，并凭莫凡那句嚣张话直接把他本月成绩列在火榜第一百名，要让他体会位列一百名每天承受什么，还撂下"被废物打败的你又是什么东西"的话头。莫凡会后问邻座黄星丽，才弄清火榜规矩：排行越高被挑战越多，输了立刻与挑战者互换排名，且挑战无休止。他意识到自己装过头了，会被车轮战到睡觉吃饭都有人跳出来挑战，甚至动了找萧院长转去雷系的念头；唯一的好消息是排名高的人不会向下挑战，前一百高手威胁不到他。大会一结束莫凡提前开溜，学员们围到他座位扑空，被挤到第一百零一名的赵季号召众人发起挑战；金火社团的秦松不屑掺和百名后的打闹；有人议论这转系生与新生大魔头莫凡同名，却因大魔头是召唤系且传闻已死而认定不是同一人。散场时丁雨眠对黄星丽说了句"这人名字有点耳熟"，随即摇头不再多说。

**关键事件**：1.魏荣把莫凡列在火榜第一百名 2.黄星丽讲清无限制挑战规则 3.莫凡提前开溜躲开围堵 4.丁雨眠觉得莫凡名字耳熟

**逐章写法公式**：

- **情绪流向**：起：压抑（被钉在百名） → 承：搞笑（发现规则慌了） → 转：轻松（找到漏洞松口气） → 合：紧张（众人群狼环伺+身份疑云）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：立规压人（确立战场规则）+ 规则讲解（让主角与读者同步认知）+ 开溜避险（延后正面冲突）+ 群像围猎（铺垫挑战之乱）
- **本章核心技巧**：用配角之口把榜单规则完整交代成"危机说明书"，再用主角的认知落差（资源多→被车轮）把设定信息转成喜剧节奏
- **卡点与伏笔**：结尾卡点：群狼围猎——十人中九人可挑战莫凡、赵季夺位怨怒，期待挑战之周的连番开打；埋设/回收伏笔：大魔头莫凡传闻已死、召唤系旧身份 → 身份疑云待回收；丁雨眠"名字有点耳熟" → 感情线钩子；东方明魔具灵种配置 → 后续强敌参照
