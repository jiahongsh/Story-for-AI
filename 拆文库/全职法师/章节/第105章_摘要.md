# 第105章 当水喝了

**概要**：赵坤三从角落跳出夸穆白好样的，说自己这辈子都不会再相信任何人了；莫凡长吐一口气，心里把穆白戏称绿茶，庆幸这个魔二代奢侈的斩魔具救了全队。何雨的血已流干，鲜红如地毯的血滩让哀伤凝重再次笼罩众人；失魂落魄站在栅栏边的张小侯听到莫凡一句"猴子，走吧"后情绪彻底垮塌，泪水奔涌，抹着泪几乎发下毒誓地吼出"凡哥，我要变强，我一定要变得更强"，莫凡愣住，感到这个傻弟弟般的小伙伴哭得像个孩子，心却在滚烫血液的洗礼下成长了。八人穿过桥梁抵达城墙般的光幕结界，看到穿戴魔法协会标志的魔法师守护，觉得这三公里路比之前十七年经历的所有还漫长；薛木生回望挂念一公里半外的大部队。军部男子来传首领召见，莫凡登上土系魔法搭建的瞭望塔，见到负手而立的斩空与左右两排如雕塑的青衣军法师——至少中阶的十人气息强大，目光如剑直指银贸大厦穹顶的翼苍狼。斩空收起吊儿郎当，说看到你活着我很高兴；莫凡回敬说最想劈头盖脸骂他一顿。被问为何怀疑白阳，莫凡讲出当初历练时看到山口泉池的水有被饮用迹象且不止一只、白阳却否认有其他召唤兽，加上幽狼兽莫名发狂，只是留了个心眼。斩空转问地圣泉，莫凡轻描淡写答"口渴，顺手喝了"——斩空差点从瞭望台边缘滑下去，威严荡然无存，瞪眼咆哮那可是博城几千年的真正底蕴、国内魔法师梦寐以求的修炼宝藏，随即神色一严肃：现在不是开玩笑的时候。

**关键事件**：1.张小侯目睹何雨之死后立誓变强 2.先锋小队八人抵达安全结界，莫凡登塔面见斩空 3.莫凡自曝把地圣泉当水喝了，震惊斩空

**逐章写法公式**：

- **情绪流向**：起：悲伤（血滩余波与张小侯垮塌） → 承：热血（我要变强的毒誓） → 转：轻松（抵达结界、登塔会面的反差笑点） → 合：紧张（地圣泉玩笑后被严肃追问）
- **节奏配比**：慢铺垫 35% / 快冲突 5% / 爽点爆发 20% / 悬念留白 40%
- **本章结构公式**：战后余波（哀伤）+立誓变强（情绪转折）+抵达结界（阶段达成）+登塔面圣与地圣泉炸弹（悬念再起）
- **本章核心技巧**：用"把至宝当水喝"的荒诞回答击碎刚立起来的威严场面，一次对话同时完成搞笑反差与核心信息（地圣泉下落）交付，再用一句严肃收口把笑声转回正题。
- **卡点与伏笔**：结尾卡点：追问悬念——地圣泉被喝了是真是假、有何后果，斩空严肃追责在即；埋设伏笔：泉池水饮用迹象→莫凡观察力的旧事回扣；十名中阶军法师+目光直指翼苍狼→诛杀统领的战力集结；大部队一公里半外→迁徙线未收。
