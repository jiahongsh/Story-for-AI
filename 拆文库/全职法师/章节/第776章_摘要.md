# 第776章 拆了你们的阁！

**概要**：大阪国府设在离海岸七八公里的两座互望山顶，双守阁间以悬空木廊相连，号称圣地。众人到西守阁石围墙前，两名日本武士袍法师戒备，一名打花伞的和服女子径直质问他们是不是中国人，并凭山下禁止游览的牌子训斥他们不识礼数。莫凡纳闷她如何认出中国人，女子傲慢警告打工华人也不行、赶紧下山。艾江图等人皆沉下脸，莫凡先劝众人别动怒，转头却指着女子骂出臭三八，扬言要拆了这两栋破石阁。和服女子气得胸脯起伏，盘起头发露出银环与牛奶肌肤的冷傲美人面目，植物枝藤从大理石地绽出桔梗花将她托起。正当剑拔弩张，西守阁内传来粗豪一声千熏住手，络腮胡老者望月名剑走出，女子这才散去植物气场。

**关键事件**：1.双守阁地形与圣地气场展示 2.和服女子傲慢盘问并驱赶众人 3.莫凡先劝后骂，扬言拆阁 4.望月千熏展露植物系气场被喝止 5.望月名剑出面化解冲突

- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：双守阁亮相（抬对手）+ 女子驱赶（制造羞辱）+ 莫凡反骂拆阁（爽点）+ 望月千熏展气场（设强敌）+ 老者喝止（留钩）
