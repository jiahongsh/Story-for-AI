# 第34章 小泥鳅坠

**概要**：穆白告诉莫凡，宇昂原本每年最多获得三到四个月的星尘魔器使用权，"拜你所赐"增至半年以上；莫凡追问为何不全年供给，穆白解释星尘魔器不是路边石头、家族子弟多只能轮流使用，整个家族只有穆宁雪一直持有一件灵级星尘魔器，并科普凡级每天提升约20%修炼时间、灵级可达40%，一提灵级他神往不已。穆白泼冷水称自己能用一个月、莫凡只有十天很快甩开他十万八千里，莫凡不在意，心里把穆氏核心子弟当真正对手。薛木生语气很重地叮嘱众人爱惜魔器、时间一到必须按时归还。入夜熄灯后，莫凡独自坐在教学楼天台大蓄水坝上，把装在宝贵盒子里的蔚蓝色尘石星尘魔器当坠子戴上，胸前黑乎乎的泥鳅状坠子与魔器相碰，发出一声空灵的敲击响。莫凡回忆泥鳅坠是学校后山门卫嬴老头的遗物，觉醒那天它不停颤动，自己正是戴着它在茅屋睡觉才遭遇世界大变，还担心摘下坠子一切会变回原样。他以意念探入星尘魔器毫无反应，泥鳅坠反而有能量溢出；意念探入泥鳅坠如坠温泉，修炼十小时的精神疲惫被丝丝暖流驱散、隐感还能再修一小会。莫凡激动猜想：这个一直被自己嫌弃的小泥鳅坠，难道也是一件星尘魔器。

**关键事件**：1.穆白科普星尘魔器等级与穆宁雪的灵级孤品 2.泥鳅坠与星尘魔器相碰发叮声 3.泥鳅坠显滋养之能引出魔器猜想

- **情绪流向**：起：问情报的斗嘴 → 承：夜探天台的静谧 → 转：叮声异响与校发魔器失灵的反常 → 合：温泉滋养、惊人猜想
- **节奏配比**：慢铺垫 50% / 快冲突 5% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：情报问答（铺设定）+ 深夜独处（造氛围）+ 双器碰撞（异象）+ 猜想收口（留钩）
