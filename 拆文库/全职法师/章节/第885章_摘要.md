# 第885章 魔鬼巢窟

**概要**：潘晋高喊离开，倒下的人持续增加、已超二十，金战猎人团朝庄园外冲。团长葛明却拦在结界处，让潘晋看结界外——遍地黄黑血、黑灰尸体，凡踏出牧场围栏者无一生还。原来守在外围的猎人同样毒发，踏出围栏不出五十步便死，围栏外黑灰尸更多、黑血如溪。葛明精神崩溃：全团近千人折损近半、死近四百，却不知怎么死的。一名女猎人失智冲出，潘晋欲阻被葛明拉住，那女猎人跑出十米便吐黑血、拼命爬回却半卡围栏黑灰化而死，潘晋泪流。葛明令拦住旅客别出围栏，毒变暂止、结界救下许多人，众人却不懂为何精心捕猎变黑巢窟。

**关键事件**：1.葛明拦逃跑示结界外皆死 2.踏出围栏不出五十步死，死近四百 3.女猎人失智冲出黑灰化死 4.葛明令阻旅客，毒变暂止

**逐章写法公式**：

- **情绪流向**：起：逃跑冲动的慌乱 → 承：结界外皆死的绝望 → 转：女猎人惨死的刺痛 → 合：毒变暂止却无解的压抑
- **节奏配比**：慢铺垫 15% / 快冲突 35% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：潘晋喊逃葛明拦（阻） + 结界外皆死囚笼（爆点） + 女猎人爬回死（虐点） + 毒变暂止无解（钩子）
- **本章核心技巧**：用"逃生路即死路"的视角反转，把群体恐慌收束成无解囚笼，逼出毒变之谜。
- **卡点与伏笔**：结尾卡点：毒变暂止、众人不懂为何变黑巢窟，下章期待毒变根源揭晓；埋设/回收伏笔：结界围栏 → 本章功能（困住活人亦保命，后续禁出令回收）；黑血如溪 → 伏笔（毒变规模化，指向红茶潜伏）
