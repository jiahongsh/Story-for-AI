# 第351章 震撼楼影

**概要**：莫凡无视城市禁令乘疾星狼在机动车道上飞驰，到延安路一带收狼，推着心夏悠闲逛街：热饮、抱行楼梯、更衣室外被心夏拒之门外，又买下一套价格不考虑的复古汉装。随后在高视野餐厅靠窗对坐，心夏求他别轻易出城，并点破穆宁雪早已把历练的事告诉了她。莫凡望向窗外转移话题，留意到左边银行大楼穹顶带泳池、右前是五星级酒店，而两楼之间立着一栋没亮灯的黑色高楼。心夏说前阵子来过附近从没见过这栋楼，越看越觉得它"不像楼"。莫凡用意念去看，整个人僵住，震惊转为极致惊恐——那栋黑影缓缓转了过来，像感受到人们的注视正在回眸。

**关键事件**：1.莫凡带心夏逛街买下复古汉装 2.心夏点破穆宁雪已告知历练真相 3.两人发现两楼之间突兀的黑色高楼，黑影缓缓转头

**逐章写法公式**：

- **情绪流向**：起：轻松 → 承：甜 → 转：紧张 → 合：恐怖
- **节奏配比**：慢铺垫 55% / 快冲突 5% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：都市狼奔与逛街（甜宠日常） + 谎言被点破（关系补笔） + 黑楼发问（疑点铺垫） + 黑影转头（惊悚卡点）
- **本章核心技巧**：日常甜宠线全程铺温，再用一个"多出来的楼"完成类型骤转。
- **卡点与伏笔**：结尾卡点：惊悚悬置——黑影转头身份未明，下章期待真相揭晓；埋设伏笔：银行大楼穹顶游泳池与五星级酒店 → 下章瀑发男子的落点与对峙场景；穆宁雪与心夏互通消息 → 主角团情报网细节。
