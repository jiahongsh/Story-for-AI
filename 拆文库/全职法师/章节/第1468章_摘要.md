# 第1468章 我是一个老实学生

**概要**：莫凡认定此事远未到你死我活，却也担心收叛逆魔影会被海蒂意念利刃千穿百孔，遂咬牙收回魔影，海蒂遂以意念利刃在莫凡身上划出几道未伤要害的血痕，留其活命。莫凡冷哼"这下满意了吧"，海蒂反称是"我饶你"，逼其道歉；莫凡戏言"道歉两次你给我再看一次算扯平"，气得海蒂几乎夷平此地。此时瀑布之上金碧法袍的珈蓝导师飘落，背后洁白羽翼、水雾自动弹开，温言称不过是误会，并道自己早就在上方观战。海蒂见珈蓝微抱拳行礼，珈蓝说明阿尔卑斯是受邀与明珠学府交流、莫凡等是宾客，要海蒂勿为难；海蒂却坚持与莫凡厮杀到底，莫凡反驳融洞本是谁都可挑战的考验、自己只是闯入看见，海蒂冷言再提一句便让他消失——绝不容被看光之事传开。李教授鞋底贴水面走来提议喝茶，莫凡借坡下驴跳上索桥喊疗伤。雪莉尔、伊迪丝见莫凡流血大出恶气，李夕眉却非治愈系；珈蓝亲自以治愈精灵蝶为莫凡愈伤，莫凡嘲学府"女流氓"想回市区。莫凡自称老实巴交、差点拿奖学金的优秀生，李教授当即揭穿其明珠大魔头旧事，赵满延式调侃其越年轻越不要脸。珈蓝请众人入内用餐，海蒂在导师面前不敢动粗，只以杀意冰冷的目光紧盯莫凡脖后。

**关键事件**：1.莫凡收魔影，海蒂留血痕未杀 2.珈蓝导师现身调停称误会 3.海蒂坚持厮杀被压，融洞被看光秘辛 4.李夕眉非治愈，珈蓝愈伤 5.莫凡自称老实学生被李教授揭穿

**逐章写法公式**：

- **情绪流向**：起：收招留血的紧绷余波 → 承：道歉闹剧的喜剧 → 转：珈蓝调停与秘辛 → 合：老实学生梗的轻松收尾
- **节奏配比**：慢铺垫 15% / 快冲突 10% / 爽点爆发 5% / 悬念留白 10% / 日常轻松 60%
- **本章结构公式**：收魔影留血痕（收） + 道歉闹剧（逗） + 珈蓝调停秘辛（解） + 老实学生梗收尾（松）
- **本章核心技巧**：用长辈权威破死局，再用"自夸被揭穿"的喜剧收束战斗章节，节奏由紧转松
- **卡点与伏笔**：结尾卡点：日常型——海蒂盯脖后杀意未消，一月交流伏笔；埋设/回收伏笔：珈蓝导师→阿尔卑斯掌权者，后续交流主导；治愈精灵蝶→珈蓝治愈系能力展示
