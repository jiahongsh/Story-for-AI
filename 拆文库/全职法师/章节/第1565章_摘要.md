# 第1565章 七个黑暗剑主

**概要**：莫凡与赵满延密谋图腾源力大计，赵满延兴奋到幻想靠各国图腾成为禁咒法师，莫凡纠正目标是超阶——他们与海蒂都卡在高阶顶端，找不到通往超阶的门，而年轻超阶如赫卡萨、瓦尼早已迈过这道坎。队伍逼近灰怨风暴地带时，赵满延与穆白拿海蒂和米奥斯的屁股开黄色玩笑，气得史瑞夫不知如何接话。前方暗红盆地中三座金字塔尽收眼底，狮身人面像斯芬克斯沉睡被沙土覆盖，莫凡自称曾打伤它遭众人讥笑，实则是山峰之尸将其打趴。史瑞夫警告守卫金字塔的有十位黑暗剑主，莫凡纠正为七个——那场战役里三个黑暗剑主一死骸刹骨龙、二被肉丘尸臣砸倒遭丧尸啃噬。史瑞夫献计：他去门卡乌拉金字塔外放法老源泉引木乃伊自相残杀，调走黑暗剑主，队伍再乘灰怨风暴进塔。

**关键事件**：1.莫凡与赵满延规划靠图腾源力冲击超阶之路 2.莫凡纠正黑暗剑主由十位变七位，暴露其参与过北疆战役 3.史瑞夫献计引开黑暗剑主，让队伍乘灰怨风暴混入金字塔

- **情绪流向**：起：超阶之梦 → 承：无节操玩笑 → 转：七剑主秀资历 → 合：偷渡计划
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：超阶焦虑（动机） + 插科打诨（缓冲） + 剑主纠错（资历） + 偷渡计策（推进）
