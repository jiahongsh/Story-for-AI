# 第801章 第一代红魔

**概要**：望月名剑带莫凡与望月千熏到西山祀灵，灵位所刻"一秋"正是鹤田生父、名剑挚友。名剑回溯当年四人（名剑、一秋、雅子、信子）均分凝华珠能量后逐渐迷失，虐杀妖魔与犯人，唯有理智的一秋阻止众人并偷珠远走，反被三人追杀、下落不明。名剑承认当年与雅子合谋杀害一秋，雅子因此自责早逝，鹤田自幼受迁怒之苦。莫凡急于查清红魔是为替灵灵父亲报仇，名剑表示会设法从高木处救出鹤田，并强调邪珠绝不能落入高木之手。

**关键事件**：1.西山祀灵灵位揭示一秋是鹤田生父 2.名剑回溯四人分珠迷失、一秋阻止后被杀 3.莫凡表明查清红魔是为灵灵父亲 4.名剑承诺救鹤田、护住邪珠

**逐章写法公式**：

- **情绪流向**：起：祀灵祭拜的肃穆 → 承：一秋身世与四人分珠的回溯 → 转：合谋杀挚友的悲剧揭露 → 合：救鹤田与护珠的承诺钩子
- **节奏配比**：慢铺垫 50% / 快冲突 15% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：西山祀灵（定调） + 一秋身世（揭身世） + 分珠迷失与杀挚友（悲情爆发） + 承诺救鹤田（收束埋线）
- **本章核心技巧**：用反派自白式回溯揭开伦理悲剧，再以角色情感债锚定行动目标
- **卡点与伏笔**：结尾卡点：名剑将如何救鹤田，下章期待委托护送邪珠；埋设/回收伏笔：一秋偷珠远走 → 上代红魔来源
