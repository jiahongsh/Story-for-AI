# 第586章 闯入墓室

**概要**：余青素的惊雷轰碎裹布尸将半边肩膀，尸将受伤后原地旋转化作金属钻钻入土中逃走，坤之林困不住钻地的它，余青素不甘心地盘算着尸将稀少的亡灵结晶。十字疤男身后传来诡异声响，地面裂开，两根裹尸布破土而出勒住他的脖子，他虽幻化魔铠护体仍被拖倒在地，拽入一个隐蔽的墓穴洞中。余青素毫不犹豫跳洞救人，莫凡呼唤小炎姬，召唤星图描到一半小炎姬就自己钻了出来，矮男震惊于这违背魔法常识的一幕，莫凡以空间系血统搪塞。莫凡提着矮男跳下垂直的墓井，落到空旷的古墓室，余青素却不见踪影——她也已被拖走。

**关键事件**：1.余青素惊雷轰碎尸将半边肩，尸将钻地逃走 2.裹布尸将破土偷袭，把十字疤男拖进墓穴洞 3.余青素跳洞救人，莫凡提矮男随小炎姬跳下墓室

**逐章写法公式**：

- **情绪流向**：起：痛快（惊雷轰碎） → 承：愕然（钻地逃脱） → 转：惊变（疤脸被拖走） → 合：决然（跳洞救援）
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：雷霆轰杀（放爽点） + 钻地逃生（转战局） + 破土偷袭（爆惊变） + 跳洞救援（立义气）
- **本章核心技巧**：用敌方撤退技制造追杀动线，把战场从旷野无缝转入墓室新场景
- **卡点与伏笔**：结尾卡点：环境悬念——空旷墓室深处藏着什么、余青素被拖往何处；埋设/回收伏笔：裹布尸将的诡诈能力与稀少亡灵结晶 → 墓室战中继续兑现
