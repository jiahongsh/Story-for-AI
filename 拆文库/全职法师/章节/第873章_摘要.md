# 第873章 猎妖队来访

**概要**：古都浩劫后魔法协会以审判会为主联合军方、猎者联盟、政府与世族对全国锁境，誓要拿下撒朗，但因经济压力有高层主张解封外国人出入境，撒朗借此外籍渠道逃脱，审判会锁定崇明岛并秘密请外人铲除党羽。灵灵、莫凡、穆宁雪在牧场庄园，灵灵据撒朗能从严密排查中脱身判断审判会内部存在派系矛盾被撒朗利用，而非黑教廷混入（心灵之誓可排除）。赵品霖奉上特产红茶，卡莉与傅管家随后接待自称城市猎妖队的额疤男子一行，对方盘查月前黑灰化中毒身亡事件，指责庄园掩盖并威胁次日带资料否则停业。灵灵偷听对话，担忧猎妖队打草惊蛇破坏行动。

**关键事件**：1.锁境追捕撒朗因经济压力解封外籍通道致其逃脱，审判会锁定崇明岛 2.灵灵判断审判会内部派系矛盾被撒朗利用 3.城市猎妖队盘查中毒事件并威胁停业 4.灵灵偷听担忧打草惊蛇

**逐章写法公式**：

- **情绪流向**：起：锁境追凶的紧张背景 → 承：撒朗逃脱引出的体制疑云 → 转：猎妖队闯入打破平静 → 合：灵灵担忧打草惊蛇的压抑钩子
- **节奏配比**：慢铺垫 40% / 快冲突 25% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：交代锁境撒朗逃脱背景（设谜） + 灵灵分析审判会内部分裂（推因） + 赵品霖送茶卡莉接待（日常铺垫） + 猎妖队盘查威胁停业（外力冲突）
- **本章核心技巧**：用"高层经济立场 vs 审判会公道立场"的对抗，把反派逃脱写成体制裂缝而非个人失误，为后续内鬼线埋逻辑。
- **卡点与伏笔**：结尾卡点：灵灵偷听猎妖队对话后愁眉，担忧打草惊蛇；埋设/回收伏笔：审判会内部有问题 → 本章功能（灵灵核心判断，后续赵品霖线回收）；特产红茶 → 伏笔（后续毒变根源回收）
