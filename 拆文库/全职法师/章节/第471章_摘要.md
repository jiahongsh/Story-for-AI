# 第471章 坑害队友！

**概要**：晨颖以帝都学府前列强者的眼光感叹莫凡短时间肃清白沙巨人，自己靠疾星狼保护才消灭十来只。灵灵调度莫凡尽快支援赵满延，心夏叫住他，放出乳白治愈精灵嗅血寻伤、快速愈合其背部血窟窿，精灵光辉随治疗黯淡，完全透明时魔法结束。莫凡豪气冲天冲去救人，看见白沙巨人数量超百只后豪气尽消，赵满延在通讯仪里咆哮三分钟救不出便做鬼也缠着众人，莫凡犯难过不去巨人墙，心夏提出用安抚救人。此时张小侯带着一群白沙巨人冲到莫凡面前，莫凡笑容消失，张小侯却自信飞扬地转弯，引着追兵朝赵满延的巨人墙撞去，白沙巨人们见到同伴竟毫不减速。

**关键事件**：1.心夏用治愈精灵为莫凡疗伤，精灵光辉随治疗黯淡。 2.莫凡见赵满延处超百只巨人豪气尽消，心夏提议用安抚救人。 3.张小侯引着白沙巨人撞向赵满延的巨人墙，巨人毫不减速。

**逐章写法公式**：

- **情绪流向**：起：晨颖惊叹、治愈精灵疗伤的温馨 → 承：百只巨人浇灭豪气的压力 → 转：张小侯带怪撞墙的火上浇油 → 合：巨人毫不减速冲向沙墙的悬念
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：治愈精灵疗伤（续战资本）+ 百只巨人困局（危机升级）+ 心夏提出安抚方案（解法伏笔）+ 张小侯引怪撞墙（反转悬念）
- **本章核心技巧**：用治愈系设定补战斗续航，再用队友乌龙式操作把危机引向意外转折
- **卡点与伏笔**：结尾卡点：悬念——张小侯引来的白沙巨人毫无减速撞向巨人墙，结果未知；埋设/回收伏笔：治愈精灵随治疗黯淡的规则 → 支撑后续长途作战的续航设定
