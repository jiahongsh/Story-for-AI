# 第1116章 狐狸蹄子

**概要**：三方混战日，战场设于独立空间，苍天之林、奔河与断崖席位构成庞大场地，十二名助理裁判入场，每名学员配自动触发的威尼斯之戒。中国首发莫凡、艾江图、官鱼、穆婷颖、赵满延直趋河林，先撞见希腊，阿莎蕊雅眉目传情挑逗莫凡；英国人至，哲罗为首。艾江图主张先打英国，希腊却骤然逼近——黑暗剑主冲出斩向高处巡视的官鱼，英国人希伯特同时以光落漫丈洗礼中国，赵满延怒骂英希联手。阿莎蕊雅居高临下俯视莫凡，哲罗前后包夹而来。

**关键事件**：1.三方混战开场，战场与威尼斯之戒规则交代 2.中国撞希腊又遇英国，艾江图主张打英 3.希腊黑暗剑主斩官鱼，英希似联手夹击中国

- **情绪流向**：起：战场奇观的铺陈 → 承：撞希腊遇英国的布局 → 转：英希联手夹击的爆发 → 合：哲罗包夹的钩子
- **节奏配比**：慢铺垫 40% / 快冲突 40% / 爽点爆发 5% / 悬念留白 15%
- **本章结构公式**：战场设定（铺陈） + 撞见两国（布局） + 黑暗剑主斩官鱼（反转） + 英希夹击（加压） + 哲罗包夹（钩子）
- **本章核心技巧**：用大段设定铺陈后，以"盟友反水"瞬间把中国推入绝境
- **卡点与伏笔**：结尾卡点：莫凡被哲罗阿莎蕊雅包夹，下章风水轮流转反制；埋设/回收伏笔：威尼斯之戒自动保护→后文多次判定出局依据
