# 第334章 狼少年（祝安妮早日康复）

**概要**：简陋山洞篝火旁，衣裳褴褛如原始人的长发男子守着被救的离曼，因疗毒褪去她的军绿长裤，醒悟忘了帮她穿回。离曼苏醒后本能凝魔力戒备，男子咧嘴露出尖锐虎牙告知她中了毒，并说自己也曾染上此毒、费了很大功夫才解掉，本以为她至少昏迷七八天。问答中她得知自己巡查的"杀戮过重的东西"令男子不自然地岔开话题，他还点破她的毒正是山谷所中、自己提醒过几批人却无人理会，死了不知多少人。离曼担心大锤队安危，请男子去警告猎队，男子抱怨山谷中心沼泽的东西本已受伤，这些日子一队队法师跑去送温暖、拉都拉不住。她起疑：别人走半路就死、偏偏他活得好好的，昏迷前分明感应到死神靠近，怎么救自己的成了这个野人。男子自称梵墨，头发如钢丝、虎牙如獠牙，活脱脱狼族少年。离曼以军统职责提议两人联手除掉山谷之物，莫凡愣住打量她后应下，指出还需一个灵活的家伙引开毒物，离曼便提到一路鬼鬼祟祟跟着猎队、疑似学过军方追踪隐匿本领的人，莫凡补一句还得有能和统领级周旋的强者，并预先声明自己要的东西不许抢，离曼答她对东西没兴趣。

**关键事件**：1.莫凡（自称梵墨）山洞救醒离曼 2.揭示毒源与山谷连死数队人的真相 3.离曼起疑野人身份未果 4.两人约定组队除害并寻找第三个帮手

**逐章写法公式**：

- **情绪流向**：起：紧张（山洞苏醒、本能戒备）→ 承：轻松（憨直问答与偷看尴尬）→ 转：紧张（毒源真相与离曼起疑）→ 合：热血（联手除害提议达成、招人计划启动）
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：篝火苏醒（建立救援关系）+ 中毒与救人自述（人设信息互换）+ 偷看与裤子尴尬（喜剧调剂）+ 山谷毒物真相（危机升格）+ 起疑与化名（身份猫鼠）+ 组队分工（行动钩子）
- **本章核心技巧**：主角以化名和野人形象与新角色同居一洞，用救治之恩掩护身份，让情报交换、喜剧错位、怀疑反查三种张力在同一场景内轮转。
- **卡点与伏笔**：结尾卡点：组队卡点——还缺引开毒物的灵活人手，离曼推荐了暗中的跟踪者，期待三人碰头；埋设伏笔：梵墨这个化名与狼少年形象 → 莫凡身份不被识破的伪装线；山谷中心受伤的毒物 → 讨伐对象与流沼所在的祸源；莫凡声明"我要的东西别跟我抢" → 他收集的正是养魂精魄类目标。
