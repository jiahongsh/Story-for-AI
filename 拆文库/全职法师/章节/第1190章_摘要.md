# 第1190章 威胁

**概要**：莫凡联系金战猎人团团长葛明，葛明爽快答应其加入，并说明此次只挑十二名经验老道的沙漠猎人前往，除自己超阶外皆为高阶。莫凡觉得穆宁雪走不开需再找人保护，灵灵说此人既要实力强又要信得过，建议找刚突破瓶颈的牧奴娇，莫凡犹豫其危险、灵灵笑说张小侯油滑不易死。莫凡正要打电话给牧奴娇，老爹莫家兴的专属铃音却响起，接起竟是宇昂的声音——他声称莫凡害自己落到这步、父亲已在手上，并以“你知道我是怎么对待许昭霆的”相威胁。莫凡强压怒火，灵灵分析博城是军事要塞、宇昂绝无可能无声挟持，定是圈套，随后查到是审判会走正规途径带走了莫家兴。莫凡赶往北雨山，途中吸血鬼博拉化作黑翼追上，莫凡令其“不要手下留情”，二人同飞而去。

**关键事件**：1.莫凡加入金战团、寻人保护 2.老爹电话被宇昂接、以父相挟 3.灵灵查实是审判会带走莫父、识破圈套 4.莫凡赴北雨山、博拉追上同行

**逐章写法公式**：

- **情绪流向**：起：组队寻人的轻松 → 承：老爹来电被挟的惊怒 → 转：灵灵破局识圈套 → 合：博拉追主赴北雨山的燃
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：组队寻人（铺线） + 宇昂挟父（危机） + 灵灵破套（揭示） + 博拉追主（战前钩子）
- **本章核心技巧**：用“专属铃音”的反差让旧敌归来更具冲击力，再以角色专业分析稳住节奏、亮出隐藏强援转入大战。
- **卡点与伏笔**：结尾卡点：莫凡与博拉飞赴北雨山，大战将启；埋设/回收伏笔：审判会与宇昂勾结 → 下章北雨山大打出手伏笔。
