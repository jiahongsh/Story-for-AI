# 第1355章 全线戒备

**概要**：莫凡跟踪引渡者牧羊人和程英，一路从镇北要塞城向北深入黄土高原，黑教廷警惕心极高，只有莫凡的暗影系能继续跟进，赵满延与灵灵留在要塞城内待命。灵灵查证小镇古埃及资料无果，赵满延拨通国际长途联系埃及参谋芬纳，芬纳起初态度冷淡，听罢老伯所言后讲出古老传说——冥神与孔丝，一个类似潘多拉魔盒的故事，其中反复提及的"次元三角镜"竟与老伯含糊的呓语吻合，据说此物根本不存在，又据说被放置于大金字塔内，芬纳答应去查证。赵满延与灵灵感到莫名寒意，为防万一前往魔法集市购买防腐败解毒剂和冰系魔器。赵满延在城墙上质疑古长城抵御北疆荒兽的实际作用，遭一位英姿飒爽的女军官鄙夷不屑，正纠缠间手机响起，莫凡在通讯那头焦虑大喊，要求立刻让镇北关全线戒备。

**关键事件**：1.赵满延联系埃及参谋芬纳，获知冥神与孔丝传说及次元三角镜线索 2.赵满延与灵灵在魔法集市购置防亡灵道具 3.赵满延在城墙上质疑古长城作用遭女军官嘲讽 4.莫凡来电喝令镇北关全线戒备

**逐章写法公式**：

- **情绪流向**：起：追踪中的谨慎 → 承：探寻线索的疑惑 → 转：传说验证的寒意 → 合：戒备指令的骤紧
- **节奏配比**：慢铺垫 45% / 快冲突 15% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：莫凡尾随黑教廷（铺悬念）+ 芬纳讲冥神孔丝传说（抛线索）+ 赵满延备置防亡灵道具（加压）+ 莫凡来电全线戒备（扔钩子）
- **本章核心技巧**：借远程角色之口交代传说背景，再用听者前后反应回扣既有线索，章末用一句危机指令把闲谈场景拽入险局
- **卡点与伏笔**：结尾卡点：突发式——莫凡来电喝令全线戒备，原因成谜；埋设/回收伏笔：次元三角镜 → 后续黑教廷阴谋核心道具
