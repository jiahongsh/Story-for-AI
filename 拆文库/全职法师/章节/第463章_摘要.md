# 第463章 可怕之河！

**概要**：沙惘河看似平静的白沙下遍布白沙妖兵，灵灵让张小侯把沙啸虎内脏远远抛入河中试探，白色沙地瞬间炸开，四五十只三米高的持刀半巨人围拢内脏，几秒后又化沙归寂，众人看得目瞪口呆，决定河畔扎营、天亮再过河。夜里莫凡守下半夜时听见远处动静，独自摸到石壁夹缝窥探，只见六七只沙啸虎正追杀一队猎法师，细看竟是白天索要分成的黑黄女法师和黑胡须队长。二人慌不择路逃进沙惘河四五百米，沙啸虎在河畔驻足不敢再追，随即成排白沙妖兵拔地而起，沙化大刀重重叠叠落下，那群猎法师瞬间化作漫天飞血。

**关键事件**：1.内脏试探引出四五十只白沙妖兵 2.莫凡夜窥沙啸虎追杀猎法师 3.逃入沙惘河的猎法师被白沙妖兵砍杀

**逐章写法公式**：

- **情绪流向**：起：试探妖兵的惊骇 → 承：扎营夜宿的平静 → 转：夜窥屠戮现场 → 合：妖兵拔刀，鲜血飞溅
- **节奏配比**：慢铺垫 35% / 快冲突 35% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：内脏试探（立威） + 扎营休整（喘息） + 夜窥追杀（悬念） + 妖兵屠戮（恐怖收束）
- **本章核心技巧**：用旁观者视角写一场屠杀，不参战只记录，恐怖感靠距离与无力感放大
- **卡点与伏笔**：结尾卡点：恐怖场面型，妖兵成排拔起砍杀逃入河中的猎法师，下章期待队伍如何过河；埋设/回收伏笔：沙啸虎不敢入河 → 河内妖兵更凶的规则铺垫；心夏安抚承诺 → 过河计划核心
