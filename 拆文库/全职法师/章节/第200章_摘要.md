# 第200章 高价，战将精魄

**概要**：事件平息后赵满延成了全校知名的风云人物，知恩图报常给莫凡介绍对象。周末莫凡随他进入国贸中心顶楼竞拍场，这里没有会员或地位、有钱也进不来，赵满延顺势讲了魔法资源稀缺、被大势力瓜分的现实。莫凡盘点家底：奖学金两百万、委托男子补付的一百万与早前十五万委托金，共315万，而当日拍品价值均超五百万。莫凡亮出要卖的战将级精魄，赵满延先应下小事一桩随即愣住失态，接着科普亡魂器皿只有亡灵系法师能炼制、最差的也要五百万左右，精魄是星尘魔器星云魔器的原料、得到几个可一夜暴富。莫凡由此意识到残魄精魄似乎只有自己能收集，对小泥鳅坠的来历愈发好奇，赵满延把精魄加进拍卖单。

**关键事件**：1.莫凡凭赵满延的关系进入国贸中心顶楼竞拍场 2.亮出战将级精魄，获知亡魂器皿与精魄市场规则 3.意识到只有自己能收集精魄，对小泥鳅坠起疑

**逐章写法公式**：

- **情绪流向**：起：轻松（成名后的插科打诨）→ 承：压抑（门槛与身家的落差）→ 转：爽（精魄震住世家子弟）→ 合：期待（加进拍卖单待价而沽）
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：进场讲规矩（立门槛）+ 盘点家底（立落差）+ 亮精魄科普（立价值）+ 加单待拍（留期待）
- **本章核心技巧**：拍卖前戏全用配角反应加规则科普抬价，宝物未上拍价值已立满。
- **卡点与伏笔**：结尾卡点：期待（精魄加单，卖价几何留到下章）；埋设/回收伏笔：委托男子补付百万 → 回收体育馆委托线；小泥鳅坠能收精魄 → 挂坠来历之谜加深；精魄只有自己能收集 → 后续生财暗线。
