# 第405章 穿上

**概要**：年末莫凡重返明珠学府穿上高校学服，回顾年初离校后大半年的历练——龙族血统大蜥蜴、刽子手军统、变身野人与武壳巨蜥沼毒千蚣斗智、杭州风波，自嘲不知经历了什么鬼。他用花盆下的钥匙开门回到公寓，屋内艾图图正向牧奴娇控诉周书茗当众扬言要让她做周家媳妇的嚣张行径。莫凡熟门熟路换鞋挂包脱外套，把两位惊呆的姑娘吓得不轻；艾图图怀疑见鬼、认真查过窗外阳光排除了闹鬼，又以觉醒亡灵系威胁要收了他，张开双臂护在牧奴娇身前；牧奴娇反而上前挡住她，红着脸提醒艾图图先去把衣服穿上——后者才发现自己衣不蔽体，尖叫着捂胸逃上楼。牧奴娇毒舌说像你这样的坏人总是不那么容易死的，楼上艾图图狮吼震屋，牧奴娇留下一句你好自为之便踩着拖鞋上楼，莫凡讨要劫后重逢拥抱未果；回房后她靠在门背上如释重负，许久唇角悄悄浮起笑意。

**关键事件**：1.莫凡死而复生年末返校，用旧钥匙回到公寓 2.艾图图向牧奴娇控诉周书茗当众扬言娶她进周家 3.重逢闹剧后牧奴娇独处时靠门浮笑

**逐章写法公式**：

- **情绪流向**：起：慨叹（半年历练回顾） → 承：惊疑（死而复生闯门） → 转：爆笑（见鬼乌龙与忘穿衣） → 合：甜意（门后浮笑）
- **节奏配比**：慢铺垫 25% / 快冲突 15% / 爽点爆发 20% / 悬念留白 40%
- **本章结构公式**：返校自述（时间线收束）+ 归来惊变（死讯反转）+ 乌龙连环（喜剧泄压）+ 傲娇收尾（甜点钩子）
- **本章核心技巧**：用「熟人视角的死讯反转+一层层自我拆台的误会喜剧」让重逢既惊且笑，再用独处镜头补一勺糖
- **卡点与伏笔**：结尾卡点：牧奴娇唇角浮笑、一切更值得期待，感情线回暖；埋设/回收伏笔：周书茗当众扬言娶牧奴娇→情敌线埋雷；花盆下的钥匙→两人同居关系的旧设定回收；艾图图觉醒亡灵系→她的系别信息
