# 第1118章 风水轮流转

**概要**：希腊新上场队员在林间迷路躲英国人，误把现身的莫凡当队友，被炎剑破防后靠空间履魔具远遁，遭穆宁雪重力空间锁步、三人围殴泄愤，威尼斯之戒护身被抬下；希腊因人数劣势未报复中国。莫凡以风水轮流转挑衅阿莎蕊雅，卡洛欧丝请战被拦，阿莎蕊雅提议联手抗英。谈妥后卡洛欧丝治愈艾江图穆婷颖莫凡至八九成，阿莎蕊雅祭星源沙漏项链为全员补三成魔能，穆婷颖质疑、南珏析明同盟逻辑，中希正式联手。

**关键事件**：1.希腊新员林间被莫凡伪装队友突袭围殴出局 2.莫凡挑衅阿莎蕊雅、卡洛欧丝请战被拦 3.阿莎蕊雅提议并谈成中希联手抗英 4.卡洛欧丝治愈伤势、星源项链补魔能恢复战力

**逐章写法公式**：

- **情绪流向**：起：希腊新员侥幸躲藏 → 承：被伪装突袭围殴的憋屈与爽感 → 转：莫凡挑衅、同盟谈判落定 → 合：治愈补魔能满血，联手钩子
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：落单新员入场（被报复） + 莫凡挑衅阿莎蕊雅（加压） + 阿莎蕊雅谈条件（转折） + 治愈补魔能联手（收束）
- **本章核心技巧**：用先泄愤后谈利把阵营转换写成利益清算，避免突兀和解
- **卡点与伏笔**：结尾卡点：中希联手满状态对抗英国（类型加内容加下章期待）；埋设/回收伏笔：星源沙漏项链 → 后续团战续航神器
