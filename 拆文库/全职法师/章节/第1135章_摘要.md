# 第1135章 召的没杀得快

**概要**：莫凡因幽灵祭司在侧不敢用高阶魔法，米奥斯嘲讽其魔法极端必受制，莫凡退入丛林以巨影钉定身、中境界念控将幽灵祭司打得魂飞魄散。米奥斯不信邪连唤三只幽灵祭司，被莫凡以静止念令与黑暗影剑阵一一清除。米奥斯改唤三只臃肿的死刀木乃伊，巨刀却被莫凡无形气势压得斩不下去，最终被火焰蛟龙轰飞、闪电劈碎、压缩空间碾饼、雷爆灭杀。莫凡遁影禁锢米奥斯未遂，反以压缩空间与天焰葬礼清掉其反复召唤的木乃伊群，连狂斧木乃伊也被苍雷爪一并灭掉。史瑞夫加入围攻，米奥斯前后召出约五百只木乃伊却被莫凡杀光，呼唤速度远不及莫凡杀速。莫凡继续逼近，被新一波木乃伊包围，却因古都亡灵汪洋中历练而毫不在意。

**关键事件**：1.莫凡以念控与影剑阵清除幽灵祭司 2.死刀木乃伊被莫凡压制覆灭 3.米奥斯史瑞夫亡灵海被莫凡杀穿

**逐章写法公式**：

- **情绪流向**：起：被克制的紧张 → 承：连环清场 → 转：死刀覆灭 → 合：杀穿亡灵海
- **节奏配比**：慢铺垫 5% / 快冲突 75% / 爽点爆发 15% / 悬念留白 5%
- **本章结构公式**：幽灵威胁（压制） + 念控破局（反转） + 死刀考验（再压） + 杀穿海（碾压）
- **本章核心技巧**：用敌人越召越被杀得快的写数量反差，把消耗战写成单方面碾压爽章
- **卡点与伏笔**：结尾卡点：莫凡被围仍从容，下章如何破局；埋设/回收伏笔：古都历练→抗压底气；精神中境界→破幽灵
