# 第993章 深海惊心战！

**概要**：莫凡称这是除煞渊外最惊心动魄的任务：保护歹蛆、引龙、惊扰雷暴乌贼、在潜礁与恶名前五的伪龙厮杀。分工后穆宁雪先下海引龙，莫凡潜入礁窟中层搞乌贼，鲍比灵灵布置绝缘带。穆宁雪潜入漆黑深海，循鼾声找到乌海伪龙洞窟，以冰锁扎刺引其怒而出洞追击。莫凡在迷宫般礁窟找到雷暴乌贼老巢却寻不到统帅，索性以寂雷死光引爆雷暴，整片海域化为雷电地狱，海猴族群成片被电灭。莫凡穿玄蛇铠甲狼狈逃出海面，乌海伪龙也承受不住雷霆逃上岸。灵灵与鲍比在快船严阵以待，鲍比本以为遇年轻伪龙，谁知露出水面的竟是一头牙如大剑的老伪龙。

**关键事件**：1.穆宁雪深海引龙出洞 2.莫凡引爆雷暴乌贼制造雷区 3.乌海伪龙与莫凡先后逃出海面，老伪龙现身

- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 15% / 悬念留白 15%
