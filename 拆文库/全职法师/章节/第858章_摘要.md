# 第858章 冻结铁尸！

**概要**：赛义德笑称穆宁雪只躲无用，穆宁雪风之轨迹炉火纯青，灰布铁尸碰不到她衣角，即便铁尸爆发全速她也镇定站力蛮边缘。她靴下已无轻风——并未放风轨，而是暗布冰蔓，赛义德惊觉铁尸被冰霜覆透、内部冻结。穆宁雪解释冰系克尸骨类，只需冻住关键关节便废其发力，铁尸成白雪人。她扇起风盘卷飞霜撞向铁尸，赛义德急令死刀木乃伊劈散风盘救铁尸，黑刀气却在穆宁雪面前三四米停住，她偏头袖口被划出五公分血痕。穆宁雪凝重踏地震出冰锁阵，冰雪悬空组合成锁环。

**关键事件**：1.穆宁雪风轨闪避，暗布冰蔓冻铁尸 2.冰系克尸骨，铁尸成雪人 3.风盘撞铁尸，死刀劈散救场 4.穆宁雪袖口受伤，启冰锁阵

**逐章写法公式**：

- **情绪流向**：起：风轨闪避显从容 → 承：暗布冰蔓冻铁尸 → 转：风盘撞尸死刀救场 → 合：袖口留血启冰锁阵
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：闪避布局（智） + 冻结铁尸（爽） + 死刀救场（危） + 冰锁蓄势（钩）
- **本章核心技巧**：用"表面逃跑、暗地冰冻"的误导结构，把冰系克制具象为可见胜利
- **卡点与伏笔**：结尾卡点：穆宁雪启冰锁阵，下章期待她如何借冰锁硬撼死刀；埋设/回收伏笔：冰蔓暗中扩散 → 冰之领域持续侵蚀的伏笔
