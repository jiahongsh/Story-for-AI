# 第240章 再现诅咒畜妖！

**概要**：宇昂念动咒语，灰色音符织成符咒之门，放出一只浑身布满铁烙疤痕的诅咒畜妖，其气息与许昭霆当年的诅咒味相同、实力达战将级。宇昂介绍诅咒畜妖的炼制法——活人入池前先折磨得怨气十足，怨恨越强成妖概率越大：这是他的第一只，许昭霆是第二只，莫凡将成第三只；天生双系的莫凡正是上佳材料。莫凡借此摸清黑教廷教徒—教士—执事的阶级，并得知许昭霆成妖时因保有意识而逃脱被弃。真相更为骇人：这只绝对忠诚的诅咒畜妖竟是宇昂的亲生父亲——他七岁入黑教廷后第一件事就是把虐待自己的父亲做成黑畜妖，入穆家潜伏十年借资源淬炼此妖，凭它当上灰衣教士。宇昂挥鞭下令撕下莫凡的皮，诅咒畜妖以缩骨之能惊悚地钻进铁笼；耳塞里执事大人传来"马上撤离"的示警，宇昂以地圣泉即将到手说动对方为冒险再等片刻。

**关键事件**：1.宇昂放出诅咒畜妖并宣称莫凡将是第三只 2.诅咒畜妖身世揭晓——宇昂的亲生父亲 3.缩骨入笼行凶在即，执事示警撤离被宇昂劝留

**逐章写法公式**：

- **情绪流向**：起：恐怖（符门开启、畜妖现世） → 承：压抑（炼妖原理与许昭霆旧案） → 转：恐怖（生父成妖的真相、缩骨入笼） → 合：紧张（执事示警、风险将押后一瞬）
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：念咒放妖（恐怖登场） + 炼妖自白（设定与旧案） + 身世炸弹（父成妖、十年潜伏） + 入笼行刑（示警与冒险卡点）
- **本章核心技巧**：把反派背景故事的揭晓压在行刑前一刻，用"最忠诚的妖是最亲的人"这一定罪式细节同时完成人物立体化与恐怖加码
- **卡点与伏笔**：结尾卡点：行刑卡点——畜妖缩骨入笼、执事犹豫再等，下章期待笼中死战与审判会赶到；埋设/回收伏笔：宇昂潜伏穆家十年 → 穆家内鬼大伏笔；撒朗主教与蓝衣执事 → 黑教廷上层线；许昭霆保有意识逃脱 → 许昭霆线索未尽；执事"不好的预感" → 审判会逼近的救援时钟
