# 第327章 灵魂反噬

**概要**：斩空告诉莫凡他需要海量精魄养魂，只有军部供魄才能保住灵魂，并点破恶魔系等于和恶魔签契约——恶魔给力量后会来收走灵魂。莫凡意识消失，如凶狼般跃起狂奔出金林区，斩空伤重施展不出风之翼，只能眼看恶魔身影冲向深山老林、灵魂恐被抽干。斩空复盘：博城灾难后他一直留意莫凡、令人盯住陆年动向，却低估了陆年让部下卸任来做灭绝勾计的手段，学员死了近半，他怒得一拳砸地。斩空找到四名学员与陆年手下，警告反抗就地处决；蒋艺束手就擒，问军统下落，得知"死了，被你们成就的恶魔给撕了"，众人见到陆年胸膛被打穿、面容扭曲的尸体，蒋艺等痛哭，赵满延三人只觉大仇得报。白婷婷问莫凡伤势，斩空红着眼只答"我会通知他的家人"。事后历练学员以史上最低生存率返回帝都学府，军部想压下丑闻、校方不罢休；依斩空要求恶魔系与莫凡恶魔化均不公开，知情的蒋艺和军官全部被处死，蒋艺留下最后一点善良，让莫凡在世人眼中成为舍身救人的英雄。另一边穆宁雪在家中醒来，回忆起昏厥前的魔鬼面孔与自己那支冻结之箭，迷糊中曾听见有人哭着谈论与莫凡有关的事。

**关键事件**：1.斩空讲解精魄养魂之法，莫凡仍暴走失踪 2.斩空收押陆年余部，宣告陆年死讯 3.军方校方封口，蒋艺被处决前把莫凡塑造成英雄 4.穆宁雪醒来，隐约听说莫凡出事

**逐章写法公式**：

- **情绪流向**：起：紧张（精魄保命的抢话）→ 承：压抑（暴走失踪、斩空无力追赶的复盘）→ 转：悲伤（陆年尸体、白婷婷问莫凡伤势）→ 合：悲伤（宁雪醒来，隐约听见关于莫凡的哭谈）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：讲解精魄解法（给希望）+ 暴走失踪（希望落空）+ 斩空复盘自责（补叙防务线）+ 收押余部宣告死讯（清算余波）+ 封口与英雄化（世界观信息层）+ 宁雪醒来（视角切换钩子）
- **本章核心技巧**：主角离场后立刻用三个视角（斩空、官方叙事、穆宁雪）接力补完余波，把单一战场收束成多条后手线。
- **卡点与伏笔**：结尾卡点：信息差卡点——宁雪听见哭谈却不知莫凡下落，下章期待她获知"死讯"；埋设伏笔：精魄养魂 → 恶魔系续命资源的长期需求线；蒋艺等知情人全部处死 → 真相仅存于极少数人手中。
