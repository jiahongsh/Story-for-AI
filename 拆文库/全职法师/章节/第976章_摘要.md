# 第976章 紫风神殿法师

**概要**：蓝衣执事随手推出厚重冰墙，将莫凡的陨拳打散，寂雷死光也只击中残影。周围冰镜折射出数十个蓝衣幻象逼近，莫凡火系威力被对方冰之领域压下四成，九道火柱难破冰层。莫凡展开司夜统治，蓝衣却瞬至身后甩出冰铁锁链，莫凡化碎影避过，暗中对射的电弧也被冰甲挡下；蓝衣再掀冰刃刀舞充斥黑暗领域，整条街被绞成粉末，莫凡靠血兽靴与遁影才逃出。赵满延大喊快逃，莫凡深知撒朗动真格派出强敌。千钧一发，一名黑金翼魔具的中年神殿法师悬停怒喝，却被蓝衣精神冲击扰乱心神，半山峰冰块当头砸下，莫凡念控将其拽开。随后紫风神殿法师携紫旋风现身，实力远胜前者，蓝衣忌惮自由神殿超阶赶来，借冰雹乱中遁走。紫风留他不住，诧异莫凡未被速杀，确认其中国国府身份后预警行刑人必再寻机下手。

**关键事件**：1.莫凡火雷被冰墙冰镜压制，司夜碎影避冰刃刀舞 2.神殿法师现身救场，莫凡念控救其脱半山峰冰块 3.紫风神殿来援，行刑人遁走 4.紫风确认莫凡实力并预警再袭

**逐章写法公式**：

- **情绪流向**：起：火雷被压的憋 → 承：冰刃刀舞的绝 → 转：神殿救场的松 → 合：行刑遁走的余悸
- **节奏配比**：慢铺垫 10% / 快冲突 55% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：火雷被冰域压（施压） + 碎影避冰刃刀舞（挣扎） + 双神殿救场（反转） + 行刑遁走预警（钩子）
- **本章核心技巧**：用"领域克制+环境改造"把强敌写到绝望，再用援力递进两级回收局势
