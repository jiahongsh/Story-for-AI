# 第613章 肉丘障碍

**概要**：博成街的幸存者被赵坤三和王三胖安置在关押妖魔的铁笼里，前方主干道被肉丘尸臣和大量亡灵堵死。腐尸闯入后，两人用位移魔法配合光刺魔具将其杀死，却又引来十几头腐尸围笼。莫凡赶到，以第四级雷印借铁笼导电麻痹尸群，周敏随后用火滋焚骨清场。众人得知前方是尸臣盘踞的死街，决定先查看道路，再寻找绕行或突围办法。

**关键事件**：1. 幸存者躲入铁笼并发现主干道被肉丘尸臣封死 2. 王三胖和赵坤三杀死闯入铁笼的腐尸 3. 莫凡与周敏联手压制并清除围笼腐尸

**逐章写法公式**：

- **情绪流向**：起：惊惧 → 承：封锁加压 → 转：援军压制 → 合：发现死街与尸臣
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：幸存者藏身（暂避亡灵） + 腐尸闯入（迫使低阶法师应战） + 尸群围笼（扩大危机） + 雷火清场（确认前方更危险）
- **本章核心技巧**：用封闭空间里的连续逼近放大亡灵威胁，再用属性克制的救场动作短暂释放压力。
- **卡点与伏笔**：结尾卡点：死街型危机，众人必须穿过尸臣控制的主干道；埋设/回收伏笔：肉丘尸臣与亡灵密集 → 后续揭示其淬尸化骷的功能。
