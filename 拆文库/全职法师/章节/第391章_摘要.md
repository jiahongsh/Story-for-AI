# 第391章 野心议员

**概要**：莫凡喂药后坐在图腾玄蛇脑袋上，心灵畏惧消散不少；他检查发现玄蛇溃烂的皮明显脱落、深伤也连同旧皮剥落，蛇身像被劈出另一具身体。灵灵带着迷你笔记本赶来监控，点破那是蜕皮——大蛇总算开始蜕皮、应能渡过蜕皮期，若王小筠顺利归来危机便有惊无险。但灵灵随即发现王小筠行程突然停在地面上，周围并无强大生物，莫凡担忧他遇到事情。此时王小筠正趴在灰鹰背上，头顶白魔鹰如白色巨网笼罩夜空涌向杭州，而拦住他去路的是罗冕议员。罗冕假意称任务完成得很好、要他交出鹰红草由自己送去隔离区救人；知道瘟病真相的王小筠拒绝，坚持亲手交给军司。罗冕笑容变冷，喝令交出空间手环——他身为至高暗影系超阶法师，全杭州无人想到他能悄无声息穿梭战场；他盘算着祝蒙已不再信自己、议员之位难保，若拿到鹰红草便握住全杭州的救命稻草，不但无人敢兴师问罪还能借势更上一层楼。他轻蔑威胁王小筠：献上东西可饶命并保其仕途，否则这个无名小卒会彻底从世上消失，此刻的他如贪婪冷酷的吸血鬼。

**关键事件**：1.图腾玄蛇开始蜕皮，恢复有望 2.王小筠返程突然停滞，灵灵监控发现异常 3.罗冕暗影超阶法师之身拦路，威胁抢夺鹰红草

**逐章写法公式**：

- **情绪流向**：起：蛇口余生的松弛 → 承：蜕皮揭晓的欣喜 → 转：行程停滞的不安 → 合：罗冕现身的愤怒压抑
- **节奏配比**：慢铺垫 35% / 快冲突 35% / 爽点爆发 5% / 悬念留白 25%
- **本章结构公式**：蜕皮解忧（支线报喜）+ 监控异停（悬念转移）+ 视角切换对峙（危机具象）+ 反派摊牌（压迫收尾）
- **本章核心技巧**：前半章用报喜松弦，后半章以"监控异常"为镜头切换枢纽，把读者的安心瞬间转押到新危机上
- **卡点与伏笔**：结尾卡点：生死对峙——超阶暗影法师罗冕威胁要让王小筠从世上消失，鹰红草归属未决；埋设伏笔：玄蛇蜕皮期 → 恢复后的战力悬念；灰鹰"弱成渣"的血脉 → 被轻视伏笔；罗冕暗影超阶身份 → 其战力底牌；祝蒙不再信罗冕 → 朝堂清算线
