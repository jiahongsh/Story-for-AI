# 第235章 斩杀党羽！

**概要**：宋霞不顾同伴劝阻循着更刚猛的火焰气息返回，发现原地堆起焦黑尸体、妖魔化粉，认出遍地残留的血红火焰是灵火而非凡火，判断阵中另有一位拥有灵火的强火法，并提醒众人"这里掺进了不属于学校的东西"。另一边，灰一贴着黑暗之墙围捕精疲力尽的暗影妖兽，却被一队误入的学员惊叫坏事，妖兽速度暴增遁走；灰一压下怒火，以"李桐学长"的身份换上笑脸，应邀加入这支恰有暗影系学员、缺一人的队伍。借暗影系队友追踪，他们很快再度围住跑不动的妖兽，灰一却冷笑着站到四人背后准备偷袭论功。此时莫凡自黑暗之墙中现身，连暗影系学员都察觉不到他的遁影；他无视自称明珠学府四杰的学员，死死锁定李桐，点破"看看你的黑畜妖"——李桐最强的黑畜妖已被一根若隐若现的巨钉死死钉在墙面上。

**关键事件**：1.宋霞发现灵火痕迹，警觉校内混入外来者 2.灰一假扮李桐混入四人队图谋偷袭 3.莫凡黑暗现身揭穿李桐，其最强黑畜妖被钉墙上

**逐章写法公式**：

- **情绪流向**：起：紧张（宋霞折返察痕） → 承：压抑（灰一伪装入队） → 转：紧张（偷袭前一瞬） → 合：爽（莫凡现身钉敌揭穿）
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：痕迹鉴定（旁证主角火力） + 围兽失手（灰一被搅局） + 借队潜行（伪装接近猎物） + 现身亮钉（先手揭穿卡点）
- **本章核心技巧**：用"鉴定—伪装—揭穿"三段让同一场猎杀在正反两方视角间倒手，读者全知、四杰无知，悬在偷袭前一瞬收章
- **卡点与伏笔**：结尾卡点：揭穿卡点——黑畜妖被钉、莫凡点名李桐别演戏，下章期待党羽被逐一斩杀；埋设/回收伏笔：灵火残留 → 莫凡焚焰系灵种秘密被宋霞盯上；"不属于学校的东西" → 黑教廷渗透的官方视角线索；李桐身份 → 灰一假名伏笔
