# 第332章 路遇女人

**概要**：西照谷每到夕照便流光异彩，传说是傍晚盛开的奇花，吸引过探险家；真相是日晒积热后会分泌油亮角质皮层的褐皮蜥颅巨妖成群爬出沼泽塘铺满谷中向阳处，皮油反光如遍地珠宝，送掉几波人命后这层美丽面纱才被揭开，部落扩张后人们迁离，恶闻流传至今。傍晚，全副武装的大锤猎人队沿泥路进发——这是比翼市有名的五人组，全员中阶法师，从线人处得知西照谷藏有价值上千万的宝物。半途加入的黑衣独行女子自称迷路，实则对宝物没兴趣、只为调查一件怪事；她身材惹眼、用木枝盘发的野性打扮撩得队员们天天借口解手。队长梁大锤私下感叹独行女人在荒野遇上无良猎队便是劫杀抛尸无人管。 strategist红鸟定下傍晚从东面入谷的计划，翌日果然一路无蜥——蜥颅巨妖全在西面泥浴晒太阳。红鸟向女子讨刮目相看未果；这位自称"我一般负责解决问题"的女子名叫离曼，她只对沿途莫名出现的蜥颅巨妖尸体感兴趣，嘀咕着雷力击穿、秒杀，自己应该离那家伙越来越近了。

**关键事件**：1.西照谷奇光真相揭晓 2.大锤猎人队携独行女子入谷寻宝 3.红鸟借蜥蜴晒太阳的习性择路避战 4.离曼循雷击尸追踪目标

**逐章写法公式**：

- **情绪流向**：起：悬念（西照谷奇光传说）→ 承：轻松（猎队荤段子与寻宝吹嘘）→ 转：压抑（独行女人的凶险处境私语）→ 合：紧张（入谷顺利，离曼嘀咕接近目标）
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：奇光传说与真相（舞台铺设）+ 猎队群像与荤段子（轻松过场）+ 独行女人入队（核心人物隐身登场）+ 红鸟择路复盘（智斗小展示）+ 离曼追踪雷击尸（主线钩子）
- **本章核心技巧**：把最重要的追踪者藏在"路遇的女人"视角里，用猎队的贪与色做掩护，结尾一句嘀咕完成主线召唤。
- **卡点与伏笔**：结尾卡点：追踪卡点——离曼循雷击尸体接近"那家伙"，期待与恶魔莫凡的相遇；埋设伏笔：西照谷千万级宝物 → 猎队贪念的祸源；离曼的"完成某个任务探查怪事" → 与比翼军区调查线并轨。
