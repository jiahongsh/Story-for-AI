# 第400章 图腾玄蛇VS银色穹主（上）

**概要**：武平景身负重伤，靠祝蒙从银光中救回才没变成尸体；唐忠掩护二人撤退，武平景虚弱提议退回城市防御结界，祝蒙怒斥若连超阶都退守便无人挡住妖孽，任何技能落在医院学校都将是成百上千条人命。他自认不能像穹主那样冷血驱子民送死，议员若对数百万生灵置之不理与妖魔无异，咬牙开启从未动用的魔具天霆宫铠，苍白闪电披甲加身、背后燃起火焰翅膀，又唤出烈焰骑士长枪，借初升旭日之势焚开穹主的利刃领域杀入其中，这是开战至今唯一收获。然而穹主轻蔑一扇巨翅，力量不足以刺穿其身躯的祝蒙化作紫红陨石从数千米坠落，砸毁城市边缘一整条空街，吐血撑起后自责五名超阶联手也敌不过它。高空只剩云枫、梨天、唐忠束手无策之际，城市里传来震天嘶吼，图腾玄蛇托着青黑迷雾穿过白魔鹰军团直上高空——穹主全程忌惮的地面之物正是它；穹主尖叫着呼唤军团飞蛾扑火撞向玄蛇，玄蛇也有自己的君主领域：青色屏障般的毒气。

**关键事件**：1.祝蒙拒绝退守，以天霆宫铠和旭日长枪焚开穹主利刃领域 2.祝蒙被一翼扇落数千米坠毁街道，五超阶联手不敌穹主 3.图腾玄蛇升空直逼穹主，揭示穹主全程忌惮之物正是它

**逐章写法公式**：

- **情绪流向**：起：揪心（伤员议退） → 承：热血（雷铠旭日枪破领域） → 转：跌落（一翼扇落坠街） → 合：燃点（玄蛇升空对峙）
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：退守之辩（价值观立人设）+ 双魔具爆发（爽点释放）+ 一翼打回原形（再压）+ 守护神升空（救场钩子）
- **本章核心技巧**：让配角燃烧到极限仍败，用其绝望垫高守护神登场的分量，爽点后置两章才兑现
- **卡点与伏笔**：结尾卡点：双君主领域对撞——穹主利刃领域对玄蛇青色毒气屏障，军团飞蛾扑火撞向玄蛇，胜负下章揭晓；埋设/回收伏笔：穹主总望地面→回收为忌惮图腾玄蛇；天霆宫铠与旭日长枪→祝蒙压箱底魔具已尽、战力见底
