# 第1492章 这才是真相吗？

**概要**：凌长者自知难敌整个学府，最终离开。珈蓝老师托莫凡一行把伊迪丝乔装成明珠学府学员押往圣裁院，布兰妾与海蒂也换装同行，郑教授召出莽山兽驮行半天，抵达雪山盆谷中的圣裁院，将伊迪丝押入大牢。布兰妾与海蒂在众神大殿遇见一名蒙面纱女子，卡萨世族长老称其为神女殿下，因她出手救下小公爵赫卡萨而来道谢，并许诺为莱茵世家金耀骑士讨公道出力。莫凡认出这女子是伊之纱，一番对质后意识到伊迪丝是伊之纱安插的人，自己与阿尔卑斯山学府、卡萨世族都成了她手中摆布的棋子，而其余人依旧一无所知。

**关键事件**：1.凌长者退走，伊迪丝被乔装押往圣裁院大牢 2.莫凡在众神大殿认出神女殿下即伊之纱 3.莫凡识破伊迪丝是伊之纱的人，整个事件是其布局

**逐章写法公式**：

- **情绪流向**：起：押送启程的轻松 → 承：圣裁院山门的肃穆 → 转：认出伊之纱的惊变 → 合：识破棋局的细思极恐
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：乔装押送（任务线推进） + 圣裁院见闻（场景建立） + 认出伊之纱（身份反转） + 识破全盘布局（全书级钩子）
- **本章核心技巧**：在押送任务顺利完成的高点上，用一句自白把前几章的案件整体推翻
- **卡点与伏笔**：结尾卡点：信息揭示+伊之纱布局、其他人一无所知；埋设/回收伏笔：伊之纱的邪笑 → 心夏在帕特农神庙的安危线；卡萨世族结盟 → 伊之纱神女大选的势力布局
