# 第171章 任选魔具

**概要**：萧院长一早带莫凡到图书馆顶楼不对外开放的会议室发放新生大赛奖励。萧院长点破当天虽没看清他怎么逃出坤之林、却嗅到了黑暗气息，莫凡表示他若去查博城的情况并不难知道——天生双系本要在魔法高考当天公开，那是朱校长的意思，结果博城灾难降临、主持公开的朱校长战斗牺牲，此事便无人再提。萧院长说不必去查，终有一天你会自己暴露。随后谈妥资源折算：毕业生捐赠部分不参与，学院出资的公共资源折算成莫凡能用的资源。萧院长袖管一扬摆出数件适用中阶魔法师战斗的魔具任选一件，每件放到市面上卖至少五百万。他逐一讲解：血靴由长白山血兽骨血炼成，穿上双腿获得血兽的奔跑爆发力、速度比风轨·飘影更强，每补一次血兽精魂可用一次破山之力；青鳞铠柔软灵活、风系法师穿上都不受影响，缺陷是防御不强，遇到战将级或中阶魔法攻击顶多保命。莫凡盘算后觉得铠魔具对自己有些鸡肋。

**关键事件**：1.萧院长点破嗅到黑暗气息 2.资源折算规则谈定 3.魔具任选一件、市价至少五百万 4.血靴与青鳞铠性能讲解

**逐章写法公式**：

- **情绪流向**：起：轻松（领奖的期待） → 承：紧张（黑暗气息被点破） → 转：爽（五百万级魔具任选） → 合：其他（铠魔具鸡肋的权衡）
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 35% / 悬念留白 15%
- **本章结构公式**：顶楼领奖（仪式感） + 气息点破（秘密余震） + 折算谈定（规则铺垫） + 魔具开箱（爽点钩子）
- **本章核心技巧**：把奖励发放写成一场装备开箱加科普讲解，用萧院长的师者口吻把设定信息全部剧情化。
- **卡点与伏笔**：结尾卡点：血靴与青鳞铠讲解完毕、乌斩未讲，下章期待选定哪件魔具；埋设/回收伏笔：黑暗气息被萧院长察觉→多系之谜的知情人又添一人且被默许；朱校长牺牲、双系公开中断→回收博城线；宇昂的履魔具→前文决斗的旧对照。
