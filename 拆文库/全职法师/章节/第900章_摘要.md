# 第900章 手撕诅咒畜妖！

**概要**：天焰葬礼将大祭殿几乎毁尽，教徒无活口，唯四名灰衣教士借岩系防御与魔具躲过一劫带伤逃窜。莫凡穿火海锁定四人，以巨影钉梨刺扎穿一腿慢灰衣教士双膝将其钉墙，趁其骂死神时拧出雷电闪鞭抽飞偷袭的诅咒畜妖，再以空间念控将其生生撕成两半。莫凡追其余人，被钉墙的灰衣以为获赦，却见天焰葬礼火海蔓延过来，恐惧渐深。

**关键事件**：1.天焰葬礼清殿留四教士 2.巨影钉钉灰衣教士 3.雷鞭抽飞诅咒畜妖 4.念控手撕畜妖 5.火海反噬被钉者

**逐章写法公式**：

- **情绪流向**：起：清殿的爽 → 承：追杀的酷 → 转：手撕的爆 → 合：火海反噬的余味
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：清殿留口（爽） + 钉妖制场（酷） + 念控撕妖（爆） + 火海反噬（余味）
- **本章核心技巧**：群杀后留单个猎物，用"以为赦"反差收尾
- **卡点与伏笔**：结尾卡点：被钉灰衣如何死，火海揭晓；伏笔：巨影钉梨刺 → 莫凡暗影系手段
