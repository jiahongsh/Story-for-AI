# 第614章 死街

**概要**：莫凡一行来到宽阔却被亡灵占据的主干道，发现骷髅、腐尸、恶鬼以及多只尸将、骨将聚集在街上，肉丘尸臣像一座肉山堵住通路。矮男去寻找其他法师，莫凡独自借楼影和遁影探查。他在咖啡店附近遇到一只恶鬼并用雷印击杀，随后穿过大厅，藏在临街橱窗的模特后观察死街，确认亡灵数量超过两百且横穿道路极难。莫凡选出一条通往狭窄步行街的斑马线，又发现对街有携带风之翼的紫衣法师正在观察自己。

**关键事件**：1. 众人确认主干道已成为亡灵密集的死街 2. 莫凡独自潜入楼群和咖啡店侦查 3. 莫凡找到可通往步行街的斑马线并被紫衣法师发现

**逐章写法公式**：

- **情绪流向**：起：压迫 → 承：潜行侦查 → 转：发现可行路线 → 合：陌生法师搭话
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：确认死街（建立障碍） + 楼群潜行（靠近目标） + 雷印灭鬼（处理意外） + 橱窗观察（筛选路线） + 紫衣搭话（引出援手）
- **本章核心技巧**：用连续移动场景展示能力，同时把路线筛选和新角色登场放在同一个侦查动作的结尾。
- **卡点与伏笔**：结尾卡点：紫衣法师以心灵之音询问人数和身份；埋设/回收伏笔：斑马线与步行街路线 → 后续成为七百人过死街的通道。
