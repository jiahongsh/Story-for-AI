# 第194章 活下去的权力

**概要**：莫凡在半空等到妖母扑至三米内才抛出火滋·爆裂，借爆炸冲击力改向坠向中央大舞台，仍被妖母的爪刃旋风撕伤手臂、胸膛和左脸，重伤摔上舞台飙血。场馆里被寄生的女生接连现形，八只青黄女妖将莫凡包围，达到战将级的妖母忌惮烈拳不肯近身，只在圈外指挥围猎，还嘲笑着说杀了莫凡这里就是它的巢穴。灵灵传话说猎妖队准备杀入、必须放弃被寄生的女生，指挥者与光头队长都断言莫凡杀不了战将级生物。莫凡想起第一个从妖体内爬出、只想活下去的女孩，对耳机怒吼再给点时间。馆外巨兽头颅上的猎王开口拍板：再给他点时间，她们也有活下去的权力。

**关键事件**：1.莫凡空中自爆火焰改向仍重伤坠台，被八只青黄女妖合围 2.指挥部决定牺牲被寄生者强攻，莫凡怒拒并索要时间 3.猎王拍板再给时间，一百多名女生暂得生机

**逐章写法公式**：

- **情绪流向**：起：紧张（空中追杀近身）→ 承：压抑（重伤坠台、群妖围困、牺牲决议）→ 转：悲伤（回忆爬出妖体的女孩）→ 合：热血（怒骂索时间、猎王拍板）
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：空中爆炎自救（脱坠）+ 群妖合围（断牌）+ 指挥部牺牲决议（立道德困境）+ 怒骂换时间（反转卡点）
- **本章核心技巧**：把救不救一百多人的道德困境交给配角说出来，主角用一句怒骂完成人设宣誓。
- **卡点与伏笔**：结尾卡点：悬置（猎王给了时间，但莫凡仍被群妖围着，破局留下章）；埋设/回收伏笔：一百多名被寄生女生 → 全章道德重量，后文生还回收；猎王、光头队长、李院士、周正华 → 馆外决策线人物入场。
