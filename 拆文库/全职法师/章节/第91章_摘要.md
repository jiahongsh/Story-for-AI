# 第91章 妖魔袭城！

**概要**：蓝色警戒意味着至少上千只妖魔徘徊安界附近，博城近十年未曾拉响。万断风接到巡逻队长周金的来电：队伍遭群兽袭击，光法师已死、无法继续释放光耀；周金留下向斩空和潘丽君代为抱歉的遗言后挂断，万断风明白那种情况下打电话的人绝无活路，含悲下令拉响血色警戒，把不敢置信的哨岗军法师咆哮着催促执行。山岳背后的咆哮随即连成一片，一只三眼魔狼傲立孤松顶端、以三颗红眼俯视人类驿站如看羊圈，其后成群独眼魔狼涌现，三四百只齐声呼唤同伴，最终如青黑潮水覆盖山岭，狂奔着冲击雪峰山驿站——妖魔袭城。

**关键事件**：1.周金遗言来电后赴死 2.万断风下令拉响血色警戒 3.三眼魔狼率群狼现身袭城

**逐章写法公式**：

- **情绪流向**：起：警号错愕 → 承：遗言锥心 → 转：血色令下 → 合：兽潮压城
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：警戒分级科普（定标尺）+ 周金绝命来电（人命落锤）+ 血色警戒令（升级）+ 三眼魔狼与狼潮亮相（灾难正面登场）
- **本章核心技巧**：用"一条人命+一次升级+一个敌酋"三连击把警戒从信号变成可见的兽潮，全程不写主角保持灾难的纯粹压迫
- **卡点与伏笔**：结尾卡点：狼潮冲向驿站、守军生死未卜；埋设/回收伏笔：三眼魔狼统帅群狼（回收第90章光耀信号、埋后文统领线）、周金遗言托付斩空与潘丽君（人情债伏笔）、血色警戒（主角线灾难总开关）
