# 第42章 坑学生

**概要**：三组刚过河谷，一名戴草帽的记分员便从树上跳下登记，随即走向空旷草地的帐篷——学生们以为被扔进大山无人管，实则老师和教官们都在帐篷里吃零食喝小酒，一路暗中跟随按表现记分。斩空听报张小侯表现出色，感叹修为只是基础、独当一面的法师靠脑子和胆量，让潘丽君记下名字给高分。老师们点破更深的局：悬赏本身根本无人能完成，连教官都未必行；目的地独眼魔狼巢穴已确保百分百没有残留妖魔，驿站派了召唤系法师带着召唤兽驻守其中，充当学生们的最后一道考验——以召唤兽扮演妖魔，既让学生见识真正妖魔的效果，又保障安危。张建国打包票称任教二十来年没听说学生第一次面对妖魔能完整释放魔法，1级技能根本伤不到召唤兽筋骨。唐月却没笑：她暗想莫凡持星尘魔器整整一年，火滋若已升级将是唯一能打伤召唤兽的学生，打伤可拿S；而只要在召唤兽那关释放出任一技能，斩空就会给A——A已是历年学生从教官手上拿到的最高成绩。

**关键事件**：1.草帽记分员揭底：老师教官暗中跟随学生记分，斩空批示张小侯给高分 2.罗云波揭局中局：巢穴无妖魔，召唤系法师的召唤兽扮演最后一道考验 3.张建国断言学生不可能伤到召唤兽，唐月暗押莫凡是唯一变数

**逐章写法公式**：

- **情绪流向**：起：记分员现身的揭秘趣味 → 承：套路被点破的轻松 → 转：召唤兽考局的新悬念 → 合：唐月暗押莫凡的期待
- **节奏配比**：慢铺垫 40% / 快冲突 5% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：记分员汇报（揭第一层）+ 坑学生内幕自白（揭第二层）+ 召唤兽考局（揭第三层）+ 唐月押注莫凡（留变数）
- **本章核心技巧**：纯揭秘章，用三层递进反转把一个考核的底牌一张张翻开，末尾留一张不翻
- **卡点与伏笔**：结尾卡点：悬念型——学生们即将撞上假妖魔真召唤兽，下章期待谷内遭遇；埋设伏笔：唐月押注莫凡火滋升级可拿S → 莫凡爆发线；打伤召唤兽给S的评分规则 → 后文兑现
