# 第422章 哪个系转来的？

**概要**：李玉洁安然无恙，白眉老师称赞莫凡有分寸，魏荣见他魔能所剩无几劝其到此为止，被莫凡拒绝。莫凡目光投向台下说不出话的郑佳慧，回想在杭州认识的军旅打杂少年面对白魔鹰军团与堕落超阶法师都未退半步，认定郑佳慧在毫无生命危险的校园里挤不出一点骨气是自私，他要打脸的对象正是郑佳慧而非整个火院。魏荣叫出第111名刘黔，女生们尖叫，黄星丽期待刘黔终结莫凡。刘黔先礼后兵，被莫凡以谁更帅一问斥为虚伪，变脸冷言宣战。老师们核查莫凡来历，雷院钱坤否认是自己学生，召唤系主任易玉泉欲言又止。

**关键事件**：1.魏荣劝停被莫凡拒绝 2.莫凡点明打脸对象是怯懦的郑佳慧 3.第111名刘黔登场与莫凡言语交锋 4.老师们发现莫凡并非雷院转来，易玉泉欲言又止

**逐章写法公式**：

- **情绪流向**：起：轻松（老师松气劝停） → 承：压抑（怯懦者与旧人对照） → 转：轻松（谁更帅的言语交锋） → 合：紧张（来历成谜欲言又止）
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：劝停拒绝（延续战线） + 动机揭示（价值观支撑） + 新敌登场言语交锋（树靶） + 来历追问卡章（留钩）
- **本章核心技巧**：把主角继续战斗的理由从胜负改成价值观，用一段回忆完成动机正当化，再用章末身份悬念收口。
- **卡点与伏笔**：结尾卡点：悬念+易玉泉有话要说，下章期待莫凡真正来历揭晓；埋设/回收伏笔：杭州军旅打杂少年 → 为莫凡的行为逻辑埋下人物注脚
