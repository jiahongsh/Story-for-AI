# 第70章 魔狼精魄

**概要**：杨作河脚踏缓缓褪去的星图立于老屋顶，为来迟致歉并问徐大荒伤势——黎文杰报队长胸膛被撕开但内脏没事、还活着，杨作河已请治愈系法师赶来，自己以风轨瞬移接近被暴浪冲得半死不活的魔狼，再施中阶风系魔法风盘：浑浊龙卷将动弹不得的魔狼拽上二十多米高空，龙卷散去令其重重摔下，水泥地凹陷出蛛裂纹，魔狼粉身碎骨、血浆飞溅，在两记中阶魔法下再无一声咆哮。莫凡跟至尸旁，杨作河肯定其已死，认出先前雷印是他所放、夸他做得很好并许诺协会联合猎者联盟和政府给一次嘉奖。莫凡掏出小泥鳅坠，坠子对刚断气的魔狼反应强烈，一缕狼魂从狼口飘出即被吸入、发出饱足颤鸣——他意识到这次不是浑浊勉强的残魄，而是精魄：受地圣泉滋养的妖魔死后出精魄概率相当高，精魄价值五百万，只有亡灵系法师或特殊器皿能采集、三分钟内即自行消散。趁杨作河转身交代现场之际，这笔巨款无声落入莫凡之手。

**关键事件**：1.杨作河风盘处决进阶期魔狼，两记中阶魔法碾杀 2.徐大荒确认内脏无碍存活 3.小泥鳅坠吸走狼魂级精魄，价值五百万且杨作河毫不知情

**逐章写法公式**：

- **情绪流向**：起：尘埃落定的余悸 → 承：风盘处决的降维爽感 → 转：坠子异动的暗喜 → 合：五百万入袋的窃喜
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 45% / 悬念留白 5%
- **本章结构公式**：战后确认（收队长悬念）+ 风盘处决（中阶收尾）+ 尸旁拾魄（金手指进账）+ 错身藏富（信息差收尾）
- **本章核心技巧**：大战之后用打扫战场式的处决戏延续爽感，真正的章眼却藏在尸旁三分钟——把横财写成一个只有读者和主角知道的秘密
- **卡点与伏笔**：结尾卡点：暗财悬念型——五百万精魄无人知晓，小泥鳅坠吃下后会有何变化待揭；埋设/回收伏笔：地圣泉滋养妖魔出精魄 → 地圣泉价值再抬升、与反派泉修线对撞；杨作河许诺三方嘉奖 → 莫凡梵墨身份的官方认证在途；星图中阶之证 → 中阶体系视觉符号；狼尸本身值钱 → 后续处理或交易线索
