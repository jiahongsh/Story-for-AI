# 第1321章 红衣主教-冷爵

**概要**：广州塔454米观景台上，黑色帽袍遮面的杀手卑匠与一位紫色眼睛的少年冷爵密谈。冷爵委托卑匠给被追查的女副判长致命一击，称不想在自己精心谋划北原一切时被中国审判会扫荡，并放话世上不可能只有撒朗而没有冷爵，随后如普通游客般乘电梯离去。一名熊孩子在摩天轮处踩空坠塔，母亲昏厥，卑匠闪现至摩天轮上方佯装要救，却笑着说自己不过是来欣赏他摔成肉酱的美景。莫凡与灵灵因航班延误两小时赶到广州，找到藏身城中村出租屋、奄奄一息的冷青，冷青的贴身审判使小苹坚决阻止送医，说那个杀手有鹰一样的眼睛盘旋上空、走到审判会可能就没命。灵灵与莫凡分析出审判会里有内奸，冷青四面楚歌。小苹终于说出内情：冷青追查黑教廷时触碰到一位红衣主教的行踪，那位主教嗅觉恐怖、命令盘查，他们逃入城市仍差点死在杀手手上。莫凡与灵灵愣住——竟是黑教廷七大红衣主教之一，小苹吐出名字"冷爵"时浑身一冷，仿佛那双紫色眼睛正在窗外凝望。

**关键事件**：1.冷爵委托杀手卑匠刺杀女副判长，密谋北原计划 2.莫凡灵灵赴广州，找到重伤的冷青与小苹 3.小苹道出冷青触碰到红衣主教冷爵的内情

**逐章写法公式**：

- **情绪流向**：起：广州塔密谈的阴冷悬念 → 承：卑匠变态人设的恐怖冲击 → 转：冷青重伤、无处可去的绝境 → 合：红衣主教冷爵身份的震撼揭示
- **节奏配比**：慢铺垫 20% / 快冲突 20% / 爽点爆发 0% / 悬念留白 60%
- **本章结构公式**：塔上密谈亮反派（开悬念） + 小孩坠塔显变态（立人设） + 城中村寻见冷青（推危机） + 红衣主教冷爵揭底（爆信息）
- **本章核心技巧**：两线并进——反派线用塔上密谈营造"敌在暗我在明"的压迫，主角线用伤者绝境与信息层层解密汇成章末爆点
- **卡点与伏笔**：结尾卡点：悬念型——冷青触碰到红衣主教冷爵，而杀手卑匠已接下刺杀令，莫凡与灵灵如何带她脱困；埋设/回收伏笔：冷爵的北原计划 → 后续黑教廷主线；审判会里有内奸 → 冷青不敢求援的原因；冷青卧底黑教廷触到红衣主教 → 她被追杀的根源；卑匠的夺命之影 → 其能力与最终对决的铺垫
