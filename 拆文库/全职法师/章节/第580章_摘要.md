# 第580章 被迫加入

**概要**：蒋黎与妖男针锋相对后，几位超阶法师完成部署：高阶法师纠缠统领级亡灵、中阶法师掩护分散军团，关键是消灭白幽鬼臣及其白阴鬼群。妖男受命统帅集结法师、护卫光法师团，却当场要求把莫凡编入队中。莫凡拒绝后被祝蒙一把拧回队列，祝蒙以开除学籍相胁，把他推给妖男，莫凡被迫加入。夜色中亡灵大军如潮水集结，煞渊怨气让沉睡的亡灵提前进阶。城楼号令既下，两百多名中阶以上法师随祝蒙、陆虚、飞角、独萧四位超阶法师跃出城墙，冲向黑色远方，众法师憧憬着斩杀君主级生物的战功。

**关键事件**：1.超阶法师完成部署，妖男受命统帅集结法师 2.莫凡拒绝加入，被祝蒙强行拧回队列并威胁开除学籍 3.两百多名法师随四位超阶法师跃出城墙冲向亡灵大军

**逐章写法公式**：

- **情绪流向**：起：憋屈（被强征） → 承：不安（战争渺小感） → 转：肃杀（亡灵大军压境） → 合：热血（大军跃墙）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：部署交代（立战术） + 征召风波（定阵容） + 心理独白（留反差） + 敌势渲染（加压） + 跃墙出击（起战）
- **本章核心技巧**：以主角被迫参赛的憋屈视角写大战序幕，让热血群像与个体退缩感互相拉扯
- **卡点与伏笔**：结尾卡点：战局悬念——莫凡所在的护卫队将遭遇什么；埋设/回收伏笔：莫凡精魄缺口与煞渊亡灵口粮 → 为战争中凝炼精魄蓄力
