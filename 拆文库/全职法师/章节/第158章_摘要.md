# 第158章 进阶期幽狼兽（下）

**概要**：幽狼兽厉爪撕破水御，在风系学员胸膛划出一道触目惊心的血痕；痘痘惊恐不解自己三级的水御为何失效，被李俊巍呵斥释放太慢。雷系学员以雷印围轰，幽狼兽嗅到焦灼之气跃开躲过。随后它朝雷系学员方向吐出飞沙走石，范围比莫凡当年所见的粗狂不止一倍，化作覆盖四分之一斗兽铁笼的小型沙尘暴；李俊巍双手拍地释放地波，把雷系火系两个伙伴推送到铁笼两侧，再开启防御魔具藤墙护住自己和痘痘。萧院长与土系系主任周正华盛赞李俊巍的处置给茫然的土系学生上了一课，萧院长随即补上一句"可惜，它们败了"——尘埃沉淀后，完成三段爆发的幽狼兽已出现在李俊巍面前不到1米处。李俊巍确认这是半只脚踏入战将级的进阶期生物，认识到五人团队在它面前如同孩童。

**关键事件**：1.幽狼兽破水御重伤风系学员 2.放大版飞沙走石逼出李俊巍地波加藤墙的教科书应对 3.三段爆发现身，五人组确认遇上进阶期生物

**逐章写法公式**：

- **情绪流向**：起：紧张（破盾见血） → 承：紧张（雷印交锋与吐息酝酿） → 转：爽（沙暴覆盖全场的压制） → 合：压抑（三段爆发宣判实力鸿沟）
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：破盾伤人（立压制开局） + 吐息沙暴（攻击层级放大） + 地波藤墙（保留败者尊严的应对） + 三段爆发现身（宣判实力差）
- **本章核心技巧**：让看台权威给败者的应对打分、再用一句判词提前剧透胜负，把过程张力从谁赢转到怎么败上。
- **卡点与伏笔**：结尾卡点：实力定论+进阶期幽狼兽立于李俊巍面前，下章期待莫凡收场与各方震动；埋设/回收伏笔：上章李俊巍的吐息警告→本章放大版飞沙走石回收；三段爆发定级→为莫凡借幽狼兽夺资源的野心铺垫。
