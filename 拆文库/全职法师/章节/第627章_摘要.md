# 第627章 不到两公里！

**概要**：莫凡从柳茹的血液反哺中醒来，回想起古都浩劫仍未结束。柳茹用小蝙蝠印记带他寻找张小侯等人，两人穿过亡灵吞没的街区，发现华村村民躲在异土公园，附近腐尸却没有攻击他们。柳茹解释昆井之水能够提供暂时庇佑，并派出血气蝙蝠侦查。她还透露有人送血迹给自己且一直跟踪他们，莫凡由此察觉有人可能在暗中保护或监视华村，话题牵出新的线索。

**关键事件**：1.莫凡从沉睡中醒来 2.柳茹以蝙蝠印记寻找张小侯 3.两人目睹亡灵吞没北城 4.华村村民得到昆井之水庇佑 5.有人暗中送血迹并跟踪柳茹

**逐章写法公式**：

- **情绪流向**：起：睡醒后的轻松 → 承：记忆恢复与亡灵逼近 → 转：发现华村暂时安全 → 合：跟踪者与血迹线索浮现
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：醒来确认灾难（恢复主线） + 追随蝙蝠印记（推进寻找） + 穿过亡灵海（扩大危机） + 侦查华村公园（引出跟踪者）
- **本章核心技巧**：用轻松插科打诨承接灾难移动场景，再以一个被隐瞒的跟踪细节切回悬念。
- **卡点与伏笔**：结尾卡点：柳茹说有人送血迹并跟着他们，莫凡突然想到其中可能有关键联系；埋设/回收伏笔：小蝙蝠印记 → 找到张小侯等人的位置。
