# 第970章 无一败绩

**概要**：拿下墨西哥国馆勋章后，队伍奔赴下一站美国，美国国馆设在纽约自由神殿所在的自由岛。自由神殿是美洲最高魔法协会，整座自由女神像便是神殿殿堂，圣蓝与金黄交织，底座设观光与法师厅堂，颈部为不对外开放的自有神殿。奥露娜因莫凡助擒卡索而受神殿赞赏，亲自到广场接应并主动带往国馆。莫凡玩笑求放水，其弟费洛姆当即不满，直言中国人喜走后门；奥露娜介绍弟弟是国馆选手，费洛姆蓝琥珀眼、桀骜轻蔑，莫凡回敬并挑眉暧昧问"我特殊对待？"，惹得费洛姆吃醋炸毛，放话国馆挑战上让莫凡好看。蒋少絮发现国馆墙上各国国旗后全画着叉，费洛姆自豪称顶页亦全叉——美国国馆至今无一败绩。更刺眼的是今日中国国旗后也已先画上叉，费洛姆称队长提前填好结果，并甩出"尊重只属强者"，南珏与江昱愤而反驳，奥露娜也不好置评。

**关键事件**：1.自由神殿即女神像，队伍赴美 2.奥露娜亲迎，费洛姆因放水之言挑衅莫凡 3.墙上连败记录揭美国国馆不败 4.中国国旗被提前画叉，双方言语交锋

**逐章写法公式**：

- **情绪流向**：起：神殿震撼的仰视 → 承：费洛姆挑衅的绷紧 → 转：不败记录的压力 → 合：提前画叉的战意点燃
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：神殿场景铺敬畏（定标） + 费洛姆挑衅立敌（加压） + 全叉墙显强（施压） + 提前画叉激战意（钩子）
- **本章核心技巧**：用连败记录与提前画叉把"强敌"量化成可感知的羞辱，逼出主角团背水斗志
- **卡点与伏笔**：结尾卡点：战意型，美国国馆不败且已判中国失败，下章期待五战五对决；埋设/回收伏笔：奥露娜受赞赏 → 回收擒卡索红利；费洛姆 → 新劲敌伏笔
