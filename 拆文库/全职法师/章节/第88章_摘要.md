# 第88章

**概要**：地圣泉藏在博城地标银贸大厦地下十五层，穆卓云与唐月陪同莫凡乘秘密电梯下到晶岩地厅，这里由中阶魔法师梁斌带巡逻队看守。穆卓云没好气交待规则：进图腾门修炼一周，坐在泉中皮蒲团上冥修，别碰泉水的循环。临别时唐月叫住莫凡，送他四卷昂贵的星图之书，并讲解中阶原理——星尘化星云、49颗星子连成星图，中阶魔法才成；星图之书能在法师把控力不足时代为排列星子释放中阶魔法，但星云未成就使用会被抽成干尸。穆卓酸溜溜点破此物有钱买不到、唐月不止是高中老师。莫凡心中感动，立志早日中阶、赚钱娶唐月报答恩情。入泉前他听见梁斌叮嘱守卫提防地沟老鼠，随即联想到独眼魔狼正是得了地圣泉温泽才那般恐怖。

**关键事件**：1.唐月赠四卷星图之书并讲解中阶原理 2.穆卓云点破唐月身份不简单 3.莫凡联想到独眼魔狼与地圣泉温泽的关联

- **情绪流向**：起：轻松探秘 → 承：授业温情 → 转：干尸警告 → 合：暗线惊心

- **本章结构公式**：下地探泉（新场景开图）+ 唐月赠书讲道（设定+情感）+ 干尸警告（泼冷水埋险）+ 守卫叮嘱勾连旧案（暗线钩子）
