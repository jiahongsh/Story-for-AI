# 第705章 鬼木手

**概要**：狄凯厄斯双手一扬，金褐色气流在莫凡冷青周围组成风之屏障并迅速缩紧，莫凡嘀咕其一念星图中阶瞬发。冷青松开手让莫凡自由落体，自己震碎飓风屏障，眼中黑褐岩魔之瞳苏醒，以天纱凝石笋攻去。狄凯厄斯也展魇魔之瞳化天纱铠防御，却被冷青拆天纱成沙鞭抽落坠地恼羞成怒。莫凡趁机杀到飞机前大骂，格洛肯出舱质问，莫凡第四级烈拳轰烂机翼，格洛肯跳下欲教训，脚下草地裂开鬼藤将莫凡打飞十几米。

**关键事件**：1.狄凯厄斯风屏障裹二人，冷青岩魔之瞳反击 2.沙鞭抽落狄凯厄斯 3.莫凡杀到飞机轰烂机翼 4.格洛肯鬼藤打飞莫凡
