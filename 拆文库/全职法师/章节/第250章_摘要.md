# 第250章 帝都学府

**概要**：莫凡一行随领队老教授秋雨华游览帝都名胜：长城为秦始皇所建、最早用来抵御妖魔入侵，如今已成遗迹；莫凡调侃古时魔法落后，被秋雨华正色驳斥——秦始皇是史上最了不起的土系魔法师，以莫凡修为强攻十天也休想在长城上打出裂痕；始皇陵至今无法涉足，否则便不会有亡灵天堂——西安境外那片令猎人寸步难行的亡灵之地。老教授借古迹宣讲：人类魔法文明由无数强者尸体堆砌而成，后人须努力修行抵御百倍千倍于人类的妖魔；莫凡感慨此界历史科技与原世界吻合、唯格局不同，人妖之战从未停歇。随后一行进入中国第一的帝都学府；外交老师顾翰手气衰，从985工程近40校中偏偏抽中排名第一的帝都学府，校领导气得七窍生烟。帝都世家子弟多如普通学员、天才一抓一大把，明珠领导不愿怂，萧院长定名单第一个写下莫凡——黑教廷都敢杀的人去帝都保证吃不了亏；再点赵满延、牧奴娇、宋霞、郑冰晓、罗宋、沈明笑、白婷婷、彭亮，连同莫凡共9人，顾翰领队、秋雨华随队讲课，除彭亮外全是熟人——如果有仇的也算。

**关键事件**：1.秋雨华借长城宣讲魔法文明史与亡灵天堂设定 2.顾翰衰手抽中帝都学府，交换生对抗成行 3.萧院长点齐以莫凡为首的九人名单出征帝都

**逐章写法公式**：

- **情绪流向**：起：轻松（长城游览吟诗） → 承：压抑（亡灵天堂与文明代价） → 转：紧张（帝都底蕴压顶、妖孽如菜） → 合：轻松（九人名单与仇人同行的吐槽）
- **节奏配比**：慢铺垫 55% / 快冲突 5% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：长城史课（世界观扩容） + 文明之训（主题升华） + 抽签与底蕴对比（对手立威） + 九人名单（队伍集结）
- **本章核心技巧**：用现实名胜的"魔法化导游课"完成世界观扩容与主题宣讲，再以选人名单的绰号速写完成队伍集结，为切磋篇蓄力
- **卡点与伏笔**：结尾卡点：集结卡点——仇人同队的九人抵达帝都，下章期待学界切磋；埋设/回收伏笔：秦始皇陵与亡灵天堂 → 长线秘境伏笔；故宫魔法宫廷的次日行程 → 历史宝物线；顾翰抽签衰运 → 明珠帝都对抗由头；宋霞"太暴力"的吐槽 → 队伍化学反应
