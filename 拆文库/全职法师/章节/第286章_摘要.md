# 第286章 离队独行

**概要**：队伍找安全处休整，宋霞伤重未卜，小峰的腿已完全健全。白婷婷点明若非穆宁雪及时冻住伤口止血流逝，宋霞必死，宋霞虚弱醒后感激望向穆宁雪。郑冰晓问接下来怎么办，重伤加退意令人心不和。穆宁雪表态"总之我不会走"——真正的历练是对实力最大的考验，没有理由退缩；牧奴娇持同见：名门出身的她深知经不住生死考验会影响修为，若这次离开将来再也提不起闯关的勇气。两个女子都留下，廖明轩等男人没脸再提回去。但廖明轩、沈明笑、明聪对莫凡的敌意未消，廖明轩骂他遇到危险就跑、品格低劣，明聪自夸若非自己的光系斩魔具众人未必冲得出来。莫凡大步逼近放话两人一起上也给个半残不死。牧奴娇压下争吵，莫凡当即提出离队单走另一勘测点——不愿与只会狗叫的人为伍。牧奴娇郑冰晓劝阻无果，廖明轩冷笑看他能否活着出来，罗宋落井下石说是他自己要离队。白婷婷需照顾宋霞、赵满延被莫凡劝回队中。临别牧奴娇赠出随身护身符水晶守珠，叮嘱完好带回；莫凡调戏说没回来就找个好人家嫁了，牧奴娇恼怒扭头就走。莫凡独自折返倒塌的市政大楼废墟，翻检被咬烂的伪怖魔头颅想找精魄，一无所获，只安慰小泥鳅坠：独享总好过与那群恶心家伙分羹。

**关键事件**：1.穆宁雪牧奴娇表态坚持任务，压下退意 2.莫凡与廖明轩明聪彻底决裂，负气离队独行 3.牧奴娇赠水晶守珠，莫凡独返废墟寻伪怖魔精魄未果

**逐章写法公式**：

- **情绪流向**：起：压抑（伤情与人心不和） → 承：热血（穆宁雪牧奴娇表态留人） → 转：压抑转爽（决裂挑衅与硬刚离队） → 合：甜（守珠相赠）转轻松（废墟寻宝自语）
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：去留之争（立场分化）+ 决裂挑衅（矛盾爆发）+ 赠珠离队（情感落点）+ 废墟折返（下章钩子）
- **本章核心技巧**：用"离队"解决团队矛盾僵局——不强行和解，让主角带怒单飞开辟新线，冲突能量转化为叙事动力
- **卡点与伏笔**：结尾卡点：莫凡独自回到伪怖魔毙命的废墟、精魄未现，独行线开启；埋设/回收伏笔：水晶守珠→防身底牌（待回收）、廖明轩争风吃醋→情敌线、穆宁雪临别交代→双向牵挂、伪怖魔精魄落空→小泥鳅坠收集体系缺口
