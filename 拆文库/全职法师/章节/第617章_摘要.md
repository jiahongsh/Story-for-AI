# 第617章 淬尸化骷！

**概要**：左锋飞近肉丘尸臣后，看见十几只幽灵鬼将不断搬运活人和尸体，把它们送进尸臣张开的巨口；尸臣下方的小嘴又持续吐出刚炼成的骷髅。左锋确认肉丘尸臣正在把城市居民转化成亡灵，立即让一名禁卫法师回内城报告并请求高阶法师增援。莫凡得知真相后意识到死去的人会继续变成骷髅，要求人群加快过街，否则七百人的尸体会成为新的骷髅军团。穆白和周敏开始指挥土系法师推开车辆，利用汽车堆成路障。

**关键事件**：1. 左锋发现肉丘尸臣正在淬尸化骷 2. 一名禁卫法师返城报告尸臣的重大威胁 3. 莫凡催促人群加速过街并以车辆设置路障

**逐章写法公式**：

- **情绪流向**：起：侦查 → 承：真相揭露 → 转：亡灵转化恐惧 → 合：人群加速并建立路障
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：靠近尸臣（观察目标） + 发现吞吐循环（揭示机制） + 请求增援（升级危机） + 通知莫凡（扩散恐惧） + 推车筑障（落地应对）
- **本章核心技巧**：先用连续动作呈现怪物机制，再用角色对话把机制转译为会影响群体选择的现实后果。
- **卡点与伏笔**：结尾卡点：人群已在路障和亡灵之间过街，尸臣生产骷髅的危机尚未解决；埋设/回收伏笔：淬尸化骷 → 后续尸臣会把七百人作为骷髅军团的材料。
