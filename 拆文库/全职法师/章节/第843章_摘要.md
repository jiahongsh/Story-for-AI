# 第843章 怨念未消

**概要**：穆宁雪独自在房间为家族被穆氏世族除名而落泪，官鱼敲门进来见状，自作主张提出让自己爷爷栽培她，并让她先以形式婚姻进入官鱼家族作为国府之争的后盾。穆宁雪心神根本不在官鱼的话上，官鱼却误以为她默认，转身激动地打电话给大爷爷提亲。大爷爷听后勃然大怒，痛骂官鱼蠢，指出穆宁雪被穆氏踢走是因为连穆氏都怕惹火烧身，此事牵连巨大、古都浩劫的怨念尚未消除，命令官鱼从此离她越远越好。官鱼呆立当场，这才意识到穆宁雪失势的影响远比他想的沉重。

**关键事件**：1.穆宁雪独处落泪被官鱼撞见 2.官鱼借机提亲，要穆宁雪进官鱼家换资源栽培 3.官鱼自作主张打电话向大爷爷提亲 4.大爷爷怒斥官鱼，点明穆宁雪失势牵连巨大、古都怨念未消

**逐章写法公式**：

- **情绪流向**：起：穆宁雪脆弱落泪 → 承：官鱼误判时机提亲 → 转：大爷爷怒斥点破真相 → 合：官鱼呆立，悬念留给穆宁雪
- **节奏配比**：慢铺垫 50% / 快冲突 30% / 爽点爆发 0% / 悬念留白 20%
- **本章结构公式**：穆宁雪落泪（示弱） + 官鱼提亲（误判） + 电话提亲（推进） + 大爷爷怒斥（揭真相）
- **本章核心技巧**：用一段权威电话对话把主角的背景危机一次性外化，避免平铺直叙
- **卡点与伏笔**：结尾卡点：官鱼呆立醒悟，穆宁雪失势影响远超想象，下章期待她如何回应；埋设/回收伏笔：古都浩劫怨念 → 后续穆氏家族被全民声讨的伏笔
