# 第597章 冰封灵柩

**概要**：莫凡击杀肉瘤尸将后，潜伏地下的铁臂尸将抓住他的脚踝。莫凡用第四级雷印麻痹对方并将其从土中带出，却因血兽靴消失、火光过亮无法遁影，被铁臂尸将一拳击飞，随后又躲开喷毒尸将的毒雨。另一边，妖男以水花天幕挡住尸臣触手，完成冰霜星座后施展冰封灵柩，把肥硕尸臣连同地面一起冻入冰棺。妖男说明尸臣内部已被血毒破坏，冰冻后亡灵结晶也会继续受损。

**关键事件**：1.莫凡发现并击退地下铁臂尸将 2.妖男以水花天幕防御触手 3.冰封灵柩困住肥硕尸臣

**逐章写法公式**：

- **情绪流向**：起：误以为清除近身威胁 → 承：地下尸将突袭 → 转：妖男水幕蓄力冰封尸臣 → 合：尸臣受困并进入持续死亡状态
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：击杀后的松懈（制造盲区） + 地下抓袭（追加危机） + 水幕防守（争取施法时间） + 冰封灵柩（完成控制）
- **本章核心技巧**：两条战线交替推进，一边用近身突袭保持危险，一边用蓄力型大招完成另一处战场的解决。
- **卡点与伏笔**：结尾卡点：肥硕尸臣被冰封但战斗结果仍需确认；埋设/回收伏笔：血毒已破坏尸臣内部 → 冰封后加速其亡灵结晶损坏。
