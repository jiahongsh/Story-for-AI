# 第673章 法师中的战斗机

**概要**：莫凡让小炎姬附体，烈焰化作战铠后以九蛟陨拳直接轰杀大尸将并焚灭百余亡灵，邪眼铜镜前的超阶法师因此重新评估他的实力。韩寂说明炎姬能将火种与控火能力加持给主人，陆续又点出莫凡多系与强化魔法的优势。地面上张小侯牵制亡灵、柳茹凭血族力量近战，三人配合使亡灵数量持续下降。莫凡再用霹雳清场，疾星狼与小炎姬补杀残敌，近两千亡灵被大幅消灭，高层遂将走出死门间的希望寄托在这支小队身上。

**关键事件**：1.小炎姬附体强化莫凡的火系攻击。 2.莫凡以九蛟陨拳秒杀大尸将并清扫亡灵。 3.张小侯、柳茹加入，三人形成分流与输出配合。 4.莫凡和两只契约兽清理残敌，死门间出现可被突破的希望。

**逐章写法公式**：

- **情绪流向**：起：紧张 → 承：爽 → 转：热血 → 合：悬念
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 25% / 悬念留白 5%
- **本章结构公式**：附体强化动作（建立优势） + 范围魔法清场（兑现战力） + 队友分工牵制（扩大战果） + 残敌肃清与高层判断（抛出通关期待）
- **本章核心技巧**：用旁观者的连续误判和解释，把主角一次攻击扩写成实力层级被重新认定的场景。
- **卡点与伏笔**：结尾卡点：目标悬念，莫凡的战力或可带队踏入祭坛；埋设/回收伏笔：炎姬附体加成 → 解释莫凡火系攻击的异常威力。
