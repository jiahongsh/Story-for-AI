# 第131章 暴火唐月！

**概要**：被钉住的朝赫看到唐月没有一点惊讶，反而扬言要再追加两条罪名，其中之一正是"杀死审判员"。唐月不理会，脚下勾勒火系星图，却发现一团浑浊之物快速涌出、漂浮在小水库上空组成稠密乌云，遮蔽整片空地连火灵种的火光都被吞掉——漆黑之中朝赫的影子不复存在，他因此挣脱巨影钉恢复行动。他自曝早几天就察觉被跟踪，在唐月假扮旅客所吃的食物里悄悄放了东西；唐月不信审判员会吃下毒物，朝赫得意道自己本就是出色的药剂师，下的不是毒、是令女性燥热动情的滋补药物。药力发作，唐月口干舌燥、脸颊红晕、浑身酥软，回想先前把莫凡按在树影下时竟觉对方有吸引力，才惊觉中了招；而审判会追拿朝赫，本是想从他口中得知"暴躁之泉"的由来。树林深处的莫凡看懂局面后犹豫是否出手，唐月一声怒喝"我要把你烧成灰烬"，施展朱砂之红的"雀炎"、第三级的烈拳与"九宫"，震撼画面令莫凡整个人呆滞。

**关键事件**：1.朝赫以乌云抹影解禁、自曝早已下药 2.唐月药力发作受制、得知审判会追查目标为暴躁之泉 3.唐月怒而施展雀炎烈拳九宫

**逐章写法公式**：

- **情绪流向**：起：对峙的凛然 → 承：解禁下药的阴冷 → 转：药力施暴的屈辱 → 合：雀炎爆发的燃
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：追加罪名（挑衅）+ 乌云解禁（反制）+ 下药真相（凌辱）+ 雀炎九宫起势（爆发掐断）
- **本章核心技巧**：先把执法者从优势位拖进泥沼，再用尊严被践踏的怒火点燃爆发，屈辱换燃点
- **卡点与伏笔**：结尾卡点：雀炎·烈拳·九宫蓄势轰向地表，威力下章揭晓；埋设/回收伏笔：巨影钉依赖影子（规则被反制回收）、朝赫药剂师身份（药物阴招线）、暴躁之泉由来（审判会追查主线）、唐月非凡品火种（其身份势力伏笔）
