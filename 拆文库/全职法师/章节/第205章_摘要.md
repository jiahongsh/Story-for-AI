# 第205章 斗备胎！

**概要**：艾图图欢快地去选房间，牧奴娇因不想与男人合租而眉黛紧锁地跟上。莫凡盘算要两个房间，等心夏放假就接来同住，又打算给要回博城久住的老爹莫家兴卡里打一百万供他挥霍。艾图图被牧奴娇叫住后进言：合租正好弄清莫凡当初用什么方法逃出坤之林、他单杀鳞皮母妖身上藏着什么秘密，还搬出萧院长说他前途不可限量、可趁机招揽入缺乏人才的牧家，牧奴娇本坚决反对，因好奇与招揽的可能而动摇，勉为其难答应，只提醒他与赵家的人走得近要小心。莫凡一口气付清下半学期房租，躺进一楼大厅的软沙发享受。随后两名长相清秀的男生殷勤地扛着比人还大的白兔娃娃上门，艾图图打发他们走时，戴眼镜的儒雅男子当面撕下人畜无害的面孔，呵斥躺在沙发上的莫凡滚出这屋，奶油男生也骂他做白日梦，莫凡起身声明自己住在这里，双方剑拔弩张，艾图图却跑到旁边抓起一包零食边吃边看，连劝都不劝。

**关键事件**：1.艾图图层层进言，说动牧奴娇勉强同意合租 2.莫凡付清房租入住，盘算接心夏、给老爹打一百万 3.两名备胎送娃娃后撕脸呵斥莫凡，双方剑拔弩张，艾图图看戏不劝

**逐章写法公式**：

- **情绪流向**：起：轻松（选房合租落定）→ 承：好奇（艾图图劝进的秘密线）→ 转：紧张（备胎撕脸对峙）→ 合：搞笑（艾图图抓零食看戏）
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：合租落定（立生活框架）+ 艾图图进言（立窥秘暗线）+ 莫凡付租享受（立翻身爽点）+ 备胎对峙（留冲突钩子）
- **本章核心技巧**：用双视角信息差推进合租局：女主方密谋套秘密，男主方毫不知情只顾享乐，读者全知等待碰撞。
- **卡点与伏笔**：结尾卡点：冲突悬置（备胎与莫凡剑拔弩张，动手一触即发）；埋设/回收伏笔：莫凡单杀鳞皮母妖的传闻 → 牧奴娇窥秘动机；萧院长的赏识 → 牧家招揽线；与赵家走得近的提醒 → 赵家线暗记；两个撕脸的备胎 → 后续报复冲突。
