# 第1138章 一念万钧，群链

**概要**：莫凡以四十九颗战将级精魄将雷系星子全数强化，中阶雷系可无限释放，遂让焦头烂额的牧奴娇等人退入山障迷阵休息，独自面对五名埃及人召唤的亡灵军团。亡灵如海啸吞没小岛半边，观众与奈夫鲁皆以为莫凡狂妄送死，队友也腿脚发颤。莫凡却因古都百万亡灵围城历练而兴奋，晴空一指释放霹雳电链，中阶魔法一念而成，先锋未至已如麦子倒下。奈夫鲁笑其被围，莫凡却引近千亡灵逼近、触发叠加的荒雷印记，启动暴君制裁，万雷破空将近千亡灵一举肃清，立雷区如雷电君王，第五级霹雳与暴君制裁结合仅耗苍雷爪十分之一魔能。

- **情绪流向**：起：换人承压 → 承：军团压境 → 转：一念电链 → 合：暴君制裁清场
- **节奏配比**：慢铺垫 15% / 快冲突 40% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：强化退队（铺排） + 军团压境（加压） + 一念电链（展技） + 暴君制裁（爆发）
