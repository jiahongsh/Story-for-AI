# 第83章 决斗还没完！

**概要**：朱校长出面打圆场，说两位年轻俊才都表现无比出色、就此结束，请穆卓云把年轻人的狂言付之一笑；穆宁雪也将眸子落在父亲脸上盼他作罢，深知若非魔具优势宇昂基本要输，这样赢并不光彩。穆卓云冷哼拒绝，坚持什么人都敢指着他鼻子骂、以后没法在博城混，赢就是赢、当初说了就该履行。席位上老园丁向莫家兴揭开赌约：宇昂输了穆卓云要亲自给父子俩道歉当年的事，莫凡输了就要磕头道歉到满意为止——莫家兴此前根本不知道有此事。他匆匆跑向主座替子求情被穆卓云坚决回绝，情急之下提出子不教父之过，当着众人跪下要代子磕头；想到儿子是为给这个家找回颜面才立下赌约、磕头会给天才儿子留一辈子阴影，而对自己这个老司机不痛不痒，一咬牙真磕了下去。决斗场上的莫凡目睹这一幕顿时心如中箭，内心质问高高在上者始终高高在上、这社会是否人人平等；他让父亲起来，又留下决斗还没完一话，眼里满是冰冷与愤怒，莫家兴与穆卓云都没听懂他说的回礼是什么意思。

**关键事件**：1.穆卓云拒绝朱校长与穆宁雪的求情坚持赌约 2.莫家兴得知赌约后当众跪下代子磕头 3.莫凡目睹父跪心如刀绞，宣称决斗还没完

**逐章写法公式**：

- **情绪流向**：起：紧张（校长求情被拒）→ 承：压抑（赌约真相揭开）→ 转：悲伤（父亲当众下跪磕头）→ 合：热血（决斗还没完的宣告）
- **节奏配比**：慢铺垫 35% / 快冲突 35% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：两度求情被拒（断退路）+ 园丁揭赌约（揭开最痛赌注）+ 父亲代跪磕头（痛到谷底）+ 决斗还没完（绝地立誓）
- **本章核心技巧**：让不知情的至亲替主角承受当众羞辱，用亲情之痛替代主角之痛，把翻盘怒火烧到最旺再收章。
- **卡点与伏笔**：结尾卡点：宣言悬念型——决斗还没完、回礼一词无人听懂，等下章掀底牌；埋设/回收伏笔：赌约全文揭晓 → 坐实磕头危机；莫家兴在邀请名单（前章埋）→ 兑现为当众受辱；穆宁雪盼父亲作罢 → 她观战的立场持续铺垫。
