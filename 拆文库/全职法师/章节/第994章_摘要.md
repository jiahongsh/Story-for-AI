# 第994章 惊涛之爪

**概要**：鲍比吓得失神驾船远逃，乌海伪龙翻起七八米海浪欲拍碎快船。莫凡唤穆宁雪靠近，穆宁雪被伪龙带黑电的龙须吐息击中，以冰盾护身，伪龙因忌惮下方雷区聪明停手。莫凡以劫炎玫炎化火蛟龙轰击，被水华天幕化解，再施天焰葬礼火海逼迫伪龙不敢下海。小炎姬兴奋，莫凡化飞翼陨拳砸退伪龙上百米、鳞甲溃烂。穆宁雪万箭天冰附冻结令鳞甲冰脆，莫凡重力压缩困其行动；穆宁雪冰之领域、莫凡司夜统治双重控制。伪龙怒吼以深蓝破坏光圈挣脱所有枷锁，连吐水柱将二人击飞，扬爪化惊涛之爪拍落，莫凡穆宁雪躲避不及被拍断骨、浑身瘫软。

**关键事件**：1.莫凡穆宁雪陆面合击伪龙 2.双重领域控制被伪龙破坏光圈挣脱 3.惊涛之爪拍飞二人致重伤

**逐章写法公式**：

- **情绪流向**：起：伪龙浪袭的危机 → 承：双系合击占优的铺垫 → 转：领域控制的高潮 → 合：被拍飞重伤的落差
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：火海逼龙（压制） + 双领域控场（高潮） + 破坏光圈挣脱（反转） + 惊涛之爪拍飞（落败）
- **本章核心技巧**：先堆双重控制占优再一击反扑，用落差保住强敌压迫感
- **卡点与伏笔**：结尾卡点：类型冲突+重伤后如何翻盘引下章；埋设/回收伏笔：小炎姬兴奋→后续参战伏笔
