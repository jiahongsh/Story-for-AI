# 第30章 脑子进水了？

**概要**：穆卓云当着所有人的面宣布，家族前阵子得到的火系修炼资源将给天赋不错的莫凡，让他往后随长子穆江铭一起修行；他自认这对连穆氏子弟都不算的莫凡是一跃龙门、给足了面子。穆贺急忙替侄子穆白争辩称其天赋更好只是紧张，志在族内核心名额的穆白如遭鞭尸。薛木生催莫凡谢恩，张小侯、陆小斌、许青林羡慕不已，莫凡却愣了半晌，开口便问"你脑子进水了吧"，还怕对方没听清又一字一句重复，全场石化。随后他当面痛骂：莫凡不是被打一巴掌再给点甜头就忠心的傻子，三年前穆卓云把他和父亲当狗看的话他记得清清楚楚，别说现在拉他进家族，就算把穆宁雪连人带嫁妆打包送到面前求他，他也不稀罕。校长、校董、穆贺、穆白、薛木生、八班学生以及穆宁雪本人全部傻了，穆卓云怒意实化，脚下豁然冻出坚固晶冰，短短几秒整个操场沙地冻成镜面般的冰晶之地，酷夏骤变凛冬，全校学生惊叫——他连魔法都没释放，仅凭气息便冻住一切。猎者联盟校董邓凯站出来挡在两人之间，提醒他这里是学校还有很多没有防御能力的学生，唐月也止步戒备，不允许穆卓云伤害自己的学生。

**关键事件**：1.穆卓云当众许诺资源招揽莫凡 2.莫凡骂"脑子进水"拒招揽并揭三年旧怨 3.穆卓云怒气冻结操场、邓凯唐月护场

**逐章写法公式**：

- **情绪流向**：起：招揽施恩的体面 → 承：众人羡慕层层加码 → 转："脑子进水"惊全场、痛骂宣泄 → 合：冰封操场的威压与邓凯唐月护场
- **节奏配比**：慢铺垫 40% / 快冲突 30% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：当众施恩（造落差）+ 群像羡慕（抬价）+ 当场掀桌（爆发）+ 威压压场（转危局）
- **本章核心技巧**：先让权力的施舍显得无比贵重，再让主角一文不值地当场摔碎，用"拒绝的代价"反衬主角骨气。
- **卡点与伏笔**：结尾卡点：危机型，穆卓云动怒，莫凡安危悬于一线；埋设/回收伏笔：三年前旧怨 → 长线背景在此首次细节化；"打包穆宁雪"宣言 → 全书感情线梗。
