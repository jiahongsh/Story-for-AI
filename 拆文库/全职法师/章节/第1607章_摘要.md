# 第1607章 谁在吃人？（上）

**概要**：开罗战城进入战争第四阶段，沙土战城已被摧毁大半、魔法师疲惫不堪，海夫拉的第一波攻势却雷声大雨点小，两天两夜大战后被击退，战地反而收复数个防御堡垒。大军首哈肯归功于中国亡灵帝国给冥界施加的压力，而前任总指挥伊森气恼不已——他本料定第四阶段撑不下去、让哈肯接手背黑锅，谁知战局转好，自己错失成为开罗军神的机会，还被街头民众踩到泥里。伊森乘黑车进城，命凯文召来被他贬去维持城内次序的萨斯，自己则到开罗酒店天台泳池会见泳池里的小美人——她正是阿帕丝。伊森献殷勤讨好，提议让她召蛇蝎军团击垮哈肯军部、制造变局助他上位再演大胜之戏，阿帕丝却冷然拒绝，直言演戏只会让双方尸骨无存，并宣布合作到此为止。契约的精神刺激传来，阿帕丝愤然上楼——她已是莫凡的契约兽，得伺候莫凡端果汁、被他调戏跳舞脱衣，面对"你在美杜莎里算什么级别、为何能长得像人类"的追问，她小下巴微仰，傲然不语。

**关键事件**：1.第四阶段战争意外被轻松击退，哈肯威信大涨 2.伊森密谋阿帕丝以蛇蝎军团助自己上位被拒、合作破裂 3.阿帕丝因契约被莫凡召唤，从盟友转身为伺候他的契约宠

**逐章写法公式**：

- **情绪流向**：起：战场捷报的振奋 → 承：伊森失势的怨毒 → 转：天台密谋被拒的反转 → 合：契约主仆逗趣的余味
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 30% / 悬念留白 20%
- **本章结构公式**：战场转机（立背景）+ 伊森失意（立动机）+ 天台密谋（揭合作真相+决裂）+ 契约日常（收束新关系）
- **本章核心技巧**：用同一角色在不同场景的双重身份制造反差喜感，同时推进阴谋线与契约线
- **卡点与伏笔**：结尾卡点：悬念+阿帕丝身份等级之谜未答，她与伊森的旧谋如何清算；埋设/回收伏笔：伊森靠阿帕丝屡胜蛇蝎大军 → 其把柄与末日伏笔；国际军事法庭指控 → 伊森倒台线索
