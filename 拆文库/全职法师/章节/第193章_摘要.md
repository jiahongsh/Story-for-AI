# 第193章 激战鳞皮妖母

**概要**：体育馆空中舞台上，鳞皮妖母正要对偶像少女下口，莫凡从舞台角落阴影中现身，妖母认出他就是杀死自己配偶的猎人，仇人见面分外眼红。妖母长鞭般的舌头一击将镰骨盾拍成粉末，余力抽得莫凡后背出现深深淤痕，莫凡据此判断它实力恐怕已达战将级。莫凡以遁影·穿梭没入阴影脱身到偶像少女身边，请她让灯光师把舞台灯打成光影交错，随后跃上护栏抛出火滋·焚骨持续焚烧妖母、靠不断补火激怒诱敌，想把它引到对自己有利的地形。但焚骨火焰烧不穿妖母的表皮鳞片，狭窄舞台上又非处处有影可借，莫凡只能跳下舞台转移，妖母早预判此招，蹬栏加速在半空追及，厉爪伸出要将他撕成肉片。

**关键事件**：1.莫凡现身救偶像少女，镰骨盾被妖母长舌一击粉碎、后背受创 2.莫凡判断妖母已达战将级，以遁影与焚骨火焰诱敌周旋 3.莫凡跳台转移被妖母半空扑击，命悬一线

**逐章写法公式**：

- **情绪流向**：起：紧张（妖母欲害少女、莫凡现身）→ 承：压抑（镰骨盾被秒碎、背伤、战将级判断）→ 转：热血（遁影走位加焚骨诱敌）→ 合：紧张（跳台遭半空扑杀卡点）
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：阴影现身对峙（立仇怨）+ 防具被毁（立强度差）+ 遁影与焚骨诱敌（立战术）+ 跳台遭空中扑杀（卡点收章）
- **本章核心技巧**：用旧依仗被一击粉碎瞬间抬高敌人强度，再借技能漏洞说明收紧主角的生存空间。
- **卡点与伏笔**：结尾卡点：生死悬置（厉爪将对半空的莫凡开膛，下章看如何脱身）；埋设/回收伏笔：光影交错的舞台灯请求 → 为遁影战术续章铺垫；妖母记得莫凡杀其配偶 → 仇怨动机线。
