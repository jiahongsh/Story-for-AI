# 第591章 亡灵，无穷无尽

**概要**：十字疤男的风盘天罗卷碎二十多只腐尸，但四人刚前进不远，前方、左侧和后方又出现新的尸队。莫凡判断腐尸会像潮水一样封死他们与大部队之间的道路，主动让众人靠近并施展第四级烈拳九宫，一次消灭五十多只腐尸。小炎姬和余青素继续用火焰、雷云阻挡追兵，矮男终于看到大部队。周敏等人组织掩护，召唤师放出血纹兽接应，妖男确认四人用二十分钟杀出一公里亡灵血路。

**关键事件**：1.风盘天罗暂时清理尸群 2.莫凡以烈拳九宫解除三面包围 3.大部队掩护四人完成会合

**逐章写法公式**：

- **情绪流向**：起：暂时突围 → 承：尸潮再次包围 → 转：烈拳九宫清场 → 合：大部队接应并确认突围成功
- **节奏配比**：慢铺垫 5% / 快冲突 55% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：风盘清场（争取距离） + 三面再围（扩大危机） + 烈拳九宫（大范围解决） + 火雷接力（抵达会合点）
- **本章核心技巧**：反复刷新包围范围，再用一次高强度技能制造明显战力差，最后以援军接力完成收束。
- **卡点与伏笔**：结尾卡点：四人归队但亡灵大军仍持续涌来；埋设/回收伏笔：残魄约80个可凝炼一个精魄 → 本章战斗收益线。
