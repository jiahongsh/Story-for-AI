# 第1368章 斩冥君蛙

**概要**：冥君蛙夺命之舌卷来，角度与卷力足以一口吞下八九十个精英法师。赵满延挺身冲至最前，以"霸下之印-天淬岩-岩魔之瞳-巨人之身"连招唤起一尊蓝褐色岩石巨像，张开双臂将所有军士护在身后，冥君蛙的君主级攻击打在巨像上虽令其碎裂、令赵满延口吐鲜血，却没让一丝力量席卷到队伍——高阶法师硬挡君主级全力一击，震住全场。借这个空档，军法师撤至安全距离，符印纤夫被连杀十几只，数百纤夫随之瓦解，士气大振。召唤高手叶鸿驾驭闪剑鸟赶到，以巨影钉束缚、雷电之剑破防，将符印纤夫抛回军阵轰杀，并凭借铁血的指挥预判冥君蛙吞地之势，提前全员后撤，救下三个大队。随后"一鼓作气"，三百多只纤夫尽数斩尽，战场上只剩孤零零的冥君蛙被军团包围。彬蔚与叶鸿互让帅位，彬蔚把斩蛙指挥交给叶鸿，前任总指挥虽未入超阶，却立誓斩下这头君主。

**关键事件**：1.赵满延以巨人之身硬挡冥君蛙君主级攻击，护住全队 2.叶鸿驾闪剑鸟参战，雷系破防绞杀符印纤夫 3.叶鸿预判冥君蛙吞地之势提前后撤，救下三个大队 4.冥界纤夫尽数歼灭，只剩冥君蛙被包围

**逐章写法公式**：

- **情绪流向**：起：绝命舌卷的窒息 → 承：巨像硬挡的爆燃 → 转：叶鸿指挥的惊叹 → 合：主帅交接的豪迈
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：巨像挡君（立爆点）+ 借隙剿符（乘胜势）+ 叶鸿救阵（引强援）+ 尽歼交帅（收战局）
- **本章核心技巧**：让防守者先挡出全场高光，再让指挥官用一道反常识军令点出"真正的强"，一武一谋双爆点交替
- **卡点与伏笔**：结尾卡点：决战式——冥君蛙孤立无援，斩蛙指挥权交予叶鸿；埋设/回收伏笔：叶鸿跨超阶的桎梏与彬蔚的古长城奥义 → 后续战场角色分工
