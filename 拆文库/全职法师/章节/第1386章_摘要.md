# 第1386章 岩霸锤！

**概要**：棱角分明的岩之角斗场如小型岩山从天而降，紫鬼退无可退，被重重岩层罩成一座高隆的坟墓，赵满延就在其中直勾勾盯着他。紫鬼身上还沾着毒血无法隐化，见对方不是超阶法师便讥笑贬低，暗地却隔空在赵满延身后凝出冰之剑针偷袭，被岩铠挡下，剑阵破不了这件石铠防御。赵满延在角斗场内土系威力提升，重岩破追逐紫鬼将其逼到角落，紫鬼以水华天幕挡住土之精灵，赵满延立刻光落曼丈摧毁他的铠魔具，又借翼魔具化作石人将他撞飞，再唤十米光之狂刀抡砍。紫鬼终于亮出隐藏的第三系——空间系，以"隔空碎心"透过厚实防御直取内脏，赵满延祭出威尼斯之戒护住内脏，反手唤出岩霸锤，万吨之力砸向地面，碾碎风暴追着紫鬼炸开，紫鬼以水御勉强抵挡，全身骨头碎裂、口鼻耳一齐喷血。紫鬼见无胜算索性不逃，嘲讽盛典已到、冥界大军将踏平城市；赵满延踩扁其腿骨，逼得紫鬼痛不欲生，却仍强撑吐出关键一句：他手下有隐藏者，契约并不在他身上。赵满延皱眉，继续用近千斤的石铠拳头砸向紫鬼。

**关键事件**：1.岩之角斗场将紫鬼与赵满延困于一体，毒血缠身的紫鬼无法隐化 2.紫鬼冰之剑阵与空间系"隔空碎心"均被赵满延防御化解 3.赵满延岩霸锤万吨之力重创紫鬼，其全身骨头碎裂喷血 4.紫鬼嘲讽盛典已到、透露手下有隐藏者、契约不在他身上 5.赵满延踩扁紫鬼腿骨，继续挥拳砸杀

**逐章写法公式**：

- **情绪流向**：起：角斗场落定的决绝 → 承：紫鬼连招被破的压制爽感 → 转：空间系底牌反扑的惊险 → 合：紫鬼吐露隐藏者情报的悬念
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：角斗场困敌（锁死战场）+ 技能对撞全面压制（碾压过程）+ 空间系底牌被防（反转应对）+ 垂死吐情报（埋钩收尾）
- **本章核心技巧**：在一对一死斗里用"对手底牌逐层翻出、逐层被克"推进节奏，最后让败者濒死吐真言，把战斗胜利转化成情报悬念
- **卡点与伏笔**：结尾卡点：紫鬼透露"手下有隐藏者、契约不在我身上"后被赵满延追杀，莫凡能否照常释放恶魔；埋设/回收伏笔：契约不在紫鬼身上→直接推翻莫凡赵满延原计划的前提，重塑主线目标
