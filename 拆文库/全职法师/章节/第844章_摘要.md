# 第844章 我也退队

**概要**：官鱼挂断电话转身撞见身后的穆宁雪，顿时手足无措，穆宁雪平静表示他误会了自己的意思，自己不需要任何人的帮助，对官鱼的提亲更无半点兴趣，只是听到电话里那些刺耳的话脸色更难看了。官鱼仍说等威尼斯决战打出荣耀后会帮她向所有人澄清，让她先回国忍耐，穆宁雪却重重地说"我会回来，一定会"，这句话是说给自己听的，她要亲自洗清家族背负的骂名。午后冷雨，导师们傍晚离队，莫凡忽然跑来喊自己也回去，当众宣布退出国府之队，要去国馆陪穆宁雪，气得封离暴怒，莫凡却说先退出再杀回来，国馆表现好照样能晋升，赵满延急得要跪求他道歉，莫凡收拾好东西跟松鹤挽肩道别，封离骂他滚并让他顺带买机票、解禁身份。

**关键事件**：1.穆宁雪明确拒绝官鱼，立志自己澄清家族骂名 2.莫凡当众宣布退出国府之队陪穆宁雪去国馆 3.封离暴怒，莫凡以"先退再杀回"回应 4.莫凡收拾东西道别，封离让他捎带买机票解禁

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|

**逐章写法公式**：

- **情绪流向**：起：穆宁雪冷拒官鱼 → 承：冷雨送别导师 → 转：莫凡突喊退队引爆全场 → 合：莫凡洒脱道别，封离被迫捎人
- **节奏配比**：慢铺垫 35% / 快冲突 40% / 爽点爆发 15% / 悬念留白 10%
- **本章结构公式**：穆宁雪立志（立骨） + 导师离队（铺垫） + 莫凡退队（爆发） + 封离妥协（钩子）
- **本章核心技巧**：用群体震惊的反应层把主角的惊人决定重量放大，再以"退而再回"的注解化解悲壮
- **卡点与伏笔**：结尾卡点：莫凡退队要随穆宁雪去国馆，下章期待国馆如何接纳；埋设/回收伏笔：国馆可晋升机制 → 后续守馆人路线的伏笔
