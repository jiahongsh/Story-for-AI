# 第1280章 队伍分歧

**概要**：莫凡本想追去救郭木壮，但顾虑灵灵、晨颖、钟蜜、胡朵几个女孩子只能交给中看不中用的陈彬彬和实力不明的汪华保护，只好留守。另一头，赵满延借掉队之机把涉世未深的关溪溪引到林溪边大献殷勤，正要得逞时，一条穿着裤鞋的断腿砸在树干上，草丛里爬出下半截身子没了、满嘴血的郭木壮，身后还跟着一头啃着人腿的血腥山人。赵满延用光盾护住郭木壮，又以岩魔之瞳石盔困住山人，让关溪溪用续骨瓶封住伤口，把郭木壮背回队伍。众人问起瘦男，赵满延才知道还有一人，只救回伤势紧急的郭木壮。莫凡让赵满延留守女眷，自己带晨颖回头寻人，汪华不敢跟去还冷嘲热讽，被钟蜜当面指责。队伍就郭木壮的去留爆发分歧：赵满延主张去找别的猎人队伍求治愈法师，陈彬彬、汪华、胡朵坚持留守等长老，两派互不相让。

**关键事件**：1.赵满延救下半截身子的郭木壮 2.莫凡晨颖前去寻找瘦男 3.队伍为救人还是留守爆发分歧

**逐章写法公式**：

- **情绪流向**：起：两难（救人不救人） → 承：惊变（断腿与郭木壮） → 转：施救（光盾石盔） → 合：分裂（去留之争）
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：两难权衡（莫凡留守）+ 救人遇袭（赵满延线）+ 生死急救（续骨瓶）+ 路线分歧（队伍撕裂）
- **本章核心技巧**：双线并行，一暗一明——赵满延线负责惊悚与爽快，莫凡线负责决断与压抑，汇合后集中引爆分歧
- **卡点与伏笔**：结尾卡点：选择分歧型，队伍一分为二、郭木壮性命垂危，下章期待两条线各自遭遇；埋设/回收伏笔：山人分割战术→草海大狩猎场；关溪溪对赵满延的好感→后文羁绊
