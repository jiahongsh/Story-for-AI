# 第833章 落井下石

**概要**：千片火羽爆破火光冲天，烈焰中蓝谷凶离兽鳞甲失效、翻滚寻潮水，一头撞进融化的冰面没入十米海水，身躯收缩后踪影难觅。广濑心有余悸问是否逃了，穆宁雪断定它只是受伤取水灭火必会再出。果然莫凡所立冰面突现血芒，厚冰被整齐切开，无备的他被虚空妖斩侧腰划出深痕，幸有玄蛇铠甲才免拦腰断。莫凡捂伤退开，疼得呼吸都扯动腰侧，穆宁雪郑重催促趁其不敢明追赶紧回二十街区送解毒素救南荣倪。归途莫凡两处伤重、脸色发白，还严肃问"肾在左还是右"，被穆宁雪忍无可忍喝止；他勉强接受夜罗刹口水糊伤口止血，一路祈祷别伤到肾。返抵二十街区，水面漂满锯齿绿妖尸体，数目倍于想象，幸有望月千熏这高阶法师坐镇。南珏等人见二人染红归来又喜又忧，夜罗刹将解毒素交蒋少絮涂于南荣倪溃烂腿伤，南荣倪已昏死苍白。穆婷颖冷嘲"再迟些便如愿"，激得夜罗刹挠其脖，南珏责其毒舌。蒋少絮推了推一直沉默的莫凡，见他脸色煞白惊得捂嘴。

**关键事件**：1.蓝谷入水灭火、虚空斩伤莫凡 2.催归救南荣倪、莫凡伤重搞笑问肾 3.返程秒妖、二十街区绿妖尸遍地、解毒素涂南荣倪 4.穆婷颖讽、夜罗刹挠脖、莫凡煞白

- **节奏配比**：慢铺垫 15% / 快冲突 30% / 爽点爆发 15% / 悬念留白 40%

- **卡点与伏笔**：结尾卡点：莫凡脸色煞白、南荣倪解毒未明，下章期待二者安危；埋设/回收伏笔：解毒素 → 涂南荣倪伤口，回收"须原妖肉瘤解毒"全章主线。
