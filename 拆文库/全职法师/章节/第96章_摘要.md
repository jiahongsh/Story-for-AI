# 第96章 先锋小队

**概要**：薛木生大喊全体跟他走、风系到前面探路，楼道里各班学生疯狂拥挤尖叫，局面彻底失控；莫凡冷眼旁观，把这种恐惧传染比作受惊的麋鹿群与踩踏事件。许昭霆怒然出手，雷印·狂策的紫色电弧疯狂鞭打篮球场上的独眼魔狼，王三胖用地波之术把它撞上篮球架，周敏火滋·焚骨准确命中，实践课老师们再补上数道魔法，合力将魔狼轰成焦黑尸体。薛木生随即召集许昭霆、赵坤三、穆白、周敏等表现镇定的学生，提出组建一支大部分由学生组成、走在大部队最前面的先锋小队，为全校近两千人开路，由他带队、自愿参加；周敏率先加入，许昭霆、王三胖、穆白、赵坤三与一名土系男生相继跟上。张小侯问莫凡去留，莫凡决定加入，并私下点破：大部队恐惧互相传染、战力有限，一百只妖魔足以令其全军覆没，跟大部队更危险。

**关键事件**：1.许昭霆等学生合力击杀闯入的独眼魔狼 2.薛木生组建学生先锋小队 3.莫凡加入并点破大部队更危险

**逐章写法公式**：

- **情绪流向**：起：慌乱崩溃 → 承：合力斩狼 → 转：点将授命 → 合：理性入伙
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：楼道失控（危机日常）+ 三连技杀狼（群像爽点）+ 先锋小队召集（任务发布）+ 莫凡入伙与冷眼剖析（主角定调）
- **本章核心技巧**：用一场三接力的团战给配角发糖，再借"自愿高危任务"的招募完成主角的理性人设反打
- **卡点与伏笔**：结尾卡点：先锋小队成型在即、开拔在即，前路妖魔未明；埋设/回收伏笔：先锋小队为全校两千人开路（撤离行动主线）、莫凡怀藏地圣泉蓝瓶（随身炸弹未爆）、后山五十多只独眼魔狼（下一章接战）
