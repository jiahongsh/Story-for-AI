# 第1636章 鹅雪银羽

**概要**：凌霜落下的几秒钟内，巴巴罗被冻成冰块失去生命气息，园林法师看傻了眼、游客满脸惊恐，无人敢拦，巴沙缪笑着转身登上更高处。他停步等人接头，一名帽檐遮脸的阴冷男子现身，巴沙缪将装着达到"泰坦之心"程度药物的铁木盒子交给他，帽檐男子警觉到有人跟踪，隐匿在树后观望。莫凡与穆宁雪走出林子直逼而来，巴沙缪先误认他们是魔法协会来追究凡尔登暮花，又看中穆宁雪的绝色姿容；莫凡连番质问确认他就是歹郎公会银饰会会主巴沙缪，并追问收集幼童之心喂海妖之事，巴沙缪得意承认。莫凡确认找对人后三魂火暴起，一记上勾拳轰出烈焰蛟龙，又召来暴君闪电地毯式轰炸；巴沙缪以冰封铠甲、魔具石岩和凌霜领域反压，逼退莫凡，并看出他不过是高阶法师、满脸不屑。穆宁雪随即释放磐冰领域，鹅毛雪羽与凌霜两个领域如两支雪的军团在林间厮杀，胜负未分。

**关键事件**：1.巴沙缪冻杀巴巴罗并与帽檐男子接头交货 2.莫凡穆宁雪现身确认巴沙缪身份并暴起出手 3.巴沙缪以凌霜领域压制莫凡，穆宁雪释放磐冰领域迎战

**逐章写法公式**：

- **情绪流向**：起：惊惧(少年冻毙无人敢救) → 承：暗流(接头交货被人追踪) → 转：暴怒(莫凡确认身份怒轰) → 合：对峙(双冰领域厮杀)
- **节奏配比**：慢铺垫 25% / 快冲突 50% / 爽点爆发 15% / 悬念留白 10%
- **本章结构公式**：接头的暗线(推进案件) + 身份确认(点燃冲突) + 火雷暴袭(主角攻势) + 领域反压(反派立威)
- **本章核心技巧**：用"主角全力输出+反派轻描淡写接下"的反差，一次战斗完成敌人立威与主角受挫的双重叙事
- **卡点与伏笔**：结尾卡点：战局卡点，双冰领域厮杀未分胜负，莫凡已被压制，下章期待穆宁雪的领域能否扭转局面；埋设/回收伏笔：幼童之心喂海妖的罪行 → 对应莫凡追查此案的动机；帽檐男子及追踪链条 → 背后更大的组织与"某人"
