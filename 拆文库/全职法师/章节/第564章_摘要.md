# 第564章 大显神威

**概要**：风盘秒杀四只鬼尸，苏小洛与村民惊觉失忆的福大竟是无师自通的中阶风系法师；张小侯再施风盘-天罗，以风之壁障笼住十几名村民，扑上的亡灵尽数撞成碎片，谢桑苦战许久的亡灵远不如他两个魔法来得干净。谢桑喝令村民躲入井窖避难，尸体来不及处理。雨势稍缓时，村口出现头戴竹斗笠的蓑衣男子，身旁腐尸如仆人般跟随，他自语竟然还有别的法师，把村民尸体赏给腐尸，狂笑着问躲入井窖有用吗，随后隐入雨幕。镜头转回：雨停后莫凡一行启程，矮男警告华村附近有煞渊，莫凡以要么退钱要么上路逼行；壮男方幼苗自述是羊阳村人，叔叔前年起不许他回村，如今村子没了，誓要查清家人失踪原因。众人抵达华村，却发现华村人也失踪了。

**关键事件**：1.张小侯风盘天罗护村肃清亡灵 2.蓑衣男子现身点出张小侯法师身份 3.莫凡一行抵达华村发现空村

**逐章写法公式**：

- **情绪流向**：起：风盘天罗肃清亡灵 → 承：蓑衣男子现身布谜 → 转：莫凡线启程争执 → 合：华村空村悬念
- **节奏配比**：慢铺垫 15% / 快冲突 25% / 爽点爆发 20% / 悬念留白 40%
- **本章结构公式**：风盘天罗护村（支线高潮）+ 蓑衣男子现身（幕后钩子）+ 莫凡线启程（主线回归）+ 华村空村（悬念汇合）
- **本章核心技巧**：支线高潮后立刻用神秘反派钩子切断，再切主线让两条线在空村悬念上汇合。
- **卡点与伏笔**：结尾卡点：华村人全部失踪；埋设/回收伏笔：蓑衣男子与变种亡灵 → 幕后黑手；方幼苗羊阳村身世 → 村灭真相；煞渊警告 → 后续险途
