# 第41章 风轨，飞崖！

**概要**：悬赏公布十天后，莫凡所在的三组20名学生斩荆披棘穿过大山丛林，苦不堪言；历练没有老师带队、没有教官跟随，只发一张地图让学生自己寻找百草谷。挡在终点前的是一条约10米宽的山崖河谷，湍急河水撞礁咆哮，看得人心惊胆颤。张树华提议打道回府指望别的组完成，被周敏斥没骨气；许昭霆等人力劝风系的张英璐绑绳跳到对岸捆绳索，她吓得小脸煞白死活不肯。莫凡转向班里不起眼的张小侯，一句"猴子，敢吗"点燃后者：张小侯捆上绳索，意念化狂风为隐形风之轨迹，喝出风轨加疾行沿轨迹助跑，一脚踩碎崖边岩石跃起，在两崖之间划出弧线，惊险落在对岸最边缘连滚撞树，模样滑稽却赢得全组敬意——20人中风系有4个左右，敢跳的只有他一个。许昭霆率先攀绳，19人全部过崖，抵达百草谷，完成历练第一大考验。

**关键事件**：1.三组学生无师长跟随，持地图跋涉十天被河谷拦路 2.风系尖子张英璐不敢跳，不起眼的张小侯自告奋勇施展风轨疾行飞跃河谷 3.全组攀绳过崖抵达百草谷

**逐章写法公式**：

- **情绪流向**：起：十天跋涉的疲惫抱怨 → 承：河谷拦路与逼跳僵局的焦灼 → 转：张小侯飞跃的燃 → 合：全组过崖的轻松与抵达
- **节奏配比**：慢铺垫 40% / 快冲突 25% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：跋涉抱怨（铺苦境）+ 河谷僵局（立障碍）+ 张小侯请缨（反转人选）+ 风轨飞崖（燃点释放）
- **本章核心技巧**：把团队关卡写成群像筛选，让被低估的配角在主角一句激将下完成高光
- **卡点与伏笔**：结尾卡点：抵达型——终于抵达百草谷，下章期待谷中考验；埋设伏笔：张小侯的胆量被暗中记分 → 后文高分回报
