# 第652章 杀出一条道！

**概要**：凌溪的屠风斩清出道路后，韩寂命令两翼法师团跟随方阵全速推进。队伍前进近一公里时，原本被自愿者吸引的腐尸军团转向主力，山峰之尸以心灵力量号令群尸发动进攻。尸毒风暴先一步覆盖战场，内城留守者一度以为突围队已经覆灭。随后光系法师在毒雾中驱散尸毒，金色与乳白色光芒重新显现，法师军团开始反击。消息传回内城，避难者高喊“法师万岁”，把这支军团视为人类文明不屈的信仰。

**关键事件**：1.两翼法师团加入推进 2.腐尸军团转向主力 3.山峰之尸号令群尸 4.尸毒风暴覆盖战场 5.光系法师驱散毒雾 6.内城重新燃起希望

**逐章写法公式**：

- **情绪流向**：起：屠风斩后的推进 → 承：尸群和毒雾压境 → 转：光阵驱散毒雾 → 合：民众欢呼，法师军团继续前进
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：两翼支援（扩大推进） + 尸群转向（改变战局） + 尸毒遮蔽（制造假败局） + 光阵反击（恢复希望）
- **本章核心技巧**：先让整支队伍在视觉上消失，再用光系法术从黑暗中重新“显影”，完成大幅情绪反弹。
- **卡点与伏笔**：结尾卡点：法师军团冲破尸毒风暴并继续向煞渊前进；埋设/回收伏笔：自愿者吸引尸群 → 尸群在高智慧号令下转向真正主力。
