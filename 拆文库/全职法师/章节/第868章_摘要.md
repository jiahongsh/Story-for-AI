# 第868章 草场别墅

**概要**：莫凡、穆宁雪、灵灵以"情侣带妹妹游玩"的假身份登岛，盘查警官被灵灵装出的天真可爱彻底骗过，还顺带得知崇明岛多镇保留原生态牧场。过检后灵灵立刻恢复老成模样，莫凡与穆宁雪都叹她不拿奥斯卡可惜。巴士上灵灵用迷你电脑排查全岛贸易公司，排除大半后锁定六家挂豪门私有旗号、最易作假掩人耳目的嫌疑目标，最近的是晚风镇金枪鱼贸易。众人抵达模范镇晚风镇，穆宁雪与灵灵换上姐妹装回头率爆棚，莫凡险些忘记此行是龙潭虎穴。他们以走错路为由逛遍金枪鱼企业厂房，确认其正常无嫌疑，全镇亦无异常。莫凡严肃叮嘱不可让黑教廷先察觉意图，穆宁雪联想到宇昂、穆贺的潜伏教训点头。为不露端倪，灵灵主张假戏真做玩上一整天，夜里开房却是莫凡独睡、两女同屋。次日转往以牧业为主的平邑镇、珍名镇，沿途苏格兰调草地令同车大学生郊游团惊呼，金边眼镜青年与齐刘海女孩遥指草坡上漂亮建筑。

**关键事件**：1.三人假身份登岛盘查，灵灵装可爱骗过警官。 2.灵灵用电脑排查锁定六家嫌疑贸易公司。 3.晚风镇实地排查金枪鱼企业无嫌疑。 4.莫凡叮嘱勿被黑教廷察觉，灵灵主张玩一天假戏真做。 5.转往平邑镇途中展现原生态牧场风光。

**逐章写法公式**：

- **情绪流向**：起：登岛盘查的轻快 → 承：灵灵专业排查的安心 → 转：实地无果的微调压 → 合：转场风景的轻松钩子
- **节奏配比**：慢铺垫 35% / 快冲突 5% / 爽点爆发 10% / 悬念留白 50%
- **本章结构公式**：假身份过检（建立伪装） + 灵灵数据排查（锁定范围） + 晚风镇实地核查（排除干扰） + 转场平邑镇（推进下一 suspect）
- **本章核心技巧**：用"专业排查+生活化伪装"双线推进潜入，把悬疑藏在度假闲笔里，松紧交替控制暴露焦虑
- **卡点与伏笔**：结尾卡点：草坡上漂亮建筑引发好奇，下章期待平邑镇牧场庄园登场；埋设/回收伏笔：六家嫌疑贸易公司 → 后续逐镇排查的清单；宇昂穆贺 → 黑教廷潜伏特性的回扣
