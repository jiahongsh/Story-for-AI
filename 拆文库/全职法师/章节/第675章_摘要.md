# 第675章 死门之灾

**概要**：内城高层讨论带少数人突围的逃亡计划，却承认即使逃出也将死伤惨重，外出救援的独萧、祝蒙等人和疲惫的守城法师仍未归来。死门间内，近万骷髅大军的震踏使狭小空间濒临崩坏，莫凡等四人面对骨海一度无法思考。莫凡命张小侯、柳茹和苏小洛向后寻找出口，自己留下阻挡追兵；张小侯欲回头同战，被柳茹以梦霾催眠后带上疾星狼离开。莫凡明知空间尽头外是风暴、几乎没有生路，仍决定死战争取时间。小炎姬为无力对抗骷髅海哭泣并强行催动火源想要进阶，莫凡安慰她，却知道这种尝试难以立即成功。

**关键事件**：1.内城承认逃亡计划代价惨重。 2.近万骷髅迫近，莫凡命队友先撤。 3.柳茹催眠张小侯并带人离开。 4.莫凡决定留下死战，小炎姬试图强行进阶。

**逐章写法公式**：

- **情绪流向**：起：悲伤 → 承：恐怖 → 转：紧张 → 合：悲伤
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：高层讨论退路（铺陈代价） + 骷髅压境动作（具象化危险） + 主角分派撤离（制造牺牲） + 契约兽求变无果（留下战前钩子）
- **本章核心技巧**：先以群体失策证明危机等级，再把主角的留守决定压缩到无法回避的具体选择中。
- **卡点与伏笔**：结尾卡点：力量悬念，小炎姬强行进阶是否能改变死局；埋设/回收伏笔：空间尽头与空间风暴 → 说明向后撤离也不是可靠出口。
