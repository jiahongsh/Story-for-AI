# 第1150章 不知自己身份

**概要**：莫凡忆起张小侯曾被忘虫所害，唐忠详述黑教廷以忘虫控制重要潜伏人员，使其连自己都不知黑教廷身份，而心夏体内也有忘虫，特定时间撒朗记忆才会复苏、过后被掩埋如常人。唐忠、冷青、唐月三人起初同不信指控、以为是选举之争污蔑，证据揭开后不得不接受：羸弱善良的心夏本人无辜，掩埋的撒朗灵魂才是万恶之源，但圣裁院与帕特农终将罪责定给同躯的心夏。灵灵问莫凡打算，莫凡决意"我要去见她"；唐忠说心夏被禁圣女殿、罪石判决完即正式认定，莫凡不理会铁证只求见到她。莫凡离青天猎所，唐月追上赠其一枚珠子，莫凡接下说若酿成过错自己承担，唐月说决定也是他们的决定。莫凡重入希腊雅典卫城前往帕特农神山，飞花如画中忆心夏说选完就离开；庞莱、韩寂、祝蒙已在神山旁等候多时，表明不能出手抗圣裁、只能在危机时保其性命。庞莱提及等"老神官"消息，莫凡惊知包老头竟是圣裁院老神官、监管十三判官。与此同时帕特农裁决殿内十三判官闭门会，雷纳主张心夏无辜、杜兰克坚称血石不撒谎她是撒朗，黑白罪石将定生死。

**关键事件**：1.唐忠以忘虫解释心夏不知自身撒朗身份 2.莫凡决意见心夏，唐月赠珠明志 3.莫凡重入希腊，庞莱韩寂祝蒙等候并告不能出手 4.莫凡惊知包老头是圣裁院老神官 5.裁决殿十三判官闭门会投罪石，雷纳与杜兰克立场对立

**逐章写法公式**：

- **情绪流向**：起：忘虫揭示的压抑 → 承：莫凡明志的决绝 → 转：盟友赠珠与不能出手的暖冷交织 → 合：神山对峙与罪石悬念
- **节奏配比**：慢铺垫 40% / 快冲突 0% / 爽点爆发 0% / 悬念留白 60%
- **本章结构公式**：唐忠补忘虫机制（解谜） + 莫凡决见心夏（行动） + 唐月赠珠盟友明志（温情） + 神山对峙与闭门会（悬念）
- **本章核心技巧**：用"不能出手只保命"的盟友立场制造孤立感，把外部压力（圣裁、神官）与内部温度（赠珠）并置放大主角独行
- **卡点与伏笔**：结尾卡点：悬念+十三判官黑白罪石将定心夏生死，下章期待莫凡闯山；埋设/回收：包老头=圣裁院老神官（新身份→可干预判官）
