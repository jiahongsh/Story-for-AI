# 第330章 骗局

**概要**：斩空一夜没睡好，反复琢磨洞庭湖怪事是不是恶魔化的莫凡所为——若是则他还活着，可他是否保有心智、为何不停屠杀蜥颅巨妖都无答案。清点人手时他得知张小侯天未亮就带上远行物资离开了军部，部下提醒擅离职守要记大罪，斩空却让部下补一份出任务申明、盖上自己的军统章，称这小子蠢是蠢但也是好苗子，随后安排送密信给比翼军区的师兄秋信，托他处理洞庭湖怪事并顺路把张小侯提回来。张小侯此时已到比翼市，向鞋脸路贩打探魔法卖场和精魄，得知此地紧邻洞庭湖、精魄每天都有新鲜货。他自报手头有卖掉一件魔具凑来的九百万、想买三个精魄，鞋脸贩子自称大金，把他七拐八拐领进一家蒙尘的私人魔法铺。大金与两百斤肥老板合谋，把花二十多万收来的伪精魄按三百万一个卖他，还约定以后把外地傻子多往店里带。张小侯把无密码、不绑身份的钻卡交去验钱后，用意念探入器皿立刻发现精魄不对，要求退卡，肥老板却翻脸不认收了卡，搬出交易规矩抵赖——张小侯这才明白两人是合伙设局骗钱。

**关键事件**：1.斩空为擅离职守的张小侯补盖军统章 2.张小侯携九百万到比翼市买精魄 3.大金与肥老板合谋售卖伪精魄 4.张小侯识破假货，钻卡被扣

**逐章写法公式**：

- **情绪流向**：起：压抑（斩空失眠忧心莫凡）→ 承：温馨（补任务书庇护张小侯）→ 转：搞笑（大金拉客与后堂合谋的嘴脸）→ 合：紧张（识破伪精魄，钻卡被扣）
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：斩空自问与安排（主线悬念保温）+ 张小侯亮出巨款（把猎物身份坐实）+ 骗子双人组合谋（反派视角前置）+ 识破与扣卡（冲突爆发留扣）
- **本章核心技巧**：切反派视角预演骗局再让受害者进场，读者全程比老实人知道得多，为他揪心的同时铺垫打脸期待。
- **卡点与伏笔**：结尾卡点：危机卡点——九百万钻卡被扣、伪精魄退回，张小侯人单势孤，期待他如何翻盘；埋设伏笔：斩空的密信与"见着张小侯就提回来"→ 军方线与骗局线的交汇伏笔；精魄用途 → 呼应恶魔系养魂需求。
