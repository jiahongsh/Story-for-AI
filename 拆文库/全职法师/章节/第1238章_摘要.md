# 第1238章 自然天敌法则

**概要**：地狱火在暗红森林砸出直径超百米的大坑，玛瑙头蛛脑袋碎了、肢爪断了几根，慌忙爬出逃窜。莫凡正要补上苍雷爪，漫天青色飞蛾如血海深仇般扑出，堵死它的退路，用利刃般的光芒把皮甲溃烂处的玛瑙头蛛切成碎片。白鸿飞诉说俞师师的苦衷，莫凡却望着飞蛾皱起眉头，嫌数量多得反常。青镇政大院，俞师师脸上温婉尽褪，露出阴恶狂妄的笑容，扬言让所有人不得好死。青色狂风之蛾笼罩青镇，冰锁被弄断，俞师师光脚跨过卫兵长封广阔的尸体，踏着飞蛾长毯升上夜空，青蛾之粉洒落，全镇人昏死，飞蛾如蝴蝶采蜜般在每个人身上采集精气。莫凡赶回青镇，怒骂白鸿飞还相信她，恍然大悟玛瑙头蛛正是牵制俞师师的天敌，自己重创蜘蛛等于帮她除掉了天敌。离曼曾说过，妖魔与妖魔互相牵制才让人类城市安宁，军方甚至会故意留关键妖魔一条生路。白鸿飞失魂落魄濒临崩溃，曹琴琴落泪认错，莫凡布置学员启动水循环大阵、加快水脉流动，自己赶去拖延俞师师。

**关键事件**：1.飞蛾群起将重创的玛瑙头蛛切成碎片 2.俞师师脱困升空，青蛾之粉毒倒全镇、采集精气 3.莫凡悟出玛瑙头蛛是天敌，自己除蛛反酿大祸 4.莫凡兵分三路布防，亲赴拖延俞师师

**逐章写法公式**：

- **情绪流向**：起：地狱火余威的爽感 → 承：飞蛾复仇的惊变 → 转：俞师师脱困屠镇的恐怖 → 合：天敌法则醒悟与紧急布防
- **节奏配比**：慢铺垫 15% / 快冲突 40% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：飞蛾复仇分食蜘蛛（收旧敌）+ 俞师师脱困毒镇（引爆灾难）+ 天敌法则醒悟（揭真相）+ 兵分三路布防（开决战）
- **本章核心技巧**：让主角亲手促成灾难，用既定世界观法则完成剧情反转，再以补救行动稳住节奏
- **卡点与伏笔**：结尾卡点：决战预告型——莫凡亲赴拖延俞师师，青镇全镇性命系于一线；埋设/回收伏笔：离曼讲过的天敌法则 → 本章回扣，又为后续妖魔生态设定奠基；封广阔的死亡 → 城市猎妖队防线崩溃
