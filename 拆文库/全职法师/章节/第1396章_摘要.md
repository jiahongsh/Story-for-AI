# 第1396章 就让它扮演一次博城

**概要**：冷爵外肌被毁后只剩血肉模糊之躯，吐出无孔不入的恶角黑烟夺人性命，并将黑烟不分敌我地涌向宏伟之墙，墙上的黑教廷教众与镇守者皆遭吞噬，莫凡以瞬息移动十公里赶回魔烽火台，将灵灵、赵满延、张小侯等数百镇守者转移到要塞城后。先知与张小侯确认土之源泉枯竭、宏伟之墙难撑，决意撤往飞皇市。莫凡因恶魔代价未偿无法离开，忆及博城之痛，决意让陌生的芦城扮演自己心中的博城独自守城。宏伟之墙最终决堤倒塌，众人溃逃，唯莫凡向前踏出一步，借炎姬魂影与瞬息移动将全体镇守者送离几公里外。张小侯则请赵满延以翼魔具送其西行，欲往煞渊说服古老王对抗胡夫金字塔。

**关键事件**：1.冷爵吐恶角黑烟不分敌我屠戮，莫凡瞬息移动救走数百镇守者 2.土之源泉枯竭、宏伟之墙决堤，莫凡因恶魔代价独留守城 3.张小侯西行煞渊，欲请古老王对抗胡夫金字塔

**逐章写法公式**：

- **情绪流向**：起：冷爵垂死反扑的阴毒 → 承：救人与撤离抉择的紧绷 → 转：墙塌众人溃逃、莫凡独留的悲壮 → 合：张小侯西行煞渊的钩子
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：冷爵黑烟屠戮（加压） + 莫凡救走镇守者（解围） + 墙塌独留守城（转折） + 张小侯赴煞渊（新线）
- **本章核心技巧**：以配角群像的反应层（赵满延急、张小侯不甘、先知决断）交替推进撤离与独留两条线，用博城回忆做主角动机锚点。
- **卡点与伏笔**：结尾卡点：张小侯能否说动古老王对抗胡夫金字塔，下章期待煞渊之行；埋设/回收伏笔：凝华邪珠未填满 → 莫凡必须继续屠戮冥界生物偿还代价，承接后续战局
