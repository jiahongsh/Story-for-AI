# 第565章 迁离

**概要**：莫凡一行步入遭袭后空无一人的华村，矮男探井时一张脸从井下凑出，吓得他坐倒在地，众人捞出落井的洪俊后才知道，这口不大的井里竟藏着上百名村民。洪俊与隔壁村壮男方幼苗相认，井中爬出的一男一女里，莫凡认出正是张小侯，可失忆的张小侯眼神迷茫认不出他，只死死依赖救过自己的医女苏小洛，莫凡仍重重抱了他一把。洪俊提议全村趁天亮迁往古都，村长谢桑动员村民收拾行囊，但绝大多数村民坚信出村死得更快，宁愿躲井里熬难关，只有三十多人愿意离开，谢桑果断定下十分钟后在村口集合出发。

**关键事件**：1.莫凡一行进入遭袭后空无一人的华村，矮男探井发现井里藏着上百村民 2.莫凡认出失忆的张小侯，张小侯只依赖苏小洛 3.村长谢桑动员迁徙，多数村民拒绝离开，仅三十余人愿走

**逐章写法公式**：

- **情绪流向**：起：疑惑（空村惨状） → 承：惊喜（井中遇人） → 转：震惊（张小侯失忆） → 合：压抑（村民分歧）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：空村探查（找线索） + 井中寻人（解悬念） + 重逢失忆（引爆情绪） + 迁徙决断（埋下险局）
- **本章核心技巧**：用「重逢却不相识」的信息差制造情感冲击，把生死抉择交给群像对话推动
- **卡点与伏笔**：结尾卡点：迁徙决定与留守伏笔并存，下章期待众人如何走出村庄；埋设/回收伏笔：灰蒜与井水庇佑是否有效、狗子的诅咒之说
