# 第126章 双系就是烧钱

**概要**："火系灵种"是学校没教过的概念。唐月讲解：天地孕育元素、元素按生长环境分品阶，特别活跃之地会产生有灵性的火种，火系魔法师炼化吸纳后火系技能威力成倍提升——这解开了莫凡"修为高威力却不变"的长期困惑。最普通的火系灵种市价也高达两千万、多半还需竞拍，那个亡命之徒正是被它引出来的。莫凡想起穆宁雪，唐月解释天生灵种体系：穆宁雪的天生琉璃冰种是灵品冰种里最强的冰类、威力比凡种强2.5倍、觉醒还比常人早几年，难怪被帝都学府直接录取。莫凡感叹草根没活路，唐月却说天生双系比穆宁雪更受宠、多一系可遇不可求；随即补刀：双系同级修炼的时间和资源都要多得多，烧钱烧资源，修为提不上去跟废人没区别。莫凡想到星之痕要买双份、火雷两系灵种都得攒，自嘲这是一辈子住郊区的节奏。

**关键事件**：1.唐月讲解灵种体系与两千万天价 2.揭示穆宁雪天生琉璃冰种2.5倍威力之谜 3.唐月点破双系受宠但烧钱烧资源的代价

**逐章写法公式**：

- **情绪流向**：起：斗嘴的轻松 → 承：灵种知识的兴奋 → 转：天才对比的落差 → 合：烧钱账单的肉痛
- **节奏配比**：慢铺垫 60% / 快冲突 5% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：概念提出（灵种定义）+ 天价锚定（价值确认）+ 同类对比（穆宁雪天生灵种）+ 代价反噬（双系烧钱）
- **本章核心技巧**：把一整章世界观设定全部塞进师生问答，用主角的贪心和肉痛当情绪过山车的轨道
- **卡点与伏笔**：结尾卡点：双系烧钱无解，逼出"投靠势力"的下一步讨论；埋设/回收伏笔：灵种威力翻倍（实力成长新路径）、火系灵种两千万（争夺战价值锚）、穆宁雪天生琉璃冰种（回收第一女天才之名）、雷系灵种更贵（莫凡资源长线需求）
