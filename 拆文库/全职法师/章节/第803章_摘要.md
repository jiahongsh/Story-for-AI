# 第803章 岛屿真相

**概要**：国府队以冻结身份坐地铁转巴士前往东京，望月千熏随行监督莫凡护送邪珠。车上赵满延称梦见双守阁海域有发出海豚般叫声的庞然大物，莫凡起初不以为意，忽觉与昨晚警戒光吻合，遂向望月千熏求证，确认上阁观测信息未外泄、赵满延无从得知。莫凡联想到西熊市"不存在的岛"，当众断定宫田所言非谎——她那夜是站在一头可伪装小岛的巨型海兽背上，而该生物从太平洋起一路尾随队伍至今，昨晚再现于双守阁海域。

**关键事件**：1.队伍冻结身份转巴士赴东京，望月千熏随行监督 2.赵满延梦到双守阁海域巨型生物，莫凡求证望月千熏 3.莫凡以"不存在的岛"推断宫田站在海兽背上 4.断定巨型海兽一路尾随队伍

**逐章写法公式**：

- **情绪流向**：起：赴东京途中的松散 → 承：赵满延梦境引发的疑窦 → 转：莫凡推断岛即海兽的反转 → 合：海兽尾随的钩子
- **节奏配比**：慢铺垫 50% / 快冲突 0% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：登程赴东京（过场） + 赵满延梦境（埋疑） + 莫凡求证回扣（破谜） + 断定尾随（大钩子）
- **本章核心技巧**：用配角梦境制造信息差，再以多卷伏笔收束成一句震撼断言
- **卡点与伏笔**：结尾卡点：海兽为何尾随，下章期待众人反应；埋设/回收伏笔：西熊市不存在的岛 → 本卷核心悬念揭晓
