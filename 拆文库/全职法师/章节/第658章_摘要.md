# 第658章 白色墓宫

**概要**：坠入煞渊后，莫凡被成百上千怨鬼反复灌输痛苦记忆，经历吊死、溺死、凌迟和活埋等梦魇，自己的经历几乎被覆盖。醒来后，他发现现实中坠落只过了几秒，柳茹、张小侯、方谷和苏小洛都还活着，众人从尸山下的黑色窟窿进入另一层空间。柳茹指向远处白色墓宫，莫凡确认那是古老王皇陵。张小侯也从梦魇中醒来，众人意识到古老王在煞渊中制造了独立天地，墓宫的白色外观却充满死亡气息。

**关键事件**：1.怨鬼以记忆折磨莫凡 2.莫凡恢复自我 3.众人进入煞渊第二层空间 4.发现白色墓宫 5.确认这里就是古老王皇陵

**逐章写法公式**：

- **情绪流向**：起：怨念梦魇 → 承：恢复自我 → 转：发现第二层空间 → 合：白色墓宫出现
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：怨念侵入（精神受创） + 醒来确认（恢复自我） + 穿过窟窿（转入新层） + 发现墓宫（锁定目标）
- **本章核心技巧**：用极端漫长的精神体验压缩成几秒现实时间，再用醒来后的空间反差重建探索感。
- **卡点与伏笔**：结尾卡点：白色墓宫确认是古老王陵，下一章期待墓宫入口和守卫机关；埋设/回收伏笔：煞渊空间漂移 → 回收为内部独立天地。
