# 第144章 幽狼兽！

**概要**：秃顶黎考官起身相迎罗宋，低声责怪他没事跑明珠来还非要和召唤系学生争，罗宋只说你知道我的底细。老教授发现莫凡什么都没带，问他为何不备辅助道具——特意推迟一周本就是想让学生回家商量买道具以大幅增加录取率，他愿意收召唤系但凡事要名正言顺；莫凡直接答太贵了买不起，辅助道具动辄几十万上百万，全身家当只有保命的镰骨盾。罗宋讥笑没钱还学召唤系，指出召唤系最烧钱，召唤生物弱不如狗强可敌妖魔，强靠自身修炼加烧资源。召唤开始，莫凡闭眼连起七颗召唤系星子，月牙状星轨在空间上撕开通往另一位面的裂痕，他的意识如上帝俯视梦境般闯入崭新的召唤位面大陆。黎考官提醒用意念说服选中的生物，莫凡深知停留时间有限，意念驰骋万米锁定孤峰上仰天长啸的幽蓝幽狼兽。第一次他用意念化绳索强套，绳索被扯断印记失败；老教授提示召唤生物并非主仆关系、要达成共识而非强制捆绑，第二次莫凡将精神印记化为柔和光芒洒落，吃软不吃硬的幽狼兽额头浮现烙印。莫凡呼唤完成回到试炼场，现实中秃顶考官的茶杯还没放下，幽狼兽从月色星轨裂痕中走出到他身旁，黎考官惊呼第一次召唤怎么可能召出幽狼兽。

**关键事件**：1.莫凡买不起辅助道具裸考，老教授解释延迟一周的用意 2.莫凡意识入召唤位面锁定幽狼兽，两次烙印由强索改柔光成功 3.幽狼兽现身试炼场，黎考官惊呼不可能

**逐章写法公式**：

- **情绪流向**：起：压抑（裸考被讥） → 承：紧张（位面初探） → 转：紧张（烙印一败一成） → 合：爽（幽狼现身+考官惊呼）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 30% / 悬念留白 20%
- **本章结构公式**：道具之问（劣势摆上桌） + 位面初探（异界奇观） + 双次烙印（规则试错） + 幽狼出世（惊艳收章）
- **本章核心技巧**：把一场考试写成"入异界选宠"的完整冒险，用两次烙印的失败与纠正把召唤系规则教给读者，结尾借考官之口为成果盖章
- **卡点与伏笔**：结尾卡点：强卡点，黎考官惊呼第一次召唤不可能召出幽狼兽，考核胜负与幽狼兽成色留待下章；埋设/回收伏笔：回收141章辅助道具线（买不起）、回收唐月意念强弱定品质的教导（中阶意念召来高战力生物）、回收142章动物园闭眼一抓的比喻（抓到狼）、埋下罗宋"你知道我的底细"的实力底牌、埋下黎考官与罗宋的私交
