# 第172章 一根指头

**概要**：萧院长继续介绍斩魔具乌斩——激活后幻化出乌蛰前臂使出镰舞风斩，杀伤力堪比两只进阶期妖魔合力一击。莫凡权衡：自己已掌控火、雷两大暴力之系，攻击手段不缺，而暗影系遁影的局限在于必须有光影落差才能施展，于是决定多一个逃生能力最重要，选定血兽靴并完成精神烙印，魔具与灵魂相连、意念一动即可幻化到双腿。修炼资源的折算结果出人意料：学院向主院申请了三步塔修炼机会一次——主校区中阶学员争得头破血流的地方，新生无资格进入，莫凡打破先河。萧院长特意建议他择成熟时机再入塔，现在去收益达不到最大化；莫凡盘算等四系修为将破时再用。此外还有助幽狼兽进阶战将级的兽将灵血，萧院长警告强行冲破血脉界限违背自然法则、失败可能灰飞烟灭，切勿操之过急；以及一张两百万元奖金的银行卡。萧院长告诫钱财只是辅助之物，莫凡回应自己可不满足于小小的中阶。莫凡最后问翼魔具的价格，萧院长慢悠悠伸出一根指头：至少这个数，更多时候不做竞卖。

**关键事件**：1.乌斩介绍后选定血兽靴并烙印 2.资源折算为三步塔修炼一次 3.获兽将灵血与两百万奖金 4.翼魔具价格高悬

**逐章写法公式**：

- **情绪流向**：起：爽（魔具开箱继续） → 承：期待（血靴烙印到手） → 转：好奇（三步塔资格） → 合：爽（两百万奖金与新目标悬置）
- **节奏配比**：慢铺垫 40% / 快冲突 5% / 爽点爆发 40% / 悬念留白 15%
- **本章结构公式**：乌斩补讲（选择收束） + 血靴烙印（即时爽点） + 三步塔+灵血+奖金（三连奖励） + 一根指头（新钩子）
- **本章核心技巧**：把奖励清单拆成性能讲解、风险警告、择机建议三层，每层都为后续剧情预埋接口而非一次性发完。
- **卡点与伏笔**：结尾卡点：翼魔具价格成谜且不做竞卖，下章期待资金用途与实力提升路线；埋设/回收伏笔：三步塔修炼机会→延后使用的跨章大机缘；兽将灵血+血脉进化风险→幽狼兽进阶战将级的伏笔与失败可能；暗影遁影需光影差→下一arc实战中被光线限制的伏笔。
