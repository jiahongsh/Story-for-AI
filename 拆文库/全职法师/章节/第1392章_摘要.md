# 第1392章 恶魔之火漫天

**概要**：乌纳斯之死让冷爵彻底发狂，他讥讽撒朗掀起古都浩劫仍没覆灭整座城，自称才是最强大的红衣大主教、真正的死亡主宰，发誓要比撒朗做得更完美，北原绝不留活口，撒朗屠百万他就屠千万。他身上那些脸谱衣画纷纷活了过来，各自呈现憎恨、愤怒、仇怨、悲伤、绝望的情绪，化成一团团厉鬼烟尘扑向镇北关——这些痛苦之鬼不受神楚之界限制，钻入军法师身体便引爆他人一生的痛苦记忆，几名军官崩溃跳墙，被墙下亡灵哄抢而食，一名军法师中邪般喊着"我的女儿其其格"差点坠墙，被赵满延拉住。灵灵道破原理：正如图腾以供奉得神力，憎恨愤怒恐惧众志成城也会聚成邪恶信仰之力，正面信仰是祝福、邪恶信仰就是诅咒，而承载这一切的邪恶信仰体正是冷爵。彬蔚脸色苍白苦撑，自谓多撑一分钟就能多救活一个村子的人。绝望之际，痛苦之鬼忽然集体呜鸣飞出人体，向十公里外的一头冥君蛙飞去，冷爵位置就此暴露，可十公里茫茫冥军令人望而生畏。灵灵又指向一道十公里外仍清晰可见的血墨色冷光，先知一眼认出那是莫凡——当初正是这血墨色光芒之人打退山峰之尸，救下古都。恶魔之炎以烈霞色与红褐交织在十公里外澎湃炸开，连正在攻墙的斯芬克斯都转身嘶吼，蝎君美杜莎与方圆三十公里的冥界君主纷纷停止攻击，警惕地望向这出现在冥军深处的异类威胁。

**关键事件**：1.冷爵脸谱化痛苦厉鬼扑向镇北关，军法师被痛苦记忆侵蚀、有人跳墙被亡灵哄食 2.灵灵道破邪恶信仰原理，锁定冷爵就是邪恶信仰体 3.痛苦之鬼集体飞向十公里外的冥君蛙，冷爵位置暴露 4.十公里外的血墨色冷光被先知认出是莫凡 5.恶魔之炎爆发，斯芬克斯、美杜莎与方圆三十公里冥界君主全部停止攻墙

**逐章写法公式**：

- **情绪流向**：起：冷爵发狂宣言的压抑 → 承：痛苦厉鬼侵蚀守军的恐怖 → 转：痛苦之鬼退散、血墨色冷光出现的转机 → 合：恶魔之炎爆发、全场君主停攻的震撼
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：冷爵厉鬼攻势（敌方大招）+ 守军崩溃与原理揭示（危机深化）+ 痛苦之鬼飞离暴露冷爵（转折）+ 莫凡恶魔之炎镇压全场（爽点收尾）
- **本章核心技巧**：精神攻击铺压至全线崩溃的谷底，再用"痛苦之鬼集体退散"这个反常现象引出一连串转机，最后以主角降临、万敌侧目收束
- **卡点与伏笔**：结尾卡点：恶魔莫凡现身在冥界大军深处，冷爵、斯芬克斯、美杜莎等强敌尽数警惕，大战一触即发；埋设/回收伏笔：血墨色光芒打退山峰之尸→回收古都旧事，坐实恶魔莫凡的战力与功绩
