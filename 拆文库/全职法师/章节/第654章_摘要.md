# 第654章 空间罗盘，死轴！

**概要**：山峰之尸逼近前路，韩寂派祝蒙、凌溪、石峥、耀庭、陆虚、楚嘉、李于坚率近百名高阶以上法师迎击，自己继续保护煞渊小队。大量火焰和冰封灵柩轰在山峰之尸身上，却只留下轻微痕迹，山峰之尸随后以拳击裂空间，杀死冰系法师并迫使众人学习根据空间波颤闪避。耀庭构建空间系星宫，在山峰之尸面前连续瞬移，最后喊出空间罗盘·死轴，准备正面重创这只亡灵霸主。

**关键事件**：1.韩寂派近百法师迎击山峰之尸 2.高阶魔法难以伤害山峰之尸 3.山峰之尸以空间裂痕反击 4.耀庭寻找裂痕前兆 5.耀庭发动空间罗盘·死轴

**逐章写法公式**：

- **情绪流向**：起：集群迎击 → 承：常规高阶魔法失效 → 转：空间裂痕制造伤亡 → 合：耀庭完成死轴蓄势
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：集结法师团（分担威胁） + 魔法洗礼（证明无效） + 空间裂痕（反杀强者） + 死轴锁定（准备反击）
- **本章核心技巧**：先让常规高阶手段全部失效，再给空间系法师发现可利用的攻击前兆，为终招制造技术性可信度。
- **卡点与伏笔**：结尾卡点：耀庭完成空间罗盘·死轴，下一章期待死轴能否击穿山峰之尸；埋设/回收伏笔：空间波颤前兆 → 成为法师躲避空间裂痕的生存规则。
