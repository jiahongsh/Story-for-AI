# 第925章 空中遇妖袭

**概要**：国际航班遇强烈气流颠簸，广播甜美女声安抚，乘客渐不安，舱灯突灭、氧气罩掉落引发尖叫。邻座女孩芬芬吓得抱紧莫凡胳膊。莫凡解安全带去甲板驾驶室，得知一只操纵气流的妖魔闯入航线、领空法师约二十分钟到。广播寻高阶法师，戴厚眼镜的贾老师傲气现身却斥莫凡学生凑热闹。二人经尾部特殊舱门上尾翼，狂风如洪水。贾老师风之翼飞出以中阶打怪鸟无效、动高阶反被逼近，莫凡抽雷座之书灌雷系魔能，一束雷光灼穿近公里外巨型蜂鸟翼膀，怪鸟惨叫逃走，贾老师骇然认出雷系高阶。

**关键事件**：1.客机被操纵气流的妖魔扰乱，氧气罩掉落 2.贾老师傲气轻视莫凡，中阶打怪鸟无效 3.莫凡雷座之书雷光束灼穿怪鸟，贾老师惊其雷系高阶

**逐章写法公式**：

- **情绪流向**：起：气流颠簸的不安 → 承：灯灭氧气罩的恐慌 → 转：贾老师轻视与中阶失效 → 合：莫凡雷光退敌的爽点
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：妖魔乱流（设压）+ 贾老师轻视（错位）+ 中阶失效（加压）+ 雷座之书退敌（收束）
- **本章核心技巧**：用傲慢配角作对比台阶，把主角高阶实力在绝境一次性点亮
- **卡点与伏笔**：结尾卡点：贾老师惊雷系高阶，下章期待其态度转变与莫凡落地；埋设/回收伏笔：雷座之书 → 莫凡卷轴类外挂的实战首秀
