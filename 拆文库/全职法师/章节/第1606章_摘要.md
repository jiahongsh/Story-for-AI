# 第1606章 新契约宠

**概要**：亡灵大军退潮，开罗得到喘息，市区夜生活热闹。赵满延在酒店酒廊拒绝美女搭讪、暗自感叹玩太疯伤了肾，随即看到莫凡步伐沉重、双眼无神、脸色发白地回来，误以为他被阿帕丝榨干，还发现口袋里那盒东西未开封，絮叨他做男人要负责任、怎么向两个老婆交代。莫凡有气无力地说自己刚收了一只美杜莎做契约宠，赵满延长篇论证美杜莎宁死不会接受契约、绝无可能。真相是九幽后没有让阿帕丝灰飞烟灭并非心慈手软，而是契约成立后若从内部粉碎契约兽灵魂，血脉相连的莫凡会遭大君主级反噬、必死无疑。回到房间，疲惫的九幽后现身解释召唤契约一旦成立主仆关系即确立，实力再强的生物都被契约压制，除非飞升帝王级，而阿帕丝再修炼几百年也未必成帝。她抱怨自己与阿帕丝两败俱伤毁掉多年修为却让莫凡白捡便宜，要求独睡契约空间；莫凡召出小炎姬，她坐在桌上啃魂级火系碎片，一脸吃瓜。

**关键事件**：1.莫凡确认阿帕丝已成为自己的第二契约兽 2.九幽后解释契约霸道性与帝王级晋升之难 3.九幽后与阿帕丝两败俱伤，莫凡白得高血统契约宠

**逐章写法公式**：

- **情绪流向**：起：赵满延插科打诨的轻松 → 承：求证新契约宠的戏谑 → 转：灵魂反噬真相的惊险 → 合：契约确立+九幽后抱怨的余味
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 30% / 悬念留白 20%
- **本章结构公式**：喜剧重逢（调剂情绪）+ 常识否定（立预期差）+ 真相复盘（释疑惊险）+ 契约盘点（结算战利品）
- **本章核心技巧**：用配角的不信与吐槽对冲主角的惊天所得，喜剧感与爽感并存
- **卡点与伏笔**：结尾卡点：状态+阿帕丝苏醒后如何相处、美杜莎之心是否会反噬；埋设/回收伏笔：第二契约空间 → 阿帕丝正式入驻；帝王级晋升条件 → 后续战力天花板参照
