# 第1428章 有利于海妖的地带

**概要**：救援队驶出数公里后，发现求救轮船反而更远，唐鹏判断被猎脏者拖向深海。唐鹏向莫凡科普海洋分层：浅层200米内对人类有利，中深层海妖隐匿且妖术增幅，深海更是天然护盾。众人又行三公里终见轮船，登船却发现空无一人、无破损。莫凡抛火炸开烈霞之炎照亮海面，骤然浮现无数死灰之眼的猎脏者头颅——这是以求救信号设下的陷阱，且已身处深海不利地带，唐鹏急令撤退，但为时已晚被包围。

**关键事件**：1.救援船越追越远，唐鹏判断轮船被拖入深海 2.唐鹏向莫凡科普海洋浅中深层对战斗的影响 3.队伍再行三公里见轮船，登船发现空无一人且无破损 4.莫凡抛火照亮海面，露出无数猎脏者头颅 5.识破陷阱，唐鹏急令撤退但已被包围

**逐章写法公式**：

- **情绪流向**：起：夜海航行稍安 → 承：越追越远、科普加压 → 转：登空船、抛火现敌 → 合：识破陷阱、被包围留白
- **节奏配比**：慢铺垫 35% / 快冲突 35% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：追船反常（起疑）+ 唐鹏科普分层（铺设定）+ 见空船（加压）+ 莫凡抛火揭陷阱（反转）+ 急退被围（钩子）
- **本章核心技巧**：用"越追越远"的反常逐层累积，最后以主角一个小动作引爆陷阱真相
- **卡点与伏笔**：结尾卡点：类型悬念+内容"已入深海陷阱被包围"、下章期待破局；伏笔：海妖具备设伏智慧→后续海妖全面攻势
