# 第679章 灼火炎剑！

**概要**：小炎姬维持附体，让莫凡在连续施放火系魔法后仍能借用她的能力。骷髅大军并未减少，十多个铁球骷髅方阵逼近，莫凡踏着火浪化为火焰曜石撞入第一个方阵，击飞并焚毁大批铁球骷髅。其余方阵用骨球和骨锁围攻，莫凡以影分身引走骷髅，使它们挤成骨丘。小炎姬赋予莫凡以意念拟化火焰的能力，他凝出十米炎剑斩向骨丘，留下焦土剑坑并烧死周围铁球骷髅。

**关键事件**：1.铁球骷髅方阵形成新的群体威胁。 2.莫凡以火焰曜石撞毁首个方阵。 3.莫凡利用影分身聚怪后以炎剑完成范围斩杀。

**逐章写法公式**：

- **情绪流向**：起：压抑 → 承：热血 → 转：紧张 → 合：爽
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：敌阵逼近动作（展示规则） + 曜石冲阵动作（清除首阵） + 影分身诱导动作（聚集敌群） + 炎剑斩落动作（完成清场）
- **本章核心技巧**：连续清场后更换敌军攻击机制，再用诱导站位把新能力的展示集中到一次解决。
- **卡点与伏笔**：结尾卡点：能力类，莫凡已能在附体状态下拟化炎剑；埋设/回收伏笔：小炎姬附体消耗 → 每次借用能力都在损耗她的身体机能。
