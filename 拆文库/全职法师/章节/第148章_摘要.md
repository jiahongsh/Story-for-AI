# 第148章 入学风云（下）

**概要**：新生会上蒋云明介绍召唤系是放养式教学，除每周几堂重要课程外学生自己培育召唤兽，正合兼修四系的莫凡心意。他随即抛出头等大事：学院对召唤系有特别的迎新节目，表现优异的前两名可得一瓶炼兽之血——能让召唤生物洗髓、实力大幅增长，甚至可能让奴仆级巅峰的召唤兽进阶，六名男生听后眼放渴望，但蒋云明卖关子不肯说节目内容。回宿舍后赵满延透露内幕：历届迎新大会举行斗兽大赛，全校师生坐在青校区最大的斗馆，放进超大铁笼里的怪兽就是召唤系新生的召唤兽，供全校新生自发入笼挑战。莫凡大骂学校坑召唤系，哭丧着脸感叹这何止刺激简直丧心病狂，担心幽狼兽架不住全校轮战。睡前莫凡问起红发家伙去向，赵满延淡淡说对方应已申请换宿舍，其余舍友却眼神怪异似怕赵满延、闭口不谈，莫凡察觉这位舍友本事不小。

**关键事件**：1.蒋云明宣布迎新节目与炼兽之血奖励 2.赵满延揭底：斗兽大赛的兽就是召唤系新生的召唤兽 3.红发舍友换宿舍内幕成谜，赵满延深浅莫测

- **情绪流向**：起：放养教学的惬意 → 承：炼兽之血的诱惑 → 转：斗兽真相的哭丧 → 合：舍友之谜的余味
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：放养教学设定（给主角自由度） + 炼兽之血悬赏（立目标） + 赵满延揭斗兽规则（转折） + 换宿舍疑云（埋暗线）
- **本章核心技巧**：把「规则不公」做成两段式揭底——官方藏一半、情报贩子式舍友补一半，落差感由主角的哭丧脸承接
