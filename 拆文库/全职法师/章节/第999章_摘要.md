# 第999章 撒哈拉救援

**概要**：莫凡听赵满延报领域魂种约八亿，看穆宁雪玩闹自叹天生天赋坑钱，称六系全领域魂种何年马月。赵满延说无领域魂种也强两三倍，莫凡坚持要领域，定买雷系——火系靠小炎姬近魂火、黑暗有司夜统治，唯海上战斗火系无用需雷系领域。江昱神秘插话：提诺阿亚海边骸骨鉴定为亚君主级猛犸海兽被剔只剩骨，莫凡联想到那是歹蛆所化、已游远，细思极恐是否还有更高等级生物；江昱又说附近岛屿发现同症状的人骨，莫凡鸡皮疙瘩。视角切沙漠：绿豹纹女子见灾级沙尘暴，众人逃入撒哈拉。好望角魔堡黑须老者怒责学员闯禁地，魔堡侍卫请中国国府队先去搜索救援并付高雇佣费，老者允。莫凡等离开葡萄牙赴埃及时接到撒哈拉救援紧急任务，众人惊呼那是禁地不去。

**关键事件**：1.莫凡定买雷系领域魂种，江昱曝歹蛆化猛犸海兽 2.沙漠学员遇灾级沙尘暴逃入撒哈拉 3.好望角魔堡请中国国府队救援，莫凡等接任务

**逐章写法公式**：

- **情绪流向**：起：魂种价高的轻松 → 承：歹蛆威胁升级铺垫 → 转：沙漠灾变与救援转折 → 合：接禁地任务的惊呼钩子
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：魂种议价（收线） + 歹蛆威胁升级（惊悚） + 沙漠灾变（危机） + 请援接任务（钩子）
- **本章核心技巧**：用江昱的情报把上一阶段威胁升级，再切视角铺开新地图危机
- **卡点与伏笔**：结尾卡点：类型悬念+国府队是否去撒哈拉引下章；埋设/回收伏笔：猛犸海兽骸骨→歹蛆更可怕形态伏笔
