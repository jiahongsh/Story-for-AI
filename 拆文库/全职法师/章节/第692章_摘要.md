# 第692章 咽喉，要害！

**概要**：艳阳般的光辉洒落灰色内城，最恐怖的山峰之尸被轰出数公里外，人们脸上浮现压抑许久的欣喜。恶魔莫凡从陨石沉坑中站起，火焰似邪焰凤凰飞扬成尸臣不敢入的炙热领域，笼罩数公里，原本密集的尸海大军稀疏不少。山峰之尸身上原有七位超阶留的伤痕，再遭天陨冲击后厚尸皮铠烂开，它嘶吼着未立刻攻击，而是调动无数尸将尸臣当炮灰——肉丘尸臣与血尸臣十余只聚集脚边，皮糙肉厚冲向莫凡，将他火焰领域踩踏大半。一只三十米肉丘尸臣张口吞下莫凡，却在胃中消化时身躯膨胀至三倍炸裂，全身火焰的莫凡一跃落上信号铁塔，咬碎吞下它的黑色亡灵结晶以补干枯魔能、抵御恶魔化副作用。莫凡焦躁于被炮灰拖垮，此时祝蒙在背后提醒：山峰之尸的亡灵结晶就在咽喉之下。灰白人、韩寂、左锋相继现身助战，韩寂点明必须打碎咽喉下的亡灵结界，左锋率仅剩的十几名禁卫冲出结界接下尸臣。

**关键事件**：1.莫凡站陨石坑，火焰领域逼退尸海 2.山峰之尸召十余尸臣当炮灰 3.肉丘尸臣吞莫凡反被撑爆，莫凡吞亡灵结晶 4.祝蒙报尸君要害在咽喉下 5.灰白人、韩寂、左锋率残卫助战

**逐章写法公式**：

- **情绪流向**：起：内城欣喜的反转 → 承：尸臣炮灰加压 → 转：吞爆反杀补魔 → 合：要害揭示与援军钩子
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：火焰领域（压制） + 尸臣围攻（加压） + 吞爆补魔（反转） + 要害揭示（钩子）
- **本章核心技巧**：用“敌人吞噬机制”做反转破局，再以情报收束boss要害坐标
- **卡点与伏笔**：结尾卡点：众人合力要打碎咽喉亡灵结界，读者期待总攻能否奏效；埋设/回收伏笔：亡灵结晶补魔能 → 莫凡抵御恶魔化副作用的续命手段
