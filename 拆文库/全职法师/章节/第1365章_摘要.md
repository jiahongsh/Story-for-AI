# 第1365章 七鬼

**概要**：莫凡指着北方夜空的冥光问是不是冥君蛙，被蓝蝙蝠呵斥别问，他索性装疯卖傻感慨期待冷爵大人的盛典。莫凡身上有伤未愈，眼下无法阻止冥君蛙，且冥君蛙不止一只，每只奴役约两千多只冥界纤夫，等同冥界军队碾向中原。他此时才道出北鹿身份的真相——这是审判长冷青埋在黑教廷的内线代号，冷青为保此身份丧命，莫凡追踪牧羊人程英时得代号人告知，便开杀戒杀光包括北鹿在内的黑教廷人员，甘冒被识破的风险接下这具身份。两人循冥光行至光秃秃的山后，冥界之咒正组成次元之门，黑衣教士跪拜匍匐，莫凡以残暴姿态一脚踩烂不顺眼教士的脸。男蓝衣紫鬼现身，自称七鬼之一，心计深重地盘问莫凡，莫凡凭偷看程英与引渡首视频的细节答出"赤鬼"，消去疑心。莫凡反讥紫鬼是七鬼最末，惹来杀气，随即抛出一个消息——慌不择路的老农是审判会的人，紫鬼与蓝蝙蝠均证实所见。

**关键事件**：1.莫凡自述北鹿身份的真相与接替过程 2.莫凡蓝蝙蝠抵达冥界之门筑造现场 3.紫鬼盘问引渡首之名，莫凡答出"赤鬼"过关 4.莫凡谎称老农是审判会的人，转移紫鬼注意力

**逐章写法公式**：

- **情绪流向**：起：夜探冥光的紧张 → 承：身份真相的沉重 → 转：踩脸立威的癫狂 → 合：盘问危机的险象
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：夜探冥光（入险地）+ 身份自述（释前因）+ 残暴立威（融环境）+ 赤鬼过关（渡危机）
- **本章核心技巧**：把身份设定放在最危险的场景中央交代，用"越危险越补背景"的手法让读者在信息释出中持续提心吊胆
- **卡点与伏笔**：结尾卡点：设局式——莫凡把审判会的人指认为暴露源，将牵制紫鬼；埋设/回收伏笔：冷青埋下的北鹿线、赤鬼之名 → 莫凡继续深入引渡首层面的跳板
