# 第320章 给我吐出来！

**概要**：恶魔系实验超千例，蒋艺从未见过像莫凡这样保持原貌却更恐怖的试验品。恶魔莫凡凝视得她浑身僵硬，随后口吐人言忘了告诉你——我不是三系，这是实验中唯一还能说话的活体。他蓄力如人型长弓一跃跳上一百多米高的信号塔楼，落点踏出蛛网裂纹；蒋艺失神喃喃，意识到若他拥有整整四系，恶魔化威力就越恐怖。巨蜥伪龙扑出巢穴，张口将天鹰与皮网中四人整个吞进嘴里；四人将滑入胃中被消化之际，塔尖的恶魔莫凡化作飞矢，烈焰巨拳狠砸伪龙喉咙，食物被生生吐出，伪龙被轰飞上百米、在峰穴砸出窟窿。莫凡反腿扫出半月之芒，无声切断峰穴一段、巨石从三百多米高空砸向市中心。蒋艺确认莫凡是四系法师、达成完美恶魔化且保有心智——实验成功了。

**关键事件**：1.恶魔莫凡自称不是三系、一跃百米 2.巨蜥伪龙一口吞下四学员 3.莫凡一拳轰喉救出众人、轰飞统领 4.半月之芒切峰 5.蒋艺确认四系完美恶魔化

**逐章写法公式**：

- **情绪流向**：起：紧张（邪性凝视）→ 承：热血（一跃百米）→ 转：恐怖（伪龙吞人）→ 合：爽（轰喉救人与切峰奇观）
- **节奏配比**：慢铺垫 20% / 快冲突 25% / 爽点爆发 45% / 悬念留白 10%
- **本章结构公式**：旁白定价（千例无此人）+ 半句底牌（我不是三系）+ 蓄力跳跃（立身体规格）+ 生吞危机（压到谷底）+ 一拳逆转与月芒切峰（双重爆发）+ 蒋艺定性（完美恶魔化）
- **本章核心技巧**：把救场拆成"吼声预告-拳头命中-吐出食物-轰飞-反腿切峰"五连拍，用连续的物理奇观替代一句"他赢了"
- **卡点与伏笔**：结尾卡点：爽点余韵型——完美恶魔化成立但只是冰山一角，下章期待对伪龙正战；埋设伏笔：四系身份被蒋艺一方确认 → 军方对莫凡价值的重新估算，蒋艺自知罪孽难逃制裁 → 后续审判线
