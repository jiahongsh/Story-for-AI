# 第1338章 夜煞契约

**概要**：卑匠的黑暗侵染之力是最可怕的追踪手段，能反馈被侵染者接触的一切，正是挖出冷爵所需；控影能力也让莫凡想起被魔影子耗得遍体鳞伤的惨境，他志在必得。冯州龙再度警告卑匠魂魄会给予致命灵魂创伤，莫凡自信灵魂强大不以为意。冯州龙道出这黑暗物质名叫夜煞，比魂级元素种更强，但莫凡暗影系修为刚至高阶第一级，需勤加修炼才能任意操控。冯州龙用聚魂魔具释放夜煞后离开，白屋只剩莫凡与卑匠鬼魂。卑匠鬼魂叫嚣要让莫凡生不如死，莫凡冥想接纳夜煞，与黑暗之主签订以魔能祭献的黑暗契约；夜煞则要求每施展相关技能祭献战将级残魄，魔影之术需统领级残魄。莫凡签字成交，夜煞融入灵魂，赐予黑暗侵染与影煞之术。卑匠鬼魂趁融合冲入灵魂复仇，莫凡反称老婆是帕特农圣女、冷青心脏衰竭被救活，令卑匠鬼势削减，随即小泥鳅坠涌出千米漩涡般的吸扯力，将卑匠鬼魂收入囊中。

**关键事件**：1.夜煞与莫凡签订黑暗契约，赠黑暗侵染与影煞之术 2.卑匠鬼魂趁融合攻击莫凡灵魂 3.莫凡以帕特农救活冷青反击卑匠，小泥鳅坠吞噬其鬼魂

**逐章写法公式**：

- **情绪流向**：起：盘点黑暗侵染与控影价值的跃跃欲试 → 承：夜煞契约条件与代价的权衡 → 转：卑匠鬼魂趁机复仇的惊险 → 合：小泥鳅坠吞魂的爽快收尾
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：能力价值盘点（动机） + 夜煞契约与代价（规则建立） + 卑匠鬼魂反扑（冲突） + 小泥鳅坠吞魂（解决） + 新能力入手（收获）
- **本章核心技巧**：把"变强"写成一场签契约的仪式，先立代价规则再化解风险，让主角获得能力的同时顺手清算反派残念
- **卡点与伏笔**：结尾卡点：能力到手——黑暗侵染与影煞之术待实战验证，冷爵线索仍在钓鱼；埋设/回收伏笔：小泥鳅坠→吸魂能力的展示；战将级/统领级残魄→后文技能消耗的资源线
