# 第1001章 消失的南珏

**概要**：莫凡每走百米回头看穆宁雪，发现目标总在不同方位，实则穆宁雪未挪、只放斗笠旋风信号。走一公里后黄沙茫茫，沙丘雷同如黑暗，通讯仪也受干扰。莫凡以穆宁雪为圆心搜得一公里，半小时后发现沙中浅绿帐篷与存水袋、食物干，确认非洲学员队曾在此、约一天半前失联，便撑绿帐篷作旗标返回。众人顺信号汇合，却发觉南珏迟迟不发五分钟信号，等至十五分钟无反应。蒋少絮以心灵之音提醒注意沙色，众人惊觉自己已偏离、走进殷黄沙地，赵满延飞高发现方圆几公里全透红、南珏踪影全无——龙尾消失，众人完全陷入沙漠迷界。

**关键事件**：1.莫凡找到学员绿帐篷旗标 2.南珏超时未发信号 3.众人偏离陷迷界、南珏消失

**逐章写法公式**：

- **情绪流向**：起：探界信号的平静 → 承：寻旗标与汇合铺垫 → 转：南珏失联与偏航反转 → 合：全陷迷界的不安钩子
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：寻旗标（行动） + 汇合发现失联（异动） + 沙色辨偏航（反转） + 全陷迷界（危机）
- **本章核心技巧**：用"严格纪律者反常失联"制造失踪悬念，再用沙色视觉收束迷失真相
- **卡点与伏笔**：结尾卡点：类型悬念+如何走出迷界引下章；埋设/回收伏笔：南珏失踪→后续沙暴煞灵伏笔
