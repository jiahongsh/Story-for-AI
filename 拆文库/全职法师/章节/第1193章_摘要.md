# 第1193章 没有不敢杀的！

**概要**：莫凡以地狱火石轰退三名冰系抵抗的审判员，火焰呈鲜红玫瑰色，不由想念小炎姬的劫炎。陆冰峰鼓动暗影审判员以司夜统治配合巨影钉锁莫凡心魂，却被莫凡瞬移反制、以黑暗禁锢之刃刺其后腰与脑后。陆冰峰唤锯齿鬼木锯向莫凡，莫凡以银色空间系光辉制住鬼木。两名心灵系审判员同时对莫凡施心灵冲击，莫凡却以虚空之爪反抓两人——他已是第四境中境界，碾压第三境的小境界审判员，年长者的自信冲击被一爪捂住。莫凡施展时滞，将冰锥、火雨、巨木尽数静止在五米内，走出后念力如惊涛撞飞两心灵审判员。他走到陆冰峰面前，问“姓陆？是你们把我父亲带走的？”，黑暗封死其心魂后将陆冰峰抛向空中，十二倍雷霆将其撕成焦黑血雨。其余审判员惊恐，莫凡煞气镇住全场。高空中陆斩天发狂俯冲，博拉闪身挡下、利爪撕断其臂上血管与筋。

**关键事件**：1.莫凡地狱火石退敌、想念小炎姬 2.暗影与心灵系审判员被反制 3.时滞静止魔法、第四境碾压 4.雷撕陆冰峰、博拉撕陆斩天臂

**逐章写法公式**：

- **情绪流向**：起：火石退敌的轻 → 承：暗影心灵系围攻的紧 → 转：时滞碾压的爽 → 合：雷撕陆冰峰、博拉撕臂的爆
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：火石退敌（铺垫） + 多系围攻（加压） + 时滞碾压（破局） + 雷撕处决（爆发钩子）
- **本章核心技巧**：用精神境界设定差解释碾压合理性，再以“时滞静止”的视觉奇观把围杀转为单方面处决。
- **卡点与伏笔**：结尾卡点：陆斩天被博拉撕臂，下章莫凡将直取宇昂；埋设/回收伏笔：陆家复仇线 → 后续蔓叶镇清算伏笔。
