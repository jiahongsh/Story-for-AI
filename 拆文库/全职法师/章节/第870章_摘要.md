# 第870章 故事风云

**概要**：夜里海风河风如女人呜咽，莫凡三人受赵品霖、荣盛之邀到离别墅约一公里的篝火棚聚会。半坡木屋配钢化玻璃天顶，云团星空相争，一公里照明取暖全靠中央篝火，营造紧张又刺激的幻境。荣盛提议轮流讲恐怖故事，输者走到坡顶。莫凡抢先讲日本闫明寺宫田的亲身经历，添油加醋形容半面女鬼与恶灵折磨，细节逼真令众人噤声、一女生想回酒店，穆宁雪踩他一脚嫌其败兴，灵灵则嗤之以幼稚。荣盛忙讲乌镇传闻缓和：他哥城市猎人两月前遇鬼雾与失踪，当地传言是"蛾女"与食肉飞蛾。赵品霖笑称不过是吸游客的传说。莫凡却插嘴说鬼雾确有其事，自己前阵离乌镇时正逢城市猎妖队赶去，蛾女未证实。灵灵补刀案件未结。众男生女生一听莫凡经历也是真的顿时慌乱要回。轮到本地女孩郭文衣，她讲夜走两公里回镇时闻到似沼气池的臭味，话到此处莫凡原本散漫的眼神骤然凌厉。

**关键事件**：1.篝火棚聚会，荣盛提议讲鬼故事。 2.莫凡讲闫明寺亲身经历吓得众人噤声。 3.荣盛讲乌镇蛾女传闻，莫凡证实鬼雾真事。 4.灵灵补刀案件未结，众人慌乱。 5.郭文衣讲夜路怪事开头，莫凡眼神凌厉。

**逐章写法公式**：

- **情绪流向**：起：夜风呜咽的阴森 → 承：篝火聚会的轻松 → 转：亲身鬼故事的惊悚 → 合：郭文衣怪事引出的凌厉钩子
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：环境压阴（定调） + 鬼故事游戏（松） + 莫凡真事吓人（紧） + 郭文衣线索（钩）
- **本章核心技巧**：用"篝火讲鬼故事"框架把多个独立案件串成闲谈，主角反应当探雷针，自然过渡到主线线索
- **卡点与伏笔**：结尾卡点：郭文衣只说到臭味莫凡便凌厉，下章期待她看见什么；埋设/回收伏笔：乌镇鬼雾蛾女 → 城市猎妖队未结案件，后续或回扣；闫明寺宫田 → 莫凡过往经历的回扣
