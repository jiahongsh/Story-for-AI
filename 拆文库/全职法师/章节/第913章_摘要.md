# 第913章 完虐赛以德！

**概要**：牧奴娇提醒莫凡死刀木乃伊极强，莫凡笑称不放在眼里。死刀吨位十足、举黑巨刀斩出分空间刀影掠百米，莫凡下沉分身躲、刀气扩散再遁影，念墙挡下。莫凡重识其力量后直接天焰葬礼，火云集中其头顶烧成火山，中阶难躲高阶之火。赛以德惊其为高阶法师，急收木乃伊，唤铁尸袭被莫凡念力打飞，虚爪抛远。赛以德再唤亡灵，莫凡空间波将铁尸与其一同推飞界外。白东威惊其空间系，守馆人傻眼，白教员宣莫凡胜，岳棠心嘀咕好帅。

- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 35% / 悬念留白 15%
