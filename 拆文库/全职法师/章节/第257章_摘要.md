# 第257章 你的契约兽呢？

**概要**：第一局落败后，沈明笑质问彭亮魂影钉为何不控制用火的赵明月，彭亮当场回怼，内讧被顾翰劝阻。沈明笑请求下一场继续上，指出彭亮、赵满延毫无作用实为二打四；负责沟通的李静老师帮腔说莫凡、郑冰晓两个召唤系配置不妥，郑冰晓主动让位。沈明笑要求莫凡听他指挥，莫凡回敬他实力不济还瞎蹦跶、靠别人让位，沈明笑怒骂他是哗众取宠的废物，莫凡不再纠缠转而与牧奴娇同行，沈明笑因追求牧奴娇而脸色更沉。牧奴娇压低声音让莫凡拿出全部三系实力。宋霞充当指挥询问莫凡召唤系情况——召唤生物离战将还有一步之遥、契约兽还没找到合适的，众人集体皱眉：这等于凭白少了一系中阶魔法。

**关键事件**：1.败后内讧、沈明笑请战 2.郑冰晓让位、莫凡顶入第二局 3.莫凡与沈明笑正面互怼 4.契约兽空白曝光、众人认为少一系中阶

**逐章写法公式**：

- **情绪流向**：起：败局后的内讧怨气 → 承：请战换人与让位风波 → 转：莫凡与沈明笑正面互怼 → 合：契约兽空白曝光、全队信心受挫
- **节奏配比**：慢铺垫 60% / 快冲突 25% / 爽点爆发 5% / 悬念留白 10%
- **本章结构公式**：败后内讧（泄怨立矛盾）+ 请战与让位（换人风波）+ 互怼（立沈莫私怨）+ 契约兽质问（唱衰主角收钩）

- **卡点与伏笔**：结尾卡点：压抑——契约兽还没找到、召唤生物离战将一步之遥，等于少一系中阶魔法，读者等莫凡如何自证；埋设/回收伏笔：牧奴娇知道莫凡有三系本领 → 隐藏实力线蓄压；沈明笑与彭亮结怨、沈明笑追求牧奴娇 → 队内人际矛盾线；郑冰晓让位善举 → 善缘伏笔
