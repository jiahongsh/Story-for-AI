# 第1195章 好言相劝

**概要**：莫凡径直走到蔓叶镇陆家大宅，身后吸血鬼博拉拖着半死不活的陆斩天，陆家男丁虽虎视眈眈却无人敢动。议员陆辛见儿子被打得不成样暴怒呵斥，莫凡反问陆家要对陆一林之死不满便冲我来、玩阴谋手段真当不敢撕破脸。陆辛威胁议员府邸可径直斩杀，莫凡不为所动，回头示意博拉指尖陷入陆斩天脖颈，陆辛慌喊住手。老熟人祝蒙赶来，劝莫凡看其薄面留陆斩天一条命，说军方已揪出违规军官、陆斩天罪名落实将坐牢，私自用刑反给陆辛把柄。陆辛本怒，见儿子惨状终妥协“留他一条命什么都好说”，莫凡却冷淡回“有点难”。

**关键事件**：1.莫凡拖陆斩天上门震慑陆家 2.陆辛暴怒威胁、被博拉反制 3.祝蒙劝留命、说陆斩天将坐牢 4.陆辛妥协、莫凡冷淡以对

**逐章写法公式**：

- **情绪流向**：起：上门立威的爽 → 承：陆辛威胁反被制的紧 → 转：祝蒙劝留命的缓 → 合：陆辛妥协、莫凡冷淡的悬
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：拖敌上门（立威） + 陆辛威胁被制（加压） + 祝蒙劝留（转圜） + 莫凡冷淡（钩子）
- **本章核心技巧**：用“拎敌首上门”的视觉立威开篇，再以第三方点破合法处置的利害收束，主角不松口留钩。
- **卡点与伏笔**：结尾卡点：莫凡说“有点难”，陆斩天生死未定；埋设/回收伏笔：陆斩天 Abuse 私刑将坐牢 → 下章陆辛知图腾玄蛇后彻底屈服伏笔。
