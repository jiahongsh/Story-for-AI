# 第1014章 戾剑死侍！

**概要**：赵满延说有莫凡打头阵事情变简单，国府队追着毒金木乃伊四处跑，莫凡、艾江图、穆宁雪三人尤为彪悍。众人发现坡后有军队发求救信号，被毒障困住，南珏令去援救。中央区域芬纳参谋见求救信号却冷令继续前进，南军统罗瓦尔不敢再提。罗瓦尔说高坡有最难对付的戾剑死侍，芬纳沉默。芬纳欲亲自出手，副官反对，因超阶法师仅三名各司其职。芬纳令二十分钟后抵高坡。高坡处莫凡孤身追十几头毒金木乃伊，用巨影钉困住超度后回头发现同伴不见。旁岩石后窜出浑身漆黑、持乌黑剑、眼透妖红光的戾剑死侍，莫凡好战脾气上涌，以雷拳对黑色X斩，千钧之雷与黑暗剑斩相斥。

**关键事件**：1.国府队追杀毒金木乃伊 2.发现军队求救信号芬纳令继续前进 3.罗瓦尔说戾剑死侍难对付芬纳欲亲自上 4.莫凡迷路独斗毒金木乃伊 5.遭遇戾剑死侍
