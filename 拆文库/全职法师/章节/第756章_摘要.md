# 第756章 勾魂者

**概要**：莫凡追上蒋少絮，宫田之事挥之不去，蒋少絮嫌其用幼稚手段失望，二人入西熊市，蒋少絮见居酒屋便拉莫凡小酌，老板露黄牙说日文、备清酒烤鱿鱼，莫凡指住处为山寺，老板闻是闫明寺骤然色变，压低声音称寺中发生过勾魂之事——年轻男子去后莫名昏厥一睡不醒、治愈法师难救，老人言其魂魄被勾。莫凡将信将疑，蒋少絮只当故事听，飞吻路人显狐狸精态。夜宵后二人回寺，见厢房电灯亮、人影走动，推门而入众人目光齐刷刷如见鬼，江昱称以为他俩失踪；莫凡扫视队伍却发现少了一人，浑身一冷——赵满延不在。

**关键事件**：1.居酒屋老板称闫明寺有勾魂之事 2.莫凡蒋少絮回寺，众人以为他俩失踪 3.莫凡发现赵满延不在

**逐章写法公式**：

- **情绪流向**：起：宫田余疑 → 承：居酒屋勾魂传说加压 → 转：回寺误会 → 合：赵满延失踪惊雷
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：追蒋少絮（过渡） + 勾魂传说（加压） + 回寺误会（误导） + 赵满延不在（爆发钩子）
- **本章核心技巧**：用"误以为A失踪"做误导性铺垫，再"真B失踪"反转收钩
- **卡点与伏笔**：结尾卡点：赵满延离奇不在（强悬念）；埋设/回收伏笔：勾魂之说 → 呼应赵满延昏迷；莫凡化名赵满延 → 前章伏笔
