# 第395章 图腾之怒（上）

**概要**：西湖苏堤冷风如呜咽，莫凡和灵灵听完全程悲愤难平之际，图腾玄蛇完全苏醒——伤势全消，换上青黑色光鳞，伤痕累累的旧皮囊脱落浸泡湖中，整体虽小了一圈却彻底摆脱虚弱、完成蜕皮。它同样听到了一切，怒视西面天空——它也是被罗冕陷害、差点成为瘟病替罪羔羊的受害者。得到莫凡"你想要报仇"的确认后，玄蛇升到俯瞰西湖的高度仰天怒吼，宣告扼杀它的敌人噩梦到来，整个西湖卷起滔天巨浪。莫凡明白罗冕手捏城市命脉、待其送回鹰红草便会如日中天，复仇刻不容缓；玄蛇向莫凡心灵传达听从之意——它记得最虚弱时是谁帮了自己，愿化作莫凡心中的怒火焚尽罪魁。灵灵通过标记的空间手环锁定罗冕在西要塞与总隔离区之间的小平原。玄蛇从西湖一飞冲天如夜龙破天，湖中现逆流瀑布奇观，再腾云驾雾掠过杭州上空，对即将冲破防线的白魔鹰军团看都不看，径直俯视小平原搜寻罗冕。灵灵提醒对方碰头的人不少，话音未落，玄蛇散去迷雾，盘山般的蛇躯笔直向地面砸去——它是图腾，放眼世界没几个生物能被它放在眼里。

**关键事件**：1.图腾玄蛇完成蜕皮，脱胎换骨恢复君主级威严 2.玄蛇与莫凡心灵相通，立誓同仇复仇 3.玄蛇载莫凡灵灵腾云直扑罗冕所在小平原

**逐章写法公式**：

- **情绪流向**：起：悲愤未平的沉郁 → 承：蜕皮焕新的振奋 → 转：同盟缔结的狂喜 → 合：直扑目标的酣畅
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 35% / 悬念留白 15%
- **本章结构公式**：悲愤承接（情绪延续）+ 蜕皮归来（力量到位）+ 心灵同盟（意志合一）+ 腾云赴杀（行动发起）

- **卡点与伏笔**：结尾卡点：决战钩子——玄蛇携怒直砸罗冕所在的多人集会，正面冲撞一触即发；埋设伏笔：玄蛇蜕皮后整体变小 → 形态变化的后续影响；心灵相通的契约 → 人蛇长期同盟；罗冕与不少人碰头 → 敌方阵容悬念；白魔鹰军团即将破界入城 → 并行危机线
