# 第1107章 老子不轰趴他们？

**概要**：中国与德国战队激战正酣，南珏被瑞迪的穿透型毁灭魔法击退后，江昱上场以进阶统领级的巨岩将军充当肉盾，却被乔森的黑暗之蚀与重力层层瓦解；瑞迪的森绿闪电可无视防御，江昱隐忍至被轰伤才令夜罗刹突袭其脖颈要害，却被乔森以地波精准挪走瑞迪化解。暴怒的瑞迪落下天焰葬礼地狱火，艾江图全力瞬息移动救援、以意念空间硬扛，仍被穿透将穆婷颖冲撞结界判定出局；南荣倪随后上场以治愈术令全员恢复，瑞迪却化作雷暴炸药桶持续碾压，赵满延渐无魔具可用。封离命莫凡准备上场，牧奴娇加油，莫凡放言要轰趴德国。

**关键事件**：1.南珏遭瑞迪穿透魔法击退，江昱携巨岩将军上场 2.乔森腐蚀并重力压垮岩石将军，夜罗刹刺杀瑞迪被救 3.瑞迪地狱火将穆婷颖判出局，南荣倪治愈全员 4.封离令莫凡上场待命

**逐章写法公式**：

- **情绪流向**：起：赵满延被困的焦虑 → 承：江昱顶上又被瓦解的加压 → 转：瑞迪地狱火判出局的爆发 → 合：南荣倪治愈后莫凡待命的钩子
- **节奏配比**：慢铺垫 30% / 快冲突 45% / 爽点爆发 10% / 悬念留白 15%
- **本章结构公式**：南珏退场露德国穿透（设危） + 江昱巨盾被乔森破解（加压） + 夜罗刹刺杀被救（反转失败） + 地狱火判出局南荣倪治愈（谷底） + 莫凡待命（钩子）
- **本章核心技巧**：用瑞迪的"穿透"特征贯穿全章，让每一场压制都回扣同一设定，使危机有据可循
- **卡点与伏笔**：结尾卡点：莫凡上场预告，下章四人围殴；埋设/回收伏笔：乔森地波挪人→后续坐实其为德国最强人物
