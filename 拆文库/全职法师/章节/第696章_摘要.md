# 第696章 亡潮褪去

**概要**：混沌之穴将合力一击尽数吸收，神秘灰白人提醒众人这股力量会被打回，韩寂则察觉山峰之尸头顶那人气息古怪危险。山峰之尸竟缓缓蹲跪下来载着那人，那人一身乌黑邪气铠袍与古老王羽化画卷吻合，神秘灰白人认出是古老王，众人面如土色。莫凡平视看清那张脸竟是总教官斩空，铠袍人扬手再开混沌之穴，翻转旋风吐出昏迷的柳茹、张小侯、苏小洛，莫凡跃起将三人救回信号塔。斩空冷漠转身离去，山峰之尸载其北去，八方亡君率领亡灵大军随之远去，内城之外黑色汪洋渐渐消失，幸存之城在阳光下沉寂。

**关键事件**：1.混沌之穴反吞合力攻击，韩寂察觉尸顶人危险 2.山峰之尸下跪载乌铠袍人，众人认出古老王 3.莫凡看清是斩空，混沌之穴吐出柳茹张小侯苏小洛被救 4.斩空离去亡灵随退，内城浩劫结束

**逐章写法公式**：

- **情绪流向**：起：合力落空的错愕 → 承：铠袍人威压与古老王疑云 → 转：认出斩空与救回三人的震动 → 合：亡潮褪去、浩劫终结的余波
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：混沌反吞合力（悬念） + 山峰之尸下跪臣服（烘托） + 莫凡认出斩空救三人（反转） + 斩空离去亡灵退潮（收束）
- **本章核心技巧**：用反派臣服与角色直视完成身份揭晓，再回收伏笔反转用途
- **卡点与伏笔**：结尾卡点：收束型——浩劫结束但斩空是否存活成谜，下章众人反应；埋设/回收伏笔：混沌之穴→救回三人，斩空铠袍→古老王身份
