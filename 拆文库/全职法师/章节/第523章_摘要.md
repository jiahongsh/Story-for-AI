# 第523章 尸堆暴袭！

**概要**：入夜未久尸物暴起，陆红京双腿被钢钎般的尸手扼住啃咬，膝盖以下转眼只剩白骨。张小侯第一时间用地波把土地凝成岩石，凝固住尸爪，王童踏风轨把他扛回队中。成片人形亡灵破土而出，有的由兽骨拼成骷髅巨人，有的兽身安着人头，全都在拼命凑成人形。石少菊判断死气浓烈遮蔽了阳光，尸物未等天黑透便出土。队伍没有治愈系法师，陆红京只能包腿止血、拖命续行。张小侯自告奋勇开路，石少菊以坤之林困住一群尸物，众人紧跟张小侯，他走过之处土地即固化成石，全力赶往四公里外的羊阳村。

**关键事件**：1.陆红京双腿被尸手啃成白骨，张小侯地波凝石救下他 2.成片人形亡灵破土出世，石少菊解说死气遮蔽阳光 3.张小侯自告奋勇开路，队伍加速奔赴羊阳村

**逐章写法公式**：

- **情绪流向**：起：尸手咬腿的惊变 → 承：地波凝石的急援 → 转：亡灵群出世的恐怖 → 合：开路疾行的紧张
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：陆红京遇袭（惊变）+ 张小侯救场（立功）+ 亡灵成因说明（规则）+ 开路上路（转移）
- **本章核心技巧**：危机开场先伤一人立血仇，再用灵种功能性化解围困
- **卡点与伏笔**：结尾卡点：四公里外的羊阳村能否带来安全，村中避亡灵之法存疑；埋设/回收伏笔：无治愈系的困境 → 为陆红京伤情恶化埋线
