# 第944章 纳斯卡地画！

**概要**：直升机飞往纳斯卡途中，众人从高空俯视才发现橙红色大地上铺着巨幅地画——先是猿猴之画，与袭击矿脉的怪猿一致；继而发现更巨大的怪鸟之画和精细的蜘蛛之画，震撼不已。莫凡想起灵灵的情报仍觉不可思议。艾江图驾驶生疏，直升机剧烈摇晃砸落地面。众人在地画中步行寻找却一无所获，风餐露宿三天无进展。深夜他们看到怪猿地画泛白光、蜘蛛地画泛红光并有蛛群爬动。清晨南珏召唤众人上山顶，借晨光发现怪鸟地画眼睛位置黯淡——原本镶嵌的宝石眼睛被人盗走，纳斯卡因而降下厄运，而盗窃者就在近期闯入禁地者之中。

**关键事件**：1.高空俯视发现猿猴、怪鸟、蜘蛛三幅纳斯卡巨画 2.艾江图生疏驾驶致直升机坠地 3.地画中寻宝三天无果，深夜见异象 4.南珏发现怪鸟地画眼睛缺失，推断宝石被盗引发厄运

- **情绪流向**：起：飞行好奇 → 承：高空巨画震撼 → 转：寻宝落空压抑 → 合：眼睛缺失揭谜留钩
- **节奏配比**：慢铺垫 35% / 快冲突 10% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：空中俯视见三画（展奇） + 坠机落地找无获（加压） + 三日露宿见异象（蓄势） + 山顶发现眼缺失（揭谜）
