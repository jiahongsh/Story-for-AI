# 第1609章 制裁伊森！

**概要**：莫凡当面骂伊森是自己见过最恶心的人，伊森狂妄宣称能拖他下地狱的全在他所属的阶级里、莫凡不够格也无力让国际法庭制裁他。莫凡自知国际法庭深陷权力泥潭、自己又无恶魔之力杀不了这位超阶军首，便唤出阿帕丝——命她给伊森建造一座地狱。伊森仍以为阿帕丝只是把莫凡当玩物，却被她金粉色蛇瞳骤然施展美杜莎诅咒：整个开罗蛇瞳诅咒大蛇母的力量源头正是她。伊森虽为超阶强者却非精神类高手，诅咒深深烙入灵魂，他跌入泳池，幻觉中养母惨死鬼脸索命——那是他军途上升时为保威望封锁掩盖的旧案。阿帕丝宣告这诅咒会在他最心安理得时浮现他真正恐惧之事，莫凡补充每增一分罪恶诅咒便增强一分，待他自首洗净罪孽方可解除。伊森暴怒爆出四种元素之力欲杀莫凡，阿帕丝挺身一站、金粉瞳辉将其气势压成萤火，伊森颓然坐倒。莫凡认为这种制裁比杀了他更妥当——他掌握军部，暴毙反伤开罗；事后阿帕丝要求解除契约，莫凡拒绝，自称把她当路边捡到的小妹妹并要正式教她魔法，气得阿帕丝暗骂他比伊森可恶十倍百倍。

**关键事件**：1.阿帕丝对伊森施展美杜莎诅咒，令其夜夜活在恐惧与悔恨中 2.莫凡借阿帕丝之威镇压伊森暴怒 3.莫凡拒绝解除契约并要正式教阿帕丝魔法

**逐章写法公式**：

- **情绪流向**：起：对质伊森的愤怒 → 承：命令阿帕丝出手的爽利 → 转：金瞳诅咒镇压的痛快 → 合：契约不肯解的逗趣收尾
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：理念对峙（攒怒气）+ 召唤惩戒（亮底牌）+ 诅咒立威（打爆反派）+ 契约留白（收人物关系）
- **本章核心技巧**：把"主角制裁不了强敌"的困局交给新收的契约兽破解，兑现前文埋的战力
- **卡点与伏笔**：结尾卡点：状态+伊森是否会在诅咒折磨下自首、阿帕丝教魔法是否暗藏心机；埋设/回收伏笔：蛇瞳诅咒机制 → 伊森后续下场；美杜莎之母后裔身份 → 阿帕丝身世后续展开
