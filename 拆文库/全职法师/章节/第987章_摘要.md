# 第987章 水母歹蛆

**概要**：灵灵与莫凡抵达诺科死亡现场，灵灵以空间系魔法隔绝现场气味并阻止警方与魔法协会过早介入，随后将铁盆边沿的皮屑收进真空袋带回研究。她坚持解剖鲍比弟弟诺科的尸体以查明死因，鲍比虽因亲弟弟心理障碍强烈反对，仍被莫凡以查出真凶说服。对饮中莫凡得知诺科一周前开始失常、近期胃口异常变好，联想到之前探访的其他死者家属也提过类似情况，便派穆宁雪风系走访，确认所有溺咒死者生前食欲均增至一到两倍。灵灵解剖后指出诺科身体实则虚弱如十几日未进食，体表肿胀只是体内积水假象。她用过滤网滤出血中蠕动的透明血块，水冲后血块消失，滤网上仅余一只拇指大、近乎透明的蛆——水母歹蛆幼体。灵灵推断歹蛆为可塑胚胎、可成长成任何生物包括人，正是溺咒根源，鲍比怒斥，灵灵称需考证，并担忧海边巨骨是其所为。

**关键事件**：1.灵灵抵达现场采集皮屑并决定解剖诺科 2.穆宁雪走访证实所有溺咒死者食欲大增 3.灵灵从血中滤出透明水母歹蛆幼体并推测其为溺咒根源

- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 0% / 悬念留白 50%
