# 第1007章 走出迷界

**概要**：视角切好望角魔堡超阶法师戴文率队乘翼兽赴撒哈拉，于金沙地发现昏迷的南珏。南珏苏醒后说遇怪物袭击、同伴仍在迷界，戴文队伍将其带回。与此同时江昱召唤巨犀后蒋少絮心灵恐慌起效，沙怖狐退却；天空忽升南珏的魔法信号，五人趁机狂奔，却被两族倾巢追击。莫凡殿后潜走，众人冲出迷界见南珏与戴文等魔法师，身后却跟着两大族群，全员转头借戴文风舟极速逃离。南珏得知五人始终未挪动、坚守坐标才走出，戴文赞这是唯一正确选择。莫凡说仅见帐篷碎片，戴文嘱盼失踪者亦坚守坐标，并问及南珏所述一团沙尘中的瞳孔怪物。

**关键事件**：1.戴文队救起昏迷南珏 2.五人借信号冲出迷界、风舟逃离 3.戴文赞坚守坐标、问瞳孔怪物

**逐章写法公式**：

- **情绪流向**：起：戴文救南珏的平行线 → 承：信号升起与脱困铺垫 → 转：两族追击与风舟逃 → 合：坚守正解与怪物钩子
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：戴文救南珏（平行线） + 信号脱困（汇流） + 风舟逃命（高潮） + 坚守正解（收束）
- **本章核心技巧**：用久候信号引爆双线汇流脱困，再用权威回扣给角色定力正名
- **卡点与伏笔**：结尾卡点：类型悬念+沙尘中瞳孔怪物是什么引下章；埋设/回收伏笔：南珏遇袭怪物→沙暴怨灵伏笔
