# 第326章 撕碎陆年

**概要**：恶魔莫凡将浑身雷电凝成长矛，一击烧穿陆年的金色软甲、贯穿其胸膛。陆年摸向胸前焦洞的手被电得焦黑却感觉不到疼痛，生命疯狂流逝，他至死不解这股本应为自己所用的力量为何先杀死自己，仰面倒下时蔚蓝天空中印着莫凡血纹的脸。莫凡随即放出数之不尽的狼之影爪，凌迟陆年脱离躯壳的灵魂并将其撕成碎片，令他连化作亡魂的机会都没有，灵魂碎片被吸入如冥河般飘荡妖魔亡魂的小泥鳅坠中，坠子颤动间莫凡能听见陆年灵魂的痛苦嘶吼，入坠亡魂终将被炼化。杀敌后莫凡脑海一半空白一半狂暴，斩空注视却不敢靠近；他因认得这位博城总教官而未攻击，紧接着血利子的精神冲击爆发，莫凡如野兽嘶吼、火焰雷电失控狂舞，发狂得想把自己的脑袋撕成两半。斩空告知恶魔系无法成为真正魔法系正因副作用巨大——它提前透支灵魂潜藏的能量换取短暂战力，莫凡的灵魂很可能被冲垮；莫凡保存着一些理智，问出"告诉我，我要怎么做"。

**关键事件**：1.雷电长矛贯穿陆年胸膛将其杀死 2.影爪撕碎陆年灵魂，吸入小泥鳅坠炼化 3.血利子副作用爆发，莫凡濒临失控 4.斩空讲解恶魔系代价，莫凡开口求救

**逐章写法公式**：

- **情绪流向**：起：热血（雷电长矛成形）→ 承：爽（贯穿胸膛、陆年毙命）→ 转：恐怖（影爪撕魂、冥河炼化）→ 合：紧张（血利子副作用爆发，向斩空求救）
- **节奏配比**：快冲突 40% / 爽点爆发 25% / 悬念留白 25% / 慢铺垫 10%
- **本章结构公式**：雷电长矛贯穿（终结仇敌）+ 影爪撕魂入坠（超额复仇与炼化设定揭示）+ 杀敌后空白狂暴（情绪余波）+ 精神反噬爆发（新危机压顶）+ 向斩空求教（下章钩子）
- **本章核心技巧**：复仇高潮刚落幕立刻用"副作用爆发"接续压力，爽点不留回味直接转入生存危机，情绪链不断档。
- **卡点与伏笔**：结尾卡点：危机卡点——恶魔化副作用足以把灵魂打散，莫凡强撑理智问"我要怎么做"，下章期待自救或获救之法；埋设伏笔：小泥鳅坠吸纳炼化陆年之魂→ 坠子吸魂能力的再次确认；血利子副作用 → 恶魔系的长期代价线。
