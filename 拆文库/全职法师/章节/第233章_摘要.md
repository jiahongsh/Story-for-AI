# 第233章 一网打尽！

**概要**：司夜统治把战场分割成无数黑暗小密室，学员星子不安、无法远望，才惊觉暗影妖兽被带走也无人知晓。宋霞向白藏锋一伙解释这是校方防伤亡的大阵，并透露她早在莫凡甩兽时给妖兽打了魔法印记可循迹追踪；沈明笑与罗宋困在黑暗中怒骂，身旁已有人闻到翔味、看见爬行的猴鬼脸怪物。莫凡原地未动，心中定策：司夜统治压制不了暗影系的他，遁影之术可来去自如，这黑暗既是黑教廷的保护伞也是囚牢，今夜一个也别想活着出去。真相揭晓——他从未把吸收了地圣泉的小泥鳅坠抛进妖兽腹中，只让小泥鳅坠分解出一小滴地圣泉作饵。小泥鳅坠发光指引方向，莫凡循光穿墙寻兽，却发现方向不断变动、原地不动光也增强，暗影妖兽挣脱捆锁狂奔而过，身后是黑教廷唤出的黑畜妖群在追猎。莫凡冷笑：跟着暗影妖兽就能把他们一网打尽。

**关键事件**：1.宋霞凭魔法印记率队寻兽 2.莫凡借小泥鳅坠指引进迷宫猎敌 3.暗影妖兽挣脱、黑畜妖群猎追，莫凡决意一网打尽

**逐章写法公式**：

- **情绪流向**：起：恐怖（黑暗迷宫分割全场） → 承：紧张（宋霞印记、黑畜妖现身） → 转：爽（莫凡揭底反为主场猎人） → 合：紧张（妖兽狂奔、群敌猎追，杀局铺开）
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：群像陷阵（规则生效） + 双线追踪（宋霞印记与莫凡指环） + 真相揭底（饵中饵） + 兽逃妖追（杀局合拢）
- **本章核心技巧**：把上一章压制全场的环境大阵翻转成主角的主场优势，同一环境在不同阵营眼中的意义截然相反
- **卡点与伏笔**：结尾卡点：追猎卡点——黑畜妖群追暗影妖兽、莫凡暗中尾随，下章期待黑暗中的猎杀开场；埋设/回收伏笔：小泥鳅坠分解地圣泉一滴 → 地圣泉真身仍在莫凡处；宋霞魔法印记 → 她可能撞破黑教廷杀局；沈明笑罗宋困阵 → 后续遭遇伏笔
