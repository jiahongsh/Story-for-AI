# 第878章 善变之人

**概要**：赵品霖搂着汪栩栩大摇大摆走进餐厅，亲密程度像相恋已久。同学纷纷起哄询问昨夜细节，荣盛脸上的幸福笑意瞬间凝固。他追问汪栩栩为何昨夜答应自己今晨却跟赵品霖一起，汪栩栩低声称昨夜只是迁就他、其实与赵品霖才是一路，荣盛如遭雷击。同学劝慰荣盛"当做了个梦"。事后郭文衣找到莫凡，出示汪栩栩深夜发给自己的短信——里面汪栩栩分明更中意荣盛、觉得赵品霖不安全，可今晨却判若两人；郭文衣说汪栩栩一直死拽袖口、显得很害怕，怀疑她被要挟、像变了个人，莫凡暗暗记下。

**关键事件**：1.赵品霖搂汪栩栩入场引同学起哄 2.汪栩栩称只是迁就荣盛，荣盛如遭雷击 3.郭文衣示汪栩栩短信曾中意荣盛 4.郭文衣疑汪栩栩被要挟，莫凡暗记

**逐章写法公式**：

- **情绪流向**：起：亲密入场的错愕 → 承：汪栩栩改口的解释 → 转：荣盛如遭雷击的虐心 → 合：郭文衣揭短信疑被要挟的悬念
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：搂人入场起哄（爆点） + 汪栩栩称迁就荣盛（反转） + 荣盛崩溃同学劝（虐点） + 郭文衣揭短信疑胁迫（钩子）
- **本章核心技巧**：用"甜蜜短信 vs 当场改口"的第三方证据，把情感反转写成悬疑而非狗血。
- **卡点与伏笔**：结尾卡点：莫凡暗记汪栩栩"害怕、可能受要挟"，下章期待他如何查赵品霖；埋设/回收伏笔：汪栩栩深夜短信 → 本章功能（证其非善变，坐实被胁迫）；拽袖口恐惧 → 伏笔（赵品霖威胁线，后续黑教廷手段回收）
