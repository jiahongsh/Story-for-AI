# 第106章 诛杀翼苍狼！

**概要**：莫凡严肃解释没开玩笑——带着温泽四散的地圣泉就像唐僧肉吸引各方妖魔，不敢扔怕出大事，正好口干舌燥一口气喝得一滴不剩，说着掏出空瓶抛给斩空。斩空接瓶细看，表情从未有过的丰富，退后几步免得摔下去，无奈说换作灾难之前这种奢侈够上火刑架，但他和穆卓云、杨作河等人本就只求地圣泉别落入黑教廷，它日后终会枯竭，保住博城才是重中之重；莫凡咧嘴说黑教廷找到他，抛开尸体最多找到一泡腥臭的尿。斩空心中未必全信，却决定就算私藏也当是莫凡救城的奖赏。确认要面对的只剩一只统领级翼苍狼，斩空目如闪电高喝听令，九名中阶部下换军姿铿锵齐应"诛杀翼苍狼，不死不休"。斩空跃下瞭望台，米白色的风之翼豁然展开，九只载着军官的天鹰紧随飞向银贸大厦，安全结界内响起守卫者如雷欢呼——灾难终于要有了断，魔法师的天职便是斩尽入侵妖魔。受保护人群中，茶色少年张小侯从何雨死后黯淡的眼睛重燃火焰，默念要让舍身救他的女孩看到弱男孩将来成为镇守一城的军法师，握拳找到了方向。莫凡下塔偶遇女教官潘丽君，得知安界外不少洞窟有明显挖掘痕迹、妖魔靠地通越界入城且入口位置无人知晓；他脑中电闪——挖掘力极强的巨眼猩鼠！近一年猩鼠猖獗，博城的灾难早有预兆。

**关键事件**：1.莫凡交出空瓶，地圣泉悬念就此了结 2.斩空率九名中阶军法师誓师跃塔，出击诛杀翼苍狼 3.莫凡从洞窟挖掘痕迹推断妖魔入口与巨眼猩鼠有关、灾难早有预兆

**逐章写法公式**：

- **情绪流向**：起：轻松（空瓶与腥臭尿玩笑） → 承：热血（誓师出击、风之翼与天鹰） → 转：热血（张小侯重燃方向） → 合：紧张（妖魔入口未解、灾难早有预兆）
- **节奏配比**：慢铺垫 30% / 快冲突 10% / 爽点爆发 40% / 悬念留白 20%
- **本章结构公式**：空瓶收线（了结宝物悬念）+誓师跃塔（集结爆发）+少年觉醒（余波升华）+入口情报（新谜开局）
- **本章核心技巧**：用誓师仪式与风之翼的视觉奇观把阶段性情绪推到顶点，再借配角觉醒与新情报把情绪落点转成下一阶段的钩子，高潮与转场一气呵成。
- **卡点与伏笔**：结尾卡点：推谜悬念——妖魔地下入口在哪里、如何填埋摧毁；埋设/回收伏笔：回收近一年巨眼猩鼠猖獗（前文猎妖日常）→黑教廷预谋的时间线证据；风之翼+九天鹰出击→诛狼战役战果待下章揭晓；张小侯立志成为军法师→人物长期路线；潘丽君眉宇间不散的哀伤→军部战损伏笔。
