# 第505章 心灵系VS心灵系

**概要**：鬼妇白布崩裂露出烧焦面孔，南珏提醒众人其第三系为土系。鬼妇施展高阶石化之瞳，灰白阴影掠过之处木屋水花尽数凝结成石，直逼莫凡、心夏、赵满延三人。赵满延先后以光佑画壁、盾魔具、水御-循环硬撑，张小侯补上岩障，穆家兄妹穆休、穆亭乐以冰锁、冰蔓参战，冰霜冻住岩石遏制了石化蔓延。鬼妇转以心灵系厉鬼尖叫散播恐惧，扰乱众人施法，心夏识破后施展心灵系初阶魔法灵漪-安抚净化心神，再度化解鬼妇的袭击，鬼妇恼羞成怒却无计可施。

**关键事件**：1.鬼妇施展石化之瞳险些团灭众人 2.穆家兄妹冰系参战压制石化 3.心夏灵漪-安抚破解恐惧

**逐章写法公式**：

- **情绪流向**：起：慌张 → 承：石化逼近的绝望 → 转：冰系反制 → 合：恐惧再袭被安抚化解
- **节奏配比**：慢铺垫 30% / 快冲突 50% / 爽点爆发 10% / 悬念留白 10%
- **本章结构公式**：南珏预告弱点（铺垫） + 石化之瞳爆发（加压） + 多系防御接力（抵抗） + 心灵系反制（破解）
- **本章核心技巧**：用队友轮流救援的防御接力拖住高阶魔法，再以克制系当众反制，把必死局翻成僵局
- **卡点与伏笔**：结尾卡点：鬼妇心灵系再被破解、恼羞成怒扬言报复，下章期待她如何变招；埋设/回收伏笔：鬼妇提及火劫果实，南珏提及鬼妇杀害其教官的旧仇
