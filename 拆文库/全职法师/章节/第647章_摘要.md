# 第647章 封神盛典

**概要**：莫凡发现煞渊正在一步步接近内城，祝蒙回忆它曾从沙惘河、咸池和北外城逐渐靠近，判断下一次空间漂移就会让百万避难者全部死亡。穆贺宣布这将成为撒朗以城市覆灭、百万人和法师高层的绝望完成封神的盛典。韩寂终于崩溃，跪下请求撒朗放过城中居民。神秘灰白男子意识到魔法协会完全落入黑教廷的计划，但此时一名禁卫法师送来暗号纸条，带来可能的希望。神秘男子与韩寂确认消息可信，决定放手一搏。

**关键事件**：1.煞渊逼近内城 2.穆贺解释撒朗的封神盛典 3.韩寂向撒朗哀求 4.神秘灰白男子判断计划失败 5.暗号带来新希望 6.众人决定放手一搏

**逐章写法公式**：

- **情绪流向**：起：空间逼近 → 承：反派封神宣言 → 转：韩寂崩溃 → 合：暗号到来，行动重启
- **节奏配比**：慢铺垫 20% / 快冲突 25% / 爽点爆发 5% / 悬念留白 50%
- **本章结构公式**：确认煞渊轨迹（量化末日） + 宣布封神盛典（揭露反派目标） + 韩寂跪求（压低情绪） + 暗号送达（恢复行动）
- **本章核心技巧**：把宏大末日转换成反派的仪式叙事，再用一张小纸条切断绝望并重新启动主角线。
- **卡点与伏笔**：结尾卡点：神秘人获得绝对可信的新情报，众人决定放手一搏；埋设/回收伏笔：煞渊三次漂移位置 → 确认其下一步将进入内城。
