# 第521章 亡灵之冢

**概要**：莫凡从萧院长处得知世界学府大赛有他一个坑，起初毫无反应，等选人如火如荼才意识到这名额千金难换，但他既来之则安之，借战胜丁雨眠换来的一月七天三步塔机会安心修炼召唤系，计划把小炎姬喂起来。场景切到古都：千年亡魂积郁，掘地百米必有骨，亡灵只剩饥饿杀戮本性，魔法协会、猎者联盟、军方每月忙于超度。张小侯赶回临潼军区即领任务：勘测队前往咸池调查亡灵滋长、遣散村落，因沙惘河躁动四村一夜消失，勘测队又发现猩风后失踪近两月，上头令张小侯的九人军官特别组确认死因、找回遗体。斥候王童一路抱怨，队长秦虎乘天鹰开路。

**关键事件**：1.莫凡从萧院长处得知内定名额，计划借三步塔修炼召唤系 2.铺陈古都亡灵世界的规则与警戒格局 3.张小侯领命营救失踪的咸池勘测队，九人军官队开拔

**逐章写法公式**：

- **情绪流向**：起：莫凡对名额的淡然 → 承：修炼计划的心安 → 转：古都亡灵背景的压抑 → 合：张小侯接任务的紧张
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：莫凡修炼日常（承接上章）+ 古都规则铺陈（新地图）+ 任务发布（新线）+ 队伍成员亮相（群像）
- **本章核心技巧**：用一条闲笔收束莫凡支线，再以勘测队失踪案开启新副本
- **卡点与伏笔**：结尾卡点：队伍开拔进亡灵之地，前路未知；埋设/回收伏笔：勘测队失踪、沙惘河躁动 → 本章立起救援任务主线
