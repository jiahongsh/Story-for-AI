# 第1363章 秃鹰下的幸存者

**概要**：帕特农神庙神女殿，雅典城阴云低垂，心夏望着窗外无心言语，她通过小炎姬共心感知到莫凡的气息极弱，躺在一堆尸体之中，疲惫得连挪动身体都做不到，若再有黑教廷的人出现必死无疑。塔塔宽慰她，说莫凡不会轻易将性命交给命运，又转开话题——她们查过伊之纱的复活并非帕特农神庙的复活神术，更可能与埃及法老源泉有关，是用了某种埃及妖术。画面切回北疆硬土，一百多具尸体横陈，秃鹰盘旋试探后开始啄食，发现一个尚有气息的人，便围着他啄脸啄胸，那人任由秃鹰啃食，抓过旁边尸体上的灰蓝色衣袍套上，又用指甲引动黑暗之气在自己胸口划出印记。一对灰蓝衣裳的男女蓝衣执事随后而至，议论被审判会盯上、牧羊人与蓝衣鹰瞳被杀的损失，提及乌纳斯亲自下达的任务。女蓝衣发现尸体中的活口也是一位蓝衣，胸口黑暗印记被鹰啄花，男蓝衣言明说不出代号便杀了他，那人拼尽力气吐出"北鹿"二字——正是冷爵大人提过的杰出新人。男蓝衣为补人手勉为其难决定救他。

**关键事件**：1.心夏经小炎姬感知莫凡气息极弱、倒在尸堆之中 2.塔塔透露伊之纱复活与法老源泉有关的线索 3.重伤的莫凡假扮蓝衣"北鹿"，引动黑暗之气自划印记 4.男女蓝衣执事验明"北鹿"身份，决定救下他

**逐章写法公式**：

- **情绪流向**：起：神女殿的牵挂 → 承：尸场的惨烈 → 转：秃鹰啄食的惊悚 → 合：身份过关的险胜
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 10% / 悬念留白 45%
- **本章结构公式**：心夏感知危局（远程牵挂）+ 秃鹰尸场（实景惨烈）+ 自划印记伪身份（暗手布置）+ 蓝衣验明北鹿（过关即入局）
- **本章核心技巧**：用两条线交替推进——神庙牵挂线与战场自救线，让莫凡的绝境在他人视角下加倍揪心，再用身份过关完成章尾钩子
- **卡点与伏笔**：结尾卡点：入局式——莫凡以蓝衣"北鹿"身份被救入黑教廷任务组；埋设/回收伏笔：乌纳斯亲自下达的任务、牧羊人呼唤多只冥君蛙 → 下章冥界之门阴谋
