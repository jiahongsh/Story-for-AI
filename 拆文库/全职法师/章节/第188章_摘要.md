# 第188章 封锁隔离

**概要**：赵满延建议莫凡直接用霹雳轰杀，莫凡拒绝——霹雳威力太强会连同肉身毁掉，他不想成为杀人犯；瓜子脸女生提醒女妖撞到光系魔法后便自己蜕皮，恐怕很怕光。门随即被六只女妖撕开，三人暴露。赵满延以最低级的1级光耀·净化射入一只女妖口中，光在其体内炸出针尖般的光芒，灼燃其体内寄生血液，女妖自撕鳞片倒地——莫凡震撼于自己费力击杀的对手被一个光耀秒杀。四只女妖飞扑众人，莫凡想起朱校长说过血兽靴可主动施展一次力踢山石，回旋飞踢以血色波动放大十倍之力将一只女妖踢得头骨碎裂横飞楼道；瓜子脸女生施放冰蔓·覆盖冻住地板墙壁令女妖行动迟缓，赵满延快速补刀再灭一只，三人有惊无险清场。莫凡由金色护盾确认赵满延是中阶光系，问他新生斗兽大赛为何不出手，赵满延自嘲光系单挑就是免费沙包。此时楼内响起自动门启动声，灵灵告知：校方和猎者联盟已封死体育馆所有出口，实行封锁隔离——包括莫凡在内，任何携带寄生血的人都不能出去。

**关键事件**：1.三人合力歼灭六只女妖，光系克制鳞皮妖兵的战术成型 2.血兽靴"力踢山石"首次主动施展显威 3.校方与猎者联盟封锁体育馆所有出口，莫凡被隔在疫区内

**逐章写法公式**：

- **情绪流向**：起：紧张（拒用霹雳、门被撕开） → 承：爽（光耀秒杀、飞踢碎颅） → 转：轻松（战术成型、队友斗嘴） → 合：压抑（出口尽封，全员困于疫区）
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：设限对峙（打出克制战术）+三人团战（各自技能首秀）+身份确认（队友底牌摊开）+封锁宣告（局势急转收尾）
- **本章核心技巧**：把团队首战写成"技能说明书连放"，每个角色用一个高光镜头立住功能位，再用结尾的封锁翻转压掉胜利余韵。
- **卡点与伏笔**：结尾卡点：困局——所有出口封死、莫凡也在隔离区内，退路归零；埋设/回收伏笔：光系克鳞皮→战术核心验证；朱校长血兽靴提示→主动技兑现；赵满延中阶光系→新生斗兽大赛隐忍的缘由；瓜子脸女生冰系→第三人功能位；封锁隔离→下一章高层决策视角。
