# 第529章 煞渊，万尸坑（上）

**概要**：本章先说明亡灵可借死气滋养，或通过拼凑、吞噬尸骸获得生前能力。以贾曦头颅拼成的刀斧尸将因保留人类视觉和强烈怨念，认出秦虎等八名军官并号令群尸围杀。逃亡中陆红京被腐尸吞没，石少菊要求张小侯不要回头救援；队长秦虎随后遭尸将贯穿，临死仍提醒张小侯继续逃。张小侯在无力救人的愤怒里渴望晋升高阶，失神冲向前方时又撞见地面塌陷形成的深渊，并在坑底看见难以置信的恐怖景象。

**关键事件**：1.刀斧尸将以贾曦怨念锁定军官并驱使群尸追击 2.陆红京与秦虎接连殒命，张小侯被迫逃离 3.张小侯在逃路尽头发现塌陷深渊

- **情绪流向**：起：紧张 → 承：压抑 → 转：悲伤 → 合：悬念
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：解释尸将异常能力（建立追杀理由） + 群尸围猎与队员掉队（连续加压） + 秦虎临终警告与张小侯自责（沉淀代价） + 地表塌陷显露深渊（切换更大危机）
