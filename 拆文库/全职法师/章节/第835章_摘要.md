# 第835章 精壮如牛

**概要**：一千两百万对刚入中阶是巨款，对巅峰中阶却杯水车薪——冲击高阶的星河之脉一份至少一亿。休战期穆宁雪大清早赴东京拍卖会，却苦笑发现国内星河之脉约一亿、东京竟要一亿一千万，东海城苦战所得刚抵消浮动差价，前路渺茫。她清楚队里不少人中阶巅峰早已摸至高阶或高阶，换人机制临近，背后势力会把星河之脉"当不要钱砸"，到时还停留在中阶的只怕只剩她一人；国府真正的竞争在队内，每抵一地便取代一到两人。满心忧郁回到东海城，她推门见床铺上躺着个男人正要发火，却发现自己走错了、进的是莫凡房间——满屋是他的衣服袜子。穆宁雪借口"看腰伤"圆场，莫凡手忙脚乱藏起女优网页，称肾无碍。莫凡隔空移物将臭袜子扔出窗外，邀她去卖场淘宝。莫凡穿内裤扑进浴室，穆宁雪气得银牙咬碎。待二人同行，莫凡前日重伤此刻却生龙活虎，穆宁雪疑其装伤；原来恶魔系虽无新魔法，却赋予远超妖魔的康复体能，莫凡两三天便可自愈，只是这能力战时无用，且相关力量他不轻易用。

**关键事件**：1.佣金不够买星河之脉、穆宁雪赴东京价更高 2.队内取代机制、忧仅己滞留中阶 3.误入莫凡房、臭袜扔窗、卖场之约 4.莫凡康复过快、恶魔系体能揭秘

**逐章写法公式**：

- **情绪流向**：起：资源鸿沟的沉 → 承：离队危机的忧 → 转：走错房的笑 → 合：恶魔系揭秘的奇
- **节奏配比**：慢铺垫 30% / 快冲突 5% / 爽点爆发 5% / 悬念留白 25% / 搞笑 35%
- **本章结构公式**：价高愁钱（沉） + 取代机制忧（压） + 走错房笑（松） + 恶魔系揭秘（奇）
- **本章核心技巧**：用"经济困境+制度危机"压住，再用误入房间的喜剧与恶魔系揭秘做情绪释放。
- **卡点与伏笔**：结尾卡点：恶魔系能力莫凡不轻易用，下章期待其底牌何时亮；埋设/回收伏笔：恶魔系 → 第六系，承接前文"以身引雷/邪珠"伏笔，正式点明体系。
