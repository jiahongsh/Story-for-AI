# 第157章 进阶期幽狼兽（上）

**概要**：明珠学府斗兽大赛上，李俊巍作为五人挑战团队代表叫莫凡放出召唤兽。莫凡喊出"为我而战"，幽狼兽从次元裂痕中踏出，成年健壮的形态与之前那只小幽狼兽判若两物，围观学员惊呼，召唤系老师蒋云明在后台自语它好像比上次更强。李俊巍五人摆出风系在前、水系在后、雷火两翼、土系坐中的五元之阵，开战前李俊巍逐人交代战术：提醒大头用风轨·飘影牵制、警告痘痘提防幽狼兽操纵飞沙碎石的吐息。莫凡见对方应战经验不逊于城市猎妖队，起了战意。幽狼兽抢先杀出，大头靠三级风轨·飘影避开第一击拉开二十米，幽狼兽却在1秒内收力转向发动二段爆发冲向他，李俊巍愕然之余急令痘痘放水御保护，幽狼兽看着凝成的水珠瞳孔闪过不屑，利爪依然朝风系学员狠狠撕去。

**关键事件**：1.莫凡召唤出远超众人认知的成年幽狼兽 2.李俊巍五人组摆五元之阵并逐人布置战术 3.幽狼兽二段爆发连破飘影与水御，章末利爪直取风系学员

**逐章写法公式**：

- **情绪流向**：起：轻松（莫凡懒洋洋应战） → 承：紧张（五人列阵、战术交代） → 转：紧张（首击扑空与二段爆发） → 合：紧张（利爪撕裂水御的悬置）
- **节奏配比**：慢铺垫 40% / 快冲突 45% / 爽点爆发 10% / 悬念留白 5%
- **本章结构公式**：召唤亮相（立召唤兽威慑） + 阵型战术铺垫（立对手专业度） + 首击与二段爆发（立反常强度） + 撕向水御卡点（悬置杀伤）
- **本章核心技巧**：把"变强"拆成兽风压场、爆发扑击、二段连击三级递进，每一级都配懂行者的惊呼或解说来标定层级。
- **卡点与伏笔**：结尾卡点：动作悬置+利爪撕向被水御迟滞保护的风系学员，下章期待伤情与五人组反击；埋设/回收伏笔：蒋云明"比上次更强"→进阶期身份的悬念线；李俊巍提醒的飞沙走石吐息→下章放大版吐息的预兆。
