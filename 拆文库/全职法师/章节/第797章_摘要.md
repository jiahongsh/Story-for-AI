# 第797章 凝华邪珠！

**概要**：莫凡打晕光系守卫山治，另两守卫被黑气缠住不需打昏，望月千熏向莫凡道谢。她贴门用日语与里面人交谈，确认被关者正是其兄鹤田。鹤田声音微弱，称自己找到凝华珠欲上报大阪政府，却被高木将军截获私吞并软禁关押。莫凡追问下得知诅咒大阵不仅抽魂，更将众魔头灵魂之力凝聚成珠。望月千熏怒斥高木为让天岭兽进阶君主级而残害他人，决意带走凝华珠以免大哥被灭口，莫凡则暗想此珠可为其疾星狼塑魂。二人按鹤田指示潜入城堡最底阵点，见到中央悬浮一颗浑浊透邪的珠子，莫凡直觉此物邪性极重。

- **情绪流向**：起：制服守卫后的确认 → 承：鹤田身世与高木黑幕的揭开 → 转：凝华珠真相引发的愤怒与贪念 → 合：见到邪珠的警示钩子
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：打晕守卫确认身份（收束上章） + 鹤田自述遭囚（揭黑幕） + 凝华珠真相（扩设定） + 潜入阵点见珠（埋钩）

- **卡点与伏笔**：结尾卡点：邪珠现身，下章期待莫凡与望月千熏如何处理；埋设/回收伏笔：凝华珠塑魂之力 → 后续召唤兽进阶与寄生危机
