# 第736章 诱上岸杀

**概要**：毒穴噬蜂钻入裂妖伤口使其恶化。裂妖欲控水却被鬼刑压制，钻入海中。周旭欲追被艾江图止。裂妖化作旋风钻从冰下袭莫凡，莫凡遁影躲过；众人魔法齐轰，裂妖再钻袭祖吉明（赵满延南珏护下）与南珏。艾江图主张暂退轮船，穆宁雪说裂妖必寻仇，艾江图定计将它引上岸封死后路再杀。

- **情绪流向**：起：毒蜂恶化的稳 → 承：钻海偷袭的紧 → 转：接连受伤的压抑 → 合：定计诱敌的期待
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：毒蜂恶化（削） + 裂妖钻海偷袭（压） + 退守轮船（转） + 定计引上岸（设局）

- **卡点与伏笔**：结尾卡点：在缺口附近休息引它上钩；埋设/回收伏笔：引上岸→后续礁岛决战
