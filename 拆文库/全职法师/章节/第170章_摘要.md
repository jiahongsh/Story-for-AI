# 第170章 谋略

**概要**：新生大赛后，召唤系其余六人识相地只要原本属于自己的那份，莫凡抢来的资源全归他一人，他盘算着把资源换成幽狼兽进阶战将级的资材。生活随之变化：两名舍友怕被莫凡的仇怨牵连申请换宿舍，宿舍只剩莫凡、对他崇拜得五体投地的张平谷和言行如常的赵满延，赵满延最常问的是牧奴娇到底是C还是D。一个多月后，新生大赛的话题被新强者传闻取代，有人被捧为战斗力可能在莫凡之上。张平谷带回消息：牧奴娇把败局责任揽到自己身上，以牧大世家名义捐出几乎等同于学校公共资源的补偿给全系学生，被奉为女神。赵满延一语道破这是谋略——世家把每年用于争夺名校学员的经费提前透支，借牧奴娇夺回资源失败的完美借口一次性收买全校新生；并判断多半是牧家授意、自责的牧奴娇顺水推舟。莫凡感慨真正的名门懂得维系形象拉拢潜力法师。张平谷追问莫凡如何逃出坤之林囚牢，赵满延先替他挡下，随即自己猥琐凑过来打探，被莫凡以嘴型回敬"滚犊子"。

**关键事件**：1.六舍友让资源、宿舍人员变动 2.牧奴娇以世家名义捐资源补偿全系 3.赵满延拆解世家收买人心的谋略 4.逃脱之法保密

**逐章写法公式**：

- **情绪流向**：起：轻松（分资源与宿舍日常） → 承：好奇（牧奴娇捐资源的反常消息） → 转：期待（赵满延拆穿世家谋略） → 合：轻松（逃脱之法保密的宿舍斗嘴）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：战利分配（消化胜利） + 宿舍变动（处境更新） + 女神赐福传闻（抛反常） + 谋略拆解（揭真相）
- **本章核心技巧**：让情报型配角代偿主角的视角盲区，用一段宿舍闲谈把对手的公关谋略讲成商战课。
- **卡点与伏笔**：结尾卡点：莫凡压箱底的逃脱之法仍无人知晓，下章期待领奖与资源兑现；埋设/回收伏笔：暗影系逃脱之法→持续掩盖多系之谜；赵满延精通世家人脉运作→其世家背景的暗示；入学晚于莫凡的更强新生传闻→后续对手铺垫；牧奴娇全系补偿→回收上一章她自责出头的动机。
