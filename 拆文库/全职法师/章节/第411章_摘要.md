# 第411章 有辱尊严！

**概要**：莫凡骂遍火院的事传遍校内论坛，植物系学堂里艾图图乐呵呵念给牧奴娇听，牧奴娇笑说世家子弟都想尽办法打响名头，莫凡不代表任何势力却专做一鸣惊人的事，但随即担忧他这次做过头了——主校区全是中阶法师，各代表派别势力，高阶以下皆可留校进修，什么怪胎都有；她本人植物系排行也仅一百四十五名。莫凡回公寓吃完水果，收到灵灵信息去青天猎所报到。包老头生意冷清，莫凡请他引荐铸造师打造铠魔具——武壳巨蜥尸骸已被离曼处理、一千九百万打入卡中。包老头答应让他去东方明珠魔法协会找老朋友，却顺势压给他一叠积压委托：下水道抓血纹巨眼猩鼠、捉逃跑驯兽乃至收保护费式的碎单，还以"谁让你是青天猎所最弱的猎人"打趣。莫凡抱怨以自己的实力接单十万起价、中阶法师出场费不比大明星低，可回想起虐暴巨蜥伪龙、智杀武壳巨蜥、拯救图腾玄蛇、赶走银色穹主的风光，如今干这些找狗贴小广告式的委托，实在有辱强者尊严。

**关键事件**：1.骂院风波传遍校内论坛 2.莫凡收到1900万武壳巨蜥货款并求引荐铸造师 3.包老头压给他一叠低端委托 4.莫凡自嘲有辱强者尊严

**逐章写法公式**：

- **情绪流向**：起：轻松（论坛吃瓜看热闹） → 承：紧张（主校区怪胎警告） → 转：搞笑（猎所低端委托） → 合：压抑（强者尊严受辱的自嘲）
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：吃瓜旁证（侧面放大风波）+ 环境警告（铺垫危机深度）+ 猎所报到（转入日常线）+ 委托羞辱（埋赚钱与锻造动力）

- **卡点与伏笔**：结尾卡点：动力悬念——为铠魔具与大价钱单子，莫凡得先忍辱做完碎单，期待挑战之周与锻造线；埋设/回收伏笔：1900万货款+离曼 → 资金线；东方明珠魔法协会铸造师 → 铠魔具装备线；"最弱的猎人"称号 → 猎所内地位梗；回杀银色穹主等战绩清单 → 前情战力标尺
