# 第136章 我可以负责的

**概要**：后视镜破碎声让唐月清醒，她推开莫凡蜷到车子另一边，随即又在魅惑驱使下反复扑上来又推开，把莫凡折磨得内心崩溃。到市区后唐月买下抑制药物，带着羞愧逃走。她随后发短信威胁"这件事你敢说出去，我就把你阉了"，莫凡回"其实我是会负责的"，唐月又抛出"审判员一生可以有两次误杀的机会"恐吓，莫凡借机约咖啡，唐月看完回复没忍住扑哧一笑，心想连中阶魔法都要靠星图之书的小家伙怎么对自己负责。莫凡回上海后决定自修一年、来年直接杀入明珠学府，理由是靠星图之书放中阶魔法太慢、装B需要实力保障、还想多了解诅咒系这类知识。讲诚信的唐月发短信让他去上海魔法协会觉醒，有人引领。莫凡抵达坐落在东方明珠法师塔的东方魔法协会，了解到魔法师公约三条铁律与审判会的地位，想起唐月二十出头就有烈拳·九宫的破坏力竟只是审判员的基本标准。

**关键事件**：1.唐月魅惑反复拉扯后买药羞愧逃离 2.两人短信斗嘴唐月以误杀名额威胁 3.莫凡决定自修一年再入明珠学府 4.莫凡了解魔法师公约与审判会

**逐章写法公式**：

- **情绪流向**：起：紧张（车上拉扯） → 承：轻松（短信斗嘴） → 转：热血（自修宣言） → 合：其他（世界观铺陈）
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：魅惑余波收尾（情感账） + 短信互怼（关系定型） + 修炼路线决策（下一卷目标） + 世界观补课（公约与审判会）
- **本章核心技巧**：用一条短信对话链完成"威胁—调侃—反撩—偷笑"的情感回合，再切主角独白敲定下阶段目标，过渡章写出双内容点
- **卡点与伏笔**：结尾卡点：轻卡点，审判员皆是战斗力爆表怪物、唐月实力只是基本标准的感叹收章；埋设/回收伏笔：回收车上激情门（短信清算）、回收朝赫之死（正面交锋唐月本可胜）、埋下自修一年杀入明珠学府的目标、埋下上海魔法协会觉醒之行
