# 第598章 脱离战场

**概要**：冰封灵柩中的肥硕尸臣血管堵塞，冰块和冻肉不断脱落，妖男取出它的残魄后飞离，黑色尘暴随尸臣死亡逐渐散去。他在地面找到仍活着的莫凡和重伤中毒的疾星狼，交给莫凡自己配制的解毒药剂。莫凡处理疾星狼伤口时得知妖男辅修毒系，也听见妖男解释毒系、亡灵系及高阶后可能接触的空间、音系和混沌系。妖男把统领级残魄作为酬劳交给莫凡，随后带他离开战场，莫凡从空中看到尸将和统领级亡灵仍在不断增多。

**关键事件**：1.肥硕尸臣死亡并被取出残魄 2.妖男救治中毒的疾星狼并透露毒系知识 3.莫凡离开战场并看见更大规模的亡灵军团

**逐章写法公式**：

- **情绪流向**：起：尸臣死亡余波 → 承：救治疾星狼的缓和 → 转：高阶魔法知识带来向往 → 合：俯瞰无穷亡灵，局部胜利转为整体压力
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 25% / 悬念留白 30%
- **本章结构公式**：残骸变化（确认击杀） + 解毒救治（处理代价） + 魔法闲谈（补充设定） + 空中俯瞰（扩大危机）
- **本章核心技巧**：让战后治疗同时承担人物关系、世界观说明和奖励交付，再用远景把情绪从放松重新推向压迫。
- **卡点与伏笔**：结尾卡点：统领级亡灵如小山般出没，期待城墙和法师军团如何应对；埋设/回收伏笔：统领级残魄作为酬劳 → 小泥鳅坠后续凝炼。
