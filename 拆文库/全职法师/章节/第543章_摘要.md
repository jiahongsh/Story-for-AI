# 第543章 我养得起你

**概要**：莫凡发现微醉的牧奴娇正为学府之争烦闷，先因失态惹她发怒，随后认真询问缘由。牧奴娇说明世家子弟接受资源便须用成绩偿还，若继续向家族索取却无法胜出，往后可能连婚姻也受家族支配；穆宁雪获得帝都学府提名的消息又让她感到落后。面对想变强又害怕失去自由的牧奴娇，莫凡劝她放弃继续向家族借力，并用“我养得起你”回应，牧奴娇恼怒离开，莫凡仍在背后表明自己是认真的。

**关键事件**：1.牧奴娇借酒放松，莫凡察觉她为学府之争忧虑。 2.牧奴娇解释世家资源与联姻束缚，并提及穆宁雪已获帝都提名。 3.莫凡劝她不要再向家族索取，提出由自己养她。

**逐章写法公式**：

- **情绪流向**：起：轻松暧昧 → 承：压抑困惑 → 转：坦白家族束缚 → 合：甜中带恼的留白
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：醉酒互动动作（暴露异常） + 世家规则对话（交代压力） + 提名消息对比（加重挫败） + 直白承诺（关系推进）
- **本章核心技巧**：用看似闲聊的私密场景承接制度信息，再让情感回应替代说教式结论。
- **卡点与伏笔**：结尾卡点：关系回应，莫凡的认真承诺与牧奴娇的恼怒离开并置，留下她会否接受的期待；埋设/回收伏笔：家族资源债务与联姻风险 → 解释牧奴娇后续选择的压力来源。
