# 第918章 活人，死人？

**概要**：天山白之痕裂谷是凡人禁地，连熔浆流入也瞬凝成冰。黑甲男子斩空披散长发携擎天山峰之尸来到谷口，命尸身留守后独自跃入幽暗深谷。谷底他拾起冻成冰块的头戴，灾风卷来上百根十几米冰锥，斩空引动空间波震令时间静止、冰锥落地；现身叫嚣的冰白色天虎察觉杀念拔腿逃窜。斩空凝视冰墙轻唤“羽儿”，扬手层层脱去冰层，露出被冰存十年的女子——她身着斩空十来年前亲自为她披上的鹅绒衣，青春定格二十四岁。薄冰如镜映出斩空毫无生气、带活死人印斑的黑色面孔，与冰中女子形成刺眼对比，他抚摸冰面自问“我究竟是死人，还是活人”。一掌拍裂薄冰后他转身飘离，命天虎将苏醒的女子送出裂谷送往山下镇子，只留裂谷中“死人？活人？我到底是什么”的低语。

**关键事件**：1.斩空携山峰之尸入白之痕，独探谷底 2.空间时滞化解冰锥，天虎惧逃 3.脱冰见被封存十年的女子，斩空自问死活身份

- **情绪流向**：起：禁地环境的冷峻 → 承：坠谷与冰锥的紧张 → 转：脱冰见人的心疼 → 合：死活之问的余痛
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：禁地环境铺陈（定调）+ 坠谷遇袭（加压）+ 脱冰见人（情感反转）+ 死活自问（钩子）
