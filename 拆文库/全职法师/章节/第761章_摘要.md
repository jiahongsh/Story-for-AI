# 第761章 勾魂再现

**概要**：莫凡守夜时暗恼官鱼凑热闹，静静注视冥修的穆宁雪、被其冰肌银发吸引，整夜无事后天亮推唤却发现穆宁雪不睁眼、重力摇晃也无应，摸其额头冰凉、翻眼皮见瞳孔蒙灰，状况竟与赵满延一般无二，官鱼骇然怨毒怪罪莫凡，莫凡怒立誓不放过宫田。南荣倪确诊穆宁雪与赵满延同遭勾魂，莫凡称整夜紧盯、少女未现屋内，艾江图遂分兵：官鱼黎凯风寻和尚、江昱组打探、莫凡蒋少絮南珏与自己入后山，莫凡指前山无异常、勾魂少女应有栖息所，后山最可疑，四人循荒废古道入山，南珏不解宫田为何偏需名字，莫凡恨那同可见少女的年轻和尚不在。

**关键事件**：1.穆宁雪也被勾魂，与赵满延同状 2.艾江图分兵，莫凡组入后山 3.南珏问需名之谜，年轻和尚缺席

**逐章写法公式**：

- **情绪流向**：起：守夜暧昧 → 承：天亮发现中招 → 转：确诊怒誓 → 合：分兵入后山
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：守夜（铺垫） + 惊觉中招（爆发） + 确诊分兵（收束） + 入后山（推进）
- **本章核心技巧**：用"天亮推唤—体征递进"做延迟揭示的惊雷，再用排除法把视线锁到后山
- **卡点与伏笔**：结尾卡点：后山探查，需名之谜未解（悬念）；埋设/回收伏笔：年轻和尚不在 → 知情人缺席阻碍；后山栖息所 → 木鱼线索
