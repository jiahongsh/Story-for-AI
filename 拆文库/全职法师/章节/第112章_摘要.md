# 第112章 十只黑畜妖！

**概要**：莫凡心中暗笑穆卓云栽培的世家接班人竟是黑教廷十年前安插的卧底——激怒翼苍狼、挖掘地下入口、狂暴泉水、偷换地圣泉全是蓄谋，只因自己顶替穆宇昂进入地圣泉，毁城计划才没能彻底发力。穆宇昂怒吼要让莫凡品尝十倍百倍的痛苦，其身后接连现出黑畜妖，莫凡扔出火滋·爆裂拖延后逃向电梯口，穆宇昂接连召唤，共十只黑畜妖聚齐——这本是撒朗吩咐守护妖魔入口的力量。此时鹰钩鼻男子耳机传令称有魔法师队伍正接近妖魔入口，穆宇昂畏惧撒朗不敢违抗，留下"黑畜妖会剥皮挑骨挖器官"的狠话离去。莫凡掰开电梯门跳进电梯井攀缆绳上爬，第一只黑畜妖坠井摔在负一楼，第二只抓缆绳猛追被他掌心放出的电弧沿电缆击落。黑畜妖随即分兵，四只守电梯口、六只绕自动扶梯上楼包抄，莫凡爬到二楼扒开电梯门逃入应急通道，称到了那里就有对策。

**关键事件**：1.莫凡理清黑教廷十年毁城阴谋全貌 2.穆宇昂被召回，留十只黑畜妖追杀莫凡 3.莫凡电梯井电击退敌后遭分兵包抄，逃入应急通道

**逐章写法公式**：

- **情绪流向**：起：轻松（莫凡暗笑拼出真相）→ 承：紧张（爆裂突围、十妖聚齐）→ 转：紧张（电梯井电击反杀）→ 合：紧张（分兵包抄、逃入通道）
- **节奏配比**：慢铺垫 20% / 快冲突 60% / 爽点爆发 10% / 悬念留白 10%
- **本章结构公式**：真相复盘（信息）+嘴仗与爆裂突围（冲突）+十妖围杀与敌首被召回（转折）+电梯井攻防+分兵包抄（连续钩子）
- **本章核心技巧**：追逐战中用环境道具（玻璃、缆绳、扶梯）轮换解法，让攻防每一回合都换空间
- **卡点与伏笔**：结尾卡点：黑畜妖上下包抄，莫凡逃入应急通道自称有对策；埋设/回收伏笔：鹰钩鼻传令"魔法师队伍接近妖魔入口"→与第110章程军官队伍的行动线交汇；十只黑畜妖→下章破门逼出莫凡突破
