# 第363章 见习审判员

**概要**：祝蒙采纳罗冕之策，下令调遣所有实习与预备审判员缉拿唐月。浙江学府的柳一林经大哥柳钟鸣运作拿到任务名额，得知表现出色可直接晋身正式审判员，向死党放话任务顺利后整个学府无人能与自己相比。另一边莫凡不敢开跑车，与唐月徒步出城，途中闲聊冷青与青天猎所的旧事；唐月愧疚自己连累莫凡上了追捕名单，莫凡打趣要她以身相许，唐月认真应允。她随即吐露亡父"像星辰一样凝视守望"的话语，直到神的身影浮现西湖水下才懂得其意，蛇如父亲般守护她多年，此次拼死也要护它渡劫，莫凡听后决定不趁人之危。

**关键事件**：1.祝蒙下令调遣实习与预备审判员缉拿唐月 2.柳一林为晋升名额加入追捕行动 3.唐月应允以身相许并吐露与蛇的父女般羁绊

**逐章写法公式**：

- **情绪流向**：起：压抑（祝蒙下令调兵） → 承：热血（柳一林的小宇宙燃烧） → 转：甜（以身相许的许诺） → 合：温馨（星辰独白与莫凡收手）
- **节奏配比**：慢铺垫 50% / 快冲突 10% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：反派调兵（压力升级） + 小人物领命（追兵视角铺垫） + 逃亡闲聊（缓和+前史补充） + 许诺独白（情感动机落定）
- **本章核心技巧**：用追兵阵营新角色的晋升欲望做敌人视角铺垫，与主角线的情感独白双线并行，为后续相遇预埋信息差。
- **卡点与伏笔**：结尾卡点：情感承诺型——唐月许诺以身相许、莫凡自嘲收手，期待两人关系走向与追兵遭遇；埋设/回收伏笔：柳一林的晋升执念→后续被莫凡再揍的恩怨；冷青、青天猎所前史→世界观回扣。
