# 第874章 碎骨痕迹

**概要**：莫凡意外城市猎妖队闯入牧场庄园，担心这支隶属审判会的力量打乱揪出黑教廷的计划；灵灵主张让姐姐撤掉猎妖队，莫凡却反对，认为贸然撤人会反引怀疑，且猎妖队反而能吸引黑教廷注意、掩护三人身份。玩乐一天中莫凡估算三座庄园连片有上千游客加约两千服务人员。入夜莫凡找本地女孩郭文衣打听当年"吃马的东西"所在，郭文衣惊恐，莫凡劝她直面恐惧。二人前往小林子，扒开草丛发现一块嵌在泥里的马脸碎骨，又见半米方圆寸草不生的光秃地，判断是黑畜妖或诅咒畜妖唾液腐蚀所致，总算有了眉目。

**关键事件**：1.莫凡担心猎妖队打乱计划，与灵灵分歧 2.估算庄园人数规模 3.莫凡带郭文衣去小林子寻吃马地点 4.发现碎骨与腐蚀光秃地，判断畜妖唾液

**逐章写法公式**：

- **情绪流向**：起：猎妖队打乱计划的焦虑 → 承：莫凡翻转视作掩护的释然 → 转：夜探小林子的紧张寻证 → 合：碎骨与腐蚀地坐实畜妖的爽感
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：猎妖队来袭引分歧（设阻） + 估算人数显规模（加压） + 劝郭文衣同往林子（推进） + 碎骨腐蚀地坐实畜妖（破局）
- **本章核心技巧**：先用"先否定再惊呼反转"的找证据节奏，把平淡搜证写成发现爽点。
- **卡点与伏笔**：结尾卡点：莫凡笑称"总算有点眉目"，下章期待灵灵化验与林中动静；埋设/回收伏笔：腐蚀光秃地 → 本章功能（坐实黑畜妖/诅咒畜妖，后续毒变根源回收）；吃马怪物 → 伏笔（郭文衣早年目击，后续黑畜妖真容回收）
