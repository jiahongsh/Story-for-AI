# 第1356章 全线戒备

**概要**：赵满延被莫凡的话惊住，通讯随即挂断，他相信莫凡不会拿性命开玩笑，转身追向那位女军官，先是亮出预防组身份，见军人们哄笑不信，索性亮出国府勋章，吼出自己赵满延、预防组七组副领队的身份，要求立刻通报总指挥官全线戒备。女军官凝视北面片刻，抬手制止手下，平静地吐出"全线戒备"四字，赵满延催促她去通报总指挥官，才得知她就是镇北关总指挥官彬蔚。彬蔚换上战备袍后气质大变，赵满延意识到她与芬纳同级别。众副官谋官劝她不要小题大做，加重戒备即可，免得影响威信被敌对派弹劾，彬蔚却道出自己考虑的始终是身后榆林市、安秦市、飞皇市、众宁城的平民性命，不会拿千万人的生命去赌，赵满延听罢对她彻底改观。全线戒备全面铺开，要塞寂静无声，彬蔚紧盯着古长城之外的荒原，忽然捕捉到一股强大的气息正从北面逼来，副官们也随之神色骤变。

**关键事件**：1.赵满延亮出国府勋章吼出身份，要求全线戒备 2.女军官自称总指挥官彬蔚，下令全线戒备 3.彬蔚说出以身后平民性命为重的为将之道，赵满延改观 4.彬蔚察觉北面有强大气息逼近

**逐章写法公式**：

- **情绪流向**：起：通传戒备的焦灼 → 承：身份被疑的火大 → 转：彬蔚剖白的震撼 → 合：强敌逼近的肃冷
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：吼出身份逼其戒备（立目标）+ 彬蔚自称总指挥（反转身份）+ 副官劝退与彬蔚剖白（亮立场）+ 北面气息逼近（扔钩子）
- **本章核心技巧**：让身份疑云与角色剖白先后登场，先靠台词冲突制造张力，再靠立场宣言完成人物立起，最后用外部威胁收束
- **卡点与伏笔**：结尾卡点：悬疑式——北面真的有强大气息逼近，敌未现形；埋设/回收伏笔：彬蔚对古长城外土地的凝视 → 即将到来的敌人
