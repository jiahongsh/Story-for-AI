# 第798章 闯大祸了！

**概要**：望月千熏欲将凝华珠带出作为揭发高木的证据，莫凡见珠后反生排斥，坦言此物白送也不要，只愿陪她确认兄长下落而不愿沾手。二人在山下分开，莫凡胸前的石坠小泥鳅对珠子流露厌恶与提防，印证其直觉此珠如潘多拉魔盒。望月千熏携珠夜奔大阪，途中青发醉汉朝冈拦路辱骂，被她召出的鬼木手拍飞、遭卡车碾断一腿；她路过处花卉萎蔫、路灯昏暗，周身笼罩诡异黑暗之气。路人指其邪恶，望月千熏转身时双眼深邃骇人，玻璃橱窗映出的竟是猩红目光、遍生鬼须的恐怖黑影，引路人尖叫。

**关键事件**：1.莫凡见珠后断言邪性拒绝沾手 2.小泥鳅对凝华珠流露厌恶印证不祥 3.望月千熏携珠夜奔，途中失控伤人与枯萎草木 4.玻璃映出恐怖黑影，暗示已被寄生

**逐章写法公式**：

- **情绪流向**：起：莫凡拒绝沾手的冷静 → 承：小泥鳅验证不祥的压抑 → 转：望月千熏失控伤人的恐怖 → 合：黑影现身的钩子
- **节奏配比**：慢铺垫 35% / 快冲突 30% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：莫凡拒珠（立态度） + 小泥鳅验证（加砝码） + 望月千熏夜奔失控（爆发恐怖） + 黑影倒影（埋钩）
- **本章核心技巧**：用灵物反应与镜像反差两处客观证据，把邪珠危险写得可信而非主角说教
- **卡点与伏笔**：结尾卡点：望月千熏化身黑影，下章期待莫凡如何应对；埋设/回收伏笔：小泥鳅的灵性厌恶 → 后续确认邪珠寄生本质
