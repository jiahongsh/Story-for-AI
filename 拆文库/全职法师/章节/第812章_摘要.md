# 第812章 承包一个街区（下）

**概要**：赖恒宝离去前提醒后天大涨潮，赵满延冷笑日本以战场城外包敛财、死的是卖身杀妖的法师。南珏称队伍被分至二十街区，电脑图片显示区主为卷曲胖叔，其旁橙发男子正是曾救穆宁雪的区主之子。江昱玩笑让穆宁雪去攀关系换四星，遭冷眼；穆婷颖刺道即便穆宁雪战死也无资源份。清晨穆宁雪在黑屋醒来掌心结霜，自语恐有醒不过来之日，独自走向海岸，被一腼腆青年搭讪。

**关键事件**：1.赖恒宝提醒大涨潮，赵满延冷笑权术 2.队伍分至二十街区，区主之子是橙发男 3.江昱玩笑被冷眼，穆婷颖刺穆宁雪 4.穆宁雪清晨结霜独行海岸，遇腼腆青年

**逐章写法公式**：

- **情绪流向**：起：赖恒宝离去的规则提醒 → 承：赵满延冷笑与街区分配 → 转：江昱玩笑与穆婷颖暗刺 → 合：穆宁雪结霜独白的钩子
- **节奏配比**：慢铺垫 50% / 快冲突 10% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：提醒涨潮（收束上章） + 街区分配与区主（扩线） + 玩笑与暗刺（人际张力） + 穆宁雪结霜（埋线）
- **本章核心技巧**：用配角世故之眼写制度荒诞，再以日常结霜细节埋角色灵魂隐疾
- **卡点与伏笔**：结尾卡点：穆宁雪遇腼腆青年所为何事，下章期待溺咒；埋设/回收伏笔：穆宁雪掌心冰霜 → 冰晶刹弓反噬恶化的体征
