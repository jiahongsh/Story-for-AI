# 第985章 国际悬赏池

**概要**：穆宁雪回过神来，向莫凡转述东海城那桩诡事：有人自行冲入海中、身体泛白溺死，看似病疫却能强迫人自杀。莫凡骇然，又补上海疆猛犸骨髓尽失、骨架中空才得以漂浮的线索。穆宁雪执意要查清溺咒，莫凡则联系纽约的灵灵求助资料库。灵灵一听溺咒两眼放光，得知二人在葡萄牙提诺阿亚便当即买票赶来。她透露国际猎者联盟早已就这桩全球死亡案例发布悬赏，且采用"悬赏池"机制——无人完成便金额累加，眼下已累至三亿五千万。莫凡历经裴历一役深知自己缺领域，盘算火雷暗影已高阶、召唤将破高阶，急缺下一个星河之脉与一枚领域魂种，正愁没钱，这悬赏池无异雪中送炭。灵灵抵城后据电子图归纳：溺咒全发于近海城市，三大洋皆有，中国海域少见，而提诺阿亚正是溺咒率最高的中心地带，她坚信定能解开。

**关键事件**：1.穆宁雪述东海城溺咒，莫凡补骸骨空髓 2.灵灵接案，揭国际悬赏池累至三亿五千万 3.莫凡求领域魂种，灵灵抵城归纳全球分布规律

**逐章写法公式**：

- **情绪流向**：起：溺咒悚然的沉 → 承：悬赏池惊喜的亮 → 转：求领域魂种的务实 → 合：全球分布规律的悬
- **节奏配比**：慢铺垫 20% / 快冲突 5% / 爽点爆发 25% / 悬念留白 50%
- **本章结构公式**：溺咒转述（设谜） + 悬赏池揭晓（利好） + 领域刚需（成长） + 全球分布（扩局）
- **本章核心技巧**：用"悬赏池"把诅咒调查写成有利可图的猎人任务，同时推进主角装备线
- **卡点与伏笔**：结尾卡点：期待型，诅咒中心提诺阿亚待解，下章期待实地走访线索；埋设/回收伏笔：裴历领域压制 → 回收前章"有领域没领域"痛点；东海城溺咒 → 回收上章伏笔
