# 第984章 再现溺咒

**概要**：海边骸骨散发怪味，港口围满惊骇的人群，谣言悄然酝酿，赵满延落地后也叹其大得夸张。莫凡请识妖专家江昱辨认，江昱一口报出这是海疆猛犸——头身似远古巨象、下半身鲸体的远深海霸道生物，号称轮船杀手，一口生吞海妖；他又据牙开始泛黑判断其死亡未超两天，南珏则困惑于骨骼完整、皮肉血内脏尽失、且骨轻如轮船般漂浮。江昱更点出海边这只接近君主级，赵满延浑身一哆嗦——接近君主级者竟如此惨死，意味着附近潜藏着真正的君主。莫凡对国馆赛毫无兴趣，艾江图索性让他去探骸骨，赵满延、蒋少絮、穆宁雪随之同行。穆宁雪中途离队拐入海边街巷，却在石桥边见浅滩上火系法师正为黑袋裹尸举行火葬，老伯叹这是本月第三次。细问方知死者是自行发疯冲入海水、窒息干枯而亡，穆宁雪顿时想起日本东海城的诡异旧事——这正是相隔半球的"溺咒"。

**关键事件**：1.江昱辨出海疆猛犸，近君主级惨死引恐慌 2.穆宁雪离队独行，浅滩见火葬 3.老伯道出死者自发溺海，穆宁雪认出溺咒再现

**逐章写法公式**：

- **情绪流向**：起：骸骨围观的奇观 → 承：猛犸近君主级的恐 → 转：穆宁雪离队独探 → 合：溺咒再现的悚
- **节奏配比**：慢铺垫 30% / 快冲突 5% / 爽点爆发 5% / 悬念留白 60%
- **本章结构公式**：骸骨辨种立威（奇观） + 近君主级惊众（加压） + 穆宁雪离队（转场） + 浅滩火葬认溺咒（钩子）
- **本章核心技巧**：用专家定性把奇观翻成生存威胁，再以配角离队自然过渡到诅咒线
- **卡点与伏笔**：结尾卡点：悬念型，穆宁雪认出溺咒相隔半球再现，下章期待与莫凡共查真相；埋设/回收伏笔：东海城溺咒 → 回收前文穆宁雪日本经历；海疆猛犸 → 新海洋谜团伏笔
