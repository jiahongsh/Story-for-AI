# 第11章 叶心夏

**概要**：莫凡哼着小苹果走向铭文中学——全夏城最水嫩时尚少女聚集的私立女子中学，学生多是有家庭魔法背景的魔二代法二代，放学高峰校道挤满豪华轿车。深知心夏脾气的他绕开正门，穿过后院到熟悉的胡同小道堵她，摆好姿势等了半天不见人。闭眼习惯性要冥修时，他忽然听到从胡同口通往小山方向传来的嘈杂声——那声音正常会被高墙隔绝，他猜测冥修附带增强了感知，循声走去。山丘草坪的冬藤木秋千上坐着黑色瀑布长发的少女叶心夏，安静得像融入画卷的娇莲。莫凡心口涌起暖流，随即察觉不对劲快步上前；心夏温雅一笑唤"莫凡哥哥"，仿佛早知道他会来。莫凡问"又是那般狗东西对不对"，心夏沉默劝他"他们人很多，算了吧"，莫凡怒而上山。小亭里，脖缠青色纹身的徐冰正与同伙打牌，自称这是第十六次向她表白、给她考虑时间，还放话莫凡是"战斗力不足五的渣渣、人肉沙包随便揍"。

**关键事件**：1.莫凡放学堵截接心夏，却在秋千旁发现她又被地痞纠缠 2.心夏劝阻无效，莫凡怒上小山 3.徐冰第十六次表白缠扰，并当众贬莫凡为人肉沙包

**逐章写法公式**：

- **情绪流向**：起：赴约路上的轻快 → 承：秋千画面的温柔 → 转：察觉欺凌的怒意 → 合：山上反派的嚣张
- **节奏配比**：慢铺垫 55% / 快冲突 20% / 爽点爆发 0% / 悬念留白 25%
- **本章结构公式**：堵截计划（立熟稔）+ 感知异常（显修炼收益）+ 秋千相逢（亮心夏）+ 沉默劝阻（立欺凌）+ 亭中群像（立反派）
- **本章核心技巧**：全章零战斗零爽点，用"静画面+旧账对话"把情绪全部蓄到下一章爆发的临界点
- **卡点与伏笔**：结尾卡点：愤怒型——莫凡单枪匹马上山对五人，被打还是打人；埋设/回收伏笔：心夏的轮椅（下一章揭晓）→她腿疾与被欺凌的核心痛点；青熊帮给富家少女做打手→第12章赵坤三穆白的指使线；冥修感知增强→双系修炼的隐性收益再确认
