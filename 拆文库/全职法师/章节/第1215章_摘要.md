# 第1215章 军中败类

**概要**：莫凡靠近林飞历居住的山洞，见洞口两名军官驻守，蒋少絮隔百米施展高阶心灵系摄魂控心将二人轻易操控，莫凡、牧奴娇、灵灵大摇大摆走过，其一还向洞内汇报。入内抵岩谷，躲岩后见金战猎人团被困、谷内百余名军官，为首张七虎体型彪悍、一脸棕毛虎相。蒋少絮说张七虎实力极强、石千寿只负责对付葛明，莫凡借暗爵斗篷潜入查明岩谷只这些守军、余人已从另一通道往地底更深去，分散可逐个击破；蒋少絮探得共七名高阶、余皆中阶。莫凡部署牧奴娇鬼木铺岩下、蒋少絮对付心灵诅咒系、其余归己。张七虎与一名朝天鼻军官下流谈论被放的两女、称兵匪无别，黄艺愤而斥责，藏身的牧奴娇蒋少絮听得面红耳赤。莫凡冷笑，钦佩斩空般用命的军人、对这些堕落败类不必心慈手软。他开启召唤之门兽潮，白色巨狼群冲入岩谷，军官训练有素列阵以岩石屏障阻挡，冰川色飞川皑狼踩碎岩屏袭人；莫凡立狼肩打天焰雨拳打散进攻小队，跃火焰羽翼拳轰火焰蛟龙将朝天鼻军官焚成灰，牧奴娇蒋少絮出一口恶气。杨宝、许平东等猎人见莫凡杀入又惊又喜，许平东劝其快逃报信。

**关键事件**：1.蒋少絮控心两官，莫凡暗探知敌分散 2.军官下流议两女，莫凡决意不留情 3.召唤兽潮破阵，火焰蛟龙焚朝天鼻军官

**逐章写法公式**：

- **情绪流向**：起：潜入探敌的稳 → 承：败类言论的愤 → 转：兽潮破阵的炸 → 合：点杀焚敌的爽
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 30% / 悬念留白 5%
- **本章结构公式**：控心潜入探敌（布势） + 败类言论激杀意（加压） + 召唤兽潮破阵（爆发） + 火焰蛟龙点杀（收爽）
- **本章核心技巧**：让反派自白坐实败类，再用兽潮三段式破阵把杀意转成爽点
- **卡点与伏笔**：结尾卡点：许平东劝莫凡快逃报信，下章莫凡力敌百人军；埋设/回收伏笔：暗爵斗篷→潜入；七高阶→下章张七虎三将；飞川皑狼→后文撕黄艺
