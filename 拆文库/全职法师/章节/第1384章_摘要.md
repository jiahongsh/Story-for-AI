# 第1384章 神木镇守，张小侯

**概要**：神木关城墙上，审判使姜林对上依仗暴瘾畜妖的高阶枯脸蓝衣，连连吃亏，祭出天瀑重创畜妖后却被枯脸蓝衣趁隙背袭，冰棱直刺后心。张小侯出手，风系土系并用，身法快近瞬息移动，一招风鲸尾将枯脸蓝衣击上半空，再以风切翼刃化作风杀羽环将其分尸，两招秒杀高阶蓝衣，姜林惊叹不已。姜林忽见张小侯身旁水汽汇聚出冰刺警示，紫鬼的声音随之响起，冰之剑针直刺张小侯后心，不给他一念星轨的反应时间。生死之际，张小侯周身环绕的不起眼尘埃竟齐聚受创处化作坚固甲心，挡下致命一击，紫鬼骇然——这土系元素种竟有自我防御意识。张小侯随即在方圆百米造出泥沼领域吸住紫鬼双脚，紫鬼只得放弃偷袭远遁，身体渐渐透明化消失于空气，令张小侯费解，暗影系明明需依托阴影。谜底揭开：那些细比沙粒十倍的尘埃是张小侯的尘埃领域精灵，当领域者生命受威胁时会以自身组成甲胄护主。紫鬼是刺客法师，一击不成远遁千里，遁入安全处后隐而不出，改令手下围攻，又把姜林最看好的潜力审判员踢给诅咒畜妖分吃，逼姜林怒不可止。

**关键事件**：1.姜林天瀑重创暴瘾畜妖却被枯脸蓝衣背袭 2.张小侯风鲸尾加风切翼刃两招秒杀高阶枯脸蓝衣 3.紫鬼隐身突袭张小侯后心，被尘埃甲心挡下 4.张小侯泥沼领域逼退紫鬼，紫鬼透明化消失 5.紫鬼改屠姜林麾下审判员挑衅，姜林怒不可止

**逐章写法公式**：

- **情绪流向**：起：姜林受挫的憋屈 → 承：张小侯秒杀强敌的痛快 → 转：紫鬼致命偷袭被甲心挡下的惊险 → 合：紫鬼遁形转屠他人、姜林暴怒的愤怒
- **节奏配比**：慢铺垫 25% / 快冲突 45% / 爽点爆发 15% / 悬念留白 15%
- **本章结构公式**：姜林苦战（铺垫敌人强度）+ 张小侯两招秒杀（爽点）+ 紫鬼偷袭被尘埃甲挡下（惊险反转）+ 紫鬼遁形改屠旁人（情绪推向愤怒）
- **本章核心技巧**：以一场遭遇战同时立住正反两个角色的招牌能力——张小侯的防御型领域与紫鬼的隐形刺杀，各自用一次"出其不意"互相克制
- **卡点与伏笔**：结尾卡点：紫鬼隐于暗处逐个清除有实力的守将、姜林怒欲拼命，下章张小侯能否揪出隐身的紫鬼；埋设/回收伏笔：尘埃领域精灵→回收前文"细微尘埃"描写，并埋下防御型领域设定
