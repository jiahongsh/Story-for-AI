# 第337章 杀沼湖巨物？

**概要**：张小侯在洞庭湖平原寻到失踪数月的莫凡，博城一别两年后重逢。张小侯掏出从比翼市买的两个奴仆级精魄相赠——斩空告诉他莫凡灵魂岌岌可危需大量精魄守护，这两个精魄几乎花光他的积蓄。莫凡明知奴仆级精魄已起不了作用，仍被这份情意弄得眼角湿润。莫凡滞留洞庭湖的真相随之揭开：他借恶魔系力量杀妖魔、靠小泥鳅坠凝炼精魄护住灵魂，四系力量对应四次恶魔反噬，前三次已在痛苦中熬过，一星期后最后一次吞噬将最猛烈，他急需一个统领级魂魄坐镇。沼泽湖中心那只受重伤的统领是他唯一的希望，恰逢张小侯与实力不弱的女法师离曼在场，莫凡宣布"我们去杀沼湖中心的怪物"，张小侯想起吞掉猎法师队伍的巨影当场瞪直了眼。

**关键事件**：1.张小侯千里寻来重逢并赠两个精魄 2.揭开莫凡滞留洞庭湖杀妖凝魄护魂、化身洞庭湖死神的真相与最后反噬倒计时 3.莫凡宣布猎杀湖心重伤统领

**逐章写法公式**：

- **情绪流向**：起：重逢温情 → 承：赠魄感动 → 转：反噬危机与死神真相的冷揭示 → 合：猎统领宣言与张小侯震惊的钩子
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：重逢（引出帮手）+ 赠礼（加深情感）+ 揭底（交代动机与倒计时）+ 宣战（立下章目标）
- **本章核心技巧**：用配角千里送宝的暖场戏包裹力量代价与倒计时的冷设定，温情与危机同章对撞
- **卡点与伏笔**：结尾卡点：宣言式卡点，猎统领行动下章展开，读者等着看怎么杀；埋设伏笔：一周后最后一次恶魔反噬 → 本卷主线倒计时；湖心重伤统领 → 下章猎杀目标
