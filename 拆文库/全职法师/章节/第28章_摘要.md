# 第28章 竟然是S！

**概要**：校长质问三位考官时，穆贺抢先定性星感石是受能量干扰出了小问题，派秃顶的王主任去储备室再取一块新石，把暗石之事压成设备故障，堵住考官禀报实情的口子；唐月皱眉心知此事估计与穆贺脱不了关系，但考虑公开后校领导难做、学生考核也受影响，选择就此作罢。秃顶考官抓住救命稻草宣布莫凡成绩作废、给予重考，陆小斌激动感谢唐月、庆幸可以继续和莫凡一起潇洒出校门，黄飞峰如释重负，赵坤三擦着冷汗庆幸莫凡没门缝过关，薛木生则哭笑不得地忧心三年没开封的惩罚名额真被自己班学生开了。别班测试基本结束，人群围拢过来，莫凡意外成为全场焦点。重测前莫凡没有再感受到那股扑打的冰冷气息，确认是穆白他们做了手脚，冷哼一声后闭眼将手放上星感石。赤红光辉像从石头内部烧起，毫无压制地彻底释放并溢出星感石，火系外溢光芒甚至比穆白的冰系光辉还强几分。穆卓云第一个露出不可思议，校长、副校长、校董们瞪大眼睛，薛木生彻底傻眼，学生们被"我草"刷屏，三考官哆嗦着给出三个S。一直面无表情的穆宁雪终于动容，心里随外溢的火光散开一片阳光。校董们感叹差点错过一名杰出魔法师、竞相恭维唐月明察秋毫，唐月浅笑，内心同样吃惊，认定沉心修炼、不攀比不暴露的莫凡是魔法师的好胚子。

**关键事件**：1.穆贺圆场掩盖暗石、莫凡获重考 2.重测光芒外溢惊爆全场拿三S 3.穆宁雪首次对莫凡动容

**逐章写法公式**：

- **情绪流向**：起：阴谋被抹平的憋闷 → 承：众人各怀心思等待重考 → 转：赤红光辉外溢、三S定音 → 合：穆宁雪动容、校董恭维
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 40% / 悬念留白 10%
- **本章结构公式**：反派抹案（蓄压）+ 群像预热（多视角期待）+ 光芒外溢（爆发）+ 女神动容（余韵收口）
- **本章核心技巧**：用"重考"制造同场景二次表演机会，以第一次被压制的黯淡做锚点，放大第二次彻底释放的冲击。
- **卡点与伏笔**：结尾卡点：期待型，星尘S已定、释放考核未考，下章看火滋表现；埋设/回收伏笔：回收暗石案；唐月一眼识破石之异的感应 → 其修为长线伏笔。
