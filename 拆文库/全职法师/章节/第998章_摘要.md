# 第998章 领域魂种

**概要**：冰河渐解，莫凡穆宁雪因终极引雷与冰晶刹弓精疲力竭，深知正常应对不知战到何时且易逃跑，更认清实力之重要。轮船已毁，二人只能徒步返回，所幸歹蛆伪龙完全体疫苗到手，回提诺阿亚城溺咒应得解决。鲍比问是否再无人溺咒死，灵灵摇头说生物进化、歹蛆不灭可寄生妖魔，将来或出现越过疫苗的更可怕小魔鬼。莫凡沉思种族延续与进化，感灵灵父猎人职责亦是前进。疫苗归灵灵处理，猎者联盟提升莫凡称谓，媒体头条称青天猎所解决世界疫咒获巨额悬赏——灵灵低调归名。赵满延凑问，确认是莫凡灵灵干活，嫉妒悬赏金。莫凡捏火红晶体喂小炎姬，与赵满延议去国际魔法卖场，盘算卖国府资源加悬赏共五亿买魂种，穆宁雪将全数悬赏给莫凡，赵满延报领域魂种需六亿起、成交约八亿。

**关键事件**：1.疫苗到手、灵灵点明歹蛆难灭 2.悬赏归青天猎所、莫凡称谓提升 3.议买魂种，穆宁雪全给悬赏、领域魂种价高

**逐章写法公式**：

- **情绪流向**：起：战后疲惫的余波 → 承：疫苗与进化论铺垫 → 转：悬赏归属与称谓提升 → 合：魂种新目标的钩子
- **节奏配比**：慢铺垫 40% / 快冲突 0% / 爽点爆发 10% / 悬念留白 50%
- **本章结构公式**：冰解休整（收束） + 灵灵清醒（升华） + 悬赏归属（落袋） + 魂种议价（新目标）
- **本章核心技巧**：用大事件后的清醒认知做主题升华，再顺势抛出魂种新目标
- **卡点与伏笔**：结尾卡点：类型其他+莫凡如何凑领域魂种引下章；埋设/回收伏笔：领域魂种价高→后续沙漠救援赚钱伏笔
