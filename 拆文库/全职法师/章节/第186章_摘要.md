# 第186章 （无标题）

**概要**：莫凡跑得飞快，没听清灵灵最后一句警告，冲进室内篮球室听见拍球声，以为找到可以联手灭妖的同学，还回头微笑面对追来的三只青黄女妖。女妖冲入场内朝莫凡方向发出啼叫，正在打比赛的一队人应声一个个痛苦倒地，用变长的指甲生生撕开皮肤、露出青黄色鳞片——灵灵那句"室内篮球场全是红点"不合时宜地飘进来，莫凡意识到身后整支女篮队全被寄生，十几人的"帮手"瞬间变成包围自己的黑子。他来不及逐个割拇指，果断开启血兽靴狂奔逃出光线充足、无处遁影的球场，血兽靴又救他一命。女妖们如橄榄球队般叠层涌入选手通道追击，莫凡跑到通道尽头反身设伏，玫炎·烈拳·轰天将烈拳集中于右手轰出，整条通道被玫瑰火焰填满，五只女妖尽数焦黑毙命，通道外两只也被气浪轰得半身不遂。灵灵点评这些只是奴仆级，实力与智商都不如杰作私家花园那两只。

**逐章写法公式**：

- **情绪流向**：起：轻松（以为找到帮手、回头得意） → 承：恐怖（全场集体蜕皮反包围） → 转：紧张（血兽靴逃命） → 合：爽（通道尽头烈拳一击团灭）
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：误判帮手（安全感铺垫）+全场异变（恐怖反转）+装备逃生（危机处理）+通道团灭（战术爽点收束）
- **本章核心技巧**：用"希望→绝望→反杀"的三段翻转写遭遇战，先给主角一个虚假的援军，再让援军整体变成敌军，把恐怖感做在信任崩塌上。
- **卡点与伏笔**：结尾卡点：余敌未清——还有女妖未入通道只是半身不遂，且灵灵定性奴仆级，暗示更强的母体另有其人；埋设/回收伏笔：血兽靴→朱校长赠礼再次救场；女篮队集体寄生→宿舍制传染的后果兑现；奴仆级与杰作私家花园两级对比→幕后母妖实力阶梯铺垫。
