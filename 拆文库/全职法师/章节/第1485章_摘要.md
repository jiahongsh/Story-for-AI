# 第1485章 有实力，会装B

**概要**：李夕眉惊得合不拢嘴，李、郑二教授半晌才回神、被莫凡力量震撼。赵满延竖大拇指，目光斜瞥佩里院长。李教授表面叮嘱莫凡留颜面，内心大爽，甚至想让孙女李夕眉勾搭这"有实力还会装B"的年轻人；郑教授含蓄代明珠谢过。赫卡萨皮笑肉不笑认捐物资，班波王子因无权开皇家海学院交换生而尴尬。莫凡笑称"小班波多向我学习"。班波迁怒佩里院长，质问为何不派最强学员——海蒂就在旁由珈蓝治疗，闻言怒目。珈蓝劝海蒂"挫败是好事"，称能击败莫凡却非真正的她，次元法师先要战胜自己。佩里院长则恨莫凡坏了她讨好赫卡萨的大事。

**关键事件**：1.众教授震撼 2.李教授内心大爽 3.赫卡萨认捐、班波尴尬 4.珈蓝劝海蒂战胜自己 5.佩里恨莫凡坏好事

- **情绪流向**：起：众惊的震撼 → 承：李教授暗爽的滑稽 → 转：班波露怯的轻松 → 合：珈蓝点化与佩里怨愤
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 30% / 悬念留白 25%
- **本章结构公式**：众震于火力（收爽点）+ 李教授暗爽撮合（调剂）+ 班波赫卡萨认输（压对家）+ 珈蓝点化海蒂（埋成长）

- **卡点与伏笔**：结尾卡点：类型+内容+下章期待（佩里恨莫凡，下章赫卡萨突生毒咒危机）；埋设/回收伏笔：珈蓝"战胜自己" → 海蒂后文心性历练伏笔
