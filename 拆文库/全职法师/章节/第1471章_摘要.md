# 第1471章 报复计划

**概要**：教罚处是一座半山浅蓝城堡，负责学府安危与处罚。深夜莫凡、穆白、赵满延被横眉女巡逻法师以"吃大半烤兔"人赃并获地带到城堡坪前。教罚处老师布兰妾年纪与海蒂相仿、韵味十足却灭绝师太般严厉，全身裹得严实只露额头，莫凡曾猜她受过心灵重伤，不想转眼落入她手。布兰妾厌恶三人无视规矩，赵满延辩称已出学府区域，布兰妾加重"不得伤害小生灵"的语气；李、郑教授与石俊盛（幸灾乐祸）赶来，海蒂、伊迪丝、雪莉尔随后到场，二女对望窃喜，莫凡确认正是她们举报且此前含糊告知规矩、故意坑人，遂起"不给教训不姓凡"之念。珈蓝求情称他们误将"阿尔卑斯山"理解为学府范围，布兰妾仍坚持规矩必执行，判禁闭半月；莫凡问禁闭给吃肉否，被布兰妾视为挑衅。后半夜放回后，赵满延在咖啡书屋大骂屈辱，莫凡与赵满延决意报复，穆白被问及能否配催情药，遂在午餐番茄浓汤中投药，欲让雪莉尔、伊迪丝下午陪同时许身燥热出丑。汤按序分碗，莫凡因餐桌有超强法师而在上桌前投放，却算错空位——那碗有料的汤正落在临时入座的布兰妾面前，布兰妾未察觉饮下。三人惊知布兰妾是近三十年最天才、修为超老教授、仅海蒂可比的隐居高手，慌忙收拾行李欲逃，怕药力过后被活剐。

**关键事件**：1.烤兔被抓至教罚处，布兰妾主罚 2.二女举报坑人，莫凡立誓报复 3.禁闭半月，莫凡问吃肉 4.催情药误投布兰妾汤中 5.知布兰妾是高手，三人欲逃

**逐章写法公式**：

- **情绪流向**：起：被抓受罚的憋屈 → 承：识破二女坑人立誓报复 → 转：投药计划反噬布兰妾 → 合：知是高手慌逃的紧张
- **节奏配比**：慢铺垫 20% / 快冲突 5% / 爽点爆发 15% / 悬念留白 20% / 日常轻松 40%
- **本章结构公式**：烤兔被抓受罚（抑） + 识破举报立誓（愤） + 投药误中布兰妾（反） + 知高手欲逃（惊）
- **本章核心技巧**：用"精准恶作剧→算错座位→踢到铁板"的三段式把喜剧反转成紧张，结尾以高手身份点爆危机
- **卡点与伏笔**：结尾卡点：悬念型——布兰妾饮下药汤，药力将至三人欲逃；埋设/回收伏笔：魔法手环→下章限制逃跑；布兰妾高手身份→为后续雪山事件与追凶埋伏笔
