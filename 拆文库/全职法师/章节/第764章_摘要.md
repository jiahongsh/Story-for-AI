# 第764章 幻境寻妖

**概要**：蒋少絮按南珏之法催眠莫凡与艾江图，南珏引二人魂念入木鱼，木鱼本身的诅咒系魔法将灵魂吸扯锁入器皿，正是市民口中"勾魂"；莫凡睁眼后发现蒋少絮、南珏与木鱼皆消失，来时杂草掩埋的小路竟变空旷洁净，返回寺庙见后厨和尚忙碌、香客络绎，与先前冷清迥异，胖和尚日语斥其擅入后山，二人听不懂，急寻同伴却见厢房住满上香客。莫凡疑穿越，艾江图沉思后点破二人已入器皿世界——木鱼内天地即此寺庙、依宫田记忆所造，诅咒与心灵系结合成真实噩梦，艾江图警其不可妄为杀人，莫凡嚼菜根时鼻嗅淡玫瑰香，方知蒋少絮在旁护法、二人肉身未挪，站山寺前却为满城栩栩如生的虚幻人、难觅妖灵而犯难。

**关键事件**：1.莫凡艾江图魂入木鱼幻境，同伴与木鱼消失 2.识破幻境即器皿世界、依宫田记忆所造 3.莫凡借淡玫瑰香知肉身未挪，难寻妖灵

**逐章写法公式**：

- **情绪流向**：起：魂入器皿 → 承：感官错位加压 → 转：点破幻境 → 合：香味锚定现实留难
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：入幻境（起） + 错位惊疑（加压） + 点破身份（转折） + 香味锚定（收束留难）
- **本章核心技巧**：用"感官逐项错位"建立异界不真实感，再用一句定性收束，最后以香味锚回现实
- **卡点与伏笔**：结尾卡点：满城虚幻人难觅妖灵（强悬念）；埋设/回收伏笔：淡玫瑰香 → 蒋少絮护法锚点；器皿依宫田记忆 → 寻妖线索
