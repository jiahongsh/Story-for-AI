# 第800章 跑出去一只

**概要**：凝华邪珠察觉将被收回东守阁，竟自行滚向路边排水口企图借下水道老鼠寄生逃脱，莫凡以意念将其挪回并掩饰为看错。望月名剑赶到，邪珠在其威压下惧成死珠，被银布包裹，他封锁消息以免高木知晓。名剑将二人带入星空般的冥室，承认凝华珠实为众邪法师怨、邪、婪等残念在黑暗大阵中滋长的产物，并警示若非莫凡阻拦，新的红魔将降临日本。当名剑说明红魔死后灵魂烙暗红印记时，莫凡猛然联想到灵灵父亲与吸血鬼聂东之死，断定东守阁多年前曾跑出一只红魔，名剑震骇默认。

**关键事件**：1.邪珠欲借下水道逃走被莫凡挪回 2.望月名剑到场以银布封珠并封锁消息 3.名剑说明邪珠为残念滋长之物，警示新红魔危机 4.莫凡由暗红印记联想到旧案，逼问出名剑跑出过红魔

**逐章写法公式**：

- **情绪流向**：起：邪珠逃窜的紧张 → 承：名剑封珠、带入冥室的压抑 → 转：残念滋长真相与红魔警示 → 合：暗红印记勾连旧案的大钩子
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：邪珠逃窜被阻（小冲突） + 名剑封珠保密（收束） + 解说邪珠本质（扩设定） + 暗红印记逼问红魔（大钩子）
- **本章核心技巧**：用一枚暗红印记把本卷新谜与跨卷旧案回扣，借配角震骇默认坐实秘辛
- **卡点与伏笔**：结尾卡点：上一代红魔往事，下章期待名剑讲述；埋设/回收伏笔：暗红灵魂印记 → 回扣灵灵父、聂东之死
