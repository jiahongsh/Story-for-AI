# 第43章 处处心机！

**概要**：穿过河谷与比人高的杂草丛，学生们终于望见百草山谷，入谷狭道里树藤草藤交错如青黑色蟒蛇窝。王三胖逞英雄开路，踏入藤蔓领地即被会动的妖藤五花大绑倒吊起来，藤上荆棘划破肥皮鲜血直流；许昭霆施雷印蟒痕鞭打妖藤，植物天生抗雷，妖藤只稍缩又继续拖人，更有一根藤条勒住王三胖咽喉令他喊不出声。妖藤又抓住水系女生郑云霞的脚踝，她吓得连星尘都忘了。班长周敏娇喝出手，连成火系星轨施放火滋灼烧，妖藤见火如见鬼轰散，王三胖滚肚落地保住脸，全班欢呼班长威武；许昭霆脸色难看，莫凡则全程未出手——周敏的火滋还停在第一级，而自己的火滋出发当天已提升，能省点蓝是一点。帐篷里，斩空对火系少女周敏颇有好感；一组进度最快，靠穆白冰冻妖藤即将遭遇幽狼兽。唐月惊问白阳不是传说阵亡的光法师吗，斩空笑答那是编的，白阳是驿站召唤系法师，而蓝色的镯子是真的，就在巢穴里。

**关键事件**：1.王三胖开路被妖藤倒吊，许昭霆雷印无功 2.周敏火滋灼烧驱逐妖藤救下两人，莫凡藏拙不出手 3.斩空揭白阳阵亡系编造、蓝镯子真在巢穴，一组即将遭遇幽狼兽

- **情绪流向**：起：抵达谷口的松气 → 承：王三胖被缚、雷印无功的惊乱 → 转：周敏火滋解围的爽 → 合：蓝镯子悬念的收紧

- **本章结构公式**：谷口藤道（铺环境）+ 妖藤缚人（引爆危机）+ 雷败火胜（属性克制爽点）+ 帐篷揭秘与蓝镯子（埋终极钩子）

- **卡点与伏笔**：结尾卡点：悬念型——一组即将遭遇幽狼兽，蓝镯子真在巢穴，下章期待妖魔现身；埋设伏笔：莫凡火滋出发当天升级 → 对战召唤兽的底牌；蓝镯子 → 巢穴目标物；白阳与幽狼兽有分寸 → 幽狼兽失控的反转前奏
