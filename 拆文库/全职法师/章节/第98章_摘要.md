# 第98章 街战猩鼠！

**概要**：张小侯以二级风轨·闪步把咬死张英璐的巨眼猩鼠引开，在杂乱停放的车辆间灵巧穿梭周旋。莫凡爬上巴士顶，借寻妖粉飘动方向发现另一只猩鼠躬身躲在公交广告牌后，其瞳孔即将释放能打穿人体的腥红光束且正锁定张小侯；薛木生及时施展光系光耀·失明，强光灼瞎它的双眼令其乱撞哀嚎，张小侯趁机脱身归队道谢。莫凡以全场最快速度连起星轨，三级火滋·爆裂不给猩鼠闪躲余地，把行凶那只巨眼猩鼠轰上奶茶店卷铁门，毛发焦落、皮肉绽开，薛木生看在眼里暗忖先锋小队有莫凡在不至于全军覆没。王三胖欲上前生剥猩鼠为同学报仇，莫凡喝止不及，诈死的猩鼠突然窜起咬下他肩头一块血肉；许昭霆怒施雷印·狂策将其抽得无法动弹，再与周敏、张树华合力把它轰得稀烂。众人毫无轻松之意，最强学生组成的先锋小队第一次遇妖魔就一死一伤。薛木生任命熟悉妖魔习性的莫凡带队指挥，自己与吓得神志恍惚的何雨负责保护，严令她下次遇袭必须放出水御，否则剩下九人和身后四千民众都会失去方向；何雨满脸泪水说完成不了星轨，薛木生鼓励说相信她能做到。

**关键事件**：1.薛木生用光耀·失明救下被腥红光束锁定的张小侯 2.莫凡三级火滋·爆裂重创巨眼猩鼠 3.诈死猩鼠咬伤王三胖后被许昭霆三人合力轰杀 4.薛木生任命莫凡带队并逼何雨承担水御职责

**逐章写法公式**：

- **情绪流向**：起：紧张（张小侯引怪周旋） → 承：恐怖（腥红光束锁定+诈死反扑） → 转：爽（光耀失明+火滋爆裂+雷印抽杀） → 合：压抑（一死一伤，何雨哭着领责）
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：引怪周旋（立险）+暗鼠锁定光束（加压）+光耀救场火滋重创（转折爆发）+诈死反扑合杀后压责（余波与新钩）
- **本章核心技巧**：在爽点中段插入诈死反扑再补一刀，避免一顺到底；战局刚定就用伤亡余波和责任移交把紧张感续存到下一章。
- **卡点与伏笔**：结尾卡点：任务悬念——何雨能否在下一次妖魔袭击时放出救命水御，九名队友与四千民众系于她一身；埋设/回收伏笔：回收寻妖粉→锁定第二只猩鼠；薛木生授权莫凡带队→莫凡指挥地位确立；王三胖肩伤→队伍伤员负担；腥红光束→猩鼠能力谱系。
