# 第413章 真心相爱

**概要**：牧奴娇红着脸佯怒骂艾图图别瞎说，艾图图却凑到莫凡耳边点破：牧姐姐回来后爱损他、爱泼冷水，不是真讨厌就是喜欢上了；还补刀说上门女婿又没说是牧奴娇。莫凡顺势认真表态"给她做上门女婿，不送魔具我也去"，艾图图又拿牧家联姻行情打压他：牧奴娇这等掌上明珠至少要捆绑回有希望至尊超阶的高阶法师，聘礼得高质量魔具堆满房间，没有倒贴的说法。莫凡仰头感慨"万恶的阶级社会容不得真心相爱"，牧奴娇听不下去逃回房间，心里吐槽艾图图当初说好一起惩治大魔头如今却联手上阵，还留意到艾图图一提大魔头眼睛就发亮。挑战周临近，莫凡抓紧修炼，出门吃饭都被举着手机的人喊"活捉火系赵日天"，这外号让全校皆知。前三百名专享的训练场（移动靶加魔法石台）让他彻底明白排行低者疯狂挑战的缘由，也让他头疼怎么在车轮战中保住第一百名特权。转角处他撞上火院倒数第一郑佳慧，对方自暴自弃打算念完这一年就离开明珠学府，莫凡眼睛一亮抛出交易：帮他做件事，就给不菲修炼资源、帮他摆脱最后一名，酬劳是借他星云魔器修炼。

**关键事件**：1.艾图图点破牧奴娇口是心非 2.莫凡被冠名火系赵日天 3.莫凡撞上郑佳慧并抛出交易 4.郑佳慧自暴自弃想退学

- **情绪流向**：起：甜（调笑上门女婿） → 承：搞笑（真心相爱梗笑倒众人） → 转：紧张（赵日天之名与挑战压力） → 合：悬念（郑佳慧交易成形）
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：感情戏调笑（推进暧昧）+ 名声发酵（放大主角声量）+ 特权体验（交代挑战制度根由）+ 偶遇收编（开启保名计划）
- **本章核心技巧**：先用群口相声式的三人互怼推进感情线，再用一个底层角色的困境给主角的计谋当引子，两线都靠对话扛
- **卡点与伏笔**：结尾卡点：计谋悬念——莫凡要郑佳慧做的事未揭晓，期待保名计划；埋设/回收伏笔：火系赵日天外号 → 全校声量梗；星云魔器作酬 → 交易筹码；艾图图眼睛发亮 → 艾家召婿调侃线；郑佳慧大半年垫底 → 末名翻身线
