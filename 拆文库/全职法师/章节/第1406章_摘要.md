# 第1406章 八方亡君（下）

**概要**：八方亡君除幽灵统帅外三大已现，山峰之尸为铠袍帝王开道、边行边抛肉丘尸臣袭金字塔，鬼统帅瓦解邪鳞法老，骸刹骨龙率骷髅海成冲锋军团、可同化冥界生物为骷髅。其余五位亡君依次现身，以铠袍为中心形成亡灵漩涡碾压前进。羊头魔君率双胞牛鬼冲锋，玛瑙尸君出战肉搏踩碎魔杖，刀斧尸将组绞肉战车破开冥军、因戾剑死侍早被瓦解而无阻；羊头倒后双胞牛鬼被碾，肉丘尸臣吞吃其骨化为新骷髅听令骨龙。另三亡君——红骷魔主、鬼魖君王（真身）、九幽后随侍，九幽后以摄魂之瞳印画面于莫凡脑海，被铠袍制止后笑言可治愈。骷髅海没过宏伟之墙，冥军聚屯回防；铠袍嗤之以鼻"我的杰作竟被糟蹋"，莫凡疑其身份。此时一只黑色夜煞之蝇飞来——是冷爵，莫凡战意重燃绝不放其逃走。

**关键事件**：1.八方亡君齐聚成亡灵漩涡碾压冥军 2.玛瑙尸君破双胞牛鬼、肉丘同化造骷髅 3.九幽后摄魂被止，莫凡借夜煞之蝇锁定冷爵

- **情绪流向**：起：八方亡君齐聚的震撼 → 承：玛瑙破阵、同化造骷的碾压 → 转：九幽摄魂被止的诡异 → 合：冷爵线引爆、莫凡战意重燃的钩子
- **节奏配比**：慢铺垫 10% / 快冲突 50% / 爽点爆发 20% / 悬念留白 20%
- **本章结构公式**：亡君齐聚漩涡（全景） + 玛瑙破双胞（局部胜） + 九幽摄魂被止（诡异） + 夜煞现冷爵（钩子）
