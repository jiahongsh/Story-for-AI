# 第93章 血染博城

**概要**：林雨欣启动地圣泉紧急保护方案：按下机关令圣泉尽数流入小孔，再掀开莫凡坐热的皮蒲团、打开隔板取出装着全部泉水的一只蓝瓶。她在石墙上如输密码般摁开一条通往天澜高中后山的密道，并把装泉之瓶托付给莫凡——黑教廷有备而来、必以她这副卫长为目标，作为学生的莫凡反会被忽视。莫凡追问何事，得到的答案是全城已拉响血色警戒；他忆起课本常识：血色警戒即成百上千妖魔入城的毁灭与屠杀。两人穿过密道抵达城中山北面，大雨中的博城血迹斑斑，居民区菜市场的活人鲜血汇成小溪注入下水道；抬头望去，银贸大厦顶端趴着一头尾巴垂落近半楼高、肉翼遮蔽十几层写字楼的巨大妖魔。

**关键事件**：1.地圣泉收入蓝瓶并托付莫凡 2.林雨欣告知血色警戒已拉响 3.博城血染、巨兽盘踞银贸大厦之顶

**逐章写法公式**：

- **情绪流向**：起：抢救紧张 → 承：托付沉重 → 转：知识回冷 → 合：地狱俯瞰
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：收泉取瓶（抢救行动）+ 密道托付（责任转移）+ 血色警戒科普（定性灾难）+ 出密道见血城巨兽（灾难全景）
- **本章核心技巧**：先给主角一件必须保住的随身物，再让灾难全景压顶，把"逃难"升级成"带宝逃难"
- **卡点与伏笔**：结尾卡点：银贸大厦顶端的巨兽身份未揭；埋设/回收伏笔：地圣泉蓝瓶（莫凡的烫手责任、贯穿后文的携带物）、黑教廷有备而来（幕后敌线）、血色警戒分级知识（世界观标尺）
