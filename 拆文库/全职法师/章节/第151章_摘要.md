# 第151章 怎么是他？

**概要**：萧院长果断请七位召唤系新生上台，宣称击败了他们就是今日真正的主角，斗馆沸腾。土系坐席里甜美的秦小棉认出莫凡，惊讶出声；她给觉醒师师傅郭立语发短信，得知莫凡正是当初审判员介绍来觉醒的年轻中阶魔法师，如今竟靠觉醒仅一年的召唤系考进明珠学府，郭立语连发惊叹并怂恿徒弟去认识人家，秦小棉脸红，这一幕全被李俊巍看在眼里，他锁定莫凡放话谁跟他抢秦小棉谁死得惨。同坐席的罗宋认出莫凡，决定不当场摊牌、要慢慢玩，并自信一人能灭掉召唤系所有召唤兽。雷系坐席上，博城旧同学许昭霆瞪大双眼呆滞失神，向同伴透露自己认识莫凡时他不是召唤系，女孩惊觉莫凡是中阶魔法师；许昭霆自认历练、穆氏双系展现、灾难应对都远不及莫凡，不愿说穿他隐藏的系别以尊重这位救下博城的人，只含糊称他召唤系刚学应该不会太强。

**关键事件**：1.七名召唤系新生登台，院长宣布击败他们就是主角 2.秦小棉、罗宋、许昭霆三路旧识各自认出莫凡 3.许昭霆守住莫凡中阶的秘密，李俊巍生妒

**逐章写法公式**：

- **情绪流向**：起：新生登台的沸腾 → 承：三路认人的各怀心思 → 转：许昭霆揭秘中阶的震动 → 合：他摇头守密的余味
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 35% / 悬念留白 20%
- **本章结构公式**：院长请主角上台（点燃） + 秦小棉郭立语短信线（旧事揭底） + 罗宋李俊巍敌意线（埋雷） + 许昭霆守密线（抬主角收章）
- **本章核心技巧**：主角一句话没说，全章用观众席三个熟人视角把他的过去、实力、人望全部翻新一遍——「缺席的主角」式烘托
- **卡点与伏笔**：结尾卡点：期待型（悬而未决），莫凡中阶身份知情人增加但无人当场说破，斗兽一触即发；埋设/回收伏笔：博城觉醒店旧事（前文）→ 秦小棉即当年女学徒，人物回收同时为她与莫凡后续交集埋钩；罗宋「慢慢玩」→ 指向下章斗兽大赛阴招
