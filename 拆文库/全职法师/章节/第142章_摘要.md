# 第142章 次元召唤

**概要**：莫凡打电话向唐月请教召唤系知识，说明市面上次元魔法的书少之又少，唐月听出不怀好意却更诧异他觉醒了召唤系，约他来杭州西湖。莫凡坐动车再赴杭州，路上幻想召唤兽能当免费霸气的专车。唐月住在推窗可望西湖全貌的高档公寓，闺房挑口红的她忽然想起出租车后座那个快不能呼吸的激吻，脸颊羞赧，自语不是说好不见这家伙的，一年过去见面还是火辣辣，最终说服自己坦然赴约。西湖边重逢，唐月回头率极高，莫凡暗自得意。散步中唐月开讲：召唤系是所有魔法系中浮动最大的，用得好等同领域无敌，用得不好跟遛狗的普通人没区别；初阶魔法师往往要组队才能击杀奴仆级妖魔，召唤出等同妖魔战力的生物等于开局就有初阶团队层次，比雷系还变态。次元召唤的机制是意识进入召唤兽位面飞速游荡搜寻生物，遇到的召唤兽完全不同，如动物园闭眼一抓；以中阶魔法师的意念召唤多半能呼唤实力较高的生物。唐月还提及世界位面并非单一、许多神秘位面与我们平行，而莫凡心里翻腾——他自己就是从别的位面过来的。

**关键事件**：1.莫凡赴杭州向唐月系统请教召唤系 2.唐月重逢前对激吻旧事脸红心跳 3.莫凡获知次元召唤的位面机制与意念规则

**逐章写法公式**：

- **情绪流向**：起：轻松（电话调笑） → 承：甜（闺房心事与重逢） → 转：其他（体系讲解） → 合：紧张（意念决定召唤品质）
- **节奏配比**：慢铺垫 50% / 快冲突 5% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：请教借口（关系复联） + 赴约心事（情感线推进） + 散步授课（体系总纲） + 规则落点（意念强弱定品质）
- **本章核心技巧**：把枯燥的设定说明书包进"久别重逢的约会"里，一景一问交替推进情感线与知识线，两边都不过载
- **卡点与伏笔**：结尾卡点：轻卡点，次元召唤可能比高阶魔法还变态的结论收章；埋设/回收伏笔：回收出租车激吻（成为唐月心结）、回收莫凡觉醒召唤系（唐月诧异）、埋下召唤兽位面与平行位面观、埋下莫凡穿越者身份与位面话题的呼应、埋下"穷要找活干"的金钱线
