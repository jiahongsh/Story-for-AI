# 第366章 我是你的尹志平啊

**概要**：唐忠向祝蒙摊牌：即便瘟疫是图腾玄蛇所为也要保它性命，只接受驱逐，并拒绝透露其去向；祝蒙宣布隐患战略就是斩草除根、必杀不可，还放话眼线已发现唐月与一男子在白镇附近，最迟明天斩下蛇头示众。白镇瞭望塔上，武平景令见习与预备审判员先行追击、侍卫待命，并向部下科普蜕皮期的玄蛇实力弱如普通妖魔、唐月身边男子只是中阶法师。白山山脚平原上，疾星狼载着两人狂驰时遭神秘植物系法师伏击，藤蔓织成牢笼、化作钢索抽打，疾星狼头部中鞭翻滚，两人滚落草丛，狼被藤蔓捆死；对方藏身不露、以枪状藤蔓直取两人要害，目的就是拖延等支援。莫凡用遁影躲过袭杀，唐月部署自己打掩护、莫凡潜行用魂影钉禁锢对方。

**关键事件**：1.唐忠拒透蛇的去向、祝蒙放话明天斩蛇头 2.武平景坐镇白镇待命 3.平原遭植物系法师藤蔓伏击、疾星狼被擒 4.两人定下反猎分工

**逐章写法公式**：

- **情绪流向**：起：压抑（必杀宣言与拒透行踪） → 承：紧张（行踪暴露的倒计时） → 转：紧张（平原藤蔓伏击） → 合：热血（遁影反猎的分工）
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：立场对峙（宣战） + 敌情交代（追兵部署） + 藤蔓伏击（遭遇战） + 分工反猎（反击启动）
- **本章核心技巧**：先让高层把"必杀"与"时限"喊满，再把冲突落到一场敌人全程不露面的植物系伏击上，用未知维持压迫。
- **卡点与伏笔**：结尾卡点：反击启动型——唐月掩护、莫凡遁影寻敌，期待揪出植物系法师；埋设/回收伏笔：敌人只拖不打等支援→后续更多追兵将至；蛇的感知避开宫廷侍卫→逃亡战术依赖。
