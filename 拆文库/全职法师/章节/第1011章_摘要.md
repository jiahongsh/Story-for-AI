# 第1011章 金字塔，海市蜃楼

**概要**：莫凡回到营地后听江昱等人商议战事，对海市蜃楼竟能威胁城市感到不解，江昱从埃及亡灵与金字塔的关系讲起。埃及亡灵源自法老诅咒系魔法，始终围绕金字塔陵墓活动，现代城市已迁离金字塔领地以求井水不犯河水。江昱领莫凡登上南城山瞭望塔，莫凡亲眼看见妖异冰冷的金字塔虚影浮现于城郊。江昱点明海市蜃楼将金字塔折射到城市附近，亡灵无法分辨虚像，误以为人类侵占其领土而开战。江昱进一步说明金字塔分级别、共九十三座，最大为胡夫金字塔，提及胡夫海市蜃楼会令埃及半国沦陷，当地守卫闻言大怒，莫凡得知此说极其忌讳。

**关键事件**：1.江昱向莫凡讲解埃及亡灵与金字塔的因果 2.莫凡登瞭望塔目睹妖异金字塔虚影 3.江昱解释海市蜃楼折射引发亡灵战争 4.提及胡夫金字塔级别与忌讳

**逐章写法公式**：

- **情绪流向**：起：莫凡疑惑轻松 → 承：江昱科普加压 → 转：登塔见虚影惊疑 → 合：胡夫忌讳留钩子
- **节奏配比**：慢铺垫 60% / 快冲突 10% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：莫凡质疑海市蜃楼威胁（引疑） + 江昱讲亡灵金字塔因果（铺知） + 登塔亲见虚影（奇观） + 点破战争机制与胡夫伏笔（钩子）
- **本章核心技巧**：用角色问答推进设定科普，先抛奇观再给机制，借本地人反应做侧面烘托
- **卡点与伏笔**：结尾卡点：提及胡夫金字塔忌讳，制造更大威胁悬念；埋设/回收伏笔：海市蜃楼折射机制→后续进击金字塔的动机；胡夫金字塔→后期更大危机铺垫
