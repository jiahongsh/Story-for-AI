# 第140章 四系一起修！

**概要**：莫凡回到住处，见妹妹心夏在阳台恬静冥修，为了来年的魔法高考她也很勤奋。莫凡想分享觉醒的喜悦却不愿打扰，决定留到以后给她一个大惊喜，看着阳光下端庄娴美的心夏，他想起博城灾难夜许下的承诺——假如她不能走，就送她一双翅膀，而翼魔具贵到普通人几辈子买不起，他立志变强攒钱终有一天亲手兑现。回房后莫凡不敢浪费一点时间闭关苦修：四系觉醒只意味着更大的提升空间，需要更多时间与资源，幸好吸纳了地圣泉的小泥鳅坠让他冥修速度硬性提升约两倍（对比凡品星尘魔器加两成、灵品加四成），不冥修时滋养效果仍潜移默化涨修为。三个月后暗影系星尘达到当初花一年才有的水准，莫凡推算小泥鳅2.5倍加成只能解释半年多，多出来的部分说明自己冥修效率还提升了约1.5倍，如同老爹拉扯大两个熊孩子后带老三老四信手拈来。暗影、召唤两系星尘到可释放程度后他开始哄骗星子建信任，并忍住施展新技能的冲动，把时间全砸在连接七颗星子的基本功上。

**关键事件**：1.莫凡许诺终有一天送心夏翼魔具翅膀 2.小泥鳅坠令冥修速度提升两倍四系同修 3.三个月暗影系星尘速成一年水准，莫凡推迟技能练习专攻基本功

**逐章写法公式**：

- **情绪流向**：起：温馨（阳台看心夏） → 承：心疼（轮椅与翅膀之诺） → 转：爽（外挂与速成） → 合：热血（基本功宣言）
- **节奏配比**：慢铺垫 40% / 快冲突 5% / 爽点爆发 40% / 悬念留白 15%
- **本章结构公式**：亲情锚点（翅膀之诺） + 外挂量化（小泥鳅2倍） + 速成验证（三月抵一年） + 方法论收束（基本功优先）
- **本章核心技巧**：用"许愿—装备标价—攒实力"的情感闭环给修炼章注入动力源，再用可复算的数值拆解把无战斗的修炼过程写出爽感
- **卡点与伏笔**：结尾卡点：轻卡点，莫凡忍住不练释放、坐等大学场地，暗示入场后的爆发；埋设/回收伏笔：回收博城灾难夜的承诺（翼魔具）、回收小泥鳅坠吸收地圣泉（品阶再蜕变无法判定）、埋下心夏来年魔法高考线、埋下四系同修的资源缺口
