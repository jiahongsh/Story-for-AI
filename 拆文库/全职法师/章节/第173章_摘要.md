# 第173章 魔都城管！

**概要**：离开图书馆，莫凡盘点手头资源：玫炎市场价超两千万、雷种更贵，两百万奖学金买不起灵种，便决定先改善生活——给考入浙江名校、行动不便的叶心夏雇个阿姨照顾，以后再雇女保镖。他采纳萧院长实践与苦修结合的建议，决定重操旧业做城市猎法师，理由是当初东方世家四名中阶法师正因战斗经验不足被朝赫的诅咒技能一网打尽，而且做猎法师才有钱赚。他婉拒了张平谷约见水系女生的邀请，前往陆家嘴的猎者联盟大厦。五十层大厅人流庞大、滚动着全国乃至国外的悬赏信息，但女助理告知：在魔都做城市猎妖人至少需要猎人精英称谓，莫凡在博城提交的数据只是中级猎人、贡献值785，离猎人精英还差9215，只能慢慢积累。莫凡苦笑自己把事情想得太简单，做魔都城管还得是博士学位。女助理随即提议他可以考虑私人猎所——由知名猎人团队或大师创办，雇主主动上门、完成率可靠、对称谓没有硬性要求。莫凡一拍桌子拍板就这个了，自封专治疑难杂症的神探莫凡。

**关键事件**：1.两百万先用于改善生活与心夏安置 2.决定重操猎法师旧业 3.猎者联盟遇称谓门槛 4.转向加入私人猎所

**逐章写法公式**：

- **情绪流向**：起：轻松（盘钱的日常） → 承：热血（重操旧业的决心） → 转：压抑（称谓门槛被拒） → 合：期待（私人猎所的新路）
- **节奏配比**：慢铺垫 45% / 快冲突 15% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：巨款盘算（金钱落点） + 猎法复兴（职业规划） + 联盟碰壁（制度壁垒） + 猎所指路（新舞台开门）
- **本章核心技巧**：用资质数字壁垒把主角逼离大路，让职业线转向时不需要任何外力巧合。
- **卡点与伏笔**：结尾卡点：莫凡选定私人猎所路线并自封神探，下章期待猎所面试与搭档；埋设/回收伏笔：东方世家四中阶败于朝赫诅咒→回收前文并强化实战优先的价值观；心夏在浙江名校→异地安置的长期牵挂；灵品雷种的价格悬念→雷系进化目标。
