# 第79章 魔法决斗！

**概要**：邓凯看到宇昂一身魔器魔具差点从椅子上跳起来，数不出他身上有几件装备，校方人员心寒，莫凡只有一件镰骨盾；穆卓云点名邓凯做裁判，等着看猫虐鼠的好戏。邓凯宣布点到为止后退到可马上出手的位置；握手时宇昂掌心凝出寒冰偷袭，寒气要侵入莫凡骨髓，莫凡手臂通红以火焰守护，另一只手竖中指回敬，两人互撂狠话。回到位置后莫凡环视满场嘲笑与同情的眼睛，暗誓今天让他们全部闭嘴。开战后莫凡星轨连成速度极快，却只释放了一级的火滋·灼烧，教官罗云波当众疑惑他为何不用更强的焚骨；宇昂不慌不忙施展冰蔓·凝结，赛场从酷热盛夏骤转凛冬，冰蔓覆盖莫凡所在的大片区域，三秒冻人的规则令满场观众喊他快跑，莫凡不跑反而咧嘴而笑——掌心的火滋没有朝宇昂抛去，这火滋·灼烧他自有妙用。

**关键事件**：1.宇昂握手凝冰偷袭被莫凡火焰化解 2.莫凡抢先只释放一级火滋·灼烧引众人疑惑 3.宇昂冰蔓·凝结封场，莫凡不退反笑留下悬念

**逐章写法公式**：

- **情绪流向**：起：压抑（装备碾压）→ 承：紧张（握手偷袭与狠话）→ 转：紧张（冰蔓封场众人喊跑）→ 合：紧张（主角反常站桩留钩）
- **节奏配比**：慢铺垫 30% / 快冲突 50% / 爽点爆发 10% / 悬念留白 10%
- **本章结构公式**：清点装备立绝望（压）+ 握手偷袭互撂狠话（点火）+ 一级火滋示弱（设疑）+ 冰蔓封场主角不跑（留钩）
- **本章核心技巧**：先立三秒必冻的规则共识，再让主角当众违反规则，用旁观者的错愕把悬念顶到章末。
- **卡点与伏笔**：结尾卡点：战术悬念型——掌心火滋自有妙用，等下章揭晓；埋设/回收伏笔：罗云波的疑惑（为何不用焚骨）→ 为灼烧的巧用铺垫；邓凯站位可随时出手 → 为裁判即时救场埋线；镰骨盾被点名 → 压低读者对魔具的预期。
