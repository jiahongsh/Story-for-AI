# 第839章 背后的势力

**概要**：穆宁雪不愿莫凡浪费资源，点破国府之路的残酷才刚开始——越近威尼斯，大势力越会疯狂砸资源，星河之脉只是开端；连这道小槛都自跨不过，将来更无资本比拼。她称莫凡是全队最特殊者，无人知他背后是谁、实力从何来，一切靠己，故不关心旁人是自修还是被扶，也希望他明白自己拒收的原因。莫凡长叹"砸一亿女人投怀"的定理在已拥有一亿的女人面前失效。回东海城他一脚踢开赵满延房门，感应到对方气息变了——赵满延竟用了三份星河之脉突破，还妄图骗老爹再弄一份偷给莫凡应急，却被监察抓包骂得狗血淋头，其赵氏股东会议甚至递了咔嚓他的协议。赵满延劝莫凡趁早买脉送穆宁雪，莫凡亮出已送过的星河之脉，赵满延竖大拇指。莫凡借此问穆宁雪所言是否真——赵满延鄙夷这草根竟不知国府是势力之争，继而揭底：江昱是帝都宫廷首席庞莱弟子，黎凯风背后校联、其家族供长江以南所有魔法高中器具，穆婷颖出自庞然大物穆氏世族；莫凡忆起小泥鳅吃过学校星尘魔器、穆卓云不过大穆氏一分支。

**关键事件**：1.穆宁雪析资源比拼拒受、莫凡叹砸钱定理 2.莫凡踢门、赵满延三份星河突破 3.赵满延偷脉被抓、劝送反见莫凡已送 4.赵满延揭江昱/黎凯风/穆婷颖背景

**逐章写法公式**：

- **情绪流向**：起：资源比拼的实 → 承：赵满延突破的笑 → 转：偷脉被抓的喜剧 → 合：群像背景揭底的惊
- **节奏配比**：慢铺垫 20% / 快冲突 5% / 爽点爆发 0% / 悬念留白 15% / 搞笑 30% / 信息 30%
- **本章结构公式**：拒受析势（实） + 赵满延突破（笑） + 偷脉被抓（喜剧） + 背景揭底（惊）
- **本章核心技巧**：用活宝富二代当"设定播音员"，把势力图谱与草根盲区一并抖出。
- **卡点与伏笔**：结尾卡点：莫凡方知队友皆大有来头，下章期待他这"无背景者"如何自处；埋设/回收伏笔：小泥鳅吃星尘魔器 → 呼应前文，坐实莫凡"也算受惠者"的自嘲。
