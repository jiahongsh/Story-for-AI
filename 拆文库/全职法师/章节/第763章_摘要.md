# 第763章 器皿世界

**概要**：南珏以冰寒地孕育冰精灵、小炎姬喻元素生灵，说明器皿有魂亦可孕育妖灵，莫凡讶于木鱼里竟诞害人少女；南珏称器妖灵往往仅器皿拥有者可见，蒋少絮疑莫凡何能看见且被排斥，莫凡暴脾气欲砸木鱼，南珏却称南荣倪言须借妖灵方能唤醒、毁之穆宁雪赵满延或永醒不来。南珏提出解法：强大魂级器皿内有独立天地，可令灵魂神游进入内天地对付妖灵，莫凡以小泥鳅坠内天地为样本心领神会、迫不及待，蒋少絮惧灵魂脱壳拒入，艾江图艺高胆大与莫凡同入，南珏将掌按木鱼引雷丝忍痛，称先由蒋少絮催眠再引魂、意念强探会遭禁制反馈，并将此器皿视作制造幻境之绝品。

**关键事件**：1.南珏释器妖灵与内天地之法 2.莫凡欲砸被阻，改灵魂神游入内天地 3.蒋少絮拒入护法，艾江图与莫凡同入

**逐章写法公式**：

- **情绪流向**：起：器妖灵设定 → 承：毁器两难加压 → 转：内天地解法 → 合：分工入险
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：释设定（铺垫） + 毁器两难（加压） + 内天地解法（转折） + 分工入险（推进）
- **本章核心技巧**：用"先堵死毁器、再开灵魂神游"两拍给解法，借小泥鳅样本让新设定落地
- **卡点与伏笔**：结尾卡点：莫凡艾江图将灵魂入木鱼内天地（强悬念）；埋设/回收伏笔：小泥鳅坠内天地 → 设定锚点；器皿即幻境 → 下章展开
