# 第841章 淘汰之日

**概要**：赵满延骂莫凡不肯透古都内幕，点出那位罩他者必因古都浩劫中的大贡献才将其塞进国府。莫凡转身离去，赵满延独坐窗前忽疑：南荣世家最懂海洋妖魔，南荣倪怎会辨不出白泣妖婴儿哭声是假。与此同时穆婷颖在房中睁眼迎旭日，一份星河之脉便将冰系突破至高阶，畅快宣称从此可彻底碾压无脉的穆宁雪、重获世族宠儿之位。东海城再涨小潮，随众人陆续高阶、整队战力大涨。导师降临集合，封离评价"表现凑合"，松鹤替穆宁雪说情称其出色，封离却平淡点破"只有穆宁雪未达高阶"。蒋少絮开口求将奖励资源分给穆宁雪，穆婷颖暗嫉其"跳出来当好人"。封离搬出规矩：新队员明日抵日，穆宁雪收拾东西随队回国。穆宁雪淡然称东西已收拾，另有事要问导师。

**关键事件**：1.赵满延追问古都、疑南荣倪哭声 2.穆婷颖冲高阶、宣碾压穆宁雪 3.全队高阶、导师集合评表现 4.封离点穆宁雪未高阶、令其回国

- **情绪流向**：起：古都追问的悬 → 承：穆婷颖冲阶的爽/压 → 转：全队高阶的势 → 合：淘汰判决的冷
- **节奏配比**：慢铺垫 20% / 快冲突 5% / 爽点爆发 15% / 悬念留白 20% / 压抑 40%
- **本章结构公式**：古都追问（悬） + 穆婷颖冲阶（爽/压） + 全队高阶（势） + 淘汰判决（冷）
- **本章核心技巧**：用"对手冲阶+铁面判决"双线把主角的淘汰危机做实，留守馆人转机。
- **卡点与伏笔**：结尾卡点：穆宁雪称有事要问导师，下章期待其如何破局；埋设/回收伏笔：白泣妖假哭声 → 赵满延疑南荣倪，承接"南荣倪误中剧毒"线，留身份疑云。
