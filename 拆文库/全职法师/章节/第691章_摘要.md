# 第691章 契约，火恶魔！

**概要**：山峰之尸仰头猛吸头顶厚厚尸云，胸腔鼓胀、空气稀薄，显然在囤积足以夷平山脉的死亡之气准备一口吐碎金色结界。莫凡站在结界顶部，看见内城人山人海眼中尽是无助之光、结界淡痕遍布，断定不能让它再攻结界，于是咬牙弹射向云空引开战场；他心里清楚恶魔化之力虽不足以彻底抗衡，但自己掌控六种能力，小炎姬赋予的天地劫炎才是真正王牌。山峰之尸对莫凡不屑一顾，跃到北城门外吐出磅礴黑死风，两公里内残骸与亡灵大军尽被卷起。莫凡见状调动全身火焰力量抽空方圆数公里火元素，借炎姬契约将漫天火精灵凝成耀斑，肉躯被烧成灰烬后重塑为熔浆浇铸、火发倒燃的火焰魔人，身后狼魂影换作炎姬火焰冠冕。他化作悬于云端的烈焰浩日倾斜坠下，目标正是吐息的山峰之尸，这一小型天体般的火球将擎天之尸轰飞，外城卷起烈海、瞬间焚灭成千上万狂尸军团。

**关键事件**：1.山峰之尸蓄死亡之气欲破结界 2.莫凡弹射引开，亮出六种能力王牌 3.炎姬契约控火，重塑火焰魔人形态 4.烈焰浩日坠击轰飞山峰之尸 5.外城烈海焚灭狂尸军团

**逐章写法公式**：

- **情绪流向**：起：尸君蓄气的危机 → 承：莫凡引开亮王牌 → 转：火焰魔人重生 → 合：浩日轰飞爽点
- **节奏配比**：慢铺垫 20% / 快冲突 25% / 爽点爆发 40% / 悬念留白 15%
- **本章结构公式**：尸君蓄息（加压） + 莫凡引开（破局） + 炎姬重塑（变身） + 浩日轰飞（爽点）

- **卡点与伏笔**：结尾卡点：火焰魔人形态初成、外城烈海焚军，读者期待莫凡能否借此击败尸君；埋设/回收伏笔：炎姬灵魂契约 → 火焰魔人形态的来源与代价（燃命）
