# 第239章 落入铁笼！

**概要**：莫凡转身逃向建筑物，沈明笑、贾文清踩风轨、罗宋与傅天明借魔具紧追，罗宋以冰锁加履魔具第一个杀到，却在迷雾中捆了个空，众人判断莫凡跑进里面，一拥而入。这栋土系法师随手筑成的石屋最深处是考核目的地驯兽铁笼——足容一个足球场、高二十米、统领级以下妖魔短期难破。莫凡在低能见度迷雾中找藏身处，竟一头误闯入铁笼，唯一的出口被轰然砸落的二十米高铁门死死锁住，铁杆间距、穹顶铁丝与补织铁网封死了钻出的可能。迷雾中传来鬼似的声音，戴口罩、黑刘海遮半脸的男子现身石阶——正是宇昂，自称已得到暗影妖兽，要让全校欣赏刺激的真人秀。莫凡凭乌鸦般的嗓音认出他是博城旧敌，出言讥其整容与"给人做儿子十年"，又戳他任务再失败半边脸是否会被上头弄烂。宇昂冷笑到狰狞，忆起许昭霆当年也是这般找死被折磨得人畜模样，誓要将莫凡加倍折磨。

**关键事件**：1.莫凡诱敌遁走，众人追入驯兽铁笼建筑 2.莫凡迷雾中误闯铁笼，被坠落铁门困死 3.宇昂现身摊牌，与莫凡言语交锋结下死结

**逐章写法公式**：

- **情绪流向**：起：紧张（诱敌狂奔与追兵围杀） → 承：悬念（迷雾误闯、铁门锁笼） → 转：轻松（认人嘴仗、毒舌互呛） → 合：恐怖（宇昂狰狞立誓、酷刑预告）
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：假逃诱敌（引众入笼） + 误闯锁笼（猎场变囚笼） + 现身摊牌（真人秀预告） + 嘴仗结仇（旧怨与酷刑预告）
- **本章核心技巧**：把主角主动设计的诱敌与意外误闯叠加，让"猎人进笼"同时成立设局与入局两种读法，悬念留到下一章翻转
- **卡点与伏笔**：结尾卡点：困兽卡点——莫凡被锁巨笼、宇昂扬言留一块完整皮，下章期待笼中反杀；埋设/回收伏笔：宇昂博城旧怨与半边脸 → 前作恩怨线回收；"给人做儿子十年" → 宇昂身世与上头关系钩子；真人秀预告 → 全校围观的大战钩子；许昭霆被折磨旧事 → 复仇动机再加重
