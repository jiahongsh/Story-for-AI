# 第1216章 力敌百人军！

**概要**：张七虎冷视莫凡，不屑亲自收拾，摆手令黄艺、老银、张丹三人处理。张丹笑言要活捉割皮，张七虎骂其变态嗜好，准其捉了拖旁施刑。张丹跳上独立岩石操控倒刺鬼木搅杀，莫凡不闪躲，鬼木近二十米便自燃烧成红霞烈火灭尽；莫凡伸念控虚爪扼住张丹脖颈提至半空，其铠魔具级别不高被捏碎，张七虎见弟弟三两下被制顿时紧张令杀。此时天之纱巨矛、天瀑俯冲与进攻小队的烈焰拳海啸、紫闪齐袭，莫凡却一手抓张丹、脚下银星图闪耀，举拳"停滞"，银菱空间律动地带时间静止，所有毁灭魔法尽数凝固，许平东、杨宝等目瞪口呆。咯噶一声张丹被拧断脖落死，张七虎眼红暴怒化为石铠战车冲撞，莫凡化影鸟贴壁挪移、瞬息移动穿梭其身后百米。张七虎令暗影系法师以巨影钉大阵封其瞬息移动，莫凡笑其蠢，自施暗影高阶星座"司夜统治"，光被黑暗吞没、岩谷陷入阴霾失了目标，随后黑暗巨影剑阵禁锢落下，暗影军官身与心被钉死。

**关键事件**：1.莫凡时空停滞废掉全部围攻魔法，拧断张丹脖 2.张七虎石甲追击被瞬移戏耍 3.司夜统治罩谷，黑暗巨影剑阵钉死暗影军官

**逐章写法公式**：

- **情绪流向**：起：三将围攻的压 → 承：时空停滞的震 → 转：瞬移戏耍张七虎 → 合：司夜统治钉死暗影
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 40% / 悬念留白 5%
- **本章结构公式**：三将围攻莫凡（堆压） + 时空停滞全废（爆爽） + 瞬移破石甲（耍敌） + 司夜统治钉暗影（收）
- **本章核心技巧**：绝境魔法堆满后一招空间停滞清空，再用同系碾压破对方暗影反制
- **卡点与伏笔**：结尾卡点：暗影军官被钉死，下章莫凡灭张七虎；埋设/回收伏笔：念控虚爪→擒张丹；寂灭死光→下章穿岩甲；飞川皑狼→后文撕黄艺
