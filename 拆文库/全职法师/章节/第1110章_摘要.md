# 第1110章 德国最可怕的人

**概要**：苍雷爪与荒雷制裁将黄沙战场轰得满目疮痍，全场为莫凡的毁灭之力沸腾，封离激动叫好。莫凡打起飞川皑狼与小炎姬乘胜追击，飞川皑狼盯上德国冰系新学员，小炎姬压制瑞迪；艾江图以囚之空间将乔森锁死，与恢复的江昱联手攻之。乔森却以光刃陷阱重创夜罗刹，令江昱心疼收回，随后化作虚影遁走，从背后以暗刃在江昱脖颈划下浅痕将其判出局，自己再化黑烟消失。众人这才惊觉，真正可怕且全身而退的德国人不是瑞迪，而是队长乔森。

**关键事件**：1.莫凡召唤兽追击，艾江图囚困乔森 2.乔森光刃焚伤夜罗刹后遁影 3.乔森暗刃划江昱脖颈判其出局，坐实德国最强

**逐章写法公式**：

- **情绪流向**：起：全场为莫凡沸腾的爽 → 承：召唤兽追击与囚困乔森的延续爽 → 转：夜罗刹被焚的波折 → 合：乔森暗刃出局江昱的惊愕钩子
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 20% / 悬念留白 20%
- **本章结构公式**：莫凡乘胜召唤兽（爽） + 囚之空间锁乔森（加压） + 光刃焚夜罗刹（波折） + 乔森遁影暗刃（反转） + 江昱出局坐实乔森最强（钩子）

- **卡点与伏笔**：结尾卡点：乔森成德国最大威胁，下章其遁影再袭小炎姬救瑞迪；埋设/回收伏笔：囚之空间→艾江图空间魔法标志，后文反复用于控场
