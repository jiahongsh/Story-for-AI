# 第678章 骨刺骷髅阵

**概要**：莫凡现身后以雷系魔法彻底轰碎锋刃骨将，强化计数升至三十五。小炎姬随即示警，骨刺骷髅从高空连续投下骨矛，莫凡抱住小炎姬、召出玄蛇铠甲，用背部挡住数轮骨刺洗礼。察觉骨刺方阵会持续远程压制后，他与恢复些许的小炎姬附体，带着玄蛇铠甲和劫炎冲向方阵，以陨拳九蛟焚灭成百骷髅，雷系强化计数升至三十九。

**关键事件**：1.莫凡彻底击杀锋刃骨将。 2.骨刺骷髅以密集投矛迫使莫凡防御。 3.小炎姬附体后，莫凡摧毁骨刺方阵。

- **节奏配比**：慢铺垫 10% / 快冲突 55% / 爽点爆发 25% / 悬念留白 10%
