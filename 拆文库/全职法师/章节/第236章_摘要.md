# 第236章 这雷不是凡雷

**概要**：灰一撕下伪装，放出瘴气毒倒明珠四杰，唯有那名暗影系学员遁影脱身，莫凡高喊让他把同伴救走。莫凡遁影闪至灰一身后欲出雷手，却被对方钻地而出的冰锁近身缠捕，只能开启血兽靴借爆发力在冰锁与黑暗之墙间弹射闪避，狼狈脱困。灰一自恃中阶冰系加十余只黑畜妖协助，扬言被黑教廷盯上的人没有一个能好好活着，还盘算解决莫凡后带暗影妖兽去教士大人处领最大功劳。莫凡召出幽狼兽独战黑畜妖群，狼爪当场拍死两只偷袭者；他判定灰一是黑教廷小头目，决定在找出主使前先斩党羽，不再废话，脚下亮起雷系星图、周身腾起紫黑色雷电弧光。灰一正收拢冰锁结防御，看清那雷的颜色后眼睛瞪大——这雷不是凡雷。

**关键事件**：1.灰一瘴气毒倒四杰、撕破伪装 2.莫凡血兽靴闪避冰锁围捕，召幽狼兽挡住黑畜妖群 3.莫凡亮出紫黑色灵雷，灰一惊觉不是凡雷

**逐章写法公式**：

- **情绪流向**：起：恐怖（瘴气毒倒四杰） → 承：紧张（冰锁追捕贴身缠斗） → 转：热血（幽狼兽冲锋、莫凡亮雷） → 合：紧张（灰一惊觉灵雷、攻防一触即发）
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：毒瘴清场（剪除无辜者） + 冰锁缠杀（主角闪避遇险） + 分兵御兽（幽狼兽挡群妖） + 亮雷立威（灵雷压轴卡点）
- **本章核心技巧**：让主角先吃亏（冰锁近身险被锁）再亮底牌（紫黑灵雷），用先抑后扬把一章的爽点全部压到最后一色
- **卡点与伏笔**：结尾卡点：对轰卡点——灵雷将出、灰一仓促结防，下章期待一雷定音；埋设/回收伏笔：血兽靴灵魂印记 → 装备体系伏笔；灰一"成为最大功臣"念头 → 宇昂主线联结；"不是所有博城的人都是好惹的" → 莫凡出身与复仇动机回扣
