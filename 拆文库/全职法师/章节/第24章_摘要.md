# 第24章 魔法释放考核

**概要**：张小侯在唐月「老师相信你」的鼓励下走上星感石，首测因紧张光辉时暗时明，稳定后青色风系光辉胜过何雨却带不稳定，三位考官报出A、A、A+的分歧；他不甘心要求重测，第二次镇定发挥，光芒密集无闪烁，三考官一致判A+，全班惊羡这是稳进尖子班的成绩。得知考核排行高者获得星尘魔器的时间更长，张小侯主动加考第二项释放考核——考试共两项，星尘测试过关即可留校，释放环节专为约百名触碰到释放领域的尖子生加分。可惜紧张的他没能把七颗风系星子连成星轨，考官酌情加分；唐月拍肩安慰并答他之问：释放靠练习，更要处事不惊的心境。随后黄飞峰测B吵着改分被警告、学渣罗四拿C乐得跳起，八班多为B、C。校领导巡视至七班考场，议论称雷系许照庭稳居全校第一；校长亲自向穆卓云引荐许照庭，穆卓云让穆宁雪观看学弟表现。许照庭当众释放雷系初阶技能雷之印，紫色电弧如狂蟒轰得人形木偶焦黑碎裂、地面犁出黑色沟壑，全场尖子生倒吸凉气——什么风轨、水域、火滋全弱爆了，站着个人直接就挂了。

**关键事件**：1.张小侯重测夺A+、加考释放失利 2.双项考核制与星尘魔器时长挂钩规则揭晓 3.唐月点拨「功底+心境」 4.许照庭当众释放雷之印震撼全场，穆卓云穆宁雪在场观礼

**逐章写法公式**：

- **情绪流向**：起：张小侯赴测（忐忑） → 承：重测A+与加考失利（爽后低落） → 转：唐月温柔点拨（回暖） → 合：许照庭雷印轰场（震撼+压迫）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 35% / 悬念留白 20%
- **本章结构公式**：同伴两段式考核（立标杆） + 规则教学（定激励） + 快剪众生相（节奏调剂） + 对手天花板表演（抬威胁）
- **本章核心技巧**：以「配角成绩梯度」（A+/B/C）铺设全场坐标系，再用最高规格观众的注视给最强表演加权，为莫凡后章的爆出预留坐标原点
- **卡点与伏笔**：结尾卡点：许照庭雷印轰成渣的震撼刚落、莫凡即将登场，下章期待莫凡的考核；埋设/回收伏笔：星尘魔器使用时长与考核排行挂钩 → 莫凡夺魔器的动力；唐月「处事不惊的心境」 → 主角大场面发挥的教义伏笔；全校第一许照庭的公开雷印 → 莫凡私下已实战用雷印的双重身份反差；穆卓云穆宁雪巡视至七班附近 → 大人物即将目睹莫凡考核；张小侯释放失败但考官认可 → 其风轨已在宿舍演示过的呼应
