# 第86章 众势力争抢

**概要**：穆贺提醒宇昂还躺在决斗场上，穆卓云才想起这场赌战输了要当众道歉，胸口剧烈翻滚。莫凡看都懒得看宇昂一眼，走到穆卓云面前冷哼，称父亲已把礼回给他、让他自己看着办；莫家兴心软劝莫凡算了，穆贺也跳出来打圆场。穆卓云挣扎一番后咬牙说出愿赌服输，双膝慢慢屈了下去，莫家兴急忙将他扶起，莫凡见父亲发话便收手，认为多年怨气已在雷印狂躁那一刻宣泄干净。朱校长趁势感慨博城接连诞生穆宁雪与莫凡两位天才。随后斩空认真开出加入军部可成一城军部首领的条件，为拉拢莫凡先自称结拜弟弟又改口让莫凡当哥，杨作河抗议强拉，两位教官罗云波、潘丽君看得瀑布汗想把他拖走。

**关键事件**：1.穆卓云当众屈膝兑现赌约 2.莫家兴以德报怨扶起穆卓云 3.斩空开价并自认结拜兄弟拉拢莫凡

**逐章写法公式**：

- **情绪流向**：起：憋闷压抑 → 承：讨债施压 → 转：屈膝低头 → 合：争抢闹剧
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：穆贺提醒赌约（重启压力）+ 莫凡当面讨账（施压）+ 穆卓云屈膝与莫家兴搀扶（爆发与软化）+ 斩空结拜闹剧（余波转轻松）
- **本章核心技巧**：把复仇兑现拆成"讨账—挣扎—低头—宽恕"四拍，身体反应承载情绪，再用喜剧收尾泄压
- **卡点与伏笔**：结尾卡点：斩空开价与结拜闹剧未落定，留下莫凡选择势力的轻松悬念；埋设/回收伏笔：穆卓云道歉兑现（回收上章赌约）、斩空承诺一城军部首领（日后军部线）
