# 第805章 飞来横柱！

**概要**：受高阶资源鞭策，队伍直奔东海海战城，这座月牙形钢铁要塞城以东京之盾护住东京，城内往来者几乎皆是法师。莫凡因护送邪珠未随队。众人正听南珏讲经历，前方忽有十米石柱横飞而来，艾江图以空间系念控在距众两米处将柱悬停放下。一名橙发男子情急下推开穆宁雪，被赵满延与蒋少絮调侃借机搭讪，众人尚未回神，前方街道又现惊骇一幕。

**关键事件**：1.队伍直奔东海海战城，莫凡未随队 2.石柱横飞，艾江图空间系念控悬停 3.橙发男子推开穆宁雪被调侃 4.前方街道再现惊骇一幕

**逐章写法公式**：

- **情绪流向**：起：抵达海战城的壮观 → 承：城内法师氛围与南珏讲述 → 转：石柱横飞、艾江图救场的爆发 → 合：前方惊骇一幕的钩子
- **节奏配比**：慢铺垫 45% / 快冲突 40% / 爽点爆发 10% / 悬念留白 5%
- **本章结构公式**：抵达海战城（立景象） + 城内见闻与讲述（铺垫） + 石柱横飞艾江图救场（爆发） + 前方惊骇（钩子）
- **本章核心技巧**：先用空间结构描写立住要塞城，再在危机前一刻让主角以高阶实力救场立威
- **卡点与伏笔**：结尾卡点：前方街道的海妖，下章期待蓝谷凶离兽；埋设/回收伏笔：橙发男子 → 后续二十街区区主之子
