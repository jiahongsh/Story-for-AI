# 第1104章 心灵幻觉

**概要**：德方查到赵满延是赵氏花钱塞入的「混子」，未料其防御极强，遂转将进攻重心放回被蒋少絮、南珏牵制的瑞迪，乔森令解除其枷锁。德国幻觉系法师柏克对蒋少絮施「摄魂控心·心幻」，将其拽入以亡兄蒋少军为核的悲伤幻觉；沙场上蒋少絮泪流不止、似已迷失，南珏唤不醒、艾江图令弃，亚龙将她抓起，慕尼黑法师嘲讽之际，蒋少絮却骤然睁眼死死盯住他——已苏醒。

**关键事件**：1.德查赵底细，转攻瑞迪解枷锁 2.柏克心幻，蒋少絮入亡兄幻觉 3.沙场泪流迷失，艾江图令弃 4.蒋少絮睁眼苏醒

**逐章写法公式**：

- **情绪流向**：起：德查底细转攻 → 承：柏克心幻入梦 → 转：沙场泪流失迷 → 合：睁眼苏醒钩转机
- **节奏配比**：慢铺垫 25% / 快冲突 15% / 爽点爆发 5% / 悬念留白 55%
- **本章结构公式**：查底转攻（破牵制）+ 心幻入梦（揭伤）+ 沙场迷失（危机）+ 睁眼钩子（转机）
- **本章核心技巧**：用幻觉长段把角色前史与软肋托出，再以「泪中睁眼」把崩溃瞬间转为反击前奏
- **卡点与伏笔**：结尾卡点：蒋少絮苏醒反制，下章期待控制地亚龙；埋设伏笔：蒋少军之死、柏克幻觉系、瑞迪枷锁解除
