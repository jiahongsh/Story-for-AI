# 第1610章 七巨头之一

**概要**：莫凡想借阿帕丝号令蛇蝎大军，阿帕丝嗤之以鼻；九幽后从墙上的画里幽魅飘出，揭穿阿帕丝是"不务正业的美杜莎王后继承人"。她爆出惊天消息：真正的蛇蝎大军总BOSS、非洲七巨头之一的美杜莎之母即将死去，而阿帕丝正是它最小的女儿——影响非洲及周边数国命运的超级大妖之女，如今成了莫凡的契约兽。美杜莎之母还有两个强势姐姐佩摩杰与狄伊诺，二人笼络各族美杜莎、掌控从好望角到地中海的蛇蝎势力，阿帕丝出生晚、道行低、部落拥护少，若非母亲护着早被姐姐做成美容蛇羹，王位继承全无胜算，顶多吓唬几个小部落。九幽后还揭出她与伊森的合作：伊森拿蛇蝎情报与让道特权，助她铲除两个姐姐的部落。莫凡趁机自夸比伊森靠谱、承诺将来帮她吊打姐姐，阿帕丝气到想生吃二人，最后躲进契约空间睡觉。

**关键事件**：1.九幽后揭出美杜莎之母将死、阿帕丝是非洲七巨头之女 2.阿帕丝的两个姐姐掌控蛇蝎大势、其王位无望 3.阿帕丝与伊森的合作内容曝光，莫凡趁机揽功自夸

**逐章写法公式**：

- **情绪流向**：起：讨要兵力的玩笑 → 承：美杜莎身世的重磅揭秘 → 转：王位无望的惋惜与九幽后损嘴 → 合：莫凡自夸、阿帕丝逃睡的收尾
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：请求落空（立期望）+ 幽灵爆料（揭身世）+ 姐妹内斗（展格局）+ 逗趣收尾（留人物温度）

- **卡点与伏笔**：结尾卡点：状态+美杜莎之母死后阿帕丝将面临被吞或起义的命运；埋设/回收伏笔：佩摩杰、狄伊诺两个姐姐 → 后续妖界势力线；伊森拿蛇蝎情报 → 其罪名之一
