# 第176章 来钱比抢还快

**概要**：包老头确认了莫凡"梵墨"的资料，提醒孙女心智不比一般人、清高自傲，有冒犯别介意。谈及报酬：委托对方预付了十万、完成后再打二十万，青天猎所不收公共费用，完成后莫凡与灵灵均分、十五万打到他账户——一个晚上十五万，莫凡感叹这赚钱速度比抢还快。老头还透露三十万的委托在猎所里属于最低级别，师兄们压根不接一百万以下的单子。老头自我介绍姓包、是青天猎所会长，让莫凡把这里当半个家。莫凡在店里等灵灵查资料时，二楼爷孙有一场莫凡没听见的对话：灵灵问爷爷为什么让那个人进来，老头说这小子实力不错是个好苗子、会带给你惊喜；随后叮嘱——冷青正在协助审判会追查撒朗，不出意外撒朗就是博城灾难的主谋，这件事别和梵墨提，他现在的实力根本涉入不了，否则会像小鼎一样死于非命。灵灵咬着银牙发誓一定查出杀死小鼎师兄的凶手，老头说这些事交给大人，实力不够前别碰。中午老头留莫凡吃饭，透露老店是爷孙的家。灵灵约莫凡天黑前在杰作私家花园会合，还一眼点破他是在校生。傍晚莫凡打车前往，拼车同行的三个女学生里，短发的贾文倩主动搭讪，被同伴打趣直接管人家要电话。

**关键事件**：1.委托分账十五万定下 2.包老头身份揭晓 3.爷孙密谈泄露撒朗追查与小鼎之死 4.杰作私家花园会合在即

**逐章写法公式**：

- **情绪流向**：起：轻松（分钱与安家） → 承：期待（爷孙密谈的好苗子评价） → 转：压抑（撒朗与小鼎之死的暗线） → 合：轻松（拼车三女的打闹）
- **节奏配比**：慢铺垫 50% / 快冲突 5% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：分账定约（利益绑定） + 爷孙密谈（暗线上浮） + 店宅人情（据点落地） + 花园会合（行动前奏）
- **本章核心技巧**：用一段主角缺席的楼上密谈，把本书最大暗线（撒朗）挂进日常章节而不惊动主角。
- **卡点与伏笔**：结尾卡点：天黑前花园会合、今晚守护孩子，下章期待守夜与妖魔现身；埋设/回收伏笔：冷青协助审判会追查撒朗、撒朗疑为博城灾难主谋→跨卷大暗线，莫凡被刻意隔离；小鼎之死→灵灵的复仇动机与猎所难招人之谜；灵灵十秒扫一页→她的超常心智细节。
