# 第1301章 占为己有

**概要**：芍女的鬼木在树坡威力大增，能控制天冠紫椴神树的粗壮树根将山人扫开、捆住半残的古铜牙大山人，但它生命力强悍仍在挣扎呼救，一大群山人不顾军法师轰炸涌来救援，啃断根须后莫凡用十几柄巨影钉将它死死禁锢，再施展高阶魔法「天焰葬礼-地狱火」召唤硕大的燃烧之石砸落，把一大群山人焚烧成灰，古铜牙大山人气息渐渐弱下去。汪大阔、汪华、胡朵等人在低处目睹，汪华认出莫凡脸色难看。军领队发现古铜牙大山人死后这片山人战意松散，军人与猎人全力斩杀，七彩妖雀攻势更猛，场面一面倒。战场的另一处，聂冷山拎着古铜牙硕大的头颅从高空抛下，杀了最大的山人首领。两大首领一死，山人们瑟瑟发抖被追杀、倒下，树下彻底血流成河。莫凡提议尽快离开——这么大面积血腥味会遭来更大灾祸，政府负责人童尚却大笑说君主级霸主是自然死亡，这是千载难逢的机会，要把外昆嵛山纳入安界、将天冠紫椴神树占为己有，甚至打算联合超阶法师消灭树层上的妖魔巢穴。

**关键事件**：1.芍女鬼木控树根捆住古铜牙大山人，莫凡巨影钉禁锢 2.地狱火焚烧群山人，古铜牙大山人气衰 3.聂冷山击杀最大山人首领，山人全线溃败 4.莫凡提议离开遭童尚反对 5.童尚决意将天冠紫椴神树占为己有

**逐章写法公式**：

- **情绪流向**：起：地狱火焚杀山人、双首领授首的爽 → 承：血洗神树、单方面横扫的热血 → 转：莫凡预警离开与童尚贪婪占树的冲突 → 合：神树未来走向成谜的压抑
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：鬼木禁锢与地狱火焚杀（爽点） + 双首领死亡战场横扫（热血） + 莫凡预警与童尚争辩（冲突） + 童尚决意占树（悬念钩子）
- **本章核心技巧**：用「胜利的喧腾」与「直觉的隐忧」双轨并行，让战场大胜的同时埋下更深层危机，把读者情绪从爽拉向不安，为后续大转折蓄势
- **卡点与伏笔**：结尾卡点：童尚执意占树、要探索云顶树冠，血腥味可能招来更大灾祸 → 下章期待树层探索与灾祸降临；埋设/回收伏笔：霸主死于何人手 → 神树主线悬念；莫凡让聂冷山留意图腾图案 → 图腾线伏笔
