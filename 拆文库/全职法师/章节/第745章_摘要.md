# 第745章 杀统领（上）

**概要**：穆宁雪踩出海上冰道率众人飞驰增援。孤岛莫凡以冥离盾抗赤潮，借小炎姬劫炎震散，炎剑破浪墙不成，再电灾雷碎裂妖胸甲露腐蚀伤，祖吉明毒发作。裂妖弃妖术近战，莫凡炎剑斩裂胸膛，火羽千层爆将其炸得血肉横飞。小炎姬飞出带走劫炎，莫凡急描星座欲施天焰葬礼。

**关键事件**：1.穆宁雪冰道率众增援 2.莫凡冥离盾抗潮炎剑破墙 3.电灾雷碎胸甲毒发 4.炎剑斩+火羽爆 5.小炎姬带劫炎莫凡天焰葬礼

- **情绪流向**：起：冰道增援的期待 → 承：冥离盾抗潮的稳 → 转：雷碎毒发斩妖的爽 → 合：火羽爆天焰蓄的燃
- **节奏配比**：慢铺垫 10% / 快冲突 50% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：冰道增援（期） + 冥离盾抗潮（稳） + 雷碎毒发斩（爽） + 火羽爆天焰（燃）
- **本章核心技巧**：把跨章毒伤伏笔在决战点回收放大，战力层层递进到大招前夜
- **卡点与伏笔**：结尾卡点：莫凡急描星座施天焰葬礼；埋设/回收伏笔：祖吉明毒→雷碎胸甲腐蚀
