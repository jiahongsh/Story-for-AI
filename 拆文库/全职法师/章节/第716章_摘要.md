# 第716章 阻碍城市的海妖

**概要**：飞鸟市林氏集团总裁林军闲因城市萧条、投资惨败而迁怒上下，在图纸上打红叉撕碎，认定被市长隐瞒要事、飞鸟市扶不起来。与此同时赵满延带众人闯入林贸大厦，断言楼主有头疼事，并以"海妖作祟挡了财路"点破城市萧条的真正原因，自荐率十四人替林氏剿妖换一个方便。女秘书将信将疑，十四人剿妖族群在她看来无异神经病。

**关键事件**：1.林军闲投资败撕图认输 2.赵满延闯大厦点破楼主有麻烦 3.赵断言海妖挡财路自荐剿妖 4.女秘书疑十四人剿妖是神经病

**逐章写法公式**：

- **情绪流向**：起：林总裁失意的压抑 → 承：赵延闯厦的自信 → 转：点破海妖挡财的爽利 → 合：女秘书不信的喜剧收束
- **节奏配比**：慢铺垫 40% / 快冲突 5% / 爽点爆发 15% / 悬念留白 40%
- **本章结构公式**：林氏困局（反派铺垫） + 赵延闯厦点麻烦（破局切入） + 断言海妖挡财（揭谜） + 自荐剿妖被疑（埋期待）
- **本章核心技巧**：用专业配角一句话揭穿上章悬念，并借本地人轻视把"以少胜多"的爽点前置
- **卡点与伏笔**：结尾卡点：悬念型，女秘书不信十四人能剿妖，下章期待林氏是否接招与出海；埋设/回收伏笔：海妖挡财路 → 本章回收上章伏笔；十四人剿妖 → 延续至出海章
