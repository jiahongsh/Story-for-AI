# 第150章 至高魔法

**概要**：斗兽大赛日，校园各处挂着召唤兽彩带，全校讨论下午的大赛。幽狼兽仍在沉睡，莫凡自觉没了戏，一大早整理容装，称原本是展示才智双全的绝佳机会，现在只能尽情展示帅气逼人的一面。舍友张平谷让莫凡剧透召唤兽，莫凡直说一只幽狼兽，张平谷苦笑全宿舍加起来打不过他一个，最迟来的苏龙冷言不要用你的标准衡量所有人。随后众人到恢弘的青斗馆，决斗场已变成巨大的斗兽铁笼，四面阶梯坐席可容万人，召唤系学生作为主角提前到后台准备。后台杨义看着人山人海紧张不安，海大富却兴奋放话白铠战蛰会让叫嚣者知道什么叫碾压。仪式开始，萧院长先发表讲话：只求受尊敬、高俸禄、高品质生活的人来错了地方，明珠学府缺的不是财富名声，而是一颗追求至高魔法的永恒之心。莫凡在后台观察到几乎每个人眼里都在闪烁。

**关键事件**：1.莫凡剧透幽狼兽，苏龙出言暗讽 2.万人青斗馆与斗兽铁笼就位，后台众生相 3.萧院长发表至高魔法演讲点燃全场

**逐章写法公式**：

- **情绪流向**：起：大赛日的轻松嬉闹 → 承：入馆排场的隆重 → 转：后台忐忑与狂言 → 合：演讲点燃的热血
- **节奏配比**：慢铺垫 55% / 快冲突 5% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：晨间剧透（舍友定位） + 场馆铺排（抬高规格） + 后台众生相（群像与气氛） + 院长演讲（立价值观钩）
- **本章核心技巧**：大战前的「静场章」——不提前打，用场馆体量、坐席人潮、权威演讲三层把仪式感堆满，让读者期待值顶到格
- **卡点与伏笔**：结尾卡点：期待型（悬而未决的比赛开局），演讲毕、七位主角即将登场；埋设/回收伏笔：幽狼兽沉睡（上章危机）→ 持续未醒，强化「莫凡无牌可打」的绝境感
