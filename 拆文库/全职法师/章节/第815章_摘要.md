# 第815章 大潮逼近

**概要**：莫凡不愿再护送后白干，望月千熏以"上一代红魔"为由劝其同赴东海城，并指挥魔藤拦住欲走的疾星狼。二人骑疾星狼横穿大东京，望月千熏沿途讲解东海城填海战场、不擅水战可借楼层窄道周旋。抵达东海城，莫凡见月牙形双堤与蓝白妖潮卷来，海妖如繁星密布潮屏，望月千熏称大潮下二十街区将淹过半、大海妖可任意穿行，莫凡方知此战比古都浩劫更夸张。

**逐章写法公式**：

- **情绪流向**：起：莫凡不愿白干的赌气 → 承：红魔为饵同行的松动 → 转：途中环境讲解的铺垫 → 合：大潮妖潮压迫的钩子
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：红魔留人（动机） + 骑狼横穿（过场） + 环境讲解（铺垫） + 妖潮卷来（钩）
- **本章核心技巧**：用未解谜题驱动角色同行，再以宏观视觉建立战争压迫
- **卡点与伏笔**：结尾卡点：大潮下的二十街区，下章期待入城遇险；埋设/回收伏笔：上一代红魔 → 持续牵引莫凡线
