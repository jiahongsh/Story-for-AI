# 第381章 浮出水面

**概要**：灵灵偷来证件，莫凡假扮身份潜入守卫空虚的白镇军需大院血剂仓库，目睹一名军官索要血剂给前线伤员、被白衣守卫以仓库里的不是血剂为由拒绝，明阔军统怒斥守卫囤货发财、强开仓库命人将满仓血剂全部运走，尖嘴军医搬出副审判长王毅压人无效、慌张致电。莫凡假扮军医讨得一箱血剂，明阔分文不取，称都是在为这座城市流血。灵灵接收血剂开始分析成分，莫凡将王毅的名字反馈给冷青，冷青沉默许久后称离瘟疫真相越来越近，命两人立刻混入西要塞、盯住那批被运往军方的血剂，相信很快有人要浮出水面。

**关键事件**：1.明阔军统强开仓库运走满仓血剂，守卫方阻拦失败 2.尖嘴军医搬出副审判长王毅，莫凡锁定关键人物 3.冷青命莫凡灵灵混入西要塞跟踪血剂流向

**逐章写法公式**：

- **情绪流向**：起：紧张（定计潜入）→ 承：紧张（仓库对峙）→ 转：爽（军统强开仓库运走血剂）→ 合：紧张（冷青下令转赴要塞）
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：定计潜入（进场）+ 仓库对峙（黑幕现形）+ 讨药赠药（人性微光）+ 反馈定策（转场钩子）
- **本章核心技巧**：用"不知情的第三方冲击黑幕现场"推进调查，主角只旁观记录不亲自破局
- **卡点与伏笔**：结尾卡点：混入西要塞守株待兔，下章等关键人露头；埋设/回收伏笔：王毅之名 → 下章其人现身触发罗冕暴露；问题血剂流向军方 → 军师病发的实证预埋
