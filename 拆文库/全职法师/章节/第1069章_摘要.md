# 第1069章 争抢宝物

**概要**：庞莱指点莫凡将召唤系从中阶突破至高阶并喂养疾星狼，江昱替莫凡求庞莱亲自挑选兽魂，庞莱应允。因莫凡资金有限，庞莱带二人去威尼斯魔法卖场而非竞拍会，凭眼力以七千万为莫凡购得星河之脉。逛至兽魂区时，庞莱在一间深邃小店发现一枚统领级兽魂，标价三亿。恰逢自由神殿副长老吉赛携弟子亚克前来争抢，亚克谎称先物色并亮出神殿身份施压，庞莱不惧反亮明中国宫廷法师首席身份，一番言辞令店长赫本按公道收下庞莱的卡。吉赛得知庞莱身份后骇然，赫本庆幸未偏袒。事后庞莱让莫凡先付现有的一亿五千万，余款从夺宝赛所得偿还。

**关键事件**：1.庞莱指导莫凡突破召唤系并喂养疾星狼 2.江昱求庞莱代选兽魂，庞莱答应 3.庞莱凭金眼眼力以七千万为莫凡购得星河之脉 4.深邃小店发现统领级兽魂引发亚克师徒与庞莱争抢 5.庞莱亮身份迫使店长公道交易，莫凡欠下余款

**逐章写法公式**：

- **情绪流向**：起：庞莱指点进阶的安心 → 承：卖场淘宝的轻松与眼力展示 → 转：亚克师徒抢宝的身份对峙 → 合：公道交易达成、余款悬念
- **节奏配比**：慢铺垫 35% / 快冲突 30% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：庞莱定进阶方案（铺垫） + 江昱求情代选兽魂（推动） + 卖场购星河之脉（小目标） + 小店争兽魂亮身份（高潮冲突）
