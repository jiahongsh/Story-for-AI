# 第26章 说好的信任呢

**概要**：穆白毫无停顿一气呵成释放冰蔓，人形木偶瞬间爬满白色冰霜如刷了一层冰漆，冰蔓还咯吱作响扩散到考场地面，学生吓得后退，考官们认为这是放在成人魔法师协会都能过关的成熟技能。穆白忐忑望向穆宁雪，却发现她压根没看自己、目光落在莫凡身上，脸瞬间扭曲，暗誓要让莫凡死得很惨很惨。考官给出星尘S、释放B的最终成绩，全校第一稳稳到手。莫凡紧随其后被点名，暗自怀疑绿茶男考完立刻轮到自己绝非巧合。原来穆贺赛前已买通秃顶考官并安排好考试顺序，让穆白测试时在星感石下放一颗吸收光辉的暗石，足以把勉强C的莫凡稳定压到D甚至更低，把他清出学校。穆卓云认出莫凡是夫人司机的儿子并提点穆宁雪，见女儿神色平静未把莫凡放在心上而满意。莫凡测试时星感石光芒先弱被嘲不如D，随后却持续增强，从D爬到C仍在发亮，学渣舍友陆小斌惊呼学渣之间的信任崩塌。

**关键事件**：1.穆白冰蔓释放锁定全校第一 2.暗石陷害阴谋全貌揭示 3.莫凡星尘成绩不降反升逼近B

**逐章写法公式**：

- **情绪流向**：起：穆白冰蔓技惊全场 → 承：女神注视旁落、暗石阴谋揭开 → 转：莫凡光芒从D级弱势一路爬升 → 合：逼近B级、信任梗爆点收尾
- **节奏配比**：慢铺垫 45% / 快冲突 15% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：对手完美表演（立高标）+ 阴谋全貌揭示（压主角）+ 光芒异常变强（反转启动）+ 惊呼定格（卡点）
- **本章核心技巧**：先完整展示阴谋细节，再让受害者的成绩逆势上爬，用"读者知情、角色不知"的落差持续供能期待感。
- **卡点与伏笔**：结尾卡点：悬念型，光芒仍在慢慢扩散未定格，下章看最终评级与阴谋是否暴露；埋设/回收伏笔：暗石 → 下章唐月查出；穆白"死得很惨"誓言 → 长线敌意升级。
