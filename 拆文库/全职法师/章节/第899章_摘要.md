# 第899章 虐杀邪员（下）

**概要**：莫凡骂赵品霖人渣，又一道雷电落下将其劈成两半崩解为血块血珠，郭文衣荣盛见其神勇震惊崇拜。莫凡嘱二人照顾穆宁雪后步入地下迷宫，循灵灵指引前行，在长直通道被灰衣教士卢耿发现，黑畜妖围堵。莫凡烈拳填满通道将教徒与畜妖烧成粉末，唯卢耿爬起欲逃，被虚空之爪拧回。莫凡称其值九百万，将药液浇灌其头，卢耿在熟悉的惨叫中融化。莫凡推开红门入大祭殿，见头骨祭坛与跪拜教徒，直接天焰葬礼将整殿黑教廷成员烧成焦尸，自语复仇之火可灭群丑。

**关键事件**：1.莫凡雷劈赵品霖 2.嘱同伴照顾穆宁雪 3.通道烈拳清场 4.药液融卢耿 5.天焰葬礼烧祭殿

**逐章写法公式**：

- **情绪流向**：起：骂人渣的狠 → 承：雷劈的爽 → 转：通道清场的爆 → 合：火海复仇的燃
- **节奏配比**：慢铺垫 15% / 快冲突 35% / 爽点爆发 40% / 悬念留白 10%
- **本章结构公式**：雷劈赵品霖（解恨） + 嘱托同伴（温情） + 烈拳清道（爆） + 天焰葬殿（燃）
- **本章核心技巧**：用赏金数字作动机锚点，串起连续碾压爽点
- **卡点与伏笔**：结尾卡点：祭殿后还有什么，下章揭晓；伏笔：九百万赏金 → 莫凡金钱动机
