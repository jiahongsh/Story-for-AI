# 第305章 最佳试验品

**概要**：莫凡变卦，提出以释放陆正河为条件换取"死个明白"。陆年意外于他明知必死却毫无不安，心中暗疑他在拖延时间，想不明白拖延意义后权衡答应。陆年透露他们在做一项"可能改变人类自欺欺人格局"的实验，并痛陈战争真相：与妖魔的战争里覆灭了多少人、多少座城无人告诉世人，人类只在都市中苟延残喘地繁衍，等繁衍够多便是妖魔的饕餮盛宴——"它们不全部吃光，吃光了，人就不再繁衍了"；他更以"人类比猪羊更适合圈养"的言论享受摧毁学生世界观的快感。莫凡内心被撼动，联想博城灾难觉得此言或许为真。陆年随后抛出核心机密：实验关系到"新的系"，成功后他们就是新系的开创者，光系的诞生远远不够。讲到狂热处，陆年指着莫凡宣布：你就是新系的最佳试验品，因为你天生双系。

**关键事件**：1.莫凡以真相换人质 2.陆年抛出"妖魔圈养人类"的战争观 3.揭晓新系实验与莫凡天生双系的关系

**逐章写法公式**：

- **情绪流向**：起：紧张（以话换命的博弈） → 承：压抑（战争真相演讲） → 转：压抑（圈养论碾压认知） → 合：紧张（最佳试验品揭晓）
- **节奏配比**：慢铺垫 20% / 快冲突 10% / 爽点爆发 0% / 悬念留白 70%
- **本章结构公式**：交易开启（换真相）+ 反派立论（战争观）+ 主角动摇（认知受冲）+ 概念揭晓（新系与双系）
- **本章核心技巧**：以反派长独白承载世界观设定，用主角内心下沉与旧事件回扣做"信息接收器"，让设定章不悬空
- **卡点与伏笔**：结尾卡点：莫凡被指认为新系最佳试验品、缘于天生双系，下章期待双系与实验的具体关联；埋设/回收伏笔：博城灾难→圈养论的印证；"改变世界格局"的宏伟目标→陆年势力线；陆年入战争后世界观被摧毁的过往→反派堕落动因
