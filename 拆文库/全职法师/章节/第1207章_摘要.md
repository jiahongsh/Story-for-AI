# 第1207章 掩埋的十一年

**概要**：采集顺利，灵灵电脑地图后方密布紫黑点，表明尘暴魔蜢数量可怕，葛明心有余悸催大家快走，凭分布图选新路线加速。走出三公里热风扑面，回望暴尘魔蜢已覆盖原区域，对碧盔豹蛰无兴趣反成其无天敌保护伞，沙漠热力强如蒸炉，冰水系法师不停解暑耗魔能。葛明称快到老驿站，十几年后沿途妖魔凶险基本废了，桐立执意要插旗留人类足迹，他熟沙漠能找埋沙之物。驿站石砌半掩、外围木屋房檐露地不到半米，桐立奔入寻找。灵灵告莫凡火焰山脉离此不远温度不寻常，用温度仪探得热风自北来；莫凡遣张小侯往北探，自己留驿站。张小侯离驿站一公里见深色岩石高温龟裂缝冒火焰，心喜来对地方。他进朝驿站的小洞窟，见兽皮焦食生锈道具，背后突遭火焰袭击，转身见只穿兽皮裤、毛发邋遢、露野兽眼的野人盯住自己。野人看清张小侯后愣住，口齿不清问"人…人？"，艰难沟通后挖出勋章，张小侯行军礼认出是军人，野人见礼回标准军礼。张小侯问被困多久，野人摇头不知，低问是否一人生活十一年，野人顿时泪如雨下。

**关键事件**：1.灵灵地图现尘暴魔蜢紫黑点，队伍加速离危 2.驿站半掩，张小侯北探见焦岩冒火发现野人 3.野人示勋章证军人身份，困居十一年泪下

**逐章写法公式**：

- **情绪流向**：起：地图紫点催行的紧 → 承：蒸炉炎热与驿站荒废的压抑 → 转：洞窟野人现身的疑 → 合：军礼相认与十一年泪下的悲
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：灵灵地图示危催行（布环境） + 驿站半掩桐立寻妹（埋亲情线） + 张小侯北探遇野人（抛悬念） + 勋章军礼十一年泪（揭身份收悲）
- **本章核心技巧**：先写陌生野人如威胁，再揭军人勋章与军礼，用身份反转把惊疑扭成悲悯
- **卡点与伏笔**：结尾卡点：野人困居十一年泪下，下章揭其名林飞历与斯塔驿站往事；埋设/回收伏笔：桐立寻妹→后文骸骨；火焰山脉北→后文火焰魔山；黑岩蕊→后文矿脉疑云
