# 第1296章 音系芍女

**概要**：高草林中，一位冷艳的女音系法师指挥着十几名军人法师配合剿灭山人，她用光耀在黑暗中印出埋伏的山人轮廓，军人们用缠绕束缚之根和冻结之霜配合，几轮毁灭性魔法后由音系法师下令直接击杀，收走山人的牙作为复仇标志。发现猎人残骸后她下令取信物就地掩埋。她连续用光耀标记出一群协同作战的山人，方圆几公里山人都逃不过她的听波，豹头猎人团跟随她一路扫荡，已宰杀三四百只山人。队伍里有人认出她是芍女——一年前独闯蓝凌妖巢穴全灭它们、拒绝各族招揽、还把蓬莱世家二公子吕文星打得体无完肤的传奇女法师。芍女又侦测到三公里外有落难猎人队伍，带队前往营救，高老师和刘小佳的学长提醒她山人会模仿人类呼救声，她自信能分辨，有条理地分配救援与剿灭任务。突然一头体型高大的古铜牙山人从芍女身后跳出，她没料到自己音系洞悉竟会漏掉敌人，被凌厉爪子在胸口划过、肩头撕开，躲避时又被扯下五道血口，命悬一线。

**关键事件**：1.音系女法师用光耀标记山人，军法师配合击杀 2.发现猎人残骸，取信物掩埋 3.芍女身世传闻：独闯蓝凌妖巢穴、暴打吕文星 4.芍女安排救援与剿灭任务 5.古铜牙山人偷袭芍女，她重伤负伤

**逐章写法公式**：

- **情绪流向**：起：音系扫荡山人的爽 → 承：芍女身世传闻的好奇与敬畏 → 转：分派任务有条不紊的自信 → 合：被古铜牙山人偷袭重伤的危机
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：光耀标记击杀山人立威（爽点） + 猎人残骸掩埋与芍女传闻（铺垫） + 有条理分派救援任务（推进） + 古铜牙山人偷袭重伤（钩子）
- **本章核心技巧**：先充分建立音系法师的「洞察神话」，再让这个神话被一头漏网山人击碎，以「体系信任崩塌」制造强转折，为新角色立危险也立人情
- **卡点与伏笔**：结尾卡点：芍女重伤、古铜牙山人仍在，谁能救她 → 下章期待救援；埋设/回收伏笔：山人模仿呼救 → 后续真假救援的战术；芍女此战 → 与莫凡线会合的伏笔
