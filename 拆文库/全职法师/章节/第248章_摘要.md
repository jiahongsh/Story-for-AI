# 第248章 扫荡之夜！

**概要**：清扫之夜，魔都阴暗角落里的黑教廷毒瘤势力一夜之间被全面清扫，莫凡躺在高层阳台几次致电唐月都只等来留言——这一夜审判会全员奋战的战争无人看见、却真实发生。艾图图穿着吊带睡衣跳出来逼问真相，从黑教廷为何对付他一路猜到他是审判会卧底，最后抛出最重要的问题：你到底是哪一系魔法师？这也是牧奴娇想问的——新生大会上的召唤系、对战中展现的雷系、铁笼里的火系烈拳-地刹，修为未到高阶却身怀三系。莫凡坦然认下，艾图图惊呼怪胎、天生双系只是传说；牧奴娇握住重点：他系多却每一系修为都极高、火系最强且是灵火，自感伯仲之间的她挫败徒生，艾图图气呼呼跑掉。同一夜杭州也发生轰动全城的怪事、新闻无从求证，莫凡从心夏电话里略知一二，隐约想起唐月似乎提过在应对此事。事后莫凡到心夏学校探望，灵灵称杭州有审判会会议所、黑教廷一般不敢来，却说发现了莫凡可能都没察觉的事——心夏姐姐好像有人在保护着。

**关键事件**：1.审判会连夜清扫魔都黑教廷势力 2.莫凡向艾图图、牧奴娇承认三系修为、火系最强 3.杭州怪事无解，灵灵透露心夏似有人在暗中保护

**逐章写法公式**：

- **情绪流向**：起：紧张（清扫之夜） → 承：轻松（艾图图闹场拷问） → 转：爽（三系摊牌震住两女） → 合：紧张（杭州怪事与心夏被保护之谜）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 25% / 悬念留白 30%
- **本章结构公式**：夜扫旁白（战争幕后） + 两女拷问（喜剧加压） + 三系摊牌（爽点兑现） + 双悬念收尾（杭州怪事＋心夏守护）
- **本章核心技巧**：战后过渡章用闲谈式拷问完成主角实力情报的公开化，再用两条新悬念（杭州西湖怪事、心夏守护者）无缝衔接下一段剧情
- **卡点与伏笔**：结尾卡点：谜团卡点——心夏身边有不明守护者，下章期待查明身份；埋设/回收伏笔：杭州西湖怪事＋唐月参与应对 → 新事件线；心夏被人暗中保护 → 神秘守护者线；三系公开于牧奴娇、艾图图 → 声名与天骄视线；审判会全城扫荡 → 魔都黑教廷清零收尾
