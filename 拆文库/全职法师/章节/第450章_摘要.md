# 第450章 绝对防御！

**概要**：赵满延抱怨莫凡不等他独自犯险，莫凡借圣盾防护原地描画雷系星图，千钧-霹雳-夜叉化作五道叉状闪电劈中聂东，电弧窜体、骨头松软，若非吸血鬼强横体魄早被电得崩解。赵满延跟上水系暴浪-洪卷，洪流霸占整条街将聂东冲出百米并附带虚弱，莫凡再补一道紫黑霹雳砸中他脑袋，湿身导电令他半天站不起来。聂东怒吼两个小法师也妄想与他抗衡，爪子伸到半米长，腥红十字厉爪把街道两旁路灯齐刷刷拦腰斩断；莫凡四周无阴影、遁影难躲，开启冥离之盾仍被震退十来米。聂东又借暗影穿梭到立于阴影处的赵满延身后，利爪刺胸欲挖内脏，被水御化解；赵满延趁机以光耀-失明灼烧其瞳孔。失明的聂东伸长血牙狂咬，先磕在金色守护盾上只留浅印，再举起连人带盾要撕碎赵满延，又被铠魔具、光佑圣盾层层挡住，血化镰刀斩上圣盾即化死水。四道防御轮转不休，聂东如猛虎咬山龟无从下嘴，恼羞成怒只能把这只「山龟」狠狠扔出去。

**关键事件**：1.莫凡夜叉闪电与紫黑霹雳两度重创聂东 2.聂东十字厉爪斩断路灯、震退冥离盾 3.赵满延光耀失明灼其瞳孔 4.赵满延四重防御耗疯聂东，被整个扔飞

**逐章写法公式**：

- **情绪流向**：起：爽（夜叉闪电劈中聂东） → 承：紧张（十字厉爪、偷袭刺胸） → 转：爽（光耀灼瞳、四重防御） → 合：搞笑（山龟无从下嘴、扔飞了事）
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：远程连招压打（立优势） + 反派狂暴反击（夺回主动） + 偷袭与反偷袭（攻防互换） + 防御流耗疯反派（喜剧收束）
- **本章核心技巧**：用「技能循环攻防」代替血条互耗，每个回合换一种能力，保持打斗新鲜感
- **卡点与伏笔**：结尾卡点：僵局待破——聂东扔飞赵满延后战局胶着，待看莫凡终结手段；埋设/回收伏笔：光系克吸血鬼、水系附带虚弱 → 属性克制体系持续生效；聂东血化之力 → 其血系技能库尚有后手
