# 第1362章 雪上加霜

**概要**：彬蔚断言绝不能让冥君蛙继续前行，否则不知会从冥界拽出何等无法抗衡的魔鬼。军谋广明提出需要支援，彬蔚却说支援已发出，但东面传来一个坏消息——上头发来的不是告知讯息，而是调遣兵力的命令，要从正被冥界生物围攻的镇北关抽调兵力，副官当场失控怒斥，军谋们惊呼"开什么玩笑"。困境撞上绝境之际，常沂指挥战斗出色，摸出纤夫规律、不冒进追击，率军法师消灭了被封在城墙下的纤夫，重振士气。彬蔚却铁面下令：带领四军撤离镇北关，前往东面。副手们暴跳如雷，指责她记仇妒忌、怕抢军功。常沂以榆林市为家乡相胁，说若榆林出半点闪失绝不放过于她，仍红着眼执行军令；彬蔚承诺这些冥界生物除非从她尸体上踏过去。她拽紧拳头立誓撑住三天，更意识到上头明知镇北关遇袭仍调兵，说明国土必有大变。她转而向赵满延、灵灵询问莫凡动向，灵灵说不知其行踪，但相信他正以比火焰更炙热的血性阻止这一切。灵灵最后问及古都亡灵浩劫时为何不筑长城之坝，彬蔚苦涩反问"你觉得古长城防御是谁筑造的"，灵灵猛然想起历史书上那个名字——古老王，亡灵系鼻祖，土系魔法造诣登峰造极。

**关键事件**：1.东面传来坏消息，上头要镇北关抽调兵力而非支援 2.常沂率军消灭封门内纤夫重振士气 3.彬蔚下令四军撤离镇北关前往东面，常沂以榆林家乡为念含怒执行 4.灵灵问及古长城由谁筑造，指向古老王

**逐章写法公式**：

- **情绪流向**：起：绝境中的紧绷 → 承：调兵令下的愤怒 → 转：常沂出征的悲壮 → 合：古老王之名的震撼
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：坏消息揭晓（外部加压）+ 常沂亮眼战绩（内部提振）+ 四军撤离令（冲突爆发）+ 古老王之名（长线抛钩）
- **本章核心技巧**：让"打胜仗"与"被抽兵"同场出现，用局部胜利反衬全局困境，再用一个历史名字把战线拉长
- **卡点与伏笔**：结尾卡点：身世悬念——古长城由亡灵系鼻祖古老王筑造，冥界之乱与之有何关联；埋设/回收伏笔：古老王之名 → 与冥界生物起源相关长线伏笔
