# 第631章 小炎姬，敌我不分

**概要**：黑畜妖首先扑向莫凡，柳茹瞬间出手将其撕碎，随后凭借速度和预判连续消灭多只黑畜妖。诅咒畜妖趁柳茹应对夹击时割开她的脖子，却被她抓住脚踝砸碎并斩首，伤口也迅速愈合。女执事认出柳茹是血族，命令剩余诅咒畜妖同时攻击。莫凡召唤小炎姬并解除约束，小炎姬释放灭世劫炎，把周围黑畜妖全部卷入火焰，连柳茹也只能及时跃起躲避。

**关键事件**：1.柳茹秒杀黑畜妖 2.柳茹反杀诅咒畜妖并自愈 3.女执事确认柳茹血族身份 4.小炎姬自行出现 5.灭世劫炎不分敌我

**逐章写法公式**：

- **情绪流向**：起：敌袭爆发 → 承：柳茹连续反杀 → 转：诅咒畜妖与血族身份升级 → 合：小炎姬放火，敌我皆需躲避
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：黑畜妖群攻（展示速度） + 诅咒畜妖偷袭（抬高威胁） + 血族自愈（完成反杀） + 小炎姬放火（扩大战场）
