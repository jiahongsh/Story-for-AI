# 第121章 魔都上海

**概要**：博城灾难后翼苍狼威胁未除、特有资源被黑教廷掠尽、地圣泉又被莫凡喝掉，莫凡就此事不止一次被请去喝茶，杨作河、穆卓云、斩空等人没有深究。莫家兴表示儿子已是顶天立地的男子汉、全听他安排，莫凡决定去魔都上海，莫家兴打听到上海有博城安置小区后报了名，一家三口经厦门乘动车出发。车上莫凡感叹这是自己第一次出远门，一本正经胡吹科学世界，被邻座一位明珠学府历史老教授训斥不尊重魔法先辈，莫凡由此得知明珠学府是上海一家独大的魔法学府。他盘算中阶可获一次新的觉醒机会、觉醒石昂贵且掌握在各组织手中，比起魔法协会，走魔法学校路线资源能者多得，于是向老教授打听特招。老教授先说除非某领域有杰出表现基本没有特招，被莫凡追问后改口"有，但我并不觉得那是正常人可以完成的"，没有再透露条件。

**关键事件**：1.莫凡决定全家迁往魔都上海并报上安置房 2.动车上结识明珠学府历史教授 3.教授透露特招存在但非正常人可完成

**逐章写法公式**：

- **情绪流向**：起：离乡的无奈 → 承：迁居的轻松 → 转：动车上的错位喜剧 → 合：特招悬念钩子
- **节奏配比**：慢铺垫 50% / 快冲突 0% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：交代离博城因果（收束前情）+ 定居魔都决定（开启新篇）+ 动车偶遇老教授（埋入学线）+ 特招之问（留钩收尾）
- **本章核心技巧**：用一场日常旅途戏完成地图切换，顺路借同车高人之口埋下入学途径的信息钩
- **卡点与伏笔**：结尾卡点：明珠学府特招存在但条件"非正常人可以完成"，条件未明引下章追问；埋设/回收伏笔：翼苍狼可能再袭（回收博城大战）、地圣泉被莫凡喝掉（回收前文）、明珠学府与特招（新篇入学引线）、第二次觉醒机会与觉醒石（后续觉醒线）
