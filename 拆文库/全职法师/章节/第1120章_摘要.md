# 第1120章 最强人（上）

**概要**：莫凡一剑斩出百米火焰剑坑几断水道，西士顿履魔具险避，却发现炎剑不消反被横扫火弧吞没；阿莎蕊雅瞬息移动将西士顿送回莫凡面前，莫凡苍雷爪加祝福强化近八倍将其鞭策。哲罗飞翼赶来救场，被阿莎蕊雅再次空间之镯送走。西士顿绝望，威尼斯之戒亮起出局。与此同时艾江图与卡洛欧丝解决希伯特，穆宁雪南珏逼退艾琳，穆婷颖再灭英一员；哲罗折返，众人围住艾琳，哲罗却落于其前不逃。希腊原队长伽门侬与哲罗本为死对头，阿莎蕊雅嘱南珏别让艾琳用魔具。哲罗两召唤兽发难：鹰爵叼起穆婷颖空中，大地邪虫将卡洛欧丝拖入地下。

**关键事件**：1.莫凡炎剑加苍雷爪解决西士顿 2.哲罗两度被送走，英多人出局 3.哲罗召唤兽鹰爵大地邪虫分别擒穆婷颖卡洛欧丝

**逐章写法公式**：

- **情绪流向**：起：炎剑斩西士顿的爽 → 承：送回沙包补刀的荒诞爽 → 转：哲罗召唤兽救场的波折 → 合：围艾琳的钩子
- **节奏配比**：慢铺垫 10% / 快冲突 50% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：炎剑斩（爽） + 送回补刀（荒诞爽） + 哲罗再送走（反转） + 西士顿出局（解决） + 召唤兽擒人围艾琳（钩子）
- **本章核心技巧**：用"增益不消+瞬移送回"把单个敌人做成连续喜剧式碾压
- **卡点与伏笔**：结尾卡点：哲罗召唤兽擒二人，下章风隶领域发威；埋设/回收伏笔：鹰爵大地邪虫→哲罗招牌，后文反复阻人
