# 第657章 跳入煞渊！

**概要**：韩寂离开后，莫凡、张小侯、方谷和苏小洛来到煞渊边缘。柳茹突然被阴风卷住，莫凡冲过去抓住她，四人合力仍被拖向深渊，莫凡只得让小泥鳅魂光扩大，把柳茹一起护住。韩寂已经离开，众人决定带柳茹一同下去。煞渊内部堆满鬼煞、狂尸和多年怨念，方谷承认自己宁愿自杀也不想跳入其中。张小侯最终先行，苏小洛提议四人一起跳，莫凡抱紧柳茹随后跃下。怨念穿透魂光，开始侵入莫凡的脑海和记忆。

**关键事件**：1.韩寂离开 2.柳茹被阴风卷住 3.莫凡用魂光保护柳茹 4.张小侯决定先跳 5.四人一起跳入煞渊 6.怨念侵入记忆

**逐章写法公式**：

- **情绪流向**：起：韩寂离场后的空缺 → 承：柳茹被卷入 → 转：四人面对煞渊恐惧 → 合：跳入后怨念侵入心灵
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：救回柳茹（扩大保护范围） + 观察煞渊（抬高恐怖） + 张小侯先跳（承担风险） + 四人坠落（进入新场景）
- **本章核心技巧**：用一次临时救援把外部关系转为共同冒险，再让跳跃动作结束地面准备、开启精神恐怖。
- **卡点与伏笔**：结尾卡点：怨念已经侵入莫凡脑海，下一章期待他能否保住自我；埋设/回收伏笔：小泥鳅魂光 → 保护莫凡和柳茹进入煞渊。
