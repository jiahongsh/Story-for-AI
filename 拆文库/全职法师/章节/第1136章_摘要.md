# 第1136章 战争老手！

**概要**：莫凡不信亡灵无穷无尽，回想哲罗混沌与纳斯卡巨画皆被破解，认定埃及亡灵亦非无限，只因希腊英国被消磨意志。他凭扎实基本功以初阶中阶魔法应战，雷印立场麻痹、地煞轰灭墓窟、念控退散、火滋千羽密集爆裂，魔耗极低。史瑞夫与米奥斯惊其如杀戮机器，奈夫鲁点破莫凡参加过战争、懂保存魔能。牧奴娇等人发现莫凡一人杀的亡灵堆成山，想起他经古都浩劫。莫凡盯住史瑞夫将其巨影钉封印后扔进海里出局，米奥斯大怒。莫凡借小泥鳅凝炼残魄如收金币，第五级霹雳有望，末了米奥斯竟召唤出统领级亡灵。

**关键事件**：1.莫凡以初阶中阶碾压亡灵 2.史瑞夫被扔海出局 3.米奥斯召出统领级亡灵

**逐章写法公式**：

- **情绪流向**：起：理念铺垫 → 承：低耗清场 → 转：史瑞夫出局 → 合：统领级悬念
- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：不信无限（立论） + 低耗群战（展技） + 扔史瑞夫（小爽） + 统领级钩子（加压）
- **本章核心技巧**：用敌方与队友双视角点评，把主角的战争老手人设坐实，再以收益视角淡化杀戮
- **卡点与伏笔**：结尾卡点：统领级亡灵登场，莫凡如何应对；埋设/回收伏笔：古都浩劫→抗压；小泥鳅→第五级霹雳
