# 第669章 活路是杀出来的！

**概要**：钟楼收到军方、猎人和禁卫法师大量伤亡的消息，楚嘉再次质疑跳入煞渊的决定，独萧反驳后带伤飞去救援。死门间中银色漩涡停止降下亡灵，但四人已被近两千只亡灵包围。刚刚晋升高阶却还不能构架高阶魔法的莫凡召出疾星狼和小炎姬，让疾星狼保护柳茹和苏小洛，小炎姬跟随张小侯，自己站到亡灵洪流前。亡灵冲入攻击范围后，莫凡用火系烈拳九蛟轰杀最前方数十只腐尸，并向同伴说活路不是走出来而是杀出来，准备独自杀穿死门间。

**关键事件**：1.钟楼收到各队伤亡消息 2.楚嘉和独萧争论 3.独萧飞去救援 4.亡灵雨停止 5.莫凡四人被近两千只亡灵包围 6.召出疾星狼和小炎姬 7.莫凡分配保护任务 8.烈拳九蛟轰杀腐尸

**逐章写法公式**：

- **情绪流向**：起：外界伤亡和争论 → 承：独萧离场、死门间形成包围 → 转：召唤兽分工与莫凡迎战 → 合：烈拳打出缺口并提出杀路
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：伤亡汇报（放大代价） + 救援离场（并行责任） + 亡灵包围（锁定战场） + 烈拳开路（给出主动方案）
- **本章核心技巧**：先让外界绝望和内部绝境同时达到高点，再用明确的战术分工把主角的升级转成可执行行动。
- **卡点与伏笔**：结尾卡点：烈拳只清掉最前方一小群腐尸，更多亡灵仍在逼近；埋设/回收伏笔：莫凡刚晋升高阶但尚未构架星座 → 迫使他依赖多系初中阶魔法和召唤兽作战。
