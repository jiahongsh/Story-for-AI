# 第662章 冲击高阶壁垒

**概要**：莫凡接过无法摧毁的永生妖莲，避开同伴和铜镜视线后取出小泥鳅坠。小泥鳅坠将妖莲吸成魂魄之光，收入内部的冥河天地；妖莲花瓣随后在冥河中逐瓣枯萎，再没有恢复。妖莲能量被吸收后，小泥鳅坠内部天地和冥河扩大，莫凡感受到连续传来的庞大力量。他把力量引入火系星云，开始冲击停滞已久的高阶壁垒。星云外的修为壁垒出现裂痕，但莫凡还需要更多能量才能完成突破。

**关键事件**：1.莫凡接触妖莲 2.小泥鳅坠吸收妖莲 3.妖莲在冥河中枯萎 4.坠内天地扩大 5.温养之力传入莫凡 6.莫凡把能量引入火系星云 7.高阶壁垒出现裂痕

**逐章写法公式**：

- **情绪流向**：起：众人对妖莲束手无策 → 承：小泥鳅坠吸收并验证克制关系 → 转：能量冲击火系星云 → 合：壁垒出现裂痕但突破尚未完成
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：隐蔽取出坠子（避免暴露） + 吸收妖莲（解决机关） + 观察枯萎（确认效果） + 冲击壁垒（转入修炼危机）
- **本章核心技巧**：把解决墓宫机关的道具收益转化为修为突破资源，使外部机关线和主角成长线在同一动作中合流。
- **卡点与伏笔**：结尾卡点：火系星云的壁垒仅出现裂痕，莫凡仍需承受更多能量冲击；埋设/回收伏笔：小泥鳅坠内部冥河 → 后续持续吸收妖莲并改变莫凡修炼状态。
