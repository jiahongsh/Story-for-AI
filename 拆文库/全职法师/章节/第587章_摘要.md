# 第587章 霸道宝宝小炎姬

**概要**：小炎姬兴奋地在墓室带路，莫凡与矮男循声找到被裹尸布绑在石柱上的十字疤男，裹布尸将倒挂一旁戏弄余青素。莫凡派小炎姬出击，余青素怒斥拿幼年期召唤兽送死，小炎姬却化作火球追撞尸将，火球越滚越大、从两米长到四米，天劫火焰烧得裹布尽毁，尸将裹布失效被追得满墓室乱跑。余青素看得目瞪口呆，被莫凡喊去解救人质。她全神贯注操控藤蔓解救疤脸时，一只羊角黑影从她背后无声站起，举着匕首正要割她的喉咙——矮男及时放出光佑圣盾，光系力量灼得鬼影惨叫逃窜。

**关键事件**：1.小炎姬化四米火球追得裹布尸将满墓室乱跑 2.余青素被莫凡喊去救疤脸，羊角黑影自背后持刀偷袭 3.矮男光佑圣盾救下余青素，灼退封喉角鬼

**逐章写法公式**：

- **情绪流向**：起：荒唐（小炎姬玩闹） → 承：惊讶（火球暴长） → 转：惊魂（暗影割喉） → 合：侥幸（圣盾护身）
- **节奏配比**：慢铺垫 10% / 快冲突 50% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：灵宠带路（转场景） + 火球碾压（放爽点） + 救援双线（埋暗杀） + 圣盾救命（立功臣）
- **本章核心技巧**：用明线战斗加暗线偷袭的平行剪辑，让读者先于角色察觉危机、替角色捏汗
- **卡点与伏笔**：结尾卡点：危机悬念——逃入暗处的羊角鬼影还会否再来；埋设/回收伏笔：封喉角鬼的偷袭能力 → 下章揭露其身份与威胁等级
