# 第1540章 军队首脑

**概要**：开罗方塔指挥部内，军统萨斯向坐中央首脑位的冷眸首脑（伊森）汇报战败，被讥讽训斥。冷眸首脑嘱咐安抚小美杜莎、处理逃掉的人，并让萨斯写假报告掩盖私调部队。矮小老者哈肯军首突然驾临，冷眸起身让出主位。哈肯以自己门徒战死、萨斯军队与法师交火等事旁敲侧击，冷眸用话术敷衍，还称否决并训斥了芬纳将军的荒唐报告。另一边，莫凡一行在西郊被军队通缉无法进城，蛇妖又步步紧逼，穆白判断他们得罪的不止一位将军，莫凡决定寻找设防薄弱处硬闯开罗。

**关键事件**：1.冷眸首脑训斥萨斯战败，布置处理善后 2.哈肯军首驾临，冷眸让位，二人暗藏交锋 3.莫凡一行被通缉困于西郊，蛇妖紧逼，陷入两难

**逐章写法公式**：

- **情绪流向**：起：萨斯受训的斥责 → 承：哈肯驾临的权斗 → 转：冷眸敷衍的揭底 → 合：主角被通缉的困境
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 0% / 悬念留白 50%
- **本章结构公式**：军部问责（反派内景） + 首脑交锋（权力博弈） + 通缉困局（主角受压） + 定计闯城（重启行动）

- **卡点与伏笔**：结尾卡点：全城军部通缉、蛇妖紧逼，众人决定硬闯开罗，前路凶险；埋设/回收伏笔：哈肯对冷眸的怀疑
