# 第161章 植物系！

**概要**：不服者在入口排成长龙。庄氏世家弟子庄离风上场自报家门，宣称从莫凡上场起就看他相当不爽；莫凡则因对方气息与别人明显不同而起了警惕。庄离风对风轨的运用远超常人，在斗兽场布下自己的风轨领域，幽狼兽连续三次爆发只在他右臂撕开一条小伤口；火系女学员的火滋·爆裂趁隙炸在幽狼兽身上，把它轰飞好几米，这是它当天第一道伤。莫凡让幽狼兽绕开庄离风先解决其他人，幽狼兽锁定火系女学员狂驰，却在距她20米处被地下窜出的带刺蔓藤捆住下肢拽倒——庄离风亮出第二系植物系，全场惊呼又是一个中阶魔法师。莫凡笑指他和罗宋还有很大差距，点破他描画不出完整星图、放不出任何中阶魔法。幽狼兽蛮力崩断怪藤脱身，撞飞火系女学员并依次送走冰系、光系学员；庄离风见伙伴全灭，眼里闪过狠意，趁幽狼兽缠斗之际借风轨直扑莫凡本人。

**关键事件**：1.庄离风以风轨领域牵制幽狼兽 2.庄离风暴露植物系第二系、藤变拽倒幽狼兽 3.莫凡点破其放不出中阶魔法 4.庄离风舍召唤兽直扑莫凡

**逐章写法公式**：

- **情绪流向**：起：轻松（长龙叫阵的群像） → 承：紧张（风轨领域与火滋首伤） → 转：爽（断藤反制、连清三人） → 合：紧张（庄离风直扑莫凡的惊变）
- **节奏配比**：慢铺垫 20% / 快冲突 55% / 爽点爆发 15% / 悬念留白 10%
- **本章结构公式**：对手亮底（风轨领域） + 反转牌（植物系藤变） + 压回（点破星图短板） + 惊变（直扑召唤师）
- **本章核心技巧**：给对手一张反转牌的同时立刻让主角用信息差压回，反转只用来抬高落差，不真正改变局势走向。
- **卡点与伏笔**：结尾卡点：动作悬置+庄离风借风轨飘影扑向莫凡，下章期待莫凡本人出手；埋设/回收伏笔：莫凡开场对气息的直觉→庄离风中阶身份的回收；召唤师本体可被攻击→下章蒋云明的规则说明。
