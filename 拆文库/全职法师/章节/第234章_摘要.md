# 第234章 烈拳·地刹

**概要**：宋霞循魔法印记带白藏锋、庄离风等五人锁定暗影妖兽方位，迎面撞上恶臭扑鼻的黑畜妖群——鬼猴脸、畸形人身、密密麻麻能倒爬行走。白藏锋顶着司夜统治的压制勉强放出风盘·龙卷，只摔死约三只黑畜妖，反惹得睚眦必报的妖群锁定围攻；宋霞斥他惹错了对象，又指挥庄离风放出坤之林·囚牢封路，却被大阵压制得只剩三分之二、留出明显缺口。宋霞站到队伍最前，以烈焰裹身施展烈拳·地刹，火焰能量顺地表蔓延炸出火刹之莲，把冲来的黑畜妖尽数烧成黑色粉末，随后下令趁余焰快撤。五人转身后，莫凡从黑暗迷宫墙中现身，火焰在司夜统治下丝毫不受压制，以威力更强的玫炎·烈拳·地刹轰向残存妖群，成片黑畜妖在复仇之火中化为灰烬。

**关键事件**：1.白藏锋风盘龙卷误惹黑畜妖群遭围攻 2.宋霞烈拳·地刹烧灭妖群救场撤离 3.莫凡现身以玫炎·烈拳·地刹收割残群

**逐章写法公式**：

- **情绪流向**：起：紧张（循印记遇袭） → 承：恐怖（黑畜妖群涌来） → 转：热血（宋霞地刹救场） → 合：爽（莫凡玫炎地刹碾压收割）
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：循迹遇妖（目标与危机同时抵达） + 误击惹祸（白藏锋引火烧身） + 地刹救场（宋霞立威断后） + 主角收割（莫凡超规格补刀）
- **本章核心技巧**：同一种魔法（烈拳·地刹）让精英与主角各施一次，用规则例外与火焰成色把两人的差距写成肉眼可见的画面
- **卡点与伏笔**：结尾卡点：猎杀卡点——莫凡火力全开、成片妖群化灰，下章期待循妖群追到黑教廷本体；埋设/回收伏笔："除非自身拥有暗影系可保证其他魔法不受限制" → 暗示莫凡暗影系底牌；玫炎异于常火 → 焚焰异变伏笔；坤之林被压制 → 牧奴娇坤之林的同源对照
