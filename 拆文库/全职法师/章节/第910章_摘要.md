# 第910章 算钱！

**概要**：残余黑教廷成员欲混入旅客逃走，因上头被擒难脱审判会核查。暴毙毒母一死毒变停止、毒怪彻底消亡，审判使者夜鹰清扫庄园，莫凡将芳少俪交其带回，自己到橙楼诅池捞起汪栩栩洗净披衣。金战猎人团团长葛明凭高修为奇迹活命，葛明潘晋对莫凡感激称青天猎所之恩。莫凡盘算赏金：灰衣教士八九千万、芳少俪头值一亿二，先给穆宁雪买星河之脉，余钱下月结供小炎姬、召唤与暗影空间进阶。闲来想起未报国馆，赶到时正撞埃及队赛以德率队寻仇。

**关键事件**：1.毒变停审判会清扫 2.莫凡救汪栩栩 3.葛明活命金战致谢 4.赏金核算分配 5.莫凡撞埃及队

- **情绪流向**：起：毒变停的安 → 承：救人的温 → 转：致谢的暖 → 合：算账撞敌的转
- **节奏配比**：慢铺垫 30% / 快冲突 10% / 爽点爆发 20% / 悬念留白 40%
- **本章结构公式**：毒变停（安） + 救汪栩栩（温） + 金战致谢（暖） + 算账撞敌（转）
- **本章核心技巧**：战斗后用"算账"做喘息，长线伏笔收束并接新事件
- **卡点与伏笔**：结尾卡点：埃及队来意，下章揭晓；伏笔：星河之脉 → 穆宁雪进阶线
