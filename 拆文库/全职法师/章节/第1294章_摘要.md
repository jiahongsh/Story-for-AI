# 第1294章 贱到极致的山人

**概要**：突围中山人不断被意念撞飞跌落，莫凡的精神修为进入第五境界后意念可分化更多缕、威力大增，一个意念撞击角度好甚至能秒杀，视野盲区的偷袭也被他连头都不转地撞飞。赵满延防御与进攻交替，魔能枯竭得严重，他怨自己想过各种死法却没想过死在树上。山人们蹲在下方树枝上不再追赶，赵满延却高兴不起来——野外经验告诉他，敌人忽然罢手意味着前方有更危险的东西。众人继续上爬数百米甩开山人，来到一片过分安静的枝叶迷宫，发现一头脑袋如蜥、身如妖豹、大统领级的四命蜥虎正趴在树杈上酣睡，灵灵压低声音说它嗜睡但醒了非常可怕、连君主级都不畏惧。众人蹑手蹑脚逃离时，一只小山人竟从下面跳上来冲到四命蜥虎嘴边狂啼，把沉睡的四命蜥虎唤醒后当场被生吞，四命蜥虎抬眼直勾勾盯向众人，速度快到只剩残影地追来。莫凡用瞬息移动把七人一起传送出三四百米，再连施第二个星座甩开四命蜥虎。事后赵满延暴躁发誓要把山人全宰了，灵灵让莫凡用暗影气息隐藏，众人躲藏休息。关溪溪问晨颖高度，晨颖却出神地凝视夜空，说自己好像见过这幅画面——是在外婆屋子里挂着的一幅画，树叶连天、枝干成道、星光在远方。

**关键事件**：1.莫凡意念突破后碾压山人，甩开追兵 2.赵满延预警敌人罢手意味着更危险 3.发现酣睡的四命蜥虎，众人蹑手蹑脚逃离 4.小山人主动送死唤醒四命蜥虎，众人被追击 5.莫凡连续瞬息移动脱身，藏匿休息 6.晨颖认出神树画面与外婆屋里的画相似

**逐章写法公式**：

- **情绪流向**：起：意念碾压山人脱困的爽 → 承：敌人罢手的反常预警与四命蜥虎的压抑 → 转：山人送死唤醒蜥虎、极速追杀的恐怖 → 合：脱身藏匿的喘息与晨颖认画的悬念
- **节奏配比**：慢铺垫 20% / 快冲突 40% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：莫凡意念碾压追兵（爽点） + 山人罢手与四命蜥虎现身（铺垫） + 小山人送死唤醒、极速追杀（冲突） + 瞬息移动脱身与晨颖认画（收束+钩子）
- **本章核心技巧**：用敌人的反常行为做危险预告，再用「最小代价换最大威胁」的送死战术刷新威胁定义，最后用技能透支代价与人物记忆线索双重留钩
- **卡点与伏笔**：结尾卡点：晨颖认出神树画面与外婆屋里的画相似，画从何来、与神树什么关系 → 下章期待真相；埋设/回收伏笔：四命蜥虎在树上游荡 → 后续威胁；山人不甘堵在下层 → 复仇线延续
