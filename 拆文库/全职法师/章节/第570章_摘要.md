# 第570章 绿茶男

**概要**：莫凡按矮男的指引找到博城人聚集的回离街，这是一条卖碎小魔法物品的横道，店员老板多是博城人，日子过得不错。他撞见开店骂街的赵坤三，赵坤三满肚子气骂进货的垃圾货，听到有人叫自己外号赵腿子顿时火大要轰死人，认出是莫凡后声音越来越小，态度大变。赵坤三马上把莫凡来踢店的事禀报给穆白，穆白面无表情赶来，莫凡一句绿茶男让他脸色一阴。闲谈中穆白透露这条街是他买下的，博城迁徙来的人多在此做事，还冷哼一声说穆家把我们当乞丐，大穆氏根本不把小分支放在眼里，只对穆宁雪的天生天赋感兴趣。穆白订了餐厅，约周敏、王胖子晚上聚会。

**关键事件**：1.莫凡在回离街撞见赵坤三，认出彼此 2.穆白赶来，透露穆家只重视穆宁雪天赋、看不起小分支 3.穆白订餐厅约周敏、王胖子晚上聚会

- **情绪流向**：起：怀旧（他乡见老乡） → 承：闹剧（赵坤三变脸） → 转：暗涌（穆白旧怨） → 合：叙旧（约定聚会）
- **节奏配比**：慢铺垫 60% / 快冲突 20% / 爽点爆发 0% / 悬念留白 20%
- **本章结构公式**：寻街认亲（背景铺开） + 赵坤三变脸（喜剧小冲突） + 穆白对话（信息量） + 约定聚会（钩子）

- **卡点与伏笔**：结尾卡点：晚上聚会周敏王胖子会聊什么，下章期待同学会与城墙之行；埋设/回收伏笔：穆家对穆宁雪天赋的觊觎
