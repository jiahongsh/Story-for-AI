# 第49章 智商碾压！

**概要**：洞窟中莫凡把火滋·焚骨抛向高空，焚骨烈焰瞬间烧断巨大钟乳石细长的根部，倒垂而下的钟乳石如岩石巨剑般从背部贯穿至腹部，把动弹不得的幽狼兽活活钉死，狼血在其下淌成醒目一滩。山口外，遍体鳞伤的学生们目睹总教官斩空背凝风之翼从高处飞落，惊呼天使降临；斩空飞入洞窟释放火滋·爆裂照亮整个洞窟寻找那名释放焚骨的学生，却看到不敢相信的一幕呆立当场。石台处，白阳解释自己从未下达杀戮命令、不知召唤兽为何发狂，随即感到如灵魂被砍一刀的剧痛，跪倒在地，失魂落落地吐出“我的幽狼兽它死了”，语气连他自己都不信。

**关键事件**：1.莫凡烧断钟乳石将幽狼兽钉死 2.斩空展风之翼入洞目睹狼尸震惊呆立 3.白阳灵魂剧痛当众感知幽狼兽已死

**逐章写法公式**：

- **情绪流向**：起：绝境对峙的紧张 → 承：抛火滋制造悬念 → 转：钟乳石贯穿的爽点爆发 → 合：白阳痛报狼死的错愕余波
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：抛火滋烧钟乳石（布局杀招）+ 巨石贯穿钉杀（爽点爆发）+ 斩空入洞目击（反应放大）+ 白阳痛报死讯（悬念钩子）
- **本章核心技巧**：杀招先藏后揭，再用救援者与召唤师两个远端视角的反应层把单杀战绩推到最大化
- **卡点与伏笔**：结尾卡点：狼死消息惊爆而凶手未揭，下章期待真相大白；埋设/回收伏笔：白阳不知召唤兽为何发狂 → 失控原因成待查线索
