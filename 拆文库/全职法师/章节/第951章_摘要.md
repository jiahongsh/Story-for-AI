# 第951章 两边要钱！

**概要**：蒋少絮欲叫支援，却发现村寨有信号屏蔽，通讯失效。西葛的手下已盯上年轻女孩，西葛假意给一刻钟，随即反悔索要两倍价并要带走村中女子。蒋少絮怒不可遏，莫凡定下"雌雄双盗"伪装之计。二人径直走到西葛面前，莫凡抛两枚最小面值硬币侮辱蒋少絮身价，激怒西葛。莫凡反称此村自己早盯上，开口索要三千万赎金。一村民误以为他们是来救人的，莫凡当众轰飞他（实则暗中以空间魔法托住未死）示威。于是莫凡一边向红饰要钱、一边向村民也要钱，"两边要钱"的猖狂局面令全场傻眼。

**关键事件**：1.信号屏蔽无法求援，西葛加码逼价 2.莫凡蒋少絮定雌雄双盗伪装计 3.莫凡抛硬币侮辱、开价三千万 4.轰飞误认救援的村民示威，两边要钱

**逐章写法公式**：

- **情绪流向**：起：断援加压 → 承：西葛逼价愤怒 → 转：双盗反抢爽感 → 合：两边要钱留钩
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：屏蔽断援（困局） + 西葛逼价（激愤） + 双盗反抢（爽爆） + 轰民示威（蓄势）
- **本章核心技巧**：用"主角扮恶反制恶"的错位计谋写逆袭，把营救藏进狠辣表演里
- **卡点与伏笔**：结尾卡点：红饰公会如何应对反抢留悬念；埋设/回收伏笔：轰飞村民未死→后续揭空间托底
