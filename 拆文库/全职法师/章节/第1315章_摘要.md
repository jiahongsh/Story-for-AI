# 第1315章 九宫蛟炎龙

**概要**：焰星从天而降在潘西、黎红眉、南荣熙三人之间爆开，火焰冲击冕将三人掀飞，莫凡的身影在团团火焰中浮现，身上交织着红霞焚天之色与褐色天地劫炎——小炎姬成功蜕变为成长期，赐予他最纯净的灼原北角天之火焰。莫凡怒骂送几人去投胎，灼火之目逼得四人后退，南荣倪认出他却不以为意，黎红眉不屑地称他不过走了运的毛头小子，自告奋勇来对付他。黎红眉以岩碎尘埃困住莫凡，反被莫凡以高阶瞬息移动绕后，火莲绽开、通天巨炎拳轰碎其层层山岩防御，一拳将她打得口吐鲜血砸入水中，火焰入水不灭仍灼烧其身。另一边南荣熙与潘西对穆宁雪使出杀手锏，穆宁雪凭修为勉强支撑。莫凡解决黎红眉后杀意凝视潘西，想起威尼斯之仇绝不放他，随即瞬息移动逼到南荣熙面前放话要打残他，双火领域爆发令海水沸腾蒸发，南荣熙的水系掌控大打折扣。火元素达暴躁临界点，莫凡一拳轰向空中，九条火之蛟龙以九宫之阵冲天而起，岛屿狂颤、海水晃动。

**关键事件**：1.小炎姬成长期赐予莫凡灼原北角天之火焰，双火附体现身 2.莫凡火莲加通天巨炎拳轰飞黎红眉 3.莫凡双火领域压制水系南荣熙，释放九宫蛟炎龙

**逐章写法公式**：

- **情绪流向**：起：焰星落地的震撼登场 → 承：群敌轻敌、黎红眉缠斗 → 转：巨炎拳轰飞黎红眉、杀意锁定潘西 → 合：九宫蛟炎龙的压制高潮
- **节奏配比**：慢铺垫 10% / 快冲突 55% / 爽点爆发 30% / 悬念留白 5%
- **本章结构公式**：焰星登场震慑全场（亮实力） + 黎红眉轻敌缠斗被秒（爽点） + 旧恨引出潘西、逼向南荣熙（情感加压） + 九宫蛟炎龙压制水系（技惊四座）
- **本章核心技巧**：用升级后的一招秒杀确立新实力档次，再用"旧恨+新仇"的对象切换维持情绪热度
- **卡点与伏笔**：结尾卡点：悬念型——九宫蛟炎龙冲天而起、威力惊人，南荣熙与潘西如何应对、穆宁雪能否脱险留待下章；埋设/回收伏笔：小炎姬成长期蜕变 → 莫凡获得灼原北角天之火焰；威尼斯潘西奸计 → 莫凡此刻复仇的执念；水系被火域蒸发 → 莫凡属性克制压制南荣熙的依据
