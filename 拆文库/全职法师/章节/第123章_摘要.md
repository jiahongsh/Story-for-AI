# 第123章 唐月的邀请

**概要**：吞噬地圣泉后，莫凡不冥修星云也保持成长。近一个月的把控练习里，前七颗星子他熟练连成初阶星轨；第8颗星子搬入安置房第一个星期就"妥协"，第9颗威逼利诱才屈服且稍不专心就断裂，第10颗需在保持九星星轨主轴不断裂的同时开辟新星轨，失败无数次后终于固定——他由此掌握中阶星图要领，而不少中阶魔法师钻研星图要数年、能释放时已鬓发苍白。他练习已有魔法，雷印火滋已压到约1.5秒。这时唐月来电，从斩空处问到他的下落，警告上海水深、穆氏这样的大族在大魔都都算小家族，邀他去杭州偏北的镇子协助执行任务，并许诺任务完成后带他去魔法协会觉醒。莫凡追问她的身份未果，只得知对方"正好需要一位雷法师"、已备好雷系星图之书，听到"干完这一票"的措辞只能腹诽人民教师注意用词。

**关键事件**：1.莫凡练成第10颗星子把控、掌握星图要领 2.唐月来电邀他赴杭州协助任务 3.唐月许诺事后带他觉醒并备好雷系星图之书

**逐章写法公式**：

- **情绪流向**：起：修炼的枯燥 → 承：第10颗成功的突破 → 转：唐米来电的意外 → 合：赴约前的好奇与期待
- **节奏配比**：慢铺垫 55% / 快冲突 0% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：星子逐颗驯服（进度推进）+ 第10颗攻克（小爽点）+ 释放提速确认（实力校准）+ 唐月来电邀约（新任务钩）
- **本章核心技巧**：修炼章不写流水账，把每颗星子写成有性格的对手，再用一通电话把剧情甩入新任务
- **卡点与伏笔**：结尾卡点：唐月身份成谜、任务内容不明，"干完这一票"引人赴约；埋设/回收伏笔：第10颗星子（中阶释放线）、1.5秒释放偏慢（顺发目标线）、唐月身份与星图之书来源（大势力伏笔）、觉醒石报酬（第二次觉醒线）
