# 第118章 博城勇士

**概要**：莫凡推心夏走出广场，看到痛苦爬行的黑畜妖中三只已被其他生物啃得尸断几截，侥幸逃走的受伤妖魔在同类眼中比人类更可口、走不远就会被吃光。他告知计划是到嘉美高架桥取军方的暗石摩托返回安全结界，随后以时走时停、忽而加速、借遮蔽物隐藏的走位带心夏穿过妖魔游荡的街区，游荡的妖魔见了他们反而忌惮绕行。心夏惊问之下，莫凡透露是妖魔感受到了比自己强大的气息，心夏惊喜确认他已是中阶魔法师；莫凡大笑承认，又坦承中阶魔法并未完全练成，能释放全靠唐月送的星图之书，四张已烧掉两张、最多还能使用两次中阶魔法。忽然莫凡感知到一大群高速移动的妖魔正在接近，抱起心夏躲进楼道一口气跑上五楼，从窗口目睹数不清的独眼魔狼与巨眼猩鼠如潮水灌满附近街道、疯狂追逐几个人影：罗云波踩着风轨拉着潘丽君，徐大荒与另一位军法师在另一条街道逃命。莫凡望见铭文女子中学的食堂与操场塌陷成硕大坑洞——妖魔入口已被摧毁、博城保住了；但程军官等人已不见踪影，罗云波与潘丽君被妖魔包夹。莫凡抱起心夏冲上天台，认定他们是博城的勇士，无论如何不能见死不救。

**关键事件**：1.莫凡携心夏穿城，坦白中阶靠星图之书、仅剩两次限额 2.目睹妖魔入口被摧毁、教官小队仅余四人被追杀 3.莫凡决心上天台救援博城勇士

**逐章写法公式**：

- **情绪流向**：起：轻松（穿城同行）→ 承：紧张（妖群压境）→ 转：压抑（勇士被围、程军官疑似牺牲）→ 合：热血（上天台救人）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：穿城坦白（温情+信息）+感知躲避（危机逼近）+窗边观战（成功与绝境同框）+冲上天台（决心钩子）
- **本章核心技巧**：用"旁观者窗口"（五楼窗户）同时呈现大胜与大败，把下一场爆发戏的地势与动机一并备齐
- **卡点与伏笔**：结尾卡点：莫凡携心夏冲上天台，如何隔街救人留待下章；埋设/回收伏笔：星图之书剩两张→本章公示限额；程军官队伍的入口位置（第110章推测在食堂之下）→本章确认摧毁；翼苍狼与斩空→借罗云波的心愿侧写，留在外线
