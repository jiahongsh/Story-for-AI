# 第755章 你看不见她？

**概要**：入夜闫明寺寂静无虫鸣，纸油灯幽幽，莫凡坐石龟觉寺庙不寻常想讲下午离奇经历，蒋少絮却催其陪自己下山采购，二人顺阶而下时蒋少絮刻意贴近暧昧，提及莫凡名字耳熟，莫凡自嘲大众名；行至中途莫凡闻到一缕非蒋少絮身上的草香，前方阶梯忽现宫田——朴素淡雅、带燕尾蝶装饰，笑容纯白却透妖异。蒋少絮却看不见前方少女，笑莫凡用无聊手段骗豆腐，甚至与宫田擦身而过浑然无觉，宫田礼貌与莫凡交谈、称"赵满延"是不错的名字后渐融夜色，莫凡确认唯己可见、蒋少絮真听不见，前方只余一缕药草芬芳。

**关键事件**：1.蒋少絮邀莫凡夜陪下山，途中暧昧 2.宫田夜现石阶，蒋少絮却看不见 3.宫田与莫凡交谈后消失，唯莫凡可见

**逐章写法公式**：

- **情绪流向**：起：入夜安静铺垫 → 承：暧昧下山 → 转：宫田夜现惊悚 → 合：唯己可见留悬
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：入夜疑寺（铺垫） + 暧昧同行（调剂） + 宫田夜现（惊） + 视角矛盾消失（钩子）
- **本章核心技巧**：用"蒋少絮看不见/莫凡看得见"的视角矛盾做信息差，恐怖感来自他人无觉
- **卡点与伏笔**：结尾卡点：宫田唯莫凡可见、身份成谜（强悬念）；埋设/回收伏笔：药草芬芳 → 后续循香寻人；莫凡化名赵满延 → 勾魂需名伏笔
