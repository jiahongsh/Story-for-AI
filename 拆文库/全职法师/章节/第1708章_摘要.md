# 第1708章 同样是带队

**概要**：队伍进入潮湿阴凉的卢岭裂谷，娑风减弱，张小侯凭多年秦岭经验带队疾行，引开潜伏妖魔，遇到无法避让的便"关门杀"速战速决，四五公里畅通无阻。许参谋一句称赞被李德鑫瞪眼。白鸿飞感慨张小侯比紫禁军更有军人气质，赵满延顺势提起北疆黑教廷与胡夫金字塔的往事，绘声绘色讲给白鸿飞、阿帕丝、俞师师听，涉及机密的古老王与恶魔系被他咽了回去，只换来俞师师一句"怎么感觉你是哪里听来的"。

**关键事件**：1.张小侯带队轻松穿过裂谷 2.白鸿飞感慨张小侯的军人气质 3.赵满延讲北疆黑教廷与金字塔往事 4.赵满延发毒誓担保故事真实

**逐章写法公式**：

- **情绪流向**：起：轻松 → 承：称赞与暗流 → 转：故事开讲 → 合：斗嘴收尾
- **节奏配比**：慢铺垫 45% / 快冲突 5% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：张小侯带队过关（展示实力）+ 许参谋称赞被瞪（暗线冲突）+ 赵满延讲北疆往事（回馈旧剧情）+ 俞师师怀疑与发誓（制造笑点）
- **本章核心技巧**：以行军过程铺底色，把回忆性剧情包在熟人互怼的对话里自然带出。
- **卡点与伏笔**：结尾卡点：对话型——俞师师"怎么感觉你是哪里听来的"后赵满延发毒誓，下章期待：继续赶路逼近百拔山；埋设/回收伏笔：北疆、金字塔、古长城往事 → 为白鸿飞日后与主角团共事铺垫背景
