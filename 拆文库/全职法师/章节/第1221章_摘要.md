# 第1221章 覆灭之军

**概要**：安角镇上空深褐尘埃振动颤地，数不尽的尘暴魔蜢遮天蔽日、比暴风雨可怕千倍，镇上大楼被魔蜢塞满、正试图冲破地下避难所大门；石门后百余名军法师轮守，幽暗大厅里挤满瑟瑟发抖的工人居民，黎庆坦言魔蜢不散便活不成，老者只求八岁孙女活命。安角镇十五公里外岩层后，四支千人军由四军统率领、勺参谋总指挥，离曼率五十余人的特殊作战营随行；莫凡等高地处见黑压魔蜢如通天黑风罩住全镇十公里。离曼说千人火系军穿火铠组火之护罩、先带食水入镇查结界失效因，并讲木达军司创火焰结界使魔蜢隔于要塞外、魔蜢最怕火。灵灵忽然问会不会有不怕火的魔蜢，离曼极肯定不可能；莫凡听罢浑身一栗，取出变异小魔蜢所赠岩晶捏碎，内里竟是一头胎死卵中的尘暴魔蜢！莫凡拉离曼冲向指挥营。与此同时火系千人军背负食水踏入魔蜢漩涡，范亮领喊"无所畏惧"拒听撤离令，通讯中断；十五公里外指挥营众人目睹千人军渐被魔蜢吞没、火焰结界无效、军人被叼成白骨，莫凡自责未早识火焰魔山石堆全是变异卵。

**关键事件**：1.避难所万人绝望，前线部署火护罩送粮 2.岩晶现魔蜢卵，证变异种不怕火 3.千人先锋军拒撤令、被魔蜢覆灭成白骨

- **情绪流向**：起：避难所绝望的悲 → 承：火护罩计划的指望 → 转：岩晶卵揭变异的寒 → 合：千人覆灭的白骨
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：避难所绝境（悲） + 火护罩送粮（望） + 岩晶卵揭变异（寒） + 千人拒撤覆灭（殇）
