# 第828章 只身引雷

**概要**：莫凡摸出银纸包裹的凝华邪珠，嫌其邪光诡异不宜久带，打算事了就丢给望月千熏。他忽觉奇冷，跳上高处见五百米外一片冰霜覆楼、海水冻结，认出是穆宁雪的冰霜之气，喜出望外循迹杀去。冰刃风暴在冰寒中心飞旋撕碎低阶狞鲨妖，风暴中央一名十几米高怪兽正挥倒刺臂狂锤施法者。莫凡冲到见穆宁雪银发依旧艳丽，衣上却一片嫣红、血染冰块，顿时暴怒跃起引紫黑雷电加身，以霹雳砸中蓝谷凶离兽尖足，再咆哮"电灾"编织雷网电击，第四级霹雳连统领级鳞甲也难成绝对防御，却令他雷系星云剧烈动荡。脑海蛊惑声劝他借邪珠之力，被莫凡怒骂滚开、断定是那破珠子作祟。他施展念控虚空之爪将电麻的蓝谷举起吊甩，撞碎两三栋冻结楼房，广濑惊觉这是空间系力量。穆宁雪骇然认出那银辉与艾江图同属空间系。莫凡再唤小炎姬化火球撞去、引燃主街，并召出玄蛇铠甲与血兽靴摆出肉搏架势。

**关键事件**：1.莫凡寻冰霜找到穆宁雪、见其染血暴怒 2.以身引雷电灾击蓝谷、拒邪珠蛊惑 3.念控甩飞蓝谷、广濑穆宁雪认空间系 4.唤小炎姬与魔具暴走迎战

**逐章写法公式**：

- **情绪流向**：起：寻人的期待 → 承：见血染的怒 → 转：引雷电灾的燃 → 合：空间系曝光+暴走的更燃
- **节奏配比**：慢铺垫 15% / 快冲突 35% / 爽点爆发 40% / 悬念留白 10%
- **本章结构公式**：寻迹定位（引） + 见血暴怒（爆） + 引雷甩兽（爽） + 亮空间系+召炎姬（升级）
- **本章核心技巧**：用"挚友重伤"做情绪开关，把新能力（空间系）在怒极时刻自然亮出。
- **卡点与伏笔**：结尾卡点：莫凡全副武装暴走，下章期待如何与蓝谷硬撼；埋设/回收伏笔：凝华邪珠蛊惑 → 首次主动诱主，承接前章魔音，留邪珠长线。
