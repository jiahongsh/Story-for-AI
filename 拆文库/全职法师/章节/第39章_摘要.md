# 第39章 雪峰山驿站

**概要**：一百名尖子生进入雪峰山小寨，主道集市上摊贩二秃子叫卖用奔妖后肢皮做的履魔具，另有摊位出售五彩魔石。借莫凡的观察补全世界观：魔石由元素浓郁之地孕育、蕴含类似魔能的能量，可镶嵌魔器魔具供能、提炼后可当货币，这个世界不存在石油水能风能电能，电厂靠雷系魔石、蒸汽机由火系魔法师瓦特依火系魔法图驱动，而妖魔同样以魔石为重要食物和变强能量，人魔之战因此从未停歇，人类大多只能生活在需魔法师守护的城市里。张小侯提醒莫凡，历练评估占考大学20%的比重、由军方总教官评定，穆宁雪所在的帝都学府至少要A，莫凡决心拿到A以上；王三胖却爆料教官是学校打点过的，混日子也至少拿B或C。百名学生在中央广场集合，被驿站老猎者们围观讥笑、打赌多少人会吓尿裤子，一队军法师随后走来，总教官正是哨岗玩火的斩空。

**关键事件**：1.驿站集市展现魔具魔石生态，补全魔石即世界能源的设定 2.张小侯点明历练评估占20%且系帝都学府门槛，莫凡立下拿A目标 3.学生广场集合遭老猎者讥笑，总教官斩空现身

**逐章写法公式**：

- **情绪流向**：起：逛集市的松弛 → 承：世界观与利害信息的加压 → 转：被围观讥笑的憋闷 → 合：总教官现身的悬念
- **节奏配比**：慢铺垫 70% / 快冲突 10% / 爽点爆发 5% / 悬念留白 15%
- **本章结构公式**：集市见闻（铺世界观）+ 评估利害（立动机）+ 打点内幕（放松误导）+ 广场受嘲与总教官现身（压势加钩子）
- **本章核心技巧**：把魔石经济、人魔矛盾等硬设定全部缝进逛街、对话与吐槽，信息密度大而叙事不停顿
- **卡点与伏笔**：结尾卡点：亮相型——总教官正是玩火的斩空，下章期待考核内容；埋设伏笔：帝都学府需A → 莫凡升学长线；猎者的轻视 → 后文打脸势能
