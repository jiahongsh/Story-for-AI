# 第904章 群石念控

**概要**：一群黑畜妖扑向莫凡，方脸男管家嘲讽其逞英雄，莫凡认出这管家正是给卡莉下套、坑金战猎人团的黑教廷成员。熔浆之拳横扫黑畜妖成焦土，男管家续派群妖当炮灰，莫凡令疾星狼撕咬。小炎姬火羽之翼助推莫凡飞冲长桥，千层火羽四射将桥上畜妖成片爆破。六名灰衣教士中阶联排炮台轰来，莫凡遁影暂避，退至桥边以空间念控操控大石、碎石、中石悬浮如骤雨砸向法师，令其抱头鼠窜。

**关键事件**：1.莫凡认男管家是黑教廷 2.熔浆拳扫黑畜妖 3.小炎姬火羽冲桥 4.千层火羽爆破 5.念控群石砸法师

- **情绪流向**：起：认反派的冷 → 承：扫妖的爽 → 转：火羽冲桥的爆 → 合：念控砸法的酷
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：认反派（冷） + 扫妖群（爽） + 火羽冲桥（爆） + 念控砸法（酷）

- **卡点与伏笔**：结尾卡点：法师群是否被全灭，下章揭晓；伏笔：男管家土系 → 岩障将破
