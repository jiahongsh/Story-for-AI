# 第644章 挟持人城！

**概要**：莫凡从穆贺关于今夜覆灭的说法中意识到黑教廷可能马上执行更大的计划，穆贺则要求他替自己向韩寂传话。莫凡猜出黑教廷要救出撒朗，穆贺承认他们将撒朗性命与百万人城绑定：若不取消断头计划，黑教廷就让整座内城陪葬。作为交换，穆贺愿意提供秦王皇陵的位置。莫凡回到钟楼，把韩寂、神秘灰白男子、张小侯、周敏、穆白、方谷及多方高层召集起来。穆贺随后公开穿着蓝衣执事风衣现身，要求释放软禁高层，并声称张小侯的忘虫解药可验证他提供的陵墓位置。

**关键事件**：1.穆贺提出向韩寂传话 2.黑教廷以百万人城威胁 3.秦王皇陵成为谈判筹码 4.穆贺在钟楼公开现身 5.穆贺要求释放软禁高层并交出忘虫解药

**逐章写法公式**：

- **情绪流向**：起：夜幕将至的疑问 → 承：百万人城被威胁 → 转：皇陵成为筹码 → 合：穆贺公开谈判，魔法协会被迫回应
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：提出传话（制造谈判） + 绑定城市命运（抬高筹码） + 提供皇陵位置（给出希望） + 公开现身（迫使释放高层）
- **本章核心技巧**：让反派用“最后希望”包装威胁，把主动权从抓捕现场转为条件交换。
- **卡点与伏笔**：结尾卡点：穆贺以忘虫解药和皇陵位置要求释放高层，下一章期待魔法协会是否接受；埋设/回收伏笔：张小侯体内忘虫 → 成为验证穆贺情报真伪的筹码。
