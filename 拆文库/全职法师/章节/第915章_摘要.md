# 第915章 一拳解决！（上）

**概要**：莫凡在国馆斗场上指着埃及队的米奥斯，用对方曾羞辱自己的原话“滚出我的视线”回敬，逼得米奥斯脱去外套亲自下场。埃及队长辛德察觉莫凡不简单，主动请战并断言米奥斯胜算不到六成，反被米奥斯怒斥。莫凡抢先违规召唤小炎姬，小炎姬化作直径三米的劫炎火球冲撞，米奥斯以高阶土系天纱凝出弧沙墙盾挡下大半。米奥斯再凝巨型沙爪拍向小炎姬，莫凡用空间系虚空之力将小炎姬扯离险境。见米奥斯掌控力逼近领域级，莫凡让小炎姬附体，方圆百米燃起玫炎与劫炎混合的虚实火域，背后更展开两扇赤红千层火羽，震慑全场。

**关键事件**：1.莫凡以原话羞辱米奥斯，逼其亲自上场 2.辛德评估莫凡实力，称米奥斯胜算不足六成 3.小炎姬附体，莫凡展开火翼虚领域，战局全面升级

**逐章写法公式**：

- **情绪流向**：起：对峙挑衅的火药味 → 承：辛德示警加压 → 转：小炎姬爆发与附体反转 → 合：火翼展开的余波震慑
- **节奏配比**：慢铺垫 35% / 快冲突 40% / 爽点爆发 15% / 悬念留白 10%
- **本章结构公式**：莫凡言语挑衅（逼米奥斯下场）+ 辛德示警（抬高对手）+ 小炎姬首轮冲撞（试探）+ 附体火翼（升级钩子）
- **本章核心技巧**：用对手阵营的内部评估与外部反应层层放大主角实力，强能力分段释放制造递进爽感
- **卡点与伏笔**：结尾卡点：莫凡火翼展开未出手，下章期待一拳定胜负；埋设/回收伏笔：小炎姬附体 → 后续火系质变的战力锚点
