# 第1404章 杀无赦

**概要**：莫凡在斩空铠袍扶肩下站起，方知那座金字塔之山原是自己失了力气与信念。斩空问及"埃及亡灵"，莫凡答是胡夫金字塔、胡夫现为冥神，斩空冷冷不屑"故弄玄虚也敢称冥神"。古老王重重跺脚，黑色亡灵波纹锥形席卷金字塔，令其冥辉涣散出现空洞、埃及亡灵将遭蒸发，并意念传令"半天之内带陵墓亡灵滚出华夏之土"。胡夫令斯芬克斯黄金冲刺扑来，地底却拔起山峰之尸，以更雄壮之躯迎击、举摔斯芬克斯并拳砸其脸，连冥君蛙亦被踢撞统帅。胡夫质问"何方神圣"，古老王回以"犯我华夏之土，杀无赦"，再跺脚放出更磅礴亡灵波，与此同时九百黄石山脉上浩浩荡荡的古都亡灵大军破土而出，灰色与血色死气覆盖了北原疆土。

**关键事件**：1.斩空不屑伪冥神，亡灵波重创胡夫金字塔冥辉 2.山峰之尸拔地迎击、碾压斯芬克斯 3.古老王下"杀无赦"令，古都亡灵大军破土覆北原

**逐章写法公式**：

- **情绪流向**：起：莫凡信念归来的稳 → 承：斩空不屑、亡灵波重创冥辉的压制 → 转：山峰之尸碾压斯芬克斯的爽点 → 合：古都亡灵破土、杀无赦令的震撼全景
- **节奏配比**：慢铺垫 15% / 快冲突 40% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：信念归位（稳） + 亡灵波重创冥辉（压制） + 山峰之尸碾斯芬克斯（爆点） + 帝国破土杀无赦（全景）
- **本章核心技巧**：用"反派雷霆质问 vs 主角方轻描淡写"的反差建立碾压感，再以镜头拉远完成帝国级力量全景亮相。
- **卡点与伏笔**：结尾卡点：古都亡灵帝国对决胡夫金字塔，下章期待八方亡君逐一登场；埋设/回收伏笔：山峰之尸（古都阴霾） → 本章作为先锋碾压斯芬克斯，呼应古都浩劫设定
