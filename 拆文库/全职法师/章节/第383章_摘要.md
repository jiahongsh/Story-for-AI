# 第383章 追踪议员

**概要**：莫凡愁问题血剂说明不了瘟病根源，灵灵告知已在王毅手下身上放了窃听器，得知王毅正赶回杭州隔离区罗冕身边；莫凡梳理罗冕立场反常与梨天冷青掌握的不利证据。隔离区疫情恶化、已有病人死去，蛇血抗体无法压制病菌。罗冕在一干手下的簇拥下巡视隔离区，不戴口罩、主动握病人手安慰，把民愤引向瘟病之蛇与供奉它的族人，平息骚乱后屏退左右，向鹿先生索要能放倒玄蛇的烈毒，鹿先生答玄蛇乃毒之鼻祖用毒绝无可能，并透露血液分析证实玄蛇之毒与瘟病病菌并非同一种、不该再将心思放在大蛇身上。罗冕忧民的面容褪去、透出恼怒焦虑，意识到军方强用血剂加鹿先生的证词将令整件事败露，冷冷下令按照之前的计划行事。

**关键事件**：1.灵灵放窃听器追踪王毅一行回到罗冕身边 2.罗冕隔离区表演忧民、私索烈毒毒杀玄蛇 3.鹿先生证实玄蛇之毒与瘟病病菌非同一种，罗冕自觉败露下令按计划行事

**逐章写法公式**：

- **情绪流向**：起：紧张（窃听布控）→ 承：压抑（隔离区死亡与表演）→ 转：紧张（索毒被拒、证词反转）→ 合：紧张（罗冕密令、风暴将至）
- **节奏配比**：慢铺垫 35% / 快冲突 35% / 爽点爆发 5% / 悬念留白 25%
- **本章结构公式**：布控跟梢（技术准备）+ 双面表演（人设立伪）+ 索毒碰壁（图穷匕见）+ 证词翻案（定性崩塌）+ 密令收尾（钩子上弦）
- **本章核心技巧**：用"同一场域内的善面与恶行交替"剥皮反派——读者全知视角看表演，比角色早一步愤怒
- **卡点与伏笔**：结尾卡点：按之前计划行事——什么计划下章揭晓；埋设/回收伏笔：鹿先生证词 → 为玄蛇翻案攒实证；罗冕索毒 → 印证其杀人灭口意图
