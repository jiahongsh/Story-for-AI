# 第1618章 智商比你高几倍

**概要**：莫凡千里迢迢到希腊想看心夏，却得知她不在帕特农神山，而是去了英国艾琳所在的维多利亚世族。赵满延科普：艾琳是第一继承人、世族在英国历史上赫赫有名，卡萨世族当年都只是其附属，且维多利亚世族是保守派、坚持化解干戈善待民众，不可能支持铁血手腕的伊之纱。他点破心夏转战英国扳回一局，她的智商与眼界远超莫凡想象——能在帕特农神庙的尔虞我诈与伊之纱的争斗中存活，还曾在阿尔卑斯山一箭三雕，绝非柔弱可欺的妹妹。莫凡这才明白维多利亚世族轻易不站队、站队即是魄力。两人又聊起帕特农神庙的选举制度：靠全世界魔法组织、祝福庙堂、学府与民众选票，政府票不计，学府选票分量极重；阿尔卑斯山学府靠遍布世界的孤儿院培养大量天才、影响力巨大。莫凡动起心思，想借海蒂与布兰妾牵线，说服佩里院长和珈蓝老师，让心夏与阿尔卑斯山学府合作——阿尔卑斯山得罪了卡萨世族正缺资助者，两家若放下旧怨合作，便能双赢。

**关键事件**：1.心夏赴英国争取维多利亚世族支持 2.莫凡认清心夏的超群智商与政治手腕 3.莫凡计划为心夏牵线阿尔卑斯山学府

- **情绪流向**：起：扑空心夏的失落 → 承：维多利亚世族讲解的新奇 → 转：心夏智商认知的震撼 → 合：牵线阿尔卑斯山的计划

- **本章结构公式**：扑空铺垫（立背景）+ 世族科普（信息输入）+ 心夏认知反转（情感震撼）+ 合作谋划（立行动）
