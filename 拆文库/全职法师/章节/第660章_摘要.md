# 第660章 心灵画廊

**概要**：五人登上墓宫正门，发现石俑没有立即活化，莫凡把原因归于危居村血统。方谷和苏小洛从白色阶梯的形状认出它与昆井夜间出现的井水画相同，推断危居村世代看到的画面其实就是古老王陵墓景。方谷用一面小铜镜照向正门的邪眼铜镜，铜镜眨动后白色石门打开，阴风从门内冲出。石俑随即苏醒并沿阶梯追来，五人赶紧进入墓宫。方谷提醒画廊中的石版画带有心灵陷阱，柳茹险些被勾魂，张小侯则发现画廊似乎一直没有尽头。

**关键事件**：1.危居村井水画与墓宫阶梯对应 2.小铜镜开启邪眼铜镜 3.墓宫石门打开 4.石俑苏醒追击 5.五人进入墓宫 6.心灵画廊形成新陷阱

**逐章写法公式**：

- **情绪流向**：起：机关未动的疑惑 → 承：井水画真相揭开 → 转：石门开启与石俑追击 → 合：进入心灵画廊并发现新陷阱
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：确认井水画（回收历史） + 铜镜开门（解决机关） + 石俑追击（制造即时压力） + 画廊预警（切换精神危机）
- **本章核心技巧**：让已知的村落习俗成为墓宫导航，再在入口解决后立刻放置另一种不可见陷阱。
- **卡点与伏笔**：结尾卡点：画廊没有尽头且石版画会吞噬心神，下一章期待五人如何通过；埋设/回收伏笔：邪眼铜镜与昆井井水画 → 解释危居村为何能窥见皇陵。
