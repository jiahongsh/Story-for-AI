# 第842章 双重打击

**概要**：穆婷颖嘲讽穆宁雪"没资格还舔脸呆在队里"，被穆宁雪当空气。穆宁雪转而认真问导师：离开国府之队后能否做守馆人。封离一时被难住——守馆人即国府二队、各国历练至中国须来国馆盖章，不公开故对势力无价值，历届未见半路淘汰者去当。他终露欣赏，准其去做，却直言国府队皆高阶、她跨不过槛则希望渺茫，问她真觉能杀回来吗。穆宁雪未答，但知这样离开便彻底被超，纵可骄傲自在离去，也会悔恨一生——她要不断超越、为衰败的家族站上巅峰。她先回房独坐，淡然尽失、心里难受：十年努力获穆氏认可却如此离开，亲人散尽，更怀念博城小庄园。穆卓云来电，她轻声"我被淘汰了"；父亲嘱其随导师回国避身份检查麻烦，终难以启齿令她改用母姓——连姓氏都要换。穆宁雪强忍针扎心痛，挂断后泪始滑落，却用手背狠狠抹去，不肯显半分没骨气。

**关键事件**：1.穆婷颖嘲被无视、穆宁雪问守馆人 2.守馆人设定、封离准其杀回 3.穆宁雪决不退缩、回房独伤 4.穆卓云令改母姓、泪抹去显骨气

**逐章写法公式**：

- **情绪流向**：起：嘲讽无视的冷 → 承：守馆转机的亮 → 转：独处难受的沉 → 合：改姓抹泪的悲/骨
- **节奏配比**：慢铺垫 25% / 快冲突 5% / 爽点爆发 5% / 悬念留白 15% / 压抑 50%
- **本章结构公式**：嘲讽无视（冷） + 守馆转机（亮） + 独伤回忆（沉） + 改姓抹泪（悲）
- **本章核心技巧**：用"制度留缝+家族连坐"把淘汰写成双重打击，再以克制肢体收悲立骨。
- **卡点与伏笔**：结尾卡点：穆宁雪抹泪立誓，下阶段期待其以守馆人身份杀回；埋设/回收伏笔：改母姓 → 坐实穆氏对穆宁雪一支的彻底切割，呼应前文"污名打落"。
