# 第212章 放手一搏！

**概要**：莫凡意识到自己实力在变强，但老爹莫家兴和心夏没有自保能力，宇昂还活着，黑教廷要逼他交出地圣泉，最直接的办法就是袭击家人。他当即致电灵灵改保护对象：让大生去保护父亲莫家兴、灵灵去保护妹妹叶心夏，因为「他们要是出了事，我跟死了也没有什么区别」。灵灵犹豫时包老头拍板应允，还放话没人敢在他包老头的地盘撒野，实在不行莫凡可以躲到猎所。莫凡撂下狠话：正想会会他们，来年回家用他们的血去祭祀。他回想体育馆救人与何雨之死，认定力所能及却转身离开的良心谴责会伴随一生。随后莫凡坚决向萧院长申请立刻进三步塔修炼——包老头透露高阶人物多被盯死、学府有萧院长坐镇，黑教廷高手绝无可能潜入，但漏网爪牙与买凶无法百分百防，躲得了一时躲不了一世。萧院长同意申请，提到体育馆功劳已被莫凡做了交易、又刚差点失手杀人。莫凡离开后，顾翰老师从侧厅走出，质疑为何不让学生躲起来；萧院长透露校方已得到审判会暗示：借黑教廷再次出动的机会挖出有分量的幕后黑手、追查撒朗行踪，莫凡实际是诱饵；但他选择相信这个没有逃、反而申请三步塔想与黑教廷抗衡的学生。

**关键事件**：1.莫凡改派大生护父、灵灵护妹，自己放手一搏 2.莫凡申请进三步塔，萧院长应允 3.顾翰与萧院长密谈，揭出莫凡是诱饵与追查撒朗的布局

**逐章写法公式**：

- **情绪流向**：起：压抑（家人无自保能力的忧虑）→ 承：热血（护亲改派与血祭狠话）→ 转：紧张（三步塔申请与诱饵真相）→ 合：热血（萧院长的信任背书）
- **节奏配比**：慢铺垫 30% / 快冲突 15% / 爽点爆发 25% / 悬念留白 30%
- **本章结构公式**：护亲改派（动机落地）+ 宣言回溯（立复仇之志）+ 申请三步塔（行动升级）+ 师长密谈（揭全局布局）
- **本章核心技巧**：主角动机戏与高层信息戏前后脚排布，读者同时看到决心与棋局，戏剧张力来自主角不知自己是饵。
- **卡点与伏笔**：结尾卡点：布局悬念（黑教廷何时出动、萧院长们能否兜底）；埋设/回收伏笔：宇昂还活着 → 下章现身；三步塔机会可能仅一次 → 修炼线开启；审判会借机追撒朗 → 主线推进；莫凡把功劳做了交易 → 旧事件回扣；躲到猎所的保底选项 → 包老头实力暗示。
