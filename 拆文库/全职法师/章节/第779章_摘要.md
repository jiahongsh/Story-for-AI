# 第779章 三个人就够

**概要**：西守阁的日本人多半被气饱，信子老师顺水推舟让布置斗场，望月名剑叹这群年轻人火气大。金发冈本嵩第一个报名教育中国学员，信子却按规矩让国府方挑对手，官鱼立刻锁定冈本嵩。斗场设在面海悬空的菱台，由灰晶构成无护栏，妖艳的小池翔子阴阳怪气说不打石头只打人脸，蒋少絮顺口回怼。艾江图把众人带到一边，直接定下蒋少絮、官鱼、莫凡三人出战。冈本嵩质疑说好五场一对一，艾江图答胜三场就算赢，只需三人足矣，军司恼怒却无可奈何。江昱暗竖拇指，赵满延叫好，南珏点明三人谁都不能输。官鱼抢先站出打头阵，国馆十名学员中九人跪坐前排、额系白丝带以示不屈斗志。

**关键事件**：1.信子同意布场，冈本嵩报名 2.官鱼锁定冈本嵩为对手 3.斗场地形与灰晶材质展示 4.艾江图定三人出战，以胜三场论赢 5.官鱼抢头阵，国馆学员亮白丝带

- **情绪流向**：起：日被气饱的压抑 → 承：定对手的期待 → 转：只派三人的爽 → 合：官鱼抢阵与白丝带的紧张
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：同意布场（推进）+ 锁定对手（设对局）+ 斗场亮相（铺险地）+ 只派三人（爽点）+ 抢阵亮志（钩子）
