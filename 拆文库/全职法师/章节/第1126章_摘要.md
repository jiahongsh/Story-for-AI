# 第1126章 迎接雷电

**概要**：莫凡火焰环烧尽刺花，带穆宁雪逃出林，穆宁雪添鬼藤伤。哲罗高处风鞭抽来，阿莎蕊雅尾随，莫凡决意对哲罗、穆宁雪对阿莎蕊雅，飞川皑狼助穆宁雪。莫凡炎翼冲哲罗化火蛟龙，折其两片风翼；哲罗混沌之涡将莫凡雷反射，苍雷爪亦被吸反打。莫凡凭暴君领域与恶魔体质硬抗被强化数成的苍雷爪，连放三道苍雷爪皆被反射，却屹立不倒，似在迎接自己的雷电。

**关键事件**：1.莫凡火焰环破刺花，带伤穆宁雪突围 2.莫凡炎翼折哲罗两风翼，雷被混沌反射 3.莫凡硬抗三道苍雷爪，迎接雷电

**逐章写法公式**：

- **情绪流向**：起：突围的紧张 → 承：对哲罗的硬刚 → 转：雷被反射的波折 → 合：硬抗三苍雷爪迎雷的钩子
- **节奏配比**：慢铺垫 10% / 快冲突 60% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：火焰破花（突围） + 分敌应对（布局） + 折翼冲撞（爽） + 雷被反射（波折） + 硬抗迎雷（钩子）
- **本章核心技巧**：用"明知无效仍连轰"的执念写法，把败象写成蓄力
- **卡点与伏笔**：结尾卡点：莫凡迎接雷电，下章以海纳百川破哲罗；埋设/回收伏笔：暴君领域海纳百川→前文吸雷此处升级破混沌
