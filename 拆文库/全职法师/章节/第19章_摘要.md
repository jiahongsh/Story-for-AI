# 第19章 风之力，风轨！

**概要**：博城天气任性，台风逼近，宿舍里陆小斌怂恿风系的张小侯去试试释放初阶技能风轨，反被莫凡骂堂堂水系出门还打伞不怕丢人（陆小斌其实只掌控4颗星子、离水御还远）；舍长提到除周敏把火滋用出来外，班里还没人完整施展过魔法。学期末已掌握七颗星子的张小侯答应演示，他闭眼起势引来书本翻动、灰尘飞扬，连舍长床底的三角裤都被卷上天空骚走位；念出「风轨·疾行」后张小侯眼睛呈青色，莫凡看清一条从宿舍延伸到走廊尽头厕所的气流轨道，张小侯如凌波微步般瞬移狂驰，却不会刹车、整个人撞贴在厕所门上，破门漏水、腥臭漫楼层，倒地流鼻血还被落下的三角裤盖脸，舍管咆哮赶来，莫凡默默收回脑袋装作无事，心中评点风系移速不比车速慢、只是张小侯科目三不合格。随后年度考核到来，不合格者将被请离学校；穆氏庄园里穆白盛装赴考，校董叔叔穆贺亲自送行，叮嘱他为快被穆氏世家遗忘的小家族争气——世家修炼资源按家族贡献与年轻一辈成绩分配，今日考核正由穆贺主持；穆白信心满满，又眼睛一转低声问起：听说穆宁雪今天也会去天澜高中。

**关键事件**：1.张小侯宿舍演示风轨·疾行，速度惊人却撞上厕所门惨败收场 2.莫凡观摩确认风系技能实用价值 3.年度考核日到来、淘汰制度揭晓 4.校董穆贺送穆白赴考并交代世家资源规则，穆白探问穆宁雪是否降临

**逐章写法公式**：

- **情绪流向**：起：风雨闲扯（轻松） → 承：风轨演示的高光（热血） → 转：撞门翻车（爆笑） → 合：考核压顶与穆氏庄园的暗流（紧张+期待）
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 30% / 悬念留白 25%
- **本章结构公式**：宿舍闹剧（技能展示+喜剧） + 时间跳跃（考核日） + 反派赴考（家族政治） + 女神预告（章末钩子）
- **本章核心技巧**：用「成功一半」的技能演示（能疾行不会刹车）同时完成爽点与笑点，再以场景硬切把日常章抬入大事件前夜
- **卡点与伏笔**：结尾卡点：穆白低问穆宁雪今天是否也去天澜高中，下章期待穆宁雪登场；埋设/回收伏笔：穆氏世家按贡献与成绩分配年轻子弟修炼资源 → 穆白的成绩焦虑与后续穆宁雪资源地位；校董穆贺主持考核 → 考核公平性与穆白背景；周敏已能释放火滋 → 考核对手；年度考核淘汰制 → 莫凡必须放出火滋的硬压力；张小侯七颗星子 → 可私下找唐月辅导的人选
