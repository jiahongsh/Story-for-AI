# 第187章 光系舍友！

**概要**：剩余六只青黄女妖趁莫凡魔法间息期踩着烧毁的通道追来，莫凡靠血兽靴甩开它们。体育馆二楼创意屋里，黄发男子正与瓜子脸女生亲热，女生惊见一只青黄女妖如蜘蛛般倒爬天花板逼近。男子还调侃"我就是那个要吃了你的妖怪"，女妖扑咬他脖颈的瞬间他兀然转身，浑身金光乍现施展出刻着梵文符咒的光佑·圣盾，将两人护住；女妖撞盾被圣光灼得全身溃开，痛苦之下竟自己撕掉青黄外皮，蜕出一个满身粘液的女生，扯桌布裹身失魂落魄。女生劝下男子杀招，男子打电话叫舍友帮忙送人去医务室，电话那头传来咆哮——正是被六只女妖追杀上楼的莫凡。铃声引来了女妖，莫凡循赵满延指路卷风冲进创意屋，赵满延从猫眼数出六只追兵，屋内莫凡瞥见两个衣衫不整的女人，赵满延尴尬解释，莫凡摆手先解决追兵。

**逐章写法公式**：

- **情绪流向**：起：紧张（魔法间息期被追杀） → 承：轻松（创意屋旖旎与调侃） → 转：恐怖（女妖倒爬逼近、扑咬） → 合：爽（圣盾反杀、舍友会师备战）
- **节奏配比**：慢铺垫 30% / 快冲突 35% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：追逃开场（延续危机）+旖旎遇袭（新场景新人物入场）+圣盾反杀（实力揭示）+电波会合（双线并流收束）
- **本章核心技巧**：用"温情旖旎场景+怪物突袭"的冷热对撞引出隐藏高手，让实力揭示自带惊吓前摇与喜剧余味。
- **卡点与伏笔**：结尾卡点：兵临门外——六只女妖追至创意屋门外，两人如何应对留待下章；埋设/回收伏笔：赵满延光系中阶→此前隐藏实力的猜测验证；光系圣灼克鳞皮→后续战术核心；被救女生裹桌布→又一名受害者；莫凡铃声引敌→巧合推动会合。
