# 第74章 三年！

**概要**：校长室里朱校长补充地圣泉规则：资源极有限，每届只为一名学生开启，魔法家族与世家子弟同样参与争夺，学校已很多年没拿到资格。邓凯劝莫凡不必把胜负看得太重，承诺无论输赢学校都愿继续栽培；朱校长点明后天比试也是机遇，全城有头有脸的人物都会到场，若被一方势力看中资助，大学之路会顺畅许多。莫凡走出校门感慨三年已过，想起三年前穆贺趾高气昂夺走自家房屋、父亲莫家兴满脸卑微，两年前穆卓云把一家人像狗一样撵走，立誓要凭苦修狠挫穆氏打造的弟子。校门口莫家兴特意来接他，三年奔波黝黑干瘦许多，还听驿站老法师说起星尘魔器能加快修炼，打算筹钱给儿子买一个；莫凡谎称学校有提供，让父亲拿自己汇去的十来万佣金去租房，心里清楚星尘魔器努力几辈子也买不起，没有说出实情。

**关键事件**：1.朱校长说明地圣泉每届仅一人且学校多年未得资格 2.莫凡回忆穆贺夺房与穆卓云撵人旧恨，立誓挫败穆氏弟子 3.莫家兴接儿子放假并想筹钱买星尘魔器，莫凡隐瞒天价实情劝父亲租房

**逐章写法公式**：

- **情绪流向**：起：压抑（奖品稀缺、胜算渺茫）→ 承：温馨（师长许诺栽培）→ 转：热血（旧恨回忆点燃斗志）→ 合：温馨（父子相聚暗藏辛酸）
- **节奏配比**：慢铺垫 70% / 快冲突 5% / 爽点爆发 0% / 悬念留白 25%
- **本章结构公式**：校长室补充奖品规则（压胜率）+ 师长给出退路与机遇（递台阶）+ 校门回忆旧恨立誓（蓄怒）+ 父子对话隐瞒实情（蓄情）
- **本章核心技巧**：用师长的现实分析和父亲的糊涂温情双线压情绪，让后面的决斗爆发同时有怨与情两层燃料。
- **卡点与伏笔**：结尾卡点：温情悬置型——决斗前夜父子对胜负的认知错位未解，牵引成年礼到来；埋设/回收伏笔：独眼魔狼偷食地圣泉 → 回收前期设定抬高奖品价值；星尘魔器天价 → 为莫凡的资源焦虑与依赖学校魔器埋线；学校愿继续栽培 → 为校方阵营的持续庇护铺垫。
