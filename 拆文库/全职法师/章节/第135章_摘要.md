# 第135章 这太刺激了

**概要**：玫炎炼化完成，嫣红火焰之影像斗篷般笼罩莫凡，脚踏地面留下焦黑火焰脚印。恢复过来的唐月冷哼这次真便宜了这家伙，宣布遗物全部充公，莫凡听话上交；朝赫尸体上剩下一枚造型奇特的戒指被唐月拿走。魔具与灵魂绑定，人死即销毁，四人身上本没多少值钱物。回程出租车上，唐月讲解灵火会改变魔法师体质、令火焰伤害大幅减弱，又透露追捕朝赫是为查暴躁之泉——怀疑有药剂师违反魔法师公约把这种最高级禁品卖给黑教廷，线索可能就在朝赫的戒指里。唐月体内魅惑后遗症未消，双手抓得座椅靠垫快破，突然嫣红小嘴吻上莫凡，莫凡如触电般酥麻。出租车司机回头偷看内心爆炸，莫凡一道紫色电流打碎后视镜警告"敢转过来看一眼你就死定了"，吓得司机哆嗦转回去。

**关键事件**：1.玫炎炼化完成唐月宣布遗物充公并收走朝赫的戒指 2.唐月透露暴躁之泉疑与黑教廷有关、线索在戒指 3.唐月魅惑发作在出租车上吻了莫凡，莫凡放电碎后视镜警告偷看司机

- **情绪流向**：起：爽（炼化完成余韵） → 承：轻松（充公交谈+车程） → 转：甜（唐月突袭之吻） → 合：轻松（电碎后视镜的护食警告）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：收尾分赃（利益交代） + 世界观补课（灵火体质与暴躁之泉） + 情感突袭（魅惑之吻） + 喜剧收口（司机视角）

- **卡点与伏笔**：结尾卡点：轻卡点，司机偷听鼻咛整个人都要塌陷的窘境收章；埋设/回收伏笔：回收玫炎炼化（完成，火焰之影斗篷）、回收邪蜘之阱（唐月后遗症未清）、埋下朝赫的戒指（暴躁之泉线索）、埋下唐月"解开那层封印代价太大、可以考虑焚体而亡"的自语
