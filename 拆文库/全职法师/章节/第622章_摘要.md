# 第622章 妖孽法师

**概要**：莫凡离开后，左锋和国字脸禁卫法师继续处理肉丘尸臣，左锋操控尸臣五秒，使它反撞并碾碎数百只自己制造的骷髅，随后两名禁卫法师用高阶魔法压制尸臣。他们猜测莫凡的四级烈拳可能依靠罕见魔具，并计算出强化到第四级需要四十九颗精魄和巨大花费，最终确认莫凡的援手救了众人。莫凡因连续战斗和魔能耗尽，骑在接受治疗的疾星狼背上睡去。他没有继续随大部队前往内城，而是与矮男、周敏、穆白分开，循着疾星狼记住的气味去寻找柳茹。

**关键事件**：1. 左锋控制尸臣五秒并让它碾碎骷髅 2. 禁卫法师确认莫凡四级烈拳的异常价值 3. 莫凡魔能耗尽后离队寻找柳茹

**逐章写法公式**：

- **情绪流向**：起：战局收尾 → 承：旁观者追证 → 转：主角疲惫 → 合：离队寻找重要之人
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：尸臣反撞（延续爆发收益） + 高阶收尾（完成战斗） + 价值核算（扩散认可） + 主角昏睡（显示代价） + 离队寻人（开启个人支线）
- **本章核心技巧**：在大场面之后用旁观者复盘延长爽点，再用身体疲惫和分路行动切换叙事焦点。
- **卡点与伏笔**：结尾卡点：莫凡循着柳茹气味离开大部队，柳茹的状态和位置待确认；埋设/回收伏笔：疾星狼鼻子与柳茹气味 → 下一章找到柳茹。
