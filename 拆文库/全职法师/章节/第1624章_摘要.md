# 第1624章 迷上阿帕丝的人

**概要**：洛茜追问冷青声称泰坦袭城的依据，冷青因依据只是阿帕丝的心念判断而无法作答，祖宽立冷笑斥其杞人忧天。冷青以审判长身份严正声明后起身告辞，祖向天兄弟留在席上，扬言要用更文明的办法整死莫凡。牧奴欣起身相送，坦言生意留一线，并答应托人查泰坦之心来历，随后打趣问起阿帕丝来历，莫凡胡吹被阿帕丝翻白眼拆台。临别时阿帕丝低声告诉莫凡，宴上两人中有人对自己有强烈的想法，离开后可能正设法打探她的身份与关系，莫凡以为说的是祖宽立，阿帕丝却笑着否认，言下另有其人。

**关键事件**：1.冷青因拿不出泰坦袭城证据遭祖家反讥，严正声明后告辞 2.祖向天扬言用文明办法报复莫凡 3.阿帕丝点破觊觎者并非祖宽立

**逐章写法公式**：

- **情绪流向**：起：追问依据的僵局 → 承：冷青严正声明、祖家谋划 → 转：牧奴欣相送的轻松打趣 → 合：阿帕丝低声道破觊觎
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：冷青交涉破裂（收束上一章）+ 祖向天谋划报复（展露敌方）+ 牧奴欣相送打趣（缓冲节奏）+ 阿帕丝示警（抛出悬念）
- **本章核心技巧**：用离席后的对话段落承接饭桌冲突，把敌意与轻松两条线并置，再以一句否认收尾制造反转钩子
