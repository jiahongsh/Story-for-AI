# 第590章 杀出一条血路

**概要**：矮男用光佑画壁困住封喉角鬼，余青素以狂雷重创，矮男再用光耀将其消灭并得到鬼篷。十字疤男和余青素要求分赃，矮男拿出灵种碎片、魔石和奴仆级精魄分给众人，莫凡借精魄强化了第39颗星子。众人离开墓室后发现已被大量腐尸包围，莫凡让小炎姬喷火开路，自己与余青素用雷印麻痹亡灵，十字疤男以冰锁开路，四人向一公里外的大部队突围。

**关键事件**：1.封喉角鬼被合力击杀并掉落鬼篷 2.矮男分配鬼篷收益并给莫凡精魄 3.四人在腐尸包围中向大部队突围

**逐章写法公式**：

- **情绪流向**：起：围剿鬼怪的紧张 → 承：分赃插科打诨 → 转：墓室外亡灵包围 → 合：四人突围并逼近大部队
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：光墙困敌（限制行动） + 雷光与光耀击杀（获得战利品） + 分赃强化（兑现收益） + 火雷冰连续开路（抬高突围压力）
- **本章核心技巧**：用战利品分配制造轻松对话，再立刻切换到大规模追杀，让情绪在松紧之间快速换挡。
- **卡点与伏笔**：结尾卡点：四人距离大部队仍有一公里且被尸群包围，期待风盘开路；埋设/回收伏笔：鬼篷价值与分赃 → 本章战利品收益。
