# 第95章 袭击校园

**概要**：安全隔离区在三公里外，莫凡自知凭一己之力无法穿过遍布妖魔的城区，决定先与学校同学汇合撤离，穿过暂未被血洗的老巷赶往天澜高中。学校里朱校长等高层都不在，薛木生拍桌主张赶紧撤离，决策落在教导处主任陈伟亮手上，他坚持让学生留校组成安全防线，直到周老师报来后山狼群逼近、蓝老师被分尸的消息；薛木生以血色警戒下结界外存活率不足三成为由嘶吼力争，陈伟亮终于下令全校一千七百多人撤往三公里外的安全结界，又接到后山新增四十只独眼魔狼的急报。薛木生在楼道遇见刚从密道逃出的莫凡，莫凡证实后山狼况，并提醒巨眼猩鼠会挖穿地下室。张小侯见到莫凡激动眼红，随即一只独眼魔狼跃下后山踩碎篮球架、贪婪盯上教学楼里的学生，满楼尖叫。

**关键事件**：1.校方由守转撤作出全校撤离决定 2.莫凡与班级汇合并通报后山狼情 3.独眼魔狼闯入校园盯上学生

**逐章写法公式**：

- **情绪流向**：起：孤身赶路 → 承：决策焦灼 → 转：死讯定夺 → 合：狼窥课堂
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：独行汇合判断（主角动机）+ 守撤之争（群体决策）+ 蓝老师死讯与撤离令（破局）+ 莫凡归队与魔狼窥伺（会合+临门危机）
- **本章核心技巧**：用一场"守还是撤"的会议戏承接灾难，让死亡消息代替说理完成决策，结尾再把危险推到学生眼前
- **卡点与伏笔**：结尾卡点：独眼魔狼盯上满楼学生，战一触即发；埋设/回收伏笔：安全隔离区三公里（撤离目标）、巨眼猩鼠挖穿地下室（逃生限制条件）、血色警戒存活率30%（行军风险预告）、这还不是妖魔进攻的最高峰（更大灾难预告）
