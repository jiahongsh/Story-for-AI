# 第1388章 斯芬克斯

**概要**：乌纳斯站在巍峨金字塔前自称"伟大的冥神"，莫凡意识到她很可能是一个能与冥界沟通的亡灵法师。乌纳斯向金字塔内的冥神求援，称冥界大军被古老华夏之盾挡下，请冥神借力击垮它；金字塔周围伫立着十位君主级黑暗剑主，金字塔内传出缥缈浑厚的一句"这点小事交给斯芬克斯吧"，声浪震得众人脑子发炸。乌纳斯一行飞往镇北关正北面二十公里处，蓝蝙蝠发现一片连冥界生物都特意绕开的大谷，谷内趴着一头与黄土同色、气息全无的灰色巨物，呼吸一次长达三分钟，连蝎君美杜莎都绕行。乌纳斯命蓝衣执事乌里下去叫醒它，乌里不愿送死，乌纳斯点破斯芬克斯只认冥神、旁人打扰其美梦会被直接吃掉，并以灵魂契约精神命令迫使乌里跳下。乌里战战兢兢喊了一声，斯芬克斯睁眼凝视，猛一吸气将他撞在牙齿上血肉横飞。乌纳斯搬出冥神之名与斯芬克斯约定配合摧毁镇北关，斯芬克斯立起时如一座耸起的岛屿。莫凡猛然发现：紫鬼虽死契约未解，真正握着灵魂契约的人是乌纳斯，被摆了一道，真正要杀的人是眼前这个女人。另一线，飞往镇北关的赵满延像惊弓之鸟般躲入石堡，灵灵追问之下，他吐出一句"脸……那张人脸"，灵灵望去，亡灵大军中露出一张带着虚假笑意的人脸——那人脸狮身的惊世怪物，是埃及国兽狮身人面像斯芬克斯。

**关键事件**：1.乌纳斯向金字塔内冥神求援，冥神令斯芬克斯出手 2.乌纳斯以灵魂契约逼迫乌里叫醒斯芬克斯，乌里被直接吞杀 3.斯芬克斯立起如岛屿，乌纳斯以冥神之名约定配合摧毁镇北关 4.莫凡发现灵魂契约真正在乌纳斯身上，紫鬼已死契约未解 5.赵满延在镇北关外撞见人脸狮身的斯芬克斯真面目

**逐章写法公式**：

- **情绪流向**：起：通冥求援的神秘 → 承：斯芬克斯吞杀乌里的恐惧 → 转：契约真主揭晓的震撼 → 合：赵满延撞见狮身人面的惊悚收尾
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：乌纳斯通冥求援（敌方底牌浮出）+ 斯芬克斯现身吞人（恐怖实体化）+ 契约真主揭晓（主线反转）+ 赵满延撞见斯芬克斯（悬念撞线）
- **本章核心技巧**：两线同时逼近同一个巨物——莫凡在敌营看它现形并发现契约真相，赵满延在墙外撞见它真面目，大敌与主线危机在章末交汇
- **卡点与伏笔**：结尾卡点：斯芬克斯将配合乌纳斯摧毁镇北关，且莫凡灵魂契约握在乌纳斯手中，下章如何破局；埋设/回收伏笔：灵魂契约真正归属→回收紫鬼临死"契约不在我身上"之言，推翻原刺杀目标
