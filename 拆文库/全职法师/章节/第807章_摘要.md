# 第807章 妖魔弱点

**概要**：蒋少絮无位移技能落单被蓝谷凶离兽追，祖吉明自顾逃命未施援手；艾江图以空间系瞬移回队，用念控将凶兽锐足悬停半空救下蒋少絮，众人燃起战意合展多系魔法围攻，却难破其鳞甲。祖吉明毒蜂被凶兽吹散，艾江图退避时意外发现其头顶无鳞甲乃弱点，急告众人，却见凶兽从窄道另一端逼近躲在那里的江昱。

**关键事件**：1.蒋少絮落单被追，艾江图瞬移念控救场 2.众人合展多系魔法难破鳞甲 3.祖吉明毒蜂被凶兽识破吹散 4.艾江图发现头顶弱点，凶兽逼近江昱

**逐章写法公式**：

- **情绪流向**：起：蒋少絮落单的危机 → 承：艾江图救场与团队围攻的燃 → 转：鳞甲难破与毒蜂被破的压抑 → 合：头顶弱点+江昱被逼的钩子
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 20% / 悬念留白 15%
- **本章结构公式**：蒋少絮被追艾江图救（解危） + 团队围攻（燃） + 难破鳞甲毒蜂被破（压） + 发现弱点江昱被逼（钩）
- **本章核心技巧**：先以"打不动"的压抑蓄势，再让破局来自角色偶然观察而非外挂
- **卡点与伏笔**：结尾卡点：江昱窄道被凶兽逼近，下章期待脱困；埋设/回收伏笔：头顶无鳞甲弱点 → 后续围攻依据
