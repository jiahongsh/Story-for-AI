# 第285章 食物链顶端

**概要**：伪怖魔的木桩脑袋在蜥颅巨妖獠牙间彻底粉碎，巨妖吮尽浆液后振翅飞天毫不在意其他，第二三级大楼随之彻底崩垮，烟尘卷垮周边居民楼。楼内十四人顶着塌陷狂冲，植物墙已僵死不再阻拦，岩魔人扛着冰冻的宋霞，众人借风轨地波逃出死亡市政大楼。白婷婷立即施中阶治愈魔法，治愈精灵钻入宋霞腹部血洞，内脏破损不致命、致命的是血液流失，她耗尽魔能不停造血抢命。灰头土脸的队员迁怒于提议进楼的莫凡，腿部被贯穿的廖明轩狠毒指控他躲在外面让他们送死，沈明笑罗宋趁机围攻，莫凡冷笑反讥"我要你们死就顺手把门堵了"。赵满延问起大楼倒塌缘由，莫凡答"这座城食物链顶端的生物救了你们"，白婷婷补充是统领级蜥颅巨妖一口生吃了伪怖魔，众人膛目结舌。廖明轩带头喊要回去、骂松鹤院长脑子进水，陆正河劝阻称猎者联盟情报有误加上运气不好，小心些仍可完成任务。赵满延却点破真相：大厅里的尸体说明活回去汇报的猎法师没遇到强妖魔所以评估一般，遇到的全死绝了——死人不会汇报凶险。

**关键事件**：1.蜥颅巨妖咬碎伪怖魔、市政大楼崩塌，十四人逃生 2.白婷婷耗尽魔能为宋霞抢命 3.赵满延道破猎者联盟情报失真的幸存者偏差真相

**逐章写法公式**：

- **情绪流向**：起：恐怖（伪怖魔被咬碎） → 承：紧张（崩塌逃生与抢命） → 转：压抑（队内甩锅冲突） → 合：悬念（幸存者偏差揭真相）
- **节奏配比**：慢铺垫 15% / 快冲突 40% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：怪物互食（威胁降维）+ 崩塌逃生（动作高潮）+ 甩锅内讧（余波冲突）+ 偏差揭底（认知升级收尾）
- **本章核心技巧**：大战后先写情绪余波（甩锅）再上认知反转（幸存者偏差），让休整段同时推进人物关系与世界观深度
- **卡点与伏笔**：结尾卡点：荒城真实危险度远超情报、任务去留未决；埋设/回收伏笔：大厅猎人尸骨→情报失真证据（已回收）、宋霞重伤垂危→治愈进度与队伍去留牵动、莫凡与廖明轩沈明笑罗宋对立→队伍分裂线、陆正河反常劝阻→其心思伏笔
