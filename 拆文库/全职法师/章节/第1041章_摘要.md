# 第1041章 地震雷暴

**概要**：三倍威力的寂雷死光仍令黎凯风浑身抽搐，莫凡将其提到高处重重摔向场地边界。穆婷颖凝凌霄冰霜化冰封灵柩欲封莫凡，莫凡遁影躲过，南荣倪以鬼木须锁定位置拍下，却只捕到黑影。莫凡在二女身前数米显形，雷域上空降下苍黄雷电群地毯式轰击，震地雷暴将二人掀飞，火凤再补，穆婷颖南荣倪魔铠破碎、面目全非失去战力。莫凡仍聚雷爪欲下杀手，赵满延等惊呼阻止，称杀了必遭审判会制裁。封离带穆宁雪现身，穆宁雪冷拒莫凡代劳，称拱桥那日便可废她们，莫凡从她冰雪晴眸中看到颠覆穆氏的野心。

**关键事件**：1.莫凡摔飞黎凯风、躲过冰封与鬼木须 2.雷电群与火凤重创二女 3.赵满延等阻止莫凡下杀手 4.穆宁雪现身冷拒代劳，显露野心

**逐章写法公式**：

- **情绪流向**：起：残敌被摔的收束 → 承：二女反扑落空 → 转：雷电群火凤的碾压高潮 → 合：被杀意阻断、穆宁雪野心钩子
- **节奏配比**：慢铺垫 10% / 快冲突 55% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：摔敌收尾（清场） + 二女反扑落空（加压） + 雷火碾压（高潮） + 杀意被拦野心显（钩子）
- **本章核心技巧**：把团战收尾写成主角单方面的处刑秀，再用制度后果与外部视角收束情绪
- **卡点与伏笔**：结尾卡点：穆宁雪将如何处置穆氏，下章封离定调；伏笔：穆宁雪眼中野心，与穆氏终极对抗
