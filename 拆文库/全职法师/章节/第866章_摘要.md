# 第866章 全是绵羊

**概要**：穆宁雪冷静表明自己需这次机会、愿听莫凡安排但必去，莫凡无奈答应并叮嘱一切听他。二人达成协议到青天猎所问冷青，冷青确认撒朗确从崇明岛逃走、那里是黑教廷国内最后据点，因分会伪装成普通公司、崇明岛独立易监控，审判会怕打草惊蛇才外包给猎人，且多数猎所惧黑教廷报复不敢接。冷青点出人性"全是绵羊假装猛虎"，穆氏惨状多因舆论跟风而非仅古都受害者。

**关键事件**：1.穆宁雪冷静立誓听安排必去 2.莫凡妥协，二人赴青天猎所 3.冷青确认崇明岛为黑教廷最后据点 4.冷青点破"全是绵羊"人性

**逐章写法公式**：

- **情绪流向**：起：穆宁雪冷静必去 → 承：莫凡妥协赴猎所 → 转：冷青确认据点 → 合：全是绵羊人性反思
- **节奏配比**：慢铺垫 35% / 快冲突 5% / 爽点爆发 10% / 悬念留白 50%
- **本章结构公式**：立誓必去（稳） + 妥协问讯（推进） + 据点确认（钩） + 人性反思（升）
- **本章核心技巧**：用"权威确认+人性反思"把悬赏从情绪事件落成任务与主题
- **卡点与伏笔**：结尾卡点：冷青说需找绝对信得过且有黑教廷经验的人，下章（后续）期待行动展开；埋设/回收伏笔：崇明岛黑教廷分会 → 后续铲除行动的伏笔
