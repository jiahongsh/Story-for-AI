# 第78章 今夜，配角

**概要**：莫凡在宴会走了一圈，从许多人口中获知两个年轻人的决斗搞得这么大阵仗，终究是博城的势力之争，表现出色用一战成名形容也不为过。同学们周敏、张小侯、何雨、张英璐、许昭霆、王三胖等凭学校名额和穆白的门路入场，许昭霆话带酸意说名额原本该是他的，但历练的性命都是莫凡救的，仍盼他表现出色为学校挣面子；张小侯发现莫家兴也在邀请名单中，估计是穆贺干的，莫凡只答这是好事。穆卓云高坐主席举杯，宣称这宴席是为博城的将来举行，杨作河第一个起身带头敬酒，唐月却听得直翻白眼。宴罢迎来重头戏魔法决斗，莫凡早早听安排候在椭形决斗场中央，宇昂迟迟不出现等着做华丽登场，莫凡自觉像斗牛场里先被展示给观众的牛；莫家兴在席位间跟穆氏老员工炫耀儿子，工人提醒宇昂平常训练都下手特别狠，另有宾客下注赌莫凡一招被秒。最后宇昂一身特制白衣如王子般登场，与差点穿凉鞋来的莫凡形成巨大反差。

**关键事件**：1.同学们到场声援，张小侯发现莫家兴在邀请名单 2.穆卓云发表宏图祝词后莫凡独候决斗场 3.宇昂王子造型压轴登场与莫凡形成反差

- **情绪流向**：起：轻松（同学相聚打气）→ 承：压抑（配角处境与圣泉科普）→ 转：压抑（独候赛场的羞辱感）→ 合：压抑（王子登场的反差）
- **节奏配比**：慢铺垫 75% / 快冲突 10% / 爽点爆发 0% / 悬念留白 15%
- **本章结构公式**：同学入场声援（聚人情）+ 祝词与科普（立格局与赌注）+ 独候赛场（压主角）+ 宇昂压轴登场（立反差待爆）

- **卡点与伏笔**：结尾卡点：反差顶点型——王子般登场的宇昂与凉鞋风莫凡对峙，只等开打；埋设/回收伏笔：莫家兴在邀请名单 → 为其当众受辱埋线；宇昂训练下手狠 → 预告狠辣打法；赌一招被秒的闲客 → 为反转打脸预备。
