# 第767章 不存在的小岛（下）

**概要**：蒋少絮向江昱复述七海乱来、嫉妒奈良原空带来香客、反污其与该送药宫田有奸情，江昱补述市民对峙当夜去向、宫田称在"海岩外小岛"吹海风看日出的谎言，穆婷颖点破该岛根本不存在、致众人坐实禁忌恋冤案，宫田为证清白自尽后寺庙流传勾魂传说；黎凯风寻和尚归来，蒋少絮向他解释器皿妖灵幻境，莫凡艾江图在幻境中打听知全案，尾随伤心绝望的奈良原空至北山、见其以宫田刻刀自残刻石，艾江图觉时间到、二人退出。醒回现实后莫凡急问奈良原空下落，黎凯风称其几年前已死，莫凡称昨日才与之交谈，南珏沉着问"除你还有谁见过这年轻和尚"，莫凡浑身一冷。

**关键事件**：1.揭七海诬陷、宫田"不存在小岛"谎言致冤案 2.幻境见奈良原空自残刻石，退出 3.醒回现实知奈良原空已死，南珏点破唯莫凡可见

**逐章写法公式**：

- **情绪流向**：起：复述冤案 → 承：幻境见奈良自残 → 转：退出醒回 → 合：唯你可见惊雷
- **节奏配比**：慢铺垫 30% / 快冲突 20% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：揭冤案（铺垫） + 幻境悲情（渲染） + 退出现实（转场） + 唯你可见（钩子）
- **本章核心技巧**：用"不存在小岛"谎言三拍坐实冤案，再以"唯莫凡可见"一句点破第二妖灵
- **卡点与伏笔**：结尾卡点：奈良原空已死却唯莫凡可见（强悬念）；埋设/回收伏笔：不存在小岛 → 本章揭谎；刻石流血 → 与宫田对称
