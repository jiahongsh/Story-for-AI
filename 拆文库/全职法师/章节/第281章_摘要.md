# 第281章 踏入荒城

**概要**：队伍沿废弃铁轨跋涉近十天才抵达金林市外围，除隧道那次惊险外一路未再遇到成群妖魔。翻过山岭高处，断壁残垣、杂草丛生的金林市映入眼帘，郑冰晓感叹十五年就把城市变成这样，菁菁解释妖魔栖息过必会如此——房屋街道尽毁，植物以妖魔粪便为养料疯长。宋霞布置先勘测外围统计游荡妖魔数量。外林探查意外顺利，只有几只觅食妖魔，图纸涂上绿色标记。罗宋催促早点完成，陆正河指出勘测点很多，提议分头行动被宋霞否决——十七人一起遇成群妖魔尚能应付，分散就不好说了。众人踏入荒城：外环公路堵满生出铜绿的弃车，可想见当年撤离时水泄不通弃车而逃；街道裂痕爬满杂草，房屋被爬山虎藤蔓吞没，远处不时传来低吼，人人神情凝重。第一个勘测点旧居民区堆积着风干如山的妖魔粪便和巨大动物骸骨，显然有大群妖魔栖息过。白婷婷叹息满城空寂。沈明笑提议先找安全落脚点，陆正河定下标准：占据天台可与别楼相连、可攻可撤的高楼作基地，莫凡指向远端一栋保存完好的灰色大楼，宋霞对照地图确认那是金林市政大楼。

**关键事件**：1.队伍跋涉十日抵达金林市，外围勘测顺利 2.踏入荒城目睹末世景象，居民区发现大群妖魔栖息痕迹 3.选定金林市政大楼作为据点

**逐章写法公式**：

- **情绪流向**：起：轻松（旅途顺利） → 承：压抑（荒城末世景象） → 转：紧张（妖魔栖息痕迹与低吼） → 合：其他（定下基地、行动感恢复）
- **节奏配比**：慢铺垫 50% / 快冲突 10% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：抵达远眺（定调荒城）+ 外围探查（虚惊顺利）+ 入城废墟游（压抑沉浸）+ 选址定楼（行动锚点收尾）
- **本章核心技巧**：过渡章用"环境细节考古"代替事件推进，弃车、粪便、骸骨都是无声的叙事者，让静态场景自带悬念
- **卡点与伏笔**：结尾卡点：市政大楼定为基地，下章入住与危险并存；埋设/回收伏笔：居民区妖魔粪便成山→大群妖魔曾栖息（危险预告）、外林异常安静只几只觅食妖魔→妖魔分布反常（潜在异动）、隧道遇袭+荒城勘测任务→勘测图纸进度线
