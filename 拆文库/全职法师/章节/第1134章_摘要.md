# 第1134章 幽灵祭司

**概要**：牧奴娇以万物生长催出锋刃妖树、叶舞撕碎冲前的二十多只殷红木乃伊，赵满延推起山屏将七八十只困住，莫凡以火焰之拳地毯式轰炸将其全灭。烟尘未散，绿色眼睛再闪，埃及唤出至少两百只更大一波木乃伊，并有一头三层楼高的煞斧木乃伊与后来追加的两只。江昱岩石将军与群兽践踏抵挡，官鱼专攻大个，赵满延骂其如塔防。莫凡让众人掩护，借暗爵斗篷潜近埃及五人，确认其确施亡灵之术、滴血仪式古怪，正琢磨无限召唤的图咒，却被米奥斯埋伏的幽灵祭司自脖后突袭。米奥斯称幽灵祭司专为克莫凡毁灭魔法，因幽灵无身躯、对除光系外元素免疫。

**关键事件**：1.牧奴娇莫凡清掉首波木乃伊 2.埃及唤出两百只加煞斧木乃伊 3.莫凡潜近被幽灵祭司突袭

**逐章写法公式**：

- **情绪流向**：起：清波小爽 → 承：更大波压迫 → 转：潜行遇伏 → 合：新克制危机
- **节奏配比**：慢铺垫 10% / 快冲突 60% / 爽点爆发 15% / 悬念留白 15%
- **本章结构公式**：清首波（爽点） + 涌大波（加压） + 群兽防守（拉锯） + 潜行遇伏（反转）
- **本章核心技巧**：用刚清又来的数量压迫制造塔防式绝望，再以潜行遇伏抛出新克制逼变招
- **卡点与伏笔**：结尾卡点：幽灵祭司克毁灭系，莫凡如何应对；埋设/回收伏笔：阿莎蕊雅预警埃及非己力→幽灵祭司坐实；暗爵斗篷→潜行战术
