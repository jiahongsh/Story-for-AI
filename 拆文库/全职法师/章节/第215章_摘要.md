# 第215章 第三层空间！

**概要**：潜心修炼让莫凡的雷系与火系星云迈入第二个级别，魔能增加两倍不止，信心大增。但三步塔效果像吃药产生抗体：修炼速度从一百倍递减到八十、第五天五十倍、第六天只剩三十倍，而这类天材地宝往往只有初次效果最佳。期限只剩一天，莫凡决定凭自己整整四系的魔能冲击第三层——层越高精神重力越强，这正是把元素浓度压缩到极高的设计。每上一级阶梯，脑袋就像多绑一个铅球，冲到一半如被唐僧念了紧箍咒般痛苦不堪，莫凡几乎放弃时却发现第三层就在眼前，半死不活地爬了进去，精神压力瞬间全消。第三层元素浓度高达八十倍、修炼速度两百倍，一天等于两百天，七天苦修顶得上外面好几年。莫凡把重心全放在火系上，期待再突破一个层次、触及烈拳九宫与唐月所在的领域。七天期满，他神清气爽出塔，注意到第三层之上还有更高区域。归途上艾图图来电谎称在星巴克吃完忘带钱，被莫凡拆穿星巴克本是先付钱；到店后她乳燕归巢般跑来亲昵挽住他的手臂，莫凡随即感受到邻桌几人投来的冰冷愤怒目光，确认她是惹上了大麻烦找自己脱身。

**关键事件**：1.雷火双系迈入第二级别，修炼速度逐日递减 2.莫凡强闯精神重力争抵第三层，获两百倍修炼速度，主攻火系 3.七天期满出塔，被艾图图一通谎报求助的电话骗到商业街卷入麻烦

**逐章写法公式**：

- **情绪流向**：起：爽（双系进账第二级别）→ 承：紧张（收益递减与冲层苦行）→ 转：爽（第三层两百倍速度）→ 合：轻松转紧张（艾图图的陷阱求助）
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 35% / 悬念留白 15%
- **本章结构公式**：阶段盘点（收成果）+ 收益递减（逼决策）+ 冲层苦行（压极限）+ 出塔入局（切新事件）
- **本章核心技巧**：修炼章后半用一通谎话电话急切换地图，爽点余温未散就落新冲突，避免闭关流水账拖节奏。
- **卡点与伏笔**：结尾卡点：冲突悬置（邻桌冰冷愤怒的目光，艾图图惹的是谁）；埋设/回收伏笔：初次效果抗体规律 → 宝地修炼设定；第三层之上还有更高区域 → 下次入塔目标；火系将达烈拳九宫 → 战力进度线；艾图图的麻烦 → 下章东南亚人事件。
