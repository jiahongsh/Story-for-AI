# 第886章 毒变根源（上）

**概要**：莫凡将庄园里黑血夺命的惨状尽收眼底，连他也心生恐惧，每次呼吸都格外谨慎。灵灵迅速把死亡数据输入电脑，称落到众人身上的毒变概率约百分之一，莫凡苦笑自嘲坠入死亡之渊。灵灵判断毒变恐怕只是暂时停止，群体诅咒近禁咒级别，三人绝不能暴露身份——黑教廷明显在报复金战猎人团，却连累旅客。通讯被阻隔，外界难知。郭文衣忽然发现汪栩栩不见，王斌忙问赵品霖，赵品霖故作疑惑称她锁在房里不舒服；荣盛闻言暴怒欲拽赵品霖，赵推说"她自己锁的"。郭文衣说并不在房，有人猜汪栩栩已变黑灰尸，荣盛郭文衣齐怒，赵品霖却淡然吐出"尸体都灰黑辨认不了"。荣盛扑上扭打，赵品霖脸上带伤、眼中闪过歹毒之光，咽气转身回房。众人维持秩序躲进窗厅等救援，一男生渴要茶被王斌冷哼"会传播"。灵灵仍敲电脑找毒变答案，穆宁雪轻念"茶？"，提醒初到时管家卡莉曾给每人斟过特品红茶——灵灵眼睛骤亮：有毒变！

**关键事件**：1.灵灵算毒变概率百分之一，莫凡忧坠死亡之渊 2.通讯阻隔黑教廷报复连累旅客 3.汪栩栩失踪，赵品霖故作不知引荣盛扭打 4.穆宁雪提初到特品红茶，灵灵惊觉有毒变

**逐章写法公式**：

- **情绪流向**：起：莫凡恐惧灵灵算概率 → 承：通讯阻隔连累旅客的压抑 → 转：汪栩栩失踪赵品霖伪善扭打 → 合：茶字钩出毒变真相的揭晓
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：毒变概率收惊（轻） + 通讯阻隔连累（加压） + 汪栩栩失踪赵伪善（冲突） + 茶字钩出毒变（揭晓）
- **本章核心技巧**：章内用"茶"一字作延迟揭示的钩子，把前半的失踪闹剧与后半的毒变真相缝合成回扣。
- **卡点与伏笔**：结尾卡点：灵灵惊觉"有毒变"，下章期待她如何找出毒变根源与解药；埋设/回收伏笔：特品红茶 → 本章功能（毒变载体线索，下章回收）；汪栩栩失踪 → 伏笔（被赵品霖囚禁，后续寻人线）
