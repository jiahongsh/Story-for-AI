# 第13章 初尝魔法！

**概要**：山丘亭子里，莫凡首次完整释放的雷系初阶技能雷印威力远超他自己的预期，徐兵和肌肉男被雷击倒地抽搐，烟男、牛仔裤男子等三名混混吓破了胆连声求饶。莫凡怒气平息，让三人自己叫救护车送医、医药费自理，随后叮嘱他们对外统一口径称徐兵二人是偷电出的意外，并威胁谁敢泄露他是法师就让他这辈子永远闭嘴，还交代了在赵坤三和慕白面前的说法，恩威并施后扛着叶心夏的轮椅下山。下山路上莫凡忍不住仰天大笑，回想几个月前自己还是幻想拥有力量击垮地痞的普通学生，如今已真正手握雷电之力；他盘算在半年后的魔法考核前学会火系初阶技能火滋，还惦记能让人飞翔的风系高阶技能风之翼。另一边，坐在秋千上的叶心夏看到亭子方向闪过紫色光，自言自语「是魔法师吗」，为莫凡的安危忐忑，直到看见他双手举着轮椅、带着傻醉的笑容走下石阶。

**关键事件**：1.雷印余威震慑五名地痞，莫凡放人送医 2.莫凡封口：偷电口径+威胁+恩威并施，点名幕后主使赵坤三和慕白 3.莫凡山道狂喜，定下学会火滋、风之翼的技能目标 4.叶心夏目击紫色光芒，自问「是魔法师吗」

**逐章写法公式**：

- **情绪流向**：起：余威震慑（爽） → 承：封口善后（冷静掌控） → 转：山道狂喜（压抑释放） → 合：心夏远望（温馨+悬念）
- **节奏配比**：慢铺垫 15% / 快冲突 25% / 爽点爆发 35% / 悬念留白 25%
- **本章结构公式**：余波收尾（立威） + 封口善后（控制后果） + 狂喜独白（释放成长意义） + 心夏目击（埋信息差钩子）
- **本章核心技巧**：用旁观者（心夏）视角复述同一事件，制造「当事人狂喜/旁观者惊奇」的双层信息差
- **卡点与伏笔**：结尾卡点：心夏望见紫光自问「是魔法师吗」，下章期待莫凡法师身份是否被心夏识破；埋设/回收伏笔：赵坤三、慕白只是马前卒的清算预告 → 后续校园冲突来源；火滋、风之翼技能清单 → 半年考核的修炼目标
