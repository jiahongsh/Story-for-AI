# 第864章 高阶雷系！

**概要**：莫凡从三步塔出来遇关英，关英刚把第二系修到中阶正兴奋，误把莫凡冲"星河"（实为高阶雷系）当成冲星云，莫凡微笑点头承认自己突破高阶，关英意念试探后脸色惨白、比突破失败还难受。莫凡回空公寓失落，给唐月灵灵报喜后，门开竟是牧奴娇带穆宁雪回来——穆宁雪来上海国馆报道、无宿舍，牧奴娇便带她合租，却不知莫凡也住这，穆宁雪淡淡问"同居？"后被解释清楚。

**关键事件**：1.莫凡雷系高阶出关，关英误判被打击 2.莫凡报喜无人回，牧奴娇带穆宁雪归来 3.穆宁雪入住牧奴娇家，误会同居 4.合租真相澄清

**逐章写法公式**：

- **情绪流向**：起：出关遇关英错判 → 承：点头认高阶打击路人 → 转：空房报喜落寞 → 合：双美归来误会同居
- **节奏配比**：慢铺垫 35% / 快冲突 5% / 爽点爆发 30% / 悬念留白 30%
- **本章结构公式**：出关错判（爽） + 路人受打击（笑） + 空房落寞（转） + 双美误会（暖）
- **本章核心技巧**：用路人配角的"误判+崩溃"给主角高阶突破做轻松注脚
- **卡点与伏笔**：结尾卡点：穆宁雪入住合租，下章期待她与莫凡如何谈黑教廷悬赏；埋设/回收伏笔：雷系高阶 → 莫凡实力再进一步的伏笔落实
