# 第45章 幽狼兽！

**概要**：学生们如受惊野鸟般慌乱外逃。张小侯拽起吓傻的何雨，想施风轨却发现心率狂跳下星子根本无法连成——平时百分百不出错的星轨，在妖魔20米外全成了扯淡；所有人的星子都像吓坏的小鹿乱撞，没人施展魔法，全凭本能逃命。莫凡也只能连到第6颗星子，被妖魔一声咆哮震散意念，索性一把扛起要留下拖住魔狼的周敏狂奔——他心里明白，逃等于挨个被杀，山口那条绳索一次爬不下几个人。逃出的二十多人发现绳索竟不见了，洞里还昏倒着十来人，学生们吓哭、尿裤，赵坤三一句不如去吃洞里昏倒的招来周敏许昭霆怒瞪。三百米外的山壁石台上，斩空、罗云波、潘丽君与召唤师白阳正观战：白阳笑到捂肚，斩空对无人能施展魔法一个劲摇头，三位老师神情尴尬——学校只追求修为分。直到穆白沉住气释放冰蔓，冻住幽狼兽四肢，成为全场第一个出手的法师，斩空记下名字，薛木生称这位穆氏世家子弟足可拿A。

**关键事件**：1.妖魔面前全员魔法失灵，莫凡扛起周敏逃出山口，绳索不见退路断绝 2.斩空携白阳等石台观战，对学生无人施展魔法深感失望 3.穆白第一个释放冰蔓冻住幽狼兽四肢，被记名可拿A

**逐章写法公式**：

- **情绪流向**：起：溃逃的慌乱 → 承：魔法失灵、绳索消失的绝望 → 转：观察台失望点评的冷幽默 → 合：穆白出手的一线光
- **节奏配比**：慢铺垫 20% / 快冲突 55% / 爽点爆发 10% / 悬念留白 15%
- **本章结构公式**：全员溃逃（引爆）+ 逃生路断（压死）+ 石台观战（换视角揭底）+ 穆白冰蔓（留第一道光）
- **本章核心技巧**：用生理失能写恐惧（星子连不成、尿裤、吓昏），再以高位观察视角冷眼点评同一惨状
- **卡点与伏笔**：结尾卡点：微光型——第一个施法者出现，下章期待反击能否奏效；埋设伏笔：白阳与幽狼兽有分寸 → 失控反转蓄力；断绳与洞内昏迷者 → 被迫一战的前提
