# 第768章 和尚要出事

**概要**：莫凡浑身冷意未消、呆立当场，艾江图忽悟妖灵有两个、后续记忆属奈良原空，急问黎凯风老和尚所在，得知在满英山；莫凡艾江图对视读出惊愕共识，莫凡高声催赴满英山，艾江图瞬息移动先去，南珏蒋少絮黎凯风随莫凡疾驰。莫凡对蒋少絮称幻境中见奈良原空刻奇怪文字，蒋少絮误以为因爱刻石，莫凡点破其刻石处正是众和尚做法式的满英山，三人骇然，相隔老街的满英山忽泛血色妖异之光，蒋少絮惊叫"和尚们要出事了"。

**关键事件**：1.艾江图悟有双妖灵，奈良原空记忆在后 2.众人急赴满英山，莫凡点破刻石处即和尚做法式之山 3.满英山血光泛起，和尚将出事

**逐章写法公式**：

- **情绪流向**：起：冷意惊悚 → 承：悟双妖灵急赴 → 转：点破地点 → 合：血光预警
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：悟双妖灵（揭秘） + 急赴满英山（加压） + 点破刻石地（转折） + 血光预警（钩子）
- **本章核心技巧**：用"虚拟记忆地点→现实地点"映射，把幻境伏笔落到真实危机
- **卡点与伏笔**：结尾卡点：满英山血光起、和尚将遭难（强悬念）；埋设/回收伏笔：奈良原空记忆 → 双妖灵揭晓；刻石满英山 → 危机地点
