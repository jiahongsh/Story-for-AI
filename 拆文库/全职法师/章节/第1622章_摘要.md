# 第1622章 他乡遇故仇

**概要**：莫凡、阿帕丝与冷青前往希腊新兴世家布托伦拜访女主人洛茜——她近年一手经营起家族，收购的产业里就包括莫凡他们泡过的香草池。庭院湖亭里，燕尾服管家发现自己带错了人，原来洛茜今晚要接待的是另外三位来自中国魔都的客人；洛茜大方圆场，邀两拨人同桌共餐。三位客人中，走在最前的亚裔女子竟是牧奴欣——她一眼认出莫凡，笑着又把他当成"白家公子"重演了当年的误会；一旁脸俊长的男子听说白鸿飞之名便目光带剑，等莫凡自报真名后，两人神情骤变——他们与莫凡有结怨。莫凡察觉牧奴欣故意遮掩他的身份，却不惧事大地直接亮名。脸俊长男子从椅中站起、怒目欲动，年长男子则强压怒意沉声重复"莫凡，很好"；女主人洛茜看着满桌剑拔弩张无语凝噎，牧奴欣拍肩安慰她——面具笑脸社交在莫凡这种暴脾气面前根本无用。

**关键事件**：1.管家带错人，洛茜圆场促成两拨人同席 2.牧奴欣误认莫凡为白鸿飞，引出旧梗 3.莫凡自报真名，与有旧怨的两位男子当堂对峙

**逐章写法公式**：

- **情绪流向**：起：拜访世家的闲适 → 承：带错人的尴尬与圆场 → 转：故人重逢的惊喜 → 合：仇家对峙的骤冷
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 20% / 悬念留白 20%
- **本章结构公式**：世家拜访（铺背景）+ 圆场合席（造交集）+ 故人认亲（转气氛）+ 仇名引爆（立钩子）
- **本章核心技巧**：用巧合式会面把旧友与仇敌同时送上桌，以名字为引信瞬间翻脸
- **卡点与伏笔**：结尾卡点：冲突+这两位仇家是谁、积怨为何，席间将如何收场；埋设/回收伏笔：牧奴欣的遮掩 → 仇家身份悬念；白鸿飞旧梗 → 牧家往事支线
