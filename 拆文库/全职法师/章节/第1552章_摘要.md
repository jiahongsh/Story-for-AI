# 第1552章 我给你造的坟墓

**概要**：地牢里穆白用第三系植物系的塑骨木为赵满延修复被打碎的四肢关节，骨头奇迹般复原，两人关系也拉近为兄弟。赵满延从偷听中推断小美杜莎被送去军方前线，而萨斯、冈玛的背后是某位埃及军部首脑。两人出狱看到莫凡正追着超阶法师萨斯暴打。赵满延一见到坑害过自己的费列罗便怒不可遏，不顾海蒂劝阻，立起岩之角斗场把费列罗困在当中，举起斩魔具扬言要在这里造一座他的坟墓。

**关键事件**：1.穆白用塑骨木修复赵满延断骨，赵满延重获行动力 2.赵满延据偷听信息推断小美杜莎与埃及军部首脑有关 3.赵满延立岩之角斗场围住费列罗，亮斩魔具报仇

- **情绪流向**：起：狱中治疗 → 承：情报推断 → 转：怒火爆燃 → 合：立场锁敌
- **节奏配比**：慢铺垫 40% / 快冲突 30% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：塑骨修复（恢复战力） + 情报推断（锁定目标） + 冲出牢狱（汇合战局） + 立场报仇（制造决战）
