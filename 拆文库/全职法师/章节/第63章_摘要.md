# 第63章 老街区怪事

**概要**：暑假剩下的时间莫凡修炼与出任务并行，随城市猎妖队再完成两项猎妖悬赏，面对妖魔已能镇定释放技能、彻底脱离菜鸟境界，星尘成长随之加快；高三开学当天，他的雷系星子彻底蜕变，雷印与火滋双双达到二级。开学后同学们为魔法高考涌入训练场，莫凡却以随队实战代替打木偶训练。张小侯凑过来点破：历练之后一向傲娇的班长周敏对莫凡格外好、还总偷看这边。周敏鼓起勇气约莫凡放学一叙，讲出正事——奶奶家所在的榕树街老城区待拆改，暑假她陪住时频繁听到旁边工地震响，可施工队说夜里并不施工，奶奶坚称那片废墟里有东西又死活不肯搬，她想请莫凡陪自己去看看。莫凡联想到食堂之震，怀疑又是巨眼猩鼠，又转述猎者联盟关于近期猩鼠频繁乱窜的消息，当晚与周敏一同进入那片拆迁过半、只剩流浪汉与留守老人的老街区。

**关键事件**：1.莫凡暑假随队出任务脱菜鸟、开学当天雷印升至二级 2.周敏求助：榕树街工地夜里频震而施工队称夜里不施工，奶奶不肯搬 3.莫凡疑为巨眼猩鼠作祟，当晚陪周敏进老街区探查

**逐章写法公式**：

- **情绪流向**：起：开学蜕变的松弛轻快 → 承：暧昧邀约的甜味 → 转：老街区怪事的阴翳 → 合：夜探废墟的隐隐不安
- **节奏配比**：慢铺垫 55% / 快冲突 0% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：任务沉淀（完成升级）+ 同学点破（铺感情线）+ 周敏求助（抛怪事）+ 夜入废墟（踩入险地）
- **本章核心技巧**：用日常校园的甜与闹包裹怪谈引子，结尾把人物放进空城般的废墟，情绪由甜转冷只花一个场景切换
- **卡点与伏笔**：结尾卡点：场景侵入型——两人走进只剩流浪汉与老人的死寂街区，危机一触即发；埋设/回收伏笔：食堂之震后仍有微弱震动 → 城市异动线索；猩鼠频繁乱窜如交配季 → 妖魔集体异动伏笔；雷印二级 → 实战检验待机；奶奶坚称废墟里有东西 → 民间感知型预警
