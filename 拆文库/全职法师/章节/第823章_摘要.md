# 第823章 灵猫之威！

**概要**：披着绿色疙瘩皮的锯齿绿妖成批跃出水面盘踞屋顶，眼中凶戾疯狂。太平洋海妖以杀人为无上荣耀，会在鳞片划痕计数如军衔，先前试探的绿妖摸清人数后发动围剿欲让人类法师全军覆没。官鱼认出此前被冻僵的小头目仍在其中，且小头目数量不少、战力高于大战将。赵满延焦虑杀光绿妖前南荣倪已被毒死，蒋少絮跳到龟壳法师所在的屋顶寻求保护，周旭叹穿不过包围。艾江图担心离队且虚弱的穆宁雪，命江昱的夜罗刹冲出去寻人并找出白泣妖，江昱交代契约兽妃妃务必护住她。夜罗刹化黑影线掠过四五只绿妖，小头目招呼七八只围杀，夜罗刹空中踩眼借力、爪刃将一只斩成两半后甩开追兵。江昱与艾江图趁机清场，艾江图布诅咒邪蛛抽三只绿妖灵魂，江昱唤次元召唤兽。东海城弥漫海雾、海水上涌，银发湿漉的穆宁雪在迷蒙中漫寻白泣妖，誓绝不任海妖夺走南荣倪性命。

**关键事件**：1.海妖围剿倒计时、小头目带队压境 2.艾江图派夜罗刹寻穆宁雪与白泣妖 3.夜罗刹斩绿妖脱身、江昱艾江图清场 4.穆宁雪海雾中誓救南荣倪

**逐章写法公式**：

- **情绪流向**：起：海妖压境的压抑 → 承：时间不够救人的焦虑 → 转：夜罗刹清场+穆宁雪誓愿的爽/燃 → 合：海雾寻妖的悬念
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：海妖围剿亮底（压） + 派夜罗刹寻人（转机） + 夜罗刹斩妖脱身（爽） + 穆宁雪海雾誓寻（钩）
