# 第569章 六村覆灭

**概要**：莫凡火雷并用秒杀奴仆级亡灵，为泄愤连火滋就能轰烂的亡灵都动用中阶霹雳夜叉，他背起被咬断腿的村民，把救下的人交给带药的苏小洛照料。柳茹坐到莫凡身边说起亡灵少年的事，莫凡表情凝重，不自觉扫了一眼远处的谢桑，越发觉得白天袭人的亡灵与这个有隐瞒的村长有关，但又不愿管闲事，决定把人送到古都就行。队伍赶在天黑前抵达古都外城墙，守卫队长拿出早报，头条写着咸池一带六个危居村全部遭亡灵洗劫、罕有生还者，村长谢桑看得表情怪异。张小侯不肯离开苏小洛，莫凡只得先通知军区，把张小侯托付给苏小洛照顾，又因教官飞角外出执行任务未归，决定在古都多留几天，顺便去见博城老乡。

**关键事件**：1.莫凡秒杀亡灵、背起伤者，与柳茹把幸存村民交给苏小洛照料 2.古都城门得知咸池六村全部覆灭的报纸头条，谢桑表情怪异 3.张小侯只肯跟苏小洛，莫凡因飞角未归决定滞留古都

**逐章写法公式**：

- **情绪流向**：起：怒火（泄愤杀亡灵） → 承：沉重（清点伤亡） → 转：震动（六村覆灭） → 合：暂留（托付与等待）
- **节奏配比**：慢铺垫 35% / 快冲突 35% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：杀敌泄愤（情绪出口） + 善后托付（责任收尾） + 城下惊闻（信息爆炸） + 滞留等待（新线开启）
- **本章核心技巧**：借报纸头条把局部救援的功劳感冲掉，用别的村全灭垫高华村生还的价值与疑点
- **卡点与伏笔**：结尾卡点：见老乡会遇到什么、飞角未归的等待里藏着什么，下章期待古都新线；埋设/回收伏笔：六村覆灭的共性、谢桑怪异表情、亡灵白天袭人
