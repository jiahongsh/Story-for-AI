# 第25章 冰系，冰蔓！

**概要**：许照庭考完雷印自觉满意，以为获得了穆宁雪的注视，穆宁雪却只评一句"一般"便继续前行，穆卓云解释帝都学府里初阶雷印只是基本功，替校领导们解围。校领导认定许照庭将拿全校第一，副校长提出八班的穆白有一拼之力，穆贺顺势介绍穆白是自己过世兄弟穆阳之子、被接进庄园抚养，穆卓云便带着校长与校董们移步八班考场。走在最前的穆贺与秃顶考官对视暗示，考官会意点名穆白。穆白暗恋穆宁雪多年，渴望借家族重视与女神的注视证明自己，他凭平日苦练压住激动完成冥修，白色冰芒从星感石强烈扩散并外溢印到他脸上，三位考官第一时间全部给出S，压过许照庭的两S一A，全班惊叹、女生花痴，穆卓云只评"不错"，穆宁雪仍未动容。穆白认定释放考核才是真正评判，走入考场将七颗冰系星子连成星轨。

**关键事件**：1.穆宁雪冷评许照庭，领导团移步八班考场 2.穆白星尘测试冰芒外溢获三考官S 3.穆白进入释放考核连成星轨

**逐章写法公式**：

- **情绪流向**：起：考后自得遭女神冷评 → 承：领导移场、穆白临考的紧绷与渴望 → 转：冰芒外溢三S全场沸腾 → 合：穆宁雪未动容、穆白带期待进入释放考核
- **节奏配比**：慢铺垫 50% / 快冲突 10% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：女神冷评压场（立眼界标杆）+ 领导移场聚焦（聚光灯转场）+ 穆白三S爆发（抬升对手）+ 释放考核起手（留钩）
- **本章核心技巧**：先立"许照庭两S一A"的可量化参照分数，再让穆白以三S压过，用分数阶梯逐级抬高读者对后续莫凡考试的期待。
- **卡点与伏笔**：结尾卡点：悬念型，穆白星轨已连、冰蔓未出，下章看释放效果与最终评分；埋设/回收伏笔：秃顶考官与穆贺的眼神暗号 → 为暗石陷害铺垫；穆白暗恋穆宁雪 → 嫉恨莫凡的长线动机。
