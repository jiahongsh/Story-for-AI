# 第1100章 心术不正

**概要**：祖吉明借莫凡「受他国邀请」的戏言当众敲打，莫凡反骂其废物；祖吉明的姑母、议长秘书祖慧殷出面，以「心术不正、可能卖国」为由要剥夺莫凡夺宝资源。邵郑放任争吵以暴露队伍矛盾，韩寂则强硬要求祖慧殷向莫凡道歉，陆辛议员为侄子陆一林之死向莫凡发难。韩寂限祖慧殷三场比赛内道歉，否则将公开一事，祖慧殷傲然不退，暗自借机拉拢陆家。

**关键事件**：1.祖吉明敲打，莫凡骂回 2.祖慧殷斥心术不正欲夺资源 3.韩寂护莫凡逼道歉，陆辛发难 4.限三场道歉，祖慧殷不退

**逐章写法公式**：

- **情绪流向**：起：祖吉明敲打 → 承：祖慧殷上纲夺资源 → 转：韩寂逼道歉陆辛发难 → 合：限三场倒计时
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：戏言敲打（引冲突）+ 上纲夺资源（加压）+ 护徒逼道歉（反转）+ 限日倒计时（钩子）
- **本章核心技巧**：用一句戏言引爆政坛派系冲突，以长辈护短与倒计时把矛盾推向公开回扣
- **卡点与伏笔**：结尾卡点：祖慧殷三场内须道歉，下章期待莫凡出场宣事；埋设伏笔：陆一林之死、韩寂将公布之事、小团体见死不救
