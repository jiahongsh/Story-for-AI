# 第1080章 六国联军

**概要**：莫凡早将赃物分藏三人身上，即便落网也只吐三分之一。皮诺尔等七八人从远处包围，水牢不牢却被堵死空旷地。皮诺尔要莫凡交还魂种与搜刮物，亚克、安吉洛、汉娜偕加英法意学员陆续赶到，多国因共仇莫凡结成联军。长河事件上主荧幕全球转播，中国成仇恨点、高层却无奈——三人未违规，别国也都在抢。中国网民呼声压过欧盟。庞莱等看荧幕感叹莫凡惹出"八国联军"，议长邵郑也紧张盼其脱身。穆宁雪与艾琳竟从隐藏处跑出往莫凡而去，希伯特见艾琳入伙愕然，加拿大末流女学员贝斯则想借踩艾琳上位。

**关键事件**：1.莫凡分散藏赃、被多国联军围捕 2.主荧幕转播、中外舆论两极 3.庞莱等看荧幕感叹八国联军 4.穆宁雪艾琳跑来会合 5.希伯特愕然、贝斯想踩艾琳

**逐章写法公式**：

- **情绪流向**：起：落网冷静的轻松 → 承：联军围捕与舆论两极 → 转：庞莱感叹八国联军 → 合：二女回援的紧张暖意
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：分散藏赃（铺垫） + 联军围捕（冲突） + 舆论两极（反应） + 二女回援（钩子）
- **本章核心技巧**：用"国内外舆论反差"把抢宝写成喜剧，再以二女回援把爽转回危机
- **卡点与伏笔**：结尾卡点：二女回援将致全军，下章期待被弃或血战；埋设/回收伏笔：分散藏赃 → 落网只损三一
