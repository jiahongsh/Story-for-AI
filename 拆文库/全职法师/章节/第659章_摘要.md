# 第659章 邪眼铜镜

**概要**：城墙上的神秘灰白男子观察撤回的法师，判断能杀出去却很少有人能回来，左锋和妖男最终带回消息，确认莫凡等人已抵达煞渊但生死不明。危居村村长谢桑声称看到皇陵，神秘男子准备前往钟楼，负伤归来的独萧却因青眸巨兽死亡而神情黯然。煞渊深层，莫凡等人发现头顶“云层”其实是尸体和煞鬼组成的尸雨，沿白色阶梯攀向墓宫。石俑像守卫一样排列在阶梯两旁，方谷和莫凡联想到白沙妖兵的历史。张小侯抬头发现墓宫正门悬着一面诡异的大铜镜。

**关键事件**：1.神秘男子等待突围消息 2.左锋确认小队已抵达煞渊 3.独萧失去青眸巨兽 4.煞渊出现尸雨 5.五人攀登白色墓宫阶梯 6.邪眼铜镜出现

**关键信息与扩写技法**：

**逐章写法公式**：

- **情绪流向**：起：地面战场的失联 → 承：少数归来与牺牲 → 转：深层空间攀登 → 合：邪眼铜镜出现
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：确认突围代价（补足地面线） + 独萧归来（展示损失） + 发现尸雨（建立墓宫环境） + 铜镜出现（抛出机关）
- **本章核心技巧**：地面与地下两条视角交替推进，地面提供生死结果，地下提供未知机关。
- **卡点与伏笔**：结尾卡点：墓宫正门出现邪眼铜镜，下一章期待铜镜开启方式；埋设/回收伏笔：昆井水画与石阶相似 → 暗示危居村早已窥见皇陵景象。
