# 第8章 根本停不下来

**概要**：觉醒后两个月，莫凡每天只做一件事：坐在操场绿荫树下冥修。班主任薛木生第一天第一节课讲了魔法释放的三步骤——冥修、把控、释放；闭眼放空脑海便能看见紫色雷系星尘与火系星尘浮现，雷系星尘内有七颗无规则乱跑的星子，这是两个月里全体学生唯一的家庭作业。自认冥修熟练的莫凡提前试起把控：要用精神意念让星子安静停在特定位置连成星轨，魔法之力才能传导释放。可星子颗颗高冷，一碰意念就跑得飞快，像吃了五百斤炫迈根本停不下来，雷系星子活跃性极高，莫凡自嘲"雷印要何年马月才学得会"。一个多月后他已把控住4颗星子：过程像高难度多米诺牌，必须全神贯注压住前一颗的反抗再分神驯下一颗，一旦偏移就前功尽弃；把控失败一次精神疲倦几分，一天最多练两小时就会耳鸣眼花、精神崩溃——用他的话说，练习把控贼TM耗蓝，一管蓝最多用两小时。

**关键事件**：1.魔法释放三步骤（冥修、把控、释放）课程展开 2.莫凡两个月完成冥修，提前自试把控遭星子"停不下来"的挫败 3.苦练一个多月把控住4颗星子，确认把控的巨大精神消耗

**逐章写法公式**：

- **情绪流向**：起：树下苦修的平静 → 承：星子不听话的挫败 → 转：四颗入控的小进展 → 合：耗蓝极限的喘息
- **节奏配比**：慢铺垫 65% / 快冲突 10% / 爽点爆发 5% / 悬念留白 20%
- **本章结构公式**：三步骤授课（立规则）+ 冥修达成（过第一关）+ 把控碰壁（立难度）+ 四颗星子（见进度）+ 蓝条极限（定代价）
- **本章核心技巧**：把修炼体系完全游戏化（步骤、进度条、蓝耗），用拟人与游戏黑话让设定章节不枯燥
- **卡点与伏笔**：结尾卡点：期待型——第七颗星子何时收服、雷印何时释放；埋设/回收伏笔：雷系星子七颗→雷印需七星连轨；一天两小时的练习上限→双系蓝量翻倍的天赋暗线；雷印为所有系初阶魔法最实用→莫凡战斗力的第一块拼图
