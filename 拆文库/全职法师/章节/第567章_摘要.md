# 第567章 白天遭袭

**概要**：矮男说出旧事，前年杀血兽后他随队遇上刚从羊阳村离开的勘测队，对方送补给并说羊阳村根本没有一个人，返回古都不久后便听说勘测人员全部失踪；如今村长谢桑又特意让他们走不经过羊阳村的路，显然不希望往那里去。一旁的张小侯听到这番话莫名浑身一颤。队伍安然度过第二夜，天亮后只剩一个白天就能抵达古都，村民们以为已脱离危险，走得零散，莫凡在前开路。忽然队伍后方传来惨叫，一片血雾在人群中溅起，大批亡灵大白天地从土里钻出，无视井水庇佑，专杀村民，杀完一个立刻追下一个，纯粹为杀戮。村民四散奔逃死伤惨重，莫凡连用雷印、疾星狼、巨影钉救援，失忆的张小侯本能施展岩系中阶魔法，两个岩障化作山屏挡住亡灵，莫凡跳上岩屏指挥柳茹把小孩带进保护圈。

**关键事件**：1.矮男说出勘测队失踪与羊阳村无人的旧事，张小侯闻之颤抖 2.亡灵大白天地从土里钻出专杀村民，无视井水庇佑 3.张小侯岩障护民，莫凡跳上岩屏指挥柳茹救小孩

**逐章写法公式**：

- **情绪流向**：起：轻松（第二夜平安） → 承：闲聊铺陈（矮男旧事） → 转：爆发（白天遭袭） → 合：惊险（岩障救场）
- **节奏配比**：慢铺垫 45% / 快冲突 45% / 爽点爆发 0% / 悬念留白 10%
- **本章结构公式**：矮男密语（埋雷） + 平安赶路（松懈） + 白天遭袭（引爆） + 岩障救场（收束）
- **本章核心技巧**：用两夜平安的假安全垫高白日突袭的冲击，让混乱场面靠具体死法推进
- **卡点与伏笔**：结尾卡点：岩障能否挡住亡灵、柳茹在外处境，下章期待突围；埋设/回收伏笔：羊阳村无人、勘测队失踪、张小侯对村名的异样反应
