# 第211章 误下重手！

**概要**：莫凡激活血兽靴主动效果，将力量凝聚双腿，一记血兽铁蹄踢碎了有一面墙高的假山，躲在后面的中阶风系法师傅天明骨裂声清晰可闻，倒在废墟里爬不起来。另两名埋伏者看傻了眼，自述是明珠学府的学生，因为贾文清的一顿饭，受命蹲点教训一个据说猥亵牧奴娇的狂徒，误把莫凡当成了那人；莫凡冷声追问指使者，两人答是贾文清。莫凡意识到这班人不是黑教廷——黑教廷出手必索性命，便让两人赶紧把只剩半条命的傅天明送去医务室。张兵、李旺抬着骨头几乎全碎的学长仓皇离开。莫凡回家后回想博城灾难中死去的熟人——何雨、姑丈、徐大荒、肥石、徐兵等，明白刚才的战斗带着痛恨所以没留手，险些杀人的闹剧让他后怕。开学后「大魔头差点杀风系学长」的新闻传遍全校，臭名加倍，莫凡被教导处请去喝茶，萧院长亲自过问，问他为何下手这么重、是不是遇到了麻烦，莫凡不做解释；萧院长放他回去，叮嘱主校区考核注意别再出事。莫凡走在校园里心中阴云不散，最终自问自答：自己不是怕黑教廷，是怕他们再将自己身边熟悉的人的性命带走。

**关键事件**：1.血兽铁蹄重创傅天明，两名埋伏者供出指使者贾文清 2.莫凡确认非黑教廷后放人送医 3.校方处理险杀人事件，莫凡自省恐惧的真正来源

**逐章写法公式**：

- **情绪流向**：起：爽（一蹄碎山重创强敌）→ 承：搞笑（闹剧揭晓与抬人逃跑）→ 转：压抑（死者名单与恶名加倍）→ 合：压抑（恐惧来源的自省）
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：重招爆发（收上章卡点）+ 误会揭晓（降格冲突）+ 创伤回溯（给暴力以动机）+ 校方问话与自省（转压抑留钩）
- **本章核心技巧**：把一场误会的过度反击，用死者名单回溯升格为创伤宣泄，闹剧与悲剧一章内两读。
- **卡点与伏笔**：结尾卡点：情绪暗线（对身边人安危的恐惧，驱动下章改派保护）；埋设/回收伏笔：贾文清指使 → 与206章阴狠目光呼应，报复线坐实；傅天明重伤两月、无缘主校区 → 后文疗养院线引子；萧院长一句你是不是遇到了什么麻烦 → 校方知情线；何雨等死者 → 复仇动机长期伏笔。
