# 第127章 渔翁与黄雀

**概要**：唐月建议莫凡日后投靠财大气粗的势力换资源，莫凡乘机调戏"不如你包养我"，被俏脸一红的唐月怒目瞪回。两人暗中尾随猎法师队伍，找到已干成泥潭、剩晒干鱼骨的溪水源头小水库，发现先到的猎法师十人队与刚赶到的东方世家四人剑拔弩张：唐装男子喝令潘熊带人滚蛋，扬言东方世家看上的火系灵种没有分一杯羹的规矩。唐月判断躲在某处的帽男是要让两拨人鹬蚌相争、坐收渔翁之利，自己则要"黄雀在后"拿下此人（原文此处称其为蒋卢）。东方世家四人全是中阶火系、火滋信手拈来；猎法师队也有三名中阶、七名初阶精英，战力估计有资本猎杀战将级妖魔。唐月带莫凡用暗影初阶"遁影"瞬移到安全距离观战，双方以初阶魔法快速互轰成火海；随后唐装男子在队友品字型掩护下画出星图、被赤红火焰包裹如复仇焰魂，一声"烈拳·轰天"将烈焰聚于右拳。

**关键事件**：1.猎法师队与东方世家在小水库对峙开战 2.唐月点破帽男渔翁意图、决意黄雀在后 3.东方唐装男子在队友掩护下起势烈拳·轰天

**逐章写法公式**：

- **情绪流向**：起：斗嘴的轻松 → 承：对峙的紧绷 → 转：开战的热烈 → 合：烈拳起势的屏息
- **节奏配比**：慢铺垫 40% / 快冲突 40% / 爽点爆发 10% / 悬念留白 10%
- **本章结构公式**：投靠建议（资源线）+ 尾随至水库（抵达战场）+ 双方对峙与阵容清点（战前分析）+ 烈拳起势（爆点掐断）
- **本章核心技巧**：三方博弈章把主角放在观战位，用"看戏＋偷师"双收益抵消主角不出手的憋闷
- **卡点与伏笔**：结尾卡点：唐装男子烈拳·轰天蓄势待发，威力下章见分晓；埋设/回收伏笔：帽男坐收渔利（朝赫陷阱线）、遁影技能展示（暗影系诱饵）、东方世家与猎者联盟结怨（后续冲突引线）、火系灵种未出土（核心宝物悬念）
