# 第147章 入学风云（上）

**概要**：考核结束后，蒋云明对莫凡非常满意——中阶魔法师有实力有资金，能把召唤生物养得更强，不再视其为鸡肋。萧院长注意到莫凡档案属地是博城，问他是否来自博城，称从其身上看不到一点灾难后懦弱的阴霾，并批准他直接住校。莫凡离开后，萧院长留话「这学生蛮有意思的，好好培养」，考官们猜测院长是否看出了更多隐藏。莫凡提前两个月入住，摸清明珠学府分青校区与主校区两级。开学日舍友陆续到来：光系的赵满延与莫凡相谈甚欢，两名沉默舍友自顾不暇，红发火系学生陆匀峥进门就霸占赵满延的床位、把他的行李扔到一边。当晚新生会，莫凡在空教室独等，直到蒋云明与六名男生先后到来——召唤系全系新生只有七人，莫凡自嘲演葫芦娃正好够。

**关键事件**：1.萧院长确认莫凡来自博城并批准住校，留话好好培养 2.舍友报到，陆匀峥强占赵满延床位 3.新生会揭底：召唤系新生仅七人

**逐章写法公式**：

- **情绪流向**：起：录取余韵的温情 → 承：住校适应的日常 → 转：陆匀峥占床的憋气 → 合：全系七人的爆笑反转
- **节奏配比**：慢铺垫 50% / 快冲突 20% / 爽点爆发 5% / 悬念留白 25%
- **本章结构公式**：考官定评+院长留话（收上章余波） + 住校摸底世界观（铺垫） + 舍友群像与占床冲突（立人际） + 新生会七人揭底（幽默钩）
- **本章核心技巧**：用「人数揭晓」做章末反转——先铺空教室的错位尴尬，再一句「都到齐了」把召唤系的惨况变成笑点兼信息点
- **卡点与伏笔**：结尾卡点：幽默型，全系新生仅七人、召唤系弱势地位摊开，下章看迎新节目怎么整他们；埋设/回收伏笔：萧院长「好好培养」的留话 → 暗示莫凡隐藏双系可能已被察觉，长线伏笔
