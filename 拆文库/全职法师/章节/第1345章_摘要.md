# 第1345章 反其道而行

**概要**：炎火天图的火波从云端贯穿山岭轰落在乌羊将军身上，将它冲下山的脊背，几十座小山丘被碾成平地，烧红的重锤被它扔在地上。炎女姬滑翔中化作火烈鸟卷起烈火飓爆将乌羊将军轰倒。赵满延提议去追牧羊人与程英，莫凡摇头，说他已在两人身上埋下黑暗物质，能清楚知道他们的位置，放他们走是为给其优越感和安全感，才有机会触碰引渡首与红衣大主教。随后赵满延带莫凡从千米高空俯冲，莫凡以蓄力已久的雷电轰开乌羊将军头颅，炎女姬以天地劫炎织出火焰磅剑扎入其胸膛，乌羊将军惨叫中急剧缩小，逃窜时被炎女姬以空间系魔法拧回继续烘烤。莫凡分析牧羊人随意丢弃召唤兽、很可能拥有一群羊角怪物，实力极强。与齐阳汇合后得知司机精神受损，巴士被救下但丢了一条命。莫凡摊开手掌，一只黑色小精灵落手，指出牧羊人与程英翻过山反其道而行，重新隐入了城市。

**关键事件**：1.莫凡与炎女姬联手击杀乌羊将军，炎女姬战斗惊爆 2.莫凡透露已用黑暗物质标记牧羊人程英，放长线钓大鱼 3.牧羊人与程英反其道而行逃回城市，齐阳的山野搜寻落空

**逐章写法公式**：

- **情绪流向**：起：炎火天图碾压乌羊将军的爽快 → 承：放长线钓大鱼的谋略反转 → 转：高空雷击与火焰磅剑斩杀怪物 → 合：黑色小精灵报信、目标逃回城市的悬念
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：火波碾压（战斗主秀） + 放长线解释（谋略揭示） + 高空雷击火焰剑（斩杀收尾） + 黑色精灵报信（新追踪线）
- **本章核心技巧**：战斗与谋略双线交替，先给足视觉爽点再反转出"故意放跑"的布局，收尾以追踪信息衔接下一阶段
- **卡点与伏笔**：结尾卡点：目标入城——牧羊人程英逃回城市，齐阳搜寻失算；埋设/回收伏笔：黑暗物质夜煞→持续追踪牧羊人程英的引线；牧羊人的羊群→后续更可怕的召唤兽威胁
