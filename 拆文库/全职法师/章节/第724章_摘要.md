# 第724章 复仇法师！

**概要**：江昱与穆婷颖返回飞鸟市查案，其余人留在岛上。莫凡抓来一只小赤凌妖，让心灵系的蒋少絮将"你们吃人类婴孩，我们法师就灭你们族群"的杀意转达进它心灵，一脚将其踢回海里。蒋少絮同时在小赤凌妖身上留下心灵印记，众人乘轮船尾随它找到赤凌妖老巢。穆宁雪介绍赤凌妖水战强于陆战，官鱼、南荣倪相继探明碎岛分布、海猴怪附庸与赤凌妖数量，艾江图权衡后决定理智行动、不鲁莽。

- **情绪流向**：起：留守的平静 → 承：莫凡宣战的狠厉加压 → 转：尾随定位的推进 → 合：探明敌情后的理智钩子
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：莫凡抓妖传话（宣战） + 蒋少絮留印记（定位） + 官鱼南荣倪探岛（摸敌） + 艾江图权衡（定计）

- **卡点与伏笔**：结尾卡点：艾江图说有怒不代表没理智；埋设/回收伏笔：心灵印记→后续直捣老巢
