# 第950章 嚣张至极的头目

**概要**：队伍穿过一处依山临海、遍植妃红香草的童话小寨，赵满延上前与守口挂饰女子搭讪，却得知小寨正"举行节日"不接待旅客，队伍只得离开。莫凡与蒋少絮借口偷溜上山探看，缘由是莫凡的凝华邪珠亮起指向小寨。二人潜近发现村寨法师密度极高，且红衣挂饰者多达七八十人皆为老法师。正围观时，红饰公会头目西葛以"东西已归我，出钱买回"勒索寨长，烈性少女吐唾沫遭西葛淫威胁迫。莫凡与蒋少絮躲在树丛识破这是强盗劫持，并想起途经镇上正贴着红饰公会的悬赏。

**关键事件**：1.童话香草小寨拒入，莫凡蒋少絮偷溜上山 2.凝华邪珠指引，发现村寨法师密集异常 3.西葛勒索寨长、威胁少女，识破强盗劫持 4.忆及镇上红饰公会悬赏

**逐章写法公式**：

- **情绪流向**：起：童话小寨轻松 → 承：邪珠指引疑云 → 转：勒索威胁愤怒 → 合：识破强盗留出手钩
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：美寨拒入（设奇） + 邪珠引探（钩谜） + 识破勒索（激愤） + 忆悬赏（蓄势）
- **本章核心技巧**：用"美丽表象+邪珠异动"制造反差，再以无耻勒索把读者情绪推到想出手
- **卡点与伏笔**：结尾卡点：莫凡蒋少絮如何收拾红饰公会留悬念；埋设/回收伏笔：凝华邪珠→恶魔系伏笔；红饰悬赏→前情呼应
