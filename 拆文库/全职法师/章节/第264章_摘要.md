# 第264章 暴力法师！

**概要**：穆宁雪的风轨透着宝石蓝、能量超出普通青色风元素，速度冠绝在场风系，轻松躲开地刹烈焰——她早料到莫凡施展的魔法。她无缝衔接施展第二级风盘-天罗：宝蓝青风托身轻微悬浮，身周展开直径二十米的青蓝气场，从冰之灵女化为风暴之姬；观者惊呼灵级风种，帝都学员喊队长被逼出第二系、莫凡死定了。天罗直接在目标所在地涌起陀螺状旋风，风壁困人撕裂、末尾一甩一抛一摔不亚于坠崖，灵级风种威力翻倍，其他战场的法师远远退开。战场演变成莫凡与穆宁雪两人之战。莫凡在风眼中以烈拳-轰天连轰三拳——第三拳"给我散"把灵种风盘天罗生生轰散。彭亮叹服明珠大魔头；老师们这才明白萧院长、周正华主任为何非把莫凡弄进交换生——这货是来踢馆的。莫凡宣言总算找到一个勉强能和他打的。

**关键事件**：1.穆宁雪亮出第二系灵级风种、风盘-天罗困住莫凡 2.莫凡三拳轰散灵种天罗 3.全场重估莫凡为"踢馆者" 4.莫凡宣言双灵种对双灵种

**逐章写法公式**：

- **情绪流向**：起：风暴之姬登场的压迫 → 承：天罗困人的绝境机制 → 转：三拳连轰以攻破防的爆发 → 合：轰散天罗、踢馆宣言的意气飞扬
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 30% / 悬念留白 5%
- **本章结构公式**：天罗成阵（敌方亮第二系）+ 机制科普（绝境可视化）+ 三拳递进（暴力破局）+ 全场重估与宣言（立暴力法师人设）
- **本章核心技巧**：用"摇晃—扭曲—轰散"的三拳重复递进把一次破解写出节奏感，再以旁观者重估与主角宣言双收，完成人设定名
- **卡点与伏笔**：结尾卡点：紧张——莫凡宣称这赛场不是只有她有双灵种，二人的巅峰对决胜负未分；埋设/回收伏笔：萧院长、周正华主任刻意把莫凡塞进交换生 → 回扣"收好处卖命"的校方布局线；莫凡火系星云持续供能、放中阶不需喘息 → 魔能异常伏笔；穆宁雪宝石蓝灵级风种 → 双灵种规格确立；"明珠大魔头"名号经彭亮之口再响 → 称号线回扣
