# 第600章 复仇，真相！

**概要**：黑夜中的古宅小院被活死人屠杀，狗子被卸掉手臂，柳茹、苏小洛和张小侯只能在院中抵抗。亡灵法师方谷指责华村村民当年拒绝收留失去昆井之水保佑的羊阳村人，说明自己曾亲手杀死村民并把他们炼成活死人，为的是让华村感受被死亡包围的绝望。方谷还透露，他把最后的昆井井水加入淬炼，使亡灵能够在白天活动，这解释了此前白日遇袭的原因。柳茹指出方谷还屠灭其他六村，方谷却坚持只杀华村，并准备连同三名外人一起杀死。

**关键事件**：1.方谷操控活死人屠杀华村村民 2.方谷讲出羊阳村被拒后的复仇经过 3.昆井井水使亡灵白日活动的真相揭开

**逐章写法公式**：

- **情绪流向**：起：村民惨叫与屠杀 → 承：方谷讲述被拒和等死 → 转：亲手炼尸及昆井井水真相 → 合：柳茹质疑范围，方谷准备继续杀戮
- **节奏配比**：慢铺垫 10% / 快冲突 40% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：活死人行凶（制造惨状） + 方谷质问村长（引出旧怨） + 自述炼尸经过（补足真相） + 白日亡灵解释（回收伏笔并留下杀机）
- **本章核心技巧**：让反派在施暴现场讲述自身创伤，把复仇的受害者与加害者位置交错，形成难以简单裁决的伦理冲突。
- **卡点与伏笔**：结尾卡点：方谷扬言要让柳茹等人陪葬，期待三人如何抵挡活死人；埋设/回收伏笔：昆井井水能让亡灵白天活动 → 解释此前白日亡灵袭击。
