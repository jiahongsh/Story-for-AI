# 第1269章 战斗骗术

**概要**：莫凡被三头犬的瞳光锁魂，闭眼躲避反而让上百双幽火瞳孔在脑海中浮现，第四境界的精神修为被折磨得呼吸艰难，凝神项链泛起层层水蓝涟漪才把他的心脏平顺下来。他睁开眼时，三头犬的碾血之踏已高悬头顶，莫凡一把搂住没有独自闪躲的穆宁雪，强行施展瞬息移动，在犬男嘲讽"施法时间太长"的当口从踩碎两百多米树林的铁蹄下遁走。莫凡绕到三头犬后方，抡起烈焰炎剑横扫，烈霞炎与劫炎在怪物身上撕开一条灼烧长痕，穆宁雪由此判断那抗揍的血气护罩极其消耗能量、不能时时维持。犬男恼羞成怒发动凛咒凝视，莫凡以司夜统治封住视线，让恐惧锁身无从施展，随即用一道弱小的火拳骗出三头犬的血气护罩，接着虚张声势大喊"最强毁灭魔法"、实际只送出一颗照明级小火球，再一次骗掉护罩，犬男被耍得脸色通红。穆宁雪的冰空玫瑰趁机在怪物解除护罩的瞬间绽放，成百上千的冰刺扎满三头犬全身血洞，寒冰顺着伤口侵入体内，令它的速度与力量严重受损，犬男憋屈至极，想不通世界学府第一的学员竟会用这种无赖手段连续骗他两次。

**关键事件**：1.莫凡强施瞬息移动，从碾血之踏下带走穆宁雪 2.炎剑突袭撕开长痕，点破血气护罩消耗巨大的弱点 3.司夜统治封视线，弱火拳与虚张声势连骗两次护罩 4.穆宁雪冰空玫瑰趁隙扎满血洞，寒冰入体重创三头犬

**逐章写法公式**：

- **情绪流向**：起：锁魂绝境的恐怖 → 承：极限瞬移的惊险 → 转：连骗两次的战斗智斗 → 合：冰空玫瑰收网的畅快
- **节奏配比**：慢铺垫 10% / 快冲突 40% / 爽点爆发 40% / 悬念留白 10%
- **本章结构公式**：精神绝境（压迫）+ 极限逃生（惊险）+ 骗术连击（智斗）+ 队友收网（爽点）
- **本章核心技巧**：把"骗"字做成战斗的贯穿动作，先铺垫对手防御机制的可骗性，再用连续两次骗术制造不对称的智斗爽感。
- **卡点与伏笔**：结尾卡点：压制类，三头犬遭重创、犬男憋屈愤怒，反扑在即；埋设/回收伏笔：血气护罩消耗巨大的弱点 → 下章彻底破防，寒冰入体的削弱 → 下章速度减半。
