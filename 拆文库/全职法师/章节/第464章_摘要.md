# 第464章 踏河惊魂

**概要**：白沙妖兵排成四五列围死那队猎法师，钝沙刀成排落下，把众人砸得血肉横飞，防御顷刻粉碎，惨叫声回荡空寂荒漠，莫凡全程没有出手相救的念头。众人被惊醒，亲眼目睹这一幕，心夏晨颖捂住嘴，赵满延头皮发麻想打道回府，张小侯说话都不利索。晨颖质疑心灵系魔法能否护住全队，心夏承诺只要走未染血腥味的区域便可保众人无恙，并立下铁规矩：未经她允许，河内不得动用任何魔法，否则妖兵必然群起攻击。一夜不安熬到天亮，赵满延提议先派人下水试探，推来推去反被大家推举为试水者，硬着头皮踏入沙惘河，刚走出几步，周围便涌起层层白浪，数十只白沙妖兵拔地而起。

**关键事件**：1.队伍目睹猎法师被妖兵团灭 2.心夏立下河内禁用魔法的铁规矩 3.赵满延被推为试水者遭妖兵包围

- **节奏配比**：慢铺垫 40% / 快冲突 25% / 爽点爆发 0% / 悬念留白 35%
