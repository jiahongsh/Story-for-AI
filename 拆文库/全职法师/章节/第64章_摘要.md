# 第64章 独眼魔狼

**概要**：莫凡回忆食堂消灭巨眼猩鼠后校内仍出现过微弱震动、警方查无结果，对工地之震满腹狐疑。夜里他带周敏潜入废工地：他潇洒翻墙落地，周敏却从旁边小门直接走进，气氛一度尴尬。莫凡撒出寻妖粉，晶莹粉末在十米外的地面粘出一只脚印轮廓——寻妖粉能粘附妖魔十天内的气息足迹，周敏认出道具后吓得脸色发白，劝他赶紧通知猎妖队，莫凡心中自嘲自己就是猎妖队的，且指出足迹只是嫌疑、非铁证。他近看脚印判断不像巨眼猩鼠的，顺足迹深入工地，痕迹尽头指向一座堆满水泥袋废料的烂尾商场楼。周敏忽然声音僵硬地提醒，莫凡顺其目光望去，看见一楼砖墙后一团黑色巨影在蠕动——一头半直立、脑袋几乎顶到二层楼板的独目巨狼。周敏认出这是妖魔课上反复提过的凶残妖魔独眼魔狼，以人为食、对人类天性敌意，而它此刻正咀嚼着一条断掉的人的手臂，莫凡以一句吃夜宵轻描淡写作答，周敏几近吓昏。

**关键事件**：1.寻妖粉在工地显出妖魔脚印，排除巨眼猩鼠 2.足迹尽头锁定烂尾商场楼 3.两人目击独眼魔狼当场啃食人臂，确认城市里潜伏吃人妖魔

**逐章写法公式**：

- **情绪流向**：起：夜探废墟的诡静 → 承：寻妖粉显影的惊疑 → 转：黑影蠕动的骤恐 → 合：吃人现场的窒息
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：翻墙入园（喜剧松扣）+ 撒粉显影（物证递进）+ 辨迹锁楼（收窄范围）+ 目击食人（恐怖引爆）
- **本章核心技巧**：用探案式的证据链逐步显影怪物，恐怖靠延迟揭示与反应层放大，全程不见一滴多余的血
- **卡点与伏笔**：结尾卡点：恐怖定格型——魔狼咀嚼活人手臂的画面收尾，读者与周敏一同失语；埋设/回收伏笔：脚印非巨眼猩鼠 → 引出新妖魔；体型大出两号 → 妖魔异常强壮之谜；流浪汉失踪无人统计 → 下章食源逻辑；莫凡就是猎妖队的身份信息差 → 周敏尚不知情
