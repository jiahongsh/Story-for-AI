# 第914章 基本上碾压

**概要**：莫凡嘴不饶人讽埃及队不如回沙漠修炼，史瑞夫跳出来称赛以德仅中下游、自己来收拾莫凡，莫凡指名要副队长米奥斯。史瑞夫施诅咒系恐惧之霾干扰莫凡星图，莫凡耳边回荡撒朗死亡通牒的幻听——那本是史瑞夫挖出的最深恐惧，莫凡却无恐惧唯有愤怒。双系高阶精神力强一倍的他银澜撞飞史瑞夫，疾星狼咬肩、六枚暗影钉梨刺锁关节，燃烧拳头将史瑞夫浑身燃着倒飞出界骨断皮烂。守馆人惊呼莫凡碾压国府队员，埃及脸丢尽。

**关键事件**：1.莫凡讽埃及要米奥斯 2.史瑞夫恐惧之霾 3.莫凡幻听撒朗却愤怒 4.银澜疾星狼暗影钉碾压 5.史瑞夫出界骨断

**逐章写法公式**：

- **情绪流向**：起：讽敌的狂 → 承：诅咒对拼的紧 → 转：幻听转怒的燃 → 合：碾压出界的爽
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 35% / 悬念留白 15%
- **本章结构公式**：讽敌要米奥斯（狂） + 恐惧之霾（紧） + 幻听转怒（燃） + 碾压出界（爽）
- **本章核心技巧**：用反派诅咒反向引出主角意志，层级差坐实碾压收尾
- **卡点与伏笔**：结尾卡点：米奥斯是否亲自下场，留白；伏笔：撒朗通牒 → 贯穿终极线
