# 第1111章 血性之争

**概要**：乔森解决江昱后直窜瑞迪处，艾江图瞬息移动未恢复无法阻拦。乔森对小炎姬施司夜统治将其笼罩黑暗，以黑暗长矛禁锢其精神力使其无法进攻，却不恋战小炎姬，只为保瑞迪释放地狱火翻盘。瑞迪森绿烈火凝聚成火石坠落，中国席位众人倒吸凉气，莫凡赵满延南荣倪皆难逃范围。艾江图转攻风笛，南荣倪坦白无魔具。赵满延拒绝撤离，要莫凡瞄准德国佬，展金翼撞向地狱火石，层层施展水御、光佑、岩铁肌肤、图腾印记等所有防御，却仍被森绿火焰逐层剥开；庞莱点破瑞迪天生天赋非无视一切，每道防御都在削弱威力，地狱火石终在五十米炸开，赵满延被烧得面目全非抬下，莫凡重叹。

**关键事件**：1.乔森司夜统治禁锢小炎姬，保瑞迪放地狱火 2.赵满延金翼撞地狱火，层层防御被剥 3.地狱火石五十米炸开，赵满延重伤抬下

**逐章写法公式**：

- **情绪流向**：起：乔森保瑞迪的压迫 → 承：地狱火降临全员危局的加压 → 转：赵满延撞火的爆发 → 合：火石炸开重伤抬下的余波
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：乔森禁锢小炎姬（设危） + 瑞迪地狱火凝聚（加压） + 赵满延金翼撞火（反转高光） + 层层防御被剥（波折） + 火石炸开重伤（钩子）
- **本章核心技巧**：用"贪生者赴死"的性格反转，把一个被动挨打的局面写成角色高光
- **卡点与伏笔**：结尾卡点：赵满延生死未卜，下章莫凡雷火领域复仇；埋设/回收伏笔：庞莱点破天赋弱点→后文众人针对性备战的依据
