# 第31章 骂个痛快！

**概要**：穆贺勃然大怒骂莫凡混账东西、命他马上向穆卓云道歉。莫凡称道歉当然可以，但穆卓云也得先为三年前的事道歉，还放话别拿修为和权力压人、"你要在我这个年龄，我能把你打得满地找牙"，气得穆卓云直接爆出粗口。穆白跳出来请战魔法决斗，要莫凡输了就跪下给穆老爷子道歉，盘算借同辈公平之名把莫凡往死里打。此时穆宁雪出声"不用你"，走到父亲与莫凡之间，称两人同岁，既然莫凡说父亲只会欺凌小辈、以权打压靠自己修炼的魔法师，那就用最公平的魔法决斗来解决。邓凯称赞穆宁雪冰雪傲骨、是非分明，劝穆卓云由女儿代劳免得以大欺小；他又劝莫凡为鲁莽行为道歉，莫凡回应可以浑身背着荆棘、用最传统的磕头方式道歉到满意为止，但前提是穆卓云先为三年前的事道歉，并警告大人物别惹小人物——蝼蚁拍死之前绝对骂得你脑淤血。校长瞪眉称这是法治社会最多把莫凡开除，邓凯顺势定下赌约：穆宁雪与莫凡魔法决斗，莫凡输则道歉到穆卓云满意为止，穆卓云冷笑"宁雪怎么可能会输"。莫凡只问一句"你就说你敢不敢吧"，内心自白尊严不因大世家更高贵、也不因自家颠沛流离而低贱，与其当逃不过脚掌的蝼蚁不如骂个痛快。章末穆卓云目光扫过女儿，丢下一句"宁雪，这事不用你来"。

**关键事件**：1.莫凡提对等条件拒不道歉 2.穆宁雪挺身代父应战 3.邓凯定决斗赌约、穆卓云却叫停女儿

**逐章写法公式**：

- **情绪流向**：起：骂战余波互呛 → 承：穆白请战添乱 → 转：穆宁雪代父应战、赌约成立 → 合：穆卓云叫停女儿留悬
- **节奏配比**：慢铺垫 20% / 快冲突 50% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：互呛升级（拉满对抗）+ 对手请战（借刀）+ 女神代战（反转）+ 赌约悬置（转钩）
