# 第202章 发财了！

**概要**：拍卖会上莫凡跟着赵满延认货：魔具是与灵魂相连、激活后幻化特殊力量的战斗装备，魔器是附带滋养效果、大都无法激活的物件，如给火系魔法附加火毒效果的毒火戒，价格比灵级火种还贵。蓝绒巨雀蛋底价七千万仍出价者比比皆是，此雀拥有蓬莱云雀血统、成年实力不亚于战将级还可载人飞行；赵满延趁机科普次元召唤是不停耗魔能的临时工、契约召唤才是签约即终身驯化的亲儿子，建议把炼兽资源留给契约幻兽。随后莫凡的战将级精魄作为插队品上拍，起拍价1200万，因直接挂钩星尘魔器星云魔器，在场的几乎人人出价；赵满延嘱咐以后有精魄可直接联系赵家鉴定师。莫凡盘算以后靠卖精魄赚钱，更疑惑小泥鳅坠的本领。精魄最终以2900万成交，超出本值近千万。

**关键事件**：1.竞拍场上魔具魔器之别与召唤系双技科普 2.战将级精魄插队上拍，全场近乎人人出价 3.精魄以2900万成交，莫凡自叹真发财了

**逐章写法公式**：

- **情绪流向**：起：好奇（奇珍异宝开眼）→ 承：压抑（七千万买不起的落差）→ 转：紧张（精魄上拍哄抢）→ 合：爽（2900万落袋）
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：认货科普（立规则）+ 巨雀蛋开眼（立价坐标）+ 精魄插队哄抢（抬价）+ 2900万成交（爽点收章）
- **本章核心技巧**：先让主角看一遍买不起的顶级货，再让他自己的货被全场哄抢，贫富反转一次完成。
- **卡点与伏笔**：结尾卡点：兑现（发财了，钱怎么花留到下章）；埋设/回收伏笔：契约召唤的资源建议 → 召唤系养成路线；赵家鉴定师渠道 → 精魄生财暗线；小泥鳅坠的本领之谜 → 挂坠伏笔加深。
