# 第1125章 致命陷阱

**概要**：阿莎蕊雅转攻英国队员，混战出局骤增：南珏出局，艾江图被伽门侬哲罗送下，伽门侬反被穆婷颖冰之荆棘套装打出水晶荆棘出局。中国剩莫凡、穆宁雪、穆婷颖，希腊剩三无名额，英国独哲罗。封离将治愈师南荣倪排最后，替换时南荣倪随机隐藏入场；英希放弃互杀同寻南荣倪。莫凡见植物根藤打结寻至河边，穆婷颖不理穆宁雪"陷阱"警告冲前招呼南荣倪，南荣倪却描植物系星图——莫凡悟是陷阱，带穆宁雪遁逃，南荣倪已被操控心智布下鬼藤窟窿。

**关键事件**：1.混战出局增，中希英仅余核心，封离藏南荣倪最后 2.南荣倪随机入场被英希同寻，穆婷颖不理警告冲前 3.南荣倪用植物系露馅，莫凡悟陷阱带穆宁雪遁逃

**逐章写法公式**：

- **情绪流向**：起：出局雪崩的紧张 → 承：藏南荣倪的期待 → 转：穆婷颖莽撞冲前的波折 → 合：陷阱揭穿遁逃的钩子
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：出局雪崩（加压） + 藏治愈（设伏） + 同寻南荣倪（布局） + 穆婷颖莽撞（波折） + 陷阱揭穿（钩子）
- **本章核心技巧**：用"以为救队友实为入陷阱"的误判，把救援行动写成惊魂一刻
- **卡点与伏笔**：结尾卡点：莫凡穆宁雪陷鬼藤，下章迎接雷电突围；埋设/回收伏笔：南荣倪被控→希腊心灵系米塔幕后
