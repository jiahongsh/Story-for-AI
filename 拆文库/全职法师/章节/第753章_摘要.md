# 第753章 海之惩罚

**概要**：艾江图催众人离港免被认出偷渡，一字胡警官随即盘查游轮，蒋少絮以流利日语扮作日本姑娘称系林氏集团游轮、有登陆许可，待警官疑心盘问江昱、南珏时，二人装聋哑不语，蒋少絮顺势称自己是聋哑学院老师、众人是天生聋哑的有钱人并打手语，南珏会意配合，警官疑消后凭许可放行。莫凡暗恼被查或因同行妹纸，众人过检查入西熊市，因无证件住不了宾馆，出香油钱被半山闫明寺收留；莫凡坐寺前石龟眺望海景，被清秀年轻和尚日语数落坐"圣龟"，换用国际通用语后和尚称其糟蹋文化、坐圣龟出海必遭海洋惩罚，并抱怨居民诋毁圣龟、出事反诬寺庙邪恶。

**关键事件**：1.蒋少絮手语蒙混过关入境 2.众人借宿闫明寺，莫凡坐圣龟被和尚数落 3.年轻和尚称坐圣龟必遭海洋惩罚

- **情绪流向**：起：离港避险 → 承：盘查过关紧张 → 转：入寺轻松 → 合：海洋惩罚钩子
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：催离港（铺垫） + 盘查蒙混（冲突） + 借宿寺庙（过渡） + 圣龟冲突（钩子）
- **本章核心技巧**：用"危机—应变—放行"小目标嵌套推进过渡章，结尾以文化冲突落钩子
- **卡点与伏笔**：结尾卡点：无（钩子收束）；埋设/回收伏笔：海洋惩罚 → 后续赵满延中招呼应；闫明寺冷清 → 异事件铺垫
