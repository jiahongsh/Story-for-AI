# 第1230章 莫凡老师（下）

**概要**：莫凡坐在明珠湖畔教学楼教室里等毕业生，牧奴娇在一旁偷笑。萧院长的算盘随之揭晓，他是院长本可指派助理导师，正好让莫凡带队搞定自己进展不顺的水脉项目环节，一举两得。六名毕业生兴冲冲赶来，把坐在讲台上的莫凡当成抢座的同窗，老气学员出言劝诫，俊酷男子更直接动手把他拉下讲台并口出狂言。莫凡以空间之力将俊酷男子推飞撞墙，平静宣布我是你们导师，众人惊得目瞪口呆，俊酷青年瞬间服软结巴道歉。莫凡交代任务，萧院长的水系循环阵卡在桐乡水源头被堵塞，需前往安界之外查明原因，而源头水栖息着妖魔族群。返回住处后，牧奴娇分析萧院长的水循环大阵以自然水脉为源动力可无消耗守护江南，又疑惑妖魔从不打水脉主意，桐乡水脉被阻不合常理，莫凡却只顾纠结明天该如何装出老师的架势。

**关键事件**：1.六名毕业生误把莫凡当同学，俊酷男子动手拉人被空间之力震飞 2.莫凡宣布我是你们导师，学生集体震惊道歉 3.莫凡布置桐乡水源头堵塞的毕业任务 4.牧奴娇点出水脉被阻违背妖魔常识的疑点

**逐章写法公式**：

- **情绪流向**：起：等人的闲适 → 承：学生冒犯的冲突 → 转：身份揭晓的爽感 → 合：任务与疑点的悬念
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 20% / 悬念留白 20%
- **本章结构公式**：萧院长算盘揭晓（补背景）+ 学生冒犯被打脸（立威）+ 布置桐乡任务（开新线）+ 水脉疑点与老师人设烦恼（设钩子）
- **本章核心技巧**：用一个空间系小施展立住导师权威，喜剧与威势在同一动作里完成
- **卡点与伏笔**：结尾卡点：反常疑问型——水脉被阻违背妖魔不动水脉的常识，下章深入桐乡探因；埋设/回收伏笔：安界外源头栖息妖魔族群 → 水源头冒险对手；水脉被阻真相 → 后续水脉主线
