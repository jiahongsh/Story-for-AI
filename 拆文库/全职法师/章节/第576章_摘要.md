# 第576章 集结信号

**概要**：一声脆鸣，狞骨魔将的下肢在霹雳擦身而过后化为粉碎，不堪重负地崩断，庞然骨躯如石屋砸落般倒塌。领队慧眼识出莫凡的灵雷拥有空间震荡，那记霹雳本不为劈中身体，落地时引起空间与大地的同时震荡，生生崩断冻脆的骨腿。冰霜之力持续侵蚀，狞骨魔将全身关节凝结成冰丝毫不能活动。众人凯旋，周敏目光闪烁露出小女生崇拜，城墙上猎法师们称赞接近大骨将实力的狞骨魔将被一次击杀，赵坤三和王三胖趁机阴阳怪气挤兑蒋黎，蒋黎被气走。周敏学分大涨之际，冗长城道被巨大血光笼罩，雄浑钟鸣回荡，领队认出是连发四个的紧急集结信号，隶属各势力的法师必须前往。众人赶到北主城楼，满髯须的祝蒙议员带着宫廷侍卫与军统走下阶梯，莫凡一眼认出他，两人目光相撞互瞪互怼，在场众人惊讶于一个中阶法师竟认识这样的大议员。

**关键事件**：1.灵雷空间震荡崩断冻脆的狞骨魔将下肢，魔将倒塌 2.赵坤三王三胖挤兑蒋黎，蒋黎被气走 3.连发四个集结信号，众人赶往北城楼，祝蒙议员与莫凡互怼

**逐章写法公式**：

- **情绪流向**：起：痛快（魔将倒塌） → 承：欢乐（挤兑蒋黎） → 转：警觉（血光钟鸣） → 合：悬疑（祝蒙现身）
- **节奏配比**：慢铺垫 10% / 快冲突 30% / 爽点爆发 30% / 悬念留白 30%
- **本章结构公式**：崩腿斩将（爽点闭环） + 小人得志（喜剧余波） + 集结信号（气氛转折） + 议员登场（新钩子）
- **本章核心技巧**：一场战斗打完立刻切换新威胁信号，用大人物登场把爽点引向下一个任务
- **卡点与伏笔**：结尾卡点：连发四信号的大事件与祝蒙的态度，下章期待煞渊级事件展开；埋设/回收伏笔：莫凡与祝蒙旧交、广义集结的紧急事件
