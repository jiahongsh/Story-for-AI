# 第790章 有妖进海

**概要**：第三场蒋少絮对小池翔子，心灵系单挑基本无解，持续心灵冲击让对手放不出魔法，小池翔子不堪受辱认输，蒋少絮昂然称这是国府与守馆差距，三场全胜不负此前嚣张。众人回屋休息，深夜日本军司在木回廊打电话，称已录下战斗信息今夜发出，可惜只派三名选手。电话那头浑浊声音说西守阁学员令人失望，高木将军接话称那名与千熏切磋的中国选手许久未败、似有罕见火元素契约兽。高木问鹤田还不肯说，对方要将其留东守阁用刑罚逼供。高木遇千熏，她以困为借口摆脱纠缠，却抬头注视黑漆漆的东守阁，喃喃问大哥鹤田是否真在里面、为何被囚。此时上阁警戒红光与防空警报骤响，哨岗报海中东西撞毁上百警标器，却只有一个生物，千熏满眼惊愕恐惧。

**关键事件**：1.蒋少絮心灵系胜小池翔子，三场全胜 2.深夜军司通话暴露鹤田被囚东守阁 3.高木遇千熏，千熏问东守阁换防 4.千熏疑大哥鹤田被囚 5.海域巨物触发警报

- **情绪流向**：起：三场全胜的爽 → 承：深夜通话的悬念 → 转：高木邪光与鹤田线的压抑 → 合：海域巨物的紧张钩子
- **节奏配比**：慢铺垫 25% / 快冲突 10% / 爽点爆发 20% / 悬念留白 45%
- **本章结构公式**：蒋少絮胜（爽）→ 深夜通话（埋线）→ 高木遇千熏（暗线）→ 鹤田疑云（压抑）→ 海域巨物（钩子）
