# 第274章 隧道怪物

**概要**：队伍抵达一条两公里长的荒废铁路隧道。宋霞建议翻山避开与未知品种、未知数量的妖魔打交道，陆正河嫌翻山耽误时间主张直接杀过去，郑冰晓也赞成穿越。郑冰晓召唤三米高的岩魔人打头阵，陆正河嘲其没到进阶期够省资源，又承认这种又臭又硬的生物打头阵再合适不过；许大龙土系自荐断后，风系的廖明轩、沈明笑在前，赵满延与宋霞每走十米点亮一个光耀之术照明兼驱散浊气。途中队员发现隧道散落白色碎石，以为是工程遗留。莫凡挨着牧奴娇献殷勤，被她反问"你不是应该保护好你的大老婆吗"，吃瘪后交代穆宁雪是以前隔壁邻居、也是博城人。廖明轩以中级猎人和胸前银鼠炫耀，莫凡暗笑自己高级猎人都不好意思说。牧奴娇问莫凡是否感觉有东西在盯着他们，廖明轩还在打包票时银鼠突然竖毛尖叫，莫凡让赵满延朝牧奴娇身侧掷出光耀——照出洞壁黑藤缝隙里一对对幽蓝眼睛。莫凡把牧奴娇护到身后，火滋烧毁大片黑藤，照出数个手持带血骨棒的佝偻怪影。

**关键事件**：1.队伍决定穿越两公里隧道，岩魔人开路、光耀照明排布队列 2.莫凡与牧奴娇隧道拌嘴，廖明轩炫耀中级猎人身份 3.银鼠报警、光耀照出黑藤缝隙中密布的幽蓝眼睛，莫凡烧藤现出骨棒怪影

**逐章写法公式**：

- **情绪流向**：起：紧张（隧道抉择）→ 承：轻松（拌嘴与炫耀）→ 转：恐怖（墙中之眼）→ 合：紧张（怪影现身）
- **节奏配比**：慢铺垫 45% / 快冲突 20% / 爽点爆发 10% / 悬念留白 25%
- **本章结构公式**：路线之争（立险）+ 队形推进（铺氛围）+ 恋爱拌嘴（松一档）+ 银鼠报警（陡收紧）
- **本章核心技巧**：恐怖谷递进——碎石、浊气、被盯感、银鼠报警、灯照揭幕五级信号把隧道惊悚逐步拉满
- **卡点与伏笔**：结尾卡点：骨棒怪影现身、数量品种未知→下章开打；埋设伏笔：白色碎石真面目、黑藤覆盖的洞壁缺口
