# 第637章 无助之城

**概要**：亡灵黑潮吞没古都外城，逃入内城的人群挤满道路，哭喊和绝望逐渐被死寂取代。张小侯因早已见过黑教廷却没能阻止灾难而自责，苏小洛安慰他，并提醒虎津大执事可能就是博城人。莫凡带着穆白、周敏、赵坤三和王三胖赶来，让众人按记忆排查博城旧识。周敏先提到林雨欣和邓凯，莫凡与张小侯分别确认两人不可能是黑教廷成员，穆白却在众人追问下沉默，似乎掌握着新的怀疑对象。

**关键事件**：1.亡灵吞没外城 2.难民挤入内城 3.张小侯因无力阻止灾难自责 4.莫凡召集博城旧识排查虎津 5.穆白即将说出新线索

**逐章写法公式**：

- **情绪流向**：起：群体绝望 → 承：张小侯自责 → 转：旧识排查启动 → 合：穆白迟疑，新的嫌疑人即将出现
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：展示亡城（扩大灾难） + 张小侯自责（连接旧创伤） + 莫凡召集同伴（启动调查） + 穆白沉默（留下线索）
- **本章核心技巧**：用群体灾难背景压低人物情绪，再以熟人名单排查把宏大危机转成可追踪的个人悬念。
- **卡点与伏笔**：结尾卡点：穆白欲言又止，下一章期待他揭露怀疑对象；埋设/回收伏笔：张小侯听过虎津声音 → 转为博城旧识排查。
