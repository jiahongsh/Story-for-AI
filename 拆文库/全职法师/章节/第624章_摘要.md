# 第624章 一次预演

**概要**：柳茹说能帮助莫凡恢复魔能，莫凡误以为她要使用类似双修的血族秘术，柳茹却说明自己准备抓鬼将、抽取魂魄能量，再反哺莫凡的精神世界。她的手臂伤痕已经自行恢复，随后飞出院子行动，莫凡则在暖屋中沉沉睡去。与此同时，古都外城墙被凶灵大潮摧垮，亡灵海洋从四面入城，钟楼上的高位者讨论山峰之尸、摩角鬼主和西面鬼物等威胁。药师确认雨水含有九幽之露，使亡灵能在白天获得生机。有人因此判断黑教廷重演博城灾难，包裹严实的陌生男子却揭露博城只是撒朗为古都灾难做的一次预演。

**关键事件**：1. 柳茹说明用鬼将魂魄能量帮助莫凡恢复魔能 2. 古都外城墙被凶灵海潮摧毁并全面入城 3. 高位者得知雨水含九幽之露，陌生男子揭示博城灾难只是预演

**逐章写法公式**：

- **情绪流向**：起：暧昧误会 → 承：睡眠与灾难并置 → 转：古都全面失守 → 合：陌生人揭示更大阴谋
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 5% / 悬念留白 45%
- **本章结构公式**：误解恢复方法（轻松开场） + 柳茹出动（推进资源线） + 莫凡入睡（短暂安宁） + 外城墙崩塌（灾难扩大） + 雨水真相（寻找人为原因） + 预演揭示（抬高主线悬念）
- **本章核心技巧**：用私人室内的轻松误会与城市全景灾难交替切换，在结尾以陌生人的一句新定义重写前期灾难的意义。
- **卡点与伏笔**：结尾卡点：博城灾难被定义为古都灾难的预演，陌生男子身份和亡灵国度国主尚未揭开；埋设/回收伏笔：雨水中的九幽之露 → 解释亡灵白天活动；博城灾难 → 被重新定义为预演。
