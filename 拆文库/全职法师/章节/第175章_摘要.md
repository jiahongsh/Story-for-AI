# 第175章 小萝莉队友

**概要**：老头委婉拒绝少妇的委托，让她去找警察；少妇哀求派一名猎妖师保护她度过今晚、可以马上付钱，也被以猎妖师都在执行大任务回绝。少妇怒喊若家庭出事做鬼都不会放过他们，失魂落魄地跑出猎所。莫凡不解为何不帮，老头敲着烟斗说凡事不能看表面，随手抛给他一份协议：这是一份今早七点左右签订的彻夜保护委托，委托人正是刚才那女人的丈夫，所述情况与女人相似——说妻子半夜行凶，且写明若委托人自己遭遇不测并不追究责任，只希望保护好他们的孩子。两份委托地址相同，都在大学城偏南的私家花园。老头随即把这件委托交给刚来面试的莫凡解决，并指定队友是灵灵——她上一个搭档小鼎在为审判会追查一件事时死了。莫凡抗议要带这么个小丫头去猎妖，灵灵鄙夷纠正：是我带你这个菜鸟猎妖——并掏出一枚猎人大师徽章，联盟颁发的徽章无法作假、身份捆绑，莫凡差点从高椅子上摔下来。灵灵嫌莫凡蠢头蠢脑容易坏事，老头劝青天猎所一直难招人、有个不怕死的来很不容易，灵灵冷哼一声合书进屋。莫凡对优秀猎妖团队的幻想就此破灭成娇滴滴的一个小身影。

**关键事件**：1.猎所拒单、少妇含恨离场 2.丈夫的委托协议揭出同址矛盾 3.首单指派给莫凡、搭档灵灵 4.灵灵猎人大师身份揭晓

**逐章写法公式**：

- **情绪流向**：起：压抑（少妇被拒的绝望） → 承：紧张（同址协议的罗生门） → 转：其他（萝莉大师的身份反转） → 合：轻松（幻想破灭的吐槽）
- **节奏配比**：慢铺垫 40% / 快冲突 15% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：拒单逐客（冷面表象） + 协议揭底（罗生门成立） + 首单指派（主角入局） + 大师徽章（搭档反转）
- **本章核心技巧**：用一式两份、互相矛盾的委托书把家庭悬案升级为叙事诡计，谁是人谁是妖延后揭晓。
- **卡点与伏笔**：结尾卡点：今晚保护孩子、夫妻谁真谁假未解，下章期待守夜与真相；埋设/回收伏笔：小鼎死于审判会追查→灵灵的旧伤与后续复仇线；丈夫委托只求保孩子→委托金条款在后文回收；猎人大师徽章→灵灵实力背书。
