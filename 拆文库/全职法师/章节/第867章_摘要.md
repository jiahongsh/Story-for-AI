# 第867章 七大主教

**概要**：冷青在魔都向莫凡说明崇明岛黑教廷分会的剿除方案。审判会因顾忌黑教廷以岛上普通人质要挟、且未查明对方人数与据点，不便大举封岛，遂以秘密悬赏请强大会所协助。冷青定下以莫凡小团队为主、自己暗中策应但须保持距离的方略，并用审判会保密级别反将莫凡一军，迫其接下任务。悬赏按人头计：灰衣教徒五十万、黑衣教士九百万、蓝衣执事一亿两千万，活捉蓝衣执事可至两亿并利于连根拔除。冷青进一步透露黑教廷共有七位红衣主教，撒朗仅是其中之一，另四位身份成谜。为锁定窝点，灵灵也将随队潜入，莫凡以性命担保其安全，冷青另嘱穆宁雪勿感情用事。

**关键事件**：1.冷青向莫凡说明崇明岛行动受限于人质与情报，改发秘密悬赏。 2.冷青定下莫凡小团队主导、自己远程策应的方案，并以保密级别迫使莫凡接下任务。 3.悬赏金额公布，活捉蓝衣执事价值更高且利于连根拔除。 4.冷青透露黑教廷共有七位红衣主教，撒朗仅为其中之一。 5.灵灵获准随队潜入，莫凡以性命担保其安全。

**逐章写法公式**：

- **情绪流向**：起：任务压下的严肃 → 承：莫凡被套住的哭笑不得 → 转：七主教真相带来的震撼 → 合：灵灵涉险的凝重钩子
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 20% / 悬念留白 30%
- **本章结构公式**：冷青交代背景（铺垫难度） + 以保密相胁定下莫凡出马（制造被迫行动） + 悬赏数字刺激贪念（给目标） + 七主教真相与灵灵入局（抛更大悬念）
- **本章核心技巧**：用权威角色对话批量交代世界观设定，把"七位红衣主教"的反转嵌在任务布置里，借角色反应放大信息冲击
- **卡点与伏笔**：结尾卡点：冷青沉重托付灵灵入局，下章期待莫凡如何带小队潜入；埋设/回收伏笔：七位红衣主教 → 后续追查其他主教的长期线索；星河之脉 → 穆宁雪冲阶的资金动机
