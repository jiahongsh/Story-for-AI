# 第616章 七百人过死街

**概要**：莫凡站在高处看见撤离人群已经达到七百人，其中法师约九十名，中阶法师十七名，绝大多数仍是初阶法师。矮男强行安排抱婴儿者和低龄孩子进入人群内部，孩子父亲把男婴交给大妈后站到外围。穆白开始承担组织者职责，莫凡则负责高处狙击亡灵并联系左锋。左锋先以风之翼飞过街道吸走一批亡灵，莫凡确认亡灵暂时疏散后示意穆白下令，人群被后方推挤着冲出楼房，正式进入死街。

**关键事件**：1. 七百人和约九十名法师聚集完成 2. 撤离队伍按孩子在内、法师在外的方式重新编排 3. 左锋引开亡灵后，七百人开始冲过死街

**逐章写法公式**：

- **情绪流向**：起：紧张集结 → 承：分配风险 → 转：援军先手 → 合：人潮冲入死街
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 20% / 悬念留白 25%
- **本章结构公式**：统计人数（放大规模） + 重排队伍（明确牺牲位置） + 高处分工（建立指挥关系） + 左锋引怪（制造窗口） + 人潮冲锋（进入高潮）
- **本章核心技巧**：把群体逃生写成一组明确的站位和时机决策，让抽象的死亡率落到外围与内圈的具体位置上。
- **卡点与伏笔**：结尾卡点：七百人已经进入亡灵密集的死街；埋设/回收伏笔：左锋以风之翼引怪 → 后续与肉丘尸臣交战时继续争取时间。
