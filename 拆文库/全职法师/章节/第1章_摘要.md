# 第1章 世界大变

**概要**：科学世界的水南中学里，学渣莫凡数学考六分被当堂念出，遭全班与优等生穆白嘲笑。放学后他到后山茅屋取已故守卫嬴老头的遗物——一枚内部有八个巢孔的黑不溜秋戒指，戴上后入睡。当晚学校所在的南山被时空空洞漩涡吞没半边山，漩涡中心正是后山茅屋，熟睡的莫凡坠入平行魔法位面。次日世界已变：早餐摊七叔叮嘱他备考魔法考核，胡段长当众施展风轨·疾行几秒消失在校门，数学课变成讲星子星轨的魔法课，语文老师秦老师更宣称"科学在这里是不存在的"。莫凡想起嬴老头的魔法位面遗言，逐渐接受新世界；目睹银白风袍男子施展高阶魔法风翼飞过天空后内心彻底被点燃，拒绝父亲莫家兴安排的跑业务工作，坚持要学魔法、争取魔法高中的觉醒机会，并自找天澜魔法高中图书馆临时工恶补知识，莫家兴应承想办法。

**关键事件**：1.莫凡戴上嬴老头遗留的黑戒指在后山茅屋入睡，当夜时空漩涡吞没半边山，他坠入魔法位面 2.莫凡接连遭遇风轨、魔法课本、黑魔法课等冲击，确认世界已变成魔法世界 3.目睹高阶魔法风翼飞行后立志学魔法，拒绝父亲安排的跑业务路子，进天澜魔法高中图书馆打杂备考

**逐章写法公式**：

- **情绪流向**：起：日常被嘲的憋屈 → 承：位面巨变的错愕慌乱 → 转：风翼点燃的热血 → 合：立志学魔法的期待
- **节奏配比**：慢铺垫 45% / 快冲突 10% / 爽点爆发 5% / 悬念留白 40%
- **本章结构公式**：学渣日常（立人设）+ 遗物入睡（埋引信）+ 位面巨变（换世界）+ 日常连环冲击（验新世界）+ 风翼立志（立目标）+ 父子谈判（定路径）
- **本章核心技巧**：把世界观说明书拆进"早餐摊—课堂—街头"三个日常场景，用主角的错愕反应层代替设定灌输
- **卡点与伏笔**：结尾卡点：悬念型——学渣莫凡如何考上魔法高中获得觉醒；埋设/回收伏笔：黑戒指（八个巢孔，后文作黑色坠子出现）→位面穿越与后续觉醒异变的源头；嬴老头"魔法位面"遗言→世界观钥匙；图书馆临时工→后续校园线与恶补知识的入口
