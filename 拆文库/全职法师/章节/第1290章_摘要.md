# 第1290章 狼群VS山人族

**概要**：莫凡大喊冲，用意念之波撞飞堵在前面的几十只山人开出通路，众人沿粗大树根狂奔。古铜牙山人像指挥官般啼叫指挥，莫凡一路撞飞山人但精神修为有限，同时凝炼的七缕意念波渐渐应付不来，便召唤出飞川皑狼开路。飞川皑狼速度如残影扫出大片血雾，却被一百多只山人团团围住，山人围成怪异怪圈协同作战、手舞足蹈干扰判断，让飞川皑狼每次攻击都扑空，连莫凡的霹雳也被提前避让，两人都被戏耍。灵灵点出「鱼群效应」——山人如鱼群般协同聚散、以同伴移动为参考，视觉错觉干扰判断，建议用大面积火系或召唤兽潮打乱节奏。莫凡开启召唤之门放出白色巨狼兽潮，飞川皑狼长吼一声整顿纪律，白狼群如白色坦克车队横冲直撞冲散山人的协同阵型，冲开三四百米道路。众人狂奔撤退，莫凡用重力空间拖慢追兵，古铜牙山人率一百多只近三米的精英山人亲自跳来拦截，飞川皑狼仰头狂吼率白狼群迎击。

**关键事件**：1.莫凡意念开路，众人沿树根狂奔 2.飞川皑狼被山人怪圈戏耍扑空 3.灵灵点破鱼群效应与视觉错觉 4.莫凡开启召唤之门放白狼兽潮，飞川皑狼整顿纪律冲散阵型 5.古铜牙山人亲率精英山人拦截，狼群迎击

**逐章写法公式**：

- **情绪流向**：起：意念开路突围的急迫 → 承：飞川皑狼与莫凡被戏耍的憋屈 → 转：灵灵点破鱼群效应、兽潮破阵的爽 → 合：古铜牙山人亲率精英拦截的紧张
- **节奏配比**：慢铺垫 20% / 快冲突 45% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：意念开路冲出重围（行动） + 飞川皑狼被鱼群战术戏耍（冲突） + 灵灵解析机制并破阵（转机） + 兽潮冲散阵型、强敌亲自下场（爆发+钩子）
- **本章核心技巧**：先让主角方最强的武力失效（打不中），再用智囊解析敌人战术原理，把「破解」写成知识碾压，最后用更高位阶敌人拦截保住持续压力
- **卡点与伏笔**：结尾卡点：古铜牙山人率精英山人亲自拦截，狼群与山人族正面决战 → 下章期待决战结果；埋设/回收伏笔：小炎姬沉睡中 → 火系短板延续；兽潮持续时间有限 → 时间压力
