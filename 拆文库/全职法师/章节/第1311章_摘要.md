# 第1311章 欺人太甚的世家

**概要**：东海魔法协会总部立于闽江口鼓浪屿，直属亚洲迪拜魔法协会，世家的年度比斗在此进行以定资源归属。飞鸟市北面出现大碎晶矿，凡雪山因领土相邻被唤来商议，却在比斗中连败。大黎世家的黎灵以水浪一招击败凡雪山的田庭步，扬言小门族没资格与世家同席。穆宁雪欲亲自应战被穆临生拦下，南荣倪则卸下面具，以劝慰口吻讥讽凡雪山难成气候。主持会议的东海魔法协会长老林泽宣布凡雪山输了、对大碎晶矿不必有幻想，穆临生援引矿脉归属规定据理力争，林泽以东海方式裁定、门族无争夺权等四点反驳，众世家掌事纷纷附和欲多分一杯羹。穆临生怒斥世家联手欺凡雪山无人，南荣倪掩嘴嘲笑他只会撒脾气。正当凡雪山被群起攻之时，一个平淡如水的声音说"我来会会他"，穆宁雪意外发现出声的是本欲挑战自己的芍雨，芍雨表示暂算凡雪山之人，比试若输便加入凡雪山。

**关键事件**：1.黎灵一招击败田庭步，凡雪山在世家比斗中连败 2.长老林泽与穆临生就碎晶矿归属激烈交锋，裁定凡雪山无份 3.看不过眼的芍雨出声应战，赌上败则加入凡雪山

**逐章写法公式**：

- **情绪流向**：起：世家比斗的规矩与热闹 → 承：凡雪山连败受辱、据理力争被压 → 转：群起攻之的绝境 → 合：芍雨意外应战的转机
- **节奏配比**：慢铺垫 25% / 快冲突 40% / 爽点爆发 0% / 悬念留白 35%
- **本章结构公式**：旁观众人交代规则与资源（铺背景） + 斗场连败与言语羞辱（受压迫） + 争矿被逐条驳回（加压） + 芍雨挺身应战（反转钩子）
- **本章核心技巧**：先借路人铺陈"拳头决定资源"的残酷规则，再让主角势力在规则内被层层打压，最后以规则外变数破局
- **卡点与伏笔**：结尾卡点：悬念型——芍雨应战，赌注是败则加入凡雪山，下章期待这场比斗如何改变局势；埋设/回收伏笔：穆宁雪与穆氏世族为敌 → 所有世家轻视凡雪山的原因；柳茹身份尴尬不能参与正规比斗 → 埋伏凡雪山底牌；芍雨本欲挑战穆宁雪 → 从对手变援手
