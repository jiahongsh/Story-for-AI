# 第27章 陷害考核

**概要**：莫凡星感石上的光芒持续增强，围观学生惊呼这绝对有B，学渣逆袭的议论炸开；同为火系的黄飞峰快哭了，班主任薛木生更是狂喜——这位他只求别拖后腿的大佛竟高于B-的平均分。穆白傻眼，穆贺压低声音追问暗石是否放下，穆白坚称绝对放了，两人想不通中了暗石的莫凡为何不降反升。穆卓云只以"不出所料的平凡"评价莫凡，欲带众人去下一个班级，面对穆贺的再三相求只回一句"过年给他们家多分一些，以示鼓励"，令志在核心培养名额的穆白彻底心死。此时唐月突然出声质疑这光芒不对，称老师虽无权质疑判定、但有权质疑考核意外并检查测试设备，薛木生和校领导纷纷暗示她别在校董面前生事，穆卓云反倒起了兴趣。唐月闭眼感应后直奔星感石，宣布星感石有问题、这场考核必须重来；穆贺厉声喝斥她目无考场纪律也未能吓退。天澜校长正气凛然命考官检查，三位考官从星感石处发现那颗暗石，另一考官惊讶此前每轮都检查过不该有此物——负责穆白考后检查的秃顶考官想到考试包庇陷害是大罪，当场吓到失禁般恐慌。

**关键事件**：1.莫凡逆袭成绩逼近B震动全场 2.穆卓云轻慢离场、打发穆白 3.唐月顶住喝斥查出暗石

**逐章写法公式**：

- **情绪流向**：起：逆袭余波的众生反应 → 承：阴谋者慌乱、穆卓云轻慢离场 → 转：唐月突声质疑、顶住喝斥 → 合：暗石现形、秃顶考官恐慌
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：余波反应（放大逆袭）+ 阴谋者内视角慌乱（自曝）+ 权威轻慢（蓄压）+ 唐月破局（释放）
- **本章核心技巧**：让反派一路"差点蒙混过关"，再由无权势的新老师以制度条款强行破局，制造以弱抗强的双重爽感。
- **卡点与伏笔**：结尾卡点：悬念型，暗石被发现，穆贺穆白如何脱身、莫凡成绩作废与否留待下章；埋设/回收伏笔：回收上一章暗石计划；唐月的感应能力 → 其深不可测修为的长线伏笔。
