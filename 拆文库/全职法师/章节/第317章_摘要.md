# 第317章 星之座，高阶魔法！

**概要**：陆年认出南方军部的斩空，疑惑秘密为何走漏，讥他守不住博城、质疑他早知莫凡天生双系却隐瞒至今。斩空粗俗回骂，怒斥他灭了帝都魔都精英学员、是军方多年未有的败类。陆年心想事败正好无所顾忌，下令把四名学员送去喂峰穴顶端苏醒的巨蜥伪龙，驾鹰军官不敢违令。。见过伪龙的白婷婷冷汗淋漓，告知赵满延、牧奴娇那是一口吃掉伪怖魔的生物，三人宁愿摔死不做口粮。陆年又以天山裂痕下等他收尸的人戳斩空痛处，讥他是彻头彻尾的废物；斩空怒到极致反而面无表情，立下三誓：再踏天山不论她生死、以狼血与黑教廷头颅祭博城亡灵、必斩陆年不死不休。他驾风翼横穿救人，陆年构成褐色星座施展土系高阶魔法星之座石化，云团数秒化作泥灰剥落。

**关键事件**：1.陆年下令把四学员喂巨蜥伪龙 2.白婷婷道破伪龙即死神 3.陆年以天山旧事戳斩空痛处 4.斩空立三誓并横穿救人 5.陆年施展星之座石化云空

**逐章写法公式**：

- **情绪流向**：起：紧张（对峙骂阵）→ 承：恐怖（喂龙令与伪龙阴影）→ 转：压抑（天山戳心）→ 合：热血转紧张（三誓立心、石化云空）
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：骂阵互怼（立立场）+ 喂龙令（把危机推向极端）+ 旁观者恐惧（妖魔定价）+ 旧伤戳心与三誓（人物弧光）+ 星之座石化（战力钩子）
- **本章核心技巧**：反派用"递进式加码"作恶（从灭口到喂龙），正派用"旧伤+誓言"完成人物立骨，恶行与立誓互相垫高
- **卡点与伏笔**：结尾卡点：紧张型——石化之埃扩散、斩空能否挡住未揭；埋设伏笔：天山裂痕下被封的人与斩空的承诺 → 长线人物线索，博城翼苍狼与黑教廷的复仇誓言 → 后续回收，巨蜥伪龙苏醒 → 318-324章主线对手
