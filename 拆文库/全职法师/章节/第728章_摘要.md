# 第728章 冻结之岛

**概要**：三角连岛中心被穆宁雪冻结成白色冰环并不断扩散，艾江图嘱众人围绕她战斗以压制赤凌妖控水。一只五米大赤凌妖率众杀来，官鱼首当其冲周旋。 Meanwhile 莫凡赵满延身后的巨浪竟被冻结成静止冰浪，全岛化为冰霜之岛。赤凌妖转向中心，二人解放后尾随宰杀，莫凡再试空间念控抓三米赤凌妖。

**关键事件**：1.穆宁雪冰封全岛 2.五米赤凌妖率众来犯 3.巨浪被冻结二人得救 4.莫凡再试念控抓妖

**逐章写法公式**：

- **情绪流向**：起：冰封的震撼 → 承：妖来犯的加压 → 转：巨浪冻结的解围 → 合：尾随宰杀的爽感
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：穆宁雪冰封（亮威） + 五米妖来犯（加压） + 巨浪冻结解围（反转） + 尾随宰杀试念控（推进）
- **本章核心技巧**：用自然物候（鸟、浪、岛）的冻结画面替代直接夸赞，外化角色实力
- **卡点与伏笔**：结尾卡点：莫凡念控只抓得动猴子；埋设/回收伏笔：冰封海域→赤凌妖战力大减
