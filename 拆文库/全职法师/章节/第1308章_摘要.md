# 第1308章 换血命虎

**概要**：穆宁雪呼唤六翼风之羽在前方引路，气流助力让众人逐渐拉开与追杀大军的距离，其风系已达第三级，令一路南下本欲挑战她的芍女斗志尽失。逃入山岭地带后七彩云雀大军被甩远，统领级的四命蜥虎却穷追不舍。莫凡决意先除掉这追踪者，与穆宁雪以天诛冰锁阵配合十二倍苍雷之爪连番重创四命蜥虎，后者却突然泛出兽光换命脱胎换骨，反扑一口咬住飞川皑狼的脖子，莫凡急忙用帕特农神庙圣药救下老狼。灵灵点破四命蜥虎有四条命、换命即换血，穆宁雪改用冰侵其体内，在它欲换命的时刻冻住命血，莫凡再以暗影剑钉锁死其身，令其再也无法换命。穆宁雪断言它已死，众人踏风撤走，跑出五六百米后身后一声巨响，冰封灵柩碎散，四命蜥虎化作冰雕四分五裂。

**关键事件**：1.穆宁雪以六翼风之羽引路，众人甩开妖军、逃至山岭 2.莫凡与众人围杀追踪的统领级四命蜥虎，识破其换血命理 3.穆宁雪冰封灵柩冻住命血，四命蜥虎被冻成冰雕四分五裂

**逐章写法公式**：

- **情绪流向**：起：脱险喘息 → 承：追踪者逼压、围杀受挫 → 转：换命真凶揭示、针对性反击 → 合：断言死亡、尸体碎裂的爽快收束
- **节奏配比**：慢铺垫 15% / 快冲突 60% / 爽点爆发 20% / 悬念留白 5%
- **本章结构公式**：风之领路脱险（舒缓节奏） + 四命蜥虎追踪逼战（引出目标） + 换命机制揭穿（反转破解） + 冰封冻血歼灭（兑现爽点）
- **本章核心技巧**：先用两次"打伤—莫名复原"制造压迫，再用角色之口点破机制，最后以针对机制的攻击一次性解决
- **卡点与伏笔**：结尾卡点：解决型——四命蜥虎化作冰雕四分五裂，众人脱身，但七彩云雀大军与钢铁妖猕即将抵达；埋设/回收伏笔：四命蜥虎换命即换血的特性 → 穆宁雪以冰封命血破解；心夏送的一麻袋帕特农神庙圣药 → 关键时刻救飞川皑狼
