# 第566章 护送村民

**概要**：华村上百人只有三十多人愿意离开，且以年轻人居多，老奶奶临走前念叨离村是背弃祖宗，又劝回几个顽固者。梦婀带着两名随从对护送毫无兴趣，早早道别离开。队伍启程后一个白天走得安稳，入夜后不远处传来亡灵饥荒般的叫声，莫凡安排柳茹殿后保护小孩。一行人走出约一公里，亡灵对这群活人毫无反应，说明灰蒜与井水庇佑都没有失效，村民们这才松一口气。苏小洛疑惑庇佑没问题那天为何遭大量亡灵攻击，洪俊猜测是变种亡灵，谢桑坚持到古都才算真安全，莫凡则隐约觉得这位最守祖宗规矩的村长有所隐瞒。一夜安稳后继续赶路，矮男小声对莫凡说他知道点事，是与认识方幼苗之前有关的事。

**关键事件**：1.三十余人启程迁往古都，梦婀带随从提前道别 2.入夜亡灵对队伍毫无反应，灰蒜与井水庇佑似乎有效 3.谢桑特意绕开羊阳村被莫凡察觉有隐瞒，矮男欲说出早年旧事

**逐章写法公式**：

- **情绪流向**：起：凝重（启程护送） → 承：怀疑（庇佑失效的疑问） → 转：松一口气（亡灵无反应） → 合：悬念（矮男未说完的话）
- **节奏配比**：慢铺垫 60% / 快冲突 0% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：启程护送（交代任务） + 绕路疑点（埋雷） + 夜行验证（提心吊胆） + 矮男密语（钩子）
- **本章核心技巧**：用「平安无事」写「有事要发生」，把危机压在对话与细节里
- **卡点与伏笔**：结尾卡点：矮男话说到一半，下章期待旧事真相与路上的变故；埋设/回收伏笔：羊阳村、勘测队失踪、谢桑的隐瞒
