# 第37章 野外历练

**概要**：唐月在教学楼天台告诉莫凡，本季度修炼结束后将带学生出城进行为期两个月的野外历练、见识真正的妖魔，并叮嘱他遇事冷静、思考怎么活下去，说完整个人融入黑暗中彻底消失；莫凡由此推断她至少是中阶魔法师，动了抱紧这条粗大腿的心思。历练消息传遍全校，从未见过真妖魔的学生们既兴奋又害怕。凭借小泥鳅戒，莫凡已把雷系、火系星尘修炼到当初五六倍的程度，火滋约3秒、雷印近4秒的释放速度远超同学的5到10秒。尖子班百人分成五组，由罗云波、潘丽君两名教官领队乘巴士前往雪峰山驿站；张建国与罗云波先后警告，驿站即安全区域边界，之外便是妖魔可能出没之地，走出去只剩一堆骸骨。

**关键事件**：1.唐月夜谈预告两个月野外历练，叮嘱以活下去为先 2.莫凡目睹唐月遁入黑暗消失，推断她至少是中阶魔法师 3.莫凡修炼速度远超同学，随尖子班分五组出发前往雪峰山驿站，教官警告驿站之外即妖魔出没地

**逐章写法公式**：

- **情绪流向**：起：夜谈轻松带悬念 → 承：全校议论的期待与不安 → 转：修炼成果确认的小爽 → 合：出发上路、边界警告压上阴影
- **节奏配比**：慢铺垫 60% / 快冲突 5% / 爽点爆发 15% / 悬念留白 20%
- **本章结构公式**：唐月夜谈预告（立悬念）+ 全校议论（铺氛围）+ 修炼进度对比（立爽点）+ 分组出发与边界警告（推进并埋危机）
- **本章核心技巧**：借老师与教官两个权威之口反复前置危机信息，让平静的出发行程自带阴影
- **卡点与伏笔**：结尾卡点：警告型——驿站之外皆是妖魔出没地，下章期待驿站真容与历练安排；埋设伏笔：唐月遁影之术与至少中阶的修为 → 长线人物底牌
