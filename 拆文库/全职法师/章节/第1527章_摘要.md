# 第1527章 溃灼邪眼

**概要**：莫凡一行绕开战区，穿过戈壁大峡谷抵达落日长坡上的落日神殿区域，查德发现银蛇斗士巡逻队并提出用黄昏魔鼠引开它们。众人依计穿过巡逻地带后在破败古殿中躲藏，等待凌晨。本茨率先后背溃烂，随后娑法、赵满延、莫凡等人都出现同样的溃烂症状，众人怀疑是传闻中靠近神殿三公里会溃烂的诅咒。莫凡依据猎人女郎安娜以信鹰送来的情报与月光异常的细节推理，断定是泥塔上一颗发幽光的邪眼在作祟，便带上海蒂与娑法潜近泥塔，认出那是古籍记载的"溃灼邪眼"，一种由古老神兽器官制成的光之结界，能散放死光毒光致人溃烂，先前死于神殿的猎人正是被它所杀。

**关键事件**：1.查德提议用黄昏魔鼠引开银蛇斗士，队伍潜入落日神殿遗址 2.全队身体莫名溃烂，怀疑中了神殿诅咒 3.莫凡识破溃灼邪眼，锁定泥塔上发幽光的眼珠为源头

**逐章写法公式**：

- **情绪流向**：起：谨慎潜入敌后 → 承：巡逻与溃烂蔓延的不安 → 转：识破邪眼源头的警醒 → 合：夜探泥塔的决定
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 15% / 悬念留白 25%
- **本章结构公式**：潜入神殿（隐蔽行踪） + 全员溃烂（制造恐慌） + 月光推理（揭开成因） + 夜探泥塔（锁定目标）
- **本章核心技巧**：用"全体同步染病"的感官压迫把环境威胁具象化，再以推理链逐一排除疑点收束到单一真相
- **卡点与伏笔**：结尾卡点：溃灼邪眼被锁定为元凶，莫凡带人逼近泥塔，下章期待破除结界；埋设/回收伏笔：猎人口传的三公里诅咒 → 实为溃灼邪眼结界
