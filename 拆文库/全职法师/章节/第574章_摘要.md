# 第574章 就你会用刺？

**概要**：狞骨魔将撞碎岩障后从众人之间横冲直撞而过，肩部粗壮如角的长骨脱离身体化作骨刺飞射，一根像长矛一样穿过绒帽女孩的手臂把她钉在地上。穆白跳到她面前，用泛寒霜的手抓住骨刺，冰力沿骨刺蔓延冻住骸骨与伤口，掐碎两端只留贯穿的一截止住伤势。他回头以三条冰锁捆缚狞骨魔将，被它暴虐崩断；蒋黎的黑色风盘也被它张开双臂拍散。烈拳地煞、霹雳轰顶、魔藤束缚、冰锁碾骨接连轰上去，狞骨魔将白骨依旧坚硬如钢，领队判断众人魔法威力不足以伤它，决定后撤另想办法。狞骨魔将倒拔尖刺化作骨矛掷向周敏，莫凡从影子中浮起挡在她面前，推出冥离盾扎在土地挡住骨矛，矛尖几乎顶到他面门。冥离盾受冲击触发反击，飞出一柄深蓝尖刺正好钉进狞骨魔将左眼，它却毫不在意，拔都不拔直接冲向莫凡。

**关键事件**：1.狞骨魔将骨刺钉穿绒帽女孩手臂，穆白冻刺救她 2.群轰无效后狞骨魔将掷骨矛袭周敏，莫凡冥离盾挡下并触发反击刺瞎其左眼 3.狞骨魔将毫不在意地冲向莫凡

**逐章写法公式**：

- **情绪流向**：起：混乱（骨刺伤人） → 承：焦灼（群轰无效） → 转：惊险（骨矛掷周敏） → 合：爽快（冥离刺破眼）
- **节奏配比**：慢铺垫 20% / 快冲突 60% / 爽点爆发 20% / 悬念留白 0%
- **本章结构公式**：骨刺袭人（危机） + 群攻无效（压力） + 遁影挡矛（救援） + 冥离反击（破局）
- **本章核心技巧**：用无效攻击清单垫高单点破防的爽感，让每一次失败都在给胜利蓄势
- **卡点与伏笔**：结尾卡点：瞎一眼的狞骨魔将冲向莫凡，下章期待玄蛇魔铠硬接；埋设/回收伏笔：冥离盾反击特性
