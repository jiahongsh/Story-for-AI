# 第1328章 黑暗脸谱

**概要**：冯州龙质疑让莫凡独自面对卑匠是否妥当，灵灵解释若超阶法师在附近，卑匠会察觉是陷阱而不现身，计划便徒劳，她只能坐在冷青病床边等待，比谁都担心却什么都做不了。莫凡独自走到城郊空旷荒地，看着掌上只剩两瓣的黑暗之花，焦躁渐生，深知要在这点时间内击败连超阶法师都留不住的卑匠无比渺茫。公路分道线中央，卑匠的身影豁然出现，笑着提起被他害死的胖男孩，并点破他看穿了一切：他知道冷青只剩十五分钟，本可等她死后再现身取莫凡性命，却嫌乏味决定给这个简陋的计划一点机会，还放话取莫凡的命只需五分钟。卑匠融入黑暗，化作一张巨大的诡笑脸谱扑向莫凡，窜入脑海的笑声干扰精神、放大他对灵灵的牵挂与悲伤。莫凡腹背受敌时胸前专注之坠发出星辰蓝华光，荡出涟漪解除精神恐惧，黑暗脸谱消失。战斗才刚开始，保命的精神魔具便已用掉，莫凡不知该如何撑过接下来的攻势，更不知如何在十五分钟内击垮对方。

**关键事件**：1.灵灵解释莫凡必须独自诱敌的原因 2.卑匠现身点破陷阱，宣告冷青只剩十五分钟 3.卑匠以黑暗脸谱攻击莫凡精神，莫凡被迫动用专注之坠

**逐章写法公式**：

- **情绪流向**：起：等待与诱敌的沉重 → 承：卑匠现身看穿陷阱 → 转：黑暗脸谱的精神碾压 → 合：底牌用尽、时限逼近的困局
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：灵灵等待交代处境（铺压力） + 卑匠点破陷阱亮倒计时（立规则） + 黑暗脸谱精神攻击（施压） + 专注之坠用尽的困局（留悬念）
- **本章核心技巧**：把"倒计时+底牌消耗"双轨并行，让主角每一步都被动，压迫感随章节推进逐级加码
- **卡点与伏笔**：结尾卡点：悬念型——底牌已用的莫凡如何在十五分钟内击败连超阶都留不住的卑匠；埋设/回收伏笔：只剩两瓣的黑暗之花 → 冷青生命的可视化倒计时；专注之坠的星辰蓝涟漪 → 对抗精神系攻击的保命道具；卑匠对莫凡的兴趣 → 冷爵上头的授意
