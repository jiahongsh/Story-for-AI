# 第860章 木乃伊弱点

**概要**：穆宁雪凌空踱步避过死刀横扫，众人彻底信服其国府实力。她飘落中继续凝冰锁，借冰之领域让中阶魔法信手拈来，幻化四条冰锁缠住死刀木乃伊双臂，冰蔓在裹尸布上凝霜、寒意冻入肌肉。穆宁雪看透冰系克尸骨——只需冻关节便废其发力，且越持久越强，死刀木乃伊急得眼露慌乱。白东威也看破死刀木乃伊的巨大破绽：它硕壮肥肥、迈步吃力、蛮力全在双手与那柄刀，避开刀斩便不可怕。赛义德烦躁令再斩，死刀木乃伊双手将旋转的大刀连风漩朝穆宁雪掷去。

**关键事件**：1.穆宁雪凌空避刀获信服，飘落凝冰锁 2.四条冰锁缠死刀臂，冰蔓冻肌 3.白东威看破死刀破绽：站桩机器 4.赛义德烦躁，死刀掷出风漩大刀

**逐章写法公式**：

- **情绪流向**：起：凌空避刀获信服 → 承：冰锁缠臂冻肌 → 转：白东威看破站桩破绽 → 合：死刀掷刀留钩
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 25% / 悬念留白 15%
- **本章结构公式**：信服落定（爽） + 冰锁冻肌（压制） + 看破破绽（智） + 掷刀钩子（危）
- **本章核心技巧**：用"主角压制+配角点破"双线，既爽又让读者看懂赢在哪
- **卡点与伏笔**：结尾卡点：死刀木乃伊掷出风漩大刀，下章期待穆宁雪如何挡；埋设/回收伏笔：冰之领域持续侵蚀 → 死刀终将被冻死的伏笔
