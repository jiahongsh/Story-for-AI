# 第751章 水下之影

**概要**：游轮化作快艇后航程仍显漫长，莫凡催赵满延带自己飞上高空查看前方有无岛屿，二人晴空万里中越飞越高却仍不见陆地，莫凡于海平线望见一条黑色海岸线，判其过长绝非岛屿；赵满延俯望航线时却发现蓝色海面上有一片黑色，莫凡俯视才知那并非海水变黑，而是与白色游轮重叠的一团黑影，其体积远超三十多米长的游轮，抬头确认晴空无云后断定是水下巨影，顿时惊叫着令赵满延俯冲，心脏狂跳不敢置信，而游轮上的同伴对此浑然不知仍向前行驶。

**关键事件**：1.莫凡赵满延飞空探路见海岸线 2.发现水下巨影远超游轮 3.莫凡惊叫俯冲，船上人未知

**逐章写法公式**：

- **情绪流向**：起：飞空探路的轻松 → 承：渐次发现异象加压 → 转：确认水下巨影惊叫 → 合：船上无知留悬
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：飞空看岛（铺垫） + 黑斑渐显（加压） + 体量确认巨影（爆发） + 俯冲留悬（钩子）
- **本章核心技巧**：用双视角接力（赵满延发现→莫凡确认）做延迟揭示，体量对比收束惊悚
- **卡点与伏笔**：结尾卡点：水下巨影压顶、船上人未知（强悬念）；埋设/回收伏笔：水下巨影 → 下章揭示未知生物
