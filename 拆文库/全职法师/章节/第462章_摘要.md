# 第462章 沙惘河

**概要**：一队年轻猎法师追到现场，指责莫凡等人抢走了他们合力打伤的沙啸虎，黑黄皮肤的女法师尖声要人，赵满延、莫凡回嘴调侃，对方队长出面要求查验尸骸五五分账，莫凡谈钱一毛不让。灵灵不动声色亮出猎人大师勋章，猎者联盟规定低级猎人不得与前辈争抢猎物，对方当场噎住，灰溜溜离去。众人继续前行，戈壁一带沙啸虎渐多，张小侯以身引开成群虎群护队伍通行，终抵达沙惘河——一条干涸不知多少年、最窄处也有十来公里、如土色长龙横卧敦煌的高原流脉。

**关键事件**：1.猎法师队伍索要沙啸虎被灵灵勋章镇退 2.张小侯引开成群沙啸虎保队伍通行 3.队伍抵达沙惘河

**逐章写法公式**：

- **情绪流向**：起：被指抢猎物的憋屈 → 承：唇枪舌剑与分成僵局 → 转：勋章亮出反杀 → 合：穿过戈壁抵达沙惘河
- **节奏配比**：慢铺垫 45% / 快冲突 30% / 爽点爆发 15% / 悬念留白 10%
- **本章结构公式**：对方索赔（立冲突） + 双方对峙（加压） + 勋章碾压（反转） + 行军抵达沙惘河（转场）
- **本章核心技巧**：用身份勋章做降维打击，冲突全程不动手，靠规则与反应写爽感
- **卡点与伏笔**：结尾卡点：环境预告型，沙惘河如土色长龙横卧敦煌，下章期待过河之法；埋设/回收伏笔：沙惘河象沙妖兵 → 上章调查结论的具象化；猎人勋章等级 → 灵灵猎人大师身份的长期资源
