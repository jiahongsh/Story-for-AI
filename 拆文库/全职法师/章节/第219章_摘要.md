# 第219章 设下陷阱！

**概要**：莫凡判断黑教廷越没动静蓄谋越久，最完美的下手时机正是无法取消的主校区考核。他致电军方的张小侯，借其战友之力于当天下午拿到暗影妖兽资料，得知被驯化的暗影妖兽嗜食牛肉、尾巴毛发易脱落且有荧光效果。莫凡以高级猎人身份请警局整理牛肉失窃报案，锁定浦东新区靠近港口的万街，连查二十多家牛肉仓库后找到快成粉末的荧光尾毛，判断妖兽停留短暂、线索中断；他前脚离开，沈明笑、罗宋一队人便借猎者联盟关系追查到同一仓库。此时警局女文案来电称许江岸一家老肉厂大量牛肉失窃，莫凡赶赴途中，读者视角揭开女文案实则已被戴半块面具的男子用黑畜妖挟持威胁封口——他没杀她只为不被审判会追踪，自从脸被毁后，他会把每个被自己杀掉的人想象成莫凡的样子。

**关键事件**：1.张小侯提供暗影妖兽嗜牛肉、荧光尾毛的资料 2.莫凡循失窃案锁定浦东万街后线索中断 3.女文案被面具男挟持，伪造线报引莫凡赶往许江岸

**逐章写法公式**：

- **情绪流向**：起：黑教廷阴云的警觉 → 承：友情报料的暖意与侦查推进 → 转：线索中断的焦灼 → 合：线报传来的杀机
- **节奏配比**：慢铺垫 40 / 快冲突 10 / 爽点爆发 5 / 悬念留白 45
- **本章结构公式**：敌情推演立预警（定调）+ 借力取证（推主线）+ 循迹查仓库扑空（挫一下）+ 线报与胁迫双线收口（下钩子）
- **本章核心技巧**：把陷阱信息拆成主角侧的顺藤摸瓜与反派侧的胁迫布局，双线在章末对位剪接成信息差
- **卡点与伏笔**：结尾卡点：危机——假线报引莫凡孤身赴许江岸，面具男杀意已被克制；埋设/回收伏笔：荧光尾毛与牛肉癖好 → 侦查规则设定；面具男毁容忌讳 → 宇昂身份线；沈明笑扬言夺兽 → 后文争抢冲突线
