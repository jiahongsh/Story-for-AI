# 第55章 城市猎妖队

**概要**：莫凡确认雷系在猎者行业吃香后，为不暴露天生双系，用黑色蜡笔把脸涂黑、穿上灰色长款斗篷卫衣乔装，前往城市猎妖队应聘。招聘台后，裹着纱布的魁梧队长对排队人群满是嫌弃，队员们议定凑合选个火系阿诚，此时招聘女孩慌张来报有一位雷法师申请加入，队长眼睛放光直接走出后台，问莫凡是不是雷法师。莫凡缓缓扬手，一道电弧从指缝穿过落在桌前，把桌布电焦一个小洞，队长当场朝长龙嗷一嗓子宣布招到人了；队伍抗议走后门，队长放话谁要是雷系也破格录取，众人一听雷系全蔫了散去。队长徐大荒介绍队员：水系小可、风系黎文杰、土系肥石，莫凡自称梵墨。副队长郭彩棠出言警告这菜鸟连妖魔都没见过、别仗着雷系了不起；莫凡认出她与穆氏沾亲带故，暗叹到哪都遇到穆氏的人，要早点考上大学离开博城。

**关键事件**：1.莫凡乔装化名梵墨应聘城市猎妖队 2.一道电弧令队长当场解散长龙破格录取 3.莫凡认出副队长郭彩棠是穆氏亲故

**逐章写法公式**：

- **情绪流向**：起：乔装赴聘的窃喜 → 承：队内嫌弃候选人的敷衍 → 转：雷法师来投的瞬间变脸 → 合：穆氏阴霾的一丝不快
- **节奏配比**：慢铺垫 35% / 快冲突 30% / 爽点爆发 25% / 悬念留白 10%
- **本章结构公式**：乔装赴聘（伪装建立）+ 队内议人（垫低期望）+ 电弧破格（爽点引爆）+ 彩棠警告（埋人际刺）
- **本章核心技巧**：先把招聘现场写成敷衍的职场，再让“雷系”两个字瞬间掀桌，用前后态度落差捧主角
- **卡点与伏笔**：结尾卡点：副队长是穆氏亲故，队内关系存变数；埋设/回收伏笔：化名梵墨 → 双重身份随时可能穿帮；郭彩棠与穆氏的关系 → 与穆氏冲突长线
