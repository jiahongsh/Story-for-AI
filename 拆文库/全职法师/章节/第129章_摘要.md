# 第129章 诅咒系

**概要**：猎法师退走后，东方家一名随员觊觎灵种，东方骏不容抗拒地宣布"这东西归我、自会给你们别的好处"，无人敢与能和宗门高层同桌吃饭的嫡系子弟相争。此时帽男现身，声音阴冷："这东西归我，我心情好的话可以让你们死得稍微痛快一点。"他摘下棒球帽，露出额头被烙铁烙过的死刑印记——正是通缉杀人魔朝赫，还称同宗女孩东方青儿"吃起来蛮有味道"，四人起满鸡皮疙瘩。朝赫自称比众人先到，早已布下修炼到第三级的诅咒系中阶魔法"邪蛛之阱"：落网者闭眼施法便会在精神世界遭遇邪恶狂蛛的亡魂，根本无法把控星子，只能被一点点抽走灵魂精气。唐月本想等朝赫对付东方家时雷霆出手，却因这张早布之网慢了一步；她主修火系次修暗系、雷系也无用——诅咒系技能提前释放，就算杀掉释放者诅咒依然持续蚕食，四人从踏入未察觉那刻起性命已不属于自己。她只能等朝赫收获灵种放松警惕时再出手。

**关键事件**：1.朝赫现身自曝死刑烙印与食人恶行 2.朝赫邪蛛之阱瞬间控住东方世家四人 3.唐月解析诅咒无解、只能隐忍等待时机

**逐章写法公式**：

- **情绪流向**：起：分赃的暗流 → 承：朝赫现身的阴冷 → 转：邪阱罩落的绝望 → 合：隐忍待机的凝重
- **节奏配比**：慢铺垫 35% / 快冲突 35% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：东方家内部分赃（内患）+ 朝赫摘帽摊牌（外敌）+ 邪蛛之阱一网打尽（碾压）+ 唐月判无解并定策（蓄力）
- **本章核心技巧**：让刚打完硬仗的胜者被第三方一招全收，用战力落差瞬间抬高真正反派的恐怖段位
- **卡点与伏笔**：结尾卡点：唐月只能等朝赫收灵种松懈时一击必杀，成败悬于一线；埋设/回收伏笔：朝赫死刑烙印（审判会通缉线）、东方青儿被吃（东方世家复仇线）、诅咒系提前释放的规则（后文唐月中招前置）、邪蛛之阱第三级（精神攻击设定）
