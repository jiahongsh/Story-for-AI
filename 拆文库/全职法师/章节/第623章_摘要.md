# 第623章 灾难一吻

**概要**：疾星狼带着熟睡的莫凡穿过尚未被肉丘尸臣占据的区域，抵达一片老居民区。莫凡醒来后，疾星狼跳进青砖巷子的一处院落，柳茹立刻从屋里出来扑进他怀中。莫凡看见柱子上绑着三个流氓，以为柳茹受欺负，柳茹解释后把他带进有火炕的屋子，并说明自己保护华村村民时受伤、损失了许多本源血液。她发现莫凡魔能耗尽，又无法抵抗由莫凡血液带来的本源血脉诱惑，于是将他按在墙边吸血亲吻。吸血结束后，柳茹暗示自己可以帮助莫凡恢复魔能。

**关键事件**：1. 莫凡被疾星狼带到柳茹所在的居民区 2. 柳茹说明保护华村村民后受伤的经历 3. 柳茹吸取莫凡血液并提出帮助他恢复魔能

**逐章写法公式**：

- **情绪流向**：起：疲惫与末日压迫 → 承：意外重逢 → 转：误会和血族饥渴 → 合：吸血结束并提出恢复方案
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 15% / 悬念留白 35%
- **本章结构公式**：循味找人（维持目标） + 屋院重逢（释放情感） + 绑匪误会（制造轻松错位） + 受伤说明（补充前情） + 吸血亲吻（关系与能力并进）
- **本章核心技巧**：把灾难背景压在亲密场景外部，用误会和身体需求调节沉重基调，并在结尾留下能力恢复钩子。
- **卡点与伏笔**：结尾卡点：柳茹表示可以帮助莫凡恢复魔能，方法尚未揭开；埋设/回收伏笔：莫凡血液是柳茹的本源血脉 → 本章吸血，并可能用于后续恢复。
