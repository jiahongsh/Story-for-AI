# 第56章 失踪少女

**概要**：入队手续办完后，肥石告诉莫凡城市猎人证件有不少特权，相当于博城的执法人员，黎文杰笑称这支“城管小队”收拾的不是违规商贩，而是夜里出来作怪的东西。徐大荒接到电话咆哮责问为何不早汇报，随即布置任务：铭文女子中学的食堂每到深夜莫名颤震，查过并无施工队，校园流传食堂成精的怪说，莫凡想到叶心夏正在该校，回忆两个月前她在电话里提过食堂好可怕。徐大荒进一步宣布有第二个女生失踪了——几个月前该校就有一名女生失踪、警方数月无果，这次真真切切在校内失踪，校方这才慌忙求助。小可问人员失踪是否该找警察，徐大荒告知有光法师找到了不属于人类的足迹；黎文杰断言事发一周才上报、那女孩死定了，郭彩棠冷哼学校一贯想掩盖坏事。莫凡心中一跳：叶心夏有整整一星期没与自己联系，往常每周必通电话。他借肥石手机拨打，听到的是“您拨打的号码已停机”，当即飞奔出猎者联盟大厅直奔小姑莫青家，肥石把手机抛给他当联络工具。

**关键事件**：1.莫凡领证件入队并接下食堂震门任务 2.第二名校内失踪女生与非人足迹曝光 3.叶心夏一周失联加停机、莫凡狂奔离队

**逐章写法公式**：

- **情绪流向**：起：入队领证的轻松嬉笑 → 承：任务布置的凝重 → 转：心夏失联的惊惶 → 合：飞奔寻人的急切
- **节奏配比**：慢铺垫 30% / 快冲突 30% / 爽点爆发 5% / 悬念留白 35%
- **本章结构公式**：领证入队（日常过渡）+ 接警布置（案件上桌）+ 失联对号（私人危机）+ 停机飞奔（行动钩子）
- **本章核心技巧**：把公共案件与主角私人牵挂逐条对表，同一信息在他眼里全部变味，案件瞬间成为必须亲赴的私事
- **卡点与伏笔**：结尾卡点：停机加一周失联，心夏是否安全悬而未决；埋设/回收伏笔：食堂震门怪谈 → 妖魔藏身处；非人足迹 → 妖魔作案实锤；第一位失踪女生旧案 → 陈年线索；肥石的手机 → 联络道具
