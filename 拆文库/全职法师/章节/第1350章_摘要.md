# 第1350章 三角次元镜

**概要**：少年向老牧民阐明埃及的海市蜃楼并非光之错乱的自然现象，而是冥神部队降临、血光冲天尸横遍野的灾难。少年又讲起信仰之力的另一半秘密——人们尊敬、忠诚、膜拜会化为信仰之力让神壮大，而人们唾弃、憎恨、厌恶也会化成恶怨之力，赐予邪恶魔灵无与伦比的邪力；世上像孔丝那样的人比其其格更多，所以邪恶神灵比善良神灵更强大。少年随即自曝身份，称他们就是邪恶神灵的信仰者，世人越厌恶教会，他们获得的力量就越强。少年与老牧民打赌，若老伯不怨恨不憎恨不厌恶他，便放弃红衣大主教身份做个好人，并自白"待人礼貌是我的修养，作恶多端却是我的本性"。老牧民问短旗袍美妇是否是少年的弟弟，美妇自称是他的小奴隶。美妇挥手摧毁其其格雕像以设立坐标，少年说老伯生气便已输了。美妇举起真正的三角次元镜——少年与撒朗从纽约神殿偷出的最重要零件，孔丝所用不过高仿。次元镜安置后射出贯穿线、纵地线与横地线，将莽莽大地分割成四块，组成冷光空间坐标，晴天午后顿成蒙蒙阴冷。

**关键事件**：1.少年揭示恶怨之力成就邪恶神灵，自曝红衣大主教身份 2.旗袍美妇摧毁其其格雕像设立坐标 3.真正的三角次元镜开启空间坐标，天地被分割

**逐章写法公式**：

- **情绪流向**：起：海市蜃楼真相与信仰之力的论证 → 承：少年自曝身份的惊骇 → 转：打赌与雕像被毁的冲突 → 合：三角次元镜画出天地坐标的震撼
- **节奏配比**：慢铺垫 45% / 快冲突 15% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：海市蜃楼定性（真相） + 信仰之力黑暗面（理论） + 自曝身份与打赌（冲突） + 次元镜真品（道具揭示） + 空间坐标成形（行动钩子）
- **本章核心技巧**：用长篇对话完成反派世界观宣讲，结尾以道具实机启动把理论变成可见的灾难征兆
- **卡点与伏笔**：结尾卡点：坐标已立——空间坐标指向何处未明，最美的时刻即将来临；埋设/回收伏笔：恶怨之力→黑教廷力量的来源设定；三角次元镜→冷爵大计划的核心道具
