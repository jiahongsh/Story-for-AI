# 第980章 新劫炎，附体！

**概要**：李雨娥恢复神智满心惊喜，莫凡断言这次绝不放裴历逃走，江昱赶来照顾她并驱散医院附近人群，司夜统治将整座医院罩入黑暗。裴历跳出窗外落于停车场，恼怒自己天衣无缝的陷阱竟被识破，疑是李雨娥提前告知。他闭目释放心灵感知，借手背信图确认方圆数公里内无一神殿法师，断定来者仅莫凡，转身迎战。莫凡化作紫黑霹雳从五楼轰下，裴历却不在意，讥其附近无神殿法师、自己曾如丧家犬。他好奇莫凡如何避开感知布下司夜，殊不知莫凡新得的暗爵斗篷被动隐匿气息，正是此物使其布阵未被觉察。裴历欲展真正冰之领域，却骇然发现十公里冰之元素早被高楼上的穆宁雪抽空，领域无法降临，仅留十分钟窗口。裴历仍以魂种冰封灵柩瞬罩莫凡，雷抑火散；冰寒侵体之际，小炎姬撞入莫凡灵魂，劫炎爆发清空冰毒，冰封灵柩融化崩裂，莫凡化身褐焰战甲，气势滔滔。

**关键事件**：1.裴历感知无神殿，断定仅莫凡来袭 2.暗爵斗篷隐蔽+穆宁雪抽冰元素，冰之领域失效十分钟 3.冰封灵柩锁莫凡，小炎姬附体劫炎破局

**逐章写法公式**：

- **情绪流向**：起：裴历觉无神殿的轻敌 → 承：斗篷+抽元素破域的智 → 转：冰柩锁身的危 → 合：劫炎破甲的热血
- **节奏配比**：慢铺垫 15% / 快冲突 40% / 爽点爆发 30% / 悬念留白 15%
- **本章结构公式**：裴历轻敌迎战（设危） + 斗篷抽元素破域（破局） + 冰柩锁身（加压） + 小炎姬劫炎破甲（爆发）
- **本章核心技巧**：用"装备隐蔽+队友抽元素"双保险废掉敌方领域，再用附体爆发做章节高潮
- **卡点与伏笔**：结尾卡点：爆发型，劫炎战甲成型，下章期待莫凡如何借势斩杀裴历；埋设/回收伏笔：暗爵斗篷 → 回收上章"暗影系宝贝"伏笔；小炎姬成长期 → 回收附体伏笔
