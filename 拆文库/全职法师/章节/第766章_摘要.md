# 第766章 不存在的岛（上）

**概要**：莫凡对天求来淡玫瑰香确认外界能借味传信，二人依"艾草不多"线索在山寺下两公里寻到宫田药园，园中创造者记忆更真切、往南小岛清晰；问得宫田在海岩后，二人见扎高马尾的宫田蹲崖以刻刀刻字，指血渗槽、边刻边泣，哭罢"为何都不信我们什么都没有"便闭眼冲崖坠亡，莫凡发现她只是虚影无法拦，艾江图认其多年前自杀、莫凡疑其化妖灵，莫凡断那非本人仅为记忆残影。二人循檀香回寺，见宫田死讯传开、山门紧闭，和尚们聚后堂，信雨称有逼迫责任欲压下、肥和尚怕损香火，奈良原空低头隐忍、脸色阴沉，忽怒指七海私会被撞反诬自己，七海称宫田编"海岩外小岛"谎言狡辩。

**关键事件**：1.寻到药园见宫田刻石坠崖的记忆残影 2.莫凡断其为残影非本人 3.回寺闻和尚议事，奈良原空怒揭七海诬陷

**逐章写法公式**：

- **情绪流向**：起：香味确认线索 → 承：药园见悲情残影 → 转：断非本人 → 合：回寺揭冤案
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：寻药园（推进） + 坠崖残影（悲情） + 断残影（揭秘） + 和尚诬陷（钩子）
- **本章核心技巧**：用"记忆残影"把悲剧演出却点破非本人，再以和尚议事揭开冤案全貌
- **卡点与伏笔**：结尾卡点：七海诬陷、小岛谎言（强悬念）；埋设/回收伏笔：海岩外小岛 → 下章揭"不存在的岛"；檀香 → 外界引路信号
