# 第1711章 藤索桥之战

**概要**：张小侯带队伍沿缠山藤木攀爬，行至断头处由凌菲用植物系魔法操控藤木架起连接两座山的四百米藤索桥。娑风夹击、光系护盾被击垮，一群羽妖发现众人四面围攻。莫凡先以念控掰山岩当炮弹，羽妖仗着娑风身法迅捷躲开，莫凡改使空间律动时滞困住羽妖，再以暴君荒雷大片秒杀，凌菲对雷系威力吃惊。羽妖割断藤端时赵满延欲亮翼魔具，被张小侯以"羽妖领空不可挑衅、会遭全族围攻"喝止，莫凡只来得及瞬移带走灵灵与阿帕丝，赵满延没赶上脚下一空坠落，凌菲大喊抓住藤索。

**关键事件**：1.凌菲架藤索桥渡壑 2.羽妖借娑风围攻藤索桥 3.莫凡时滞加荒雷秒杀羽妖 4.藤索桥被割断、赵满延坠落

**逐章写法公式**：

- **情绪流向**：起：谨慎攀爬 → 承：桥中断裂 → 转：大战羽妖 → 合：坠落悬心
- **节奏配比**：慢铺垫 35% / 快冲突 45% / 爽点爆发 15% / 悬念留白 5%
- **本章结构公式**：爬藤索桥（进入险地）+ 羽妖围攻（危机爆发）+ 莫凡雷系大杀（爽点释放）+ 桥断坠落（新危机钩子）
- **本章核心技巧**：把一场遭遇战锁死在"半空独木桥"的绝境地形里，再用新危机收尾。
- **卡点与伏笔**：结尾卡点：危机型——藤索桥被割断、赵满延脚下踏空坠落，下章期待：众人能否落回山体；埋设/回收伏笔：羽妖领空不可飞行的铁律 → 后文盛典混飞时的规则翻转
