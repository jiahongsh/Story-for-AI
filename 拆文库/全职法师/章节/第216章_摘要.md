# 第216章 东南亚人

**概要**：几名穿正装、身怀魔法气息的男子围住莫凡与艾图图，为首的高鼻梁年轻人口误说出「对我们王大不敬」又改口少主，要求艾图图去给他们少主道个歉，莫凡多管闲事免谈。艾图图怼对方武侠看多了、少主无非吃饱了撑着的二世祖。莫凡细看这几人虽有亚洲面孔，眸子和面部轮廓却更像东南亚人，艾图图也不知道对方身份。高鼻梁男子释放带红色热浪的魔法气息，其他几人也不顾街道行人，眼看要动手，鉴定师郭立语恰巧路过，笑着和莫凡打招呼称他「审判会小兄弟」；东南亚人似乎非常忌惮审判会，二话不说转身离开。艾图图借口熟人相聊天没说完就跑路。郭立语闲聊间透露前阵子见过唐月、其修为令他自叹不如，唐月托他找一种对蛇族有吸引力的玉石，还说下次莫凡觉醒再去找他用最好的材料。莫凡疑惑唐月在做什么任务要用蛇玉石。回到住处，莫凡见难得在大厅冥修的牧奴娇手腕上戴着流转特殊光泽的星云魔器镯子，光泽不逊小泥鳅坠，感叹牧家资产庞大、高手都有自己的际遇。他到阳台入定后，牧奴娇睁眼暗惊莫凡修为提升之快——雷系星云必到第二级别、召唤系恐怕也到中阶水准，暗下决心自己还需更努力。

**关键事件**：1.东南亚面孔的男子围逼艾图图道歉，因郭立语一句审判会称呼忌惮撤离 2.郭立语透露唐月托找对蛇族有吸引力的玉石 3.莫凡归家见牧奴娇的星云魔器，两人暗中较劲修炼

**逐章写法公式**：

- **情绪流向**：起：紧张（正装男子围逼）→ 承：轻松（艾图图毒舌与跑路）→ 转：悬念（审判会震退与蛇玉石）→ 合：紧张（牧奴娇暗惊较劲）
- **节奏配比**：慢铺垫 30% / 快冲突 25% / 爽点爆发 15% / 悬念留白 30%
- **本章结构公式**：围逼道歉（起冲突）+ 审判会退敌（意外解决）+ 蛇玉石情报（埋支线）+ 归家较劲（收人物暗流）
- **本章核心技巧**：街头冲突用第三方误认的身份一句话化解，把悬念从「打不打」转移到「他们是谁、怕什么」，冲突降温但好奇升温。
- **卡点与伏笔**：结尾卡点：人物暗涌（牧奴娇与莫凡修为互相紧咬，主校区考核竞争升级）；埋设/回收伏笔：对我们王的口误 → 东南亚神秘势力身份悬念；怕审判会就跑 → 偷渡或非法身份暗示；唐月托找蛇玉石 → 呼应三潭印月结界与封印白蛇传说；下次觉醒用最好材料 → 高阶觉醒远期伏笔；牧奴娇的星云魔器 → 牧家资源与考核底牌。
