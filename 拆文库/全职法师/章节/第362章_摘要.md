# 第362章 超强感知

**概要**：出发前莫凡给心夏打平安电话，得知学校出现治愈系魔法无效的怪病、已有学员被隔离。唐月将摩天蛇收入图腾珠，两人乘夜撑船离城，计划将其送往杭州安界边境白镇白山千洞中族内秘传的隐蔽洞窟。祝蒙在别墅摔杯大怒，武平景汇报盯死了图腾族骨干却漏了实力不算出众的唐月；祝蒙下令直接抓捕唐月。一直与祝蒙针锋相对的罗冕现身劝和，原来他早已与祝蒙密谋，只因唐忠起疑整夜拉他下棋才未能通风报信。罗冕点破图腾玄蛇蜕皮期感知成倍提升、方圆二十公里内的高手尽在掌握，这正是唐月避开布控的原因，并献计调实习审判员与预备审判员前去阻扰拖延，待宫廷侍卫赶到便可让唐月束手就擒。

**关键事件**：1.心夏透露学校出现怪病 2.两人带蛇连夜出城前往白山千洞 3.罗冕暴露祝蒙同谋身份并点破玄蛇超强感知 4.罗冕献计派实习审判员追击

**逐章写法公式**：

- **情绪流向**：起：紧张（平安电话里的怪病） → 承：紧张（连夜出城西逃） → 转：压抑（祝蒙摔杯、罗冕暴露同谋） → 合：紧张（实习审判员毒计出炉）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：平安电话（闲笔埋雷） + 出逃路线（目标确立） + 祝蒙震怒（反派反应层） + 罗冕献策（下一波冲突预告）
- **本章核心技巧**：主角线只做转移，全章压力由反派密谈推进，并把关键设定（超强感知）作为"唐月如何脱身"的谜底延迟揭示。
- **卡点与伏笔**：结尾卡点：阴谋预告型——实习审判员大军将出动阻扰追捕，下章期待追兵与主角的遭遇；埋设/回收伏笔：心夏口中的怪病→瘟病主线伏笔；蜕皮期超强感知→后续逃亡依赖的核心手段。
