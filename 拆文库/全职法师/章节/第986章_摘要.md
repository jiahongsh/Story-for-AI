# 第986章 溺亡血中

**概要**：莫凡与穆宁雪受命走访提诺阿亚城各处溺咒死者，先访目击过八具尸体的老伯，老伯称此为海祭献神之说，莫凡断定是封建迷信不信；又从本月三名死者家属处得知三人互不认识却都酷爱游泳、皮肤晒黑，暂无线索。二人行至摆满鲜花的窗子巷，遇一名手持啤酒的水系法师对穆宁雪吹口哨，莫凡以空间之力将其击退，对方逃入巷中。随后二人探访第七家，闻恶臭入屋，竟发现屋主正是方才那名流氓法师鲍比。鲍比打开被钉死反锁的房间，弟弟诺科手腕割开、面部浸于装满鲜血的铁盆中溺亡，死状与溺咒吻合。鲍比哭诉哥哥三个月前亦死于溺咒，家中两起溺咒。莫凡推断诺科中咒后被锁家中不得近水，遂以血完成溺咒仪式，反映精神控制，已通知灵灵保留现场追查。

**关键事件**：1.莫凡穆宁雪走访溺咒死者，老伯特说海祭传说、三人共通点为酷爱游泳 2.鲜花巷遇水系法师吹口哨骚扰穆宁雪，莫凡以空间系之力将其击退 3.第七家访查遇鲍比，开反锁房间发现弟弟诺科溺死于血盆，家中两起溺咒吻合 4.莫凡推断溺咒含精神控制并通知灵灵保留现场

- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：走访老伯取传说（铺线索） + 巷遇流氓以空间力击退（小冲突） + 第七家闻臭识屋主（反转） + 开反锁房见诺科溺血导出精神控制（高潮钩子）
