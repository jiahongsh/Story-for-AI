# 第1421章 桀火洞

**概要**：牧奴娇肚子叫，莫凡带她与小炎姬去夜市吃烤翅，牧奴娇被大哥撞见并斥其不该和"不三不四的人"混。莫凡随后盘算回国后去凡雪山（穆宁雪不在便不急），又去竞拍会找火系魂种，却发现价格被炒到近八亿且效果平平，敦煌珏火虽特殊也要十一亿。赵满延解释海岸线危机后魂种暴涨、悬赏难赚，并建议莫凡去东方世家元素圣地"桀火洞"试炼寻找合意魂种，莫凡决定去找同学东方烈。

**关键事件**：1.夜市吃烤翅，牧奴娇大哥撞见斥责 2.莫凡盘算去凡雪山（穆宁雪不在不急） 3.竞拍会魂种价高质次 4.赵满延解释行情并荐桀火洞 5.莫凡决定找东方烈

**逐章写法公式**：

- **情绪流向**：起：夜市温馨轻松 → 承：大哥偏见的小尴尬 → 转：竞拍会价高质次的现实压力 → 合：桀火洞新线索的期待
- **节奏配比**：慢铺垫 30% / 快冲突 10% / 爽点爆发 10% / 悬念留白 50%
- **本章结构公式**：夜市吃烤翅（日常温情） + 大哥撞见斥责（小冲突） + 凡雪山盘算（支线交代） + 竞拍会失望（需求受阻） + 赵满延荐桀火洞（新方向）
- **本章核心技巧**：用具体价格数字堆出资源稀缺压力，再以对话揭示新地图设定收束
- **卡点与伏笔**：结尾卡点：莫凡决定找东方烈进桀火洞，下章期待两人会面；埋设/回收伏笔：凡雪山穆宁雪不在 → 解释莫凡暂不回去；魂种需求 → 贯穿全章动机
