# 第321章 血战伪龙

**概要**：白婷婷睁眼看到的不是伪龙胃壁而是阳光蓝天——满脸血狼纹的恶魔莫凡提着皮网，沿高楼穹顶从峰穴最高处跳到地面，若非顾虑被封印灵魂的四人，他根本不需要落点。莫凡全身被灌注比血兽靴强无数倍的血脉之力，思考变得令人厌恶，杀念怒气被放大，杀戮摧毁才是迎接新身体的仪式；他脑中只有一个本能执念——除了自己，谁都不许动他们一根头发。被削顶的峰穴中，巨蜥伪龙因颈部凹陷与老窝被毁震怒咆哮、全城蜥群颤抖待命，随即滑翔而下撞塌楼房。恶魔莫凡消失原地，在伪龙阴影处显出狼魂，狼魂之影扑咬伪龙咽喉却被浑浊吐息灌得涣散，莫凡唤回狼魂，弹身以尾随雷电的爪芒撕开伪龙钢躯胸膛，雷电顺伤口钻入其肌肉。

**关键事件**：1.恶魔莫凡提四学员跳楼落地 2.莫凡体验恶魔化身体与躁动本能 3.伪龙震怒俯冲开战 4.狼魂搏杀失利被唤回 5.雷爪撕裂伪龙钢躯

**逐章写法公式**：

- **情绪流向**：起：温馨转紧张（重见阳光与提网落地）→ 承：压抑（躁动本能的内心独白）→ 转：恐怖（伪龙震怒俯冲）→ 合：热血（狼魂搏杀与雷爪破防）
- **节奏配比**：慢铺垫 30% / 快冲突 40% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：获救视角切入（余波收束）+ 身体与本能自述（立代价）+ 伪龙宣战（重开大战）+ 狼魂出战失利（先抑）+ 雷爪撕躯（后扬）
- **本章核心技巧**：用获救者的陌生眼光重新介绍恶魔化的主角，一石二鸟地完成救人收尾与变身外观描写
- **卡点与伏笔**：结尾卡点：热血型——爪芒撕开钢躯、雷电入体，伪龙反击未至；埋设伏笔：守护四人是恶魔化本能执念 → 恶魔化人格机制线索，杀念被放大 → 莫凡能否收回自己的隐患
