# 第461章 第五个级别？

**概要**：沙啸虎四肢陷入流沙仍生生跃起，狂暴跳到晨颖的岩障上，血影附身从高处猛扑张小侯，张小侯闪避不及，赵满延以光佑-圣盾硬接下这一扑，张小侯毫发无伤。张小侯继续拉仇恨，莫凡与晨颖以中阶魔法夹击，莫凡一道霹雳把沙啸虎轰回流沙，半身沉没，又补上巨影钉锁死其影子，这只战将级凶物有力无处使，终被众人制服。灵灵点破沙啸虎在软沙中发挥不出全力才这般好打。莫凡搜检尸骸，既无异骨异皮，灵魂也只是最普通的残魄，收进小泥鳅坠凝炼精魄。赵满延问他为何不把初阶魔法升到第五个级别，晨颖震惊，莫凡骂出四级升五级需七颗战将级精魄、价值一亿多的天价。灵灵催促继续向沙惘河进发。

**关键事件**：1.沙啸虎血影反扑被圣盾挡下，张小侯无碍 2.流沙加巨影钉困杀沙啸虎 3.第五级初阶魔法需七颗战将级精魄的天价揭示

- **情绪流向**：起：沙啸虎绝地反扑 → 承：圣盾救场与中阶压制 → 转：流沙巨影钉收网 → 合：战利品寒酸与升级天价，转战沙惘河
- **节奏配比**：慢铺垫 15% / 快冲突 55% / 爽点爆发 20% / 悬念留白 10%
- **本章结构公式**：反扑被挡（惊险） + 双线压制（缠斗） + 控场收割（收网） + 分赃与升级之议（转场）

- **卡点与伏笔**：结尾卡点：预告型，灵灵催促赶往此行最凶险的沙惘河，下章期待新险关；埋设/回收伏笔：血影力量与莫凡血兽靴同类 → 战力体系呼应；残魄入小泥鳅坠 → 凝炼精魄升暗影初阶的长期目标
