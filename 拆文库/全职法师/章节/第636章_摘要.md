# 第636章 浩劫将至！

**概要**：张小侯说除了黑教廷外还有人在监视华村，正因这个人存在，黑教廷才没有立刻杀他，柳茹判断那就是送血迹的人。洪俊死后，张小侯说出自己在煞渊附近听见的关键信息：黑教廷成员称一名戴面具的人为虎津大执事。方谷说明虎津是蓝衣执事首领，也是撒朗的左膀右臂；张小侯又确认自己听见的声音来自博城，且对方担心被认出。众人决定寻找穆白、周敏并通知祝蒙，方谷准备同行和自首。此时亡灵汪洋已逼近一公里，金色结界笼罩的内城成了黑海中的孤岛，浩劫正式压向城墙。

**关键事件**：1.送血者身份与监视线索合并 2.张小侯说出虎津大执事 3.确认虎津与撒朗的关系 4.确定虎津声音来自博城 5.众人决定寻找线索并赶往内城 6.亡灵汪洋逼近内城

**逐章写法公式**：

- **情绪流向**：起：自保原因确认 → 承：虎津身份揭示 → 转：博城声音线索出现 → 合：亡灵逼近，调查与逃生同步启动
- **节奏配比**：慢铺垫 25% / 快冲突 25% / 爽点爆发 10% / 悬念留白 40%
- **本章结构公式**：确认第二监视者（补足自保逻辑） + 揭出虎津大执事（明确目标） + 锁定博城声音（缩小范围） + 直面亡灵海（升级倒计时）
- **本章核心技巧**：把战斗胜利后的信息盘点迅速转为更大的调查目标，再用灾难全景把个人线索压回生死倒计时。
- **卡点与伏笔**：结尾卡点：亡灵汪洋冲向金色结界，内城能否抵挡未明；埋设/回收伏笔：神秘送血者、虎津声音、博城幸存者 → 指向潜伏者追查线。
