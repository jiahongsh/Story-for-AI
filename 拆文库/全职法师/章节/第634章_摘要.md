# 第634章 反叛者

**概要**：钢铁骷髅用骨锤杀死最后两名黑衣教士，随后继续冲向其他黑畜妖和诅咒畜妖。莫凡准备让小炎姬再次附体轰杀女执事时，洪俊突然用匕首抵住张小侯的脖子，逼莫凡收起火焰。女执事随即承认洪俊是黑教廷安插在危居村的灰衣教徒。洪俊因厌恶祖训、贫困和村民身份而投向黑教廷，谢桑则承认自己曾为洪俊偷偷取用昆井之水。张小侯突然恢复清醒，暗示自己早已看穿洪俊，莫凡和张小侯准备继续杀敌。

**关键事件**：1.钢铁骷髅杀死剩余教士 2.洪俊挟持张小侯 3.洪俊身份被揭穿 4.谢桑承认帮助洪俊取水 5.张小侯恢复伪装下的清醒

**逐章写法公式**：

- **情绪流向**：起：清场后的胜势 → 承：人质挟持强制停火 → 转：叛徒身份与欲望根源揭开 → 合：张小侯恢复清醒，火焰再次蓄势
- **节奏配比**：慢铺垫 20% / 快冲突 35% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：钢铁骷髅清场（削弱敌人） + 洪俊挟持（制造变数） + 家庭欲望回溯（解释背叛） + 张小侯反转（夺回主动）
- **本章核心技巧**：在战斗即将结束时引入人质，把外部战力冲突转成身份与选择冲突，再用伪装反转恢复爽点。
- **卡点与伏笔**：结尾卡点：张小侯恢复清醒，莫凡身上的两种火焰重新旺盛；埋设/回收伏笔：洪俊长期跟随张小侯 → 回收为黑教廷潜伏者身份。
