# 第629章 时间紧迫

**概要**：茶庄内，虎津执事斥责手下办事失误，茶庄老板说明蓝衣执事已出手，自己的胞弟也会带回最后一份昆井之水。得知莫凡出现后，虎津仍要求先处理方谷。另一边，莫凡和柳茹进入异土公园，柳茹确认张小侯等人被困在纪念碑附近，四周潜伏着七八十只黑畜妖、七只诅咒畜妖以及一名气息隐藏极好的高阶法师。两人判断黑教廷和亡灵大军都在逼近，必须尽快解决战斗。

**关键事件**：1.虎津部署处理方谷 2.虎津得知莫凡出现但暂不理会 3.莫凡进入异土公园 4.柳茹清点埋伏力量 5.战斗被时间与亡灵同时逼迫

**逐章写法公式**：

- **情绪流向**：起：敌方焦躁 → 承：主角进入埋伏 → 转：敌人数量与高阶气息确认 → 合：亡灵逼近，战斗必须速决
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：敌方茶庄部署（交代目标） + 主角进入公园（接近陷阱） + 柳茹清点敌人（量化压力） + 亡灵逼近（压缩时间）
- **本章核心技巧**：先展示敌方低估莫凡，再用侦查结果逐级抬高伏击难度，让战斗在开打前形成清晰压力。
- **卡点与伏笔**：结尾卡点：高阶法师、诅咒畜妖和亡灵大军同时迫近，下一章期待双方正式交锋；埋设/回收伏笔：虎津执事与最后一份昆井之水 → 延续黑教廷夺泉行动。
