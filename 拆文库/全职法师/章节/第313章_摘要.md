# 第313章 血利子

**概要**：莫凡被蒋艺一伙与蜥颅巨妖围困在金林市中心废墟，他认定杀死菁菁、赵明月的蒋艺不可信，以脏话回骂拒绝投降。蒋艺趁机宣讲血利子实验：从寄生生物提取的血脉可改变法师体质，陆年一伙不惜被政府与五大洲协会严禁、猎者联盟通缉也要完成。莫凡讥讽他们为何不自己用，蒋艺承认历次活体全是自愿者但皆失败——要么变成无理智怪物，要么魔能抽干成干尸；血利子按精神级别汲取超过星云上限的能量，天生双系的莫凡是唯一能承受超额抽取的最佳试验品，她称战变后理论上只是修为倒退不会死。莫凡反问她对死掉的人是否也这么说，蒋艺沉默——她自愿做活体实验的弟弟正是死前满眼怨恨。疾星狼赶走巨亡蜥为莫凡争得喘息。

**关键事件**：1.蒋艺宣讲血利子实验理念劝降 2.莫凡得知天生双系的自己是最佳试验品 3.蒋艺回忆弟弟死于活体实验

**逐章写法公式**：

- **情绪流向**：起：紧张（重围对峙）→ 承：压抑（实验真相层层剥开）→ 转：愤怒（莫凡诛心反问）→ 合：悲伤（蒋艺弟弟之死留白）
- **节奏配比**：慢铺垫 50% / 快冲突 20% / 爽点爆发 0% / 悬念留白 30%
- **本章结构公式**：围困对峙（立危机与立场）+ 实验理念宣讲（铺设定）+ 失败案例揭示（加压）+ 弟弟之死留白（埋人性伏笔）
- **本章核心技巧**：让反派用"伟大理念"当传声筒完成设定说明，主角的骂战台词承担打断与批判功能，信息释放不冷场
- **卡点与伏笔**：结尾卡点：压抑悬念型——蒋艺之弟满眼怨恨死去的往事未展开，读者对她与陆年的关系生疑；埋设伏笔：血利子超额抽取星云能量的原理 → 为莫凡日后恶魔化铺垫，"修为倒退不会死亡"的承诺 → 待验证的说法
