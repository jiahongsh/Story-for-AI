# 第635章 张小侯的伪装

**概要**：洪俊见莫凡无视威胁，刺魔具直接刺向张小侯，却只刺中一道风之残影。张小侯现身洪俊身后，斥责他投靠黑教廷，随后用风盘龙卷将洪俊抛到高空，风刃把他解肢成血雾。莫凡也以流星陨和九条烈焰蛟龙烧死蓝衣女执事。战斗结束后，张小侯向莫凡道歉，承认自己一直假装失忆和低智商。为了躲过黑教廷灭口，他在煞渊附近看到黑教廷成员后继续伪装，并在华村中寻找潜伏者，直到莫凡出现。

**关键事件**：1.洪俊刺杀张小侯失败 2.张小侯以风盘龙卷反杀洪俊 3.莫凡击杀蓝衣女执事 4.张小侯承认假装失忆 5.张小侯讲述煞渊见闻与华村自保过程

**逐章写法公式**：

- **情绪流向**：起：人质危机 → 承：张小侯反杀叛徒 → 转：蓝衣女执事被消灭 → 合：伪装真相揭开并引出煞渊线索
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 30% / 悬念留白 20%
- **本章结构公式**：刺杀落空（拆穿挟持） + 风盘龙卷（反杀叛徒） + 烈焰蛟龙（完成主战） + 回溯伪装（抛出新线索）
- **本章核心技巧**：先用动作反转解决即时危机，再用长段回溯把“失忆”改写成主动伪装，完成情感补偿和悬念升级。
- **卡点与伏笔**：结尾卡点：莫凡追问张小侯究竟看到了什么；埋设/回收伏笔：张小侯的呆滞表现 → 回收为重伤后的主动伪装。
