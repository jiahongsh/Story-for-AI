# 第510章 多少钱都不卖！

**概要**：新闻把乐活小镇城山大火定性为陨石意外，莫凡看破赵玉林把消息掩盖成天灾，也算大彻大悟。心夏回校，张小侯、南珏各自回军区，莫凡到明珠塔霍佗处取玄蛇铠魔具。霍佗一眼认出莫凡肩头的小炎姬，当场疯狂开价要买，原来炎姬自带双火、可助三火锻造师霍佗成为四火锻造师问鼎世界。莫凡以开十亿买你孙女反讽拒绝，多少钱都不卖。霍佗死缠烂打无果，白送玄蛇铠魔具、断了加工费念头，又改口要收莫凡为徒学锻造，莫凡拿上魔具转身就走，立志当法王对锻造毫无兴趣。

**关键事件**：1.新闻将灾变定性为陨石意外 2.霍佗认出炎姬疯狂求购 3.莫凡拒卖炎姬、白得玄蛇铠魔具

**逐章写法公式**：

- **情绪流向**：起：尘埃落定的轻松 → 承：取货途中插科打诨 → 转：霍佗认出炎姬的疯狂 → 合：拒卖白拿装备的得意
- **节奏配比**：慢铺垫 30% / 快冲突 10% / 爽点爆发 30% / 悬念留白 30%
- **本章结构公式**：新闻收尾（交代后事） + 各人归位（清场） + 霍佗求购（价值认证） + 拒卖拿甲（爽点落地）
