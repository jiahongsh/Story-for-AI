# 第48章 雷与火！

**概要**：幽狼兽为压焚烧跳入泉池，浑身湿漉漉爬起后绿瞳赫然变赤红——幽狼兽野性难驯，受强刺激极易发狂，此刻对学生便是灭顶之灾。发狂的它死死锁住莫凡，杀气扑面令他浑身僵住；张小侯在必须完成否则莫凡即死的念力下强行连成风轨，从静止到狂奔不足一秒的狼口下抢出莫凡，向洞穴深处疾行，扑空的幽狼兽再爆发追击，撞飞洞中刚爬起的昏迷学生。莫凡选定死胡同般的深处洞窟为战场，张小侯幽幽问引开幽狼兽算不算伟大，莫凡笑骂放屁。幽狼兽喷出飞沙走石，张小侯本可自躲，却一咬牙把莫凡推到高石后，自己被尖石打得千穿百孔血洞赫现。暴怒的莫凡瞳孔布满紫色电光，星子前所未有地团结，雷印蟒痕化作雷电战士轰击缠绕鞭策，电得幽狼兽肌肉发麻、黑色血水狂溢；再连星轨施火滋焚骨，瞳孔由紫转红，心中再无恐惧只剩愤怒与果决。赤瞳幽狼兽满眼不屑——焚骨杀不死它，麻痹一结束就能把眼前人类拦腰啃断。莫凡怒吼看看死得是谁，炙热火焰再度凝聚掌心。

**关键事件**：1.幽狼兽赤瞳发狂锁定莫凡，张小侯风轨狼口夺人 2.张小侯推莫凡避石、自己被尖石打得千穿百孔 3.莫凡怒施雷印蟒痕加火滋焚骨连击，与发狂幽狼兽在死胡同洞窟对决

**逐章写法公式**：

- **情绪流向**：起：赤瞳发狂的窒息 → 承：狼口夺人的狂奔与死胡同绝境 → 转：张小侯挡血的悲壮 → 合：雷火连击与看看死得是谁的燃
- **节奏配比**：慢铺垫 10% / 快冲突 50% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：发狂锁定（立死局）+ 风轨逃生（抢时间）+ 挡石重伤（情感引爆）+ 雷火连击（怒气释放留钩）
- **本章核心技巧**：用救命之恩把主角逼入绝境，再让愤怒接管恐惧完成双系连击，情绪链一气贯通
- **卡点与伏笔**：结尾卡点：决斗型——最后一记焚骨火团凝聚待发，下章期待致命一击与幽狼兽生死；埋设伏笔：焚骨杀不死幽狼兽的判断 → 莫凡仍藏后手；张小侯生死未卜 → 友情线回收
