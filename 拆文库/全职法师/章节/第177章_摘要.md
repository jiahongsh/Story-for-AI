# 第177章 原形毕露！

**概要**：莫凡赶到杰作私家花园，灵灵叉着腰抱怨他来晚了，递给他一台迷你笔记本电脑——画面分成大厅、卧室、厨房、浴室、书房数区、秒数跳动，她早已在那一家里装满了摄像头和监听。两人上楼顶蹲守，灵灵坐在二十多层楼顶的最边沿晃着腿看监控，吓得莫凡出一身汗。监视画面里一切如常：小孩在大厅看喜羊羊，丈夫在书房坐立不安，女人说去洗澡。莫凡想抢着盯浴室画面，被灵灵骂色狼屏蔽掉。将近半小时过去浴室还传来水声，灵灵忽然锁眉起疑：今天早上哭花了眼的女人，哪有心思化妆、还兴致勃勃洗半个多小时的澡。她调出画面——浴室里挂着的不是洗澡的女人，而是一张湿漉漉头发的人皮。灵灵断定这东西像蛇一样蜕皮行凶，它不是鬼是活人，那女人此刻多半就在本小区行凶，且此物喜欢吸年轻女人的血、对魔法师兴趣更大。两人分工：灵灵守着孩子，莫凡下楼揪出真面目的女人。莫凡双手一撑从楼顶边沿跳下，坠入楼体下半段阴影时整个人消失，灵灵惊讶地认出他是暗影系——这招跳楼遁影是唐月所教，靠楼房光暗差完成坠落遁影。

**关键事件**：1.灵灵的全程监控揭底 2.人皮现形、蜕皮行凶定论 3.分工：守孩子与追女妖 4.莫凡跳楼遁影亮出暗影系

**逐章写法公式**：

- **情绪流向**：起：轻松（天台蹲守的斗嘴） → 承：紧张（洗澡破绽的推理） → 转：恐怖（人皮现形） → 合：热血（跳楼遁影的追击）
- **节奏配比**：慢铺垫 40% / 快冲突 20% / 爽点爆发 20% / 悬念留白 20%
- **本章结构公式**：监控接管（情报优势） + 天台蹲守（日常降温） + 破绽推理（疑点收束） + 人皮与分工（惊悚爆发）
- **本章核心技巧**：把恐怖揭底挂在一条生活逻辑链（哭花眼的女人不会化妆泡澡半小时）上，惊悚感由推理驱动而非血浆堆砌。
- **卡点与伏笔**：结尾卡点：女妖正在小区行凶、莫凡独自追击，下章期待猎物是谁；埋设/回收伏笔：灵灵的黑客级监控→猎人大师含金量；吸年轻女人的血、魔法师更佳→三个女大学生猎物的铺垫；跳楼遁影是唐月所教→回收师承线并成为莫凡招牌机动技。
