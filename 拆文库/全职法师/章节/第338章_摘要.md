# 第338章 完美计划

**概要**：莫凡确认泥沼湖中心的巨物是不带翅膀、块头比巨蜥伪龙大许多的巨蜥。离曼探谷带回坏消息：两队猎法师即将进谷，她堵死东面入口也只能拖延一两天，加上武壳巨蜥伤势渐愈，莫凡拍板次日动手。篝火旁他用树枝画图定计：武壳巨蜥重伤仍具秒杀中阶法师的战力且智商极高，曾让一队准备齐全的猎法师顷刻全军覆没，硬拼毫无胜算；但谷中还栖息着一只毒性可让统领级虚弱的变态毒虫，计划是把毒虫引到武壳巨蜥处让两者相残，再借毒性收拾残局。引毒虫的危险任务因莫凡离曼都缺位移本领，落在风土双修、受过军方追踪隐匿训练的张小侯头上。针对前后夹击的死局，莫凡亮出后手：汇合点下方岩层脆弱，干涸地下河谷贯穿谷底，轰开湖底即可乘漩涡遁入地下金蝉脱壳。计划敲定，只剩一个问题——武壳巨蜥由谁去引。

**关键事件**：1.猎法师将入谷迫使行动提前到次日 2.定下毒虫与巨蜥相残的借刀杀人计划，张小侯领引虫任务 3.金蝉脱壳路线敲定，章末留下谁引巨蜥的悬念

**逐章写法公式**：

- **情绪流向**：起：敌情加压 → 承：定计的兴奋与吐槽 → 转：夹击死局的慌张 → 合：金蝉脱壳揭底加悬念收口
- **节奏配比**：慢铺垫 40% / 快冲突 5% / 爽点爆发 15% / 悬念留白 40%
- **本章结构公式**：敌情（逼行动提前）+ 画图定计（立借刀杀人框架）+ 挑人选（喜剧化分派）+ 补漏洞（地下河谷后手）+ 留问（谁引巨蜥）
- **本章核心技巧**：把作战会议写成问答闯关，每抛一个漏洞就补一个后手，用配角发问代替读者质疑
- **卡点与伏笔**：结尾卡点：问题式卡点，武壳巨蜥谁去引未揭晓；埋设伏笔：毒虫真实形态未露面 → 下章登场反差；地下岩层脆弱点 → 漩涡逃生与土系灵种伏笔
