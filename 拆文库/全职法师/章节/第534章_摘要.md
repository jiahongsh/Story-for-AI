# 第534章 泼骂！

**概要**：丁雨眠带莫凡赶到比赛场时，艾图图已冒用他的身份上场，四人队伍一个不少。艾图图先因魔藤束缚落空而受制，后为救被围困的顾剑施放光耀失明，却同时令顾剑看不见敌人；顾剑随即被冰霜锁链击飞，铠魔具破碎，十一队再次落败。白宇郎嘲笑顾剑后，顾剑把两场败局的怒火尽数倾泻到艾图图身上，艾图图哭着逃离时撞见莫凡，并被他抱住。

**关键事件**：1.莫凡到场发现艾图图正在冒名参赛。 2.艾图图施法误伤顾剑，十一队第二场失利。 3.顾剑辱骂艾图图，莫凡在她逃离时出现。

**逐章写法公式**：

- **情绪流向**：起：错愕与看热闹 → 承：比赛受制的紧张 → 转：败局与辱骂的压抑 → 合：莫凡接住艾图图的温馨
- **节奏配比**：慢铺垫 15% / 快冲突 45% / 爽点爆发 0% / 悬念留白 40%
- **本章结构公式**：莫凡到场发现替身（确认危机） + 艾图图救援失误（战局崩盘） + 顾剑公开泼骂（情绪爆发） + 莫凡抱住逃离者（关系卡点）
- **本章核心技巧**：用一次敌我不分的施法失误把战斗失败和人物冲突合并推进，再在最低点切入关系动作。
- **卡点与伏笔**：结尾卡点：关系钩子，艾图图担心莫凡也会责骂自己；埋设/回收伏笔：艾图图冒名参加提名赛 → 莫凡在其崩溃后当面发现真相。
