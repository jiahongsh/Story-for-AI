# 第328章 逼婚

**概要**：穆卓云向女儿转述经过：莫凡舍身把巨蜥伪龙引出与陆年拼得两败俱伤，四人才获救；莫家兴曾来探望并谢绝了穆卓云给的高薪职位。穆宁雪确认莫凡死讯出自不可能说谎的斩空之口，回忆起教堂里莫凡对自己说的话，无法验证真假便成了遗言，一点期待彻底烟消云散。穆卓云叮嘱她一年内别再用冰晶刹弓，穆家在帝都穆氏世族下寄人篱下，全靠她撑住。穆卓云刚出房便接待上门的周家父子：周有宏对穆宁雪垂涎已久，其父先以"非亲非故、须守世家规矩"挡回穆卓云想谈的异骨渠道生意，周有宏随即挑明尽快办婚事——成婚周家才有理由全力相助，才能拿出库里名贵天灵药材给宁雪调理，宁雪在内校也需周家支持否则天赋优势很快被甩远。穆卓云明知婚事能让濒临破产的小家族复苏，却因莫凡刚为女儿舍命而无法立刻点头，只能以养伤拖延；周家父子留下"过阵子再来"的话离去。送客后穆卓云独白点破家族、世家、世族三层之别：他和穆贺在世族中形同高级佣人，唯有依靠年轻一辈才有抬头之日。

**关键事件**：1.穆宁雪确认莫凡死讯，遗言成空 2.周家父子上门以援助为条件逼婚 3.穆卓云拖延未允，独白家族困境

**逐章写法公式**：

- **情绪流向**：起：悲伤（死讯确认、遗言成空）→ 承：温馨（父女叮嘱休养）→ 转：紧张（周家上门开价逼婚）→ 合：压抑（送客独白，寄人篱下的家族困境）
- **节奏配比**：慢铺垫 35% / 快冲突 20% / 爽点爆发 0% / 悬念留白 45%
- **本章结构公式**：转述救援真相（确认牺牲）+ 死讯与遗言回忆（感情线收痛）+ 禁弓叮嘱（埋战力封印）+ 周家上门三重开价（危机具象化）+ 父亲拖延（道德两难）+ 送客独白（世界观等级落地）
- **本章核心技巧**：主角缺席章用"施恩者尸骨未寒+逼婚者趁虚而入"的时间差制造道德挤压，让读者替缺席主角憋一股火。
- **卡点与伏笔**：结尾卡点：困境卡点——周家过阵子再来逼婚，家族存亡压在穆宁雪婚事上，期待后续变数；埋设伏笔：教堂告白成为遗言 → 感情线悬而未决；一年内禁用冰晶刹弓 → 女主战力封印；莫家兴谢绝职位 → 莫家后续线。
