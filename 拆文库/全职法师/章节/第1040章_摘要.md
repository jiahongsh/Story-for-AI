# 第1040章 碾压，以一敌四！

**概要**：莫凡摆手制止赵满延江昱蒋少絮相助，称此事自己能处理，怕牵连他们背后家族。他迎向四人，火焰却被穆婷颖魂种冰霜压制，反倒附上冰霜。莫凡嘲祖吉明黎凯风为废物，四人联手试探：祖吉明毒牙刺背，黎凯风暗影藏击，南荣倪祝福加持，莫凡以空间之墙轻松化解并嘲讽。旋即莫凡掐灭火种仰天爆吼，暴君荒雷领域展开，苍黑雷弧横扫将凌霄冰霜尽数粉碎，穆婷颖惊觉对方竟是拥有领域的雷系魂种。苍雷爪一击打散四人，第二爪袭祖吉明撕碎防御，祖吉明逃却被暴君制裁轰倒焦黑；黎凯风欲用禁术，被雷电爪抽飞，困于重力空间，寂雷死光直取。

**关键事件**：1.莫凡独战四人，遣回同伴免牵连 2.空间之墙化解四人试探 3.暴君荒雷领域压制魂冰 4.苍雷爪重创祖吉明、压制黎凯风

- **情绪流向**：起：独战宣言的孤勇 → 承：四人试探被化解的从容 → 转：雷域展开的反压高潮 → 合：重创二人的碾压余势
- **节奏配比**：慢铺垫 15% / 快冲突 50% / 爽点爆发 30% / 悬念留白 5%
- **本章结构公式**：遣回同伴（护友） + 空间化解（试探） + 雷域反压（高潮） + 苍雷重创（碾压）
