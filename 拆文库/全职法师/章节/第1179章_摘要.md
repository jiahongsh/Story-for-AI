# 第1179章 颤栗雅典城（下）

**概要**：伊之纱从叶棺中苏醒，在帕特农神庙与殿母对峙，以蔑视姿态宣称要取回本属于自己的帕特农神魂，贬低持有神魂的叶心夏没有远见与胆魄，并将黑教廷渗透之责推给殿母，暗示其应当退位安养天年。殿母深知整场阴谋中支持伊之纱者众多、连圣裁院都已被其掌控，无可奈何。伊之纱俯瞰雅典城，将能抗衡骸旯的恶魔莫凡视为必须铲除的威胁。与此同时，莫凡以雷枪击穿骸旯胸膛，但黑暗不死虫不断再生并飞出黑色光幕，啃噬城区建筑与神山信徒，将活人化为白骨。殿母质问伊之纱，伊之纱冷血表示神魂到手前斗争不会停止，随后组织骑士殿与裁决殿成员组建抵抗不死虫的队伍。

**关键事件**：1.伊之纱苏醒与殿母对峙，宣称取回神魂并贬低叶心夏 2.伊之纱暗示殿母退位，殿母无力反抗 3.莫凡击穿骸旯但黑暗不死虫外溢啃噬城市与神山，信徒化为白骨 4.殿母组织骑士殿裁决殿抵抗不死虫

**逐章写法公式**：

- **情绪流向**：起：伊之纱苏醒的压迫感 → 承：逼宫与权力碾压的压抑 → 转：城市被不死虫啃噬的恐怖 → 合：殿母被迫组织抵抗的悬而未决
- **节奏配比**：慢铺垫 40% / 快冲突 30% / 爽点爆发 10% / 悬念留白 20%
- **本章结构公式**：伊之纱醒来说理逼宫（树立反派） + 俯瞰定下铲除莫凡之心（埋危机） + 莫凡战骸旯不死虫外溢（灾难升级） + 殿母组织抵抗（钩子）
- **本章核心技巧**：用反派与配角的对话反推其掌控全局的权力，再用市民受难的具体镜头放大危机规模。
- **卡点与伏笔**：结尾卡点：殿母率队抵抗不死虫，城市仍危；埋设/回收伏笔：伊之纱对恶魔莫凡的杀意 → 后续审判与冲突伏笔。
